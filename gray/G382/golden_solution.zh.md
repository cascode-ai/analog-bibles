$Z_{id}$ 是一个约 0.77 pF 的电容，$Z_{ic}$ 是一个约 65 fF 的电容（若在共模半边电路中忽略 $r_{o1}$，则 ≈ 61 fF）。
- T 形网络：每个串联元件 $Z_{id}/2$ 是 1.53-pF 电容；并联元件 $Z_{ic}/2 - Z_{id}/4$ 是约 137 fF 的电容（采用近似的 $C_{ich}$ 时 ≈ 128 fF）。
- π 形网络：每个并联元件 $Z_{ic}$ 约为 65 fF；跨接元件 $Z_{id}\|(-2Z_{ic})$ 是约 0.73–0.74 pF 的电容。

推导（$g_{m1} = 1$ mA/V，$r_{o1} = 100$ kΩ，$r_{o3} = 200$ kΩ，$r_{o5h} = 100$ kΩ，由半边电路（half circuit）得差模增益 $a_{dm} = -66.7$，共模增益 $a_{cm} = -25/13 = -1.92$）：
- 差模半边电路：源极为交流地，栅极到漏极的增益为 −66.7。$C_{idh} = C_{gs} + C_{gd}(1 - a_{dm}) = 180 + 20(67.7) = 1533$ fF。半边电路看到的是 $Z_{id}/2 = 1/(sC_{idh})$，因此 $Z_{id}$ 对应 $C_{idh}/2 = 0.767$ pF。
- 共模半边电路（栅极接 $v_{ic}$，源极经 $r_{o5h}$ 接地，漏极负载为 $r_{o3}$，保留 $r_{o1}$）：漏极电流与源极电流相等，因此 $v_s = -v_{oc}\,r_{o5h}/r_{o3} = -v_{oc}/2$，对源极列 KCL 得 $v_s/v_{ic} = 25/26 = 0.962$，$v_{oc}/v_{ic} = -25/13 = -1.92$。于是 $C_{ich} = C_{gs}(1 - 25/26) + C_{gd}(1 + 25/13) = 6.9 + 58.5 = 65.4$ fF，$Z_{ic} = 1/(sC_{ich})$。（若忽略 $r_{o1}$：$v_s/v_{ic} = g_{m1}r_{o5h}/(1 + g_{m1}r_{o5h}) \approx 0.99$，增益 ≈ −1.98，$C_{ich} \approx 1.8 + 59.6 \approx 61$ fF。）
- T 形网络并联元件：$1/C = 1/(2C_{ich}) - 1/(2C_{idh})$ → $C = 1/(1/130.8\ \text{fF} - 1/3067\ \text{fF}) \approx 137$ fF（$C_{ich} = 61$ fF 时 ≈ 128 fF）。
- π 形网络跨接元件：$C = C_{idh}/2 - C_{ich}/2 = 767 - 33 \approx 734$ fF（$C_{ich} = 61$ fF 时 ≈ 736 fF）。
