# Golden Solution - G287

## Reference answer

(1) $T \approx 65.9$; (2) $T \approx 26.0$; (3) $\mathcal{R} \approx 35.1$ for both circuits. The two-port loop gains depend on the feedback type assumed and on how the source is connected; the return ratio does not.

- (1) h parameters: $a = 1000\cdot\frac{50}{116.7}\cdot\frac{300}{1300} = 98.9$, $f = 2/3$ → 65.9.
- (2) y parameters: $a = -(R_1\|R_2\|R_i)\,a_v\,\frac{R_2}{R_2+R_o} = -2.60$ MΩ, $f = -1/R_2$ → 26.0.
- (3) $\mathcal{R} = a_v\,\frac{R_1\|R_i}{R_o + R_2 + R_1\|R_i} = 35.1$.
- Why: two-port analysis splits the circuit into a unilateral basic amplifier and a feedback network using a representation chosen by the feedback type (h for series-shunt, y for shunt-shunt); the loading terms (other port shorted or opened) and the placement of the input source differ, so $a$ and $f$ — and hence $T$ — are different numbers for the same loop. The h/y representations themselves are exact; the difference comes from the split: the two-port $T$ takes "no feedback" as $h_{12f} = 0$ (or $y_{12f} = 0$) with the port loads fixed at their open/short-circuit values, whereas the return ratio takes it as $a_v = 0$, keeping the feedback network's bilateral coupling, so $\mathcal R = -h_{21a}h_{12f}/(h_{11}h_{22} - h_{21f}h_{12f})$ (and likewise in y). Neglecting the feed-forward $h_{21f}$, $y_{21f}$ in $a$ is not the cause: keeping it gives 66.8 and 25.7, about 1% from 65.9 and 26.0. Physically, the op-amp output ($R_o$) sees $R_1+R_2 = 300$ kΩ in the h split, $R_2 = 100$ kΩ in the y split, but the true $R_2 + R_1\|R_i = 140$ kΩ in the return ratio. The return ratio is defined for one controlled source with all independent sources zeroed, so it is unique for a given circuit (the two circuits become identical when $V_i$ is shorted and $I_i$ opened). The ratios $T_h/\mathcal R = 171/91 \approx 1.88$ and $T_y/\mathcal R = 57/77 \approx 0.74$ do not depend on $a_v$; they are large here because $R_o$ is large compared with the feedback resistors and $R_i$ is comparable to them (with $R_o \to 0$ all three become 285.7); nevertheless the closed-loop gains agree closely with the exact values (e.g., series-shunt: $a/(1+T) = 1.4776$ vs exact 1.4779 from $A_\infty\mathcal R/(1+\mathcal R) + d/(1+\mathcal R)$ with $d = 0.70$).
