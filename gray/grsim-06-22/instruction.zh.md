对于 [图 1] 所示的带有源共源共栅（active cascode）的折叠式共源共栅（folded cascode）运放（辅助放大器 $A_1$ 如 [图 2]，$A_2$ 如 [图 3]，偏置电路如 [图 4]），选择器件尺寸，使峰峰值输出摆幅（output swing）至少为 2.5 V。采用 0.4-μm CMOS 参数 $\mu_nC_{ox} = 194\ \mu\mathrm{A/V^2}$，$\mu_pC_{ox} = 64.7\ \mu\mathrm{A/V^2}$，$L_d = 0.09\ \mu$m，$dX_d/dV_{DS} = 0.02\ \mu$m/V（n 沟道）和 0.04 μm/V（p 沟道），但所有晶体管取 $\gamma = 0.25\ \mathrm{V^{1/2}}$ 和 $X_d = 0$，n 沟道和 p 沟道晶体管分别取 $V_{t0} = 0.7$ V 和 $-0.7$ V。为简化设计，假设所有晶体管都采用画出的沟道长度 $L = 1\ \mu$m。取 $I_{BIAS} = 25\ \mu$A，偏置电流应为 $|I_{D5}| = I_{D11} = I_{D12} = I_{D25} = |I_{D35}| = 200\ \mu$A。假设 $V_{DD} = V_{SS} = 1.65$ V，且匹配是理想的。当直流输入电压 $V_I = 0$ 时，假设除 $M_{106}$ 和 $M_{114}$ 以外的所有晶体管都工作在有源区（active region），且过驱动电压（overdrive voltage）的幅值相等。为了使增益对工作点的小幅漂移不敏感，设计电路时应使每个工作在有源区的晶体管的漏源电压幅值比其过驱动电压幅值至少大 100 mV。手算时忽略体效应（body effect）。用 SPICE 验证你的设计，选择 $M_{106}$ 和 $M_{114}$ 的宽度，并求出增益。另外，用 SPICE 求出 n 沟道晶体管 $V_{t0} = 0.6$ V、p 沟道晶体管 $V_{t0} = -0.8$ V 时的增益，并解释运放增益由此产生的变化。
