A shunt-series feedback amplifier is modeled as follows. The basic amplifier has input impedance $z_i$ and a Norton output: a controlled current source $a\,i_\epsilon$ in parallel with an output impedance $z_o$, where $i_\epsilon$ is the current flowing into the basic-amplifier input and $a$ is a dimensionless current gain. The feedback network is ideal and unilateral: it senses the output current $i_o$ in series with the output (it adds zero impedance in the output loop) and feeds back a current $i_{fb} = f\,i_o$ in shunt with the input (it presents infinite impedance across the input), so that $i_\epsilon = i_i - f\,i_o$, where $i_i$ is the input signal current from an ideal current source. The basic amplifier transmits only forward. Let $T = af$. Show that the closed-loop current gain (with the output port short-circuited), the input impedance and the output impedance are
$$\frac{i_o}{i_i} = \frac{a}{1+af},\qquad Z_i = \frac{z_i}{1+T},\qquad Z_o = z_o(1+T).$$
