A technique that allows the return ratio to be simulated using SPICE without disrupting the dc operating point is the following. Choose a point X in the feedback loop where the signal flows from one side (the "return" side, toward the amplifier output) to the other (the "driven" side, toward the amplifier input). (i) Inject an ac test current $i_t$ from ground into node X; with $i_d$ the current flowing from X into the driven side and $i_m$ the current flowing from the return side into X, compute $\mathscr{R}'_i = -i_m/i_d$. (ii) Instead, insert an ac test voltage source $v_t$ in series at X (+ terminal on the driven side); with $v_d$ the voltage of the driven side and $v_m$ the voltage of the return side (both to ground), compute $\mathscr{R}'_v = -v_m/v_d$. The return ratio for the controlled source is then given by $\dfrac{1}{1 + \mathscr{R}} = \dfrac{1}{1 + \mathscr{R}'_i} + \dfrac{1}{1 + \mathscr{R}'_v}$.
Apply this to the CMOS op amp of [Fig. 1] (supplies ±5 V, bias 20 μA, $C_c$ = 5 pF, gate of $M_9$ at the positive supply with $M_9$ sized so that its on-resistance equals $1/g_{m6}$, cancelling the right half-plane zero), connected in a noninverting unity-gain configuration (output tied to the gate of $M_1$, input at the gate of $M_2$).
(a) Use the technique to simulate the return ratio at frequencies of 1 kHz, 100 kHz, 10 MHz, and 1 GHz.
(b) Use the technique to plot the magnitude and phase of the return ratio. Determine the unity-gain frequency of the return ratio and the phase and gain margins. (This requires combining the complex values of $\mathscr{R}'_i(j\omega)$ and $\mathscr{R}'_v(j\omega)$ to find the complex quantity $\mathscr{R}(j\omega)$.)
