[图 1] 所示为一个达林顿级（Darlington stage）的交流电路图（ac schematic），其中 $Q_1$ 和 $Q_2$ 的集电极连在一起作为输出，$Q_1$ 的发射极驱动 $Q_2$ 的基极；$R_S = 100\ \mathrm{k\Omega}$，$R_L = 3\ \mathrm{k\Omega}$。用零值时间常数法（zero-value time-constant method）计算电压增益 $v_o/v_i$ 的 −3-dB 频率。参数：$\beta = 100$，$f_T = 500$ MHz（$I_C = 1$ mA 时），$C_\mu = 0.4$ pF，$C_{je} = 2$ pF，$C_{cs} = 1$ pF（集电极到交流地），$r_b = 0$，$r_o = \infty$，$I_{C1} = 10\ \mu$A，$I_{C2} = 1$ mA，$V_T = 26$ mV；$C_\mu$、$C_{cs}$ 和 $C_{je}$ 均为偏置点处的值，且两管相同。采用 $C_\pi = \tau_Fg_m + C_{je}$，其中正向渡越时间（forward transit time）$\tau_F$ 由 $f_T$ 求得（$\omega_T = g_m/(C_\pi + C_\mu)$）。
