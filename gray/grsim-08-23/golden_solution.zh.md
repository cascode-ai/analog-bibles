- 偏置：$M_2$ 与 $R_1$：$300\ \mu(V_{SG2} - 0.8)^2 = (5 - V_{SG2})/10\text{k}$ → $V_{SG2} = 1.83$ V，$I = 317$ μA。$M_3$、$M_5$ 对其镜像（$W/L$ 相同，$\lambda = 0$）：$I_{D3} = I_{D5} = 317$ μA，因此 $I_{D1} = I_{D6} = 317$ μA；$M_4$ 的 $V_{DS} = 0$（$V_{GD6} = 0$ 意味着 $M_1$ 的漏极电压等于 $V_o$），不流过直流电流。$V_{GS6} = V_{GS1} = 0.8 + \sqrt{317/600} = 1.53$ V，因此 $V_o = V_i = 1.53$ V。
- $M_4$ 是工作在 $V_{DS} = 0$ 的线性区（triode region）电阻：$R_4 = 1/[\mu_nC_{ox}(W/L)_4(V_{GS4} - V_{t4})]$，计入体效应（body effect）后 $V_{t4} = 0.8 + 0.5(\sqrt{0.6 + 1.53} - \sqrt{0.6}) = 1.14$ V。$V_c = 3$ V：$V_{GS4} - V_{t4} = 0.33$ V，$R_4 = 20.1$ kΩ。$V_c = 4$ V：1.33 V，$R_4 = 5.0$ kΩ。
- 小信号（$g_{m1} = g_{m6} = 2I/V_{ov} = 0.872$ mS）：节点方程给出 $v_o/v_i = g_{m1}(R_4 - 1/g_{m6}) = g_{m1}R_4 - 1$（同相）：$V_c = 3$ V 时约 16.6，$V_c = 4$ V 时约 3.4。输出电阻 $= 1/g_{m6} \approx 1.15$ kΩ，与 $V_c$ 无关（输入短路时，$M_6$ 的栅极经 $M_4$ 跟随输出）。
- 大信号：$V_i$ 远低于 1.5 V 时 $V_o$ 很低（约 0.1–0.2 V，$M_6$ 被强驱动）；经过工作点 $V_i = V_o = 1.53$ V 时以约 16.6（$V_c = 3$ V）或约 3.4（$V_c = 4$ V）的斜率上升；随后出现峰值：$V_i$ 更大时 $M_6$ 截止，$M_5$ 的电流必须经 $M_4$ 和 $M_1$ 流走。$V_c = 3$ V 时 $M_4$ 在低于 317 μA 时就饱和，因此 $M_5$ 进入线性区，$V_o$ 保持在高电平（峰值约 4.8 V，在 $V_i = 3$ V 时缓慢降到约 4.4 V）。$V_c = 4$ V 时 $M_4$ 在线性区就能流过全部电流，因此输出在 $V_i \approx 1.8$ V 附近达到约 4.2 V 的峰值后，又回落到 $V_i = 3$ V 时的约 1.1 V（非单调）。增益较高的设置其线性输入范围较窄。
