两种选择给出相同的精确结果 $R_{out} = r_{o1} + r_{o2} + (1+a)g_{m2}r_{o1}r_{o2} \approx a\,g_{m2}r_{o1}r_{o2}$；不同的只是如何拆分为“$R(k{=}0)$”和回归比（return ratio）。（结果中不出现 $g_{m1}$：$M_1$ 的栅极由 $M_3$–$R$ 偏置支路保持在交流地，$M_1$ 只相当于电阻 $r_{o1}$。由于 $M_1$ 与 $M_2$ 流过相同的漏极电流，且 $(W/L)_1 = (W/L)_2$、$\gamma = 0$，有 $g_{m1} = g_{m2}$，所以结果也可以写成用 $g_{m1}$ 表示的形式。）

- 取 $k = g_{m2}$：$R(g_{m2}{=}0) = r_{o1}+r_{o2}$，$\mathcal{R}_{sc} = (1+a)g_{m2}(r_{o1}\|r_{o2})$，$\mathcal{R}_{oc} = 0$。此时“开环”电阻很小，全部倍增作用（局部共源共栅作用和运放环路）都集中在一个很大的回归比中。
- 取 $k = a$：$R(a{=}0) = r_{o1}+r_{o2}+g_{m2}r_{o1}r_{o2}$（普通共源共栅，已经包含 $M_2$ 的局部反馈），$\mathcal{R}_{sc} = a\,g_{m2}(r_{o1}\|r_{o2})/[1+g_{m2}(r_{o1}\|r_{o2})] \approx a$，$\mathcal{R}_{oc} = 0$。
- 两个乘积相同，因为布莱克曼公式对任何受控源都是精确的；回归比取决于所选的受控源，但闭环阻抗与此无关。两种情形下端口开路的回归比都为零，因此反馈使电阻增大到 $1+\mathcal{R}_{sc}$ 倍；有源共源共栅的输出电阻约为普通共源共栅的 $a$ 倍。
