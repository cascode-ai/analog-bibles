$I_{\text{out}} = I_{EE}\tanh\!\left(\dfrac{V_1}{2V_T}\right)\tanh\!\left(\dfrac{V_2}{2V_T}\right)$，因此对每个 $V_1$，随 $V_2$ 变化的曲线都是形状相同的 tanh 曲线，关于原点奇对称，并按 $\tanh(V_1/2V_T)$ 缩放：
- $V_1 = 0.1V_T$：$\tanh(0.05) = 0.050$；极限值 $\pm 0.050\,I_{EE}$，原点处斜率 $0.025\,I_{EE}/V_T$。
- $V_1 = 0.5V_T$：$\tanh(0.25) = 0.245$；极限值 $\pm 0.245\,I_{EE}$，斜率 $0.122\,I_{EE}/V_T$。
- $V_1 = V_T$：$\tanh(0.5) = 0.462$；极限值 $\pm 0.462\,I_{EE}$，斜率 $0.231\,I_{EE}/V_T$。
- 每条曲线在 $|V_2| \lesssim V_T$ 内近似线性，在 $V_2 = V_T$ 处达到其极限值的 46%，在 $2V_T$ 处达到 76%，在 $4V_T$ 处达到 96%，超过约 $\pm 4V_T$ 后变平（饱和）。$I_{\text{out}}$ 与 $V_1V_2$ 同号（按图中所标极性，$V_1, V_2 > 0$ 时为正）。
- 饱和电平之比为 1 : 4.9 : 9.2，而不是 1 : 5 : 10：因为在 $V_1 = V_T$ 时，$V_1$ 输入本身已被 tanh 压缩。

推导：下面的差分对给出 $I_{c1} - I_{c2} = I_{EE}\tanh(V_2/2V_T)$。$V_1$ 的 + 端驱动 $Q_3$ 和 $Q_6$ 的基极，因此 $I_{c3} - I_{c4} = I_{c1}\tanh(V_1/2V_T)$，$I_{c6} - I_{c5} = I_{c2}\tanh(V_1/2V_T)$。于是 $I_{\text{out}} = (I_{c3} + I_{c5}) - (I_{c4} + I_{c6}) = (I_{c1} - I_{c2})\tanh(V_1/2V_T)$。
