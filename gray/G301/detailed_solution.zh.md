# 详细步骤 - G301

第二级输入端的并联电容只会降低主极点；与密勒补偿不同，它不会把 500 kHz 极点分裂开。因此 500 kHz 和 10 MHz 两个极点都留在环路中，共同决定了与 $60^\circ$ 裕度相容的最高单位增益频率。再把主极点放在使交点恰好落在该处的位置，由节点电阻求出电容。

### 第 1 步 — $60^\circ$ 裕度下的单位增益频率

单位增益反馈时 $T=a$。在远高于主极点的交点 $f_u$ 处，主极点贡献 $-90^\circ$，因此两个次极点只能共贡献 $30^\circ$：
$$
\tan^{-1}\frac{f_u}{500\ \mathrm{kHz}}+\tan^{-1}\frac{f_u}{10\ \mathrm{MHz}}=30^\circ .
$$
数值求解得 $f_u=271$ kHz（500 kHz 极点贡献 $28.4^\circ$，10 MHz 极点贡献 $1.6^\circ$）。

### 第 2 步 — 主极点

$a_0=10^{108/20}=2.51\times10^5$，500 kHz 以下以 $-20$ dB/dec 滚降，渐近增益为 $|a|=a_0|p_1|/f$。令其在 $f_u$ 处等于单位值：
$$
\frac{|p_1|}{2\pi}=\frac{f_u}{a_0}=\frac{271\ \mathrm{kHz}}{2.51\times10^5}=1.08\ \mathrm{Hz}.
$$

### 第 3 步 — 并联电容

主极点是第二级输入节点的 $RC$ 极点，$|p_1|=1/(R_1C)$，$R_1=1.95\ \mathrm{M\Omega}$。（原来的 30 kHz 极点在该节点只对应 $1/(2\pi\times30\ \mathrm{kHz}\times1.95\ \mathrm{M\Omega})=2.7$ pF，与外加电容相比可以忽略。）因此
$$
C=\frac{1}{2\pi(1.08\ \mathrm{Hz})(1.95\ \mathrm{M\Omega})}=76\ \mathrm{nF},
$$
在这一渐近设计中，开环增益约在 **270 kHz** 处降到 0 dB。

### 第 4 步 — 精确校验与比较

在 271 kHz 处，次极点使 $|a|$ 降低 $\sqrt{(1+0.542^2)(1+0.027^2)}=1.14$ 倍。因此取 76 nF 时真实的 0 dB 频率更低，为 245 kHz，$\mathrm{PM}\approx63^\circ$。若要求恰在 271 kHz 处 $|a|=1$，主极点应升高到 $1.08\times1.14=1.23$ Hz，得 $C=76\ \mathrm{nF}/1.14=67$ nF，此时在 271 kHz 处 $\mathrm{PM}=60^\circ$。

与同一放大器的密勒补偿（约 6 pF，0 dB 约在 5.8 MHz）相比，由于 500 kHz 极点仍在环路中，带宽约低 20 倍；并联电容则大四个数量级：它没有密勒倍增 $g_mR_2\approx550$，而且还必须产生低 20 倍的主极点。结果：$C\approx76$ nF（精确设计为 67 nF），0 dB 频率约为 270 kHz。
