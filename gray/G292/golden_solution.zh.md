$A_0 = 200$：PM ≈ 36°；$A_0 = 100$：PM ≈ 23°。

- $A_0 = 200$：$T_0 = 199$；$|T| = 1$ 出现在 ≈ 249 kHz 处；相位 $= -89.5° - 51.2° - 3.6° = -144.3°$ → PM ≈ 35.7°。
- $A_0 = 100$：$T_0 = 399$；$|T| = 1$ 出现在 ≈ 374 kHz 处；相位 $= -89.7° - 61.9° - 5.3° = -156.9°$ → PM ≈ 23.1°。
- 趋势：反馈越深（闭环增益越小），穿越频率越向 200 kHz 极点靠近并越过它，相位裕度随之下降。（若在 200 kHz 以上采用 −40 dB/dec 渐近线，穿越频率 ≈ 282 kHz 和 400 kHz，得到 PM ≈ 31° 和 21°。）
