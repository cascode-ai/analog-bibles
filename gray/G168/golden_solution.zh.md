有效的理由（任选三条，每条都需说明原因）：
1. 跨导更高：电子迁移率约为空穴迁移率的 2–3 倍，因此在电流和 $W/L$ 相同时，n 沟道对管的 $g_{m1}$ 更大（$\propto\sqrt{\mu}$）。这提高了第一级增益 $g_{m1}(r_{o2}\parallel r_{o4})$ 和增益带宽积（gain-bandwidth product）$g_{m1}/C_C$。或者，可以用电容更小的较小器件获得相同的 $g_m$，从而提高速度。
2. 由负载引起的输入失调较低：电流镜失配的贡献为 $(g_{m3}/g_{m1})\Delta V_{t3,4}$。采用 n 沟道输入对管和 p 沟道电流镜时，该比值为 $\sqrt{\mu_p/\mu_n} < 1$（而不是 $\sqrt{\mu_n/\mu_p} > 1$），在尺寸和电流相同时约低 3 倍。
3. 在给定偏置电流和相同 $W/L$（强反型）下，输入参考热噪声（白噪声）较低，因为热噪声电压 $\propto 1/\sqrt{g_m}$，而 n 沟道对管的 $g_m$ 较大；等价地，可以用较小的输入器件或较小的电流达到给定的白噪声指标。
4. 输入共模范围（input common-mode range）向正电源方向移动：n 沟道输入级在 $V_{IC}$ 约从 $-V_{SS} + V_t + 2V_{ov}$ 到 $V_{DD} - |V_{GS3}| + V_t$（考虑体效应时可能更高）的范围内工作。当输入信号接近 $V_{DD}$ 时（例如高端检测）应选择它。
5. 工艺/阱的考虑：在 p 阱工艺中，只有 n 沟道器件可以放在各自的阱中并将源极接衬底。这消除了体效应以及经由衬底的电源电容耦合（在开关电容电路中 PSRR 更好），因此在这种工艺中，能获得这些好处的是 n 沟道输入。（在三阱工艺中两种极性的器件都可以隔离，因此这在该工艺中并不是 n 沟道独有的优点。）
6. 电源抑制：在常规的互补连接中，尾电流源和第二级负载所参考的那个电源会得到抵消效果（在偏置匹配且比例恰当时，低频 PSRR 非常高）；采用 n 沟道输入时，这个电源是负电源。若负电源噪声较大，应选择它。
（一个已知的缺点，而非理由：p 沟道器件的 1/f 噪声通常较低；而且在常规的直接耦合拓扑中，n 沟道输入第一级的输出位于 $V_{DD} - |V_{GS3}|$，与 p 沟道驱动管的 $V_{SG}$ 相匹配，因此第二级驱动管变成 $g_m$ 较低的 p 沟道器件，使次极点降低。反之，带 n 沟道电流镜的 p 沟道输入对管自然驱动 n 沟道第二级。）
