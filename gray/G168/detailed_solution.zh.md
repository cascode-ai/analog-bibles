# 详细步骤 - G168

在常规的互补连接中比较两种极性：n 沟道输入对管配 p 沟道电流镜负载和 p 沟道共源驱动管，p 沟道输入对管则用相反的器件。大部分差别来自电子迁移率约为空穴的 2–3 倍，使相同尺寸和电流下 n 沟道器件的 $g_m=\sqrt{2\mu C_{ox}(W/L)I_D}$ 更大；其余差别来自输入级在两电源之间所处的位置。

### 第 1 步 — 跨导更高：增益与带宽更大

在相同电流和 $W/L$ 下，n 沟道对管的 $g_{m1}$ 更大，约为 $\sqrt{\mu_n/\mu_p}\approx1.7$ 倍。这提高了第一级增益 $g_{m1}(r_{o2}\parallel r_{o4})$ 和增益带宽积 $g_{m1}/C_C$。也可以用更小的输入器件得到相同的 $g_{m1}$，其电容更小、速度更高。

### 第 2 步 — 电流镜负载引起的失调更低

电流镜的阈值失配折合到输入端为 $(g_{m3}/g_{m1})\Delta V_{t(3-4)}$。采用 n 沟道输入对管和 p 沟道电流镜时，该比值为 $\sqrt{\mu_p/\mu_n}\approx0.58$，而不是 $\sqrt{\mu_n/\mu_p}\approx1.73$；在尺寸和电流相同时，这部分失调约小三倍。

### 第 3 步 — 输入参考热噪声更低

强反型下，对管输入参考热噪声电压密度按 $1/\sqrt{g_{m1}}$ 变化（功率按 $1/g_{m1}$）。n 沟道对管的 $g_{m1}$ 较大，因此在相同电流和 $W/L$ 下白噪声更低，或者用更小的电流或更小的器件达到给定噪声指标。

### 第 4 步 — 输入共模范围靠近正电源

n 输入级的共模输入范围约为 $-V_{SS}+V_t+2V_{ov}$ 至 $V_{DD}-|V_{GS3}|+V_t$，体效应还可使其扩展到 $V_{DD}$ 甚至更高。它适合输入靠近正电源轨的应用，例如高边电流检测；在这种情况下 p 输入级的尾电流源会没有足够的电压余度。

### 第 5 步 — 其他考虑

- **电源抑制。** 在互补连接中，尾电流源和第二级负载所参考的那个电源会得到低频抵消（PSRR 很高）；采用 n 沟道输入时这是负电源。当负电源噪声较大时应选择它。
- **阱隔离。** 在 p 阱工艺中，只有 n 沟道器件能放在自己的阱中并使源极接衬底，从而消除体效应及经衬底的电源耦合；此时得到这一好处的正是 n 沟道对管。

也有一个相反方向的已知缺点：p 沟道器件的 $1/f$ 噪声通常较低；并且在常规的直接耦合设计中，n 输入级驱动的是 $g_m$ 较低的 p 沟道第二级器件，使次极点降低。
