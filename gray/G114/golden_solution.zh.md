设负载线在 $V_{ce}$ 轴上的截距为 $V_0$，在 $I_c$ 轴上的截距为 $I_0$：$I_c = I_0(1 - V_{ce}/V_0)$，斜率为 $-I_0/V_0$。
- 沿双曲线 $I_c = P/V_{ce}$，斜率为 $dI_c/dV_{ce} = -P/V_{ce}^2 = -I_c/V_{ce}$。
- 相切要求两者有公共点且斜率相等：$I_c/V_{ce} = I_0/V_0$。代入负载线方程得 $I_0V_{ce}/V_0 = I_0(1 - V_{ce}/V_0)$，故 $V_{ce} = V_0/2$，$I_c = I_0/2$——正是中点。
- 等价的看法：在负载线上，$P = I_cV_{ce} = I_0V_{ce}(1 - V_{ce}/V_0)$ 是 $V_{ce}$ 的抛物线，在 $V_{ce} = V_0/2$ 处取最大值 $I_0V_0/4$；经过该点的双曲线是负载线所能接触到的最高的一条，且恰在该点与之相切。因此，中点也是任意负载线上器件瞬时功耗最大的点。
