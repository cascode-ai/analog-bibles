# Golden Solution - G227

## Reference answer

$v_o/v_i = -g_{m1}R_L = -38.7$. With $\lambda = 0$ the common-gate device passes $M_1$'s drain current to $R_L$ unchanged (current gain 1), so the gain equals that of the plain common-source stage; $g_{m1} = 1.94$ mA/V.

## Grading notes

+2: −38.7 (±3%) with the unity current gain of $M_2$ noted or used. +1: small numerical slip. 0: gain multiplied by an extra factor from a misread connection but the method otherwise sound. −2 (asserted as fact): cascode gain claimed to be $(g_mR_L)^2$ or $g_{m1}/g_{m2}$, or a gain ≈ −1 (taking $1/g_{m2}$ as the load).
