$$R_{out} = (r_{o1}+r_{o2})\,[1 + (1+a)\,g_{m2}\,(r_{o1}\|r_{o2})] = r_{o1} + r_{o2} + (1+a)\,g_{m2}r_{o1}r_{o2} \approx a\,g_{m2}r_{o1}r_{o2}.$$
（结果中不出现 $g_{m1}$：$M_1$ 的栅极为交流地，$M_1$ 只相当于电阻 $r_{o1}$。由于 $M_1$ 与 $M_2$ 流过相同的漏极电流，且 $(W/L)_1 = (W/L)_2$、$\gamma = 0$，有 $g_{m1} = g_{m2}$，所以结果也可以写成用 $g_{m1}$ 表示的形式；但从物理上看，这个因子来自 $M_2$。）

- $R_{out}(g_{m2}{=}0) = r_{o1} + r_{o2}$。
- $\mathcal{R}$（输出短路）：用测试电流 $i_t$（从漏极流向源极）代替 $g_{m2}v_{gs2}$。漏极接地时，$i_t$ 流入源极节点，该节点对地电阻为 $r_{o1}\|r_{o2}$：$v_s = i_t(r_{o1}\|r_{o2})$。运放把栅极驱动到 $v_g = -a v_s$，所以 $v_{gs2} = -(1+a)v_s$，返回电流为 $g_{m2}v_{gs2}$：$\mathcal{R}_{sc} = (1+a)g_{m2}(r_{o1}\|r_{o2})$。
- $\mathcal{R}$（输出开路）：漏极开路时，$i_t$ 经 $r_{o2}$ 返回，没有净电流流入 $r_{o1}$，$v_s = 0$，$\mathcal{R}_{oc} = 0$。
- $R_{out} = (r_{o1}+r_{o2})[1 + (1+a)g_{m2}(r_{o1}\|r_{o2})]$。
