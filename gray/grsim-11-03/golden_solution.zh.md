$S_o(f) = \dfrac{(r_d\parallel R)^2\left[2qI_D(1 + f_c/f) + 4kT/R\right]}{1 + (f/f_1)^2} \approx \dfrac{4.65\times10^{-19}(1 + 938/f)}{1 + (f/2.85\text{ MHz})^2}$ V²/Hz。

- 偏置：$I_D = 0.465$ mA，$r_d = 55.9\ \Omega$，$R_{eq} = r_d\parallel20\text{ k} = 55.8\ \Omega$。
- 闪烁噪声转折频率 $f_c = K_1/2q = 937.5$ Hz；极点 $f_1 = 1/(2\pi R_{eq}C) = 1/(2\pi\cdot55.8\cdot1\text{ nF}) = 2.85$ MHz。
- 数值（V²/Hz）：1 Hz 时 $4.3\times10^{-16}$；100 Hz 时 $4.8\times10^{-18}$；938 Hz 时 $9.3\times10^{-19}$；10 kHz 时 $5.1\times10^{-19}$；100 kHz 时 $4.7\times10^{-19}$；1 MHz 时 $4.1\times10^{-19}$；2.85 MHz 时 $2.3\times10^{-19}$；10 MHz 时 $3.5\times10^{-20}$。
- 双对数坐标下的形状：约 940 Hz 以下斜率为 −1（−10 dB/decade），随后平坦，约为 $4.65\times10^{-19}$ V²/Hz，约 2.85 MHz 以上斜率为 −2（−20 dB/decade）。
