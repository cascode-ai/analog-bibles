# Golden Solution - G123

## Reference answer

$A_v^- \approx 0.833$ (at $V_i = -0.5$ V, where $V_o \approx -1.538$ V).
- $V_{ov1} = 0.1$ V (constant current $I_Q$).
- $-0.5 = V_o + 0.8 + 0.5\left(\sqrt{V_o + 3.1} - \sqrt{0.6}\right)$ → $\sqrt{V_o + 3.1} = 1.2499$, $V_o = -1.538$ V.
- $A_v^- = 1/(1 + 0.25/1.2499) = 1/1.2000 = 0.833$. The slope is lower than at the quiescent point because the source–body voltage, and hence $\sqrt{2\phi_f + V_{SB}}$, is smaller, making the body effect relatively stronger.
