有效 $(W/L)_9 ≈ 139$，即等于 $M_6$ 的有效 $W/L$；若画图长度为 $L_9 = 1$ μm（线性区中 $L_{\text{eff}} = 0.82$ μm），则 $W_9 ≈ 114$ μm，$W/L ≈ 114/1$。此时 $R_Z = 1/g_{m6} ≈ 304$ Ω。

- 当 $R_Z = 1/g_{m6}$ 时零点位于无穷远。
- $M_6$：100/1，$L_{\text{eff}} = 0.72$ μm，$I_{D6} = 200$ μA（为 $M_4$ 的 100 μA 的两倍）。$V_{ov6} = \sqrt{2 \times 200\text{ μA}/(194\text{ μA/V}^2 \times 138.9)} = 0.122$ V，$g_{m6} = 2I_D/V_{ov} = 3.28$ mA/V。
- 偏置电路：$M_{10}$ 镜像 $M_8$（宽度相同），因此 $M_{11}$ 和 $M_{12}$ 流过 200 μA。$M_{12}$（100/1，200 μA）与 $M_6$ 匹配，因此 $V_{GS12} = V_{GS6}$：$M_{11}$ 的源极与 $M_9$ 的源极（即 $M_6$ 的栅极）处于相同电压。由于源极电压和衬底电压都相同，$V_{GS9} = V_{GS11}$ 且 $V_{t9} = V_{t11}$，体效应（body effect）的影响相互抵消，因此 $V_{GS9} - V_{t} = V_{ov11} = 0.122$ V。
- 线性区电阻 $R_Z = 1/[k'_n(W/L)_9(V_{GS9} - V_t)]$。令其等于 $1/g_{m6} = 1/[k'_n(W/L)_6 V_{ov6}]$，并利用 $V_{ov11} = V_{ov6}$，得 $(W/L)_{9,\text{eff}} = (W/L)_{6,\text{eff}} = 100/0.72 = 139$。
- 在线性区（$V_{DS} ≈ 0$）中 $L_{\text{eff}} = 1 - 0.18 = 0.82$ μm，因此 $W_9 = 139 \times 0.82 ≈ 114$ μm。（若对 $M_9$ 也减去 $X_d$，则 $W_9$ = 100 μm，即 $M_9$ 是 $M_6$ 的复制品。）
