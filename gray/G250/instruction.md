A series-series feedback amplifier is modeled as follows. The basic amplifier has input impedance $z_i$ and a Norton output: a controlled current source $a\,v_\epsilon$ in parallel with an output impedance $z_o$, where $v_\epsilon$ is the voltage across the basic-amplifier input and $a$ is a transconductance. The feedback network is ideal and unilateral: it senses the output current $i_o$ in series with the output (zero impedance in the output loop) and feeds back a voltage $v_{fb} = f\,i_o$ in series with the input (zero impedance in the input loop), so that $v_\epsilon = v_i - f\,i_o$, where $v_i$ is the input signal voltage from an ideal voltage source; $f$ is a transresistance. The basic amplifier transmits only forward. Let $T = af$. Show that the closed-loop transconductance (with the output port short-circuited), the input impedance and the output impedance are
$$\frac{i_o}{v_i} = \frac{a}{1+af},\qquad Z_i = z_i(1+T),\qquad Z_o = z_o(1+T).$$
