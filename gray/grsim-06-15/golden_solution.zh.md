手工分析结果（平方律，$L_{eff} = 0.72\ \mu$m，$\lambda = 0.0556\ \mathrm{V^{-1}}$，$|V_A| = 18$ V）：
- 偏置电流：$|I_{D8}| = 200\ \mu$A。$M_5$ 和 $M_7$ 的 $V_{SG}$ 和 $W/L$ 与 $M_8$ 相同，因此 $|I_{D5}| = |I_{D7}| = 200\ \mu$A。于是 $|I_{D1}| = |I_{D2}| = I_{D3} = I_{D4} = 100\ \mu$A，$I_{D6} = 200\ \mu$A（忽略沟道长度调制引起的百分之几的差别）。尺寸满足 $(W/L)_3/(W/L)_6 = \tfrac12(W/L)_5/(W/L)_7$，因此 $M_3$、$M_4$、$M_6$ 的电流密度相等。
- 过驱动电压（overdrive voltage）：$|V_{ov1,2}| = V_{ov3,4} = V_{ov6} = \sqrt{2\cdot100\ \mu/(64.7\ \mu\cdot208)} = 0.122$ V，$|V_{ov5,7,8}| = 0.172$ V。
- 增益：$g_{m1} = 1.64$ mS，$g_{m6} = 3.28$ mS；$r_{o2} = r_{o4} = 180$ kΩ，$r_{o6} = r_{o7} = 90$ kΩ。$A_{v1} = g_{m1}(r_{o2}\parallel r_{o4}) = 148$，$A_{v2} = -g_{m6}(r_{o6}\parallel r_{o7}) = -148$，因此 $A_v \approx -2.2\times10^4$（87 dB）。若把版图尺寸比当作有效 $W/L$，则 $A_v \approx -1.6\times10^4$。
- 共模范围（$M_1$/$M_2$ 无体效应）：$V_{t3} - |V_{t1}| + V_{ov3} - V_{SS} < V_{IC} < V_{DD} - |V_{t1}| - |V_{ov1}| - |V_{ov5}|$，即 $-1.58\ \mathrm{V} < V_{IC} < +0.41$ V。下限低于 −1.5 V 电源，因此实际范围从大约负电源轨延伸到 +0.41 V。
- 电源增益：
  - $A^+ = v_o/v_{dd} \approx 0$：经 $r_{o7}$ 的耦合（$+r_{o6}/(r_{o6}+r_{o7}) = +0.5$）与经尾电流源和第一级的耦合（$\approx -g_{m6}(r_{o6}\parallel r_{o7})/(2g_{m3}r_{o5}) = -0.5$）相互抵消，因为 $V_{A5} = V_{A7}$ 且 $V_{ov3} = V_{ov6}$。采用精确的小信号表达式时会留下 $10^{-3}$ 量级的残差，因此 $PSRR^+$ 非常大。
  - $A^- = v_o/v_{ss} = r_{o7}/(r_{o6}+r_{o7}) = 0.5$，因此 $PSRR^- = |A_{dm}|/A^- \approx 4.4\times10^4$（93 dB）。
