The MOS differential amplifier shown in [Fig. 1] has $I_{SS} = 1$ mA, $R_S = 5\ \mathrm{k\Omega}$ and $R_L = 3\ \mathrm{k\Omega}$. The tail current source has an output resistance $R_T = 300\ \mathrm{k\Omega}$ in parallel with a capacitance $C_T = 2$ pF, both from the common-source node to ac ground. Calculate the differential-mode gain $A_{dm} = v_{od}/v_{id}$, the common-mode gain $A_{cm} = v_{oc}/v_{ic}$ (where $v_{oc}$ is the common-mode, i.e. average, output voltage of the two drains for a common-mode input $v_{ic}$ applied to both gates through their $R_S$) and the common-mode rejection ratio $\mathrm{CMRR} = |A_{dm}/A_{cm}|$ as functions of frequency. Sketch the magnitudes of these quantities in decibels from $f = 10$ kHz to $f = 20$ MHz, using a log frequency scale.

NMOS data (both transistors): $W = 100\ \mu$m, $L_{\text{eff}} = 1.6\ \mu$m, $k_n' = 60\ \mu\mathrm{A/V^2}$, $\lambda = 0$, $\gamma = 0$, $C_{gs} = \tfrac23WL_{\text{eff}}C_{ox}$ with $C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$, $C_{gd} = 14$ fF, $C_{sb} = C_{db} = 0$. Square-law model.
