采用漏极电流的缓变沟道（gradual-channel）形式，在忽略体效应和沟道长度调制时它对所有工作区都成立：对于源极电压为 $V_S$、漏极电压为 $V_D$、栅极电压为 $V_G$ 的器件，
$$I_D = \frac{k'W}{L}\int_{V_S}^{V_D} g(V)\,dV,\qquad g(V) = \max(V_G - V_t - V,\,0)$$
（当 $V_S \ge V_G - V_t$ 时截止；线性区 $I_D = \frac{k'W}{L}[(V_G-V_S-V_t)(V_D-V_S) - (V_D-V_S)^2/2]$；当 $V_D \ge V_G - V_t$ 时饱和，积分上限实际上被限制在 $V_G - V_t$，得到 $\frac{k'W}{2L}(V_G-V_S-V_t)^2$）。

设 $V_X$ 为中间节点电压。两个器件中流过相同的电流：
$I_DL_1 = k'W\int_{V_S}^{V_X}g\,dV$（M1）和 $I_DL_2 = k'W\int_{V_X}^{V_D}g\,dV$（M2）。两式相加，
$$I_D(L_1+L_2) = k'W\int_{V_S}^{V_D}g\,dV \;\Rightarrow\; I_D = \frac{k'W}{L_1+L_2}\int_{V_S}^{V_D}g\,dV,$$
这正是在相同 $V_G$、$V_S$、$V_D$ 下单个 $W/(L_1+L_2)$ 器件的电流，对每个工作区都成立。两个器件具有相同的 $V_t$（无体效应，尽管 M2 的源极位于 $V_X$）且没有沟道长度调制，这正是使两者的 $g$ 相同、积分可以相加的条件。（这一限制来自以源极为参考的平方律模型；在以衬底为参考的缓变沟道电荷薄层模型中，被积函数只取决于局部沟道电势，因此即使存在体效应，串联等效也严格成立。）

显式验证：当串联管导通时，$V_X < V_G - V_t$，因此 M1 总是处于线性区。若 M2 饱和，则 $I_D = \frac{k'W}{2L_2}(V_G - V_X - V_t)^2$，且 $I_D = \frac{k'W}{L_1}[V_{ov}(V_X - V_S) - (V_X-V_S)^2/2]$，其中 $V_{ov} = V_G - V_S - V_t$；令 $u = V_G - V_X - V_t$，第二式化为 $I_D = \frac{k'W}{2L_1}(V_{ov}^2 - u^2)$；消去 $u^2 = 2I_DL_2/(k'W)$ 得 $I_D = \frac{k'W}{2(L_1+L_2)}V_{ov}^2$。若 M2 处于线性区，同样的消元可得到以 $L_1+L_2$ 表示的线性区表达式。
