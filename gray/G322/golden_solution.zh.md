$C_{m1} ≈ 16$ pF，$C_{m2} ≈ 13.4$ pF（与 $g_{m1}$ 的取值无关）。

- 主极点（dominant pole，由 $C_{m2}$ 的密勒效应决定）：$p_1 ≈ -1/(g_{m1}R_1g_{m2}R_2R_0C_{m2})$，因此单位增益频率为 $\omega_u ≈ a_0|p_1| = g_{m0}/C_{m2}$。
- 高频极点由 $D'(s) = 1 + \frac{a_2}{a_1}s + \frac{a_3}{a_1}s^2$ 决定，其中 $\dfrac{a_2}{a_1} ≈ \dfrac{(g_{m2} - g_{m1})C_{m1}}{g_{m1}g_{m2}}$，$\dfrac{a_3}{a_1} ≈ \dfrac{C_1C_2 + C_{m1}(C_1 + C_2)}{g_{m1}g_{m2}}$；对于间隔很大的实极点，
$p_2 ≈ -\dfrac{g_{m1}g_{m2}}{(g_{m2} - g_{m1})C_{m1}} = -\dfrac{1.2\,g_{m1}}{C_{m1}}$，$p_3 ≈ -\dfrac{(g_{m2} - g_{m1})C_{m1}}{C_1C_2 + C_{m1}(C_1 + C_2)} = -\dfrac{5g_{m1}C_{m1}}{3\text{ pF}^2 + 6.5\text{ pF}\,C_{m1}}$。
- $|p_3| = 10|p_2|$：$5C_{m1}^2 = 12(3 + 6.5C_{m1})$（单位 pF）→ $C_{m1} = 16.0$ pF；于是 $|p_2| = 0.075\,g_{m1}/\text{pF}$，$|p_3| = 0.75\,g_{m1}/\text{pF}$。
- 45°（使 $|p_2|$ 位于 $\omega_u$ 处）：$g_{m0}/C_{m2} = 1.2\,g_{m1}/C_{m1}$ → $C_{m2} = C_{m1}/1.2 = 13.4$ pF。
- 验证：用这些值计算环路增益（实际穿越频率略低于 $|p_2|$，$p_3$ 约损失 5° 相位），得到相位裕度 ≈ 48°，即不低于 45°；此时实际极点比约为 7.7。若同时保留 $C_0$ 项（$a_2 ∝ C_{m1}[C_0g_{m2} + C_{m2}(g_{m2} - g_{m1})]$ 等），按同一准则得 $C_{m1} ≈ 16.4$ pF，$C_{m2} ≈ 14.3$ pF。
- 同样有效的精确设计：令实际极点比（由二次式求得）恰为 10，并精确满足 45° 相位条件和单位幅值条件，得 $C_{m1} ≈ 19.8$ pF，$C_{m2} ≈ 14.1$ pF（PM = 45.0°，$|p_3|/|p_2|$ = 10.0，与 $g_{m1}$ 无关）。
