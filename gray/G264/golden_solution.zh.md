$i_o/i_s \approx -10.7$；环路增益 $T \approx 47$；$Z_{in} \approx 9.9$ Ω（包括 $R_S$）；$Z_{out} \approx 8.5$ MΩ（精确小信号值；二端口简便算法给出 ≈ 14 MΩ）。

- $g_m = 38.5$ mS，$r_\pi = 5.2$ kΩ，$r_o = 100$ kΩ。
- 反馈网络（g 参数）：输入端 $g_{11f} = 1/(R_E+R_F) = 1/1.1$ kΩ；$Q_2$ 发射极中 $g_{22f} = R_E\|R_F = 90.9$ Ω；$f = -\dfrac{R_E}{R_E+R_F}\dfrac{1}{\alpha_2} = -0.0914$，因此 $A_\infty = 1/f = -10.94$。
- 基本放大器：输入节点 $R_S\|(R_E+R_F)\|r_{\pi1} = 476$ Ω；$Q_2$ 的输入 $R_{in2} = r_{\pi2} + 201\times90.9 = 23.5$ kΩ；$Q_1$ 的负载 $R_{L1}\|r_{o1}\|R_{in2} = 3305$ Ω。$a = -476\cdot g_{m1}\cdot3305\cdot\beta/R_{in2} = -515$。
- $T = af = 47.1$；$A = a/(1+T) = -515/48.1 = -10.72$。
- $Z_{in} = 476/48.1 = 9.9$ Ω。
- $Z_{out}$：基本放大器的输出电阻 $z_{oa} \approx r_{o2}[1 + g_{m2}R'_E\,r_{\pi2}/(r_{\pi2} + R_b + R'_E)] \approx 299$ kΩ（$R'_E = 90.9$ Ω，$R_b = R_{L1}\|r_{o1}$）。简便算法 $(1+T)z_{oa} = 14.4$ MΩ 偏高，因为环路检测的是 $Q_2$ 的发射极电流，而它的基极电流不受控制；精确的节点分析给出 8.5 MΩ（低于上限 $(\beta+1)r_{o2} = 20$ MΩ）。图中发射极电流的标注 $i_o/\alpha_2$ 是二端口近似；$r_{o2}$ 有限时发射极电流为 $i_o/\alpha_2 - (v_{c2}-v_{e2})/(\beta r_{o2})$，这一项对 $Z_{out}$ 有影响，因此输出阻抗需要用完整的混合 π 关系式求解（或用布莱克曼公式：$307.6\text{k}\times(1+45.75)/(1+0.70) = 8.46$ MΩ）。
- 环路传输的不同定义：二端口 $T = af = 47.1$ 与 $g_{m1}$ 的回归比（return ratio，45.75）决定减敏（desensitivity）程度，两者一致。其他回归比按各自的定义是精确的，但在这里并不等于 $af$：$g_{m2}$ 给出 83.5（其中还包含 $Q_2$ 的局部负反馈环路），无源元件 $R_F$ 给出 $Z_\Delta/R_F = 86.4\text{k}/1\text{k} = 86.4$（$Z_\Delta$ 为去掉 $R_F$ 后其两端之间的阻抗，$i_s = 0$，保留 $R_S$）。
- 小信号验证（线性混合 π 网表，计入全部 $r_o$）：$i_o/i_s = -10.718$，$Z_{in} = 9.893$ Ω（包括 $R_S$；不含时为 9.99 Ω），$Z_{out} = 8.458$ MΩ，$T_{g_{m1}} = 45.75$，$T_{g_{m2}} = 83.5$，$Z_\Delta/R_F = 86.4$。
