这里体效应很弱：$\gamma \approx 0.095\ \mathrm{V^{1/2}}$，因此 $V_{SB}$ = 0、0.5 和 1 V 时 $V_t$ 分别为 0.600、0.626 和 0.646 V。三条曲线几乎是相同的平方律抛物线，在 $V_t$ 以下为零，向右分别只平移了 26 mV 和 46 mV。

- $C_{ox} = \epsilon_{ox}/t_{ox} = 3.45\times10^{-13}/8\times10^{-7} = 4.31\times10^{-7}$ F/cm²（4.31 fF/µm²）；$\gamma = \sqrt{2q\epsilon_{Si}N_A}/C_{ox} = 4.08\times10^{-8}/4.31\times10^{-7} = 0.0946\ \mathrm{V^{1/2}}$。
- $V_t = V_{t0} + \gamma(\sqrt{2\phi_f + V_{SB}} - \sqrt{2\phi_f})$：$0.6 + 0.0946(1.049 - 0.775) = 0.626$ V；$0.6 + 0.0946(1.265 - 0.775) = 0.646$ V。
- 由于 $V_{DS} = 2$ V 且 $V_{ov} \le 1.4$ V，器件在整个扫描范围内都处于有源区（active region）：$I_D = \tfrac12k'(W/L)(V_{GS}-V_t)^2(1+2\lambda) = 1.017\ \mathrm{mA/V^2}\,(V_{GS}-V_t)^2$。
- 数值（$V_{SB}$ = 0 / 0.5 / 1 V）：$V_{GS}$ = 1 V 时为 0.163 / 0.142 / 0.127 mA；1.5 V 时为 0.823 / 0.777 / 0.741 mA；2 V 时为 1.99 / 1.92 / 1.86 mA（不计 $1+\lambda V_{DS}$ 因子时：1.90 / 1.83 / 1.78 mA）。
