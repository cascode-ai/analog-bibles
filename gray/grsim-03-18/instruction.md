Determine the differential-mode gain, common-mode gain, differential-mode input resistance, and common-mode input resistance for the emitter-coupled pair shown in [Fig. 1] with $I_{\text{TAIL}} = 20\ \mu$A, $R_{\text{TAIL}} = 10\ \mathrm{M\Omega}$, $R_C = 100\ \mathrm{k\Omega}$, and $V_{EE} = V_{CC} = 5$ V (dc inputs at 0 V). Neglect $r_b$, $r_o$, and $r_\mu$. Calculate the CMRR. Definitions: $v_{id} = v_{i1} - v_{i2}$, $v_{ic} = (v_{i1}+v_{i2})/2$, $v_{od} = v_{o1} - v_{o2}$, $v_{oc} = (v_{o1}+v_{o2})/2$; $A_{dm} = v_{od}/v_{id}$, $A_{cm} = v_{oc}/v_{ic}$; $R_{id} = v_{id}/i_b$ (pure differential input), $R_{ic} = v_{ic}/i_b$ (pure common-mode input, $i_b$ of one transistor); CMRR $= |A_{dm}/A_{cm}|$. npn data: $\beta_F = \beta_0 = 200$, $I_S = 5\times10^{-15}$ A, $V_T = 26$ mV. Check with SPICE and use SPICE to investigate the effects of adding nonzero $r_b$ and finite $V_A$, using $r_b = 200\ \Omega$ and $V_A = 130$ V.
