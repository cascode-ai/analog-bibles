对于 [图 1] 所示的射极耦合对（emitter-coupled pair），取 $I_{\text{TAIL}} = 20\ \mu$A，$R_{\text{TAIL}} = 10\ \mathrm{M\Omega}$，$R_C = 100\ \mathrm{k\Omega}$，$V_{EE} = V_{CC} = 5$ V（直流输入为 0 V），求其差模增益（differential gain）、共模增益（common-mode gain）、差模输入电阻和共模输入电阻。忽略 $r_b$、$r_o$ 和 $r_\mu$。计算 CMRR。定义：$v_{id} = v_{i1} - v_{i2}$，$v_{ic} = (v_{i1}+v_{i2})/2$，$v_{od} = v_{o1} - v_{o2}$，$v_{oc} = (v_{o1}+v_{o2})/2$；$A_{dm} = v_{od}/v_{id}$，$A_{cm} = v_{oc}/v_{ic}$；$R_{id} = v_{id}/i_b$（纯差模输入），$R_{ic} = v_{ic}/i_b$（纯共模输入，$i_b$ 为单个晶体管的基极电流）；CMRR $= |A_{dm}/A_{cm}|$。npn 参数：$\beta_F = \beta_0 = 200$，$I_S = 5\times10^{-15}$ A，$V_T = 26$ mV。用 SPICE 验证，并用 SPICE 研究加入非零 $r_b$ 和有限 $V_A$ 的影响，取 $r_b = 200\ \Omega$，$V_A = 130$ V。
