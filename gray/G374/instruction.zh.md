[图 1] 所示为一个宽带集成放大器：由 $Q_1$–$Q_3$ 组成的串联-串联反馈三级放大器（series-series feedback triple，反馈网络为 $R_{E1}$、$R_F$、$R_{E2}$）、输出射极跟随器（emitter follower）$Q_4$ 以及偏置电路。电阻值见图。集电极偏置电流为 $I_{C1} = 0.6$ mA、$I_{C2} = 1$ mA、$I_{C3} = 4$ mA；所有晶体管的 $\beta = 100$，$r_b = 100\ \Omega$。$C_B$ 是一个大旁路电容（在信号频率下相当于交流短路）；$C_P$ 和 $C_F$ 是可以忽略的小补偿电容。忽略闪烁噪声（flicker noise），假设频率响应在 50 MHz 处陡然截止，计算该放大器的总等效输入噪声电压（equivalent input noise voltage）。然后计算源电阻为 50 Ω 时该电路的平均噪声系数（noise figure）。取 $4kT = 1.66\times10^{-20}$ V·C、$q = 1.6\times10^{-19}$ C，$kT/q = 26$ mV。
