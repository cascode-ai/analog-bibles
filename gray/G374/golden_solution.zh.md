等效输入噪声电压 ≈ $3.6\times10^{-18}$ V²/Hz（噪声电阻 ≈ 215–222 Ω）→ 50 MHz 内 ≈ 13.5 µV rms；源电阻为 50 Ω 时的平均噪声系数 ≈ 5.3–5.5，即 ≈ 7.3–7.4 dB。

- 输入端的串联反馈：$\overline{v_i^2} = \overline{v_{ia}^2} + \overline{i_{ia}^2}R^2 + 4kTR$，其中 $Q_1$ 发射极处看到的反馈电阻为 $R = R_{E1}\parallel(R_F + R_{E2}) = 100\parallel740 = 88\ \Omega$。
- 基本放大器：$Q_1$：$4kT(r_b + 1/2g_{m1}) = 4kT(100 + 21.7)$；$Q_1$ 集电极处的噪声经其跨导 $\approx 1/(1/g_{m1} + 88\ \Omega) \approx 1/132\ \Omega$ 折算回输入端：$R_A$（9 kΩ）贡献 $4kT\cdot132^2/9\text{ k} \approx 4kT(1.9\ \Omega)$，$Q_2$ 的基极电流噪声 $2qI_{B2}$ 贡献 ≈ $4kT(3.4\ \Omega)$；后级可以忽略。
- $\overline{i_{ia}^2}R^2 = 2qI_{B1}\cdot88^2 \approx 4kT(0.9\ \Omega)$。
- 总和 ≈ $4kT(100 + 21.7 + 1.9 + 3.4 + 0.9 + 88) \approx 4kT(216\ \Omega) = 3.6\times10^{-18}$ V²/Hz（对同一核心模型进行保留有限 β 项的节点分析，得到 $4kT(222\ \Omega)$；$Q_4$–$Q_8$ 及偏置网络的少量残余噪声因其电流未给出，全程忽略）。× 50 MHz = $1.8\times10^{-10}$ V² → 13.4–13.6 µV rms。
- 输入电流噪声：$2qI_{B1} + 4kT/R_D = 1.9\times10^{-24} + 1.4\times10^{-24} = 3.3\times10^{-24}$ A²/Hz（由于 $C_B$ 接地，12-kΩ 的 $R_D$ 在输入端构成并联支路），在 50 Ω 源电阻下可以忽略。
- 所有噪声都是白噪声，因此平均噪声系数与点噪声系数相同：$F = 1 + \dfrac{216 + 0.5}{50} \approx 5.3$ → 7.3 dB。
