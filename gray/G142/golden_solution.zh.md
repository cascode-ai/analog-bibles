$V_o^- = -V_{SS} + V_{ov6} + |V_{gs2}|$，其中 $V_{ov6} = V_{GS6} - V_{t6} = \sqrt{2|I_{D3}|/(k_n'(W/L)_6)}$，$|V_{gs2}| = |V_{t2}| + |V_{ov2}|$ 为 $M_2$ 在该输出下所吸收电流对应的源栅电压。
- 当 $V_o < 0$ 时，$M_2$ 作为源极跟随器工作，$M_1$（几乎）截止：$V_o = V_{g2} + |V_{gs2}|$，而 $M_2$ 的栅极就是 $M_6$ 的漏极。
- $V_{g2}$ 随 $V_i$ 升高而下降，但 $M_6$ 必须保持在有源区（active region）才能起驱动作用：$V_{DS6} \ge V_{ov6}$。由于 $M_3$、$M_4$、$M_5$ 和 $M_6$ 串联且栅极不取电流，$M_6$ 流过固定电流 $|I_{D3}|$，由此决定 $V_{ov6}$。因此 $V_{g2,min} = -V_{SS} + V_{ov6}$。
- $|V_{gs2}|$ 应在 $|I_{d2}| \approx |V_o^-|/R_L$（再加上 $M_1$ 中的残余电流）下计算，并且包含体效应（body effect）：$M_2$ 的 n 阱接 $V_{DD}$，因此负输出时 $V_{BS2} = V_{DD} - V_o$ 很大，使 $|V_{t2}|$ 升高。
- 与正向一侧一样，这一极限离电源轨比双极型电路远得多，因为 $|V_{gs2}|$ 包含一个阈值电压（被体效应抬高）和一个平方根形式的过驱动电压。（让 $M_6$ 进入线性区可使输出再略微下降，趋近 $-V_{SS} + |V_{gs2}|$，但代价是失去驱动级的增益。）
