两条负载线都经过静态工作点 $Q$：$V_{ce1} = 15$ V，$I_{c1} = I_Q = 2.86$ mA，并满足 $V_{ce1} = V_{CC} - (I_{c1} - I_Q)R_L$。
- $R_L = 2\ \mathrm{k\Omega}$：斜率 $-1/R_L = -0.5$ mA/V。上端点在 $Q_1$ 饱和处：$V_{ce1} = 0.2$ V，$I_{c1} = 2.86 + 14.8/2 = 10.26$ mA。下端点在 $Q_1$ 截止处：$I_{c1} = 0$，$V_{ce1} = V_{CC} + I_QR_L = 20.72$ V（输出停在 $-I_QR_L = -5.72$ V，$Q_2$ 仍处于有源区）。该负载线终止于 $V_{ce}$ 轴上。
- $R_L = 10\ \mathrm{k\Omega}$：斜率 $-0.1$ mA/V。上端点在 $Q_1$ 饱和处：$V_{ce1} = 0.2$ V，$I_{c1} = 2.86 + 1.48 = 4.34$ mA。下端点在 $Q_2$ 饱和处（$V_o = -14.8$ V，因为 $I_QR_L = 28.6\ \mathrm{V} > V_{CC}$）：$V_{ce1} = 29.8$ V，$I_{c1} = 2.86 - 1.48 = 1.38$ mA。该负载线到不了 $V_{ce}$ 轴（其延长线与该轴交于 43.6 V）。

偏置：$I_Q = I_R = (0 - 0.7 + 15)\ \mathrm{V}/5\ \mathrm{k\Omega} = 2.86$ mA（面积相等的电流镜，$R_1 = R_2 = 0$）。
