[图 1] 所示为一个全差分（fully differential）电流镜运放（current-mirror op amp）：NMOS 输入对 $M_1$–$M_2$，尾电流管为 $M_5$；二极管连接（diode-connected）的 PMOS 负载 $M_3$、$M_4$ 以 1:1 镜像到 $M_8$（输出 $V_{o2}$）和 $M_6$（输出 $V_{o1}$）；输出端接 NMOS 电流源 $M_9$ 和 $M_7$。$M_1$ 与 $M_2$ 匹配，$M_7$ 与 $M_9$ 匹配，$M_3$、$M_4$、$M_6$、$M_8$ 是相同的 PMOS 器件。所有晶体管取 $|V_{ov}| = 0.2$ V，$I_{D5} = 200\ \mu$A，$V_{An} = 10$ V，$|V_{Ap}| = 20$ V（$r_o = |V_A|/|I_D|$），$\gamma = 0$。此时共模控制（CMC）输入端接 $M_7$ 和 $M_9$ 的栅极，$M_5$ 的栅极接偏置电压。计算低频 CMC 增益 $a_{cmc} = v_{oc}/v_{cmc}$（$v_{ic} = 0$）。
