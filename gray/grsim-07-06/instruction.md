A bipolar differential amplifier as shown in [Fig. 1] has $I_{EE} = 1$ mA, $R_S = 5\ \mathrm{k\Omega}$ and $R_L = 3\ \mathrm{k\Omega}$. Transistor data: $r_b = 300\ \Omega$, $\beta = 200$, $f_T = 500$ MHz (at $I_C = 0.5$ mA), $C_\mu = 0.3$ pF, $C_{cs} = 0$, $V_A = \infty$, $V_T = 26$ mV. The tail current source has an associated resistance $R_T = 300\ \mathrm{k\Omega}$ and capacitance $C_T = 2$ pF, both from the common-emitter node $E$ to ac ground. Calculate the differential-mode gain $A_{dm} = v_{od}/v_{id}$, the common-mode gain $A_{cm} = v_{oc}/v_{ic}$ ($v_{oc}$ = common-mode, i.e. average, collector voltage for a common-mode input $v_{ic}$ applied to both bases through their $R_S$) and the CMRR $= |A_{dm}/A_{cm}|$ as functions of frequency. Sketch the magnitude of these quantities in decibels from $f = 10$ kHz to $f = 20$ MHz, using a log frequency scale. Compare your answer with a SPICE simulation (for example the linear hybrid-π model with $C_\pi$ from $f_T$, plus $R_T \| C_T$ from node $E$ to ground).
