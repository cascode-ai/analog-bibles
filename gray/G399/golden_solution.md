# Golden Solution - G399

## Reference answer

Both amplifiers have $a_{dm} \approx -66.7$. Without the tail source $a_{cm} \approx -66.7$; with the tail source $a_{cm} \approx -1.96$, so removing the tail source raises $|a_{cm}|$ about 34× and leaves CMRR = 1.

- [Fig. 1]: each side is an independent common-source stage, $a_{dm} = a_{cm} = -g_{m1}(r_{o1}\|r_{o3}) = -(1\ \text{mA/V})(66.7\ \text{k}\Omega) = -66.7$.
- [Fig. 2]: DM half-circuit is the same, $a_{dm} = -66.7$. In the CM half-circuit, $M_1$ is degenerated by $r_{o5h} = 2(10\ \text{V}/200\ \mu\text{A}) = 100$ kΩ: $a_{cm} \approx -(R_{o(\text{down})}\|r_{o3})/r_{o5h} = -196\ \text{k}/100\ \text{k} \approx -1.96$ (exact half-circuit value $-g_{m1}r_{o3}/[1 + g_{m1}r_{o5h} + (r_{o3} + r_{o5h})/r_{o1}] = -1.92$).
- Implication: without a tail source, CM input changes (and supply noise, mismatch) reach the outputs as strongly as DM signals (CMRR = 1), and the dc CM output level, set only by the balance of the NMOS and PMOS currents, is extremely sensitive to $V_{ic}$ and to mismatch. The tail source cuts $|a_{cm}|$ to about 2 (CMRR ≈ 35) but does not define the output CM level: with current-source loads the outputs are high-impedance nodes (CM output resistance ≈ $r_{o3}\|[r_{o1}(1 + g_{m1}r_{o5h}) + r_{o5h}] ≈ 196$ kΩ), so $V_{OC}$ is set by the balance between $I_{D5}$ and $|I_{D3}| + |I_{D4}|$ and shifts strongly with small mismatches. Both stages therefore need common-mode feedback to set $V_{OC}$; the tail source improves CM rejection but is not a substitute for CMFB.
