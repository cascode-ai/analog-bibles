闭环特性保持相同的三段式奇对称形状，其中：
- $|S_i| \le 0.84$ mV：斜率 $A_1 = a_1/(1+a_1f) = 50{,}000/6 = 8333$（$S_o$ 最高到 ±7 V）；
- $0.84\text{ mV} \le |S_i| \le 2.04$ mV：斜率 $A_2 = a_2/(1+a_2f) = 20{,}000/3 = 6667$（$S_o$ 从 ±7 V 到 ±15 V）；
- $|S_i| \ge 2.04$ mV：$S_o = \pm 15$ V（斜率为 0；在硬饱和区反馈无能为力）。

推导：在第 1 段，$T_1 = a_1 f = 5$；转折点位于 $S_o = 7$ V，此时 $S_\epsilon = 7/50{,}000 = 0.14$ mV，$S_i = S_\epsilon + fS_o = 0.14\text{ mV} + 0.7\text{ mV} = 0.84$ mV $= (S_{o1}/a_1)(1+a_1f)$。在第 2 段，$T_2 = a_2f = 2$；在 $S_i = 0.84\text{ mV} + 8\text{ V}/6667 = 2.04$ mV 处达到饱和（此时 $S_\epsilon = 0.14 + 0.40 = 0.54$ mV，$fS_o = 1.5$ mV）。闭环斜率比 $A_1/A_2 = 1.25$，而开环时 $a_1/a_2 = 2.5$：反馈使相对斜率变化减半，但由于仅有 $T = 2$–5，非线性仍然清晰可见。
