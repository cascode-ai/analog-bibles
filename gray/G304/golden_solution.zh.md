在给定的 $R_F$、$R_E$ 下：$|f_0| = R_E/(R_E + R_F) = 0.0099$，$T_0 = 39.6$，低频增益 $A_0 = 4000/40.6 = 98.5$（39.9 dB）。极点位置（以 $s/2\pi$ 表示）：
- 无 $C_F$：$-4.5 \pm j26.7$ MHz（$\omega_n$ = 27 MHz，$Q ≈ 3.0$）。
- 有 $C_F$：$-21.3 \pm j16.7$ MHz（$Q ≈ 0.63$，与负实轴约成 38°），另有一个由反馈网络引起的、位于约 −2.1 GHz 的远极点。

有 $C_F$ 时的反馈函数：$f(s) = -\dfrac{R_E}{R_E+R_F}\,\dfrac{1 + sR_FC_F}{1 + s\frac{R_ER_F}{R_E+R_F}C_F}$：零点位于 $1/(2\pi R_FC_F)$ = 21.2 MHz，极点位于其 101 倍处（2.14 GHz，可忽略）。因此环路增益的极点位于 −3 和 −6 MHz，有 $C_F$ 时还有一个位于 −21.2 MHz 的零点。

根轨迹：
- 无 $C_F$：从 −3 和 −6 MHz 出发的极点在 −4.5 MHz 处相遇（$T_0 = 0.125$，$f = 3.1 \times 10^{-5}$），然后沿 Re = −4.5 MHz 垂直分开；$f = 0.0099$ 时位于 $-4.5 \pm j26.7$ MHz（Q 值很高）。
- 有 $C_F$：在 −4.57 MHz 处分离（$T_0 = 0.16$，$f = 4.0 \times 10^{-5}$）；复数分支沿以零点（−21.2 MHz）为圆心、半径为 16.6 MHz 的圆移动，该圆将在 $T_0 = 79$（$f = 0.0197$，超出所给范围）时于 −37.9 MHz 处回到实轴，之后一支趋向零点，另一支趋向 −∞。$f = 0.0099$ 时极点位于圆的顶部/底部，即 $-21.3 \pm j16.7$ MHz。反馈零点使轨迹弯离 $j\omega$ 轴。
- 闭环极点由 $s^2 + s(|p_1| + |p_2| + T_0|p_1||p_2|/\omega_z) + (1+T_0)|p_1||p_2| = 0$ 求得（有 $C_F$ 时）；若无该电容，方程相同，只是 $s$ 的系数中没有 $T_0$ 项。

增益幅值 $|i_o/i_s|$（10 kHz–100 MHz）：
- 无 $C_F$：在几 MHz 以下平坦，为 98.5（39.9 dB），在 26 MHz 附近峰化至 ≈ 300（+9.7 dB），在 ≈ 41 MHz 处为 −3 dB，之后以 −40 dB/dec 下降（100 MHz 处 ≈ 7.7）。
- 有 $C_F$：平坦，为 98.5，无峰化，在 ≈ 24 MHz 处为 −3 dB，之后以 −40 dB/dec 下降（100 MHz 处 ≈ 7.2）。反馈零点不是 $i_o/i_s$ 的零点（即“幻零点”，phantom zero），因此响应只有两个极点而没有零点。
