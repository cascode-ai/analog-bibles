回归比 $\mathscr{R} = a_v\dfrac{Z_1}{Z_1 + Z_2}$；闭环极点是 $(1 + a_v)Z_1 + Z_2 = 0$ 的根，对任意 R/C 组合，这些极点要么不存在，要么是负实数，因此电路总是稳定的。

回归比：令 $V_s = 0$，并把受控源换成独立源 $a_v v_t$。输出为 $a_v v_t$；分压得到节点电压 $a_v v_t Z_1/(Z_1 + Z_2)$，而 $v_x$ 等于该节点电压取负，所以返回信号 $v_r = -a_v v_t Z_1/(Z_1 + Z_2)$，$\mathscr{R} = -v_r/v_t = a_vZ_1/(Z_1 + Z_2)$。

稳定性：闭环极点是 $1 + \mathscr{R}$ 的零点，即 $(1 + a_v)Z_1 + Z_2$ 的零点（$Z_1 + Z_2$ 为有限值时）：
- $Z_1 = R_1$，$Z_2 = R_2$：与 $s$ 无关，没有极点。
- $Z_1 = R$，$Z_2 = 1/sC$：$(1 + a_v)R + 1/(sC) = 0$ → $s = -1/[(1 + a_v)RC] < 0$。
- $Z_1 = 1/sC$，$Z_2 = R$：$(1 + a_v)/(sC) + R = 0$ → $s = -(1 + a_v)/(RC) < 0$。
- $Z_1 = 1/sC_1$，$Z_2 = 1/sC_2$：$\mathscr{R} = a_vC_2/(C_1 + C_2)$ 为常数；没有有限极点。
由于 $a_v > 0$ 使 $1 + a_v > 0$，所有极点都位于左半平面。等价地说，$Z_2/Z_1$ 是正实数，或是正虚数乘以常数（取 ±），因此 $1 + Z_2/Z_1$ 的实部为正，$\mathscr{R}(j\omega)$ 始终位于右半平面，其奈奎斯特图（Nyquist plot）不可能包围 −1。
