输入阻抗（忽略 $C_\mu$）：$z_i = \dfrac{z_\pi + r_b}{1 + g_mz_\pi}$，与由源电阻 $r_b$ 驱动的射极跟随器（emitter follower）的输出阻抗相同。感性等效电路：$R_2$ 与（$R_1$ 串联 $L$）并联：
- 简单公式：$R_1 = 1/g_m + r_b/\beta_0 = 52 + 2 = 54\ \Omega$，$R_2 = r_b = 200\ \Omega$，$L = C_\pi r_\pi r_b/\beta_0 = 104$ nH。
- 对该模型的精确拟合：$z_i(0) = (r_\pi + r_b)/(\beta_0 + 1) = 53.5\ \Omega$，$R_2 = 200\ \Omega$，$R_1 = 73\ \Omega$，$L = 141$ nH；零点位于 82.6 MHz，极点位于 309 MHz。
- 草图：$|z_i| \approx 53.5\ \Omega$，从 100 kHz 到 ≈ 20 MHz 保持平坦（10 MHz 处 53.9 Ω，30 MHz 处 57 Ω），之后（呈感性）上升，100 MHz 处 ≈ 80 Ω（若用简单公式的元件值则 ≈ 65 Ω）；在远高于 300 MHz 处才会趋于 $r_b = 200\ \Omega$。

输出阻抗：发射极由理想电流源驱动时，发射极处的 KCL 迫使 $v_1 = 0$，因此 $g_m$ 受控源不携带信号，$z_o = r_b + 1/(sC_\mu)$：$C_\mu = 0.3$ pF 与 $r_b = 200\ \Omega$ 串联（由于 $r_o = \infty$，直流时电阻为无穷大）。草图：$|z_o|$ 以 −20 dB/decade 从 100 kHz 处的 5.3 MΩ 下降到 100 MHz 处的 5.3 kΩ（$r_b$ 只在 ≈ 2.7 GHz 以上才起作用）。
