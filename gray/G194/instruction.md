A common-base stage is driven at its emitter by a signal current source (source resistance $R_S = \infty$); the base is at ac ground through the transistor's base resistance and the collector feeds a load $R_L = 0$. Transistor data: $I_C = 0.5$ mA, $C_\pi = 10$ pF, $C_\mu = 0.3$ pF, $r_b = 200\ \Omega$, $\beta = 100$, $r_o = \infty$, $V_T = 26$ mV. Calculate the values of the elements in small-signal equivalent circuits for the input impedance (looking into the emitter) and the output impedance (looking into the collector) of the stage, and sketch the magnitudes of these impedances from $f = 100$ kHz to $f = 100$ MHz using log scales.
