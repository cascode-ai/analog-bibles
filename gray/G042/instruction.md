Calculate the threshold voltage of the $p$-channel transistors of a silicon-gate $n$-well CMOS process with the following $p$-channel parameters: $n$-well (substrate) doping $N_D = 10^{16}\ \mathrm{cm^{-3}}$, gate oxide thickness $t_{ox} = 400$ Å, metal-silicon work function $\phi_{ms} = -0.1$ V, surface-state density $Q_{ss}/q = 10^{11}\ \mathrm{cm^{-2}}$; threshold-adjust implant: $p$-type, box distribution with an effective depth of 0.3 μm and an effective concentration of $0.9\times10^{16}\ \mathrm{cm^{-3}}$. First do the calculation for the unimplanted transistor, then for the case in which the device receives the channel implant specified. Note that this is a $p$-type implant, so that the effective surface concentration is the difference between the background substrate concentration and the effective concentration in the implant layer.

Use $n_i = 1.5\times10^{10}\ \mathrm{cm^{-3}}$, $kT/q = 26$ mV, $\epsilon_{ox} = 3.9\epsilon_0$, $\epsilon_{Si} = 11.6\epsilon_0$, $\epsilon_0 = 8.86\times10^{-14}$ F/cm, $q = 1.6\times10^{-19}$ C.
