未注入：$V_t \approx -1.54$ V。注入后：$V_t \approx -1.2$ V（若假设耗尽层位于反型掺杂层之内，为 −1.16 V；更准确地考虑耗尽层延伸到下方 $10^{16}$ 的阱中，则为 −1.25 V）。

- $C_{ox} = 3.9\times8.86\times10^{-14}/(400\times10^{-8}) = 8.64\times10^{-8}$ F/cm²。
- $|\phi_f| = (kT/q)\ln(N_D/n_i) = 0.026\ln(6.67\times10^5) = 0.349$ V → $2|\phi_f| = 0.70$ V。
- $|Q_b| = \sqrt{2q\epsilon_{Si}N_D(2|\phi_f|)} = \sqrt{2(1.6\times10^{-19})(1.03\times10^{-12})(10^{16})(0.70)} = 4.79\times10^{-8}$ C/cm² → $|Q_b|/C_{ox} = 0.55$ V。
- $Q_{ss}/C_{ox} = 1.6\times10^{-19}\times10^{11}/8.64\times10^{-8} = 0.19$ V。
- PMOS：$V_t = \phi_{ms} - 2|\phi_f| - |Q_b|/C_{ox} - Q_{ss}/C_{ox} = -0.1 - 0.70 - 0.55 - 0.19 = -1.54$ V。
- 注入后：表面净掺杂为 $10^{16} - 0.9\times10^{16} = 10^{15}$ cm⁻³（$n$ 型），深至 0.3 μm；反型条件按阱的掺杂取，$2|\phi_f|$ = 0.70 V（改用反型掺杂层的 $2|\phi_f|$ = 0.58 V 也是同样可以接受的约定；对于均匀的 $10^{15}$ 矩形分布得 −1.02 V，对于双层解得 −1.09 V）。矩形模型且耗尽层位于该层之内：$|Q_b|/C_{ox} = 0.18$ V → $V_t = -1.16$ V。验证：$10^{15}$ 掺杂在 0.7 V 下的耗尽层深约 0.95 μm，超出了 0.3 μm 的注入层，因此求解双层情况（$\psi = \tfrac{q}{\epsilon}[N_1x_i^2/2 + N_2(W^2-x_i^2)/2] = 0.70$ V）得 $W \approx 0.41\ \mu$m，$|Q_b| = q(10^{15}\times0.3\ \mu\mathrm{m} + 10^{16}\times0.11\ \mu\mathrm{m}) = 2.29\times10^{-8}$ C/cm² → 0.26 V → $V_t \approx -1.25$ V。（若把注入视为薄电荷层，剂量 $2.7\times10^{11}$ cm⁻²，则 $\Delta V_t = +0.50$ V，$V_t \approx -1.04$ V。）
