采用常用近似 $\omega_u ≈ g_{m1}/C$ 时 $C ≈ 5.7$ pF；精确的双极点穿越频率计算给出 ≈ 5.0 pF。

- 极点：$p_1 ≈ -1/(g_{m6}R_1R_2C)$，$p_2 ≈ -g_{m6}C/[C_1C_2 + C(C_1+C_2)] ≈ -g_{m6}/(C_1 + C_2)$。
- 由于在 $|p_1|$ 以上环路增益（loop gain）以 −20 dB/dec 下降，单位增益频率为 $\omega_u ≈ a_0|p_1| = g_{m1}/C$。
- 60° PM：$\arctan(\omega_u/|p_2|) = 30°$ → $|p_2| = \sqrt{3}\,\omega_u$：
$\dfrac{g_{m6}}{C_1 + C_2} = \sqrt{3}\,\dfrac{g_{m1}}{C}$ → $C = \sqrt{3}\,\dfrac{g_{m1}}{g_{m6}}(C_1 + C_2) = 1.732 \times 0.645 \times 5.12\text{ pF} = 5.7$ pF（若忽略 $C_1$ 为 5.6 pF；若用 $p_2$ 的完整表达式为 5.8 pF）。
- 精确的双极点计算：穿越频率为 $\omega_c = |p_2|/\sqrt{3}$，且 $|T(j\omega_c)| = (g_{m1}/C\omega_c)/\sqrt{4/3} = 1$ → $g_{m1}/C = \tfrac{2}{3}|p_2|$ → $C = 1.5\,(g_{m1}/g_{m6})(C_1+C_2) ≈ 5.0$ pF。
- （对于 45° 裕度，同样的规则给出 3.3 pF，因此 60° 需要多用约 70% 的电容。）
