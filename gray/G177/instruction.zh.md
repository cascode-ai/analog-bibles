[图 1]、[图 2] 和 [图 3] 分别为某三级双极型运放（$V_{EE} = 0$）的输入级、第二级和输出级，[图 4] 为输出级及为其提供偏置的反馈环路。求下列条件下该运放的低频小信号电压增益。

- 工作点：共模输入足够低，使 $Q_1$、$Q_2$ 截止；输出向 2-kΩ 负载提供 $I_L = 1$ mA 电流。忽略基极电流计算得到的直流电流为：$|I_{C3}| = |I_{C4}| = 3\ \mu$A；$I_{C9} = I_{C10} = |I_{C13}| = |I_{C14}| = 6\ \mu$A；$|I_{C16}| = |I_{C19}| = 4\ \mu$A（为 pnp 射极跟随器 $Q_{21}$、$Q_{22}$ 提供偏置）；$|I_{C17}| = |I_{C18}| = 21\ \mu$A；$I_{C25} = I_{C26} = I_{C27} = I_{C28} = 10\ \mu$A；$|I_{C61}| = I_{C62} = 6\ \mu$A；$I_{C63} = 33\ \mu$A（来自带发射极负反馈的电流镜 $Q_{62}$–$Q_{63}$，$R_{62} = 14$ kΩ，$R_{63} = 1.2$ kΩ）；$I_{C69} = 6\ \mu$A；$|I_{C74}| = 1.2$ mA，$I_{C75} = 210\ \mu$A；$|I_{C66}| = |I_{C74}|/32$（$Q_{74}$ 的发射极面积是 $Q_{66}$ 的 32 倍）；$I_{R65} = V_{EB74}/R_{65}$，其中 $V_{EB74} = 0.75$ V。在该工作点（$|I_{C74}| \gg I_{C75}$ 时），[图 4] 的输出级偏置环路使 $I_{C75}$ 几乎保持恒定；[图 4] 中 $Q_{39}$ 的基极电压以及 $Q_{39}$–$Q_{40}$ 的尾电流均为恒定值。
- 基极电流：在直流偏置计算中忽略 $\beta_F$ 的影响，但在重新估算 $I_{C64}$、$|I_{C65}|$ 和 $I_{C68}$ 时除外：在 $|I_{C65}|$（流过 $I_{R65}$ 加上该基极电流）中计入 $Q_{74}$ 的基极电流，在 $I_{C64}$（流过 $I_{C63}$ 减去该基极电流）中计入 $Q_{65}$ 的基极电流，在 $I_{C68}$（流过 $I_{C69}$ 加上该基极电流）中计入 $Q_{75}$ 的基极电流，并计入 $Q_{62}$–$Q_{63}$ 的基极电流使 $I_{C62}$（从而 $I_{C63}$）减小的影响。
- 小信号参数：$\beta_{F(npn)} = \beta_{0(npn)} = 80$，$\beta_{F(pnp)} = \beta_{0(pnp)} = 20$，$V_{A(npn)} = 30$ V，$V_{A(pnp)} = 20$ V，$V_T = 26$ mV。忽略所有电容（以及 $R_{25}$、$R_{26}$）和正常情况下截止的晶体管（$Q_{23}$、$Q_{24}$、$Q_{67}$、$Q_{70}$、$Q_{72}$、$Q_{73}$）。
