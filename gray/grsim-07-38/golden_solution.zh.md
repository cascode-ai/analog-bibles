- 偏置链：$V_{GS6} = 0.7 + \sqrt{2(100\ \mu)/(60\ \mu\cdot50)} = 0.958$ V；$|V_{GS4}| = 0.7 + \sqrt{2(100\ \mu)/(30\ \mu\cdot50)} = 1.065$ V；$|V_{GS5}| = 5 - 0.958 - 1.065 = 2.977$ V（无体效应），$|V_{ov5}| = 2.277$ V → $(W/L)_5 = 2(100\ \mu)/(30\ \mu\times2.277^2) = 1.29$。
- $M_2$（100/2，100 µA）：$V_{GS2} = 0.958$ V，因此 $M_1$ 的源极位于 0.958 V；$V_{t1} = 0.7 + 0.4(\sqrt{1.558} - \sqrt{0.6}) = 0.889$ V；$V_{ov1} = 2.5 - 0.958 - 0.889 = 0.652$ V → $(W/L)_1 = 2(100\ \mu)/(60\ \mu\times0.652^2) = 7.83$。
- 小信号：$g_{m1} = 0.307$ mA/V，$g_{mb1} = 0.049$ mA/V，$r_o = 1/(0.03\times100\ \mu) = 333\ \mathrm{k\Omega}$；跟随器增益 $g_{m1}/(g_{m1} + g_{mb1} + 2/r_o) = 0.848$，跟随器输出电阻 2.76 kΩ；$g_{m2} = 0.775$ mA/V，$R_{\text{out}} = r_{o2}\|r_{o3} = 167\ \mathrm{k\Omega}$，第二级增益 −129；总增益约 −109。
- 零值时间常数（zero-value time constant）（主要项）：$C_{gd2}$（30 fF）看到的电阻为 $2.76\ \mathrm{k} + 167\ \mathrm{k} + g_{m2}(167\ \mathrm{k})(2.76\ \mathrm{k}) \approx 0.53$ MΩ → 15.8 ns；$C_{gd3}$（30 fF，从输出端接到 $M_3$/$M_4$ 栅极节点，该节点约 1.6 kΩ）看到约 0.27 MΩ → 8.0 ns；$C_{db2}$ 和 $C_{db3}$（2.5 V 时各 35 fF）看到 $R_{\text{out}}$ → 各 5.9 ns；偏置节点和 $M_2$ 栅极的各项约 2.7 ns。$T_0 \approx 38$ ns → $f_{-3\text{dB}} \approx 4.2$ MHz。
