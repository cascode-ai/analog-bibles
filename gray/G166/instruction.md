A two-stage CMOS op amp uses an n-channel differential input pair $M_1$–$M_2$ (fed by a tail current source) and a p-channel current-mirror load $M_3$–$M_4$ ($M_3$ diode-connected). Calculate its random input offset voltage, assuming the matching is perfect except that $V_{t3}-V_{t4} = 10$ mV, that all transistors have equal $W/L$ and operate in the active region, and ignoring the second stage and short-channel effects. Use the square-law model with $\mu_nC_{ox} = 194\ \mu\mathrm{A/V^2}$ and $\mu_pC_{ox} = 64.7\ \mu\mathrm{A/V^2}$. Give the offset as the voltage $V_{G1}-V_{G2}$ needed to balance the first stage.
