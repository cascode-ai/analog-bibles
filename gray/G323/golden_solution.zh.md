一种有效设计（完整的 $g_mR \gg 1$ 模型，计入 $C_0$）：$C_{m1} ≈ 3.4$ pF（复数极点 $p_{2,3}$，$Q ≈ 0.71$），$C_{m2} ≈ 6.1$ pF，PM ≈ 60°。同一模型下的其他有效选择：$C_{m1} = 2$ pF 配 $C_{m2} ≈ 4.4$ pF；$C_{m1} ≈ 1.8$ pF 配 $C_{m2} ≈ 4.1$ pF（$Q ≈ 1$）。若忽略 $C_0$（$C_0 \ll C_{m2}$），对应的设计为 $C_{m1} ≈ 3.5$ pF、$C_{m2} ≈ 5.8$ pF（$Q = 0.707$）以及 $C_{m1} = 2$ pF、$C_{m2} ≈ 3.9$ pF。解是一个单参数族（只有一个相位裕度条件，却有两个电容）；这些值与 $g_{m1}$ 无关。

- 主极点（dominant pole）$p_1 ≈ -1/(g_{m1}R_1g_{m2}R_2R_0C_{m2})$；在其上方，环路增益为 $T(s) ≈ \dfrac{g_{m0}}{sC_{m2}}\cdot\dfrac{1}{D'(s)}$，其中
$D'(s) = 1 + \left[\dfrac{(g_{m2} - g_{m1})C_{m1}}{g_{m1}g_{m2}} + \dfrac{C_0C_{m1}}{g_{m1}C_{m2}}\right]s + \dfrac{C_1C_2 + C_{m1}(C_1 + C_2) + C_0(C_1C_2 + C_1C_{m1} + C_1C_{m2} + C_2C_{m1} + C_{m1}C_{m2})/C_{m2}}{g_{m1}g_{m2}}s^2$。
忽略 $C_0$ 得到较简单的 $D'(s) = 1 + \dfrac{(g_{m2} - g_{m1})C_{m1}}{g_{m1}g_{m2}}s + \dfrac{C_1C_2 + C_{m1}(C_1 + C_2)}{g_{m1}g_{m2}}s^2 = 1 + \dfrac{5C_{m1}}{6g_{m1}}s + \dfrac{3 + 6.5C_{m1}}{6g_{m1}^2}s^2$（电容单位为 pF）；对给定的 $C_0 = 0.5$ pF，$C_0$ 项使 $s$ 系数增大约 10%，使 $s^2$ 系数增大约 16%。
- 当 $4a_3/a_1 > (a_2/a_1)^2$，即 $C_{m1} \lesssim 7$ pF 时（两种模型均如此），$p_2, p_3$ 为复数。选取类巴特沃斯（Butterworth）极点对，$Q = \sqrt{a_3/a_1}\,/(a_2/a_1) = 0.707$，则（忽略 $C_0$）$C_{m1} = 3.53$ pF，$p_{2,3} = (-0.34 \pm j0.34)\,g_{m1}/\text{pF}$（$\omega_0 = 0.48\,g_{m1}/$pF）；计入 $C_0$ 时，$C_{m1} = 3.41$ pF，$p_{2,3} = (-0.32 \pm j0.32)\,g_{m1}/\text{pF}$。
- 然后选择 $C_{m2}$，使 $|T| = 1$ 处 $T(j\omega)$ 的相位为 −120°：忽略 $C_0$ 且 $C_{m1} = 3.53$ pF 时得 $C_{m2} = 5.79$ pF，穿越频率 $\omega_c = 0.171\,g_{m1}/$pF（例如 $g_{m1}$ = 1 mA/V 时为 171 Mrad/s），$D'$ 贡献的相移为 30°；计入 $C_0$ 时，$C_{m1} = 3.41$ pF 给出 $C_{m2} = 6.14$ pF，$\omega_c = 0.162\,g_{m1}/$pF。在完整模型中检验，忽略 $C_0$ 得到的组合（3.53, 5.79 pF）给出 PM ≈ 57°，而（2, 3.9 pF）只有 ≈ 55°。
- 与按 45° 进行的实极点大间隔设计（$C_{m1} ≈ 16$ pF，$C_{m2} ≈ 13$ pF）相比，复数极点设计所用电容小得多，单位增益频率（$g_{m0}/C_{m2}$）约为其 2.3 倍。
