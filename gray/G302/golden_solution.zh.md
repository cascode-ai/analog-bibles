$f \approx 0.058$ 时不稳定（低频环路增益 $T_0 = 11.7$），此时极点在 ±$j$4.36 MHz 处穿过 $j\omega$ 轴。

根轨迹（坐标为 $s/2\pi$，单位 MHz；$T$ 的极点位于 −1、−3、−4）：
- 实轴上的轨迹段：−1 与 −3 之间，以及 −4 的左侧。
- 从 −1 和 −3 出发的两支相遇，并在 $\sigma_i$ = −1.78 MHz 处分离（由 $\tfrac{1}{\sigma+1} + \tfrac{1}{\sigma+3} + \tfrac{1}{\sigma+4} = 0$ 求得），此时 $T_0 = 0.176$（$f = 8.8 \times 10^{-4}$）；它们以直角离开实轴，并弯向渐近线。
- 渐近线为 ±60° 和 180°，与实轴交于 $(-1-3-4)/3 = -2.67$ MHz。
- 从 −4 出发的一支沿实轴向左趋于 −∞（当复极点对到达 $j\omega$ 轴时它位于 −8 MHz）。
- 标定：$f = 0.01$（$T_0 = 2$）：$-5.79$，$-1.10 \pm j2.24$；$f = 0.03$：$-7.0$，$-0.5 \pm j3.43$；$f = 1$（$T_0 = 200$）：$-16.1$，$+4.06 \pm j11.5$（不稳定）。

不稳定：特征方程（characteristic equation）$(s+1)(s+3)(s+4) + 12T_0 = s^3 + 8s^2 + 19s + 12(1+T_0) = 0$ 在 $8 \times 19 = 12(1+T_0)$，即 $T_0 = 11.67$、$f = T_0/200 = 0.058$ 时有位于 $j\omega$ 轴上的根，对应 $\omega = \sqrt{19}$ → 4.36 MHz。若假设根轨迹沿 60° 渐近线走（在 $j2.67\tan 60° = j4.62$ 处穿越），则得到估计值 $T_0 \approx 13.3$，$f \approx 0.066$。
