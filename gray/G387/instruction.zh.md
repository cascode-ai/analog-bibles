[图 1] 所示全差分（fully differential）运放的所有晶体管都工作在有源区（active region），$|V_{ov}| = 0.1$ V，$I_{D5} = 100\ \mu$A（$I_{D1} = I_{D2} = |I_{D3}| = |I_{D4}| = 50\ \mu$A），$V_{An} = 10$ V，$|V_{Ap}| = 20$ V（$r_o = |V_A|/|I_D|$），无体效应；其低频输入阻抗为无穷大。共模反馈（common-mode feedback）采用 [图 2] 中的方案：源极跟随器（source follower）缓冲两个输出，两个相等的电阻 $R_{cs}$ 对其取平均，共模检测放大器将结果与参考电压比较，并驱动 CMC 输入端（$M_5$ 的栅极）。从 $v_{oc}$ 到 $v_{cmc}$ 的共模检测通路的总低频增益为 $a_{cms} = 1$，且跟随器不对运放输出构成负载。

该运放接成 [图 3] 的反馈电路，$R_1 = R_2 = R_3 = R_4 = 100$ MΩ。计算低频闭环增益（closed-loop gain）$A_{dm} = v_{od}/v_{sd}$ 和 $A_{cm} = v_{oc}/v_{sc}$（$v_{sd} = v_{s1} - v_{s2}$，$v_{sc} = (v_{s1} + v_{s2})/2$，$v_{od} = v_{o1} - v_{o2}$，$v_{oc} = (v_{o1} + v_{o2})/2$）。
