所加主极点 $|p_D| \approx 60$ Hz（精确 45° 时为 59.4 Hz）；单位反馈时的带宽名义上 ≈ 300 kHz（环路增益实际在 ≈ 235 kHz 处降到单位值；闭环 −3 dB 频率 ≈ 400 kHz，并有 ≈ 2.4 dB 的峰化）。

- 设计规则：使增益以 −20 dB/dec 从 5000 下降，在第一个原有极点 300 kHz 处降到单位值：$|p_D| = 300\text{ kHz}/5000 = 60$ Hz。在穿越频率处，所加极点贡献 −90°，300 kHz 极点贡献约 −45°，因此 PM ≈ 45°。
- 验证：取 $|p_D| = 60$ Hz 时，环路增益（loop gain）在 ≈ 235 kHz 处为单位值（实际曲线在 300 kHz 处比渐近线低 3 dB），相位 −135.2°，PM ≈ 44.8°。精确 45° 需要 $|p_D| = 59.4$ Hz（穿越频率 233 kHz，此处三个原有极点共贡献 45°）。
- 加反馈后的带宽 ≈ 环路增益为单位值的频率：名义上为 $|p_1| = 300$ kHz（精确值 ≈ 235 kHz）；闭环幅值在 ≈ 400 kHz 处为 −3 dB。
