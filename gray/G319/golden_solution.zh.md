按常用设计准则（环路增益在 $|p_2|$ 处降为单位增益），$C ≈ 0.32$ pF；精确的双极点 45° 点对应 $C ≈ 0.25$ pF。两者都约为相同指标下密勒补偿（Miller compensation）所需电容值的三分之一。

- 采用电流缓冲器模型时的传递函数：$\dfrac{v_o}{i_s} = \dfrac{g_{m6}R_1R_2}{1 + s[R_1C_1 + R_2(C + C_2) + g_{m6}R_1R_2C] + s^2R_1R_2C_1(C_2 + C)}$（没有零点）。
- 极点：$p_1 ≈ -1/(g_{m6}R_1R_2C)$；$p_2 ≈ -\dfrac{g_{m6}}{C + C_2}\cdot\dfrac{C}{C_1}$（由于 $C$ 不给节点 ① 加负载，该极点比密勒补偿时大得多）。
- 环路穿越频率 $\omega_c ≈ T_0|p_1| = 0.5\,g_{m1}/C$（$T_0 = 0.5 \times 2 \times 10^4$）。
- 45°：$0.5\,g_{m1}/C = g_{m6}C/[(C + C_2)C_1]$ → $g_{m6}C^2 = 0.5\,g_{m1}C_1(C + C_2)$ → $2C^2 - 0.025C - 0.2 = 0$（单位 pF、mA/V）→ $C = 0.32$ pF；此时 $|p_2| ≈ 7.7 \times 10^8$ rad/s。
- 用完整的二次分母精确计算相位裕度：$C$ = 0.32 pF 时为 54°；$C$ = 0.25 pF 时为 45°（穿越频率 ≈ 104 MHz）。
