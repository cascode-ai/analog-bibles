利用半边电路（half circuit）的概念，求 [图 1] 所示电路的差模增益（differential-mode gain）$A_{dm} = v_{od}/v_{id}$ 和共模增益（common-mode gain）$A_{cm} = v_{oc}/v_{ic}$，其中 $v_{id} = v_{i1} - v_{i2}$，$v_{ic} = (v_{i1}+v_{i2})/2$，$v_{od} = v_{o1} - v_{o2}$，$v_{oc} = (v_{o1}+v_{o2})/2$。忽略 $r_o$、$r_\mu$ 和 $r_b$；两个电流源 $I_{EE}$ 均为理想电流源。另外计算差模输入电阻和共模输入电阻（纯差模输入时 $R_{id} = v_{id}/i_b$，纯共模输入时 $R_{ic} = v_{ic}/i_b$，$i_b$ 为一个晶体管的基极电流）。用 $R_C$、$R_L$、$R_E$、$\beta_0$ 以及 $g_m = I_C/V_T$（$I_C = \alpha_0 I_{EE}$ 为每个晶体管的直流集电极电流）和 $r_\pi = \beta_0/g_m$ 表示结果。
