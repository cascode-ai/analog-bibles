$T \approx 65.9$（$a = 98.9$，$f = 2/3$）。

- 反馈网络的 h 参数：$f = h_{12f} = R_1/(R_1+R_2) = 2/3$；$h_{11f} = R_1\|R_2 = 66.7$ kΩ 与运放输入端串联；$h_{22f}$：$R_1+R_2 = 300$ kΩ 跨接在输出端。
- 基本放大器：$v_x = v_i\,R_i/(R_i + 66.7\text{k}) = 0.4286\,v_i$；$v_o = a_vv_x\,\dfrac{300\text{k}}{300\text{k} + 1\text{M}} = 0.2308\,a_vv_x$；$a = 1000\times0.4286\times0.2308 = 98.9$。
- $T = af = 65.9$（闭环增益 $a/(1+T) = 1.478$，理想值为 1.5）。这是标准的单向二端口划分，忽略了反馈网络的前馈（feedforward）$h_{21f} = -2/3$（与 $h_{21a} = -a_vR_i/R_o = -50$ 相比）；若将其保留在前向项中，则得 $T = 66.8$。
- 并非同一个量：受控源 $a_v$ 的回归比（return ratio）（令 $V_i$ 置零，保留全部负载效应）为 $a_v\,\frac{R_1\|R_i}{R_o+R_2+R_1\|R_i} = 35.1$。它是精确的环路量，但并不是这里所要求的 h 参数 $af$；两者之所以不同，是因为二端口划分在另一端口短路/开路的条件下确定 $h_{11f}$ 和 $h_{22f}$ 的负载效应。
