$R_i = r_e = \alpha_0/g_m \approx 103.5\ \Omega$（约 104 Ω），$G_m = g_m = 9.62$ mA/V，$R_o = R_C = 10\ \mathrm{k\Omega}$。

- $g_m = I_C/V_T = 9.62$ mA/V；$\alpha_0 = \beta_0/(\beta_0+1) = 0.995$。
- 基极接地时从发射极看进去的输入电阻：$r_e = r_\pi \| (1/g_m) = \alpha_0/g_m = 0.995 \times 104\ \Omega = 103.5\ \Omega$。
- 输出短路时集电极电流为 $g_m v_e = g_m v_i$，因此 $G_m = g_m$。
- 忽略 $r_o$ 时集电极相当于理想电流源，因此 $R_o = R_C = 10$ kΩ。
