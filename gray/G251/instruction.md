In the shunt-shunt feedback amplifier shown in [Fig. 1], an op amp with feedback resistor $R_F = 100$ kΩ (from the output to the inverting input) is driven by a signal current $i_i$ into the inverting input; the non-inverting input is grounded, and a load resistor $R_L = 15$ kΩ is connected from the output to ground. Model the op amp by an input resistance $R_i = 500$ kΩ between its inputs, an output resistance $R_o = 200$ Ω in series with a controlled source $a_v(v_+ - v_-)$, with $a_v = 75{,}000$. Using two-port feedback analysis (absorb the loading of the feedback network into the basic amplifier, compute the basic-amplifier gain $a$, the feedback factor $f$ and $T = af$, then use $A = a/(1+T)$ and divide the loaded basic-amplifier impedances by $1+T$), calculate the input resistance, the output resistance, the loop transmission (here the loop gain $T = af$) and the closed-loop transresistance $v_o/i_i$.
