- 在 $V_o = 1$ V 时：$V_{t2} = -0.355$ V，$I_D = \tfrac12(200\ \mu)(100)(0.355)^2 = 1.26$ mA，直流输入 $V_I = 0.955$ V；两个器件均饱和（$V_{DS1} = 1$ V，$V_{DS2} = 2$ V > 0.355 V）。
- 求反函数：$\sqrt{0.6 + V_o} = 2(C - V_i)$，其中 $C = 1.2 + 0.5\sqrt{0.6}$，因此 $V_o = 4(C - V_i)^2 - 0.6$——恰好是二次式。在工作点 $C - V_I = 0.5\sqrt{1.6} = 0.632$ 附近展开：$a_1 = -8(0.632) = -5.06$，$a_2 = 4$，$a_3 = 0$。
- $HD_2 = \tfrac12|a_2/a_1|\hat v_i = \tfrac12(4/5.06)(0.01) = 0.0040$；无三次谐波。
