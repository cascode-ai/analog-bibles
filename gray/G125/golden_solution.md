# Golden Solution - G125

## Reference answer

$A_v^+ = a_1 + 2a_2\hat v_i + 3a_3\hat v_i^2$, $A_{vQ} = a_1$, $A_v^- = a_1 - 2a_2\hat v_i + 3a_3\hat v_i^2$, from $A_v = a_1 + 2a_2v_i + 3a_3v_i^2$ evaluated at $v_i = +\hat v_i$, $0$, $-\hat v_i$.

## Grading notes

+2: all three expressions correct. +1: one sign or factor slip in a single term. 0: only $A_{vQ}$ correct, or correct method without final expressions. −2 (asserted as fact): the large-signal ratio $v_o/v_i$ used instead of the derivative, or the $a_3$ term given opposite signs at the two extremes.
