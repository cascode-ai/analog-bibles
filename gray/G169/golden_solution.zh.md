$-V_{SS} + 1.6\ \mathrm{V} \le V_{IC} \le V_{DD} - 1.4\ \mathrm{V}$（用符号表示为 $-V_{SS} + |V_t| + 3|V_{ov}| \le V_{IC} \le V_{DD} - |V_t| - 2|V_{ov}|$）。范围宽度为 $V_{DD}+V_{SS} - 3.0$ V，比不带共源共栅的两级运放窄得多。

- $M_1$–$M_2$ 的公共源极：$V_S = V_{IC} + |V_t| + |V_{ov}| = V_{IC} + 1.2$ V。
- 上限，$M_5$ 处于有源区：$V_{DD} - V_S \ge |V_{ov}|$，因此 $V_{IC} \le V_{DD} - |V_t| - 2|V_{ov}| = V_{DD} - 1.4$ V。
- 下限，$M_{1A}$ 处于有源区。$M_9$ 使共源共栅管的栅极跟随 $V_S$，因此对任何 $V_{IC}$，$M_1$ 都保持在饱和区边缘：其漏极（即 $M_{1A}$ 的源极）位于 $V_S - |V_{ov}| = V_{IC} + 1.0$ V。$M_{1A}$ 的漏极是二极管连接的共源共栅电流镜的顶端：$-V_{SS} + 2(V_t + V_{ov}) = -V_{SS} + 2.4$ V。$M_{1A}$ 需要 $V_{SD} \ge 0.2$ V：$V_{IC} + 1.0 - (-V_{SS} + 2.4) \ge 0.2$，因此 $V_{IC} \ge -V_{SS} + 1.6$ V。
- 另一侧的 $M_2$/$M_{2A}$ 也有相同的限制。与输入对管串联的共源共栅结构牺牲了范围的下端：$M_{1A}$ 的漏极必须比 $-V_{SS}$ 高出两个二极管压降。
