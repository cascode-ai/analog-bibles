从 [图 1] 所示的两级 CMOS 运放出发，将每个晶体管的极性反转，构成一个新的运放：$M_1$–$M_2$ 变为 n 沟道差分对（differential pair），其公共源极由 n 沟道尾电流源（tail current source）$M_5$（源极接 $-V_{SS}$）供电；$M_3$–$M_4$ 变为源极接 $V_{DD}$ 的 p 沟道电流镜（current mirror）负载（$M_3$ 为二极管连接）；$M_6$ 变为 p 沟道共源第二级晶体管（源极接 $V_{DD}$，栅极接 $M_2$ 和 $M_4$ 的漏极），以 n 沟道电流源 $M_7$（源极接 $-V_{SS}$）为负载；$M_8$ 变为二极管连接的 n 沟道晶体管（源极接 $-V_{SS}$），它从 $V_{DD}$ 接收 $I_{BIAS}$，并驱动 $M_5$ 和 $M_7$ 的栅极。所有晶体管都工作在有源区，匹配完美，$I_{BIAS}$ 是与电源无关的理想电流，$|V_{A5}| = |V_{A7}|$，且宽长比满足 $(W/L)_3/(W/L)_6 = (W/L)_4/(W/L)_6 = \tfrac12 (W/L)_5/(W/L)_7$（从而 $M_3$、$M_4$、$M_6$ 的过驱动电压相等）。

求对两个电源的低频电源抑制比（power-supply rejection ratio）$PSRR^+ = A_{dm}/A^+$ 和 $PSRR^- = A_{dm}/A^-$，其中 $A^+ = v_o/v_{dd}$ 和 $A^- = v_o/v_{ss}$ 分别是输入接小信号地时从正、负电源到输出的小信号增益，$A_{dm}$ 为差模增益。结果用过驱动电压（overdrive voltage）和厄利电压（Early voltage）表示（对 p 沟道器件，$V_{ov}$、$V_A$ 为负值）。
