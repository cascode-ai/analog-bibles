An NMOS common-gate stage is driven at its source by a signal current source (source resistance $R_S = \infty$); the gate is at ac ground and the drain feeds a load $R_L = 0$. The transistor is biased at $I_D = 0.5$ mA. NMOS data: $W = 100\ \mu$m, $L_{\text{eff}} = 1.6\ \mu$m, $k_n' = 60\ \mu\mathrm{A/V^2}$, $\lambda = 0$, $\gamma = 0$, $C_{gs} = \tfrac23WL_{\text{eff}}C_{ox}$ with $C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$, $C_{gd} = 14$ fF, $C_{sb} = C_{db} = 0$; square-law model. Calculate the values of the elements in small-signal equivalent circuits for the input impedance (looking into the source) and the output impedance (looking into the drain) of the stage, and sketch the magnitudes of these impedances from $f = 100$ kHz to $f = 100$ GHz using log scales.
