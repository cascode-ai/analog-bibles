无 $C_{cs}$ 时：$a_{cms}(s) = \dfrac{1}{1 + sR_{cs}C_1/2}$，极点位于 $s = -2/(R_{cs}C_1)$。

有 $C_{cs}$ 时：$a_{cms}(s) = \dfrac{1 + sR_{cs}C_{cs}}{1 + sR_{cs}(C_{cs} + C_1/2)}$，在 $-1/(R_{cs}C_{cs})$ 处有一个左半平面零点（left-half-plane zero），在 $-1/[R_{cs}(C_{cs} + C_1/2)]$ 处有一个极点；高频增益为 $2C_{cs}/(2C_{cs} + C_1)$，而不再是 0。

- 对于共模输出（$v_{o1} = v_{o2} = v_{oc}$），两条支路并联：$R_{cs}/2$（或 $Z/2$，其中 $Z = R_{cs}\|1/(sC_{cs})$）驱动 $C_1$，因此 $v_{cms} = v_{oc}/(1 + sC_1Z/2)$。代入 $Z = R_{cs}/(1 + sR_{cs}C_{cs})$ 即得结果。
- 作用：该零点几乎抵消该极点（若 $C_{cs} \gg C_1/2$，二者构成间距很近的零极点对）。于是共模检测器在高频下成为一个电容分压器（capacitive divider），增益接近 1，相位滞后很小，从而改善共模反馈（CMFB）环路的相位裕度（phase margin）。代价是运放输出端的容性负载增加：每个 $C_{cs}$ 都接到差模交流地的中点，因此直接计入差模负载电容。
