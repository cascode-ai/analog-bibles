Model the op amp by an input resistance $R_i = 500$ kΩ between its inputs, an output resistance $R_o = 200$ Ω in series with a controlled source $a_v(v_+ - v_-)$, with $a_v = 75{,}000$. Using return-ratio analysis for the controlled source $a_v$ (return ratio $\mathcal{R}$, asymptotic gain $A_\infty$, direct feedthrough $d$, closed-loop gain $A = A_\infty\frac{\mathcal{R}}{1+\mathcal{R}} + \frac{d}{1+\mathcal{R}}$, and Blackman's formula $Z = Z(a_v{=}0)\,\frac{1+\mathcal{R}(\text{port shorted})}{1+\mathcal{R}(\text{port open})}$), calculate the input resistance, the output resistance, the loop transmission (here the return ratio $\mathcal{R}$) and the closed-loop transresistance $v_o/i_i$.
