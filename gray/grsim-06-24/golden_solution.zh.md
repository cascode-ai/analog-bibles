(a) 共模输入范围：
$-V_{SS} + V_{t1} + 2V_{ovn} \le V_{IC} \le -V_{SS} + V_{t1} + V_{t3} + V_{ovn} + V$，
其中 $V_{t1}$ 为输入管的阈值，$V_{t3}$ 为二极管连接的镜像管的阈值。
- 下限：$I_1$ 晶体管需要 $V_{DS} \ge V_{ovn}$，而公共源极位于 $V_{IC} - V_{t1} - V_{ovn}$。
- 上限：输入管漏极位于二极管电压加 $V$，即 $-V_{SS} + V_{t3} + V_{ovn} + V$，而输入管需要 $V_{GD} \le V_{t1}$。
- p 沟道电流源 $I_3$ 必须保持在有源区：$V \le V_{DD} + V_{SS} - V_{t3} - V_{ovn} - |V_{ovp}|$。取这一最大 $V$ 时，上限变为 $V_{DD} - |V_{ovp}| + V_{t1}$，即可以包含 $V_{DD}$。

输出摆幅：$-V_{SS} + V_{ovn} \le V_O \le V_{DD} - |V_{ovp}|$（最大峰峰值为 $V_{DD} + V_{SS} - V_{ovn} - |V_{ovp}|$）。它只受第二级 n 沟道驱动管和 p 沟道电流源 $I_2$ 的限制，与 $V$ 无关。电平移位使第一级的漏极可以处于较高电位（共模范围好），而电流镜和第二级栅极则位于比 $-V_{SS}$ 高一个 $V_{GS}$ 的电位。

(b) 设计与 I–V 特性：
- $V = V_{GS1} + V_{GS2}$：$M_1$（栅极接 +）流过 $I_B$，$M_2$（栅极接 $M_1$ 的源极，漏极接 +，源极接 −）流过 $I$。因此 $V = 2V_t + V_{ov1} + V_{ov2} = 1.5$ V，得 $V_{ov1} + V_{ov2} = 0.3$ V。
- 小信号电阻：$M_1$ 的电流固定，因此 $v_{gs2} = v$，$r = 1/g_{m2} = V_{ov2}/(2I)$。$r < 1$ kΩ 要求 $V_{ov2} < 0.2$ V。
- 选择：$V_{ov1} = V_{ov2} = 0.15$ V，$(W/L)_1 = (W/L)_2 = 2(100\ \mu)/(194\ \mu\times0.15^2) \approx 46$，$r = 750\ \Omega$。其他可行的选择：$V_{ov2} = 0.1$ V，$V_{ov1} = 0.2$ V，$(W/L)_2 = 103$，$(W/L)_1 = 26$，$r = 500\ \Omega$。
- 大信号 I–V 特性（下端接 $-V_{SS}$，λ = 0）：
  - 当 $V < V_{GS1} + V_t = 1.35$ V 时 $I = 0$；
  - 高于此值时，$M_2$ 饱和（$V_{DS2} = V > V_{GS2} - V_t$），因此 $I = \tfrac12\mu_nC_{ox}(W/L)_2(V - 1.35)^2 = 100\ \mu\mathrm{A}\,[(V-1.35)/0.15]^2$：1.5 V 时为 100 μA，1.65 V 时为 400 μA（抛物线）。
  - 当 $V$ 低于约 $V_{GS1} = 0.75$ V 时，理想的 $I_B$ 会迫使 $M_1$ 的源极低于 $-V_{SS}$。若用晶体管电流源，它在此处会失效，但这不影响已经为零的 $I$。
