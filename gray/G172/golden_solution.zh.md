一种可行的设计（电流：$|I_{D1}| = |I_{D2}| = I$，$|I_{D5}| = 2I$，$I_{D11} = I_{D12} = 2I$，因此每个共源共栅支路流过 $I$；$\mu_n/\mu_p = 3$）。其输出摆幅为 $-V_{SS} + 3V_{ov} \le V_O \le V_{DD} - 3|V_{ov}|$，即峰峰值 $V_{DD}+V_{SS} - 6|V_{ov}|$。

电路图：
- p 沟道输入对管 $M_1$、$M_2$，尾电流源 $M_5$（$V_{BIAS1}$）接 $V_{DD}$。折叠电流源 $M_{11}$、$M_{12}$（n 沟道，接 $-V_{SS}$）。
- $M_{11}$ 上叠放 n 沟道共源共栅管 $M_{1A}$/$M_{1B}$，$M_{12}$ 上叠放 $M_{2A}$/$M_{2B}$，栅极分别接 $V_{CN1}$ 和 $V_{CN2}$。
- p 沟道三层叠放电流镜 $M_3$/$M_{3A}$/$M_{3B}$（输入侧，$M_{3B}$ 的漏极接 $M_{1B}$ 的漏极）和 $M_4$/$M_{4A}$/$M_{4B}$（输出侧，$M_{4B}$ 的漏极 = 输出 = $M_{2B}$ 的漏极）。
- $M_3$、$M_4$ 的栅极接 $M_{3B}$ 的漏极（电流镜输入节点），因此 $M_3$ 不受 $V_{SD} = V_{SG}$ 的限制。$M_{3A}$/$M_{4A}$ 和 $M_{3B}$/$M_{4B}$ 的栅极分别接偏置电压 $V_{CP1} = V_{DD} - |V_t| - 2|V_{ov}|$ 和 $V_{CP2} = V_{DD} - |V_t| - 3|V_{ov}|$，因此 $M_3$、$M_4$、$M_{3A}$、$M_{4A}$ 都工作在 $V_{SD} = |V_{ov}|$。
- n 侧栅极偏置：$V_{BIAS3}$（$M_{11}$、$M_{12}$ 的栅极）$= -V_{SS} + V_t + V_{ov}$；$V_{CN1} = -V_{SS} + V_t + 2V_{ov}$；$V_{CN2} = -V_{SS} + V_t + 3V_{ov}$，因此 $M_{11}$、$M_{1A}$（以及 $M_{12}$、$M_{2A}$）工作在 $V_{DS} = V_{ov}$。
- 偏置产生电路：二极管连接的器件，每个都注入电流 $I$。单位 $W/L$ 的二极管给出 $V_t + V_{ov}$；$W/L$ 缩小 4 倍时给出 $V_t + 2V_{ov}$；缩小 9 倍时给出 $V_t + 3V_{ov}$。

W/L（过驱动电压相等，$W/L \propto |I_D|/\mu$）：
- p 沟道，电流为 $I$：$M_1$、$M_2$、$M_3$、$M_4$、$M_{3A}$、$M_{4A}$、$M_{3B}$、$M_{4B}$：$1\times(W/L)_1$。$M_5$（$2I$）：$2(W/L)_1$。
- n 沟道：$M_{11}$、$M_{12}$（$2I$）：$2\times\frac13 = \frac23(W/L)_1$。$M_{1A}$、$M_{2A}$、$M_{1B}$、$M_{2B}$（$I$）：$\frac13(W/L)_1$。
- 偏置二极管（电流为 $I$）：p 沟道 $V_{BIAS1}$ 二极管 $1\times$，$V_{CP1}$ 二极管 $\frac14$，$V_{CP2}$ 二极管 $\frac19$。n 沟道 $V_{BIAS3}$ 二极管 $\frac13$，$V_{CN1}$ 二极管 $\frac1{12}$，$V_{CN2}$ 二极管 $\frac1{27}$（均乘以 $(W/L)_1$）。

检查：
- 输出高端：$M_4$、$M_{4A}$ 各占 $|V_{ov}|$，再加上 $M_{4B}$ 的过驱动电压，得 $V_O \le V_{DD} - 3|V_{ov}|$。输出低端：$M_{12}$、$M_{2A}$ 各占 $V_{ov}$，再加上 $M_{2B}$，得 $V_O \ge -V_{SS} + 3V_{ov}$。
- 在输入侧，$M_{3B}$ 的 $V_{SD} = |V_t| - |V_{ov}|$，这要求 $|V_t| \ge 2|V_{ov}|$。
- 输出电阻和增益提高到单层共源共栅结构的约 $g_m r_o$ 倍（增益量级为 $g_{m1}\,[(g_mr_o)^2 r_o \parallel (g_mr_o)^2(r_{o2}\parallel r_{o12})]$），代价是摆幅两端各多损失一个过驱动电压。
