外延层厚度约为 5.8 μm（525 mV 的晶圆）到约 13.6 μm（560 mV 的晶圆）；外延夹断电阻的方块电阻约为 7.2 kΩ/□（薄外延层，525 mV）到约 1.9 kΩ/□（厚外延层，560 mV）。

- 外延层掺杂：$N_D = 1/(q\mu_n\rho) = 1/(1.6\times10^{-19}\times800\times2) = 3.9\times10^{15}\ \mathrm{cm^{-3}}$。
- 均匀基区：$I_S = qAD_pn_i^2/Q_B$，其中 $Q_B = N_DW_B$（基区中单位面积的施主数），因此 $Q_B = \dfrac{qAD_pn_i^2}{I_C}e^{V_{BE}/V_T}$；$qAD_pn_i^2/I_C = (1.6\times10^{-19})(5.1\times10^{-5})(10)(2.25\times10^{20})/10^{-5} = 1836$ cm⁻²。
- 525 mV：$Q_B = 1836\,e^{20.19} = 1.08\times10^{12}$ cm⁻² → $W_B = Q_B/N_D = 2.8\ \mu$m → $t_{epi} = W_B + 3\ \mu\mathrm{m} = 5.8\ \mu$m。
- 560 mV：$Q_B = 4.15\times10^{12}$ cm⁻² → $W_B = 10.6\ \mu$m → $t_{epi} = 13.6\ \mu$m。
- 外延夹断电阻使用的是覆盖层下方同一段外延层（厚度为 $W_B$）：$R_\square = \rho/W_B = 1/(q\mu_nQ_B)$ = 7.2 kΩ/□（525 mV）和 1.9 kΩ/□（560 mV）。
