开环增益 ≈ 3.9 × 10⁴（≈ 92 dB）；单位增益带宽 ≈ 3.3 × 10⁸ rad/s ≈ 52 MHz；压摆率 = 40 V/μs。

- $L_{\text{eff}} = 1 - 0.18 - 0.1 = 0.72$ μm；$\lambda_n = 0.02/0.72 = 0.0278$ V⁻¹，$\lambda_p = 0.04/0.72 = 0.0556$ V⁻¹。
- 电流：$M_5$ 和 $M_7$ 镜像 $M_8$（尺寸相同），各为 200 μA；$M_1$、$M_2$ 各为 100 μA；$M_6$（100/1，为 $M_4$ 的两倍）流过 200 μA，与 $M_7$ 匹配。
- $g_{m1} = \sqrt{2k'_p(W/L)_1 I_{D1}} = \sqrt{2 \times 64.7\text{ μA/V}^2 \times 208.3 \times 100\text{ μA}} = 1.64$ mA/V（$|V_{ov}|$ = 0.12 V）。
- $R_1 = r_{o2}\|r_{o4} = 180\text{ kΩ}\|360\text{ kΩ} = 120$ kΩ；第一级增益 $g_{m1}R_1 = 197$。
- $g_{m6} = \sqrt{2 \times 194\text{ μA/V}^2 \times 138.9 \times 200\text{ μA}} = 3.28$ mA/V；$R_2 = r_{o6}\|r_{o7} = 180\text{ kΩ}\|90\text{ kΩ} = 60$ kΩ；第二级增益 197。
- $a_0 = 197 \times 197 ≈ 38{,}800$（91.8 dB）。（题目只要求幅值；从图中标为 + 的输入端看，它驱动的是电流镜二极管一侧的 $M_1$，第一级为同相，$M_6$ 反相，因此从该输入端到输出的总增益为负。）
- 零点被消除后，单位增益带宽 $= g_{m1}/C_c = 1.64\text{ mA/V}/5\text{ pF} = 3.28 \times 10^8$ rad/s → 52 MHz。
- 压摆率 $= I_{D5}/C_c = 200\text{ μA}/5\text{ pF} = 40$ V/μs。
