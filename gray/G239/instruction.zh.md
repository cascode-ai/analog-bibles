[图 1] 所示为一个宽带电流放大器的交流电路图（ac schematic），将其中的 MOS 晶体管换成双极 $npn$ 晶体管（栅极 → 基极，漏极 → 集电极，源极 → 发射极）：输入电流 $i_i$ 驱动二极管连接（diode-connected）的 $Q_1$，其基极同时驱动 $Q_2$；输出电流 $i_o$ 是 $Q_2$ 流入交流短路的集电极电流。$Q_2$ 的发射区面积是 $Q_1$ 的四倍，偏置电流为 $I_{C1} = 1$ mA 和 $I_{C2} = 4$ mA。计算低频小信号电流增益 $i_o/i_i$，用零值时间常数法（zero-value time-constant method）估算 −3-dB 频率，并计算小阶跃输入下的 10%～90% 上升时间（rise time）。工作点处的参数：$Q_1$：$\beta = 200$，$\tau_F = 0.2$ ns，$C_\mu = 0.2$ pF，$C_{je} = 1$ pF，$C_{cs} = 1$ pF，$r_b = 0$，$r_o = \infty$。$Q_2$：$\beta = 200$，$\tau_F = 0.2$ ns，$C_\mu = 0.8$ pF，$C_{je} = 4$ pF，$C_{cs} = 4$ pF，$r_b = 0$，$r_o = \infty$。$V_T = 26$ mV；发射极和衬底均接交流地。
