$C \approx 2.2$ pF（由 CMFB 环路决定；此时差模环路的相位裕度大于 45°）。

- 差模环路：反馈系数（feedback factor）$f_{dm} = C_F/(C_F + C_S + C_{idh}) = 5/10.9 = 0.459$；负载 $C_{2d} = C_L + C_F(C_S + C_{idh})/(C_F + C_S + C_{idh}) = 2 + 5(5.9)/10.9 = 4.7$ pF。令环路增益在 $|p_2|$ 处等于单位增益：$g_{m2}f_{dm}/C = g_{m6}/C_{2d}$ → $C = (1.0/1.55)(4.7)(0.459) = 1.39$ pF。
- CMFB 环路：共模负载 $C_{2c} = C_L + C_FC_S/(C_F + C_S) = 2 + 10/7 = 3.43$ pF。第一级从 $v_{cmc}$ 起的共模跨导为 $g_{m5h}$，因此 $g_{m5h}|a_{cms0}|/C = g_{m6}/C_{2c}$ → $C = (0.4/1.55)(2.5)(3.43) = 2.21$ pF。
- 取较大值 $C \approx 2.2$ pF。此时 CMFB 环路的相位裕度为 45°，差模环路则过补偿（PM > 45°，带宽较低）。另一种做法是保持 $C$ = 1.39 pF，并通过拆分 $M_5$ 来减小 $g_{m5h}$。
- 上述判据是常用的主极点判据（穿越频率估计值 = 低频环路增益 × $|p_1|$，令其等于 $|p_2|$）；此时实际穿越频率 ≈ 0.79$|p_2|$，CMFB 环路的 PM ≈ 52°。若改用 $|p_2|$ 处的精确两极点幅值（多一个因子 $1/\sqrt2$），则环路增益恰好在 $|p_2|$ 处达到单位增益时相位裕度恰为 45°，此时 $C \approx 2.21/\sqrt2 \approx 1.56$ pF（由 CMFB 限制；差模 ≈ 0.98 pF）；对所给判据的这种理解同样可以接受。
