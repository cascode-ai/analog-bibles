$R_x = R_1 \parallel R_2 = \dfrac{R_1R_2}{R_1+R_2}$。

- $V_{in} = 0$ 时，同相输入端电压为 $V_+ = -I_B R_x$（偏置电流从地流出，经 $R_x$ 流入输入端）。
- 在反相输入端，令 $V_{out} = 0$ 并利用虚短 $V_- = V_+$ 列 KCL：偏置电流 $I_B$ 必须经由 $R_1$ 和 $R_2$ 提供，二者另一端都接 0 V，因此 $V_- = -I_B (R_1\parallel R_2)$。
- 于是 $V_- = V_+$ 要求 $R_x = R_1 \parallel R_2$：两个输入端看到相同的直流电阻，相等的偏置电流产生相等的压降。该结果与 $I_B$ 的符号无关。
- 若 $R_x = 0$，输出将为 $V_{out} = I_B R_2$。
