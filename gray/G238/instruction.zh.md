[图 1] 所示为一个宽带 MOS 电流放大器的交流电路图（ac schematic）：输入电流 $i_i$ 驱动二极管连接（diode-connected）的 $M_1$，其栅极同时驱动 $M_2$；输出电流 $i_o$ 是 $M_2$ 流入交流短路的漏极电流。$M_2$ 的 $W/L$ 是 $M_1$ 的四倍，偏置电流为 $I_{D1} = 1$ mA 和 $I_{D2} = 4$ mA。计算低频小信号电流增益 $i_o/i_i$，用零值时间常数法（zero-value time-constant method）估算 −3-dB 频率，并计算小阶跃输入下的 10%～90% 上升时间（rise time）。工作点处的参数：$M_1$：$C_{gd} = 0.05$ pF，$C_{gs} = 0.2$ pF，$C_{sb} = C_{db} = 0.09$ pF，$V_{ov} = 0.3$ V，$r_o = \infty$。$M_2$：$C_{gd} = 0.2$ pF，$C_{gs} = 0.8$ pF，$C_{sb} = C_{db} = 0.36$ pF，$V_{ov} = 0.3$ V，$r_o = \infty$。源极和衬底均接交流地。
