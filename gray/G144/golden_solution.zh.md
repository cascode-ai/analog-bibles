将每个器件替换为其互补器件，并将电路在两条电源轨之间上下翻转（$V_{DD} \leftrightarrow -V_{SS}$）：
- $M_2$：n 沟道，源极接 $-V_{SS}$，漏极接 $V_o$，栅极接误差放大器输出节点 X。
- $M_{21}$、$M_{22}$：p 沟道差分对；$M_{21}$ 的栅极 = $V_i$，$M_{22}$ 的栅极 = $V_o$；两源极相连，由 $I_{\text{TAILP}}$ 从 $V_{DD}$ 供电（电流从 $V_{DD}$ 流入共源节点）。$M_{21}$ 的漏极 → 节点 X；$M_{22}$ 的漏极 → 节点 Y。
- $M_{23}$、$M_{24}$：源极接 $-V_{SS}$ 的 n 沟道电流镜；$M_{23}$ 为二极管连接（diode-connected）（栅极 = 漏极 = 节点 Y），$M_{24}$ 的栅极接节点 Y，$M_{24}$ 的漏极 → 节点 X。
- $M_{25}$、$M_{26}$：漏极接 $V_{DD}$ 的 n 沟道共漏管；$M_{25}$ 的源极接节点 Y，$M_{26}$ 的源极接节点 X；二者栅极相连并接到节点 Z。
- $M_{27}$：n 沟道，源极接 $-V_{SS}$，栅极接节点 Y（镜像 $M_{23}$），漏极接节点 Z。
- $I_{\text{BIASP}}$：从 $V_{DD}$ 流入节点 Z（将 Z 上拉，与下拉的 $I_{\text{BIAS}}$ 互补）。
- 衬底：n 沟道接 $-V_{SS}$，p 沟道接 $V_{DD}$（或与上方电路相同）。
极性检查：$V_i$ 升高 → $M_{21}$ 流入 X 的电流减小，而 $M_{24}$ 吸收的电流固定 → $M_{26}$ 必须提供更多电流，因此 X（$M_2$ 的栅极）下降 → $M_2$ 导通减弱 → $V_o$ 升高，与 [图 2] 一致（下方放大器：$+$ 输入为 $V_o$，$-$ 输入为 $V_i$）。偏置环路：$M_{27}$ 和 $M_{25}$ 使 $M_{27}$ 的电流保持为 $I_{\text{BIASP}}$，因此 $I_{D23} = I_{D24} = I_{\text{BIASP}}(W/L)_{23}/(W/L)_{27}$，$I_{D2} = I_{\text{BIASP}}(W/L)_2/(W/L)_{27}$。
