# 详细步骤 - G422

去掉电流镜通路（$M_{25}\to M_5$），让检测器件像 [图 2] 中的 $M_{21A}$、$M_{21B}$ 那样，把电流直接送入第一级节点（$M_1$/$M_3$ 与 $M_2$/$M_4$ 的漏极）。设计由三个要求决定：在给定 $I_{D3}=I_{D4}=150\ \mu$A 下第一级节点满足 KCL；共模环路为负反馈；向两个节点注入相等的（只含共模的）电流。

### 第 1 步 — 尾电流与所需注入电流

$M_5$ 的栅极现在接固定偏置，$|I_{D5}|=200\ \mu$A，故 $|I_{D1}|=|I_{D2}|=100\ \mu$A。在 $M_1$ 漏极列 KCL，PMOS $M_1$ 和注入器件向该节点提供电流，NMOS $M_3$ 吸收电流：

$$
|I_{D1}|+I_{\mathrm{inj}}=I_{D3}
\;\Rightarrow\;
I_{\mathrm{inj}}=150\ \mu\mathrm A-100\ \mu\mathrm A=50\ \mu\mathrm A
$$

即每个节点需注入 50 μA，$M_2$ 漏极同理。由于必须提供（source）电流，检测差分对改用 PMOS 器件（与 [图 1] 中的 NMOS 差分对互补），尾电流源 $M_{26}$、$M_{27}$ 为接 $V_{DD}$ 的 PMOS。

### 第 2 步 — 修改后的共模检测电路

- 差分对 1：PMOS $M_{21}$（栅极接 $V_{o1}$）与 $M_{22}$（栅极接 $V_{CM}$），尾电流 $M_{26}$ = 100 μA。
- 差分对 2：PMOS $M_{23}$（栅极接 $V_{CM}$）与 $M_{24}$（栅极接 $V_{o2}$），尾电流 $M_{27}$ = 100 μA。
- $M_{21}$ 和 $M_{24}$ 的漏极接 $-V_{SS}$。
- 栅极接 $V_{CM}$ 的器件作为注入器件。把每个器件分成相等的两半：$M_{22}\to M_{22A}$、$M_{22B}$，$M_{23}\to M_{23A}$、$M_{23B}$。$M_{22A}$ 和 $M_{23A}$ 的漏极接 $M_1$ 的漏极，$M_{22B}$ 和 $M_{23B}$ 的漏极接 $M_2$ 的漏极。
- 去掉 $M_{25}$。

### 第 3 步 — 偏置电流

平衡时（$V_{oc}=V_{CM}$）每个差分对平分其尾电流。

| 器件 | 电流 |
|---|---|
| $M_5$（固定偏置） | 200 μA |
| $M_1$、$M_2$ | 各 100 μA |
| $M_{26}$、$M_{27}$（PMOS 尾电流源） | 各 100 μA |
| $M_{21}$、$M_{24}$（接 $-V_{SS}$） | 各 50 μA |
| $M_{22A}$、$M_{22B}$、$M_{23A}$、$M_{23B}$ | 各 25 μA |
| 注入每个第一级节点 | $25+25=50$ μA |
| $M_3$、$M_4$ | 各 $100+50=150$ μA ✓ |
| $M_6$、$M_7$、$M_9$、$M_{10}$ | 各 400 μA（不变） |

### 第 4 步 — 共模环路的极性

设 $V_{oc}$ 升高。栅极接输出的 PMOS 器件 $M_{21}$、$M_{24}$ 栅压升高、导通减弱，在尾电流固定的情况下，栅极接 $V_{CM}$ 的器件导通增强。相对于固定的电流沉 $M_3$、$M_4$，注入两个第一级节点的电流增大，这两个节点电位升高。它们驱动 NMOS 共源管 $M_6$、$M_9$ 的栅极，使其导通增强，把两个输出拉低。$V_{oc}$ 最初的升高受到抑制：环路为负反馈。

### 第 5 步 — 注入电流中没有差模分量

尾电流固定、小信号条件下，PMOS 差分对把其栅极电压差转换为该差值的 $\pm g_m/2$ 倍：

$$
i_{22}=+\frac{g_m}2(v_{o1}-V_{CM}),\qquad i_{23}=+\frac{g_m}2(v_{o2}-V_{CM}).
$$

每个第一级节点各得到二者的一半：

$$
i_{\mathrm{inj},1}=i_{\mathrm{inj},2}=\frac{i_{22}+i_{23}}2=\frac{g_m}2\left(\frac{v_{o1}+v_{o2}}2-V_{CM}\right)=\frac{g_m}2(v_{oc}-V_{CM}),
$$

因此差模部分 $\pm v_{od}/2$ 相互抵消，两个节点得到相同的、只含共模的电流。若把 $M_{22}$ 的全部电流送入一个节点，就会增加一条差模反馈通路；若送错节点，这一差模反馈可能变为正反馈。

### 第 6 步 — 与原方案的比较

共模反馈环路不再经过 $M_{25}$–$M_5$ 电流镜，因此电流镜节点的极点从环路中消除。代价是注入器件的漏极电容加在高阻的第一级节点上，降低了该处极点的频率。
