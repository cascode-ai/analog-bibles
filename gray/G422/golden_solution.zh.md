一种可行的设计：
- $M_5$ 的栅极接固定偏置；$|I_{D5}| = 200\ \mu$A，因此 $|I_{D1}| = |I_{D2}| = 100\ \mu$A。去掉 $M_{25}$ 及其与 $M_5$ 的连接。
- $M_1$ 漏极处的 KCL：$|I_{D1}| + I_{\text{inj}} = I_{D3}$，因此每个节点需要注入（流入）$I_{\text{inj}} = 150 - 100 = 50\ \mu$A。由于 $|I_{D1}| = 100\ \mu$A，注入器件必须提供（拉出）电流，因此检测对改为 PMOS 对（NMOS 对的互补形式），PMOS 尾电流源接 $V_{DD}$：$M_{26}$、$M_{27}$ 各 100 μA。（从节点吸收电流的 NMOS 对方案同样可行，只要提高尾电流使 $|I_{D1}| = I_{D3} + I_{\text{sink}}$，例如 $|I_{D5}| = 400\ \mu$A，每个节点吸收 50 μA；此时仍须由栅极接 $V_{CM}$ 的器件作为注入器件，极性同样为负反馈：$V_{oc}$ 升高时它们吸收的电流减小，节点电压升高，输出下降。）
- 对 1：$M_{21}$（栅极接 $V_{o1}$）和 $M_{22}$（栅极接 $V_{CM}$）。对 2：$M_{23}$（栅极接 $V_{CM}$）和 $M_{24}$（栅极接 $V_{o2}$）。$M_{21}$ 和 $M_{24}$ 的漏极接 $-V_{SS}$。由栅极接 $V_{CM}$ 的器件注入电流：把 $M_{22}$ 拆成两半 $M_{22A}$、$M_{22B}$，把 $M_{23}$ 拆成 $M_{23A}$、$M_{23B}$。$M_{22A}$ 和 $M_{23A}$ 接到 $M_1$ 的漏极，$M_{22B}$ 和 $M_{23B}$ 接到 $M_2$ 的漏极。
- 偏置：$V_{oc} = V_{CM}$ 时每对电流按 50/50 分配：$M_{21}$、$M_{24}$ 各 50 μA；$M_{22A}$、$M_{22B}$、$M_{23A}$、$M_{23B}$ 各 25 μA。每个节点得到 25 + 25 = 50 μA，$M_3$、$M_4$ 吸收 150 μA ✓。第二级：$I_{D6} = I_{D7} = I_{D9} = I_{D10} = 400\ \mu$A。
- 极性：若 $V_{oc}$ 升高，栅极接输出端的 PMOS 器件导通电流减小，因此栅极接 $V_{CM}$ 的器件导通电流增大。注入第一级节点的电流增大，节点电压升高，$M_6$/$M_9$ 导通电流增大，输出下降：为负反馈。
- 差模抑制：$M_{22}$ 的电流按 $+g_m(v_{o1} - V_{CM})/2$ 变化，$M_{23}$ 的电流按 $+g_m(v_{o2} - V_{CM})/2$ 变化。每个节点各得到两者的一半，即 $g_m(v_{oc} - V_{CM})/2$，因此差模分量相互抵消。若把 $M_{22}$ 的全部电流送到一个节点，就会引入差模反馈；若送错节点，则会引入差模正反馈。
- 优点：CMFB 环路中没有 $M_5$–$M_{25}$ 镜像极点；代价：检测器件在第一级节点上增加了电容。
