# Golden Solution - G422

## Reference answer

One valid design:
- Gate of $M_5$ goes to a fixed bias; $|I_{D5}| = 200\ \mu$A, so $|I_{D1}| = |I_{D2}| = 100\ \mu$A. $M_{25}$ and its connection to $M_5$ are removed.
- KCL at the drain of $M_1$: $|I_{D1}| + I_{\text{inj}} = I_{D3}$, so each node needs $I_{\text{inj}} = 150 - 100 = 50\ \mu$A sourced into it. With $|I_{D1}| = 100\ \mu$A the injecting devices must source current, so the sense pairs become PMOS pairs (the complement of the NMOS pairs) with PMOS tail sources from $V_{DD}$: $M_{26}$, $M_{27}$ each 100 μA. (An NMOS-pair version that sinks current from the nodes is also valid if the tail is raised so that $|I_{D1}| = I_{D3} + I_{\text{sink}}$, e.g. $|I_{D5}| = 400\ \mu$A with 50 μA sunk per node; the $V_{CM}$-gated devices must still be the injectors, and the polarity is again negative: a rising $V_{oc}$ makes them sink less, so the nodes rise and the outputs fall.)
- Pair 1: $M_{21}$ (gate $V_{o1}$) and $M_{22}$ (gate $V_{CM}$). Pair 2: $M_{23}$ (gate $V_{CM}$) and $M_{24}$ (gate $V_{o2}$). Drains of $M_{21}$ and $M_{24}$ go to $-V_{SS}$. The $V_{CM}$-gated devices inject: split $M_{22}$ into two halves $M_{22A}$, $M_{22B}$ and $M_{23}$ into $M_{23A}$, $M_{23B}$. Connect $M_{22A}$ and $M_{23A}$ to the drain of $M_1$, and $M_{22B}$ and $M_{23B}$ to the drain of $M_2$.
- Bias: at $V_{oc} = V_{CM}$ each pair splits 50/50: $M_{21}$, $M_{24}$ 50 μA each; $M_{22A}$, $M_{22B}$, $M_{23A}$, $M_{23B}$ 25 μA each. Each node receives 25 + 25 = 50 μA and $M_3$, $M_4$ sink 150 μA ✓. Second stages: $I_{D6} = I_{D7} = I_{D9} = I_{D10} = 400\ \mu$A.
- Polarity: if $V_{oc}$ rises, the PMOS devices gated by the outputs conduct less, so the $V_{CM}$-gated devices conduct more. More current is injected into the first-stage nodes, they rise, $M_6$/$M_9$ conduct more and the outputs fall: negative feedback.
- DM rejection: the current of $M_{22}$ varies as $+g_m(v_{o1} - V_{CM})/2$ and that of $M_{23}$ as $+g_m(v_{o2} - V_{CM})/2$. Each node receives half of each, i.e. $g_m(v_{oc} - V_{CM})/2$, so DM components cancel. Sending all of $M_{22}$ to one node would add DM feedback; sending it to the wrong node would add positive DM feedback.
- Advantage: no $M_5$–$M_{25}$ mirror pole in the CMFB loop; cost: the sense devices add capacitance at the first-stage nodes.

## Grading notes

Open design question: accept any design that (1) injects current into the drains of $M_1$/$M_2$ with the tail at a fixed bias, (2) gives negative CM feedback, (3) satisfies KCL with the given $I_{D3} = I_{D4} = 150\ \mu$A (e.g. tail 200 μA and 50 μA injected per side, or another consistent split), and (4) injects equal (CM-only) currents into the two nodes. A version that keeps the NMOS pairs and $M_{25}$ and mirrors $M_{25}$'s current through two PMOS devices into the nodes is acceptable (+1 if the extra mirror pole is not acknowledged; +2 if it is). +2: a complete design with correct polarity, KCL and bias values. +1: correct structure and bias values, with the DM-cancellation or polarity check missing. 0: correct idea with a KCL inconsistency or the polarity left unverified. −2 (asserted as fact): a bias set that violates KCL at the first-stage nodes ($|I_{D1}| + I_{\text{sourced}} - I_{\text{sunk}} \ne I_{D3}$, e.g. NMOS devices sinking current while $|I_{D1}|$ stays at 100 μA), positive CM feedback, or the tail still driven by the CMFB while also injecting with no consistent bias.
