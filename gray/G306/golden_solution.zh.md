（位置以 $s/2\pi$ 表示。）
- $f = 10^{-3}$（$T_0 = 100$）：极点位于 −10.3 kHz 和 −98.1 kHz（仍为实数）；零点位于 −120 kHz。
- $f = 1$（$T_0 = 10^5$）：极点位于 −120.3 kHz 和 −8.31 MHz；零点位于 −120 kHz。

根轨迹：$T$ 的极点位于 −100 Hz 和 −100 kHz，零点位于 −120 kHz。实轴上的轨迹段：−100 Hz 与 −100 kHz 之间，以及 −120 kHz 的左侧。两个极点相向移动，在 −71.0 kHz 处分离（$T_0 = 504$，$f = 5.0 \times 10^{-3}$）；复数分支沿以零点（−120 kHz）为圆心、半径为 $\sqrt{(120 - 0.1)(120 - 100)}$ = 49.0 kHz 的圆移动，并在 −169.0 kHz 处回到实轴（$T_0 = 2854$，$f = 0.0285$）。此后一支向右移动到 −120 kHz 的零点，另一支向左趋于 −∞。只有当 $5.0 \times 10^{-3} < f < 0.0285$ 时极点才是复数。

闭环极点由 $(1 + s/0.1)(1 + s/100) + T_0(1 + s/120) = 0$ 求得（以 kHz 为单位）：
- $T_0 = 100$：$s^2 + 108.4s + 1010 = 0$ → −10.3、−98.1 kHz。
- $T_0 = 10^5$：$s^2 + 8433s + 1.0 \times 10^6 = 0$ → −120.3 kHz、−8.31 MHz。
