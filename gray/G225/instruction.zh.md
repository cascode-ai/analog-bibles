将 [图 1] 所示有源负载（active load）差分电路中的所有双极晶体管换成 MOS 晶体管（$npn$ → $n$ 沟道，$pnp$ → $p$ 沟道；基极 → 栅极，发射极 → 源极，集电极 → 漏极）。调节偏置电压 $V_B$，使 $M_1$ 和 $M_2$ 的漏极直流电位为 +5 V，$R_{B1}$ 和 $R_{B2}$ 的取值使 $I_{D5} = 1$ mA。$W_1 = W_2 = W_5 = W_6 = 100\ \mu$m，$W_3 = W_4 = 50\ \mu$m，$L_{\text{drwn}} = 2\ \mu$m。计算低频小信号电压增益 $v_o/v_i$，并在差模半边电路（half circuit）中用零值时间常数法（zero-value time-constant method）估算差模增益的 −3-dB 频率。

所有晶体管的参数：$L_d = 0.2\ \mu$m，$X_d = 1\ \mu$m（故 $L_{\text{eff}} = L_{\text{drwn}} - 2L_d - X_d = 0.6\ \mu$m），$\gamma = 0$。NMOS：$V_{tn} = 1$ V，$k_n' = 60\ \mu\mathrm{A/V^2}$，$\lambda_n = 1/(100\ \mathrm{V})$，$C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$，$C_{j0} = 0.4\ \mathrm{fF/\mu m^2}$，$C_{jsw0} = 0.4\ \mathrm{fF/\mu m}$。PMOS：$V_{tp} = -1$ V，$k_p' = 20\ \mu\mathrm{A/V^2}$，$|\lambda_p| = 1/(50\ \mathrm{V})$，$C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$，$C_{j0} = 0.2\ \mathrm{fF/\mu m^2}$，$C_{jsw0} = 0.2\ \mathrm{fF/\mu m}$。栅电容：$C_{gs} = \tfrac23WL_{\text{eff}}C_{ox} + WL_dC_{ox}$，$C_{gd} = WL_dC_{ox}$。结电容：$C_{db} = C_{db0}/\sqrt{1 + V_{DB}/\psi_0}$，其中 $\psi_0 = 0.6$ V，$C_{db0} = A_DC_{j0} + P_DC_{jsw0}$，$A_D = (5\ \mu\mathrm{m})W$，$P_D = W$。NMOS 的衬底接 −10 V，PMOS 的衬底接 +10 V。采用平方律模型。
