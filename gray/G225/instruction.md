In the differential circuit with active loads shown in [Fig. 1], all bipolar transistors are replaced by MOS transistors ($npn$ → $n$-channel, $pnp$ → $p$-channel; base → gate, emitter → source, collector → drain). Bias voltage $V_B$ is adjusted so that the drains of $M_1$ and $M_2$ are at +5 V dc, and the values of $R_{B1}$ and $R_{B2}$ set $I_{D5} = 1$ mA. $W_1 = W_2 = W_5 = W_6 = 100\ \mu$m, $W_3 = W_4 = 50\ \mu$m, $L_{\text{drwn}} = 2\ \mu$m. Calculate the low-frequency small-signal voltage gain $v_o/v_i$, and use the zero-value time-constant method in the differential-mode half-circuit to estimate the −3-dB frequency of the differential-mode gain.

Data for all transistors: $L_d = 0.2\ \mu$m, $X_d = 1\ \mu$m (so $L_{\text{eff}} = L_{\text{drwn}} - 2L_d - X_d = 0.6\ \mu$m), $\gamma = 0$. NMOS: $V_{tn} = 1$ V, $k_n' = 60\ \mu\mathrm{A/V^2}$, $\lambda_n = 1/(100\ \mathrm{V})$, $C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$, $C_{j0} = 0.4\ \mathrm{fF/\mu m^2}$, $C_{jsw0} = 0.4\ \mathrm{fF/\mu m}$. PMOS: $V_{tp} = -1$ V, $k_p' = 20\ \mu\mathrm{A/V^2}$, $|\lambda_p| = 1/(50\ \mathrm{V})$, $C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$, $C_{j0} = 0.2\ \mathrm{fF/\mu m^2}$, $C_{jsw0} = 0.2\ \mathrm{fF/\mu m}$. Gate capacitances: $C_{gs} = \tfrac23WL_{\text{eff}}C_{ox} + WL_dC_{ox}$, $C_{gd} = WL_dC_{ox}$. Junction capacitances: $C_{db} = C_{db0}/\sqrt{1 + V_{DB}/\psi_0}$ with $\psi_0 = 0.6$ V, $C_{db0} = A_DC_{j0} + P_DC_{jsw0}$, $A_D = (5\ \mu\mathrm{m})W$, $P_D = W$. NMOS bodies at −10 V, PMOS bodies at +10 V. Square-law model.
