手算分析：
(a) 偏置：由 $V_{GS1} + |V_{GS5}| = |V_{GS6}| + V_{GS3}$，且 $(W/L)_6 = (W/L)_5$、$(W/L)_3 = (W/L)_1$，得 $M_2$、$M_3$、$M_6$、$M_7$ 以及共源共栅电流镜中均为 $I_B = I_1 = 20$ μA。$\beta_n = \mu_nC_{ox}(W/L)_3 = 1.2$ mA/V²，$\beta_p = \mu_pC_{ox}(W/L)_6 = 1.2$ mA/V²，因此 $g_{m3} = g_{m6} = \sqrt{2 \times 1.2\text{ mA/V}^2 \times 20\text{ μA}} = 0.219$ mA/V。
- $G_m = \dfrac{2g_{m3}}{1 + g_{m3}/g_{m6}} = g_{m3} = 0.219$ mA/V。
- $R_o = (g_{m14}r_{o14}r_{o13}) \| (g_{m15}r_{o15}r_{o16})$，其中 $r_o = 1/(0.05 \times 20\text{ μA}) = 1$ MΩ，$g_{m14} = 0.49$ mA/V，$g_{m15} = 0.38$ mA/V：$R_o ≈ 490\text{ MΩ} \| 380\text{ MΩ} ≈ 214$ MΩ。
- 开环增益 $A_v = G_mR_o ≈ 4.7 \times 10^4$（约 93 dB）；单位增益带宽 $G_m/C_L = 21.9$ Mrad/s ≈ 3.5 MHz。
- 大信号：定义 $\beta_s$ 满足 $1/\sqrt{\beta_s} = 1/\sqrt{\beta_n} + 1/\sqrt{\beta_p}$（$\beta_s = 0.3$ mA/V²），由回路 $V_i + V_{GS1} + |V_{GS5}| = V_{GS3} + |V_{GS6}|$ 得 $I_3 = \frac{\beta_s}{2}(V_i + V_0)^2$ 和 $I_7 = \frac{\beta_s}{2}(V_0 - V_i)^2$，其中 $V_0 = \sqrt{2I_1/\beta_s} = 0.365$ V。四个器件全部导通（$|V_i| < V_0$）时：$I_o = I_3 - I_7 = 2\sqrt{2\beta_sI_1}\,V_i = G_mV_i$——严格线性，0.219 mA/V。当 $V_i > V_0$ 时，$M_2$ 和 $M_7$ 截止，$I_o = \frac{\beta_s}{2}(V_i + V_0)^2 = 0.15\text{ mA/V}^2\,(V_i + 0.365\text{ V})^2$（$V_i < -V_0$ 时与之镜像对称）。转折发生在 $|V_i| = \sqrt{2I_1/\beta_s} = \sqrt{8I_1/\beta_n} = 0.365$ V，此时 $|I_o| = 4I_1 = 80$ μA。
(b) 线性模型：单极点，$\tau = C_L/G_m = 45.6$ ns；$V_o(t) = -1.5 + 3(1 - e^{-t/45.6\text{ ns}})$ V（46 ns 时达到 63%，约 210 ns 时误差在 1% 以内）；初始电流 $G_m \times 3$ V = 0.66 mA。实际峰值电流（按大信号规律，$t = 0^+$ 时差模输入为 3 V）：$0.15\text{ mA/V}^2 \times (3.365)^2 ≈ 1.7$ mA，因此实际响应起始速度约为线性预测的 2.6 倍（20 ns 时约 +0.2 V，而线性预测为 −0.44 V），约 185 ns 内建立到 1% 以内；不存在通常意义上的压摆率（slew rate）限制。
预期的仿真结果：开环增益约 90–95 dB，单位增益频率约 3–3.5 MHz，$I_o$–$V_i$ 曲线在约 ±0.37 V 以内为线性、之外为平方律，阶跃响应比线性指数响应快，峰值负载电流约为 1.5–1.7 mA 量级。
