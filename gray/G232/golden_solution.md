# Golden Solution - G232

## Reference answer

$v_o/v_i = -\alpha\,g_mR_L\dfrac{r_\pi}{R_S + r_\pi} = -0.990\times39.5 = -39.1$.

$Q_1$ is a CE stage ($g_m = 38.5$ mA/V, $r_\pi = 2.6\ \mathrm{k\Omega}$) whose collector current passes through the common-base $Q_2$ with current gain $\alpha = \beta/(\beta+1) = 0.990$.
