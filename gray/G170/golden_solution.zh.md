输出范围：$V_{IC} - V_t + V_{ov} \le V_O \le V_{DD} - 2|V_{ov}|$，即 $V_{IC} - 0.8\ \mathrm{V} \le V_O \le V_{DD} - 0.4$ V（摆幅为 $V_{DD} - V_{IC} + 0.4$ V）。最佳值为允许的最低 $V_{IC} = -V_{SS} + V_t + 2V_{ov} = -V_{SS} + 1.4$ V，此时 $-V_{SS} + 0.6\ \mathrm{V} \le V_O \le V_{DD} - 0.4$ V：峰峰值摆幅为 $V_{DD} + V_{SS} - 1.0$ V（比总电源电压少五个过驱动电压）。

电路：n 沟道 $M_1$–$M_2$，尾电流管 $M_5$ 接 $-V_{SS}$；其漏极上接 n 沟道共源共栅管 $M_{1A}$、$M_{2A}$，栅极由 $M_9$ 驱动（从共源节点接出的二极管连接 n 沟道管，由来自 $V_{DD}$ 的 $I_C$ 偏置）；接 $V_{DD}$ 的 p 沟道高摆幅共源共栅电流镜 $M_3/M_{3A}$（输入侧，接 $M_{1A}$）和 $M_4/M_{4A}$（输出侧）；输出取自 $M_{2A}$ 和 $M_{4A}$ 的漏极。

- 摆幅上端：高摆幅电流镜将 $M_4$ 偏置在 $V_{SD4} = |V_{ov}|$，因此只要 $V_O \le V_{DD} - 2|V_{ov}| = V_{DD} - 0.4$ V，$M_{4A}$ 就保持在有源区。这与 $V_{IC}$ 无关。
- 摆幅下端：公共源极 $V_S = V_{IC} - V_t - V_{ov} = V_{IC} - 1.2$ V。$M_9$ 使 $M_2$ 保持在边缘，因此 $M_{2A}$ 的源极位于 $V_S + V_{ov} = V_{IC} - 1.0$ V，$M_{2A}$ 需要 $V_O \ge V_{IC} - 1.0 + 0.2 = V_{IC} - 0.8$ V。最低输出随共模输入变化。
- $V_{IC}$ 的下限由尾电流源决定：由 $V_S + V_{SS} \ge V_{ov}$ 得 $V_{IC} \ge -V_{SS} + V_t + 2V_{ov} = -V_{SS} + 1.4$ V。（其上限由 $M_{1A}$ 相对于电流镜输入节点电压（接近 $V_{DD}$）决定，远高于最佳值，此处无关紧要。）
- 在 $V_{IC} = -V_{SS} + 1.4$ V 时，最低输出为 $-V_{SS} + 0.6$ V（$M_5$、$M_2$、$M_{2A}$ 各占一个过驱动电压），因此摆幅为 $(V_{DD} - 0.4) - (-V_{SS} + 0.6) = V_{DD} + V_{SS} - 1.0$ V。例如 ±1.5 V 电源时摆幅为 2.0 V 峰峰值。
