A technique that allows the return ratio to be simulated using SPICE without disrupting the dc operating point is the following. Choose a point X in the feedback loop where the signal flows from one side (the "return" side, toward the amplifier output) to the other (the "driven" side, toward the amplifier input). (i) Inject an ac test current $i_t$ from ground into node X; with $i_d$ the current flowing from X into the driven side and $i_m$ the current flowing from the return side into X, compute $\mathscr{R}'_i = -i_m/i_d$. (ii) Instead, insert an ac test voltage source $v_t$ in series at X (+ terminal on the driven side); with $v_d$ the voltage of the driven side and $v_m$ the voltage of the return side, compute $\mathscr{R}'_v = -v_m/v_d$. The return ratio is then given by $\dfrac{1}{1 + \mathscr{R}} = \dfrac{1}{1 + \mathscr{R}'_i} + \dfrac{1}{1 + \mathscr{R}'_v}$.
