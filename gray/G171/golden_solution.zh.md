$-V_{SS} - 0.8\ \mathrm{V} \le V_{IC} \le V_{DD} - 1.4\ \mathrm{V}$（用符号表示为 $-V_{SS} + V_{ov} - |V_t| \le V_{IC} \le V_{DD} - |V_t| - 2|V_{ov}|$）。该范围延伸到负电源以下 0.8 V。

- p 沟道对管的公共源极：$V_S = V_{IC} + |V_t| + |V_{ov}| = V_{IC} + 1.2$ V。
- 上限，$M_5$ 处于有源区：$V_{DD} - V_S \ge |V_{ov}|$，因此 $V_{IC} \le V_{DD} - 1.4$ V。
- 下限：$M_{11}$、$M_{12}$ 处于边缘时，$M_1$、$M_2$ 的漏极（折叠节点）位于 $-V_{SS} + V_{ov} = -V_{SS} + 0.2$ V，与 $V_{IC}$ 无关。只要 $V_S - V_{D1} \ge |V_{ov}|$，$M_1$ 就保持在有源区：$V_{IC} + 1.2 - (-V_{SS} + 0.2) \ge 0.2$，因此 $V_{IC} \ge -V_{SS} - 0.8$ V。
- 折叠结构使输入对管的漏极降到比 $-V_{SS}$ 高一个过驱动电压处，而不是高一个二极管压降（两级运放）或两个二极管压降（套筒式）。这就是范围下端好得多的原因。
