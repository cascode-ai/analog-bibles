$M_{11}$ 源极的输入电阻为 $1/g_{m11}$ 时：
$\dfrac{v_o}{i_s} = \dfrac{g_mR_1R_2\,(1 + sC/g_{m11})}{(1 + sR_1C_1)\left[(1 + sR_2C_2)(1 + sC/g_{m11}) + sR_2C\right] + g_mR_1R_2\,sC}$，
它在 $s = -g_{m11}/C$ 处有一个左半平面零点（left-half-plane zero），并多出一个极点；当 $g_{m11} \to \infty$ 时退化为题中给出的表达式。

推导：
- 由于 $r_{o11} = \infty$、$\gamma = 0$，$M_{11}$ 的栅极为交流地，其源极呈现电阻 $1/g_{m11}$。设 $v_s$ 为源极电压，$i_c$ 为从输出端经 $C$ 流入源极的电流；$i_c$ 全部从漏极流入节点 ①。于是 $v_s = i_c/g_{m11}$，$i_c = sC(v_o - v_s)$，因此
$i_c = \dfrac{sC\,v_o}{1 + sC/g_{m11}}$。
- 节点 ①：$-i_s = v_1/R_1 + sC_1v_1 - i_c$。输出节点：$g_mv_1 + v_o/R_2 + sC_2v_o + i_c = 0$。
- 消去 $v_1$ 并在两边同乘 $(1 + sC/g_{m11})$，即得上式。因子 $(1 + sC/g_{m11})$ 出现在分子中，是因为反馈电流 $i_c$ 本身是 $v_o$ 的一阶低通函数，时间常数为 $C/g_{m11}$；该因子在 $s = -g_{m11}/C$ 处为零。
