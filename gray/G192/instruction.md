A MOS source follower has its gate driven from a source with resistance $R_S = 1\ \mathrm{M\Omega}$; $g_m = 0.3$ mA/V and $\gamma = 0$ (no body effect). Model the transistor by $g_m$ and $C_{gs}$ only ($C_{gd} = C_{gb} = C_{sb} = 0$, $r_o = \infty$). The value of $C_{gs}$ is not specified, so express break frequencies in terms of $C_{gs}$. Find the small-signal output impedance $z_o$ looking into the source terminal (load excluded, input source set to zero) and plot its magnitude versus frequency from $f = 10$ kHz to $f = 10$ GHz using log scales, identifying the low- and high-frequency levels, the break frequencies and the slope.
