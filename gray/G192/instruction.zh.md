一个 MOS 源极跟随器（source follower）的栅极由源电阻为 $R_S = 1\ \mathrm{M\Omega}$ 的信号源驱动；$g_m = 0.3$ mA/V，$\gamma = 0$（无体效应）。晶体管仅用 $g_m$ 和 $C_{gs}$ 建模（$C_{gd} = C_{gb} = C_{sb} = 0$，$r_o = \infty$）。$C_{gs}$ 的值未给出，因此用 $C_{gs}$ 表示各转折频率。求从源极看进去的小信号输出阻抗（output impedance）$z_o$（不含负载，输入信号源置零），并在对数坐标下画出其幅值随频率变化的曲线，频率范围为 $f = 10$ kHz 到 $f = 10$ GHz，标出低频和高频电平、各转折频率以及斜率。
