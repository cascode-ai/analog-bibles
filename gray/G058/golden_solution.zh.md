$R_o = (\beta_0+1)(r_o + r_e) = (\beta_0+1) r_o + r_\pi \approx \beta_0 r_o$。

推导：理想电流源驱动的源电阻为无穷大，因此发射极节点只与 $r_e$（接地）和 $r_o$（接集电极）相连。在集电极施加 $v_x$：
- 发射极节点的 KCL：$(v_x - v_e)/r_o = v_e/r_e$，因此 $v_e = v_x r_e/(r_o + r_e)$。
- 流入集电极的电流：$i_x = (v_x - v_e)/r_o - g_m v_e = v_e (1/r_e - g_m) = v_e/r_\pi$（因为 $1/r_e = g_m + 1/r_\pi$）。
- $R_o = v_x/i_x = r_\pi (r_o + r_e)/r_e = (\beta_0 + 1)(r_o + r_e)$。

从物理上看，发射极电流不能变化，因此集电极电压的变化只能改变基极电流：输出电阻提高到约 $\beta_0 r_o$，这是采用发射极负反馈所能达到的最大值。例如，在 $I_C = 250\ \mu$A、$\beta_0 = 200$、$V_A = 130$ V 时，该值约为 105 MΩ。
