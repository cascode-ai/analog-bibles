在 [图 1] 所示的放大级中，将所有双极晶体管换成 $n$ 沟道 MOS 晶体管（基极 → 栅极，发射极 → 源极，集电极 → 漏极）：$M_1$ 和 $M_4$ 是由 10-µA 电流源偏置的源极跟随器（source follower），$M_2$、$M_3$ 构成差分对（differential pair），带有 1-mA 尾电流源（tail current source）和 5-kΩ 漏极电阻；10-kΩ 电阻分别串联在 $M_1$ 和 $M_4$ 的栅极上，$M_1$ 的栅极直流电位为 0 V。对差模半边电路（half circuit）应用零值时间常数法（zero-value time-constant method），计算增益 $v_o/v_i$ 的 −3-dB 频率。

NMOS 参数（所有晶体管）：$W = 100\ \mu$m，$L_{\text{drwn}} = 2\ \mu$m，$L_d = 0.2\ \mu$m，$X_d = 0$（$L_{\text{eff}} = 1.6\ \mu$m），$\lambda = 0$，$k_n' = 60\ \mu\mathrm{A/V^2}$，$\gamma = 0$，$V_t = 1$ V，$C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$，每 µm 栅宽的交叠电容（overlap capacitance）$C_{ol} = 0.15$ fF，故 $C_{gs} = \tfrac23WL_{\text{eff}}C_{ox} + C_{ol}W$，$C_{gd} = C_{ol}W$；$C_{j0} = 0.4\ \mathrm{fF/\mu m^2}$，$C_{jsw0} = 0.4\ \mathrm{fF/\mu m}$。结电容：$C_{sb} = C_{sb0}/\sqrt{1 + V_{SB}/\psi_0}$，$C_{db} = C_{db0}/\sqrt{1 + V_{DB}/\psi_0}$，其中 $\psi_0 = 0.6$ V，$C_{sb0} = C_{db0} = A_DC_{j0} + P_DC_{jsw0}$，$A_D = (5\ \mu\mathrm{m})W$，$P_D = W$。衬底接 −6 V。采用平方律模型；电流源为理想电流源。
