# Golden Solution - G414

## Reference answer

$a_{dm} \approx -66.7$ (−66 including the small mirror-node loading), $R_{od} \approx 133$ kΩ, $a_{cm} \approx +0.66$, $R_{oc} \approx 66.7$ kΩ. Network: series elements $R_{od}/2 = 66.7$ kΩ, shunt element $R_{oc}/2 - R_{od}/4 = 33.3 - 33.3 = 0$.

Currents: $I_{D1} = I_{D2} = |I_{D3}| = |I_{D4}| = 100\ \mu$A; with 1:1 mirrors $|I_{D6}| = |I_{D8}| = I_{D7} = I_{D9} = 100\ \mu$A. So $g_{m1} = 1$ mA/V, $r_{o6} = 200$ kΩ, $r_{o7} = 100$ kΩ, $r_{o6}\|r_{o7} = 66.7$ kΩ, $r_{o5h} = 2(10/200\ \mu\text{A}) = 100$ kΩ.
- DM: the drain current of $M_1$ ($g_{m1}v_{id}/2$) flows into diode $M_3$ and is copied by $M_8$ into $V_{o2}$; $M_2$'s current ($-g_{m1}v_{id}/2$) is copied by $M_6$ into $V_{o1}$. Each output node has resistance $r_{o6}\|r_{o7}$. $v_{o1} = -g_{m1}(v_{id}/2)(66.7\ \text{k})$, $v_{o2} = +g_{m1}(v_{id}/2)(66.7\ \text{k})$, so $a_{dm} = -g_{m1}(r_{o6}\|r_{o7}) = -66.7$ and $R_{od}/2 = 66.7$ kΩ.
- CM: $M_1$, $M_2$ degenerated by $r_{o5h}$: $G_m \approx g_{m1}/(1 + g_{m1}r_{o5h}) \approx 9.8$–10 μA/V. Raising $v_{ic}$ raises both mirrored currents, so both outputs rise: $a_{cm} = +G_m(r_{o6}\|r_{o7}) \approx +0.65$–0.67. $R_{oc} = r_{o6}\|r_{o7} = 66.7$ kΩ (each output is just $r_{o6}\|r_{o7}$, unaffected by the other side).
