[图 1] 所示为一个全差分（fully differential）电流镜运放（current-mirror op amp）：NMOS 输入对 $M_1$–$M_2$，尾电流管为 $M_5$；二极管连接（diode-connected）的 PMOS 负载 $M_3$、$M_4$ 以 1:1 镜像到 $M_8$（输出 $V_{o2}$）和 $M_6$（输出 $V_{o1}$）；输出端接 NMOS 电流源 $M_9$ 和 $M_7$。$M_5$、$M_7$ 和 $M_9$ 的栅极接偏置电压。$M_1$ 与 $M_2$ 匹配，$M_7$ 与 $M_9$ 匹配，$M_3$、$M_4$、$M_6$、$M_8$ 是相同的 PMOS 器件。所有晶体管取 $|V_{ov}| = 0.2$ V，$V_{tn} = -V_{tp} = 0.6$ V，$I_{D5} = 200\ \mu$A，$V_{An} = 10$ V，$|V_{Ap}| = 20$ V（$r_o = |V_A|/|I_D|$），$\gamma = 0$；$V_{DD} = V_{SS} = 1.65$ V，$V_{ic} = 0$。

计算 [图 2] 中戴维南（Thévenin）输出端口模型的低频参数，该模型定义为 $v_{o1} = a_{dm}v_{id}/2 + a_{cm}v_{ic} + (R_{od}/2)i_{od} + R_{oc}i_{oc}$ 和 $v_{o2} = -a_{dm}v_{id}/2 + a_{cm}v_{ic} - (R_{od}/2)i_{od} + R_{oc}i_{oc}$，其中 $v_{id} = v_{i1} - v_{i2}$，$v_{ic} = (v_{i1} + v_{i2})/2$，$i_{od} = (i_{o1} - i_{o2})/2$，$i_{oc} = (i_{o1} + i_{o2})/2$（$i_{o1}$、$i_{o2}$ 流入输出端）。给出 $a_{dm}$、$a_{cm}$、$R_{od}$、$R_{oc}$ 以及该网络的元件值。
