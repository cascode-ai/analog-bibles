电流：$I_{D1} = I_{D2} = |I_{D3}| = |I_{D4}| = 100\ \mu$A；由于是 1:1 镜像，$|I_{D6}| = |I_{D8}| = I_{D7} = I_{D9} = 100\ \mu$A。因此 $g_{m1} = 1$ mA/V，$r_{o6} = 200$ kΩ，$r_{o7} = 100$ kΩ，$r_{o6}\|r_{o7} = 66.7$ kΩ，$r_{o5h} = 2(10/200\ \mu\text{A}) = 100$ kΩ。
- 差模：$M_1$ 的漏极电流（$g_{m1}v_{id}/2$）流入二极管连接的 $M_3$，并由 $M_8$ 复制到 $V_{o2}$；$M_2$ 的电流（$-g_{m1}v_{id}/2$）由 $M_6$ 复制到 $V_{o1}$。每个输出节点的电阻为 $r_{o6}\|r_{o7}$。$v_{o1} = -g_{m1}(v_{id}/2)(66.7\ \text{k})$，$v_{o2} = +g_{m1}(v_{id}/2)(66.7\ \text{k})$，因此 $a_{dm} = -g_{m1}(r_{o6}\|r_{o7}) = -66.7$，$R_{od}/2 = 66.7$ kΩ。
