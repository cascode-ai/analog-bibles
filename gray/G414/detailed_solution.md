# Detailed solution - G414

Each output node is driven only by a mirrored copy of one input transistor's drain current and is loaded by $r_{o6}\parallel r_{o7}$ (or $r_{o8}\parallel r_{o9}$); the two outputs share no node except through the input pair's tail. Find the DM and CM transconductances from the input to the mirrored output currents, the resistance at each output, and then match them to the port model of [Fig. 2].

### Step 1 — Bias currents and small-signal parameters

The pair splits $I_{D5}=200\ \mu\mathrm A$, so $I_{D1}=I_{D2}=|I_{D3}|=|I_{D4}|=100\ \mu\mathrm A$; the 1:1 mirrors give $|I_{D6}|=|I_{D8}|=100\ \mu\mathrm A$, which $M_7$ and $M_9$ must sink, so $I_{D7}=I_{D9}=100\ \mu\mathrm A$. With $g_m=2I_D/|V_{ov}|$ and $r_o=|V_A|/|I_D|$:

| Device | $g_m$ | $r_o$ |
|---|---|---|
| $M_1$, $M_2$ (NMOS, 100 μA) | 1 mA/V | 100 kΩ |
| $M_3$, $M_4$, $M_6$, $M_8$ (PMOS, 100 μA) | 1 mA/V | 200 kΩ |
| $M_7$, $M_9$ (NMOS, 100 μA) | — | 100 kΩ |
| $M_5$ (NMOS, 200 μA) | — | 50 kΩ ($r_{o5h}=100$ kΩ) |

The resistance at each output node is

$$
R=r_{o6}\parallel r_{o7}=200\ \mathrm{k\Omega}\parallel100\ \mathrm{k\Omega}=66.7\ \mathrm{k\Omega}.
$$

### Step 2 — DM gain

For a DM input the tail node is an ac ground. $M_1$ draws $i_{d1}=g_{m1}v_{id}/2$ from diode $M_3$; $M_8$ copies it and pushes it into $V_{o2}$, raising $v_{o2}$. $M_2$ draws $-g_{m1}v_{id}/2$ from $M_4$, which $M_6$ copies into $V_{o1}$. Hence

$$
v_{o1}=-g_{m1}\frac{v_{id}}2R,\qquad v_{o2}=+g_{m1}\frac{v_{id}}2R,
\qquad
a_{dm}=-g_{m1}(r_{o6}\parallel r_{o7})=-(1\ \mathrm{mA/V})(66.7\ \mathrm{k\Omega})=-66.7.
$$

The diode node is not a perfect short: its resistance $1/g_{m3}\parallel r_{o3}\approx1$ kΩ diverts about 1% of $M_1$'s current into $r_{o1}$, and the mirror transfers $g_{m6}/(g_{m3}+1/r_{o3})=0.995$ of the diode current. Including both effects gives $a_{dm}\approx-65.7$, i.e. about $-66$.

### Step 3 — CM gain

For a CM input the tail node moves, and each input transistor is degenerated by half the tail, $r_{o5h}=100$ kΩ. Its drain current per volt of $v_{ic}$ is

$$
G_{m}\approx\frac{g_{m1}}{1+g_{m1}r_{o5h}}=\frac{1\ \mathrm{mA/V}}{1+100}=9.9\ \mu\mathrm{A/V}
$$

(9.75 μA/V after the small diode-node and mirror corrections of Step 2). Raising $v_{ic}$ increases both $I_{D1}$ and $I_{D2}$, so both mirrored currents into the outputs increase and both outputs rise:

$$
a_{cm}=+G_mR\approx+(9.75\ \mu\mathrm{A/V})(66.7\ \mathrm{k\Omega})=+0.65.
$$

### Step 4 — Output resistances

The output nodes are high-impedance nodes driven by $M_6$/$M_7$ and $M_8$/$M_9$; a test current injected into $V_{o1}$ only changes $V_{o1}$, because nothing connects back from $V_{o1}$ to the rest of the circuit. In the model, with $i_{o1}=i$, $i_{o2}=0$ ($i_{od}=i_{oc}=i/2$):

$$
v_{o1}=\left(\frac{R_{od}}4+\frac{R_{oc}}2\right)i=R\,i .
$$

DM test currents ($i_{o1}=-i_{o2}=i$, so $i_{od}=i$, $i_{oc}=0$) give $v_{o1}=(R_{od}/2)i=Ri$, and CM test currents ($i_{o1}=i_{o2}=i$, so $i_{oc}=i$, $i_{od}=0$) give $v_{o1}=R_{oc}i=Ri$:

$$
R_{od}=2R=133\ \mathrm{k\Omega},\qquad R_{oc}=R=66.7\ \mathrm{k\Omega}.
$$

### Step 5 — Element values of the port model

| Element | Value |
|---|---|
| $a_{dm}$ | $-66.7$ ($\approx-66$ with mirror-node loading) |
| $a_{cm}$ | $+0.65$ |
| Series resistors $R_{od}/2$ | 66.7 kΩ each |
| Shunt resistor $R_{oc}/2-R_{od}/4$ | $33.3-33.3=0$ |
| Shunt source $a_{cm}v_{ic}$ | $0.65\,v_{ic}$ |

The shunt resistor is zero because the two outputs are independent: each one alone is $R$ to ground, so a CM test current sees the same resistance as a DM test current.
