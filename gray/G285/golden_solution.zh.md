$T \approx 26.0$（$a = -2.60$ MΩ，$f = -1/R_2 = -10^{-5}$ S）。

- 反馈网络（$R_2$）：$y_{11f} = y_{22f} = 1/R_2$，$f = y_{12f} = -1/R_2$。
- 基本放大器：输入节点电阻为 $R_1\|R_2\|R_i = 200\text{k}\|100\text{k}\|50\text{k} = 28.57$ kΩ，$v_x = -v_-$；输出端：$a_vv_x$ 经 $R_o$ 驱动 $R_2$（100 kΩ），分压系数为 $100/1100 = 0.0909$。$a = -28.57\text{k}\times1000\times0.0909 = -2.597$ MΩ。
- $T = af = 25.97$（闭环增益 $a/(1+T) = -96.3$ kΩ，理想值为 $-R_2 = -100$ kΩ；精确值为 $-96.26$ kΩ）。这是标准的单向划分，忽略了反馈网络的前馈（feedforward）$y_{21f} = -10\ \mu$S（与 $y_{21a} = a_v/R_o = 1$ mS 相比）；若将其保留在前向项中，则得 $T = 25.7$。
- 并非同一个量：受控源 $a_v$ 的回归比（return ratio）（令 $I_i$ 开路，保留全部负载效应）为 $a_v\,\frac{R_1\|R_i}{R_o+R_2+R_1\|R_i} = 35.1$，等价于 $-y_{12f}y_{21a}/[(y_{11a}+y_{11f})(y_{22a}+y_{22f}) - y_{12f}y_{21f}]$，其中 $R_1$ 计入 $y_{11a}$。它是精确的环路量，但不是这里所要求的 y 参数 $af$；两者的差别在于二端口划分所舍弃的 $y_{12f}y_{21f}$ 项。
