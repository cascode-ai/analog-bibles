[图 1] 所示为源极跟随器（source follower）输出级（output stage），其中 $M_1$ 的衬底接 $-V_{DD}$。假设 $V_{DD} = 2.5$ V，$I_Q = 1$ mA，$R_L \to \infty$，$(W/L)_1 = 1000$，$k' = 200\ \mu\mathrm{A/V^2}$，$V_{t0} = 0.7$ V，$\phi_f = 0.3$ V，$\gamma = 0.5\ \mathrm{V^{1/2}}$，且 $V_t = V_{t0} + \gamma\left(\sqrt{2\phi_f + V_{SB}} - \sqrt{2\phi_f}\right)$，无沟道长度调制。输入为 $V_i = V_I + \hat v_i\sin\omega t$，其中 $V_I = 0$，$\hat v_i = 0.5$ V。令 $A_v^+$、$A_{vQ}$、$A_v^-$ 分别为输入处于最大值、直流值和最小值时传输特性的增量斜率 $dV_o/dV_i$，并令 $E^\pm = (A_v^\pm - A_{vQ})/A_{vQ}$。利用小失真关系 $HD_2 \approx (E^+ - E^-)/8$ 和 $HD_3 \approx (E^+ + E^-)/24$，计算 $HD_2$ 和 $HD_3$。将结果与 $HD_2 = 0.0040$ 和 $HD_3 = -1.8\times10^{-4}$ 进行比较，后者是对同一电路的传输特性在静态工作点附近作三阶幂级数（泰勒）展开得到的。
