[图 1] 所示为一个电压并联反馈（shunt–shunt feedback）放大器的交流电路图（ac schematic）：三个共源级（common-source stage）$M_1$–$M_3$，各带 5-kΩ 漏极负载，从输出到 $M_1$ 栅极接一个 10-kΩ 反馈电阻；输入为电流源 $i_i$。每个 MOS 晶体管的 $W = 100\ \mu$m，$L = 1\ \mu$m（$L_d = X_d = 0$，因此 $L_{\text{eff}} = 1\ \mu$m），$I_D = 100\ \mu$A，$k' = \mu_nC_{ox} = 194\ \mu$A/V²，$t_{ox} = 80$ Å（$C_{ox} = \epsilon_{ox}/t_{ox} = 4.31$ fF/µm²）。噪声模型：漏极热噪声 $\overline{i_d^2} = 4kT\frac{2}{3}g_m\Delta f$，闪烁噪声（flicker noise）用折算到栅极的发生器 $\overline{v^2} = \dfrac{K_f}{WLC_{ox}f}\Delta f$ 表示，其中 $K_f = 3\times10^{-24}$ F·V²。忽略栅极电流噪声和经电容耦合的栅极噪声，并忽略器件电容。计算 0.01 Hz 到 100 kHz 带宽内的总等效输入噪声电流（equivalent input noise current）。取 $4kT = 1.66\times10^{-20}$ V·C。
