采用常用设计规则（环路增益在 $|p_2|$ 处降到单位值）时 $C ≈ 1.1$ pF；用精确的双极点传递函数直接数值计算 45° 点，得 $C ≈ 0.76$ pF（取 $C = 1.1$ pF 时实际裕度 ≈ 53°）。

- $a_0 = g_{m1}R_1\,g_{m6}R_2 = 100 \times 200 = 2 \times 10^4$；环路增益 $T_0 = 0.5a_0 = 10^4$。
- $p_1 ≈ -1/(g_{m6}R_1R_2C)$，因此环路穿越频率为 $\omega_c ≈ T_0|p_1| = 0.5\,g_{m1}/C$。
- $p_2 ≈ -g_{m6}C/[C_1C_2 + C(C_1 + C_2)]$。
- 45°：$0.5\,g_{m1}/C = |p_2|$ → $g_{m6}C^2 = 0.5g_{m1}[C_1C_2 + C(C_1+C_2)]$ → $2C^2 - 2.025C - 0.2 = 0$（单位为 pF、mA/V）→ $C = 1.10$ pF。若用 $p_2 ≈ -g_{m6}/(C_1+C_2)$：$C = 0.5 g_{m1}(C_1+C_2)/g_{m6} = 1.01$ pF。
- 此时 $|p_2|$ ≈ 230 Mrad/s，穿越频率 ≈ 230 Mrad/s（名义上 ≈ 36 MHz）。
- 用 $D(s) = 1 + s[(C_2+C)R_2 + (C_1+C)R_1 + g_{m6}R_1R_2C] + s^2R_1R_2(C_1C_2 + CC_1 + CC_2)$ 进行精确验证：$C = 0.76$ pF 时 PM = 45.0°（穿越频率 36 MHz）；$C$ = 1.0 pF 时 ≈ 51°。
