## Reference answer

$v_o/v_s \approx 7.50$ (ideal $1 + R_F/R_{E1} = 7.55$); loop gain $T \approx 169$ (two-port $T = af$, $r_o$ neglected; ≈ 153 with all $r_o$ included in the basic amplifier); $Z_{in} \approx 3.5$ MΩ with the given $V_A$ (all $r_o$ included; $r_{o1}$ bridging collector and emitter of $Q_1$ caps it), ≈ 6.25 MΩ if $r_o$ is neglected; $Z_{out} \approx 0.37$–0.40 Ω. (Full small-signal model with all $r_o$, checked numerically: $v_o/v_s = 7.498$, $Z_{in} = 3.495$ MΩ, $Z_{out} = 0.394$ Ω.)

- Feedback network ($R_F$ and $R_{E1}$, h parameters): $f = R_{E1}/(R_{E1}+R_F) = 290/2190 = 0.1324$; $h_{11f} = R_{E1}\|R_F = 252$ Ω in the emitter of $Q_1$; output loading $R_{E1}+R_F = 2.19$ kΩ in parallel with $R_{E2}$ at the emitter of $Q_3$: $R'_E = 290\|2190 = 256$ Ω.
- Basic amplifier: $R_{in1} = r_{\pi1} + 121\times252 = 36.7$ kΩ; $i_{c1} = 120v_s/R_{in1}$; $v_{c1} = -i_{c1}(R_{L1}\|r_{\pi2})$; $v_{c2} = -g_{m2}v_{c1}(R_{L2}\|R_{in3})$ with $R_{in3} = r_{\pi3} + 121\times256 = 35.3$ kΩ; $v_o = v_{c2}\cdot121\cdot256/R_{in3}$ → $a = 1280$; $T = af = 169$.
- $A = 1280/170 = 7.51$; $Z_{in} = 36.7\text{k}\times170 = 6.25$ MΩ.
- $z_{oa} = R'_E \| [(r_{\pi3} + R_{L2})/(\beta+1)] = 256\|84.9 = 63.8$ Ω; $Z_{out} = 63.8/170 = 0.374$ Ω (exact with $r_o$: 0.39 Ω).
- If the loop gain is instead taken as a return ratio, its value depends on the controlled source chosen (the circuit is the same as in the series-series version, only the output variable differs): ≈ 962, 169, 102 for $g_{m1}$, $g_{m2}$, $g_{m3}$ with $r_o$ neglected (≈ 545, 153, 101 with all $r_o$ included); the two-port $T$ is close to the return ratio of $g_{m2}$. Taking $R_F$ itself as the reference element (port impedance $Z_\Delta$ across the opened $R_F$ with $v_s = 0$, $T = Z_\Delta/R_F$) gives $306.4\text{k}/1.9\text{k} \approx 161$ with all $r_o$ ($\approx 179$ with $r_o$ neglected).
