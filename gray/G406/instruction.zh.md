对于 [图 1] 中的全差分（fully differential）电路，假设运放是理想的：输入电阻无穷大，输出电阻为零，差模增益 $a_{dm} \to -\infty$，共模增益 $a_{cm} = 0$（因此 $v_{oc} = 0$）。在 $R_1 = 1.01$ kΩ、$R_2 = 0.99$ kΩ、$R_3 = R_4 = 5$ kΩ 时，求闭环增益（closed-loop gain）$A_{dm} = v_{od}/v_{sd}$、$A_{cm} = v_{oc}/v_{sc}$、$A_{dm-cm} = v_{oc}/v_{sd}$ 和 $A_{cm-dm} = v_{od}/v_{sc}$。（$v_{sd} = v_{s1} - v_{s2}$，$v_{sc} = (v_{s1} + v_{s2})/2$，$v_{s1}$ 经 $R_1$ 加入；$v_{od} = v_{o1} - v_{o2}$，$v_{oc} = (v_{o1} + v_{o2})/2$，$v_{o1}$ 为上方的输出端。）
