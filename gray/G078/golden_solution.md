# Golden Solution - G078

## Reference answer

$A_{dm} = -10$, $A_{cm} \approx -5.0\times10^{-3}$, $A_{cm-dm} \approx -1.0\times10^{-4}$, $A_{dm-cm} = -0.05$.

With $\bar R = (R_1+R_2)/2 = 10$ kΩ, $\Delta R = R_1 - R_2 = 0.2$ kΩ, $g_m = 1$ mA/V (exact here, since only the loads differ):
- Differential input: by symmetry of the transistors the tail node does not move, $i_{d1} = -i_{d2} = g_m v_{id}/2$. $v_{od} = -\frac{g_m v_{id}}{2}(R_1 + R_2)$ → $A_{dm} = -g_m\bar R = -10$. $v_{oc} = \frac{1}{2}\left(-\frac{g_m v_{id}}{2}R_1 + \frac{g_m v_{id}}{2}R_2\right)$ → $A_{dm-cm} = -g_m\Delta R/4 = -0.05$.
- Common-mode input: each transistor is degenerated by $2r_{\text{tail}}$: $i_{d1} = i_{d2} = g_m v_{ic}/(1 + 2g_m r_{\text{tail}})$. $A_{cm} = -g_m\bar R/(1 + 2g_m r_{\text{tail}}) = -10/2001 = -5.0\times10^{-3}$; $A_{cm-dm} = -g_m\Delta R/(1 + 2g_m r_{\text{tail}}) = -0.2/2001 = -1.0\times10^{-4}$.
- $A_{cm}$ and $A_{cm-dm}$ shrink with $r_{\text{tail}}$, but $A_{dm-cm}$ does not depend on $r_{\text{tail}}$.

## Grading notes

Four results, equal weight. +2: all four magnitudes within ±3% (10, 0.0050, 1.0×10⁻⁴, 0.05) with signs consistent with the stated definitions (all negative). +1: magnitudes right with a sign error in one cross gain, or one slip. 0: $A_{dm}$ and $A_{cm}$ right but the cross gains wrong or missing. −2 (asserted as fact): $A_{cm-dm}$ or $A_{dm-cm}$ claimed to be zero, $A_{dm-cm}$ with a factor $1/(1+2g_m r_{\text{tail}})$ (≈ 2.5×10⁻⁵), $A_{dm} = -g_m\bar R/2$, or $A_{cm}$ without the $2r_{\text{tail}}$ degeneration.
