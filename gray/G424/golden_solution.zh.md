CMIR ≈ 0.57 V 至 1.98 V（原来输入管阈值为 0.5 V 时为 0.77 V 至 2.18 V）。

- 过驱动电压：$V_{ov1} = \sqrt{2(2.0\ \text{mA})/[170\ \mu(10)(133.3)]} = 0.133$ V；$V_{ov5} = V_{ov6} = 0.133$ V（$m$ 和电流相同）；$|V_{ov1A}| = \sqrt{2(2.4\ \text{mA})/[45\ \mu(24)(133.3)]} = 0.183$ V。
- 下限：当 $V_{DS5} = V_{ov5}$ 时 $M_5$、$M_6$ 到达线性区边缘：$V_{IC(\min)} = V_{t1} + V_{ov1} + V_{ov5} = 0.3 + 0.133 + 0.133 \approx 0.57$ V。
- 上限：$M_1$ 在栅极比漏极高 $V_{t1}$ 时进入线性区，而其漏极位于 $M_{1A}$ 的源极：$V_{S1A} = V_{BiasC} + |V_{t1A}| + |V_{ov1A}| = 1.0 + 0.5 + 0.183 = 1.683$ V。$V_{IC(\max)} = V_{S1A} + V_{t1} = 1.98$ V。
- 降低 $V_{t1}$ 使整个范围下移 0.2 V（范围宽度不变）；上端仍略低于 $V_{DD}$ = 2 V。
