从 [图 1] 所示的两级 CMOS 运放出发，将每个晶体管的极性反转，构成一个新的运放：$M_1$–$M_2$ 变为 n 沟道差分对（differential pair），其公共源极由 n 沟道尾电流源（tail current source）$M_5$（源极接 $-V_{SS}$）供电；$M_3$–$M_4$ 变为源极接 $V_{DD}$ 的 p 沟道电流镜（current mirror）负载（$M_3$ 为二极管连接）；$M_6$ 变为 p 沟道共源第二级晶体管（源极接 $V_{DD}$，栅极接 $M_2$ 和 $M_4$ 的漏极），以 n 沟道电流源 $M_7$（源极接 $-V_{SS}$）为负载；$M_8$ 变为二极管连接的 n 沟道晶体管（源极接 $-V_{SS}$），它从 $V_{DD}$ 接收 $I_{BIAS}$，并驱动 $M_5$ 和 $M_7$ 的栅极。$C_C$ 仍接在第一级输出与运放输出之间，$v_i$ 的 + 端接 $M_1$ 的栅极，− 端接 $M_2$ 的栅极。所有晶体管都工作在有源区（平方律模型；过驱动电压 $V_{ov} = V_{GS} - V_t$，厄利电压 $V_A$；对 p 沟道器件二者为负值）。

求该运放的低频小信号电压增益 $v_o/v_i$，分别用晶体管的跨导和输出电阻表示，以及用过驱动电压和厄利电压表示。
