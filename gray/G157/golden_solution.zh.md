$A_v = \dfrac{v_o}{v_i} = -g_{m1}(r_{o2}\parallel r_{o4})\,g_{m6}(r_{o6}\parallel r_{o7}) = -\dfrac{2}{V_{ov1}}\,\dfrac{2}{|V_{ov6}|}\left(\dfrac{V_{A2}|V_{A4}|}{V_{A2}+|V_{A4}|}\right)\left(\dfrac{|V_{A6}|V_{A7}}{|V_{A6}|+V_{A7}}\right)$

- 第一级（带 p 沟道电流镜负载的 n 沟道差分对）：$A_{v1} = G_{m1}R_{o1} = g_{m1}(r_{o2}\parallel r_{o4})$。电流镜将两个漏极电流的变化量相加，因此 $G_{m1} = g_{m1}$。
- 第二级：以电流源 $M_7$ 为负载的 p 沟道共源管 $M_6$：$A_{v2} = -g_{m6}(r_{o6}\parallel r_{o7})$。第二级栅极输入电阻为无穷大，因此两级增益可以直接相乘。
- 符号：提高 $M_1$ 的栅极电压会使 $I_{D1}$ 以及 $M_4$ 中的镜像电流增大，并使 $I_{D2}$ 减小，因此第一级输出升高。这使 $|V_{GS6}|$ 减小，输出下降。与原电路一样，$M_1$ 的栅极是反相输入端。
- 利用 $g_m = 2|I_D|/|V_{ov}|$、$r_o = |V_A|/|I_D|$、$|I_{D2}| = |I_{D4}|$ 和 $|I_{D6}| = |I_{D7}|$，增益即为上式中用过驱动电压/厄利电压表示的形式（每一级约为 $g_mr_o$ 量级，因此 $|A_v| \sim (g_mr_o)^2/4$）。
