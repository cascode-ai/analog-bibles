[图 1] 所示为一个放大级：横向 $pnp$ 晶体管（lateral pnp transistor）$Q_1$（发射极接 $V_{\text{SUPPLY}}$）的基极由电流源 $I_B + i_i$ 驱动，该电流源从基极节点向地抽取电流；其集电极为输出 $v_o$，负载为 $npn$ 电流源 $Q_2$ 的集电极，该电流源镜像二极管连接（diode-connected）的 $Q_3$ 的电流，而后者经一个 30-kΩ 电阻由地偏置。$V_{\text{SUPPLY}} = 10$ V，调节 $I_B$ 使直流 $V_O = 0$ V。计算低频小信号跨阻（transresistance）$v_o/i_i$，并用零值时间常数法（zero-value time-constant method）估算 −3-dB 频率。

参数。$npn$：$\beta = 100$，$I_C = 1$ mA 时 $f_T = 500$ MHz，$C_{\mu0} = 0.7$ pF，$C_{je} = 3$ pF（偏置点处），$C_{cs0} = 2$ pF，$r_b = 0$，$V_A = 120$ V。横向 $pnp$：$\beta = 50$，$I_C = -0.5$ mA 时 $f_T = 4$ MHz，$C_{\mu0} = 1.0$ pF，$C_{je} = 3$ pF（偏置点处），$C_{bs0} = 2$ pF（基区–衬底），$r_b = 0$，$|V_A| = 50$ V。结电容（junction capacitance）服从 $C = C_0/(1 + V_R/\psi_0)^n$，其中 $n = 0.5$，$\psi_0 = 0.55$ V；衬底接 $-V_{\text{SUPPLY}}$。取 $|V_{BE(\text{on})}| = 0.7$ V，$V_T = 26$ mV，在偏置计算中忽略基极电流和厄利效应。取 $C_\pi = \tau_Fg_m + C_{je}$，其中 $\tau_F$ 由 $f_T$ 求得，假设在测量 $f_T$ 的工作点处 $C_\pi + C_\mu = g_m/\omega_T$，且 $C_\mu = C_{\mu0}$、$C_{je}$ 取给定值。
