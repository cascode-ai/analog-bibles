输出仍是每个时钟周期一个台阶的阶梯波，但台阶略小：第一个台阶约为 0.1998 V 而不是 0.2 V，此后每个台阶依次缩小为前一个的约 0.9998 倍。在 20 μs 时输出约为 3.988 V 而不是 4.0 V（约 −0.3 %，即低约 12 mV）。积分器变得略有损耗，其直流增益被限制为 $a$。

- 增益有限时，求和节点电压为 $-V_o/a$ 而不是 0。从 $\phi_1$ 末尾到 $\phi_2$ 末尾应用电荷守恒：
  $-C_SV_s + C_I\left(-\tfrac{V_o[n]}{a} - V_o[n]\right) = C_S\left(-\tfrac{V_o[n+1]}{a}\right) + C_I\left(-\tfrac{V_o[n+1]}{a} - V_o[n+1]\right)$
- 因此 $V_o[n+1] = \alpha V_o[n] + \beta V_s$，其中 $\alpha = \dfrac{C_I(1+1/a)}{C_I(1+1/a) + C_S/a} = 0.99980$，$\beta = \dfrac{C_S}{C_I(1+1/a) + C_S/a} = 0.19976$。
- $V_o[n] = \beta V_s(1-\alpha^n)/(1-\alpha)$：$V_o[1] = 0.1998$ V，$V_o[20] = 3.988$ V。若时钟一直运行，终值将为 $\beta V_s/(1-\alpha) = aV_s = 1000$ V（实际上会先饱和）。因此该积分器是"有损"的，其极点略位于单位圆内。在 20 个周期内，其影响表现为每个台阶约 $(1 + C_S/C_I)/a \approx 0.1\%$ 的增益误差，并缓慢增大。
- $\phi_1$ 期间输出只是保持不变（求和节点被隔离），因此除台阶略小外，波形形状不变。
