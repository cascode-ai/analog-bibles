A fully differential op amp with mismatch is connected in the feedback circuit of [Fig. 1] with $R_1 = R_2 = 10$ kΩ and $R_3 = R_4 = 40$ kΩ. The op amp has infinite input impedance and zero output impedance and is described by
$v_{od} = a_{dm}v_{id} + a_{cm-dm}v_{ic} + a_{cmc-dm}v_{cmc}$ and $v_{oc} = a_{cm}v_{ic} + a_{dm-cm}v_{id} + a_{cmc}v_{cmc}$,
with $a_{dm} = -181$, $a_{cm} = -2.89$, $a_{cmc} = -226$, $a_{dm-cm} = 8.95$, $a_{cm-dm} = 0.15$ and $a_{cmc-dm} = 11.6$. The CMFB circuit is balanced and closes the loop with $v_{cmc} = a_{cms}v_{oc}$, $a_{cms} = 0.76$. Find the closed-loop gains $A_{dm} = v_{od}/v_{sd}$, $A_{cm} = v_{oc}/v_{sc}$, $A_{dm-cm} = v_{oc}/v_{sd}$ and $A_{cm-dm} = v_{od}/v_{sc}$. ($v_{id} = v_{i1} - v_{i2}$, $v_{ic} = (v_{i1} + v_{i2})/2$ at the op-amp inputs; $v_{sd}$, $v_{sc}$ likewise for the sources; $v_{s1}$ drives $R_1$.)
