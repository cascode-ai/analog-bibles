一个 NMOS 共栅级（common-gate stage）在源极由信号电流源 $i_i$ 驱动（源电阻 $R_S = \infty$）；栅极接交流地，漏极接负载 $R_L = 0$（交流短路）。晶体管偏置在 $I_D = 0.5$ mA。NMOS 参数：$W = 100\ \mu$m，$L_{\text{eff}} = 1.6\ \mu$m，$k_n' = 60\ \mu\mathrm{A/V^2}$，$\lambda = 0$，$\gamma = 0$，$C_{gs} = \tfrac23WL_{\text{eff}}C_{ox}$，其中 $C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$，$C_{gd} = 14$ fF，$C_{sb} = C_{db} = 0$；采用平方律模型。求小信号电流增益 $i_o/i_i$（$i_o$ 为流入负载的漏极信号电流）随频率变化的表达式，并确定电流增益比其低频值低 3 dB 时的频率。
