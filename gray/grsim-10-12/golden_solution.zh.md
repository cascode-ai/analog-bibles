当 $|V_i| \le 2\sqrt{2I_1/\beta} = 0.577$ V 时，$I_o = \dfrac{\beta}{4}V_i^2 = 300\ \mu\mathrm{A/V^2} \times V_i^2$，其中 $\beta = \mu_nC_{ox}(W/L)_n = \mu_pC_{ox}(W/L)_p = 1200\ \mu\mathrm{A/V^2}$（NMOS 与 PMOS 的 β 相等）。$I_o$ 从 $V_i = 0$ 时的 0 变化到范围边界处的 100 µA（= $2I_1$）。

推导：
- $M_1$、$M_5$（以及 $M_4$、$M_8$）流过 $I_1$ = 50 µA，故 $V_{GS1} + |V_{GS5}| = 2V_t + 2\sqrt{2I_1/\beta} = 1.4 + 2(0.2887) = 1.977$ V，两种类型器件的 $V_t$ 均为 0.7 V。
- 支路 $M_3$–$M_6$（电流 $I_A$；$M_3$ 的栅极接 − 输入端，$M_6$ 的栅极与 $M_5$ 的栅极相连）：$V_{GS3} + |V_{GS6}| = V_{GS1} + |V_{GS5}| - V_i$ → $2\sqrt{2I_A/\beta} = 2\sqrt{2I_1/\beta} - V_i$。
- 支路 $M_2$–$M_7$（电流 $I_B$；$M_2$ 的栅极接 + 输入端，$M_7$ 的栅极与 $M_8$ 的栅极相连）：$2\sqrt{2I_B/\beta} = 2\sqrt{2I_1/\beta} + V_i$。
- 因此 $I_{A,B} = \left(\sqrt{I_1} \mp V_i\sqrt{\beta/8}\right)^2$，$I_A + I_B = 2I_1 + \beta V_i^2/4$。
- $M_9$–$M_{10}$ 把 $I_A + I_B$ 镜像到输出节点，$M_1$ 和 $M_4$ 各从该节点抽走 $I_1$：$I_o = I_A + I_B - 2I_1 = \beta V_i^2/4$，与 $I_1$ 无关。
- 范围：两条支路都必须导通（$I_A, I_B \ge 0$），故 $|V_i| \le \sqrt{8I_1/\beta} = 0.577$ V。超出此范围后一条支路截止，$I_o = 150\ \mu\mathrm{A/V^2}(|V_i| + 0.577\ \text{V})^2 - 100\ \mu$A，低于平方律（在 $|V_i|$ = 1 V 时为 273 µA，而平方律为 300 µA）。
- 题中建议的偏置（− 输入端 3 V，输出 3.5 V）在此范围内使所有器件保持饱和。

预期仿真结果：直流扫描在 $|V_i| \le 0.577$ V 范围内给出精确的（在数值精度内）$I_o = 300\ \mu\mathrm{A/V^2}\,V_i^2$，且关于 $V_i$ 对称（±0.289 V 时为 25 µA，±0.5 V 时为 75 µA，±0.577 V 时为 100 µA），超出范围后增长变慢。对于 $V_i = V_a\sin\omega t$ 且 $V_a \le 0.577$ V，$I_o = \tfrac{\beta}{8}V_a^2(1 - \cos 2\omega t)$：包含一个直流项和一个二次谐波，二者幅值均为 $150\ \mu\mathrm{A/V^2} \times V_a^2$（$V_a$ = 0.5 V 时为 37.5 µA）。基波在理想情况下为零，只要驱动保持在平方律范围内，就不存在更高次谐波。

评论：该电路起平方器 / 倍频器的作用。只有器件失配或 $V_i$ 中存在直流偏移 $V_0$ 时才会出现基波（幅值为 $(\beta/2)V_0V_a$）。驱动超过 ±0.577 V 会引入 4 次及更高的偶次谐波。
