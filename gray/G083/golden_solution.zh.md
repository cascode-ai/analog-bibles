$(W/L)_6 = (W/L)/5$，$(W/L)_7 = (W/L)/3$。双重共源共栅电流镜：$R_o \approx r_o(1 + g_mr_o)^2 \approx g_m^2r_o^3$；$V_{OUT(\min)} = 3V_{ov}$；输入支路电压为 $2V_t + 4V_{ov}$；系统增益误差 ≈ 0。

尺寸：
- $I = \tfrac{k'}{2}(W/L)V_{ov}^2$（由 $M_8$ 得到）。由 $V_{DS6} = V_{DS7} = V_{ov}$ 和 $V_{GS8} = V_t + V_{ov}$，公共栅极电位为 $V_t + 3V_{ov}$。
- $M_7$：$V_{GS7} = V_t + 2V_{ov}$，$V_{DS7} = V_{ov} < 2V_{ov}$ → 线性区：$I = k'(W/L)_7[2V_{ov}^2 - V_{ov}^2/2] = 1.5k'(W/L)_7V_{ov}^2$ → $(W/L)_7 = (W/L)/3$。
- $M_6$：$V_{GS6} = V_t + 3V_{ov}$，$V_{DS6} = V_{ov}$ → 线性区：$I = k'(W/L)_6[3V_{ov}^2 - V_{ov}^2/2] = 2.5k'(W/L)_6V_{ov}^2$ → $(W/L)_6 = (W/L)/5$。

电流镜（一种可行的接法）：输出支路为 $M_1$（底部）、$M_2$、$M_3$，尺寸均为 $W/L$，栅极分别位于 $V_t + V_{ov}$、$V_t + 2V_{ov}$、$V_t + 3V_{ov}$，因此 $V_{DS1} = V_{DS2} = V_{ov}$。流过 $I_{IN}$ 的输入支路从地往上依次为：$M_A$、$M_B$、$M_C$（$M_1$–$M_3$ 的复制管，栅极接到对应的输出管栅极），然后是 $M_6$–$M_8$ 叠层，$M_6$ 的源极接 $M_C$ 的漏极。$M_C$ 的漏极（= $M_6$ 的源极，电位 $V_t + V_{ov}$）驱动 $M_A$ 和 $M_1$ 的栅极；$M_6$ 的漏极（$V_t + 2V_{ov}$）驱动 $M_B$ 和 $M_2$ 的栅极；$M_7$ 的漏极（$V_t + 3V_{ov}$）驱动 $M_C$ 和 $M_3$ 的栅极；$I_{IN}$ 流入 $M_8$ 的漏极，该漏极与 $M_6$–$M_8$ 的栅极相连（电位 $2V_t + 4V_{ov}$）。
- 输出电阻：$R_{o2} = r_{o2}(1 + g_{m2}r_{o1}) + r_{o1}$，$R_o = r_{o3}(1 + g_{m3}R_{o2}) + R_{o2} \approx r_o(1+g_mr_o)^2 \approx g_m^2r_o^3$。
- 最小输出电压：$V_{DS1} + V_{DS2} + V_{ov3} = 3V_{ov}$。
- 输入电压：到 $M_6$ 源极为 $(V_t + V_{ov})$，加上叠层上的 $V_{ov} + V_{ov} + (V_t + V_{ov})$，共计 $= 2V_t + 4V_{ov}$。
- 可行性：$M_C$ 的漏极位于 $V_t + V_{ov}$，源极位于 $2V_{ov}$，故 $V_{DS,C} = V_t - V_{ov}$；只有当 $V_t \ge 2V_{ov}$ 时它才保持在有源区。
- 系统增益误差：$M_A$ 与 $M_1$ 的 $V_{GS}$ 和 $V_{DS}$（$= V_{ov}$）都相等，唯一的差别（$M_C$ 与 $M_3$ 的 $V_{DS}$）被两级共源共栅衰减，故 $\epsilon \approx 0$。
- （若改为在叠层下方放置单个二极管连接的 $M_A$，得到的栅极电压相同，$R_o$、$V_{OUT(\min)}$ 和输入电压都不变，但 $V_{DS,A} = V_t + V_{ov}$ 而 $V_{DS1} = V_{ov}$，故 $\epsilon \approx -\lambda V_t$，约为百分之几。）
