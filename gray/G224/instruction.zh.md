[图 1] 所示为一个采用有源负载（active load）的差分电路。调节偏置电压 $V_B$，使 $Q_1$ 和 $Q_2$ 的集电极直流电位为 +5 V。偏置电阻为 $R_{B1} = 10\ \mathrm{k\Omega}$ 和 $R_{B2} = 20\ \mathrm{k\Omega}$。计算低频小信号电压增益 $v_o/v_i$，并在差模半边电路（half circuit）中用零值时间常数法（zero-value time-constant method）估算差模增益的 −3-dB 频率。

参数。$npn$：$\beta = 100$，$I_C = 1$ mA 时 $f_T = 500$ MHz，$C_{\mu0} = 0.7$ pF，$C_{je} = 3$ pF（偏置点处），$C_{cs0} = 2$ pF，$r_b = 0$，$V_A = 120$ V。横向 $pnp$（lateral pnp）：$\beta = 50$，$I_C = -0.5$ mA 时 $f_T = 4$ MHz，$C_{\mu0} = 1.0$ pF，$C_{je} = 3$ pF，$C_{bs0} = 2$ pF（基区–衬底），$r_b = 0$，$|V_A| = 50$ V。结电容（junction capacitance）服从 $C = C_0/(1 + V_R/\psi_0)^n$，其中 $n = 0.5$，$\psi_0 = 0.55$ V；衬底接 −10 V。取 $|V_{BE(\text{on})}| = 0.7$ V，$V_T = 26$ mV；偏置计算中忽略基极电流。取 $C_\pi = \tau_Fg_m + C_{je}$，其中 $\tau_F$ 由 $f_T$ 求得，假设在测量 $f_T$ 的工作点处 $C_\pi + C_\mu = g_m/\omega_T$，且 $C_\mu = C_{\mu0}$。
