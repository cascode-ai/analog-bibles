A balanced fully differential circuit displays only odd-order nonlinearity. Use SPICE to verify this fact for the fully differential two-stage CMOS op amp in [Fig. 1] (PMOS input pair $M_1$–$M_2$ with tail $M_5$, NMOS current-source loads $M_3$–$M_4$, second stages $M_6$/$M_7$ and $M_9$/$M_{10}$, Miller capacitors $C$; CMFB by the two NMOS differential pairs $M_{21}$–$M_{24}$, gates at $V_{o1}$, $V_{CM}$, $V_{CM}$, $V_{o2}$, whose current flows through diode-connected $M_{25}$ that drives the gate of $M_5$).

Design data: $V_{DD} = V_{SS} = 1.65$ V, $V_{CM} = 0$, input CM voltage 0 V. Drawn $L = 1\ \mu$m for all devices, $L_{\text{eff}} = 0.82\ \mu$m. Aspect ratios: $(W/L)_{1,2} = 77$, $(W/L)_{3,4} = 4$, $(W/L)_5 = (W/L)_{25} = 25$, $(W/L)_{6,9} = 16$, $(W/L)_{7,10} = 50$, $(W/L)_{21\text{–}24} = 8.4$, $(W/L)_{26,27} = 14$. Bias: $|I_{D1}| = |I_{D2}| = 100\ \mu$A, $|I_{D5}| = 200\ \mu$A, $I_{D6} = I_{D9} = 400\ \mu$A, $I_{D26} = I_{D27} = 200\ \mu$A (set $V_{B1}$, $V_{B2}$, $V_{B3}$ accordingly). Compensation: $C = 1.39$ pF in series with $R_Z = 758\ \Omega$. Process (0.4-μm CMOS): $\mu_nC_{ox} = 194\ \mu\text{A/V}^2$, $\mu_pC_{ox} = 64.7\ \mu\text{A/V}^2$, $V_{tn} = 0.6$ V, $V_{tp} = -0.8$ V, $t_{ox} = 80$ Å, $L_d = 0.09\ \mu$m, $dX_d/dV_{DS} = 0.02\ \mu$m/V (NMOS) and 0.04 μm/V (PMOS) (so $\lambda_n = 0.02/0.82 = 0.024\ \text{V}^{-1}$, $\lambda_p = 0.049\ \text{V}^{-1}$), overlap capacitance 0.35 fF/μm.

(a) Either use SPICE to find the distortion in the output waveform for a low-frequency differential sinusoidal input, or use SPICE to plot the dc transfer characteristic $V_{od}$ versus $V_{id}$ and verify that the characteristic is odd.

(b) Repeat (a) with a 1 percent mismatch between $W_1$ and $W_2$. Observe that even-order nonlinearity now exists.
