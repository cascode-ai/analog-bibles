平衡的全差分（fully differential）电路只表现出奇次非线性（nonlinearity）。用 SPICE 对 [图 1] 中的全差分两级 CMOS 运放验证这一事实（PMOS 输入对 $M_1$–$M_2$，尾电流管为 $M_5$；NMOS 电流源负载 $M_3$–$M_4$；第二级为 $M_6$/$M_7$ 和 $M_9$/$M_{10}$；密勒电容 $C$；共模反馈（CMFB）由两个 NMOS 差分对 $M_{21}$–$M_{24}$ 实现，其栅极分别接 $V_{o1}$、$V_{CM}$、$V_{CM}$、$V_{o2}$，电流流过二极管连接的 $M_{25}$，后者驱动 $M_5$ 的栅极）。

设计数据：$V_{DD} = V_{SS} = 1.65$ V，$V_{CM} = 0$，输入共模电压为 0 V。所有器件的版图沟长 $L = 1\ \mu$m，$L_{\text{eff}} = 0.82\ \mu$m。宽长比：$(W/L)_{1,2} = 77$，$(W/L)_{3,4} = 4$，$(W/L)_5 = (W/L)_{25} = 25$，$(W/L)_{6,9} = 16$，$(W/L)_{7,10} = 50$，$(W/L)_{21\text{–}24} = 8.4$，$(W/L)_{26,27} = 14$。偏置：$|I_{D1}| = |I_{D2}| = 100\ \mu$A，$|I_{D5}| = 200\ \mu$A，$I_{D6} = I_{D9} = 400\ \mu$A，$I_{D26} = I_{D27} = 200\ \mu$A（据此设置 $V_{B1}$、$V_{B2}$、$V_{B3}$）。补偿：$C = 1.39$ pF 与 $R_Z = 758\ \Omega$ 串联。工艺（0.4-μm CMOS）：$\mu_nC_{ox} = 194\ \mu\text{A/V}^2$，$\mu_pC_{ox} = 64.7\ \mu\text{A/V}^2$，$V_{tn} = 0.6$ V，$V_{tp} = -0.8$ V，$t_{ox} = 80$ Å，$L_d = 0.09\ \mu$m，$dX_d/dV_{DS} = 0.02\ \mu$m/V（NMOS）和 0.04 μm/V（PMOS）（故 $\lambda_n = 0.02/0.82 = 0.024\ \text{V}^{-1}$，$\lambda_p = 0.049\ \text{V}^{-1}$），交叠电容 0.35 fF/μm。

(a) 可以用 SPICE 求低频差分正弦输入下输出波形的失真，也可以用 SPICE 画出直流传输特性 $V_{od}$ 随 $V_{id}$ 变化的曲线，并验证该特性是奇函数。

(b) 在 $W_1$ 与 $W_2$ 存在 1% 失配的情况下重复 (a)。观察到此时出现了偶次非线性。
