$-0.6\ \mathrm{V} \le V_{IC} \le V_{CC} - 1.5\ \mathrm{V}$。该范围延伸到负电源轨（$-V_{EE} = 0$）以下 0.6 V。

- 射极跟随器把输入电平抬高一个 $V_{EB}$：$Q_1$/$Q_2$ 的基极位于 $V_{IC} + 0.7$ V，其公共发射极位于 $V_{IC} + 1.4$ V。
- 在纯共模输入下，$Q_1$ 和 $Q_2$ 的集电极位于 $V_{BE3} = 0.7$ V（二极管连接的电流镜）。
- 下限：
  - $Q_1$/$Q_2$ 处于有源区需要 $V_{EC} \ge 0.1$ V：$V_{IC} + 1.4 - 0.7 \ge 0.1$，故 $V_{IC} \ge -0.6$ V。
  - $Q_6$/$Q_7$（集电极接 0 V）需要 $V_{IC} + 0.7 - 0 \ge 0.1$，同样得到 $V_{IC} \ge -0.6$ V。
- 上限：
  - 尾电流源 $Q_5$：$V_{CC} - (V_{IC} + 1.4) \ge 0.1$，故 $V_{IC} \le V_{CC} - 1.5$ V。
  - 跟随器的电流源 $Q_8$/$Q_9$ 需要 $V_{CC} - (V_{IC}+0.7) \ge 0.1$，即 $V_{IC} \le V_{CC} - 0.8$ V，限制较宽松。
- 若没有跟随器，在 $V_{IC} = 0$ 时差分对的集电极（0.7 V）只比其发射极低 0.7 V，范围只能到约 $+0.1$ V 为止。由 $V_{EB}$ 实现的电平移位补足了所缺的电压余度（headroom），同时保留了有源（高增益）电流镜负载。
