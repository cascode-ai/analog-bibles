[图 1] 所示为一个两级双极型放大器。计算低频小信号电压增益 $v_o/v_i$，并用零值时间常数法（zero-value time-constant method）估算 −3-dB 频率。对差分对采用差模半边电路（half circuit）。用 SPICE 估算电路的第一和第二主极点。参数：$npn$：$\beta = 200$，$f_T = 400$ MHz（$I_C = 1$ mA 时），$C_\mu = 0.3$ pF，$C_{je} = 3$ pF，$C_{cs} = 1.5$ pF，$r_b = 0$，$V_{BE(\text{on})} = 0.6$ V，$r_o = \infty$。横向 $pnp$：$\beta = 100$，$f_T = 6$ MHz（$I_C = -0.5$ mA 时），$C_\mu = 0.3$ pF，$C_{je} = 3$ pF，$C_{bs} = 1.5$ pF（基区-衬底），$r_b = 0$，$V_{BE(\text{on})} = -0.6$ V，$r_o = \infty$。（$C_\mu$、$C_{cs}$、$C_{bs}$ 和 $C_{je}$ 的值均为偏置点处的值；采用 $C_\pi = \tau_Fg_m + C_{je}$，其中 $\tau_F$ 由 $f_T$ 求出，即在给定电流下 $C_\pi + C_\mu = g_m/\omega_T$。）$V_T = 26$ mV；计算偏置时忽略基极电流。
