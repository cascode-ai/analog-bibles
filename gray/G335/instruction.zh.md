考虑一个由 [图 1] 等效电路建模的两级 CMOS 运放，其中 $i_s = g_mv_{id}$，$v_{id}$ 为运放的差分输入；输入级跨导与第二级的跨导取相同的值 $g_m$。设 $g_m = 19.7$ mA/V，$R_1 = R_2 = 6.67$ kΩ，$C_1 = C_2 = C = 2$ pF。施加与频率无关的负反馈，当反馈系数（feedback factor）$f$ 从 0 变化到 1 时，计算并画出根轨迹（root locus）草图。计算极点变为复数时 $s$ 的实部。该放大器是否无条件稳定？若是，计算单位增益反馈时的极点位置；若否，求引起不稳定所需的环路增益（loop gain）。
