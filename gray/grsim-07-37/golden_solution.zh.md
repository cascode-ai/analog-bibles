(a) 偏置：$V_{SB2} = 2.5$ V → $V_{t2} = 0.7 + 0.4(\sqrt{3.1} - \sqrt{0.6}) = 1.094$ V；$I_D = 30\ \mu(4)(2.5 - 1.094)^2 = 237\ \mu$A；$V_{ov1} = 0.281$ V，$V_{GS1} = 0.981$ V（直流输入）。$g_{m1} = 1.69$ mA/V，$g_{m2} = 0.337$ mA/V，$g_{mb2} = 0.038$ mA/V；负载 $1/(g_{m2} + g_{mb2}) = 2.66\ \mathrm{k\Omega}$；增益 $= -g_{m1}/(g_{m2} + g_{mb2}) = -4.49$。
电容：$C_{gs1} = 145$ fF，$C_{gd1} = 30$ fF，$C_{db1}$（2.5 V）= 35.2 fF，$C_{gs2} = 5.8$ fF 和 $C_{sb2}$ = 1.4 fF（均在输出端）。时间常数：$C_{gs1}R_S = 0.145$ ns；$C_{gd1}(R_S + R_L + g_{m1}R_LR_S) = 30\ \mathrm{fF}\times8.15\ \mathrm{k\Omega} = 0.245$ ns；输出端 $(100 + 35.2 + 5.8 + 1.4)\ \mathrm{fF}\times2.66\ \mathrm{k\Omega} = 0.379$ ns；$T_0 = 0.769$ ns → $f_{-3\text{dB}} \approx 207$ MHz。
预期的仿真结果：−3 dB 点约 238 MHz；极点约 245 MHz 和 1.3 GHz（第二主极点约 1.3 GHz）；右半平面零点（RHP zero）约 8.9 GHz。带宽随直流输入的变化：$V_i < 0.7$ V 时增益约为 0、带宽无定义（M1 截止）；之后带宽大致按 $\sqrt{I_D}$ 增大，而增益保持在约 −4.3 到 −4.5：$V_i = 0.8$ V 时约 110 MHz，0.98 V 时约 240 MHz，1.2 V 时约 320 MHz，约 1.39 V 时约 365 MHz，此时 $M_1$ 到达线性区（triode region）边缘（$V_O \approx 0.7$ V）；$V_i$ 更大时 $M_1$ 处于线性区，增益幅值下降，而带宽继续增大。
(b) $R_{SX1} = 1/(1.5\times10^6\times60\times10^{-6}\times100\times10^{-6}) = 111\ \Omega$，$R_{SX2} = 2.78\ \mathrm{k\Omega}$。$G_{m1} = g_{m1}/(1 + g_{m1}R_{SX1}) = 1.42$ mA/V；负载电阻 $R_{SX2} + 1/(g_{m2} + g_{mb2}) = 5.44\ \mathrm{k\Omega}$；增益 $= -1.42\times5.44 = -7.7$。时间常数：$C_{gs1}$：0.145 ns；$C_{gd1}$：$30\ \mathrm{fF}\times14.2\ \mathrm{k\Omega} = 0.425$ ns；输出端：$142\ \mathrm{fF}\times5.44\ \mathrm{k\Omega} = 0.775$ ns；$T_0 = 1.35$ ns → $f_{-3\text{dB}} \approx 118$ MHz（精确值约 130 MHz）。小尺寸负载管中的速度饱和（velocity saturation）使其等效电阻增大，因此增益上升而带宽下降。
