# Golden Solution - G126

## Reference answer

$E^+ + E^- = 6\dfrac{a_3}{a_1}\hat v_i^2$ and $E^+ - E^- = 4\dfrac{a_2}{a_1}\hat v_i$.
- $A_v^\pm = a_1 \pm 2a_2\hat v_i + 3a_3\hat v_i^2$, $A_{vQ} = a_1$, so $E^\pm = \pm 2(a_2/a_1)\hat v_i + 3(a_3/a_1)\hat v_i^2$.
- Sum cancels the $a_2$ terms; difference cancels the $a_3$ terms.

## Grading notes

+2: both expressions correct. +1: one coefficient slip (e.g. 3 instead of 6). 0: correct $E^\pm$ but not combined, or only one combination right. −2 (asserted as fact): sum and difference interchanged (sum depending on $a_2$), or $E^\pm$ built from large-signal ratios.
