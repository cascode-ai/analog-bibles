闭环特性在硬限幅之前基本上是一条斜率 ≈ 10 的直线：
- $|S_i| \le 0.70014$ V：斜率 $A_1 = 50{,}000/5001 = 9.998$（$S_o$ 最高到 ±7 V）；
- $0.70014\text{ V} \le |S_i| \le 1.50054$ V：斜率 $A_2 = 20{,}000/2001 = 9.995$（$S_o$ 从 ±7 到 ±15 V）；
- $|S_i| \ge 1.50054$ V：$S_o = \pm 15$ V。

推导：$T_1 = 5000$，$T_2 = 2000$。转折点 1：$S_\epsilon = 0.14$ mV，$S_i = 0.14\text{ mV} + 0.1\times 7 = 0.70014$ V。转折点 2：$S_\epsilon = 0.14 + 8/20{,}000\ \text{V} = 0.54$ mV，$S_i = 0.54\text{ mV} + 1.5\text{ V} = 1.50054$ V。两个斜率仅相差 0.03%（$A_1/A_2 = 1.0003$），因此基本放大器的斜率变化实际上看不出来；±15 V 处的饱和不变。
