每一项的符号取决于：在尾电流固定时，为恢复 $|I_{D2}| = I_{D4}$，两个栅极必须向哪个方向失衡。对于 p 沟道对管，栅极电压越负电流越大，且 $V_{ov(1-2)} < 0$。

- $V_{t1}-V_{t2}$（系数为 +1）：若 $V_{t1} > V_{t2}$（$|V_{t1}| < |V_{t2}|$），在 $V_{GS}$ 相等时 $M_1$ 导通更强。理想电流镜要求 $|I_{D1}| = |I_{D2}|$，即过驱动电压相等，因此 $V_{GS1} - V_{t1} = V_{GS2} - V_{t2}$，$V_{G1} - V_{G2} = V_{t1} - V_{t2}$：当 $V_{t1} > V_{t2}$ 时为正。
- $V_{t(3-4)}\,g_{m3}/g_{m1}$（+）：若 $V_{t3} > V_{t4}$，$M_4$（与二极管连接的 $M_3$ 的 $V_{GS}$ 相同）的电流大于 $M_3$，$I_{D4} = I_{D3} + g_{m3}(V_{t3}-V_{t4})$。平衡要求 $|I_{D2}|$ 比 $|I_{D1}|$ 大 $g_{m3}V_{t(3-4)}$，因此 $|V_{GS2}| > |V_{GS1}|$，$M_2$ 的栅极必须更低，$V_{G1}-V_{G2} = +(g_{m3}/g_{m1})V_{t(3-4)} > 0$。电流误差经由 $g_{m1}$ 折算到输入端。
- $\frac{V_{ov}}{2}\frac{\Delta(W/L)_{(3-4)}}{(W/L)}$：若 $W_3 > W_4$，电流镜只复制 $|I_{D1}|$ 的 $(W/L)_4/(W/L)_3 < 1$ 倍，因此平衡要求 $|I_{D2}| < |I_{D1}|$，即 $|V_{GS2}| < |V_{GS1}|$：$M_2$ 的栅极必须高于 $M_1$ 的栅极，因此 $V_{G1} - V_{G2} < 0$。电流失衡 $\Delta I/I = \Delta(W/L)/(W/L)$ 需要 $\Delta|V_{GS}| = (|V_{ov}|/2)\Delta(W/L)/(W/L)$。在公式中，$V_{ov(1-2)} < 0$ 乘以正的 $\Delta(W/L)_{(3-4)}$，得到负号。
- $-\frac{V_{ov}}{2}\frac{\Delta(W/L)_{(1-2)}}{(W/L)}$：若 $W_1 > W_2$，在 $V_{GS}$ 相等时 $M_1$ 导通更强。平衡要求电流相等，因此 $|V_{GS1}| < |V_{GS2}|$，$M_1$ 的栅极必须更高，$V_{G1}-V_{G2} > 0$。在公式中，$-(\text{negative }V_{ov})\times(\text{positive})/2 > 0$。
- 出现过驱动电压因子的原因是：对平方律器件（$g_m = 2I/V_{ov}$），相对电流误差 $\delta$ 需要 $\delta\,V_{ov}/2$ 的 $V_{GS}$ 变化量来补偿。
