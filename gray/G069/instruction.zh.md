求 [图 1] 所示超级源极跟随器（super source follower；$M_1$ 为 p 沟道晶体管，$M_2$ 为 n 沟道晶体管）的短路跨导（short-circuit transconductance），即输出节点保持在小信号地电位时单位输入电压所产生的输出电流。假设 $I_1 = 200\ \mu$A，$I_2 = 100\ \mu$A（理想电流源），$W_1 = 30\ \mu$m，$W_2 = 10\ \mu$m。并假设两个晶体管都工作在有源区（active region），忽略体效应。

工艺参数（平方律，$I_D = \frac{k'}{2}\frac{W}{L_{\text{eff}}}(V_{GS}-V_t)^2$）：所有晶体管的版图长度 $L_{\text{drwn}} = 0.4\ \mu$m，横向扩散（lateral diffusion）$L_d = 0.09\ \mu$m，$X_d = 0.1\ \mu$m，因此 $L_{\text{eff}} = L_{\text{drwn}} - 2L_d - X_d = 0.12\ \mu$m。$k'_n = \mu_n C_{ox} = 194\ \mu\mathrm{A/V^2}$，$k'_p = \mu_p C_{ox} = 65\ \mu\mathrm{A/V^2}$（$t_{ox} = 8$ nm，$\mu_n = 450$，$\mu_p = 150$ cm²/V·s）。沟道长度调制（channel-length modulation）$dX_d/dV_{DS} = 0.02\ \mu$m/V（n 沟道）和 $0.04\ \mu$m/V（p 沟道），$\lambda = (dX_d/dV_{DS})/L_{\text{eff}}$，$r_o = 1/(\lambda I_D)$。
