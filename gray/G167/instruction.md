Two two-stage CMOS op amps have identical second stages and first stages that differ only in device polarity: (i) a p-channel input pair $M_1$–$M_2$ with an n-channel current-mirror load $M_3$–$M_4$, and (ii) an n-channel input pair with a p-channel current-mirror load. In both, all transistors have equal $W/L$ and operate in the active region, the pair and the mirror carry the same current per device, and the only mismatch is a 10-mV threshold difference between the two current-mirror load transistors. The process has $\mu_nC_{ox} = 194\ \mu\mathrm{A/V^2}$ and $\mu_pC_{ox} = 64.7\ \mu\mathrm{A/V^2}$ (square-law model, no short-channel effects). Which of the two configurations gives the lower input offset voltage? Explain, with numbers.
