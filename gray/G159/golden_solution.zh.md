输入为零时的直流输出为 $V_O = V_{DD} - |V_{t3}| - |V_{ov3}|$，因此
$$V_{OS(sys)} = \frac{\dfrac{V_{DD}-V_{SS}}{2} - \left(V_{DD} - |V_{t3}| - |V_{ov3}|\right)}{A_v} = \frac{\dfrac{V_{DD}+V_{SS}}{2} - |V_{t3}| - |V_{ov3}|}{|A_v|}\quad(\text{as } v_{G1}-v_{G2}),$$
其中 $A_v = -g_{m1}(r_{o2}\parallel r_{o4})g_{m6}(r_{o6}\parallel r_{o7})$ 为运放的（负）增益。除非 $|V_{GS3}| = (V_{DD}+V_{SS})/2$，否则失调不为零。

- 输入为零且匹配完美时，$V_{SD4} = V_{SD3} = |V_{GS3}|$（这是 $M_2$ 与 $M_4$ 电流一致的唯一工作点），因此第二级的 $|V_{GS6}| = |V_{GS3}|$。
- $|I_{D3}| = I_{D5}/2$，$|I_{D6}| = I_{D7} = I_{D5}(W/L)_7/(W/L)_5$（$M_5$、$M_7$ 的栅极电压相同）。宽长比条件使 $|I_{D3}|/(W/L)_3 = |I_{D6}|/(W/L)_6$：$M_3$、$M_4$ 和 $M_6$ 的电流密度和过驱动电压相等，因此在 $|V_{GS6}| = |V_{GS3}|$ 且漏源电压相同时，$M_6$ 恰好流过 $M_7$ 提供的电流。
- 因此 $V_{SD6} = V_{SD3} = |V_{t3}| + |V_{ov3}|$，$V_O = V_{DD} - |V_{t3}| - |V_{ov3}|$。将输出移到中点 $(V_{DD}-V_{SS})/2$ 所需的输入为（中点 $-V_O$）$/A_v$。
- 由于 $A_v < 0$，若输出位于中点之上（通常情形，$|V_{GS3}| < (V_{DD}+V_{SS})/2$），则需要正的 $v_{G1} - v_{G2}$。失调很小，量级为（输出误差）/$(g_mr_o)^2$。
- 前提（教材中的近似，由所要求的表达形式隐含）：把 $M_6$ 视为 $M_3$ 的复制，p 沟道器件的 $r_o$ 为有限值，而把 $M_5$ 和 $M_7$ 视为理想电流源，因此 $I_{D7}/I_{D5} = (W/L)_7/(W/L)_5$ 严格成立。
- 其他理解方式。(i) 所有器件均取 $\lambda = 0$ 的严格平方律：在 $v_i = 0$ 时，只要输出电压使 $M_6$、$M_7$ 保持饱和，电流就是平衡的，因此输出电压不确定，增益无穷大，失调为零；该模型无法得出所要求的依赖于 $A_v$ 的结果。(ii) 所有器件都保留 $\lambda$：$|I_{D6}| = I_{D7}$ 要求 $(1+|\lambda_p|V_{SD6})/(1+|\lambda_p|V_{SD3}) = (1+\lambda_nV_{DS7})/(1+\lambda_nV_{DS5})$，一阶近似下得到 $V_O \approx (|\lambda_p|x + \lambda_n V_S)/(|\lambda_p|+\lambda_n)$，其中 $x = V_{DD} - |V_{GS3}|$，$V_S$ 为尾节点电压。这并不是一个小修正（当 $\lambda_n \approx |\lambda_p|$ 时，$V_O$ 大致位于 $x$ 与 $V_S$ 的中间，并随输入共模电平变化），因此此时失调还与 $V_S$ 和各 $\lambda$ 有关，无法只用所要求的变量表示。Level-1 仿真（$\pm2.5$ V，$|V_{GS3}| = 0.92$ V）：$\lambda_n = 0$、$\lambda_p = 0.05$ 时，$V_O(0) = 1.58$ V，$V_{OS} = 30\ \mu$V，与公式相符；所有器件 $\lambda = 0.05$ 时，$V_O(0) = 0.38$ V（$V_{CM} = 0$）或 0.88 V（$V_{CM} = 1$ V），$V_{OS} = 26$ 或 66 $\mu$V。
