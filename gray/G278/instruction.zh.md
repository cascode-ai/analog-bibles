[图 1] 所示为一个电压跟随器（voltage follower）反馈电路：运放驱动 NMOS 源极跟随器（source follower）的栅极（漏极接 $V_{DD}$，衬底接地，源极由理想电流源 $I_D$ 接地作为负载）；源极为输出 $V_o$，并反馈到反相输入端；$V_i$ 驱动同相输入端。MOS 晶体管参数：$I_D = 0.5$ mA，$k' = 180\ \mu\mathrm{A/V^2}$，$r_o = \infty$，$W/L = 100$，$|\phi_f| = 0.3$ V，$\gamma = 0.3\ \mathrm{V^{1/2}}$；直流输入（及输出）电压为 0 V，因此工作点处源-衬底电压为零。运放参数：$R_i = 1$ MΩ（两输入端之间），$R_o = 10$ kΩ（与其输出串联），$a_v = 1000$。用二端口反馈分析，计算输入电阻、输出电阻、环路传输（loop transmission，这里即环路增益 $T = af$）以及闭环增益 $v_o/v_i$。
