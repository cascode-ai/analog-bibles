A voltage-follower feedback circuit is shown in [Fig. 1]: an op amp drives the gate of an NMOS source follower (drain at $V_{DD}$, body grounded, source loaded by an ideal current source $I_D$ to ground); the source is the output $V_o$ and is fed back to the inverting input; $V_i$ drives the non-inverting input. For the MOS transistor, $I_D = 0.5$ mA, $k' = 180\ \mu\mathrm{A/V^2}$, $r_o = \infty$, $W/L = 100$, $|\phi_f| = 0.3$ V and $\gamma = 0.3\ \mathrm{V^{1/2}}$; the dc input (and output) voltage is 0 V, so the source–body voltage is zero at the operating point. For the op amp, $R_i = 1$ MΩ (between its inputs), $R_o = 10$ kΩ (in series with its output) and $a_v = 1000$. Using two-port feedback analysis, calculate the input resistance, output resistance, loop transmission (here the loop gain $T = af$) and closed-loop gain $v_o/v_i$.
