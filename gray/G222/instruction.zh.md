在 [图 1] 所示的放大级中，将晶体管换成 MOS 器件：$Q_1$ 换成 $p$ 沟道晶体管 $M_1$（源极接 $V_{\text{SUPPLY}}$，漏极接输出），$Q_2$、$Q_3$ 换成 $n$ 沟道晶体管 $M_2$、$M_3$（二极管连接的 $M_3$ 经 30-kΩ 电阻由地偏置，由 $M_2$ 镜像）。在 $M_1$ 的栅极与源极之间加一个阻值为 $1/g_{m1}$ 的电阻；电流源 $I_B + i_i$ 从 $M_1$ 的栅极节点抽取电流。$V_{\text{SUPPLY}} = 2.5$ V，调节 $I_B$ 使直流 $V_O = 0$ V。计算低频小信号跨阻（transresistance）$v_o/i_i$，并用零值时间常数法（zero-value time-constant method）估算 −3-dB 频率。

所有晶体管的参数：$L_{\text{drwn}} = 2\ \mu$m，$L_d = 0.2\ \mu$m，$X_d = 1\ \mu$m（故 $L_{\text{eff}} = L_{\text{drwn}} - 2L_d - X_d = 0.6\ \mu$m），$\gamma = 0$，$W_1 = 200\ \mu$m，$W_2 = W_3 = 100\ \mu$m。NMOS：$V_{tn} = 1$ V，$k_n' = 60\ \mu\mathrm{A/V^2}$，$\lambda_n = 1/(100\ \mathrm{V})$，$C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$，$C_{j0} = 0.4\ \mathrm{fF/\mu m^2}$，$C_{jsw0} = 0.4\ \mathrm{fF/\mu m}$。PMOS：$V_{tp} = -1$ V，$k_p' = 20\ \mu\mathrm{A/V^2}$，$|\lambda_p| = 1/(50\ \mathrm{V})$，$C_{ox} = 0.7\ \mathrm{fF/\mu m^2}$，$C_{j0} = 0.2\ \mathrm{fF/\mu m^2}$，$C_{jsw0} = 0.2\ \mathrm{fF/\mu m}$。栅电容：$C_{gs} = \tfrac23WL_{\text{eff}}C_{ox} + WL_dC_{ox}$，$C_{gd} = WL_dC_{ox}$（交叠电容）。结电容：$C_{db} = C_{db0}/\sqrt{1 + V_{DB}/\psi_0}$（$C_{sb}$ 类似），其中 $\psi_0 = 0.6$ V，$C_{db0} = A_DC_{j0} + P_DC_{jsw0}$，$A_D = (5\ \mu\mathrm{m})W$，$P_D = W$。NMOS 的衬底接 $-V_{\text{SUPPLY}}$，PMOS 的衬底接 $+V_{\text{SUPPLY}}$。采用平方律模型，偏置计算中忽略 $\lambda$。
