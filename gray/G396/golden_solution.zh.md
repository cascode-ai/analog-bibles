$V_{OC} = V_{DD} - |V_{GS3}| = 2.5 - (0.6 + 0.2) = 1.7$ V。

- 栅极不取电流且电路对称，因此在没有差分信号时，20-kΩ 电阻中没有直流电流：$V_{o1} = V_{o2} =$ $M_3$/$M_4$ 的栅极电压。
- $M_3$ 和 $M_4$ 各流过 $I_{D5}/2 = 100\ \mu$A，$|V_{ov}| = 0.2$ V，因此 $|V_{GS3}| = |V_{tp}| + |V_{ov}| = 0.8$ V：对共模而言，它们相当于二极管连接（diode-connected）的负载。
- $V_{OC} = 2.5 - 0.8 = 1.7$ V（所有器件均处于有源区：$M_1$ 的漏极电压 1.7 V 远高于其栅极电压 0 V 减去 $V_t$）。
