$C_{Ld} = 3$ pF，$C_{Lc} = 13$ pF。

- 缓冲器输入端不取电流，因此从 $V_{o1}$ 吸取的电流为其 3-pF 电容的电流加上另一端被驱动到 $-V_{o2}$ 的 5-pF 电容的电流：$i_{l1} = s[3\,\text{pF}\cdot v_{o1} + 5\,\text{pF}(v_{o1} + v_{o2})] = s[8\,\text{pF}\cdot v_{o1} + 5\,\text{pF}\cdot v_{o2}]$。
- 差模（$v_{o2} = -v_{o1}$）：$i_{l1} = s(3\,\text{pF})v_{o1}$，因此 $C_{Ld} = 3$ pF；5-pF 电容中没有差模电流，因为每个电容两端的电压为 $v_{o1} + v_{o2} = 0$。
- 共模（$v_{o2} = v_{o1}$）：$i_{l1} = s(13\,\text{pF})v_{o1}$，因此 $C_{Lc} = 3 + 2(5) = 13$ pF。
- 该网络增加了共模负载电容，有利于补偿共模反馈（CMFB）环路，同时不会加重差模通路的负载。
