（位置以 $s/2\pi$ 表示。）
- $f = 10^{-3}$（$T_0 = 100$）：极点位于 −9.92 kHz 和 −122.2 kHz；零点位于 −100 kHz。
- $f = 1$（$T_0 = 10^5$）：极点位于 −99.83 kHz 和 −12.02 MHz；零点位于 −100 kHz（构成几乎相互抵消的零极点对；响应基本上是 12 MHz 处的单极点响应，外加一个建立很慢的小分量）。

根轨迹：环路增益（loop gain）的极点位于 −100 Hz 和 −120 kHz，零点位于 −100 kHz。实轴上 −100 Hz 与 −100 kHz 之间以及 −120 kHz 的左侧属于根轨迹。因此从 −100 Hz 出发的一支向左移动并终止于 −100 kHz 的零点，从 −120 kHz 出发的一支向左趋于 −∞；对所有 $f$，极点都保持为实数（没有分离点）。闭环增益的零点就是 $a(s)$ 的零点，因此对任意 $f$，−100 kHz 都是零点。

闭环极点由 $(1 + s/\omega_1)(1 + s/\omega_2) + T_0(1 + s/\omega_z) = 0$ 求得（以 kHz 为单位：$s^2/12 + s(10.008 + T_0/100) + (1 + T_0) = 0$）：
- $T_0 = 100$：$s^2 + 132.1s + 1212 = 0$ → −9.92、−122.2 kHz。
- $T_0 = 10^5$：$s^2 + 12{,}120s + 1.2 \times 10^6 = 0$ → −99.83 kHz、−12.02 MHz。
