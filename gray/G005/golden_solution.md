# Golden Solution - G005

## Reference answer

The lightly doped side must have $N \approx 8.7\times10^{14}$ atoms/cm³ (or less).

- One-sided abrupt junction: plane-junction maximum field $|\mathcal{E}_{max}| = \sqrt{2qNV_R/\epsilon}$.
- Practical junction breaks down when $1.5\sqrt{2qN\,BV/\epsilon} = \mathcal{E}_{crit}$, i.e. when the plane-junction field reaches $\mathcal{E}_{crit}/1.5 = 2\times10^5$ V/cm.
- $N = \dfrac{\epsilon(\mathcal{E}_{crit}/1.5)^2}{2q\,BV} = \dfrac{(1.04\times10^{-12})(4\times10^{10})}{2(1.6\times10^{-19})(150)} = 8.67\times10^{14}$ cm⁻³.
- (Equivalently, curvature lowers the breakdown voltage by $1.5^2 = 2.25$: the same doping would give 337 V for a plane junction.)
