$f \approx 0.053$（$T_0 \approx 2120$）时不稳定，复极点在 ±$j$899 kHz 处穿过 $j\omega$ 轴；奈奎斯特验证给出相同的值。

根轨迹（坐标为 $s/2\pi$；$T$ 的极点位于 −2 kHz、−200 kHz、−4 MHz）：
- 实轴上的轨迹段：−2 kHz 与 −200 kHz 之间，以及 −4 MHz 的左侧。
- 前两个极点之间的分离点（break-away point）约在 −99.7 kHz 处（规则：到各极点距离的倒数之和 = 0），在 $T_0 = 23.9$（$f = 6.0 \times 10^{-4}$）时到达；之后极点对大致垂直移动（标定：$f = 10^{-3}$：$-98.9 \pm j81$ kHz；$f = 0.01$：$-80 \pm j390$ kHz），随着 4 MHz 极点影响增大而弯向右半平面。
- 渐近线为 ±60°、180°，从重心 $(-0.002 - 0.2 - 4)/3 = -1.40$ MHz 出发（远离所关心的区域，因此用渐近线估计穿越点效果很差）。
- 第三支从 −4 MHz 向左移动到 −∞（穿越时位于 −4.2 MHz）。
- 当 $f = 1$（$T_0 = 40{,}000$）时：$-5.90$ MHz 以及 $+0.85 \pm j3.18$ MHz（不稳定）。

不稳定（劳斯判据，$s$ 对 $2\pi \times 2$ kHz 归一化，极点为 −1、−100、−2000）：$s^3 + 2101s^2 + 202{,}100s + 2 \times 10^5(1+T_0) = 0$；当 $2101 \times 202{,}100 = 2 \times 10^5(1+T_0)$ 时处于临界 → $T_0 = 2122$，$f = 2122/40{,}000 = 0.053$，$\omega = \sqrt{202{,}100}$ → 899 kHz。

奈奎斯特验证：$T(j\omega)$ 的相位在 899 kHz 处为 −180°（$\arctan 449.6 + \arctan 4.50 + \arctan 0.225 = 180°$），此处 $|T|/T_0 = 1/(449.6 \times 4.61 \times 1.025) = 1/2122$。只有当 $T_0 < 2122$，即 $f < 0.053$ 时，曲线才不包围 −1，与根轨迹结论一致。
