# Golden Solution - G031

## Reference answer

$R_\square = \rho/T = (1\ \Omega\text{-cm})/(5\times10^{-4}\ \mathrm{cm}) = 2000\ \Omega/\square$ (2 kΩ per square).

## Grading notes
