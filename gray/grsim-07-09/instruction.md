A lateral $pnp$ emitter follower is driven from a voltage source with source resistance $R_S = 250\ \Omega$ at the base; the collector is at ac ground and the output is taken at the emitter, loaded by $R_E = 4\ \mathrm{k\Omega}$. Transistor data: $r_b = 200\ \Omega$, $\beta = 50$, $I_C = -300\ \mu$A, $f_T = 4$ MHz, $C_\mu = 0$, $r_o = \infty$, $V_T = 26$ mV. Calculate the values of the elements in the small-signal equivalent circuits for the input impedance (looking into the base terminal, an $RC$ network in series with $r_b$ and $R_E$) and the output impedance (looking into the emitter, a resistor $R_2$ in parallel with the series combination of $R_1$ and an inductor $L$) of this emitter follower. Sketch the magnitudes of these impedances as a function of frequency from $f = 10$ kHz to $f = 20$ MHz, using log scales. Use SPICE to determine the small-signal step response of the circuit for a resistive load of 1 kΩ and then for a capacitive load of 400 pF. Use a 1-mV input pulse amplitude with zero rise time. Comment on the shape of the time-domain responses. (Bias the circuit with an ideal 300-µA current source connected to the emitter for the capacitive load test.)
