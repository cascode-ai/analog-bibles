$\mathscr{R}(s) = a_v(s)\dfrac{R}{R + 1/sC} = a_v(s)\dfrac{sRC}{1 + sRC}$；对所有 $R, C > 0$，闭环都是稳定的。

回归比：令 $V_i = 0$，并把受控源换成 $a_v(s)v_t$，则节点电压为 $a_vv_t R/(R + 1/sC)$，$v_x$ 为其负值，因此 $\mathscr{R} = a_v(s)\,sRC/(1 + sRC)$。

用劳斯判据（Routh criterion）判断稳定性：写成 $a_v(s) = a_0/(1 + b_1s + b_2s^2)$，其中 $a_0 > 0$，$b_1, b_2 > 0$（两个 LHP 极点，可为实数或复数；题意中的 $a_v$ 是这种没有有限零点的双极点模型——若存在右半平面零点，结论可能不成立，例如 $a_v = 10(1 - s)/[(s+1)(s+2)]$ 且 $RC = 100$ 时，闭环有两个右半平面极点）。闭环极点是下式的根：
$(1 + sRC)(1 + b_1s + b_2s^2) + a_0sRC = RCb_2\,s^3 + (b_2 + RCb_1)s^2 + (b_1 + RC + a_0RC)s + 1 = 0$。
所有系数均为正，且三次多项式的劳斯条件 $(b_2 + RCb_1)(b_1 + RC(1 + a_0)) > RCb_2 \times 1$ 恒成立，因为左边含有 $b_2RC(1 + a_0) > b_2RC$ 这一项。因此对任意 $R$ 和 $C$，所有根都位于 LHP。

等价的相位论证：$j\omega RC/(1 + j\omega RC)$ 的相位为 $90° - \arctan\omega RC \in (0°, 90°]$，而对有限的 $\omega$，$a_v(j\omega)$ 的相位位于 $(-180°, 0°]$ 内，因此 $\mathscr{R}(j\omega)$ 的相位永远达不到 −180°；奈奎斯特图（Nyquist plot）从不穿过负实轴，不可能包围 −1。
