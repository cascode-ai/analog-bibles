- 增益误差：$1/(1 + 2Ag_mR_L) \le 1\%$ → $2Ag_mR_L \ge 99$。$A$ 取最大值 5 时：$g_m \ge 0.099$ S。$(W/L)_1 = 10000$：$V_{ov1} = \sqrt{2(9.8\ \mathrm{mA})/(57.5\ \mu\times10^4)} = 0.185$ V，$g_m = 2I_Q/V_{ov} = 0.106$ S；$(W/L)_2 = 4530$ 使 $k_n'(W/L)_2 = k_p'(W/L)_1$。更大的 $(W/L)_1$ 会以面积为代价进一步降低误差（及失真）。
- 误差放大器：$|I_{D13}| = |I_{D14}| = 0.98$ mA，$I_{D11} = I_{D12} = 245\ \mu$A，$|I_{D15}| = |I_{D16}| = 0.98 - 0.245 = 0.735$ mA。$A = g_{m11}/g_{m16}$：取 $(W/L)_{16} = 5$，$V_{ov16} = 2.26$ V，$g_{m16} = 0.65$ mS；$(W/L)_{11} = 165$ 给出 $g_{m11} = 3.20$ mS，$A = 4.92$（≤ 5）。互补电路：$(W/L)_{25} = 5k_p'/k_n' = 2.27$，$(W/L)_{21} = 165k_n'/k_p' = 365$，$A \approx 4.93$。
