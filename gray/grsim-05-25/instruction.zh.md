[图 1] 所示为一个互补 AB 类（class AB）输出级（output stage），其输出器件为共源接法的 $M_1$（p 沟道）和 $M_2$（n 沟道），各由一个误差放大器（error amplifier）驱动。[图 2] 为上方误差放大器及 $M_1$ 的晶体管级电路图；下方误差放大器及 $M_2$ 采用互补电路，晶体管为 $M_{21}$–$M_{27}$（$M_{11}$–$M_{17}$ 的互补管），电流源为 $I_{\text{BIASP}}$、$I_{\text{TAILP}}$（$I_{\text{BIAS}}$、$I_{\text{TAIL}}$ 的互补）。在 [图 2] 中，失调为零时 $|I_{D1}| = I_{\text{BIAS}}(W/L)_1/(W/L)_{17}$，$|I_{D13}| = |I_{D14}| = I_{\text{BIAS}}(W/L)_{13}/(W/L)_{17}$，误差放大器增益为 $A = g_{m11}/(g_{m16} + g_{mb16})$；两个输出器件均处于有源区时，输出级的传输特性为 $V_o \approx V_i/(1 + 1/(2Ag_mR_L))$，当 $k_p'(W/L)_1 = k_n'(W/L)_2$ 时 $g_m = g_{m1} = g_{m2}$。设计该输出级以满足以下要求。
(a) $V_{DD} = V_{SS} = 2.5$ V。
(b) 静态功耗不超过 70 mW。
(c) $R_L = 100\ \Omega$。
(d) 在失调为零且所有晶体管均工作在有源区时，允许的最大增益误差（gain error）为 1%。
(e) $(W/L)_{17} = (W/L)_1/100$，$(W/L)_{13} = (W/L)_{14} = (W/L)_1/10$。同样，$(W/L)_{27} = (W/L)_2/100$，$(W/L)_{23} = (W/L)_{24} = (W/L)_2/10$。
(f) 为控制静态电流，允许的最大误差放大器增益为 5。
(g) 你的方案可以使用四个理想电流源，每个误差放大器中两个。为了在后续设计步骤中能用实际晶体管替换这些理想电流源，当 $V_o \ge 0$ 时，上方电路中每个理想电流源两端的电压必须至少为 0.5 V。同样，当 $V_o \le 0$ 时，互补电路中每个理想电流源两端的电压必须至少为 0.5 V。
(h) 为保证 $M_{16}$ 和 $M_{26}$ 在上述条件下不截止，假设 $I_{\text{TAIL}} = 5I_{\text{BIAS}}$，$I_{\text{TAILP}} = 5I_{\text{BIASP}}$。
(i) 对 n 沟道和 p 沟道晶体管，均假设 $\lambda = 0$，$L_d = X_d = 0$，并忽略体效应。所有晶体管取 $L_{\text{drwn}} = 1$ µm，$k_n' = 127\ \mu\mathrm{A/V^2}$，$k_p' = 57.5\ \mu\mathrm{A/V^2}$，$V_{tn} = 0.7$ V，$V_{tp} = -0.7$ V（0.8 µm 工艺，$t_{ox} = 150$ Å）。
(j) 在上述条件下应使输出级的失真最小。
