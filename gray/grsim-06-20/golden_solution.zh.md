一种有效的手工设计（$L_{eff} = 1\ \mu$m，$L_{drwn} = 1.18\ \mu$m；n 沟道 λ ≈ 0.02 V⁻¹，p 沟道 λ ≈ 0.04 V⁻¹；下面的 $W/L$ 为有效尺寸比，$W = (W/L)\times1\ \mu$m）。

电流：
- $|I_{D5}| = 100\ \mu$A，因此 $|I_{D1}| = |I_{D2}| = 50\ \mu$A。
- $I_{D11} = I_{D12} = 150\ \mu$A，因此共源共栅支路（$M_{1A}$、$M_{2A}$、$M_3$、$M_4$、$M_{3A}$、$M_{4A}$）流过 100 μA。
- 输出电流 $= |I_{D2}| - |I_{D1}|$，在差分对完全导向一侧时达到 ±100 μA，而 $M_{1A}$/$M_{2A}$ 仍保持至少 50 μA。

过驱动电压与尺寸：
- $M_1$、$M_2$：$|V_{ov}| = 0.1$ V，$W/L = 155$。$M_5$：0.1 V，$W/L = 309$。
- $M_3$、$M_4$、$M_{3A}$、$M_{4A}$：0.1 V，$W/L = 309$。
- $M_{11}$、$M_{12}$：0.15 V，$W/L = 69$。$M_{1A}$、$M_{2A}$：0.15 V，$W/L = 46$。

偏置电压：
- $V_{BIAS1} = V_{DD} - 0.9$ V = +0.6 V。
- $V_{BIAS3} = -V_{SS} + 0.75$ V = −0.75 V。
- $V_{BIAS2} = -V_{SS} + (V_{ov11} + 0.1) + V_{GS1A} = -1.5 + 0.25 + 0.75 = -0.5$ V，因此 $V_{DS11} = 0.25$ V（过驱动电压 + 100 mV）。

检查：
- 输入范围：上限 $V_{DD} - |V_{tp}| - |V_{ov1}| - |V_{ov5}| = 0.5$ V（刚好满足指标；在仿真中进一步完善）。下限 $V_{D1} - |V_{tp}| = -1.25 - 0.8 = -2.05$ V，因此包含 $-V_{SS}$。
- 输出范围：从 $-V_{SS} + 0.25 + 0.15 = -1.1$ V 到 $V_{DD} - |V_{tp}| - 2|V_{ov3}| = +0.5$ V，即 1.6 V 峰峰值。静态输出约为 −0.3 V，与电流镜输入节点相匹配。
- $V_{IC} = 0$ 时的裕量：$V_{SD5} = 0.6$ V，$V_{DS11} = 0.25$ V，$V_{DS1A} \approx V_{DS2A} \approx 0.95$ V，$V_{SD3} = V_{SD4} = 0.9$ V，$V_{SD4A} \approx 0.9$ V；均超过 $|V_{ov}| + 0.1$ V。

偏置产生电路：
- $V_T$ 基准核心电路，$I_{IN} = I_{OUT} = 25\ \mu$A，$n = 8$，$R = V_T\ln8/25\ \mu\mathrm{A} \approx 2.2$ kΩ（衬底 pnp 晶体管）。
- n 沟道 $M_3$/$M_4$（$W/L \approx 11.5$），上面叠接 n 沟道共源共栅管（$M_3$ 一侧为二极管连接）；p 沟道 $M_5$/$M_6$（$W/L = 77$，$|V_{ov}| = 0.1$ V）；复制管 $M_7$ 给出 $I_{BIAS} = 25\ \mu$A。需要一个启动电路以脱离零电流状态。
- 扩展部分：
  - $V_{BIAS1}$ 即 $M_5$/$M_6$ 的栅极线；运放中的 $M_5$ 为 $M_6$ 的 4 倍。
  - 一个 p 沟道复制管（25 μA）流入 $W/L = 11.5$ 的 n 沟道二极管（$V_{ov} = 0.15$ V），给出 $V_{BIAS3}$；$M_{11}$/$M_{12}$ 为该二极管的 6 倍。
  - 另一个 25 μA 复制管流入 $W/L \approx 1.6$ 的 n 沟道二极管（$V_{ov} = 0.4$ V，$V_{GS} = 1.0$ V），给出 $V_{BIAS2}$。（也可采用二极管加线性区器件的电平移位方案。）
- 总电源电流约为 0.4–0.5 mA。

增益（手工估算）：
- $G_m = g_{m1} = 1$ mS。
- $R_{down} \approx g_{m2A}r_{o2A}(r_{o2}\parallel r_{o12}) = 1.33\ \mathrm{mS}\times500\ \mathrm{k}\times200\ \mathrm{k} \approx 133$ MΩ。
- $R_{up} \approx g_{m4A}r_{o4A}r_{o4} = 2\ \mathrm{mS}\times250\ \mathrm{k}\times250\ \mathrm{k} = 125$ MΩ。
- $A_v \approx 1\ \mathrm{mS}\times64\ \mathrm{M\Omega} \approx 6\times10^4$（≈ 96 dB）。
