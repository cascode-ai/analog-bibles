# Golden Solution - G386

## Reference answer

$a_{cmc} \approx -396$.

- In the CM half-circuit, $M_3$ is a common-source amplifier driven by $v_{cmc}$ with $g_{m3} = 2(50\ \mu\text{A})/0.1\ \text{V} = 1$ mA/V.
- Its load is $r_{o3}$ in parallel with the resistance looking down into the drain of $M_1$, which is degenerated by the half-tail resistance $r_{o5h} = 200$ kΩ: $R_{o(\text{down})} \approx r_{o1}(1 + g_{m1}r_{o5h}) \approx 40$ MΩ ($r_{o1} = 200$ kΩ, $g_{m1} = 1$ mA/V). With $r_{o3} = 400$ kΩ the parallel value is ≈ 396 kΩ.
- $a_{cmc} = -g_{m3}(r_{o3}\|R_{o(\text{down})}) \approx -396$. Raising the PMOS gate voltages reduces $|I_{D3}|$, $|I_{D4}|$, so the outputs fall: the gain is negative. (It equals the value obtained with the gate of $M_5$ as the CMC input, because here $g_{m3} = g_{m5h} = 1$ mA/V.)
