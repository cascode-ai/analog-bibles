对于 [图 1] 所示的 MOS 共源共栅电流镜（cascode current mirror），在 $I_{\text{IN}}$ 上并联一个交流输入电流源（流入 $M_4$ 的漏极），输出端（$M_2$ 的漏极）看到的交流负载阻抗为零，其直流电压为 $V_{\text{OUT}} = V_{GS3} + V_{GS4}$。偏置电流为 $I_{\text{IN}} = 100\ \mu$A。器件参数（四只晶体管相同，衬底接地）：$\mu_nC_{ox} = 60\ \mu\mathrm{A/V^2}$，$\gamma = 0$，$\lambda = 0$，$V_t = 0.7$ V，$W = 10\ \mu$m，$L_{\text{eff}} = 1\ \mu$m，偏置点处 $C_{gs} = 20$ fF，$C_{gd} = 3$ fF，$C_{sb} = C_{db} = 10$ fF。计入由速度饱和（velocity saturation）引起的短沟道效应，临界电场（critical field）为 $\mathcal{E}_c = 1.5\times10^6$ V/m：把每只晶体管建模为一个理想平方律器件，并在其源极串联一个电阻 $R_{SX} = 1/(\mathcal{E}_c\mu_nC_{ox}W)$；保持偏置电流不变，并把器件电容接到外部源极端（$R_{SX}$ 的下端）。用零值时间常数法（zero-value time-constant method）估算电流增益 $i_{\text{out}}/i_{\text{in}}$ 的小信号主极点（dominant pole），并与器件的特征频率（transit frequency）$f_T$（同样计入短沟道效应）进行比较。
