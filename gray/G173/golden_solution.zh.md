$M_{109}$ 首先进入线性区，此时过驱动电压约为 $V_{ov} \approx 0.3$ V（考虑 100-mV 裕量时约为 0.275 V）。其所在支路在两条电源轨之间叠放了三个栅源压降。

所有过驱动电压均为 $V_{ov}$、$|V_t| = 0.7$ V 时的各点电压；总电源电压为 3.3 V：
- $M_{101}$/$M_{102}$ 是叠放的 n 沟道二极管：$V_{BIAS4} = -V_{SS} + V_t + V_{ov}$，$M_{101}$、$M_{104}$、$M_{109}$ 的栅极节点位于 $-V_{SS} + 2(V_t + V_{ov})$。
- $M_{107}$/$M_{108}$ 是叠放的 p 沟道二极管：$V_{BIAS1} = V_{DD} - (|V_t| + |V_{ov}|)$，$M_{108}$ 的漏极（= $M_{109}$ 的漏极）位于 $V_{DD} - 2(|V_t| + |V_{ov}|)$。
- $M_{109}$ 的源极比其栅极低一个 $V_{GS}$：$-V_{SS} + V_t + V_{ov}$（因此 $M_{110}$ 的 $V_{DS} = V_t + V_{ov}$）。所以 $V_{DS109} = 3.3 - 3(V_t + V_{ov}) = 1.2 - 3V_{ov}$。
- 处于有源区要求 $V_{DS109} \ge V_{ov}$，即 $V_{ov} \le 0.3$ V。考虑 100-mV 裕量时，$V_{ov} \le 0.275$ V。
- 其他非二极管连接的器件余量更大。$M_{103}$、$M_{110}$、$M_{111}$：$|V_{DS}| = |V_t| + |V_{ov}|$，总是满足。$M_{104}$（漏极位于 $V_{DD} - (V_{ov} + 0.1) - (|V_t| + |V_{ov}|)$，源极位于 $-V_{SS} + V_t + V_{ov}$）及其镜像 $M_{112}$：$|V_{DS}| = 3.3 - 2|V_t| - 3|V_{ov}| - 0.1$，只有在 $V_{ov} \approx 0.43$ V 时才降到 $|V_{ov}| + 0.1$。二极管连接的器件总有 $|V_{DS}| = |V_t| + |V_{ov}|$。

重新设计（任何去掉三个 $V_{GS}$ 叠放的方案均可），例如：
- 在不同的支路中分别产生 $V_{BIAS1}$ 和 $M_{112}$ 的共源共栅栅极电压。单个二极管连接的 p 型器件（$M_{107}$）由其自身的 n 沟道电流源供电，产生 $V_{BIAS1}$。另一个 p 型器件为 $M_{112}$ 的栅极提供偏置：采用 $W/L$ 减小的二极管，或像 $M_{105}$/$M_{106}$ 那样采用二极管加线性区器件。这样每个支路在电源轨之间至多有两个栅源压降加一个过驱动电压，过驱动电压上限提高到约 0.4–0.6 V（下一个限制是 $M_{104}$/$M_{112}$，约 0.43 V）。
- 或者用高摆幅方案偏置 n 型共源共栅管 $M_{109}$（及 $M_{104}$），使 $M_{110}$ 工作在 $V_{DS} \approx V_{ov}$ + 裕量，而不是 $V_t + V_{ov}$。这样可以腾出一个阈值电压的电压余度（headroom）（$V_{DS109} = 3.3 - 2|V_t| - 3V_{ov} - 0.1 = 1.8 - 3V_{ov}$，上限提高到约 0.43 V，与 $M_{104}$/$M_{112}$ 相同）。

缺点：
- 偏置支路增多意味着电流（功耗）和面积增加。
- 单独产生的偏置电压增多，使电路对失配以及阈值电压/过驱动电压关系随工艺/温度的变化更加敏感（基于 $W/L$ 比值或线性区器件的电平移位只能近似跟踪，而且尺寸设计中忽略了体效应）。
- 若某些电流源去掉了共源共栅，其电流将更依赖于 $V_{DS}$（沟道长度调制），降低偏置精度和电源抑制能力。
- 新增的节点可能需要注意启动/建立问题。
