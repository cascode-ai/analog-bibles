Calculation of return ratio begins by breaking a feedback loop at a controlled source. However, breaking a feedback loop at a controlled source is often impossible in a SPICE simulation because the controlled source (e.g., the $g_m$ source in a transistor's small-signal model) is embedded in a small-signal model, so it cannot be accessed or disconnected in simulation. A technique that can be used to simulate the return ratio with SPICE is illustrated in [Fig. 2] and [Fig. 3] for the noninverting amplifier in [Fig. 1]. First, the independent source $V_i$ is set to zero. Next, ac test signals $v_t$ and $i_t$ are injected into the loop at a convenient point (e.g., at the "×" in [Fig. 1]), creating two modified versions of the circuit: [Fig. 2] (test current $i_t$ injected at the × node; $i_d$ flows toward the $R_1$/inverting-input side and $i_m$ arrives from the $R_2$ side) and [Fig. 3] (test voltage $v_t$ inserted in series at the ×; $v_d$ is the node voltage on the $R_1$ side and $v_m$ on the $R_2$ side). Using [Fig. 2], calculate $\mathcal{R}'_i = -i_m/i_d$. Using [Fig. 3], calculate $\mathcal{R}'_v = -v_m/v_d$. The amplitudes of $i_t$ and $v_t$ do not affect $\mathcal{R}'_i$ or $\mathcal{R}'_v$, and these ac test signals do not affect the dc operating point. The return ratio $\mathcal{R}$ for the controlled source is related to $\mathcal{R}'_i$ and $\mathcal{R}'_v$ by
$$\frac{1}{1+\mathcal{R}} = \frac{1}{1+\mathcal{R}'_i} + \frac{1}{1+\mathcal{R}'_v}.$$
Use $R_1 = 1$ kΩ, $R_2 = 5$ kΩ, and for the op amp an input resistance $R_i = 1$ MΩ between its inputs, an output resistance $R_o = 100$ Ω in series with the controlled source $a_v(v_+ - v_-)$, with $a_v = 1\times10^4$.
(a) Compute $\mathcal{R}'_i$ and $\mathcal{R}'_v$ for these circuits. Then combine these values using the equation above to find $\mathcal{R}$.
(b) Compute $\mathcal{R}$ directly by breaking the loop at the $a_v$ controlled source. Compare the results in (a) and (b).
(c) Carry out a SPICE simulation to find $\mathcal{R}'_i$ and $\mathcal{R}'_v$. Then combine these values using the equation above to find $\mathcal{R}$. Compare with your results from (a).
