回归比（return ratio）的计算从在一个受控源处断开反馈环路开始。然而，在 SPICE 仿真中往往无法在受控源处断开反馈环路，因为受控源（例如晶体管小信号模型中的 $g_m$ 源）嵌在小信号模型内部，在仿真中无法访问或断开。[图 2] 和 [图 3] 针对 [图 1] 中的同相放大器（noninverting amplifier）说明了一种可用 SPICE 仿真回归比的技术。首先，将独立源 $V_i$ 置零。然后，在环路中一个方便的位置（例如 [图 1] 中的"×"处）注入交流测试信号 $v_t$ 和 $i_t$，得到电路的两种修改形式：[图 2]（在 × 节点注入测试电流 $i_t$；$i_d$ 流向 $R_1$/反相输入端一侧，$i_m$ 从 $R_2$ 一侧流入）和 [图 3]（在 × 处串联插入测试电压 $v_t$；$v_d$ 为 $R_1$ 一侧的节点电压，$v_m$ 为 $R_2$ 一侧的节点电压）。利用 [图 2] 计算 $\mathcal{R}'_i = -i_m/i_d$。利用 [图 3] 计算 $\mathcal{R}'_v = -v_m/v_d$。$i_t$ 和 $v_t$ 的幅度不影响 $\mathcal{R}'_i$ 或 $\mathcal{R}'_v$，而且这些交流测试信号不影响直流工作点。受控源的回归比 $\mathcal{R}$ 与 $\mathcal{R}'_i$ 和 $\mathcal{R}'_v$ 的关系为
$$\frac{1}{1+\mathcal{R}} = \frac{1}{1+\mathcal{R}'_i} + \frac{1}{1+\mathcal{R}'_v}.$$
取 $R_1 = 1$ kΩ，$R_2 = 5$ kΩ；运放的模型为：两输入端之间的输入电阻 $R_i = 1$ MΩ，与受控源 $a_v(v_+ - v_-)$ 串联的输出电阻 $R_o = 100$ Ω，其中 $a_v = 1\times10^4$。
(a) 计算这些电路的 $\mathcal{R}'_i$ 和 $\mathcal{R}'_v$。然后用上式将这些值组合起来求出 $\mathcal{R}$。
(b) 在 $a_v$ 受控源处断开环路，直接计算 $\mathcal{R}$。比较 (a) 和 (b) 的结果。
(c) 进行 SPICE 仿真求出 $\mathcal{R}'_i$ 和 $\mathcal{R}'_v$。然后用上式将这些值组合起来求出 $\mathcal{R}$。与 (a) 的结果进行比较。
