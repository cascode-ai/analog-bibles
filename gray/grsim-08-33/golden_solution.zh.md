(a) 当 $V_i = 0$ 时同相输入端接地，因此 × 的 $R_1$ 一侧看到对地电阻 $R_1\|R_i = 999$ Ω，$R_2$ 一侧经 $R_2 + R_o = 5.1$ kΩ 通向受控源 $a_v(0 - v_-) = -a_vv_-$。
- 电流注入：× 节点就是反相输入节点（$v_-$）。$i_d = v_-/(R_1\|R_i)$，$i_m = (-a_vv_- - v_-)/(R_2+R_o)$，因此 $\mathcal{R}'_i = (1+a_v)\dfrac{R_1\|R_i}{R_2+R_o} = 10{,}001\times999/5100 = 1959$。
- 电压注入：$v_d = v_-$；电流 $v_d/(R_1\|R_i)$ 从 $R_2$ 一侧流来：$(-a_vv_d - v_m)/(R_2+R_o) = v_d/(R_1\|R_i)$，因此 $\mathcal{R}'_v = a_v + \dfrac{R_2+R_o}{R_1\|R_i} = 10{,}005$。
- $\dfrac{1}{1+\mathcal{R}} = \dfrac{1}{1960} + \dfrac{1}{10{,}006} = 6.101\times10^{-4}$ → $\mathcal{R} = 1638$。
(b) 直接计算：在受控源处加测试电压，经 $R_o + R_2$ 驱动 $R_1\|R_i$：$\mathcal{R} = a_v\dfrac{R_1\|R_i}{R_o + R_2 + R_1\|R_i} = 10^4\times\dfrac{999}{6099} = 1638$。与 (a) 完全相同（对这一单环路电路，组合公式是精确的）。
(c) 对两个注入电路进行交流仿真，应得到 $\mathcal{R}'_i \approx 1959$ 和 $\mathcal{R}'_v \approx 10{,}005$（由于模型中没有电容，此处与频率无关），组合后 $\mathcal{R} \approx 1638$，与 (a) 和 (b) 一致。
