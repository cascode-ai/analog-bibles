$$R_{out} = (r_{o1} + r_{o2} + g_{m2}r_{o1}r_{o2})\left[1 + \frac{a\,g_{m2}(r_{o1}\|r_{o2})}{1 + g_{m2}(r_{o1}\|r_{o2})}\right] = r_{o1}+r_{o2}+(1+a)\,g_{m2}r_{o1}r_{o2}.$$
（结果中不出现 $g_{m1}$：$M_1$ 的栅极由 $M_3$–$R$ 偏置支路保持在交流地，$M_1$ 只相当于电阻 $r_{o1}$。由于 $M_1$ 与 $M_2$ 流过相同的漏极电流，且 $(W/L)_1 = (W/L)_2$、$\gamma = 0$，有 $g_{m1} = g_{m2}$，所以结果也可以写成用 $g_{m1}$ 表示的形式。）

- $R_{out}(a{=}0)$：$M_2$ 的栅极为交流地，电路就是普通的共源共栅：$r_{o1} + r_{o2} + g_{m2}r_{o2}r_{o1}$。
- $\mathcal{R}$（输出短路）：在 $M_2$ 栅极加测试电压 $v_t$；漏极接地时，$M_2$ 是驱动 $r_{o1}\|r_{o2}$ 的源极跟随器：$v_s = v_t\,\dfrac{g_{m2}(r_{o1}\|r_{o2})}{1+g_{m2}(r_{o1}\|r_{o2})}$，返回信号为 $-a v_s$，所以 $\mathcal{R}_{sc} = \dfrac{a\,g_{m2}(r_{o1}\|r_{o2})}{1+g_{m2}(r_{o1}\|r_{o2})}$。
- $\mathcal{R}$（输出开路）：$M_2$ 不能流过电流，因此 $v_s = 0$，$\mathcal{R}_{oc} = 0$。
- 利用 $r_{o1}+r_{o2}+g_{m2}r_{o1}r_{o2} = (r_{o1}+r_{o2})[1+g_{m2}(r_{o1}\|r_{o2})]$，乘积化简为 $r_{o1}+r_{o2}+(1+a)g_{m2}r_{o1}r_{o2} \approx a\,g_{m2}r_{o1}r_{o2}$。
