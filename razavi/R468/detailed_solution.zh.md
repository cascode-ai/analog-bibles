# 详细步骤 - R468

**思路。** 给信号通路上的每个节点关联一个极点，$\omega \approx 1/(R_{node}C_{node})$。由对称性，只需分析一侧：求出每个节点的电阻，列出其电容（电容跨接在有增益的两点之间时要乘以密勒因子），再对各极点排序。

### 第 1 步 — 信号通路及其节点

把 $M_{11}$、$M_7$ 和 $M_9$ 的公共栅极/漏极节点记为节点 A（**电流镜节点**）。差分信号通路上的节点有 X（和 Y）、A（及其右侧的对应节点）以及输出端；$M_1$/$M_2$ 的源极公共节点对差分信号而言是虚地（virtual ground），不产生极点。

在一侧，第一级从 X 抽取电流 $g_{m1}v_{in}/2$，X 处的电阻为 $r_{O1}\parallel r_{O3}$。X 驱动 $M_5$（从 $V_{out1}$ 抽取电流 $g_{m5}v_X$）；Y（$= -v_X$）驱动 $M_9$，其电流流过 A 处二极管连接（diode-connected）的 $M_{11}$（$\approx 1/g_{m11}$），$M_7$ 再把它复制到 $V_{out1}$，该节点的电阻为 $r_{O5}\parallel r_{O7}$，负载为 $C_L$。$C_{GD5}$ 跨接在 X 与 $V_{out1}$ 之间，$C_{GD7}$ 跨接在 A 与 $V_{out1}$ 之间。

### 第 2 步 — X 和 Y 处的极点（第一级的输出端）

$M_5$ 和 $M_{10}$ 的栅极不吸取电流，因此

$$R_X = r_{O1}\parallel r_{O3}\quad\text{(large)}.$$

X 处的电容：

- $M_1$：$C_{DB1}$ 和 $C_{GD1}$（接到输入端，这里视为交流地）；
- $M_3$：$C_{DB3}$ 和 $C_{GD3}$（接到 $V_b$）；
- $M_5$：$C_{GS5}$（源极接地）和跨接在 X 与 $V_{out1}$ 之间的 $C_{GD5}$。从 X 到 $V_{out1}$ 的增益为 $-A_2$，其中 $A_2 = (g_{m5} + Kg_{m9})(r_{O5}\parallel r_{O7})$（下拉管和有源上拉管都对信号作出响应），因此 $C_{GD5}$ 在 X 处表现为 $(1 + A_2)C_{GD5}$；
- $M_{10}$：$C_{GS10}$（源极接地）和 $C_{GD10}$，后者跨接在 X 与右侧电流镜节点之间，而该节点的电压为 $-(g_{m10}/g_{m12})v_X$，因此它要乘以 $(1 + g_{m10}/g_{m12})$。

$$C_X \approx C_{GS5} + C_{GS10} + C_{DB1} + C_{GD1} + C_{DB3} + C_{GD3} + (1 + A_2)C_{GD5} + \left(1 + \frac{g_{m10}}{g_{m12}}\right)C_{GD10} .$$

$$\boxed{\omega_X \approx \frac{1}{(r_{O1}\parallel r_{O3})\,C_X}}$$

由于 $R_X$ 很大，而 $C_X$ 又包含经密勒倍增的 $C_{GD5}$ 和两个栅极电容，这通常是一个**低频**极点；Y 处有相同的极点。

### 第 3 步 — 输出端的极点

$V_{out1}$ 接有 $M_5$ 和 $M_7$ 的漏极：

$$R_{out} = r_{O5}\parallel r_{O7}.$$

其电容包括 $C_L$、结电容（junction capacitance）$C_{DB5}$ 和 $C_{DB7}$、$C_{GD7}$（其另一端 A 几乎是交流地），以及密勒因子为 $(1 + 1/A_2) \approx 1$ 的 $C_{GD5}$：

$$C_{out} \approx C_L + C_{DB5} + C_{GD5} + C_{DB7} + C_{GD7} .$$

$$\boxed{\omega_{out} \approx \frac{1}{(r_{O5}\parallel r_{O7})\,C_{out}}}$$

$R_{out}$ 比 $R_X$ 小，但 $C_L$ 通常很大，因此这一极点也比较**低**。

### 第 4 步 — 电流镜节点（$M_{11}/M_7$ 和 $M_{12}/M_8$ 的栅极）处的极点

A 是二极管连接的 $M_{11}$ 的漏极和栅极，并与 $r_{O11}$、$r_{O9}$ 并联：

$$R_A = \frac{1}{g_{m11}}\parallel r_{O11}\parallel r_{O9} \approx \frac{1}{g_{m11}}\quad\text{(small)}.$$

其电容包括 $C_{GS11}$ 和 $C_{GS7}$（源极接 $V_{DD}$）、结电容 $C_{DB11}$ 和 $C_{DB9}$、$C_{GD9}$（接到 Y），以及跨接在 A 与 $V_{out1}$ 之间的 $C_{GD7}$；在低于输出极点的频率下，后者的密勒因子为 $(1 + g_{m7}R_{out})$：

$$C_A \approx C_{GS11} + C_{GS7} + C_{DB11} + C_{DB9} + C_{GD9} + (1 + g_{m7}R_{out})\,C_{GD7} .$$

$$\boxed{\omega_m \approx \frac{g_{m11}}{C_A}}$$

由于 $R_A \approx 1/g_{m11}$ 很小，这一极点通常位于**高频**，接近 $M_{11}$ 的特征频率（transit frequency），只是较大的 $M_7$ 带来的额外电容会使它有所降低。

### 第 5 步 — 电流镜极点伴随着一个零点

信号沿两条并行通路到达 $V_{out1}$：一条直接经过 $M_5$（来自 X），另一条经过 $M_9 \to M_{11} \to M_7$（来自 Y），只有后者包含电流镜极点。输出电流正比于

$$g_{m5} + \frac{Kg_{m9}}{1 + s/\omega_m} = (g_{m5} + Kg_{m9})\,\frac{1 + s/\omega_z}{1 + s/\omega_m}, \qquad \omega_z = \omega_m\,\frac{g_{m5} + Kg_{m9}}{g_{m5}} .$$

当两者贡献相等（$Kg_{m9} = g_{m5}$）时，$\omega_z = 2\omega_m$：这是一个位于电流镜极点两倍频率处的左半平面零点（left-half-plane zero），与以有源电流镜为负载的差分对中的情形相同，因此这一零极点对（doublet）对响应只有轻微影响。

### 第 6 步 — 总结与推论

| 节点 | 电阻 | 主要电容 | 极点 |
|---|---|---|---|
| X、Y | $r_{O1}\parallel r_{O3}$（大） | $C_{GS5}$、$C_{GS10}$、结电容、$(1 + A_2)C_{GD5}$ | 低 |
| $V_{out1}$、$V_{out2}$ | $r_{O5}\parallel r_{O7}$ | $C_L$ + 结电容 | 低 |
| 电流镜节点 | $\approx 1/g_{m11}$（小） | $C_{GS11} + C_{GS7}$ + 结电容 | 高（伴随约 $2\omega_m$ 处的零点） |

$\omega_X$ 和 $\omega_{out}$ 都很低且大小相当，因此未补偿的运放相位裕度（phase margin）很差，在用于反馈之前需要进行频率补偿（例如在 $M_5$/$M_6$ 两端跨接密勒电容）。

### 结果

1. **第一级输出端 X、Y：** $\omega_X \approx \dfrac{1}{(r_{O1}\parallel r_{O3})\,C_X}$，其中 $C_X \approx C_{GS5} + C_{GS10} + C_{DB1} + C_{GD1} + C_{DB3} + C_{GD3} + (1 + A_2)C_{GD5} + (1 + g_{m10}/g_{m12})C_{GD10}$，$A_2 = (g_{m5} + Kg_{m9})(r_{O5}\parallel r_{O7})$。
2. **输出端：** $\omega_{out} \approx \dfrac{1}{(r_{O5}\parallel r_{O7})(C_L + C_{DB5} + C_{GD5} + C_{DB7} + C_{GD7})}$。
3. **电流镜节点**（$M_{11}/M_7$、$M_{12}/M_8$ 的栅极）：$\omega_m \approx \dfrac{g_{m11}}{C_{GS11} + C_{GS7} + C_{DB11} + C_{DB9} + C_{GD9} + (1 + g_{m7}R_{out})C_{GD7}}$，这是一个高频极点，并伴随着 $2\omega_m$ 附近的一个零点。

**常见错误。** 给电流镜节点赋予一个大电阻（$r_{O9}$ 或 $r_{O11}$）。二极管连接的 $M_{11}$ 使它成为低阻抗节点（$\approx 1/g_{m11}$）；$M_9$/$M_{10}$ 的漏极**不是**高阻抗节点。

**常见错误。** 在 $M_1$/$M_2$ 的源极公共节点处列出一个极点，而该节点对差分信号而言是虚地。

**常见错误。** 漏掉 X 处 $C_{GD5}$ 的密勒倍增：它跨接在增益为 $A_2$ 的两点之间，表现为约乘以 $1 + A_2$，并可能在 $C_X$ 中占主导地位。
