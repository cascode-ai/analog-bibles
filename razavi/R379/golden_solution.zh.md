两个电路的戴维南阻抗相等（关闭噪声源后两个电路完全相同），但戴维南电压分别为 $V_{Thev1} = -I_nr_O$ 和 $V_{Thev2} = V_n\dfrac{-g_mr_O + sC_{GS}Z_S(1 + g_{mb}r_O)}{1 + sC_{GS}(Z_1 + Z_S)}$。因此等效要求
$$V_n = \frac{I_n\,[1 + sC_{GS}(Z_1 + Z_S)]}{g_m - sC_{GS}Z_S(g_{mb} + 1/r_O)},$$
它取决于 $Z_1$、$Z_S$ 和频率：引理一般不成立。只有当 $|sC_{GS}(Z_1+Z_S)| \ll 1$（低频）时，它才简化为 $V_n = I_n/g_m$。

- [图 1]，漏极开路：漏极总电流为零，因此栅极回路（$Z_1$–$C_{GS}$–$Z_S$）中没有源，也就没有电流：$V_G = V_S = 0$，由 $0 = V_{D}/r_O + I_n$ 得 $V_{Thev1} = -I_nr_O$。
- [图 2]，漏极开路：沟道中没有电流，因此 $V_n$ 驱动由 $Z_1$、$C_{GS}$、$Z_S$ 构成的回路：$V_{GS} = \dfrac{V_n}{1 + sC_{GS}(Z_1+Z_S)}$，$V_S = \dfrac{V_nsC_{GS}Z_S}{1 + sC_{GS}(Z_1+Z_S)}$。由沟道电流为零：$g_mV_{GS} - g_{mb}V_S + (V_D - V_S)/r_O = 0$，得 $V_D = V_S(1 + g_{mb}r_O) - g_mr_OV_{GS}$。
- 差别的原因在于：栅极电压源会推动电流经 $C_{GS}$ 流入 $Z_S$，而漏源之间的电流源不会。
