# 详细步骤 - R305

**思路。** 该电路是一个 NMOS 共源共栅级（$M_1$、$M_2$），以 PMOS 电流源（$M_3$）为负载，并有一个电容 $C_1$ 从共源共栅节点 X 接到输出端。当 $\lambda = 0$ 时，对超节点列 KCL 可知增益在**任何**频率下都是无界的，两个极限情况（$C_1$ 开路和 $C_1$ 短路）也证实了这一点。由于“无穷大”只有作为极限才有意义，随后再用有限的 $r_O$ 重复分析，并令 $\lambda\to0$。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 的漏极（$M_2$ 的源极）称为节点 X。$V_{DD}$ 和 $V_{b2}$ 为交流地：

- **$M_1$：** 从 X 流向地的电流 $g_{m1}V_{in}$（若 $\lambda\ne0$，另有从 X 到地的 $r_{O1}$）。
- **$M_2$：** 从输出端流向 X 的电流 $g_{m2}v_{gs2} = g_{m2}(0 - V_X) = -g_{m2}V_X$（若 $\lambda\ne0$，另有接在输出端与 X 之间的 $r_{O2}$）。
- **$M_3$：** $v_{gs3} = 0$，因此只剩下从输出端到交流地的 $r_{O3}$；当 $\lambda = 0$ 时，$M_3$ 是**理想电流源**（开路）。
- **$C_1$** 接在 X 与输出端之间。没有电容把 X 或输出端接到地。

当 $\lambda = 0$ 时，从该模型中去掉 $r_{O1}$、$r_{O2}$ 和 $r_{O3}$。

### 第 2 步 — 对超节点 X + 输出端列 KCL（λ = 0）

围绕 X 和输出端画一个边界。$M_2$ 的沟道和 $C_1$ 都位于边界之内，只在两个节点之间传递电流。唯一带着信号电流穿过边界的元件是 $M_1$ 的漏极，它把 $g_{m1}V_{in}$ 从 X 送到地：$M_3$ 是理想电流源，而 $M_2$ 的栅极接在 $V_{b2}$ 上，不吸取电流。因此超节点的 KCL 为

$$g_{m1}V_{in} = 0 ,$$

对于非零输入，任何有限的节点电压都无法满足此式。电流 $g_{m1}V_{in}$ 既没有到地的电阻性通路（λ = 0），也没有到地的电容性通路（没有接地电容），因此节点电压会无限增长：**增益为无穷大**，而且在任何频率下都如此，因为 $C_1$ 完全位于超节点内部。

### 第 3 步 — 极低频（λ = 0）

$C_1$ 开路，剩下一个以电流源为负载的普通共源共栅级：

$$A_v = -g_{m1}\,(R_{out,casc}\parallel r_{O3}), \qquad R_{out,casc}\approx g_{m2}r_{O2}r_{O1}.$$

当 $\lambda = 0$ 时，每个 $r_O$ 都是无穷大，因此 $R_{out,casc}\parallel r_{O3} = \infty$，且

$$A_v(\text{low}) = \infty .$$

### 第 4 步 — 极高频（λ = 0）

$C_1$ 把 X 与输出端短接，因此 $M_2$（漏源短接）不再起作用，只剩下以 $M_3$ 为负载的共源级 $M_1$：

$$A_v = -g_{m1}\,(r_{O1}\parallel r_{O3}),$$

当 $\lambda = 0$ 时它同样为无穷大：

$$A_v(\text{high}) = \infty .$$

### 第 5 步 — 作为参考：同一电路在有限 $r_O$ 下的结果

保留 $r_{O1}$、$r_{O2}$、$r_{O3}$，并令

$$i_{2} = -g_{m2}V_X + \frac{V_{out} - V_X}{r_{O2}} + (V_{out} - V_X)C_1s$$

为从输出端经 $M_2$、$r_{O2}$ 和 $C_1$ 流向 X 的总电流。输出端和 X 点的 KCL：

$$-\frac{V_{out}}{r_{O3}} = i_2 , \qquad (1)$$

$$i_2 = g_{m1}V_{in} + \frac{V_X}{r_{O1}} . \qquad (2)$$

令式 (1) 与式 (2) 相等：

$$V_X = -r_{O1}\left(g_{m1}V_{in} + \frac{V_{out}}{r_{O3}}\right). \qquad (3)$$

记 $Y = 1/r_{O2} + C_1s$，式 (1) 变为 $-V_{out}/r_{O3} = -V_X(g_{m2} + Y) + V_{out}Y$，即

$$V_X\,(g_{m2} + Y) = V_{out}\left(Y + \frac{1}{r_{O3}}\right). \qquad (4)$$

把式 (3) 代入式 (4)：

$$
\begin{aligned}
-r_{O1}\left(g_{m1}V_{in} + \frac{V_{out}}{r_{O3}}\right)(g_{m2} + Y) &= V_{out}\left(Y + \frac{1}{r_{O3}}\right)\\
-g_{m1}r_{O1}(g_{m2} + Y)\,V_{in} &= V_{out}\left[Y + \frac{1}{r_{O3}} + \frac{r_{O1}}{r_{O3}}(g_{m2} + Y)\right]\\
\frac{V_{out}}{V_{in}} &= \frac{-g_{m1}r_{O1}r_{O3}(g_{m2} + Y)}{r_{O3}Y + 1 + r_{O1}(g_{m2} + Y)}.
\end{aligned}
$$

代回 $Y = 1/r_{O2} + C_1s$，并将分子、分母同乘以 $r_{O2}$：

$$\frac{V_{out}}{V_{in}}(s) = \frac{-g_{m1}r_{O1}r_{O3}\left(1 + g_{m2}r_{O2} + C_1r_{O2}s\right)}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2} + C_1r_{O2}(r_{O1} + r_{O3})s}.$$

**低频极限**（$s\to0$），即共源共栅增益：

$$A_v(0) = -\frac{g_{m1}r_{O1}r_{O3}(1 + g_{m2}r_{O2})}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}\approx -g_{m1}\left[(g_{m2}r_{O2}r_{O1})\parallel r_{O3}\right].$$

**高频极限**（$s\to\infty$，只保留含 $s$ 的项）：

$$A_v(\infty) = -\frac{g_{m1}r_{O1}r_{O3}C_1r_{O2}}{C_1r_{O2}(r_{O1} + r_{O3})} = -g_{m1}(r_{O1}\parallel r_{O3}).$$

在高频时，$C_1$ 旁路了共源共栅器件，消除了输出电阻的提升因子 $g_{m2}r_{O2}$，因此增益从共源共栅的值降到简单共源级的值。**令 $\lambda\to0$**（$r_O\to\infty$），两个值都随 $r_O$ 增大而趋于无穷大，与第 3 步和第 4 步一致。

### 结果

当 $\lambda = 0$ 时，增益**在极低频和极高频下都是无界的（无穷大）**。X 与输出端合在一起没有到地的电阻性或电容性通路（负载为理想电流源，且没有接地电容），因此电流 $g_{m1}V_{in}$ 在任何频率下都无法被吸收。

- 低频（$C_1$ 开路）：带理想负载的共源共栅级，增益为 $-g_{m1}R_{out}$，其中 $R_{out} = \infty$。
- 高频（$C_1$ 短路）：带理想负载的共源级，$-g_{m1}(r_{O1}\parallel r_{O3}) = \infty$。

若 $r_O$ 有限：低频增益为 $-\dfrac{g_{m1}r_{O1}r_{O3}(1 + g_{m2}r_{O2})}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}\approx -g_{m1}\left[(g_{m2}r_{O2}r_{O1})\parallel r_{O3}\right]$，高频增益为 $-g_{m1}(r_{O1}\parallel r_{O3})$。

**常见错误。** 在 $\lambda = 0$ 的条件下得到有限的增益，例如 $-g_{m1}/g_{m2}$（好像输出端接的是二极管负载）或某个电容分压比。负载是理想电流源，又没有对地电容，没有任何元件能把 $g_{m1}V_{in}$ 转换为有限的电压。

**常见错误。** 在有限 $r_O$ 的分析中声称 $C_1$ 在高频时不起作用。$C_1$ 把共源共栅器件短路，因此增益失去因子 $g_{m2}r_{O2}$，降为 $-g_{m1}(r_{O1}\parallel r_{O3})$。

**常见错误。** 不加说明地改用有限 $r_O$，并只给出有限的数值。对于题目给定的 $\lambda = 0$，答案是“两端均为无穷大”；有限 $r_O$ 的表达式只是作为极限证实了这一点。
