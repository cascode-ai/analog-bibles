当 λ = 0 时，增益在极低频和极高频下都是无界的（无穷大）。
- 节点 X（$M_2$ 的源极，$M_1$ 的漏极）与输出节点之间只通过 $M_2$ 和 $C_1$ 相连。当 λ = 0 时，PMOS 管 $M_3$ 是理想电流源（current source），而且没有电容把这两个节点中的任何一个接到地。把这两个节点合在一起看，它们构成一个超节点（supernode），其唯一的小信号电流是 $M_1$ 的漏极电流 $g_{m1}V_{in}$，因此在任何频率下，任何有限的节点电压都不能满足基尔霍夫电流定律（KCL）方程 $g_{m1}V_{in} = 0$。
- 低频：$C_1$ 开路，电路是以理想电流源为负载的普通共源共栅（cascode）级：$A_v = -g_{m1}R_{out}$，其中 $R_{out} = \infty$。
- 高频：$C_1$ 把 X 与输出端短接，旁路了 $M_2$；该级变为以理想电流源为负载的共源级（common-source stage）：λ = 0 时 $-g_{m1}(r_{O1}\|r_{O3}) = \infty$。
- 作为参考，若 $r_O$ 有限：低频增益为 $-\dfrac{g_{m1}r_{O1}r_{O3}(1 + g_{m2}r_{O2})}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}} \approx -g_{m1}[(g_{m2}r_{O2}r_{O1})\|r_{O3}]$（共源共栅增益）；高频增益为 $-g_{m1}(r_{O1}\|r_{O3})$：$C_1$ 消除了共源共栅结构对输出电阻（output resistance）的提升作用。
