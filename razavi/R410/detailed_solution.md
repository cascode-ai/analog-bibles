# Detailed solution - R410

**Approach.** In the modified circuit ([Fig. 1]) the error voltage $v_{in} - v_F$ is formed by the differential pair $M_1$–$M_4$ instead of at the source of $M_1$, and the feedback network drives only the gate of $M_4$. Find the bias point, the open-loop gain and the loop gain of this series–shunt loop, and from them the closed-loop gain and output resistance. Then repeat the analysis briefly for the original circuit ([Fig. 2]) and compare.

### Step 1 — The modified circuit and its bias point

Call the common source node of $M_1$ and $M_4$ P, and the gate of $M_4$ (the junction of $R_F$ and $R_{S1}$) F.

**KCL at F.** The gate of $M_4$ draws no current, so $R_F$ and $R_{S1}$ carry the same current:

$$\frac{V_{out} - V_F}{R_F} = \frac{V_F - 1.5}{R_{S1}} \ \Longrightarrow\ V_F = \frac{V_{out} + 1.5}{2}\quad(R_F = R_{S1}).$$

**KCL at $V_{out}$** ($M_3$ supplies 0.5 mA; mA, kΩ, V):

$$
\begin{aligned}
0.5 &= \frac{V_{out}}{3} + \frac{V_{out} - V_F}{3}\ \Longrightarrow\ 1.5 = 2V_{out} - V_F = 2V_{out} - \frac{V_{out} + 1.5}{2}\\
3 &= 3V_{out} - 1.5\ \Longrightarrow\ V_{out} = 1.5\ \mathrm{V},\quad V_F = 1.5\ \mathrm{V}.
\end{aligned}
$$

**Input dc level.** $M_1$ and $M_4$ are identical, share P and carry 0.5 mA each, so they have equal $V_{GS}$ and $V_{in} = V_F = 1.5$ V. With the overdrive $\sqrt{2(0.5\ \mathrm{mA})/(13.4\ \mathrm{mA/V^2})} = 0.273$ V, solving $V_{GS} = V_{TH}(V_{SB} = V_P) + 0.273$ V with $V_P = 1.5 - V_{GS}$ by iteration gives $V_{GS} \approx 1.07$ V and $V_P \approx 0.43$ V.

$V_X = V_{DD} - |V_{GS3}| = 3 - (0.8 + 0.51) = 1.69$ V, so $V_{DS1} = 1.69 - 0.43 = 1.26\ \mathrm{V} > 0.273$ V: $M_1$ is comfortably saturated.

### Step 2 — Small-signal parameters

$$
\begin{aligned}
g_{m1} = g_{m4} &= \sqrt{2(134\ \mu\mathrm{A/V^2})(100)(0.5\ \mathrm{mA})} = 3.66\ \mathrm{mS},\\
g_{m3} &= \sqrt{2(38.4\ \mu\mathrm{A/V^2})(100)(0.5\ \mathrm{mA})} = 1.96\ \mathrm{mS},\\
r_{O1} = r_{O4} &= \frac{1}{(0.1\ \mathrm{V^{-1}})(0.5\ \mathrm{mA})} = 20\ \mathrm{k\Omega},\qquad
r_{O2} = r_{O3} = \frac{1}{(0.2\ \mathrm{V^{-1}})(0.5\ \mathrm{mA})} = 10\ \mathrm{k\Omega}.
\end{aligned}
$$

The tail source is taken as ideal.

### Step 3 — Feedback structure

$R_F$–$R_{S1}$ sense $V_{out}$ ($V_{b2}$ is ac ground) and apply $v_F = \beta v_{out}$ to the gate of $M_4$; the pair responds to $v_{in} - v_F$, so the loop is series–shunt. The gate draws no current, so the divider is unloaded:

$$\beta = \frac{R_{S1}}{R_{S1} + R_F} = 0.5 .$$

At the output the network presents $R_F + R_{S1} = 6\ \mathrm{k\Omega}$ to ground; at the input side it loads nothing.

### Step 4 — The differential pair: the body effect cancels

Neglecting $r_{O1}$, $r_{O4}$ for the moment, with the bulks grounded:

$$i_1 = g_m(v_{in} - v_P) - g_{mb}v_P, \qquad i_4 = g_m(v_F - v_P) - g_{mb}v_P .$$

The ideal tail carries no signal current, so $i_1 + i_4 = 0$:

$$
\begin{aligned}
g_m(v_{in} + v_F) - 2(g_m + g_{mb})v_P &= 0 \ \Longrightarrow\ v_P = \frac{g_m(v_{in} + v_F)}{2(g_m + g_{mb})},\\
i_1 &= g_mv_{in} - (g_m + g_{mb})v_P = g_mv_{in} - \frac{g_m(v_{in} + v_F)}{2} = \frac{g_m}{2}(v_{in} - v_F).
\end{aligned}
$$

$g_{mb}$ drops out: it only moves the common-mode level of P. With $r_{O1} = r_{O4}$ the same symmetry holds exactly with the drain of $M_1$ at ac ground, so the short-circuit current into X is $(g_m/2)(v_{in} - v_F)$.

**Resistance at X.** The source of $M_1$ is degenerated by $M_4$'s source, $R_s = 1/(g_m + g_{mb} + 1/r_{O4})$, so

$$
\begin{aligned}
R_{d1} &= r_{O1} + R_s\big[(g_m + g_{mb})r_{O1} + 1\big] = r_{O1}\left[1 + \frac{g_m + g_{mb} + 1/r_{O1}}{g_m + g_{mb} + 1/r_{O4}}\right]\\
&= 2r_{O1} = 40\ \mathrm{k\Omega}\quad(\text{since } r_{O1} = r_{O4}),
\end{aligned}
$$

$$R_X = r_{O2}\parallel R_{d1} = \frac{10\times40}{10 + 40}\ \mathrm{k\Omega} = 8\ \mathrm{k\Omega}.$$

### Step 5 — Open-loop gain, loop gain, closed-loop gain and $R_{out}$

$$
\begin{aligned}
\frac{v_X}{v_{in} - v_F} &= -\frac{g_m}{2}R_X = -(1.83\ \mathrm{mS})(8\ \mathrm{k\Omega}) = -14.6 ,\\
R_L &= R_{D2}\parallel(R_F + R_{S1})\parallel r_{O3} = 3\parallel6\parallel10\ \mathrm{k\Omega} = \frac{1}{0.6}\ \mathrm{k\Omega} = 1.67\ \mathrm{k\Omega},\\
\frac{v_{out}}{v_X} &= -g_{m3}R_L = -(1.96\ \mathrm{mS})(1.67\ \mathrm{k\Omega}) = -3.27 ,\\
A_{open} &= (-14.6)(-3.27) = 47.8,\\
T &= \beta A_{open} = 0.5\times47.8 = 23.9 .
\end{aligned}
$$

Series–shunt feedback divides both the gain and the output resistance by $1 + T$:

$$
\begin{aligned}
A_v &= \frac{A_{open}}{1 + T} = \frac{47.8}{24.9} = 1.92,\\
R_{out} &= \frac{R_L}{1 + T} = \frac{1667\ \Omega}{24.9} = 67\ \Omega .
\end{aligned}
$$

Because the gate of $M_4$ draws no current and the tail is ideal, this decomposition is exact: a full nodal analysis with every $r_O$ and $g_{mb}$ gives the same 1.92 and 67 Ω. If only the load resistances $r_{O2}$, $r_{O3}$ are kept ($R_X = 10\ \mathrm{k\Omega}$), then $A_{open} = 59.8$, $T = 29.9$, $A_v = 1.94$ and $R_{out} = 54\ \Omega$.

### Step 6 — The original circuit (Fig. 2) for comparison

In [Fig. 2] the source of $M_1$ (node S) connects to $R_{S1}$ (to ground) and $R_F$. KCL with 0.5 mA injected into S and into $V_{out}$ gives $V_S = V_{out} = 1.5$ V, so $V_{SB1} = 1.5$ V, $\eta = \gamma/(2\sqrt{0.9 + 1.5}) = 0.145$ and $g_{mb1} = 0.53$ mS. The input level is $V_{in} = 1.5 + V_{GS1} \approx 2.74$ V, and with $V_X = 1.69$ V, $V_{DS1} \approx 0.19$ V is marginal; saturation is assumed as instructed.

**Open loop** ($R_{S1}\parallel R_F = 1.5\ \mathrm{k\Omega}$ degenerates $M_1$; $R_F + R_{S1} = 6\ \mathrm{k\Omega}$ loads the output):

$$
\begin{aligned}
G_{m1} &= \frac{g_{m1}}{1 + (g_{m1} + g_{mb1})(1.5\ \mathrm{k\Omega}) + 1.5/20} = \frac{3.66}{7.36}\ \mathrm{mS} = 0.497\ \mathrm{mS},\\
R_X &= r_{O2}\parallel\big[(7.29)(20\ \mathrm{k\Omega}) + 1.5\ \mathrm{k\Omega}\big] = 10\parallel147\ \mathrm{k\Omega} = 9.36\ \mathrm{k\Omega},\\
A_{open} &= (0.497\ \mathrm{mS})(9.36\ \mathrm{k\Omega})\times3.27 = 4.66\times3.27 = 15.2 .
\end{aligned}
$$

**Loop gain.** The source of $M_1$ acts on the drain current with weight $g_{m1} + g_{mb1}$, so the fed-back voltage is scaled by $1 + \eta$: $T = (1 + \eta)\beta A_{open} = 1.145\times0.5\times15.2 = 8.7$.

$$A_v = \frac{15.2}{9.7} = 1.57\ \ (\text{exact nodal analysis: }1.55),\qquad R_{out} = \frac{1.67\ \mathrm{k\Omega}}{9.7} = 0.17\ \mathrm{k\Omega}\ \ (\text{exact: }0.166\ \mathrm{k\Omega}).$$

### Step 7 — Comparison and explanation

| | Fig. 2 (original) | Fig. 1 (with $M_4$) |
|---|---|---|
| effective input transconductance | 0.50 mS (degenerated $M_1$) | 1.83 mS ($g_m/2$ of the pair) |
| resistance at X | 9.4 kΩ | 8 kΩ |
| open-loop gain | 15.2 | 47.8 |
| loop gain | ≈ 8.7 | ≈ 24 |
| closed-loop gain | ≈ 1.55 | ≈ 1.92 |
| output resistance | ≈ 0.17 kΩ | ≈ 67 Ω |
| ideal limit of the gain | $1/[(1 + \eta)\beta] = 1.75$ | $1/\beta = 1 + R_F/R_{S1} = 2$ |

Why the modified circuit is better:

- **No source degeneration.** In Fig. 2 the network's own resistance divides $M_1$'s transconductance by $1 + (g_m + g_{mb})(1.5\ \mathrm{k\Omega}) \approx 7.3$; in Fig. 1 the network drives a gate, and the pair delivers $g_m/2$.
- **No loading at the input side.** $\beta$ is exactly 0.5, and no signal current from $M_1$ flows through $R_F$.
- **Body effect cancels.** $g_{mb}$ only moves the common-mode level of P, so the subtraction $v_{in} - v_F$ is exact and the gain tends to 2 rather than 1.75.

The loop gain rises from about 9 to about 24, the gain from 1.55 to 1.92, and $R_{out}$ drops by a factor of about 2.5 (about 3 if only $r_{O2}$, $r_{O3}$ are kept). The price is an extra transistor, an extra 0.5 mA, a tail current source and the bias $V_{b2}$; a side benefit is the lower input level (1.5 V instead of 2.74 V), which keeps $M_1$ well inside saturation.

### Result

Modified circuit (Fig. 1): $A_v \approx 1.92$ and $R_{out} \approx 67\ \Omega$ (1.94 and 54 Ω if only $r_{O2}$, $r_{O3}$ are kept), from $A_{open} \approx 48$ and loop gain $\approx 24$.

Original circuit (Fig. 2): $A_v \approx 1.55$ and $R_{out} \approx 0.17\ \mathrm{k\Omega}$ (about 1.77 if its body effect is ignored), from a loop gain of about 8.7.

The modified circuit is much closer to the ideal gain $1 + R_F/R_{S1} = 2$ and has a 2.5–3 times lower output resistance, because removing the source degeneration and the body-effect penalty raises the loop gain about threefold.

**Common mistake.** Using the full $g_m$ for the first stage of the modified circuit. The input is shared by the two halves of the pair, so $i_{d1} = (g_m/2)(v_{in} - v_F)$.

**Common mistake.** Concluding that inserting $M_4$ lowers the loop gain because "half the transconductance is lost". In the original circuit the source degeneration divides the transconductance by about 7.3, far worse than the factor 2 of the pair.

**Common mistake.** Keeping the body-effect correction in the modified circuit. With an ideal tail it cancels for the differential signal, so the ideal gain is exactly $1/\beta = 2$.
