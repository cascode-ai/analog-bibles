# 详细步骤 - R258

**思路。** 在这个低压共源共栅结构的电流镜（current mirror）中，只要 $M_4$ 饱和，两条支路就是由相同栅极电压驱动的相同电路，因此它们的电流相同，中间节点电压也相同。随着 $I_{REF}$ 增大，逐一跟踪各个电压（采用平方律模型，并计入 $M_3$ 和 $M_4$ 的体效应），并确定 $M_2$（以及 $M_1$）退出饱和区的位置。

### 第 1 步 — 器件方程

令 $\beta_{12} = \mu_nC_{ox}(W/L)_{1,2}$，$\beta_{34} = \mu_nC_{ox}(W/L)_{3,4}$。衬底接地，因此共源共栅器件的源-衬底电压等于其源极电压 $s = V_A$ 或 $V_B$，且

$$V_{TH}(s) = 0.7 + 0.45\left(\sqrt{0.9 + s} - \sqrt{0.9}\right)\ \mathrm{V}.$$

取 $\lambda = 0$，参考支路（$M_4$ 叠在 $M_2$ 之上）满足

$$
\begin{aligned}
M_4:&\quad I_{REF} = \frac{\beta_{34}}{2}\left[V_b - V_A - V_{TH}(V_A)\right]^2 \quad \text{if saturated, i.e. } V_X - V_A \ge V_b - V_A - V_{TH}(V_A),\\
M_2:&\quad I_{REF} = \frac{\beta_{12}}{2}(V_X - 0.7)^2 \quad \text{if saturated, i.e. } V_A \ge V_X - 0.7,\\
& \quad I_{REF} = \beta_{12}\left[(V_X - 0.7)V_A - \tfrac12V_A^2\right] \quad \text{if in triode.}
\end{aligned}
$$

输出支路满足同样的方程，只需把 A 换成 B，把 $I_{REF}$ 换成 $I_{out}$，并且 $M_3$ 的漏极接 $V_{DD}$ 而不是 X。**$M_3$ 始终饱和**：其饱和条件 $V_{DD} - V_B \ge V_b - V_B - V_{TH}(V_B)$ 化简为 $V_b \le V_{DD} + V_{TH}$，对任何合理的 $V_b$ 都成立。

### 第 2 步 — 为什么 $M_4$ 饱和时 $V_A = V_B$ 且 $I_{out} = I_{REF}$

当 $M_3$ 和 $M_4$ 都饱和且 $\lambda = 0$ 时，两个共源共栅器件的电流都与各自的漏极电压无关，因此两条支路是**同一个电路**：栅极电压相同（下方为 $V_X$，上方为 $V_b$），器件方程也相同。在任一条支路中，设中间节点电压为 $V$，支路电流为 $I$：

- 上方器件给出 $I = \tfrac{\beta_{34}}{2}[V_b - V - V_{TH}(V)]^2$，它随 $V$ 升高而**减小**；
- 下方器件的电流随其漏极电压 $V$ **增大**（线性区）或保持不变（饱和区）。

一条递减曲线与一条非递减曲线只相交一次，因此两条支路有相同的唯一解：

$$V_A = V_B, \qquad I_{out} = I_{REF} \quad \text{(exactly, whatever region } M_1, M_2 \text{ are in).}$$

共源共栅结构迫使 $V_{DS1} = V_{DS2}$，因此复制是精确的。

### 第 3 步 — $V_A$ 和 $V_B$ 随 $I_{REF}$ 的变化

令 $V_{ov4} = \sqrt{2I_{REF}/\beta_{34}}$，由 $M_4$ 的饱和区方程得

$$V_b - V_A - V_{TH}(V_A) = V_{ov4} \quad\Longrightarrow\quad V_A + V_{TH}(V_A) = V_b - \sqrt{\frac{2I_{REF}}{\beta_{34}}} .$$

- 当 $I_{REF} \to 0$ 时：$V_A + V_{TH}(V_A) = V_b$，因此 $V_A$ 的起点约为 $V_b - V_{TH}$。
- 随着 $I_{REF}$ 增大，右边按 $\sqrt{I_{REF}}$ 的规律减小，因此 **$V_A = V_B$ 下降**。

**体效应。** 令 $\eta = dV_{TH}/dV_A = \gamma/(2\sqrt{0.9 + V_A}) \approx 0.18$–0.23：

$$(1 + \eta)\,dV_A = -\,dV_{ov4} \quad\Longrightarrow\quad \frac{dV_A}{dI_{REF}} = -\frac{1}{(1 + \eta)\,g_{m4}}, \qquad g_{m4} = \sqrt{2\beta_{34}I_{REF}} .$$

随着 $V_A$ 下降，$V_{TH4}$ 也下降，起到部分补偿作用，因此 $V_A$ 的降幅比按 $\sqrt{I_{REF}}$ 估计的略小。

### 第 4 步 — $V_X$ 以及 $M_2$ 退出饱和区的位置

**当 $M_2$ 饱和时：**

$$V_X = 0.7\ \mathrm{V} + \sqrt{\frac{2I_{REF}}{\beta_{12}}} \qquad \text{(slow, square-root rise)}.$$

**饱和区边缘。** 只有当 $V_A \ge V_X - 0.7 = \sqrt{2I_{REF}/\beta_{12}}$ 时 $M_2$ 才饱和；$V_A$ 下降而 $V_X - 0.7$ 上升，因此两者会在某个电流处相遇。若 $\beta$ 相等且不计体效应，则 $V_A = V_b - 0.7 - V_{ov}$，由边缘条件 $V_A = V_{ov}$ 得 $V_{ov} = (V_b - 0.7)/2$，即

$$I_{REF,edge} \approx \frac{\beta}{2}\left(\frac{V_b - 0.7}{2}\right)^2 = \frac{\beta}{8}(V_b - V_{TH})^2 .$$

体效应使 $V_{TH4}$ 高于 0.7 V，从而降低 $V_A$，使边缘移到稍**小**的电流处。$M_1$ 的 $V_{GS}$ 与之相同，并且由第 2 步可知其 $V_{DS}$ 也相同，因此它在同一时刻退出饱和区，这**不会**破坏 $I_{out} = I_{REF}$。

**越过边缘之后**（$M_2$ 处于线性区），由线性区方程解出 $V_X$：

$$
\begin{aligned}
I_{REF} &= \beta_{12}\left[(V_X - 0.7)V_A - \tfrac12V_A^2\right]\\
(V_X - 0.7)V_A &= \frac{I_{REF}}{\beta_{12}} + \frac{V_A^2}{2}\\
V_X &= 0.7 + \frac{I_{REF}}{\beta_{12}V_A} + \frac{V_A}{2} .
\end{aligned}
$$

由于 $V_A$ 不断下降，$I_{REF}/(\beta_{12}V_A)$ 的增长远快于 $\sqrt{I_{REF}}$：**$V_X$ 急剧向上弯曲**。当 $V_A \to 0$，即 $I_{REF} \to \tfrac{\beta_{34}}{2}(V_b - 0.7)^2$（源极接地时 $M_4$ 所能通过的最大电流）时，它将发散；实际上，当 $V_X$ 接近 $V_{DD}$ 时，$I_{REF}$ 电流源就已没有足够的电压余度。

### 第 5 步 — $M_4$ 是否饱和？（$V_b$ 的范围）

若 $V_X \ge V_b - V_{TH}(V_A)$，则 $M_4$ 饱和。最不利的点是 $I_{REF} \to 0$，此时 $V_X \to 0.7$ V，$V_A \to V_b - V_{TH}(V_A)$，因此该条件变为 $V_A \le 0.7$ V，即

$$V_b \le 0.7 + V_{TH}(0.7) = 0.7 + 0.7 + 0.45\left(\sqrt{1.6} - \sqrt{0.9}\right) = 0.7 + 0.842 = 1.54\ \mathrm{V}.$$

若 $\beta$ 相等，则 $M_4$ 对所有更大的 $I_{REF}$ 都保持饱和：条件 $V_X - V_A \ge V_{ov4}$，即 $0.7 + V_{ov2} - V_A \ge V_{ov4}$，在 $V_{ov2} = V_{ov4}$ 时化简为 $V_A \le 0.7$ V，随着 $V_A$ 下降，这一条件只会更容易满足。此外，$V_b$ 必须大于 0.7 V，否则根本不会有电流流动。

因此预期的低压偏置为 $0.7\ \mathrm{V} < V_b \lesssim 1.54$ V，在此范围内，第 2–4 步的结论对所有 $I_{REF}$ 都成立。

### 第 6 步 — 数值示例

取所有器件 $W/L = 20/0.5$，$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，因此 $\beta = 134\ \mu\mathrm{A/V^2}\times40 = 5.36\ \mathrm{mA/V^2}$，并取 $V_b = 1.5$ V。

**当 $I_{REF} = 100\ \mu\mathrm{A}$ 时：**

$$
\begin{aligned}
V_{ov} &= \sqrt{2(100\ \mu\mathrm{A})/(5.36\ \mathrm{mA/V^2})} = \sqrt{0.0373}\ \mathrm{V} = 0.193\ \mathrm{V},\\
V_X &= 0.7 + 0.193 = 0.893\ \mathrm{V},\\
V_A + V_{TH}(V_A) &= 1.5 - 0.193 = 1.307\ \mathrm{V}.
\end{aligned}
$$

试取 $V_A = 0.501$ V：$V_{TH} = 0.7 + 0.45(\sqrt{1.401} - 0.949) = 0.7 + 0.45(1.184 - 0.949) = 0.806$ V，且 $0.501 + 0.806 = 1.307$ V ✓。因此 $V_A = V_B = 0.501$ V；由于 $V_A = 0.501 > V_X - 0.7 = 0.193$ V，$M_2$ 处于饱和区。

**饱和区边缘：** $\beta$ 相等时，边缘条件为 $V_A = V_{ov}$，因此 $2V_{ov} + V_{TH}(V_{ov}) = 1.5$ V。由此得 $V_{ov} = 0.361$ V，以及

$$I_{REF,edge} = \tfrac12(5.36\ \mathrm{mA/V^2})(0.361\ \mathrm{V})^2 = 349\ \mu\mathrm{A}$$

（若不计体效应，则为 $\tfrac{\beta}{8}(0.8\ \mathrm{V})^2 = 429\ \mu\mathrm{A}$）。

**边缘以上，$I_{REF} = 600\ \mu\mathrm{A}$：** $V_{ov4} = 0.473$ V，$V_A = 0.268$ V。于是

$$V_X = 0.7 + \frac{600\ \mu\mathrm{A}}{(5.36\ \mathrm{mA/V^2})(0.268\ \mathrm{V})} + \frac{0.268}{2} = 0.7 + 0.418 + 0.134 = 1.25\ \mathrm{V}.$$

| $I_{REF}$ | $V_X$ (V) | $V_A = V_B$ (V) | $I_{out}$ | $M_1$, $M_2$ |
|---|---|---|---|---|
| $\to 0$ | 0.700 | 0.664 | 0 | 饱和区 |
| 25 μA | 0.797 | 0.582 | 25 μA | 饱和区 |
| 100 μA | 0.893 | 0.501 | 100 μA | 饱和区 |
| 300 μA | 1.035 | 0.383 | 300 μA | 饱和区 |
| 349 μA | 1.061 | 0.361 | 349 μA | 边缘 |
| 600 μA | 1.252 | 0.268 | 600 μA | 线性区 |
| 800 μA | 1.524 | 0.207 | 800 μA | 线性区 |
| 1 mA | 1.99 | 0.154 | 1 mA | 线性区 |

$V_X$ 在约 1.2 mA 时达到 $V_{DD} = 3$ V，此时实际的参考电流源将无法正常工作。

### 第 7 步 — 附注：较大的 $V_b$

若 $V_b > 1.54$ V，则在 $I_{REF}$ 较小时 $V_X$ 太低，无法使 $M_4$ 饱和，因此 $V_A$ 从 $V_X \approx 0.7$ V 附近起始，而 $V_B = V_b - V_{GS3}$ 更高（$V_A < V_B$）。只要 $M_2$ 饱和，$M_1$（其 $V_{DS}$ 更大）也饱和，因此仍有 $I_{out} = I_{REF}$；一旦 $V_X$ 升高到足以使 $M_4$ 饱和，$V_A$ 就并入 $V_B$。只有当 $V_b$ 非常高，使 $M_2$ 在 $M_4$ 仍处于线性区时就进入线性区，$I_{out}$ 才会超过 $I_{REF}$，而且超出量很小（尺寸相同、$V_b = 3$ V 时远小于 1 %）。这不是预期的偏置方式。

### 结果

在预期的偏置下（$0.7\ \mathrm{V} < V_b \lesssim 1.54$ V，$M_4$ 饱和）：

- **$I_{out} = I_{REF}$**：过原点、斜率为 1 的直线；即使 $M_1$/$M_2$ 进入线性区后仍精确成立，因为共源共栅器件迫使 $V_B = V_A$。
- **$V_X = 0.7 + \sqrt{2I_{REF}/\beta_{12}}$**：缓慢的平方根式上升。一旦 $M_2$ 进入线性区（发生在 $V_A = \sqrt{2I_{REF}/\beta_{12}}$ 处；尺寸相同时约在 $\tfrac{\beta}{8}(V_b - V_{TH})^2$，计入体效应时略低），它就变为 $V_X = 0.7 + I_{REF}/(\beta_{12}V_A) + V_A/2$，并急剧向上弯曲，直到参考电流源在 $V_{DD}$ 附近失去电压余度为止。
- **$V_A = V_B$**：由 $V_A + V_{TH}(V_A) = V_b - \sqrt{2I_{REF}/\beta_{34}}$ 可知，它们从 $V_b - V_{TH}$ 附近起始，大致按 $\sqrt{I_{REF}}$ 的规律平滑下降（由于体效应，降幅略小），在线性区边缘处没有折点，当 $I_{REF} \to \tfrac{\beta_{34}}{2}(V_b - 0.7)^2$ 时趋向 0。
- 示例（$\beta = 5.36\ \mathrm{mA/V^2}$，$V_b = 1.5$ V）：$I_{REF} = 25$、100、300、600 μA 时，$V_X \approx 0.80$、0.89、1.03、1.25 V，$V_A = V_B \approx 0.58$、0.50、0.38、0.27 V。超过约 350 μA 后 $M_2$ 处于线性区，并且始终有 $I_{out} = I_{REF}$。

**常见错误。** 把 $V_A$ 和 $V_B$ 画成随 $I_{REF}$ **上升**，仿佛它们是二极管电压。它们是栅极固定在 $V_b$ 的跟随器的源极，电流越大就需要越大的过驱动电压（overdrive voltage），因此源极电压必须**下降**。

**常见错误。** 认为一旦 $M_1$ 和 $M_2$ 进入线性区，就有 $I_{out} \ne I_{REF}$。两者的 $V_{GS}$ 相同，$V_{DS}$ 也相同（$V_A = V_B$），因此电流仍然相等；只有 $V_X$ 反映出这一转变，表现为急剧向上弯曲。

**常见错误。** 忽略 $M_3$/$M_4$ 的体效应。它们的源极比地高约 0.3–0.6 V，$V_{TH}$ 比 0.7 V 高约 0.1 V，这会降低 $V_A$，并在本例中把 $M_2$ 的线性区边缘从 429 μA 移到 349 μA。
