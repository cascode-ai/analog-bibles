正常偏置下，$V_{TH} < V_b \lesssim 1.54$ V，$M_4$ 从一开始就工作在饱和区（saturation region），这正是低压共源共栅（cascode）电路预期的偏置方式。此时：$I_{out} = I_{REF}$（过原点、斜率为 1 的直线）；$V_X = 0.7 + \sqrt{2I_{REF}/\beta_{12}}$，一旦 $M_2$ 进入线性区（triode region）便急剧向上弯曲；$V_A = V_B = V_b - V_{GS4}$，从约 $V_b - V_{TH}$ 开始下降并趋向 0。这里 $\beta_{12} = \mu_nC_{ox}(W/L)_{1,2}$，$\beta_{34} = \mu_nC_{ox}(W/L)_{3,4}$，对 $M_3$、$M_4$ 有 $V_{TH}(s) = 0.7 + 0.45(\sqrt{0.9 + s} - \sqrt{0.9})$。

- 两条支路的唯一区别在于上方器件的漏极（$M_4$ 接 $X$，$M_3$ 接 $V_{DD}$）。$M_3$ 始终饱和（$V_b < V_{DD} + V_{TH}$）。只要 $M_4$ 饱和，两条支路就满足相同的方程，因此无论 $M_2$ 和 $M_1$ 处于哪个工作区，都精确地有 $V_A = V_B$ 和 $I_{out} = I_{REF}$。
- $V_A = V_B$ 由 $V_A + V_{TH}(V_A) = V_b - \sqrt{2I_{REF}/\beta_{34}}$ 解出：它大致按 $\sqrt{I_{REF}}$ 的规律下降，但降幅略小，因为 $V_A$ 下降会使 $V_{TH4}$ 降低。
- 当 $V_A = V_X - 0.7 = \sqrt{2I_{REF}/\beta_{12}}$ 时，$M_2$（以及 $M_1$）退出饱和区；若各 β 相等并忽略体效应（body effect），这发生在 $I_{REF} \approx \tfrac{\beta}{8}(V_b - V_{TH})^2$ 处。此后 $V_X = 0.7 + I_{REF}/(\beta_{12}V_A) + V_A/2$，其增长远快于 $\sqrt{I_{REF}}$，并在 $I_{REF} \to \tfrac{\beta_{34}}{2}(V_b - 0.7)^2$（$V_A \to 0$）时发散；实际上，在 $V_X \approx V_{DD}$ 附近，$I_{REF}$ 电流源就已没有足够的电压余度（headroom）。$V_A = V_B$ 沿同一条曲线变化，没有折点，并且仍有 $I_{out} = I_{REF}$。
- 较高的 $V_b$（$V_b > 0.7 + V_{TH}(0.7) \approx 1.54$ V）：$I_{REF}$ 较小时，$M_4$ 处于线性区（$V_X < V_b - V_{TH4}$），因此 $V_A$ 从 $V_X \approx 0.7$ V 附近起始（开始时可能上升），而 $V_B = V_b - V_{GS3}$ 更高；一旦 $M_4$ 饱和，$V_A$ 就并入 $V_B$。只要 $M_2$ 饱和，$M_1$（由于 $V_B \ge V_A$）也饱和，因此 $I_{out} = I_{REF}$。只有当 $V_b$ 高到使 $M_2$ 在 $M_4$ 仍处于线性区时就进入线性区（β 相等时，$V_b \gtrsim 2.24$ V），才会在某一段 $I_{REF}$ 范围内出现 $I_{out}$ 大于 $I_{REF}$（此时 $V_B > V_A$），而一旦 $M_4$ 饱和，又回到 $I_{out} = I_{REF}$。除非 $\beta_{12} > \beta_{34}$，否则超出量很小（仿真结果：$V_b$ = 3 V 时，β 相等为 +0.7 %，$\beta_{12} = 4\beta_{34}$ 为 +7 %；$\beta_{12} = 8\beta_{34}$、$V_b$ = 2.82 V 时 ≈ +10 %）。一般而言，只要 $V_X < V_{DD}$，就有 $I_{out} \ge I_{REF}$。
- $V_b \le 0.7$ V：不可能有电流流动，因此排除这种情况。
- 示例（所有 W/L = 20/0.5，取 $\mu_nC_{ox}$ = 134 μA/V² 时 β = 5.36 mA/V²，$V_b$ = 1.5 V；按平方律模型仿真）：$I_{REF}$ = 25、100、300、600 μA → $V_X$ ≈ 0.80、0.89、1.03、1.25 V；$V_A = V_B$ ≈ 0.58、0.50、0.38、0.27 V；超过 ≈ 350 μA 后 $M_2$ 处于线性区；始终有 $I_{out} = I_{REF}$。
