# Golden Solution - R258

## Reference answer

Normal bias ($V_{TH} < V_b \lesssim 1.54$ V, so $M_4$ is saturated from the start; this is the intended low-voltage cascode bias): $I_{out} = I_{REF}$ (slope-1 line through the origin); $V_X = 0.7 + \sqrt{2I_{REF}/\beta_{12}}$, bending sharply upward once $M_2$ enters triode; $V_A = V_B = V_b - V_{GS4}$, falling from about $V_b - V_{TH}$ toward 0. Here $\beta_{12} = \mu_nC_{ox}(W/L)_{1,2}$, $\beta_{34} = \mu_nC_{ox}(W/L)_{3,4}$, and $V_{TH}(s) = 0.7 + 0.45(\sqrt{0.9 + s} - \sqrt{0.9})$ for $M_3$, $M_4$.

- The two branches differ only in the upper drain ($X$ for $M_4$, $V_{DD}$ for $M_3$). $M_3$ is always saturated ($V_b < V_{DD} + V_{TH}$). While $M_4$ is saturated, both stacks obey the same equations, so $V_A = V_B$ and $I_{out} = I_{REF}$ exactly, whatever region $M_2$ and $M_1$ are in.
- $V_A = V_B$ solves $V_A + V_{TH}(V_A) = V_b - \sqrt{2I_{REF}/\beta_{34}}$: it falls roughly as $\sqrt{I_{REF}}$, slightly less because the falling $V_A$ lowers $V_{TH4}$.
- $M_2$ (and $M_1$) leave saturation when $V_A = V_X - 0.7 = \sqrt{2I_{REF}/\beta_{12}}$ (for equal β and ignoring body effect, at $I_{REF} \approx \tfrac{\beta}{8}(V_b - V_{TH})^2$). Above that $V_X = 0.7 + I_{REF}/(\beta_{12}V_A) + V_A/2$, which grows much faster than $\sqrt{I_{REF}}$ and diverges as $I_{REF} \to \tfrac{\beta_{34}}{2}(V_b - 0.7)^2$ ($V_A \to 0$); in practice the $I_{REF}$ source runs out of headroom near $V_X \approx V_{DD}$. $V_A = V_B$ follow the same curve with no kink and $I_{out} = I_{REF}$ still.
- Higher $V_b$ ($V_b > 0.7 + V_{TH}(0.7) \approx 1.54$ V): at small $I_{REF}$, $M_4$ is in triode ($V_X < V_b - V_{TH4}$), so $V_A$ starts near $V_X \approx 0.7$ V (it may rise at first) while $V_B = V_b - V_{GS3}$ is higher; $V_A$ merges into $V_B$ once $M_4$ saturates. While $M_2$ is saturated, $M_1$ (with $V_B \ge V_A$) is too, so $I_{out} = I_{REF}$. Only if $V_b$ is so high that $M_2$ enters triode while $M_4$ is still in triode (for equal β, $V_b \gtrsim 2.24$ V) does $I_{out}$ exceed $I_{REF}$ over a range of $I_{REF}$ (here $V_B > V_A$), returning to $I_{out} = I_{REF}$ once $M_4$ saturates. The excess is small unless $\beta_{12} > \beta_{34}$ (simulation, $V_b$ = 3 V: +0.7 % for equal β, +7 % for $\beta_{12} = 4\beta_{34}$; $\beta_{12} = 8\beta_{34}$, $V_b$ = 2.82 V: ≈ +10 %). In general $I_{out} \ge I_{REF}$ while $V_X < V_{DD}$.
- $V_b \le 0.7$ V: no current can flow, so this case is excluded.
- Example (all W/L = 20/0.5, β = 5.36 mA/V² with $\mu_nC_{ox}$ = 134 μA/V², $V_b$ = 1.5 V; square-law simulation): $I_{REF}$ = 25, 100, 300, 600 μA → $V_X$ ≈ 0.80, 0.89, 1.03, 1.25 V; $V_A = V_B$ ≈ 0.58, 0.50, 0.38, 0.27 V; $M_2$ in triode above ≈ 350 μA; $I_{out} = I_{REF}$ throughout.

## Grading notes

The sizes and $V_b$ are free, so answers may analyse the normal low-voltage-cascode bias only (stated or implied: $M_4$ saturated) or treat several $V_b$ ranges. An exact or more general case analysis must not be docked.
+2: $I_{out} = I_{REF}$ (linear), $V_X$ rising as $V_{TH} + \sqrt{2I_{REF}/\beta_{12}}$, $V_A = V_B$ falling as $V_b - V_{GS4}$, and the point where $M_2$/$M_1$ leave saturation at large $I_{REF}$ with $V_X$ then bending up while $V_A = V_B$ and $I_{out} = I_{REF}$ continue. Discussing the high-$V_b$ cases is optional; if discussed, the $M_4$-triode segment at small $I_{REF}$ ($V_A < V_B$, $I_{out} = I_{REF}$) and an $I_{out} > I_{REF}$ excursion when $M_2$ and $M_4$ are both in triode are both correct. A blanket "$I_{out} = I_{REF}$ for all $I_{REF}$" is not docked (the exception needs $V_b$ far above the usual bias). Side caveats about tiny $M_4$-triode dips at extreme size ratios are not docked.
+1: the four curves right but no breakpoint discussed, or body effect on $V_{TH4}$ ignored; or a summary line such as "$V_A = V_B$ for every $I_{REF}$" that the answer's own case analysis contradicts (an inconsistency of wording, not of conclusion); or a correct general parametric analysis that leaves the shapes of the typical curves (e.g. $V_A = V_B$ falling, $V_X$ bending up) unstated.
0: two of the curves right, others missing or wrong; or the normal-bias curves right but $I_{out} \ne I_{REF}$ asserted for the normal bias.
-2 (asserted as fact): $V_A$ or $V_B$ rising with $I_{REF}$ while $M_4$ is saturated; $I_{out}$ constant or saturating independent of $I_{REF}$; $V_X$ linear in $I_{REF}$; $V_A \ne V_B$ while $M_3$ and $M_4$ are both saturated; misread connections (e.g. $M_2$'s gate not at X).
