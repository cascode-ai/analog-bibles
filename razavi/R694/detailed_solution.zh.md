# 详细步骤 - R694

**思路。** 如果晶体管的输出电阻（output resistance）$r_O$ 下降（它在式中以平方形式出现），或者有漏电通路与输出并联，共源共栅的输出阻抗就会变小。逐一检查每种制造错误是否会产生这两种效应之一。

### 第 1 步 — 共源共栅的输出阻抗

把底部（电流源）晶体管记为 $M_1$，共源共栅晶体管记为 $M_2$，二者相接于节点 X；两个栅极都处于交流地，因此 $M_1$ 简化为从 X 到地的 $r_{O1}$，而 $M_2$ 的 $v_{gs2} = v_{bs2} = -v_X$。图中还画出了从输出端到地的寄生漏电电阻 $R_{leak}$，供后面使用（在正常电路中它为无穷大）。

<!-- diagram: diagram-01.cir -->

当 $R_{leak} = \infty$ 时，测试电流 $I_X$ 流过 $r_{O1}$，因此 $v_X = I_Xr_{O1}$；在输出节点应用基尔霍夫电流定律（KCL），得到标准的共源共栅结果：

$$I_X = -(g_{m2} + g_{mb2})v_X + \frac{V_X - v_X}{r_{O2}} \quad\Longrightarrow\quad R_{out} = \frac{V_X}{I_X} = r_{O1} + r_{O2} + (g_{m2} + g_{mb2})r_{O1}r_{O2} \approx g_{m2}r_{O2}r_{O1},$$

这里利用了 $g_{m2}r_{O2} \gg 1$，并忽略了体效应（body effect）。因此 $R_{out}$ 会通过两种途径大幅下降：

1. **$r_O$ 降低。** 由于 $R_{out} \propto r_O^2$，$r_O$ 减半会使 $R_{out}$ 变为原来的四分之一。例如：$g_{m2} = 1$ mS，$r_{O1} = r_{O2} = 50\ \mathrm{k}\Omega$ 时，$R_{out} \approx 10^{-3}\times(5\times10^4)^2 = 2.5\ \mathrm{M}\Omega$；当 $r_O = 25\ \mathrm{k}\Omega$ 时，它只有 $0.63\ \mathrm{M}\Omega$。
2. **并联漏电通路。** $R_{out,eff} = R_{out}\parallel R_{leak}$，由于 $R_{out}$ 非常大，即使很弱的漏电也会起主导作用：$R_{leak} = 1\ \mathrm{M}\Omega$ 与 2.5 MΩ 并联，结果仅为 0.71 MΩ。

（$g_{m2}$ **降低**也会使 $R_{out}$ 减小，但只是线性关系。）

### 第 2 步 — (a) 源/漏注入时的沟道效应：**可能导致**

发生沟道效应时，沿主要晶轴方向运动的离子从原子列之间的空隙穿过，穿透深度远超预定射程（通常通过倾斜 7° 注入或采用屏蔽氧化层来防止）。因此源/漏结最终会很**深**，并且在栅极下方的横向扩展随深度增大。于是：

- 有效沟道长度 $L_{eff} = L_{drawn} - 2L_D$ 变短（$L_D$ 为栅极下方的横向扩散长度）；
- 漏极电场更深地伸入沟道，栅极失去对沟道电势的控制，因此**短沟道效应**大大增强：漏致势垒降低（DIBL）、更强的沟道长度调制，以及发生穿通的趋势。

所有这些都使漏极电流更强烈地依赖于 $V_{DS}$，即**降低了 $r_O$**。$r_{O1}$ 和 $r_{O2}$ 都下降，$R_{out} \approx g_{m2}r_{O2}r_{O1}$ 随二者的乘积下降。**结论：可能。**

### 第 3 步 — (b) 遗漏沟道截止注入：**可能导致**

场氧化层上方的互连线与其两侧的 n+ 区构成一个**寄生场氧 MOSFET**；沟道截止注入（在 NMOS 场氧化层下方额外进行的 p 型掺杂）把它的阈值提高到远高于 $V_{DD}$。没有这一注入时，场区阈值可能落在电源电压范围之内，因此处于高电位的连线（例如 $V_{DD}$，或接近它的信号）就能**使表面反型**，把两个相邻的 n+ 区连通；即使上方没有连线，相邻 n+ 区之间的隔离也会减弱。

在**大型电路**中，任何器件附近的场区上方都有许多连线经过，因此很可能有某条高电位连线从共源共栅输出端的漏极扩散区（diffusion）与附近处于另一电位的 n+ 区（例如接地的源区或其他电路的节点）之间经过。这时寄生晶体管会导通一个依赖于 $V_{out}$ 的电流，相当于一个与输出并联的电阻 $R_{leak}$，它在非常高的共源共栅 $R_{out}$ 中起主导作用（见第 1 步第 2 点）。**结论：可能。**

### 第 4 步 — (c) 栅氧化层生长不足：**不会导致**

栅氧化层更薄意味着 $C_{ox} = \varepsilon_{ox}/t_{ox}$ 更大。**在设计的偏置电流下**（这是通常的情况，因为电流源是通过镜像基准电流来偏置的），跨导（transconductance）增大：

$$g_{m2} = \sqrt{2\mu_nC_{ox}\Big(\frac{W}{L}\Big)_2I_D} \;\propto\; \sqrt{C_{ox}} .$$

$r_O = 1/(\lambda I_D)$ 由电流和 $\lambda$ 决定；如果说有什么影响的话，较薄的氧化层使栅极相对于漏极对沟道的控制**更强**，从而减弱短沟道效应，提高 $r_O$。因此

$$R_{out} \approx g_{m2}r_{O2}r_{O1}$$

**增大**，而不是减小。

**如果改为栅极电压固定**（于是电流与 $C_{ox}$ 成比例地增大），则 $g_m = \mu C_{ox}(W/L)V_{ov} \propto C_{ox}$，$r_O = 1/(\lambda I_D) \propto 1/C_{ox}$，因此 $R_{out} \propto C_{ox}\cdot(1/C_{ox})^2 = 1/C_{ox}$：氧化层稍薄只会使 $R_{out}$ 按不大的倍数降低，远不及 (a) 或 (b) 造成的急剧下降。

只有氧化层薄到发生击穿或漏电时才会造成严重失效，而那是另一种缺陷（栅极故障），并不表现为输出阻抗低。**结论：不会。**

### 结果

- **(a) 源/漏注入时的沟道效应 — 可能。** 深结使 $L_{eff}$ 变短，并增强短沟道效应（DIBL、沟道长度调制、穿通），从而降低 $r_O$；由于 $R_{out} \approx g_{m2}r_{O2}r_{O1} \propto r_O^2$，输出阻抗大幅下降。
- **(b) 遗漏沟道截止注入 — 可能。** 场区阈值变低，因此处于高电位的互连线（大型电路中有很多）会使场区表面反型，在输出 n+ 区与相邻 n+ 区之间形成寄生场氧晶体管；这条与非常大的 $R_{out}$ 并联的漏电通路在其中起主导作用。
- **(c) 栅氧化层生长不足 — 不会。** 较薄的氧化层增大了 $C_{ox}$，因而在相同电流下增大了 $g_m$（并改善了栅极控制），这会**提高** $R_{out}$。

**常见错误。** 以“薄氧化层会降低 $g_m$”为理由选择 (c)。事实恰好相反：$g_m = \sqrt{2\mu C_{ox}(W/L)I_D}$ 随 $C_{ox} = \varepsilon_{ox}/t_{ox}$ 增大而增大。

**常见错误。** 把 (b) 解释为**栅极下方**的穿通。沟道截止注入位于器件之间的**场氧化层**下方；缺少它会通过寄生场氧晶体管在相邻扩散区之间造成漏电。

**常见错误。** 低估了共源共栅对此的敏感程度。在 $R_{out} = g_{m2}r_{O2}r_{O1}$ 中，$r_O$ 的适度下降会被平方，而且很大的 $R_{out}$ 很容易被哪怕阻值很高的漏电通路所主导。
