# Detailed solution - R338

**Approach.** Write the small-signal equations of the folded cascode with the signal and all four noise sources ($M_1$, $M_2$, $R_S$, $R_D$) present. KCL at the folding node X gives $v_X$; the output voltage follows from the current that $M_2$ delivers into $R_D$. Dividing the coefficient of each noise source by the signal gain refers it to the input, and the uncorrelated powers add.

### Step 1 — Small-signal model

**Nodes:** the input (gate of $M_1$), the folding node X, and the output.

- **$M_1$** (NMOS, source grounded, drain at X): with $\lambda = 0$ it is a current source $g_{m1}v_{in}$ pulling current out of X to ground. Its channel noise $I_{n1}$ ($\overline{I_{n1}^2} = 4kT\gamma g_{m1}$) is in parallel, in the same direction.
- **$R_S$**: from X to $V_{DD}$ (ac ground). Its Norton noise current $I_{nS}$ ($\overline{I_{nS}^2} = 4kT/R_S$) is in parallel; take it as flowing from $V_{DD}$ into X.
- **$M_2$** (PMOS, source at X, gate at the fixed bias $V_b$ = ac ground, drain at the output): its small-signal current from source to drain is $g_{m2}v_{sg2} = g_{m2}(v_X - 0) = g_{m2}v_X$, flowing from X into the output. Its noise $I_{n2}$ ($\overline{I_{n2}^2} = 4kT\gamma g_{m2}$) is in parallel, also from X to the output.
- **$R_D$**: from the output to ground, with its Norton noise current $I_{nD}$ ($\overline{I_{nD}^2} = 4kT/R_D$) in parallel; take it as flowing from ground into the output.

Here $k$ is Boltzmann's constant, $T$ the absolute temperature and $\gamma$ the channel-noise coefficient.

**Intuition.** $M_1$'s signal current is drawn from node X, which is fed by two paths: $R_S$ from the supply, and $M_2$, whose source presents a resistance $1/g_{m2}$. Only the part supplied through $M_2$ reaches $R_D$, so part of the signal is "lost" in $R_S$.

### Step 2 — KCL at node X

Sum of currents leaving X equals zero:

$$\underbrace{g_{m1}v_{in} + I_{n1}}_{\text{through } M_1} + \underbrace{g_{m2}v_X + I_{n2}}_{\text{through } M_2} + \underbrace{\frac{v_X}{R_S} - I_{nS}}_{\text{through } R_S} = 0 .$$

Collect the $v_X$ terms:

$$
\begin{aligned}
v_X\left(g_{m2} + \frac{1}{R_S}\right) &= I_{nS} - g_{m1}v_{in} - I_{n1} - I_{n2}\\
v_X &= \frac{I_{nS} - g_{m1}v_{in} - I_{n1} - I_{n2}}{g_{m2} + 1/R_S}.
\end{aligned}
$$

### Step 3 — Output voltage

The current delivered by $M_2$ into the output, $g_{m2}v_X + I_{n2}$, flows into $R_D$ together with $I_{nD}$:

$$v_{out} = R_D\left(g_{m2}v_X + I_{n2}\right) + R_DI_{nD}.$$

Substitute $v_X$ and bring everything over the common denominator $g_{m2} + 1/R_S$:

$$
\begin{aligned}
g_{m2}v_X + I_{n2} &= \frac{g_{m2}\left(I_{nS} - g_{m1}v_{in} - I_{n1} - I_{n2}\right) + I_{n2}\left(g_{m2} + 1/R_S\right)}{g_{m2} + 1/R_S}\\
&= \frac{g_{m2}I_{nS} - g_{m1}g_{m2}v_{in} - g_{m2}I_{n1} - g_{m2}I_{n2} + g_{m2}I_{n2} + I_{n2}/R_S}{g_{m2} + 1/R_S}\\
&= \frac{g_{m2}I_{nS} - g_{m1}g_{m2}v_{in} - g_{m2}I_{n1} + I_{n2}/R_S}{g_{m2} + 1/R_S}.
\end{aligned}
$$

Multiply numerator and denominator by $R_S$:

$$g_{m2}v_X + I_{n2} = \frac{g_{m2}R_S\left(I_{nS} - g_{m1}v_{in} - I_{n1}\right) + I_{n2}}{1 + g_{m2}R_S}.$$

Therefore

$$v_{out} = \frac{R_D}{1 + g_{m2}R_S}\Big[g_{m2}R_S\left(I_{nS} - g_{m1}v_{in} - I_{n1}\right) + I_{n2}\Big] + R_DI_{nD}.$$

### Step 4 — Signal gain

Keep only the $v_{in}$ term:

$$A_v = \frac{v_{out}}{v_{in}} = -g_{m1}R_D\,\frac{g_{m2}R_S}{1 + g_{m2}R_S}.$$

The factor $g_{m2}R_S/(1 + g_{m2}R_S) = R_S/(R_S + 1/g_{m2})$ is the current-divider ratio between $R_S$ and $1/g_{m2}$ at node X: it is the fraction of $M_1$'s signal current that actually reaches the output.

### Step 5 — Referring each noise source to the input

Divide each noise term of $v_{out}$ by $A_v$. The common factor is $\frac{R_D}{1 + g_{m2}R_S}$, and the gain is $-g_{m1}g_{m2}R_S$ times that factor.

- **$M_1$:** coefficient $-g_{m2}R_S\cdot\frac{R_D}{1 + g_{m2}R_S}$. Referred: $\dfrac{-g_{m2}R_SI_{n1}}{-g_{m1}g_{m2}R_S} = \dfrac{I_{n1}}{g_{m1}}$, so
$$\overline{V_{n,in}^2}\Big|_{M_1} = \frac{4kT\gamma g_{m1}}{g_{m1}^2} = \frac{4kT\gamma}{g_{m1}}.$$
- **$R_S$:** coefficient $+g_{m2}R_S\cdot\frac{R_D}{1 + g_{m2}R_S}$, the same magnitude as $M_1$'s. Referred: $I_{nS}/g_{m1}$, so
$$\overline{V_{n,in}^2}\Big|_{R_S} = \frac{4kT/R_S}{g_{m1}^2} = \frac{4kT}{g_{m1}^2R_S}.$$
This makes sense: $I_{nS}$ is injected into X exactly where $M_1$'s signal current is, and it divides between $R_S$ and $M_2$ in the same way.
- **$M_2$:** coefficient $\frac{R_D}{1 + g_{m2}R_S}$. Referred: $\dfrac{I_{n2}}{g_{m1}g_{m2}R_S}$, so
$$\overline{V_{n,in}^2}\Big|_{M_2} = \frac{4kT\gamma g_{m2}}{(g_{m1}g_{m2}R_S)^2} = \frac{4kT\gamma}{g_{m1}^2g_{m2}R_S^2}.$$
Only the fraction $1/(1 + g_{m2}R_S)$ of $M_2$'s noise reaches the output: the cascode device is degenerated by $R_S$, which suppresses its noise (compare a degenerated transistor's output noise current $I_n/(1 + g_mR_S)$).
- **$R_D$:** coefficient $R_D$. Referred: $\dfrac{I_{nD}(1 + g_{m2}R_S)}{g_{m1}g_{m2}R_S}$, so
$$\overline{V_{n,in}^2}\Big|_{R_D} = \frac{4kT}{R_D}\cdot\frac{(1 + g_{m2}R_S)^2}{(g_{m1}g_{m2}R_S)^2} = \frac{4kT(1 + g_{m2}R_S)^2}{g_{m1}^2g_{m2}^2R_S^2R_D}.$$

(The signs of the coefficients do not matter, since each source is squared.)

### Step 6 — Total

The four noise sources are uncorrelated, so their input-referred powers add:

$$\overline{V_{n,in}^2} = 4kT\left[\frac{\gamma}{g_{m1}} + \frac{1}{g_{m1}^2R_S} + \frac{\gamma}{g_{m1}^2g_{m2}R_S^2} + \frac{(1 + g_{m2}R_S)^2}{g_{m1}^2g_{m2}^2R_S^2R_D}\right].$$

**Check: large $R_S$.** When $R_S \to \infty$ (an ideal current source in place of $R_S$), the second and third terms vanish and the last becomes $1/(g_{m1}^2R_D)$, giving $4kT\left[\gamma/g_{m1} + 1/(g_{m1}^2R_D)\right]$. That is the noise of a simple common-source stage with load $R_D$, as expected for an ideal folded cascode. A finite $R_S$ adds its own noise, lets $M_2$'s noise through, and increases the referred $R_D$ noise because some signal is lost in $R_S$.

### Result

$$\overline{V_{n,in}^2} = 4kT\left[\frac{\gamma}{g_{m1}} + \frac{1}{g_{m1}^2R_S} + \frac{\gamma}{g_{m1}^2g_{m2}R_S^2} + \frac{(1+g_{m2}R_S)^2}{g_{m1}^2g_{m2}^2R_S^2R_D}\right]$$

with gain $A_v = -g_{m1}R_D\,\dfrac{g_{m2}R_S}{1 + g_{m2}R_S}$. The four terms come from $M_1$, $R_S$, $M_2$ and $R_D$, in that order.

**Common mistake.** Treating $R_S$ as a source-degeneration resistor of $M_1$, or as noiseless. $R_S$ is the load that supplies $M_1$'s bias current at the folding node X. Its noise current enters X exactly like $M_1$'s signal current, so it refers to the input as $4kT/(g_{m1}^2R_S)$. And it does not degenerate $M_1$, whose source is grounded.

**Common mistake.** Taking the gain as $g_{m1}R_D$, ignoring the current divider at node X. Part of $M_1$'s signal current flows through $R_S$ instead of $M_2$; the fraction reaching the output is $g_{m2}R_S/(1 + g_{m2}R_S)$, and this factor appears in how the $R_D$ and $M_2$ noise are referred.

**Common mistake.** Dropping $M_2$ on the grounds that "a cascode device adds no noise". That is true only when its source sees an infinite impedance. Here X is loaded by the finite $R_S$, so a fraction $1/(1 + g_{m2}R_S)$ of $M_2$'s noise current reaches the output.
