有源电流镜（active current mirror）的思想同样可以用于两级运算放大器（two-stage op amp）的输出级，也就是说，负载电流源（current source）可以随信号变化。[图 1] 给出了一个例子。其中第一级由 $M_1$–$M_4$ 构成（$M_3$、$M_4$ 是由 $V_b$ 偏置的 NMOS 电流源），输出由 $M_5$–$M_8$ 产生。晶体管 $M_7$ 和 $M_8$ 作为有源电流源工作，因为它们的电流分别随节点 Y 和 X 处的信号电压变化（$M_9$ 与 $M_{11}$、$M_{10}$ 与 $M_{12}$ 分别构成电流镜通路）。计算该运放在低频下的差模电压增益（differential voltage gain）。用小信号参数表示结果；令 $K = (W/L)_7/(W/L)_{11} = (W/L)_8/(W/L)_{12}$。
