# 详细步骤 - R254

**思路。** $M_3$ 的沟道位于 $V_1$ 节点与 X 之间，栅极接 Y。它的源极是沟道两端中电位较低的那一端，因此 $M_3$ 既可以把电流从 X **吸入** $V_1$（$V_1 < V_X$ 时），也可以把电流从 $V_1$ **注入** X（$V_1 > V_X$ 时）。$V_1$ 较小时，$M_3$ 夺走全部 $I_{REF}$，$M_2$ 和 $M_1$ 截止，X 紧跟在 $V_1$ 之上。当 $V_1$ 升高越过阈值区后，$M_2$ 和 $M_1$ 接管电流，Y 下降。$V_1$ 较大时曲线是平坦的，此时要么 $M_3$ 截止，要么 $M_3$ 注入一个很小的恒定电流。下面按顺序分析这些区域。

### 第 1 步 — 节点方程

令 $a = \sqrt{2I_{REF}/\beta}$，并定义没有 $M_3$ 时普通电流镜（current mirror）的节点电压（$M_1$ 饱和，这要求 $V_{Y0} \ge a$）：

$$V_{X0} = V_{GS}(I_{REF}) = 0.7 + a, \qquad V_{Y0} = V_{DD} - R_1I_{REF} .$$

衬底接地时，$M_3$ 的阈值电压（threshold voltage）取决于哪一端是其源极：$V_{TH3}(V_S) = 0.7 + 0.45(\sqrt{0.9 + V_S} - \sqrt{0.9})$。设 $I_3$ 为 $M_3$ 中从 $V_1$ 节点流入 X 的电流（从 X 流入 $V_1$ 时为负）：

$$\text{KCL at X: } I_{REF} + I_3 = \frac{\beta}{2}(V_X - 0.7)^2, \qquad \text{KCL at Y: } \frac{V_{DD} - V_Y}{R_1} = I_{D1}(V_{GS} = V_X, V_{DS} = V_Y) .$$

### 第 2 步 — $V_1$ 较小：$M_3$ 吸收 $I_{REF}$，$V_X \approx V_1$，$V_Y = V_{DD}$

假设 $V_X < 0.7$ V。则 $M_2$ 和 $M_1$ 截止，$R_1$ 中没有电流，$V_Y = V_{DD} = 3$ V。$I_{REF}$ 唯一的通路是经 $M_3$ 流入电压源 $V_1$：它的源极是接 $V_1$ 的那一端，栅极位于 $V_{DD}$，栅极驱动 $V_{ov3} = V_{DD} - V_1 - V_{TH3}(V_1)$ 很大，因此它在线性区以很小的 $V_{DS3}$ 承载 $I_{REF}$：

$$I_{REF} = \beta\left[V_{ov3}(V_X - V_1) - \tfrac12(V_X - V_1)^2\right] .$$

较小的（线性区）根为

$$V_X = V_1 + V_{ov3} - \sqrt{V_{ov3}^2 - \frac{2I_{REF}}{\beta}} \;\approx\; V_1 + \frac{I_{REF}}{\beta\left[V_{DD} - V_1 - V_{TH3}(V_1)\right]} .$$

**$V_X$ 以 ≈ 1 的斜率跟随 $V_1$，比它高几十毫伏。** 只要 $I_{REF}/\beta < 1.37\ \mathrm{V^2}$，在 $V_1 = 0$ 时这就是自洽的（$V_X < 0.7$ V），对任何合理的偏置都成立。

### 第 3 步 — 过渡：$M_2$ 和 $M_1$ 接管电流

当 $V_X$ 超过 0.7 V 时（此时 $V_1$ 略低于 0.7 V），$M_2$ 和 $M_1$ 开始导通。$M_1$ 经 $R_1$ 吸取电流，因此 $V_Y$ **下降**；较低的 $V_Y$ 减小了 $M_3$ 的栅极驱动，使 $M_3$ 吸收的 $I_{REF}$ 减少；其余电流流入 $M_2$，使 $V_X$ 升高，于是 $M_1$ 把 Y 进一步拉低。$V_X$ 趋近于 $V_{X0}$，$V_Y$ 趋近于 $V_{Y0}$。当 $M_3$ 沟道两端电压相同时，其电流过零：

$$I_3 = 0 \quad\text{at}\quad V_1 = V_X = V_{X0}\ (= V_{GS}(I_{REF})),\qquad V_Y = V_{Y0} .$$

越过这一点后，$V_1$ 节点成为 $M_3$ 的漏极，X 成为其源极。（若 $V_{DD} - R_1I_{REF} < a$，$M_1$ 最终处于线性区，此时 $V_{Y0}$ 应为 $\frac{V_{DD} - V_{Y0}}{R_1} = \beta\left(aV_{Y0} - \tfrac12V_{Y0}^2\right)$ 的根。）

### 第 4 步 — $V_1$ 较大：平坦的曲线

此时 $V_1 > V_X$，只有当 $V_Y - V_X > V_{TH3}(V_X)$ 时 $M_3$ 才向 X 注入电流。

**情形 A：$V_{Y0} \le V_{X0} + V_{TH3}(V_{X0})$。** $M_3$ 保持截止，且

$$V_X = V_{X0}, \qquad V_Y = V_{Y0} \qquad\text{for all larger } V_1 .$$

**情形 B：$V_{Y0} > V_{X0} + V_{TH3}(V_{X0})$。** $M_3$ 从 $V_1$ 向 X 导通，起初处于线性区（$V_1 - V_X$ 很小），因此其电流随 $V_1$ 增大：$V_X$ 继续略有上升，$V_Y$ 继续下降。当 $V_1 \ge V_{Yh} - V_{TH3}(V_{Xh})$ 时，$M_3$ 饱和，且在 $\lambda = 0$ 时其电流不再依赖于 $V_1$，因此电平冻结在 $(V_{Xh}, V_{Yh})$：

$$\frac{\beta}{2}(V_{Xh} - 0.7)^2 = I_{REF} + \frac{\beta}{2}\left[V_{Yh} - V_{Xh} - V_{TH3}(V_{Xh})\right]^2, \qquad V_{Yh} = V_{DD} - \frac{\beta R_1}{2}(V_{Xh} - 0.7)^2 ,$$

其中 $V_{Xh} > V_{X0}$，$V_{Yh} < V_{Y0}$。负反馈（negative feedback）$M_3 \to M_2 \to M_1 \to Y$ 使 $V_Y \approx V_X + V_{GS3}$，因此偏移很小。

在两种情形下，**两条曲线一直到 $V_1 = V_{DD}$ 都是平坦的。**

### 第 5 步 — 数值示例

$I_{REF} = 100\ \mu$A，$R_1 = 10\ \mathrm{k}\Omega$，$W/L = 10/0.5$（$\beta = 2.68\ \mathrm{mA/V^2}$）：

$$
\begin{aligned}
a &= 0.273\ \mathrm{V}, \quad V_{X0} = 0.973\ \mathrm{V}, \quad V_{Y0} = 3 - 1.0 = 2.0\ \mathrm{V},\\
V_{X0} + V_{TH3}(V_{X0}) &= 0.973 + 0.889 = 1.862\ \mathrm{V} < V_{Y0} \quad\Rightarrow\quad \text{Case B.}
\end{aligned}
$$

在 $V_1 = 0$ 时：$V_{ov3} = 3 - 0 - 0.7 = 2.3$ V，$V_X = 2.3 - \sqrt{5.29 - 0.0746} = 0.016$ V。

| $V_1$ (V) | 0 | 0.3 | 0.6 | 0.65 | 0.7 | 0.8 | 0.9 | 0.95 | 0.97 | 1.0 | ≥ 1.05 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| $V_X$ (V) | 0.016 | 0.319 | 0.624 | 0.675 | 0.726 | 0.826 | 0.923 | 0.962 | 0.972 | 0.979 | 0.981 |
| $V_Y$ (V) | 3.00 | 3.00 | 3.00 | 3.00 | 2.99 | 2.79 | 2.33 | 2.08 | 2.01 | 1.96 | 1.94 |
| $I_3$ (μA) | −100 | −100 | −100 | −100 | −99 | −79 | −33 | −8 | −1 | +4 | +6 |

在约 0.7 V 之前，$V_X$ 始终比 $V_1$ 高 16–26 mV；随后 $V_Y$ 急剧下降；$M_3$ 在 $V_1 \approx 0.97$ V 处反向；从约 1.05 V 起，两条曲线都是平坦的，$V_X \approx 0.98$ V，$V_Y \approx 1.94$ V（$M_3$ 饱和，注入约 6 μA）。

**可能出现的双稳态。** 当 $R_1I_{REF}$ 较大时，曲线可能折返。取 $\beta = 1\ \mathrm{mA/V^2}$，$I_{REF} = 0.2$ mA，$R_1 = 10\ \mathrm{k}\Omega$（$V_{X0} = 1.33$ V，$V_{Y0} = 1.0$ V），只要 $V_1 + V_{TH3}(V_1) > V_{Y0}$，即 $V_1 > 0.245$ V，“$M_3$ 截止”的状态 $(1.33\ \mathrm{V}, 1.0\ \mathrm{V})$ 就存在；而低分支（$M_3$ 吸收电流）一直存在到约 $V_1 = 0.815$ V（$V_X \approx 1.04$ V，$V_Y \approx 2.4$ V）。因此向上扫描时，电路在 0.815 V 附近跳变到高分支；向下扫描时，电路一直停留在高分支，直到约 0.245 V。对主示例而言，解是唯一的。

### 结果

- **$V_1$ 较小时：** $M_3$（源极在 $V_1$，栅极在 Y $= V_{DD}$）在线性区把全部 $I_{REF}$ 从 X 吸入 $V_1$ 节点。$V_X \approx V_1 + I_{REF}/\{\beta[V_{DD} - V_1 - V_{TH3}(V_1)]\}$ 紧跟在 $V_1$ 之上（斜率 ≈ 1）；$M_2$、$M_1$ 截止，$V_Y = V_{DD}$。
- **过渡（$V_1 \approx 0.7$–1 V）：** 一旦 $V_X > 0.7$ V，$M_2$ 和 $M_1$ 导通，$V_Y$ 下降，$M_3$ 分流减少，$M_2$ 接管 $I_{REF}$。$V_X$ 稳定在 $V_{X0} = V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$ 附近，$M_3$ 的电流在 $V_1 = V_{X0}$ 处反向。
- **$V_1$ 较大时：** 两条曲线都是平坦的。若 $V_{Y0} = V_{DD} - R_1I_{REF} \le V_{X0} + V_{TH3}(V_{X0})$，它们位于 $(V_{X0}, V_{Y0})$，$M_3$ 截止。否则 $M_3$ 从 $V_1$ 向 X 注入一个小电流，它饱和后电平略有偏移，$V_{Xh} > V_{X0}$，$V_{Yh} < V_{Y0}$（示例：0.98 V 和 1.94 V，而不是 0.97 V 和 2.0 V）。

**常见错误。** 忽略 $M_3$ 的反向导通，对所有 $V_1$ 都画成 $V_X = V_{GS}(I_{REF})$、$V_Y = V_{DD} - R_1I_{REF}$。$V_1$ 较小时，$M_3$ 的源极位于 $V_1$，栅极驱动非常大，因此它吞掉全部 $I_{REF}$，把 X 拉低到仅比 $V_1$ 略高。

**常见错误。** 把 $M_3$ 接 $V_1$ 的那一端始终当作漏极（或始终当作源极）。源极是沟道两端中电位较低的那一端：$V_1 < V_X$ 时是 $V_1$ 节点，$V_1 > V_X$ 时是 X。

**常见错误。** 认为 $M_3$ 的栅极由 $V_1$ 驱动，或认为其沟道接 Y 或 $V_{DD}$，并让 $V_Y$ 跟随 $V_1$。$V_1$ 只连接到 $M_3$ 沟道的一端；Y 由 $R_1$ 和 $M_1$ 的电流决定。
