# 详细步骤 - R647

**思路。** 把电感的品质因数（quality factor）换算为跨接在每个谐振回路两端的等效并联电阻 $R_P$。在稳态下，交叉耦合对把全部尾电流来回切换，因此每个谐振回路都由在 0 与 $I_{SS}$ 之间变化的方波电流驱动；谐振回路只让其基波通过，基波幅度为 $(2/\pi)I_{SS}$，并经 $R_P$ 转换为电压。

### 第 1 步 — 谐振回路的等效并联电阻

由 $Q = \omega L_P/R_S$，以及在 1 GHz 处

$$\omega L_P = (2\pi\times10^9\ \mathrm{s^{-1}})(5\times10^{-9}\ \mathrm{H}) = 31.4\ \Omega,$$

得到串联损耗电阻为

$$R_S = \frac{\omega L_P}{Q} = \frac{31.4\ \Omega}{4} = 7.85\ \Omega .$$

在谐振频率附近，$R_S$–$L_P$ 串联支路等效于 $L_P$ 与

$$R_P = R_S(1 + Q^2) \approx Q^2R_S = Q\,\omega L_P = 4\times31.4\ \Omega = 126\ \Omega$$

并联（精确换算给出 $7.85\ \Omega\times(1 + 16) = 134\ \Omega$；这里采用 126 Ω）。由于只考虑电感损耗，$R_P$ 是每个谐振回路中唯一的损耗。

### 第 2 步 — 稳态下的漏极电流

由于 $I_{D1} + I_{D2} = I_{SS} = 1$ mA，振荡建立后，$V_X - V_Y$ 每半个周期都把几乎全部 $I_{SS}$ 导向一个晶体管，因此每个漏极电流近似为在 0 与 $I_{SS}$ 之间变化的方波：

$$I_{D1}(t) \approx \frac{I_{SS}}{2} + \frac{2I_{SS}}{\pi}\left[\cos\omega t - \frac13\cos3\omega t + \frac15\cos5\omega t - \dots\right],$$

且 $I_{D2}(t) = I_{SS} - I_{D1}(t)$。基波幅度为 $\frac4\pi\cdot\frac{I_{SS}}{2} = \frac{2}{\pi}I_{SS}$：

$$I_1 = \frac{2}{\pi}(1\ \mathrm{mA}) = 0.637\ \mathrm{mA}.$$

<!-- diagram: diagram-01.cir -->

直流分量（$I_{SS}/2$）流过电感而没有压降，因此 X 和 Y 以 $V_{DD}$ 为中心。在 1 GHz 的谐振频率处，$L_P$ 与节点电容相互抵消，谐振回路阻抗为 $R_P$；而在各次谐波处，电容对电流起旁路作用，几乎不产生电压。因此每个节点的幅度为

$$A = I_1R_P = \frac{2}{\pi}I_{SS}R_P = (0.637\ \mathrm{mA})(126\ \Omega) = 80\ \mathrm{mV},$$

$$V_X(t) \approx V_{DD} - A\cos\omega t, \qquad V_Y(t) \approx V_{DD} + A\cos\omega t .$$

### 第 4 步 — 单端摆幅与差分摆幅

X 和 Y 反向运动：

| 物理量 | 幅度（峰值） | 峰峰值 |
|---|---|---|
| 每个节点，$V_X$ 或 $V_Y$ | ≈ 80 mV | ≈ 160 mV |
| 差分，$V_X - V_Y$ | ≈ 160 mV | ≈ 320 mV |

（若采用精确值 $R_P = 134\ \Omega$，各值约大 6 %：单端幅度为 85 mV。）

### 第 5 步 — 合理性与局限

- **为什么摆幅这么小？** $Q = 4$ 时谐振回路电阻只有 126 Ω；对于相同的电流，$Q$ 值更高的电感会给出成比例增大的 $R_P$ 和摆幅。
- **起振。** 振荡器需要 $g_mR_P \ge 1$，即每个晶体管在 0.5 mA 时 $g_m \ge 1/(126\ \Omega) = 7.96$ mS，这意味着过驱动电压至多为 $2I_D/g_m = 1\ \mathrm{mA}/7.96\ \mathrm{mS} = 0.126$ V（器件很宽）。
- **切换是否完全？** 完全导向需要 $|V_X - V_Y| \gtrsim \sqrt2\,(V_{GS} - V_{TH})_{eq} \approx \sqrt2\times0.126 = 0.18$ V，与估算的 160 mV 差分幅度相当。切换只是部分完成，因此基波电流以及摆幅可能比估算值略小；变容二极管和晶体管的损耗还会使其进一步减小。

因此，每个节点约 80 mV 的估算值是一个量级正确、偏上限的数值。

### 结果

$$R_P \approx Q\,\omega L_P = 4\times2\pi(10^9)(5\ \mathrm{nH}) \approx 126\ \Omega,$$

尾电流完全切换时，每个漏极电流都是 0 到 1 mA 的方波，其基波幅度为 $(2/\pi)I_{SS} = 0.64$ mA。谐振回路把它转换为每个节点

$$A \approx \frac{2}{\pi}I_{SS}R_P \approx 80\ \mathrm{mV}$$

的幅度（峰峰值 ≈ 160 mV），在 $V_{DD}$ 附近作正弦变化。差分输出 $V_X - V_Y$ 的幅度约为 $(4/\pi)I_{SS}R_P \approx 160$ mV（峰峰值 ≈ 320 mV）。

**常见错误。** 把谐振回路电阻取为串联电阻 $\omega L_P/Q \approx 7.9\ \Omega$，或取为 $Q^2\omega L_P$。谐振时的损耗应由并联电阻 $R_P = Q\omega L_P \approx 126\ \Omega$ 表示。

**常见错误。** 把 $I_{SS}R_P \approx 126$ mV 当作单端幅度。在 0 与 $I_{SS}$ 之间切换的电流，其基波只有 $(2/\pi)I_{SS}$，而只有基波才会在谐振回路上产生电压。

**常见错误。** 答案含义不明确：单端幅度（80 mV）、差分幅度（160 mV）以及峰峰值（160 mV 和 320 mV）之间相差 2 倍，因此必须注明所给的是哪个量。
