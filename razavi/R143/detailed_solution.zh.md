# 详细步骤 - R143

**思路。** 栅极不吸取电流，因此流入漏极的小信号电流无论多大，都会从源极流出，这同一个电流既流过 $R_D$ 也流过 $R_S$。每个输出都由各自电阻上的欧姆定律给出，因此比值不可能依赖于 $g_m$、$g_{mb}$ 或 $r_O$，它们只决定电流的**大小**。显式的增益表达式验证了这一结果。

### 第 1 步 — 同一电流流过 $R_D$ 和 $R_S$

$V_{DD}$ 为交流地，设 $i_d$ 为从漏极节点向下流入晶体管的小信号电流。

- **漏极节点**（$v_{out1}$）：只有 $R_D$ 和漏极与之相连（输出端不接负载），因此向下流过 $R_D$ 的电流就是 $i_d$。
- **晶体管**：当 $\lambda, \gamma > 0$ 时，其模型包含 $g_mv_{gs}$、$g_{mb}v_{bs}$ 和 $r_O$，它们都接在漏极与源极之间；栅极和衬底都没有电流。因此从源极流出的电流也是 $i_d$。
- **源极节点**（$v_{out2}$）：只有源极和 $R_S$ 与之相连，因此 $i_d$ 向下流过 $R_S$。

这对 $g_m$、$g_{mb}$ 和 $r_O$ 的任何取值都成立。

### 第 2 步 — 欧姆定律与比值

$i_d$ 从交流地向下流过 $R_D$，使漏极电压**低于**交流地，然后向下流过 $R_S$ 到地：

$$v_{out1} = 0 - i_dR_D = -i_dR_D ,\qquad v_{out2} = i_dR_S ,$$

$$\frac{v_{out1}}{v_{out2}} = \frac{-i_dR_D}{i_dR_S} = -\frac{R_D}{R_S}.$$

未知的 $i_d$ 被约去，因此比值与 $g_m$、$g_{mb}$、$r_O$ 以及偏置点都无关。$\blacksquare$ 沟道长度调制（channel-length modulation）和体效应（body effect）会改变 $i_d$，但它们使两个输出按相同比例变化。

### 第 3 步 — 用显式增益验证

由 $v_{gs} = v_{in} - v_{out2}$、$v_{bs} = 0 - v_{out2}$（衬底接地）以及 $v_{ds} = v_{out1} - v_{out2}$ 得：

$$i_d = g_m(v_{in} - v_{out2}) + g_{mb}(0 - v_{out2}) + \frac{v_{out1} - v_{out2}}{r_O}.$$

代入 $v_{out1} = -i_dR_D$ 和 $v_{out2} = i_dR_S$：

$$i_d = g_mv_{in} - (g_m + g_{mb})R_S\,i_d - \frac{(R_D + R_S)\,i_d}{r_O},$$

$$i_d\left[r_O + (g_m + g_{mb})R_Sr_O + R_D + R_S\right] = g_mr_O\,v_{in}.$$

记 $D \equiv R_D + r_O + R_S + (g_m + g_{mb})R_Sr_O$，则

$$\frac{v_{out1}}{v_{in}} = -\frac{g_mr_OR_D}{D},\qquad \frac{v_{out2}}{v_{in}} = +\frac{g_mr_OR_S}{D}.$$

两者之比中公共分母被约去，得到 $-R_D/R_S$ ✓。若 $R_D = R_S$（图中两者都标为 $R_D$），两个输出大小相等、方向相反，这正是该电路可用作简单的分相器（phase splitter）的原因。

### 结果

由于栅极不吸取电流，无论 $g_m$、$g_{mb}$ 和 $r_O$ 取何值，同一小信号电流 $i_d$ 都流过 $R_D$ 和 $R_S$。因此 $v_{out1} = -i_dR_D$，$v_{out2} = i_dR_S$，并且

$$\frac{V_{out1}}{V_{out2}} = -\frac{R_D}{R_S},$$

与 $\lambda$ 和 $\gamma$ 无关。

**常见错误。** 断定比值依赖于 $g_m$、$g_{mb}$ 或 $r_O$，例如用一个跟随器公式计算 $v_{out2}$，而其分母与计算 $v_{out1}$ 所用的不同。两个输出都来自**同一个**电流。

**常见错误。** 只对 $\lambda = \gamma = 0$ 的情况证明结果（例如利用 $-g_mR_D/(1 + g_mR_S)$ 和 $g_mR_S/(1 + g_mR_S)$）。电流连续性的论证直接涵盖了 $\lambda, \gamma > 0$ 的情况，因为 $r_O$ 和 $g_{mb}v_{bs}$ 同样连接在漏极与源极之间。

**常见错误。** 因为图中两个电阻都标为 $R_D$，就回答 $-1$。下面那个电阻是 $R_S$；只有两者相等时结果才简化为 $-1$。
