# 详细步骤 - R723

**思路。** 键合线电感 $L_b$ 和焊盘电容 $C_{pad}$ 在输入端构成一个二阶低通网络，其带宽与 $\omega_0 = 1/\sqrt{L_bC_{pad}}$ 成比例。求出 $C_{pad}$ 如何随焊盘尺寸变化（基本上与面积成正比），以及 $L_b$ 如何随导线直径变化（只呈对数关系），然后比较两种情况的 $L_bC_{pad}$ 乘积。

### 第 1 步 — 输入网络及其带宽

内阻为 $R_S$ 的信号源 $V_s$ 经键合线电感 $L_b$ 驱动输入节点，焊盘及其周围结构以对地电容 $C_{pad}$ 作为该节点的负载（图中把 $L_b$ 和 $C_{pad}$ 分别标为 $L$ 和 $C$）。

<!-- diagram: diagram-01.cir -->

$R_S + sL_b$ 与 $1/(sC_{pad})$ 之间的分压给出

$$\frac{V_{pad}}{V_s} = \frac{1/(sC_{pad})}{R_S + sL_b + 1/(sC_{pad})} = \frac{1}{s^2L_bC_{pad} + sR_SC_{pad} + 1},$$

这是一个二阶低通网络，$\omega_0 = 1/\sqrt{L_bC_{pad}}$，阻尼由 $R_S$ 决定。在给定阻尼下，−3 dB 带宽与 $\omega_0$ 成正比：

$$\text{BW} \propto \frac{1}{\sqrt{L_bC_{pad}}} ,$$

因此 $L_bC_{pad}$ 较小的情况更好。（如果 $R_S$ 使网络过阻尼，带宽趋于 $1/(R_SC_{pad})$，这就更有利于小的 $C_{pad}$。）

### 第 2 步 — 焊盘电容与焊盘尺寸的关系

边长为 $a$ 的方形焊盘有一个**平板（面积）项** $C_A a^2$ 和一个**边缘（周边）项** $C_F\cdot4a$，其中 $C_A$ 是单位面积电容，$C_F$ 是单位边长电容。边长减半（$a = 100 \to 50\ \mu$m）使面积项除以 4，边缘项除以 2。

**示例**，采用与前面金属 4 所用数值相近的顶层金属参数（$C_A = 7$ aF/µm²，每条边 $C_F \approx 15$ aF/µm）：

$$
\begin{aligned}
\text{(a)}\ a = 100\ \mu\mathrm{m}:&\quad C_{pad} = (7)(10^4) + (15)(400)\ \mathrm{aF} = 70 + 6 = 76\ \mathrm{fF},\\
\text{(b)}\ a = 50\ \mu\mathrm{m}:&\quad C_{pad} = (7)(2500) + (15)(200)\ \mathrm{aF} = 17.5 + 3 = 20.5\ \mathrm{fF}.
\end{aligned}
$$

$$\frac{C_{pad}^{(b)}}{C_{pad}^{(a)}} = \frac{20.5}{76} = 0.27,$$

即电容约**小 3.7 倍**，接近主导的面积项所对应的因子 4。

### 第 3 步 — 键合线电感与直径的关系

对于半径为 $r$、位于地平面上方高度 $h \gg r$ 处的圆导线，由镜像法（image theory）得到单位长度电感

$$L_b' = \frac{\mu_0}{2\pi}\ln\frac{2h}{r} = 0.2\ln\frac{2h}{r}\ \ \mathrm{nH/mm},$$

它对 $r$ 的依赖只通过一个**对数**体现。在 $h$ 不变时把直径减半（情况 (a)：$r = 25\ \mu$m；情况 (b)：$r = 12.5\ \mu$m），会使其增加

$$\Delta L_b' = 0.2\left[\ln\frac{2h}{r/2} - \ln\frac{2h}{r}\right] = 0.2\ln2 = 0.139\ \mathrm{nH/mm},$$

且与 $h$ 无关。典型键合线的 $L_b' \approx 1$ nH/mm（即 $\ln(2h/r) \approx 5$），因此

$$\frac{L_b^{(b)}}{L_b^{(a)}} = \frac{1 + 0.139}{1} = 1.14,$$

只增大了约 **14 %**（对于其他高度，大约为 10–20 %）。孤立导线公式 $L_b = (\mu_0\ell/2\pi)[\ln(2\ell/r) - 0.75]$ 给出同样的结论：对于 $\ell = 4$ mm，$r = 25\ \mu$m 时为 4.0 nH，$r = 12.5\ \mu$m 时为 4.6 nH（+14 %）。

### 第 4 步 — 比较 $L_bC_{pad}$ 与带宽

$$\frac{(L_bC_{pad})^{(b)}}{(L_bC_{pad})^{(a)}} = \frac{L_b^{(b)}}{L_b^{(a)}}\cdot\frac{C_{pad}^{(b)}}{C_{pad}^{(a)}} = 1.14\times0.27 = 0.31 ,$$

$$\frac{\text{BW}^{(b)}}{\text{BW}^{(a)}} = \frac{1}{\sqrt{0.31}} = 1.8 .$$

情况 (b) 的带宽约为情况 (a) 的 **1.8 倍**：电容几乎减小到四分之一，而电感只略有增大。

### 第 5 步 — 结论有多可靠？

- **如果其他电容占主导。** 输入节点上还有 ESD 保护电容和输入器件电容，它们不会随焊盘缩小。即使总输入电容只减半，$L_bC_{pad}$ 之比为 $1.14\times0.5 = 0.57$，带宽仍提高到 $1/\sqrt{0.57} = 1.3$ 倍；只有当焊盘自身的电容可以忽略时，(b) 才会略逊一筹（为 $1/\sqrt{1.14} = 0.94$ 倍）。
- **过阻尼情况。** 如果带宽由 $R_SC_{pad}$ 决定，改善量就是完整的电容比（≈ 3.7×）。
- **情况 (b) 的其他问题。** 较细的导线串联电阻更大：高频时趋肤效应（skin effect）使电流集中在表面，电阻约为 2×，直流时为 4×；这会在敏感的输入端增加损耗和热噪声（thermal noise）。它在熔断前能承载的电流更小，机械强度也更弱；而且 50 µm 的焊盘需要间距更细、精度更高的键合。

### 结果

**情况 (b) 更好。** 带宽按 $1/\sqrt{L_bC_{pad}}$ 变化。焊盘边长减半使焊盘电容减小约 4×（计入边缘电容时 ≈ 3.7×），而导线直径减半只使键合线电感按对数关系增大，$\Delta L_b' = 0.2\ln2 \approx 0.14$ nH/mm（≈ 10–20 %）。$L_bC_{pad}$ 乘积降到原值的约 0.3，因此输入带宽约提高 1.7–1.9×。

**常见错误。** 认为电感按 $1/r$ 或 $1/r^2$ 变化（例如变为四倍，从而 $L_bC_{pad}$ 不变，两种情况看起来等效）。导线电感只通过 $\ln(2h/r)$ 依赖于半径；直径减半只使其改变约 14 %。

**常见错误。** 因为较粗的导线电感较小而选择情况 (a)。电感上的这点小优势，远远抵不上焊盘电容大四倍的劣势。

**常见错误。** 认为焊盘电容只与周长成正比（因子 2），或者忽略焊盘电容。起主导作用的是平板电容，它与焊盘面积成正比。
