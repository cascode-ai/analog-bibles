# 详细步骤 - R526

**思路。** 噪声电压与栅极串联时，$M_6$ 是一个共源级，其源极负反馈电阻为节点 D 处的电阻（仅为 $r_{O8}$），负载为从 $M_4$ 向下看进去的电阻。在 D 和 Y 两点应用基尔霍夫电流定律（KCL），即可得到带源极负反馈共源级的精确增益。从 $M_8$ 栅极到 Y 的增益可由诺顿等效求出，然后从电压增益和输出噪声功率两方面对二者进行比较。

### 第 1 步 — 半边电路及 $M_6$ 周围的电阻

在右半边电路（节点 B、Y、D）中，P 和所有偏置线都是交流地。

- **节点 D：** $M_8$ 的栅极接 $V_{b3}$，源极接 $V_{DD}$，因此它从 D 到交流地只呈现 $r_{O8}$。
- **$M_6$ 的体效应：** 其衬底接源极，因此 $v_{bs6} = 0$，$g_{mb6}$ 不起作用。
- **Y 以下：** 从 $M_4$（栅极接 $V_{b1}$，衬底接地）的漏极向下看，其源极 B 由 $r_{O2}$ 提供负反馈：
$$R_D = \left[1 + (g_{m4} + g_{mb4})\,r_{O4}\right]r_{O2} + r_{O4} .$$

### 第 2 步 — $M_6$ 噪声的小信号模型（small-signal model）

$V_{n6}$ 与栅极串联时，$v_{g6} = V_{n6}$。节点 D 有 $r_{O8}$ 接地，节点 Y 有 $R_D$ 接地，二者之间是 $M_6$ 的受控源 $g_{m6}v_{gs6}$（从漏极 Y 流向源极 D）和 $r_{O6}$，其中 $v_{gs6} = V_{n6} - v_D$。

<!-- diagram: diagram-01.cir -->

$M_6$ 内部从 Y 流向 D 的电流 $i$ 为

$$i = g_{m6}(V_{n6} - v_D) + \frac{v_Y - v_D}{r_{O6}} .$$

它在 D 点经 $r_{O8}$ 流出，在 Y 点经 $R_D$ 从地抽取：

$$v_D = i\,r_{O8},\qquad v_Y = -i\,R_D .$$

### 第 3 步 — 求 $M_6$ 噪声到 Y 的增益

将 $v_D$ 和 $v_Y$ 代入器件方程：

$$i = g_{m6}V_{n6} - g_{m6}r_{O8}\,i - \frac{(R_D + r_{O8})\,i}{r_{O6}} ,$$

$$i\left(r_{O6} + g_{m6}r_{O6}r_{O8} + R_D + r_{O8}\right) = g_{m6}r_{O6}V_{n6},$$

$$i = \frac{g_{m6}r_{O6}V_{n6}}{R_D + r_{O8} + r_{O6} + g_{m6}r_{O6}r_{O8}} .$$

再由 $v_Y = -iR_D$ 得

$$\boxed{A_6 = \frac{v_Y}{V_{n6}} = -\frac{g_{m6}r_{O6}R_D}{R_D + r_{O8} + r_{O6} + g_{m6}r_{O6}r_{O8}}}$$

这就是 $R_S = r_{O8}$、$g_{mb} = 0$、负载为 $R_D$ 的带源极负反馈共源级的精确增益。

利用从 $M_6$ 漏极向上看进去的电阻

$$R_{up} = (1 + g_{m6}r_{O6})\,r_{O8} + r_{O6} = r_{O8} + r_{O6} + g_{m6}r_{O6}r_{O8},$$

以及 Y 点的总电阻 $R_{out} = R_{up}\parallel R_D = R_DR_{up}/(R_D + R_{up})$，增益变为

$$|A_6| = \frac{g_{m6}r_{O6}}{R_{up}}\,R_{out} \approx \frac{R_{out}}{r_{O8}}\qquad(g_{m6}r_{O6} \gg 1,\ \text{so } R_{up} \approx g_{m6}r_{O6}r_{O8}).$$

带源极负反馈的 $M_6$ 的等效跨导只有 $\approx 1/r_{O8}$：由于 $M_8$ 是电流源，其栅极电压只能通过 $r_{O8}$ 驱动电流。

### 第 4 步 — $M_8$ 的噪声所经历的增益

现在把 $V_{n8}$ 与 $M_8$ 的栅极串联，并令 $V_{n6} = 0$。$M_8$（源极接 $V_{DD}$）是一个从 D 流向地的受控源 $g_{m8}V_{n8}$（采用漏极到源极的约定；符号不影响噪声功率），而 $M_6$ 在 D 与 Y 之间充当共栅（common-gate）的共源共栅管。

<!-- diagram: diagram-02.cir -->

**诺顿方法。** 当 Y 接地时，$M_6$ 在 D 点呈现的源极电阻为 $r_{O6}/(1 + g_{m6}r_{O6})$，因此电流 $g_{m8}V_{n8}$ 在 $r_{O8}$ 和 $M_6$ 之间分流，流过 $M_6$ 的短路电流为

$$i_{sc} = g_{m8}V_{n8}\,\frac{r_{O8}}{r_{O8} + \dfrac{r_{O6}}{1 + g_{m6}r_{O6}}} = g_{m8}V_{n8}\,\frac{r_{O8}(1 + g_{m6}r_{O6})}{r_{O8}(1 + g_{m6}r_{O6}) + r_{O6}} = g_{m8}V_{n8}\,\frac{r_{O8}(1 + g_{m6}r_{O6})}{R_{up}} \approx g_{m8}V_{n8}.$$

$M_8$ 的电流几乎全部流过共源共栅管，因为与 $r_{O8}$ 相比，后者的源极是一个低阻抗点。Y 点的输出电阻同样是 $R_{out}$，因此

$$|A_8| = \frac{g_{m8}r_{O8}(1 + g_{m6}r_{O6})}{R_{up}}\,R_{out} = \frac{g_{m8}r_{O8}(1 + g_{m6}r_{O6})\,R_D}{R_D + r_{O8} + r_{O6} + g_{m6}r_{O6}r_{O8}} \approx g_{m8}R_{out}.$$

（直接求解两个节点方程也会得到同样的表达式。）

### 第 5 步 — 比较 $M_6$ 与 $M_8$

**电压增益。** 公共分母和 $R_D$ 相消：

$$\frac{|A_6|}{|A_8|} = \frac{g_{m6}r_{O6}}{g_{m8}r_{O8}(1 + g_{m6}r_{O6})} \approx \frac{1}{g_{m8}r_{O8}} .$$

**噪声功率。** 每个栅极串联 $\overline{V_n^2} = 4kT\gamma/g_m$，则 Y 点输出噪声谱密度（noise spectral density）之比为

$$\frac{S_6}{S_8} = \frac{\overline{V_{n6}^2}\,A_6^2}{\overline{V_{n8}^2}\,A_8^2} = \frac{g_{m8}}{g_{m6}}\left(\frac{A_6}{A_8}\right)^2 \approx \frac{g_{m8}}{g_{m6}}\cdot\frac{1}{(g_{m8}r_{O8})^2} = \frac{1}{g_{m6}\,g_{m8}\,r_{O8}^2}.$$

$M_6$ 和 $M_8$ 的尺寸（320 µm/80 nm）和电流（各 ≈ 0.95 mA）都相同，因此 $g_{m6} \approx g_{m8}$，且

$$\frac{S_6}{S_8} \approx \frac{1}{(g_{m8}r_{O8})^2}.$$

对于长沟道器件（$g_mr_O \sim 50$–$100$），该比值低于 0.05 %，这是教科书中的通常结论。而这里的 PMOS 器件在只有约 100 mV 的 $|V_{DS}|$ 下流过约 0.95 mA（1-V 电源要由整个堆叠结构分担），因此 $r_O$ 只有几百欧姆，$g_{m8}r_{O8}$ 只有约 5–10：

$$\frac{S_6}{S_8} \approx \frac{1}{5^2}\ \text{to}\ \frac{1}{10^2} = 4\,\%\ \text{to}\ 1\,\%,$$

虽小，但已不再可以忽略。

### 结果

$M_6$ 的栅极噪声所面对的是一个带源极负反馈的共源级：$R_S = r_{O8}$，无体效应，负载为 $R_D = [1 + (g_{m4} + g_{mb4})r_{O4}]r_{O2} + r_{O4}$：

$$A_6 = \frac{g_{m6}r_{O6}R_D}{R_D + r_{O8} + r_{O6} + g_{m6}r_{O6}r_{O8}} \approx \frac{R_{out}}{r_{O8}},$$

其中 $R_{out} = R_{up}\parallel R_D$，$R_{up} = r_{O8} + r_{O6} + g_{m6}r_{O6}r_{O8}$。$M_8$ 的栅极噪声经历的增益为

$$A_8 = \frac{g_{m8}r_{O8}(1 + g_{m6}r_{O6})R_D}{R_D + r_{O8} + r_{O6} + g_{m6}r_{O6}r_{O8}} \approx g_{m8}R_{out}.$$

因此 $A_6/A_8 = g_{m6}r_{O6}/[g_{m8}r_{O8}(1 + g_{m6}r_{O6})] \approx 1/(g_{m8}r_{O8})$，$M_6$ 相对于 $M_8$ 的输出噪声功率为 $\approx (g_{m8}/g_{m6})/(g_{m8}r_{O8})^2 \approx 1/(g_{m8}r_{O8})^2$。共源共栅管的噪声被电流源的本征增益所抑制。这对长沟道器件非常有效，但在这个 40-nm 设计中 $g_mr_O \approx 5$–10，$M_6$ 贡献的噪声功率仍约为 $M_8$ 的 1–4 %。

**常见错误。** 把 $M_6$ 的源极当作交流地，得到增益 $g_{m6}R_{out}$，与 $M_8$ 的一样大。节点 D 的负载只有 $r_{O8}$，因此 $M_6$ 受到很强的源极负反馈。

**常见错误。** 把负反馈电阻取为 $1/g_{m8}$，好像 $M_8$ 是二极管连接（diode-connected）的。它的栅极固定在 $V_{b3}$，因此其漏极呈现的是 $r_{O8}$。

**常见错误。** 在增益中计入 $g_{mb6}$。$M_6$ 的衬底接其源极，因此该项为零（而衬底接地的 $M_4$ 的体效应确实出现在 $R_D$ 中）。
