# 详细步骤 - R501

**思路。** 沿环路追踪大信号（large-signal）下的一连串事件：输入节点下降，$M_1$ 截止，其漏极上升，PMOS 输出器件 $M_2$ 截止。此时由输出端的基尔霍夫电流定律（KCL）可知，只有电流源（current source）$I_2$ 作用于输出电容，它决定了斜率。

### 第 1 步 — 静态时的电路

把输入节点（$M_1$ 的栅极）记为 A，$M_1$ 的漏极（$M_2$ 的栅极）记为 B。静态时（$I_{in} = 0$），$M_1$ 和 $M_2$ 各流过 1 mA，$M_3$ 流过 10 µA，$V_{out} = V_{GS3}$。采用该电路的典型器件参数（$V_{TH} \approx 0.7$ V，$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$），$M_3$ 只需约 0.12 V 的过驱动电压（overdrive voltage），因此 $V_{out} \approx 0.82$ V；这些数字仅供参考，因为压摆率与它们无关。

任意时刻输出端的 KCL：

$$C_L\frac{dV_{out}}{dt} = I_{D2} - I_2 ,$$

其中 $I_{D2} \ge 0$ 是 $M_2$ 推入输出端的电流。

### 第 2 步 — $M_1$ 截止，B 上升，$M_2$ 截止

很大的负 $I_{in}$ 从 A 抽取电流的速度超过了 $I_3$ 和反馈所能补充的速度，因此 A 降到 $V_{TH1}$ 以下，**$M_1$ 截止**（$I_{D1} = 0$）。

此时 B 处再没有器件吸收 $I_1$，于是 $I_1$ 把 B 向 $V_{DD}$ 充电。（若 $M_1$ 上跨接有补偿电容，它会分走一部分 $I_1$，只会减缓这一上升过程。）$M_2$ 的源极接 $V_{DD}$，因此 $V_{SG2} = V_{DD} - V_B$ 减小；一旦它低于 $|V_{THP}|$，**$M_2$ 截止**，$I_{D2} = 0$。

### 第 3 步 — 输出斜率

当 $I_{D2} = 0$ 时：

$$C_L\frac{dV_{out}}{dt} = 0 - I_2 \quad\Longrightarrow\quad \frac{dV_{out}}{dt} = -\frac{I_2}{C_L} = -\frac{1\ \mathrm{mA}}{C_L} .$$

输出线性地**下降**；压摆率为 $I_2/C_L$。例如，当 $C_L = 0.5$ pF 时：

$$SR = \frac{1\ \mathrm{mA}}{0.5\ \mathrm{pF}} = 2\times10^9\ \mathrm{V/s} = 2\ \mathrm{V/ns}.$$

$M_2$ 几乎可以向负载**上拉**任意大的电流，但只有固定的电流源 $I_2$ 能把输出**下拉**。

### 第 4 步 — 此时反馈在做什么

$M_3$ 的栅极接输出端，起始时 $V_{GS3} \approx 0.82$ V；一旦 $V_{out}$ 降到约 $V_{TH} = 0.7$ V 以下，它就会截止，因此在这一过程中环路是断开的，无法加快恢复。输出最多只能下降约 0.8 V 就到达地电位，此时 $I_2$（实际的电流源）退出饱和区（saturation region）。当输入电流恢复正常后，$M_1$ 重新导通，B 下降，$M_2$ 再次导通，环路重新取得控制。

### 结果

$$\frac{dV_{out}}{dt} = -\frac{I_2}{C_L} = -\frac{1\ \mathrm{mA}}{C_L}$$

（例如 $C_L = 0.5$ pF 时为 −2 V/ns）。事件链为：$M_1$ 截止 → 其漏极向 $V_{DD}$ 上升 → PMOS 管 $M_2$ 截止 → 仅由 $I_2$ 对 $C_L$ 放电。

**常见错误。** 使用 $I_1/C_L$ 或 $I_3/C_L$。$I_1$ 只给节点 B（$M_2$ 的栅极）充电，$I_3$ 只向输入节点供电；$M_2$ 截止后，输出端唯一的电流是 $I_2$。

**常见错误。** 认为输出会**上升**。$M_1$ 截止使 B 上升，从而使 PMOS 管 $M_2$ **截止**，于是输出失去上拉而下降。

**常见错误。** 把 $M_2$ 当作一直导通的 NMOS 源极跟随器（source follower）。它是 PMOS 共源（common-source）器件，一旦其栅极升到距 $V_{DD}$ 不足 $|V_{THP}|$ 的位置，就不再流过电流。
