# 详细步骤 - R705

**思路。** 设计规则规定了最小宽度、最小间距或最小包围，使所画的图形能够经受制造容差（光刻分辨率、对准偏差、刻蚀偏差、横向扩散）。违反规则就有发生某种具体物理失效的风险：短路、开路、漏电通路或器件定义不良。对每条规则，在版图中找到它的位置，指出涉及的节点，并说明失效模式及其对放大器的影响。

### 第 1 步 — 节点命名

把 PMOS 负载记为 $M_3$（左）和 $M_4$（右），输入对管记为 $M_1$（左）和 $M_2$（右），尾电流管记为 $M_5$。PMOS 的漏极通过竖直金属线连到 NMOS 的漏极，形成输出 $V_{out1}$（左）和 $V_{out2}$（右）。$M_1$ 的栅极多晶硅从左侧引入，接 $V_{in1}$；$M_2$ 的栅极多晶硅向右引出，接 $V_{in2}$；两个栅极的端部在中间相对。输入对管的源极在共源节点 P 处与尾电流管的漏极相连。在左下方，上面那条水平金属线传送尾电流偏置 $V_b$，下面那条是地线（连接尾电流管的源极和 p+ 衬底接触）。

### 第 2 步 — $A_1$：有源区–有源区间距（$M_1$ 与 $M_2$ 之间）

**位置。** $M_1$ 与 $M_2$ 有源区之间、与其漏极接触孔等高处的场氧化层（field oxide）间隙。

**失效。** 两个 n+ 区可能合并，或者它们之间的场区无法实现隔离（两个耗尽区之间发生穿通，或者从其上方经过的连线使寄生场氧晶体管导通）。

**影响。** 两个漏极就是两个输出，因此短路或电阻性漏电会把 $V_{out1}$ 与 $V_{out2}$ 连在一起，**差分增益急剧下降**。（相邻的源极本来就连在一起，因此只有漏极一侧有影响。）

### 第 3 步 — $A_2$：金属宽度（通往 $M_1$ 栅极的输入线）

**位置。** 把 $V_{in1}$ 引到 $M_1$ 栅极接触孔的金属线。

**失效。** 比最小宽度更窄的连线可能断开或出现“缩颈”：形成**开路**，或者形成很大且不可靠的电阻（对于承载直流电流的连线，还会过早发生电迁移失效）。

**影响。** $M_1$ 的栅极**浮空**，或者经过一个大电阻才能连通，因此放大器接收不到输入（或者其带宽和噪声性能变差）。

### 第 4 步 — $A_3$：金属–金属间距（尾电流偏置线与地线）

**位置。** 左下方两条平行的水平金属线：上面是尾电流管的栅极偏置 $V_b$，下面是地线。

**失效。** 两条线的间距小于最小值时，可能被未分辨开或残留的金属**桥接**：形成短路。

**影响。** 尾电流管的栅极与地短路，于是 $V_{GS5} = 0$，**尾电流消失**：放大器关断。部分桥接（漏电）会使偏置发生偏移；即使没有短路，较大的耦合电容也会把地线噪声注入尾电流偏置。

### 第 5 步 — $A_4$：有源区对接触孔的包围（尾电流管的接触孔）

**位置。** 尾电流管有源区边缘与其底部（源极）接触孔之间的余量。

**失效。** 对准偏差可能使接触孔部分偏离 n+ 扩散区，落在场氧化层或结的边缘上：**接触电阻变得很大或不可靠**（极端情况下开路），而且接触孔刻蚀可能使金属在结的边缘接触到 p 型衬底。

**影响。** 很大的源极接触电阻相当于不希望有的源极负反馈（degeneration）：尾电流管的源极电位升高，尾电流减小（开路时则完全消失），整个放大器的偏置出错。对于这个源极接触孔，金属与衬底接触是无害的（二者都接地；至多增加漏电）。若违反发生在尾电流管的**漏极**接触孔处，同样的问题会使节点 P 对地短路，从而旁路电流源。

### 第 6 步 — $A_5$：多晶硅–有源区间距（$M_2$ 的栅极接触区与其有源区）

**位置。** $M_2$ 有源区右边缘与用于 $M_2$ 栅极接触的宽多晶硅接触区之间的间隙。

**失效。** 存在对准偏差时，该接触区可能落到有源区上，位于薄栅氧化层之上。它会**阻挡其下方的源/漏注入**，形成一个**额外的、定义不良的栅区**（一个尺寸取决于对准偏差的寄生晶体管），并增大栅–源和栅–漏交叠电容。

**影响。** $M_2$ 不再与 $M_1$ 匹配（有效 $W/L$、阈值特性、电容），从而产生**输入失调**和不对称；如果寄生区域截断了源区或漏区，$M_2$ 可能完全失效。

### 第 7 步 — $A_6$：有源区–阱间距（NMOS 有源区与 n 阱边缘）

**位置。** n 阱下边缘与 $M_2$ 有源区漏极端之间的间隙。

**失效。** 阱在推进（drive-in）过程中会横向扩散，因此可能接触到 n+ 漏区，或者两个耗尽区合并（**穿通**）。

**影响。** n 阱处于 $V_{DD}$，因此 $V_{out2}$ **向 $V_{DD}$ 漏电或与之短路**：输出被钳在高电平，增益急剧下降，差分对失去平衡。n+ 区与阱之间狭窄的 p 区还会形成一个薄基区的横向 npn 管，增大**闩锁**敏感性。

### 第 8 步 — $A_7$：阱对有源区的包围（n 阱内的 PMOS 有源区）

**位置。** n 阱左边缘与 PMOS 有源区左边缘之间的余量。

**失效。** p+ 源/漏区可能**越过阱边缘进入 p 型衬底**（或者只留下一层很薄、容易穿通的 n 层），与衬底形成欧姆连接。

**影响。** p+ 源区（处于 $V_{DD}$）接触到接地衬底，就是**电源到地的直接短路**；p+ 漏区接触到衬底，则**使输出对地短路**。无论哪种情况放大器都会失效；即使包围余量只是勉强满足，也会增大漏电和闩锁敏感性。

### 第 9 步 — $A_8$：多晶硅–多晶硅间距（$M_1$ 与 $M_2$ 的栅极端部）

**位置。** 输入对管中间，$M_1$ 与 $M_2$ 栅极多晶硅相对端部之间的间隙。

**失效。** 两条多晶硅线可能被**桥接**。

**影响。** 两个输入 $V_{in1}$ 和 $V_{in2}$ 短接在一起：**差分输入丢失**，差分对只能看到共模（common-mode）平均值；两个驱动级也相互短路。即使没有短路，两个输入之间的耦合电容也会增大。

### 结果

| 规则 | 涉及的节点 | 物理失效 | 对放大器的影响 |
|---|---|---|---|
| $A_1$ 有源区–有源区 | $M_1$、$M_2$ 的漏极（输出） | 扩散区合并 / 场区漏电 | 输出短路，差分增益丧失 |
| $A_2$ 金属宽度 | 通往 $M_1$ 栅极的输入线 | 连线开路或高电阻 | 输入栅极浮空，放大器失效 |
| $A_3$ 金属–金属 | 尾电流偏置线与地线 | 连线桥接 | 尾电流管栅极接地，无尾电流 |
| $A_4$ 接触孔包围 | 尾电流管接触孔 | 接触孔部分偏离有源区：高 $R$/开路；金属可能接触衬底 | 尾电流减小或为零；（若为漏极接触孔，则节点 P 对地短路） |
| $A_5$ 多晶硅–有源区 | $M_2$ 的栅极接触区及其有源区 | 多晶硅覆盖有源区，阻挡源/漏注入，形成寄生栅，交叠 $C$ 增大 | 失配（mismatch）/失调，可能失效 |
| $A_6$ 有源区–阱 | NMOS 漏区与 n 阱（$V_{DD}$） | 穿通或阱接触到 n+ | 输出漏电/短路到 $V_{DD}$；有闩锁风险 |
| $A_7$ 阱包围 | PMOS 的 p+ 区与 p 型衬底 | p+ 延伸进衬底 | $V_{DD}$ 对地短路，或输出对地短路 |
| $A_8$ 多晶硅–多晶硅 | $M_1$、$M_2$ 的栅极 | 栅极线桥接 | 输入短路，差分输入丧失 |

**常见错误。** 把间距规则（$A_1$、$A_3$、$A_6$、$A_7$、$A_8$）看成只关系到面积或“匹配稍差”的问题。每条间距规则都是为了防止处于不同电位的节点之间发生短路，违反它可能使电路完全失效。

**常见错误。** 声称多晶硅落到有源区上（$A_5$）会使栅极与扩散区短路。多晶硅仍然被栅氧化层绝缘；问题在于注入被阻挡、出现寄生栅区、电容增加以及失配。

**常见错误。** 声称违反规则反而有好处，例如认为输入栅极端部靠得更近（$A_8$）可以改善匹配。匹配取决于器件的几何形状和周围环境；违反间距规则只会带来输入短路的风险。
