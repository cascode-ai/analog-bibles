# Golden Solution - R519

## Reference answer

$g_m = \beta(V_{GS}-V_{TH})^2$ is a parabola that starts at the origin with zero slope, instead of the square law's straight line. $I_D = \beta(V_{GS}-V_{TH})^3/3$ is a cubic, flat at the origin and rising more steeply, instead of the square law's parabola. Both curves bend upward (convex). $I_D$ eventually grows faster than $g_m$, since $g_m/I_D = 3/(V_{GS}-V_{TH})$ falls with overdrive.
