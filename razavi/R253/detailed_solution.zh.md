# 详细步骤 - R253

**思路。** $V_1$ 是右侧电路的“电源”：它经 $R_1$ 向 Y 供电，同时也是 $M_3$ 的漏极电压。在 $M_3$ 截止期间，X 处是由固定的 $I_{REF}$ 供电的二极管，因此 $V_X$ 恒定，而 Y 是由 $V_1$ 经 $R_1$ 供电的镜像器件的漏极。$M_3$ 是从 Y 到 X 的跟随器，只有当 Y 比 X 高出一个阈值电压（threshold voltage）时才导通，随后形成一个抑制 Y 上升的负反馈环路（$Y \to M_3 \to X \to M_1 \to Y$）。下面让 $V_1$ 从低到高依次经过这些区域进行分析。

### 第 1 步 — 节点方程

令 $a = \sqrt{2I_{REF}/\beta}$（流过 $I_{REF}$ 所需的过驱动电压），$V_{GS}(I_{REF}) = 0.7 + a$。衬底接地时，$M_3$（源极在 X）的阈值电压为

$$V_{TH3}(V_X) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right) .$$

X 点的基尔霍夫电流定律（KCL）方程：$I_{REF} + I_{D3} = I_{D2} = \frac{\beta}{2}(V_X - 0.7)^2$。Y 点的 KCL 方程：$\dfrac{V_1 - V_Y}{R_1} = I_{D1}$。

**$M_3$ 何时能够导通？** 电流从 $V_1$ 经 $R_1$ 流入 Y，因此 $V_Y \le V_1$。若 $V_1 < V_X$，$M_3$ 的源极是接 $V_1$ 的那一端，$V_{GS3} = V_Y - V_1 \le 0$：截止。若 $V_1 > V_X$，源极是 X，$M_3$ 只有在下式成立时才导通：

$$V_Y - V_X > V_{TH3}(V_X) ,$$

此时它处于饱和（由于 $V_1 \ge V_Y$，$V_{DS3} = V_1 - V_X \ge V_Y - V_X - V_{TH3}$）。

### 第 2 步 — $M_3$ 截止期间：$V_X$ 恒定

由于 $I_{D3} = 0$，二极管恰好流过 $I_{REF}$：

$$V_X = V_{GS}(I_{REF}) = 0.7 + a = 0.7 + \sqrt{\frac{2I_{REF}}{\beta}} = \text{const.}$$

### 第 3 步 — $M_3$ 截止时的 $V_Y$

$M_1$ 的过驱动电压为 $a$；它是否饱和取决于 $V_1$ 给它留下多少电压。

**(a) $V_1$ 较小：$M_1$ 处于线性区。** 由 $I_{D1} = \beta(aV_Y - \tfrac12V_Y^2)$，

$$\frac{V_1 - V_Y}{R_1} = \beta\left(aV_Y - \tfrac12V_Y^2\right) ,$$

因此 $V_Y$ 是 $V_1$ 的一部分，$dV_Y/dV_1 = 1/[1 + \beta R_1(a - V_Y)]$：它从 $1/(1 + \beta R_1a)$ 开始（$M_1$ 相当于电阻 $1/(\beta a)$，与 $R_1$ 构成分压器），并在 $V_Y \to a$ 时增大到 1。

**(b) $M_1$ 饱和**（$V_Y \ge a$）：$M_1$ 复制 $I_{REF}$，因此

$$V_Y = V_1 - R_1I_{REF} \qquad(\text{slope } 1),$$

该关系从 $V_1 = R_1I_{REF} + a$ 开始成立。

### 第 4 步 — $M_3$ 导通

由 $V_X = V_{GS}(I_{REF})$ 和（通常情况下）$V_Y = V_1 - R_1I_{REF}$，条件 $V_Y - V_X = V_{TH3}(V_X)$ 给出

$$V_{1,on} = V_{GS}(I_{REF}) + V_{TH3}\big(V_{GS}(I_{REF})\big) + R_1I_{REF} ,$$

其中，由于 $V_X \approx 1$ V，体效应（body effect）使 $V_{TH3}$ 约为 0.89 V，而不是 0.7 V。

### 第 5 步 — $M_3$ 导通后：负反馈抑制 $V_Y$ 的上升

$M_3$ 的电流与 $I_{REF}$ 一起流入 $M_2$，因此 $V_X$ 略有上升；$M_1$ 镜像这一更大的电流，$R_1$ 上的压降增大，Y 被拉回：Y 只能以环路所允许的速度上升，且 $V_Y \approx V_X + V_{GS3}$。

令 $u = V_X - 0.7$，则 $I_{D2} = \frac{\beta}{2}u^2$，$I_{D3} = \frac{\beta}{2}(u^2 - a^2)$，$M_3$ 的过驱动电压为 $w = \sqrt{u^2 - a^2}$，饱和的 $M_1$ 流过 $\frac{\beta}{2}u^2$。因此

$$V_Y = V_X + V_{TH3}(V_X) + w, \qquad V_1 = V_Y + \frac{\beta R_1}{2}u^2 .$$

对 $u$ 求导（$dV_X = du$，$dw/du = u/w$）：

$$
\begin{aligned}
dV_Y &= D\,du, & D &= 1 + \frac{dV_{TH3}}{dV_X} + \frac{u}{w},\\
dV_1 &= dV_Y + \beta R_1u\,du = (D + \beta R_1u)\,du ,
\end{aligned}
$$

$$\frac{dV_X}{dV_1} = \frac{1}{D + \beta R_1u}, \qquad \frac{dV_Y}{dV_1} = \frac{D}{D + \beta R_1u} .$$

- **在导通点**，$w = 0$，$D \to \infty$：$V_Y$ 的斜率仍为 1，$V_X$ 的斜率为 0，过渡是平滑的，起初 $V_X - V_{GS}(I_{REF}) \approx (V_1 - V_{1,on})^2/(2a)$。
- **此后**，$D$ 降到约 2，因此 $V_Y$ 的斜率降到 **1 以下**，$V_X$ 开始上升。
- **钳位的强弱**由 $\beta R_1u$ 决定：$R_1$ 大时钳位强；$R_1$ 小时钳位弱（斜率接近 1），因为增加的电流只产生很小的额外压降。

### 第 6 步 — 在 $0 < V_1 < 3$ V 内会出现哪些区域

- 若 $R_1I_{REF} + a \ge 3$ V，$M_1$ 始终不饱和：只出现区域 (a)。
- 若 $V_{GS}(I_{REF}) + V_{TH3} + R_1I_{REF} \ge 3$ V，$M_3$ 始终不导通：扫描在区域 (b) 中结束，$V_X$ 保持恒定。
- 否则三个区域都会出现。

### 第 7 步 — 数值示例

$I_{REF} = 100\ \mu$A，$W/L = 10/0.5$（$\beta = 2.68\ \mathrm{mA/V^2}$），$R_1 = 3\ \mathrm{k}\Omega$：

$$
\begin{aligned}
a &= \sqrt{2(0.1\ \mathrm{mA})/(2.68\ \mathrm{mA/V^2})} = 0.273\ \mathrm{V}, \qquad V_X = 0.973\ \mathrm{V},\\
V_{TH3}(0.973\ \mathrm{V}) &= 0.7 + 0.45(\sqrt{1.873} - 0.9487) = 0.889\ \mathrm{V},\\
\text{initial slope} &= 1/(1 + \beta R_1a) = 1/(1 + 2.20) = 0.31,\\
M_1\ \text{saturates at}\ V_1 &= 0.3 + 0.273 = 0.57\ \mathrm{V},\\
V_{1,on} &= 0.973 + 0.889 + 0.3 = 2.16\ \mathrm{V} .
\end{aligned}
$$

求解电路：

| $V_1$ (V) | 0.25 | 0.50 | 0.75 | 1.0 | 1.5 | 2.0 | 2.16 | 2.3 | 2.5 | 2.75 | 3.0 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| $V_X$ (V) | 0.973 | 0.973 | 0.973 | 0.973 | 0.973 | 0.973 | 0.973 | 0.987 | 1.021 | 1.066 | 1.110 |
| $V_Y$ (V) | 0.088 | 0.214 | 0.450 | 0.700 | 1.200 | 1.700 | 1.860 | 1.968 | 2.086 | 2.213 | 2.326 |
| $I_{D3}$ (μA) | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 11 | 38 | 79 | 125 |
| $M_1$ | 线性区 | 线性区 | 饱和 | 饱和 | 饱和 | 饱和 | 饱和 | 饱和 | 饱和 | 饱和 | 饱和 |

导通后，$V_Y$ 的斜率降到约 0.5。若 $R_1 = 300\ \Omega$，导通后的斜率约为 0.85–0.95（钳位较弱）；若 $R_1 = 30\ \mathrm{k}\Omega$，$M_1$ 在整个扫描范围内都处于线性区（3 V 时 $V_Y \approx 0.2$ V），$M_3$ 始终不导通。

### 结果

- **$V_X$** 在 $M_3$ 导通之前保持为 $V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$，之后缓慢上升（起初斜率为零）。
- **$V_Y$** 从 0 开始上升。起初 $M_1$ 处于线性区（初始斜率为 $1/(1 + \beta R_1\sqrt{2I_{REF}/\beta})$，逐渐增大到 1）。当 $M_1$ 在 $V_1 = R_1I_{REF} + \sqrt{2I_{REF}/\beta}$ 处饱和后，$V_Y = V_1 - R_1I_{REF}$（斜率为 1）。
- 当 $V_Y$ 达到 $V_X + V_{TH3}(V_X)$，即 $V_1 = V_{GS}(I_{REF}) + V_{TH3} + R_1I_{REF}$ 时（计入体效应，$V_{TH3} \approx 0.89$ V），**$M_3$ 导通**。它的电流叠加到 $M_2$ 的电流上，并被镜像到 $M_1$ 中，$R_1$ 上增加的压降抑制了 $V_Y$ 的上升（负反馈，$V_Y \approx V_X + V_{GS3}$）。两个电压都继续上升，$V_Y$ 的斜率降到 1 以下。$\beta R_1(V_X - 0.7)$ 较大时钳位强，$R_1$ 较小时钳位弱（斜率接近 1）。
- 视 $R_1I_{REF}$ 的大小，扫描可能在 $M_1$ 饱和之前或 $M_3$ 导通之前就结束了。

**常见错误。** 认为 $M_3$ 从一开始就导通。作为从 Y 到 X 的跟随器，它需要 $V_Y$ 比 $V_X$ 高出一个阈值电压（计入体效应时 ≈ 0.89 V），即 $V_1$ 要高于约 $V_{GS}(I_{REF}) + V_{TH3} + R_1I_{REF}$。

**常见错误。** 从 $V_1 = 0$ 起就画成 $V_Y = V_1 - R_1I_{REF}$，而这在 $V_1$ 较小时为负值。此时 $M_1$ 处于线性区，$V_Y$ 以斜率 $1/(1 + \beta R_1a)$ 上升。

**常见错误。** 把 $M_3$ 的漏极看成接 $V_{DD}$，或者让 $V_X$ 跟随 $V_1$。其漏极接在 $V_1$ 节点上，而且只有当 $M_3$ 向 $M_2$ 注入电流后 $V_X$ 才会变化，并且变化很慢。
