在 $M_3$ 导通之前，$V_X$ 保持为 $V_{GS}(I_{REF}) = 0.7 + a$，其中 $a = \sqrt{2I_{REF}/\beta}$。$V_Y$ 从 0 开始上升：起初 $M_1$ 处于线性区（triode region），初始斜率为 $1/(1 + \beta R_1a)$，并逐渐增大到 1；一旦 $M_1$ 饱和（在 $V_1 = R_1I_{REF} + a$ 处），就按 $V_1 - R_1I_{REF}$ 变化（斜率为 1）；最后，当 $V_Y$ 达到 $V_X + V_{TH3}(V_X)$ 时（在 $V_1 = V_X + V_{TH3} + R_1I_{REF}$ 处），$M_3$ 导通。它的电流被镜像到 $M_1$ 中，$R_1$ 上增加的压降抑制了 $V_Y$ 的上升，这是负反馈（negative feedback）的作用，$V_Y \approx V_X + V_{GS3}$；因此 $V_Y$ 的斜率降到 1 以下，而 $V_X$ 开始上升。这种钳位（clamp）作用的强弱取决于 $\beta R_1(V_X - 0.7)$：$R_1$ 大时钳位强，$R_1$ 小时钳位弱（斜率接近 1）。

- 在 $M_3$ 截止期间，$M_2$ 流过 $I_{REF}$，$M_1$ 若饱和则复制该电流：$V_Y = V_1 - R_1I_{REF}$。当 $V_1$ 较小时电压不够：$M_1$ 处于线性区，$(V_1 - V_Y)/R_1 = \beta(aV_Y - V_Y^2/2)$，$V_Y$ 是 $V_1$ 的一部分（示例中起初 ≈ 0.3 倍）。
- $M_3$（漏极接 $V_1$，栅极接 Y，源极接 X）在 $V_Y - V_X > V_{TH3}(V_X) = 0.7 + 0.45(\sqrt{0.9 + V_X} - \sqrt{0.9})$ 时导通（$V_X \approx 0.97$ V 时 ≈ 0.89 V）。它的电流叠加到 $M_2$ 的电流上，$M_1$ 复制这一更大的电流，$R_1$ 上的压降增大，$V_Y$ 被拉回。
- 在这一区域，令 $u = V_X - 0.7$，并令 $M_3$ 的过驱动电压（overdrive voltage）为 $w = \sqrt{u^2 - a^2}$：$V_Y = V_X + V_{TH3}(V_X) + w$，$V_1 = V_Y + \tfrac{\beta R_1}{2}u^2$。因此 $dV_X/dV_1 = 1/(D + \beta R_1u)$，$dV_Y/dV_1 = D/(D + \beta R_1u)$，其中 $D = 1 + dV_{TH3}/dV_X + u/w$。在导通点 $w = 0$：$V_Y$ 的斜率仍为 1，$V_X$ 的斜率为 0（平滑过渡，$V_X - V_{GS}(I_{REF}) \approx (V_1 - V_{1,on})^2/(2a)$）；此后二者都继续上升，$V_Y$ 的斜率逐渐减小到 1 以下。
- 扫描范围内的分支情况：若 $R_1I_{REF} + a \ge 3$ V，只出现线性区；若 $V_{GS}(I_{REF}) + V_{TH3} + R_1I_{REF} \ge 3$ V，$M_3$ 始终不会导通。
- 示例（$I_{REF}$ = 100 μA，W/L = 10/0.5，$\mu_nC_{ox}$ = 134 μA/V²，即 β = 2.68 mA/V²，$R_1$ = 3 kΩ；按平方律仿真）：在 $V_1 \approx 2.16$ V 之前 $V_X$ = 0.97 V；$V_Y$ 在 0.25 V 处 ≈ 0.09 V，在 0.75 V 处为 0.45 V，随后为 $V_1 - 0.3$ V，直到 ≈ 1.86 V；之后在 $V_1$ = 2.5、3 V 处分别为 2.09、2.33 V（斜率 ≈ 0.5），同时 $V_X$ 升到 1.11 V。若 $R_1$ = 300 Ω，$V_Y$ 在导通后的斜率 ≈ 0.9；若 $R_1$ = 30 kΩ，$M_1$ 在整个扫描范围内都处于线性区（3 V 时 $V_Y$ ≈ 0.2 V）。
