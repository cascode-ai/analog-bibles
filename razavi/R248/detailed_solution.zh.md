# 详细步骤 - R248

**思路。** 环路 $M_2$（二极管）→ $M_1$（NMOS 电流镜）→ $M_3$（PMOS 二极管）→ $M_4$（PMOS 电流镜）→ 回到 X，再加上同样向 X 供电的 $R_1$，构成了一个**由两个单位比例电流镜组成的正反馈环路**。按 $V_{DD}$ 的范围逐段分析：低于 NMOS 阈值电压（threshold voltage）时没有任何器件导通；在两个阈值电压之间只有 NMOS 一侧能够导通；高于 PMOS 阈值电压时环路闭合。证明此时环路不可能在所有器件都饱和的情况下工作，找出哪个器件退出饱和，并描述由此形成的大电流状态。

### 第 1 步 — 方程

$V_{GS1} = V_{GS2} = V_X$，$V_{SG3} = V_{SG4} = V_{DD} - V_Y$。KCL 方程为：

$$\text{at X: } \frac{V_{DD} - V_X}{R_1} + I_{D4} = I_{D2}, \qquad \text{at Y: } I_{D3} = I_{D1} .$$

令 $\beta_n = \mu_nC_{ox}(W/L)_{1,2}$，$\beta_p = \mu_pC_{ox}(W/L)_{3,4}$，$V_{THN} = 0.7$ V，$|V_{THP}| = 0.8$ V。

### 第 2 步 — $0 \le V_{DD} \le 0.7$ V：全部截止

$V_X \le V_{DD} \le 0.7$ V，因此 $M_1$ 和 $M_2$ 截止，于是 $M_3$、$M_4$ 也不可能有电流。$R_1$ 中没有电流：

$$V_X = V_{DD} .$$

$V_Y$ 所在的节点只与截止的器件相连，因此没有电流来确定它（实际中由漏电决定）：$\max(0, V_{DD} - 0.8\ \mathrm{V})$ 与 $V_{DD}$ 之间的任何值都是自洽的，草图中可以把它画成不确定，或者简单地让它跟随 $V_{DD}$。

### 第 3 步 — $0.7\ \mathrm{V} < V_{DD} \le 0.8\ \mathrm{V}$：只有 NMOS 一侧导通

$M_2$ 流过 $R_1$ 的电流，与电阻负载的二极管相同：

$$V_X = 0.7 + \frac{\sqrt{1 + 2\beta_nR_1(V_{DD} - 0.7)} - 1}{\beta_nR_1}\quad(\text{just above } 0.7\ \mathrm{V}).$$

$M_3$ 只有在 $V_{SG3} = V_{DD} - V_Y > 0.8$ V，即 $V_Y < V_{DD} - 0.8 \le 0$ 时才能导通，而这是不可能的，因此 $I_{D3} = I_{D1} = 0$。$M_1$ 有沟道但没有电流，因此其 $V_{DS}$ 为零：

$$V_Y = 0 .$$

$M_4$ 的 $V_{SG4} = V_{DD} \le 0.8$ V，保持截止。

### 第 4 步 — $V_{DD} > 0.8$ V：环路闭合，“全部饱和”不可能成立

**假设所有器件都饱和。** 器件相同且 $\lambda = 0$，因此 $I_{D1} = I_{D2}$（$V_{GS}$ 相同），$I_{D3} = I_{D1}$（Y 点的 KCL），$I_{D4} = I_{D3}$（$V_{SG}$ 相同）。于是 $I_{D4} = I_{D2}$，而 X 点的 KCL 要求 $(V_{DD} - V_X)/R_1 = 0$，即 $V_X = V_{DD}$。但这样 $V_{SD4} = 0$，$M_4$ 无法提供 $I_{D4} = I_{D2} > 0$（$M_2$ 的 $V_{GS} = V_{DD} > 0.7$ V）。**矛盾。** 环路增益为 $1\times1 = 1$，而 $R_1$ 还注入额外电流，因此在某个器件退出饱和、使环路增益降到小于一之前，不存在自洽的工作点。

**$M_1$ 必须处于线性区。** 若 $M_1$ 饱和，则 $I_{D3} = I_{D1} = I_{D2}$，而 X 点的 KCL 给出 $I_{D4} = I_{D2} - I_{R1} < I_{D3}$；$V_{SG}$ 相同而电流更小，说明 $M_4$ 处于线性区：

$$V_{SD4} < V_{SG4} - 0.8 \;\Longleftrightarrow\; V_{DD} - V_X < V_{DD} - V_Y - 0.8 \;\Longleftrightarrow\; V_X - V_Y > 0.8\ \mathrm{V} .$$

但 $M_1$ 饱和要求 $V_Y \ge V_X - 0.7$，即 $V_X - V_Y \le 0.7$ V。两者不可能同时成立，因此

$$M_1 \text{ is in the triode region:}\qquad V_Y < V_X - 0.7\ \mathrm{V} .$$

此时 $M_1$ 的电流小于 $M_2$（$I_{D1} < I_{D2}$），打破了单位环路增益。$M_4$ 可以饱和（此时 $I_{D4} = I_{D1}$，$I_{D2} = I_{D1} + I_{R1}$），也可以处于线性区，这取决于 $R_1$ 和 $V_{DD}$。

### 第 5 步 — 决定电流的是 $M_3$–$M_1$ 叠层

环路一旦工作，右支路就必须容纳在 $V_{DD}$ 与地之间：

$$V_{DD} = V_{SG3} + V_{DS1} = 0.8 + \sqrt{\frac{2I_{D3}}{\beta_p}} + V_Y .$$

**$R_1$ 很大时。** $I_{R1}$ 很小，因此 $I_{D1} \approx I_{D2}$，$M_1$ 刚好处于线性区边缘之内，$V_Y \approx V_X - 0.7 = V_{ov}$，其中 $V_{ov} = \sqrt{2I/\beta_n}$ 是 $M_1$、$M_2$ 的过驱动电压（overdrive voltage）。代入 $\sqrt{2I/\beta_p} = V_{ov}\sqrt{\beta_n/\beta_p}$：

$$V_{DD} - 0.8 \approx V_{ov}\left(1 + \sqrt{\beta_n/\beta_p}\right) \;\Longrightarrow\; V_X - 0.7 \approx \frac{V_{DD} - 0.8}{1 + \sqrt{\beta_n/\beta_p}}, \qquad I \approx \frac{\beta_n}{2}\left(\frac{V_{DD} - 0.8}{1 + \sqrt{\beta_n/\beta_p}}\right)^2 .$$

$V_X$ 和 $V_Y$ 随 $V_{DD}$ **线性**上升，斜率为 $1/(1 + \sqrt{\beta_n/\beta_p})$，电流则按**平方**增长，与 $R_1$ 无关。$M_4$ 保持饱和，裕量为 $|V_{THP}| - V_{THN} = 0.1$ V。

**$R_1$ 适中时。** $R_1$ 中的电流不再可以忽略：$M_1$ 更深地进入线性区，$V_Y$ 更低，并且在较高的 $V_{DD}$ 下 $M_4$ 也进入线性区。$V_X$ 仍大致线性地上升，$V_Y$ 保持在低电平，而环路电流远大于 $(V_{DD} - V_X)/R_1$。

### 第 6 步 — 数值示例

所有 $W/L = 10/0.5$（$\beta_n = 2.68\ \mathrm{mA/V^2}$，$\beta_p = 0.768\ \mathrm{mA/V^2}$，$\sqrt{\beta_n/\beta_p} = 1.87$），$R_1 = 10\ \mathrm{k}\Omega$，用完整的平方律模型求解两个 KCL 方程：

| $V_{DD}$ (V) | 0.75 | 0.80 | 0.90 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 |
|---|---|---|---|---|---|---|---|---|
| $V_X$ (V) | 0.734 | 0.757 | 0.799 | 0.841 | 1.04 | 1.23 | 1.42 | 1.61 |
| $V_Y$ (V) | 0 | 0 | 0.012 | 0.032 | 0.160 | 0.303 | 0.452 | 0.604 |
| $I_{D2}$ (μA) | 1.6 | 4.3 | 13 | 27 | 155 | 379 | 696 | 1102 |
| $I_{R1}$ (μA) | 1.6 | 4.3 | 10 | 16 | 46 | 77 | 108 | 139 |
| $M_4$ | 截止 | 截止 | 饱和 | 线性区 | 线性区 | 线性区 | 线性区 | 线性区 |

$M_1$ 始终处于线性区，$M_4$ 在 $V_{DD} \approx 0.96$ V 附近进入线性区。在 3 V 时环路电流约为 1.1 mA，是 $R_1$ 中 0.14 mA 的八倍。对于 $R_1 = 1\ \mathrm{M}\Omega$，曲线类似（3 V 时 $V_X \approx 1.48$ V，$V_Y \approx 0.75$ V，电流约 0.81 mA），与大 $R_1$ 公式 $V_X \approx 0.7 + 2.2/2.87 = 1.47$ V 相符，且 $M_4$ 保持饱和。

### 结果

- **$V_{DD} \le 0.7$ V：** 所有器件都截止；$V_X = V_{DD}$；$V_Y$ 不由任何电流决定（可以是 $[\max(0, V_{DD} - 0.8), V_{DD}]$ 中的任意值）。
- **$0.7 < V_{DD} \le 0.8$ V：** $M_2$ 流过 $R_1$ 的电流，因此 $V_X$ 略高于 0.7 V（电阻负载的二极管曲线）。$M_1$ 导通，但 PMOS 二极管无法导通（$V_{SG3} \le 0.8$ V），因此 $V_Y = 0$。
- **$V_{DD} > 0.8$ V：** 正反馈环路 $M_2 \to M_1 \to M_3 \to M_4 \to X$（环路增益为 1，另有 $R_1$ 注入的电流）不存在全部饱和的解。电流不断增大，直到 $M_1$ 进入线性区（$V_Y < V_X - 0.7$ V）；$M_4$ 饱和还是处于线性区取决于 $R_1$ 和 $V_{DD}$。电流由 $M_3$–$M_1$ 叠层决定，而不是由 $R_1$ 决定。**$V_X$ 随 $V_{DD}$ 大致线性地上升**，远高于 $V_{TH}$（$R_1$ 很大时约为 $0.7 + (V_{DD} - 0.8)/(1 + \sqrt{\beta_n/\beta_p})$；例如 3 V 时为 1.6 V），而 **$V_Y$ 保持在低电平**，低于 $V_X - 0.7$ V，缓慢上升（示例中 3 V 时约为 0.6 V）。支路电流达到毫安量级。

**常见错误。** 把电路当作所有器件都饱和、电流由 $R_1$ 决定的普通电流镜。环路中的两个单位电流镜再加上 $R_1$ 注入的电流，将要求 $I_{R1} = 0$，因此这种解并不存在。

**常见错误。** 认为有大电流流动而 $V_X$ 被钉在 $V_{DD}$。此时 $M_4$ 的源漏电压为零，无法向 X 提供任何电流。

**常见错误。** 让 $M_1$ 保持饱和，只让 $M_4$ 进入线性区。那需要 $V_X - V_Y > 0.8$ V 与 $V_X - V_Y \le 0.7$ V 同时成立；$M_1$ 必须退出饱和（$M_4$ 也可能随之退出）。
