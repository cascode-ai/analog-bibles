# 详细步骤 - R367

**思路。** 写出共栅（CG）级的输入参考噪声电压（输入端短路），以及由 $M_1$ 和 $M_2$ 的饱和条件决定的输出摆幅范围。摆幅为 $V_{DD} - V_{ov1} - V_{ov2}$，因此应选择较小的过驱动电压，确定器件尺寸，把输出偏置点放在中间（由此确定 $R_D$），计算 $V_b$，再对照 3 nV/√Hz 检验噪声。有几项选择是自由的；下面给出一个完整、自洽的设计。

### 第 1 步 — 输入参考噪声电压

把输入节点（$M_1$ 的源极、$M_2$ 的漏极）记为 X；$C_0$ 旁路了 $M_0$ 和 $I_1$ 的噪声，因此 $M_2$ 的栅极是干净的交流地。指标要求 $\overline{V_{n,in}^2} \le (3\times10^{-9})^2 = 9\times10^{-18}\ \mathrm{V^2/Hz}$。

输入端短路时，X 接地，$v_{gs1} = 0$，因此：

- $M_1$ 的噪声电流 $\overline{I_{n1}^2} = 4kT\gamma g_{m1}$ 从漏极流向接地的源极，因此全部流过 $R_D$（由于 $\lambda = 0$，不存在 $r_O$）；
- $R_D$ 的噪声电流 $\overline{I_{nD}^2} = 4kT/R_D$ 在 $R_D$ 中流动；
- $M_2$ 的噪声电流 $\overline{I_{n2}^2} = 4kT\gamma g_{m2}$ 从 X 流向地，**全部流入短路线**，根本到不了输出端，因此 $M_2$ 对输入参考噪声**电压**没有贡献。

共栅级的增益为 $|A_v| = g_{m1}R_D$，因此：

$$\overline{V_{n,out}^2} = \left(4kT\gamma g_{m1} + \frac{4kT}{R_D}\right)R_D^2,$$

$$\overline{V_{n,in}^2} = \frac{\left(4kT\gamma g_{m1} + 4kT/R_D\right)R_D^2}{g_{m1}^2R_D^2} = 4kT\left(\frac{\gamma}{g_{m1}} + \frac{1}{g_{m1}^2R_D}\right).$$

（若计入体效应，分母中的 $g_{m1}$ 变为 $g_{m1} + g_{mb1}$，噪声略有降低；这里忽略它。）电流固定时 $g_{m1} = 2I_D/V_{ov1}$，因此**较小的 $V_{ov1}$ 有利于降低噪声**。

### 第 2 步 — 输出摆幅

**$V_{out}$ 的下限。** 两个饱和条件相互叠加：

1. $M_2$ 饱和：$V_X \ge V_{ov2}$。把 X 设在其最小值 $V_X = V_{ov2}$，即可确定 $M_1$ 的栅极偏置：
$$V_b = V_X + V_{GS1} = V_{ov2} + V_{TH1} + V_{ov1}.$$
2. $M_1$ 饱和：$V_{out} \ge V_X + V_{ov1}$：
$$V_{out,min} = V_{ov1} + V_{ov2} \quad (= V_b - V_{TH1}).$$

**上限。** 输出端经 $R_D$ 上拉，故 $V_{out,max} = V_{DD}$。因此

$$V_{out,max} - V_{out,min} = V_{DD} - V_{ov1} - V_{ov2},$$

其中过驱动电压按偏置电流计算。

两个过驱动电压越小（器件越宽），摆幅越大，而平方律本身并不给出下限。实际上，过驱动电压低于约 0.15–0.2 V 时，器件接近弱反型（weak inversion），且尺寸变得很大（X 点和输出端的电容很大）；此外，较小的 $V_{ov2}$ 还会增大输入参考噪声**电流**（第 6 步）。

**选择（可自由选定）：** $V_{ov1} = V_{ov2} = 0.2$ V。

### 第 3 步 — 器件尺寸

$$\left(\frac{W}{L}\right)_{1,2} = \frac{2I_D}{\mu_nC_{ox}V_{ov}^2} = \frac{2\times0.5\times10^{-3}\ \mathrm{A}}{(134\times10^{-6}\ \mathrm{A/V^2})(0.2\ \mathrm{V})^2} = \frac{1\times10^{-3}}{5.36\times10^{-6}} = 187 .$$

取 $L = 0.5\ \mu$m，则 $M_1$ 和 $M_2$ 均为 $W \approx 93\ \mu$m，且

$$g_{m1} = g_{m2} = \frac{2I_D}{V_{ov}} = \frac{2\times0.5\ \mathrm{mA}}{0.2\ \mathrm{V}} = 5\ \mathrm{mS}.$$

（验证：$\sqrt{2\mu_nC_{ox}(W/L)I_D} = \sqrt{2(134\ \mu)(187)(0.5\ \mathrm{m})} = \sqrt{2.5\times10^{-5}} = 5$ mS。）

$M_0$ 的尺寸由镜像比确定：$(W/L)_0 = (W/L)_2\,I_1/I_{D2}$；例如取 $I_1 = 50\ \mu$A（可自由选择），得到 $(W/L)_0 = 18.7$。

### 第 4 步 — 负载电阻与输出偏置点

由于 $V_{ov1} + V_{ov2} = 0.4$ V，输出可以在 0.4 V 到 3 V 之间变化。为获得最大的对称摆幅，把静态输出电压放在中点：

$$V_{out,Q} = \frac{V_{out,min} + V_{out,max}}{2} = \frac{0.4 + 3}{2} = 1.7\ \mathrm{V}.$$

此时 $R_D$ 上的压降为 $V_{DD} - V_{out,Q} = 1.3$ V，因此

$$R_D = \frac{V_{DD} - V_{out,Q}}{I_D} = \frac{3 - 1.7\ \mathrm{V}}{0.5\ \mathrm{mA}} = 2.6\ \mathrm{k}\Omega,$$

这就是一般规律 $R_D = (V_{DD} - V_{ov1} - V_{ov2})/(2I_D)$。输出可以在 1.7 V 附近变化 $\pm1.3$ V，即摆幅为**峰峰值 2.6 V**。

### 第 5 步 — 栅极偏置电压 $V_b$

取 $V_{TH1} = V_{TH0} = 0.7$ V（忽略体效应）：

$$V_b = V_{ov2} + V_{TH1} + V_{ov1} = 0.2 + 0.7 + 0.2 = 1.1\ \mathrm{V}.$$

在偏置点，$V_{DS2} = V_X = V_b - V_{GS1} = 1.1 - 0.9 = 0.2\ \mathrm{V} = V_{ov2}$（按设计恰好处于边缘），$V_{DS1} = V_{out,Q} - V_X = 1.7 - 0.2 = 1.5\ \mathrm{V} \ge V_{ov1} = 0.2$ V ✓。

若计入体效应（取典型值 $\gamma_{body} = 0.45\ \mathrm{V^{1/2}}$，$2|\phi_F| = 0.9$ V），则 $V_{SB1} = 0.2$ V，$V_{TH1} = 0.7 + 0.45(\sqrt{1.1} - \sqrt{0.9}) = 0.7 + 0.45(1.049 - 0.949) = 0.745$ V，因此 $V_b \approx 1.15$ V。实际设计中通常给 $V_b$ 增加约 0.1 V 的裕量，使 $M_2$ 不恰好处于边缘，代价是摆幅减少 0.1 V。

### 第 6 步 — 验证噪声

$$
\begin{aligned}
\frac{\gamma}{g_{m1}} &= \frac{2/3}{5\times10^{-3}\ \mathrm{S}} = 133.3\ \Omega,\\
\frac{1}{g_{m1}^2R_D} &= \frac{1}{(5\times10^{-3})^2(2600)}\ \Omega = \frac{1}{0.065}\ \Omega = 15.4\ \Omega,\\
4kT &= 4(1.38\times10^{-23})(300) = 1.656\times10^{-20}\ \mathrm{J},\\
\overline{V_{n,in}^2} &= (1.656\times10^{-20})(133.3 + 15.4)\ \mathrm{V^2/Hz} = 2.46\times10^{-18}\ \mathrm{V^2/Hz},\\
\sqrt{\overline{V_{n,in}^2}} &= 1.57\ \mathrm{nV/\sqrt{Hz}} \;<\; 3\ \mathrm{nV/\sqrt{Hz}}\ \checkmark
\end{aligned}
$$

指标留有余量地得到满足；它并不是起决定作用的约束。

**指标有多宽松？** 保持 $V_{ov2} = 0.2$ V，并取使偏置点居中的 $R_D = (2.8\ \mathrm{V} - V_{ov1})/(1\ \mathrm{mA})$，则在 $V_{ov1} \approx 0.58$ V 左右时噪声恰好达到 3 nV/√Hz（$\gamma/g_{m1} + 1/(g_{m1}^2R_D) = 9\times10^{-18}/1.656\times10^{-20} = 543\ \Omega$）。任何更小的 $V_{ov1}$ 都满足噪声要求，而且较小的 $V_{ov1}$ 对噪声和摆幅**都**有利。

**较小 $V_{ov2}$ 的代价。** 它不影响输入参考噪声电压，但会增大输入参考噪声**电流** $\overline{I_{n,in}^2} = 4kT/R_D + 4kT\gamma g_{m2}$（输入端开路时，$M_2$ 的噪声流过 $M_1$）：

$$\overline{I_{n,in}^2} = (1.656\times10^{-20})\left(\frac{1}{2600} + \frac23\times5\times10^{-3}\right) = 6.2\times10^{-23}\ \mathrm{A^2/Hz} \;\Rightarrow\; 7.9\ \mathrm{pA/\sqrt{Hz}},$$

当该级由高阻抗信号源驱动时，这一点很重要。

### 结果

一个完整的设计（过驱动电压是自由选择的，其余参数随之确定）：

| 参数 | 数值 |
|---|---|
| $V_{ov1} = V_{ov2}$ | 0.2 V |
| $(W/L)_1 = (W/L)_2$ | $2I_D/(\mu_nC_{ox}V_{ov}^2) \approx 187$（≈ 93 μm / 0.5 μm） |
| $g_{m1}$ | 5 mS |
| $R_D$ | 2.6 kΩ（输出偏置在 1.7 V） |
| $V_b$ | $V_{ov2} + V_{TH1} + V_{ov1} \approx 1.1$ V（计入体效应时 ≈ 1.15 V） |
| $\sqrt{\overline{V_{n,in}^2}} = \sqrt{4kT(\gamma/g_{m1} + 1/(g_{m1}^2R_D))}$ | ≈ 1.57 nV/√Hz（≤ 3 nV/√Hz） |
| 输出范围 | $0.4\ \mathrm{V} \le V_{out} \le 3$ V，即峰峰值 ≈ 2.6 V |

一般而言：摆幅 $= V_{DD} - V_{ov1} - V_{ov2}$，过驱动电压越小摆幅越大；$R_D = (V_{DD} - V_{ov1} - V_{ov2})/(2I_D)$ 使偏置点居中；$M_2$ 不出现在输入参考噪声电压中。

**常见错误。** 把 $M_2$ 的噪声计入输入参考噪声**电压**。输入端短路时，它流入短路线；它只属于输入参考噪声**电流**，若把它计入电压噪声，会使噪声约束看起来比实际严格得多。

**常见错误。** 用 $g_m = I_D/V_{ov}$ 代替 $2I_D/V_{ov}$。这会使 $g_{m1}$ 减半（2.5 mS 而不是 5 mS），同一设计的噪声验算结果将变成 $\sqrt{1.656\times10^{-20}(266.7 + 61.5)} \approx 2.3$ nV/√Hz，而不是 1.57 nV/√Hz。

**常见错误。** 把输出下限仅取为 $V_{ov1}$。$M_1$ 的源极电压一旦低于 $V_{ov2}$，$M_2$ 就会进入线性区（triode region），因此输出电压必须保持在 $V_{ov1} + V_{ov2}$ 以上。
