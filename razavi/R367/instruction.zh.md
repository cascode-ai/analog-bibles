设计 [图 1] 所示的共栅（common-gate）电路，使其输入参考热噪声电压（input-referred thermal noise voltage）为 3 nV/√Hz，且输出摆幅（output swing）最大。电路中，$M_1$（栅极接 $V_b$，源极为输入端，负载 $R_D$ 接到 $V_{DD} = 3$ V）由 NMOS 电流源（current source）$M_2$ 偏置，该电流源镜像二极管连接（diode-connected）的 $M_0$ 的电流（由 $I_1$ 供电，其噪声由 $C_0$ 旁路）。假设 $I_{D1} = I_{D2} = 0.5$ mA；选择 $(W/L)_1$、$(W/L)_2$、$R_D$ 和 $V_b$，并给出由此得到的输出摆幅。采用平方律（square law），$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$V_{TH0} = 0.7$ V，$T = 300$ K，沟道噪声（channel noise）为 $4kT\gamma g_m$，其中 $\gamma = 2/3$；忽略沟道长度调制（channel-length modulation）；体效应（body effect）可以忽略，也可以计入。
