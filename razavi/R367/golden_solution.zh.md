任何满足 $4kT(\gamma/g_{m1} + 1/(g_{m1}^2R_D)) \le (3\ \mathrm{nV})^2 = 9\times10^{-18}\ \mathrm{V^2/Hz}$ 且过驱动电压（overdrive voltage）较小的设计都可以接受。示例：$V_{ov1} = V_{ov2} = 0.2$ V → $(W/L)_1 = (W/L)_2 = 2I_D/(\mu_nC_{ox}V_{ov}^2) \approx 187$（≈ 93 μm/0.5 μm），$g_{m1} = 5$ mS，$R_D = 2.6$ kΩ（输出偏置在 1.7 V，即范围中点），$V_b = V_{ov2} + V_{TH1} + V_{ov1} \approx 1.1$ V（计入体效应时 ≈ 1.15 V），由此得到 $\overline{V_{n,in}} \approx 1.57$ nV/√Hz（留有余量地满足指标），输出范围为 0.4 V ≤ $V_{out}$ ≤ 3 V，即峰峰值 ≈ 2.6 V。

- 输入端短路时，$M_2$（以及被 $C_0$ 旁路的 $M_0$）对输入参考噪声电压没有贡献：$\overline{V_{n,in}^2} = \dfrac{4kT(\gamma g_{m1} + 1/R_D)}{(g_{m1}+g_{mb1})^2} \approx 4kT\left(\dfrac{\gamma}{g_{m1}} + \dfrac{1}{g_{m1}^2R_D}\right)$。
- 摆幅：$M_2$ 工作在饱和区（saturation region）要求输入节点电压 ≥ $V_{ov2}$；于是 $V_b = V_{ov2} + V_{GS1}$，而 $M_1$ 饱和要求 $V_{out} \ge V_b - V_{TH1} = V_{ov1} + V_{ov2}$。上限为 $V_{DD}$。因此摆幅为 $V_{DD} - V_{ov1} - V_{ov2}$，过驱动电压越小（器件越宽），摆幅越大；把偏置点放在范围中点，则 $R_D = (V_{DD} - V_{ov1} - V_{ov2})/(2I_D)$。
- 这里的噪声指标很宽松：取 $V_{ov2} = 0.2$ V 且 $R_D$ 使偏置点居中时，$V_{ov1}$ 最大可到 ≈ 0.58 V 仍能满足 3 nV/√Hz；较小的 $V_{ov1}$ 对噪声和摆幅都有利。较小 $V_{ov2}$ 的代价是更大的输入参考噪声电流（$4kT\gamma g_{m2}$，其中 $g_{m2} = 2I_D/V_{ov2}$）以及更大的 $M_2$；过驱动电压能取多小，受器件尺寸/电容的限制，而不是由电压噪声指标决定。
- $(W/L)_0$ 由镜像比 $I_{D2}/I_1$ 确定。
