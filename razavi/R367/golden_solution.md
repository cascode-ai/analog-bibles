# Golden Solution - R367

## Reference answer

Any design is acceptable that satisfies $4kT(\gamma/g_{m1} + 1/(g_{m1}^2R_D)) \le (3\ \mathrm{nV})^2 = 9\times10^{-18}\ \mathrm{V^2/Hz}$ and keeps the overdrives small. Example: $V_{ov1} = V_{ov2} = 0.2$ V → $(W/L)_1 = (W/L)_2 = 2I_D/(\mu_nC_{ox}V_{ov}^2) \approx 187$ (≈ 93 μm/0.5 μm), $g_{m1} = 5$ mS, $R_D = 2.6$ kΩ (output biased at 1.7 V, mid-range), $V_b = V_{ov2} + V_{TH1} + V_{ov1} \approx 1.1$ V (≈ 1.15 V with body effect), giving $\overline{V_{n,in}} \approx 1.57$ nV/√Hz (meets the spec with margin) and an output range 0.4 V ≤ $V_{out}$ ≤ 3 V, i.e. ≈ 2.6 V peak-to-peak.

- With the input shorted, $M_2$ (and $M_0$, shunted by $C_0$) contribute nothing to the input-referred voltage: $\overline{V_{n,in}^2} = \dfrac{4kT(\gamma g_{m1} + 1/R_D)}{(g_{m1}+g_{mb1})^2} \approx 4kT\left(\dfrac{\gamma}{g_{m1}} + \dfrac{1}{g_{m1}^2R_D}\right)$.
- Swing: $M_2$ saturated needs the input node at ≥ $V_{ov2}$; then $V_b = V_{ov2} + V_{GS1}$ and $M_1$ saturated needs $V_{out} \ge V_b - V_{TH1} = V_{ov1} + V_{ov2}$. The top is $V_{DD}$. So the swing is $V_{DD} - V_{ov1} - V_{ov2}$, maximized by small overdrives (wide devices); placing the bias point mid-range, $R_D = (V_{DD} - V_{ov1} - V_{ov2})/(2I_D)$.
- The noise spec is loose here: with $V_{ov2} = 0.2$ V and $R_D$ centered, $V_{ov1}$ up to ≈ 0.58 V still meets 3 nV/√Hz; small $V_{ov1}$ helps both noise and swing. The price of a small $V_{ov2}$ is a larger input-referred noise current ($4kT\gamma g_{m2}$ with $g_{m2} = 2I_D/V_{ov2}$) and a larger $M_2$; the limit on the overdrives is set by device size/capacitance, not by the voltage-noise spec.
- $(W/L)_0$ follows from the mirror ratio $I_{D2}/I_1$.

## Grading notes

+2: correct noise expression (no $M_2$ term), a concrete design whose computed noise is ≤ 3 nV/√Hz (verified numerically within ±10%), a correct swing analysis ($V_{ov1} + V_{ov2} \le V_{out} \le V_{DD}$, $V_b = V_{ov2} + V_{GS1}$) and a consistent $R_D$/bias point; recognizing that small overdrives maximize the swing. Different but consistent design choices are fine, including reading the spec as an equality (noise exactly 3 nV/√Hz, e.g. $V_{ov1} \approx 0.58$ V with $V_{ov2} = 0.2$ V) with the swing computed correctly for that choice, or pointing out that the square law gives no finite optimum without a minimum overdrive and choosing one. Check the claimed noise by recomputing $g_{m1} = 2I_D/V_{ov1} = \sqrt{2\mu_nC_{ox}(W/L)_1I_D}$ and the noise from the answer's own $(W/L)_1$ and $R_D$ (e.g., $g_m = I_D/V_{ov}$ halves $g_{m1}$ and makes the claimed noise wrong). +1: valid design with one inconsistency (e.g., $V_b$ not computed, or bias point not placed for the stated swing). 0: correct noise analysis without a complete design, or a design that misses the spec by a small margin with otherwise sound reasoning. -2 (asserted as fact): $M_2$'s noise included in the input-referred voltage so that the design is driven by a wrong constraint, a design that violates saturation (e.g., output range computed below $V_{ov1} + V_{ov2}$), or a claimed noise value that is off by more than 30% from the chosen values.
