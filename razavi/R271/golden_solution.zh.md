主要理解方式：忽略 $C_1$ 以外的节点电容（X、Y 准静态变化），各个结视为二极管（大电流时 ≈ 0.7 V）。$V_X$ 几乎立即升到 $V_{DD}$ 并保持不变；$V_Y$ 稳定在 $M_3$ 与 $M_1$ 的平衡点上，并在 $C_1$ 充电期间缓慢下降。

- 在 $t = 0$ 时，两个衬底处于相同电位。从 $V_{DD}$ 经 $M_3$ 的源-阱结、$C_1$ 和 $M_1$ 的衬底-源结到地存在一条串联通路；两个结都处于正向偏置（forward-biased）——公共衬底电位的初始值介于两者之间，由结的特性决定，对于特性相近的结约在电源中点附近——因此很大的电流把 $C_1$ 迅速充电到约 $V_{DD} - 2V_{D,on}$（≈ 1.6 V），此时 n 阱接近 $V_{DD} - 0.7$ V，$M_1$ 的衬底接近 +0.7 V。此后结电流衰减，$C_1$ 非常缓慢地趋向 $V_{DD}$（阱 → $V_{DD}$，$M_1$ 的衬底 → 0）；拖尾形状取决于结模型，固定压降模型则停在 1.6 V 附近。
- 在此期间，两个晶体管的衬底都处于正向偏置：$|V_{TH3}|$ 和 $V_{TH1}$ 降低，使 $M_3$ 和 $M_1$ 比正常情况更强；随着 $C_1$ 充电，它们恢复到标称阈值电压（threshold voltage）。在初始的强正向偏置阶段，平方律模型下的体效应（body effect）公式不成立；一旦每个结的电压降到 ≈ 0.7 V 或更低，该公式就可以使用（两个结各为 0.7 V 时，$V_{TH1}$ ≈ 0.47 V，$|V_{TH3}|$ ≈ 0.57 V）。
- $M_1$–$M_3$–$M_2$ 环路被触发（流入和流出 Y 的结电流使 $M_3$ 导通）并发生锁定（latch）：$M_2$ 把没有直流负载的 X 拉到 $V_{DD}$。因此 $V_X$ 迅速升到 $V_{DD}$ 并保持不变。（截止状态也是一个直流解；对于任意的节点电容和 X、Y 初始值，并不能保证电路启动。）
- $V_Y$ 由二极管连接（diode-connected）的 $M_3$ 与 $M_1$ 的相互抗衡决定，前者处于饱和区（saturation region），后者栅极接 $V_{DD}$、处于线性区（triode region）：$\tfrac{\beta_p}{2}(V_{DD} - V_Y - |V_{TH3}|)^2 = \beta_n[(V_{DD} - V_{TH1})V_Y - V_Y^2/2]$。两个串联的结流过相同的电流，因此它们的正向电压以相同的速率恢复；于是对于任意尺寸比，都有 $dV_Y \propto V_Y[dV_{TH1} - \tfrac{2(V_{DD}-V_{TH1}) - V_Y}{V_{DD} - V_Y - |V_{TH3}|}\,d|V_{TH3}|] < 0$（饱和的 $M_3$ 的减弱超过了处于线性区的 $M_1$ 的减弱），因此 $V_Y$ 缓慢下降：例如 $\beta_p = \beta_n$ 时为 ≈ 0.69 → 0.62 V，$\beta_p = 10\beta_n$ 时为 1.68 → 1.52 V。在早期，$V_Y$ 可能会被某个漏极结短暂维持，因此它最初的变化方向取决于器件尺寸。
