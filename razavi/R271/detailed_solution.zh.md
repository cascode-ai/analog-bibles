# 详细步骤 - R271

**思路。** $C_1$ 把 PMOS $M_3$ 的 n 阱与 NMOS $M_1$ 的 p 型衬底连接起来。由于 $C_1$ 未充电，两个衬底的初始电位相同，这就在 $V_{DD}$ 与地之间打开了一条由两个正向偏置的 pn 结与 $C_1$ 串联构成的通路；这条通路给 $C_1$ 充电，并使两个晶体管的衬底暂时处于正向偏置。与此同时，正反馈环路 $M_1 \to M_3 \to M_2 \to M_1$ 发生锁定，使 $V_X$ 升到 $V_{DD}$，而 $V_Y$ 则随衬底偏置的恢复而变化。X 和 Y 的节点电容取为很小（X、Y 准静态变化），各个结用二极管建模（大电流时约为 0.7 V）。

### 第 1 步 — $t = 0$：正向偏置的结通路给 $C_1$ 充电

沿着从 $V_{DD}$ 到地的通路：

$$V_{DD} \xrightarrow{\ \text{p+ source of } M_3 \to \text{n-well}\ } \text{plus plate of } C_1 \xrightarrow{\ C_1\ } \text{p-bulk of } M_1 \xrightarrow{\ \text{p-bulk} \to \text{n+ source of } M_1\ } \text{ground}.$$

沿着这条通路，两个结都是“正向”的；由于 $V_{C1} = 0$，它们的正向电压之和等于全部电源电压：

$$V_{F3} + V_{F1} = V_{DD} - V_{C1} = 3\ \mathrm{V}.$$

公共衬底电位的初始值介于两者之间，对于特性相近的结，约在电源中点附近。每个结上约有 1.5 V 的正向偏置，**很大的电流**迅速给 $C_1$ 充电；一旦每个结恢复到正常的二极管压降，充电就变慢：

$$V_{C1} \approx V_{DD} - 2V_{D,on} \approx 3 - 2(0.7) = 1.6\ \mathrm{V}, \qquad V_{well} \approx 2.3\ \mathrm{V}, \qquad V_{B1} \approx 0.7\ \mathrm{V}.$$

此后，结电流随正向电压的减小而按指数规律衰减，$C_1$ **非常缓慢地趋向 $V_{DD}$**（阱 → 3 V，$M_1$ 的衬底 → 0）：对于指数型二极管，这是一个随时间按对数规律变化的拖尾（每十倍时间几十毫伏）。固定压降的二极管模型则简单地停在 1.6 V 附近；拖尾的具体形状取决于结模型和漏电。

其他结也可能短暂导通（若 $V_Y$ 比阱电压高 0.7 V，则 $M_3$ 的漏-阱结导通；若 $M_1$ 的衬底比 $V_Y$ 高 0.7 V，则 $M_1$ 的衬底-漏结导通）。它们在早期向 Y 注入电流或从 Y 抽取电流，有助于触发环路。

### 第 2 步 — 两个晶体管的衬底暂时处于正向偏置

在 $C_1$ 充电期间，$M_3$ 的阱电压**低于**其源极，$M_1$ 的衬底电压**高于**其源极：两者都是**衬底正向偏置**，它们会**降低**阈值电压的大小，使两个晶体管都比正常情况更强。对 NMOS 用 $V_{SB}$，对 PMOS 用 $V_{BS} = V_{well} - V_S$（负值表示正向偏置），有

$$V_{TH1} = 0.7 + 0.45\left(\sqrt{0.9 + V_{SB1}} - \sqrt{0.9}\right), \qquad |V_{TH3}| = 0.8 + 0.4\left(\sqrt{0.8 + V_{BS3}} - \sqrt{0.8}\right).$$

在最初的强正向偏置时刻，这些公式没有意义；一旦每个结的电压降到约 0.7 V 或更低，它们给出

$$
\begin{aligned}
V_{TH1} &= 0.7 + 0.45\left(\sqrt{0.9 - 0.7} - \sqrt{0.9}\right) = 0.7 + 0.45(0.447 - 0.949) = 0.47\ \mathrm{V},\\
|V_{TH3}| &= 0.8 + 0.4\left(\sqrt{0.8 - 0.7} - \sqrt{0.8}\right) = 0.8 + 0.4(0.316 - 0.894) = 0.57\ \mathrm{V}.
\end{aligned}
$$

随着 $C_1$ 向 $V_{DD}$ 充电，两者恢复到各自的标称值（0.7 V 和 0.8 V）。

### 第 3 步 — 环路锁定：$V_X \to V_{DD}$

$M_3$ 中的电流增大会使 $V_Y$ 降低；于是 $M_2$ 向 X 注入更多电流，而 X 只与 $M_2$ 的漏极和 $M_1$ 的栅极相连（**没有直流负载**）；X 升高，$M_1$ 导通得更强，使 $V_Y$ 进一步降低：这就是正反馈。

- **截止状态**（$V_X \le V_{TH1}$，没有电流）是一个直流解。
- 在**锁定状态**下，$M_2$ 导通但没有直流负载，因此其电流必须为零，对于导通的器件这意味着 $V_{SD2} = 0$：**$V_X = V_{DD}$**。于是 $M_1$ 的 $V_{GS1} = 3$ V，强烈导通，由 $M_3$ 提供其电流。

$t = 0$ 时流入和流出 Y 的结电流使 $M_3$（进而 $M_2$）导通，从而触发环路，因此 **$V_X$ 迅速升到 $V_{DD}$ 并保持不变**。（对于任意的初始节点电压和电容，并不能严格保证电路启动，但锁定状态是预期的结果。）

### 第 4 步 — $V_Y$ 的电平及其缓慢漂移

在锁定状态下，$M_3$（二极管连接，饱和）与 $M_1$（由于 $V_Y < V_{DD} - V_{TH1}$，处于线性区）流过相同的电流。节点 Y 的基尔霍夫电流定律（KCL）方程：

$$\frac{\beta_p}{2}\left(V_{DD} - V_Y - |V_{TH3}|\right)^2 = \beta_n\left[(V_{DD} - V_{TH1})V_Y - \tfrac12V_Y^2\right]. \tag{1}$$

**阈值电压恢复时，$V_Y$ 向哪个方向漂移？** 升高 $V_{TH1}$ 会削弱 $M_1$，使 $V_Y$ 趋于升高；升高 $|V_{TH3}|$ 会削弱 $M_3$，使 $V_Y$ 趋于降低。对 (1) 求微分，并利用 (1) 本身把 $\beta_p(V_{DD} - V_Y - |V_{TH3}|)$ 替换为 $\beta_nV_Y[2(V_{DD} - V_{TH1}) - V_Y]/(V_{DD} - V_Y - |V_{TH3}|)$：

$$dV_Y = \frac{\beta_nV_Y}{D}\left[dV_{TH1} - \frac{2(V_{DD} - V_{TH1}) - V_Y}{V_{DD} - V_Y - |V_{TH3}|}\,d|V_{TH3}|\right], \qquad D = \beta_p(V_{DD} - V_Y - |V_{TH3}|) + \beta_n(V_{DD} - V_{TH1} - V_Y) > 0 .$$

乘在 $d|V_{TH3}|$ 前面的分式大于 1，因为 $2(V_{DD} - V_{TH1}) - V_Y - (V_{DD} - V_Y - |V_{TH3}|) = V_{DD} - 2V_{TH1} + |V_{TH3}| > 0$。两个结串联、流过相同的电流，因此（对于特性相近的结）它们的正向电压以相同的速率恢复，而且 PMOS 的阈值电压甚至更敏感一些：在 0.7 V 正向偏置下，$dV_{TH}/dV_F = 0.4/(2\sqrt{0.1}) = 0.63$，而 NMOS 为 $0.45/(2\sqrt{0.2}) = 0.50$。因此 $d|V_{TH3}| \gtrsim dV_{TH1}$，方括号内的量为负：**$V_Y$ 缓慢下降**，因为饱和的 $M_3$ 的电流 $\propto$ 过驱动电压（overdrive voltage）的平方，其减弱程度超过了处于线性区的 $M_1$。

**示例**（用缓慢拖尾开始和结束时的阈值电压求解 (1)）：

- $\beta_p = \beta_n$，早期（$V_{TH1} = 0.47$，$|V_{TH3}| = 0.57$ V）：$\tfrac12(2.43 - V_Y)^2 = 2.53V_Y - \tfrac12V_Y^2$，即 $V_Y^2 - 4.96V_Y + 2.95 = 0$，因此 $V_Y = 0.69$ V。最终（0.7 V，0.8 V）：$V_Y^2 - 4.5V_Y + 2.42 = 0$，因此 $V_Y = 0.62$ V。
- $\beta_p = 10\beta_n$：早期，由 $5.5V_Y^2 - 26.84V_Y + 29.55 = 0$ 得 $V_Y = 1.68$ V；最终，由 $5.5V_Y^2 - 24.3V_Y + 24.2 = 0$ 得 $V_Y = 1.52$ V。

在非常早期、正向偏置尚未稳定时，$V_Y$ 可能会被某个导通的漏极结短暂维持，因此它最初的变化方向取决于器件尺寸。

### 结果

- **$C_1$** 把 $M_3$ 的 n 阱与 $M_1$ 的 p 型衬底连接起来。在 $t = 0$ 时，两个衬底处于相同电位，通路 $V_{DD}$ →（$M_3$ 的源-阱结）→ $C_1$ →（$M_1$ 的衬底-源结）→ 地处于正向偏置。很大的电流把 $C_1$ 迅速充电到约 $V_{DD} - 2V_{D,on} \approx 1.6$ V（阱 ≈ $V_{DD} - 0.7$ V，$M_1$ 的衬底 ≈ +0.7 V）。此后结电流衰减，$C_1$ 非常缓慢地趋向 $V_{DD}$（固定压降模型则停在 1.6 V 附近）。
- 在此期间，**两个晶体管的衬底都处于正向偏置**：$|V_{TH3}|$ 和 $V_{TH1}$ 降低（0.7 V 正向偏置下分别 ≈ 0.57 V 和 ≈ 0.47 V），随着 $C_1$ 充电，它们恢复到 0.8 V 和 0.7 V。
- **$V_X$ 几乎立即升到 $V_{DD}$ 并保持不变**：结电流触发正反馈环路 $M_1$–$M_3$–$M_2$，$M_2$ 把 X（没有直流负载）拉到 $V_{DD}$。
- **$V_Y$ 稳定在 $M_3$ 与 $M_1$ 的平衡点上**，即 $\tfrac{\beta_p}{2}(V_{DD} - V_Y - |V_{TH3}|)^2 = \beta_n[(V_{DD} - V_{TH1})V_Y - V_Y^2/2]$，并在 $C_1$ 充电期间**缓慢下降**（例如 $\beta_p = \beta_n$ 时 ≈ 0.69 → 0.62 V，$\beta_p = 10\beta_n$ 时 1.68 → 1.52 V）。

**常见错误。** 把 $C_1$ 当作接在 Y、X 或地上。它接在两个衬底端之间，因此是由结（二极管）电流而不是沟道电流充电的，并且只通过体效应影响晶体管。

**常见错误。** 以为“没有晶体管驱动它”，因而 $C_1$ 保持在 0 V。在 $t = 0$ 时，两个串联的衬底结构成一条跨接在全部电源电压上的正向偏置二极管通路，因此 $C_1$ 立即开始充电。

**常见错误。** 让 $V_X$ 稳定在某个中间的镜像电压上。X 没有直流负载，因此只要 $M_2$ 有一点导通，X 就会升到 $V_{DD}$，环路发生锁定。
