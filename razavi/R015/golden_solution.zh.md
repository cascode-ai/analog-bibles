$V_{GS} = V_X$。低于 0.7 V 时 $I_X = 0$，随后按平方律（square law）上升，此时器件处于饱和区（saturation region），直到 $I_X$ 超过 $I_1 + V_{TH}/R_1$；此后 $M_1$ 进入线性区（triode region），$I_X$ 继续上升，但更为平缓。$g_m$ 先为零，然后线性上升，在线性区则服从 $g_m = \beta V_D$：通常它在饱和区/线性区边界处达到峰值，然后下降；但若 $\beta R_1 u_B < 1$，它会继续上升（更缓慢地趋向 $1/R_1$），其中 $u_B = \sqrt{2(I_1 + 0.7/R_1)/\beta}$。
- 漏极节点：$I_1 = I_X + (V_D - V_X)/R_1$，因此 $V_D = V_X + R_1(I_1 - I_X)$。
- $V_X < 0.7$ V：$M_1$ 截止，$I_X = 0$，$g_m = 0$；$I_1$ 经 $R_1$ 流入 $V_X$ 电源（$V_D = V_X + I_1R_1$，假设它低于 3 V）。
- $V_X > 0.7$ V，饱和区：$I_X = \tfrac12\beta(V_X - 0.7)^2$，$g_m = \beta(V_X - 0.7)$。饱和要求 $V_D > V_X - V_{TH}$，即 $I_X < I_1 + V_{TH}/R_1$；边界位于 $V_{X1} = 0.7 + \sqrt{2(I_1 + 0.7/R_1)/\beta}$。注意 $I_X$ 可以超过 $I_1$：多出的电流来自 $V_X$，经 $R_1$ 流入。
- $V_X > V_{X1}$：线性区，$I_X = I_1 + (V_X - V_D)/R_1$ 继续增大（不再按二次函数规律；一旦 $V_D$ 变小，斜率就趋于 $1/R_1$），而 $g_m = \beta V_D$。在线性区，$dV_D/dV_X = (1/R_1 - \beta V_D)/[1/R_1 + \beta(V_X - 0.7 - V_D)]$，因此 $V_D$ 趋于 $1/(\beta R_1)$，$g_m$ 趋于 $1/R_1$：若 $\beta R_1 u_B > 1$（通常情况），$g_m$ 在边界处达到峰值，然后下降；若 $\beta R_1 u_B < 1$，它会继续上升，但更缓慢地趋向 $1/R_1$（例如 β = 1 mA/V²，$I_1$ = 0.1 mA，$R_1$ = 500 Ω：$V_{X1}$ = 2.43 V，到 $V_X$ = 3 V 时 $g_m$ 从 1.73 上升到 1.79 mS）。
