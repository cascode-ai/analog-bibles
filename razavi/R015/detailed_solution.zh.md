# 详细步骤 - R015

**思路。** 栅极直接由 $V_X$ 驱动，源极接地，因此始终有 $V_{GS} = V_X$。漏极电压由漏极节点的基尔霍夫电流定律（KCL）决定，$I_1$、$R_1$ 中的电流和 $I_X$ 在该节点汇合。由 KCL 求出 $V_D$，据此判断 $M_1$ 何时离开饱和区，并描述各工作区中的 $I_X$ 和 $g_m$。

### 第 1 步 — 漏极节点的 KCL

源极和衬底都接地，因此没有体效应（body effect），$V_{TH} = 0.7$ V，并且

$$V_{GS} = V_X, \qquad V_{DS} = V_D .$$

在漏极节点，$I_1$ 和 $R_1$ 中的电流 $(V_X - V_D)/R_1$ 流入，$I_X$ 流出并进入 $M_1$：

$$I_X = I_1 + \frac{V_X - V_D}{R_1} \quad\Longleftrightarrow\quad V_D = V_X + R_1\,(I_1 - I_X).$$

所以 $I_X$ **可以超过 $I_1$**：多出的电流由 $V_X$ 经 $R_1$ 提供（此时 $V_D < V_X$）。

### 第 2 步 — $V_X < 0.7$ V：$M_1$ 截止

$V_{GS} = V_X < V_{TH}$，因此 $I_X = 0$，$g_m = 0$。$I_1$ 全部经 $R_1$ 流入 $V_X$ 电源，且

$$V_D = V_X + I_1R_1 ,$$

这里假设 $V_X + I_1R_1 < V_{DD}$，使电流源 $I_1$ 有足够的电压空间正常工作。

### 第 3 步 — 刚超过 0.7 V：饱和区，按平方律上升

起初漏极电位较高（$V_D \approx V_X + I_1R_1$），远高于 $V_{GS} - V_{TH}$，因此 $M_1$ 处于饱和区：

$$I_X = \tfrac12\beta\,(V_X - 0.7)^2, \qquad g_m = \beta\,(V_X - 0.7).$$

$I_X$ 是一条从 0.7 V 处的零开始的抛物线，$g_m$ 是一条从零开始的直线；只要 $M_1$ 保持饱和，两者都与 $R_1$ 和 $I_1$ 无关。

### 第 4 步 — 饱和区/线性区边界

饱和要求 $V_{DS} \ge V_{GS} - V_{TH}$；代入第 1 步的 $V_D$：

$$
\begin{aligned}
V_X + R_1(I_1 - I_X) &\ge V_X - 0.7\\
R_1(I_1 - I_X) &\ge -0.7\\
I_X &\le I_1 + \frac{0.7\ \mathrm{V}}{R_1}.
\end{aligned}
$$

所以当 $M_1$ 的电流超过 $I_1 + V_{TH}/R_1$ 时，它离开饱和区，此时漏极被拉低到 $V_D = V_X - V_{TH}$。令平方律电流等于这一极限：

$$
\begin{aligned}
\tfrac12\beta\,(V_{X1} - 0.7)^2 &= I_1 + \frac{0.7}{R_1}\\
V_{X1} &= 0.7 + u_B, \qquad u_B = \sqrt{\frac{2\,(I_1 + 0.7/R_1)}{\beta}} ,
\end{aligned}
$$

其中 $u_B$ 是边界处的过驱动电压（overdrive voltage）。若 $V_{X1} > 3$ V，器件在整个扫描范围内都保持饱和。

### 第 5 步 — 高于 $V_{X1}$：线性区

当 $V_X > V_{X1}$ 时，

$$I_X = \beta\left[(V_X - 0.7)V_D - \tfrac12V_D^2\right], \qquad I_X = I_1 + \frac{V_X - V_D}{R_1},$$

两式共同确定 $V_D$（一个二次方程）。$I_X$ **继续增大**，但不再按二次函数规律：随着 $V_D$ 变小，额外的电流受 $R_1$ 限制，斜率趋于 $1/R_1$。

**$V_D$（从而 $g_m$）如何变化。** 把合并后的 KCL 方程 $\beta[(V_X - 0.7)V_D - \tfrac12V_D^2] - I_1 - (V_X - V_D)/R_1 = 0$ 对 $V_X$ 求导：

$$
\begin{aligned}
\beta V_D + \beta\,(V_X - 0.7 - V_D)\frac{dV_D}{dV_X} - \frac{1}{R_1} + \frac{1}{R_1}\frac{dV_D}{dV_X} &= 0\\
\frac{dV_D}{dV_X}\left[\frac{1}{R_1} + \beta\,(V_X - 0.7 - V_D)\right] &= \frac{1}{R_1} - \beta V_D\\
\frac{dV_D}{dV_X} &= \frac{1/R_1 - \beta V_D}{1/R_1 + \beta\,(V_X - 0.7 - V_D)} .
\end{aligned}
$$

分母为正（在线性区 $V_X - 0.7 > V_D$）。在线性区 $g_m = \beta V_{DS} = \beta V_D$，因此当 $\beta V_D > 1/R_1$ 时 $V_D$ 下降，当 $\beta V_D < 1/R_1$ 时则上升：**$g_m = \beta V_D$ 趋向 $1/R_1$**。边界处 $V_D = u_B$，因此 $g_m = \beta u_B$。于是：

- 若 $\beta R_1u_B > 1$（通常情况），$g_m$ **在边界处达到峰值，然后下降**，趋向 $1/R_1$；
- 若 $\beta R_1u_B < 1$，$g_m$ **继续上升**，但更缓慢地趋向 $1/R_1$。

另外，由于 $dV_D/dV_X < 1$，$dI_X/dV_X = (1 - dV_D/dV_X)/R_1 > 0$：$I_X$ 始终上升。

### 第 6 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$I_1 = 0.5$ mA，$R_1 = 2\ \mathrm{k\Omega}$。

**边界：**

$$
\begin{aligned}
I_1 + \frac{0.7\ \mathrm{V}}{R_1} &= 0.5\ \mathrm{mA} + 0.35\ \mathrm{mA} = 0.85\ \mathrm{mA},\\
u_B &= \sqrt{\frac{2\times0.85\ \mathrm{mA}}{1\ \mathrm{mA/V^2}}} = \sqrt{1.7\ \mathrm{V^2}} = 1.304\ \mathrm{V},\\
V_{X1} &= 0.7 + 1.304 = 2.00\ \mathrm{V},\\
\beta R_1u_B &= (1\ \mathrm{mA/V^2})(2\ \mathrm{k\Omega})(1.304\ \mathrm{V}) = 2.6 > 1 .
\end{aligned}
$$

所以 $g_m$ 在 $V_X = 2.0$ V 处达到峰值（$\beta u_B = 1.30$ mS），然后向 $1/R_1 = 0.5$ mS 下降。

**线性区中的一点，$V_X = 2.5$ V**（$V_{ov} = 1.8$ V）：

$$(1\ \mathrm{mA/V^2})\left[1.8V_D - \tfrac12V_D^2\right] = 0.5\ \mathrm{mA} + \frac{2.5 - V_D}{2\ \mathrm{k\Omega}} .$$

以 mA 和 V 为单位：$1.8V_D - 0.5V_D^2 = 0.5 + 1.25 - 0.5V_D$，即 $0.5V_D^2 - 2.3V_D + 1.75 = 0$，因此

$$V_D = \frac{2.3 - \sqrt{2.3^2 - 4(0.5)(1.75)}}{2(0.5)} = 2.3 - \sqrt{5.29 - 3.5} = 2.3 - 1.338 = 0.962\ \mathrm{V}$$

（另一个根 3.64 V 不在线性区）。于是 $I_X = 0.5 + (2.5 - 0.962)/2 = 1.269$ mA，$g_m = (1\ \mathrm{mA/V^2})(0.962\ \mathrm{V}) = 0.96$ mS。

| $V_X$ (V) | 工作区 | $V_D$ (V) | $I_X$ (mA) | $g_m$ (mS) |
|---|---|---|---|---|
| 0 – 0.7 | 截止 | $V_X + 1$ | 0 | 0 |
| 1.0 | 饱和区 | 1.91 | 0.045 | 0.30 |
| 1.5 | 饱和区 | 1.86 | 0.320 | 0.80 |
| 2.0 | 边界 | 1.30 | 0.85 | 1.30 |
| 2.25 | 线性区 | 1.07 | 1.09 | 1.07 |
| 2.5 | 线性区 | 0.96 | 1.27 | 0.96 |
| 3.0 | 线性区 | 0.84 | 1.58 | 0.84 |

饱和区中的一行，以 $V_X = 1.5$ V 为例：$I_X = \tfrac12(1\ \mathrm{mA/V^2})(0.8\ \mathrm{V})^2 = 0.32$ mA，$V_D = 1.5 + 2(0.5 - 0.32) = 1.86$ V $> V_{ov} = 0.8$ V ✓。大约从 $V_X = 1.7$ V 起，$I_X$ 超过 $I_1 = 0.5$ mA；多出的部分从 $V_X$ 经 $R_1$ 流入。

**相反的情形**（$\beta R_1u_B < 1$）：取 $\beta = 1\ \mathrm{mA/V^2}$，$I_1 = 0.1$ mA，$R_1 = 500\ \Omega$，则 $u_B = \sqrt{2(0.1 + 1.4)} = 1.73$ V，$V_{X1} = 2.43$ V，$\beta R_1u_B = 0.87 < 1$。此时 $g_m$ 从边界处的 1.73 mS 上升到 $V_X = 3$ V 时的约 1.79 mS，趋向 $1/R_1 = 2$ mS。

### 结果

$V_{GS} = V_X$，由漏极节点的 KCL 得 $V_D = V_X + R_1(I_1 - I_X)$。

- **$V_X < 0.7$ V：** $M_1$ 截止，$I_X = 0$，$g_m = 0$；$I_1$ 经 $R_1$ 流入 $V_X$ 电源。
- **$0.7\ \mathrm{V} < V_X < V_{X1}$：** 饱和区，$I_X = \tfrac12\beta(V_X - 0.7)^2$（按平方律上升），$g_m = \beta(V_X - 0.7)$（线性上升）。
- **边界：** 当 $I_X$ 超过 $I_1 + V_{TH}/R_1$（等价地，$V_D < V_X - V_{TH}$）时，$M_1$ 进入线性区，边界位于 $V_{X1} = 0.7 + u_B$，其中 $u_B = \sqrt{2(I_1 + 0.7/R_1)/\beta}$。
- **$V_X > V_{X1}$：** 线性区。$I_X = I_1 + (V_X - V_D)/R_1$ 继续上升，但更平缓，斜率趋于 $1/R_1$。$g_m = \beta V_D$ 趋向 $1/R_1$：通常（$\beta R_1u_B > 1$）它**在边界处达到峰值，然后下降**；若 $\beta R_1u_B < 1$，它会继续缓慢上升，趋向 $1/R_1$。

**常见错误。** 认为 $I_X$ 的上限是 $I_1$。$R_1$ 把漏极接到 $V_X$，因此一旦 $V_D$ 降到 $V_X$ 以下，电流就会从 $V_X$ 经 $R_1$ 流入漏极，$I_X$ 便会超过 $I_1$。

**常见错误。** 把平方律一直用到 3 V。随着 $I_X$ 增大，漏极被拉低，最终降到 $V_X - V_{TH}$ 以下；此后应使用线性区方程和 $g_m = \beta V_D$。

**常见错误。** 把 $V_{GS}$ 取为 $V_X$ 以外的值（例如减去 $R_1$ 上的压降）。栅极直接接 $V_X$，源极接地；$R_1$ 只影响漏极电压。
