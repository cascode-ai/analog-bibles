考虑 [图 1] 所示的共源级（common-source stage），其中电流源（current source）$I_1$ 由工作在饱和区（saturation region）的 PMOS 晶体管 $M_2$ 实现（源极接 $V_{DD}$，栅极接固定的偏置电压），其 $(W/L)_2 = 162.8/0.5$，即宽长比（aspect ratio）约为 325，这样选择是为了使它在 1 mA 下的过驱动电压（overdrive voltage）为 0.4 V。假设 $(W/L)_1 = 50/0.5$（以微米为单位的有效尺寸），$I_{D1} = 1$ mA，$R_S = 1\ \mathrm{k\Omega}$。求该电路的极点和零点，要计入 $M_1$ 的电容（$C_{GS1}$、$C_{GD1}$、$C_{DB1}$）以及 $M_2$ 中作为输出负载的电容。

器件参数：NMOS 的 $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$\lambda = 0.1\ \mathrm{V^{-1}}$，交叠电容（overlap capacitance）$0.4\ \mathrm{fF/\mu m}$（栅源和栅漏各一份），$C_j = 0.56\ \mathrm{fF/\mu m^2}$，$C_{jsw} = 0.35\times10^{-11}$ F/m；PMOS 的 $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$\lambda = 0.2\ \mathrm{V^{-1}}$，交叠电容 $0.3\ \mathrm{fF/\mu m}$，$C_j = 0.94\ \mathrm{fF/\mu m^2}$，$C_{jsw} = 0.32\times10^{-11}$ F/m；两者都有 $C_{ox} = 3.84\ \mathrm{fF/\mu m^2}$。漏区取为 $W \times E$，其中 $E = 1.5\ \mu$m（四条边都计为侧壁），并采用零偏结电容（junction capacitance）。
