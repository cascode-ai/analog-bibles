# Golden Solution - R239

## Reference answer

$|A_v| = \dfrac{g_{m1}}{2}\,[(2r_{O2})\,\|\,r_{O4}] \approx 20.7$ (noninverting from the gate of $M_1$ to $V_{out}$).

- Each input device carries 0.25 mA: $g_{m1} = g_{m2} = \sqrt{2(134\ \mu)(100)(0.25\ \mathrm{m})} = 2.59$ mS; $r_{O2} = 1/(0.1\times0.25\ \mathrm{mA}) = 40$ kΩ; $M_4$ carries $I_1 = 0.25$ mA: $r_{O4} = 1/(0.2\times0.25\ \mathrm{mA}) = 20$ kΩ.
- $G_m$: with the output shorted, the pair is symmetric and only $M_2$'s half of the signal current reaches the output ($M_1$'s drain goes to $V_{DD}$; $M_4$ is a fixed current source): $G_m = g_{m1}/2$.
- $R_{out}$: $M_2$ is degenerated by the source impedance of $M_1$, giving $2r_{O2}$ (exactly, even with body effect, for matched devices), in parallel with $r_{O4}$: $80\ \mathrm{k}\Omega\,\|\,20\ \mathrm{k}\Omega = 16$ kΩ.
- $|A_v| = 1.29\ \mathrm{mS}\times 16\ \mathrm{k}\Omega \approx 20.7$.
