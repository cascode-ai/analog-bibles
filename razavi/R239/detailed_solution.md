# Detailed solution - R239

**Approach.** Use $|A_v| = G_mR_{out}$, with $G_m$ the transconductance with $V_{out}$ at ac ground and $R_{out}$ the output resistance with the input at zero. Two observations drive the result: (i) $M_3$–$M_4$ is driven by the fixed current $I_1$, so $M_4$ is only a current-source load; (ii) $M_1$'s drain goes straight to $V_{DD}$, so only the half of the signal current in $M_2$ reaches the output. A direct nodal analysis confirms the result.

### Step 1 — Bias currents and small-signal parameters

$M_4$ copies $I_1$, so $I_{D4} = 0.25$ mA; with no external load, $I_{D2} = I_{D4} = 0.25$ mA, and $I_{D1} = I_{SS} - I_{D2} = 0.25$ mA (balanced, since $I_{SS} = 2I_1$). With $W/L = 50/0.5 = 100$:

$$g_{m1} = g_{m2} = \sqrt{2\mu_nC_{ox}\frac{W}{L}I_D} = \sqrt{2(134\ \mu\mathrm{A/V^2})(100)(0.25\ \mathrm{mA})} = \sqrt{6.70\times10^{-6}}\ \mathrm{A/V} = 2.59\ \mathrm{mS},$$

$$r_{O1} = r_{O2} = \frac{1}{\lambda_nI_D} = \frac{1}{(0.1\ \mathrm{V^{-1}})(0.25\ \mathrm{mA})} = 40\ \mathrm{k}\Omega, \qquad r_{O4} = \frac{1}{\lambda_pI_D} = \frac{1}{(0.2\ \mathrm{V^{-1}})(0.25\ \mathrm{mA})} = 20\ \mathrm{k}\Omega .$$

In the small-signal circuit $V_{DD}$ is ac ground and $I_{SS}$ is open. The gate of $M_3$, biased by the ideal $I_1$, carries no signal, so $v_{gs4} = 0$ and $M_4$ reduces to $r_{O4}$ from the output to ac ground.

### Step 2 — Short-circuit transconductance $G_m$

With $V_{out}$ shorted to ac ground, both drains are at ac ground and the pair is symmetric. For $\pm v_{in}/2$ on the gates, P does not move, so

$$i_{D1} = g_{m1}\frac{v_{in}}{2}, \qquad i_{D2} = -g_{m2}\frac{v_{in}}{2} .$$

The current of $M_1$ goes into $V_{DD}$ and is lost. $M_2$ draws $i_{D2}$ out of the output node, so the current delivered into the short is

$$i_{out} = -i_{D2} = \frac{g_{m2}}{2}v_{in} \quad\Longrightarrow\quad G_m = \frac{g_{m1}}{2} = \frac{2.59\ \mathrm{mS}}{2} = 1.29\ \mathrm{mS} .$$

(In the five-transistor OTA the mirror copies $M_1$'s signal current to the output and $G_m = g_{m1}$; here $M_3$ is fed by $I_1$, so that half is wasted.)

### Step 3 — Output resistance $R_{out}$

With both gates at ac ground, the output sees $r_{O4}$ in parallel with the path through $M_2$, whose source is degenerated by the resistance looking into the source of $M_1$.

**Looking into the source of $M_1$** (gate and drain at ac ground): a voltage $v_s$ at P drives $g_{m1}v_s$ through the controlled source and $v_s/r_{O1}$ through $r_{O1}$, so

$$i = g_{m1}v_s + \frac{v_s}{r_{O1}} \quad\Longrightarrow\quad R_S = \frac{v_s}{i} = \frac{r_{O1}}{1 + g_{m1}r_{O1}} .$$

**Looking into the drain of $M_2$** with source resistance $R_S$: a test current $i_t$ gives $v_P = i_tR_S$, $v_{gs2} = -i_tR_S$, and a current $i_t - g_{m2}v_{gs2} = i_t(1 + g_{m2}R_S)$ in $r_{O2}$, so

$$v_t = i_t(1 + g_{m2}R_S)r_{O2} + i_tR_S \quad\Longrightarrow\quad R_{D2} = r_{O2} + (1 + g_{m2}r_{O2})R_S .$$

With matched devices ($g_{m1} = g_{m2}$, $r_{O1} = r_{O2} = r_O$):

$$R_{D2} = r_O + (1 + g_mr_O)\frac{r_O}{1 + g_mr_O} = r_O + r_O = 2r_O = 80\ \mathrm{k}\Omega .$$

The factor $(1 + g_mr_O)$ cancels exactly (also with body effect, since both $R_S$ and the degeneration factor then contain $g_m + g_{mb}$). So

$$R_{out} = R_{D2}\,\|\,r_{O4} = (2r_{O2})\|r_{O4} = \frac{80\times20}{80 + 20}\ \mathrm{k}\Omega = 16\ \mathrm{k}\Omega .$$

### Step 4 — Voltage gain

$$|A_v| = G_mR_{out} = \frac{g_{m1}}{2}\left[(2r_{O2})\|r_{O4}\right] = (1.29\ \mathrm{mS})(16\ \mathrm{k}\Omega) = 20.7 .$$

If the gate of $M_1$ rises relative to that of $M_2$, $M_2$ pulls less current from the output and $V_{out}$ rises: the gain is **noninverting** from the gate of $M_1$ ($V_{in} = V_{G1} - V_{G2}$).

### Step 5 — Check by direct nodal analysis

With gate voltages $v_1$, $v_2$ and unknowns $v_P$, $v_{out}$, the drain-to-source currents are

$$i_1 = g_m(v_1 - v_P) - \frac{v_P}{r_O}, \qquad i_2 = g_m(v_2 - v_P) + \frac{v_{out} - v_P}{r_O} .$$

KCL at P (tail open), $i_1 + i_2 = 0$, and at the output, $-v_{out}/r_{O4} = i_2$, give

$$v_{out} = \frac{g_mr_Or_{O4}}{2r_O + r_{O4}}(v_1 - v_2) = \frac{g_m}{2}\cdot\frac{2r_O\,r_{O4}}{2r_O + r_{O4}}(v_1 - v_2) = \frac{g_m}{2}\left[(2r_O)\|r_{O4}\right]v_{in},$$

exactly the result above; a common-mode change ($v_1 = v_2$) produces no output.

### Result

$$A_v = \frac{V_{out}}{V_{in}} = +\frac{g_{m1}}{2}\left[(2r_{O2})\,\|\,r_{O4}\right] = (1.29\ \mathrm{mS})(80\ \mathrm{k}\Omega\,\|\,20\ \mathrm{k}\Omega) \approx 20.7,$$

noninverting from the gate of $M_1$, with $g_{m1} = 2.59$ mS, $r_{O2} = 40\ \mathrm{k}\Omega$ and $r_{O4} = 20\ \mathrm{k}\Omega$.

**Common mistake.** Using the five-transistor-OTA formula $g_{m1}(r_{O2}\|r_{O4}) \approx 34.5$. Here the PMOS mirror is driven by the fixed $I_1$, so $M_1$'s signal current is dumped into $V_{DD}$ and $G_m$ is only $g_{m1}/2$.

**Common mistake.** Taking $R_{out} = r_{O2}\|r_{O4}$ (≈ 13.3 kΩ). The source of $M_2$ is degenerated by $r_{O1}/(1 + g_{m1}r_{O1})$, which doubles the $M_2$ path to $2r_{O2}$.

**Common mistake.** Swapping the $\lambda$ values (0.1 V⁻¹ is NMOS, 0.2 V⁻¹ PMOS), or writing the gain as $g_{m1}r_{O2} \approx 104$, which ignores the load $M_4$.
