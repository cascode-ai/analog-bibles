# Detailed solution - R239

**Approach.** Use $|A_v| = G_mR_{out}$. Here $G_m$ is the short-circuit transconductance (output current per input volt with $V_{out}$ held at ac ground) and $R_{out}$ is the output resistance with the input set to zero. The key observations are: (i) the PMOS "mirror" $M_3$–$M_4$ is driven by the fixed current $I_1$, so $M_4$ is only a current-source load and carries no signal; (ii) $M_1$'s drain goes straight to $V_{DD}$, so only the half of the signal current that flows in $M_2$ reaches the output. Finally we confirm the result with a direct nodal analysis.

### Step 1 — Reading the circuit and the bias currents

- $M_1$, $M_2$: NMOS differential pair, sources at P, tail $I_{SS} = 0.5$ mA. The input $V_{in}$ is applied between the gates of $M_1$ and $M_2$.
- The drain of $M_1$ is tied to $V_{DD}$. The drain of $M_2$ is the output.
- $M_3$: diode-connected PMOS biased by the ideal current source $I_1 = 0.25$ mA. $M_4$ (same size as $M_3$, same $V_{SG}$) is the load of $M_2$.

**Bias currents.** $M_4$ copies $I_1$: $I_{D4} = 0.25$ mA. With no external load at $V_{out}$, KCL there gives $I_{D2} = I_{D4} = 0.25$ mA, and KCL at P gives $I_{D1} = I_{SS} - I_{D2} = 0.25$ mA. The pair is balanced ($I_{SS} = 2I_1$).

**Small-signal parameters** ($W/L = 50/0.5 = 100$ for all):

$$g_{m1} = g_{m2} = \sqrt{2\mu_nC_{ox}\frac{W}{L}I_D} = \sqrt{2(134\ \mu\mathrm{A/V^2})(100)(0.25\ \mathrm{mA})} = \sqrt{6.70\times10^{-6}}\ \mathrm{A/V} = 2.59\ \mathrm{mS},$$

$$r_{O1} = r_{O2} = \frac{1}{\lambda_nI_D} = \frac{1}{(0.1\ \mathrm{V^{-1}})(0.25\ \mathrm{mA})} = 40\ \mathrm{k}\Omega,$$

$$r_{O4} = \frac{1}{\lambda_pI_D} = \frac{1}{(0.2\ \mathrm{V^{-1}})(0.25\ \mathrm{mA})} = 20\ \mathrm{k}\Omega .$$

**Small-signal rules.** $V_{DD}$ is ac ground. The ideal $I_{SS}$ is an open circuit. $M_3$ is biased by the ideal source $I_1$, so its gate voltage carries no signal; hence $v_{gs4} = 0$ and $M_4$ reduces to $r_{O4}$ from the output to ac ground.

### Step 2 — Short-circuit transconductance $G_m$

Short $V_{out}$ to ac ground. Now both drains are at ac ground ($M_1$'s at $V_{DD}$, $M_2$'s at the short), so the circuit seen by the pair is perfectly symmetric. Apply $+v_{in}/2$ to the gate of $M_1$ and $-v_{in}/2$ to the gate of $M_2$.

By symmetry (equal and opposite changes in the two halves), P does not move: $v_P = 0$. Then

$$i_{D1} = g_{m1}\frac{v_{in}}{2}, \qquad i_{D2} = -g_{m2}\frac{v_{in}}{2} .$$

The current of $M_1$ goes into $V_{DD}$ and is lost. Only $i_{D2}$ flows at the output node. $M_2$ draws $i_{D2}$ *out* of the output node, so the current delivered *into* the short is $-i_{D2}$:

$$i_{out} = -i_{D2} = \frac{g_{m2}}{2}v_{in} \quad\Longrightarrow\quad G_m = \frac{g_{m1}}{2} = \frac{2.59\ \mathrm{mS}}{2} = 1.29\ \mathrm{mS} .$$

Compare the five-transistor OTA: there the current mirror copies $M_1$'s signal current to the output and $G_m = g_{m1}$. Here $M_3$ is fed by $I_1$, not by $M_1$, so that half of the signal is wasted.

### Step 3 — Output resistance $R_{out}$

Set $v_{in} = 0$ (both gates at ac ground) and look into the output node. Two paths connect it to ac ground:

- $r_{O4}$, through the load $M_4$;
- $M_2$, whose source is degenerated by whatever is seen looking into the source of $M_1$.

**Resistance looking into the source of $M_1$** (gate and drain at ac ground). Apply $v_s$ at P and find the current $i$ flowing out of P into $M_1$. Through $M_1$ from source to drain: the controlled source gives $-g_{m1}v_{gs1} = g_{m1}v_s$, and $r_{O1}$ gives $v_s/r_{O1}$:

$$i = g_{m1}v_s + \frac{v_s}{r_{O1}} \quad\Longrightarrow\quad R_S = \frac{v_s}{i} = \frac{r_{O1}}{1 + g_{m1}r_{O1}} .$$

**Resistance looking into the drain of $M_2$** with source resistance $R_S$ (degenerated device). A test current $i_t$ into the drain flows through $R_S$, so $v_P = i_tR_S$ and $v_{gs2} = -i_tR_S$. KVL along the device: the drop across $r_{O2}$ is the current in $r_{O2}$, $i_t - g_{m2}v_{gs2} = i_t(1 + g_{m2}R_S)$, times $r_{O2}$, plus $v_P$:

$$v_t = i_t(1 + g_{m2}R_S)r_{O2} + i_tR_S \quad\Longrightarrow\quad R_{D2} = r_{O2} + (1 + g_{m2}r_{O2})R_S .$$

**Insert $R_S$.** With matched devices ($g_{m1} = g_{m2}$, $r_{O1} = r_{O2} = r_O$):

$$R_{D2} = r_O + (1 + g_mr_O)\frac{r_O}{1 + g_mr_O} = r_O + r_O = 2r_O = 80\ \mathrm{k}\Omega .$$

The factor $(1 + g_mr_O)$ cancels exactly. (It also cancels if body effect is included, because both $R_S$ and the degeneration factor then contain the same $g_m + g_{mb}$.)

**Output resistance:**

$$R_{out} = R_{D2}\,\|\,r_{O4} = (2r_{O2})\|r_{O4} = \frac{80\times20}{80 + 20}\ \mathrm{k}\Omega = 16\ \mathrm{k}\Omega .$$

### Step 4 — Voltage gain

$$|A_v| = G_mR_{out} = \frac{g_{m1}}{2}\left[(2r_{O2})\|r_{O4}\right] = (1.29\ \mathrm{mS})(16\ \mathrm{k}\Omega) = 20.7 .$$

**Sign.** If the gate of $M_1$ rises relative to that of $M_2$, $M_2$ conducts less and pulls less current from the output, so $V_{out}$ rises. The gain is **noninverting** from the gate of $M_1$ ($V_{in} = V_{G1} - V_{G2}$).

### Step 5 — Check by direct nodal analysis

Unknowns $v_P$ and $v_{out}$, with gate voltages $v_1$, $v_2$. Drain-to-source currents:

$$i_1 = g_m(v_1 - v_P) - \frac{v_P}{r_O}, \qquad i_2 = g_m(v_2 - v_P) + \frac{v_{out} - v_P}{r_O} .$$

KCL at P (tail open): $i_1 + i_2 = 0$. KCL at the output (current from $r_{O4}$ equals $i_2$): $-v_{out}/r_{O4} = i_2$. Solving these two linear equations gives

$$v_{out} = \frac{g_mr_Or_{O4}}{2r_O + r_{O4}}(v_1 - v_2) = \frac{g_m}{2}\cdot\frac{2r_O\,r_{O4}}{2r_O + r_{O4}}(v_1 - v_2) = \frac{g_m}{2}\left[(2r_O)\|r_{O4}\right]v_{in},$$

exactly the result above. It also shows that a common-mode change ($v_1 = v_2$) produces no output.

### Result

$$A_v = \frac{V_{out}}{V_{in}} = +\frac{g_{m1}}{2}\left[(2r_{O2})\,\|\,r_{O4}\right] = (1.29\ \mathrm{mS})(80\ \mathrm{k}\Omega\,\|\,20\ \mathrm{k}\Omega) \approx 20.7,$$

noninverting from the gate of $M_1$, with $g_{m1} = 2.59$ mS, $r_{O2} = 40\ \mathrm{k}\Omega$ and $r_{O4} = 20\ \mathrm{k}\Omega$.

**Common mistake.** Using the five-transistor-OTA formula $g_{m1}(r_{O2}\|r_{O4}) \approx 34.5$. That formula assumes a mirror that copies $M_1$'s signal current to the output. Here the PMOS mirror is driven by the fixed current $I_1$, so $M_1$'s signal current is dumped into $V_{DD}$ and $G_m$ is only $g_{m1}/2$.

**Common mistake.** Taking $R_{out} = r_{O2}\|r_{O4}$ (≈ 13.3 kΩ). The source of $M_2$ is not at ac ground when looking into its drain: it is degenerated by $r_{O1}/(1 + g_{m1}r_{O1})$, which doubles the resistance of the $M_2$ path to $2r_{O2}$.

**Common mistake.** Swapping the channel-length-modulation coefficients ($\lambda = 0.1\ \mathrm{V^{-1}}$ is for NMOS and $0.2\ \mathrm{V^{-1}}$ for PMOS), or writing the gain as $g_{m1}r_{O2} \approx 104$, which ignores the load $M_4$.
