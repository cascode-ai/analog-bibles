# 详细步骤 - R245

**思路。** $R_2$ 从节点 X 接到地，与二极管并联，把左支路的一部分电流从 $M_2$ 分流出去；节点 X 是二极管连接（diode-connected）的 $M_2$ 的漏极和栅极，也是 $M_1$ 的栅极。导通之前，X 由 $R_1$–$R_2$ 分压器决定。导通之后，对 X 点应用基尔霍夫电流定律（KCL）确定 $V_X$，而 $M_1$ 只复制左支路电流中流过晶体管的那一部分，因此右侧 $R_1$ 上的压降较小，得到 $V_Y = (1 + R_1/R_2)V_X$。

### 第 1 步 — 两个晶体管都截止：$V_{DD} \le V_{TH}(1 + R_1/R_2)$

两个晶体管的 $V_{GS} = V_X$。令 $a = 1 + R_1/R_2$。当 $V_X < V_{TH}$ 时两管都不导通，因此左支路就是 $R_1$–$R_2$ 分压器，右支路没有电流：

$$V_X = V_{DD}\frac{R_2}{R_1 + R_2} = \frac{V_{DD}}{a}, \qquad V_Y = V_{DD} .$$

当 $V_X$ 达到 $V_{TH}$ 时晶体管导通：

$$\frac{V_{DD}}{a} = V_{TH} \quad\Longrightarrow\quad V_{DD,on} = V_{TH}\left(1 + \frac{R_1}{R_2}\right) = 0.7\left(1 + \frac{R_1}{R_2}\right)\ \mathrm{V} ,$$

它**高于** 0.7 V，因为栅极只得到 $V_{DD}$ 的一部分。在这一区域，$V_X$ 以斜率 $R_2/(R_1 + R_2) = 1/a$ 上升，$V_Y$ 以斜率 1 上升。

### 第 2 步 — 导通后的 $V_X$

$M_2$ 为二极管连接，因此处于饱和。对 X 点列 KCL（来自 $R_1$ 的电流 = $R_2$ 中的电流 + 二极管电流）：

$$\frac{V_{DD} - V_X}{R_1} = \frac{V_X}{R_2} + \frac{\beta}{2}(V_X - V_{TH})^2 .$$

令 $w = V_X - V_{TH}$，两边乘以 $R_1$ 并合并同类项：

$$V_{DD} - V_{TH} - w = \frac{R_1}{R_2}(V_{TH} + w) + \frac{\beta R_1}{2}w^2 \quad\Longrightarrow\quad \frac{\beta R_1}{2}w^2 + a\,w - \left(V_{DD} - aV_{TH}\right) = 0 .$$

取正根，

$$w = \frac{-a + \sqrt{a^2 + 2\beta R_1(V_{DD} - aV_{TH})}}{\beta R_1},$$

$$V_X = V_{TH} + \frac{\sqrt{a^2 + 2\beta R_1\left(V_{DD} - aV_{TH}\right)} - a}{\beta R_1}, \qquad V_{DD} \ge aV_{TH} .$$

斜率 $dV_X/dV_{DD} = 1/\sqrt{a^2 + 2\beta R_1(V_{DD} - aV_{TH})}$ 在导通点等于 $1/a$，与分压器的斜率一致（没有折角），随后逐渐减小：$V_X$ 像二极管电压一样从 0.7 V 开始缓慢上升。

### 第 3 步 — 导通后的 $V_Y$

由 X 点的 KCL，晶体管电流等于左支路电流减去 $R_2$ 分走的电流：

$$I_{D2} = \frac{V_{DD} - V_X}{R_1} - \frac{V_X}{R_2} .$$

$M_1$ 的 $V_{GS}$ 相同；若它饱和，则 $I_{D1} = I_{D2}$，对 Y 点列 KCL 得

$$V_Y = V_{DD} - R_1I_{D1} = V_{DD} - R_1\left(\frac{V_{DD} - V_X}{R_1} - \frac{V_X}{R_2}\right) = V_{DD} - V_{DD} + V_X + \frac{R_1}{R_2}V_X ,$$

$$\boxed{V_Y = \left(1 + \frac{R_1}{R_2}\right)V_X}$$

$M_1$ 确实处于饱和：$V_{DS1} = V_Y > V_X = V_{GS1} > V_{GS1} - V_{TH}$ ✓。

在导通点（$V_{DD} = aV_{TH}$，$V_X = V_{TH}$），$V_Y = aV_{TH} = V_{DD}$，与截止区的值一致，其斜率 $a\cdot(1/a) = 1$ 也是连续的。导通之后，斜率 $a/\sqrt{a^2 + 2\beta R_1(V_{DD} - aV_{TH})}$ 小于 1，因此 $V_Y$ 弯离 45° 线，并以更慢的速度继续上升。

$R_2$ 分走了左支路的一部分电流，而电流镜（current mirror）只复制流过晶体管的那部分，因此 $M_1$ 吸取的电流小于左侧 $R_1$ 中的电流，$V_Y$ 恰好比 $V_X$ 高 $(R_1/R_2)V_X$。

### 第 4 步 — 数值示例

例如，取 $\beta = 1\ \mathrm{mA/V^2}$，$R_1 = 10\ \mathrm{k}\Omega$，$R_2 = 20\ \mathrm{k}\Omega$（$a = 1.5$，导通点为 $1.5\times0.7 = 1.05$ V）：

| $V_{DD}$ (V) | 0.5 | 1.0 | 1.05 | 1.2 | 1.5 | 2.0 | 2.5 | 3.0 |
|---|---|---|---|---|---|---|---|---|
| $V_X$ (V) | 0.33 | 0.67 | 0.70 | 0.78 | 0.89 | 1.01 | 1.11 | 1.19 |
| $V_Y$ (V) | 0.50 | 1.00 | 1.05 | 1.17 | 1.33 | 1.52 | 1.66 | 1.79 |
| $I_{D1} = I_{D2}$ (μA) | 0 | 0 | 0 | 3 | 17 | 48 | 84 | 121 |

### 结果

- **$V_{DD} < V_{TH}(1 + R_1/R_2)$：** 两个晶体管都截止。$V_X = V_{DD}R_2/(R_1 + R_2)$（分压，斜率为 $R_2/(R_1 + R_2)$），$V_Y = V_{DD}$（斜率为 1）。
- **在 $V_{DD} = V_{TH}(1 + R_1/R_2)$ 处：** $V_X$ 达到 0.7 V，晶体管导通。
- **导通之后：** $V_X$ 从 0.7 V 开始缓慢上升，它是 $\dfrac{V_{DD} - V_X}{R_1} = \dfrac{V_X}{R_2} + \dfrac{\beta}{2}(V_X - V_{TH})^2$ 的解，即
$$V_X = V_{TH} + \frac{\sqrt{a^2 + 2\beta R_1(V_{DD} - aV_{TH})} - a}{\beta R_1}, \qquad a = 1 + \frac{R_1}{R_2},$$
且 $V_Y = (1 + R_1/R_2)V_X$。$V_Y$ 在导通点连续，在该点开始弯曲，之后继续上升，但比之前慢，始终是 $V_X$ 的 $(1 + R_1/R_2)$ 倍。

**常见错误。** 像没有 $R_2$ 的电路那样得出 $V_Y = V_X$，或者得出 $V_Y < V_X$。$M_1$ 只复制 $M_2$ 的电流，而该电流**小于**左侧 $R_1$ 中的电流，因此右侧 $R_1$ 上的压降较小，$V_Y > V_X$。

**常见错误。** 把导通点定在 $V_{DD} = 0.7$ V。栅极只得到 $V_{DD}R_2/(R_1 + R_2)$，因此 $V_{DD}$ 必须达到 $0.7(1 + R_1/R_2)$ V。
