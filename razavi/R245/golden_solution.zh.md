- $V_{DD} < V_{TH}(1+R_1/R_2)$：两个晶体管都截止。$V_X = V_{DD}R_2/(R_1+R_2)$（分压，斜率为 $R_2/(R_1+R_2)$），$V_Y = V_{DD}$。
- 在 $V_{DD} = V_{TH}(1+R_1/R_2)$ 处，$V_X$ 达到 0.7 V，$M_2$ 导通。此后 $V_X$ 从 0.7 V 开始缓慢上升（它是 $(V_{DD}-V_X)/R_1 = V_X/R_2 + \tfrac{\beta}{2}(V_X-V_{TH})^2$ 的解），且 $V_Y = (1 + R_1/R_2)V_X$：$V_Y$ 在同一点开始弯曲，之后继续上升，但比之前慢，始终是 $V_X$ 的 $(1+R_1/R_2)$ 倍。

- 推导：$M_1$ 复制 $M_2$ 的电流 $I_2 = (V_{DD}-V_X)/R_1 - V_X/R_2$（由于 $V_Y > V_X$，它处于饱和），因此 $V_Y = V_{DD} - R_1I_2 = V_X + (R_1/R_2)V_X$。
- $V_Y$ 在导通点连续（该点处 $V_Y = V_{DD} = 0.7(1+R_1/R_2)$）。
