# 详细步骤 - R204

**思路。** 在差分半边电路（half circuit）中，尾节点 P 是虚地（virtual ground）。关键在于**交叉耦合**负载：$M_3$ 的栅极由**对侧**输出驱动，而对差分信号而言对侧输出变化 $-v_X$，因此从 X 看，$M_3$ 是一个**负**电阻 $-1/g_{m3}$。对 X 点应用基尔霍夫电流定律（KCL）得到增益，然后需要解释其符号。

### 第 1 步 — 半边电路的小信号模型（small-signal model）

把左输出端（$M_1$、$M_3$ 的漏极；$M_4$ 的栅极）记为 X，右输出端（$M_2$、$M_4$ 的漏极；$M_3$ 的栅极）记为 Y。取 $v_{in1} = +v_d/2$、$v_{in2} = -v_d/2$，由对称性得 $v_Y = -v_X$，P 保持在交流地。在 X 点：

- **$M_1$**（栅极为 $v_d/2$，源极接交流地）：经 $M_1$ 流出 X 的电流为 $g_{m1}v_d/2 + v_X/r_{O1}$。
- **$M_3$**（源极接交流地，漏极接 X，栅极接 Y）：它从漏极流向源极、即流出 X 的电流为
$$g_{m3}v_{gs3} + \frac{v_{ds3}}{r_{O3}} = g_{m3}v_Y + \frac{v_X}{r_{O3}} = -g_{m3}v_X + \frac{v_X}{r_{O3}} .$$

$-g_{m3}v_X$ 项的符号是“反常”的：X 上升时，$M_3$ 向 X 注入**更多**电流。因此它相当于从 X 接到交流地的电阻 $-1/g_{m3}$。

### 第 2 步 — X 点的 KCL 与增益

流出 X 的电流之和为零：

$$g_{m1}\frac{v_d}{2} + \frac{v_X}{r_{O1}} - g_{m3}v_X + \frac{v_X}{r_{O3}} = 0 .$$

求解：

$$
\begin{aligned}
v_X\left(\frac{1}{r_{O1}} + \frac{1}{r_{O3}} - g_{m3}\right) &= -g_{m1}\frac{v_d}{2}\\
v_X &= -\frac{g_{m1}}{\dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} - g_{m3}}\cdot\frac{v_d}{2}.
\end{aligned}
$$

由 $v_{out} = v_X - v_Y = 2v_X$ 得：

$$A_v = \frac{v_{out}}{v_{in1} - v_{in2}} = -\frac{g_{m1}}{\dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} - g_{m3}} = -g_{m1}\left[r_{O1}\,\Big\|\,r_{O3}\,\Big\|\left(-\frac{1}{g_{m3}}\right)\right].$$

### 第 3 步 — 用完整的双节点方程验证

不预先假设 $v_Y = -v_X$，对 X 点和 Y 点列 KCL 得：

$$
\begin{aligned}
&g_{m1}\frac{v_d}{2} + \frac{v_X}{r_{O1}} + g_{m3}v_Y + \frac{v_X}{r_{O3}} = 0,\\
-&g_{m1}\frac{v_d}{2} + \frac{v_Y}{r_{O1}} + g_{m3}v_X + \frac{v_Y}{r_{O3}} = 0.
\end{aligned}
$$

两式**相减**得 $g_{m1}v_d + (v_X - v_Y)(1/r_{O1} + 1/r_{O3} - g_{m3}) = 0$，差模增益相同。两式**相加**得 $(v_X + v_Y)(1/r_{O1} + 1/r_{O3} + g_{m3}) = 0$，因此 $v_X + v_Y = 0$：对共模（common-mode）信号，交叉耦合对管就像一对二极管（$+g_{m3}$）；对差分信号，它就像一个负电阻（$-g_{m3}$）。

### 第 4 步 — 结果的解释：负电阻与不稳定性

分母是每个输出端的总小信号电导：

$$G_{net} = \frac{1}{r_{O1}} + \frac{1}{r_{O3}} - g_{m3}.$$

**通常情况：$g_{m3} > 1/r_{O1} + 1/r_{O3}$**，即 $g_{m3}(r_{O1}\parallel r_{O3}) > 1$；由于 $g_mr_O$ 通常为 10–100，这几乎总是成立的。此时 $G_{net} < 0$：差分负载电阻为负，该公式甚至给出符号错误的“增益”。考虑节点电容 $C$，差分扰动满足 $C\,dv_X/dt = -G_{net}v_X$，且 $-G_{net} > 0$，因此它**按指数规律增长**；环路 $X \to M_4 \to Y \to M_3 \to X$ 的增益为 $[g_{m3}(r_{O1}\parallel r_{O3})]^2 > 1$。对称偏置点是**不稳定的**，电路以再生（regenerative）方式到达两个状态之一：它是一个**锁存器**，小信号“增益”描述的是一个它无法停留的平衡点。

**数值感受：** 取 $g_{m1} = g_{m3} = 1$ mS，$r_{O1} = r_{O3} = 50\ \mathrm{k}\Omega$：

$$
\begin{aligned}
G_{net} &= 0.02 + 0.02 - 1 = -0.96\ \mathrm{mS},\\
A_v &= -\frac{1\ \mathrm{mS}}{-0.96\ \mathrm{mS}} = +1.04\quad\text{(formal value at an unstable point)}.
\end{aligned}
$$

**交叉耦合器件较弱：$g_{m3} < 1/r_{O1} + 1/r_{O3}$。** $G_{net}$ 为很小的正值，电路稳定，而且由于负电阻抵消了大部分输出电导（output conductance），增益非常大。例如，$g_{m3} = 0.03$ mS 给出 $G_{net} = 0.01$ mS 和 $A_v = -1\ \mathrm{mS}/0.01\ \mathrm{mS} = -100$。只有在这种情况下，该公式才是有意义的放大器增益。

### 结果

$$A_v = \frac{V_{out}}{V_{in1} - V_{in2}} = -\frac{g_{m1}}{\dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} - g_{m3}} = -g_{m1}\left[r_{O1}\,\Big\|\,r_{O3}\,\Big\|\left(-\frac{1}{g_{m3}}\right)\right].$$

对差分信号而言，右输出端变化 $-v_X$，因此 $M_3$（栅极接右输出端）向左节点注入 $+g_{m3}v_X$：交叉耦合对管在每边呈现负电阻 $-1/g_{m3}$。

通常 $g_{m3} > 1/r_{O1} + 1/r_{O3}$。此时总的差分负载电阻为负，“增益”改变符号，对称偏置点不稳定（电路会锁存）。只有当 $g_{m3} < 1/r_{O1} + 1/r_{O3}$ 时，该公式才是有意义的小信号增益，而且是非常大的增益。

**常见错误。** 把交叉耦合器件当作二极管负载，得到 $-g_{m1}(r_{O1}\parallel r_{O3}\parallel 1/g_{m3})$。栅极接的是**对侧**输出，而对差分信号而言它朝相反方向变化，因此 $g_{m3}$ 项的符号反转。

**常见错误。** 把 $M_3$/$M_4$ 当作电流源（current source），得到 $-g_{m1}(r_{O1}\parallel r_{O3})$。它们的栅极由输出驱动，因此它们的跨导（transconductance）会进入负载。

**常见错误。** 不检查分母的符号，就把结果当作很大的稳定增益。当 $g_{m3}(r_{O1}\parallel r_{O3}) > 1$ 时，电路是锁存器，而不是放大器。
