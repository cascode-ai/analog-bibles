# 详细步骤 - R683

**思路。** 该电路是一个共源级（common-source stage，CS）$M_1$，负载为 PMOS 电流源 $M_2$（其栅极接固定偏置 $V_b$）。其增益为 $-g_{m1}(r_{O1}\|r_{O2})$，输入参考热噪声为 $\frac{4kT\gamma}{g_{m1}}(1 + g_{m2}/g_{m1})$。在恒定电流下，随 $\mu C_{ox}$ 变化的只有跨导，而不是输出电阻（output resistance）。记号：工艺角 FF、SS、FS（快 NMOS、慢 PMOS）和 SF（慢 NMOS、快 PMOS）。

### 第 1 步 — 恒定电流下哪些量会变化

两个晶体管流过相同的恒定电流 $I$，因此

$$g_m = \sqrt{2\,\mu C_{ox}\frac{W}{L}\,I}\quad\Rightarrow\quad g_{m1} \propto \sqrt{\mu_nC_{ox}},\qquad g_{m2} \propto \sqrt{\mu_pC_{ox}} ,$$

而

$$r_{O1} = \frac{1}{\lambda_nI}, \qquad r_{O2} = \frac{1}{\lambda_pI}$$

**保持不变**（$\lambda$ 与 $\mu C_{ox}$ 无关，且 $I$ 固定）。要保持 $I$ 恒定，快工艺角下的过驱动电压（overdrive voltage）$V_{ov} = \sqrt{2I/[\mu C_{ox}(W/L)]}$ 必须减小，因此 $V_b$（以及输入偏置）必须随工艺角变化，由电流镜产生时正是如此。

### 第 2 步 — 电压增益

$M_2$ 的栅极接恒定的 $V_b$，源极接 $V_{DD}$，因此 $v_{gs2} = 0$，$M_2$ 只贡献 $r_{O2}$。在输出端应用基尔霍夫电流定律（KCL）：

$$
\begin{aligned}
g_{m1}v_{in} + \frac{v_{out}}{r_{O1}} + \frac{v_{out}}{r_{O2}} &= 0\\
A_v = \frac{v_{out}}{v_{in}} &= -g_{m1}\,(r_{O1}\,\|\,r_{O2}).
\end{aligned}
$$

由于 $r_{O1}\|r_{O2}$ 不变，

$$|A_v| \propto \sqrt{\mu_nC_{ox}} :$$

增益**只取决于 NMOS 的工艺角**：

- **FF 和 FS**（快 NMOS）：增益提高到 $\sqrt{(\mu_nC_{ox})_{fast}/(\mu_nC_{ox})_{nom}}$ 倍；
- **SS 和 SF**（慢 NMOS）：增益降低；
- PMOS 的工艺角几乎没有影响（它既不进入 $g_{m1}$，也不进入 $r_O$）。

### 第 3 步 — 输入参考热噪声

每个晶体管在漏极与源极之间都有沟道噪声电流 $\overline{I_n^2} = 4kT\gamma g_m$（两者的 $\gamma$ 相同）。对于 $M_2$，尽管对信号而言 $v_{gs2} = 0$，这一电流仍会在其沟道中产生，并在 $V_{DD}$（交流地）与输出节点之间流动。在模型中，两个噪声电流都画成从输出节点流向地（方向不影响噪声功率），输出节点的电阻为 $R_{out} = r_{O1}\|r_{O2}$。

<!-- diagram: diagram-01.cir -->

这些噪声源互不相关，因此功率相加：

$$\overline{V_{n,out}^2} = 4kT\gamma\,(g_{m1} + g_{m2})\,(r_{O1}\|r_{O2})^2 .$$

除以增益的平方 $g_{m1}^2(r_{O1}\|r_{O2})^2$：

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \frac{4kT\gamma\,(g_{m1} + g_{m2})}{g_{m1}^2}\\
&= \frac{4kT\gamma}{g_{m1}}\left(1 + \frac{g_{m2}}{g_{m1}}\right).
\end{aligned}
$$

$r_O$ 被消去。$g_{m2}/g_{m1}$ 是一个设计比值（通常小于 1，因为电流源的过驱动电压比输入器件大），在恒定电流下它按 $\sqrt{\mu_pC_{ox}/\mu_nC_{ox}}$ 变化；PMOS 的工艺角只通过这一项影响噪声。

- **FF：** $g_{m1}$ 和 $g_{m2}$ 按相同因子增大（变化量相等）；$g_{m2}/g_{m1}$ 不变而 $1/g_{m1}$ 减小。噪声功率低于标称值，$\propto 1/\sqrt{\mu C_{ox}}$。
- **SS：** 噪声高于标称值。
- **FS：** $g_{m1}$ 增大而 $g_{m2}/g_{m1}$ 减小：**噪声最低**。
- **SF：** $g_{m1}$ 减小而 $g_{m2}/g_{m1}$ 增大：**噪声最高**。

### 第 4 步 — 数值示例

设 $\mu C_{ox}$ 变化 $\pm20\ \%$（快 = 1.2×，慢 = 0.8×），标称 $g_{m2}/g_{m1} = 0.5$。以 $n$、$p$ 分别表示 NMOS 和 PMOS 的倍乘因子，则相对于标称值，增益为 $\sqrt n$，噪声功率为 $(1/\sqrt n)[1 + 0.5\sqrt{p/n}]/1.5$。

| 工艺角 | $n$, $p$ | 增益（相对值） | 噪声功率（相对值） |
|---|---|---|---|
| 标称 | 1, 1 | 1.000 | 1.000 |
| FF | 1.2, 1.2 | 1.095 | 0.913（−0.40 dB） |
| FS | 1.2, 0.8 | 1.095 | 0.857（−0.67 dB） |
| SS | 0.8, 0.8 | 0.894 | 1.118（+0.48 dB） |
| SF | 0.8, 1.2 | 0.894 | 1.202（+0.80 dB） |

例如，在 SF 下：增益为 $\sqrt{0.8} = 0.894$；噪声为 $(1/\sqrt{0.8})(1 + 0.5\sqrt{1.2/0.8})/1.5 = 1.118\times1.612/1.5 = 1.202$。

变化量相当时，噪声的排序为 **FS < FF < 标称 < SS < SF**。FS 总是最低，SF 总是最高，但 FF 与 SS 的先后取决于相对变化量：$n = 1.05$、$p = 1.3$ 的“FF”工艺角给出 1.013（高于标称值），而 $n = 0.95$、$p = 0.7$ 的“SS”工艺角给出 0.978（低于标称值），因为此时 PMOS 的变化通过 $g_{m2}/g_{m1}$ 起主导作用。

### 结果

- **增益：** $A_v = -g_{m1}(r_{O1}\|r_{O2})$。在恒定电流下，$r_{O1}$ 和 $r_{O2}$ 不变，$g_{m1} \propto \sqrt{\mu_nC_{ox}}$，因此 $|A_v| \propto \sqrt{\mu_nC_{ox}}$：在 FF 和 FS 下较高，在 SS 和 SF 下较低；PMOS 的工艺角几乎没有影响。
- **输入参考噪声：** $\overline{V_{n,in}^2} = \dfrac{4kT\gamma}{g_{m1}}\left(1 + \dfrac{g_{m2}}{g_{m1}}\right)$，其中 $g_{m1} \propto \sqrt{\mu_nC_{ox}}$，$g_{m2}/g_{m1} \propto \sqrt{\mu_pC_{ox}/\mu_nC_{ox}}$。FS 下最低，SF 下最高；变化量相当时 FS < FF < 标称 < SS < SF，否则 FF 与 SS 的先后取决于相对变化量。PMOS 的工艺角只通过 $g_{m2}/g_{m1}$ 项起作用。

**常见错误。** 像二极管连接（diode-connected）负载那样，把增益当作依赖于 PMOS 工艺角的比值 $g_{m1}/g_{m2}$。这里 $M_2$ 只贡献 $r_{O2}$，而它在恒定电流下与 $\mu C_{ox}$ 无关。

**常见错误。** 声称 $r_O$ 随 $\mu C_{ox}$ 变化。$r_O = 1/(\lambda I)$，而 $\lambda$ 和 $I$ 都不变。

**常见错误。** 以“电流源负载的栅极接固定偏置”为由忽略它的噪声，或者把 FS 和 SF 弄反。$M_2$ 的沟道噪声直接流入输出节点，并通过 $g_{m1}$ 折算到输入端；它在快 PMOS 工艺角下使噪声增大，在慢 PMOS 工艺角下使噪声减小。
