$C$ = 129 aF/μm²，$C_P$ = 90 aF/μm²，$C_P/C$ ≈ 0.70。

- 层 i 与层 j 之间的层间电容：$1/(1/C_{sub,i} - 1/C_{sub,j})$（高度 $h = \epsilon/C_{sub}$）。
- 金属 4–3：31.5；金属 3–2：22.5；金属 2–1：30；金属 1–多晶硅：$1/(1/30 - 1/90) = 45$ aF/μm²。
- $C = 31.5 + 22.5 + 30 + 45 = 129$ aF/μm²（约为两极板金属 4/金属 3 电容的 4.1 倍）。
- $C_P$ = 多晶硅对衬底的电容 = 90 aF/μm²。
- $C_P/C = 90/129 = 0.70$：密度最高的结构，但寄生比例也最差。
