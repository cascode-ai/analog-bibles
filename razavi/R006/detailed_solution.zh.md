# 详细步骤 - R006

**思路。** 先判断 $M_1$ 的哪一端是源极，并说明该晶体管只可能工作在饱和区（saturation region）。然后用平方律（square law）饱和电流公式逐点求出 $I_X$ 和跨导（transconductance）$g_m$；由于源极电位高于接地的衬底（bulk），计算时要计入体效应（body effect）。最后利用它们的导数描述曲线的形状。

### 第 1 步 — 确定各端并写出端电压

由电路图可知：$M_1$ 的栅极和上方的扩散区端（diffusion terminal）都接 $V_{DD} = 3$ V。下方的扩散区端接电压源 $V_X$ 的“+”端，衬底（substrate）接地。$I_X$ 是从 $M_1$ 向下流出、流入 $V_X$ 的电流。

MOSFET 在物理结构上是对称的。对 NMOS 而言，两个扩散区端中电位*较低*的那一端就是**源极**，因为电子正是从那里进入沟道的。这里 $V_X \le 1.5\ \mathrm{V} < V_{DD} = 3$ V，所以：

- 接 $V_X$ 的一端是源极（$V_S = V_X$）；
- 接 $V_{DD}$ 的一端是漏极（$V_D = 3$ V）；
- 栅极电位为 $V_G = 3$ V，衬底电位为 $V_B = 0$。

因此，控制该器件的三个电压为

$$
\begin{aligned}
V_{GS} &= V_G - V_S = 3 - V_X,\\
V_{DS} &= V_D - V_S = 3 - V_X,\\
V_{SB} &= V_S - V_B = V_X - 0 = V_X .
\end{aligned}
$$

其中 $V_{GS}$、$V_{DS}$ 和 $V_{SB}$ 分别为栅源电压、漏源电压和源-衬底电压。栅极不吸取直流电流，因此在源极节点应用基尔霍夫电流定律（KCL）可得

$$I_X = I_D ,$$

其中 $I_D$ 为 $M_1$ 的漏极电流。

### 第 2 步 — 工作区

当 $V_{GS} > V_{TH}$ 时 NMOS **导通**，其中 $V_{TH}$ 为阈值电压（threshold voltage）。如果同时还满足下式，它就处于**饱和区**：

$$V_{DS} \ge V_{GS} - V_{TH}.$$

本电路中栅极与漏极相连，即所谓“二极管连接”（diode-connected）的晶体管，因此 $V_{DS} = V_{GS}$。只要阈值为正，就有

$$V_{DS} = V_{GS} > V_{GS} - V_{TH}.$$

所以**只要 $M_1$ 导通，它就一定处于饱和区**，永远不会进入线性区（triode region）。剩下要做的是用数值（第 4 步）验证：在整个范围 $0 \le V_X \le 1.5$ V 内 $M_1$ 始终导通，即 $V_{GS} > V_{TH}$。

### 第 3 步 — 计入体效应的阈值电压

衬底电位为 0 V，而源极电位为 $V_X$。因此源-衬底结被 $V_{SB} = V_X$ 反向偏置（reverse-biased），从而使阈值电压升高（即**体效应**）：

$$V_{TH} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right).$$

式中各符号的含义为：

- $V_{TH0} = 0.7$ V，即 $V_{SB} = 0$ 时的阈值电压；
- $\gamma = 0.45\ \mathrm{V^{1/2}}$，即体效应系数（body-effect coefficient）；
- $2|\phi_F| = 0.9$ V，即衬底费米势（Fermi potential）的两倍。

代入数值（$\sqrt{0.9} = 0.9487$），并令 $V_{SB} = V_X$：

$$V_{TH} = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - 0.9487\right)\ \mathrm{V}.$$

在区间两端和几个中间点上求值：

- $V_X = 0$：括号内为 $\sqrt{0.9} - 0.9487 = 0$，故 $V_{TH} = 0.7000$ V。
- $V_X = 0.5$ V：$\sqrt{1.4} = 1.1832$，于是 $1.1832 - 0.9487 = 0.2345$，进而 $0.45 \times 0.2345 = 0.1055$，故 $V_{TH} = 0.8055$ V。
- $V_X = 1.0$ V：$\sqrt{1.9} = 1.3784$，于是 $1.3784 - 0.9487 = 0.4297$，进而 $0.45 \times 0.4297 = 0.1934$，故 $V_{TH} = 0.8934$ V。
- $V_X = 1.5$ V：$\sqrt{2.4} = 1.5492$，于是 $1.5492 - 0.9487 = 0.6005$，进而 $0.45 \times 0.6005 = 0.2702$，故 $V_{TH} = 0.9702$ V。

在整个范围内，阈值电压约升高 0.27 V。

### 第 4 步 — 电流 $I_X$（饱和区平方律）

题中没有给出沟道长度调制（channel-length modulation），因此取 $\lambda = 0$。**平方律饱和电流**为

$$I_X = I_D = \frac12\,\mu_nC_{ox}\frac{W}{L}\,(V_{GS} - V_{TH})^2 = \frac12\,\beta\,V_{ov}^2 .$$

其中 $\beta = \mu_nC_{ox}W/L$，$V_{ov} = V_{GS} - V_{TH}$ 为**过驱动电压**（overdrive voltage）。由第 1 步知 $V_{GS} = 3 - V_X$，因此

$$V_{ov} = 3 - V_X - V_{TH}(V_X).$$

在同样的四个点上求值：

- $V_X = 0$：$V_{ov} = 3 - 0 - 0.7000 = 2.300$ V，$V_{ov}^2 = 5.290\ \mathrm{V^2}$，故 $I_X = \tfrac12(5.290\ \mathrm{V^2})\,\beta = 2.645\,\beta$。
- $V_X = 0.5$ V：$V_{ov} = 3 - 0.5 - 0.8055 = 1.6945$ V，$V_{ov}^2 = 2.871\ \mathrm{V^2}$，故 $I_X = \tfrac12(2.871\ \mathrm{V^2})\,\beta = 1.436\,\beta$。
- $V_X = 1.0$ V：$V_{ov} = 3 - 1.0 - 0.8934 = 1.1066$ V，$V_{ov}^2 = 1.2246\ \mathrm{V^2}$，故 $I_X = \tfrac12(1.2246\ \mathrm{V^2})\,\beta = 0.612\,\beta$。
- $V_X = 1.5$ V：$V_{ov} = 3 - 1.5 - 0.9702 = 0.5298$ V，$V_{ov}^2 = 0.2807\ \mathrm{V^2}$，故 $I_X = \tfrac12(0.2807\ \mathrm{V^2})\,\beta = 0.140\,\beta$。

单位：$\beta$ 以 $\mathrm{A/V^2}$ 为单位时，$I_X$ 的单位为安培。例如 $\beta = 1\ \mathrm{mA/V^2}$ 时，$I_X$ 从 2.65 mA 降到 0.14 mA。

**工作区检查。** 每个点上都有 $V_{ov} > 0$（最小值为 0.53 V，出现在 $V_X = 1.5$ V 处）。因此始终有 $V_{GS} > V_{TH}$：$M_1$ 导通，并且由第 2 步可知，它在整个范围内都处于饱和区。

### 第 5 步 — 跨导 $g_m$

跨导定义为 $g_m = \partial I_D/\partial V_{GS}$，求导时保持 $V_{DS}$ 和 $V_{SB}$ 不变。对平方律公式求导：

$$g_m = \frac{\partial}{\partial V_{GS}}\left[\frac12\beta(V_{GS} - V_{TH})^2\right] = \beta\,(V_{GS} - V_{TH}) = \beta\,V_{ov}.$$

利用 $I_D = \tfrac12\beta V_{ov}^2$ 消去 $V_{ov}$，可得等价形式 $g_m = \sqrt{2\beta I_D}$。

因此 $g_m$ 等于 $\beta$ 乘以第 4 步求得的过驱动电压：

- $V_X = 0$ 时，$g_m = 2.300\,\beta$；
- 0.5 V 时，$g_m = 1.694\,\beta$；
- 1.0 V 时，$g_m = 1.107\,\beta$；
- 1.5 V 时，$g_m = 0.530\,\beta$。

$\beta$ 以 $\mathrm{A/V^2}$ 为单位时，$g_m$ 的单位为 A/V。例如 $\beta = 1\ \mathrm{mA/V^2}$ 时，$g_m$ 从 2.3 mS 降到 0.53 mS。

### 第 6 步 — 曲线形状：斜率与凹凸性

要正确画出曲线，需要知道它们的斜率。定义

$$\eta \equiv \frac{\partial V_{TH}}{\partial V_{SB}} = \frac{\gamma}{2\sqrt{2|\phi_F| + V_{SB}}}.$$

$\eta$ 表示 $V_{SB}$ 每增加一伏，阈值电压升高多少伏。由于 $V_{SB} = V_X$，对过驱动电压逐项求导：

$$\frac{dV_{ov}}{dV_X} = \frac{d}{dV_X}\left[3 - V_X - V_{TH}\right] = -1 - \eta .$$

$V_X$ 每升高 1 V，$V_{GS}$ 就降低 1 V，*同时* $V_{TH}$ 还升高 $\eta$ 伏，所以过驱动电压减小 $(1+\eta)$ 伏。对 $g_m = \beta V_{ov}$ 和 $I_X = \tfrac12\beta V_{ov}^2$ 应用链式法则：

$$
\begin{aligned}
\frac{dg_m}{dV_X} &= \beta\,\frac{dV_{ov}}{dV_X} = -\beta\,(1+\eta),\\
\frac{dI_X}{dV_X} &= \beta V_{ov}\,\frac{dV_{ov}}{dV_X} = -(1+\eta)\,g_m .
\end{aligned}
$$

两个端点处的数值：

- 在 $V_X = 0$ 处：$\eta = 0.45/(2\times0.9487) = 0.237$。于是 $dg_m/dV_X = -1.24\beta$/V，$dI_X/dV_X = -(1.237)(2.30\beta) = -2.85\beta$/V。
- 在 $V_X = 1.5$ V 处：$\eta = 0.45/(2\times1.5492) = 0.145$。于是 $dg_m/dV_X = -1.15\beta$/V，$dI_X/dV_X = -(1.145)(0.53\beta) = -0.61\beta$/V。

全部计算点（β 的单位为 A/V²；$I_X$ 的单位为 A；$g_m$ 的单位为 A/V）：

| $V_X$ (V) | $V_{SB}$ (V) | $V_{TH}$ (V) | $V_{ov}$ (V) | $I_X$ | $g_m$ | $dg_m/dV_X$ |
|---|---|---|---|---|---|---|
| 0 | 0 | 0.700 | 2.300 | $2.645\beta$ | $2.300\beta$ | $-1.24\beta$/V |
| 0.25 | 0.25 | 0.756 | 1.994 | $1.989\beta$ | $1.994\beta$ | $-1.21\beta$/V |
| 0.50 | 0.50 | 0.806 | 1.694 | $1.436\beta$ | $1.694\beta$ | $-1.19\beta$/V |
| 0.75 | 0.75 | 0.851 | 1.399 | $0.978\beta$ | $1.399\beta$ | $-1.18\beta$/V |
| 1.00 | 1.00 | 0.893 | 1.107 | $0.612\beta$ | $1.107\beta$ | $-1.16\beta$/V |
| 1.25 | 1.25 | 0.933 | 0.817 | $0.334\beta$ | $0.817\beta$ | $-1.15\beta$/V |
| 1.50 | 1.50 | 0.970 | 0.530 | $0.140\beta$ | $0.530\beta$ | $-1.15\beta$/V |

草图应具有以下特征：

- **$I_X$ 随 $V_X$ 的变化**：单调下降且向上凹（concave up），大致是一段抛物线。曲线从 $2.65\beta$ 开始，起始处很陡（$-2.85\beta$/V），随后逐渐变平，在 $V_X = 1.5$ V 处降到 $0.14\beta$。抛物线的最低点（电流降为零处）位于所画范围之外（见第 7 步）。
- **$g_m$ 随 $V_X$ 的变化**：近似一条直线，从 $2.30\beta$ 降到 $0.53\beta$。其斜率略有减缓，从 $-1.24\beta$/V 变为 $-1.15\beta$/V，因此曲线略微向上凹。若不考虑体效应，它将是一条斜率为 $-\beta$/V 的严格直线；体效应使它下降得更快。

### 第 7 步 — $M_1$ 在何处截止（在范围之外）

当 $V_{ov} = 0$，即 $3 - V_X = V_{TH}(V_X)$ 时，$M_1$ 截止。为求解，令 $u = \sqrt{0.9 + V_X}$，则 $V_X = u^2 - 0.9$：

$$
\begin{aligned}
3 - (u^2 - 0.9) &= 0.7 + 0.45u - 0.45(0.9487)\\
3.9 - u^2 &= 0.2731 + 0.45u\\
u^2 + 0.45u - 3.6269 &= 0\\
u &= \frac{-0.45 + \sqrt{0.2025 + 4(3.6269)}}{2} = \frac{-0.45 + 3.8354}{2} = 1.6927\\
V_X &= u^2 - 0.9 = 2.8652 - 0.9 = 1.965\ \mathrm{V}.
\end{aligned}
$$

若不考虑体效应，截止发生在 $3 - V_X = 0.7$，即 $V_X = 2.3$ V 处。两个值都高于 1.5 V，这证实了 $M_1$ 在题目要求的整个范围内都导通。

作为对比，若不考虑体效应，$V_X = 1.5$ V 处的结果将是 $V_{ov} = 0.8$ V、$I_X = 0.32\beta$、$g_m = 0.8\beta$。可见体效应使端点处的电流减小了一半以上。

### 结果

$M_1$（栅极和漏极接 $V_{DD}$，源极接 $V_X$，衬底接地）**在整个范围内都处于饱和区**，并且

$$I_X = \tfrac12\beta\,(3 - V_X - V_{TH})^2, \qquad g_m = \beta\,(3 - V_X - V_{TH}),$$

$$V_{TH} = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right)\ \mathrm{V}.$$

- $V_{TH}$：在 $V_X$ = 0、0.5、1.0、1.5 V 处依次为 0.70 → 0.81 → 0.89 → 0.97 V。
- $I_X$：2.65β → 1.44β → 0.61β → 0.14β，大致按平方规律下降（向上凹）。起点处的过驱动电压为 2.3 V，终点处为 0.53 V。
- $g_m$：2.3β → 1.69β → 1.11β → 0.53β，近似线性下降。斜率的绝对值为 $\beta(1+\eta)$，从约 1.24β/V 变为 1.15β/V，比不考虑体效应时 $\beta$/V 的下降速率更快。
- $M_1$ 要到 $V_X \approx 1.97$ V（不考虑体效应时为 2.3 V）才会截止，已超出所给范围。

**常见错误。** 忽略体效应（仍取 $V_{TH} = 0.7$ V）。衬底始终接地，而源极随 $V_X$ 上升，因此 $V_{SB} = V_X \neq 0$。忽略这一点会得到 1.5 V 处 $I_X = 0.32\beta$、$g_m = 0.8\beta$，电流是正确值的两倍多。

**常见错误。** 认为 $V_X$ 升高时 $M_1$ 会进入线性区。这里始终有 $V_{DS} = V_{GS}$，所以 $V_{DS} > V_{GS} - V_{TH}$ 自动成立。器件只可能处于饱和区或截止。

**常见错误。** 混淆源极和漏极。把接 $V_{DD}$ 的一端当作源极，会得到 $V_{GS} = 0$，晶体管“永远截止”；把 $V_X$ 当作漏极电压，则会得到随 $V_X$ 增大的 $I_X$。NMOS 的源极是电位较低的一端，这里就是 $V_X$ 节点，所以升高 $V_X$ 会*减小* $V_{GS}$，电流随之下降。同理，$g_m = \beta V_{ov}$ 也不是常数：它随过驱动电压一起下降。
