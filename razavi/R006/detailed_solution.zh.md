# 详细步骤 - R006

**思路。** $M_1$ 为二极管连接（diode-connected），源极接 $V_X$，因此它只能工作在饱和区。利用平方律（square law）饱和电流公式逐点求出 $I_X$ 和 $g_m$；由于源极电位高于接地的衬底，需要计入体效应。然后用它们的导数确定曲线的形状。

### 第 1 步 — 端电压与工作区

电位较低的端子（$V_X \le 1.5$ V）是源极；接 $V_{DD} = 3$ V 的端子是漏极。栅极接 3 V，衬底接 0：

$$V_{GS} = V_{DS} = 3 - V_X, \qquad V_{SB} = V_X ,$$

并且由于栅极不取电流，$I_X = I_D$。

栅极与漏极相连，因此 $V_{DS} = V_{GS} > V_{GS} - V_{TH}$：**只要 $M_1$ 导通，它就处于饱和区**，绝不会进入线性区（triode region）。第 3 步将用数值验证它在整个范围 $0 \le V_X \le 1.5$ V 内都保持导通（$V_{GS} > V_{TH}$）。

### 第 2 步 — 计入体效应的阈值电压（threshold voltage）

$V_{SB} = V_X$ 使源-衬底结（source–bulk junction）处于反向偏置（reverse-biased），阈值电压随之升高（取 $\sqrt{0.9} = 0.9487$）：

$$V_{TH} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - 0.9487\right)\ \mathrm{V}.$$

- $V_X = 0$：括号内为 $\sqrt{0.9} - 0.9487 = 0$，因此 $V_{TH} = 0.7000$ V。
- $V_X = 0.5$ V：$\sqrt{1.4} = 1.1832$，于是 $1.1832 - 0.9487 = 0.2345$，再得 $0.45 \times 0.2345 = 0.1055$，因此 $V_{TH} = 0.8055$ V。
- $V_X = 1.0$ V：$\sqrt{1.9} = 1.3784$，于是 $1.3784 - 0.9487 = 0.4297$，再得 $0.45 \times 0.4297 = 0.1934$，因此 $V_{TH} = 0.8934$ V。
- $V_X = 1.5$ V：$\sqrt{2.4} = 1.5492$，于是 $1.5492 - 0.9487 = 0.6005$，再得 $0.45 \times 0.6005 = 0.2702$，因此 $V_{TH} = 0.9702$ V。

在整个范围内，阈值电压升高约 0.27 V。

### 第 3 步 — 电流 $I_X$

取 $\lambda = 0$（题中未给出），$\beta = \mu_nC_{ox}W/L$：

$$I_X = \frac12\,\beta\,V_{ov}^2, \qquad V_{ov} = V_{GS} - V_{TH} = 3 - V_X - V_{TH}(V_X).$$

- $V_X = 0$：$V_{ov} = 3 - 0 - 0.7000 = 2.300$ V，$V_{ov}^2 = 5.290\ \mathrm{V^2}$，因此 $I_X = \tfrac12(5.290\ \mathrm{V^2})\,\beta = 2.645\,\beta$。
- $V_X = 0.5$ V：$V_{ov} = 3 - 0.5 - 0.8055 = 1.6945$ V，$V_{ov}^2 = 2.871\ \mathrm{V^2}$，因此 $I_X = \tfrac12(2.871\ \mathrm{V^2})\,\beta = 1.436\,\beta$。
- $V_X = 1.0$ V：$V_{ov} = 3 - 1.0 - 0.8934 = 1.1066$ V，$V_{ov}^2 = 1.2246\ \mathrm{V^2}$，因此 $I_X = \tfrac12(1.2246\ \mathrm{V^2})\,\beta = 0.612\,\beta$。
- $V_X = 1.5$ V：$V_{ov} = 3 - 1.5 - 0.9702 = 0.5298$ V，$V_{ov}^2 = 0.2807\ \mathrm{V^2}$，因此 $I_X = \tfrac12(0.2807\ \mathrm{V^2})\,\beta = 0.140\,\beta$。

若 $\beta$ 以 $\mathrm{A/V^2}$ 为单位，则 $I_X$ 以安培为单位；例如 $\beta = 1\ \mathrm{mA/V^2}$ 时，$I_X$ 从 2.65 mA 下降到 0.14 mA。

每一点都有 $V_{ov} > 0$（最小值为 0.53 V，出现在 $V_X = 1.5$ V 处），因此 $M_1$ 在整个范围内都导通，从而处于饱和区。

### 第 4 步 — 跨导 $g_m$

$$g_m = \frac{\partial I_D}{\partial V_{GS}} = \beta\,V_{ov} = \beta\,(3 - V_X - V_{TH}),$$

即 $\beta$ 乘以第 3 步中的过驱动电压：

- $V_X = 0$ 时，$g_m = 2.300\,\beta$；
- 0.5 V 时，$g_m = 1.694\,\beta$；
- 1.0 V 时，$g_m = 1.107\,\beta$；
- 1.5 V 时，$g_m = 0.530\,\beta$。

若 $\beta$ 以 $\mathrm{A/V^2}$ 为单位，则 $g_m$ 以 A/V 为单位；例如 $\beta = 1\ \mathrm{mA/V^2}$ 时，$g_m$ 从 2.3 mS 下降到 0.53 mS。

### 第 5 步 — 曲线形状：斜率与曲率

令 $\eta = \partial V_{TH}/\partial V_{SB} = \gamma/\left(2\sqrt{2|\phi_F| + V_{SB}}\right)$。由于 $V_{SB} = V_X$，

$$\frac{dV_{ov}}{dV_X} = \frac{d}{dV_X}\left[3 - V_X - V_{TH}\right] = -1 - \eta ,$$

因此由链式法则得

$$
\begin{aligned}
\frac{dg_m}{dV_X} &= \beta\,\frac{dV_{ov}}{dV_X} = -\beta\,(1+\eta),\\
\frac{dI_X}{dV_X} &= \beta V_{ov}\,\frac{dV_{ov}}{dV_X} = -(1+\eta)\,g_m .
\end{aligned}
$$

- $V_X = 0$ 时：$\eta = 0.45/(2\times0.9487) = 0.237$。于是 $dg_m/dV_X = -1.24\beta$/V，$dI_X/dV_X = -(1.237)(2.30\beta) = -2.85\beta$/V。
- $V_X = 1.5$ V 时：$\eta = 0.45/(2\times1.5492) = 0.145$。于是 $dg_m/dV_X = -1.15\beta$/V，$dI_X/dV_X = -(1.145)(0.53\beta) = -0.61\beta$/V。

全部数据点（β 的单位为 A/V²；$I_X$ 的单位为 A；$g_m$ 的单位为 A/V）：

| $V_X$ (V) | $V_{SB}$ (V) | $V_{TH}$ (V) | $V_{ov}$ (V) | $I_X$ | $g_m$ | $dg_m/dV_X$ |
|---|---|---|---|---|---|---|
| 0 | 0 | 0.700 | 2.300 | $2.645\beta$ | $2.300\beta$ | $-1.24\beta$/V |
| 0.25 | 0.25 | 0.756 | 1.994 | $1.989\beta$ | $1.994\beta$ | $-1.21\beta$/V |
| 0.50 | 0.50 | 0.806 | 1.694 | $1.436\beta$ | $1.694\beta$ | $-1.19\beta$/V |
| 0.75 | 0.75 | 0.851 | 1.399 | $0.978\beta$ | $1.399\beta$ | $-1.18\beta$/V |
| 1.00 | 1.00 | 0.893 | 1.107 | $0.612\beta$ | $1.107\beta$ | $-1.16\beta$/V |
| 1.25 | 1.25 | 0.933 | 0.817 | $0.334\beta$ | $0.817\beta$ | $-1.15\beta$/V |
| 1.50 | 1.50 | 0.970 | 0.530 | $0.140\beta$ | $0.530\beta$ | $-1.15\beta$/V |

- **$I_X$ 随 $V_X$ 的变化**：单调下降且向上凹（concave up），大致是一条抛物线。它从 $2.65\beta$ 开始，起初很陡（$-2.85\beta$/V），随后变得平缓，在 $V_X = 1.5$ V 处趋于 $0.14\beta$。抛物线的最低点（电流降为零之处）位于所画范围之外（见第 6 步）。
- **$g_m$ 随 $V_X$ 的变化**：几乎是一条直线，从 $2.30\beta$ 下降到 $0.53\beta$。其斜率略有减缓，从 $-1.24\beta$/V 变为 $-1.15\beta$/V，因此曲线略微向上凹。若没有体效应，它将是一条斜率恰为 $-\beta$/V 的直线；体效应使它下降得更快。

### 第 6 步 — $M_1$ 的截止点（在所给范围之外）

当 $V_{ov} = 0$，即 $3 - V_X = V_{TH}(V_X)$ 时，$M_1$ 截止。令 $u = \sqrt{0.9 + V_X}$，则 $V_X = u^2 - 0.9$：

$$
\begin{aligned}
3 - (u^2 - 0.9) &= 0.7 + 0.45u - 0.45(0.9487)\\
3.9 - u^2 &= 0.2731 + 0.45u\\
u^2 + 0.45u - 3.6269 &= 0\\
u &= \frac{-0.45 + \sqrt{0.2025 + 4(3.6269)}}{2} = \frac{-0.45 + 3.8354}{2} = 1.6927\\
V_X &= u^2 - 0.9 = 2.8652 - 0.9 = 1.965\ \mathrm{V}.
\end{aligned}
$$

若没有体效应，截止将发生在 $3 - V_X = 0.7$，即 $V_X = 2.3$ V 处。两个值都高于 1.5 V，因此 $M_1$ 在题目要求的整个范围内都导通。

作为比较，若没有体效应，$V_X = 1.5$ V 时 $V_{ov} = 0.8$ V，$I_X = 0.32\beta$，$g_m = 0.8\beta$：体效应使终点电流减小了一半以上。

### 结果

$M_1$（栅极和漏极接 $V_{DD}$，源极接 $V_X$，衬底接地）**在整个范围内都处于饱和区**，并且

$$I_X = \tfrac12\beta\,(3 - V_X - V_{TH})^2, \qquad g_m = \beta\,(3 - V_X - V_{TH}),$$

$$V_{TH} = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right)\ \mathrm{V}.$$

- $V_{TH}$：$V_X$ = 0、0.5、1.0、1.5 V 时依次为 0.70 → 0.81 → 0.89 → 0.97 V。
- $I_X$：2.65β → 1.44β → 0.61β → 0.14β，大致按二次函数规律下降（向上凹）。过驱动电压起点为 2.3 V，终点为 0.53 V。
- $g_m$：2.3β → 1.69β → 1.11β → 0.53β，几乎线性下降。斜率大小为 $\beta(1+\eta)$，约从 1.24β/V 变为 1.15β/V，比没有体效应时 $\beta$/V 的下降速度更快。
- $M_1$ 要到 $V_X \approx 1.97$ V 才会截止（若无体效应则为 2.3 V），这已超出所给范围。

**常见错误。** 忽略体效应（保持 $V_{TH} = 0.7$ V），尽管源极随 $V_X$ 升高，而衬底一直接地。这样在 1.5 V 处会得到 $I_X = 0.32\beta$ 和 $g_m = 0.8\beta$，电流是正确值的两倍多。

**常见错误。** 认为 $V_X$ 升高时 $M_1$ 会进入线性区。由于始终有 $V_{DS} = V_{GS}$，器件只能处于饱和区或截止。

**常见错误。** 把源极和漏极弄混：把接 $V_{DD}$ 的端子当作源极，会得到 $V_{GS} = 0$（“始终截止”）；把 $V_X$ 当作漏极电压，则会得到随 $V_X$ 增大的 $I_X$。源极是 $V_X$ 节点，因此升高 $V_X$ 会**减小** $V_{GS}$，$I_X$ 和 $g_m = \beta V_{ov}$ 都随之下降。
