# 详细步骤 - R355

**思路。** 由于 $\lambda = 0$，输出电阻（output resistance）以及电压增益都为无穷大，因此采用**输出短路电流**进行计算：信号电流和噪声电流流入同一个输出阻抗，输入参考噪声等于噪声短路电流除以短路跨导（transconductance）。求出每个晶体管的噪声有多少到达输出端，把功率相加，再除以 $g_{m1}^2$。

### 第 1 步 — 输出短路时的小信号模型（small-signal model）

把 $M_1$ 的漏极（也是二极管连接的 $M_3$ 和 $M_4$ 的栅极所在节点）记为 X，尾节点记为 P；输入为 $v_{in} = v_{in1} - v_{in2}$，输出短接到交流地。

- **$M_3$：** 向 X 送入 $g_{m3}(0 - v_X)$，即 X 到交流地之间的电阻 $1/g_{m3}$。
- **$M_4$：** 向输出端送入 $g_{m4}(0 - v_X) = -g_{m4}v_X$。
- **$M_1$：** 从 X 向 P 抽取 $i_1 = g_{m1}(v_{in1} - v_P) + I_{n1}$。
- **$M_2$：** 从输出端向 P 抽取 $i_2 = g_{m2}(v_{in2} - v_P) + I_{n2}$。
- **尾电流源：** 理想，对交流开路，无噪声。

噪声电流（功率谱密度均为 $4kT\gamma g_m$，彼此互不相关）为上面已包含的 $I_{n1}$ 和 $I_{n2}$，流入 X 的 $I_{n3}$，以及流入输出端的 $I_{n4}$。此外 $g_{m1} = g_{m2}$，$g_{m3} = g_{m4}$。从输出节点流入短路线的短路输出电流为

$$I_{out} = \underbrace{\left(-g_{m4}v_X + I_{n4}\right)}_{\text{delivered by } M_4} - \underbrace{i_2}_{\text{drawn by } M_2}.$$

### 第 2 步 — 输入对管中的电流（P 点的 KCL）

尾电流源对交流开路，因此 $i_1 + i_2 = 0$。利用 $g_{m1} = g_{m2}$：

$$
\begin{aligned}
g_{m1}(v_{in1} - v_P) + I_{n1} + g_{m1}(v_{in2} - v_P) + I_{n2} &= 0\\
v_P &= \frac{v_{in1} + v_{in2}}{2} + \frac{I_{n1} + I_{n2}}{2g_{m1}}.
\end{aligned}
$$

代入 $i_1$：

$$
\begin{aligned}
i_1 &= g_{m1}v_{in1} - g_{m1}\frac{v_{in1} + v_{in2}}{2} - \frac{I_{n1} + I_{n2}}{2} + I_{n1}\\
&= \frac{g_{m1}}{2}(v_{in1} - v_{in2}) + \frac{I_{n1} - I_{n2}}{2},
\end{aligned}
$$

且 $i_2 = -i_1$：每个输入器件的噪声平均分配到它自己的支路和（符号相反地）另一个器件中。

### 第 3 步 — 电流镜中的电流（X 点的 KCL）

$M_3$ 送入的电流（加上其噪声）等于 $M_1$ 抽取的电流：

$$-g_{m3}v_X + I_{n3} = i_1\quad\Longrightarrow\quad v_X = \frac{I_{n3} - i_1}{g_{m3}}.$$

由于 $g_{m4} = g_{m3}$，$M_4$ 送入输出端的电流为

$$-g_{m4}v_X + I_{n4} = -\frac{g_{m4}}{g_{m3}}(I_{n3} - i_1) + I_{n4} = i_1 - I_{n3} + I_{n4}.$$

电流镜以单位增益把 $i_1$ 复制到输出端，同时也复制了 $M_3$ 的噪声：$I_{n3}$ 在二极管连接管上产生 $v_X = I_{n3}/g_{m3}$，$M_4$ 再把它转换回 $-I_{n3}$。

### 第 4 步 — 短路输出电流

综合第 1 步到第 3 步：

$$
\begin{aligned}
I_{out} &= (i_1 - I_{n3} + I_{n4}) - i_2 = 2i_1 - I_{n3} + I_{n4}\\
&= g_{m1}(v_{in1} - v_{in2}) + (I_{n1} - I_{n2}) - I_{n3} + I_{n4}.
\end{aligned}
$$

短路跨导为 $G_m = g_{m1}$，并且**四个噪声电流都以单位权重到达输出端**。

### 第 5 步 — 输入参考噪声电压

信号和噪声看到的是同一个输出阻抗，因此除以 $G_m$：

$$v_{n,in} = \frac{I_{n1} - I_{n2} - I_{n3} + I_{n4}}{g_{m1}},$$

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \frac{4kT\gamma\left(g_{m1} + g_{m2} + g_{m3} + g_{m4}\right)}{g_{m1}^2} = \frac{4kT\gamma\left(2g_{m1} + 2g_{m3}\right)}{g_{m1}^2}\\
&= 8kT\gamma\left(\frac{1}{g_{m1}} + \frac{g_{m3}}{g_{m1}^2}\right).
\end{aligned}
$$

每个输入管贡献 $4kT\gamma/g_{m1}$，每个负载管贡献 $4kT\gamma g_{m3}/g_{m1}^2$，与采用电流源负载的全差分（fully differential）差分对相同；较小的 $g_{m3}/g_{m1}$ 能使负载噪声保持较小，这要求 PMOS 负载管具有大的过驱动电压（overdrive voltage）。

### 结果

$$\overline{V_{n,in}^2} = 8kT\gamma\left(\frac{1}{g_{m1}} + \frac{g_{m3}}{g_{m1}^2}\right)$$

- 由于 $\lambda = 0$，增益为无穷大，因此我们采用了输出短路电流；信号给出 $I_{out} = g_{m1}v_{in}$。
- $M_1$、$M_2$：尾电流源为理想时，$I_{n1} - I_{n2}$ 到达输出端（$M_1$ 的部分经电流镜传送）；每个折算到输入端都为 $4kT\gamma/g_{m1}$。
- $M_3$：其噪声电流流过它自身的二极管阻抗，并由 $M_4$ 以增益 1 复制到输出端。$M_4$ 的噪声直接到达输出端。每个折算到输入端都为 $4kT\gamma g_{m3}/g_{m1}^2$。

**常见错误。** 因为电压增益为无穷大，就断定输入参考噪声为零。出于同样的原因，输出噪声也是无穷大；比较短路电流才能得到有限的比值。

**常见错误。** 以为 $M_3$ 是二极管连接的，其噪声就会被抑制。二极管连接把 $I_{n3}$ 转换为栅极电压 $I_{n3}/g_{m3}$，而 $M_4$ 又把它在输出端转换回完整的电流 $I_{n3}$。

**常见错误。** 结果差了一个因子 2，或者计入了尾电流源的噪声。因子 2（$8kT$）来自两个输入器件和两个负载器件；这里尾电流源是理想的，而且即使它有噪声也属于共模（common-mode）噪声。
