# 详细步骤 - R298

**思路。** 当 $\lambda = \gamma = 0$ 时，每个晶体管都只是一个受控电流源，而理想电流源相当于开路。仅凭输出节点的 KCL 就能得出 $v_X = 0$，因此 $Z_{in} = 0$；再由输入节点 X 的 KCL 得到用输入电流表示的 $V_{out}$。

### 第 1 步 — 小信号模型（small-signal model）

把输入节点（$R_S$ 右侧）记为 X。$M_1$ 是从 X 到输出端的共源级（common-source stage），$M_2$ 是从输出端回到 X 的源极跟随器，因此环路 X → $M_1$ → 输出 → $M_2$ → X 只反相一次：**负反馈**。$V_{DD}$ 为交流地，$I_1$、$I_2$ 开路，且没有 $r_O$：

- **$M_1$：** 从输出端流向地的电流 $g_{m1}v_X$。
- **$M_2$：** 从其漏极（交流地）流入其源极 X 的电流 $g_{m2}(v_{out} - v_X)$；由于 $\gamma = 0$，没有 $g_{mb2}$。

设 $i_{in}$ 为经 $R_S$ 流入 X 的小信号电流。

### 第 2 步 — 输出节点的 KCL 迫使 $v_X = 0$

在输出端，$I_1$ 开路，$M_2$ 的栅极不吸取电流，因此唯一的信号电流就是 $M_1$ 的电流：

$$g_{m1}v_X = 0 \quad\Longrightarrow\quad v_X = 0$$

对任何输入电流都成立。输出节点没有到地的电阻性通路，因此 $M_1$ 的漏极电流不能变化，$v_X$ 也就不能变化：环路增益为无穷大，X 是理想的虚地（virtual ground），而输出端会移动到使这一点成立所需的任何电压。

### 第 3 步 — 由节点 X 的 KCL 求输出电压

在 X 点，$I_2$ 开路，$M_1$ 的栅极不吸取电流，因此流入 X 的电流只有 $i_{in}$ 和 $M_2$ 的电流：

$$i_{in} + g_{m2}(v_{out} - v_X) = 0 .$$

代入 $v_X = 0$：

$$
\begin{aligned}
i_{in} + g_{m2}v_{out} &= 0\\
v_{out} &= -\frac{i_{in}}{g_{m2}}.
\end{aligned}
$$

全部输入电流都被 $M_2$ 吸收；为了吸收这一电流，它的栅极（即输出端）必须下降 $i_{in}/g_{m2}$。

### 第 4 步 — 输入阻抗与传递函数

$$Z_{in} = \frac{v_X}{i_{in}} = \frac{0}{i_{in}} = 0 ,$$

因此 $R_S$ 右侧的节点是虚地。于是流过 $R_S$ 的电流只由 $V_{in}$ 决定：

$$i_{in} = \frac{V_{in} - v_X}{R_S} = \frac{V_{in}}{R_S},$$

代入 $v_{out} = -i_{in}/g_{m2}$ 得：

$$\frac{V_{out}}{V_{in}} = -\frac{1}{g_{m2}R_S}.$$

该电路是一个**跨阻放大器**（transimpedance amplifier），$v_{out}/i_{in} = -1/g_{m2}$；$R_S$ 把 $V_{in}$ 转换为输入电流。

### 第 5 步 — 用有限输出电阻验证

加入 $r_{O1}$（输出端到地）和 $r_{O2}$（从 $V_{DD}$，即交流地，到 X）。输出端的 KCL：

$$g_{m1}v_X + \frac{v_{out}}{r_{O1}} = 0 \quad\Longrightarrow\quad v_{out} = -g_{m1}r_{O1}v_X .$$

X 点的 KCL（经 $r_{O2}$ 流入 X 的电流为 $-v_X/r_{O2}$）：

$$i_{in} + g_{m2}(v_{out} - v_X) - \frac{v_X}{r_{O2}} = 0 .$$

代入 $v_{out}$：

$$
\begin{aligned}
i_{in} &= g_{m2}v_X(1 + g_{m1}r_{O1}) + \frac{v_X}{r_{O2}},\\
Z_{in} &= \frac{v_X}{i_{in}} = \frac{1}{g_{m2}(1 + g_{m1}r_{O1}) + 1/r_{O2}} = \frac{r_{O2}}{1 + g_{m2}r_{O2} + g_{m1}g_{m2}r_{O1}r_{O2}}\approx\frac{1}{g_{m1}g_{m2}r_{O1}}.
\end{aligned}
$$

这就是跟随器的输出电阻 $1/g_{m2}$ 除以“一加环路增益 $g_{m1}r_{O1}$”，正符合输入端并联反馈（shunt feedback）的预期。令 $r_{O1}, r_{O2}\to\infty$（$\lambda\to0$），得 $Z_{in}\to0$，与第 4 步一致。

### 结果

$$Z_{in} = 0, \qquad \frac{V_{out}}{V_{in}} = -\frac{1}{g_{m2}R_S}.$$

输出端的 KCL（$I_1$ 理想，$\lambda = 0$，无栅极电流）迫使 $g_{m1}v_X = 0$，因此 X 是虚地。输入电流 $V_{in}/R_S$ 全部被 $M_2$ 吸收，这要求 $v_{out} = -i_{in}/g_{m2}$。（若 $r_O$ 有限：$Z_{in} = r_{O2}/(1 + g_{m2}r_{O2} + g_{m1}g_{m2}r_{O1}r_{O2})\approx 1/(g_{m1}g_{m2}r_{O1})$。）

**常见错误。** 给出有限的 $Z_{in}$，例如 $1/g_{m2}$，这是栅极固定时从跟随器源极看进去的阻抗。而本题中 $M_2$ 的栅极由增益无穷大的 $M_1$ 驱动，反馈使 X 点的阻抗降为零。

**常见错误。** 符号或跨导（transconductance）用错，例如得到 $+1/(g_{m2}R_S)$ 或 $-g_{m1}/g_{m2}$。**流入** X 的电流必须由 $M_2$ 吸收，因此其栅极（即输出端）**下降**：增益为负，且只与 $g_{m2}$ 和 $R_S$ 有关。$g_{m1}$ 只决定 X 被维持在虚地的程度，而在 $\lambda = 0$ 时这种维持是完美的。

**常见错误。** 把 $M_2$ 误认为 PMOS 或共源器件。它的漏极接 $V_{DD}$，栅极接输出端，源极接 X，因此它是一个把输出反馈回 X 的 NMOS 源极跟随器。
