# 详细步骤 - R398

**思路。** 在套用反馈公式**之前**，先检查环路的极性。$M_1$ 是从节点 N 到输出端的共栅级，$M_2$ 是从输出端回到 N 的源极跟随器；两者都是同相的，因此该环路是**正**反馈。先计算环路增益（无穷大，且符号相反），再用 KCL 求出形式上的小信号 $Z_{in}$、增益和 $Z_{out}$，并说明负的输出电阻使偏置点不稳定：电路会锁定，而不是放大。

### 第 1 步 — 小信号模型（small-signal model）

把 $R_S$ 右侧的节点（$M_1$ 和 $M_2$ 的源极）记为 N。于是：

- $R_S$ 接在 in 与 N 之间；
- $M_1$：$v_{gs1} = -v_N$，因此电流 $g_{m1}v_N$ 从 N 向上流入输出端；
- $M_2$：电流 $g_{m2}(v_{out} - v_N)$ 从 $V_{DD}$（交流地）流入 N；
- 两个电流源都相当于开路；不含 $r_O$，没有体效应（body effect），也没有栅极电流；
- $C_{out}$ 是输出端不可避免的电容，用于讨论稳定性。

### 第 2 步 — 环路的极性：正反馈

- $v_N\uparrow$ → $M_1$ 从输出端抽取的电流**减少** → $I_1$ 给输出端充电 → $v_{out}\uparrow$（共栅：同相）；
- $v_{out}\uparrow$ → 跟随器 $M_2$ 抬高其源极电压 → $v_N\uparrow$（同相）。

扰动会**自我加强**，这与返回路径反相的类似电路不同。

**环路增益。** 在输出端接电阻 $R_L$（之后令其趋于无穷大），在 $M_2$ 的栅极处断开环路（这是精确的）并加 $v_t$，令 $V_{in} = 0$。由 N 点的 KCL，$g_{m2}(v_t - v_N) = v_N/R_S + g_{m1}v_N$，得

$$v_N = \frac{g_{m2}v_t}{g_{m1} + g_{m2} + 1/R_S}, \qquad v_{out} = g_{m1}R_Lv_N ,$$

$$\frac{v_{out}}{v_t} = +\frac{g_{m1}g_{m2}R_L}{g_{m1} + g_{m2} + 1/R_S}, \qquad T = -\frac{v_{out}}{v_t} = -\frac{g_{m1}g_{m2}R_L}{g_{m1} + g_{m2} + 1/R_S}.$$

返回信号与测试信号**同号**（$T < 0$），且当 $R_L \to \infty$ 时其幅度为无穷大：电路是再生的。

### 第 3 步 — 形式上的输入阻抗与增益

输出节点的 KCL（此处没有测试源）中只剩下 $M_1$ 的电流：

$$g_{m1}v_N = 0 \quad\Longrightarrow\quad v_N = 0 ,$$

在 N 点加测试电流也不会改变这一点，因此形式上 $Z_{in} = 0$。由 $v_N = 0$，N 点的 KCL 给出

$$
\begin{aligned}
\frac{V_{in}}{R_S} + g_{m2}(V_{out} - 0) &= 0\\
\frac{V_{out}}{V_{in}} &= -\frac{1}{g_{m2}R_S}.
\end{aligned}
$$

这些值描述的是一个平衡点，但（见第 5 步）它并不稳定。

### 第 4 步 — 形式上的输出阻抗：负电阻

令 $V_{in} = 0$，在输出端加 $v_X$，对 N 列 KCL：

$$
\begin{aligned}
-\frac{v_N}{R_S} + g_{m2}(v_X - v_N) - g_{m1}v_N &= 0\\
v_N &= \frac{g_{m2}v_X}{g_{m1} + g_{m2} + 1/R_S}.
\end{aligned}
$$

测试电流向下流过 $M_1$，其漏源电流为 $-g_{m1}v_N$：

$$I_X = -g_{m1}v_N = -\frac{g_{m1}g_{m2}}{g_{m1} + g_{m2} + 1/R_S}\,v_X ,$$

$$Z_{out} = \frac{v_X}{I_X} = -\frac{g_{m1} + g_{m2} + 1/R_S}{g_{m1}g_{m2}} = -\left(\frac{1}{g_{m1}} + \frac{1}{g_{m2}} + \frac{1}{g_{m1}g_{m2}R_S}\right).$$

这是一个**负**电阻：抬高输出电压会使电路从输出端向外**推出**电流，这是正反馈的标志。（反馈公式给出同样的结果：当 $R_L \to \infty$ 时，$R_L/(1 + T) \to -(g_{m1} + g_{m2} + 1/R_S)/(g_{m1}g_{m2})$。）

### 第 5 步 — 稳定性：电路发生锁定

输出端接有 $C_{out}$ 且 $V_{in} = 0$ 时，节点 N（无电容）瞬时跟随，$v_N = g_{m2}v_{out}/(g_{m1} + g_{m2} + 1/R_S)$，$M_1$ 向 $C_{out}$ 送入 $g_{m1}v_N$：

$$C_{out}\frac{dv_{out}}{dt} = g_{m1}v_N = \frac{g_{m1}g_{m2}}{g_{m1} + g_{m2} + 1/R_S}\,v_{out} = \frac{v_{out}}{|Z_{out}|}.$$

因此 $v_{out}(t) = v_{out}(0)\,e^{t/\tau}$，其中 $\tau = C_{out}|Z_{out}|$：在 $s = +1/(C_{out}|Z_{out}|)$ 处有一个**右半平面极点**。任何扰动都会增长，直到某个器件退出饱和区（$M_1$ 截止，或输出碰到电源轨）。该电路是一个锁存器，第 3–4 步得到的形式值描述的是一个无法维持的平衡点。

只有接上正的负载电阻 $R_L < |Z_{out}|$，使净输出电导 $1/R_L - 1/|Z_{out}|$ 为正（等价于 $|T| < 1$），电路才会稳定；而在理想电流源负载下这是不可能的。

### 结果

该环路是**正反馈**：$M_1$（共栅，N → $V_{out}$）和 $M_2$（源极跟随器，$V_{out}$ → N）都是同相的，在 $\lambda = 0$ 且 $I_1$ 理想的条件下，环路增益为无穷大。电路是再生的：其平衡点不稳定（只要输出端有电容，就存在右半平面极点），电路会锁定。形式上的小信号结果为

$$Z_{in} = 0, \qquad \frac{V_{out}}{V_{in}} = -\frac{1}{g_{m2}R_S}, \qquad Z_{out} = -\left(\frac{1}{g_{m1}} + \frac{1}{g_{m2}} + \frac{1}{g_{m1}g_{m2}R_S}\right),$$

其中负的输出电阻是正反馈的标志。

**常见错误。** 不检查环路极性就套用负反馈的方法，为一个“稳定的放大器”给出正的有限 $Z_{out}$，例如 $(1 + g_{m2}R_S)/(g_{m1}g_{m2}R_S)$。两级都是同相的，因此环路是正反馈。

**常见错误。** 把 $M_2$ 当作 PMOS 共源器件（就像返回路径反相的类似电路那样）。这里它是 NMOS 跟随器（漏极接 $V_{DD}$，栅极接输出端，源极接 N），增益为正。

**常见错误。** 把形式上的结果当作一个能正常工作的放大器。小信号代数运算总能给出**某个**平衡点；它是否稳定必须另行检验，这里可以通过 $Z_{out}$ 的符号或输出极点的符号来判断。
