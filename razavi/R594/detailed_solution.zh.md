# 详细步骤 - R594

**思路。** 首先求出开关电容共模反馈所建立的输出共模电平：$M_5$ 必须恰好流过 PMOS 负载提供的电流，这就确定了 $V_X = V_{GS5}$；而 $S_1$ 使输出共模电平比 $V_X$ 高一个跟随器的 $V_{GS}$。然后要求 $M_5$（决定下限）以及 $M_1$、$M_2$（决定上限）保持饱和，并考虑源极高于地电位的 NMOS 器件的体效应。

### 第 1 步 — 共模反馈如何确定输出共模电平

PMOS 负载提供固定的电流，这些电流必须全部流过 $M_1$、$M_2$ 和 $M_5$。共模反馈调节 $M_5$ 的栅极（节点 X），直到 $I_{D5} = 1$ mA（每侧 0.5 mA），因此在没有沟道长度调制的情况下，

$$V_X = V_{GS5}(1\ \mathrm{mA}).$$

在共模设定相位，两个输出都处于 $V_{out,CM}$，跟随器 $M_6$、$M_7$（各 50 µA）使其公共源极比输出低一个 $V_{GS}$，而 $S_1$ 把该节点连接到 X：

$$V_X = V_{out,CM} - V_{GS6} \quad\Longrightarrow\quad V_{out,CM} = V_{GS5} + V_{GS6}.$$

$S_1$ 断开后，$C_1$ 和 $C_2$ 保持 $V_{out} - V_X = V_{GS6}$，并持续把输出共模电平传递到 X，因此同样的输出共模电平得以维持。

### 第 2 步 — $V_{GS5}$（尾电流管）

由 $W/L = 100$，$\mu_nC_{ox}(W/L) = 134\ \mu\mathrm{A/V^2}\times100 = 13.4\ \mathrm{mA/V^2}$，且

$$V_{ov5} = \sqrt{\frac{2I_{D5}}{\mu_nC_{ox}(W/L)}} = \sqrt{\frac{2(1\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.1493}\ \mathrm{V} = 0.386\ \mathrm{V}.$$

$M_5$ 的源极接地，因此 $V_{TH5} = V_{TH0} = 0.7$ V，且

$$V_{GS5} = 0.7 + 0.386 = 1.086\ \mathrm{V} = V_X .$$

### 第 3 步 — $V_{GS6}$（跟随器，计入体效应）与输出共模电平

$$V_{ov6} = \sqrt{\frac{2(50\ \mu\mathrm{A})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.00746}\ \mathrm{V} = 0.086\ \mathrm{V}.$$

跟随器的源极处于 $V_X = 1.086$ V，衬底接地，因此 $V_{SB6} = 1.086$ V：

$$
\begin{aligned}
V_{TH6} &= V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right)\\
&= 0.7 + 0.45\left(\sqrt{0.9 + 1.086} - \sqrt{0.9}\right)\\
&= 0.7 + 0.45\,(1.4094 - 0.9487) = 0.7 + 0.207 = 0.907\ \mathrm{V},\\
V_{GS6} &= V_{TH6} + V_{ov6} = 0.907 + 0.086 = 0.994\ \mathrm{V}.
\end{aligned}
$$

输出共模电平：

$$V_{out,CM} = V_{GS5} + V_{GS6} = 1.086 + 0.994 = 2.08\ \mathrm{V}.$$

**负载管检查。** $M_3$、$M_4$ 各流过 0.5 mA：

$$|V_{ov3}| = \sqrt{\frac{2(0.5\ \mathrm{mA})}{(38.4\ \mu\mathrm{A/V^2})(100)}} = \sqrt{0.2604}\ \mathrm{V} = 0.510\ \mathrm{V},$$

因此当 $V_{out} \le V_{DD} - |V_{ov3}| = 3 - 0.51 = 2.49$ V 时它们处于饱和区，2.08 V 在此范围内。✓

输出共模电平与输入共模电平无关：只要所有器件保持饱和，环路就使 $I_{D5} = 1$ mA，从而 $V_X = 1.086$ V，$V_{out,CM} = 2.08$ V。

### 第 4 步 — 下限：$M_5$ 必须保持饱和

$M_5$ 处于饱和区的条件是其漏极（即尾节点 P）满足

$$V_P \ge V_{ov5} = 0.386\ \mathrm{V}.$$

输入共模电平等于 $V_P$ 加上 $I_{D1} = 0.5$ mA 时的 $V_{GS1}$：

$$V_{ov1} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.0746}\ \mathrm{V} = 0.273\ \mathrm{V}.$$

在临界点，$V_{SB1} = V_P = 0.386$ V：

$$
\begin{aligned}
V_{TH1} &= 0.7 + 0.45\left(\sqrt{0.9 + 0.386} - 0.9487\right) = 0.7 + 0.45\,(1.1342 - 0.9487) = 0.783\ \mathrm{V},\\
V_{in,CM,min} &= V_P + V_{TH1} + V_{ov1} = 0.386 + 0.783 + 0.273 = 1.44\ \mathrm{V}.
\end{aligned}
$$

### 第 5 步 — 上限：$M_1$、$M_2$ 必须保持饱和

$M_1$ 处于饱和区的条件是 $V_D \ge V_G - V_{TH1}$：

$$V_{in,CM} \le V_{out,CM} + V_{TH1}.$$

$V_{TH1}$ 取决于 $V_P$，后者随输入升高。在临界点 $V_{in,CM} = V_{out,CM} + V_{TH1}$，因此

$$V_P = V_{in,CM} - V_{TH1} - V_{ov1} = V_{out,CM} - V_{ov1} = 2.080 - 0.273 = 1.807\ \mathrm{V},$$

且

$$
\begin{aligned}
V_{TH1} &= 0.7 + 0.45\left(\sqrt{0.9 + 1.807} - 0.9487\right) = 0.7 + 0.45\,(1.6453 - 0.9487) = 1.013\ \mathrm{V},\\
V_{in,CM,max} &= V_{out,CM} + V_{TH1} = 2.080 + 1.013 = 3.09\ \mathrm{V}.
\end{aligned}
$$

这超过了 $V_{DD} = 3$ V，因此在电源范围内输入对管永远不会退出饱和区，输入共模电平基本上可以升到 $V_{DD}$。随着输入共模电平升高，其他器件的电压余量（headroom）只会增加（$M_5$ 的 $V_{DS}$ 增大；跟随器和负载不受影响）。

### 第 6 步 — 小结与体效应的作用

$$1.44\ \mathrm{V} \;\le\; V_{in,CM} \;\le\; 3.09\ \mathrm{V}\ (\text{i.e. up to } V_{DD} = 3\ \mathrm{V}).$$

不计体效应时（各处 $V_{TH} = 0.7$ V）：

$$
\begin{aligned}
V_{out,CM} &= 1.086 + 0.7 + 0.086 = 1.87\ \mathrm{V},\\
V_{in,CM,min} &= 0.386 + 0.7 + 0.273 = 1.36\ \mathrm{V},\\
V_{in,CM,max} &= 1.87 + 0.7 = 2.57\ \mathrm{V}.
\end{aligned}
$$

体效应使输出共模电平（经由 $M_6$、$M_7$）升高 0.21 V，使上限临界点处 $M_1$ 的阈值电压（threshold voltage）升高 0.31 V，两者合起来使上限提高了约 0.5 V。

### 结果

共模反馈设定 $V_X = V_{GS5} = 1.086$ V，$V_{out,CM} = V_{GS5} + V_{GS6} = 1.086 + 0.994 \approx 2.08$ V。输入共模范围为

$$\approx 1.44\ \mathrm{V} \le V_{in,CM} \le \approx 3.09\ \mathrm{V},$$

即从 1.44 V（由 $M_5$ 保持饱和决定，此时 $V_{TH1} = 0.78$ V）一直到基本上等于 3 V 电源（$M_1$/$M_2$ 的饱和极限 3.09 V 高于 $V_{DD}$）。若不计体效应，范围将为 1.36 V 至 2.57 V。

**常见错误。** 把输出共模电平只取为 $V_{GS5}$，或者假设一个“典型的”1.5 V。在共模设定相位，X 与跟随器的源极相连，因此输出比 $V_X$ 高一个跟随器的 $V_{GS}$（计入体效应时约 1 V）。

**常见错误。** 忽略 $M_5$ 的电压余量（下限并不只是 $V_{GS1}$），或者把跟随器的 50 µA 电流当作 $M_1$、$M_2$ 的电流，而它们各自流过 0.5 mA。
