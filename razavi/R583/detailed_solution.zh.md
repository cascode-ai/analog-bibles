# 详细步骤 - R583

**思路。** 该电路是一个跟踪保持电路：$S_1$ 闭合时，$C_H$ 以及经缓冲的输出跟随输入；$S_1$ 断开时，$C_H$ 保持最后的值。先确定输入和时钟的时序，再计算每个开关切换时刻的输入值，然后逐段构建输出波形。

### 第 1 步 — 理想特性

对于理想开关，时钟为高电平时 $V_{C_H} = V_{in}$（**跟踪**）。时钟为低电平时，没有任何东西能使 $C_H$ 放电（没有开关漏电，也没有运放输入电流），因此它保持开关断开时刻 $V_{in}$ 的值（**保持**）。运放是一个单位增益跟随器，$V_{out} = V_{C_H}$，既不反相也不缩放。

### 第 2 步 — 输入与时钟的时序

**输入。** $V_{in} = V_0\sin\omega_0 t + V_0$，其中 $V_0 = 0.5$ V：

- 最小值：$0.5 - 0.5 = 0$ V；最大值：$0.5 + 0.5 = 1$ V；平均值：0.5 V；
- 周期：$T_{in} = 1/f_0 = 1/(10\ \mathrm{MHz}) = 100$ ns。

**时钟。** $f_{CK} = 50$ MHz，占空比为 50 %：

- 周期：$T_{CK} = 1/(50\ \mathrm{MHz}) = 20$ ns；
- 高电平（跟踪）相位：$0.5 \times 20\ \mathrm{ns} = 10$ ns；低电平（保持）相位：10 ns。

**每个输入周期的采样数：** $T_{in}/T_{CK} = 100\ \mathrm{ns}/20\ \mathrm{ns} = 5$，是整数，因此波形每 100 ns 严格重复一次。

题中未规定时钟与输入的相对相位；这里选择时钟在 0–10、20–30、40–50、60–70 和 80–90 ns 为高电平。于是 $S_1$ 在 10、30、50、70 和 90 ns **断开**，在 0、20、40、60 和 80 ns **闭合**。

### 第 3 步 — 开关切换时刻的输入值

相位为 $\theta = \omega_0 t = 360^\circ\times t/(100\ \mathrm{ns})$，即每 ns 对应 $3.6^\circ$，且 $V_{in} = 0.5 + 0.5\sin\theta$（单位为 V）。

**开关断开时刻（即保持电平）：**

$$
\begin{aligned}
t = 10\ \mathrm{ns}:&\quad \theta = 36^\circ,\quad V_{in} = 0.5 + 0.5(0.5878) = 0.794\ \mathrm{V},\\
t = 30\ \mathrm{ns}:&\quad \theta = 108^\circ,\quad V_{in} = 0.5 + 0.5(0.9511) = 0.976\ \mathrm{V},\\
t = 50\ \mathrm{ns}:&\quad \theta = 180^\circ,\quad V_{in} = 0.5 + 0.5(0) = 0.500\ \mathrm{V},\\
t = 70\ \mathrm{ns}:&\quad \theta = 252^\circ,\quad V_{in} = 0.5 + 0.5(-0.9511) = 0.024\ \mathrm{V},\\
t = 90\ \mathrm{ns}:&\quad \theta = 324^\circ,\quad V_{in} = 0.5 + 0.5(-0.5878) = 0.206\ \mathrm{V}.
\end{aligned}
$$

**开关闭合时刻（输出在此跳回输入曲线上）：**

$$
\begin{aligned}
t = 0\ (100)\ \mathrm{ns}:&\quad \theta = 0^\circ,\quad V_{in} = 0.500\ \mathrm{V},\\
t = 20\ \mathrm{ns}:&\quad \theta = 72^\circ,\quad V_{in} = 0.5 + 0.5(0.9511) = 0.976\ \mathrm{V},\\
t = 40\ \mathrm{ns}:&\quad \theta = 144^\circ,\quad V_{in} = 0.5 + 0.5(0.5878) = 0.794\ \mathrm{V},\\
t = 60\ \mathrm{ns}:&\quad \theta = 216^\circ,\quad V_{in} = 0.5 + 0.5(-0.5878) = 0.206\ \mathrm{V},\\
t = 80\ \mathrm{ns}:&\quad \theta = 288^\circ,\quad V_{in} = 0.5 + 0.5(-0.9511) = 0.024\ \mathrm{V}.
\end{aligned}
$$

**跟踪段中点**（用于画曲线部分）：$V_{in}(5\ \mathrm{ns}) = 0.5 + 0.5\sin18^\circ = 0.655$ V，$V_{in}(25) = 1.000$ V（峰值），$V_{in}(45) = 0.5 + 0.5\sin162^\circ = 0.655$ V，$V_{in}(65) = 0.5 + 0.5\sin234^\circ = 0.096$ V，$V_{in}(85) = 0.5 + 0.5\sin306^\circ = 0.096$ V。

**跟踪时的斜率。** $dV_{in}/dt = V_0\omega_0\cos\theta$，其中 $V_0\omega_0 = 0.5\ \mathrm{V}\times2\pi\times10^7\ \mathrm{s^{-1}} = 3.14\times10^7$ V/s $= 31.4$ mV/ns。最陡的跟踪斜率为 31.4 mV/ns（在 0 和 50 ns 处）；在峰值和谷值附近为 $\pm9.7$ mV/ns（$\cos72^\circ = 0.309$）。

### 第 4 步 — 逐段画出输出波形

| 时间（ns） | 开关 | $V_{out}$ |
|---|---|---|
| 0 → 10 | 闭合（跟踪） | 跟随 $V_{in}$：0.500 → 0.655 → 0.794 V，上升 |
| 10 → 20 | 断开（保持） | 恒为 **0.794 V** |
| 20 | 闭合 | 从 0.794 跳升到 0.976 V |
| 20 → 30 | 跟踪 | 0.976 → 1.000（25 ns 处为峰值）→ 0.976 V |
| 30 → 40 | 保持 | 恒为 **0.976 V** |
| 40 | 闭合 | 从 0.976 跳降到 0.794 V |
| 40 → 50 | 跟踪 | 0.794 → 0.655 → 0.500 V，下降 |
| 50 → 60 | 保持 | 恒为 **0.500 V** |
| 60 | 闭合 | 从 0.500 跳降到 0.206 V |
| 60 → 70 | 跟踪 | 0.206 → 0.096 → 0.024 V，下降 |
| 70 → 80 | 保持 | 恒为 **0.024 V** |
| 80 | 闭合 | 无跳变：$V_{in}(80) = 0.024$ V 等于保持值 |
| 80 → 90 | 跟踪 | 0.024 → 0.096 → 0.206 V，上升 |
| 90 → 100 | 保持 | 恒为 **0.206 V** |
| 100 | 闭合 | 从 0.206 跳升到 0.500 V；此后波形重复 |

作图时，先用细线画出输入正弦波（0 到 1 V，周期 100 ns）。在 0–10、20–30、40–50、60–70 和 80–90 ns 期间，输出就落在这条曲线上；在每个间隔内，输出是一条水平线，其电平等于上一段跟踪结束时的值，随后以一个竖直跳变回到正弦曲线上。每次跳变的大小等于输入在 10 ns 保持期间变化的量：在正弦曲线最陡处最大（60 ns 处为 0.29 V），在保持期跨过极值点时为零（80 ns 处，因为 75 ns 处的谷值恰好落在保持期中间）。

### 第 5 步 — 几点观察

- 在这种时钟相位下，真正的最小值（75 ns 处的 0 V）落在保持期内，因此输出只降到 0.024 V；峰值（25 ns 处的 1 V）落在跟踪期内，因而会出现在输出中。
- 换一种时钟相位，五个采样时刻会同时平移相同的量，保持电平（0.794、0.976、0.500、0.024、0.206 V）随之改变，但跟踪/保持的图样不变。
- 50 MHz 的采样率超过输入频率的两倍（20 MHz），因此这些采样能够无混叠（aliasing）地表示 10 MHz 的正弦波。
- 实际开关在每次断开时会引入小的负台阶（电荷注入、时钟馈通）；对于理想开关，这些都被忽略。

### 结果

$V_{out}$ 是一个介于 0 与 1 V 之间的**跟踪保持波形**，具有单位增益且不反相。在每个 10 ns 的时钟高电平相位内它跟随正弦波，在每个 10 ns 的低电平相位内保持平坦，因此每个 100 ns 的输入周期内有 5 个采样。若时钟在 0–10、20–30、…… ns 为高电平，则保持电平为

$$0.794\ \mathrm{V},\ 0.976\ \mathrm{V},\ 0.500\ \mathrm{V},\ 0.024\ \mathrm{V},\ 0.206\ \mathrm{V}$$

（分别对应从 10、30、50、70 和 90 ns 开始的保持期），每 100 ns 重复一次。输出在两次采样之间不会归零。

**常见错误。** 画成归零波形，即 $S_1$ 断开时 $V_{out} = 0$。开关断开后没有任何东西使 $C_H$ 放电，因此输出保持最后的值。

**常见错误。** 在整个时钟周期内都画成平坦的阶梯，或者数错采样数。开关闭合时输出跟踪输入，只有在低电平相位才保持平坦；每个输入周期内有 5 个跟踪区间和 5 个保持区间，每个区间长 10 ns。

**常见错误。** 把输出画成反相的，或画成非单位增益。运放是一个跟随器，$C_H$ 接在其同相输入端，因此 $V_{out} = V_{C_H}$。
