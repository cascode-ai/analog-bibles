# Golden Solution - R522

## Reference answer

Both are straight lines through the origin, the same shapes as for the square law. $g_m = 3I_D/(V_{GS}-V_{TH}) \propto I_D$, with slope $3/(V_{GS}-V_{TH})$ instead of $2/(V_{GS}-V_{TH})$. With $\beta = kW/L$, $W/L = 3I_D/[k(V_{GS}-V_{TH})^3] \propto I_D$. At constant overdrive the current density is fixed, so the width and $g_m$ scale with the current.
