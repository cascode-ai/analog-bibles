# 详细步骤 - R522

**思路。** 保持过驱动电压 $V_{ov} = V_{GS} - V_{TH}$ 固定。利用 $g_m/I_D = 3/V_{ov}$ 把 $g_m$ 用 $I_D$ 表示，再由 $I_D = \beta V_{ov}^3/3$ 和 $\beta = kW/L$（$k$ 的单位为 A/V³，是工艺常数）解出所需的 $W/L$。两者都与 $I_D$ 成正比，因此草图是两条过原点的直线，与平方律的图类似。

### 第 1 步 — 恒定过驱动电压下 $g_m$ 随 $I_D$ 的变化

$$\frac{g_m}{I_D} = \frac{\beta V_{ov}^2}{\beta V_{ov}^3/3} = \frac{3}{V_{ov}}
\quad\Longrightarrow\quad
g_m = \frac{3}{V_{ov}}\,I_D .$$

在 $V_{ov}$ 固定时，**$g_m$ 与 $I_D$ 成正比**：一条过原点、斜率为 $3/V_{ov}$ 的直线，其陡度是平方律的 $2/V_{ov}$ 的 1.5 倍。

### 第 2 步 — 恒定过驱动电压下 $W/L$ 随 $I_D$ 的变化

$$I_D = \frac{k}{3}\,\frac WL\,V_{ov}^3
\quad\Longrightarrow\quad
\frac WL = \frac{3I_D}{k\,V_{ov}^3} .$$

在 $V_{ov}$ 固定时，**$W/L$ 与 $I_D$ 成正比**，同样是一条过原点的直线。对于平方律，$W/L = 2I_D/(\mu_nC_{ox}V_{ov}^2)$ 也是线性的；只是斜率不同。

无论器件规律如何，两者都是线性的：在固定的过驱动电压下，单位宽度的电流是固定的，因此两倍的电流需要两倍的宽度，即两个相同的器件并联，而它们的 $g_m$ 也是两倍。器件规律只决定斜率。

### 第 3 步 — 草图的示例数值

取 $V_{ov} = 0.2$ V，$k = 0.24\ \mathrm{mA/V^3}$。两条直线的斜率为

$$
\begin{aligned}
\frac{g_m}{I_D} &= \frac{3}{0.2\ \mathrm{V}} = 15\ \mathrm{V^{-1}},\\
\frac{W/L}{I_D} &= \frac{3}{(0.24\ \mathrm{mA/V^3})(0.2\ \mathrm{V})^3} = \frac{3}{1.92\ \mu\mathrm{A}} = 1.5625\ \text{per }\mu\mathrm{A}.
\end{aligned}
$$

| $I_D$ (µA) | 0 | 50 | 100 | 200 | 400 |
|---|---|---|---|---|---|
| $g_m$ (mS)，向上画 | 0 | 0.75 | 1.5 | 3.0 | 6.0 |
| $W/L$，向下画 | 0 | 78 | 156 | 312 | 625 |

例如，在 $I_D = 100\ \mu\mathrm{A}$ 时：$g_m = 15\ \mathrm{V^{-1}}\times100\ \mu\mathrm{A} = 1.5$ mS，$W/L = 1.5625\times100 = 156$。

**草图。** 在图中的坐标轴上，上半部分是一条从原点出发、斜率为 $3/V_{ov}$ 的直线（$g_m$），下半部分是一条斜率为 $3/(kV_{ov}^3)$ 的直线（$W/L$，向下画）：形状与平方律相同，只是斜率不同。

### 结果

在 $V_{GS} - V_{TH}$ 恒定时：

$$g_m = \frac{3I_D}{V_{GS} - V_{TH}} \propto I_D,\qquad \frac WL = \frac{3I_D}{k\,(V_{GS} - V_{TH})^3} \propto I_D\quad(\beta = kW/L).$$

两条曲线都是**过原点的直线**，形状与平方律相同。$g_m$ 的斜率为 $3/(V_{GS} - V_{TH})$，而不是 $2/(V_{GS} - V_{TH})$。在过驱动电压恒定时，电流密度固定，因此宽度和 $g_m$ 都与电流成比例变化。

**常见错误。** 使用 $g_m = \sqrt[3]{9\beta I_D^2} \propto I_D^{2/3}$，把 $g_m$ 画成曲线。那个形式在 $\beta$ 恒定（$W/L$ 固定）时成立；这里 $W/L$ 随 $I_D$ 增大，而在固定的过驱动电压下，$g_m = 3I_D/V_{ov}$ 与 $I_D$ 成线性关系。

**常见错误。** 把 $W/L$ 画成与 $I_D$ 无关。过驱动电压确定的是**单位宽度**的电流，因此电流越大，器件就必须按比例越宽。
