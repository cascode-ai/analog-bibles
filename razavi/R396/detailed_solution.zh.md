# 详细步骤 - R396

**思路。** $M_1$ 是从节点 N 到输出端的共源放大器，共栅 PMOS 管 $M_2$（源极接输出端，漏极接 N）检测输出电压，并向 N 注入与之成正比的电流：这是电压并联（电压-电流）反馈。求出计入负载的开环阻抗和环路增益 $T = g_{m1}R_S$，除以 $1 + T$，再用直接列 KCL 方程的方法逐一验证。

### 第 1 步 — 小信号模型（small-signal model）

把 $R_S$ 右侧的节点（$M_1$ 的栅极、$M_2$ 的漏极）记为 N。于是：

- $R_S$ 接在 in 与 N 之间；
- $M_2$：栅极接交流地，因此 $v_{sg2} = v_{out}$，它从 out 向 N 流过 $g_{m2}v_{out}$；
- $M_1$：电流 $g_{m1}v_N$ 从 out 流向地；
- 两个电流源都相当于开路；不含 $r_O$，没有体效应（body effect），也没有栅极电流。

下面始终使用的两个 KCL 方程（若有测试电流，再加上测试电流）：

$$\text{out:}\quad g_{m1}v_N + g_{m2}v_{out} = 0,$$
$$\text{N:}\quad \frac{V_{in} - v_N}{R_S} + g_{m2}v_{out} = 0.$$

### 第 2 步 — 拓扑与环路增益

$M_2$ 通过源极检测 $v_{out}$，并向 N 送入 $g_{m2}v_{out}$：这是**电压并联反馈**。它是负反馈：$v_N\uparrow$ → $M_1$ 吸取更多电流 → $v_{out}\downarrow$ → $M_2$ 向 N 注入的电流减少 → $v_N\downarrow$。

在 $M_1$ 的栅极处断开环路（精确，因为栅极无电流），用 $v_t$ 驱动它，并令 $V_{in} = 0$。$M_1$ 从输出端吸取 $g_{m1}v_t$，而输出端只看到 $M_2$ 的源极阻抗 $1/g_{m2}$，因此 $v_{out} = -g_{m1}v_t/g_{m2}$。$M_2$ 把 $g_{m2}v_{out} = -g_{m1}v_t$ 送入 N，N 只有 $R_S$ 一条通路，因此 $v_N = -g_{m1}R_Sv_t$：

$$T = -\frac{v_N}{v_t} = g_{m1}R_S .$$

### 第 3 步 — 输出阻抗

环路断开时，输出端看到的是 $M_2$ 的源极，$R_{out,open} = 1/g_{m2}$；电压检测使其除以 $1 + T$：

$$Z_{out} = \frac{1/g_{m2}}{1 + g_{m1}R_S} = \frac{1}{g_{m2}(1 + g_{m1}R_S)}.$$

**直接验证。** 令 $V_{in} = 0$，在输出端加 $v_X$，N 点的 KCL 给出 $-v_N/R_S + g_{m2}v_X = 0$，因此 $v_N = g_{m2}R_Sv_X$；输出节点的 KCL 给出 $I_X = g_{m1}v_N + g_{m2}v_X = g_{m2}v_X(1 + g_{m1}R_S)$。因此 $Z_{out} = 1/[g_{m2}(1 + g_{m1}R_S)]$ ✓。

### 第 4 步 — 输入阻抗

环路断开时，N 点的电阻（包括 $R_S$）就是 $R_S$，因为 $M_2$ 的漏极和电流源都相当于开路。并联反馈使其除以 $1 + T$：

$$R_{N,closed} = \frac{R_S}{1 + g_{m1}R_S} = R_S\parallel\frac{1}{g_{m1}},$$

它等于 $R_S$ 与单独从 N 看进去的阻抗相并联，因此

$$Z_{in} = \frac{1}{g_{m1}}.$$

**直接验证。** 向 N 注入测试电流 $i_x$（不含 $R_S$），输出节点的 KCL 给出 $g_{m2}v_{out} = -g_{m1}v_N$，N 点的 KCL 给出 $i_x + g_{m2}v_{out} = 0$，因此 $i_x = g_{m1}v_N$，$Z_{in} = 1/g_{m1}$ ✓：环路向 N 返回电流 $-g_{m1}v_N$，就像一个接地的 $1/g_{m1}$ 电阻。

### 第 5 步 — 电压增益

把信号源换成诺顿等效形式（电流 $V_{in}/R_S$ 注入 N，$R_S$ 与之并联），开环跨阻等于 $R_S$ 乘以从 N 到输出端的增益 $-g_{m1}/g_{m2}$：

$$R_{T,open} = \frac{v_{out}}{i_{in}} = R_S\cdot\left(-\frac{g_{m1}}{g_{m2}}\right) = -\frac{g_{m1}R_S}{g_{m2}}.$$

闭合环路：

$$R_{T,closed} = \frac{-g_{m1}R_S/g_{m2}}{1 + g_{m1}R_S}, \qquad \frac{V_{out}}{V_{in}} = \frac{R_{T,closed}}{R_S} = -\frac{g_{m1}}{g_{m2}(1 + g_{m1}R_S)}.$$

**直接验证。** 输出节点的 KCL 给出 $v_{out} = -(g_{m1}/g_{m2})v_N$；N 点的 KCL 给出 $(V_{in} - v_N)/R_S = -g_{m2}v_{out} = g_{m1}v_N$，因此 $v_N = V_{in}/(1 + g_{m1}R_S)$，且

$$\frac{V_{out}}{V_{in}} = -\frac{g_{m1}}{g_{m2}}\cdot\frac{1}{1 + g_{m1}R_S} = -\frac{1/g_{m2}}{R_S + 1/g_{m1}}.\ \checkmark$$

$V_{in}$ 驱动电流经 $R_S$ 流入输入电阻 $1/g_{m1}$，这一电流又在输出端的 $1/g_{m2}$ 上重现。

### 结果

$$Z_{in} = \frac{1}{g_{m1}}, \qquad Z_{out} = \frac{1}{g_{m2}(1 + g_{m1}R_S)}, \qquad \frac{V_{out}}{V_{in}} = -\frac{g_{m1}}{g_{m2}(1 + g_{m1}R_S)} = -\frac{1/g_{m2}}{R_S + 1/g_{m1}}.$$

该电路采用电压并联反馈，环路增益为 $T = g_{m1}R_S$：开环输出电阻（output resistance）$1/g_{m2}$ 和输入节点电阻 $R_S$ 都被除以 $1 + g_{m1}R_S$。

**常见错误。** 把 $M_2$ 当作源极跟随器（source follower），或者当作 NMOS 管。它的栅极接 $V_b$，源极接输出端，漏极接 N，是一个共栅 PMOS 管，把 $v_{out}$ 转换为送入 N 的电流 $g_{m2}v_{out}$。

**常见错误。** 取 $Z_{out} = 1/g_{m2}$，即开环值；环路增益使其降低 $1 + g_{m1}R_S$ 倍。

**常见错误。** 因为 N 只与一个栅极、一个漏极和一个理想电流源相连，就断定 $Z_{in}$ 为无穷大。通过环路，任何 $v_N$ 都会产生返回电流 $-g_{m1}v_N$，因此从 N 看进去相当于 $1/g_{m1}$。
