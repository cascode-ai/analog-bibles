A differential pair uses NMOS input devices with an effective channel length $L = 0.5\ \mu$m and the minimum width $W$ for which the input offset voltage is at most 2 mV, where the only mismatch is the threshold mismatch $\Delta V_{TH} = 0.1\,t_{ox}/\sqrt{WL}$ ($\Delta V_{TH}$ in millivolts, $t_{ox}$ = 90 Å in ångströms, $W$, $L$ in micrometers; that is, $\Delta V_{TH} = 9\ \mathrm{mV\cdot\mu m}/\sqrt{WL}$). If the tail current is 1 mA, what is the maximum differential input swing (peak amplitude of a sinusoid) that gives a THD of 1% (rms sum of the harmonics relative to the fundamental)? Compare the result with the same pair designed for an input offset of at most 5 mV. Use the square-law model with $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$ and assume the pair is otherwise symmetric.
