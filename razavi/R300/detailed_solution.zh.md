# 详细步骤 - R300

**思路。** 当 $\lambda = \gamma = 0$ 时，每个晶体管都只是一个受控电流源，理想电流源则相当于开路。在输出端和 X 点列 KCL 方程。输出端没有电阻性通路，因此 $M_1$ 的信号电流必须全部经 $M_2$ 从 X 取得，这使 X 点看起来就像一个二极管连接（diode-connected）的 $M_1$。传递函数由分压器 $R_S$–$Z_{in}$ 以及从 X 到输出端的增益得到。

### 第 1 步 — 小信号模型（small-signal model）

把输入节点（$R_S$ 右侧）记为 X。$M_2$ 的栅极接固定偏置 $V_b$，源极接输出端，漏极接 X，因此它是一个在输出端与 X 之间传递电流的**共栅**器件。$V_{DD}$ 和 $V_b$ 为交流地，$I_1$、$I_2$ 开路：

- **$M_1$：** 从输出端流向地的电流 $g_{m1}v_X$。
- **$M_2$：** $v_{gs2} = 0 - v_{out}$，因此从 X 流向输出端的漏源电流为 $-g_{m2}v_{out}$；等价地说，**$M_2$ 把 $g_{m2}v_{out}$ 从输出端送到 X**（输出电压升高会增大其源栅电压）。

设 $i_{in}$ 为经 $R_S$ 流入 X 的电流。

### 第 2 步 — 输出节点的 KCL

$g_{m1}v_X$ 经 $M_1$ 流出，$g_{m2}v_{out}$ 经 $M_2$ 流出；$I_1$ 不流过信号电流：

$$g_{m1}v_X + g_{m2}v_{out} = 0 \quad\Longrightarrow\quad v_{out} = -\frac{g_{m1}}{g_{m2}}\,v_X ,$$

即共源级（common-source stage）$M_1$ 以共栅器件 $M_2$ 的输入电阻 $1/g_{m2}$ 为负载时的增益。

### 第 3 步 — 节点 X 的 KCL 与输入阻抗

$i_{in}$ 和 $g_{m2}v_{out}$ 流入 X；$I_2$ 和 $M_1$ 的栅极都不流过信号电流。利用第 2 步的 $g_{m2}v_{out} = -g_{m1}v_X$：

$$
\begin{aligned}
i_{in} + g_{m2}v_{out} &= 0\\
i_{in} - g_{m1}v_X &= 0\\
i_{in} &= g_{m1}v_X ,
\end{aligned}
$$

$$Z_{in} = \frac{v_X}{i_{in}} = \frac{1}{g_{m1}} .$$

$M_1$ 的信号电流 $g_{m1}v_X$ 只能来自 $M_2$，而它又从 X 取得这一电流，因此 X 点的表现就像（经由 $M_2$）**二极管连接**的 $M_1$，结果中不出现 $g_{m2}$。

### 第 4 步 — 传递函数

$R_S$ 与 $Z_{in} = 1/g_{m1}$ 串联：

$$
\begin{aligned}
v_X &= V_{in}\,\frac{Z_{in}}{Z_{in} + R_S} = V_{in}\,\frac{1/g_{m1}}{1/g_{m1} + R_S}\\
&= \frac{V_{in}}{1 + g_{m1}R_S}.
\end{aligned}
$$

利用第 2 步的 $v_{out} = -(g_{m1}/g_{m2})\,v_X$：

$$\frac{V_{out}}{V_{in}} = -\frac{g_{m1}}{g_{m2}}\cdot\frac{1}{1 + g_{m1}R_S} = -\frac{g_{m1}}{g_{m2}(1 + g_{m1}R_S)} .$$

**用电流验证。** $i_{in} = V_{in}/(R_S + 1/g_{m1}) = g_{m1}V_{in}/(1 + g_{m1}R_S)$ 经 $M_2$ 流出，因此 $g_{m2}v_{out} = -i_{in}$，结果相同。当 $g_{m1}R_S\gg1$ 时，增益趋于 $-1/(g_{m2}R_S)$：输入电流 $V_{in}/R_S$ 经 $1/g_{m2}$ 转换为电压。

### 结果

$$Z_{in} = \frac{1}{g_{m1}}, \qquad \frac{V_{out}}{V_{in}} = -\frac{g_{m1}}{g_{m2}\,(1 + g_{m1}R_S)} .$$

$M_2$ 是共栅 PMOS 管，把 $g_{m2}v_{out}$ 从输出端送到 X。由于 $I_1$ 是理想的，$M_1$ 的信号电流 $g_{m1}v_X$ 全部经 $M_2$ 回到 X，因此 X 点看起来就像二极管连接的 $M_1$。

**常见错误。** 取 $Z_{in} = 1/g_{m2}$，这是从 $M_2$ 的**源极**看进去的阻抗。而 X 位于 $M_2$ 的**漏极**，那里的阻抗由 $M_1$ 所需的电流 $g_{m1}v_X$ 决定。

**常见错误。** 把 $M_2$ 的电流方向弄反。它的栅极处于交流地，源极（即输出端）电压升高时，从输出端向下流到 X 的电流**增大**；若取相反方向，就会得到符号错误的结果 $+g_{m1}/[g_{m2}(1 + g_{m1}R_S)]$。

**常见错误。** 把从 X 到输出端的增益 $-g_{m1}/g_{m2}$ 当作总增益。由于 $Z_{in} = 1/g_{m1}$ 很低，$R_S$ 会使输入衰减 $1 + g_{m1}R_S$ 倍。
