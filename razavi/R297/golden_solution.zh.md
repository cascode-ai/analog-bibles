共有三个极点：
- 输入节点，即 $M_1$ 的源极，属于共栅（common-gate）输入：$\omega_{in} = \dfrac{1 + (g_{m1} + g_{mb1})R_S}{R_S(C_{GS1} + C_{SB1})} = \dfrac{1}{[R_S\|\tfrac{1}{g_{m1}+g_{mb1}}](C_{GS1} + C_{SB1})}$。
- 一个位于原点的极点：由于 $\lambda = 0$ 且 $I_1$、$I_2$ 是理想的，节点 X（$M_1$ 的漏极）和输出节点都没有到交流地的电阻性通路，因此直流增益为无穷大。
- 一个由耦合 X 与输出端的 $C_{GD2}$ 决定的有限极点：$\omega_2 = \dfrac{g_{m2}C_{GD2}}{C_XC_{DB2} + (C_X + C_{DB2})C_{GD2}}$，其中 $C_X = C_{GD1} + C_{DB1} + C_{GS2}$ 是 X 点的对地电容。
（零点：$+g_{m2}/C_{GD2}$，位于右半平面。）

在上述电容组合下的精确传递函数为：
$$\frac{V_{out}}{V_{in}} = \frac{-(g_{m1}+g_{mb1})(g_{m2} - C_{GD2}s)}{[1 + (g_{m1}+g_{mb1})R_S + R_S(C_{GS1}+C_{SB1})s]\; s\,[g_{m2}C_{GD2} + (C_XC_{DB2} + C_XC_{GD2} + C_{GD2}C_{DB2})s]}$$
- 由于 $\lambda = 0$，$M_1$ 的漏极电流 $(g_{m1} + g_{mb1})(-V_S)$ 与 $V_X$ 无关，因此输入节点与电路其余部分相互隔离：其极点是精确的。
- X 与输出节点这一对构成经典的密勒积分器（Miller integrator）结构，也就是极点分裂（pole splitting）结构：跨接在 $M_2$ 两端的 $C_{GD2}$ 使响应成为积分器，低频时响应 $\approx -\dfrac{g_{m1}+g_{mb1}}{1 + (g_{m1}+g_{mb1})R_S}\cdot\dfrac{1}{C_{GD2}s}$，第二个极点位于更高频率处。简单的逐节点估算（X 和输出端的电阻都为无穷大，因而在原点有两个极点）是错误的：只有一个极点位于原点。
