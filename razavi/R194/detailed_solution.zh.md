# 详细步骤 - R194

**思路。** 两个输入连在一起，因此激励是纯共模的：在对称电路中，两个输入器件的电流相等，两个共源共栅（cascode）管的电流也相等，两个输出处于相同的电压。对折叠节点应用基尔霍夫电流定律（KCL）即可说明这一点；同时跟踪输出的共同电平以供参考。

### 第 1 步 — 由 KCL 可知两个输出相等

把 PMOS 差分对的公共源极节点记为 S。$M_1$ 的漏极与 $M_3$ 及右侧共源共栅管 $M_6$ 的源极相连；$M_2$ 的漏极与 $M_4$ 及左侧共源共栅管 $M_5$ 的源极相连；$V_{out} = V_{left} - V_{right}$，两者分别取自 $M_5$ 和 $M_6$ 的漏极。在整个扫描过程中 $V_{in1} = V_{in2} = V_{in,CM}$。

依次对 $M_1$ 和 $M_2$ 的折叠节点列 KCL：

$$I_{D1} + I_{M6} = I_N \quad\Longrightarrow\quad I_{M6} = I_N - I_{D1}, \qquad I_{M5} = I_N - I_{D2}.$$

由负载电阻得

$$V_{left} = V_{DD} - R_D(I_N - I_{D2}), \qquad V_{right} = V_{DD} - R_D(I_N - I_{D1}),$$

因此

$$V_{out} = V_{left} - V_{right} = R_D(I_{D2} - I_{D1}).$$

$M_1$ 和 $M_2$ 的栅极电压（$V_{in,CM}$）和源极电压（S）相同，尺寸也相同，它们的漏极又接着相同的共源共栅管和灌电流源，因此两者电流相等：$I_{D1} = I_{D2} = I_{D7}/2$。所以

$$V_{out} = R_D(I_{D2} - I_{D1}) = 0 .$$

交叉连线只决定每个输入器件控制哪一个输出；电流相等时，两个输出被同等程度地拉低。

### 第 2 步 — 输出的共同电平（仅供参考）

由于 $I_{D1} = I_{D2} = I_{D7}/2$，两个输出都位于

$$V_{left} = V_{right} = V_{DD} - R_D\left(I_N - \frac{I_{D7}}{2}\right),$$

因此共同电平随尾电流（tail current）变化。示例设计（参数自由选取）：$\beta_p = \mu_pC_{ox}(W/L)_{1,2} = 2\ \mathrm{mA/V^2}$，$I_{SS} = 200\ \mu$A，$I_N = 300\ \mu$A，$R_D = 5\ \mathrm{k}\Omega$；尾电流管 $M_7$ 的过驱动电压（overdrive voltage）为 0.3 V，即 $V_{SG7} = 1.1$ V，因此 $V_{b2} = 1.9$ V。

**(a) $V_{in,CM}$ 较低和居中时：差分对和尾电流管都饱和。** 每条支路流过 $I_{SS}/2$：

$$V_{left} = V_{right} = V_{DD} - R_D\left(I_N - \frac{I_{SS}}{2}\right) = 3 - (5\ \mathrm{k}\Omega)(300 - 100)\ \mu\mathrm{A} = 2.0\ \mathrm{V}.$$

当 $V_{in,CM}$ 很低时，PMOS 输入器件可能进入线性区（triode region），因为它们的漏极高于 $V_{in,CM} + |V_{THP}|$；但饱和的尾电流管仍迫使每个器件流过 $I_{SS}/2$，因此电平不变。

**(b) 尾电流管退出饱和区（saturation region）。** 源极节点位于 $V_S = V_{in,CM} + V_{SG1}$，其中

$$V_{SG1} = |V_{THP}| + \sqrt{\frac{2(I_{SS}/2)}{\beta_p}} = 0.8 + \sqrt{\frac{2(100\ \mu\mathrm{A})}{2\ \mathrm{mA/V^2}}} = 0.8 + 0.316 = 1.116\ \mathrm{V}.$$

尾电流管保持饱和的条件是 $V_{SD7} \ge V_{SG7} - |V_{THP}|$，即 $V_S \le V_{b2} + |V_{THP}| = 2.7$ V，该条件在下述情况下不再满足：

$$V_{in,CM} > 2.7 - 1.116 = 1.58\ \mathrm{V}.$$

超过这一值后，$M_7$ 处于线性区，尾电流减小；折叠进来的电流减少，共源共栅管的电流就**增大**（$I_N - I_{D7}/2$ 增大），因此两个输出都**下降**。

**(c) 差分对截止。** 当 $V_{in,CM} \ge V_{DD} - |V_{THP}| = 2.2$ V 时，即使 $V_S = V_{DD}$ 也只有 $V_{SG} \le |V_{THP}|$，因此差分对截止，共源共栅管流过全部 $I_N$：

$$V_{left} = V_{right} = V_{DD} - R_DI_N = 3 - (5\ \mathrm{k}\Omega)(300\ \mu\mathrm{A}) = 1.5\ \mathrm{V}.$$

把处于线性区的尾电流管方程与差分对的平方律（square law）方程联立，在几个点上求解，得到：

| $V_{in,CM}$ (V) | 尾电流 (µA) | $V_{left} = V_{right}$ (V) | $V_{out}$ (V) |
|---|---|---|---|
| 0 到 1.58 | 200 | 2.00 | 0 |
| 1.8 | 140 | 1.85 | 0 |
| 2.0 | 51 | 1.63 | 0 |
| 2.2 到 3.0 | 0 | 1.50 | 0 |

（1.58 V 处的转折点取决于所选的 $V_{b2}$ 和器件尺寸；而最终值 $V_{DD} - R_DI_N$ 和截止点 $V_{DD} - |V_{THP}|$ 与它们无关。）

### 结果

$$V_{out} = 0 \quad\text{for the whole sweep } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

相等的输入使 $M_1$ 和 $M_2$ 的电流相等，从而两个共源共栅管的电流相等，两个输出完全相同；草图就是一条落在横轴上的水平线。作为参考，PMOS 差分对和尾电流管都饱和时，输出的共同电平为 $V_{DD} - R_D(I_N - I_{SS}/2)$；当输入共模电平接近 $V_{DD} - |V_{THP}|$ 时，尾电流管退出饱和区，差分对截止，输出降到 $V_{DD} - R_DI_N$。

**常见错误。** 只画出一个输出（例如它在扫描接近上端时从 2.0 V 降到 1.5 V），并把它当作 $V_{out}$。那是输出的共模电平；$V_{left} - V_{right}$ 为零。

**常见错误。** 认为交叉的折叠连接会使共模输入产生差分输出。栅极电压相同时，两个输入器件的电流相同，因此两个输出一起变化。
