# 详细步骤 - R190

**思路。** 两个输入连在一起，因此激励是纯共模（common-mode）的；完全对称的电路两半边的电流和电压完全相同。因此差分输出 $V_{out} = V_A - V_{A'}$ 在整个扫描过程中都为零。下面用支路方程说明这一点，并跟踪两个输出的共同电平以供参考。

### 第 1 步 — 两半边服从相同的方程

把左输出端（$M_3$ 的漏极，$R_1$ 的上端）记为 A，$M_1$ 的漏极（$R_1$ 的下端，它驱动 $M_3$ 的栅极）记为 B；A′ 和 B′ 是它们的镜像节点，P 是 $M_1$、$M_2$ 的公共源极节点。在整个扫描过程中 $V_{in1} = V_{in2} = V_{in,CM}$。

$M_3$ 的栅极不吸取电流，因此 $M_3$ 流过 $I_{D1}$。$M_3$ 饱和时，

$$V_A = V_{DD} - |V_{THP}| - \sqrt{\frac{2I_{D1}}{\beta_p}} + I_{D1}R_1, \qquad \beta_p = \mu_pC_{ox}\left(\frac WL\right)_{3,4},$$

同理，

$$V_{A'} = V_{DD} - |V_{THP}| - \sqrt{\frac{2I_{D2}}{\beta_p}} + I_{D2}R_2 .$$

$M_1$ 和 $M_2$ 的栅极电压（$V_{in,CM}$）和源极电压（$V_P$）相同，尺寸也相同，因此在饱和区（saturation region）它们的电流相等，由 P 点的基尔霍夫电流定律（KCL）得

$$I_{D1} = I_{D2} = \frac{I_{D5}}{2}.$$

由于 $I_{D1} = I_{D2}$ 且 $R_1 = R_2$，两个表达式完全相同，因此

$$V_A = V_{A'} \quad\Longrightarrow\quad V_{out} = V_A - V_{A'} = 0 .$$

若输入器件在 $V_{in,CM}$ 较高时进入线性区（triode region），它们也是以相同的方式、在相同的漏极电压下进入的，因此电流仍然相等。这就是完全匹配的差分对所具有的共模抑制。

### 第 2 步 — 输出的共同电平（仅供参考）

每个输出都等于“二极管”电压 $V_{DD} - |V_{GS3}|$ 加上压降 $I_{D1}R_1$。示例设计（参数自由选取）：$\beta_n = 2\ \mathrm{mA/V^2}$，$\beta_p = 2\ \mathrm{mA/V^2}$，$R_1 = R_2 = 500\ \Omega$，尾电流管取 $V_b = 1$ V，$\mu_nC_{ox}(W/L)_5 = 4.44\ \mathrm{mA/V^2}$，因此

$$I_{SS} = \tfrac12(4.44\ \mathrm{mA/V^2})(1 - 0.7)^2\ \mathrm{V^2} = 200\ \mu\mathrm{A}.$$

**(a) 差分对截止，$V_{in,CM} < 0.7$ V。** 没有电流时 $R_1$ 上没有压降，因此 $M_3$ 的栅极处于其漏极电位，$V_{SG} \approx |V_{THP}|$：

$$V_A = V_{A'} \approx V_{DD} - |V_{THP}| = 2.2\ \mathrm{V}$$

实际中它会略高一些，因为亚阈值（subthreshold）导电会使它缓慢升高。

**(b) 差分对导通，尾电流管处于线性区。** 刚超过 0.7 V 时，尾电流随 $V_{in,CM}$ 增大，每边流过 $I_{D5}/2$。**算例：$V_{in,CM} = 1.0$ V。** 对 P 点列 KCL（$M_5$ 处于线性区），并利用 $M_1$ 饱和的条件：

$$2I_{D1} = (4.44\ \mathrm{mA/V^2})\left[0.3V_P - \tfrac12V_P^2\right], \qquad I_{D1} = \tfrac12(2\ \mathrm{mA/V^2})(1.0 - V_P - 0.7)^2 .$$

由此得 $V_P = 0.082$ V，$I_{D1} = (1\ \mathrm{mA/V^2})(0.218\ \mathrm{V})^2 = 47.4\ \mu$A（验证：$(4.44\ \mathrm{mA/V^2})(0.3\times0.082 - 0.5\times0.082^2) = 94.8\ \mu\mathrm{A} = 2I_{D1}$ ✓）。于是

$$
\begin{aligned}
\sqrt{\frac{2I_{D1}}{\beta_p}} &= \sqrt{\frac{2(47.4\ \mu\mathrm{A})}{2\ \mathrm{mA/V^2}}} = \sqrt{0.0474}\ \mathrm{V} = 0.218\ \mathrm{V},\\
I_{D1}R_1 &= (47.4\ \mu\mathrm{A})(500\ \Omega) = 0.024\ \mathrm{V},\\
V_A = V_{A'} &= 3 - 0.8 - 0.218 + 0.024 = 2.006\ \mathrm{V}.
\end{aligned}
$$

由于 $I_{D1}R_1 = 0.024\ \mathrm{V} < |V_{THP}|$，$M_3$ 处于饱和区。

**(c) 尾电流管饱和。** 当 $V_P = V_b - V_{THN} = 0.3$ V、每个输入器件的电流为 $I_{SS}/2 = 100\ \mu$A 时，$M_5$ 进入饱和，此时

$$V_{in,CM} = 0.3 + 0.7 + \sqrt{\frac{2(100\ \mu\mathrm{A})}{2\ \mathrm{mA/V^2}}} = 1.32\ \mathrm{V}.$$

此后每边的电流固定为 $I_{SS}/2$，因此输出电平保持不变：

$$
\begin{aligned}
V_A = V_{A'} &= V_{DD} - |V_{THP}| - \sqrt{\frac{I_{SS}}{\beta_p}} + \frac{I_{SS}R_1}{2}\\
&= 3 - 0.8 - \sqrt{\frac{200\ \mu\mathrm{A}}{2\ \mathrm{mA/V^2}}} + \frac{(200\ \mu\mathrm{A})(500\ \Omega)}{2}\\
&= 3 - 0.8 - 0.316 + 0.05 = 1.93\ \mathrm{V}.
\end{aligned}
$$

在 $V_{in,CM} = V_B + V_{THN} \approx 1.88 + 0.7 = 2.58$ V 以上，输入器件进入线性区，但尾电流管仍迫使每个输入器件流过 $I_{SS}/2$，因此电平不变。

| $V_{in,CM}$ (V) | 状态 | $V_A = V_{A'}$ (V) | $V_{out}$ (V) |
|---|---|---|---|
| 0 到 0.7 | 差分对截止 | ≈ 2.2 | 0 |
| 0.8 | 差分对导通，尾电流管处于线性区 | 2.12 | 0 |
| 1.0 | 同上 | 2.01 | 0 |
| 1.2 | 同上 | 1.95 | 0 |
| ≥ 1.32 | 尾电流管饱和 | 1.93 | 0 |

### 结果

$$V_{out} = 0 \quad\text{for the whole sweep } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

相等的输入加到对称电路上，两个输出端的电压完全相同，因此草图就是一条落在横轴上的水平线。作为参考，两个输出的共同电平在差分对截止时约为 $V_{DD} - |V_{THP}|$，尾电流管饱和后稳定在 $V_{DD} - |V_{THP}| - \sqrt{I_{SS}/\beta_p} + I_{SS}R_1/2$。

**常见错误。** 只描述一个输出（在本例中它从约 2.2 V 下降到约 1.93 V），并把它当作 $V_{out}$。那是输出的共模电平（common-mode level）；两个输出端之差为零。

**常见错误。** 以“扫描过程中尾电流在变化”为由，认为 $V_{out}$ 不为零。这一变化由两半边平均分担，在 $V_A - V_{A'}$ 中相互抵消。
