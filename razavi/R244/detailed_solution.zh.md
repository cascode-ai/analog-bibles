# 详细步骤 - R244

**思路。** 该电路是电阻负载的电流镜（current mirror），再在 X 与 Y 之间多接一个电阻 $R_2$；其中每条支路接 $R_1$，$M_2$ 为二极管连接（diode-connected），两个栅极都接 X。先证明解满足 $V_X = V_Y$，因此 $R_2$ 中没有电流，曲线与没有 $R_2$ 时相同；然后对 X 点应用 KCL 并结合平方律，求出 $V_X(V_{DD})$。

### 第 1 步 — 区域 $V_{DD} \le 0.7$ V

两个晶体管的 $V_{GS} = V_X$，且任何节点的电压都不可能高于 $V_{DD}$，因此当 $V_{DD} \le 0.7$ V 时两管都截止。剩下的唯一通路 $R_1$–$R_2$–$R_1$ 连接的是两个电位都为 $V_{DD}$ 的点，因此没有电流：

$$V_X = V_Y = V_{DD} \qquad (0 \le V_{DD} \le 0.7\ \mathrm{V}) .$$

### 第 2 步 — 证明晶体管导通时 $V_X = V_Y$

对 X 点和 Y 点列 KCL，其中 $I_{R2} = (V_X - V_Y)/R_2$ 是 $R_2$ 中从 X 流向 Y 的电流：

$$\frac{V_{DD} - V_X}{R_1} = I_{D2} + \frac{V_X - V_Y}{R_2} , \qquad (1)$$

$$\frac{V_{DD} - V_Y}{R_1} + \frac{V_X - V_Y}{R_2} = I_{D1} . \qquad (2)$$

用 (1) 减去 (2)：

$$\frac{V_Y - V_X}{R_1} - \frac{2(V_X - V_Y)}{R_2} = I_{D2} - I_{D1} \quad\Longrightarrow\quad (V_Y - V_X)\left(\frac{1}{R_1} + \frac{2}{R_2}\right) = I_{D2} - I_{D1} . \qquad (3)$$

两个器件的 $V_{GS} = V_X$，且二极管连接的 $M_2$ 处于饱和。

- **若 $M_1$ 饱和**（$V_Y \ge V_X - V_{TH}$），则 $I_{D1} = I_{D2}$（$\lambda = 0$），由 (3) 得 $V_Y - V_X = 0$。
- **若 $M_1$ 处于线性区（triode region）**（$V_Y < V_X - V_{TH}$，因而 $V_Y < V_X$），则 $I_{D1} < I_{D2}$，而 (3) 要求 $V_Y > V_X$，矛盾。

因此唯一的解是

$$V_Y = V_X, \qquad I_{R2} = 0 ,$$

此时 $V_{DS1} = V_{GS1}$，$M_1$ 确实处于饱和。**$R_2$ 连接的两个节点始终处于相同的电压，因此它没有电流，也不起任何作用。**

### 第 3 步 — $V_{DD} > 0.7$ V 时的曲线

由于 $I_{R2} = 0$，(1) 式与没有 $R_2$ 时相同：

$$\frac{V_{DD} - V_X}{R_1} = \frac{\beta}{2}(V_X - V_{TH})^2 .$$

令 $w = V_X - V_{TH}$，$D = V_{DD} - V_{TH}$，两边乘以 $2R_1$ 并取正根：

$$\beta R_1w^2 + 2w - 2D = 0 \quad\Longrightarrow\quad w = \frac{\sqrt{1 + 2\beta R_1D} - 1}{\beta R_1} ,$$

$$V_X = V_Y = V_{TH} + \frac{\sqrt{1 + 2\beta R_1(V_{DD} - V_{TH})} - 1}{\beta R_1} .$$

斜率 $dV_X/dV_{DD} = 1/\sqrt{1 + 2\beta R_1(V_{DD} - V_{TH})}$ 在 $V_{DD} = 0.7$ V 处为 1（平滑地离开 45° 线），随后不断减小，因此曲线上升得越来越慢；当 $V_{DD}$ 较大时，大致按 $V_{TH} + \sqrt{2(V_{DD} - V_{TH})/(\beta R_1)}$ 变化。

**示例。** 取 $\beta R_1 = 10\ \mathrm{V^{-1}}$（例如 $\beta = 1\ \mathrm{mA/V^2}$，$R_1 = 10\ \mathrm{k}\Omega$），无论 $R_2$ 取何值：

| $V_{DD}$ (V) | 0.5 | 0.7 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 |
|---|---|---|---|---|---|---|---|
| $V_X = V_Y$ (V) | 0.50 | 0.70 | 0.86 | 1.01 | 1.12 | 1.21 | 1.29 |

### 结果

与没有 $R_2$ 的电路完全相同：**对所有 $V_{DD}$，$V_X = V_Y$，且 $R_2$ 中没有电流。**

- $0 \le V_{DD} \le 0.7$ V：两个晶体管都截止，$V_X = V_Y = V_{DD}$。
- $V_{DD} > 0.7$ V：二者都跟随
$$V_X = V_Y = V_{TH} + \frac{\sqrt{1 + 2\beta R_1(V_{DD} - V_{TH})} - 1}{\beta R_1},$$
在 0.7 V 处以斜率 1 离开 45° 线，随后上升得越来越慢。

结果与 $R_2$ 无关，因为 $R_2$ 连接的是两个电位相同的节点。

**常见错误。** 认为 $R_2$ 中必然有电流，从而使 $V_Y$ 偏离 $V_X$。式 (3) 表明，在 $M_1$ 饱和时，任何差值 $V_Y - V_X$ 都必须为零。

**常见错误。** 断言 $M_1$ 处于线性区，或认为 $V_Y$ 趋向于零。$V_Y = V_X$ 给出 $V_{DS1} = V_{GS1}$，器件深处于饱和区（saturation region）。

**常见错误。** 把 $R_2$ 当作接地或接 $V_{DD}$ 的负载。它直接连接 X 和 Y，正因为如此，对称性使它不起作用。
