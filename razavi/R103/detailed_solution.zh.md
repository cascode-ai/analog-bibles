# 详细步骤 - R103

**思路。** 测试源 $V_X$ 决定 $M_1$ 的**源极**电压（其栅极固定在 $V_b$）。源极节点的 KCL：$I_X$ 加上晶体管电流等于 $R_S$ 中的电流。跟踪 $M_1$ 的电流：随着源极电压升高，$V_{GS}$ 减小，体效应又使阈值电压（threshold voltage）升高，因此该电流下降，直到器件截止；此后只剩下 $R_S$。

### 第 1 步 — 源极节点的 KCL

$V_X$ 是理想的，因此 $M_1$ 的源极电位就是 $V_X$：

$$V_{GS} = V_b - V_X, \qquad V_{SB} = V_X, \qquad V_{TH}(V_X) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right)\ \mathrm{V}.$$

$I_X$（来自测试源）和漏极电流 $I_{D1}$ 都流入源极节点，并经 $R_S$ 流出：

$$I_X + I_{D1} = \frac{V_X}{R_S} \quad\Longrightarrow\quad I_X = \frac{V_X}{R_S} - I_{D1} .$$

### 第 2 步 — $M_1$ 何时导通、处于哪个工作区？

**截止。** 只要 $V_b - V_X > V_{TH}(V_X)$，$M_1$ 就导通。提高 $V_X$ 会降低 $V_{GS}$ 并提高 $V_{TH}$，因此它在 $V_{X,off}$ 处截止，其中

$$V_b - V_{X,off} = V_{TH}(V_{X,off}).$$

令 $u = \sqrt{0.9 + V_{X,off}}$，上式化为 $u^2 + 0.45u - (V_b + 0.6269) = 0$，因此

$$u = \frac{-0.45 + \sqrt{0.2025 + 4(V_b + 0.6269)}}{2}, \qquad V_{X,off} = u^2 - 0.9 ,$$

由于体效应，该值**略低于 $V_b - 0.7$ V**。

**饱和区还是线性区。** 由于 $V_D = V_{DD} - I_{D1}R_D$，当满足下式时 $M_1$ 处于饱和区：

$$V_{DD} - I_{D1}R_D \ge V_b - V_{TH}(V_X) .$$

若 $R_D$ 以及 $V_X$ 较小时的电流都很大，这一条件就不满足：$M_1$ 起初处于**线性区**，随着 $V_X$ 升高、电流减小而进入饱和区。在截止点附近，电流很小，$M_1$ 总是处于饱和区。

### 第 3 步 — $M_1$ 导通时的 $I_X$

**饱和区：**

$$I_{D1} = \frac12\beta\left(V_b - V_X - V_{TH}(V_X)\right)^2, \qquad I_X = \frac{V_X}{R_S} - \frac12\beta\left(V_b - V_X - V_{TH}(V_X)\right)^2 .$$

**起点。** 在 $V_X = 0$（$V_{TH} = 0.7$ V）处，若 $M_1$ 此时处于饱和区，则

$$I_X(0) = -I_{D1}(0) = -\frac12\beta(V_b - 0.7)^2 ,$$

为负值：晶体管把其电流**注入**电压源 $V_X$。

**斜率。** $V_{GS}$ 以速率 1 下降，$V_{TH}$ 以速率 $\eta = \partial V_{TH}/\partial V_{SB}$ 上升，因此 $dI_{D1}/dV_X = -g_m(1 + \eta) = -(g_m + g_{mb})$，且

$$\frac{dI_X}{dV_X} = \frac{1}{R_S} + g_m + g_{mb} > 0 ,$$

即从共栅（common-gate）器件源极看进去的电导与 $1/R_S$ 并联。$I_X$ 起初**急剧上升**，随着 $g_m$ 在截止点降到零，斜率逐渐减小到 $1/R_S$。$M_1$ 饱和时，$R_D$ 不影响结果。

**过零点：** 当 $I_{D1} = V_X/R_S$ 时 $I_X = 0$，此时的电压就是不接测试源时电路自身稳定的源极电压（以 $R_S$ 为负载、跟随 $V_b$ 的跟随器）。

**若 $M_1$ 起初处于线性区**（$R_D$ 较大），$I_{D1}$ 受 $R_D$ 限制，约为 $(V_{DD} - V_D)/R_D$，其中 $V_D$ 很小；因此 $I_X(0)$ 的负值较小，并且在 $M_1$ 进入饱和之前，曲线在那里也不那么陡。

### 第 4 步 — $V_X \ge V_{X,off}$：只剩电阻

$$I_X = \frac{V_X}{R_S} ,$$

这是一条**过原点的直线**，在 $V_X = V_{DD}$ 时达到 $3\ \mathrm{V}/R_S$。平方律（square law）电流及其斜率在 $V_{X,off}$ 处都为零，因此曲线与这条直线**相切**衔接。

### 第 5 步 — 数值示例

为便于说明，取 $V_b = 1.5$ V，$\beta = 2\ \mathrm{mA/V^2}$，$R_D = R_S = 2\ \mathrm{k}\Omega$。

**在 $V_X = 0$ 处：** $I_{D1} = \frac12(2\ \mathrm{mA/V^2})(0.8\ \mathrm{V})^2 = 0.64$ mA，$V_D = 3 - (0.64\ \mathrm{mA})(2\ \mathrm{k}\Omega) = 1.72$ V $\ge V_b - V_{TH} = 0.8$ V，因此 $M_1$ 处于饱和区。$I_X(0) = -0.64$ mA，起始斜率为 $1/R_S + g_m(1 + \eta) = 0.5\ \mathrm{mS} + (1.6\ \mathrm{mS})(1.237) = 2.48$ mS。

**截止：** $u = (-0.45 + \sqrt{0.2025 + 4\times2.1269})/2 = (-0.45 + 2.9513)/2 = 1.2507$，因此 $V_{X,off} = 1.2507^2 - 0.9 = 0.664$ V（而 $V_b - 0.7 = 0.8$ V）。

| 0 | 0.700 | 0.640 | 0 | −0.640 |
| 0.1 | 0.723 | 0.458 | 0.05 | −0.408 |
| 0.2 | 0.745 | 0.308 | 0.10 | −0.208 |
| 0.325 | 0.771 | 0.163 | 0.163 | 0 |

| 0.664 | 0.836 | 0 | 0.332 | 0.332 |

| 3.0 | — | 0 | 1.50 | 1.500 |

（若 $R_D$ 大得多，例如 10 kΩ，$M_1$ 起初就会处于线性区：在 $V_X = 0$ 时只有约 0.28 mA 的电流，$V_D \approx 0.2$ V，$I_X(0) \approx -0.28$ mA。）

### 结果

$$I_X = \frac{V_X}{R_S} - I_{D1}$$

（源极节点的 KCL），由此得：

- **起点：** 在 $V_X = 0$ 时为负，$I_X(0) = -I_{D1}(0)$（若 $M_1$ 此时处于饱和区，则 $= -\tfrac12\beta(V_b - 0.7)^2$）。
- **上升：** 随着 $M_1$ 的电流减小，$I_X$ 上升，因为 $V_X$（即其源极电压）使 $V_{GS} = V_b - V_X$ 减小，并通过 $V_{SB} = V_X$ 使 $V_{TH}$ 升高。在饱和区，$I_{D1} = \tfrac12\beta(V_b - V_X - V_{TH}(V_X))^2$，斜率为 $1/R_S + g_m + g_{mb}$。
- **可能出现线性区：** 若漏极电压 $V_{DD} - I_{D1}R_D \ge V_b - V_{TH}$，$M_1$ 处于饱和区。若电流和 $R_D$ 都较大，它可能在 $V_X$ 较小时先处于线性区，随着 $V_X$ 升高再进入饱和区。
- **截止**发生在 $V_{X,off}$ 处，其中 $V_b - V_{X,off} = V_{TH}(V_{X,off})$；由于体效应，它略低于 $V_b - 0.7$ V。过零点满足 $I_{D1} = V_X/R_S$。
- **$V_X \ge V_{X,off}$：** $I_X = V_X/R_S$，这是一条过原点的直线，在 $V_X = V_{DD}$ 时达到 $3\ \mathrm{V}/R_S$。
- **转折点：** 可能出现的线性区/饱和区边界，$V_{X,off}$，终值 $3\ \mathrm{V}/R_S$。

**常见错误。** 把 $V_X$ 当作漏极电压，画出随 $V_X$ **增大**的 $I_{D1}$。$V_X$ 加在源极上；提高它会**减小** $V_{GS}$，因此晶体管电流下降。

**常见错误。** 只保留两个电流中的一个。$V_X$ 既要向 $R_S$ 供电，**又**要吸收 $M_1$ 的漏极电流，因此 $I_X$ 起初为负，截止后变为 $V_X/R_S$。

**常见错误。** 把截止点恰好放在 $V_X = V_b - 0.7$ V 处。由于 $V_{SB} = V_X$，截止点附近的阈值更高，因此器件会更早截止（在本例中为 0.664 V，而不是 0.8 V）。
