# 详细步骤 - R196

**思路。** 两个输入连在一起，因此激励是纯共模（common-mode）的；在完全对称的电路中，对称工作点（$V_X = V_Y$）满足所有方程：$V_{out} = 0$。由于负载是交叉耦合的正反馈（positive feedback）对管，还需检查这个工作点是否**稳定**；一旦差分对导通，它就不稳定，这对实际电路很重要。

### 第 1 步 — 对称解：$V_{out} = 0$

把左输出端（$M_1$、$M_3$ 的漏极；$M_4$ 的栅极）记为 X，右输出端（$M_2$、$M_4$ 的漏极；$M_3$ 的栅极）记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P。在整个扫描过程中 $V_{in1} = V_{in2} = V_{in,CM}$。

试取 $V_X = V_Y = V_O$。这时 $M_1$ 和 $M_2$ 的栅极、源极和漏极电压都相同，因此由 P 点的基尔霍夫电流定律（KCL）得 $I_{D1} = I_{D2} = I_{D5}/2$。$M_3$ 的栅极接 Y $= V_O$，漏极接 X $= V_O$，因此 $V_{SG3} = V_{SD3} = V_{DD} - V_O$，$M_4$ 也是如此：每个 PMOS 的行为都与流过 $I_{D5}/2$ 的**二极管连接**（diode-connected）器件完全相同。于是 X 点的 KCL（$I_{D3} = I_{D1}$）和 Y 点的 KCL（$I_{D4} = I_{D2}$）是同一个方程，由同一个 $V_O$ 满足。所以，对于理想的对称电路，

$$V_X = V_Y \quad\Longrightarrow\quad V_{out} = 0 \quad\text{for the whole sweep}.$$

### 第 2 步 — 两个输出的共同电平（仅供参考）

在对称点上，每个 PMOS 都相当于一个二极管，因此

$$V_O = V_{DD} - |V_{GS3}|, \qquad |V_{GS3}| = |V_{THP}| + \sqrt{\frac{2(I_{D5}/2)}{\beta_p}} = |V_{THP}| + \sqrt{\frac{I_{D5}}{\beta_p}},$$

其中 $\beta_p = \mu_pC_{ox}(W/L)_{3,4}$。

- **$V_{in,CM} < V_{THN} = 0.7$ V：** 差分对截止；电流为零的类二极管 PMOS 只要求 $V_{SG} \le |V_{THP}|$，因此输出位于 $V_{DD} - |V_{THP}| = 2.2$ V 与 $V_{DD}$ 之间的某处。
- **差分对导通：** 输出随尾电流的增大而下降，$M_5$ 饱和后稳定在 $V_{DD} - |V_{GS3}(I_{SS}/2)|$。

**示例：** $\beta_p = 0.2\ \mathrm{mA/V^2}$，$I_{SS} = 200\ \mu$A，得

$$|V_{GS3}| = 0.8 + \sqrt{\frac{200\ \mu\mathrm{A}}{0.2\ \mathrm{mA/V^2}}} = 0.8 + 1.0 = 1.8\ \mathrm{V}, \qquad V_O = 3 - 1.8 = 1.2\ \mathrm{V}.$$

### 第 3 步 — 对称点稳定吗？（亚稳态）

对它施加差分扰动：$v_X = +v$，$v_Y = -v$，P 是虚地（virtual ground）。$M_3$ 的栅极接 Y，因此它流入 X 的漏极电流变化量为 $g_{m3}v_{sg3} = g_{m3}(0 - v_Y) = +g_{m3}v$：X **上升**会使 $M_3$ 向 X 注入**更多**电流。计入 $r_{O1}$、$r_{O3}$ 和节点电容 $C$，对 X 点列 KCL：

$$C\frac{dv}{dt} = g_{m3}v - \left(\frac{1}{r_{O1}} + \frac{1}{r_{O3}}\right)v = \left(g_{m3} - \frac{1}{r_{O1}} - \frac{1}{r_{O3}}\right)v .$$

由于 $g_{m3} \gg 1/r_{O1} + 1/r_{O3}$（$g_mr_O \gg 1$），括号内为正，**任何微小的差分扰动都会按指数规律增长**；等价地，环路 $X \to M_4 \to Y \to M_3 \to X$ 的环路增益为

$$[g_{m3}(r_{O1}\parallel r_{O3})]^2 > 1 .$$

**示例**（在 100 µA 下取 $\lambda = 0.05\ \mathrm{V^{-1}}$）：

$$
\begin{aligned}
g_{m3} &= \sqrt{2\beta_pI_D} = \sqrt{2(0.2\ \mathrm{mA/V^2})(100\ \mu\mathrm{A})} = 0.2\ \mathrm{mS},\\
r_{O} &= \frac{1}{\lambda I_D} = \frac{1}{(0.05\ \mathrm{V^{-1}})(100\ \mu\mathrm{A})} = 200\ \mathrm{k}\Omega,\\
g_{m3}(r_{O1}\parallel r_{O3}) &= (0.2\ \mathrm{mS})(100\ \mathrm{k}\Omega) = 20,
\end{aligned}
$$

因此环路增益为 $20^2 = 400 \gg 1$。相比之下，在共模下两个节点一起变化，每个 PMOS 都相当于二极管，因此共同电平是稳定的；只有**差模**（differential-mode）是不稳定的。

**结论。** 理想分析给出 $V_{out} = 0$，但一旦差分对导通，这个平衡状态就是**亚稳态**。在实际电路中，最微小的失配、失调（offset）或噪声都会被再生放大，输出锁存到 X 高 / Y 低（$V_{out}$ 接近 $+V_{DD}$）或相反状态（$V_{out}$ 接近 $-V_{DD}$），具体是哪一个由随机的不平衡决定，而不是由 $V_{in,CM}$ 决定。

### 结果

对于完全对称的电路，

$$V_{out} = 0 \quad\text{for } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

相等的输入使两个输出端的电压完全相同。差分对导通时，每个 PMOS 都有 $V_{SG} = V_{SD}$，表现得像一个二极管，因此共同电平为 $V_{DD} - |V_{GS3}(I_{SS}/2)|$。然而，一旦差分对导通，这个对称状态就是**亚稳态**：交叉耦合负载的环路增益为 $[g_{m3}(r_{O1}\parallel r_{O3})]^2 > 1$，因此任何微小的失配或噪声都会使输出以再生方式到达 $V_{out}$ 接近 $+V_{DD}$ 或 $-V_{DD}$ 的状态。理想分析给出 0；实际电路则会锁存。

**常见错误。** 把一个输出（即共同电平，例如从接近 $V_{DD}$ 下降到 $V_{DD} - |V_{GS3}|$）描述为“$V_{out}$”。题目要求的是两个输出之差，对于理想的对称电路它为零。

**常见错误。** 画出一条随共模输入平滑变化、确定的非零 $V_{out}$ 曲线。非零输出只能来自随机失配引起的锁存，而且其符号无法预测。
