# 详细步骤 - R195

**思路。** 负载是一个**交叉耦合**的 PMOS 对管：$M_3$ 的栅极由**右**输出驱动，$M_4$ 的栅极由**左**输出驱动。小信号分析表明这个负载具有负的差分电阻，因此平衡点不稳定，电路是一个具有两个稳定状态的锁存器。再跟踪扫描过程中的大信号（large-signal）状态，就会看到突然的再生翻转和迟滞。由于题目没有给出尺寸，数值取自一个示例尺寸。

### 第 1 步 — 平衡点处的小信号分析：负电阻负载

把左输出端（$M_1$、$M_3$ 的漏极；$M_4$ 的栅极）记为 X，右输出端（$M_2$、$M_4$ 的漏极；$M_3$ 的栅极）记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P，则 $V_{out} = V_X - V_Y$。由于 $V_{in2} = 3\ \mathrm{V} - V_{in1}$，输入共模电平（common-mode level）为 1.5 V，且 $\Delta V_{in} = 2V_{in1} - 3$ V。

假设在平衡点（$V_{in1} = V_{in2}$，$V_X = V_Y$）所有器件都处于饱和区（saturation region）。对于差分扰动，$v_Y = -v_X$，P 是虚地（virtual ground）。$M_3$ 的源极接交流地，栅极接 Y，因此它注入 X 的电流变化量为

$$i_3 = g_{m3}v_{sg3} = g_{m3}(0 - v_Y) = g_{m3}v_X .$$

X 上升时，$M_3$ 向 X 注入**更多**电流：对节点 X 而言，它是一个与 $r_{O3}$ 并联的**负电导** $-g_{m3}$。在半边电路（half circuit）中对 X 点应用基尔霍夫电流定律（KCL），其中 $M_1$ 抽取 $g_{m1}\Delta v_{in}/2$，并计入其 $r_{O1}$：

$$
\begin{aligned}
g_{m1}\frac{\Delta v_{in}}{2} + v_X\left(\frac{1}{r_{O1}} + \frac{1}{r_{O3}}\right) - g_{m3}v_X &= 0\\
v_X &= -\frac{g_{m1}\,\Delta v_{in}/2}{\dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} - g_{m3}} .
\end{aligned}
$$

对于任何实际的尺寸，都有 $g_{m3} \gg 1/r_{O1} + 1/r_{O3}$（$g_mr_O$ 通常为 10–100），因此 X 点的净电导为**负**。考虑节点电容 $C$，扰动满足 $C\,dv_X/dt = (g_{m3} - 1/r_{O1} - 1/r_{O3})v_X$，并**按指数规律增长**；等价地，环路 $X \to M_4 \to Y \to M_3 \to X$ 的增益为 $[g_{m3}(r_{O1}\parallel r_{O3})]^2 > 1$。

因此平衡点不稳定，不存在增益有限且确定的区域：电路总是稳定在“X 高 / Y 低”或“X 低 / Y 高”状态。它是一个**锁存器**。

### 第 2 步 — 扫描起点（$V_{in1} = 0$）：“+”状态

当 $V_{in1} = 0$、$V_{in2} = 3$ V 时：

- $M_1$：$V_{GS1} = 0 - V_P \le 0$，因此它**截止**，$I_{D1} = 0$。
- 节点 X：没有任何器件从它抽取电流，而 $M_3$（栅极接低电位节点 Y）导通，因此其沟道把 X 拉高，直到 $V_{SD3} = 0$：$V_X = V_{DD} = 3$ V。
- $M_4$：其栅极处于 $V_X = V_{DD}$，因此 $V_{SG4} = 0$，它**截止**。
- 节点 Y：$M_2$（栅极为 3 V）导通，但没有器件向 Y 提供电流，因此 $M_2$ 以零电流把 Y 拉低到 P；尾电流为零时，$M_5$ 把 P 拉到地：$V_Y = V_P \approx 0$。

这一状态是自洽的（$V_{SG3} = 3 - 0 = 3\ \mathrm{V} > 0.8$ V，电流为零且 $V_{SD3} = 0$；$M_4$ 和 $M_1$ 截止），因此

$$V_{out} = V_X - V_Y \approx 3 - 0 = +V_{DD}.$$

尾电流已经**消失**：由于 $M_4$ 截止，$M_5$ 无法迫使其电流流过右支路。

### 第 3 步 — $V_{in1}$ 上升：“+”状态下垂，但持续到平衡点之后

示例尺寸：$\beta_n = \mu_nC_{ox}(W/L)_{1,2} = 2\ \mathrm{mA/V^2}$，$\beta_p = \mu_pC_{ox}(W/L)_{3,4} = 0.2\ \mathrm{mA/V^2}$，尾电流管取 $V_b = 1$ V，$\mu_nC_{ox}(W/L)_5 = 4.44\ \mathrm{mA/V^2}$，得到 $I_{SS} = \tfrac12(4.44\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 200\ \mu$A；计算大信号数值时取 $\lambda = 0$。

一旦 $V_{in1} > V_{THN} + V_P$，$M_1$ 就经 $M_3$ 导通；后者的栅极处于低电位节点 Y，因此仍然强导通。$M_4$ 保持截止，因此 $I_{D2} = 0$，$V_Y = V_P$，全部尾电流都流过 $M_1$ 和 $M_3$。

**$V_{in1} = 1.0$ V 时。** $M_5$ 处于线性区（triode region），对 P 点列 KCL，并利用 $M_1$ 的平方律（square law）：

$$
\begin{aligned}
(4.44\ \mathrm{mA/V^2})\left[0.3V_P - \tfrac12V_P^2\right] &= (1\ \mathrm{mA/V^2})(1.0 - V_P - 0.7)^2\\
3.222V_P^2 - 1.933V_P + 0.09 &= 0\\
V_P &= \frac{1.933 - \sqrt{1.933^2 - 4(3.222)(0.09)}}{2(3.222)} = 0.051\ \mathrm{V},\\
I_{D1} &= (1\ \mathrm{mA/V^2})(0.249\ \mathrm{V})^2 = 62\ \mu\mathrm{A}.
\end{aligned}
$$

$M_3$ 处于线性区，$V_{SG3} - |V_{THP}| = (3 - 0.051) - 0.8 = 2.149$ V：

$$
\begin{aligned}
62\ \mu\mathrm{A} &= (0.2\ \mathrm{mA/V^2})\left[2.149V_{SD3} - \tfrac12V_{SD3}^2\right]\\
V_{SD3} &= 2.149 - \sqrt{2.149^2 - 0.62} = 2.149 - 2.000 = 0.149\ \mathrm{V},\\
V_X &= 3 - 0.149 = 2.85\ \mathrm{V}, \qquad V_{out} = 2.85 - 0.05 = +2.80\ \mathrm{V}.
\end{aligned}
$$

**$V_{in1} = 1.5$ V 时（输入平衡）。** 若 $M_1$ 流过全部 $I_{SS}$，则 $V_P = 1.5 - 0.7 - \sqrt{2(200\ \mu\mathrm{A})/(2\ \mathrm{mA/V^2})} = 0.8 - 0.447 = 0.353$ V，高于 $V_b - V_{THN} = 0.3$ V，因此尾电流管如所假设的那样处于饱和。于是：

$$
\begin{aligned}
V_{SG3} - |V_{THP}| &= (3 - 0.353) - 0.8 = 1.847\ \mathrm{V},\\
200\ \mu\mathrm{A} &= (0.2\ \mathrm{mA/V^2})\left[1.847V_{SD3} - \tfrac12V_{SD3}^2\right]\ \Rightarrow\ V_{SD3} = 1.847 - \sqrt{1.847^2 - 2} = 0.659\ \mathrm{V},\\
V_X &= 2.341\ \mathrm{V}, \qquad V_Y = V_P = 0.353\ \mathrm{V}, \qquad V_{out} = +1.99\ \mathrm{V}.
\end{aligned}
$$

$M_4$ 仍然截止（$V_{SG4} = 3 - 2.341 = 0.659\ \mathrm{V} < 0.8$ V ✓），因此在 $V_{in1} = V_{in2}$ 时，电路**仍稳稳地处于“+”状态**：低电位的 Y 使 $M_3$ 保持强导通，高电位的 X 使 $M_4$ 保持截止。这就是**迟滞**的根源。

### 第 4 步 — 再生翻转

随着 $V_{in1}$ 进一步升高，$V_P = V_{in1} - 1.147$ V 上升，$V_Y = V_P$ 也随之上升。$M_3$ 的栅极驱动 $V_{SG3} = V_{DD} - V_Y$ 减小，因此为了继续流过 $I_{SS}$，它需要更大的 $V_{SD3}$，于是 **X 下降**。当 X 降到 $V_{DD} - |V_{THP}| = 2.2$ V 以下时，$M_4$ 导通并向 Y 供电；Y 升到 $V_P$ 以上，进一步削弱 $M_3$，X 进一步下降，$M_4$ 导通得更强。第 1 步中的环路增益很快就超过一，电路**突然翻转**到“X 低 / Y 高”。

**本例中的翻转起点。** 当 $M_3$ 在 $V_{SD3} = 0.8$ V 下恰好能流过 $I_{SS}$ 时，X 达到 2.2 V：

$$
\begin{aligned}
200\ \mu\mathrm{A} &= (0.2\ \mathrm{mA/V^2})\left[(V_{SG3} - 0.8)(0.8) - \tfrac12(0.8)^2\right]\\
1 &= 0.8(V_{SG3} - 0.8) - 0.32\ \Rightarrow\ V_{SG3} = 2.45\ \mathrm{V},\\
V_Y = V_P &= 3 - 2.45 = 0.55\ \mathrm{V},\\
V_{in1} &= V_P + V_{GS1} = 0.55 + 0.7 + 0.447 = 1.70\ \mathrm{V}.
\end{aligned}
$$

因此“+”分支在 $V_{in1} \approx 1.7$ V 附近结束，此时 $V_{out} \approx 2.2 - 0.55 = +1.65$ V。这时 $M_2$ 勉强导通（$V_{GS2} = 1.30 - 0.55 = 0.75$ V），几乎无法吸收 $M_4$ 开始注入 Y 的电流，因此翻转随即发生。（取 $\lambda = 0.05\ \mathrm{V^{-1}}$ 进行完整的数值求解，得到跳变点为 $V_{in1} \approx 1.72$ V。）

**翻转之后**，电路处于镜像状态：$M_3$ 截止（栅极接高电位节点 Y），$M_1$ 没有电流，X 位于 $V_P$，全部尾电流流过 $M_2$ 和 $M_4$。此时的 $V_{out}$ 等于“+”分支在镜像输入 $3\ \mathrm{V} - V_{in1}$ 处取值的相反数；在 $V_{in1} = 1.7$ V 处即为 $-V_{out}(1.3\ \mathrm{V})$。按第 3 步的方法在 1.3 V 处求解，得 $V_P = 0.186$ V，$I_{D1} = 171\ \mu$A，$V_X = 2.52$ V，$V_{out} = +2.33$ V，因此输出从约 $+1.65$ V 跳到约 $-2.33$ V。随着 $V_{in1}$ 继续升高，$M_2$ 的导通程度减弱；一旦它截止（在 $V_{in1} \approx 2.3$ V 附近，即 0.7 V 的镜像点），电流消失，$V_{out}$ 达到 $-V_{DD}$。

### 第 5 步 — 反向扫描：迟滞

从处于“−”状态的 $V_{in1} = 3$ V 开始减小 $V_{in1}$，同样的过程以镜像方式发生：电路在 $V_{in1} = 1.5$ V 处仍保持“−”状态，直到 $V_{in1} \approx 3 - 1.7 = 1.3$ V 附近才翻转回“+”状态。结果是一个**迟滞回线**：

| $V_{in1}$ (V) | 正向扫描 $V_{out}$ (V) | 反向扫描 $V_{out}$ (V) |
|---|---|---|
| 0 到 0.7 | +3.0 | +3.0 |
| 1.0 | +2.8 | +2.8 |
| 1.3 | +2.33 | 跳变后为 +2.33（跳变前瞬间为 −1.65） |
| 1.5 | +1.99 | −1.99 |
| 1.7 | 跳变前瞬间为 +1.65，之后为 −2.33 | −2.33 |
| 2.0 | −2.8 | −2.8 |
| 2.3 到 3.0 | −3.0 | −3.0 |

翻转点取决于 $\beta_p/\beta_n$ 和 $I_{SS}$。较弱的 PMOS 器件很早就被 $M_1$ 压过，因此迟滞窗口很窄（当 $\beta_p$ 很小时，只在 1.5 V 附近几十毫伏的范围内）；较强的 PMOS 器件使 X 保持高电平的时间更长，窗口更宽；负载非常强时，翻转可能要等到输入电压较低一侧的输入器件（这里是 $M_2$）截止后才会发生，此时 Y 只靠漏电流维持在低电平。在任何情况下，翻转都是突然的，而且**不**发生在 $V_{in1} = V_{in2}$ 处。

### 结果

交叉耦合 PMOS 对管是一个正反馈（负电阻）负载：它在平衡点处的差分电导 $1/r_{O1} + 1/r_{O3} - g_{m3}$ 为负，因此该电路表现为**锁存器**，而不是线性放大器。

- **$V_{in1}$ 较低时。** $M_1$ 截止。$M_3$ 的栅极处于低电位的右节点，它把左输出端拉到 $V_{DD}$ 并使 $M_4$ 保持截止；右节点被 $M_2$ 拉低到 $V_P$ 附近，电流消失。$V_{out} \approx +V_{DD}$。
- **当 $V_{in1}$ 升过** $V_{THN}$ 时，$M_1$ 经 $M_3$ 抽取电流。左节点下垂，右节点随 $V_P$ 上升，但反馈**使“+”状态一直保持到 $V_{in1} = V_{in2}$ 之后**。
- **当 $M_1$ 压过 $M_3$**、X 降到 $V_{DD} - |V_{THP}|$ 以下时，$M_4$ 导通，状态**以再生方式翻转**为 X 低 / Y 高，随后 $V_{out}$ 趋向 $\approx -V_{DD}$。
- **反向扫描时**，翻转发生在镜像对称的位置，从而产生**迟滞**。翻转阈值取决于 $\beta_p/\beta_n$ 和 $I_{SS}$（本例中约为 1.7 V 和 1.3 V）。在中心附近不存在增益有限且确定的区域。

**常见错误。** 把 $M_3$/$M_4$ 当作二极管连接（diode-connected）负载，画出增益为 $g_{m1}/g_{m3}$ 的平滑 S 形曲线。它们的栅极接到的是**对侧**的输出，因此负载电导为 $-g_{m3}$，反馈是正反馈。

**常见错误。** 把负载当作高阻抗的电流源（current source），得到线性增益 $g_{m1}(r_{O1}\parallel r_{O3})$。$-g_{m3}$ 项占主导地位，使平衡点不稳定，因此不存在这样的线性区域。

**常见错误。** 认为在 $V_{in1} = 0$ 时尾电流流过 $M_2$ 和 $M_4$，使右节点为高电平。由于 $M_4$ 的栅极处于高电位的左节点，它是截止的，因此电流消失，右节点为低电平：起始时 $V_{out} \approx +V_{DD}$。
