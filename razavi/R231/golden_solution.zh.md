$V_P \approx 0.14$ V：计入体效应（body effect）时为 0.137 V，不计时为 0.168 V。$M_3$ 和 $M_4$ 的漏极 ≈ 1.84 V；PMOS 基准二极管的漏极 ≈ 1.48 V。

- 电流：$I_T = 5I_{REF} = 500\ \mu$A，因此 $M_1$、$M_2$ 各流过 250 μA。$2(W/L)_N$ 器件经 PMOS 基准二极管吸取 $2I_{REF} = 200\ \mu$A；$M_5$、$M_6$ 复制该电流（200 μA = 0.4$I_T$）。$M_3$、$M_4$ 各流过 $250 - 200 = 50\ \mu$A。
- $V_P$：$M_1$ 的过驱动电压（overdrive voltage）= $\sqrt{2(250\ \mu)/(134\ \mu\times 20)} = 0.432$ V；$V_P = 1.3 - V_{TH}(V_P) - 0.432$，其中 $V_{TH} = 0.7 + 0.45(\sqrt{0.9+V_P}-\sqrt{0.9})$ → $V_{TH} = 0.731$ V，$V_P = 0.137$ V。
- PMOS 基准二极管电流为 200 μA：$|V_{GS}| = 0.8 + \sqrt{2(200\ \mu)/(38.4\ \mu\times20)} = 0.8 + 0.722 = 1.522$ V → 漏极电压为 1.478 V。
- $M_3$、$M_4$ 电流为 50 μA：$|V_{GS}| = 0.8 + \sqrt{2(50\ \mu)/(768\ \mu)} = 0.8 + 0.361 = 1.161$ V → 漏极电压为 1.839 V。（此时 $M_1$、$M_2$ 处于饱和：漏极 1.84 V，栅极 1.3 V。）
- 注：$V_P \approx 0.14$ V 低于 $5(W/L)_N$ 尾电流管（tail device）的过驱动电压（0.273 V），因此在这些尺寸下尾电流管实际上会处于线性区（triode region）；自洽求解得 $V_P \approx 0.165$ V，$I_T \approx 0.42$ mA，$M_3$/$M_4$ 中只有 ≈ 11 μA（漏极 ≈ 2.03 V）。题目中的饱和假设把这一情况排除在外。
