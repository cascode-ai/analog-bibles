# 详细步骤 - R231

**思路。** 在 $\lambda = 0$ 且所有器件都饱和时，每个电流镜（current mirror）都按 $W/L$ 的比例复制其基准电流，因此所有支路电流都可由 $I_{REF}$ 求出。然后，每个所求电压都由决定它的那个器件的平方律（square law）得到：$V_P$ 由 $M_1$ 求出（计入其体效应），PMOS 漏极电压由各二极管连接 PMOS 器件在各自电流下求出。最后检验饱和假设。

### 第 1 步 — 各支路电流

由 $(W/L)_N = (W/L)_P = 10/0.5 = 20$，

$$\mu_nC_{ox}(W/L)_N = (134\ \mu\mathrm{A/V^2})(20) = 2.68\ \mathrm{mA/V^2}, \qquad \mu_pC_{ox}(W/L)_P = (38.4\ \mu\mathrm{A/V^2})(20) = 0.768\ \mathrm{mA/V^2} .$$

**NMOS 电流镜**（栅极接 $M_0$，源极接地）：

$$I_T = \frac{5(W/L)_N}{(W/L)_N}I_{REF} = 5(100\ \mu\mathrm{A}) = 500\ \mu\mathrm{A}, \qquad I_{2N} = \frac{2(W/L)_N}{(W/L)_N}I_{REF} = 200\ \mu\mathrm{A} .$$

**PMOS 电流镜。** $2(W/L)_N$ 器件经 PMOS 基准二极管吸取 200 μA，而 $M_5$、$M_6$ 与该二极管的尺寸和 $V_{SG}$ 都相同，因此

$$I_{D5} = I_{D6} = 200\ \mu\mathrm{A} = 0.4\times500\ \mu\mathrm{A} = 0.4I_T ,$$

与图中所标一致。

**差分对（differential pair）。** 两个栅极电压相等，因此 $I_{D1} = I_{D2} = I_T/2 = 250\ \mu$A。

**负载。** 在 $M_1$ 的漏极，电流 $I_{D1}$ 一部分由 $M_5$ 提供，一部分由 $M_3$ 提供：

$$I_{D3} = I_{D1} - I_{D5} = 250\ \mu\mathrm{A} - 200\ \mu\mathrm{A} = 50\ \mu\mathrm{A}, \qquad I_{D4} = 50\ \mu\mathrm{A} .$$

$M_5$、$M_6$ 提供了输入对管电流的 80 %，因此二极管负载只流过 50 μA（这会增大 $1/g_{m3}$，从而提高增益）。

### 第 2 步 — 由 $M_1$ 求 $V_P$（计入体效应）

电流为 250 μA 时，

$$V_{ov1} = \sqrt{\frac{2I_{D1}}{\mu_nC_{ox}(W/L)_N}} = \sqrt{\frac{2(250\ \mu\mathrm{A})}{2.68\ \mathrm{mA/V^2}}} = \sqrt{0.1866\ \mathrm{V^2}} = 0.432\ \mathrm{V} ,$$

且

$$V_P = V_{in,CM} - V_{GS1} = 1.3\ \mathrm{V} - V_{TH1} - V_{ov1} .$$

$M_1$ 的衬底接地，因此 $V_{SB1} = V_P$，且

$$V_{TH1} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_P} - \sqrt{2|\phi_F|}\right) = 0.7 + 0.45\left(\sqrt{0.9 + V_P} - 0.9487\right) .$$

令 $u = \sqrt{0.9 + V_P}$，即 $V_P = u^2 - 0.9$：

$$
\begin{aligned}
u^2 - 0.9 &= 1.3 - 0.7 - 0.45u + 0.45(0.9487) - 0.432,\\
u^2 + 0.45u - (0.9 + 1.3 - 0.7 + 0.4269 - 0.432) &= 0,\\
u^2 + 0.45u - 1.4950 &= 0 .
\end{aligned}
$$

取正根，

$$u = \frac{-0.45 + \sqrt{0.45^2 + 4(1.4950)}}{2} = \frac{-0.45 + \sqrt{6.1824}}{2} = \frac{-0.45 + 2.4864}{2} = 1.0182 ,$$

$$V_P = u^2 - 0.9 = 1.0368 - 0.9 = 0.137\ \mathrm{V} .$$

验证：$V_{TH1} = 0.7 + 0.45(1.0182 - 0.9487) = 0.7 + 0.0313 = 0.731$ V，$V_P = 1.3 - 0.731 - 0.432 = 0.137$ V ✓。若不计体效应，$V_P = 1.3 - 0.7 - 0.432 = 0.168$ V：阈值电压（threshold voltage）升高 31 mV，使 $V_P$ 降低同样的量。

### 第 3 步 — PMOS 基准二极管的漏极电压

PMOS 的源极和衬底都接 $V_{DD}$，因此 $|V_{TH}| = 0.8$ V。电流为 200 μA 时：

$$|V_{ov}| = \sqrt{\frac{2(200\ \mu\mathrm{A})}{0.768\ \mathrm{mA/V^2}}} = \sqrt{0.5208\ \mathrm{V^2}} = 0.722\ \mathrm{V}, \qquad |V_{GS,ref}| = 0.8 + 0.722 = 1.522\ \mathrm{V} ,$$

$$V_{D,ref} = V_{DD} - |V_{GS,ref}| = 3 - 1.522 = 1.478\ \mathrm{V} .$$

### 第 4 步 — $M_3$ 和 $M_4$ 的漏极电压

电流为 50 μA 时：

$$|V_{ov3}| = \sqrt{\frac{2(50\ \mu\mathrm{A})}{0.768\ \mathrm{mA/V^2}}} = \sqrt{0.1302\ \mathrm{V^2}} = 0.361\ \mathrm{V}, \qquad |V_{GS3}| = 0.8 + 0.361 = 1.161\ \mathrm{V} ,$$

$$V_{D3} = V_{D4} = V_{DD} - |V_{GS3}| = 3 - 1.161 = 1.839\ \mathrm{V} .$$

### 第 5 步 — 检验饱和假设

二极管连接的器件总是饱和的。对于其他器件：

- **$M_1$、$M_2$：** $V_{DS1} = 1.839 - 0.137 = 1.70$ V $\ge 0.432$ V ✓。
- **$M_5$、$M_6$：** $V_{SD5} = 3 - 1.839 = 1.161$ V $\ge |V_{ov}| = 0.722$ V ✓。
- **$2(W/L)_N$ 器件：** 其过驱动电压与 $M_0$ 相同，$V_{ov0} = \sqrt{2(100\ \mu\mathrm{A})/(2.68\ \mathrm{mA/V^2})} = 0.273$ V（因此 $V_{GS0} = V_X = 0.973$ V）；$V_{DS} = 1.478$ V ✓。
- **尾电流管 $5(W/L)_N$：** 过驱动电压同样为 0.273 V，但 $V_{DS} = V_P = 0.137$ V $< 0.273$ V ✗。

因此在这些尺寸下，尾电流管实际上处于**线性区**，与题目的假设相矛盾；上面的数值是在该假设下的答案。若按尾电流管工作在线性区进行自洽求解，$I_T = \mu_nC_{ox}(5\cdot20)\left[V_{ov0}V_P - \tfrac12V_P^2\right]$，得到 $V_P \approx 0.165$ V，$I_T \approx 0.42$ mA，$M_3$/$M_4$ 中只有约 11 μA，其漏极电压约为 2.03 V。实际设计中应把 $V_P$ 抬高到尾电流管的过驱动电压之上，例如提高输入共模电平或加宽 $M_1$、$M_2$。

### 结果

支路电流：$I_T = 500\ \mu$A，$I_{D1} = I_{D2} = 250\ \mu$A，$I_{D5} = I_{D6} = 200\ \mu$A，$I_{D3} = I_{D4} = 50\ \mu$A。

- $V_P = 1.3 - V_{TH1}(V_P) - 0.432\ \mathrm{V} \approx$ **0.137 V**（其中体效应使 $V_{TH1} = 0.731$ V；若忽略体效应则为 0.168 V）。
- $M_3$ 和 $M_4$ 的漏极：$3 - (0.8 + 0.361) \approx$ **1.84 V**。
- PMOS 基准二极管的漏极：$3 - (0.8 + 0.722) \approx$ **1.48 V**。

（尾电流管的 $V_{DS} = V_P$ 低于其 0.273 V 的过驱动电压，因此实际上它会处于线性区；此时自洽解约为 0.165 V 和 2.03 V。）

**常见错误。** 认为 $M_3$/$M_4$ 流过 $M_1$/$M_2$ 的全部 250 μA（或 $M_5$/$M_6$ 的 200 μA）。由基尔霍夫电流定律（KCL），二极管负载只提供 $250 - 200 = 50\ \mu$A；若用 250 μA，漏极电压会算成约 1.4 V，而不是 1.84 V。

**常见错误。** 忽略 $M_1$ 的体效应，或者把它写成 $\sqrt{|\phi_F| + V_{SB}}$。源极在 $V_P$、衬底接地时，应使用 $\sqrt{2|\phi_F| + V_{SB}}$，其中 $2|\phi_F| = 0.9$ V，阈值电压升高到 0.731 V。

**常见错误。** 把尾电流（tail current）取为 $I_{REF}$ 或 $2I_{REF}$。尾电流管的尺寸为 $5(W/L)_N$，$V_{GS}$ 与 $M_0$ 相同，因此它流过 $5I_{REF} = 500\ \mu$A。
