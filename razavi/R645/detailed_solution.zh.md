# 详细步骤 - R645

**思路。** 振荡频率为 $f = 1/(2\pi\sqrt{LC_{tot}})$，其中 $C_{tot} = C_{var} + C_1$。变容二极管电容最大（$V_R = 0$）时频率最低，电容最小（$V_R = 2$ V）时频率最高；求出变容二极管在两端的电容值，再取两个频率之比。

### 第 1 步 — 控制范围两端的变容二极管电容

$C_1$ 与变容二极管并联，因此 $C_{tot}(V_R) = C_0/(1 + V_R/\phi_B)^m + C_1$，且电容随反向偏置的增大而减小。

**$V_R = 0$ 时：**

$$C_{var}(0) = \frac{C_0}{(1 + 0)^{0.35}} = C_0 .$$

**$V_R = 2$ V 时：**

$$
\begin{aligned}
1 + \frac{V_R}{\phi_B} &= 1 + \frac{2\ \mathrm{V}}{0.7\ \mathrm{V}} = 1 + 2.857 = 3.857,\\
(3.857)^{0.35} &= e^{0.35\ln3.857} = e^{0.35\times1.3499} = e^{0.4725} = 1.604,\\
C_{var}(2\ \mathrm{V}) &= \frac{C_0}{1.604} = 0.624\,C_0 \approx 0.62\,C_0 .
\end{aligned}
$$

由于 $m = 0.35$ 使电容随电压的变化很弱，在 2 V 的范围内，变容二极管本身的电容只变化 $1/0.624 = 1.60$ 倍。

### 第 2 步 — 最低、最高频率与调谐比

$C_1$ 在两端都存在：

$$f_{min} = \frac{1}{2\pi\sqrt{L\,(C_0 + C_1)}}, \qquad f_{max} = \frac{1}{2\pi\sqrt{L\,(0.624\,C_0 + C_1)}}.$$

两式相除，再把分子和分母同除以 $C_0$：

$$\frac{f_{max}}{f_{min}} = \sqrt{\frac{C_0 + C_1}{0.624\,C_0 + C_1}} = \sqrt{\frac{1 + C_1/C_0}{0.624 + C_1/C_0}} .$$

以 $f_{min}$ 为基准的调谐范围为

$$\frac{f_{max} - f_{min}}{f_{min}} = \sqrt{\frac{1 + C_1/C_0}{0.624 + C_1/C_0}} - 1 .$$

由于 $f \propto 1/\sqrt{C}$，电容变化 1.6 倍时，频率最多只变化 $\sqrt{1.6} \approx 1.27$ 倍。

### 第 3 步 — 数值结果

| $C_1/C_0$ | $f_{max}/f_{min}$ | $(f_{max} - f_{min})/f_{min}$ | 相对于中心频率的调谐范围 |
|---|---|---|---|
| 0 | 1.266 | 26.6 %（≈ 27 %） | 23.5 % |
| 0.25 | 1.196 | 19.6 % | 17.9 % |
| 0.5 | 1.155 | 15.5 % | 14.4 % |
| 1 | 1.110 | 11.0 % | 10.4 % |
| 2 | 1.069 | 6.9 % | 6.7 % |
| 5 | 1.033 | 3.3 % | 3.2 % |

（最后一列为 $(f_{max} - f_{min})/[(f_{max} + f_{min})/2]$，这是表示调谐范围的另一种常用方式。）

**固定电容较大时。** 当 $x = C_1/C_0 \gg 1$ 时，$\sqrt{(1 + x)/(0.624 + x)} = \sqrt{1 + 0.376/(0.624 + x)} \approx 1 + 0.188/x$，因此

$$\frac{f_{max} - f_{min}}{f_{min}} \approx 0.19\,\frac{C_0}{C_1} .$$

例如，按这一近似，$C_1 = 5C_0$ 时只剩下约 3.8 %（精确值为 3.3 %）。

$C_1$ 不随 $V_R$ 变化，却在两端都计入总电容，因此它稀释了总电容的相对变化。固定的寄生电容总会缩小调谐范围，这就是变容二极管必须在谐振回路电容中占很大比例的原因。

### 结果

由 $C_{var}(2\ \mathrm{V}) = C_0/(1 + 2/0.7)^{0.35} \approx 0.62\,C_0$ 得

$$\frac{f_{max}}{f_{min}} = \sqrt{\frac{C_0 + C_1}{0.62\,C_0 + C_1}} = \sqrt{\frac{1 + C_1/C_0}{0.62 + C_1/C_0}},$$

即调谐范围为 $\sqrt{(1 + C_1/C_0)/(0.62 + C_1/C_0)} - 1$：$C_1 = 0$ 时约为 27 %，$C_1/C_0 = 0.25$ 时为 19.6 %，0.5 时为 15.5 %，1 时为 11 %，2 时为 6.9 %，$C_1 \gg C_0$ 时约为 $0.19\,C_0/C_1$。固定电容总会使调谐范围减小。

**常见错误。** 忘记开方，把电容比当作频率比（例如 $C_1 = 0$ 时给出 60 % 的范围）。频率按 $1/\sqrt{C}$ 变化。

**常见错误。** 只在范围的一端计入 $C_1$，或把它与变容二极管串联。它是并联的恒定电容，因此 $f_{min}$ 和 $f_{max}$ 中都有它。

**常见错误。** 认为 $C_1$“增加了电容”，所以会扩大调谐范围。给最大和最小总电容加上同样的量，会**减小**二者之比。
