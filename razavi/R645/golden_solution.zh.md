$\dfrac{f_{max}}{f_{min}} = \sqrt{\dfrac{C_0 + C_1}{0.62\,C_0 + C_1}}$，因此调谐范围为 $\sqrt{\dfrac{1 + C_1/C_0}{0.62 + C_1/C_0}} - 1$：$C_1 = 0$ 时为 27%，$C_1/C_0 = 0.25$ 时为 19.6%，0.5 时为 15.5%，1 时为 11.0%，2 时为 6.9%（$C_1 \gg C_0$ 时 ≈ $0.19\,C_0/C_1$）。固定电容总会使调谐范围缩小。

推导：
- $C_{var}(2\ \mathrm{V}) = C_0/(1 + 2/0.7)^{0.35} = C_0/3.857^{0.35} = 0.62\,C_0$（0.624）。
- $V_R = 0$ 时 $f_{min} = 1/[2\pi\sqrt{L(C_0 + C_1)}]$；$V_R = 2$ V 时 $f_{max} = 1/[2\pi\sqrt{L(0.62C_0 + C_1)}]$。
- 比值如上；$C_1 = 0$ 时为 $1/\sqrt{0.62} = 1.27$，即不计电感电容时得到的 27%。
