# 详细步骤 - R095

思路： $M_1$ 是共源（common-source）输入器件。其负载是由 $R_1$、$R_2$ 和 $M_2$ 组成的网络：$M_2$ 的栅极位于跨接在 $V_{DD} - V_{out}$ 上的分压器抽头处，因此该负载是一个“$V_{GS}$ 倍增器”（其电压被分压器按比例放大的 PMOS 二极管）。先证明 $M_2$ 只要导通就处于饱和区，然后跟踪曲线：在 $M_2$ 导通之前负载为电阻 $R_1 + R_2$，之后进入软钳位；导通点和各段斜率由基尔霍夫电流定律（KCL）和小信号模型（small-signal model）求得。

### 第 1 步 — $M_2$ 的栅极电压与 KCL

把 $M_2$ 的栅极节点（即 $R_1$–$R_2$ 的抽头）记为 $G$。栅极没有电流，因此 $R_1$ 和 $R_2$ 对 $V_{DD} - V_{out}$ 分压：

$$I_R = \frac{V_{DD} - V_{out}}{R_1 + R_2}, \qquad V_{SG2} = I_RR_1 = (V_{DD} - V_{out})\frac{R_1}{R_1 + R_2} .$$

$M_2$ 的源漏电压是整个 $V_{DD} - V_{out}$，因此它只要导通就处于饱和区：

$$V_{SD2} = V_{DD} - V_{out} \ge V_{SG2} > V_{SG2} - |V_{THP}| .$$

当 $V_{SG2} > 0.8$ V 时它导通，即

$$V_{DD} - V_{out} > 0.8\left(1 + \frac{R_2}{R_1}\right)\ \mathrm{V},$$

等价地，当分压器电流达到 $I_R = 0.8\ \mathrm{V}/R_1$ 时导通。输出节点的 KCL：

$$I_{D1} = \frac{V_{DD} - V_{out}}{R_1 + R_2} + I_{D2}, \qquad I_{D2} = \frac{\beta_2}{2}\left[(V_{DD} - V_{out})\frac{R_1}{R_1 + R_2} - 0.8\right]^2\ \text{(when on)}.$$

### 第 2 步 — $M_2$ 导通之前：先为 $V_{DD}$，然后是陡峭的电阻性下降

当 $V_{in} \le 0.7$ V 时，$M_1$ 截止，因此分压器电流为零，且

$$V_{out} = V_{DD} = 3\ \mathrm{V}.$$

一旦 $M_1$ 导通，只要 $V_{DD} - V_{out} < 0.8(R_1 + R_2)/R_1$，$M_2$ 就截止，负载仅为 $R_1 + R_2$。在 $M_1$ 饱和时：

$$V_{out} = V_{DD} - (R_1 + R_2)\,\frac{\beta_1}{2}(V_{in} - 0.7)^2, \qquad \frac{dV_{out}}{dV_{in}} = -(R_1 + R_2)\,\beta_1(V_{in} - 0.7) = -g_{m1}(R_1 + R_2) .$$

$R_1 + R_2$ 很大，因此只要 $g_{m1}$ 稍有增大，这段下降就很陡峭。

### 第 3 步 — $M_2$ 导通：转折点

当 $V_{DD} - V_{out} = 0.8(1 + R_2/R_1)$，即 $M_1$ 的电流等于 $0.8/R_1$ 时，$M_2$ 导通。若此时 $M_1$ 仍处于饱和：

$$
\begin{aligned}
\frac{\beta_1}{2}(V_{in} - 0.7)^2 &= \frac{0.8\ \mathrm{V}}{R_1}\\
V_{in} &= 0.7 + \sqrt{\frac{1.6\ \mathrm{V}}{\beta_1R_1}} .
\end{aligned}
$$

只有当 $V_{in} = 3$ V 之前能到达这一点，且 $0.8(1 + R_2/R_1) < 3$ V 时，扫描范围内才会出现钳位（否则输出必须降到 0 V 以下才能使 $M_2$ 导通）。

### 第 4 步 — $M_2$ 导通：软钳位

$M_2$ 一旦导通，就吸收 $M_1$ 电流的大部分进一步增量。利用 $V_{SG2} = 0.8 + \sqrt{2I_{D2}/\beta_2}$ 和 $V_{DD} - V_{out} = V_{SG2}(R_1 + R_2)/R_1$：

$$V_{DD} - V_{out} = \left(1 + \frac{R_2}{R_1}\right)\left[0.8 + \sqrt{\frac{2I_{D2}}{\beta_2}}\right].$$

$V_{SG2}$ 只随 $\sqrt{I_{D2}}$ 增大，因此 $V_{DD} - V_{out}$ 保持在 $0.8(1 + R_2/R_1)$ 附近，只缓慢增大：输出被钳位。

负载的小信号模型。 以 $V_{DD}$ 为交流地：$R_1$ 接在 $g$ 与地之间，$R_2$ 接在 $g$ 与 $out$ 之间；$M_2$（源极接地，栅极接 $g$，漏极接 $out$）向 $out$ 注入电流 $g_{m2}v_{sg2} = -g_{m2}v_g$；$M_1$ 从 $out$ 吸取电流 $g_{m1}v_{in}$。

在 $out$ 处加测试电压 $v_x$，由分压关系得 $v_g = v_xR_1/(R_1 + R_2)$；负载吸取的电流 $i_x$ 等于流过 $R_2$ 的电流加上 $M_2$ 吸取的电流：

$$
\begin{aligned}
i_x &= \frac{v_x}{R_1 + R_2} + g_{m2}v_g = \frac{v_x}{R_1 + R_2} + g_{m2}\frac{R_1}{R_1 + R_2}v_x = \frac{1 + g_{m2}R_1}{R_1 + R_2}\,v_x,\\
R_{load} &= \frac{v_x}{i_x} = \frac{R_1 + R_2}{1 + g_{m2}R_1} .
\end{aligned}
$$

斜率：

$$\frac{dV_{out}}{dV_{in}} = -g_{m1}R_{load} = -\frac{g_{m1}(R_1 + R_2)}{1 + g_{m2}R_1} \approx -\frac{g_{m1}}{g_{m2}}\left(1 + \frac{R_2}{R_1}\right)\quad (g_{m2}R_1 \gg 1).$$

导通时 $g_{m2} = 0$，因此斜率与电阻性区域连续衔接。随着 $M_2$ 电流的增大，$g_{m2}R_1$ 很快变大，斜率减小到约 $(g_{m1}/g_{m2})(1 + R_2/R_1)$：曲线急剧弯折，进入钳位状态。

### 第 5 步 — $M_1$ 进入线性区

若 $V_{out}$ 降到 $V_{in} - 0.7$ V 以下（通常发生在输入范围的上部），$M_1$ 进入线性区：其 $g_m$ 下降，并出现沟道电导，因此斜率进一步减小，曲线趋于平缓，在 $V_{in} = 3$ V 时到达一个较低的终值。

若 $M_1$ 在 $M_2$ 导通之前就达到 $V_{out} = V_{in} - 0.7$ V（例如 $R_2/R_1$ 较大时，导通所需的压降 $0.8(1 + R_2/R_1)$ 很大），则两个转折的顺序相反。

### 第 6 步 — 数值示例

为便于说明，取 $R_1 = R_2 = 10\ \mathrm{k}\Omega$，$\beta_1 = 0.5\ \mathrm{mA/V^2}$，$\beta_2 = 10\ \mathrm{mA/V^2}$。

- 电阻性区域： $V_{out} = 3 - (20\ \mathrm{k}\Omega)(0.25\ \mathrm{mA/V^2})(V_{in} - 0.7)^2 = 3 - 5(V_{in} - 0.7)^2$，斜率为 $-10(V_{in} - 0.7)$。
- $M_2$ 导通： $V_{DD} - V_{out} = 0.8\times2 = 1.6$ V，因此 $V_{out} = 1.4$ V，对应 $V_{in} = 0.7 + \sqrt{1.6/(0.5\ \mathrm{mA/V^2}\times10\ \mathrm{k}\Omega)} = 0.7 + \sqrt{0.32} = 1.266$ V。
- 钳位： 在 $V_{in} = 1.5$ V 处，$I_{D1} = 0.16$ mA，$V_{out} = 1.166$ V，$V_{SG2} = 0.917$ V，$I_{D2} = 0.068$ mA，$g_{m2} = 1.17$ mS，$g_{m1} = 0.4$ mS；斜率 $= -(0.4\ \mathrm{mS})(20\ \mathrm{k}\Omega)/(1 + 11.7) = -0.63$。
- $M_1$ 进入线性区的位置为 $V_{in} \approx 1.73$ V（$V_{out} \approx 1.03$ V）。

### 结果

这是一个反相特性：

- $V_{in} \le 0.7$ V： 没有电流，$V_{out} = V_{DD}$。
- $M_1$ 导通、$M_2$ 截止（当 $V_{DD} - V_{out} < 0.8(R_1 + R_2)/R_1$ 时）：$V_{out} = V_{DD} - (R_1 + R_2)\cdot\tfrac12\beta_1(V_{in} - 0.7)^2$，斜率为 $-g_{m1}(R_1 + R_2)$，很陡。
- $V_{DD} - V_{out} > 0.8(1 + R_2/R_1)$： $M_2$ 导通，并吸收大部分新增电流。$V_{DD} - V_{out} = (1 + R_2/R_1)[0.8 + \sqrt{2I_{D2}/\beta_2}]$ 缓慢增大；增量负载为 $(R_1 + R_2)/(1 + g_{m2}R_1)$，斜率 $\approx -g_{m1}(R_1 + R_2)/(1 + g_{m2}R_1)$（当 $g_{m2}R_1 \gg 1$ 时 $\approx -(g_{m1}/g_{m2})(1 + R_2/R_1)$）。
- 由于 $V_{SD2} = V_{DD} - V_{out} \ge V_{SG2}$，$M_2$ 只要导通就处于饱和区。
- 若 $V_{out} < V_{in} - 0.7$ V，$M_1$ 进入线性区，斜率进一步减小。
- 转折点： $V_{in} = 0.7$ V；$V_{out} = V_{DD} - 0.8(1 + R_2/R_1)$（$M_2$ 导通，此时流过 $R_1 + R_2$ 的电流达到 $0.8/R_1$），若此时 $M_1$ 仍处于饱和，则对应 $V_{in} = 0.7 + \sqrt{1.6/(\beta_1R_1)}$；$V_{out} = V_{in} - 0.7$ V。只有当 $0.8(1 + R_2/R_1) < 3$ V 且在 $V_{in} = 3$ V 之前到达导通点时，才会出现钳位；后两个转折可能以任一顺序出现。

常见错误： 把 $V_{SG2}$ 取为整个 $V_{DD} - V_{out}$，仿佛 $M_2$ 是二极管连接（diode-connected）的，或者把分压比弄反。只有比例为 $R_1/(R_1 + R_2)$ 的那部分表现为 $V_{SG2}$，因此 $M_2$ 在 $V_{DD} - V_{out} = 0.8(1 + R_2/R_1)$ 处导通。

常见错误： 认为 $M_2$ 导通时可能处于线性区。它的 $V_{SD}$ 是整个 $V_{DD} - V_{out}$，总是大于 $V_{SG2}$。

常见错误： 只把负载当作电阻（从而一路陡降），或只把它当作二极管。$M_2$ 导通之前负载为 $R_1 + R_2$；导通之后负载变为小得多的 $(R_1 + R_2)/(1 + g_{m2}R_1)$，正是它产生了钳位。
