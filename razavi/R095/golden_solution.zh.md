# 参考答案 - R095

## 参考答案

反相：在 $M_1$ 导通之前为 $V_{DD}$；只有 $R_1 + R_2$ 作为输出端负载时急剧下降；$M_2$ 导通后，负载成为“$V_{GS}$ 倍增器”，输出进入软钳位（clamp）状态，$V_{DD} - V_{out}$ 保持在 $|V_{THP}|(1 + R_2/R_1)$ 附近，只缓慢增大。

- 栅极没有电流，因此 $M_2$ 的栅极位于 $R_1$–$R_2$ 的分压抽头处：$V_{SG2} = (V_{DD} - V_{out})\dfrac{R_1}{R_1+R_2}$；$V_{SD2} = V_{DD} - V_{out} \ge V_{SG2}$，因此 $M_2$ 只要导通就处于饱和区（saturation region）。
- $V_{in} \le 0.7$ V：没有电流，$V_{out} = V_{DD}$。
- $M_1$ 导通、$M_2$ 截止（当 $V_{DD} - V_{out} < 0.8(R_1+R_2)/R_1$ 时）：$V_{out} = V_{DD} - (R_1+R_2)\cdot\tfrac12\beta_1(V_{in} - 0.7)^2$，斜率为 $-g_{m1}(R_1+R_2)$（陡峭）。
- $V_{DD} - V_{out} > 0.8(1 + R_2/R_1)$：$M_2$ 导通，并吸收大部分新增电流；$V_{DD} - V_{out} = (1 + R_2/R_1)\left[0.8 + \sqrt{2I_{D2}/\beta_2}\right]$ 缓慢增大；增量负载为 $(R_1+R_2)/(1 + g_{m2}R_1)$，斜率 ≈ $-g_{m1}(R_1+R_2)/(1 + g_{m2}R_1)$（当 $g_{m2}R_1 \gg 1$ 时 ≈ $-(g_{m1}/g_{m2})(1 + R_2/R_1)$）。
- 若 $V_{out} < V_{in} - 0.7$ V（在输入范围的上端附近），$M_1$ 进入线性区（triode region），斜率进一步减小。
- 转折点：$V_{in} = 0.7$ V；$V_{out} = V_{DD} - 0.8(1 + R_2/R_1)$（$M_2$ 导通，此时流过 $R_1 + R_2$ 的电流达到 $0.8/R_1$），若此时 $M_1$ 仍处于饱和，则对应 $V_{in} = 0.7 + \sqrt{1.6/(\beta_1R_1)}$；$V_{out} = V_{in} - 0.7$ V。只有当 $V_{in} = 3$ V 之前能到达这一导通点，且 $0.8(1 + R_2/R_1) < 3$ V 时，扫描范围内才会出现钳位。若 $M_1$ 在 $M_2$ 导通之前就达到 $V_{out} = V_{in} - 0.7$ V，则两个转折的顺序相反；只要理由充分，两种顺序都可以接受。

## 评分说明

+2：说明输出先保持 $V_{DD}$，随后在 $R_1+R_2$ 负载下陡降，$M_2$ 在 $V_{DD}-V_{out}=|V_{THP}|(R_1+R_2)/R_1$ 处导通并形成缓慢下降的钳位，且指出 $M_2$ 导通时处于饱和区。+1：描述了钳位但缺少导通点或饱和区论证。0：只给出反相趋势，且把负载仅当作二极管或电阻。若明确断言 $V_{SG2}$ 等于完整的 $V_{DD}-V_{out}$、分压比例倒置、特性不反相，或 $M_2$ 导通时处于线性区，则扣 2 分。正确说明钳位在扫描范围内出现所需的条件不扣分。
