栅极处约为 11.9 mV（峰峰值），与 $V_{sub}$ 同相：衬底电压升高会使 $V_{TH1}$ 降低、$I_{D1}$ 增大，与 $V_{in}$ 升高的效果相同。

- 衬底起背栅（back gate）的作用：$\Delta I_{D1} = g_{mb}V_{sub}$，相当于一个栅极电压 $v_{eq} = (g_{mb}/g_m)V_{sub} = \eta V_{sub}$。
- $\eta = \gamma/(2\sqrt{2|\phi_F| + V_{SB}}) = 0.45/(2\sqrt{0.9}) = 0.237$（平均而言 $V_{SB} = 0$）。
- $g_m = \sqrt{2 \times 134\ \mu \times 200 \times 1\ \mathrm{mA}} = 7.32$ mS，$g_{mb} = 1.74$ mS；漏极电流扰动为 $1.74\ \mathrm{mS} \times 50\ \mathrm{mV} = 87\ \mu$A（峰峰值）；折算到栅极：$87\ \mu\mathrm{A}/7.32\ \mathrm{mS} = 11.9$ mV（峰峰值）。
- 结果与 W/L 和 $I_D$ 无关（它们在 $g_{mb}/g_m$ 中相互抵消）。对于 ±25 mV，由大信号阈值变化 $\gamma(\sqrt{0.925} - \sqrt{0.875})$ 得到同样的 11.9 mV。
