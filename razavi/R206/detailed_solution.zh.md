# 详细步骤 - R206

**思路。** 在差分半边电路中（$\lambda = 0$），每个输出端接有一个二极管连接的 PMOS（$M_5$，电导 $+g_{m5}$）和交叉耦合对管中的一个器件（$M_3$，栅极接**对侧**输出），后者贡献 $-g_{m3}$。由基尔霍夫电流定律（KCL）得 $A_v = -g_{m1}/(g_{m5} - g_{m3})$。对于数值情形，可以由 $g_{m5}$ 求出 $g_{m3}$，因为平衡时 $M_3$ 和 $M_5$ 的栅源电压**相同**。

### 第 1 步 — 半边电路的小信号模型（small-signal model）

把左输出端（$M_1$、$M_3$、$M_5$ 的漏极）记为 X，右输出端记为 Y。取 $v_{in1} = +v_d/2$、$v_{in2} = -v_d/2$，由对称性得 $v_Y = -v_X$，公共源极节点 P 是虚地。在 $\lambda = 0$ 时，X 点处的元件为：

- **$M_1$：** 从 X 抽取 $g_{m1}v_d/2$。
- **$M_5$（二极管）：** 其电流 $g_{m5}v_{gs5} = g_{m5}v_X$ 流出 X，相当于电导 $+g_{m5}$。
- **$M_3$（交叉耦合）：** 栅极接 Y，因此它流出 X 的电流为 $g_{m3}v_{gs3} = g_{m3}v_Y = -g_{m3}v_X$，相当于电导 $-g_{m3}$：X 上升时，$M_3$ 向 X 注入**更多**电流。

### 第 2 步 — X 点的 KCL 与一般增益表达式

$$g_{m1}\frac{v_d}{2} + g_{m5}v_X - g_{m3}v_X = 0 \quad\Longrightarrow\quad v_X = -\frac{g_{m1}}{g_{m5} - g_{m3}}\cdot\frac{v_d}{2}.$$

由 $v_{out} = v_X - v_Y = 2v_X$ 得：

$$A_v = \frac{v_{out}}{v_{in1} - v_{in2}} = -\frac{g_{m1}}{g_{m5} - g_{m3}} .$$

交叉耦合对管抵消了一部分二极管电导，因此净负载电导很小、增益很高；只要 $g_{m3} < g_{m5}$，电路就保持稳定。

### 第 3 步 — $W_{3,4} = 0.8W_{5,6}$ 时 $g_{m3}$ 与 $g_{m5}$ 的关系

在偏置点 $V_X = V_Y$。$M_5$ 的栅极接 X，$M_3$ 的栅极接 Y，两者的源极都接 $V_{DD}$，因此

$$V_{SG3} = V_{DD} - V_Y = V_{DD} - V_X = V_{SG5}.$$

在过驱动电压（overdrive voltage）$V_{ov} = V_{SG} - |V_{THP}|$ 相同、沟道长度相等的条件下，由平方律（square law）得

$$\frac{I_3}{I_5} = \frac{\tfrac12\mu_pC_{ox}(W_3/L)V_{ov}^2}{\tfrac12\mu_pC_{ox}(W_5/L)V_{ov}^2} = \frac{W_3}{W_5} = 0.8 ,$$

又由于在过驱动电压相同时 $g_m = 2I_D/V_{ov}$，

$$\frac{g_{m3}}{g_{m5}} = \frac{2I_3/V_{ov}}{2I_5/V_{ov}} = \frac{I_3}{I_5} = 0.8 \quad\Longrightarrow\quad g_{m3} = 0.8\,g_{m5}.$$

**增益：**

$$A_v = -\frac{g_{m1}}{g_{m5} - 0.8g_{m5}} = -\frac{g_{m1}}{0.2\,g_{m5}} = -5\,\frac{g_{m1}}{g_{m5}} .$$

### 第 4 步 — 用器件参数表示同一结果

在偏置点对 X 点列 KCL 得 $I_{D1} = I_5 + I_3 = I_5 + 0.8I_5 = 1.8I_5$，因此 $I_5 = I_{D1}/1.8$，且

$$
\begin{aligned}
g_{m1} &= \sqrt{2\mu_nC_{ox}(W/L)_1I_{D1}},\\
g_{m5} &= \sqrt{2\mu_pC_{ox}(W/L)_5\frac{I_{D1}}{1.8}},\\
\frac{g_{m1}}{g_{m5}} &= \sqrt{\frac{1.8\,\mu_n(W/L)_1}{\mu_p(W/L)_5}},\\
|A_v| &= 5\sqrt{1.8}\sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_5}} \approx 6.7\sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_5}} .
\end{aligned}
$$

若采用流过全部 $I_{D1}$ 的普通二极管负载，则 $|A_v| = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_5]}$；因此在器件尺寸相同的情况下，交叉耦合对管使增益提高了约 6.7 倍。

**数值感受：** 若 $\mu_n(W/L)_1 = 3.5\,\mu_p(W/L)_5$，则 $|A_v| = 6.7\sqrt{3.5} = 6.7\times1.87 \approx 12.5$。

### 结果

$$A_v = -\frac{g_{m1}}{g_{m5} - g_{m3}}, \qquad\text{and for } W_{3,4} = 0.8W_{5,6}:\quad A_v = -5\,\frac{g_{m1}}{g_{m5}} \approx -6.7\sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_5}} .$$

左输出端看到的是二极管 $M_5$（电导 $g_{m5}$）以及栅极由右输出（$-v_X$）驱动、因而注入 $g_{m3}v_X$ 的 $M_3$：净电导为 $g_{m5} - g_{m3}$。平衡时 $M_3$ 和 $M_5$ 的 $V_{SG}$ 相同，因此 $I_3/I_5 = W_3/W_5 = 0.8$，$g_{m3} = 0.8g_{m5}$。

**常见错误。** 用 $g_m \propto \sqrt{W}$ 得出 $g_{m3} = \sqrt{0.8}\,g_{m5} = 0.89g_{m5}$，从而得到约 $9g_{m1}/g_{m5}$。这一规律只在**电流**相等时成立；这里两个器件的**过驱动电压**相等，因此 $g_m$ 与 $W$ 成正比。

**常见错误。** 把电导相加，得到 $g_{m1}/(g_{m5} + g_{m3})$，好像 $M_3$ 也是一个二极管。它的栅极接在对侧输出上，而对侧输出变化 $-v_X$。

**常见错误。** 忽略交叉耦合对管（$A_v = -g_{m1}/g_{m5}$），或者断言该电路是锁存器（latch）。在 $W_3 < W_5$ 时，净电导 $0.2g_{m5}$ 仍为正，因此电路是一个稳定的高增益放大器。
