# 详细步骤 - R022

**思路。** 先判断 $M_1$ 的哪个扩散区端（diffusion terminal）充当源极，说明此时 $M_1$ 始终处于饱和区（saturation region），再利用平方律（square law）在 $V_{out}$ 处列出基尔霍夫电流定律（KCL）方程。$V_{in}$ 只通过体效应（body effect）起作用：衬底（bulk）相当于第二个栅极（“背栅”，back gate）。我们逐点求解所得方程，求出斜率和凹凸性，最后指出源-衬底结从何处开始正向偏置（forward-biased）。

### 第 1 步 — 哪一端是源极？

由图可知：

- $M_1$ 的栅极接 $+2$ V。
- 一个扩散区端（画有箭头的那一端）由电池保持在 $+2$ V。
- 另一个扩散区端即 $V_{out}$，经 $R_1$ 接地。
- 衬底由 $V_{in}$ 驱动（虚线），其值从 0 扫到 3 V。

MOSFET 是对称器件。对 NMOS 而言，电位*较低*的扩散区端就是**源极**，因为电子正是从那里进入沟道的。符号中的箭头只是一种画图习惯，并不能决定哪一端是源极。

$R_1$ 把 $V_{out}$ 拉向地。在各个结都截止的情况下，能向 $R_1$ 提供电流的唯一路径是沟道，其电流来自 2 V 端。因此 $V_{out} < 2$ V，并且：

- $V_{out}$ 端是**源极**（$V_S = V_{out}$）；
- $+2$ V 端是**漏极**（$V_D = 2$ V）。

*检验另一种选择是否自洽。* 假设 2 V 端是源极，则 $V_{GS} = 2 - 2 = 0 < V_{TH}$，沟道截止，$R_1$ 会把 $V_{out}$ 拉到 0 V。但这样一来 $V_{out}$ 端反而成了电位较低的一端，此时 $V_{GS} = 2\ \mathrm{V} > V_{TH}$，沟道*应当*导通。这一矛盾说明 2 V 端不可能是源极。

### 第 2 步 — 端电压与工作区

由 $V_G = 2$ V、$V_D = 2$ V、$V_S = V_{out}$ 和 $V_B = V_{in}$ 得：

$$
\begin{aligned}
V_{GS} &= 2 - V_{out},\\
V_{DS} &= 2 - V_{out},\\
V_{SB} &= V_{out} - V_{in}.
\end{aligned}
$$

其中 $V_{SB}$ 为源-衬底电压。饱和要求 $V_{DS} \ge V_{GS} - V_{TH}$，其中 $V_{TH}$ 为阈值电压（threshold voltage）。由于 $V_{DS} = V_{GS}$（栅极和漏极都接 2 V），只要 $V_{TH} > 0$，该条件就自动满足。所以**只要 $M_1$ 导通，它就处于饱和区**：它是一个栅极与漏极同电位的源极跟随器（source follower）。

$V_{TH}$ 是否总为正？在下面的公式仍然适用的范围内，其最小值出现在 $V_{SB} = -0.9$ V 处：

$$V_{TH} = 0.7 + 0.45(0 - 0.9487) = 0.27\ \mathrm{V} > 0 .$$

因此上述关于饱和区的论证始终成立。

### 第 3 步 — 控制方程

**计入体效应的阈值电压：**

$$V_{TH} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right) = 0.7 + 0.45\left(\sqrt{0.9 + V_{out} - V_{in}} - 0.9487\right).$$

其中 $V_{TH0} = 0.7$ V 为 $V_{SB} = 0$ 时的阈值，$\gamma$ 为体效应系数（body-effect coefficient），$2|\phi_F| = 0.9$ V。当衬底电位升高（$V_{in}\uparrow$）时，$V_{SB}$ 减小，**阈值随之降低**：衬底的作用就像一个较弱的第二栅极。

**平方律饱和电流**（题中未给出，故取 $\lambda = 0$）：

$$I_D = \frac12\,\beta\,(V_{GS} - V_{TH})^2 = \frac12\,\beta\,(2 - V_{out} - V_{TH})^2, \qquad \beta = \mu_nC_{ox}\frac{W}{L}.$$

**输出节点的 KCL。** 沟道电流流入 $R_1$；衬底结截止时，其电流可以忽略：

$$\frac{V_{out}}{R_1} = \frac12\,\beta\,(2 - V_{out} - V_{TH})^2 .$$

开平方并取正根，因为对于导通的器件，过驱动电压（overdrive voltage）$V_{ov} = V_{GS} - V_{TH}$ 为正：

$$2 - V_{out} - V_{TH} = \sqrt{\frac{2V_{out}}{\beta R_1}} .$$

解出 $V_{out}$：

$$V_{out} = 2 - V_{TH}(V_{out} - V_{in}) - \sqrt{\frac{2V_{out}}{\beta R_1}} .$$

$\beta$ 和 $R_1$ 都未给定，因此结果取决于乘积 $\beta R_1$（单位为 $\mathrm{V^{-1}}$）。我们先取**轻载极限**（light-load limit）$\beta R_1 \to \infty$，此时过驱动项消失；然后再说明有限的 $\beta R_1$ 如何使曲线移动（第 6 步）。

### 第 4 步 — 轻载曲线：求解 $V_{out} + V_{TH} = 2$ V

当 $\beta R_1 \to \infty$ 时，方程变为 $V_{out} + V_{TH}(V_{out} - V_{in}) = 2$。将其展开：

$$V_{out} + 0.7 + 0.45\sqrt{0.9 + V_{out} - V_{in}} - 0.45(0.9487) = 2 .$$

令 $u = \sqrt{0.9 + V_{out} - V_{in}}$，则 $V_{out} = u^2 - 0.9 + V_{in}$：

$$
\begin{aligned}
u^2 - 0.9 + V_{in} + 0.7 + 0.45u - 0.4269 &= 2\\
u^2 + 0.45u + (V_{in} - 0.9 + 0.7 - 0.4269 - 2) &= 0\\
u^2 + 0.45u - (2.6269 - V_{in}) &= 0 .
\end{aligned}
$$

这是关于 $u$ 的二次方程。$u$ 是平方根，必须为正，所以取求根公式中的“+”号根：

$$u = \frac{-0.45 + \sqrt{0.45^2 + 4\,(2.6269 - V_{in})}}{2} = \frac{-0.45 + \sqrt{0.2025 + 4\,(2.6269 - V_{in})}}{2}.$$

逐点求值：

- $V_{in} = 0$：$\sqrt{0.2025 + 10.5076} = 3.2726$，故 $u = (3.2726 - 0.45)/2 = 1.4113$，$u^2 = 1.9918$。于是 $V_{out} = 1.9918 - 0.9 + 0 = 1.092$ V，此时 $V_{SB} = 1.092$ V，$V_{TH} = 2 - 1.092 = 0.908$ V。
- $V_{in} = 0.5$ V：$\sqrt{0.2025 + 8.5076} = 2.9513$，故 $u = 1.2506$，$u^2 = 1.5641$。于是 $V_{out} = 1.5641 - 0.9 + 0.5 = 1.164$ V。
- $V_{in} = 1.0$ V：$\sqrt{0.2025 + 6.5076} = 2.5904$，故 $u = 1.0702$，$u^2 = 1.1453$。于是 $V_{out} = 1.245$ V。
- $V_{in} = 1.3$ V：$\sqrt{0.2025 + 5.3076} = 2.3474$，故 $u = 0.9487$，$u^2 = 0.9000$。于是 $V_{out} = 1.300$ V。此时 $V_{SB} = 0$，$V_{TH} = V_{TH0} = 0.7$ V。
- $V_{in} = 1.5$ V：$\sqrt{0.2025 + 4.5076} = 2.1703$，故 $u = 0.8601$，$u^2 = 0.7398$。于是 $V_{out} = 1.340$ V，此时 $V_{SB} = -0.16$ V（衬底电位略高于源极）。
- $V_{in} = 2.0$ V：$\sqrt{0.2025 + 2.5076} = 1.6462$，故 $u = 0.5981$，$u^2 = 0.3578$。于是 $V_{out} = 1.458$ V，此时 $V_{SB} = -0.54$ V。

**物理直观。** 轻载时器件（几乎）不流过电流，因此正好处于导通的边缘：$V_{GS} = V_{TH}$，即 $V_{out} = 2\ \mathrm{V} - V_{TH}$。升高衬底电位会降低 $V_{TH}$，源极必须升高同样的量才能保持 $V_{GS} = V_{TH}$。因此 $V_{out}$ 随 $V_{in}$ *增大*。

### 第 5 步 — 斜率与凹凸性

定义 $\eta = \partial V_{TH}/\partial V_{SB} = \gamma/\left(2\sqrt{2|\phi_F| + V_{SB}}\right)$，即 $V_{SB}$ 每变化一伏时阈值的变化量。

**轻载情形。** 对 $V_{out} + V_{TH} = 2$ 求微分，注意 $V_{SB} = V_{out} - V_{in}$：

$$
\begin{aligned}
dV_{out} + \eta\,(dV_{out} - dV_{in}) &= 0\\
dV_{out}\,(1 + \eta) &= \eta\,dV_{in}\\
\frac{dV_{out}}{dV_{in}} &= \frac{\eta}{1 + \eta}.
\end{aligned}
$$

**有限负载情形。** 对 $V_{out}/R_1 = \tfrac12\beta V_{ov}^2$ 两边求微分，其中 $V_{ov} = 2 - V_{out} - V_{TH}$。过驱动电压的变化量为 $dV_{ov} = -dV_{out} - \eta\,(dV_{out} - dV_{in})$，$g_m = \beta V_{ov}$ 为跨导（transconductance）：

$$
\begin{aligned}
\frac{dV_{out}}{R_1} &= \beta V_{ov}\,dV_{ov} = g_m\,dV_{ov}\\
\frac{dV_{out}}{R_1} &= g_m\left[-dV_{out}(1 + \eta) + \eta\,dV_{in}\right]\\
dV_{out}\left[\frac{1}{R_1} + g_m(1 + \eta)\right] &= g_m\eta\,dV_{in}\\
\frac{dV_{out}}{dV_{in}} &= \frac{g_m\eta}{1/R_1 + g_m(1 + \eta)} = \frac{\eta}{1 + \eta + 1/(g_mR_1)} = \frac{g_{mb}}{g_m + g_{mb} + 1/R_1},
\end{aligned}
$$

其中 $g_{mb} = \eta g_m$ 为体跨导（body transconductance）。这正是从*衬底*驱动的源极跟随器的增益。

轻载情形下的数值：

- $V_{in} = 0$：$\eta = 0.45/(2\times1.4113) = 0.159$，故斜率为 $0.159/1.159 = 0.14$。
- $V_{in} = 1.3$ V：$\eta = 0.45/(2\times0.9487) = 0.237$，故斜率为 $0.237/1.237 = 0.19$。
- $V_{in} = 2.0$ V：$\eta = 0.45/(2\times0.5981) = 0.376$，故斜率为 $0.376/1.376 = 0.27$。

斜率远小于 1，因为背栅的作用比前栅（front gate）弱得多（$\eta < 1$）。由于 $\eta \propto 1/\sqrt{0.9 + V_{SB}}$，斜率随 $V_{SB}$ 减小而增大。**因此曲线是上升且向上凹（concave up）的。**

### 第 6 步 — 有限 $\beta R_1$ 的影响

负载为有限值时，晶体管必须流过电流 $V_{out}/R_1$，这需要过驱动电压 $V_{ov} = \sqrt{2V_{out}/(\beta R_1)}$。这一过驱动电压使 $V_{out}$ 进一步低于 $2 - V_{TH}$。该方程用迭代法求解。

**例：$\beta R_1 = 10\ \mathrm{V^{-1}}$，$V_{in} = 0$。** 从轻载值（1.09 V）出发；这个值偏高，因为它没有留下任何过驱动电压。逐步降低猜测值，直到 $\tfrac12\beta R_1V_{ov}^2$ 等于 $V_{out}$；试几次（或用二分法）可得 $V_{out} \approx 0.758$ V。验证：

$$
\begin{aligned}
V_{SB} &= V_{out} - V_{in} = 0.758\ \mathrm{V},\\
V_{TH} &= 0.7 + 0.45(\sqrt{0.9 + 0.758} - 0.9487) = 0.7 + 0.45(1.2876 - 0.9487) = 0.7 + 0.1525 = 0.8525\ \mathrm{V},\\
V_{ov} &= 2 - V_{out} - V_{TH} = 2 - 0.758 - 0.8525 = 0.3895\ \mathrm{V},\\
\tfrac12\beta R_1V_{ov}^2 &= \tfrac12(10\ \mathrm{V^{-1}})(0.3895\ \mathrm{V})^2 = 5\times0.1517\ \mathrm{V} = 0.758\ \mathrm{V} = V_{out}.\ \checkmark
\end{aligned}
$$

过驱动电压（0.39 V）使 $V_{out}$ 比轻载值低约 0.33 V；由于 $V_{SB}$ 变小，阈值降低了 0.06 V，部分抵消了这一影响。三种负载下的结果：

| $V_{in}$ (V) | $V_{out}$, $\beta R_1\to\infty$ | $V_{out}$, $\beta R_1 = 100\ \mathrm{V^{-1}}$ | $V_{out}$, $\beta R_1 = 10\ \mathrm{V^{-1}}$ |
|---|---|---|---|
| 0 | 1.09 V | 0.97 V | 0.76 V |
| 0.5 | 1.16 V | 1.04 V | 0.82 V |
| 1.0 | 1.25 V | 1.12 V | 0.90 V |
| 1.5 | 1.34 V | 1.22 V | 1.00 V |
| 2.0 | 1.46 V | 1.34 V（结开始导通） | （结已导通） |

负载越重（$\beta R_1$ 越小），整条曲线越低，但曲线仍保持上升且向上凹的形状。

### 第 7 步 — 范围上端：源-衬底结正向偏置

一旦 $V_{in} > V_{out}$，$V_{SB}$ 就为负。此时 p 型衬底的电位高于 n+ 源区，源-衬底 pn 结处于**正向偏置**。

- 正偏电压不超过约 0.4–0.5 V 时，结电流可以忽略，体效应公式仍能描述（已降低的）阈值。
- 当 $V_{in} - V_{out}$ 达到约 0.6–0.7 V 时，该结明显导通。它像一个从 $V_{in}$ 接到 $V_{out}$ 的二极管，直接由 $V_{in}$ 向 $R_1$ 供电，因此 $V_{out} \approx V_{in} - 0.7$ V，斜率趋近于 1。
  - 轻载时，这大约发生在 $V_{in} \approx 2.1$ V 处（$V_{in} = 2.1$ V 时，$V_{in} - V_{out} = 0.61$ V）。
  - 对 $\beta R_1 = 10\ \mathrm{V^{-1}}$，这发生得更早，大约在 $V_{in} \approx 1.6$–$1.7$ V 处，因为此时在 $V_{in} = 1.5$ V 处正偏电压就已达到 0.50 V。
- 当 $V_{out} = V_{in} - 0.7$ 接近 2 V 时（约在 $V_{in} \approx 2.7$ V 处），$V_{GS} = 2 - V_{out} \to 0$，沟道电流逐渐消失。
- 当 $V_{in} \gtrsim 2.6$ V 时，衬底也比 2 V 端高出约 0.6 V，于是这个结也向 2 V 电池导通，并可能出现寄生横向双极晶体管效应（parasitic lateral-bipolar action）。$V_{out}$ 仍大致跟随 $V_{in} - 0.7$ V，但此时器件已是一对正偏二极管，而不再是 MOSFET。这一高端区域超出了平方律/体效应模型的适用范围，实际中应避免。

### 结果

$M_1$ 是一个**以衬底为输入的源极跟随器**：栅极和漏极都接 2 V，$V_{out}$ 端是源极，器件始终处于饱和区。于是

$$\frac{V_{out}}{R_1} = \tfrac12\beta\,(2 - V_{out} - V_{TH})^2, \qquad V_{TH} = 0.7 + 0.45\left(\sqrt{0.9 + V_{out} - V_{in}} - \sqrt{0.9}\right).$$

曲线的描述：

- **起点。** $V_{out}$ 从 $2\ \mathrm{V} - V_{TH}$ 附近开始：轻载时 $V_{in} = 0$ 处约为 1.09 V；$\beta R_1$ 为有限值时更低（$\beta R_1 = 100\ \mathrm{V^{-1}}$ 时为 0.97 V，$\beta R_1 = 10\ \mathrm{V^{-1}}$ 时为 0.76 V）。
- **跟随区。** 由于升高衬底电位会降低 $V_{TH}$，$V_{out}$ 随 $V_{in}$ 上升。斜率为 $g_{mb}/(g_m + g_{mb} + 1/R_1)$，远小于 1：$V_{in} = 0$ 处约为 0.14，到 $V_{in} = 2$ V 处增大到约 0.27，所以曲线向上凹。轻载时曲线经过 1.16 V（$V_{in} = 0.5$ V 处）、1.25 V（1 V 处）、1.30 V（1.3 V 处，此时 $V_{SB} = 0$）和 1.46 V（2 V 处）。
- **结导通区。** 当 $V_{in}$ 比 $V_{out}$ 高出约 0.6–0.7 V 时（轻载时约从 $V_{in} \approx 2.1$ V 开始，重载时更早），源-衬底结导通，$V_{out} \approx V_{in} - 0.7$ V。约 2.6 V 以上，衬底-漏极结也会导通，简单的 MOS 模型不再适用。

**常见错误。** 把画有箭头的那一端（接 +2 V）当作源极。这样会得到 $V_{GS} = 0$，沟道“永不导通”，在某个结导通之前 $V_{out} = 0$。如第 1 步所示，这种状态自相矛盾：NMOS 的源极总是电位较低的那一端，这里就是 $V_{out}$。

**常见错误。** 把 $V_{out}$ 画成随 $V_{in}$ *下降*。升高 NMOS 的衬底电位会*减小* $V_{SB}$，从而减小 $V_{TH}$，因此跟随器的输出是*上升*的。还要注意，依靠 MOS 沟道导电，$V_{out}$ 不可能超过 2 V：沟道只能把电流从 2 V 的漏极送到电位更低的源极。

**常见错误。** 忽略范围上端的源-衬底结。衬底比源极高出约 0.6 V 以上时，pn 结正向偏置，此后它起主导作用，把 $V_{out}$ 钳位（clamp）在 $V_{in} - 0.7$ V 附近。
