# 详细步骤 - R022

**思路。** $V_{out}$ 是 $M_1$ 的源极，该管始终处于饱和区，因此在 $V_{out}$ 节点列基尔霍夫电流定律（KCL）方程并结合平方律，可得到一个方程，其中 $V_{in}$ 只通过体效应出现，衬底相当于一个“背栅”（back gate）。逐点求解该方程，求出其斜率和曲率，并指出源-衬底结在何处变为正向偏置。

### 第 1 步 — 端电压与工作区

$R_1$ 把 $V_{out}$ 拉到 2 V 以下，因此电位较低的 $V_{out}$ 端是源极，$+2$ V 端（图中画有箭头的一端）是漏极。由 $V_G = V_D = 2$ V，$V_S = V_{out}$，$V_B = V_{in}$ 得：

$$
\begin{aligned}
V_{GS} &= 2 - V_{out},\\
V_{DS} &= 2 - V_{out},\\
V_{SB} &= V_{out} - V_{in}.
\end{aligned}
$$

由于 $V_{DS} = V_{GS}$，**$M_1$ 只要导通就处于饱和区**（前提是 $V_{TH} > 0$）：这是一个栅极和漏极都接 2 V 的源极跟随器。$V_{TH}$ 在 $V_{SB} = -0.9$ V 处最低，这是体效应公式适用范围的边缘，此时它仍为正：

$$V_{TH} = 0.7 + 0.45(0 - 0.9487) = 0.27\ \mathrm{V} > 0 .$$

### 第 2 步 — 控制方程

计入体效应，

$$V_{TH} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right) = 0.7 + 0.45\left(\sqrt{0.9 + V_{out} - V_{in}} - 0.9487\right).$$

抬高衬底电位（$V_{in}\uparrow$）会降低 $V_{SB}$，从而**降低阈值电压**（threshold voltage）：衬底就像一个较弱的第二栅极。

取 $\lambda = 0$（题中未给出），$\beta = \mu_nC_{ox}W/L$，并假设源-衬底结截止，在输出节点列 KCL 得到

$$\frac{V_{out}}{R_1} = \frac12\,\beta\,(2 - V_{out} - V_{TH})^2 .$$

取正的平方根（$V_{ov} > 0$），解出 $V_{out}$：

$$2 - V_{out} - V_{TH} = \sqrt{\frac{2V_{out}}{\beta R_1}}, \qquad V_{out} = 2 - V_{TH}(V_{out} - V_{in}) - \sqrt{\frac{2V_{out}}{\beta R_1}} .$$

$\beta$ 和 $R_1$ 都未给出，因此结果取决于乘积 $\beta R_1$（单位为 $\mathrm{V^{-1}}$）。第 3 步和第 4 步取**轻载极限** $\beta R_1 \to \infty$，此时过驱动电压（overdrive voltage）项消失；第 5 步说明有限的 $\beta R_1$ 如何使曲线移动。

### 第 3 步 — 轻载曲线：求解 $V_{out} + V_{TH} = 2$ V

当 $\beta R_1 \to \infty$ 时，方程变为 $V_{out} + V_{TH}(V_{out} - V_{in}) = 2$：

$$V_{out} + 0.7 + 0.45\sqrt{0.9 + V_{out} - V_{in}} - 0.45(0.9487) = 2 .$$

代入 $u = \sqrt{0.9 + V_{out} - V_{in}}$，则 $V_{out} = u^2 - 0.9 + V_{in}$：

$$
\begin{aligned}
u^2 - 0.9 + V_{in} + 0.7 + 0.45u - 0.4269 &= 2\\
u^2 + 0.45u - (2.6269 - V_{in}) &= 0 .
\end{aligned}
$$

由于 $u > 0$，取正根：

$$u = \frac{-0.45 + \sqrt{0.45^2 + 4\,(2.6269 - V_{in})}}{2} = \frac{-0.45 + \sqrt{0.2025 + 4\,(2.6269 - V_{in})}}{2}.$$

逐点计算：

- $V_{in} = 0$：$\sqrt{0.2025 + 10.5076} = 3.2726$，因此 $u = (3.2726 - 0.45)/2 = 1.4113$，$u^2 = 1.9918$。于是 $V_{out} = 1.9918 - 0.9 + 0 = 1.092$ V，此时 $V_{SB} = 1.092$ V，$V_{TH} = 2 - 1.092 = 0.908$ V。
- $V_{in} = 0.5$ V：$\sqrt{0.2025 + 8.5076} = 2.9513$，因此 $u = 1.2506$，$u^2 = 1.5641$。于是 $V_{out} = 1.5641 - 0.9 + 0.5 = 1.164$ V。
- $V_{in} = 1.0$ V：$\sqrt{0.2025 + 6.5076} = 2.5904$，因此 $u = 1.0702$，$u^2 = 1.1453$。于是 $V_{out} = 1.245$ V。
- $V_{in} = 1.3$ V：$\sqrt{0.2025 + 5.3076} = 2.3474$，因此 $u = 0.9487$，$u^2 = 0.9000$。于是 $V_{out} = 1.300$ V。此时 $V_{SB} = 0$，$V_{TH} = V_{TH0} = 0.7$ V。
- $V_{in} = 1.5$ V：$\sqrt{0.2025 + 4.5076} = 2.1703$，因此 $u = 0.8601$，$u^2 = 0.7398$。于是 $V_{out} = 1.340$ V，此时 $V_{SB} = -0.16$ V（衬底电位略高于源极）。
- $V_{in} = 2.0$ V：$\sqrt{0.2025 + 2.5076} = 1.6462$，因此 $u = 0.5981$，$u^2 = 0.3578$。于是 $V_{out} = 1.458$ V，此时 $V_{SB} = -0.54$ V。

轻载时器件几乎不流过电流，因此处于导通的边缘，$V_{out} = 2\ \mathrm{V} - V_{TH}$。抬高衬底电位会降低 $V_{TH}$，因此 $V_{out}$ 随 $V_{in}$ **增大**。

### 第 4 步 — 斜率与曲率

令 $\eta = \partial V_{TH}/\partial V_{SB} = \gamma/\left(2\sqrt{2|\phi_F| + V_{SB}}\right)$。

**轻载。** 对 $V_{out} + V_{TH} = 2$ 求微分，其中 $V_{SB} = V_{out} - V_{in}$：

$$
\begin{aligned}
dV_{out} + \eta\,(dV_{out} - dV_{in}) &= 0\\
dV_{out}\,(1 + \eta) &= \eta\,dV_{in}\\
\frac{dV_{out}}{dV_{in}} &= \frac{\eta}{1 + \eta}.
\end{aligned}
$$

**有限负载。** 对 $V_{out}/R_1 = \tfrac12\beta V_{ov}^2$ 求微分，其中 $V_{ov} = 2 - V_{out} - V_{TH}$，$dV_{ov} = -dV_{out} - \eta\,(dV_{out} - dV_{in})$，$g_m = \beta V_{ov}$：

$$
\begin{aligned}
\frac{dV_{out}}{R_1} &= \beta V_{ov}\,dV_{ov} = g_m\,dV_{ov}\\
\frac{dV_{out}}{R_1} &= g_m\left[-dV_{out}(1 + \eta) + \eta\,dV_{in}\right]\\
dV_{out}\left[\frac{1}{R_1} + g_m(1 + \eta)\right] &= g_m\eta\,dV_{in}\\
\frac{dV_{out}}{dV_{in}} &= \frac{g_m\eta}{1/R_1 + g_m(1 + \eta)} = \frac{\eta}{1 + \eta + 1/(g_mR_1)} = \frac{g_{mb}}{g_m + g_{mb} + 1/R_1},
\end{aligned}
$$

其中 $g_{mb} = \eta g_m$：这就是从**衬底**驱动的源极跟随器的增益。

轻载时的数值：

- $V_{in} = 0$：$\eta = 0.45/(2\times1.4113) = 0.159$，因此斜率为 $0.159/1.159 = 0.14$。
- $V_{in} = 1.3$ V：$\eta = 0.45/(2\times0.9487) = 0.237$，因此斜率为 $0.237/1.237 = 0.19$。
- $V_{in} = 2.0$ V：$\eta = 0.45/(2\times0.5981) = 0.376$，因此斜率为 $0.376/1.376 = 0.27$。

斜率远小于 1，因为背栅比前栅（front gate）弱得多（$\eta < 1$）；斜率随 $V_{SB}$ 减小而增大，因为 $\eta \propto 1/\sqrt{0.9 + V_{SB}}$。**因此曲线单调上升且向上凹。**

### 第 5 步 — 有限 $\beta R_1$ 的影响

负载有限时，晶体管必须承载 $V_{out}/R_1$，这需要过驱动电压 $V_{ov} = \sqrt{2V_{out}/(\beta R_1)}$；这会把 $V_{out}$ 进一步压到 $2 - V_{TH}$ 以下。该方程用迭代法求解。

**示例：$\beta R_1 = 10\ \mathrm{V^{-1}}$，$V_{in} = 0$。** 轻载值（1.09 V）对应的过驱动电压为零；逐步降低猜测值，直到 $\tfrac12\beta R_1V_{ov}^2 = V_{out}$，得到 $V_{out} \approx 0.758$ V。验算：

$$
\begin{aligned}
V_{SB} &= V_{out} - V_{in} = 0.758\ \mathrm{V},\\
V_{TH} &= 0.7 + 0.45(\sqrt{0.9 + 0.758} - 0.9487) = 0.7 + 0.45(1.2876 - 0.9487) = 0.7 + 0.1525 = 0.8525\ \mathrm{V},\\
V_{ov} &= 2 - V_{out} - V_{TH} = 2 - 0.758 - 0.8525 = 0.3895\ \mathrm{V},\\
\tfrac12\beta R_1V_{ov}^2 &= \tfrac12(10\ \mathrm{V^{-1}})(0.3895\ \mathrm{V})^2 = 5\times0.1517\ \mathrm{V} = 0.758\ \mathrm{V} = V_{out}.\ \checkmark
\end{aligned}
$$

过驱动电压（0.39 V）把 $V_{out}$ 拉低到比轻载值低约 0.33 V；由于 $V_{SB}$ 较小，阈值电压低了 0.06 V，部分抵消了这一影响。三种负载下的结果：

| $V_{in}$ (V) | $V_{out}$，$\beta R_1\to\infty$ | $V_{out}$，$\beta R_1 = 100\ \mathrm{V^{-1}}$ | $V_{out}$，$\beta R_1 = 10\ \mathrm{V^{-1}}$ |
|---|---|---|---|
| 0 | 1.09 V | 0.97 V | 0.76 V |
| 0.5 | 1.16 V | 1.04 V | 0.82 V |
| 1.0 | 1.25 V | 1.12 V | 0.90 V |
| 1.5 | 1.34 V | 1.22 V | 1.00 V |
| 2.0 | 1.46 V | 1.34 V（结开始导通） | （结已导通） |

负载越重（$\beta R_1$ 越小），整条曲线越低，但仍保持上升且向上凹的形状。

### 第 6 步 — 范围顶端：正向偏置的源-衬底结

一旦 $V_{in} > V_{out}$，就有 $V_{SB} < 0$：p 型衬底的电位高于 n+ 源区，因此源-衬底结**正向偏置**。

- 正向偏压在约 0.4–0.5 V 以内时，结电流可以忽略，体效应公式仍然成立。
- 在约 0.6–0.7 V 时，该结导通，像二极管一样从 $V_{in}$ 向 $R_1$ 供电：$V_{out} \approx V_{in} - 0.7$ V，斜率趋于 1。轻载时这发生在约 $V_{in} \approx 2.1$ V 处（在 $V_{in} = 2.1$ V 时，$V_{in} - V_{out} = 0.61$ V）；对 $\beta R_1 = 10\ \mathrm{V^{-1}}$，它发生得更早，约在 $V_{in} \approx 1.6$–$1.7$ V 处，因为在 $V_{in} = 1.5$ V 时正向偏压已达 0.50 V。
- 当 $V_{out} = V_{in} - 0.7$ 接近 2 V 时（$V_{in} \approx 2.7$ V 附近），$V_{GS} = 2 - V_{out} \to 0$，沟道电流逐渐消失。
- 当 $V_{in} \gtrsim 2.6$ V 时，衬底电位也比 2 V 端高约 0.6 V，因此该结也导通，并可能伴有横向双极晶体管效应。$V_{out}$ 大致继续跟随 $V_{in} - 0.7$ V，但此时器件已成为一对正向偏置的二极管，超出了平方律/体效应模型的范围。

### 结果

$M_1$ 作为一个**以衬底为输入的源极跟随器**工作：栅极和漏极都接 2 V，$V_{out}$ 端是源极，器件始终处于饱和区。于是

$$\frac{V_{out}}{R_1} = \tfrac12\beta\,(2 - V_{out} - V_{TH})^2, \qquad V_{TH} = 0.7 + 0.45\left(\sqrt{0.9 + V_{out} - V_{in}} - \sqrt{0.9}\right).$$

- **起点。** $V_{out}$ 从 $2\ \mathrm{V} - V_{TH}$ 附近开始：轻载时在 $V_{in} = 0$ 处约为 1.09 V，$\beta R_1$ 有限时更低（$\beta R_1 = 100\ \mathrm{V^{-1}}$ 时为 0.97 V，$\beta R_1 = 10\ \mathrm{V^{-1}}$ 时为 0.76 V）。
- **跟随区。** 由于抬高衬底电位会降低 $V_{TH}$，$V_{out}$ 随 $V_{in}$ 上升。斜率为 $g_{mb}/(g_m + g_{mb} + 1/R_1)$，远小于 1：$V_{in} = 0$ 时约为 0.14，到 $V_{in} = 2$ V 时增大到约 0.27，因此曲线向上凹。轻载时曲线经过 1.16 V（$V_{in} = 0.5$ V 处）、1.25 V（1 V）、1.30 V（1.3 V，此处 $V_{SB} = 0$）和 1.46 V（2 V）。
- **结导通区。** 当 $V_{in}$ 比 $V_{out}$ 高出约 0.6–0.7 V 时（轻载时约从 $V_{in} \approx 2.1$ V 起，重载时更早），源-衬底结导通，$V_{out} \approx V_{in} - 0.7$ V。在约 2.6 V 以上，衬底-漏极结（bulk–drain junction）也导通，简单的 MOS 模型不再适用。

**常见错误。** 把画有箭头的端子（+2 V）当作源极，从而得到 $V_{GS} = 0$ 以及“沟道永不导通”的结论。NMOS 的源极是其电位较低的端子，这里是 $V_{out}$。

**常见错误。** 把 $V_{out}$ 画成随 $V_{in}$ **减小**：抬高 NMOS 的衬底电位会**减小** $V_{SB}$，从而减小 $V_{TH}$，因此跟随器的输出**上升**。此外，$V_{out}$ 也不可能通过 MOS 导通超过 2 V。

**常见错误。** 忽略范围顶端的源-衬底结。一旦衬底比源极高出约 0.6 V 以上，该结就会导通，把 $V_{out}$ 钳位（clamp）在 $V_{in} - 0.7$ V 附近。
