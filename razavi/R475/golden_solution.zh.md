当反馈系数（feedback factor）β = 1/4 时（闭环增益 4 = 1/β），$A_{0,max} = 16$。若要求实际闭环增益 $A_0/(1 + \beta A_0)$ 恰好为 4，则 $A_{0,max} = 20$（β = 0.2）。
- 对于两个重合极点，PM = 60° 要求 $\omega_u = \sqrt3\,\omega_p$ 且 $\beta A_0/(1 + 3) = 1$，即环路增益（loop gain）$\beta A_0 \le 4$。
- 按名义值理解，β = 1/4：$A_0 \le 16$。当 $A_0 = 16$ 时，实际闭环增益为 16/5 = 3.2。
- 按精确值理解：β = 1/4 − 1/$A_0$，因此由 $\beta A_0 = A_0/4 - 1 \le 4$ 得 $A_0 \le 20$（β = 0.2，闭环增益为 20/5 = 4）。
