# 详细步骤 - R186

**思路。** 两个输入连在一起，因此激励是纯共模（common-mode）的，对称电路两边的节点电压完全相同。于是跨接在两个输出端之间的 $R_1$ 两端没有电压，也没有电流流过，$V_{out} = V_X - V_Y$ 在整个扫描过程中都为零。跟踪两个输出的共同电平只是作为一致性检验。

### 第 1 步 — 由基尔霍夫电流定律（KCL）得到对称解

把左输出端（$M_1$、$M_3$ 的漏极）记为 X，右输出端（$M_2$、$M_4$ 的漏极）记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P。在整个扫描过程中 $V_{in1} = V_{in2} = V_{in,CM}$，因此差分输入为零。

令 $I_R = (V_X - V_Y)/R_1$ 为 $R_1$ 中从 X 流向 Y 的电流：

- X 点的 KCL：$I_{D3} = I_{D1} + I_R$。
- Y 点的 KCL：$I_{D4} + I_R = I_{D2}$。

试取 $V_X = V_Y$。则 $I_R = 0$；$M_3$ 和 $M_4$ 的栅极电压（$V_{b2}$）、源极电压（$V_{DD}$）和漏极电压都相同，因此 $I_{D3} = I_{D4}$；$M_1$、$M_2$ 的栅极电压（$V_{in,CM}$）、源极电压（$V_P$）和漏极电压也都相同，因此 $I_{D1} = I_{D2} = I_{D5}/2$。两个 KCL 方程变为 $I_{D3} = I_{D1}$ 和 $I_{D4} = I_{D2}$，这是**同一个方程**，因此同一个 $V_X = V_Y$ 值能同时满足两式。任何微小的输出电导（output conductance）都使这一对称解成为唯一解，因此

$$V_X = V_Y \quad\Longrightarrow\quad V_{out} = 0, \qquad I_{R_1} = 0 .$$

$R_1$ 只对两个输出之间的差值有响应；在共模输入下，它相当于不存在。

### 第 2 步 — 两个输出的共同电平（仅供参考）

示例设计（尺寸可自由选取）：$\beta_n = \mu_nC_{ox}(W/L)_{1,2} = 2\ \mathrm{mA/V^2}$；$V_{b1} = 1$ V，$\mu_nC_{ox}(W/L)_5 = 4.44\ \mathrm{mA/V^2}$，由此得

$$I_{SS} = \tfrac12(4.44\ \mathrm{mA/V^2})(1 - 0.7)^2\ \mathrm{V^2} = 200\ \mu\mathrm{A};$$

再取 $V_{b2} = 1.9$ V，$\mu_pC_{ox}(W/L)_{3,4} = 2.22\ \mathrm{mA/V^2}$，得到 PMOS 的饱和电流

$$I_P = \tfrac12(2.22\ \mathrm{mA/V^2})(3 - 1.9 - 0.8)^2\ \mathrm{V^2} = 100\ \mu\mathrm{A} = \frac{I_{SS}}{2}\quad\text{(nominal design)}.$$

当 $V_X \le V_{b2} + |V_{THP}| = 2.7$ V 时，PMOS 器件处于饱和区（saturation region）。

**(a) $V_{in,CM} < 0.7$ V。** $M_1$、$M_2$ 截止。PMOS 的沟道导通（$V_{SG} = 1.1\ \mathrm{V} > 0.8$ V），但没有电流，因此 $V_{SD} = 0$：

$$V_X = V_Y = V_{DD} = 3\ \mathrm{V}.$$

**(b) 差分对导通，尾电流管尚未饱和。** 超过 0.7 V 后开始有电流，但 $V_P$ 仍然很小，因此 $M_5$ 处于线性区（triode region），$I_{D5} < I_{SS}$。每个 PMOS 提供 $I_{D5}/2 < I_P$，因此它处于线性区，输出降到 $V_{DD}$ 以下。

**算例：$V_{in,CM} = 1.0$ V。** 对 P 点列 KCL（$M_5$ 处于线性区），并利用 $M_1$ 饱和的条件：

$$
\begin{aligned}
2I_{D1} &= (4.44\ \mathrm{mA/V^2})\left[0.3V_P - \tfrac12V_P^2\right],\\
I_{D1} &= \tfrac12(2\ \mathrm{mA/V^2})(1.0 - V_P - 0.7)^2 .
\end{aligned}
$$

其解（对 $V_P$ 试值求得）为 $V_P = 0.082$ V，$I_{D1} = (1\ \mathrm{mA/V^2})(0.218\ \mathrm{V})^2 = 47.4\ \mu$A。验证：$(4.44\ \mathrm{mA/V^2})(0.3\times0.082 - 0.5\times0.082^2) = (4.44\ \mathrm{mA/V^2})(0.0213\ \mathrm{V^2}) = 94.8\ \mu$A $= 2I_{D1}$ ✓。

$M_3$ 处于线性区，电流为 47.4 µA，过驱动电压（overdrive voltage）$V_{SG3} - |V_{THP}| = 0.3$ V；取 $I = \beta_p(V_{ov}V_{SD} - V_{SD}^2/2)$ 的较小根，得

$$
\begin{aligned}
V_{SD3} &= 0.3 - \sqrt{0.3^2 - \frac{2(47.4\ \mu\mathrm{A})}{2.22\ \mathrm{mA/V^2}}} = 0.3 - \sqrt{0.090 - 0.043} = 0.3 - 0.218 = 0.082\ \mathrm{V},\\
V_X = V_Y &= 3 - 0.082 = 2.92\ \mathrm{V}.
\end{aligned}
$$

**(c) 尾电流管饱和。** 当 $V_P$ 达到 $V_{b1} - V_{THN} = 0.3$ V 时，尾电流管流过 $I_{SS}$，每边流过 $I_{SS}/2 = I_P$，PMOS 器件到达饱和边缘（$V_X = V_Y = 2.7$ V）。这发生在

$$V_{in,CM} = V_P + V_{THN} + \sqrt{\frac{2(I_{SS}/2)}{\beta_n}} = 0.3 + 0.7 + \sqrt{\frac{2(100\ \mu\mathrm{A})}{2\ \mathrm{mA/V^2}}} = 0.3 + 0.7 + 0.316 = 1.32\ \mathrm{V}.$$

**(d) 高于 1.32 V。** 所有器件都饱和：上面是两个电流源 $I_P$，下面是吸收 $I_{SS}$ 的尾电流管。在 $\lambda = 0$ 且恰好 $2I_P = I_{SS}$ 时，没有任何因素能确定共同电平；实际中，若 $2I_P > I_{SS}$，它会向 $V_{DD}$ 漂移，若 $2I_P < I_{SS}$，它会向地漂移（把输入对管推入线性区），因此需要共模反馈。无论这一电平是多少，它在 X 和 Y 处都相同。

| $V_{in,CM}$ (V) | 状态 | $V_X = V_Y$ (V) | $V_{out}$ (V) |
|---|---|---|---|
| 0 到 0.7 | 差分对截止 | 3.00 | 0 |
| 0.8 | 差分对导通；$M_5$、$M_3$、$M_4$ 处于线性区 | 2.99 | 0 |
| 1.0 | 同上 | 2.92 | 0 |
| 1.2 | 同上 | 2.80 | 0 |
| 1.32 | 尾电流管和负载进入饱和区 | 2.70 | 0 |
| 1.32 到 3 | 全部饱和；电平由 $2I_P$ 与 $I_{SS}$ 的相对大小决定 | 不确定（需要 CMFB） | 0 |

### 结果

$$V_{out} = 0 \quad\text{for the whole sweep } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

电路是对称的，因此两个输出一起变化，$R_1$ 两端没有电压，也没有电流流过，草图就是一条落在横轴上的水平线。作为参考，输出的共同电平在差分对截止时为 $V_{DD}$，差分对导通后开始下降，之后由 PMOS 电流源的电流与尾电流之间的平衡决定：没有共模反馈时它不确定，但两边相等。

**常见错误。** 只画出一个输出（例如差分对导通时从 3 V 开始下降的 $V_X$），并把它当作 $V_{out}$。那是输出的共模电平（common-mode level）；$V_X - V_Y$ 为零。

**常见错误。** 认为共模电平变化时 $R_1$ 中有电流流过，从而得出非零的 $V_{out}$。$R_1$ 连接的是两个电位相同的节点，因此其电流为零。
