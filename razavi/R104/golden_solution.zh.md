$I_X = I_{D2} - I_{D1}$：在 $V_X = 0$ 时为负，随着 $M_2$ 的电流增大、$M_1$ 的电流减小而上升；当 $M_1$ 截止且 $M_2$ 饱和后，平坦地保持在 $I_2 = \tfrac12\beta_2(V_{b2} - 0.7)^2$。

- 节点 $X$ 的基尔霍夫电流定律（KCL）：$I_X + I_{D1} = I_{D2}$。
- $M_1$ 的漏极接 $V_{DD}$、源极接 $X$，是跟随器型器件；只要 $V_{b1} \le V_{DD} + 0.7$ V，它导通时就处于饱和区（saturation region），$V_{b1}$ 更大时，它在 $V_X$ 较低时先处于线性区（triode region）。$I_{D1} = \tfrac12\beta_1(V_{b1} - V_X - V_{TH1})^2$，其中由于体效应（body effect），$V_{TH1} = 0.7 + 0.45(\sqrt{0.9+V_X} - \sqrt{0.9})$，$V_{SB} = V_X$；该电流减小，并在 $V_X = V_{b1} - V_{TH1}(V_X)$ 处降为零（略低于 $V_{b1} - 0.7$ V）。
- $M_2$：$V_X < V_{b2} - 0.7$ V 时处于线性区，$I_{D2} = \beta_2[(V_{b2} - 0.7)V_X - V_X^2/2]$，从 0 开始上升；此后处于饱和区，$I_{D2} = I_2$。（若 $V_{b2} > 3.7$ V，$M_2$ 在整个扫描过程中都处于线性区。）
- 因此 $I_X(0) = -\tfrac12\beta_1(V_{b1} - 0.7)^2$；$I_X$ 上升并穿过零点；当 $V_X$ 同时高于 $V_{b2} - 0.7$ V 和 $M_1$ 的截止点时，$I_X = I_2$（平坦；若计入 λ，斜率为 $\lambda I_2$）。
- 转折点：$V_X = V_{b2} - 0.7$ V（$M_2$ 进入饱和），$V_X = V_{b1} - V_{TH1}$（$M_1$ 截止）。
