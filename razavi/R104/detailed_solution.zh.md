# 详细步骤 - R104

**思路。** 节点 $X$ 既是 $M_1$ 的**源极**（其漏极接 $V_{DD}$，栅极接 $V_{b1}$），又是 $M_2$ 的**漏极**（其栅极接 $V_{b2}$，源极接地）。由节点 $X$ 的 KCL 得 $I_X = I_{D2} - I_{D1}$。$M_1$ 的电流随其源极电压升高而减小（计入体效应），直到截止；$M_2$ 的电流则遵循其普通的输出特性：先处于线性区，后进入饱和区。

### 第 1 步 — 节点 $X$ 的 KCL

$I_X$（来自测试源）和 $M_1$ 的漏极电流 $I_{D1}$ 流入 $X$，$M_2$ 的漏极电流 $I_{D2}$ 流出：

$$I_X + I_{D1} = I_{D2} \quad\Longrightarrow\quad I_X = I_{D2} - I_{D1} .$$

### 第 2 步 — $M_1$ 的电流（源极为 $X$ 的跟随器型器件）

$V_{GS1} = V_{b1} - V_X$，$V_{DS1} = 3 - V_X$，$V_{SB1} = V_X$，且

$$V_{TH1}(V_X) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right)\ \mathrm{V}.$$

饱和要求 $3 - V_X \ge V_{b1} - V_X - V_{TH1}$，即 $V_{b1} \le 3 + V_{TH1}$；对于不超过约 3.7 V 的任何 $V_{b1}$，这都成立（更大的 $V_{b1}$ 会使 $M_1$ 在 $V_X$ 较低时先处于线性区）。因此，导通时

$$I_{D1} = \frac12\beta_1\left(V_{b1} - V_X - V_{TH1}(V_X)\right)^2 ,$$

它随 $V_X$ 升高而**减小**（$V_{GS1}$ 减小，$V_{TH1}$ 增大）。它在 $V_{X,off}$ 处降为零，其中 $V_{b1} - V_{X,off} = V_{TH1}(V_{X,off})$；令 $u = \sqrt{0.9 + V_{X,off}}$，该式化为 $u^2 + 0.45u - (V_{b1} + 0.6269) = 0$，$V_{X,off} = u^2 - 0.9$，由于体效应，它略低于 $V_{b1} - 0.7$ V。在 $V_X = 0$ 处，$I_{D1}(0) = \frac12\beta_1(V_{b1} - 0.7)^2$。

### 第 3 步 — $M_2$ 的电流（其输出特性）

$V_{GS2} = V_{b2}$ 固定，$V_{DS2} = V_X$：

- **线性区，$V_X < V_{b2} - 0.7$ V：** $I_{D2} = \beta_2\left[(V_{b2} - 0.7)V_X - \tfrac12V_X^2\right]$，从 0 开始以逐渐减小的斜率上升。
- **饱和区，$V_X \ge V_{b2} - 0.7$ V：** $I_{D2} = I_2 = \frac12\beta_2(V_{b2} - 0.7)^2$，为常数。

（若 $V_{b2} > 3.7$ V，$M_2$ 在整个扫描过程中都处于线性区。）

### 第 4 步 — 合成：$I_X = I_{D2} - I_{D1}$

- **起点（$V_X = 0$）：** $I_{D2} = 0$，因此
$$I_X(0) = -\frac12\beta_1(V_{b1} - 0.7)^2 ,$$
为负值：$M_1$ 把电流注入电压源 $V_X$。
- **上升段：** $I_{D2}$ 增大，$I_{D1}$ 减小，因此 $I_X$ 上升，斜率为
$$\frac{dI_X}{dV_X} = \frac{dI_{D2}}{dV_X} - \frac{dI_{D1}}{dV_X} = g_{ds2} + (g_{m1} + g_{mb1}),$$
其中 $g_{ds2} = \beta_2(V_{b2} - 0.7 - V_X)$ 是 $M_2$ 的线性区沟道电导（饱和后为零），$g_{m1} + g_{mb1}$ 是从 $M_1$ 源极看进去的电导。$I_X$ 在 $I_{D2} = I_{D1}$ 处过零，此时的电压就是节点 $X$ 自身会取的电压。
- **转折：** 在 $V_X = V_{b2} - 0.7$ V 处，$M_2$ 进入饱和，它对斜率的贡献消失；在 $V_X = V_{X,off}$ 处，$M_1$ 截止，其电流和斜率都降为零。
- **平台：** 当 $V_X$ 同时高于 $V_{b2} - 0.7$ V 和 $V_{X,off}$ 时，
$$I_X = I_2 = \frac12\beta_2(V_{b2} - 0.7)^2 ,$$
一直平坦到 $V_X = 3$ V（若计入沟道长度调制，斜率为 $\lambda I_2$）。

### 第 5 步 — 数值示例

为便于说明，取 $V_{b1} = 1.5$ V，$V_{b2} = 1.2$ V，$\beta_1 = \beta_2 = 2\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_X(0) &= -\tfrac12(2\ \mathrm{mA/V^2})(0.8\ \mathrm{V})^2 = -0.64\ \mathrm{mA},\\
I_2 &= \tfrac12(2\ \mathrm{mA/V^2})(0.5\ \mathrm{V})^2 = 0.25\ \mathrm{mA}\quad(M_2\ \text{saturates at}\ V_X = 0.5\ \mathrm{V}),\\
V_{X,off}&:\ u = \frac{-0.45 + \sqrt{0.2025 + 4(2.1269)}}{2} = 1.2507,\quad V_{X,off} = 1.2507^2 - 0.9 = 0.664\ \mathrm{V}.
\end{aligned}
$$

| $V_X$ (V) | $I_{D1}$ (mA) | $M_2$ | $I_{D2}$ (mA) | $I_X$ (mA) |
|---|---|---|---|---|
| 0 | 0.640 | 线性区 | 0 | −0.640 |
| 0.1 | 0.458 | 线性区 | 0.090 | −0.368 |
| 0.2 | 0.308 | 线性区 | 0.160 | −0.148 |
| 0.285 | 0.204 | 线性区 | 0.204 | 0 |
| 0.4 | 0.099 | 线性区 | 0.240 | 0.142 |
| 0.5 | 0.038 | 饱和 | 0.250 | 0.212 |
| 0.664 | 0 | 饱和 | 0.250 | 0.250 |
| 3.0 | 0 | 饱和 | 0.250 | 0.250 |

### 结果

$$I_X = I_{D2} - I_{D1}$$

（节点 $X$ 的 KCL）。$I_X$ 在 $V_X = 0$ 时为负，随着 $M_2$ 的电流增大、$M_1$ 的电流减小而上升；当 $M_1$ 截止且 $M_2$ 饱和后，平坦地保持在 $I_2 = \tfrac12\beta_2(V_{b2} - 0.7)^2$。

- **$M_1$**（漏极接 $V_{DD}$，源极接 $X$）是跟随器型器件，只要 $V_{b1} \le V_{DD} + 0.7$ V，它导通时就处于饱和区：$I_{D1} = \tfrac12\beta_1(V_{b1} - V_X - V_{TH1})^2$，其中 $V_{TH1} = 0.7 + 0.45(\sqrt{0.9 + V_X} - \sqrt{0.9})$（体效应，$V_{SB} = V_X$）；该电流减小，并在 $V_X = V_{b1} - V_{TH1}(V_X)$ 处降为零，略低于 $V_{b1} - 0.7$ V。
- **$M_2$：** $V_X < V_{b2} - 0.7$ V 时处于线性区，$I_{D2} = \beta_2[(V_{b2} - 0.7)V_X - V_X^2/2]$ 从 0 开始上升；此后处于饱和区，$I_{D2} = I_2$。
- **因此：** $I_X(0) = -\tfrac12\beta_1(V_{b1} - 0.7)^2$；$I_X$ 上升并穿过零点；当 $V_X$ 同时高于 $V_{b2} - 0.7$ V 和 $M_1$ 的截止点时，$I_X = I_2$（平坦）。
- **转折点：** $V_X = V_{b2} - 0.7$ V（$M_2$ 进入饱和），$V_X = V_{b1} - V_{TH1}$（$M_1$ 截止）。

**常见错误。** 把 $X$ 当作 $M_1$ 的漏极，让 $M_1$ 的电流随 $V_X$ 增大。$X$ 是它的**源极**，因此提高 $V_X$ 会减小 $V_{GS1}$，$M_1$ 的电流随之下降。

**常见错误。** 在求 $M_1$ 的截止点时忽略体效应。由于 $V_{SB1} = V_X$，$M_1$ 在 $V_X$ 达到 $V_{b1} - 0.7$ V 之前就会截止（在本例中为 0.664 V，而不是 0.8 V）。

**常见错误。** 弄错 $I_X$ 的符号（例如写成 $I_X = I_{D1} - I_{D2}$），得到一条总体下降的曲线。$M_1$ 向 $X$ **注入**电流，$M_2$ 则把电流**抽出**，因此电压源提供的电流为 $I_{D2} - I_{D1}$。
