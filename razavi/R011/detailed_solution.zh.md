# 详细步骤 - R011

**思路。** 分压器 $R_1$–$R_2$ 接在 $V_{DD}$ 与 $V_X$ 之间，因此栅极得到的是 $V_{DD} - V_X$ 的一个固定比例。求出 $V_{SG}$ 和 $V_{SD}$ 随 $V_X$ 变化的表达式，证明 $M_1$ 只要导通就处于饱和区，再写出平方律（square law）电流和跨导；当 $V_{SG}$ 降到 $|V_{TH}|$ 时，两者都降为零。

### 第 1 步 — 由分压器求端电压

由于 $V_X \le V_{DD}$，电位较高的 $V_{DD}$ 端是 PMOS 的源极，$V_X$ 节点是漏极。衬底与源极相连，因此**没有体效应**，并且始终有 $|V_{TH}| = 0.8$ V。$I_X$ 只是 $M_1$ 的电流；分压器的电流另计。

栅极不取电流，因此 $R_1$ 和 $R_2$ 流过的电流为 $I_R = (V_{DD} - V_X)/(R_1 + R_2)$，而 $V_{SG}$ 就是 $R_1$ 上的压降：

$$V_{SG} = I_RR_1 = (V_{DD} - V_X)\frac{R_1}{R_1 + R_2} = k\,(3 - V_X), \qquad V_{SD} = V_{DD} - V_X = 3 - V_X ,$$

其中 $k = R_1/(R_1 + R_2)$ 为分压比（$0 < k < 1$）。

### 第 2 步 — $M_1$ 只要导通就处于饱和区

饱和要求 $V_{SD} \ge V_{SG} - |V_{TH}|$：

$$3 - V_X \;\ge\; k(3 - V_X) - 0.8 .$$

由于 $k < 1$ 且 $3 - V_X \ge 0$，左边至少为 $k(3 - V_X)$，它比右边至少大 0.8 V，因此不等式总是成立。换句话说：栅极是源极与漏极之间的一个分压抽头，因此 $V_{SD} \ge V_{SG} > V_{SG} - |V_{TH}|$。

### 第 3 步 — 截止点

当 $V_{SG} > |V_{TH}|$ 时 $M_1$ 导通：

$$
\begin{aligned}
k\,(3 - V_X) &> 0.8\\
3 - V_X &> \frac{0.8}{k}\\
V_X &< 3 - \frac{0.8}{k} = 3 - 0.8\,\frac{R_1 + R_2}{R_1} .
\end{aligned}
$$

将该值记为 $V_{X,\mathrm{off}}$；当 $V_X > V_{X,\mathrm{off}}$ 时，$M_1$ 截止。要使 $M_1$ 在该范围内能够导通（$V_{X,\mathrm{off}} > 0$），需要 $3k > 0.8$，即 $R_1/(R_1 + R_2) > 0.27$，这里假设此条件成立；否则在整个扫描范围内 $I_X = 0$，$g_m = 0$。

### 第 4 步 — 漏极电流 $I_X$

在饱和区，忽略沟道长度调制（channel-length modulation）：

$$I_X = \tfrac12\beta_p\,(V_{SG} - |V_{TH}|)^2 = \tfrac12\beta_p\left[(3 - V_X)\frac{R_1}{R_1 + R_2} - 0.8\right]^2, \qquad 0 \le V_X < V_{X,\mathrm{off}},$$

而当 $V_X \ge V_{X,\mathrm{off}}$ 时 $I_X = 0$。电流从 $V_{DD}$ 流入源极，与箭头方向一致，因此 $I_X > 0$。其斜率

$$\frac{dI_X}{dV_X} = \beta_p\,V_{ov}\cdot\frac{dV_{SG}}{dV_X} = -\beta_p\,k\,V_{ov} ,$$

为负，并随 $V_{ov}$ 一起减小到零，因此 $I_X$ 是一段**下降的抛物线弧，在 $V_{X,\mathrm{off}}$ 处与横轴相切**，之后保持为零。其起始值为

$$I_X(0) = \tfrac12\beta_p\,(3k - 0.8)^2 .$$

### 第 5 步 — 跨导

在饱和区，

$$g_m = \beta_p\,(V_{SG} - |V_{TH}|) = \beta_p\left[(3 - V_X)\frac{R_1}{R_1 + R_2} - 0.8\right],$$

它是 **$V_X$ 的线性函数**，斜率为

$$\frac{dg_m}{dV_X} = -\beta_p\,\frac{R_1}{R_1 + R_2},$$

从 $g_m(0) = \beta_p(3k - 0.8)$ 开始，在同一点 $V_{X,\mathrm{off}}$ 处降为零，之后保持为零。

### 第 6 步 — 数值示例（$R_1 = R_2$）

当 $R_1 = R_2$ 时，$k = 0.5$：

$$
\begin{aligned}
V_{SG} &= 0.5\,(3 - V_X),\\
V_{X,\mathrm{off}} &= 3 - \frac{0.8}{0.5} = 3 - 1.6 = 1.4\ \mathrm{V}.
\end{aligned}
$$

| $V_X$ (V) | $V_{SG}$ (V) | $V_{SD}$ (V) | $V_{ov}$ (V) | $I_X/\beta_p$ (V²) | $g_m/\beta_p$ (V) |
|---|---|---|---|---|---|
| 0 | 1.50 | 3.0 | 0.70 | 0.245 | 0.70 |
| 0.5 | 1.25 | 2.5 | 0.45 | 0.101 | 0.45 |
| 1.0 | 1.00 | 2.0 | 0.20 | 0.020 | 0.20 |
| 1.4 | 0.80 | 1.6 | 0 | 0 | 0 |
| 1.4 – 3 | 0.8 → 0 | 1.6 → 0 | 截止 | 0 | 0 |

以 $V_X = 0.5$ V 这一行为例：$V_{SG} = 0.5\times(3 - 0.5) = 1.25$ V，$V_{ov} = 1.25 - 0.8 = 0.45$ V，$I_X = \tfrac12\beta_p(0.45\ \mathrm{V})^2 = 0.101\beta_p\ \mathrm{V^2}$，$g_m = \beta_p(0.45\ \mathrm{V})$。每一行中 $V_{SD}$ 都远大于 $V_{ov}$，证实器件处于饱和区。

$R_1$ 相对于 $R_2$ 越大（$k$ 越大），起始电流越大，$V_{X,\mathrm{off}}$ 也越接近 $3 - 0.8 = 2.2$ V（即 $k \to 1$ 的极限情况，此时栅极接 $V_X$）。

### 结果

- $V_{SG} = (V_{DD} - V_X)\dfrac{R_1}{R_1 + R_2}$（源极接 $V_{DD}$；衬底即源极，因此没有体效应），且 $V_{SD} = V_{DD} - V_X \ge V_{SG}$，因此 **$M_1$ 只要导通就处于饱和区**。
- 当 $V_X < 3 - 0.8(R_1 + R_2)/R_1$ 时（假设 $3R_1/(R_1 + R_2) > 0.8$，使 $M_1$ 在 $V_X = 0$ 时导通），$I_X$ **按二次函数规律下降**，并在 $V_X = V_{DD} - |V_{TH}|(R_1 + R_2)/R_1$ 处与零轴相切；高于该值时为零：
$$I_X = \tfrac12\beta_p\left[(3 - V_X)\frac{R_1}{R_1 + R_2} - 0.8\right]^2 .$$
- $g_m$ 是一条**直线**，以斜率 $-\beta_pR_1/(R_1 + R_2)$ 下降，在同一点降为零，高于该点时为零：
$$g_m = \beta_p\left[(3 - V_X)\frac{R_1}{R_1 + R_2} - 0.8\right].$$
- 示例：$R_1 = R_2$ 时，截止点为 $V_X = 1.4$ V，$I_X(0) = 0.245\beta_p$，$g_m(0) = 0.7\beta_p$。

**常见错误。** 把分压比弄反，写成 $V_{SG} = (V_{DD} - V_X)R_2/(R_1 + R_2)$。$V_{SG}$ 是接在**源极**（$V_{DD}$）与栅极之间的电阻上的压降，这个电阻是 $R_1$。

**常见错误。** 认为 $V_X$ 向 $V_{DD}$ 升高时 $M_1$ 会进入线性区（triode region）。由于始终有 $V_{SD} \ge V_{SG}$，器件在可能进入线性区之前就已截止。

**常见错误。** 把 $I_X$ 画成随 $V_X$ 增大。升高 $V_X$ 会减小分压器两端的电压，从而减小 $V_{SG}$，因此电流下降。
