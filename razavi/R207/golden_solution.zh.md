三条曲线都只在差分对进行电流导引（current steering）的窗口内变化（在 $V_{in1} = 1.5$ V 附近，$|V_{in1} - V_{in2}| < \sqrt{2I_{SS}/\beta_n}$），在窗口之外都是平坦的。$V_{out}$ 是一条反相 S 形曲线；$V_X$ 下降而 $V_Y$ 上升（二者互为镜像）；由于 $R_1$ 使“截止”一侧的一部分电流流过另一个共源共栅管，摆幅受到限制。
- 平衡时：$V_X = V_Y = V_{b1} - V_{GS3}(I_{SS}/2)$，$R_1$ 中没有电流，两个输出位于 $V_{DD} - |V_{GS5}(I_{SS}/2)|$，$V_{out} = 0$。
- 随着 $V_{in1}$ 升高，$I_{D1}$ 增大：流过 $M_3$ 的电流 $I_3 = I_{D1} + (V_X - V_Y)/R_1$ 增大，因此 $V_X = V_{b1} - V_{GS3}(I_3)$ 下降，左输出 $V_{DD} - |V_{GS5}(I_3)|$ 也下降；右边则相反。
- $V_{in1}$ 较低时（$M_1$ 截止，$I_{D2} = I_{SS}$）：$M_3$ 仍然流过 $I_3 = (V_X - V_Y)/R_1$，即从 X 经 $R_1$ 流入 Y 的电流，$M_4$ 流过 $I_{SS} - I_3$，且 $V_{GS4}(I_{SS} - I_3) - V_{GS3}(I_3) = I_3R_1$。因此 $V_X > V_Y$，两者相差 $I_3R_1$，$V_{out} = |V_{GS6}(I_{SS} - I_3)| - |V_{GS5}(I_3)| = \sqrt{2/\beta_p}(\sqrt{I_{SS} - I_3} - \sqrt{I_3}) > 0$。$V_{in1}$ 较高时取镜像值。
- $R_1$ 很大时：$I_3 \to 0$，$|V_{out}| \to \sqrt{2I_{SS}/\beta_p}$；$R_1$ 很小时：X 与 Y 近乎短接，两个共源共栅管分担电流，$V_{out}$ 和 $V_X - V_Y$ 都缩小到接近零。
- 中心斜率：$dV_{out}/d(V_{in1} - V_{in2}) = -(g_{m1}/g_{m5})\cdot\dfrac{g_{m3}R_1/2}{1 + g_{m3}R_1/2}$。
