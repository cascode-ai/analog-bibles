# 详细步骤 - R693

**思路。** 接触尖刺会使源/漏扩散区（diffusion）与其下方的体区短路。首先确定正常电路的输出位于何处（只要有电流流过，就绝不会接近 $V_{DD}$），然后分析四个结中每一个发生短路时对直流输出的影响。只有其中一个能把 $V_{out}$ 拉到 $V_{DD}$。

### 第 1 步 — 正常电路的输出位于何处

二极管连接（diode-connected）的 $M_2$ 只要导通就处于饱和区（saturation region），并且 $I_{D2} = I_{D1} = I_D$，因此按平方律（square law）并取 $\lambda = 0$，有

$$I_{D2} = \tfrac12\mu_pC_{ox}\Big(\frac{W}{L}\Big)_2\big(V_{DD} - V_{out} - |V_{THP}|\big)^2 \quad\Longrightarrow\quad V_{out} = V_{DD} - |V_{THP}| - \sqrt{\frac{2I_D}{\mu_pC_{ox}(W/L)_2}} .$$

因此只要 $M_1$ 吸取电流，$V_{out}$ 就**至少比 $V_{DD}$ 低 $|V_{THP}|$**，并且电流越大，输出越低。取典型值 $|V_{THP}| \approx 0.8$ V，$V_{DD} = 3$ V，正常输出低于约 2.2 V。输出“接近 $V_{DD}$”意味着有某种东西把输出节点直接拉到了电源。

### 第 2 步 — 四个候选结

尖刺会使 $M_1$ 的某个 n+ 区与 p 型衬底（处于**地**电位）短路，或使 $M_2$ 的某个 p+ 区与 n 阱（处于 **$V_{DD}$**）短路，短路通路上有一个很小的体区扩展电阻（spreading resistance），约为几百欧姆到几千欧姆：

| 结 | 体区电位 | 尖刺造成的短路 |
|---|---|---|
| (a) $M_1$ 的 n+ 源区 / p 型衬底 | 地 | $M_1$ 的源极对地 |
| (b) $M_1$ 的 n+ 漏区 / p 型衬底 | 地 | $V_{out}$ 对地 |
| (c) $M_2$ 的 p+ 源区 / n 阱 | $V_{DD}$ | $M_2$ 的源极对 $V_{DD}$ |
| (d) $M_2$ 的 p+ 漏区 / n 阱 | $V_{DD}$ | $V_{out}$ 对 $V_{DD}$ |

### 第 3 步 — 每种尖刺对 $V_{out}$ 的影响

**(a) $M_1$ 源区与衬底短路。** $R_S$ 被旁路，因此在相同的 $V_{in}$ 下，$V_{GS1}$ 增大，电流增大。由第 1 步可知，$I_D$ 越大，$V_{out}$ 越**低**，而不是越高。

**(b) $M_1$ 漏区与衬底短路。** 输出节点接到接地的衬底，因此 $V_{out}$ 被拉到 **0 V 附近**。

**(c) $M_2$ 源区与 n 阱短路。** p+ 源区和 n 阱本来就都处于 $V_{DD}$，因此没有任何变化；$V_{out}$ 仍至少比 $V_{DD}$ 低 $|V_{THP}|$。

**(d) $M_2$ 漏区与 n 阱短路。** 输出节点（$M_2$ 的 p+ 漏区）与 n 阱相连，而 n 阱经其接触孔接到 $V_{DD}$：在 $V_{out}$ 与 $V_{DD}$ 之间出现一个小电阻 $R_{well}$，与二极管连接的 $M_2$ 并联。

<!-- diagram: diagram-01.cir -->

于是 $M_1$ 吸取的电流 $I_{D1}$ 主要由 $R_{well}$ 提供：

$$V_{out} = V_{DD} - I_{D1}R_{well} .$$

例如，$I_{D1} = 100\ \mu\mathrm{A}$，$R_{well} = 1\ \mathrm{k}\Omega$ 时

$$V_{out} = 3\ \mathrm{V} - (100\ \mu\mathrm{A})(1\ \mathrm{k}\Omega) = 3 - 0.1 = 2.9\ \mathrm{V}.$$

此时 $V_{SG2} = V_{DD} - V_{out} = 0.1\ \mathrm{V} < |V_{THP}|$，因此 $M_2$ 截止。**这与故障现象相符。** 该级也基本上没有增益：小信号负载约为 $R_{well}$，远小于设计中的 $1/g_{m2}$。

| 发生尖刺的结 | 直流输出 |
|---|---|
| $M_1$ 源区 / 衬底 | 低于正常值（电流更大） |
| $M_1$ 漏区 / 衬底 | 接近地 |
| $M_2$ 源区 / n 阱 | 正常值（无影响） |
| $M_2$ 漏区 / n 阱 | **接近 $V_{DD}$** |

### 结果

故障结是 **$M_2$ 的 p+ 漏区与其 n 阱之间的结**。尖刺使输出节点与接 $V_{DD}$ 的 n 阱短路，因此 $V_{out} \approx V_{DD} - I_{D1}R_{well}$，即接近 $V_{DD}$，该级几乎没有增益。正常的二极管连接负载总是使 $V_{out}$ 至少比 $V_{DD}$ 低 $|V_{THP}|$；$M_1$ 漏极处的尖刺会把输出拉到地，$M_1$ 源极处的尖刺会使输出降低，而 $M_2$ 源极处的尖刺则没有影响。

**常见错误。** 因为“它是与 $V_{DD}$ 相连的结”而选择 $M_2$ 的源结。该源区及其阱**本来**就处于 $V_{DD}$，因此把它们短路是无害的；只有**输出节点**（$M_2$ 的漏极）发生短路，才会把输出拉到 $V_{DD}$。

**常见错误。** 归咎于 $M_1$ 的漏结。它位于接地的 p 型衬底中，因此那里的尖刺会把输出**向下**拉到地。

**常见错误。** 以为正常电路本身就能得到 $V_{out} \approx V_{DD}$。只要 $M_1$ 导通，$M_2$ 就需要 $V_{SG2} > |V_{THP}|$，因此输出始终至少比电源低一个 PMOS 阈值电压。
