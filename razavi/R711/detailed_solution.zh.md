# 详细步骤 - R711

**思路。** 只有一种均匀介质时，每层单位面积对衬底的电容为 $\epsilon/h$，由此可确定每层金属的高度（以 $\epsilon$ 为单位），而相邻两层之间的电容等于 $\epsilon$ 除以它们的间距。两个端子交替排列（A = 金属 4 + 金属 2，B = 金属 3 + 金属 1），因此三个层间电容都连接在 A 与 B 之间，并联相加。只有最下面的极板，即金属 1，面对衬底。

### 第 1 步 — 由对衬底的电容求高度

由 $h = \epsilon/C_{sub}$，以 $\epsilon/(\mathrm{aF/\mu m^2})$ 为单位：

$$
\begin{aligned}
h_4 &= 1/7.0 = 0.1429,\\
h_3 &= 1/9.0 = 0.1111,\\
h_2 &= 1/15 = 0.0667,\\
h_1 &= 1/30 = 0.0333 ,
\end{aligned}
$$

从金属 4 到金属 1 依次降低，与预期相符。

### 第 2 步 — 层间电容

对于极板 $i$（上）和 $j$（下），间距为 $h_i - h_j$：

$$C_{ij} = \frac{\epsilon}{h_i - h_j} = \frac{1}{\dfrac{1}{C_{sub,i}} - \dfrac{1}{C_{sub,j}}}$$

（等价地，$C_{sub,i}$ 是 $C_{ij}$ 与 $C_{sub,j}$ 的串联。）

**金属 4 – 金属 3：**

$$\frac{1}{C_{43}} = \frac17 - \frac19 = \frac{2}{63}\ \frac{\mu\mathrm{m^2}}{\mathrm{aF}} \;\Longrightarrow\; C_{43} = 31.5\ \mathrm{aF/\mu m^2}.$$

**金属 3 – 金属 2：**

$$\frac{1}{C_{32}} = \frac19 - \frac{1}{15} = \frac{15 - 9}{135} = \frac{6}{135}\ \frac{\mu\mathrm{m^2}}{\mathrm{aF}} \;\Longrightarrow\; C_{32} = 22.5\ \mathrm{aF/\mu m^2}.$$

**金属 2 – 金属 1：**

$$\frac{1}{C_{21}} = \frac{1}{15} - \frac{1}{30} = \frac{2 - 1}{30} = \frac{1}{30}\ \frac{\mu\mathrm{m^2}}{\mathrm{aF}} \;\Longrightarrow\; C_{21} = 30\ \mathrm{aF/\mu m^2}.$$

### 第 3 步 — 两端子之间的总电容

沿叠层向下，各极板交替属于 A、B、A、B，因此 $C_{43}$（A 到 B）、$C_{32}$（B 到 A）和 $C_{21}$（A 到 B）都连接在两个端子之间，**并联**：

<!-- diagram: diagram-01.cir -->

$$C = C_{43} + C_{32} + C_{21} = 31.5 + 22.5 + 30 = 84\ \mathrm{aF/\mu m^2}.$$

### 第 4 步 — 寄生电容与比值

金属 1（底极板，属于端子 B）直接面对衬底；金属 2、3、4 都分别被其下方的极板屏蔽（忽略边缘效应）：

$$C_P = C_{sub,1} = 30\ \mathrm{aF/\mu m^2}, \qquad \frac{C_P}{C} = \frac{30}{84} = 0.357 \approx 0.36 .$$

**与较少层数的比较。** 两层（金属 4/金属 3）电容的 $C = 31.5$，$C_P = 9$（比值 0.29）；三层（金属 4/3/2）电容的 $C = 54$，$C_P = 15$（比值 0.28）。加上金属 1 使电容密度提高到 84 aF/µm²（两层时的 2.7 倍），但金属 1 离衬底太近，寄生电容翻倍到 30 aF/µm²，比值恶化到 0.36：增加层数是用更大的底极板寄生比例换取更高的电容密度。

### 结果

单位面积上：

$$C = 31.5 + 22.5 + 30 = 84\ \mathrm{aF/\mu m^2}, \qquad C_P = 30\ \mathrm{aF/\mu m^2}, \qquad \frac{C_P}{C} \approx 0.36 .$$

**常见错误。** 把层间电容算成对衬底电容之差（例如对金属 2–金属 1 取 $30 - 15 = 15$ aF/µm²）。由于 $C = \epsilon/h$，相减的应是倒数，得到 $C_{21} = 1/(1/15 - 1/30) = 30$ aF/µm²。

**常见错误。** 漏掉某一对相邻层。端子交替排列时，每一对相邻极板都有贡献。

**常见错误。** 把上层极板对衬底的电容计入 $C_P$。只有金属 1 面对衬底。
