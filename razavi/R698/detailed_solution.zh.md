# 详细步骤 - R698

**思路。** $M_1$ 是一个 MOS（去耦）电容：栅极是上极板，反型沟道是下极板，沟道两端由接地的源极和漏极引出。栅极电荷沿沟道的整个长度进入沟道，而电流只从两端流出，因此等效串联电阻（ESR）只是源漏沟道电阻的一部分。先确定偏置，再计算深线性区中的沟道电阻，然后由沟道中耗散的功率求出 ESR。

### 第 1 步 — $M_1$ 的偏置点

电感上没有直流压降，因此栅极（节点 X）位于 $V_{DD} = 3$ V。源极、漏极和衬底都接地，因此 $V_{GS} = 3$ V，$V_{DS} = 0$，$V_{SB} = 0$，$V_{TH} = V_{TH0} = 0.7$ V：

$$V_{ov} = V_{GS} - V_{TH} = 3 - 0.7 = 2.3\ \mathrm{V}.$$

表面处于强反型，并且由于 $V_{DS} = 0 < V_{ov}$，器件工作在**深线性区**，沟道电荷**均匀**分布。

### 第 2 步 — 源漏沟道电阻 $R_{tot}$

在深线性区，沟道相当于源漏之间的一个电阻，其中 $W/L = 100\ \mu\mathrm{m}/0.5\ \mu\mathrm{m} = 200$：

$$R_{tot} = \frac{1}{\mu_nC_{ox}\dfrac{W}{L}(V_{GS} - V_{TH})} = \frac{1}{(134\times10^{-6}\ \mathrm{A/V^2})(200)(2.3\ \mathrm{V})} = \frac{1}{0.06164\ \mathrm{A/V}} = 16.2\ \Omega .$$

这**不是**该电容的串联电阻，因为电容电流并不是从沟道的一端流到另一端。

### 第 3 步 — 电容电流在沟道中如何流动

$V_X$ 的变化驱动位移电流流过氧化层，而氧化层沿沟道均匀分布，因此电流**沿沟道长度均匀地**进入沟道（只要频率足够低，使沿沟道的压降远小于氧化层两端的电压）。然后电流**沿沟道**流向接地的源极和漏极。因此沟道是一条**分布式 RC 线**：一条总电阻为 $R_{tot}$、两端接地的电阻条，通过许多小的氧化层电容与栅极耦合。

由对称性，进入左半部分的电流从源极流出，进入右半部分的电流从漏极流出；没有电流穿过沟道中点。

### 第 4 步 — 用功率法求等效串联电阻

设流入栅极的总小信号电流为 $I$，令 $x$ 从源极（$x = 0$）取到漏极（$x = L$）。单位长度流入的电流为 $I/L$，单位长度的电阻为 $r = R_{tot}/L$。在左半部分，$x$ 处流向源极的电流等于在 $x$ 与 $L/2$ 之间流入的电流：

$$i(x) = \frac{I}{L}\left(\frac{L}{2} - x\right), \qquad 0 \le x \le \frac{L}{2},$$

它从源极处的 $I/2$ 线性下降到中点处的 0。左半部分耗散的功率为

$$P_{left} = \int_0^{L/2} i(x)^2\,r\,dx = \frac{I^2}{L^2}\cdot\frac{R_{tot}}{L}\int_0^{L/2}\left(\frac{L}{2} - x\right)^2dx .$$

令 $u = L/2 - x$：

$$\int_0^{L/2}\left(\frac{L}{2} - x\right)^2dx = \int_0^{L/2}u^2\,du = \frac{1}{3}\left(\frac{L}{2}\right)^3 = \frac{L^3}{24},$$

因此

$$P_{left} = \frac{I^2R_{tot}}{L^3}\cdot\frac{L^3}{24} = \frac{I^2R_{tot}}{24}.$$

右半部分耗散的功率与此相同，因此

$$P = 2P_{left} = \frac{I^2R_{tot}}{12}.$$

令其等于串联电阻 $R_S$ 上的功率 $I^2R_S$：

$$R_S = \frac{R_{tot}}{12}.$$

（开路的分布式 RC 线的阻抗在低频时为 $Z \approx R/3 + 1/(j\omega C)$，由此也可得到同样的结果：每一半的 $R = R_{tot}/2$，因此其串联电阻为 $R_{tot}/6$，两半并联得到 $R_{tot}/12$。）

### 第 5 步 — 数值结果与一种更简单的估计

$$R_S = \frac{R_{tot}}{12} = \frac{16.2\ \Omega}{12} = 1.35\ \Omega .$$

**集总估计。** 如果栅极电荷全部从沟道中心进入，电流 $I/2$ 将流过每个半沟道电阻 $R_{tot}/2$，两半相互并联：

$$R_S \approx \frac{R_{tot}}{2}\parallel\frac{R_{tot}}{2} = \frac{R_{tot}}{4} = \frac{16.2}{4} = 4.06\ \Omega .$$

这把 ESR 高估了 3 倍，因为实际上有很多电荷是在靠近接触端的地方进入的。

**补充参考**（答案并不需要）：取 $C_{ox} \approx 3.84\ \mathrm{fF/\mu m^2}$，则 $C \approx WLC_{ox} = (100\times0.5\ \mu\mathrm{m^2})(3.84\ \mathrm{fF/\mu m^2}) = 192$ fF，$R_SC = (1.35\ \Omega)(192\ \mathrm{fF}) \approx 0.26$ ps，因此在实际频率下用于去耦时，ESR 可以忽略。

### 结果

$M_1$ 工作在深线性区，$V_{GS} = V_{DD} = 3$ V，$V_{ov} = 2.3$ V，由此得到源漏沟道电阻

$$R_{tot} = \frac{1}{\mu_nC_{ox}(W/L)(V_{GS} - V_{TH})} = 16.2\ \Omega .$$

由于沟道是两端都有接触的分布式 RC 线，该 MOS 电容的等效串联电阻为

$$R_S = \frac{R_{tot}}{12} \approx 1.35\ \Omega$$

（较粗略的集总估计 $R_{tot}/4 \approx 4.06\ \Omega$ 是一个上限）。

**常见错误。** 把整个沟道电阻 $R_{tot} \approx 16.2\ \Omega$ 当作 ESR。电容电流经氧化层沿整个沟道进入，并从**两个**接地端流出，因此只有 $R_{tot}$ 的一部分是串联的。

**常见错误。** 把 $M_1$ 当作处于饱和区（saturation region），并使用 $1/g_m$。由于 $V_{DS} = 0$，器件处于深线性区，其沟道是一个均匀的电阻。

**常见错误。** 使用不等于 $V_{DD}$ 的栅极电压，例如减去电感上的压降。电感两端没有直流电压，因此 $V_X = V_{DD} = 3$ V，$V_{ov} = 2.3$ V。
