在 [图 1] 所示的电路中，$(W/L)_1 = 50/0.5$（NMOS $M_1$），$(W/L)_2 = 50/2$（PMOS $M_2$），两个器件都处于饱和区（saturation region）时 $I_{D1} = I_{D2} = 0.5$ mA。沟道长度调制（channel-length modulation）系数与 $L$ 成反比；下面给出的 λ 值适用于 $L = 0.5$ μm。计算小信号电压增益。尺寸均为以 μm 为单位的有效值。

器件参数：NMOS 的 $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$V_{TH0} = 0.7$ V，$\lambda = 0.1\ \mathrm{V^{-1}}$（$L = 0.5$ μm 时）；PMOS 的 $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$V_{TH0} = -0.8$ V，$\lambda = 0.2\ \mathrm{V^{-1}}$（$L = 0.5$ μm 时）。
