# Golden Solution - R380

## Reference answer

$$V_{out} = -\frac{g_{m1}r_{O1}r_{O3}}{r_{O1} + r_{O2} + r_{O3} + (g_{m1} + g_{mb1})r_{O1}r_{O2}}V_{n1}$$

- With the input open, $V_{n1}$ drives a CS stage: gate input $V_{n1}$, source degenerated by $r_{O2}$ (the only element at the input node), load $r_{O3}$. Using the degenerated-stage gain with $R_S = r_{O2}$, $R_D = r_{O3}$ gives the result.
- For $g_mr_O \gg 1$: $V_{out} \approx -\dfrac{g_{m1}}{g_{m1}+g_{mb1}}\cdot\dfrac{r_{O3}}{r_{O2}}V_{n1}$ (valid when $r_{O3} \ll (g_{m1}+g_{mb1})r_{O1}r_{O2}$), i.e. a gain of order 1: the heavy degeneration by $r_{O2}$ suppresses $M_1$'s noise.

## Grading notes

+2: expression equivalent to the reference. +1: correct with body effect omitted (stated), or with one $r_O$ term dropped in the denominator as an explicit approximation. 0: correct qualitative conclusion (gain ≈ $r_{O3}/r_{O2}$, small) without the exact expression. -2 (asserted as fact): source treated as grounded (gain $g_{m1}(r_{O1}\|r_{O3})$), $V_{n1}$ said to produce no output at all, or the load taken as $r_{O3}\|r_{O2}$.
