# 详细步骤 - R380

**思路。** 输入端开路且只有 $M_1$ 的噪声时，$V_{n1}$ 驱动的是一个共源级：$M_1$ 的源极由输入节点上仅剩的元件 $r_{O2}$ 构成源极负反馈，漏极以 $r_{O3}$ 为负载。写出该级的小信号方程（计入 $r_{O1}$ 和 $g_{mb1}$），解出 $V_{out}$。

### 第 1 步 — 简化电路

把输入节点（$M_1$ 的源极）记为 X。$M_3$ 和 $M_2$ 的栅极和源极都处于交流地，因此它们分别简化为 $r_{O3}$（从 $V_{out}$ 到交流地）和 $r_{O2}$（从 X 到地）；输入端**开路**时，X 上再没有其他元件。$M_1$ 的小信号栅极电压为 $V_{n1}$，其衬底接地，因此 $v_{bs1} = -V_X$。

因此 $V_{n1}$ 看到的是一个**以 $R_S = r_{O2}$ 作源极负反馈、以 $R_D = r_{O3}$ 为负载的共源级**。$r_{O2}$ 位于源极，**而不是**与 $r_{O3}$ 并联。

### 第 2 步 — 小信号方程

$M_1$ 的沟道中从漏极流向源极的电流为

$$I = g_{m1}(V_{n1} - V_X) + g_{mb1}(0 - V_X) + \frac{V_{out} - V_X}{r_{O1}} .$$

<!-- diagram: diagram-01.cir -->

在 X 点，$I$ 只能经 $r_{O2}$ 流出；在输出端，它只能来自 $r_{O3}$：

$$V_X = I\,r_{O2}, \qquad V_{out} = -I\,r_{O3}.$$

### 第 3 步 — 求解电流

代入沟道方程：

$$
\begin{aligned}
I &= g_{m1}V_{n1} - (g_{m1} + g_{mb1})\,I\,r_{O2} + \frac{-Ir_{O3} - Ir_{O2}}{r_{O1}}\\
I\left[1 + (g_{m1} + g_{mb1})r_{O2} + \frac{r_{O2} + r_{O3}}{r_{O1}}\right] &= g_{m1}V_{n1}.
\end{aligned}
$$

乘以 $r_{O1}$：

$$
\begin{aligned}
I\left[r_{O1} + (g_{m1} + g_{mb1})r_{O1}r_{O2} + r_{O2} + r_{O3}\right] &= g_{m1}r_{O1}V_{n1}\\
I &= \frac{g_{m1}r_{O1}\,V_{n1}}{r_{O1} + r_{O2} + r_{O3} + (g_{m1} + g_{mb1})r_{O1}r_{O2}}.
\end{aligned}
$$

### 第 4 步 — 输出电压

$$V_{out} = -r_{O3}I = -\frac{g_{m1}r_{O1}r_{O3}}{r_{O1} + r_{O2} + r_{O3} + (g_{m1} + g_{mb1})r_{O1}r_{O2}}\,V_{n1}.$$

这正是带源极负反馈的共源级增益 $-g_mr_OR_D/[R_D + R_S + r_O + (g_m + g_{mb})r_OR_S]$，其中 $R_S = r_{O2}$，$R_D = r_{O3}$。

### 第 5 步 — 结果解读

当 $g_mr_O \gg 1$ 时，分母中的 $(g_{m1} + g_{mb1})r_{O1}r_{O2}$ 项占主导（约为其他各项的 $g_mr_O$ 倍）：

$$V_{out} \approx -\frac{g_{m1}}{g_{m1} + g_{mb1}}\cdot\frac{r_{O3}}{r_{O2}}\,V_{n1}.$$

$M_1$ 的噪声所经历的“增益”只有**一**的量级，而不是 $g_mr_O$ 的量级。

**举例**（假设的数值）：$r_{O1} = r_{O2} = r_{O3} = r_O$，$g_{m1}r_O = 50$，$g_{mb1} = 0.2g_{m1}$。分母为 $3r_O + 1.2\times50\,r_O = 63r_O$，因此 $|V_{out}/V_{n1}| = 50/63 \approx 0.79$。若源极接地，增益将为 $g_{m1}(r_{O1}\parallel r_{O3}) = 25$，大约大 30 倍。

$V_{n1}$ 推动流过 $M_1$ 的任何电流都必须同时流过很大的 $r_{O2}$，这会抬高 $V_X$，抵消 $v_{gs1}$ 的大部分。这是如下事实在有限 $r_O$ 下的推广：输入端开路时，共栅器件自身的噪声不会到达输出端；当 $r_{O2} \to \infty$ 时，$V_{out} \to 0$。

### 结果

$$V_{out} = -\frac{g_{m1}r_{O1}r_{O3}}{r_{O1} + r_{O2} + r_{O3} + (g_{m1} + g_{mb1})r_{O1}r_{O2}}\,V_{n1}$$

即 $V_{n1}$ 驱动一个以 $r_{O2}$ 作源极负反馈、以 $r_{O3}$ 为负载的共源级。当 $g_mr_O \gg 1$ 时，$V_{out} \approx -[g_{m1}/(g_{m1} + g_{mb1})](r_{O3}/r_{O2})V_{n1}$，增益为 1 的量级：强源极负反馈大大抑制了 $M_1$ 的噪声。

**常见错误。** 把 $M_1$ 的源极当作接地，得到 $V_{out} = -g_{m1}(r_{O1}\parallel r_{O3})V_{n1}$。输入端开路时，源极只经 $r_{O2}$ 接地。

**常见错误。** 声称 $V_{n1}$ 根本不产生输出。这只在 $r_{O2} \to \infty$ 时成立；$r_{O2}$ 为有限值时，输出约为 $(r_{O3}/r_{O2})V_{n1}$。

**常见错误。** 把负载取为 $r_{O3}\parallel r_{O2}$。$r_{O2}$ 位于 $M_1$ 的**源极**，起源极负反馈的作用。
