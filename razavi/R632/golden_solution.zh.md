$Z(s) = \dfrac{1}{g_{m3}}\left(1 + \dfrac{sC_{GS3}}{g_{m5}}\right) = \dfrac{1}{g_{m3}} + s\,\dfrac{C_{GS3}}{g_{m3}g_{m5}}$：即电阻 $1/g_{m3}$ 与等效电感 $L_{eq} = C_{GS3}/(g_{m3}g_{m5})$ 串联。
该负载呈感性，是因为跟随器要通过其非零的输出电阻（output resistance）$1/g_{m5}$ 驱动 $C_{GS3}$：$M_3$ 的栅极电压滞后于 $V_X$，因此负载电流滞后于电压。当频率与零点 $\omega_z = g_{m5}/C_{GS3}$ 相当或更高时，即跟随器的输出时间常数 $C_{GS3}/g_{m5}$ 与信号周期相比不可忽略时（跟随器较弱，即 $g_{m5}$ 较小，或 $M_3$ 较大），感性行为就很显著。若 $g_{m5} \to \infty$，负载就是纯电阻 $1/g_{m3}$。（若 $r_{O3}$ 有限，$Z = r_{O3} \parallel Z(s)$ 在 $\omega_z$ 到约 $(1 + g_{m3}r_{O3})\,g_{m5}/C_{GS3}$ 之间呈感性。）

推导：
- $M_3$ 的源极接 $V_{DD}$（交流地），因此 $C_{GS3}$ 接在跟随器输出与地之间。在该节点应用 KCL（电流源为理想的）：$g_{m5}(V_X - V_G) = sC_{GS3}V_G$ → $V_G = V_X/(1 + sC_{GS3}/g_{m5})$。
- 从 X 吸取的电流只有 $M_3$ 的漏极电流 $g_{m3}V_G$（$C_{GS3}$ 的电流由 $M_5$ 提供，而不是来自节点 X），因此 $Z = V_X/(g_{m3}V_G)$，即上式：在 $g_{m5}/C_{GS3}$ 处有一个零点，高于该频率时 $|Z|$ 上升，相位为正。
- 相比之下，二极管连接（diode-connected）的 PMOS 给出 $Z = 1/(g_{m3} + sC_{GS3})$，呈容性（capacitive）。
