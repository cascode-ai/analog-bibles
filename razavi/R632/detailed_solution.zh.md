# 详细步骤 - R632

**思路。** 在 X 处加一个小测试电压 $v_x$，保留 $C_{GS3}$，计算负载吸取的电流。源极跟随器必须通过自身的输出电阻 $1/g_{m5}$ 给 $C_{GS3}$ 充电，因此 $M_3$ 的栅极电压及其电流都滞后于 X 处的电压，这正是电感的特征。推导 $Z(s)$，找出等效的 $R$–$L$ 电路，并说明感性部分何时起作用。

### 第 1 步 — 小信号模型

把 $M_5$ 的源极（即 $M_3$ 的栅极）记为节点 G。取 $\lambda = \gamma = 0$，并只保留 $C_{GS3}$：

- **$M_5$：** 受控电流 $g_{m5}(v_x - v_g)$ 从 $V_{DD}$（交流地）流入 G；理想偏置电流源相当于开路。
- **$C_{GS3}$：** 接在 G 与 $M_3$ 的源极之间，而该源极接 $V_{DD}$，因此实际上是**从 G 接到地**。
- **$M_3$：** 受控电流 $g_{m3}v_{sg3} = g_{m3}(0 - v_g) = -g_{m3}v_g$ 从 $V_{DD}$ 流入 X（没有 $r_{O3}$）。
- 在 X 处加测试源 $v_x$，$i_x$ 为从测试源流入负载的电流。

### 第 2 步 — $M_3$ 的栅极电压：跟随器现在有一个极点

偏置电流源不流过小信号电流，因此在 G 点应用 KCL 得

$$g_{m5}(v_x - v_g) = sC_{GS3}\,v_g \quad\Longrightarrow\quad g_{m5}v_x = v_g\left(g_{m5} + sC_{GS3}\right),$$

$$v_g = \frac{g_{m5}}{g_{m5} + sC_{GS3}}\,v_x = \frac{v_x}{1 + sC_{GS3}/g_{m5}} .$$

低频时 $v_g = v_x$（即电阻性情况下的单位增益跟随器）；频率较高时，$1/g_{m5}$ 与 $C_{GS3}$ 构成低通滤波器，因此 $v_g$ 滞后于 $v_x$。

### 第 3 步 — 从 X 吸取的电流

$M_3$ 向 X 送入 $-g_{m3}v_g$，即从 X 吸取 $g_{m3}v_g$。$M_5$ 的栅极不吸取电流，而给 $C_{GS3}$ 充电的电流由漏极接 $V_{DD}$ 的 $M_5$ 提供，**并不**来自 X。因此

$$i_x = g_{m3}v_g = \frac{g_{m3}\,v_x}{1 + sC_{GS3}/g_{m5}} .$$

### 第 4 步 — 复合负载的阻抗

$$Z(s) = \frac{v_x}{i_x} = \frac{1}{g_{m3}}\left(1 + \frac{sC_{GS3}}{g_{m5}}\right) = \frac{1}{g_{m3}} + s\,\frac{C_{GS3}}{g_{m3}g_{m5}} ,$$

即一个电阻与一个电感串联：

$$R_{eq} = \frac{1}{g_{m3}}, \qquad L_{eq} = \frac{C_{GS3}}{g_{m3}g_{m5}} .$$

$Z(s)$ 在

$$\omega_z = \frac{g_{m5}}{C_{GS3}}$$

处有一个零点，没有极点。在 $j\omega$ 轴上：

$$|Z(j\omega)| = \frac{1}{g_{m3}}\sqrt{1 + \left(\frac{\omega}{\omega_z}\right)^2}, \qquad \angle Z(j\omega) = +\tan^{-1}\frac{\omega}{\omega_z} .$$

| $\omega/\omega_z$ | $g_{m3}\lvert Z\rvert$ | $Z$ 的相位 | 特性 |
|---|---|---|---|
| 0.1 | 1.005 | +5.7° | 基本上为 $1/g_{m3}$ |
| 1 | 1.414 | +45° | 阻性部分与感性部分相等 |
| 3 | 3.16 | +71.6° | 主要呈感性 |
| 10 | 10.05 | +84.3° | 接近纯电感 |

相位为正（电压超前于电流），且 $|Z|$ 随频率升高而增大：这是感性行为。

### 第 5 步 — 呈感性的条件

只要跟随器通过不可忽略的输出电阻 $1/g_{m5}$ 驱动 $C_{GS3}$，负载就呈感性；当频率与

$$\omega_z = \frac{g_{m5}}{C_{GS3}},$$

相当或更高时，即跟随器的时间常数 $C_{GS3}/g_{m5}$ 与信号周期相比不算小时，这一效应就很显著。跟随器较弱（$g_{m5}$ 小）或 $M_3$ 较大（$C_{GS3}$ 大）都会降低 $\omega_z$，并增大 $L_{eq} = C_{GS3}/(g_{m3}g_{m5})$。当 $g_{m5} \to \infty$ 时，栅极即时跟随 X，负载为纯电阻 $1/g_{m3}$。

**与二极管连接的 PMOS 对比。** 若栅极直接接 X，$C_{GS3}$ 的电流将从 X 吸取，于是

$$Z_{diode} = \frac{1}{g_{m3} + sC_{GS3}},$$

呈**容性**。跟随器把 $C_{GS3}$ 的电流从节点 X 移开，代之以一个延迟。

**$r_{O3}$ 有限时。** 阻抗变为 $r_{O3} \parallel Z(s)$，在 $\omega_z$ 到约 $(1 + g_{m3}r_{O3})\,g_{m5}/C_{GS3}$ 之间呈感性，超过这一频率后受 $r_{O3}$ 限制。

### 结果

$$Z(s) = \frac{1}{g_{m3}}\left(1 + \frac{sC_{GS3}}{g_{m5}}\right) = \frac{1}{g_{m3}} + s\,\frac{C_{GS3}}{g_{m3}g_{m5}},$$

即电阻 $1/g_{m3}$ 与电感 $L_{eq} = C_{GS3}/(g_{m3}g_{m5})$ 串联。负载之所以呈感性，是因为跟随器通过有限的输出电阻 $1/g_{m5}$ 驱动 $C_{GS3}$，使 $M_3$ 的栅极电压及其电流都滞后于 $V_X$。在 $\omega_z = g_{m5}/C_{GS3}$ 及更高的频率处，感性行为很显著；跟随器越弱（$g_{m5}$ 越小）或 $C_{GS3}$ 越大，这种行为越强。当 $g_{m5} \to \infty$ 时，负载退化为电阻 $1/g_{m3}$。

**常见错误。** 认为 $C_{GS3}$ 的电流取自节点 X，这会得到二极管连接器件那样的容性阻抗 $Z = 1/(g_{m3} + sC_{GS3})$。这里电容由漏极接 $V_{DD}$ 的 $M_5$ 充电。

**常见错误。** 把跟随器当作理想的（在所有频率下 $v_g = v_x$），这样负载就成了纯电阻。电感的存在完全是因为 $1/g_{m5}$ 有限。

**常见错误。** 给出臆造的条件，例如“只有当 $g_{m5} < g_{m3}$ 时才呈感性”。该阻抗有一个零点而没有极点，因此在所有频率下都呈感性；$g_{m5}/C_{GS3}$ 决定的是感性部分从**哪里**开始变得重要。
