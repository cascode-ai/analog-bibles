# 详细步骤 - R223

**思路。** 把两个理想电流源替换为开路，对每个节点应用基尔霍夫电流定律（KCL）。$M_1$ 的漏极只与理想电流源 $I_1$ 相连，因此 $M_1$ 的小信号电流为零。这又迫使 $M_2$ 的电流也为零，由此依次确定 $v_{out2}$、$v_P$，最后确定 $v_{out1}$。

### 第 1 步 — 偏置点与小信号模型（small-signal model）

把公共源极节点记为 P。能流入 $M_1$ 的电流只有 $I_1$，因此 $I_{D1} = I_1$，对 P 点列 KCL 得

$$I_{D2} = I_{SS} - I_1 ,$$

这要求 $I_1 < I_{SS}$。两个电流一般不相等，因此两个器件的参数不同：

$$g_{m1} = \sqrt{2\mu_nC_{ox}(W/L)_1I_1}, \quad r_{O1} = \frac{1}{\lambda I_1}, \qquad g_{m2} = \sqrt{2\mu_nC_{ox}(W/L)_2(I_{SS} - I_1)}, \quad r_{O2} = \frac{1}{\lambda(I_{SS} - I_1)} .$$

两个晶体管都工作在饱和区（saturation region）；$V_{out1}$ 是高阻节点，它会稳定在使 $M_1$ 的电流恰好等于 $I_1$ 的电压上。

在小信号模型中，$V_{DD}$ 和 $V_b$ 为交流地，$I_1$、$I_{SS}$ 为开路。衬底接地时，控制电压为

$$
\begin{aligned}
M_1:&\quad v_{gs1} = v_{in} - v_P, & v_{bs1} &= -v_P,\\
M_2:&\quad v_{gs2} = 0 - v_P = -v_P, & v_{bs2} &= -v_P .
\end{aligned}
$$

从漏极流向源极的小信号电流为

$$
\begin{aligned}
i_1 &= g_{m1}(v_{in} - v_P) - g_{mb1}v_P + \frac{v_{out1} - v_P}{r_{O1}},\\
i_2 &= -g_{m2}v_P - g_{mb2}v_P + \frac{v_{out2} - v_P}{r_{O2}} .
\end{aligned}
$$

### 第 2 步 — KCL：没有信号电流流动，因此 $v_{out2} = 0$

**节点 $V_{out1}$。** 流入该节点的电流只来自 $I_1$，而其小信号值为零，因此 $i_1 = 0$：输入无法改变 $M_1$ 的电流，因为有一个理想电流源与它串联。

**节点 P。** 开路的尾电流源不吸收任何电流：

$$i_1 + i_2 = 0 \quad\Longrightarrow\quad i_2 = -i_1 = 0 .$$

**节点 $V_{out2}$。** $M_2$ 吸取的电流经 $R_1$ 来自交流地：

$$\frac{0 - v_{out2}}{R_1} = i_2 \quad\Longrightarrow\quad v_{out2} = -R_1i_2 = 0, \qquad \frac{V_{out2}}{V_{in}} = 0 .$$

### 第 3 步 — 节点 P 不动

由 $v_{out2} = 0$ 和 $i_2 = 0$，$M_2$ 的电流方程给出

$$0 = -g_{m2}v_P - g_{mb2}v_P + \frac{0 - v_P}{r_{O2}} = -\left(g_{m2} + g_{mb2} + \frac{1}{r_{O2}}\right)v_P .$$

括号内的量为正，因此

$$v_P = 0 .$$

$M_2$ 的栅极电压、漏极电压和电流都固定不变，因此它的源极也不能移动：P 是真正的交流地，但原因并不是通常的差分对称性。

### 第 4 步 — 到 $V_{out1}$ 的增益

由 $v_P = 0$ 和 $i_1 = 0$，$M_1$ 的电流方程给出

$$0 = g_{m1}(v_{in} - 0) - g_{mb1}\cdot0 + \frac{v_{out1} - 0}{r_{O1}} = g_{m1}v_{in} + \frac{v_{out1}}{r_{O1}} ,$$

$$v_{out1} = -g_{m1}r_{O1}\,v_{in}, \qquad \frac{V_{out1}}{V_{in}} = -g_{m1}r_{O1} ,$$

这就是 $M_1$ 的**本征增益**：由于 $I_1$ 固定了它的电流，$V_{DS1}$ 必须下降，直到沟道长度调制（channel-length modulation）抵消电流的增加，即 $g_{m1}v_{in} = -v_{out1}/r_{O1}$。$M_1$ 相当于一个源极接交流地、以理想电流源为负载的共源级（common-source stage）。

**体效应不起作用**，因为两个 $g_{mb}$ 项都乘以 $v_P = 0$。有限的 $\lambda$ 是必不可少的：若 $r_{O1} \to \infty$，方程变为 $0 = g_{m1}v_{in}$，当 $v_{in} \neq 0$ 时无解（增益无穷大；实际上 $V_{out1}$ 会碰到电源轨）。

### 第 5 步 — 联立求解全部方程进行验证

$$
\begin{aligned}
i_1 &= 0, \qquad i_1 + i_2 = 0, \qquad v_{out2} = -R_1i_2,\\
i_1 &= g_{m1}(v_{in} - v_P) - g_{mb1}v_P + (v_{out1} - v_P)/r_{O1},\\
i_2 &= -(g_{m2} + g_{mb2})v_P + (v_{out2} - v_P)/r_{O2} .
\end{aligned}
$$

这五个线性方程有唯一解 $i_1 = i_2 = 0$，$v_{out2} = 0$，$v_P = 0$，$v_{out1} = -g_{m1}r_{O1}v_{in}$，验证了第 2–4 步的结果。

### 结果

$$\frac{V_{out1}}{V_{in}} = -g_{m1}r_{O1}, \qquad \frac{V_{out2}}{V_{in}} = 0 .$$

理想电流源 $I_1$ 迫使 $M_1$ 的信号电流为零，理想尾电流源进而迫使 $M_2$ 的信号电流为零。因此 $V_{out2}$ 不动，P 点也不动（体效应无关紧要），而 $V_{out1}$ 表现出 $M_1$ 的本征增益。

**常见错误。** 把该电路当作标准的差分对（differential pair），写出 $V_{out2}/V_{in} = g_mR_1/2$ 或其他非零值。$I_1$ 阻止了 $M_1$ 电流的任何变化，因此在理想尾电流源下，不可能有电流被引导到 $M_2$ 中。

**常见错误。** 利用“虚地（virtual ground）”半边电路（half circuit）写出 $V_{out1}/V_{in} = -g_{m1}r_{O1}/2$。P 点之所以是交流地，是因为 $M_2$ 的电流、栅极和漏极都固定不变，而输入也并没有在两半边之间分配。

**常见错误。** 因为负载是理想电流源，就断言 $V_{out1}/V_{in}$ 为无穷大；这只在 $\lambda = 0$ 时成立。另外也不要写成 $-(1 + g_{m1}r_{O1})$：只有当输入驱动**源极**时才会出现“$+1$”。
