# 详细步骤 - R142

**思路。** 把电源的变化看作小信号输入 $v_{dd}$，固定偏置 $V_B$ 为交流地。于是 $M_1$ 简化为 $r_{O1}$，而 PMOS $M_2$ 的**源极**随 $v_{dd}$ 变化、栅极固定，它向输出端注入 $g_{m2}v_{dd}$。在输出端列一个基尔霍夫电流定律（KCL）方程即可得到结果。

### 第 1 步 — 小信号模型

- **$M_1$**：栅极（$V_B$）和源极（地）都是交流地，因此 $v_{gs1} = 0$，只剩下从 out 接到地的 $r_{O1}$。
- **$M_2$**：源极位于 $v_{dd}$，栅极接交流地，因此
$$v_{sg2} = v_{dd} - 0 = v_{dd}.$$
它的衬底随源极一起变化（$v_{sb2} = 0$），因此**没有体效应电流**。$M_2$ 贡献一个从电源节点流入 out 的电流 $g_{m2}v_{sg2} = g_{m2}v_{dd}$，以及接在电源节点与 out 之间的 $r_{O2}$。

<!-- diagram: diagram-01.cir -->

（当 PMOS 的栅极固定而源极升高时，$V_{SG}$ 增大，它向输出端送入**更多**电流。）

### 第 2 步 — 输出端的 KCL

从电源节点经 $M_2$ 流出的电流（$r_{O2}$ 中的电流为 $(v_{dd} - v_{out})/r_{O2}$）

$$i_2 = g_{m2}v_{dd} + \frac{v_{dd} - v_{out}}{r_{O2}},$$

由于输出端不接负载，必须全部向下流过 $r_{O1}$：

$$g_{m2}v_{dd} + \frac{v_{dd} - v_{out}}{r_{O2}} = \frac{v_{out}}{r_{O1}}.$$

### 第 3 步 — 求解 $v_{out}/v_{dd}$

合并 $v_{dd}$ 项和 $v_{out}$ 项：

$$v_{dd}\left(g_{m2} + \frac{1}{r_{O2}}\right) = v_{out}\left(\frac{1}{r_{O1}} + \frac{1}{r_{O2}}\right),$$

$$v_{dd}\,\frac{g_{m2}r_{O2} + 1}{r_{O2}} = v_{out}\,\frac{r_{O1} + r_{O2}}{r_{O1}r_{O2}}.$$

两边同乘 $r_{O1}r_{O2}$：

$$v_{dd}\,(g_{m2}r_{O2} + 1)\,r_{O1} = v_{out}\,(r_{O1} + r_{O2}),$$

$$\frac{v_{out}}{v_{dd}} = \frac{g_{m2}r_{O2} + 1}{r_{O2} + r_{O1}}\,r_{O1},$$

这正是要证明的表达式。$\blacksquare$ 等价地，

$$\frac{v_{out}}{v_{dd}} = \left(g_{m2} + \frac{1}{r_{O2}}\right)(r_{O1}\parallel r_{O2}):$$

电源向输出端注入 $(g_{m2} + 1/r_{O2})v_{dd}$ 的电流，作用在总输出电阻（output resistance）$r_{O1}\parallel r_{O2}$ 上。

### 第 4 步 — 解释与说明

- **影响的大小。** 当 $g_{m2}r_{O2} \gg 1$ 时，$v_{out}/v_{dd} \approx g_{m2}(r_{O1}\parallel r_{O2})$，其量级与本征增益（intrinsic gain）相当。若以 $V_B$ 作为信号输入（两个栅极都被驱动），增益将为 $-(g_{m1} + g_{m2})(r_{O1}\parallel r_{O2})$，因此当 $g_{m1} \approx g_{m2}$ 时，电源以约为信号增益一半的增益传到输出端：电源抑制（supply rejection）能力非常差，因为 $V_B$ 以地为参考，$V_{DD}$ 的每一点变化都会出现在 $M_2$ 的 $V_{SG}$ 中。
- **极限验证。** 当 $g_{m2} = 0$ 时，结果简化为电阻分压比 $r_{O1}/(r_{O1} + r_{O2})$，与预期一致。
- **体效应。** 若衬底改接固定电位，变化的源极会沿同一方向额外产生 $g_{mb2}v_{dd}$，相当于把 $g_{m2}$ 换成 $g_{m2} + g_{mb2}$。

### 结果

$V_B$ 为交流地时，$M_1$ 相当于接地的 $r_{O1}$，$M_2$ 的 $v_{sg2} = v_{dd}$，向输出端注入 $g_{m2}v_{dd} + (v_{dd} - v_{out})/r_{O2}$。在输出端列 KCL 得

$$\frac{V_{out}}{V_{DD}} = \frac{g_{m2}r_{O2} + 1}{r_{O2} + r_{O1}}\,r_{O1} = \left(g_{m2} + \frac{1}{r_{O2}}\right)(r_{O1}\parallel r_{O2}) \approx g_{m2}(r_{O1}\parallel r_{O2}).$$

**常见错误。** 让 $M_2$ 的栅极随 $V_{DD}$ 变化，从而得到 $v_{sg2} = 0$，只剩下分压比 $r_{O1}/(r_{O1} + r_{O2})$。$V_B$ 相对于地是固定的，因此电源的全部变化都出现在 $M_2$ 的源栅电压中。

**常见错误。** 给 $M_1$ 加上由电源驱动的受控电流。它的栅极和源极都是固定的，因此它只是 $r_{O1}$。

**常见错误。** 把 $M_2$ 流入输出端的电流写成 $-g_{m2}v_{dd}$。在 PMOS 栅极固定时抬高其源极，会使其流入输出端的电流增大。
