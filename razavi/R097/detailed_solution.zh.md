# 详细步骤 - R097

**思路。** $M_1$ 是源极跟随器（漏极接 $V_{DD}$，输出取自其源极），栅极接固定电压 $V_b$ 的 $M_2$ 是它的电流源负载。令两管的漏极电流相等，并跟踪 $M_2$ 从线性区（输出接近地）到饱和区（恒定电流 $I_2$）的过程。在每个区域中，跟随器的斜率都由小信号模型（small-signal model）求得，并计入 $M_1$ 的体效应（body effect），此时 $V_{SB1} = V_{out}$。

### 第 1 步 — 工作区边界

- **$M_1$：** $V_{GS1} = V_{in} - V_{out}$，$V_{SB1} = V_{out}$，因此 $V_{TH1} = 0.7 + 0.45(\sqrt{0.9 + V_{out}} - \sqrt{0.9})$ V。其漏极接 $V_{DD} \ge V_{in}$，故 $V_{DS1} \ge V_{GS1}$，因此它只要导通就处于饱和区。
- **$M_2$：** $V_{GS2} = V_b$（固定），$V_{TH2} = 0.7$ V。其饱和电流为
$$I_2 = \frac12\beta_2(V_b - 0.7)^2 ,$$
当 $V_{DS2} = V_{out} \ge V_b - 0.7$ V 时它处于饱和区，低于此值时处于线性区。

输出节点的基尔霍夫电流定律（KCL）：$I_{D1} = I_{D2}$。

### 第 2 步 — $V_{in} \le 0.7$ V：$M_1$ 截止

即使 $V_{out} = 0$，也有 $V_{GS1} = V_{in} \le 0.7$ V，因此 $M_1$ 中没有电流；而 $M_2$ 的沟道是导通的（$V_b > 0.7$ V），只有在 $V_{DS2} = 0$ 时其电流才能为零：

$$V_{out} = 0\qquad (V_{in} \le 0.7\ \mathrm{V}).$$

### 第 3 步 — $M_1$ 导通，$M_2$ 处于线性区（$V_{out} < V_b - 0.7$ V）

$$\frac12\beta_1\left(V_{in} - V_{out} - V_{TH1}\right)^2 = \beta_2\left[(V_b - 0.7)V_{out} - \tfrac12V_{out}^2\right].$$

在 $V_{out} = 0$ 附近，$M_2$ 相当于一个约为 $1/[\beta_2(V_b - 0.7)]$ 的电阻；随着 $V_{out}$ 升高，电流逐渐增大并趋于 $I_2$。

**斜率。** $M_1$ 向输出端注入电流 $g_{m1}(v_{in} - v_{out}) - g_{mb1}v_{out}$，$M_2$ 则是接地的线性区电阻 $R = 1/[\beta_2(V_b - 0.7 - V_{out})]$：

$$
\begin{aligned}
g_{m1}(v_{in} - v_{out}) - g_{mb1}v_{out} &= \frac{v_{out}}{R}\\
g_{m1}v_{in} &= v_{out}\left(\frac1R + g_{m1} + g_{mb1}\right)\\
\frac{dV_{out}}{dV_{in}} &= \frac{g_{m1}R}{1 + (g_{m1} + g_{mb1})R} .
\end{aligned}
$$

导通时 $g_{m1} = 0$，因此斜率从 0 开始；随着 $g_{m1}$ 增大，以及 $R$ 在接近 $M_2$ 的饱和边缘时增大，斜率逐渐上升。

### 第 4 步 — $M_2$ 饱和（$V_{out} \ge V_b - 0.7$ V）：跟随器直线

电流固定为 $I_2$，因此 $M_1$ 的过驱动电压（overdrive voltage）也固定：

$$
\begin{aligned}
\tfrac12\beta_1(V_{in} - V_{out} - V_{TH1})^2 &= I_2\\
V_{in} - V_{out} - V_{TH1} &= \sqrt{2I_2/\beta_1}\\
V_{out} &= V_{in} - V_{TH1}(V_{out}) - \sqrt{\frac{2I_2}{\beta_1}} .
\end{aligned}
$$

$M_2$ 为理想电流源（相当于第 3 步中 $R \to \infty$），因此

$$\frac{dV_{out}}{dV_{in}} = \frac{g_{m1}}{g_{m1} + g_{mb1}} = \frac{1}{1 + \eta_1}, \qquad \eta_1 = \frac{\gamma}{2\sqrt{2|\phi_F| + V_{out}}} .$$

斜率小于 1 完全是由体效应引起的（$V_{TH1}$ 随 $V_{out}$ 升高）。在 $V_{out} = 1$ V 附近，$\eta_1 = 0.45/(2\sqrt{1.9}) = 0.16$，斜率为 $1/1.16 \approx 0.86$；$\eta_1$ 随 $V_{out}$ 升高而缓慢减小，因此这条线略微向上弯曲（“近似直线”）。

### 第 5 步 — 转折点

**导通：** $V_{in} = 0.7$ V。

**$M_2$ 进入饱和区**的位置为 $V_{out} = V_b - 0.7$ V，此时电流已为 $I_2$，因此由第 4 步得：

$$
\begin{aligned}
V_{TH1}(V_b - 0.7) &= 0.7 + 0.45\left(\sqrt{0.9 + V_b - 0.7} - \sqrt{0.9}\right) = 0.7 + 0.45\left(\sqrt{V_b + 0.2} - \sqrt{0.9}\right),\\
\sqrt{\frac{2I_2}{\beta_1}} &= \sqrt{\frac{\beta_2(V_b - 0.7)^2}{\beta_1}} = (V_b - 0.7)\sqrt{\frac{\beta_2}{\beta_1}},\\
V_{in} &= (V_b - 0.7) + 0.7 + 0.45\left(\sqrt{V_b + 0.2} - \sqrt{0.9}\right) + (V_b - 0.7)\sqrt{\frac{\beta_2}{\beta_1}}\\
&= V_b + 0.45\left(\sqrt{V_b + 0.2} - \sqrt{0.9}\right) + (V_b - 0.7)\sqrt{\frac{\beta_2}{\beta_1}} .
\end{aligned}
$$

若该值超过 3 V，$M_2$ 在整个扫描过程中都处于线性区。

**终点：** 在 $V_{in} = 3$ V 时，$V_{out} = 3 - V_{TH1}(V_{out}) - \sqrt{2I_2/\beta_1}$。

### 第 6 步 — 数值示例

为便于说明，取 $V_b = 1.0$ V，$\beta_1 = \beta_2 = 2\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_2 &= \tfrac12(2\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 90\ \mu\mathrm{A},\qquad \sqrt{2I_2/\beta_1} = 0.3\ \mathrm{V},\\
V_{in}\big|_{M_2\ \mathrm{sat}} &= 1.0 + 0.45(\sqrt{1.2} - 0.9487) + 0.3 = 1.0 + 0.066 + 0.3 = 1.366\ \mathrm{V}\quad (V_{out} = 0.3\ \mathrm{V}).
\end{aligned}
$$

**终点：** $V_{out} + V_{TH1}(V_{out}) = 2.7$ V。试取 $V_{out} = 1.70$ V，得 $V_{TH1} = 0.7 + 0.45(\sqrt{2.6} - 0.9487) = 0.999$ V，而 $1.70 + 0.999 = 2.70$ V。✓

| $V_{in}$ (V) | $V_{out}$ (V) | 电流 (μA) | $M_2$ | 斜率 |
|---|---|---|---|---|
| ≤ 0.7 | 0 | 0 | 线性区 | 0 |
| 0.8 | 0.012 | 7 | 线性区 | 0.22 |
| 1.0 | 0.079 | 41 | 线性区 | 0.43 |
| 1.2 | 0.183 | 76 | 线性区 | 0.61 |
| 1.366 | 0.300 | 90 | → 饱和区 | 0.83 |
| 2.0 | 0.834 | 90 | 饱和 | 0.85 |
| 3.0 | 1.701 | 90 | 饱和 | 0.88 |

### 结果

这是一个**源极跟随器**特性，其中 $I_2 = \tfrac12\beta_2(V_b - 0.7)^2$：

- **$V_{in} \le 0.7$ V：** $M_1$ 截止，$V_{out} = 0$（$M_2$ 处于线性区，电流为零）。
- **$M_1$ 导通，$V_{out} < V_b - 0.7$ V：** $M_2$ 处于线性区（在 0 V 附近相当于约 $1/[\beta_2(V_b - 0.7)]$ 的电阻）。$V_{out}$ 以斜率 $g_{m1}R/[1 + (g_{m1} + g_{mb1})R]$ 上升，其中 $R$ 为 $M_2$ 的增量电阻，电流逐渐增大并趋于 $I_2$。
- **$V_{out} \ge V_b - 0.7$ V：** $M_2$ 饱和，电流固定为 $I_2$；$V_{out} = V_{in} - V_{TH1}(V_{out}) - \sqrt{2I_2/\beta_1}$，斜率为 $1/(1 + \eta_1)$，例如在 $V_{out} = 1$ V 附近约为 0.86。
- **$M_1$ 在整个范围内保持饱和**（漏极接 $V_{DD}$，栅极电压至多为 $V_{DD}$）。
- **转折点：** $V_{in} = 0.7$ V；$V_{out} = V_b - 0.7$ V，对应 $V_{in} = V_b + 0.45[\sqrt{V_b + 0.2} - \sqrt{0.9}] + (V_b - 0.7)\sqrt{\beta_2/\beta_1}$（若该值超过 3 V，$M_2$ 在整个扫描过程中都处于线性区）；终点为 $V_{in} = 3$ V 时的 $V_{out} = 3 - V_{TH1}(V_{out}) - \sqrt{2I_2/\beta_1}$。

**常见错误。** 把跟随器直线画成斜率恰好为 1（$V_{out} = V_{in} - V_{TH}$）。由于衬底接地，$V_{TH1}$ 随 $V_{out}$ 升高，因此斜率为 $1/(1 + \eta_1) \approx 0.83$–$0.88$，而且电平移位中还包含过驱动电压 $\sqrt{2I_2/\beta_1}$。

**常见错误。** 从导通时起就把 $M_2$ 当作电流源。在 $V_{out} = 0$ 附近，它处于线性区，相当于一个电阻；只有当 $V_{out}$ 超过 $V_b - 0.7$ V 后，跟随器才达到其完整斜率。

**常见错误。** 声称 $V_{in}$ 较高时 $M_1$ 会进入线性区。它的漏极接 $V_{DD}$，从不低于其栅极，因此始终保持饱和。
