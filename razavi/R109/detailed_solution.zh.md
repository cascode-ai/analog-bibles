# 详细步骤 - R109

**思路。** $M_2$ 是二极管连接的 PMOS（栅极接漏极节点 $X$），$M_1$ 是栅极接 $V_b$ 的 NMOS 电流源（current source）。由节点 $X$ 的基尔霍夫电流定律（KCL）得 $I_X = I_{D1} - |I_{D2}|$。$M_2$ 的电流是 $3 - V_X$ 的平方律（square law）函数，在 $V_X = V_{DD} - |V_{THP}| = 2.2$ V 处降为零；$M_1$ 的电流则遵循其先线性区、后饱和区的输出特性。

### 第 1 步 — 节点 $X$ 的 KCL

$I_X$ 和 $M_2$ 的漏极电流流入 $X$，$M_1$ 的漏极电流流出；两个器件都没有体效应（body effect）：

$$I_X = I_{D1} - |I_{D2}| .$$

### 第 2 步 — 二极管连接的 PMOS $M_2$

$$V_{SG2} = V_{SD2} = 3 - V_X ,$$

因此 **$M_2$ 只要导通就处于饱和区**，而它导通的条件是 $V_{SG2} > 0.8$ V，即 $V_X < 2.2$ V：

$$|I_{D2}| = \frac12\beta_p(3 - V_X - 0.8)^2 = \frac12\beta_p(2.2 - V_X)^2 \quad (V_X < 2.2\ \mathrm{V}), \qquad |I_{D2}| = 0 \quad (V_X \ge 2.2\ \mathrm{V}).$$

该电流在 $V_X = 0$ 时最大，为 $\frac12\beta_p(2.2)^2 = 2.42\,\beta_p$（单位为 V²），并**按二次规律下降，在 $V_X = V_{DD} - |V_{THP}| = 2.2$ V 处降为零**，以零斜率与零值衔接。

### 第 3 步 — 电流源 $M_1$

$V_{GS1} = V_b$（$> 0.7$ V），$V_{DS1} = V_X$：

- **线性区，$V_X < V_b - 0.7$ V：** $I_{D1} = \beta_n\left[(V_b - 0.7)V_X - \tfrac12V_X^2\right]$，从 0 开始上升；
- **饱和区，$V_X \ge V_b - 0.7$ V：** $I_{D1} = I_1 = \frac12\beta_n(V_b - 0.7)^2$。

### 第 4 步 — 合成：$I_X = I_{D1} - |I_{D2}|$

- **起点：** 在 $V_X = 0$ 处，$I_{D1} = 0$，因此
$$I_X(0) = -\tfrac12\beta_p(2.2\ \mathrm{V})^2 = -2.42\,\beta_p\ (\mathrm{V^2}) .$$
- **上升：** 随着 $V_X$ 增大，$I_{D1}$ 增大（或保持不变），$|I_{D2}|$ 减小，斜率为
$$\frac{dI_X}{dV_X} = g_{ds1} + g_{m2}, \qquad g_{ds1} = \beta_n(V_b - 0.7 - V_X)\ \text{(triode only)}, \quad g_{m2} = \beta_p(2.2 - V_X)\ (V_X < 2.2\ \mathrm{V}),$$
其中 $1/g_{m2}$ 是二极管连接的 $M_2$ 的小信号电阻。因此 **$I_X$ 单调增大**。
- **过零点**位于 $I_{D1} = |I_{D2}|$ 处（即去掉电压源后的节点电压）。若此时 $M_1$ 已经饱和，由 $I_1 = \tfrac12\beta_p(2.2 - V_X)^2$ 得
$$V_{X0} = 2.2\ \mathrm{V} - (V_b - 0.7)\sqrt{\frac{\beta_n}{\beta_p}},$$
该式在其结果高于 $V_b - 0.7$ V 时成立；否则过零点落在 $M_1$ 的线性区内，由 $\beta_n[(V_b - 0.7)V_X - V_X^2/2] = \tfrac12\beta_p(2.2 - V_X)^2$ 求得。
- **最终平台：** 当 $V_X$ **同时**高于 $V_b - 0.7$ V 和 2.2 V 时，$M_2$ 截止，$M_1$ 饱和：
$$I_X = I_1 = \tfrac12\beta_n(V_b - 0.7)^2 ,$$
一直平坦到 3 V（若计入沟道长度调制，斜率为 $\lambda I_1$）。

**转折点：** $V_X = V_b - 0.7$ V（$M_1$ 进入饱和，斜率中的 $g_{ds1}$ 项消失）和 $V_X = 2.2$ V（$M_2$ 截止）。二者的先后顺序取决于 $V_b$；当 $V_b$ 低于 2.9 V 时，$M_1$ 先进入饱和。

### 第 5 步 — 数值示例

为便于说明，取 $V_b = 1.0$ V，$\beta_n = 4\ \mathrm{mA/V^2}$，$\beta_p = 1\ \mathrm{mA/V^2}$：

$$I_1 = \tfrac12(4\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 0.18\ \mathrm{mA}\quad(M_1\ \text{saturates at}\ V_X = 0.3\ \mathrm{V}),\qquad I_X(0) = -2.42\ \mathrm{mA}.$$

**过零点**（$M_1$ 饱和）：$0.18 = \frac12(1)(2.2 - V_X)^2$（以 mA 为单位），因此 $2.2 - V_X = 0.6$，$V_X = 1.6$ V。

| $V_X$ (V) | $I_{D1}$ (mA) | $\lvert I_{D2}\rvert$ (mA) | $I_X$ (mA) |
|---|---|---|---|
| 0 | 0 | 2.420 | −2.420 |
| 0.1 | 0.100 | 2.205 | −2.105 |
| 0.3 | 0.180 | 1.805 | −1.625 |
| 1.0 | 0.180 | 0.720 | −0.540 |
| 1.6 | 0.180 | 0.180 | 0 |
| 2.0 | 0.180 | 0.020 | 0.160 |
| 2.2 | 0.180 | 0 | 0.180 |
| 3.0 | 0.180 | 0 | 0.180 |

### 结果

$$I_X = I_{D1} - |I_{D2}|$$

其中 $M_2$ 为二极管连接。$I_X$ 从 $-\tfrac12\beta_p(2.2\ \mathrm{V})^2 = -2.42\beta_p$ 开始上升（两个电流都使它增大），当 $V_X$ 同时高于 $V_b - 0.7$ V 和 2.2 V 时，平坦地保持在 $I_1 = \tfrac12\beta_n(V_b - 0.7)^2$。

- **$M_2$：** $V_{SG} = V_{SD} = 3 - V_X$，导通时处于饱和区：当 $V_X < 2.2$ V 时 $|I_{D2}| = \tfrac12\beta_p(2.2 - V_X)^2$，高于此值时为零。
- **$M_1$：** $V_X < V_b - 0.7$ V 时处于线性区（$\beta_n[(V_b - 0.7)V_X - V_X^2/2]$），高于此值时饱和于 $I_1$。
- $I_X$ 单调增大，在 $I_{D1} = |I_{D2}|$ 处过零，终值为 $I_1$（若计入沟道长度调制，斜率为 $\lambda I_1$）。
- **转折点：** $V_X = V_b - 0.7$ V（$M_1$ 进入饱和），$V_X = 2.2$ V（$M_2$ 截止）。

**常见错误。** 把 $M_2$ 当作栅极电压固定的电流源，从而得到一段平坦的 $-I_2$。它的栅极接 $X$，因此其电流随 $V_X$ 升高按二次规律下降。

**常见错误。** 让 $M_2$ 在 $V_X = 0.8$ V 处截止。其源极接 3 V，因此当栅极电压（这里即 $V_X$）升到 $3 - 0.8 = 2.2$ V 时才截止。

**常见错误。** 把 $I_X$ 画成下降的。提高 $V_X$ 会减小 $M_2$ 注入电压源的电流，并增大（或保持）$M_1$ 吸取的电流，因此 $I_X$ 只能上升。
