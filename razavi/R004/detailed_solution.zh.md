# 详细步骤 - R004

**思路。** $V_{DS}$ 固定时，随着 $V_{GS}$ 升高，晶体管依次经历截止、饱和、线性三个区，因此每条曲线都有两个转折点。写出各区的平方律电流，求出相邻两区的分界点，检验各段是否平滑连接，再比较几个 $V_{DS}$ 值下的曲线。

### 第 1 步 — 三个工作区

源极和衬底都接地，因此没有体效应（body effect），始终有 $V_{TH} = 0.7$ V。记 $\beta = \mu_nC_{ox}W/L$（题中未给出，因此电流以 $\beta$ 为单位给出）：

| 工作区 | 条件 | 漏极电流 |
|---|---|---|
| 截止区 | $V_{GS} < V_{TH}$ | $I_D = 0$ |
| 饱和区 | $V_{GS} > V_{TH}$ 且 $V_{DS} \ge V_{GS} - V_{TH}$ | $I_D = \tfrac12\beta(V_{GS} - V_{TH})^2$ |
| 线性区 | $V_{GS} > V_{TH}$ 且 $V_{DS} < V_{GS} - V_{TH}$ | $I_D = \beta\left[(V_{GS} - V_{TH})V_{DS} - \tfrac12V_{DS}^2\right]$ |

### 第 2 步 — 各工作区的先后顺序与转折点

$V_{DS}$ 固定时，饱和条件可写为

$$V_{DS} \ge V_{GS} - V_{TH} \quad\Longleftrightarrow\quad V_{GS} \le V_{TH} + V_{DS} .$$

因此当 $V_{GS}$ 从 0 开始升高时：$V_{GS} < V_{TH}$ 时器件**截止**；$V_{TH} < V_{GS} < V_{TH} + V_{DS}$ 时器件处于**饱和区**，因为此时过驱动电压（overdrive voltage）较小，达不到固定的漏极电压；$V_{GS} > V_{TH} + V_{DS}$ 时器件进入**线性区**。饱和区在**前**，线性区在**后**，这与熟悉的 $I_D$–$V_{DS}$ 扫描顺序正好相反。每条曲线的**两个转折点**为

$$V_{GS,1} = V_{TH} = 0.7\ \mathrm{V} \quad (\text{turn-on}), \qquad V_{GS,2} = V_{TH} + V_{DS} \quad (\text{saturation} \to \text{triode}).$$

例如：

$$
\begin{aligned}
V_{DS} = 0.2\ \mathrm{V}:&\quad V_{GS,2} = 0.7 + 0.2 = 0.9\ \mathrm{V},\\
V_{DS} = 0.5\ \mathrm{V}:&\quad V_{GS,2} = 0.7 + 0.5 = 1.2\ \mathrm{V},\\
V_{DS} = 1.0\ \mathrm{V}:&\quad V_{GS,2} = 0.7 + 1.0 = 1.7\ \mathrm{V}.
\end{aligned}
$$

### 第 3 步 — 各段曲线的形状

**饱和段。** $I_D = \tfrac12\beta(V_{GS} - V_{TH})^2$ 是一条抛物线，在 $V_{GS} = V_{TH}$ 处从零开始，起始斜率为零。它**与 $V_{DS}$ 无关**，因此在不计沟道长度调制时，曲线族中的每条曲线在这一段都沿着**同一条**抛物线。

**线性段。** 展开得

$$I_D = \beta V_{DS}\,V_{GS} - \beta V_{DS}V_{TH} - \tfrac12\beta V_{DS}^2 ,$$

$V_{DS}$ 固定时，它是**关于 $V_{GS}$ 的直线**，斜率为

$$\frac{\partial I_D}{\partial V_{GS}}\bigg|_{\text{triode}} = \beta V_{DS} ,$$

$V_{DS}$ 越大，直线越陡。

### 第 4 步 — 两段曲线在第二个转折点处平滑连接

**电流连续。** 在 $V_{GS} = V_{TH} + V_{DS}$ 处，过驱动电压 $V_{ov} = V_{DS}$，且

$$
\begin{aligned}
\text{saturation:}\quad I_D &= \tfrac12\beta V_{DS}^2,\\
\text{triode:}\quad I_D &= \beta\left[V_{DS}\cdot V_{DS} - \tfrac12V_{DS}^2\right] = \beta\left[V_{DS}^2 - \tfrac12V_{DS}^2\right] = \tfrac12\beta V_{DS}^2 .
\end{aligned}
$$

**斜率连续。** 抛物线的斜率 $\beta(V_{GS} - V_{TH})$ 在 $V_{GS} = V_{TH} + V_{DS}$ 处等于 $\beta V_{DS}$，恰好就是线性区的斜率。所以**线性区直线与抛物线相切**：所谓“转折”是从曲线变为直线，而不是一个尖角。

**转折点的轨迹。** 每个转折点都位于 $\tfrac12\beta V_{DS}^2 = \tfrac12\beta(V_{GS} - V_{TH})^2$ 处，即**就在饱和抛物线上**，而这条抛物线正是整个曲线族的上包络。

### 第 5 步 — 曲线族的数值

$I_D/\beta$ 的数值，单位为 V²（乘以 $\beta$ 即得以安培为单位的电流）：

| $V_{GS}$ (V) | $V_{DS} = 0.2$ V | $V_{DS} = 0.5$ V | $V_{DS} = 1.0$ V | $V_{DS} \ge 2.3$ V（始终饱和） |
|---|---|---|---|---|
| ≤ 0.7 | 0 | 0 | 0 | 0 |
| 0.8 | 0.005 | 0.005 | 0.005 | 0.005 |
| 0.9 | **0.020**（转折点） | 0.020 | 0.020 | 0.020 |
| 1.0 | 0.040 | 0.045 | 0.045 | 0.045 |
| 1.2 | 0.080 | **0.125**（转折点） | 0.125 | 0.125 |
| 1.5 | 0.140 | 0.275 | 0.320 | 0.320 |
| 1.7 | 0.180 | 0.375 | **0.500**（转折点） | 0.500 |
| 2.0 | 0.240 | 0.525 | 0.800 | 0.845 |
| 2.5 | 0.340 | 0.775 | 1.300 | 1.620 |
| 3.0 | 0.440 | 1.025 | 1.800 | 2.645 |

计算示例：

- 饱和区，$V_{GS} = 1.5$ V，$V_{DS} = 1$ V（因为 $1.5 < 1.7$）：$I_D = \tfrac12\beta(0.8\ \mathrm{V})^2 = 0.32\beta\ \mathrm{V^2}$。
- 线性区，$V_{GS} = 2.0$ V，$V_{DS} = 0.5$ V（因为 $2.0 > 1.2$）：$I_D = \beta[(1.3\ \mathrm{V})(0.5\ \mathrm{V}) - \tfrac12(0.5\ \mathrm{V})^2] = \beta(0.65 - 0.125)\ \mathrm{V^2} = 0.525\beta\ \mathrm{V^2}$。
- 线性区斜率：$\beta V_{DS} = (0.2\ \mathrm{V})\beta$、$(0.5\ \mathrm{V})\beta$ 和 $(1.0\ \mathrm{V})\beta$。例如，在 $V_{DS} = 0.2$ V 一列中，$V_{GS}$ 每增加 0.5 V，$I_D/\beta$ 就增加 $(0.2\ \mathrm{V})(0.5\ \mathrm{V}) = 0.1\ \mathrm{V^2}$（0.14 → 0.24 → 0.34 → 0.44）。

**草图。** 在 0.7 V 之前，所有曲线都贴在横轴上，之后沿同一条抛物线一起上升。每条曲线在各自的 $V_{GS} = 0.7\ \mathrm{V} + V_{DS}$ 处离开抛物线，沿斜率为 $\beta V_{DS}$ 的切线继续上升：$V_{DS}$ 小的曲线较早分离，并保持在较低位置；$V_{DS}$ 大的曲线沿抛物线走得更远，终点更高。因此**在任一 $V_{GS}$ 下，$V_{DS}$ 越大，电流相等或更大**。若 $V_{DS}$ 超过图中的最大过驱动电压（扫描到 3 V 时为 $V_{DS} \ge 2.3$ V），曲线就是完整的抛物线，没有第二个转折点。

### 第 6 步 — 极限情况与沟道长度调制

**$V_{DS}$ 很小（深线性区）。** 当 $V_{DS} \ll V_{GS} - V_{TH}$ 时，$\tfrac12V_{DS}^2$ 项可以忽略：

$$I_D \approx \beta V_{DS}(V_{GS} - V_{TH}),$$

这几乎是一条从 $V_{TH}$ 处开始的直线：器件相当于一个受栅压控制的电阻 $R_{on} = 1/[\beta(V_{GS} - V_{TH})]$。$V_{DS} = 0$ 时，对任何 $V_{GS}$ 电流都为零。

**沟道长度调制。** 在饱和区引入因子 $(1 + \lambda V_{DS})$ 后，每条抛物线段都放大为原来的 $(1 + \lambda V_{DS})$ 倍，因此在第二个转折点之前曲线就已略微散开，$V_{DS}$ 较大的曲线仍在上方。转折点的位置不变。

### 结果

对每个固定的 $V_{DS}$，$I_D(V_{GS})$ 都有**两个转折点**：

- $V_{GS} = V_{TH} = 0.7$ V：导通点。低于该值时 $I_D \approx 0$。
- $V_{GS} = V_{TH} + V_{DS}$：饱和区 → 线性区。
  - 两个转折点之间：饱和区，$I_D = \tfrac12\mu_nC_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$，对所有 $V_{DS}$ 都是同一条抛物线（若计入 CLM，则乘以 $1 + \lambda V_{DS}$ 而略有抬高）。
  - 第二个转折点以上：线性区，$I_D = \mu_nC_{ox}\frac{W}{L}\left[(V_{GS} - V_{TH})V_{DS} - V_{DS}^2/2\right]$，是斜率为 $\mu_nC_{ox}(W/L)V_{DS}$ 的直线，并在转折点处与抛物线相切。

$V_{DS}$ 越大，抛物线段越长，线性区直线越陡、越高；$V_{DS}$ 很小时，曲线几乎是一条从 $V_{TH}$ 出发的直线。$V_{DS} = 0.2$、0.5、1 V 时，第二个转折点分别位于 0.9、1.2 和 1.7 V。

**常见错误。** 照搬 $I_D$–$V_{DS}$ 特性中的顺序，把刚超过 $V_{TH}$ 的区域当作线性区，把 $V_{GS}$ 较大的区域当作饱和区。$V_{DS}$ 固定时，较小的过驱动电压**低于** $V_{DS}$，这正是饱和条件。

**常见错误。** 把第二个转折点放在 $V_{GS} = V_{DS}$ 或 $V_{GS} = V_{DS} - V_{TH}$ 处。饱和区的边界是 $V_{GS} - V_{TH} = V_{DS}$，因此转折点位于 $V_{TH} + V_{DS}$，抛物线在**前**，直线在后。

**常见错误。** 把曲线族的上下顺序弄反。在线性区，电流随 $V_{DS}$ 增大；在饱和区，电流与之无关（计入 CLM 时略有增大）。因此 $V_{DS}$ 越大，曲线绝不会更低。
