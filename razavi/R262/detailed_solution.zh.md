# 详细步骤 - R262

**思路。** 二极管连接（diode-connected）的 $M_2$ 的源极只接 $C_1$，因此全部 $I_{REF}$ 都经 $M_2$ 流入电容：电容电压线性斜坡上升，$V_X$ 始终比它高一个栅源电压（计入体效应）。$M_1$ 的栅极电压就是不断升高的 $V_X$，因此它的电流增大，$V_Y$ 下降，直到 $M_1$ 深入线性区。下面推导每个波形，然后计算一个数值例子。

### 第 1 步 — 电容电压：线性斜坡

$M_1$ 的栅极不取电流，因此全部 $I_{REF}$ 都经 $M_2$ 流入 $C_1$：

$$C_1\frac{dV_{C1}}{dt} = I_{REF} \quad\Longrightarrow\quad V_{C1}(t) = V_{S2}(t) = \frac{I_{REF}}{C_1}\,t .$$

$M_2$ 为二极管连接，因此处于饱和区（saturation region），且流过恒定电流 $I_{REF}$，所以它的过驱动电压（overdrive voltage）恒定：

$$V_{ov} = V_{GS2} - V_{TH2} = \sqrt{\frac{2I_{REF}}{\beta}} .$$

它的衬底接地，因此 $V_{SB2} = V_{C1}$，且

$$V_{TH}(V_{SB}) = 0.7 + 0.45\left(\sqrt{0.9 + V_{SB}} - \sqrt{0.9}\right)\ \mathrm{V}.$$

### 第 2 步 — $V_X(t)$：从 $V_{GS}(I_{REF})$ 开始的斜坡

节点 X 比 $M_2$ 的源极高一个栅源电压：

$$V_X(t) = V_{S2}(t) + V_{TH}\big(V_{S2}(t)\big) + \sqrt{\frac{2I_{REF}}{\beta}} .$$

- **在 $t = 0^+$ 时：** $V_{S2} = 0$，因此 $V_X(0^+) = 0.7 + \sqrt{2I_{REF}/\beta} = V_{GS}(I_{REF})$，即普通二极管连接器件的电压。
- **斜率：** 令 $\eta = dV_{TH}/dV_{SB} = \gamma/(2\sqrt{0.9 + V_{S2}})$，
$$\frac{dV_X}{dt} = (1 + \eta)\frac{dV_{S2}}{dt} = (1 + \eta)\frac{I_{REF}}{C_1}.$$
在 $V_{S2} = 0$ 处，$\eta = 0.45/(2\times0.949) = 0.237$，在 $V_{S2} = 1.5$ V 处降到约 0.15。因此 $V_X$ 几乎线性地斜坡上升，比电容电压本身快约 15–24 %，并且略微向下凹。

### 第 3 步 — $t = 0^+$ 时的 $V_Y$

在 $t = 0^+$ 时，两管的源极都处于地电位，栅极都接 X，因此 $M_1$ 与 $M_2$ 的 $V_{GS}$ 相同，若饱和，就复制其电流：

$$I_{D1}(0^+) = I_{REF} \quad\Longrightarrow\quad V_Y(0^+) = V_{DD} - R_1I_{REF} .$$

这里假设 $M_1$ 饱和，即 $V_{DD} - R_1I_{REF} \ge \sqrt{2I_{REF}/\beta}$，对于合理的 $R_1$ 这是通常的情况。

### 第 4 步 — $V_Y(t)$ 下降，$M_1$ 进入线性区

随着 $V_X$ 升高，$M_1$ 的栅源电压升高，而其源极始终接地，因此它的电流不再是 $I_{REF}$ 的复制，而是按**平方规律**增大。$M_1$ 饱和时：

$$I_{D1}(t) = \frac{\beta}{2}\left(V_X(t) - 0.7\right)^2, \qquad V_Y(t) = V_{DD} - R_1\frac{\beta}{2}\left(V_X(t) - 0.7\right)^2 .$$

由于 $V_X(t) - 0.7 \approx V_{ov} + (1 + \eta)I_{REF}t/C_1$，

$$V_Y(t) \approx V_{DD} - R_1I_{REF}\left(1 + \frac{t}{t_0}\right)^2, \qquad t_0 = \frac{C_1V_{ov}}{(1 + \eta)I_{REF}} :$$

这是一条开口向下的抛物线，从 $V_{DD} - R_1I_{REF}$ 开始，向下弯曲得越来越快。

**进入线性区。** 当 $V_Y = V_X - 0.7$ 时，$M_1$ 退出饱和区。此后它的行为就像一个电阻，其阻值随 $V_X$ 升高而不断减小：

$$R_{on1} = \frac{1}{\beta(V_X - 0.7)}, \qquad V_Y \approx V_{DD}\frac{R_{on1}}{R_1 + R_{on1}} .$$

因此 **$V_Y$ 在一个较低的值上趋于平坦**，并随着 $V_X$ 升高而继续缓慢地趋向零。

### 第 5 步 — 斜坡的终点：理想电流源还是实际电流源

- **理想电流源：** 没有任何因素能使充电停止。$V_{C1}$ 和 $V_X$ 无限地斜坡上升，$V_Y$ 则继续缓慢地趋向零。
- **接到 $V_{DD} = 3$ V 的实际电流源：** 当 $V_X$ 接近 $V_{DD}$ 时，其电流急剧减小，因此 $V_X$ 在 $V_{DD}$ 附近趋于平稳。电容继续（越来越慢地）充电，直到 $M_2$ 截止，即直到 $V_{C1} + V_{TH}(V_{C1}) \approx V_{DD}$，大约为 $V_{DD} - V_{TH2}$，其中阈值电压（threshold voltage）计入体效应。$V_Y$ 稳定在 $V_{DD}R_{on1}/(R_1 + R_{on1})$，其中 $R_{on1}$ 取 $V_{GS1} \approx V_{DD}$ 时的值。

题目没有说明指的是哪一种电流源；两种描述都合理，而且在 $V_X$ 接近 $V_{DD}$ 之前，两者的线性斜坡完全相同。

### 第 6 步 — 数值示例

取 $\beta = 2.68\ \mathrm{mA/V^2}$（$W/L = 10/0.5$，$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$），$I_{REF} = 100\ \mu\mathrm{A}$，$R_1 = 10\ \mathrm{k}\Omega$，$C_1 = 10$ pF。

$$
\begin{aligned}
\frac{I_{REF}}{C_1} &= \frac{100\ \mu\mathrm{A}}{10\ \mathrm{pF}} = 10\ \mathrm{V}/\mu\mathrm{s},\\
V_{ov} &= \sqrt{2(100\ \mu\mathrm{A})/(2.68\ \mathrm{mA/V^2})} = 0.273\ \mathrm{V}, \qquad V_X(0^+) = 0.973\ \mathrm{V},\\
V_Y(0^+) &= 3 - (10\ \mathrm{k}\Omega)(100\ \mu\mathrm{A}) = 2.0\ \mathrm{V} \quad (> V_{ov}, \text{ so } M_1 \text{ is saturated}),\\
t_0 &= \frac{(10\ \mathrm{pF})(0.273\ \mathrm{V})}{1.237\times100\ \mu\mathrm{A}} = 22\ \mathrm{ns}.
\end{aligned}
$$

**线性区边缘。** 令 $u = V_X - 0.7$，条件 $3 - R_1\tfrac{\beta}{2}u^2 = u$ 变为 $13.4u^2 + u - 3 = 0$，因此 $u = 0.437$ V，$V_X = 1.137$ V。当 $V_{C1} = 0.134$ V，即 $t = 13.4$ ns 时达到这一点。

| $t$ | $V_{C1}$ (V) | $V_X$ (V) | $V_Y$ (V) | $M_1$ |
|---|---|---|---|---|
| $0^+$ | 0 | 0.973 | 2.00 | 饱和区 |
| 5 ns | 0.05 | 1.035 | 1.50 | 饱和区 |
| 10 ns | 0.10 | 1.096 | 0.90 | 饱和区 |
| 13.4 ns | 0.134 | 1.137 | 0.44 | 线性区边缘 |
| 20 ns | 0.20 | 1.218 | 0.26 | 线性区 |
| 50 ns | 0.50 | 1.579 | 0.13 | 线性区 |
| 100 ns | 1.00 | 2.167 | 0.076 | 线性区 |
| 150 ns | 1.50 | 2.743 | 0.055 | 线性区 |

$V_X$ 在约 172 ns 时达到 $V_{DD} = 3$ V（$V_{C1} = 1.72$ V）。对于实际电流源，斜坡在此停止，电容电压缓慢升至约 1.97 V（此时 $V_{TH2} \approx 1.03$ V），$V_Y$ 稳定在 $3\times162\ \Omega/(10\ \mathrm{k}\Omega + 162\ \Omega) \approx 0.05$ V 附近。

### 结果

- **$V_{C1}$** 以 $I_{REF}/C_1$ 的斜率线性上升：$I_{REF}$ 除了经 $M_2$ 流入 $C_1$ 之外没有其他通路。
- **$V_X$** 从 $V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$ 开始，以斜率 $(1 + \eta)I_{REF}/C_1$ 几乎线性地上升；该斜率略大于 $I_{REF}/C_1$，因为源极电压升高时体效应使 $V_{TH2}$ 增大。对于理想电流源，斜坡无限持续。实际电流源在 $V_X$ 接近 $V_{DD}$ 时失去电压余度，因此斜坡在那里停止，$C_1$ 最终充到约 $V_{DD} - V_{TH2}$（计入体效应）。
- **$V_Y$** 从 $V_{DD} - R_1I_{REF}$ 开始（此时 $M_1$ 复制 $I_{REF}$），沿开口向下的抛物线下降，因为 $I_{D1} = \tfrac{\beta}{2}(V_X - 0.7)^2$ 按平方规律增大。随后 $M_1$ 进入线性区，$V_Y$ 在一个较低的值 $\approx V_{DD}R_{on1}/(R_1 + R_{on1})$ 上趋于平坦，其中 $R_{on1}$ 是 $V_{GS1} \approx V_X$ 时的导通电阻。

**常见错误。** 把该电路当作普通电流镜（current mirror），认为 $V_X$ 恒等于 $V_{GS}(I_{REF})$，$V_Y = V_{DD} - R_1I_{REF}$ 也保持不变。$M_2$ 的源极接在对 $I_{REF}$ 进行积分的 $C_1$ 上，因此参考支路中的每个电压都在斜坡上升。

**常见错误。** 把 $V_X$ 画成指数型（RC）的建立过程。$C_1$ 由恒定电流 $I_{REF}$ 充电，得到的是线性斜坡；$R_1$ 位于另一条支路，对 $C_1$ 没有影响。

**常见错误。** 把 $V_Y$ 画成向 $V_{DD}$ 上升。$M_1$ 的源极接地而栅极电压升高，因此它导通得**更强**，把 $V_Y$ **拉低**。
