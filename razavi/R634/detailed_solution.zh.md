# 详细步骤 - R634

**思路。** 漏极电流来自差分对，它是一个强非线性的**限幅**元件：摆幅很大时，它把全部尾电流从一侧切换到另一侧，因此电流接近方波。漏极电压是这些电流流过 LC 谐振回路后的结果，谐振回路只在谐振频率附近呈现大阻抗，在各次谐波处阻抗则很小。用傅里叶级数和谐振回路阻抗对这两种效应进行定量分析。

### 第 1 步 — 电流为何失真：差分对的限幅作用

由于 $I_{D1} + I_{D2} = I_{SS}$，每个电流都被限制在 $0 \le I_D \le I_{SS}$ 范围内，差分对只对小输入近似呈线性响应。按平方律（square law），一旦 $|V_X - V_Y|$ 超过 $\sqrt2\,(V_{GS} - V_{TH})_{eq}$，一个晶体管就会截止，另一个则流过全部 $I_{SS}$；这里 $(V_{GS} - V_{TH})_{eq}$ 是平衡时的过驱动电压（overdrive voltage）。

- **在振荡建立的初期**，摆幅很小，差分对是线性的，两个电流都是围绕 $I_{SS}/2$ 的正弦波（电压也是如此）。
- **随着幅度增大**，在每个周期的大部分时间里 $V_X - V_Y$ 都超过这一切换电压，因此每半个周期全部 $I_{SS}$ 都被导向一侧。电流在 0 和 $I_{SS}$ 处饱和，只在很短的时间内处于过渡状态，趋近于**方波**。

占空比为 50 %、在 0 与 $I_{SS}$ 之间变化的方波，其傅里叶级数为

$$I_{D1}(t) = \frac{I_{SS}}{2} + \frac{2I_{SS}}{\pi}\left[\cos\omega_0t - \frac13\cos3\omega_0t + \frac15\cos5\omega_0t - \frac17\cos7\omega_0t + \dots\right].$$

它只含奇次谐波（半波对称），各次谐波的幅度为基波的 $1/n$：3 次谐波为 33 %，5 次谐波为 20 %，依此类推，总谐波失真（total harmonic distortion）为 $\sqrt{\pi^2/8 - 1} \approx 48\%$。$I_{D2}$ 是同一波形平移半个周期。

### 第 2 步 — 漏极电压是如何形成的

$V_X$ 等于 $V_{DD}$ 减去谐振回路上的压降，每个电流分量产生的电压等于该分量乘以谐振回路在其频率处的阻抗：

- **直流分量**（$I_{SS}/2$）：它流过电感，（理想情况下）没有压降，因此 $V_X$ 和 $V_Y$ 以 $V_{DD}$ 为中心；
- **$n\omega_0$ 处的分量**，幅度为 $I_n$：它产生幅度为 $I_n\,|Z(jn\omega_0)|$ 的电压。

电压频谱就是用 $|Z(j\omega)|$ 加权后的电流频谱。

### 第 3 步 — 谐振回路在各次谐波处的阻抗

取 $\omega_0 = 1/\sqrt{L_PC_P}$，$Q = R_P\,\omega_0C_P = R_P/(\omega_0L_P)$，并联谐振回路的阻抗为

$$Z(j\omega) = \frac{R_P}{1 + jQ\left(\dfrac{\omega}{\omega_0} - \dfrac{\omega_0}{\omega}\right)},$$

它在谐振时达到最大值 $R_P$。在第 $n$ 次谐波处，$\omega/\omega_0 - \omega_0/\omega = n - 1/n = (n^2 - 1)/n$，因此

$$|Z(jn\omega_0)| = \frac{R_P}{\sqrt{1 + Q^2\left(\dfrac{n^2 - 1}{n}\right)^2}} \approx \frac{n}{Q\,(n^2 - 1)}\,R_P .$$

对于 $n = 3$：$|Z(3\omega_0)| \approx 3R_P/(8Q)$。在 $3\omega_0$ 处，电容的导纳是谐振时的三倍，电感的导纳则是谐振时的三分之一；二者不再抵消，$C_P$ 在谐波电流产生电压之前就把它们旁路到 $V_{DD}$（交流地）。

### 第 4 步 — 漏极电压的谐波含量

相对于基波，3 次谐波电压为

$$\frac{V_3}{V_1} = \frac{I_3}{I_1}\cdot\frac{|Z(3\omega_0)|}{R_P} \approx \frac13\cdot\frac{3}{8Q} = \frac{1}{8Q}.$$

对于 $Q = 5$ 的谐振回路：

| 谐波次数 $n$ | 电流，$I_n/I_1 = 1/n$ | 谐振回路，$\lvert Z(jn\omega_0)\rvert/R_P$ | 电压，$V_n/V_1$ |
|---|---|---|---|
| 1 | 1 | 1 | 1 |
| 3 | 0.333 | 0.075 | 0.025 |
| 5 | 0.200 | 0.042 | 0.0083 |
| 7 | 0.143 | 0.029 | 0.0042 |
| THD | ≈ 48 % | | ≈ 2.7 % |

三次谐波从电流中的 33 % 降到电压中的 2.5 %，更高次的谐波被抑制得更多；$Q = 10$ 时，电压的 THD 降到约 1.3 %。因此，尽管产生漏极电压的电流接近方波，漏极电压本身却非常接近正弦波，其幅度约为 $(2/\pi)I_{SS}R_P$。相比之下，电流没有经过任何滤波，所以其谐波依然存在。

### 结果

漏极电流由差分对产生，而差分对具有限幅作用：幅度很大时，$V_X - V_Y$ 每半个周期都把全部尾电流导向一个晶体管，因此 $I_{D1}$ 和 $I_{D2}$ 被削波限制在 0 与 $I_{SS}$ 之间，趋近于方波，含有很大的奇次谐波（3 次谐波 ≈ 基波的 1/3，5 次谐波 ≈ 基波的 1/5）。漏极电压等于这些电流乘以谐振回路阻抗 $Z = R_P/[1 + jQ(\omega/\omega_0 - \omega_0/\omega)]$；该阻抗只在谐振频率附近等于 $R_P$，在各次谐波处则由于 $C_P$ 的旁路作用而小得多（$|Z(3\omega_0)| \approx 3R_P/(8Q)$）。3 次谐波电压只有基波的约 $1/(8Q)$（$Q = 5$ 时 ≈ 2.5 %，而电流中为 33 %）。因此，$V_X$ 和 $V_Y$ 在 $V_{DD}$ 附近保持近似正弦，而 $I_{D1}$ 和 $I_{D2}$ 则接近矩形波；在振荡建立的初期，差分对仍是线性的，二者都是正弦波。

**常见错误。** 认为电压呈正弦是“因为晶体管保持线性”。若晶体管是线性的，电流也会是正弦的，但图 2 显示电流被削波；干净的电压波形来自谐振回路的滤波作用。

**常见错误。** 只给出一半的解释：“谐振回路滤除了谐波”，却不说明电流为何失真，也不说明谐振回路为何会衰减谐波。差分对的限幅作用和谐振器的频率选择性二者缺一不可。

**常见错误。** 把平滑作用归因于电感单独起积分器的作用。单独一个电感在谐波处的阻抗**更高**；正是它与 $C_P$ 的并联谐振，才使阻抗在 $\omega_0$ 处出现峰值，而在 $3\omega_0$、$5\omega_0$……处下降。
