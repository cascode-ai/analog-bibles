# 详细步骤 - R430

**思路。** 节点 X 驱动 PMOS 电流源（current source）$M_7$ 和 $M_8$ 的栅极。$M_7$ 的电流已知，等于尾电流（tail current）的一半，因此由平方律（square law）可以确定其源栅电压；其源极接 $V_{DD}$，于是其栅极电压、也就是 X 的电压就确定了。

### 第 1 步 — $M_7$ 的电流与源栅电压

这是一个低电压共源共栅电流镜（low-voltage cascode mirror）：$M_7$ 的栅极取自其共源共栅管 $M_5$ 的漏极（节点 X），而不是取自它自己的漏极，因此环路 $M_7 \to M_5 \to$ X $\to$ $M_7$ 的栅极迫使 $M_7$ 恰好传导下方支路所要求的电流。左侧支路 $M_7$–$M_5$–$M_3$–$M_1$ 是一条串联通路，因此在平衡时

$$|I_{D7}| = I_{D1} = \frac{I_{SS}}{2} = 0.5\ \mathrm{mA}.$$

$M_7$ 饱和，且 $W/L = 100/0.5 = 200$：

$$
\begin{aligned}
|V_{OD7}| &= \sqrt{\frac{2|I_{D7}|}{\mu_pC_{ox}(W/L)}} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{(38.4\ \mu\mathrm{A/V^2})(200)}} = \sqrt{\frac{1\times10^{-3}}{7.68\times10^{-3}}}\ \mathrm{V} = \sqrt{0.1302}\ \mathrm{V} = 0.361\ \mathrm{V},\\
|V_{GS7}| &= |V_{THP}| + |V_{OD7}| = 0.8 + 0.361 = 1.161\ \mathrm{V}.
\end{aligned}
$$

### 第 2 步 — X 点的电压

$M_7$ 的源极接 $V_{DD}$，栅极接 X：

$$V_X = V_{DD} - |V_{GS7}| = 3 - 1.161 = 1.84\ \mathrm{V}.$$

这一电压与 $V_{b1}$、$V_{b2}$ 无关：若 X 更高，$M_7$ 提供的电流就会少于下方要求的 0.5 mA，X 将被拉低，直到它恰好提供 0.5 mA。$V_{b2}$ 只需使 $M_5$ 和 $M_7$ 保持饱和（大约在 1.04 V 与 1.48 V 之间）。

### 第 3 步 — 自洽性检查

- **$M_3$：** 其漏极（X，1.84 V）必须不低于 $V_{b1} - V_{TH} = 1.7 - 0.7 = 1.0$ V。✓
- **$M_8$：** 其栅极也接 X，因此 $|V_{GS}| = 1.161$ V 相同，若处于饱和，也传导同样的 0.5 mA，这正是电流镜（current mirror）应有的行为。

### 结果

$$V_X = V_{DD} - |V_{GS7}| = 3 - (0.8 + 0.361) \approx 1.84\ \mathrm{V},$$

它由栅极接 X、传导 $I_{SS}/2 = 0.5$ mA 的 $M_7$ 决定；只要所有晶体管都处于饱和，它就与 $V_{b1}$ 和 $V_{b2}$ 无关。

**常见错误。** 把负载当作标准的双二极管共源共栅电流镜，得到 $V_X = V_{DD} - |V_{GS5}| - |V_{GS7}| \approx 0.68$ V。X 与 $V_{DD}$ 之间只隔一个栅源电压；$M_5$ 由 $V_{b2}$ 偏置，而不是二极管连接（diode-connected）的。

**常见错误。** 认为 $V_X$ 由 $V_{b1}$ 决定。$V_{b1}$ 确定的是 $M_3$/$M_4$ 的**源极**；它们的漏极 X 由 PMOS 一侧决定。

**常见错误。** 用 $W/L = 100$ 代替 $100\ \mu\mathrm{m}/0.5\ \mu\mathrm{m} = 200$，这会把过驱动电压（overdrive voltage）高估为 0.51 V，并得到 $V_X \approx 1.69$ V。
