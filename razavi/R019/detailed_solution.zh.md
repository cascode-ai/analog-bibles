# 详细步骤 - R019

**思路。** $V_{in}$ 节点是 PMOS 管 $M_1$ 的源极，其栅极固定在 1 V。计入体效应计算 $|V_{TH}|$：n 阱（n-well）接 3 V，高于源极。然后求出导通点，再分析饱和区和线性区。

### 第 1 步 — 端电压与体效应

$R_1$ 中的电流只能来自 $V_{in}$ 并经过 $M_1$，因此 $0 \le V_{out} \le V_{in}$：电位较高的 $V_{in}$ 端是 PMOS 的源极，$V_{out}$ 节点是漏极。用正的量表示，

$$
\begin{aligned}
V_{SG} &= V_{in} - 1,\\
V_{SD} &= V_{in} - V_{out},\\
V_{BS} &= 3 - V_{in} \ \ (\ge 0, \text{ reverse bias of the source–well junction}).
\end{aligned}
$$

计入体效应（$\sqrt{0.8} = 0.8944$）：

$$|V_{TH}| = 0.8 + 0.4\left(\sqrt{0.8 + 3 - V_{in}} - 0.8944\right) = 0.8 + 0.4\left(\sqrt{3.8 - V_{in}} - 0.8944\right)\ \mathrm{V}.$$

随着 $V_{in}$ 向 3 V 升高，源极电位接近 n 阱电位，$|V_{TH}|$ 向 0.8 V **下降**；$V_{in}$ 较低时它较大（例如 $V_{in} = 2$ V 时为 0.98 V）。

### 第 2 步 — 导通点

当 $V_{SG} > |V_{TH}|$ 时 $M_1$ 导通；在边界处

$$V_{in} - 1 = 0.8 + 0.4\sqrt{3.8 - V_{in}} - 0.4\times0.8944 .$$

代入 $w = \sqrt{3.8 - V_{in}}$，则 $V_{in} = 3.8 - w^2$：

$$
\begin{aligned}
3.8 - w^2 - 1 &= 0.8 + 0.4w - 0.3578\\
2.8 - w^2 &= 0.4422 + 0.4w\\
w^2 + 0.4w - 2.3578 &= 0\\
w &= \frac{-0.4 + \sqrt{0.16 + 9.4311}}{2} = \frac{-0.4 + 3.0969}{2} = 1.3485\\
V_{in} &= 3.8 - 1.3485^2 = 3.8 - 1.8184 = 1.98\ \mathrm{V}.
\end{aligned}
$$

验算：$|V_{TH}| = 0.8 + 0.4(1.3485 - 0.8944) = 0.98$ V，$V_{SG} = 1.98 - 1 = 0.98$ V。✓

所以 **当 $0 \le V_{in} \le 1.98$ V 时 $V_{out} = 0$**。若没有体效应，器件将在 $1 + 0.8 = 1.8$ V 处导通；n 阱电位高于源极，使 $|V_{TH}|$ 增大，从而使导通推迟约 0.18 V。

### 第 3 步 — 饱和区

饱和要求 $V_{SD} \ge V_{SG} - |V_{TH}|$：

$$
\begin{aligned}
V_{in} - V_{out} &\ge V_{in} - 1 - |V_{TH}|\\
V_{out} &\le 1 + |V_{TH}| ,
\end{aligned}
$$

因此漏极电位至多只能比栅极高 $|V_{TH}|$，即约 1.8–1.98 V。刚导通时 $V_{out}$ 很小，$M_1$ 处于饱和区。在输出节点列基尔霍夫电流定律（KCL）方程：

$$\frac{V_{out}}{R_1} = \tfrac12\beta_p\,(V_{SG} - |V_{TH}|)^2 \quad\Longrightarrow\quad V_{out} = \tfrac12\beta_pR_1\,(V_{in} - 1 - |V_{TH}|)^2 .$$

右边只依赖于 $V_{in}$（源极接输入，栅极固定）：这是**共栅**（common-gate）组态，而不是跟随器。$V_{out}$ 从零开始**按二次函数规律**上升，并且比纯抛物线略快，因为随着 $|V_{TH}|$ 下降，过驱动电压的增长速率为 $1 + \gamma/(2\sqrt{3.8 - V_{in}}) \approx 1.15$–$1.22$/V。

**在范围的顶端**（$V_{in} = 3$ V）：$V_{BS} = 0$，因此 $|V_{TH}| = 0.8$ V，且

$$V_{ov} = 3 - 1 - 0.8 = 1.2\ \mathrm{V}, \qquad V_{out} = \tfrac12\beta_pR_1(1.2\ \mathrm{V})^2 = 0.72\,\beta_pR_1\ \mathrm{V^2},$$

其中 $\beta_p$ 以 A/V² 为单位，$R_1$ 以 Ω 为单位。这只在 $0.72\,\beta_pR_1 \le 1 + 0.8 = 1.8$ V，即 $\beta_pR_1 \le 2.5\ \mathrm{V^{-1}}$ 时成立。

### 第 4 步 — 线性区（$\beta_pR_1$ 较大）

若 $V_{out}$ 在 $V_{in} = 3$ V 之前就达到 $1 + |V_{TH}|$，$M_1$ 进入线性区：

$$\frac{V_{out}}{R_1} = \beta_p\left[(V_{in} - 1 - |V_{TH}|)(V_{in} - V_{out}) - \tfrac12(V_{in} - V_{out})^2\right].$$

此时 $M_1$ 相当于接在 $V_{in}$ 与输出之间的电阻 $R_{on} \approx 1/[\beta_p(V_{in} - 1 - |V_{TH}|)]$，$V_{out} \approx V_{in}R_1/(R_1 + R_{on})$ 从下方**趋近 $V_{in}$**，$\beta_pR_1$ 越大越接近；它永远不会超过 $V_{in}$。

### 第 5 步 — 数值曲线

三个点处的阈值电压（threshold voltage）和过驱动电压：

$$
\begin{aligned}
V_{in} = 2.2\ \mathrm{V}:&\quad |V_{TH}| = 0.8 + 0.4(\sqrt{1.6} - 0.8944) = 0.8 + 0.4\times0.3705 = 0.948\ \mathrm{V},\ V_{ov} = 1.2 - 0.948 = 0.252\ \mathrm{V},\\
V_{in} = 2.5\ \mathrm{V}:&\quad |V_{TH}| = 0.8 + 0.4(\sqrt{1.3} - 0.8944) = 0.8 + 0.4\times0.2458 = 0.898\ \mathrm{V},\ V_{ov} = 1.5 - 0.898 = 0.602\ \mathrm{V},\\
V_{in} = 3.0\ \mathrm{V}:&\quad |V_{TH}| = 0.800\ \mathrm{V},\ V_{ov} = 1.200\ \mathrm{V}.
\end{aligned}
$$

对 $\beta_pR_1 = 1\ \mathrm{V^{-1}}$，$V_{out} = \tfrac12V_{ov}^2$：在这三点分别为 0.032 V、0.181 V 和 0.72 V，始终处于饱和区。

对 $\beta_pR_1 = 10\ \mathrm{V^{-1}}$，饱和区公式给出 $V_{out} = 5V_{ov}^2$：2.2 V 时为 0.317 V，2.5 V 时为 1.81 V，刚好低于 $1 + |V_{TH}| = 1.90$ V。线性区边界（$5V_{ov}^2 = 1 + |V_{TH}|$）位于 $V_{in} \approx 2.51$ V；高于该点后，线性区方程给出 2.6 V 时为 2.17 V，3 V 时为 2.74 V。

| $V_{in}$ (V) | $V_{out}$，$\beta_pR_1 = 1\ \mathrm{V^{-1}}$ | $V_{out}$，$\beta_pR_1 = 10\ \mathrm{V^{-1}}$ |
|---|---|---|
| 0 – 1.98 | 0 | 0 |
| 2.1 | 0.009 | 0.093 |
| 2.2 | 0.032 | 0.317 |
| 2.3 | 0.068 | 0.677 |
| 2.4 | 0.117 | 1.17 |
| 2.5 | 0.181 | 1.81（线性区边缘） |
| 2.6 | 0.259 | 2.17（线性区） |
| 2.8 | 0.459 | 2.49（线性区） |
| 3.0 | 0.720 | 2.74（线性区） |

**形状。** 1.98 V 以前恒为零，随后是类似抛物线的上升（饱和区）。$\beta_pR_1$ 较小时，3 V 处只达到 $0.72\beta_pR_1$ V；$\beta_pR_1$ 较大时，一旦 $V_{out}$ 超过约 $1 + |V_{TH}| \approx 1.9$ V，曲线就开始弯曲，随后紧贴在直线 $V_{out} = V_{in}$ 下方延伸。

### 结果

- PMOS 的源极是 $V_{in}$ 节点（电位较高）：$V_{SG} = V_{in} - 1$，$V_{BS} = 3 - V_{in}$，$|V_{TH}| = 0.8 + 0.4(\sqrt{3.8 - V_{in}} - \sqrt{0.8})$。
- **导通点**满足 $V_{in} - 1 = |V_{TH}|$：**$V_{in} \approx 1.98$ V**（此时 $|V_{TH}| \approx 0.98$ V；若没有体效应则为 1.8 V）。低于该值时 $V_{out} = 0$。
- 当 $V_{out} < 1 + |V_{TH}|$ 时（漏极至多比栅极高 $|V_{TH}|$）处于**饱和区**：$V_{out} = \tfrac12\beta_pR_1(V_{in} - 1 - |V_{TH}|)^2$，按二次函数规律上升。在 $V_{in} = 3$ V 时，过驱动电压为 1.2 V（$|V_{TH}| = 0.8$ V），因此 $V_{out} = 0.72\,\beta_pR_1$（V），除非受到线性区的限制。
- 若 $\beta_pR_1$ 大到使 $V_{out}$ 将超过 $1 + |V_{TH}| \approx 1.8$–$1.9$ V，则器件进入**线性区**：此时 $V_{out}$ 趋近 $V_{in}$。始终有 $V_{out} \le V_{in}$。

**常见错误。** 把 $M_1$ 当作 NMOS，或者把 $V_{out}$ 节点当作源极。PMOS 的源极是电位较高的端子，这里是输入节点，因此 $V_{SG} = V_{in} - 1$。

**常见错误。** 预测 $V_{in}$ 较小时输出不为零。栅极为 1 V，源极必须升到 $1 + |V_{TH}|$ 以上才能形成沟道，即 $V_{in} \approx 1.98$ V。

**常见错误。** 忽略体效应，把导通点定在 1.8 V。n 阱接 3 V，而源极接近 2 V，因此导通时 $|V_{TH}|$ 升高到约 0.98 V。
