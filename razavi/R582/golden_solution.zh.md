经过许多个时钟周期后（稳态），$\overline{v_{n,out}^2} = kT/C$，对应的均方根（rms）值为 $\sqrt{kT/C}$。对于第一次转移（$C_2$ 初始时无噪声）：$3kT/(4C)$。

- $M_1$ 关断时，$C_1$ 上保持一个方差为 kT/C 的采样噪声。
- $M_2$ 导通期间，它的热噪声只会在 $C_1$ 与 $C_2$ 之间搬移电荷。电荷之和（即平均值 $(V_1 + V_2)/2$）保持不变，但差值 $V_1 - V_2$ 被重新随机化。$M_2$ 断开时，$V_1 - V_2$ 的方差为 $kT/(C_1 \text{ in series with } C_2) = 2kT/C$，与之前的值无关。
- $V_{out} = (V_1 + V_{2,old})/2 - (V_1 - V_2)_{noise}/2$，因此 $\sigma_{out}^2 = (kT/C)/4 + \sigma_{old}^2/4 + (2kT/C)/4 = \sigma_{old}^2/4 + 3kT/(4C)$。
- 第一次转移（$\sigma_{old}$ = 0）：$3kT/(4C)$。稳态：$\sigma^2 = \sigma^2/4 + 3kT/(4C)$，因此 $\sigma^2 = kT/C$。
