$C$ = 31.5 aF/μm²，$C_P$ = 9.0 aF/μm²，$C_P/C$ ≈ 0.29。

- 每层对衬底的电容为 $\epsilon/h$，因此其高度为 $h = \epsilon/C_{sub}$。两层之间的电容为 $\epsilon/(h_i - h_j) = 1/(1/C_{sub,i} - 1/C_{sub,j})$（由串联关系反推：$1/C_{sub,4} = 1/C_{43} + 1/C_{sub,3}$）。
- $C = 1/(1/7 - 1/9) = 31.5$ aF/μm²。
- 底极板（金属 3）直接面对衬底：$C_P = 9.0$ aF/μm²。上极板被金属 3 完全屏蔽，因此它对衬底没有电容。
- $C_P/C = 9/31.5 = 0.286$。
