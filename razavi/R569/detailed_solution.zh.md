# 详细步骤 - R569

**思路。** 把运放建模为 $G_m$ 和 $R_{out}$，推导从 $V_{in}$ 到 X 的传递函数，计算它在 100 MHz 处的幅值和相位，并据此写出并画出 $V_X(t)$。再用阻抗分压（$C_1$ 与运放闭环输出电阻之间的分压）验证这些数值。

### 第 1 步 — 从 $V_{in}$ 到 X 的传递函数

X 与 $V_{out}$ 是同一个节点：$C_1$ 向它注入 $C_1s(V_{in} - V_X)$，运放注入 $G_m(0 - V_X) = -G_mV_X$，$R_{out}$ 从它抽走 $V_X/R_{out}$：

$$C_1s(V_{in} - V_X) - G_mV_X - \frac{V_X}{R_{out}} = 0 ,$$

$$
\begin{aligned}
C_1sV_{in} &= V_X\left(C_1s + G_m + \frac{1}{R_{out}}\right)\\
H(s) = \frac{V_X}{V_{in}} &= \frac{R_{out}C_1s}{1 + G_mR_{out} + R_{out}C_1s},
\end{aligned}
$$

这是一个高通响应，极点位于 $\omega_p = (1 + G_mR_{out})/(R_{out}C_1)$。

### 第 2 步 — 数值

$$
\begin{aligned}
\omega &= 2\pi\times100\ \mathrm{MHz} = 6.283\times10^{8}\ \mathrm{rad/s},\\
G_mR_{out} &= \frac{20\ \mathrm{k}\Omega}{100\ \Omega} = 200, \qquad 1 + G_mR_{out} = 201,\\
\omega R_{out}C_1 &= (6.283\times10^{8})(20\times10^{3})(1\times10^{-12}) = 12.57,\\
\omega_p &= \frac{201}{(20\ \mathrm{k}\Omega)(1\ \mathrm{pF})} = 1.005\times10^{10}\ \mathrm{rad/s}\quad(f_p = 1.6\ \mathrm{GHz}).
\end{aligned}
$$

100 MHz 比极点**低** 16 倍，因此电路工作在其高通响应的上升段，即起微分作用的区域。

### 第 3 步 — 100 MHz 处的幅值与相位

$$H(j\omega) = \frac{j\,12.57}{201 + j\,12.57},$$

$$|H| = \frac{12.57}{\sqrt{201^2 + 12.57^2}} = \frac{12.57}{\sqrt{40401 + 158}} = \frac{12.57}{201.4} = 0.0624 ,$$

$$\angle H = 90^\circ - \arctan\frac{12.57}{201} = 90^\circ - 3.58^\circ = 86.4^\circ ,$$

因此 $V_X$ **超前**于 $V_{in}$。

**阻抗验证。** 在单位增益反馈下，X 处看到的是闭环输出电阻 $1/(G_m + 1/R_{out}) = 1/(0.01 + 0.00005)\ \mathrm{S} = 99.5\ \Omega$，而 $C_1$ 的容抗为 $1/(\omega C_1) = 1/(6.283\times10^{-4}\ \mathrm{S}) = 1592\ \Omega$，因此

$$|H| = \frac{99.5}{\sqrt{99.5^2 + 1592^2}} = \frac{99.5}{1595} = 0.0624 .$$

### 第 4 步 — X 处的波形

对于 $V_{in}(t) = (1\ \mathrm{V})\sin\omega t$，稳态为

$$V_X(t) = (62.4\ \mathrm{mV})\,\sin(\omega t + 86.4^\circ),$$

以 0 V 为中心（这是 X 的直流电平，因为同相输入端接地，且 $C_1$ 中没有直流电流）。86.4° 的超前量相当于 10 ns 周期的 $86.4/360$，即 **2.4 ns**：

| $t$ (ns) | $V_{in}$ (V) | $V_X$ (mV) |
|---|---|---|
| 0 | 0 | +62.3 |
| 1.25 | +0.707 | +46.8 |
| 2.5 | +1.000 | +3.9 |
| 3.75 | +0.707 | −41.3 |
| 5 | 0 | −62.3 |
| 6.25 | −0.707 | −46.8 |
| 7.5 | −1.000 | −3.9 |
| 8.75 | −0.707 | +41.3 |
| 10 | 0 | +62.3 |

**草图。** 把 $V_{in}$ 画成峰值为 1 V、周期为 10 ns 的正弦波，并在同一坐标轴上把 $V_X$ 画成一个小得多的正弦波（±62 mV），向左平移接近四分之一周期。它的峰值（位于 $t \approx 0.1$ ns、10.1 ns、……）几乎与 $V_{in}$ 的上升过零点重合，而它的过零点几乎与 $V_{in}$ 的峰值重合。

远低于极点时，$H(s) \approx R_{out}C_1s/(G_mR_{out}) = C_1s/G_m$，因此

$$V_X(t) \approx \frac{C_1}{G_m}\,\frac{dV_{in}}{dt}:$$

运放只有在产生（电流）/$G_m$ 大小的输入误差时，才能吸收电容电流 $C_1\,dV_{in}/dt$。这一近似给出 $\omega C_1/G_m = (6.283\times10^{8})(1\ \mathrm{pF})(100\ \Omega) = 62.8$ mV 和 90° 的超前，与精确值 62.4 mV 和 86.4° 很接近。

### 第 5 步 — 对采样的影响

$C_1$ 两端的电压为 $V_{in} - V_X = (1 - H)V_{in}$，其中

$$1 - H = \frac{201}{201 + j\,12.57}, \qquad |1 - H| = \frac{201}{201.4} = 0.998, \qquad \angle(1 - H) = -3.6^\circ .$$

因此 $C_1$ 上是一个幅度为 0.998 V、滞后 $V_{in}$ 3.6° 的正弦电压，而“虚地”上带有 100 MHz、62 mV 的纹波，约为输入的 6 %。

### 结果

$V_X$ 是 100 MHz 的正弦波，峰值幅度约为 **62 mV**（0.0624 V），**超前 $V_{in}$ 约 86°**（接近 90°，即 2.4 ns）：

$$V_X(t) = 62.4\ \mathrm{mV}\cdot\sin(\omega t + 86.4^\circ),$$

以运放的直流电平（0 V）为中心。它由 $H(j\omega) = j\omega R_{out}C_1/(1 + G_mR_{out} + j\omega R_{out}C_1)$ 得到，其中 $\omega R_{out}C_1 = 12.57$，$1 + G_mR_{out} = 201$：$|H| = 12.57/\sqrt{201^2 + 12.57^2} = 0.0624$，$\angle H = 90^\circ - \arctan(12.57/201) = 86.4^\circ$。节点 X 的行为就像微分器的输出，$V_X \approx (C_1/G_m)\,dV_{in}/dt$，因为 100 MHz 远低于约 1.6 GHz 处的极点。$C_1$ 两端电压的幅度为 0.998 V，滞后 $V_{in}$ 约 3.6°。

**常见错误。** 把 X 当作理想虚地，画成 0 V 处的一条水平线。运放只有产生（电容电流）/$G_m$ 大小的误差，才能把 X 保持在地电位附近；在 100 MHz 时这一误差的峰值约为 62 mV。

**常见错误。** 把 $V_X$ 画成与 $V_{in}$ 同相、滞后或反相。在极点以下，$C_1$–$1/G_m$ 高通电路起微分作用，因此其输出超前接近 90°，在 $V_{in}$ 上升最快时达到峰值。

**常见错误。** 得到接近 1 V 的幅度，例如把极点放在 100 MHz 以下，或者只用 $R_{out}$（20 kΩ，远大于 $1/(\omega C_1)$）作为 X 处的阻抗。有反馈时该阻抗为 $1/(G_m + 1/R_{out}) \approx 100\ \Omega$，远小于 $C_1$ 的 1.6 kΩ 容抗。
