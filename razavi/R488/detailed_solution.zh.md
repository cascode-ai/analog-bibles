# 详细步骤 - R488

**思路。** X 和 Y 是第二级 PMOS 器件 $M_5$ 和 $M_6$ 的栅极，这两个器件的源极接 $V_{DD}$，并且必须流过由其 NMOS 电流源负载（$M_7$、$M_8$）强制的 1 mA 电流。在饱和区，平方律（square law）就确定了 $|V_{GS5}|$，X 和 Y 的共模（CM）电平为 $V_{DD} - |V_{GS5}|$。

### 第 1 步 — 什么决定了 X 和 Y 的电平

X 是位于两个电流源之间的高阻节点（$M_3$ 推入、$M_1$ 拉出 $I_{SS}/2 = 0.125$ mA），因此第一级本身并不能确定它的直流电压。但 X 同时也是 $M_5$ 的栅极，而该管与 $M_7$ 串联，因而在饱和区流过 1 mA：这只允许唯一的栅源电压，从而确定了 $V_X$。Y 和 $M_6$ 的情况相同。

$M_5$ 的源极和衬底都接 $V_{DD}$，因此没有体效应：

$$|V_{TH5}| = |V_{TH0}| = 0.8\ \mathrm{V}.$$

### 第 2 步 — 流过 1 mA 所需的过驱动电压（overdrive voltage）

计算偏置时忽略沟道长度调制（channel-length modulation），因为题目未给出 $\lambda$；由 $I_D = \frac12\mu_pC_{ox}(W/L)(|V_{GS}| - |V_{TH}|)^2$ 得

$$|V_{ov5}| = \sqrt{\frac{2I_{D5}}{\mu_pC_{ox}(W/L)_5}} .$$

取 $(W/L)_5 = 60/0.5 = 120$：

$$
\begin{aligned}
\mu_pC_{ox}\left(\frac WL\right)_5 &= (38.4\ \mu\mathrm{A/V^2})(120) = 4.608\ \mathrm{mA/V^2},\\
\frac{2I_{D5}}{\mu_pC_{ox}(W/L)_5} &= \frac{2\times1\ \mathrm{mA}}{4.608\ \mathrm{mA/V^2}} = 0.434\ \mathrm{V^2},\\
|V_{ov5}| &= \sqrt{0.434\ \mathrm{V^2}} = 0.659\ \mathrm{V}.
\end{aligned}
$$

### 第 3 步 — 栅源电压与共模电平

$$|V_{GS5}| = |V_{TH5}| + |V_{ov5}| = 0.8\ \mathrm{V} + 0.659\ \mathrm{V} = 1.459\ \mathrm{V}.$$

节点 X 比 $M_5$ 的源极低 $|V_{GS5}|$：

$$V_X = V_{DD} - |V_{GS5}| = 3\ \mathrm{V} - 1.459\ \mathrm{V} = 1.541\ \mathrm{V}.$$

$M_6$ 与之完全相同，也流过 1 mA，因此 $V_Y = V_X$：X 和 Y 的共模电平约为 **1.54 V**。

### 第 4 步 — 自洽性检查

- **$M_3$、$M_4$ 处于饱和区。** $M_3$ 流过 0.125 mA，$W/L = 100$，因此其过驱动电压为 $\sqrt{2(0.125\ \mathrm{mA})/(38.4\ \mu\mathrm{A/V^2}\times100)} = \sqrt{0.0651}\ \mathrm{V} = 0.255$ V，远低于其源漏电压 $V_{DD} - V_X = 3 - 1.541 = 1.46$ V。
- **输入对。** 只要 X 和 Y（1.54 V）不低于 $V_{in,CM} - V_{TH,n}$，$M_1$ 和 $M_2$ 就保持饱和；这限制了输入共模电平，但不改变 $V_X$。
- **$\lambda$ 的影响。** 沟道长度调制只会使 $|V_{GS5}|$ 变化过驱动电压的百分之几，因此 1.54 V 就是预期的估计值。

### 结果

$$V_X = V_Y = V_{DD} - \left(|V_{TH}| + \sqrt{\frac{2I_{D5}}{\mu_pC_{ox}(W/L)_5}}\right) = 3 - (0.8 + 0.659) \approx 1.54\ \mathrm{V}.$$

**常见错误。** 对 $M_5$ 使用 $W/L = 50/0.5$，而 $M_{5,6}$ 实际为 $60/0.5$。若用 50/0.5，过驱动电压将为 0.722 V，$V_X \approx 1.48$ V。

**常见错误。** 写成 $V_X = V_{DD} - |V_{TH}| = 2.2$ V，即忘记了过驱动电压。这是 $M_5$ 刚好截止时的栅极电压，而不是它流过 1 mA 时的栅极电压。

**常见错误。** 试图由第一级的 NMOS 器件（或用 NMOS 参数）求 $V_X$。X 由两个电流源驱动，因此其电平由它所驱动的、流过第二级偏置电流的 PMOS 器件 $M_5$ 决定。
