# 详细步骤 - R211

**思路。** 寄生电阻 $R_P$ 连接节点 A（$M_1$ 的漏极，即共源共栅管 $M_3$ 的源极）和右输出端 Y（$M_4$ 的漏极）。电路不再对称，因此要写出整个电路的小信号方程。由于尾电流源是理想的、差分对是匹配的，且 $R_P$ 位于差分对**之上**，共模输入不会改变任何电流；差分情形则由内部节点的 KCL 得到。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 的漏极（$M_3$ 的源极）记为 A，$M_2$ 的漏极（$M_4$ 的源极）记为 B，左输出端（$M_3$ 的漏极）记为 X，右输出端（$M_4$ 的漏极）记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P；$V_{out} = V_X - V_Y$。取 $V_{DD}$ 和 $V_{b1}$ 为交流地：

- $M_1$：$i_1 = g_m(v_{in1} - v_P)$，从 A 流向 P；$M_2$：$i_2 = g_m(v_{in2} - v_P)$，从 B 流向 P。
- $M_3$（栅极接交流地）：$i_3 = g_{m3}(0 - v_A) = -g_{m3}v_A$，从 X 向下流到 A；$M_4$：$i_4 = -g_{m4}v_B$，从 Y 向下流到 B。
- $R_P$：$(v_Y - v_A)/R_P$，从 Y 流向 A。
- 尾电流管 $M_5$（$\lambda = 0$）：没有信号电流。

（在直流下，$R_P$ 中有一些从 Y 流向 A 的电流，因此 $M_3$ 的偏置电流略小于 $M_4$，$g_{m3} \ne g_{m4}$；结果只取决于 $g_{m3}$。）

### 第 2 步 — 共模输入：电流都不变

由于尾电流源是理想的，P 点的 KCL 给出 $i_1 + i_2 = 0$。对于 $v_{in1} = v_{in2} = v_c$，匹配的器件给出 $i_1 = g_m(v_c - v_P) = i_2$，因此

$$i_1 = i_2 = 0, \qquad v_P = v_c .$$

在 $\lambda = 0$ 时，$M_1$、$M_2$ 的漏极电压不影响其电流，而其余元件都只通过这些电流被驱动（共源共栅管的栅极接固定偏置）。因此 A、B、X、Y 的节点方程都是齐次的，其唯一解为 $v_A = v_B = v_X = v_Y = 0$：

$$A_{CM} = 0, \qquad \mathrm{CMRR} = \infty\quad(\text{within this model}).$$

该缺陷位于输入对管**之上**，而共模信号电流根本到达不了那里，因此它无法把共模转换为差模。

### 第 3 步 — 差分输入：输入对管的电流

对于 $v_{in1} = +v_d/2$、$v_{in2} = -v_d/2$：$i_1 + i_2 = g_m(0 - 2v_P) = 0$，因此 $v_P = 0$，且

$$i_1 = g_m\frac{v_d}{2}, \qquad i_2 = -g_m\frac{v_d}{2} = -i_1 .$$

### 第 4 步 — 内部节点的 KCL

**节点 B：** 这里只连接 $M_4$ 和 $M_2$，因此 $i_4 = i_2$；这确定了 $v_B = -i_2/g_{m4}$，而它不影响其他任何量。

**节点 A**（$i_3$ 和 $R_P$ 中的电流流入，$i_1$ 流出）：

$$-g_{m3}v_A + \frac{v_Y - v_A}{R_P} = i_1 . \tag{1}$$

**输出端 X**（向下流过左边 $R_D$ 的电流就是 $M_3$ 的电流）：

$$-\frac{v_X}{R_D} = i_3 = -g_{m3}v_A\quad\Longrightarrow\quad v_X = g_{m3}R_Dv_A . \tag{2}$$

**输出端 Y**（向下流过右边 $R_D$ 的电流供给 $M_4$ 和 $R_P$）：

$$-\frac{v_Y}{R_D} = i_4 + \frac{v_Y - v_A}{R_P} = i_2 + \frac{v_Y - v_A}{R_P}. \tag{3}$$

### 第 5 步 — 求解

由 (1)，$(v_Y - v_A)/R_P = i_1 + g_{m3}v_A$；代入 (3) 并利用 $i_1 + i_2 = 0$：

$$-\frac{v_Y}{R_D} = i_2 + i_1 + g_{m3}v_A = g_{m3}v_A\quad\Longrightarrow\quad v_Y = -g_{m3}R_Dv_A , \tag{4}$$

因此由 (2) 得 $v_X = -v_Y$：输出是纯差分的。把 (4) 代回 (1)：

$$
\begin{aligned}
-g_{m3}v_A + \frac{-g_{m3}R_Dv_A - v_A}{R_P} &= i_1\\
-v_A\left[g_{m3}R_P + g_{m3}R_D + 1\right] &= R_Pi_1\\
v_A &= -\frac{R_Pi_1}{1 + g_{m3}(R_D + R_P)} .
\end{aligned}
$$

再由 (2) 得：

$$v_X = g_{m3}R_Dv_A = -\frac{g_{m3}R_DR_P}{1 + g_{m3}(R_D + R_P)}\,i_1 = -\frac12g_mR_D\,\frac{g_{m3}R_P}{1 + g_{m3}(R_D + R_P)}\,v_d .$$

由 $v_{out} = v_X - v_Y = 2v_X$ 得：

$$A_{DM} = \frac{v_{out}}{v_d} = -g_mR_D\,\frac{g_{m3}R_P}{1 + g_{m3}(R_D + R_P)} = -g_mR_D\,\frac{R_P}{R_P + R_D + 1/g_{m3}} .$$

当 $R_P \to \infty$ 时，$A_{DM} \to -g_mR_D$，即 $\lambda = 0$ 时普通共源共栅差分对的增益；很大但有限的 $R_P$ 只使增益乘以因子 $R_P/(R_P + R_D + 1/g_{m3}) \approx 1$。

**数值感受：** $g_m = 1$ mS，$g_{m3} = 1$ mS，$R_D = 5\ \mathrm{k}\Omega$，$R_P = 500\ \mathrm{k}\Omega$：

$$A_{DM} = -5\times\frac{500}{500 + 5 + 1} = -4.94 .$$

### 结果

$$A_{DM} = -g_mR_D\,\frac{g_{m3}R_P}{1 + g_{m3}(R_D + R_P)} = -g_mR_D\,\frac{R_P}{R_P + R_D + 1/g_{m3}} \approx -g_mR_D,$$

$$A_{CM} = 0, \qquad \mathrm{CMRR} = \infty\ (\text{within this model}).$$

在 $\lambda = 0$ 时，尾电流管 $M_5$ 是理想的，且 $M_1$、$M_2$ 匹配，因此共模输入不会改变任何一个漏极电流（$i_1 = i_2$ 且 $i_1 + i_2 = 0$）。由于共源共栅管的栅极接固定偏置，电路中没有其他元件被驱动，因此不会出现输出：寄生电阻位于输入对管之上，无法把共模转换为差模。

**常见错误。** 类比于接到尾节点（随 $V_{in,CM}$ 变化）的电阻，得出非零的共模增益，例如 $R_D/R_P$。这里 $R_P$ 连接的是输入对管之上的两个节点，共模电流根本到达不了那里。

**常见错误。** 把 $A_{DM}$ 算成一半或两倍。两个输出都在变化（$v_X = -v_Y$），因此 $v_{out} = 2v_X$，而 $v_d = 2v_{in}$，所以 $|A_{DM}| \approx g_mR_D$。

**常见错误。** 搞错 $R_P$ 接在哪个节点上。分别对 A、B、X、Y 列 KCL，并明确 $R_P$ 接在 A 与 Y 之间，就可以避免这类错误。
