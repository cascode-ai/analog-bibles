$A_{DM} = -g_mR_D\,\dfrac{g_{m3}R_P}{1 + g_{m3}(R_D + R_P)} = -g_mR_D\,\dfrac{R_P}{R_P + R_D + 1/g_{m3}} \approx -g_mR_D$；$A_{CM} = 0$；CMRR = ∞（在此模型范围内）。
- 当 λ = 0 时，尾电流管 $M_5$ 是理想的，且 $M_1$、$M_2$ 匹配，因此共模输入不会改变任何一个漏极电流（$i_1 = i_2$ 且 $i_1 + i_2 = 0$）。电路中没有其他元件被驱动（共源共栅管的栅极接固定偏置），因此不会出现输出：寄生电阻位于输入对管之上，无法把共模转换为差模（differential-mode）。
- 差分输入（$i_1 = g_mv_d/2 = -i_2$）：记 A 为 $M_1$ 的漏极（$M_3$ 的源极），B 为 $M_2$ 的漏极，$i_3 = -g_{m3}v_A$，$i_4 = -g_{m4}v_B = i_2$；A 点的基尔霍夫电流定律（KCL）：$i_3 + (v_Y - v_A)/R_P = i_1$；右输出端：$-v_Y/R_D = i_2 + (v_Y - v_A)/R_P$；$v_X = -R_Di_3$。求解得 $v_X = -v_Y = -\tfrac12 g_mR_D\,\dfrac{g_{m3}R_P}{1 + g_{m3}(R_D + R_P)}v_d$。
- （$R_P$ 中有直流电流，因此 $M_3$ 的电流略小于 $M_4$，$g_{m3} \ne g_{m4}$；结果只取决于 $g_{m3}$。）
