# Golden Solution - R247

## Reference answer

$V_X = V_Y = V_{DD}$ up to 0.7 V. Above that, $V_X$ follows the simple diode curve $V_X = 0.7 + [\sqrt{1+2\beta R_1(V_{DD}-0.7)}-1]/(\beta R_1)$ (slow, sub-linear rise), while $V_Y$ stays above $V_X$ and keeps rising almost linearly with $V_{DD}$ (slope below 1).

- $M_1$ is degenerated by $R_2$ and suffers body effect ($V_{SB1} = R_2I_{D1}$), so with the same gate voltage it carries less current than $M_2$: $I_{D1} < I_{D2}$, hence $V_Y = V_{DD} - R_1I_{D1} > V_{DD} - R_1I_{D2} = V_X$.
- $I_{D1}$ grows only about as $(V_X - V_{GS1})/R_2$ with the slowly rising $V_X$, so $R_1I_{D1}$ increases slowly and $V_Y$ climbs with a slope somewhat below 1.
- $M_1$ stays saturated throughout ($V_{DS1} > V_{GS1} - V_{TH}$ because $V_Y > V_X$).
- Example (W/L = 10/0.5, $R_1$ = 5 kΩ, $R_2$ = 1 kΩ): at $V_{DD}$ = 1, 2, 3 V, $V_X$ ≈ 0.85, 1.07, 1.22 V and $V_Y$ ≈ 0.90, 1.55, 2.26 V.
