频率：$\omega_{osc}^2 = \dfrac{g_mL_1 + R_P(C_1+C_2)}{R_PL_1C_1C_2} \approx \dfrac{1}{L_1\,C_1C_2/(C_1+C_2)}$。条件（高 Q 近似）：$g_mR_P \ge \dfrac{(C_1+C_2)^2}{C_1C_2}$（≥ 4，在 $C_1 = C_2$ 时取最小值）——与考毕兹振荡器完全相同。精确结果（实部与虚部联立求解）：$g_m \ge \dfrac{R_P(C_1+C_2)^2}{R_P^2C_1C_2 - L_1(C_1+C_2)}$，即 $g_mR_P \ge \dfrac{(C_1+C_2)^2}{C_1C_2}\cdot\dfrac{Q^2}{Q^2-1}$，其中 $Q = R_P/(\omega_0L_1)$，$\omega_0^2 = (C_1+C_2)/(L_1C_1C_2)$；在这一临界值处 $\omega_{osc} = \omega_0Q/\sqrt{Q^2-1}$。

推导：
- 向漏极节点 D 注入 $I_{in}$（节点为 G 和 D；源极接地）。令 $Y = 1/(L_1s) + 1/R_P$。G 点的 KCL：$Y(V_G - V_D) + C_1sV_G = 0$。D 点：$Y(V_D - V_G) + C_2sV_D + g_mV_G = I_{in}$。
- 解得：$\dfrac{V_D}{I_{in}} = \dfrac{R_PL_1C_1s^2 + L_1s + R_P}{R_PC_1C_2L_1s^3 + (C_1+C_2)L_1s^2 + [g_mL_1 + R_P(C_1+C_2)]s + g_mR_P}$。
- 在 $s = j\omega$ 处：由虚部 → $\omega^2 = [g_mL_1 + R_P(C_1+C_2)]/(R_PL_1C_1C_2) \approx (C_1+C_2)/(L_1C_1C_2)$（当 $g_mL_1 \ll R_P(C_1+C_2)$ 时）；由实部 → $(C_1+C_2)L_1\omega^2 = g_mR_P$，即采用近似的 ω 时，临界条件为 $g_mR_P = (C_1+C_2)^2/(C_1C_2)$（采用精确的 ω 时还要乘以上面的因子 $Q^2/(Q^2-1)$），要使振荡增长则需更大。
- 结果完全相同的原因：该电路与考毕兹振荡器是同一个三节点网络（电感接在栅极与漏极之间，$C_1$ 接在栅源之间，$C_2$ 接在漏源之间）；只是交流地节点不同，而这并不改变自然频率。等价地说，$M_1$ 与 $C_1$、$C_2$ 一起向电感呈现 $-g_m/(C_1C_2\omega^2)$ 与 $C_1C_2/(C_1+C_2)$ 的串联。
