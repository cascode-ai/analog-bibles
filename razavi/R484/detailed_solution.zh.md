# 详细步骤 - R484

**思路。** 在零点 $s_z$ 处，虽然输入不为零，输出却为零，因此负载（$R_L$、$C_L$）中没有电流，输出端的 KCL 只涉及两个电流：晶体管的电流和补偿支路的电流。令二者相互抵消即得 $s_z$；完整的传递函数可以验证这一结果。

### 第 1 步 — 小信号模型

把 $M_9$ 的栅极记为节点 E（电压为 $V_E$）；$C_E$ 接在 E 与 $V_{DD}$（交流地）之间。补偿支路和负载的导纳分别为

$$Y_c(s) = \frac{1}{R_z + \dfrac{1}{sC_C}} = \frac{sC_C}{1 + sR_zC_C}, \qquad G_L(s) = \frac{1}{R_L} + sC_L$$

（$M_9$ 的输出电阻都可以并入 $R_L$）。$M_9$ 是源极接交流地的 PMOS 管，因此它**流入**输出端的小信号电流为 $g_{m9}V_{SG} = -g_{m9}V_E$：抬高其栅极电压会减小它推入输出端的电流。$M_9$ 的其他所有电容均忽略不计。

### 第 2 步 — 零点频率处输出端的 KCL

在 $s = s_z$ 处，$V_{out} = 0$，而 $V_{in} \ne 0$。此时也有 $V_E \ne 0$：若二者都为零，$C_E$ 和补偿支路中就没有电流，$R_S$ 中也就没有电流，这将迫使 $V_{in} = 0$。由于 $V_{out} = 0$，$R_L$ 和 $C_L$ 中的电流为零（如提示所述，输出端相当于一条不流过电流的短路线），因此输出节点上只剩下两个电流。来自补偿支路的电流（E 点电压为 $V_E$，输出为 0 V）为

$$I_c = \frac{V_E - 0}{R_z + 1/(sC_C)} = \frac{V_E}{R_z + 1/(sC_C)} ,$$

以及来自 $M_9$ 的 $-g_{m9}V_E$。KCL：

$$\frac{V_E}{R_z + 1/(sC_C)} - g_{m9}V_E = 0 .$$

### 第 3 步 — 求解 $s_z$

两边除以 $V_E \ne 0$：

$$
\begin{aligned}
\frac{1}{R_z + \dfrac{1}{s_zC_C}} &= g_{m9}\\
R_z + \frac{1}{s_zC_C} &= \frac{1}{g_{m9}}\\
\frac{1}{s_zC_C} &= \frac{1}{g_{m9}} - R_z\\
s_z &= \frac{1}{C_C\left(g_{m9}^{-1} - R_z\right)} .
\end{aligned}
$$

这就是要证明的结果，$\omega_z = 1/[C_C(g_{m9}^{-1} - R_z)]$。按照题目的约定（分子 $\propto 1 - s/\omega_z$），$s_z = +\omega_z$，因此正的 $\omega_z$ 是位于右半平面（RHP）的零点。

$R_S$、$C_E$、$R_L$ 和 $C_L$ 都没有出现：它们要么只决定 $V_E$ 与 $V_{in}$ 之间的关系（一个会被约去的非零因子），要么在零点处不流过电流。

### 第 4 步 — 用完整传递函数验证

**节点 E 的 KCL**（经 $R_S$ 流入的电流从 $C_E$ 和补偿支路流出），其中 $G_S = 1/R_S$：

$$G_S(V_{in} - V_E) = sC_EV_E + Y_c(V_E - V_{out}). \tag{1}$$

**输出端的 KCL**（从支路流入的电流 = $M_9$ 抽走的电流 + 流入负载的电流）：

$$Y_c(V_E - V_{out}) = g_{m9}V_E + G_LV_{out}. \tag{2}$$

由式 (2)：

$$V_E\,(Y_c - g_{m9}) = V_{out}\,(Y_c + G_L) \quad\Longrightarrow\quad V_E = V_{out}\,\frac{Y_c + G_L}{Y_c - g_{m9}} .$$

将式 (1) 改写为 $G_SV_{in} = V_E(G_S + sC_E + Y_c) - Y_cV_{out}$，并代入 $V_E$：

$$
\begin{aligned}
G_SV_{in} &= V_{out}\left[\frac{(Y_c + G_L)(G_S + sC_E + Y_c)}{Y_c - g_{m9}} - Y_c\right]\\
\frac{V_{out}}{V_{in}} &= \frac{G_S\,(Y_c - g_{m9})}{(Y_c + G_L)(G_S + sC_E + Y_c) - Y_c(Y_c - g_{m9})} .
\end{aligned}
$$

分母中的 $Y_c^2$ 项相互抵消：

$$\frac{V_{out}}{V_{in}} = \frac{G_S\,(Y_c - g_{m9})}{G_L(G_S + sC_E) + Y_c\,(G_S + sC_E + G_L + g_{m9})} .$$

分子和分母同乘以 $(1 + sR_zC_C)$，并利用 $Y_c(1 + sR_zC_C) = sC_C$。分子变为

$$
\begin{aligned}
G_S\left[sC_C - g_{m9}(1 + sR_zC_C)\right] &= G_S\left[-g_{m9} + sC_C(1 - g_{m9}R_z)\right]\\
&= -G_Sg_{m9}\left[1 - sC_C\left(\frac{1}{g_{m9}} - R_z\right)\right],
\end{aligned}
$$

分母变为 $G_L(G_S + sC_E)(1 + sR_zC_C) + sC_C(G_S + sC_E + G_L + g_{m9})$。两者同除以 $G_SG_L$（$= 1/R_SR_L$，即 $s = 0$ 时的分母）：

$$\frac{V_{out}}{V_{in}} = -g_{m9}R_L\,\frac{1 - s/\omega_z}{D(s)}, \qquad \omega_z = \frac{1}{C_C\left(g_{m9}^{-1} - R_z\right)}, \qquad D(0) = 1 .$$

直流增益为 $-g_{m9}R_L$，而 $R_S$、$C_E$、$R_L$、$C_L$ 只出现在 $D(s)$ 中：它们决定（三个）极点，而从不影响零点。在该模型内结果是精确的；“≈”考虑的是被忽略的 $M_9$ 的电容（例如，$C_{GD9}$ 会使前馈导纳 $Y_c$ 增加 $sC_{GD9}$）。

### 第 5 步 — 解释：用 $R_z$ 移动零点

信号经两条路径到达输出端：经过 $M_9$ 的**反相**路径（电流 $-g_{m9}V_E$）和经过补偿支路的**同相前馈**路径（电流 $Y_cV_E$）；零点就是二者恰好抵消之处。

- **$R_z = 0$：** $\omega_z = g_{m9}/C_C$，是一个 RHP 零点，位于 $sC_C$ 等于 $g_{m9}$ 之处。它像极点一样带来相位**滞后**，同时却使幅值上升，这会损害相位裕度（phase margin）。
- **$0 < R_z < 1/g_{m9}$：** RHP 零点移向更高的频率。
- **$R_z = 1/g_{m9}$：** $g_{m9}^{-1} - R_z = 0$，零点移到无穷远处；支路导纳永远不会超过 $1/R_z = g_{m9}$，因此前馈电流永远不能完全抵消晶体管电流。
- **$R_z > 1/g_{m9}$：** $\omega_z < 0$，即位于 $s = -1/[C_C(R_z - g_{m9}^{-1})]$ 处的**左半平面**零点。它带来相位**超前**，并可以放在输出极点之上将其抵消。

### 结果

在零点处 $V_{out} = 0$，因此负载中没有电流，由输出端的 KCL 得 $Y_c(s_z) = g_{m9}$，即 $R_z + 1/(s_zC_C) = 1/g_{m9}$：

$$\omega_z = \frac{1}{C_C\left(g_{m9}^{-1} - R_z\right)},$$

且 $V_{out}/V_{in} = -g_{m9}R_L(1 - s/\omega_z)/D(s)$。当 $R_z < 1/g_{m9}$ 时零点位于 RHP（$R_z = 0$ 时简化为 $g_{m9}/C_C$），当 $R_z = 1/g_{m9}$ 时位于无穷远处，当 $R_z > 1/g_{m9}$ 时位于 LHP。它与 $R_S$、$C_E$、$R_L$ 和 $C_L$ 无关。

**常见错误。** 弄错 PMOS 电流的符号，写成 $V_E/(R_z + 1/sC_C) + g_{m9}V_E = 0$，从而得到 $1/[C_C(R_z + g_{m9}^{-1})]$。前馈电流与晶体管电流符号相反，这正是它们能够相互抵消的原因。

**常见错误。** 把 $R_L$、$C_L$、$R_S$ 或 $C_E$ 计入零点。在零点处负载中没有电流，而 $R_S$、$C_E$ 只对 $V_E$ 起比例缩放作用，因此这四个元件都只影响极点。

**常见错误。** 认为 $R_z$ 只是移动极点。它的主要作用是移动零点：它减小了支路的前馈导纳，把 RHP 零点推到无穷远处（$R_z = 1/g_{m9}$）或推入 LHP（$R_z > 1/g_{m9}$）。
