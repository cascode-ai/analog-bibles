零点位于 $s_z = \dfrac{1}{C_C(1/g_{m9} - R_z)}$：当 $R_z < 1/g_{m9}$ 时位于右半平面（$R_z = 0$ 时简化为 $g_{m9}/C_C$），当 $R_z = 1/g_{m9}$ 时位于无穷远处，当 $R_z > 1/g_{m9}$ 时位于左半平面。

推导（零输出法）：
- 在 $s = s_z$ 处，$V_{out} = 0$，而栅极电压 $V_1 \ne 0$。此时 $R_L$ 和 $C_L$ 中没有电流，因此输出端的基尔霍夫电流定律（KCL）方程只涉及 $M_9$ 和 $R_z$–$C_C$ 支路。
- $M_9$ 流入输出端的小信号（small-signal）电流为 $-g_{m9}V_1$（PMOS 管，源极接交流地）。从栅极节点经该支路流入输出端的电流为 $V_1/(R_z + 1/sC_C)$。
- KCL：$-g_{m9}V_1 + \dfrac{V_1}{R_z + 1/(sC_C)} = 0$，因此 $R_z + \dfrac{1}{sC_C} = \dfrac{1}{g_{m9}}$，$s_z = \dfrac{1}{C_C(g_{m9}^{-1} - R_z)}$。
- 等价地，完整传递函数的分子正比于 $g_{m9} - Y_c$，其中 $Y_c = sC_C/(1 + sR_zC_C)$，即正比于 $g_{m9} - sC_C(1 - g_{m9}R_z)$。$R_S$、$C_E$、$R_L$ 和 $C_L$ 只影响极点。
- 在该模型中结果是精确的。“≈”是考虑到被忽略的 $C_{GD9}$：它会使前馈（feedforward）导纳增加 $sC_{GD9}$。
