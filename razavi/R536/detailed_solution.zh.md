# 详细步骤 - R536

**思路。** 偏置核心有一个稳定的零电流状态。跟踪 $V_{DD}$ 上升过程中启动网络的行为：$M_6$、$R_a$ 和 $R_b$ 决定 $V_X$，而 $M_5$ 只在 $V_X > V_{TH}$ 时导通。然后写出电源达到终值时启动支路的方程，并要求 $V_X < V_{TH}$，使 $M_5$ 在正常工作时关断。

### 第 1 步 — 简并态与启动电路的连接

偏置核心的环路方程在零电流时同样成立：所有器件都截止时，$M_4$ 不向二极管连接（diode-connected）的 $M_1$ 提供电流，因此 $M_1$/$M_2$ 的栅极处于 0 V；于是 $M_2$ 不从 $M_3$ 抽取电流，$M_3$/$M_4$ 的栅极浮动上升到接近 $V_{DD}$，使它们保持截止。启动电路必须把偏置核心推出这一状态，然后自身退出工作。

把 $R_a$ 与 $R_b$ 的连接点记为 N，它也是 $M_6$ 的栅极。$M_6$ 的漏极接 X，源极接地；$M_5$ 的栅极接 X，漏极接 $M_3$ 的栅极/漏极节点（即 $M_2$ 的漏极）。

### 第 2 步 — 上电过程中启动电路如何工作

**(a) $V_{DD} < V_{TH}$。** $M_6$ 截止，而且 $M_5$、$M_6$ 的栅极不吸取电流，因此 $R_a$、$R_b$ 中没有电流：

$$V_X = V_N = V_{DD}.$$

**(b) $V_{DD}$ 刚刚高于 $V_{TH}$。** $V_X > V_{TH}$，于是 $M_5$ 导通，把 $M_3$/$M_4$ 的栅极拉低：$M_3$ 和 $M_4$ 导通，$M_4$ 向 $M_1$ 注入电流，$M_1$/$M_2$ 导通，$M_2$ 从 $M_3$ 抽取电流，使这一过程进一步加强。偏置核心的正反馈环路再生，到达正常工作点；启动电路只是“推它一把”。

**(c) 电源更高时。** $M_6$ 导通更强，其电流 $I_{D6}$ 从 $V_{DD}$ 经 $R_a$ 和 $R_b$ 流入其漏极，因此 $R_b$ 上的压降把 X 拉到 N 之下：

$$V_X = V_N - I_{D6}R_b = V_{GS6} - I_{D6}R_b .$$

一旦它降到 $V_{TH}$ 以下，$M_5$ 就关断。而且它必须关断：$M_5$ 中的任何电流都会叠加到 $M_3$ 中的 $I_{D2}$ 上，$M_4$ 再把它镜像到 $M_1$ 中，于是两条支路电流不再相等，偏置也会通过 $V_X$ 依赖于 $V_{DD}$。

### 第 3 步 — 电源达到终值时启动支路的方程

由于 $V_N = V_{GS6}$（$M_6$ 的栅极，源极接地）：

$$I_{D6} = I_{R_a} = \frac{V_{DD} - V_{GS6}}{R_a},$$

同样的电流流过 $R_b$（$M_5$ 的栅极不吸取电流）：

$$V_X = V_{GS6} - I_{D6}R_b = V_{GS6} - \frac{R_b}{R_a}\,(V_{DD} - V_{GS6}).$$

### 第 4 步 — 条件 $V_X < V_{TH}$

$$V_{GS6} - \frac{R_b}{R_a}(V_{DD} - V_{GS6}) < V_{TH}$$

代入 $V_{DD} = 3$ V 和 $V_{TH} = 0.7$ V，得

$$\boxed{\frac{R_b}{R_a}\,(3\ \mathrm{V} - V_{GS6}) > V_{GS6} - 0.7\ \mathrm{V}}$$

**等价形式。**
- $I_{D6}R_b > V_{GS6} - V_{TH}$：$R_b$ 上的压降必须超过 $M_6$ 的过驱动电压（overdrive voltage）。
- 若 $M_6$ 处于饱和（$V_{GS6} - V_{TH} = \sqrt{2I_{D6}/\beta_6}$），对 $I_{D6}R_b > \sqrt{2I_{D6}/\beta_6}$ 两边平方：
$$I_{D6}^2R_b^2 > \frac{2I_{D6}}{\beta_6} \quad\Longrightarrow\quad I_{D6} > \frac{2}{\beta_6R_b^2}.$$
- 由于 $g_{m6} = \sqrt{2\beta_6I_{D6}}$，这就是 $g_{m6}R_b > 2$。

若 $V_{GD6} = I_{D6}R_b < V_{TH}$，则 $M_6$ 处于饱和，这是一个较宽松的附加约束。

**数值示例。** 设终值电流下 $V_{GS6} = 0.9$ V（过驱动电压为 0.2 V），

$$\frac{R_b}{R_a} > \frac{0.9 - 0.7}{3 - 0.9} = \frac{0.2}{2.1} = 0.095 .$$

例如，$R_b/R_a = 0.2$ 给出 $V_X = 0.9 - 0.2\times2.1 = 0.48$ V，远低于 0.7 V，而 $I_{D6}R_b = 0.42\ \mathrm{V} < 0.7$ V 使 $M_6$ 保持饱和。

### 第 5 步 — 设计说明：启动窗口

采用平方律时，$V_X - V_{TH} = \sqrt{2I_{D6}/\beta_6} - I_{D6}R_b$，它只在 $I_{D6} < 2/(\beta_6R_b^2)$ 时为正，并在 $I_{D6} = 1/(2\beta_6R_b^2)$ 处取得最大值 $1/(2\beta_6R_b)$。因此 $M_5$ 只在一个低电源电压的窗口内（微弱地）导通，这个窗口必须覆盖偏置核心能够启动的范围（大致为 $V_{DD} > V_{GS1} + |V_{GS3}|$）；相对于 $R_b$ 取较大的 $R_a$，可使 $I_{D6}$ 随 $V_{DD}$ 缓慢增长，同时也限制了 $R_a$–$R_b$–$M_6$ 支路的静态电流。

### 结果

**工作原理。** 偏置核心可能停留在零电流状态。上电过程中，在 $M_6$ 导通之前，$V_X = V_N = V_{DD}$。一旦 $V_X > V_{TH}$，$M_5$ 就从 $M_3$ 的栅极/漏极节点（即 $M_2$ 的漏极）抽取电流。$M_3$/$M_4$ 导通，$M_4$ 驱动 $M_1$，$M_1$/$M_2$ 导通，偏置核心的正反馈环路稳定在正常工作点。随着 $V_{DD}$ 升高，$M_6$ 导通电流 $I_{D6} = (V_{DD} - V_{GS6})/R_a$，该电流流过 $R_a$ 和 $R_b$，把 X 拉低到 $V_X = V_{GS6} - I_{D6}R_b$。当它低于 $V_{TH}$ 时，$M_5$ 关断，不再破坏两条支路电流的相等关系。

**条件**（电源达到终值时）：

$$V_X = V_{GS6} - \frac{R_b}{R_a}(V_{DD} - V_{GS6}) < V_{TH}\quad\Longleftrightarrow\quad \frac{R_b}{R_a}(3\ \mathrm{V} - V_{GS6}) > V_{GS6} - 0.7\ \mathrm{V},$$

等价于 $I_{D6}R_b > V_{GS6} - V_{TH}$，即 $I_{D6} > 2/(\beta_6R_b^2)$，或 $g_{m6}R_b > 2$。

**常见错误。** 说 $M_5$ 向 $M_1$ 的栅极注入电流，或者说它一直导通。$M_5$ 是把 $M_3$/$M_4$ 的栅极节点**拉低**，以开启 PMOS 电流镜（current mirror），而且在稳态时必须关断。

**常见错误。** 把 $M_6$ 看成二极管连接（栅极接 X）。它的栅极接在 N 上，正因如此，压降 $I_{D6}R_b$ 才能把 X 拉到 $V_{GS6}$ **之下**，从而低于 $V_{TH}$。

**常见错误。** 要求稳态时 $V_X > V_{TH}$，“好让启动电路随时待命”。导通的 $M_5$ 会给 $M_3$ 增加一个与电源有关的电流，从而破坏基准。
