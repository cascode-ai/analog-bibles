# Golden Solution - R485

## Reference answer

$\omega_X \approx 1.25\times10^8$ rad/s (≈ 20 MHz), $\omega_Y \approx 7.4\times10^9$ rad/s (≈ 1.18 GHz), low-frequency gain ≈ 20, PM ≈ 75°.
- $M_1$, $M_2$: $I_D$ = 0.25 mA, $g_m = \sqrt{2(134\ \mu)(100)(0.25\ \mathrm{m})} = 2.59$ mS, $r_{O2}$ = 40 kΩ. $M_3$: $r_{O3}$ = 1/(0.2 × 0.25 mA) = 20 kΩ.
- Node X: looking into the drain of $M_2$, whose source is degenerated by $M_1$ (≈ $1/g_{m1}$), gives ≈ $2r_{O2}$ = 80 kΩ, in parallel with $r_{O3}$: $R_X$ ≈ 16 kΩ, so $\omega_X = 1/(16\ \mathrm{k\Omega} \times 0.5\ \mathrm{pF}) = 1.25\times10^8$ rad/s. (The cruder $r_{O2} \parallel r_{O3}$ = 13.3 kΩ gives 1.5×10⁸ rad/s, and the PM changes by < 1°.)
- Node Y (source follower): $g_{m4} = \sqrt{2(134\ \mu)(100)(0.5\ \mathrm{m})} = 3.66$ mS, $r_{O4}$ = 20 kΩ, $R_Y = (1/g_{m4}) \parallel r_{O4} \approx 270\ \Omega$, so $\omega_Y = 1/(270\ \Omega \times 0.5\ \mathrm{pF}) = 7.4\times10^9$ rad/s.
- Gain: the differential input is split across the pair, so $G_m = g_m/2$ = 1.29 mS. $A_0 = (g_m/2)R_X \cdot g_{m4}r_{O4}/(1 + g_{m4}r_{O4}) \approx 1.29\ \mathrm{mS} \times 16\ \mathrm{k\Omega} \times 0.987 \approx 20.4$ (17 with 13.3 kΩ). Feedback goes from $V_{out}$ to the gate of $M_2$ (the inverting input).
- Unity gain: $|H| = 1$ at $\omega_u \approx 2.42\times10^9$ rad/s (close to GBW = $(g_m/2)A_{v4}/C_X = 2.55\times10^9$). Phase = −(87.0° + 18.1°), so PM ≈ 75°.

## Grading notes

+2: $\omega_Y \approx 7.4\times10^9$ rad/s (±10%), $\omega_X$ in (1.2–1.5)×10⁸ rad/s (either model for $R_X$), and PM 72–77°. 70–72° is accepted if the dominant pole's phase is explicitly approximated as 90°. +1: PM right but one pole value somewhat off (e.g., $r_{O4}$ handled loosely), or PM right with a missing pole value. 0: right structure with a slip giving a PM outside 68–78°. -2 (asserted as fact): $G_m = g_m$ instead of $g_m/2$ (PM ≈ 61°), $R_Y$ taken as $r_{O4}$ or $R_X$ as $1/g_m$, or the amplifier treated as having positive feedback.
