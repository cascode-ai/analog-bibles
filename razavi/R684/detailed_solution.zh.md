# 详细步骤 - R684

**思路。** 在这个以二极管连接 PMOS 为负载的共源级（common-source stage）中，$M_1$ 的过驱动电压（overdrive voltage）$V_{ov1}$ 现在是固定的，因此其电流以及随之而来的所有量都随 $\mu_nC_{ox}$ 变化。先用 $K_n = \mu_nC_{ox}(W/L)_1$ 和 $K_p = \mu_pC_{ox}(W/L)_2$ 表示电流、$g_{m1}$ 和 $g_{m2}$，再求增益 $\approx g_{m1}/g_{m2}$ 和输入参考噪声 $\frac{4kT\gamma}{g_{m1}}(1 + g_{m2}/g_{m1})$，并与恒定电流偏置的情况比较。记号：工艺角 FF、SS、FS（快 NMOS、慢 PMOS）和 SF（慢 NMOS、快 PMOS）。

### 第 1 步 — 偏置电流与跨导（transconductance）

过驱动电压 $V_{ov1} = V_{GS1} - V_{TH1}$ 固定（$V_{TH}$ 不随工艺角变化）：

$$I = \frac12\,K_nV_{ov1}^2 \;\propto\; \mu_nC_{ox}.$$

电流（以及功耗）随 NMOS 的工艺角变化：在 FF 和 FS 下增大，在 SS 和 SF 下减小。二极管连接的 $M_2$ 流过 $M_1$ 所设定的电流，其 $V_{SG2}$ 随之调整。于是

$$g_{m1} = K_nV_{ov1} \;\propto\; \mu_nC_{ox}\quad\text{(linear, not square root)},$$

$$g_{m2} = \sqrt{2K_pI} = \sqrt{2K_p\cdot\tfrac12K_nV_{ov1}^2} = V_{ov1}\sqrt{K_pK_n}.$$

### 第 2 步 — 电压增益

输出端的二极管连接负载为 $1/g_{m2}$（与 $r_{O2}$ 并联），因此

$$A_v = -g_{m1}\left(\frac{1}{g_{m2}}\,\Big\|\,r_{O1}\,\Big\|\,r_{O2}\right) \approx -\frac{g_{m1}}{g_{m2}},$$

再由第 1 步得

$$|A_v| = \frac{K_nV_{ov1}}{V_{ov1}\sqrt{K_pK_n}} = \sqrt{\frac{K_n}{K_p}} .$$

偏置电流被消去：增益取决于 NMOS 与 PMOS 的 $\mu C_{ox}$ 之**比**，与恒定电流偏置时完全一样：

- **FF、SS：** 基本为标称值（相对变化量相等时完全不变）；
- **FS：** 最高；
- **SF：** 最低。

### 第 3 步 — 输入参考热噪声

每个晶体管都在输出节点贡献一个沟道噪声电流 $4kT\gamma g_m$；它们的功率相加，再把输出噪声 $4kT\gamma(g_{m1} + g_{m2})R_{out}^2$ 除以增益的平方 $(g_{m1}R_{out})^2$，得

$$\overline{V_{n,in}^2} = \frac{4kT\gamma}{g_{m1}}\left(1 + \frac{g_{m2}}{g_{m1}}\right).$$

利用 $g_{m1} = K_nV_{ov1}$ 和 $g_{m2}/g_{m1} = \sqrt{K_p/K_n}$：

$$\overline{V_{n,in}^2} = \frac{4kT\gamma}{K_nV_{ov1}}\left(1 + \sqrt{\frac{K_p}{K_n}}\right).$$

现在前置因子按 $1/\mu_nC_{ox}$ 变化，而恒定电流时是 $1/\sqrt{\mu_nC_{ox}}$：噪声在各工艺角之间的变化**更加剧烈**。

- **FF：** $g_{m1}$ 按 $\mu C_{ox}$ 成比例增大，比值不变：噪声功率按 $\propto 1/\mu C_{ox}$ 下降。
- **SS：** 噪声按同样的比例上升。
- **FS：** $g_{m1}$ 增大而负载项 $\sqrt{K_p/K_n}$ 减小：**最低**。
- **SF：** $g_{m1}$ 减小而负载项增大：**最高**。

### 第 4 步 — 数值示例

设变化量为 $\pm20\ \%$（$n$、$p$：$\mu_nC_{ox}$、$\mu_pC_{ox}$ 的倍乘因子），标称增益为 3（$\sqrt{K_p/K_n} = 1/3$），$V_{ov1} = 0.15$ V，因此标称 $V_{ov2} = \sqrt{2I/K_p} = V_{ov1}\sqrt{K_n/K_p} = 0.45$ V。相对值：电流为 $n$；增益为 $3\sqrt{n/p}$；噪声为 $(1/n)\left[1 + \tfrac13\sqrt{p/n}\right]/\tfrac43$。

| 工艺角 | $n$, $p$ | 电流 | $\lvert A_v\rvert$ | 噪声功率（相对值） | 恒定电流时的噪声（作对比） | $V_{ov2}$ |
|---|---|---|---|---|---|---|
| 标称 | 1, 1 | 1.0 | 3.00 | 1.000 | 1.000 | 0.45 V |
| FF | 1.2, 1.2 | 1.2 | 3.00 | 0.833（−0.79 dB） | 0.913 | 0.45 V |
| SS | 0.8, 0.8 | 0.8 | 3.00 | 1.250（+0.97 dB） | 1.118 | 0.45 V |
| FS | 1.2, 0.8 | 1.2 | 3.67 | 0.795（−1.00 dB） | 0.871 | 0.55 V |
| SF | 0.8, 1.2 | 0.8 | 2.45 | 1.320（+1.21 dB） | 1.181 | 0.37 V |

例如，在 SF 下：噪声 $= (1/0.8)(1 + \tfrac13\sqrt{1.2/0.8})/\tfrac43 = 1.25\times1.408/1.333 = 1.320$。排序为 **FS < FF < 标称 < SS < SF**，从最好到最差的差异（约 2.2 dB）比恒定电流时（约 1.3 dB）更大。如果 NMOS 与 PMOS 的变化量相差很大，FF 和 SS 的位置可能改变；FS 和 SF 始终是两个极端。

### 第 5 步 — 输出直流电平

$$V_{out} = V_{DD} - |V_{GS2}| = V_{DD} - |V_{TH2}| - V_{ov2}, \qquad V_{ov2} = \sqrt{\frac{2I}{K_p}} = V_{ov1}\sqrt{\frac{K_n}{K_p}} .$$

- **FF、SS：** $K_n/K_p$ 不变，因此 $V_{ov2}$ 和 $V_{out}$ 都不变。
- **FS：** $V_{ov2}$ 增大（在本例中 0.45 → 0.55 V），因此 $V_{out}$ 下降约 0.1 V，挤占了 $M_1$ 的 $V_{DS}$ 裕量，甚至可能把它推向线性区。
- **SF：** $V_{ov2}$ 减小，因此 $V_{out}$ 升高（在本例中约升高 0.08 V）。

### 结果

- **偏置电流：** $I = \frac12\mu_nC_{ox}(W/L)_1V_{ov1}^2 \propto \mu_nC_{ox}$（在 FF 和 FS 下较大，在 SS 和 SF 下较小；功耗随之变化）。
- **增益：** $|A_v| \approx g_{m1}/g_{m2} = \sqrt{K_n/K_p}$，与电流无关，因此在各工艺角下的表现与恒定电流偏置时相同：在 FF 和 SS 下基本为标称值（变化量相当时），FS 下最高，SF 下最低。
- **输入参考噪声：** $\overline{V_{n,in}^2} = \dfrac{4kT\gamma}{K_nV_{ov1}}\left(1 + \sqrt{K_p/K_n}\right)$，按 $1/\mu_nC_{ox}$ 而不是 $1/\sqrt{\mu_nC_{ox}}$ 变化：FF 下较低，SS 下较高，FS 下最低，SF 下最高（变化量相当时 FS < FF < 标称 < SS < SF），各工艺角之间的差异比恒定电流时更大。
- **输出电平：** 在 FF 和 SS 下不变，在 FS 下降低，在 SF 下升高。

**常见错误。** 把 $M_2$ 的 $V_{GS}$ 也当作固定的，从而得到 $g_{m2} \propto \mu_pC_{ox}$ 以及增益 $\propto K_n/K_p$。$M_2$ 是二极管连接的：它流过由 $M_1$ 设定的电流，因此 $g_{m2} = \sqrt{2K_pI}$。

**常见错误。** 声称增益随偏置电流按比例变化。$g_{m1}$ 和 $g_{m2}$ 都取决于工作点，而在两者之比中电流被消去了。

**常见错误。** 读错输出节点，写出诸如 $-g_{m1}/(g_{m1} + g_{m2})$ 的增益。输出是 $M_1$ 的漏极，负载为 $1/g_{m2}$；增益为 $-g_{m1}/g_{m2}$。
