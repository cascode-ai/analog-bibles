$W/L \approx 29.9$，$WL = 3.24\ \mu\mathrm{m^2}$，由此得 $W \approx 9.8\ \mu$m，$L \approx 0.33\ \mu$m（有效尺寸）。
- 仅由阈值失配引起的电流失配：$\Delta I_D/I_D = 2\Delta V_{TH}/(V_{GS}-V_{TH})$ → $\Delta V_{TH} = 0.02\times0.5/2 = 5$ mV。
- 面积：$9/\sqrt{WL} = 5$ → $\sqrt{WL} = 1.8\ \mu$m，$WL = 3.24\ \mu\mathrm{m^2}$。
- 宽长比（aspect ratio）：$W/L = 2I_D/[\mu_nC_{ox}(V_{GS}-V_{TH})^2] = 1\ \mathrm{mA}/(134\ \mu\mathrm{A/V^2}\times0.25\ \mathrm{V^2}) = 29.85$。
- $L = \sqrt{3.24/29.85} = 0.329\ \mu$m，$W = 29.85\times0.329 = 9.83\ \mu$m。若把 2% 视为上限，则任何 W/L 相同而面积更大的设计也都满足要求（例如 L = 0.5 μm、W = 14.9 μm，给出 1.3%）。
