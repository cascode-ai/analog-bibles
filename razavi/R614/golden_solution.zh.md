$I_{D1} - I_{D2} = I_{SS}\tanh\dfrac{V_{in}}{2\zeta V_T}$。谐波（没有偶次谐波）：基波（fundamental）为 $\dfrac{I_{SS}V_m}{2\zeta V_T}$（再减去一个小的压缩量 $I_{SS}V_m^3/(32\zeta^3V_T^3)$），三次谐波（third harmonic）为 $\dfrac{I_{SS}V_m^3}{96\,\zeta^3V_T^3}$，HD3 $= \dfrac{V_m^2}{48\,\zeta^2V_T^2}$。
- 证明：两管的源极共用一个节点，因此 $I_{D1}/I_{D2} = \exp[(V_{G1}-V_{G2})/(\zeta V_T)] = e^{V_{in}/\zeta V_T}$（共同的源–衬电压被抵消），且 $I_{D1} + I_{D2} = I_{SS}$。因此 $I_{D1} = I_{SS}/(1 + e^{-V_{in}/\zeta V_T})$，$I_{D2} = I_{SS}/(1 + e^{V_{in}/\zeta V_T})$，$I_{D1} - I_{D2} = I_{SS}\dfrac{e^{V_{in}/\zeta V_T}-1}{e^{V_{in}/\zeta V_T}+1} = I_{SS}\tanh\dfrac{V_{in}}{2\zeta V_T}$。
- $\tanh z = z - z^3/3 + 2z^5/15 - \dots$（只有奇次项）。令 $z = \tfrac u2\cos\omega t$，$u = V_m/(\zeta V_T)$：$z^3/3 = \tfrac{u^3}{24}\cos^3\omega t = \tfrac{u^3}{96}(3\cos\omega t + \cos3\omega t)$。
- 因此 $I_{D1}-I_{D2} \approx I_{SS}\left[\left(\tfrac u2 - \tfrac{u^3}{32}\right)\cos\omega t - \tfrac{u^3}{96}\cos3\omega t\right]$。由于 $I_{SS} = 2I$，基波等于 $IV_m/(\zeta V_T)$，与电流为 $I$ 的共源级（common-source stage）相同，而后者的 HD2 为 $V_m/(4\zeta V_T)$。
