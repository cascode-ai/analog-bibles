# 详细步骤 - R318

**思路。** 对差分信号而言，尾节点是交流地，栅极由理想电压源驱动，因此每个半边都是一个跨导器（transconductor）$g_{m1}$，驱动由 $M_3$、$R$ 和 $C$ 构成的负载 $Z_L$。由 $M_3$ 栅极处的 $R$–$C$ 分压推导 $Z_L(s)$，得到 $V_{out}/V_{in} = -g_{m1}Z_L$，求出 $|Z_L|$ 随频率升高（感性负载）的条件，再考察这一单极点、单零点响应在单位增益频率（unity-gain frequency）处的相位。

### 第 1 步 — 半边电路（half circuit）

把 $M_3$ 的栅极称为节点 G；每一侧的 $R$ 都接在输出端（$M_3$ 的漏极）与 G 之间，$C$ 接在 G 与 $V_{DD}$ 之间。对差分输入而言，尾节点是交流地，理想电压源驱动也不产生输入极点，因此每个半边都是以 $Z_L$ 为负载的 $M_1$（源极接地，$v_{gs1} = V_{in}/2$）。$\lambda = 0$，并忽略所有其他电容。

### 第 2 步 — 负载阻抗 $Z_L$

<!-- diagram: diagram-01.cir -->

在 $M_3$ 的漏极加测试电压 $V_{out}$，求流入负载（流向 $V_{DD}$）的电流 $I$。栅极不吸取电流，因此 $R$ 和 $C$ 对 $V_{out}$ 分压后加到 G 上：

$$V_G = V_{out}\,\frac{1/(Cs)}{R + 1/(Cs)} = \frac{V_{out}}{1 + RCs}.$$

$M_3$ 的源极处于交流地，流过电流 $g_{m3}V_G$；$R$–$C$ 支路流过 $V_{out}/[R + 1/(Cs)] = Cs\,V_{out}/(1 + RCs)$：

$$I = g_{m3}\frac{V_{out}}{1 + RCs} + \frac{Cs\,V_{out}}{1 + RCs} = V_{out}\,\frac{g_{m3} + Cs}{1 + RCs},$$

$$Z_L(s) = \frac{V_{out}}{I} = \frac{1 + RCs}{g_{m3} + Cs}.$$

### 第 3 步 — 传递函数

每个半边给出 $V_{out1} = -g_{m1}Z_L\,V_{in}/2$，另一半边给出相反的值，且 $V_{out} = V_{out1} - V_{out2} = 2V_{out1}$：

$$\frac{V_{out}}{V_{in}}(s) = -g_{m1}Z_L(s) = -g_{m1}\,\frac{1 + RCs}{g_{m3} + Cs},$$

其直流增益为 $-g_{m1}/g_{m3}$，高频增益为 $-g_{m1}R$，零点位于 $\omega_z = 1/(RC)$，极点位于 $\omega_p = g_{m3}/C$。

### 第 4 步 — 负载何时呈感性？

$Z_L(0) = 1/g_{m3}$：$C$ 开路，$R$ 中没有电流，$M_3$ 为**二极管连接**（diode-connected）。$Z_L(\infty) = R$：$C$ 把栅极与 $V_{DD}$ 短接，$M_3$ 变为电流源（current source），在 $\lambda = 0$ 时其阻抗为无穷大，只剩下 $R$。因此当满足下式时，$|Z_L|$ 随频率**升高**，即负载呈**感性**：

$$R > \frac{1}{g_{m3}}\qquad(\text{equivalently } \omega_z = 1/(RC) < \omega_p = g_{m3}/C).$$

减去直流值：

$$
\begin{aligned}
Z_L - \frac{1}{g_{m3}} &= \frac{g_{m3}(1 + RCs) - (g_{m3} + Cs)}{g_{m3}(g_{m3} + Cs)} = \frac{(g_{m3}R - 1)Cs}{g_{m3}(g_{m3} + Cs)}\\
&= \frac{\left(R - \dfrac{1}{g_{m3}}\right)\dfrac{C}{g_{m3}}s}{1 + \dfrac{C}{g_{m3}}s} = \left(R - \frac{1}{g_{m3}}\right)\parallel sL,\qquad L = \frac{C}{g_{m3}}\left(R - \frac{1}{g_{m3}}\right).
\end{aligned}
$$

因此当 $R > 1/g_{m3}$ 时，负载是 $1/g_{m3}$ 与 $(R - 1/g_{m3})\parallel L$ 的串联，即一个**有源电感**（active inductor）。

<!-- diagram: diagram-02.cir -->

当 $R < 1/g_{m3}$ 时，同样的推导会得到负的“电感”：极点在前，$|Z_L|$ 从 $1/g_{m3}$ 下降到 $R$，负载呈容性。

### 第 5 步 — 响应的相位

相对于直流反相，$V_{out}/V_{in}$ 在 $s = j\omega$ 处的相位为

$$\theta(\omega) = \arctan\frac{\omega}{\omega_z} - \arctan\frac{\omega}{\omega_p} = \arctan(\omega RC) - \arctan\frac{\omega C}{g_{m3}},$$

这是两个介于 0° 与 90° 之间的角度之差，因此在任何频率下都有 $-90^\circ < \theta < +90^\circ$。

**容性情况**（$R < 1/g_{m3}$，极点低于零点）。增益从 $g_{m1}/g_{m3}$ **下降**到 $g_{m1}R$；若 $g_{m1}R < 1 < g_{m1}/g_{m3}$，则会穿过单位增益。相位是小于 90° 的滞后，由于零点的回拉作用，它甚至比单个极点的滞后还小：计入反相时介于 180° 与 270° 之间；不计入时介于 0° 与 90° 之间。**永远不会有 135° 的滞后。**

**感性情况**（$R > 1/g_{m3}$，零点低于极点）。相位为**超前**，最大值为 $90^\circ - 2\arctan(1/\sqrt{g_{m3}R})$（出现在 $\omega = \sqrt{\omega_z\omega_p}$ 处）。若把反相计为 180°，45° 的超前将给出“180° − 45° = 135°”，这需要 $g_{m3}R\ge(1 + \sqrt2)^2 = 3 + 2\sqrt2\approx5.8$；但此时增益从 $g_{m1}/g_{m3}$ **升向** $g_{m1}R$，永远不会降到单位增益。

**结论。** 只有 $C_1$ 和 $C_2$ 时，电路是一阶的（一个极点、一个零点），不能在增益降至单位增益的频率处提供 135° 的相移。

### 第 6 步 — 输出节点电容是否有帮助？

$Z_L\parallel(1/C_{out}s)$ 是二阶的，但由第 4 步，$Z_L$ 是由**正**电阻和一个电感（当 $R < 1/g_{m3}$ 时为一个电容）组成的网络，加上 $C_{out}$ 后仍然是无源 RLC 阻抗。它的实部非负，因此相位始终在 ±90° 以内，半边电路的增益 $-g_{m1}\left[Z_L\parallel(1/C_{out}s)\right]$ 与频率有关的相位滞后仍至多为 90°。这里同样被忽略的右半平面零点（right-half-plane zero）$g_{m1}/C_{GD1}$ 只会增加几度。要在单位增益处达到 135°，需要在信号通路本身中增加一个极点，例如第二个增益级。

### 结果

$$\frac{V_{out}}{V_{in}}(s) = -g_{m1}Z_L(s) = -g_{m1}\,\frac{1 + RCs}{g_{m3} + Cs}, \qquad Z_L = \frac{1 + RCs}{g_{m3} + Cs},$$

其中直流时 $Z_L = 1/g_{m3}$，高频时为 $R$，零点位于 $1/(RC)$，极点位于 $g_{m3}/C$。

- **感性负载**：当 $R > 1/g_{m3}$ 时（零点低于极点，$|Z_L|$ 上升），$Z_L = \dfrac{1}{g_{m3}} + \left(R - \dfrac{1}{g_{m3}}\right)\parallel sL$，其中 $L = \dfrac{C}{g_{m3}}\left(R - \dfrac{1}{g_{m3}}\right)$。
- **单位增益处的 135°：不能。** 该响应只有一个极点和一个零点，因此相对于反相的相位始终在 ±90° 以内。只有在容性负载（$R < 1/g_{m3}$）时增益才会下降并穿过单位增益，而此时滞后小于 90°；对于感性负载，相位是超前的，但增益上升而不是下降。必须在信号通路中有第二个极点。

**常见错误。** 把零点和极点弄反，即认为 $R < 1/g_{m3}$ 时负载呈感性。零点位于 $1/(RC)$，极点位于 $g_{m3}/C$；只有当 $R > 1/g_{m3}$ 时，零点才在前，$|Z_L|$ 才上升。

**常见错误。** 在所有频率下都把 $M_3$ 当作电流源。在低频时，其栅极经 $R$ 跟随漏极，因此它是二极管连接的（$1/g_{m3}$）；只有在高频时 $C$ 才把它的栅极“冻结”住。

**常见错误。** 仅由 $C_1$、$C_2$ 推导出二阶传递函数。每个半边只有一个电容，因此恰好只有一个极点和一个零点；差分输出只是半边电路输出的两倍。
