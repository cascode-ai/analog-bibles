# 详细步骤 - R688

**思路。** $M_1$ 是以二极管连接的 PMOS 管 $M_2$ 为负载的共源级（common-source stage）。在 $M_1$ 的每个工作区中用平方律写出 $I_{D1} = I_{D2}$，并检查 $C_{ox}$ 如何出现在方程中：氧化层变厚使两个晶体管的 $C_{ox}$ 按同一因子变化，因此它会从每个决定 $V_{out}$ 的方程中消去。

### 第 1 步 — 氧化层变厚改变了什么，以及基本方程

较长的氧化时间使 $t_{ox}$ 增大，因而 $C_{ox} = \varepsilon_{ox}/t_{ox}$ 减小；两个晶体管共用同一层栅氧，因此二者减小的比例相同：

$$C_{ox,\text{actual}} = \alpha\,C_{ox,\text{target}}, \qquad \alpha = \frac{t_{ox,\text{target}}}{t_{ox,\text{actual}}} < 1 .$$

阈值、迁移率和 $W/L$ 都不变，因此 $\mu_nC_{ox}$ 和 $\mu_pC_{ox}$ 都按 $\alpha$ 下降。每个管子的衬底都接到各自的源极，所以没有体效应（body effect），阈值电压保持为 0.7 V 和 0.8 V。

暂取 $\lambda = 0$。二极管连接的 $M_2$ 只要导通就处于饱和区，其 $V_{SG2} = V_{DD} - V_{out}$：

$$I_{D2} = \frac12\mu_pC_{ox}\Big(\frac{W}{L}\Big)_2 (V_{DD} - V_{out} - |V_{THP}|)^2 = \frac12\mu_pC_{ox}\Big(\frac{W}{L}\Big)_2 (2.2\ \mathrm{V} - V_{out})^2 .$$

输出端不接负载，因此 $I_{D1} = I_{D2}$。定义无量纲比值

$$A = \sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_2}} = \sqrt{\frac{\mu_nC_{ox}(W/L)_1}{\mu_pC_{ox}(W/L)_2}},$$

由第二种写法可见，它与 $C_{ox}$ 无关。

### 第 2 步 — 区域 I：$M_1$ 截止（$0 \le V_{in} \le 0.7$ V）

$M_1$ 截止时，$M_2$ 的电流也必须为零；在平方律模型中，这要求

$$V_{SG2} \le |V_{THP}| \quad\Longrightarrow\quad V_{DD} - V_{out} \le 0.8\ \mathrm{V} \quad\Longrightarrow\quad V_{out} \ge 2.2\ \mathrm{V}.$$

该模型无法在 $[2.2, 3]$ V 中确定唯一的值。按惯例取导通的临界点，这也正是 $M_1$ 刚导通时曲线所取的值：

$$V_{out} = V_{DD} - |V_{THP}| = 3 - 0.8 = 2.2\ \mathrm{V}.$$

（在实际器件中，$M_1$ 完全截止时，$M_2$ 的亚阈值导电会把输出缓慢地充电至接近 $V_{DD}$。）这一电平中不含 $C_{ox}$。

### 第 3 步 — 区域 II：$M_1$ 饱和（直线段）

在 $V_{in} = 0.7$ V 稍上方，$V_{out} \approx 2.2$ V 远高于 $V_{in} - 0.7$ V，因此 $M_1$ 处于饱和区。令两管的饱和电流相等：

$$\frac12\mu_nC_{ox}\Big(\frac{W}{L}\Big)_1 (V_{in} - 0.7)^2 = \frac12\mu_pC_{ox}\Big(\frac{W}{L}\Big)_2 (2.2 - V_{out})^2 .$$

因子 $\tfrac12 C_{ox}$ 被消去，再除以 $\mu_p(W/L)_2$，得到

$$(2.2 - V_{out})^2 = A^2 (V_{in} - 0.7)^2 .$$

两个器件都导通时，两个括号内的量都为正，因此

$$\boxed{V_{out} = 2.2\ \mathrm{V} - A\,(V_{in} - 0.7\ \mathrm{V})}$$

这是一条**直线**，其斜率为

$$\frac{dV_{out}}{dV_{in}} = -A = -\sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_2}} .$$

这就是小信号增益 $-g_{m1}/g_{m2}$：两管流过相同的电流，$g_{m1} = \sqrt{2\mu_nC_{ox}(W/L)_1I_D}$，$g_{m2} = \sqrt{2\mu_pC_{ox}(W/L)_2I_D}$，因此二者之比为 $A$。由于两个器件服从同样的平方律，该级是线性的。

### 第 4 步 — $M_1$ 何时退出饱和区

只要 $V_{out} \ge V_{in} - 0.7$，$M_1$ 就保持饱和。第 3 步中的直线与 $V_{out} = V_{in} - 0.7$ 相交于

$$2.2 - A(V_{in} - 0.7) = V_{in} - 0.7 \quad\Longrightarrow\quad 2.2 = (1 + A)(V_{in} - 0.7),$$

$$V_{in,B} = 0.7 + \frac{2.2}{1 + A}\ \mathrm{V}, \qquad V_{out,B} = V_{in,B} - 0.7 = \frac{2.2}{1 + A}\ \mathrm{V}.$$

式中只出现 $A$，因此这个转折点与 $C_{ox}$ 无关。

### 第 5 步 — 区域 III：$M_1$ 处于线性区

当 $V_{in} > V_{in,B}$ 时，令 $M_1$ 的线性区电流等于 $M_2$ 的饱和电流：

$$\mu_nC_{ox}\Big(\frac{W}{L}\Big)_1\Big[(V_{in} - 0.7)V_{out} - \tfrac12V_{out}^2\Big] = \frac12\mu_pC_{ox}\Big(\frac{W}{L}\Big)_2 (2.2 - V_{out})^2 .$$

$C_{ox}$ 再次被消去。两边除以 $\tfrac12\mu_pC_{ox}(W/L)_2$：

$$A^2\Big[2(V_{in} - 0.7)V_{out} - V_{out}^2\Big] = (2.2 - V_{out})^2 ,$$

对每个 $V_{in}$，这都是关于 $V_{out}$ 的二次方程。随着 $V_{in}$ 增大，$M_1$ 相当于一个越来越小的电阻 $R_{on1} \approx 1/[\mu_nC_{ox}(W/L)_1(V_{in} - 0.7)]$，$V_{out}$ 向零下降，**但永远达不到零**：若 $V_{out} = 0$，$M_1$ 中将没有电流，而 $M_2$ 的电流却达到最大值，这违反基尔霍夫电流定律（KCL）。曲线最终平坦于一个较小的正值，该值由 $R_{on1}$ 与二极管 $M_2$ 之间的分压关系决定。

### 第 6 步 — 取 $A = 2$ 的数值示例

取 $A = 2$（例如 $\mu_n \approx 2\mu_p$ 且 $(W/L)_1 = 2(W/L)_2$）；$A$ 取其他值时曲线形状相同，只是斜率和转折点不同。

**转折点：**

$$V_{in,B} = 0.7 + \frac{2.2}{1 + 2} = 0.7 + 0.733 = 1.433\ \mathrm{V}, \qquad V_{out,B} = 0.733\ \mathrm{V}.$$

**线性区方程**，其中 $V_{ov1} = V_{in} - 0.7$：

$$
\begin{aligned}
4\big(2V_{ov1}V_{out} - V_{out}^2\big) &= 4.84 - 4.4V_{out} + V_{out}^2\\
5V_{out}^2 - (8V_{ov1} + 4.4)V_{out} + 4.84 &= 0 .
\end{aligned}
$$

有效的根是较小的那个（它必须满足 $V_{out} < V_{ov1}$）：

$$V_{out} = \frac{(8V_{ov1} + 4.4) - \sqrt{(8V_{ov1} + 4.4)^2 - 96.8}}{10}.$$

**终点 $V_{in} = 3$ V**（$V_{ov1} = 2.3$ V）：

$$
\begin{aligned}
8V_{ov1} + 4.4 &= 8(2.3) + 4.4 = 22.8,\\
(22.8)^2 - 96.8 &= 519.84 - 96.8 = 423.04,\\
\sqrt{423.04} &= 20.568,\\
V_{out} &= \frac{22.8 - 20.568}{10} = 0.223\ \mathrm{V}.
\end{aligned}
$$

**各点数值（$A = 2$），对两种氧化层厚度都成立：**

| $V_{in}$ (V) | $M_1$ 的工作区 | $V_{out}$ (V) |
|---|---|---|
| 0 – 0.7 | 截止 | 2.20 |
| 1.0 | 饱和 | $2.2 - 2(0.3) = 1.60$ |
| 1.2 | 饱和 | $2.2 - 2(0.5) = 1.20$ |
| 1.433 | 线性区边缘 | 0.733 |
| 1.5 | 线性区 | 0.635 |
| 2.0 | 线性区 | 0.374 |
| 2.5 | 线性区 | 0.278 |
| 3.0 | 线性区 | 0.223 |

草图依次为：2.2 V 处的水平段；从 $V_{in} = 0.7$ V 开始、斜率为 $-A$ 的直线下降段；$V_{in,B}$ 处的平滑弯折；以及逐渐变平、趋于几百毫伏的尾段。

### 第 7 步 — 与目标氧化层厚度的比较

在决定 $V_{out}$ 的每个方程（第 2–5 步）中，$C_{ox}$ 要么根本不出现，要么是 $I_{D1} = I_{D2}$ 两边的公共因子。因此 2.2 V 的平台、导通点 $V_{in} = 0.7$ V、斜率 $-A$、转折点 $V_{in,B}$ 以及 $V_{in} = 3$ V 处的低电平**全都不变**：厚氧化层的曲线与目标曲线完全重合。

**沟道长度调制不会改变这一结论。** 额外的因子 $(1 + \lambda_nV_{out})$ 和 $(1 + \lambda_p(V_{DD} - V_{out}))$ 分别乘在方程两边，但其中不含 $C_{ox}$。从小信号角度看，在给定工作点上 $g_m = \mu C_{ox}(W/L)V_{ov} \propto C_{ox}$，$r_O = 1/(\lambda I_D) \propto 1/C_{ox}$，因此 $g_{m1}/g_{m2}$ 和 $g_{m1}r_{O1}$ 这类增益都与 $C_{ox}$ 无关。

**真正改变的是电流和速度。** 在任一 $V_{in}$ 下，过驱动电压（overdrive voltage）都与目标设计相同，因此电流与 $C_{ox}$ 成比例：

$$I_{D,\text{actual}} = \alpha\, I_{D,\text{target}}, \qquad \alpha = \frac{t_{ox,\text{target}}}{t_{ox,\text{actual}}}.$$

例如，氧化层比设计值厚 20 % 时，$\alpha = 1/1.2 = 0.83$，即电流减小 17 %。跨导按同一因子下降，因此二极管负载的电阻 $1/g_{m2}$ 增大为原来的 $1/\alpha$ 倍。栅电容（$\propto C_{ox}WL$）也会减小，但结电容和外部负载电容不变，因此尽管直流传输曲线完全相同，**该级的速度变慢了**。

### 结果

厚氧化层时的 $V_{out}$–$V_{in}$ 特性与目标情况**完全相同**，因为 $\mu_nC_{ox}$ 和 $\mu_pC_{ox}$ 按同一因子下降，$C_{ox}$ 在 $I_{D1} = I_{D2}$ 中被消去。令 $A = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_2]}$，则：

- $0 \le V_{in} \le 0.7$ V：$M_1$ 截止，$V_{out} = V_{DD} - |V_{THP}| = 2.2$ V（按惯例取值；$M_2$ 的亚阈值漏电会把它缓慢拉向 3 V）。
- $M_1$ 饱和：$V_{out} = 2.2 - A(V_{in} - 0.7)$，是一条斜率为 $-A$ 的直线（小信号增益为 $-g_{m1}/g_{m2}$）。
- $M_1$ 在 $V_{in} = 0.7 + 2.2/(1 + A)$ 处进入线性区；此后 $V_{out}$ 逐渐变平，趋于由 $A^2[2(V_{in} - 0.7)V_{out} - V_{out}^2] = (2.2 - V_{out})^2$ 确定的较小非零值。$A = 2$ 时：转折点在 1.43 V，$V_{in} = 3$ V 时 $V_{out} = 0.22$ V。
- 只有偏置电流和跨导按 $t_{ox,\text{target}}/t_{ox,\text{actual}}$ 的比例下降，因此电路变慢。

**常见错误。** 认为“氧化层变厚使 $g_m$ 降低，所以增益下降”。$g_{m1}$ 和 $g_{m2}$ 按同一因子下降，而增益是二者之比；只有电流大小（从而速度）发生变化。

**常见错误。** 把 $M_2$ 当作电流源（current source），画出一直降到 0 V 的输出。二极管连接的 $M_2$ 是一个阻值约为 $1/g_{m2}$ 的平方律“电阻”：它使饱和区内的曲线成为斜率为 $-A$ 的直线，并且即使在 $V_{in} = V_{DD}$ 时 $V_{out}$ 仍高于零。

**常见错误。** 在 $V_{in} < 0.7$ V 时把输出画在 $V_{DD} = 3$ V，并在导通时垂直跳变到 2.2 V。一旦有可观的电流流过，$M_2$ 就需要 $V_{SG2} \ge |V_{THP}|$，因此在平方律模型下，刚导通时输出就位于 2.2 V；亚阈值导电只会在远低于阈值的区域使输出逐渐漂向 $V_{DD}$。
