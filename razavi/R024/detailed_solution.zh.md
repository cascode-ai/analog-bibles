# 详细步骤 - R024

**思路。** $M_1$ 为二极管连接，源极接地，因此它始终处于饱和区，其电流只取决于 $V_X$。该电流由电容提供，由此得到一个一阶非线性微分方程。精确求解该方程，然后描述 $V_X(t)$ 和 $I_X(t)$，并将这种衰减与指数衰减作比较。

### 第 1 步 — 微分方程

$V_{GS} = V_{DS} = V_X$；由于没有体效应（body effect），$V_{TH} = 0.7$ V。因为 $V_{DS} = V_{GS}$，$M_1$ 只要导通（即 $V_X > 0.7$ V）就处于饱和区。忽略沟道长度调制（channel-length modulation），并注意 $I_X$ 只能来自电容，得到

$$I_X = \tfrac12\beta\,(V_X - 0.7\ \mathrm{V})^2 = -C_1\frac{dV_X}{dt} \quad\Longrightarrow\quad C_1\frac{dV_X}{dt} = -\tfrac12\beta\,(V_X - 0.7)^2 .$$

### 第 2 步 — 求解

令过驱动电压（overdrive voltage）$u = V_X - 0.7$ V（$du/dt = dV_X/dt$）：

$$\frac{du}{dt} = -\frac{\beta}{2C_1}\,u^2 \quad\Longrightarrow\quad -\frac{du}{u^2} = \frac{\beta}{2C_1}\,dt .$$

从 $t = 0$（此时 $u = u_0$）开始积分：

$$
\begin{aligned}
\left[\frac{1}{u}\right]_{u_0}^{u} &= \frac{\beta}{2C_1}\,t\\
\frac{1}{u} - \frac{1}{u_0} &= \frac{\beta}{2C_1}\,t\\
u(t) &= \frac{u_0}{1 + \dfrac{\beta u_0}{2C_1}\,t} .
\end{aligned}
$$

初始过驱动电压为 $u_0 = 3 - 0.7 = 2.3$ V。引入特征时间

$$T = \frac{2C_1}{\beta u_0} = \frac{2C_1}{\beta\,(2.3\ \mathrm{V})} ,$$

$$V_X(t) = 0.7\ \mathrm{V} + \frac{2.3\ \mathrm{V}}{1 + t/T} .$$

### 第 3 步 — 电流

$$I_X(t) = \tfrac12\beta\,u(t)^2 = \frac{\tfrac12\beta\,(2.3\ \mathrm{V})^2}{(1 + t/T)^2} = \frac{2.645\,\beta\ \mathrm{V^2}}{(1 + t/T)^2} .$$

初始电流为 $I_X(0) = \tfrac12\beta(2.3\ \mathrm{V})^2 = 2.645\beta$（V²），例如 $\beta = 1\ \mathrm{mA/V^2}$ 时为 2.65 mA。

验算：$dV_X/dt = -2.3/[T(1 + t/T)^2]$，因此 $-C_1\,dV_X/dt = 2.3C_1/[T(1 + t/T)^2] = 2.3C_1\beta(2.3)/[2C_1(1 + t/T)^2] = \tfrac12\beta(2.3)^2/(1 + t/T)^2$。✓

### 第 4 步 — 曲线形状

| $t/T$ | $V_X$ (V) | $I_X/\beta$ (V²) |
|---|---|---|
| 0 | 3.00 | 2.65 |
| 0.5 | 2.23 | 1.18 |
| 1 | 1.85 | 0.66 |
| 2 | 1.47 | 0.29 |
| 4 | 1.16 | 0.106 |
| 9 | 0.93 | 0.026 |
| 19 | 0.815 | 0.0066 |
| 99 | 0.723 | 0.0003 |

- **$V_X$** 起初下降很快，然后越来越慢地趋向 **0.7 V**（$V_{TH}$），在有限时间内永远达不到。它**不会**降到零。
- **$I_X$** 从 $2.65\beta$ 开始，按 $1/(1 + t/T)^2$ 衰减到零。

**是双曲线衰减，而不是指数衰减。** 当 $t \gg T$ 时，$V_X - 0.7 \approx 2.3\,T/t$：剩余的过驱动电压只按 $1/t$ 下降。它在 $t = 0$ 到 $T$ 之间减半，但再减半一次要到 $3T$，再减半一次要到 $7T$，因为器件的电导 $I_X/u = \tfrac12\beta u$ 随过驱动电压一起减小（若是电阻，电导保持不变，衰减就是指数式的）。在实际器件中，亚阈值导电会继续使 $V_X$ 非常缓慢地降到 0.7 V 以下（大致随时间按对数规律变化），但在平方律模型中，最终值为 $V_{TH}$。

### 结果

$M_1$ 为二极管连接，因此**始终处于饱和区**：

$$C_1\frac{dV_X}{dt} = -\tfrac12\beta\,(V_X - 0.7)^2 .$$

令 $u = V_X - 0.7$ V，得到 $1/u = 1/u_0 + \beta t/(2C_1)$，其中 $u_0 = 2.3$ V，因此

$$V_X(t) = 0.7 + \frac{2.3}{1 + 2.3\beta t/(2C_1)}\ \mathrm{V}, \qquad I_X(t) = \tfrac12\beta\,(V_X - 0.7)^2 = \frac{2.65\,\beta}{\left[1 + 2.3\beta t/(2C_1)\right]^2}.$$

- $V_X$ 从 3 V **按双曲线规律**衰减，趋向 $V_{TH} = 0.7$ V 但达不到（按 $\propto 1/t$ 趋近，比指数衰减慢）。
- $I_X$ 从 $\tfrac12\beta(2.3\ \mathrm{V})^2 = 2.65\beta$ 衰减到零。
- 实际上，亚阈值导电会使 $V_X$ 继续缓慢降到 0.7 V 以下。

**常见错误。** 让 $V_X$ 放电到 0 V。一旦 $V_X = V_{GS}$ 降到 $V_{TH}$，二极管连接的器件就截止，因此在平方律模型中，没有任何东西能把电容电压拉到 0.7 V 以下。

**常见错误。** 在后期把 $M_1$ 当作线性区（triode region）器件或固定电阻，画出指数衰减。它始终处于饱和区，其电流是 $V_X - V_{TH}$ 的二次函数，由此得到更慢的双曲线拖尾。

**常见错误。** 把特征时间写成 $2C_1u_0/\beta$，而不是 $2C_1/(\beta u_0)$。量纲检查（$\beta u_0$ 的单位为 A/V = S，$C_1/S$ 的单位为秒）证实了正确的形式：初始过驱动电压越大，时间**越短**。
