# 详细步骤 - R697

**思路。** 该电路是一个单位增益采样器。在运放的反相输入端利用电荷守恒推导其增益误差，其中计入有限的开环增益 $A$ 以及该节点的寄生电容 $C_{in}$。误差只取决于 $A$ 和 $C_{in}/C_1$，因此只有当某种制造错误降低了 $A$ 或增大了 $C_{in}$ 时，才会造成很大的增益误差；用这一点逐一检验三种错误。

### 第 1 步 — 采样相：节点 X 上的电荷

把运放的反相输入端记为 X，把运放建模为 $V_{out} = A(V_+ - V_-) = -AV_X$，并令 $C_{in}$ 为从 X 到地的总寄生电容（运放输入电容加上 $S_2$ 的结电容和交叠电容）。在采样期间，$S_1$ 把 $V_{in}$ 加到 $C_1$ 的左极板（节点 P）上，$S_2$ 使运放处于单位增益反馈状态，因此 $V_{out} = V_X$，且

$$V_X = -AV_X \;\Longrightarrow\; V_X(1 + A) = 0 \;\Longrightarrow\; V_X = 0 .$$

<!-- diagram: diagram-01.cir -->

于是与 X 相连的各极板上的电荷为

$$Q_X = C_1(V_X - V_P) + C_{in}(V_X - 0) = C_1(0 - V_{in}) + 0 = -C_1V_{in}.$$

### 第 2 步 — 放大相与增益误差

此时 $S_3$ 把 P 接到输出端，因此只有 $C_1$ 构成反馈环路：该电路是一个**单位增益采样器**，理想情况下对任何 $C_1$ 值都有 $V_{out} = V_{in}$，而不是增益由电容比决定的放大器。$S_2$ 断开后，X 被隔离，因此 $Q_X$ **守恒**，且 $V_P = V_{out}$，$V_X = -V_{out}/A$。

<!-- diagram: diagram-02.cir -->

$$C_1(V_X - V_{out}) + C_{in}V_X = -C_1V_{in}.$$

代入 $V_X = -V_{out}/A$，两边乘以 $-1$ 并除以 $C_1$：

$$V_{out}\Big[C_1\Big(1 + \frac1A\Big) + \frac{C_{in}}{A}\Big] = C_1V_{in} \quad\Longrightarrow\quad V_{out}\Big[1 + \frac1A\Big(1 + \frac{C_{in}}{C_1}\Big)\Big] = V_{in},$$

$$\frac{V_{out}}{V_{in}} = \frac{1}{1 + \dfrac1A\Big(1 + \dfrac{C_{in}}{C_1}\Big)} \approx 1 - \frac1A\Big(1 + \frac{C_{in}}{C_1}\Big).$$

**增益误差：**

$$\varepsilon \approx \frac{1}{A}\left(1 + \frac{C_{in}}{C_1}\right).$$

例如，$A = 1000$ 且 $C_{in}/C_1 = 0.1$ 时，$\varepsilon = 1.1/1000 = 0.11\ \%$。因此，**很大**的增益误差需要**运放增益 $A$ 大大降低**（或 $C_{in}$ 相对于 $C_1$ 大大增加）。节点 P 并不出现在式中：无论 P 上挂有多大的电容，它在两个相位中都由电压源充电。

### 第 3 步 — (c) 源/漏注入时的沟道效应：原因所在

发生沟道效应时，注入的离子沿晶体中开放的方向运动，穿透深度远超预期。

- 源/漏结变得**异常地深**，在栅极下方的横向扩展也更大，因此 $L_{eff} = L_{drawn} - 2L_D$ 缩短（$L_D$ 为横向扩散长度）。
- **短沟道效应**（漏致势垒降低、强烈的沟道长度调制、趋向穿通）大大增强，因此每个器件的 $r_O$ 都下降。
- 运放增益由各管的本征增益（intrinsic gain）构成：每级 $A \propto g_mr_O$，共源共栅级则 $\propto g_mr_O^2$。在目标偏置电流下 $g_m$ 大致不变，而 $r_O$ 急剧下降，因此 **$A$ 急剧下降**。
- 更深的结侧壁面积也更大，因此 X 处 $S_2$（以及其他任何器件）的结电容增大，**使 $C_{in}$ 增大**。

这两种效应都会增大 $\varepsilon = (1 + C_{in}/C_1)/A$。**结论：是，(c) 可能造成很大的增益误差。**

### 第 4 步 — (b) 节点 P 处 $C_1$ 底极板的极重掺杂：不是原因

底极板掺杂加重——例如以扩散区（diffusion）作为底极板——会增大其对衬底的寄生电容 $C_P$，但 $C_P$ 挂在**节点 P** 上，而该节点**始终被驱动**：采样期间经 $S_1$ 由 $V_{in}$ 驱动，放大期间经 $S_3$ 由 $V_{out}$ 驱动。$C_P$ 并不与 X 相连，因此它不出现在第 2 步的电荷方程中，建立完成后 $V_{out}$ 不变。（这正是把底极板放在 P 而不是 X 的原因。）它唯一的影响是给运放输出端和 $S_1$ 增加了额外的电容负载，即**建立变慢**；只有当某个相位短到无法完全建立时，它才会表现为误差。

即使 $C_1$ 本身发生变化（极板重掺杂会使电容略微变大，线性度也更好）也无关紧要：对任何 $C_1$ 理想增益都为 1，而较大的 $C_1$ 只会**减小** $C_{in}/C_1$ 项。**结论：不是原因。**

### 第 5 步 — (a) 阈值调整注入剂量过大：不是原因

在运放偏置电流为目标值的情况下：

- $g_m = \sqrt{2\mu C_{ox}(W/L)I_D}$ 和 $r_O = 1/(\lambda I_D)$ 中都不含 $V_{TH}$，因此 **$A$ 基本不变**：晶体管工作在不同的 $V_{GS}$ 下，但过驱动电压相同。（沟道掺杂加重会使迁移率有所下降，而 $g_m \propto \sqrt{\mu}$，但这是一个很小的影响。）
- **只有间接影响。** 较大的 $V_{GS}$ 可能占用电压余度，使运放中的某个器件退出饱和区；或者减小 NMOS 开关的过驱动电压（导通电阻增大，建立变慢）。这些取决于具体的偏置电平和时序。
- $S_2$ 的**电荷注入**随 $V_{TH}$ 变化，但 $S_2$ 在虚地 X 处开关，因此其注入的电荷与 $V_{in}$ 无关：这是**失调**，而不是增益误差。在通常的底极板采样（bottom-plate sampling）时序中，$S_1$ 比 $S_2$ 稍晚断开，此时 X 已被隔离，因此 $S_1$ 的注入不会改变 $Q_X$。

**结论：不是原因。**

### 结果

- **(c) 源/漏注入时的沟道效应 — 是。** 深结使 $L_{eff}$ 变短并增强短沟道效应，降低 $r_O$，从而降低运放增益 $A$（并在求和节点增加结电容）。因此单位增益采样器的误差 $\varepsilon \approx (1 + C_{in}/C_1)/A$ 显著增大。
- **(b) P 处 $C_1$ 底极板重掺杂 — 否。** 节点 P 先由 $V_{in}$、后由 $V_{out}$ 驱动，因此其寄生电容不影响 X 处的电荷；它只会使建立变慢。
- **(a) 阈值调整注入剂量过大 — 否。** 在固定偏置电流下，$g_m$ 和 $r_O$（因而 $A$）都与 $V_{TH}$ 无关；它只可能产生间接影响（电压余度、开关电阻），而它对电荷注入的影响是失调，而不是增益误差。

**常见错误。** 把该电路当作增益由电容比决定的反相放大器，并认为 (b) “改变了电容比”。$C_1$ 先对 $V_{in}$ 采样，然后被接入反馈通路，因此理想情况下对任何电容值都有 $V_{out} = V_{in}$。

**常见错误。** 声称 P 处的底极板寄生电容会引起电荷分享（charge sharing）。电荷分享需要一个浮空节点；而 P 在两个相位中都由 $V_{in}$ 或 $V_{out}$ 驱动。

**常见错误。** 认为阈值升高会降低运放的 $g_m$。这只在 $V_{GS}$ 固定时成立；在偏置电流等于目标值时，$g_m$ 和 $r_O$ 都与 $V_{TH}$ 无关。
