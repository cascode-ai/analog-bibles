# 详细步骤 - R607

**思路。** 用偏置量重写增益：$|A_v| = 2IR_D/(V_{GS} - V_{TH})$。于是提高增益只有两种途径：减小过驱动电压，或增大直流压降 $IR_D$；两者分别通过不同的机理降低线性度：前者作用于输入端（电压–电流转换），后者作用于输出端，涉及电压余量（headroom）与线性区。

### 第 1 步 — 用过驱动电压和负载压降表示增益

令 $V_{ov} = V_{GS} - V_{TH}$，由 $I = \tfrac12\mu_nC_{ox}(W/L)V_{ov}^2$ 得 $\mu_nC_{ox}(W/L) = 2I/V_{ov}^2$，因此

$$|A_v| = \mu_nC_{ox}\frac{W}{L}V_{ov}R_D = \frac{2I}{V_{ov}^2}V_{ov}R_D = \frac{2\,IR_D}{V_{ov}},$$

这对共源级以及差分对的每一侧（$I = I_{SS}/2$）都成立。可调的手段只有两个：

1. **降低 $V_{ov}$**（例如在电流不变时增大 $W/L$，或在 $IR_D$ 不变时减小电流）；
2. **增大 $IR_D$**（增大 $R_D$，或增大流过它的电流）。

### 第 2 步 — 效应 1：较小的过驱动电压使输入管的线性度变差

电压–电流转换的失真由输入摆幅**相对于过驱动电压**的大小决定。

**共源级。** 令 $V_{GS} = V_{GS0} + V_m\cos\omega t$：

$$I_D = \tfrac12\mu_nC_{ox}\tfrac{W}{L}(V_{ov} + V_m\cos\omega t)^2 = \text{DC} + \mu_nC_{ox}\tfrac{W}{L}V_{ov}V_m\cos\omega t + \tfrac14\mu_nC_{ox}\tfrac{W}{L}V_m^2\cos2\omega t,$$

因此

$$\mathrm{HD2} = \frac{V_m}{4V_{ov}}.$$

**差分对。** 偶次谐波相互抵消，而 $\Delta I = kV_{ov}V_{in}\sqrt{1 - V_{in}^2/(4V_{ov}^2)} \approx kV_{ov}V_{in} - kV_{in}^3/(8V_{ov})$（其中 $k = \mu_nC_{ox}W/L$）中的三次项给出

$$\mathrm{HD3} = \frac{V_m^2}{32V_{ov}^2},$$

同时线性输入范围 $\sqrt2V_{ov}$（此时一个晶体管截止）随 $V_{ov}$ 减小而缩小。

**一句话概括折中关系。** 由 $V_{ov} = 2IR_D/|A_v|$：

$$\mathrm{HD2}_{CS} = \frac{|A_v|\,V_m}{8\,IR_D}, \qquad \mathrm{HD3}_{pair} = \frac{|A_v|^2V_m^2}{128\,(IR_D)^2}.$$

对于给定的 $IR_D$ 和输入幅度，失真与增益成正比（共源级）或与增益的平方成正比（差分对）。例如：取 $IR_D = 1$ V，$V_m = 20$ mV，$V_{ov} = 0.4$ V 的共源级有 $|A_v| = 5$，HD2 = 1.25 %；把过驱动电压降到 0.2 V 会使增益加倍到 10，但 HD2 也加倍到 2.5 %。过驱动电压较小时，斜率 $g_m$ 在整个摆幅范围内变化很快。

### 第 3 步 — 效应 2：较大的 $IR_D$ 压缩输出端的电压余量

漏极电压为

$$V_{D} = V_{DD} - IR_D,$$

它随 $IR_D$ 增大而下降，而输出摆幅 $|A_v|V_m = 2IR_DV_m/V_{ov}$ 与 $IR_D$ 成正比增大。

只要 $V_D \ge V_G - V_{TH}$，晶体管就保持饱和。在共源级中，最坏的时刻是栅极处于峰值（$V_{GS0} + V_m$）而漏极处于谷值（$V_{DD} - IR_D - |A_v|V_m$）：

$$V_{DD} - IR_D - |A_v|V_m \;\ge\; V_{ov} + V_m .$$

对于差分对（每个栅极围绕 $V_{in,CM}$ 摆动 $\pm V_m/2$，每个漏极围绕 $V_{DD} - IR_D$ 摆动 $\pm|A_v|V_m/2$）：

$$V_{DD} - IR_D - \frac{|A_v|V_m}{2} \;\ge\; V_{in,CM} + \frac{V_m}{2} - V_{TH}.$$

增大 $IR_D$ 会从两方面侵蚀不等式左边：直流压降增大，输出偏移也增大。一旦不等式不再成立，晶体管就会在输出峰值处进入**线性区**，增量增益骤降，输出波形被削平：产生严重失真。

把 $|A_v| = 2IR_D/V_{ov}$ 与 $IR_D \le V_{DD} - V_{ov} - (\text{swing})$ 结合：

$$|A_v| \le \frac{2\,(V_{DD} - V_{ov} - \text{swing})}{V_{ov}},$$

因此在给定电源电压下，增益越高，留给线性输出摆幅的空间就越小，而单纯增大 $R_D$ 最终会把器件推入线性区。

### 第 4 步 — 两种机理小结

| 提高 $\lvert A_v\rvert = 2IR_D/V_{ov}$ 的途径 | 线性度受损之处 | 表现 |
|---|---|---|
| 减小 $V_{ov}$（增大 $W/L$ 或减小电流） | 输入端：电压–电流转换 | HD2 $= V_m/(4V_{ov})$（共源级），HD3 $= V_m^2/(32V_{ov}^2)$（差分对），输入范围变窄 |
| 增大 $IR_D$（增大 $R_D$） | 输出端：电压余量 | 漏极偏置降低，输出摆幅增大，晶体管在峰值处被推入线性区 |

### 结果

由于 $|A_v| = g_mR_D = 2IR_D/(V_{GS} - V_{TH})$，只能通过以下途径提高增益：

1. **减小过驱动电压**（在电流固定时增大 $W/L$）。此时输入摆幅占 $V_{GS} - V_{TH}$ 的比例变大，电压–电流转换的非线性加重：共源级中 HD2 $= V_m/[4(V_{GS} - V_{TH})]$，差分对中 HD3 $= V_m^2/[32(V_{GS} - V_{TH})^2]$，且差分对的线性输入范围（$\approx\sqrt2(V_{GS} - V_{TH})$）也随之缩小。
2. **增大 $R_D$（即压降 $IR_D$）。** 漏极偏置 $V_{DD} - IR_D$ 下降，而输出摆幅 $|A_v|V_m$ 增大，因此在输出峰值处漏极电压逼近 $V_G - V_{TH}$，晶体管进入线性区，造成严重失真。在电源电压固定时，增益越高，留给线性输出摆幅的空间越小。

**常见错误。** 认为较低的过驱动电压因为带来更高的增益而改善线性度。在开环情况下恰恰相反：输入器件的失真由 $V_m/V_{ov}$ 决定，而它随 $V_{ov}$ 降低而增大。

**常见错误。** 认为较大的 $R_D$ 使晶体管远离线性区。它**降低**了直流漏极电压，又**增大**了输出摆幅，两者都使漏极电压更接近 $V_G - V_{TH}$。
