# 详细步骤 - R595

**思路。** 首先求出开关电容共模反馈所设定的输出共模电平：$M_5$ 必须恰好流过负载电流，这就确定了 $V_X = V_{GS5}$；在共模设定期间，$S_1$ 把 X 连接到跟随器的公共源极，因此输出比 X 高一个跟随器的 $V_{GS}$。然后要求 $M_5$（决定下限）以及 $M_1$、$M_2$（决定上限）保持饱和，并考虑每个源极高于地电位的 NMOS 的体效应。

### 第 1 步 — 共模反馈如何确定输出共模电平

PMOS 负载的总电流必须流过 $M_1$、$M_2$ 和 $M_5$，共模反馈调节 $M_5$ 的栅极（节点 X），直到 $I_{D5} = 1$ mA。在没有沟道长度调制的情况下，这只取决于 $V_{GS5}$：

$$V_X = V_{GS5}(1\ \mathrm{mA}).$$

在共模设定相位，两个输出都处于 $V_{out,CM}$，跟随器 $M_6$、$M_7$（各 50 µA）使其公共源极处于 $V_{out,CM} - V_{GS6}$，而 $S_1$ 把该节点连接到 X：

$$V_{out,CM} = V_X + V_{GS6} = V_{GS5} + V_{GS6}.$$

$S_1$ 断开后，$C_1$ 和 $C_2$ 保持 $V_{GS6}$，维持同样的输出共模电平；只要所有器件都处于饱和区，它就与输入共模电平无关。

### 第 2 步 — $V_{GS5}$

对于 $M_1$–$M_5$，$\mu_nC_{ox}(W/L) = 134\ \mu\mathrm{A/V^2}\times(50/0.5) = 13.4\ \mathrm{mA/V^2}$：

$$V_{ov5} = \sqrt{\frac{2(1\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.1493}\ \mathrm{V} = 0.386\ \mathrm{V}.$$

$M_5$ 的源极接地（无体效应）：

$$V_{GS5} = V_{TH0} + V_{ov5} = 0.7 + 0.386 = 1.086\ \mathrm{V} = V_X.$$

### 第 3 步 — 较小跟随器的 $V_{GS6}$ 与输出共模电平

跟随器的 $W/L = 10/0.5 = 20$，因此 $\mu_nC_{ox}(W/L)_6 = 134\ \mu\mathrm{A/V^2}\times20 = 2.68\ \mathrm{mA/V^2}$：

$$V_{ov6} = \sqrt{\frac{2(50\ \mu\mathrm{A})}{2.68\ \mathrm{mA/V^2}}} = \sqrt{0.0373}\ \mathrm{V} = 0.193\ \mathrm{V}.$$

它们的公共源极处于 $V_X = 1.086$ V，衬底接地，因此 $V_{SB6} = 1.086$ V：

$$
\begin{aligned}
V_{TH6} &= V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB6}} - \sqrt{2|\phi_F|}\right)\\
&= 0.7 + 0.45\left(\sqrt{1.986} - \sqrt{0.9}\right) = 0.7 + 0.45\,(1.4094 - 0.9487) = 0.907\ \mathrm{V},\\
V_{GS6} &= V_{TH6} + V_{ov6} = 0.907 + 0.193 = 1.100\ \mathrm{V}.
\end{aligned}
$$

输出共模电平：

$$V_{out,CM} = V_{GS5} + V_{GS6} = 1.086 + 1.100 = 2.19\ \mathrm{V}.$$

**PMOS 负载管检查**（各 0.5 mA）：

$$|V_{ov3}| = \sqrt{\frac{2(0.5\ \mathrm{mA})}{(38.4\ \mu\mathrm{A/V^2})(100)}} = 0.510\ \mathrm{V},\qquad V_{out,max} = 3 - 0.510 = 2.49\ \mathrm{V} > 2.19\ \mathrm{V},\ \checkmark$$

因此负载管处于饱和区，还有 0.3 V 的裕量。

### 第 4 步 — 输入共模电平的下限（$M_5$ 处于饱和区）

只要尾节点 P 满足 $V_P \ge V_{ov5} = 0.386$ V，$M_5$ 就保持饱和。每个输入管流过 0.5 mA：

$$V_{ov1} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.0746}\ \mathrm{V} = 0.273\ \mathrm{V}.$$

在临界点，$V_{SB1} = V_P = 0.386$ V：

$$
\begin{aligned}
V_{TH1} &= 0.7 + 0.45\left(\sqrt{0.9 + 0.386} - 0.9487\right) = 0.7 + 0.45\,(1.1342 - 0.9487) = 0.783\ \mathrm{V},\\
V_{in,CM,min} &= V_P + V_{TH1} + V_{ov1} = 0.386 + 0.783 + 0.273 = 1.44\ \mathrm{V}.
\end{aligned}
$$

这一极限只涉及 $M_5$ 和 $M_1$，因此不受跟随器尺寸的影响。

### 第 5 步 — 输入共模电平的上限（$M_1$、$M_2$ 处于饱和区）

$M_1$ 处于饱和区的条件是 $V_D \ge V_G - V_{TH1}$，即

$$V_{in,CM} \le V_{out,CM} + V_{TH1}.$$

在这一临界点，$V_P = V_{in,CM} - V_{TH1} - V_{ov1} = V_{out,CM} - V_{ov1}$：

$$
\begin{aligned}
V_P &= 2.187 - 0.273 = 1.914\ \mathrm{V},\\
V_{TH1} &= 0.7 + 0.45\left(\sqrt{0.9 + 1.914} - 0.9487\right) = 0.7 + 0.45\,(1.6774 - 0.9487) = 1.028\ \mathrm{V},\\
V_{in,CM,max} &= V_{out,CM} + V_{TH1} = 2.187 + 1.028 = 3.21\ \mathrm{V}.
\end{aligned}
$$

这超过了 $V_{DD} = 3$ V，因此对于直到电源电压的任何输入共模电平，输入对管都保持饱和（提高输入共模电平只会增大 $V_{DS5}$）。

### 第 6 步 — 小结与比较

$$1.44\ \mathrm{V} \;\le\; V_{in,CM} \;\le\; 3.21\ \mathrm{V}\ \ (\text{effectively up to } V_{DD} = 3\ \mathrm{V}).$$

不计体效应时（所有器件的 $V_{TH} = 0.7$ V）：

$$
\begin{aligned}
V_{out,CM} &= 1.086 + 0.7 + 0.193 = 1.98\ \mathrm{V},\\
V_{in,CM,min} &= 0.386 + 0.7 + 0.273 = 1.36\ \mathrm{V},\\
V_{in,CM,max} &= 1.98 + 0.7 = 2.68\ \mathrm{V}.
\end{aligned}
$$

**较小跟随器的影响。** 把 $M_6$、$M_7$ 从 50/0.5 缩小到 10/0.5，使其过驱动电压（overdrive voltage）从 0.086 V 增大到 0.193 V，因此输出共模电平升高约 0.11 V（从 2.08 V 升到 2.19 V）。上限也上移了相近的量，下限不变，而 PMOS 负载的电压余量（headroom）减小（2.19 V，而其极限为 2.49 V）。

### 结果

共模反馈设定 $V_X = V_{GS5} = 1.086$ V，$V_{out,CM} = V_{GS5} + V_{GS6} = 1.086 + 1.100 \approx 2.19$ V。允许的输入共模范围为

$$\approx 1.44\ \mathrm{V} \le V_{in,CM} \le \approx 3.21\ \mathrm{V},$$

即从 1.44 V（尾电流管 $M_5$ 处于饱和边缘）一直到基本上等于 $V_{DD} = 3$ V（$M_1$/$M_2$ 的饱和极限 3.21 V 高于电源电压）。不计体效应时：1.36 V 至 2.68 V。

**常见错误。** 把输出共模电平只取为 $V_{GS5}$（相当于 X 直接接到输出），或者假设为 1.5 V。在共模设定相位，X 与跟随器的公共源极相连，因此输出比 X 高一个跟随器的 $V_{GS}$（这里计入体效应后为 1.10 V）。

**常见错误。** 认为跟随器尺寸会改变下限。下限只由 $M_5$ 的电压余量和 $M_1$ 在 0.5 mA 下的 $V_{GS}$ 决定；跟随器的 50 µA 只流过 $M_6$、$M_7$。
