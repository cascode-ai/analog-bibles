# Golden Solution - R472

## Reference answer

For $I_P < I_{SS} < 2I_P$ the slew rate is $(2I_P - I_{SS})/C_L$ in both directions, as long as the input stays within the input common-mode range. (The circuit cannot be biased for $I_{SS} \ge 2I_P$: each folding branch must carry $I_P - I_{SS}/2 > 0$ at rest.) The starved folding node (X or Y) collapses to about $V_P$, driving $M_1$ (or $M_2$) into the triode region and slowing the recovery. Only when the step leaves the input CM range does the tail source starve; the slewing current then rises toward $I_P$.

- Bookkeeping: let $i_1$, $i_2$ be the input-pair currents. At X and Y, $i_1 + i_3 = I_P$ and $i_2 + i_4 = I_P$; the mirror gives $i_6 = i_3$, so the current into $C_L$ is $i_4 - i_6 = i_1 - i_2$, with $i_1 + i_2 = I_{SS}$ and $i_1, i_2 \le I_P$ ($M_3$, $M_4$ cannot conduct in reverse).
- Positive step: $M_1$ can take only the $I_P$ that $M_9$ supplies, so $M_3$ turns off and $V_X$ falls until $M_1$ is in the triode region with $i_1 = I_P$. The tail node then falls only until $M_2$ (gate at $V_{out}$) conducts the remaining $I_{SS} - I_P$. Since $I_{SS} - I_P < I_{SS}/2$, $V_P$ stays above its quiescent value and the tail source remains saturated. $M_4$ delivers $I_P - (I_{SS} - I_P) = 2I_P - I_{SS}$ while the mirror sinks nothing: $dV_{out}/dt = +(2I_P - I_{SS})/C_L$.
- Negative step (symmetric): $M_4$ turns off, $V_Y$ collapses, $M_2$ carries $I_P$ in the triode region, $M_1$ carries $I_{SS} - I_P$, and $M_3$ and the mirror pull $2I_P - I_{SS}$ out of the output: $dV_{out}/dt = -(2I_P - I_{SS})/C_L$.
- Outside the CM range: if a negative step takes $V_{in}$ below about $V_{TH} + V_{OD1}(I_{SS} - I_P) + V_{DS,sat}$ of the tail device, $M_1$ cannot carry $I_{SS} - I_P$. The tail source then enters the triode region and the weak input device carries only $i_w < I_{SS} - I_P$, so the slewing current is $I_P - i_w$, growing continuously with the depth of the excursion toward $I_P$ ($|SR| \to I_P/C_L$ when $M_1$ is nearly off and the tail carries only $\approx I_P$). Likewise, a positive step starting from an output level below the CM range slews at up to $I_P/C_L$ until $V_{out}$ is high enough for $M_2$ to conduct $I_{SS} - I_P$. With an ideal tail source this regime never occurs. (Depending on the internal capacitances, a short transient with a larger current may also occur at the start of a step while the tail node settles; it does not set the slew rate.)
- Transistor-level check (square-law devices, $I_P = 1$ mA, $C_L = 1$ pF, steps between 1.3 V and 1.9 V inside the CM range): the slewing current is ±0.48–0.50 mA for $I_{SS} = 1.5$ mA, ±0.76–0.80 mA for 1.2 mA and ±0.19–0.20 mA for 1.8 mA, i.e. $2I_P - I_{SS}$. A negative step to 0.6 V, below the CM range, gives −1.0 mA $= -I_P$.
- (For $I_P \ge I_{SS}$ the slew rate is $I_{SS}/C_L$.)

## Grading notes

+2: $|SR| = (2I_P - I_{SS})/C_L$ in both directions with the mechanism ($M_3$ or $M_4$ cut off, the corresponding input transistor limited to $I_P$, the opposite input transistor carrying $I_{SS} - I_P$ so that the tail source still sinks $I_{SS}$). The condition $I_{SS} < 2I_P$, the collapse of X/Y with slow recovery, and a correct treatment of the out-of-range case (tail starved, slewing current $I_P$ when the input, or for a positive step the starting output level, lies below the input CM range) are pluses. +1: $(2I_P - I_{SS})/C_L$ with sketchy reasoning or derived for one direction only; or $I_P/C_L$ (or $(I_P - i_w)/C_L$) derived with the explicit and correct condition that the step leaves the input CM range so that the tail source starves and the weak input device (nearly) cuts off (a valid special case, but not the in-range result). 0: correct mechanism for one direction but a wrong value for the other. -2 (asserted as fact): slew rate $I_{SS}/C_L$ (ignoring the limitation), $(I_{SS} - I_P)/C_L$, the annotated $I_P - I_{SS}$ currents treated as negative currents actually flowing, or $I_P/C_L$ given as the general result on the claim that the opposite input transistor stays off (or that the tail source drops into the triode region) while the input remains in its CM range.
