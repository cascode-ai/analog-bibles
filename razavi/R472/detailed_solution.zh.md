# 详细步骤 - R472

**思路。** 对折叠节点 X、Y 和输出端应用基尔霍夫电流定律（KCL），把流入 $C_L$ 的电流用两个输入管的电流表示出来。然后求出 $I_{SS} > I_P$ 时电路所能提供的最大电流；此时尾电流源仍吸收 $I_{SS}$，而任一折叠节点向其输入管提供的电流都不能超过 $I_P$。

### 第 1 步 — 支路电流与 KCL

将尾节点记为 P，电流镜输入端（$M_3$ 的漏极）记为 N。所有电流均以图中所画方向为正：流过输入对的 $i_1$（X → P）和 $i_2$（Y → P），流过共源共栅管的 $i_3$（X → N）和 $i_4$（Y → $V_{out}$），电流镜输出端（$M_6$、$M_8$）从 $V_{out}$ 吸收的 $i_6$，以及流入 $C_L$ 的 $i_C$，于是 $dV_{out}/dt = i_C/C_L$。

由 X、Y 处的 KCL 以及 1:1 电流镜得到

$$i_3 = I_P - i_1, \qquad i_4 = I_P - i_2, \qquad i_6 = i_3 .$$

输出端的 KCL（$M_2$ 的栅极不吸取电流）：

$$
\begin{aligned}
i_C &= i_4 - i_6\\
&= (I_P - i_2) - (I_P - i_1)\\
&= i_1 - i_2 .
\end{aligned}
$$

只要尾电流源保持饱和，就有 $i_1 + i_2 = I_{SS}$。两个共源共栅管都不会反向导通（$i_3 \ge 0$，因为节点 N 只接 NMOS 器件，它们只能吸收电流；$V_{out}$ 处于正常摆幅范围内时 $i_4 \ge 0$），因此输入管吸取的电流永远不会超过其 PMOS 电流源提供的 $I_P$：

$$i_1 \le I_P, \qquad i_2 \le I_P .$$

### 第 2 步 — 静态工作点：为什么要求 $I_{SS} < 2I_P$

静态时（$V_{in} = V_{out}$），$i_1 = i_2 = I_{SS}/2$，因此折叠支路中的器件流过

$$i_3 = i_4 = I_P - \frac{I_{SS}}{2},$$

要使共源共栅管和电流镜导通，该电流必须为正：

$$I_P - \frac{I_{SS}}{2} > 0 \quad\Longleftrightarrow\quad I_{SS} < 2I_P .$$

因此题目所问的情形是 $I_P < I_{SS} < 2I_P$；若 $I_{SS} \ge 2I_P$，放大器甚至无法正常偏置。

### 第 3 步 — 正向输入阶跃

大的正向阶跃使 $M_1$ 试图让全部尾电流 $I_{SS}$ 流过自身，但 $i_1 \le I_P < I_{SS}$：

1. $M_1$ 吸取了 $M_9$ 的全部电流，因此 $i_3 = 0$：**$M_3$ 截止**，电流镜也随之截止（$i_6 = 0$）。
2. 再没有别的电流流入 X，因此 $V_X$ 不断下降，直到 $M_1$ 进入**线性区**，此时它在很小的 $V_{DS1}$ 下恰好导通 $i_1 = I_P$。X 点电压塌陷到仅略高于 $V_P$。
3. 尾电流源仍要求 $I_{SS}$，因此 P 点稳定在 $M_2$（栅极接 $V_{out}$）恰好导通所缺电流的位置：
$$i_2 = I_{SS} - I_P .$$

**尾电流源保持饱和。** 阶跃之前两个栅极都处于 $V_0$，各流过 $I_{SS}/2$，因此 $V_{P0} = V_0 - V_{TH} - V_{ov}(I_{SS}/2)$，其中 $V_{ov}(I) = \sqrt{2I/(\mu_nC_{ox}W/L)}$ 是流过电流 $I$ 所需的过驱动电压（overdrive voltage）。现在 $M_2$ 的栅极仍处于 $V_{out} \approx V_0$，而它流过的电流更小，
$$I_{SS} - I_P < \frac{I_{SS}}{2} \quad(\text{because } I_{SS} < 2I_P),$$
因此 $V_P = V_0 - V_{TH} - V_{ov}(I_{SS} - I_P) > V_{P0}$：尾电流源的电压余度（headroom）比静态时**更大**，能继续吸收 $I_{SS}$。随着 $V_{out}$ 斜坡上升，P 点通过 $M_2$ 跟随它变化。

**输出电流。** 由第 1 步：
$$
\begin{aligned}
i_4 &= I_P - i_2 = I_P - (I_{SS} - I_P) = 2I_P - I_{SS},\\
i_6 &= i_3 = 0,\\
i_C &= i_4 - i_6 = 2I_P - I_{SS},
\end{aligned}
$$
这与 $i_C = i_1 - i_2 = I_P - (I_{SS} - I_P)$ 相同。因此
$$\frac{dV_{out}}{dt} = +\frac{2I_P - I_{SS}}{C_L}.$$

$M_1$ 无法吸收的那部分尾电流由 $M_2$ 从 Y 抽走，经 $M_4$ 到达 $C_L$ 的电流也就相应减少同样多。

### 第 4 步 — 负向输入阶跃

此时 $M_1$ 的栅极降到远低于 $V_{out}$，$M_2$（栅极接 $V_{out}$）试图获取全部尾电流。由对称性：

1. $i_2$ 被限制为 $I_P$：**$M_4$ 截止**（$i_4 = 0$），$V_Y$ 向 $V_P$ 塌陷，$M_2$ 进入线性区并流过 $i_2 = I_P$。
2. $M_1$ 流过其余电流 $i_1 = I_{SS} - I_P$，它决定了 $V_P = V_{in} - V_{TH} - V_{ov}(I_{SS} - I_P)$。
3. 因此
$$
\begin{aligned}
i_3 &= I_P - i_1 = I_P - (I_{SS} - I_P) = 2I_P - I_{SS},\\
i_6 &= i_3 = 2I_P - I_{SS},\\
i_C &= i_4 - i_6 = 0 - (2I_P - I_{SS}) = -(2I_P - I_{SS}),
\end{aligned}
$$
$$\frac{dV_{out}}{dt} = -\frac{2I_P - I_{SS}}{C_L}.$$

只要 $V_P \ge V_{DS,sat}$（指尾电流管的饱和电压），即 $V_{in} \ge V_{TH} + V_{ov}(I_{SS} - I_P) + V_{DS,sat}$，尾电流源就保持饱和：也就是说，输入保持在输入共模（CM）范围之内。

### 第 5 步 — 上限、数值例子与过载情形

**上限。** 由 $i_C = i_1 - i_2$、$i_1 + i_2 = I_{SS}$ 以及 $0 \le i_1, i_2 \le I_P$ 可知，差值最大时其中一个电流达到其上限 $I_P$，这迫使另一个电流等于 $I_{SS} - I_P$：
$$|i_C|_{max} = I_P - (I_{SS} - I_P) = 2I_P - I_{SS},$$
因此没有其他工作状态能以更快的速率压摆。

**数值例子。** 取 $I_P = 1$ mA、$I_{SS} = 1.5$ mA、$C_L = 1$ pF：
$$SR = \frac{2(1\ \mathrm{mA}) - 1.5\ \mathrm{mA}}{1\ \mathrm{pF}} = \frac{0.5\ \mathrm{mA}}{1\ \mathrm{pF}} = 0.5\ \mathrm{V/ns}.$$
若 $I_{SS} = I_P = 1$ mA，压摆率将为 $I_{SS}/C_L = 1$ V/ns：把 $I_{SS}$ 增大到超过 $I_P$ 反而会**降低**压摆率，并在 $I_{SS} = 2I_P$ 时降为零。

**超出输入共模范围。** 若负向阶跃使 $V_{in}$ 低到在尾电流管饱和的条件下 $M_1$ 无法流过 $I_{SS} - I_P$，尾电流源就会落入线性区，$M_1$ 只流过某个 $i_w < I_{SS} - I_P$。此时压摆电流为 $i_3 = I_P - i_w$，当 $M_1$ 接近截止时它趋近于 $I_P$。（若正向阶跃起始时的输出电平低于共模范围，在 $V_{out}$ 升高到足以使 $M_2$ 导通 $I_{SS} - I_P$ 之前，情况与此类似。）这是大信号（large-signal）过载情形，而不是正常的压摆率。

**恢复。** 压摆期间，X（或 Y）处于约 $V_P$ 的电位，$M_1$（或 $M_2$）处于线性区，而 $M_3$（或 $M_4$）以及可能还有电流镜处于截止状态。在环路重新取得控制之前，这些节点必须由很小的电流重新充电，因此恢复过程很慢：这是实际中选择 $I_P > I_{SS}$ 的一个理由。

### 结果

当 $I_P < I_{SS} < 2I_P$ 时（若 $I_{SS} \ge 2I_P$，电路无法偏置）：
$$SR = \frac{2I_P - I_{SS}}{C_L}$$
只要输入保持在输入共模范围之内，两个方向均如此。

- 正向阶跃：$M_3$ 截止，$M_1$ 处于线性区且 $i_1 = I_P$，$M_2$ 流过 $I_{SS} - I_P$，$M_4$ 向 $C_L$ 提供 $2I_P - I_{SS}$。
- 负向阶跃：$M_4$ 截止，$M_2$ 处于线性区且 $i_2 = I_P$，$M_1$ 流过 $I_{SS} - I_P$，电流镜从 $C_L$ 抽走 $2I_P - I_{SS}$。
- （作为对比，若 $I_P \ge I_{SS}$，压摆率为 $I_{SS}/C_L$。）

**常见错误。** 沿用 $I_P > I_{SS}$ 情形下的 $SR = I_{SS}/C_L$：$M_1$ 吸取的电流不可能超过 $M_9$ 提供的 $I_P$。图中标注的电流 $I_P - I_{SS}$ 在这里将为负值，而共源共栅管不能流过负电流，该器件只会截止。

**常见错误。** 以“另一个输入管截止”为由认为 $SR = I_P/C_L$：尾电流源仍吸收 $I_{SS}$，因此当一个输入管被限制在 $I_P$ 时，另一个输入管**必须**导通 $I_{SS} - I_P$，这部分电流要从输出电流中扣除。只有当输入超出共模范围、尾电流源电流不足时，才会出现 $I_P/C_L$。

**常见错误。** 写成 $(I_{SS} - I_P)/C_L$：$I_{SS} - I_P$ 是另一侧输入管**分流**走的电流，而不是输送给 $C_L$ 的电流。
