# 详细步骤 - R020

**思路。** $M_1$ 为二极管连接，因此始终处于饱和区，并流过固定电流 $I_1$；其栅源电压 $V_{out}$ 等于阈值电压（threshold voltage）加上一个固定的过驱动电压（overdrive voltage）。$V_{in}$ 驱动衬底，因此它只通过体效应改变 $V_{out}$。用 $V_{in}$ 和 $V_{out}$ 表示 $V_{SB}$，求解所得方程，描述斜率，并指出源-衬底结在何处变为正向偏置。

### 第 1 步 — $V_{out}$ = 阈值电压 + 过驱动电压

栅极和漏极都接 $V_{DD} = 3$ V，

$$
\begin{aligned}
V_S &= V_{DD} - V_{GS} = 3 - V_{out},\\
V_{SB} &= V_S - V_{in} = 3 - V_{out} - V_{in}.
\end{aligned}
$$

$V_{DS} = V_{GS}$，因此 $M_1$ 只要导通就处于饱和区，沟道中流过 $I_1$：

$$I_1 = \tfrac12\beta\,(V_{GS} - V_{TH})^2 \quad\Longrightarrow\quad V_{GS} - V_{TH} = \sqrt{\frac{2I_1}{\beta}} .$$

过驱动电压是**恒定的**，因此

$$V_{out} = V_{GS} = V_{TH}(V_{SB}) + \sqrt{\frac{2I_1}{\beta}} ,$$

对 $V_{in}$ 的全部依赖关系都来自

$$V_{TH} = 0.7 + 0.45\left(\sqrt{0.9 + V_{SB}} - 0.9487\right),\qquad V_{SB} = 3 - V_{out} - V_{in}.$$

### 第 2 步 — 变化的方向

升高 $V_{in}$ 会使衬底电位向源极靠近，从而减小 $V_{SB}$，进而降低 $V_{TH}$，因此随着 $V_{in}$ 升高，**$V_{out}$ 下降**。（$V_{out}$ 下降时，源极 $V_S = 3 - V_{out}$ 略有升高，部分抵消了 $V_{SB}$ 的减小；这就是变化幅度不大的原因。）

**斜率。** 令 $\eta = \partial V_{TH}/\partial V_{SB} = \gamma/(2\sqrt{0.9 + V_{SB}})$，过驱动电压恒定，于是 $dV_{out} = dV_{TH} = \eta\,dV_{SB}$，且 $dV_{SB} = -dV_{out} - dV_{in}$：

$$
\begin{aligned}
dV_{out} &= \eta\,(-dV_{out} - dV_{in})\\
dV_{out}\,(1 + \eta) &= -\eta\,dV_{in}\\
\frac{dV_{out}}{dV_{in}} &= -\frac{\eta}{1 + \eta}.
\end{aligned}
$$

斜率为负，且幅度较小（$\eta \approx 0.14$–$0.3$）；随着 $V_{SB}$ 减小，斜率**变陡**，因为 $\eta \propto 1/\sqrt{0.9 + V_{SB}}$ 增大。所以曲线**单调下降且向下凹**。

### 第 3 步 — 数值示例

取 $\sqrt{2I_1/\beta} = 0.2$ V（取其他值只是把整条曲线上下平移）。于是 $V_{out} = V_{TH} + 0.2$ V，$V_{SB} = 2.8 - V_{TH} - V_{in}$。令 $u = \sqrt{0.9 + V_{SB}}$，从而 $V_{TH} = 3.7 - V_{in} - u^2$，体效应方程变为（$0.7 - 0.45\times0.9487 = 0.2731$）

$$
\begin{aligned}
3.7 - V_{in} - u^2 &= 0.2731 + 0.45u\\
u^2 + 0.45u - (3.4269 - V_{in}) &= 0\\
u &= \frac{-0.45 + \sqrt{0.2025 + 4\,(3.4269 - V_{in})}}{2} .
\end{aligned}
$$

**$V_{in} = 0$：**

$$
\begin{aligned}
u &= \frac{-0.45 + \sqrt{0.2025 + 13.7076}}{2} = \frac{-0.45 + 3.7296}{2} = 1.6398,\\
V_{SB} &= u^2 - 0.9 = 2.6890 - 0.9 = 1.789\ \mathrm{V},\\
V_{TH} &= 0.7 + 0.45\,(1.6398 - 0.9487) = 1.011\ \mathrm{V},\\
V_{out} &= 1.011 + 0.2 = 1.21\ \mathrm{V}.
\end{aligned}
$$

验算：$V_S = 3 - 1.211 = 1.789$ V，$V_{SB} = 1.789 - 0 = 1.789$ V。✓

**$V_{in} = 2.1$ V：** $u = (-0.45 + \sqrt{0.2025 + 5.3076})/2 = (-0.45 + 2.3474)/2 = 0.9487$，因此 $V_{SB} = 0.9 - 0.9 = 0$，$V_{TH} = V_{TH0} = 0.7$ V，$V_{out} = 0.90$ V。此时衬底恰好处于源极电位（$V_S = 3 - 0.9 = 2.1\ \mathrm{V} = V_{in}$），因此 $V_{out} = V_{TH0} + \sqrt{2I_1/\beta}$。

同样的步骤给出：

| $V_{in}$ (V) | $V_{SB}$ (V) | $V_{TH}$ (V) | $V_{out}$ (V) | 斜率 $dV_{out}/dV_{in}$ |
|---|---|---|---|---|
| 0 | 1.79 | 1.011 | 1.21 | −0.12 |
| 0.5 | 1.35 | 0.948 | 1.15 | −0.13 |
| 1.0 | 0.92 | 0.880 | 1.08 | −0.14 |
| 1.5 | 0.50 | 0.805 | 1.00 | −0.16 |
| 2.1 | 0 | 0.700 | 0.90 | −0.19 |
| 2.5 | −0.32 | 0.617 | ≈ 0.82 | −0.23 |

### 第 4 步 — 范围上段：正向偏置的源-衬底结

当 $V_{in} > V_S$ 时（示例中约高于 2.1 V），p 型衬底的电位高于 n+ 源区，因此源-衬底结**正向偏置**（$V_{SB} < 0$）。

- 正向偏压在几百毫伏以内时（$V_{in} = 2.5$ V 时约为 0.3 V），结电流可以忽略，上面的公式仍是合理的估算：阈值电压继续下降，$V_{out}$ 也继续下降，而且越来越陡。
- 当正向偏压接近 0.6–0.7 V 时（趋近 $V_{in} = 3$ V 时；公式在该处给出约 0.68 V），该结大量导通，直接从 $V_{in}$ 提供 $I_1$ 的很大一部分，把它从沟道中分走。源极被拉高到约等于 $V_{in}$ 减去一个二极管压降，$V_{out}$ 进一步下降，体效应公式不再有意义。
- 漏-衬底结保持截止，因为漏极为 3 V $\ge V_{in}$。

### 结果

$M_1$ 为二极管连接（始终处于饱和区），并流过 $I_1$，因此

$$V_{out} = V_{GS} = V_{TH}(V_{SB}) + \sqrt{\frac{2I_1}{\beta}}, \qquad V_{SB} = V_S - V_{in} = (3 - V_{out}) - V_{in}.$$

- $V_{out}$ 随 $V_{in}$ 升高而**下降**，因为升高衬底电位会减小 $V_{SB}$，从而降低 $V_{TH}$。
- 斜率为 $-\eta/(1 + \eta)$，其中 $\eta = \gamma/(2\sqrt{2|\phi_F| + V_{SB}})$，因此 $V_{SB}$ 越接近零，下降越陡（向下凹）。
- 当 $V_{in}$ 等于源极电压（$V_{SB} = 0$）时，$V_{out}$ 达到 $V_{TH0} + \sqrt{2I_1/\beta}$。示例，取 $\sqrt{2I_1/\beta} = 0.2$ V：$V_{in} = 0$ 时为 1.21 V（$V_{SB} \approx 1.79$ V），1 V 时为 1.08 V，1.5 V 时为 1.00 V，2.1 V 时为 0.90 V（$V_{SB} = 0$），2.5 V 时 ≈ 0.82 V（正向偏压 ≈ 0.3 V）。
- 超过该点后，源-衬底结正向偏置。在接近范围顶端时，它大量导通，把 $I_1$ 从沟道中分走，MOS 模型不再适用。

**常见错误。** 因为二极管连接的器件流过固定电流，就断定 $V_{out}$ 恒定。过驱动电压确实固定，但 $V_{TH}$ 依赖于 $V_{SB}$，而后者会被 $V_{in}$ 通过衬底直接改变。

**常见错误。** 把符号弄反。把 NMOS 的衬底电位向源极抬高会**降低**阈值电压，因此 $V_{out}$ 随 $V_{in}$ 减小。

**常见错误。** 把体效应公式一直用到 $V_{in} = 3$ V。一旦衬底比源极高出约 0.5–0.6 V 以上，源-衬底结就会导通，平方律（square law）/体效应的描述随之失效。
