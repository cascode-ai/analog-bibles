# 详细步骤 - R429

**思路。** 共源共栅（cascode）管 $M_3$、$M_4$ 把输入对管的漏极钳定在 $V_{b1} - V_{GS3}$，与输入无关。提高输入共模电平会使 $M_1$、$M_2$ 的栅极升高，而它们的漏极保持不变，因此最高输入共模电平就是 $M_1$ 到达饱和边缘时的电平。

### 第 1 步 — 输入器件的漏极电压

每条支路的电流为 $I_{SS}/2 = 0.5$ mA，所有器件的 $W/L = 100/0.5 = 200$，且没有体效应：

$$V_{OD3} = \sqrt{\frac{2I_D}{\mu_nC_{ox}(W/L)}} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{(134\ \mu\mathrm{A/V^2})(200)}} = \sqrt{0.0373\ \mathrm{V^2}} = 0.193\ \mathrm{V},$$

$$V_{GS3} = V_{TH} + V_{OD3} = 0.7 + 0.193 = 0.893\ \mathrm{V}.$$

$M_3$ 的源极，即 $M_1$ 的漏极，比 $V_{b1}$ 低一个 $V_{GS3}$：

$$V_{D1} = V_{b1} - V_{GS3} = 1.7 - 0.893 = 0.807\ \mathrm{V},$$

$M_2$ 经 $M_4$ 也是如此。由于 $M_3$ 的电流固定为 0.5 mA，这一电压不随输入共模电平变化。

### 第 2 步 — $M_1$ 的饱和限制

只要 $V_{D1} \ge V_{G1} - V_{TH1}$，$M_1$ 就处于饱和，其栅极电压为 $V_{in,CM}$：

$$
\begin{aligned}
V_{D1} &\ge V_{in,CM} - V_{TH1}\\
V_{in,CM} &\le V_{D1} + V_{TH1} = V_{b1} - V_{GS3} + V_{TH1}\\
&= 0.807 + 0.7 = 1.507\ \mathrm{V}.
\end{aligned}
$$

$$V_{in,CM,max} \approx 1.51\ \mathrm{V}.$$

利用 $V_{GS3} = V_{TH} + V_{OD3}$，上式就是 $V_{in,CM,max} = V_{b1} - V_{OD3}$。提高 $V_{in,CM}$ 会使差分对（differential pair）的源极节点升高同样的量（尾电流固定，$V_{GS1}$ 固定），从而使 $V_{DS1}$ 减小，直到 $M_1$ 退出饱和。

### 第 3 步 — 附带检查：其他器件

- **$M_3$：** 其漏极是节点 X（$M_3$/$M_5$ 的漏极、$M_7$ 的栅极），电压为 $V_X = V_{DD} - |V_{GS7}|$。由 $|V_{OD7}| = \sqrt{2(0.5\ \mathrm{mA})/((38.4\ \mu\mathrm{A/V^2})(200))} = 0.361$ V 得 $|V_{GS7}| = 1.161$ V，$V_X = 3 - 1.161 = 1.84$ V。$M_3$ 要求 $V_X \ge V_{b1} - V_{TH} = 1.0$ V。✓ 这与 $V_{in,CM}$ 无关。
- **尾电流源：** 是理想的，因此输入范围的下端不在本题讨论之列。

因此上限由输入对管决定。

### 结果

$$V_{in,CM,max} = V_{b1} - V_{GS3} + V_{TH1} = 1.7 - 0.893 + 0.7 \approx 1.51\ \mathrm{V},$$

它由 $M_1$（以及 $M_2$）到达饱和边缘决定，因为它们的漏极被共源共栅管钳定在 $V_{b1} - V_{GS3} = 0.807$ V。

**常见错误。** 把 $V_{b1} - V_{GS3} = 0.807$ V 或 $V_{b1} = 1.7$ V 当作极限。NMOS 的栅极可以比其漏极高出一个**阈值电压**，器件仍不退出饱和。

**常见错误。** 把这一结果当作下限。输入越高，差分对越趋向线性区（triode region），因此这是**最高**电平。

**常见错误。** 用 $W/L = 100$ 代替 $100\ \mu\mathrm{m}/0.5\ \mu\mathrm{m} = 200$，这会得到 $V_{OD3} = 0.273$ V，极限约为 1.43 V。
