# 详细步骤 - R259

**思路。** $I_{REF}$ 固定时，各过驱动电压（overdrive voltage）也随之固定，因此扫描共源共栅（cascode）栅极电压 $V_b$ 的问题，就归结为确定在扫描的两端分别是哪个晶体管退出饱和区。采用平方律模型并计入 $M_3$ 和 $M_4$ 的体效应，先找出所有器件都饱和的“正常”窗口，再分析低于和高于该窗口时的电路行为。

### 第 1 步 — 符号与饱和条件

定义在固定电流 $I_{REF}$ 下饱和时的过驱动电压：

$$v_L = \sqrt{\frac{2I_{REF}}{\beta_{12}}} \ \ (M_1, M_2), \qquad v_U = \sqrt{\frac{2I_{REF}}{\beta_{34}}} \ \ (M_3, M_4),$$

其中 $\beta_{12} = \mu_nC_{ox}(W/L)_{1,2}$，$\beta_{34} = \mu_nC_{ox}(W/L)_{3,4}$。共源共栅器件的衬底接地，因此当源极电压为 $s$ 时

$$V_{TH}(s) = 0.7 + 0.45\left(\sqrt{0.9 + s} - \sqrt{0.9}\right)\ \mathrm{V}.$$

饱和条件：

- $M_2$：$V_A \ge V_X - 0.7$。
- $M_4$：$V_X - V_A \ge V_b - V_A - V_{TH}(V_A)$，即 $V_X \ge V_b - V_{TH}(V_A)$。
- $M_3$：$V_{DD} - V_B \ge V_b - V_B - V_{TH}(V_B)$，即 $V_b \le V_{DD} + V_{TH}$，这在扫描到 $V_{DD}$ 的整个范围内都成立，因此 **$M_3$ 始终饱和**。

只要 $M_3$ 和 $M_4$ 都饱和（$\lambda = 0$），两条支路就是栅极电压相同的相同电路，因此无论 $M_1$ 和 $M_2$ 处于哪个工作区，都精确地有 $V_A = V_B$ 和 $I_{out} = I_{REF}$：在每条支路中，上方器件的电流随中间节点电压升高而减小，下方器件的电流则增大或保持不变，因此中间节点电压是唯一的。

### 第 2 步 — 正常区域：所有晶体管都饱和

**$V_X$。** $M_2$ 在饱和区中流过 $I_{REF}$：

$$V_X = V_{GS2} = 0.7 + v_L = \text{constant},$$

与 $V_b$ 无关。

**$V_A = V_B$。** $M_4$ 在饱和区中流过 $I_{REF}$，因此 $V_{GS4} = V_{TH}(V_A) + v_U$ 是固定的：

$$V_A = V_b - V_{GS4} \quad\Longleftrightarrow\quad V_A + V_{TH}(V_A) = V_b - v_U .$$

$M_4$ 起源极跟随器（source follower）的作用，因此 $V_A$ 跟随 $V_b$ 变化。令 $\eta = dV_{TH}/dV_A = \gamma/(2\sqrt{0.9 + V_A})$：

$$(1 + \eta)\,dV_A = dV_b \quad\Longrightarrow\quad \frac{dV_A}{dV_b} = \frac{1}{1 + \eta} \approx \frac{1}{1 + 0.19} \approx 0.84 .$$

斜率略小于 1，因为 $V_A$ 升高时体效应使 $V_{TH4}$ 增大。

**$I_{out}$。** $M_1$ 与 $M_2$ 的 $V_{GS}$ 相同且处于饱和区，因此 $I_{out} = I_{REF}$。

### 第 3 步 — 下边界：$M_2$ 进入线性区

只要 $V_A \ge V_X - 0.7 = v_L$，$M_2$ 就保持饱和。在 $V_A + V_{TH}(V_A) = V_b - v_U$ 中令 $V_A = v_L$，即得正常区域的下边界：

$$V_{b,low} = v_L + V_{TH}(v_L) + v_U ,$$

即一个阈值电压（threshold voltage）加两个过驱动电压，这正是我们熟悉的低压共源共栅结构的最低偏置。

### 第 4 步 — $V_b$ 较低：$M_2$（以及 $M_1$）处于线性区，$V_X$ 急剧上升

当 $V_b < V_{b,low}$ 时，$V_A < v_L$，$M_2$ 处于线性区。$M_4$ 仍然饱和，因此 $V_A$ 仍满足 $V_A + V_{TH}(V_A) = V_b - v_U$，并随 $V_b$ 继续下降。$M_2$ 必须以更小的 $V_{DS}$ 流过同样的 $I_{REF}$，因此其栅极电压必须升高：

$$
\begin{aligned}
I_{REF} &= \beta_{12}\left[(V_X - 0.7)V_A - \tfrac12V_A^2\right]\\
V_X - 0.7 &= \frac{I_{REF}}{\beta_{12}V_A} + \frac{V_A}{2} = \frac{v_L^2}{2V_A} + \frac{V_A}{2}\\
V_X &= 0.7 + \frac{v_L^2 + V_A^2}{2V_A}, \qquad \text{using } I_{REF}/\beta_{12} = v_L^2/2 .
\end{aligned}
$$

当 $V_A = v_L$ 时，上式给出 $0.7 + v_L$，与平坦区域连续衔接。当 $V_A \to 0$ 时，$V_X \to \infty$；当 $V_b - v_U = V_{TH}(0) = 0.7$ V 时 $V_A$ 降到 0，即在

$$V_b \to 0.7 + v_U .$$

- **理想电流源：** 当 $V_b \to 0.7 + v_U$ 时 $V_X$ 发散，低于该值则不存在直流解。
- **实际电流源：** 节点 X 在 $V_{DD}$ 附近失去电压余度，参考电流本身下降，$I_{out}$ 也随之下降，当 $V_b$ 降向 $V_{TH}$ 时降为零。

在整个区域内 $M_3$ 和 $M_4$ 都饱和，因此仍有 $V_A = V_B$ 和 $I_{out} = I_{REF}$（只要电流源能提供 $I_{REF}$）。

### 第 5 步 — 上边界：$M_4$ 进入线性区

只要 $V_X \ge V_b - V_{TH}(V_A)$，$M_4$ 就保持饱和。在正常区域中，$V_X = 0.7 + v_L$，$V_A = V_b - V_{TH}(V_A) - v_U$。在边界处 $V_b - V_{TH}(V_A) = V_X$，因此 $V_A = V_X - v_U$，且

$$V_{b,high} = V_{GS2} + V_{TH}\!\left(V_{GS2} - v_U\right).$$

此时 $M_4$ 的漏源电压 $V_X - V_A$ 恰好等于其过驱动电压 $v_U$。

只有当 $V_{b,high} > V_{b,low}$ 时正常窗口才存在。尺寸相同时（$v_L = v_U = v$），两者之差为 $0.7 - v + V_{TH}(0.7) - V_{TH}(v)$，当 $v$ 低于约 0.7 V（通常情况）时该差值为正。

### 第 6 步 — $V_b$ 较高：$V_A$ 变平，$V_B$ 继续上升

当 $V_b > V_{b,high}$ 时，$M_4$ 处于线性区。$M_2$ 此时稳稳地处于饱和区（其漏极电压 $V_A$ 较高），因此 $V_X = 0.7 + v_L$ 保持平坦。$M_4$ 以很小的漏源电压流过 $I_{REF}$：

$$I_{REF} = \beta_{34}\left[(V_b - V_A - V_{TH}(V_A))(V_X - V_A) - \tfrac12(V_X - V_A)^2\right] \ \Longrightarrow\ V_X - V_A \approx \frac{I_{REF}}{\beta_{34}\,(V_b - V_A - V_{TH})} .$$

随着 $V_b$ 增大，$M_4$ 的过驱动电压增大，$V_X - V_A$ 减小，因此 **$V_A$ 在略低于 $V_X = V_{GS2}$ 处变平**：$M_4$ 的行为就像一个连接 A 和 X 的闭合开关。

然而 $M_3$ 仍然饱和（其漏极接 $V_{DD}$），因此

$$V_B + V_{TH}(V_B) = V_b - v_U :$$

**$V_B$ 继续上升**，斜率为 $1/(1 + \eta)$，此时 $V_B > V_A$。$M_1$ 的 $V_{DS1} = V_B > V_A > v_L$，因此它在 $V_{GS1} = V_X$ 下处于饱和区，故仍有 $I_{out} = I_{REF}$（$\lambda = 0$ 时如此；若 $\lambda > 0$，$V_{DS1} > V_{DS2}$ 会使 $I_{out}$ 略大）。

### 第 7 步 — 数值示例

取所有器件 $W/L = 20/0.5$，$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，因此 $\beta_{12} = \beta_{34} = 5.36\ \mathrm{mA/V^2}$，并取 $I_{REF} = 100\ \mu\mathrm{A}$：

$$
\begin{aligned}
v_L = v_U &= \sqrt{2(100\ \mu\mathrm{A})/(5.36\ \mathrm{mA/V^2})} = \sqrt{0.0373}\ \mathrm{V} = 0.193\ \mathrm{V},\\
V_{GS2} &= 0.7 + 0.193 = 0.893\ \mathrm{V},\\
V_{TH}(v_L) &= 0.7 + 0.45\left(\sqrt{1.093} - 0.949\right) = 0.744\ \mathrm{V},\\
V_{b,low} &= 0.193 + 0.744 + 0.193 = 1.13\ \mathrm{V},\\
V_{TH}(V_{GS2} - v_U) &= V_{TH}(0.700) = 0.7 + 0.45\left(\sqrt{1.6} - 0.949\right) = 0.842\ \mathrm{V},\\
V_{b,high} &= 0.893 + 0.842 = 1.74\ \mathrm{V},\\
\text{divergence of } V_X: \ V_b &\to 0.7 + v_U = 0.89\ \mathrm{V}.
\end{aligned}
$$

求解完整的平方律方程：

| $V_b$ (V) | $V_X$ (V) | $V_A$ (V) | $V_B$ (V) | $I_{out}$ | 工作区 |
|---|---|---|---|---|---|
| 0.92 | 1.57 | 0.022 | 0.022 | 100 μA | $M_2$ 线性区 |
| 0.95 | 1.13 | 0.046 | 0.046 | 100 μA | $M_2$ 线性区 |
| 1.00 | 0.96 | 0.087 | 0.087 | 100 μA | $M_2$ 线性区 |
| 1.13 | 0.893 | 0.193 | 0.193 | 100 μA | 下边界 |
| 1.40 | 0.893 | 0.417 | 0.417 | 100 μA | 全部饱和 |
| 1.60 | 0.893 | 0.585 | 0.585 | 100 μA | 全部饱和 |
| 1.74 | 0.893 | 0.700 | 0.700 | 100 μA | 上边界 |
| 2.00 | 0.893 | 0.826 | 0.926 | 100 μA | $M_4$ 线性区 |
| 2.50 | 0.893 | 0.868 | 1.358 | 100 μA | $M_4$ 线性区 |
| 3.00 | 0.893 | 0.878 | 1.795 | 100 μA | $M_4$ 线性区 |

在正常窗口内，$V_A$ 的斜率为 $(0.585 - 0.417)/0.2 = 0.84$，与 $1/(1 + \eta)$ 吻合。

### 结果

三个区域（通常的尺寸，$v_U = \sqrt{2I_{REF}/\beta_{34}} < 0.7$ V，扫描至 $V_b \approx V_{DD}$）：

- **正常区域**，$v_L + V_{TH}(v_L) + v_U \lesssim V_b \lesssim V_{GS2} + V_{TH}(V_{GS2} - v_U)$，所有器件都饱和：$V_X = V_{GS2} = 0.7 + \sqrt{2I_{REF}/\beta_{12}}$（平坦）；$V_A = V_B = V_b - V_{GS4}$，以斜率 $1/(1 + \eta) \approx 0.8$ 上升；$I_{out} = I_{REF}$。
- **$V_b$ 较低：** $M_2$ 和 $M_1$ 处于线性区，$V_A = V_B$ 仍随 $V_b$ 下降，$V_X = 0.7 + (v_L^2 + V_A^2)/(2V_A)$ 急剧上升。对于理想电流源，当 $V_b \to 0.7 + v_U$ 时它发散。对于实际电流源，节点 X 在 $V_{DD}$ 附近失去电压余度，随后当 $V_b \to V_{TH}$ 时，参考电流和 $I_{out}$ 都跌向零。
- **$V_b$ 较高：** $M_4$ 处于线性区，因此 $V_A$ 在略低于 $V_{GS2}$ 处变平，而 $V_B = V_b - V_{GS3}$ 继续上升（$M_3$ 的漏极接 $V_{DD}$，因而保持饱和）。$M_1$ 保持饱和，因此 $I_{out} = I_{REF}$（$\lambda = 0$ 时）。
- **只要解存在，就有 $I_{out} = I_{REF}$。**
- **示例**（所有器件 $\beta = 5.36\ \mathrm{mA/V^2}$，$I_{REF} = 100\ \mu\mathrm{A}$）：$V_b \gtrsim 1.13$ V 时 $V_X = 0.89$ V；$V_b = 1.2$、1.4、1.6 V 时 $V_A = V_B \approx 0.25$、0.42、0.59 V；高于约 1.74 V 后，$V_A \approx 0.83$–0.88 V，而 $V_b = 2$、2.5、3 V 时 $V_B \approx 0.93$、1.36、1.80 V。

**常见错误。** 让 $V_X$ 跟随 $V_b$ 变化。在正常区域和高端区域，$V_X$ 是 $M_2$ 在固定电流 $I_{REF}$ 下的栅源电压，与 $V_b$ 无关；只有在低端 $V_X$ 才会变化，而且 $V_b$ **下降**时它反而**上升**，因为 $M_2$ 被挤入线性区。

**常见错误。** 在 $V_b$ 较高时把 $V_B$ 和 $V_A$ 一起钳位（clamp）。只有 $M_4$ 进入线性区，因为它的漏极是 X，电压为较低的 $V_{GS2}$；$M_3$ 的漏极接 $V_{DD}$，因此 $V_B$ 继续跟随 $V_b$。

**常见错误。** 认为 $I_{out}$ 与 $V_b$ 成正比。$I_{out}$ 由 $M_1$ 的栅极电压 $V_X$ 决定；$V_b$ 只决定 $M_1$ 和 $M_2$ 的漏极电压，而在 $\lambda = 0$ 时，只要 $M_1$ 饱和或与 $M_2$ 匹配，漏极电压就无关紧要。
