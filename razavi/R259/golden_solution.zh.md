在通常的尺寸下（$v_U = \sqrt{2I_{REF}/\beta_{34}} < 0.7$ V，扫描至 $V_b \approx V_{DD}$），曲线分为三个区域。只要解存在，就有 $I_{out} = I_{REF}$；$V_X$ 在低端非常高，随后下降，然后保持平坦，等于 $V_{GS2} = 0.7 + v_L$（$v_L = \sqrt{2I_{REF}/\beta_{12}}$）；$V_A = V_B = V_b - V_{GS4}$ 以略小于 1 的斜率一同上升，之后 $V_A$ 在略低于 $V_{GS2}$ 处变平，而 $V_B$ 继续上升。这里 $\beta_{12}$、$\beta_{34}$ 分别是 $M_{1,2}$ 和 $M_{3,4}$ 的 β，对 $M_3$、$M_4$ 有 $V_{TH}(s) = 0.7 + 0.45(\sqrt{0.9 + s} - \sqrt{0.9})$。

- 正常区域 $v_L + V_{TH4}(v_L) + v_U \lesssim V_b \lesssim V_{GS2} + V_{TH4}(V_{GS2} - v_U)$：所有器件都工作在饱和区（saturation region）。$V_X = V_{GS2}$（平坦）；由于体效应（body effect），$V_A = V_B = V_b - V_{GS4}$ 以斜率 $1/(1+\eta) \approx 0.8$ 上升；$I_{out} = I_{REF}$。
- $V_b$ 较低时：$V_A < v_L$，$M_2$（以及 $M_1$）处于线性区（triode region），$V_X = 0.7 + (v_L^2 + V_A^2)/(2V_A)$ 必须升高才能维持 $I_{REF}$；仍有 $V_A = V_B$ 和 $I_{out} = I_{REF}$（$M_3$、$M_4$ 饱和，两条支路完全相同）。当 $V_b \to 0.7 + v_U$ 时，$V_A \to 0$，$V_X \to \infty$：低于该值，理想的 $I_{REF}$ 不存在直流解。对于实际的电流源，节点 X 在 $V_{DD}$ 附近会失去电压余度（headroom），参考电流和 $I_{out}$ 随之下降，当 $V_b$ 降向 $V_{TH}$ 时 $I_{out} \to 0$；对低端的这两种描述都是正确的。
- $V_b$ 较高时（高于 $V_{GS2} + V_{TH4}$）：$M_4$ 进入线性区，因此 $V_A$ 趋近 $V_{GS2}$ 并在略低于它的位置变平，而 $V_B = V_b - V_{GS3}$ 继续上升（只要 $V_b < V_{DD} + V_{TH3}$，漏极接 $V_{DD}$ 的 $M_3$ 就保持饱和，即在扫描到 $V_{DD}$ 的整个过程中都饱和；超过该值后，$V_B$ 将趋于平坦并逼近 $V_{DD}$）。$M_1$ 饱和，因此在 λ = 0 时 $I_{out} = I_{REF}$（若 λ > 0，$V_B > V_A$ 会使 $I_{out}$ 略大）。
- 若 $v_U > 0.7$ V（$M_{3,4}$ 非常小），全饱和窗口消失：$M_4$ 在 $M_2$ 饱和之前就进入线性区；当两者都处于线性区时，$V_B > V_A$，$I_{out}$ 会出现一个略高于 $I_{REF}$ 的小凸起，一旦 $M_2$ 饱和又回到 $I_{REF}$。
- 示例（所有 W/L = 20/0.5，取 $\mu_nC_{ox}$ = 134 μA/V² 时 β = 5.36 mA/V²，$I_{REF}$ = 100 μA；按平方律模型仿真）：$V_b \gtrsim 1.13$ V 时 $V_X$ = 0.89 V；$V_b$ = 1.2、1.4、1.6 V 时 $V_A = V_B$ ≈ 0.25、0.42、0.59 V；高于 ≈ 1.75 V 后，$V_A$ ≈ 0.83–0.88 V，而 $V_b$ = 2、2.5、3 V 时 $V_B$ ≈ 0.93、1.36、1.80 V；在低端，$V_b$ = 1.0 V 时 $V_X$ ≈ 0.96 V，0.95 V 时为 1.13 V，当 $V_b \to 0.89$ V 时发散（理想电流源）。
