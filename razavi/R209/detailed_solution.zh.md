# 详细步骤 - R209

**思路。** 没有对称性时，尾节点 P **不是**虚地（virtual ground），因此要写出整个电路的小信号方程：每条支路一个电流、节点电压 $v_P$、理想尾电流源给出的约束，以及计入体效应（body effect）的晶体管方程。消去 $v_P$ 即得支路电流，再由两个负载电阻得到输出。

### 第 1 步 — 未知量与尾电流源约束

把 $R_{S1}$、$R_{S2}$ 与尾电流源的公共节点记为 P。未知量为 $i_1$、$i_2$（**向下**流过 $M_1$、$M_2$ 的小信号漏极电流）、$v_P$ 以及源极电压 $v_{S1}$、$v_{S2}$；$V_{DD}$ 为交流地。在 $\lambda = 0$ 时，每个晶体管满足 $i_D = g_mv_{gs} + g_{mb}v_{bs}$，由于衬底接地，$v_{bs} = -v_s$。

尾电流源是**理想**电流源，其小信号电流为零，因此由 P 点的基尔霍夫电流定律（KCL）得

$$i_1 + i_2 = 0\quad\Longrightarrow\quad i_2 = -i_1 .$$

与两个独立的共源级（common-source stage）不同，$v_P$ 可以自由变化，其变化量恰好使总电流保持不变。

### 第 2 步 — 源极电压

$i_1$ 从 $M_1$ 的源极经 $R_{S1}$ 流入 P，$i_2$ 则经 $R_{S2}$ 流入 P：

$$v_{S1} = v_P + i_1R_{S1}, \qquad v_{S2} = v_P + i_2R_{S2} = v_P - i_1R_{S2}.$$

### 第 3 步 — 计入体效应的晶体管方程

对于 $M_1$，$v_{gs1} = v_{in1} - v_{S1}$，$v_{bs1} = 0 - v_{S1}$，因此

$$
\begin{aligned}
i_1 &= g_{m1}(v_{in1} - v_{S1}) + g_{mb1}(0 - v_{S1}) = g_{m1}v_{in1} - (g_{m1} + g_{mb1})v_{S1}\\
v_{S1} &= \frac{g_{m1}v_{in1} - i_1}{g_{m1} + g_{mb1}} .
\end{aligned}
$$

对 $M_2$ 同理，利用 $i_2 = -i_1$ 得：

$$v_{S2} = \frac{g_{m2}v_{in2} - i_2}{g_{m2} + g_{mb2}} = \frac{g_{m2}v_{in2} + i_1}{g_{m2} + g_{mb2}} .$$

体效应以 $g_m + g_{mb}$ 的形式出现：源极电压升高还会降低 $v_{bs}$，使阈值电压（threshold voltage）升高，因此源极的“反抗”比仅靠 $g_m$ 时更强。

### 第 4 步 — 消去 $v_P$ 并求解 $i_1$

将第 2 步的两个方程相减，消去 $v_P$：

$$v_{S1} - v_{S2} = i_1(R_{S1} + R_{S2}).$$

把第 3 步的表达式代入左边：

$$\frac{g_{m1}v_{in1} - i_1}{g_{m1} + g_{mb1}} - \frac{g_{m2}v_{in2} + i_1}{g_{m2} + g_{mb2}} = i_1(R_{S1} + R_{S2}),$$

$$\frac{g_{m1}}{g_{m1} + g_{mb1}}v_{in1} - \frac{g_{m2}}{g_{m2} + g_{mb2}}v_{in2} = i_1\left[R_{S1} + R_{S2} + \frac{1}{g_{m1} + g_{mb1}} + \frac{1}{g_{m2} + g_{mb2}}\right],$$

因此

$$i_1 = \frac{\dfrac{g_{m1}}{g_{m1} + g_{mb1}}v_{in1} - \dfrac{g_{m2}}{g_{m2} + g_{mb2}}v_{in2}}{R_{S1} + R_{S2} + \dfrac{1}{g_{m1} + g_{mb1}} + \dfrac{1}{g_{m2} + g_{mb2}}} .$$

### 第 5 步 — 输出电压

每个漏极电流都从 $V_{DD}$ 流过其负载电阻，因此

$$v_{D1} = -R_{D1}i_1, \qquad v_{D2} = -R_{D2}i_2 = +R_{D2}i_1 ,$$

$$v_{out} = v_{D1} - v_{D2} = -(R_{D1} + R_{D2})\,i_1,$$

$$V_{out} = -(R_{D1} + R_{D2})\,\frac{\dfrac{g_{m1}}{g_{m1} + g_{mb1}}V_{in1} - \dfrac{g_{m2}}{g_{m2} + g_{mb2}}V_{in2}}{R_{S1} + R_{S2} + \dfrac{1}{g_{m1} + g_{mb1}} + \dfrac{1}{g_{m2} + g_{mb2}}} .$$

两个负载电阻都出现在结果中，是因为**同一个**电流 $i_1$ 从一边流出、又流入另一边。

### 第 6 步 — 增益 $V_{out}/(V_{in1} - V_{in2})$

若 $g_{m1}/(g_{m1} + g_{mb1}) \ne g_{m2}/(g_{m2} + g_{mb2})$，共模输入也会产生一定的输出，因此输出不只是 $V_{in1} - V_{in2}$ 的函数。当两边的体效应比值相同，即 $g_{mb1}/g_{m1} = g_{mb2}/g_{m2} = \eta$ 时（晶体管处于相同的阱和偏置条件下），增益才有明确的定义。此时两边都有 $g_m/(g_m + g_{mb}) = 1/(1 + \eta)$，因此

$$
\begin{aligned}
\frac{V_{out}}{V_{in1} - V_{in2}} &= -\frac{R_{D1} + R_{D2}}{1 + \eta}\cdot\frac{1}{R_{S1} + R_{S2} + \dfrac{1}{g_{m1}(1 + \eta)} + \dfrac{1}{g_{m2}(1 + \eta)}}\\
&= -\frac{R_{D1} + R_{D2}}{(1 + \eta)(R_{S1} + R_{S2}) + \dfrac{1}{g_{m1}} + \dfrac{1}{g_{m2}}} .
\end{aligned}
$$

**检验：**

- **无体效应**（$\eta = 0$）：$-\dfrac{R_{D1} + R_{D2}}{R_{S1} + R_{S2} + 1/g_{m1} + 1/g_{m2}}$。
- **对称情形**（两边的 $R_D$、$R_S$、$g_m$ 都相等）：$-\dfrac{2R_D}{2(1 + \eta)R_S + 2/g_m} = -\dfrac{R_D}{(1 + \eta)R_S + 1/g_m}$，即我们熟悉的带源极负反馈（source degeneration）差分对的增益。
- **体效应：** $\eta > 0$ 会**增大**等效的源极负反馈 $(1 + \eta)(R_{S1} + R_{S2})$，因此会**减小**增益。

**数值感受：** $g_{m1} = 1$ mS，$g_{m2} = 2$ mS，$\eta = 0.2$，$R_{S1} = 1\ \mathrm{k}\Omega$，$R_{S2} = 2\ \mathrm{k}\Omega$，$R_{D1} = 10\ \mathrm{k}\Omega$，$R_{D2} = 20\ \mathrm{k}\Omega$：

$$\frac{V_{out}}{V_{in1} - V_{in2}} = -\frac{30\ \mathrm{k}\Omega}{1.2\times3\ \mathrm{k}\Omega + 1\ \mathrm{k}\Omega + 0.5\ \mathrm{k}\Omega} = -\frac{30}{5.1} = -5.9 .$$

### 结果

$$V_{out} = -(R_{D1} + R_{D2})\,\frac{\dfrac{g_{m1}}{g_{m1} + g_{mb1}}V_{in1} - \dfrac{g_{m2}}{g_{m2} + g_{mb2}}V_{in2}}{R_{S1} + R_{S2} + \dfrac{1}{g_{m1} + g_{mb1}} + \dfrac{1}{g_{m2} + g_{mb2}}},$$

若两边的体效应系数相等（两边都有 $g_{mb}/g_m = \eta$），则

$$\frac{V_{out}}{V_{in1} - V_{in2}} = -\frac{R_{D1} + R_{D2}}{(1 + \eta)(R_{S1} + R_{S2}) + 1/g_{m1} + 1/g_{m2}} .$$

若两边的 $g_m/(g_m + g_{mb})$ 不同，共模输入也会产生一定的输出，因此只有在 $\eta$ 相等或纯差分驱动的情况下，比值 $V_{out}/(V_{in1} - V_{in2})$ 才是精确的。

**常见错误。** 把 P 当作交流地，把每一边当作独立的带源极负反馈共源级来分析。没有对称性时 P 会移动，其移动量恰好迫使 $i_1 + i_2 = 0$，这就是两个 $R_S$ 和两个 $1/g_m$ 出现在同一个分母中的原因。

**常见错误。** 分子中只放一个负载电阻。向下流过左支路的电流 $i_1$ 正是从右支路流出的电流（$i_2 = -i_1$），因此 $V_{out}$ 中包含 $R_{D1} + R_{D2}$。

**常见错误。** 把 $g_{mb}$ 的符号弄反，使体效应反而增大增益。衬底接地时，源极电压升高会使 $v_{bs}$ 变负，从而减小漏极电流，因此体效应表现为乘在 $R_S$ 上的因子 $(1 + \eta)$。
