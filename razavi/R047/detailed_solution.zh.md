# 详细步骤 - R047

**思路。** 用输出端的电压表示 PMOS 的源栅电压，分别利用大信号（large-signal）平方律和小信号阻抗，考察 $I_1$ 如何随该电压变化。电流源需要电流**不**随端电压变化，即需要非常高的阻抗。

### 第 1 步 — 端电压：总是饱和

把输出端（PMOS 的源极）的电压记为 $V_{out}$。栅极和漏极都接地，因此

$$V_{SG} = V_{out} - 0 = V_{out}, \qquad V_{SD} = V_{out} - 0 = V_{out} .$$

由于 $V_{SD} = V_{SG} \ge V_{SG} - |V_{TH}|$，只要晶体管导通，它就处于饱和区，与题目所述一致：它是**二极管连接**的。

### 第 2 步 — 大信号电流：强烈依赖于 $V_{out}$

暂时忽略沟道长度调制（channel-length modulation），并令 $V_{SG} = V_{out}$，

$$I_1 = \frac12\,\mu_pC_{ox}\frac{W}{L}\,(V_{SG} - |V_{TH}|)^2 = \frac12\,\mu_pC_{ox}\frac{W}{L}\,(V_{out} - |V_{TH}|)^2 .$$

电流是**端电压的二次函数**。只有在 $V_{SG}$ 保持不变时，饱和才使电流对 $V_{SD}$ 不敏感；而这里端电压**就是** $V_{SG}$，因此 $V_{out}$ 的每一点变化都会一对一地改变栅极驱动。

**示例。** 假设 $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$W/L = 50$，$|V_{TH}| = 0.8$ V，衬底接源极。于是 $\mu_pC_{ox}W/L = 1.92\ \mathrm{mA/V^2}$，例如在 $V_{out} = 1.5$ V 时：

$$I_1 = \tfrac12(1.92\ \mathrm{mA/V^2})(1.5 - 0.8\ \mathrm{V})^2 = 0.96\times0.49\ \mathrm{mA} = 0.47\ \mathrm{mA}.$$

| $V_{out}$（V） | 1.0 | 1.2 | 1.5 | 2.0 | 2.5 |
|---|---|---|---|---|---|
| $I_1$（mA） | 0.038 | 0.154 | 0.47 | 1.38 | 2.77 |

$V_{out}$ 变化 1 V（从 1.5 V 到 2.5 V）会使这个“电流源”的电流变为原来的六倍，而真正的电流源会使 $I_1$ 几乎保持不变。

### 第 3 步 — 从端口看进去的小信号阻抗

在输出（源极）节点加一个小测试电压 $v_x$，栅极和漏极接地，求流入该节点的电流 $i_x$。晶体管等效为从漏极到源极的受控源 $g_mv_{gs}$ 与 $r_O$ 并联，其中 $v_{gs} = v_g - v_s = 0 - v_x = -v_x$。

<!-- diagram: diagram-01.cir -->

受控源从漏极到源极的电流为 $g_mv_{gs} = -g_mv_x$，即从源极到漏极为 $+g_mv_x$；$r_O$ 中从源极到漏极的电流为 $v_x/r_O$。在输出节点列 KCL：

$$i_x = g_mv_x + \frac{v_x}{r_O} ,$$

$$R_{out} = \frac{v_x}{i_x} = \frac{1}{g_m + 1/r_O} = \frac{1}{g_m}\parallel r_O \approx \frac{1}{g_m}\qquad(g_mr_O \gg 1).$$

由第 2 步也可得到同样的结果，因为 $dI_1/dV_{out} = \mu_pC_{ox}(W/L)(V_{out} - |V_{TH}|) = g_m$。若衬底（n 阱）接 $V_{DD}$ 而不是源极，$v_x$ 还会改变 $V_{BS}$，增加体效应电流 $g_{mb}v_x$，阻抗进一步降低为 $1/(g_m + g_{mb})\parallel r_O$。

**数值。** 在上述示例中，$V_{out} = 1.5$ V 时，$g_m = (1.92\ \mathrm{mA/V^2})(0.7\ \mathrm{V}) = 1.34$ mS，因此 $R_{out} \approx 1/g_m = 744\ \Omega$。在相同电流下，正确连接的 PMOS 电流源的 $R_{out} = r_O = 1/(\lambda I_D)$，例如当 $\lambda = 0.2\ \mathrm{V^{-1}}$ 时为 $1/[(0.2\ \mathrm{V^{-1}})(0.47\ \mathrm{mA})] = 10.6\ \mathrm{k}\Omega$，大约高 14 倍（器件更长时还要高得多）。

### 第 4 步 — 电流源需要什么

MOS 电流源需要：

1. $V_{GS}$（这里是 $V_{SG}$）由偏置网络**固定**，与输出电压无关；
2. 输出取自**漏极**，使输出电压只改变 $V_{DS}$，而电流对它不敏感（阻抗为 $r_O$）。

对于 PMOS：源极接 $V_{DD}$，栅极接固定偏置 $V_b$，输出取自漏极，于是 $I_D = \tfrac12\mu_pC_{ox}(W/L)(V_{DD} - V_b - |V_{TH}|)^2$，在一阶近似下与输出电压无关。图中的结构违反了这两个条件：输出是源极，而栅极以地为参考，因此 $V_{SG}$ 等于输出电压。

### 结果

该 PMOS 是**二极管连接**的（栅极和漏极都接地），并且它的**源极就是输出端**。由于 $V_{SD} = V_{SG}$，它总是处于饱和区，但其栅源电压就是输出电压本身：

$$I_1 = \tfrac12\mu_pC_{ox}\frac{W}{L}(V_{out} - |V_{TH}|)^2 ,$$

它随端电压按平方关系变化。等价地说，从端口看进去的阻抗只有 $1/g_m\parallel r_O \approx 1/g_m$（若衬底接 $V_{DD}$，则更低，为 $1/(g_m + g_{mb})$）。该结构的行为像一个非线性电阻（一个“二极管”），而不像电流源；电流源需要固定的 $V_{SG}$，并且输出取自漏极。

**常见错误。** 认为“晶体管处于饱和区，所以电流恒定”。饱和只是**在 $V_{GS}$ 固定时**才使 $I_D$ 与 $V_{DS}$ 无关；这里输出电压直接决定了 $V_{SG}$。

**常见错误。** 归咎于线性区（triode region）工作。由于 $V_{SD} = V_{SG}$，器件永远不会进入线性区；问题出在输出端的取法，而不在于工作区。

**常见错误。** 把器件误读为栅极偏置固定的 NMOS，或者把输出阻抗取为 $r_O$。输出位于二极管连接 PMOS 的源极，因此阻抗为 $1/g_m$，比 $r_O$ 小，大约相差本征增益（intrinsic gain）$g_mr_O$ 倍。
