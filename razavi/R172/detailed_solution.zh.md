# 详细步骤 - R172

**思路。** 所有晶体管都必须保持饱和。**下限**来自尾电流管，它两端需要有其过驱动电压：$V_{in,CM} \ge V_{GS1} + V_{ov,SS}$。**上限**来自输入器件，它们的漏极被二极管负载钉在 $V_{DD} - |V_{GS3}|$：$V_{in,CM} \le V_{DD} - |V_{GS3}| + V_{TH1}$。两种情况下，$V_{TH1}$ 都要计入相应尾节点电压下的体效应。

### 第 1 步 — 过驱动电压

平衡时每个输入器件和每个负载都流过 $I_{SS}/2 = 0.25$ mA，尾电流管流过 0.5 mA。

**输入器件** $M_1$、$M_2$，$\mu_nC_{ox}(W/L) = (134\ \mu\mathrm{A/V^2})(100) = 13.4\ \mathrm{mA/V^2}$：

$$V_{ov1} = \sqrt{\frac{2(0.25\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.0373\ \mathrm{V^2}} = 0.193\ \mathrm{V}.$$

**尾电流管**（NMOS，$W/L = 50/0.5$，0.5 mA）：

$$V_{ov,SS} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.0746\ \mathrm{V^2}} = 0.273\ \mathrm{V}.$$

**PMOS 负载** $M_3$、$M_4$，$\mu_pC_{ox}(W/L) = (38.4\ \mu\mathrm{A/V^2})(10/0.5) = (38.4\ \mu\mathrm{A/V^2})(20) = 0.768\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
|V_{GS3}| - |V_{TH3}| &= \sqrt{\frac{2(0.25\ \mathrm{mA})}{0.768\ \mathrm{mA/V^2}}} = \sqrt{0.651\ \mathrm{V^2}} = 0.807\ \mathrm{V},\\
|V_{GS3}| &= 0.8 + 0.807 = 1.607\ \mathrm{V}.
\end{aligned}
$$

尺寸小、迁移率（mobility）低的 PMOS 负载需要很大的过驱动电压，这一很大的二极管压降将限制上限。

### 第 2 步 — 最小输入共模电平

尾电流管只有在满足下式时才处于饱和：

$$V_P \ge V_{ov,SS} = 0.273\ \mathrm{V}.$$

由 $V_{in,CM} = V_P + V_{TH1} + V_{ov1}$，并且在该界限处 $V_{SB1} = 0.273$ V：

$$
\begin{aligned}
V_{TH1} &= V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB1}} - \sqrt{2|\phi_F|}\right)\\
&= 0.7 + 0.45\left(\sqrt{0.9 + 0.273} - \sqrt{0.9}\right)\\
&= 0.7 + 0.45(1.0831 - 0.9487) = 0.7 + 0.0605 = 0.761\ \mathrm{V}.
\end{aligned}
$$

因此

$$V_{in,CM,min} = V_{ov,SS} + V_{ov1} + V_{TH1} = 0.273 + 0.193 + 0.761 = 1.227\ \mathrm{V}.$$

### 第 3 步 — 二极管负载决定的漏极电位

每个二极管连接的 PMOS 流过 $I_{SS}/2$（由尾电流决定），且 $|V_{GS3}| = V_{DD} - V_X$，因此

$$V_X = V_Y = V_{DD} - |V_{GS3}| = 3 - 1.607 = 1.393\ \mathrm{V},$$

它与输入共模电平无关。（负载始终处于饱和，因为 $V_{SD} = V_{SG}$。）

### 第 4 步 — 最大输入共模电平

若 $V_{DS1} \ge V_{GS1} - V_{TH1}$，则 $M_1$ 饱和；由 $V_{DS1} = V_X - V_P$ 和 $V_{GS1} = V_{in,CM} - V_P$：

$$V_X - V_P \ge V_{in,CM} - V_P - V_{TH1} \quad\Longrightarrow\quad V_{in,CM} \le V_X + V_{TH1} = V_{DD} - |V_{GS3}| + V_{TH1}.$$

$V_{TH1}$ 必须按该界限处的尾节点电压计算，此时 $V_{in,CM} = V_X + V_{TH1}$：

$$V_P = V_{in,CM} - V_{TH1} - V_{ov1} = V_X - V_{ov1} = 1.393 - 0.193 = 1.200\ \mathrm{V}.$$

由 $V_{SB1} = 1.200$ V：

$$
\begin{aligned}
V_{TH1} &= 0.7 + 0.45\left(\sqrt{0.9 + 1.200} - \sqrt{0.9}\right)\\
&= 0.7 + 0.45(1.4491 - 0.9487) = 0.7 + 0.2252 = 0.925\ \mathrm{V}.
\end{aligned}
$$

因此

$$V_{in,CM,max} = V_X + V_{TH1} = 1.393 + 0.925 = 2.318\ \mathrm{V}.$$

这里体效应的影响大得多，因为 $P$ 已升到 1.2 V；而且较高的阈值反而**有利**：它使栅极在 $M_1$ 离开饱和区之前可以比漏极高出更多。

### 第 5 步 — 电压分布汇总

| 物理量 | $V_{in,CM,min}$ 时 | $V_{in,CM,max}$ 时 |
|---|---|---|
| $V_P$ | 0.273 V（尾电流管处于饱和边缘） | 1.200 V |
| $V_{TH1}$ | 0.761 V | 0.925 V |
| $V_{GS1}$ | 0.954 V | 1.118 V |
| $V_X = V_Y$ | 1.393 V | 1.393 V（$M_1$ 处于饱和边缘） |
| $V_{in,CM}$ | **1.227 V** | **2.318 V** |

不考虑体效应时（始终取 $V_{TH1} = 0.7$ V），两个界限分别为 $0.273 + 0.193 + 0.7 = 1.17$ V 和 $1.393 + 0.7 = 2.09$ V。

### 结果

$$V_{in,CM,min} = V_{ov,SS} + V_{ov1} + V_{TH1} \approx 1.23\ \mathrm{V}, \qquad V_{in,CM,max} = V_{DD} - |V_{GS3}| + V_{TH1} \approx 2.32\ \mathrm{V}$$

（不考虑体效应时为 1.17 V 和 2.09 V）。其中 $V_{ov1} = 0.193$ V，$V_{ov,SS} = 0.273$ V，$|V_{GS3}| = 1.607$ V，在两个界限处 $V_{TH1} = 0.761$ V 或 0.925 V。

**常见错误。** 忽略二极管连接负载的过驱动电压，即把最大值取为 $V_{DD}$ 或 $V_{DD} - |V_{THP}| + V_{TH1}$。二极管 0.81 V 的过驱动电压使漏极降到 1.39 V，上限也随之降低同样的 0.81 V。

**常见错误。** 计算最小值时忽略尾电流管的电压余度（headroom），给出 $V_{GS1} \approx 0.89$–0.95 V。尾电流管需要 $V_P \ge 0.273$ V 才能保持为电流源。

**常见错误。** 用 $\mu_nC_{ox}$ 而不是 $\mu_pC_{ox}$ 计算二极管压降，而后者要低 3.5 倍；这正是负载过驱动电压如此之大的原因。
