# 详细步骤 - R350

**思路。** $M_1$ 是源极跟随器，其输出端还由 $M_2$ 供电：后者的栅极接固定偏置，它从输入节点抽取电流并送到输出端。在输出端（理想的 $I_1$ 相当于开路）列基尔霍夫电流定律（KCL）方程，用 $v_{in}$ 和噪声表示 $v_{out}$，从而得到输入被驱动时的 $\overline{V_{n,in}^2}$。为求 $\overline{I_{n,in}^2}$，再在开路的输入节点（计入 $R_G$）列 KCL 方程，求解后除以跨阻。

### 第 1 步 — 小信号模型（small-signal model）

- **$M_1$**（漏极接交流地）：它向输出端送入 $g_{m1}(v_{in} - v_{out}) + I_{n1}$，其中 $\overline{I_{n1}^2} = 4kT\gamma g_{m1}$。
- **$M_2$**（栅极接交流地，漏极接输入端，源极接输出端）：其漏源电流 $g_{m2}(0 - v_{out}) + I_{n2} = -g_{m2}v_{out} + I_{n2}$（$\overline{I_{n2}^2} = 4kT\gamma g_{m2}$）**从输入节点抽出，并送到输出端**。
- **$R_G$：** 接在输入端与交流地之间，其诺顿噪声 $I_{nG}$（$\overline{I_{nG}^2} = 4kT/R_G$）从 $V_{DD}$ 流入输入节点。
- **$I_1$：** 理想且无噪声，对交流信号相当于开路。

### 第 2 步 — 输出端的 KCL

$I_1$ 不承载交流电流，因此 $M_1$ 和 $M_2$ 送入的电流之和为零：

$$g_{m1}(v_{in} - v_{out}) + I_{n1} - g_{m2}v_{out} + I_{n2} = 0 ,$$

$$v_{out} = \frac{g_{m1}v_{in} + I_{n1} + I_{n2}}{g_{m1} + g_{m2}}. \tag{1}$$

从输出端看，$M_2$ 相当于一个接到交流地的电阻 $1/g_{m2}$ 加上一个噪声电流：它是跟随器的电阻性负载。

### 第 3 步 — 输入参考噪声电压（输入由信号源驱动）

输入端的理想信号源吸收 $R_G$ 的电流和 $M_2$ 的漏极电流，但 $M_2$ 的源极仍接在输出端，因此式 (1) 照样成立：增益为 $A_v = \dfrac{g_{m1}}{g_{m1} + g_{m2}}$，输出噪声为 $\dfrac{I_{n1} + I_{n2}}{g_{m1} + g_{m2}}$。两者相除得 $v_{n,in} = (I_{n1} + I_{n2})/g_{m1}$，由于各噪声源互不相关，

$$\overline{V_{n,in}^2} = \frac{4kT\gamma g_{m1} + 4kT\gamma g_{m2}}{g_{m1}^2} = 4kT\gamma\left(\frac{1}{g_{m1}} + \frac{g_{m2}}{g_{m1}^2}\right),$$

这与以电流源为负载、且该负载带有 $M_2$ 噪声的源极跟随器的结果相同。

### 第 4 步 — 输入开路时的输出噪声

在输入节点，电流经 $R_G$ 支路流入，经 $M_2$ 的漏极流出：

$$-\frac{v_{in}}{R_G} + I_{nG} = -g_{m2}v_{out} + I_{n2}\quad\Longrightarrow\quad v_{in} = R_G\left(I_{nG} + g_{m2}v_{out} - I_{n2}\right). \tag{2}$$

把式 (2) 代入乘以 $(g_{m1} + g_{m2})$ 后的式 (1)：

$$
\begin{aligned}
v_{out}(g_{m1} + g_{m2}) &= g_{m1}R_G\left(I_{nG} + g_{m2}v_{out} - I_{n2}\right) + I_{n1} + I_{n2}\\
v_{out}\left(g_{m1} + g_{m2} - g_{m1}g_{m2}R_G\right) &= g_{m1}R_G\,I_{nG} + I_{n1} + (1 - g_{m1}R_G)\,I_{n2}.
\end{aligned}
$$

$-g_{m1}g_{m2}R_G$ 项代表**正反馈**：若 $v_{out}$ 升高，$M_2$ 从输入节点抽取的电流减小，$v_{in}$ 升高，跟随器又把 $v_{out}$ 推得更高。环路增益 $L = g_{m1}g_{m2}R_G/(g_{m1} + g_{m2})$ 小于 1，因此分母为正，电路是稳定的。

### 第 5 步 — 跨阻与输入参考噪声电流

输入电流 $i_{in}$ 与 $I_{nG}$ 完全一样地进入输入节点，因此

$$R_T = \frac{v_{out}}{i_{in}} = \frac{g_{m1}R_G}{g_{m1} + g_{m2} - g_{m1}g_{m2}R_G}.$$

把 $v_{out}$ 中的噪声部分除以 $R_T$，分母被约去：

$$I_{n,eq} = \frac{g_{m1}R_GI_{nG} + I_{n1} + (1 - g_{m1}R_G)I_{n2}}{g_{m1}R_G} = I_{nG} + \frac{I_{n1}}{g_{m1}R_G} + \frac{1 - g_{m1}R_G}{g_{m1}R_G}\,I_{n2}.$$

三个噪声源互不相关；令 $x = g_{m1}R_G$，并利用 $\left(\frac{1 - x}{x}\right)^2 = \left(1 - \frac1x\right)^2$：

$$
\begin{aligned}
\overline{I_{n,in}^2} &= \frac{4kT}{R_G} + \frac{4kT\gamma g_{m1}}{g_{m1}^2R_G^2} + 4kT\gamma g_{m2}\left(\frac{1 - g_{m1}R_G}{g_{m1}R_G}\right)^2\\
&= \frac{4kT}{R_G} + \frac{4kT\gamma}{g_{m1}R_G^2} + 4kT\gamma g_{m2}\left(1 - \frac{1}{g_{m1}R_G}\right)^2 .
\end{aligned}
$$

### 第 6 步 — 物理解释

- **$R_G$** 把噪声直接注入输入节点，就像输入电流一样：权重为 1。
- **$M_1$：** 输入开路时，其折算到栅极的噪声 $I_{n1}/g_{m1}$ 必须由流过 $R_G$ 的电流产生：权重为 $1/(g_{m1}R_G)$。
- **$M_2$** 从输入节点**抽走** $I_{n2}$（权重为 $-1$），又把它**加到**输出端（权重为 $+1/(g_{m1}R_G)$）。这两种作用完全相关并部分抵消，得到 $(1 - 1/(g_{m1}R_G))^2$，当 $g_{m1}R_G = 1$ 时它为零。

### 结果

$$\overline{V_{n,in}^2} = 4kT\gamma\left(\frac{1}{g_{m1}} + \frac{g_{m2}}{g_{m1}^2}\right),\qquad \overline{I_{n,in}^2} = \frac{4kT}{R_G} + \frac{4kT\gamma}{g_{m1}R_G^2} + 4kT\gamma g_{m2}\left(1 - \frac{1}{g_{m1}R_G}\right)^2$$

- 电压（输入由信号源驱动）：增益为 $g_{m1}/(g_{m1} + g_{m2})$；$M_2$ 相当于跟随器的一个有噪声的负载，$R_G$ 只是输入信号源的负载。
- 电流（输入开路）：跨阻为 $g_{m1}R_G/(g_{m1} + g_{m2} - g_{m1}g_{m2}R_G)$；$I_{n,eq} = I_{nG} + I_{n1}/(g_{m1}R_G) + I_{n2}(1 - g_{m1}R_G)/(g_{m1}R_G)$。

**常见错误。** 在输入开路的条件下计算噪声电压，使 $R_G$ 或环路增益因子出现在结果中。输入由理想信号源驱动时，经 $M_2$ 漏极的反馈被断开，只剩下 $M_1$ 的噪声和 $M_2$ 在输出侧的噪声。

**常见错误。** 把跟随器的增益取为 1，并在噪声电压中略去 $M_2$ 的噪声。$M_2$ 的源极接在输出端：它以 $1/g_{m2}$ 作为跟随器的负载（增益为 $g_{m1}/(g_{m1} + g_{m2})$），并在那里注入 $I_{n2}$。

**常见错误。** 把 $M_2$ 对噪声电流的两部分贡献按功率相加，或以相同的符号相加。噪声电流从输入节点流出、流入输出节点，因此这两种作用应按幅值、以相反的符号相加，即 $(1 - 1/(g_{m1}R_G))$。
