# Golden Solution - R203

## Reference answer

$A_v \approx +g_{m1}\left(R_D\,\big\|\,R_{cas}\right)$, with $R_{cas} = r_{O5} + [1 + (g_{m5} + g_{mb5})r_{O5}](r_{O1}\|r_{O3})$; exactly, $A_v = \dfrac{g_{m1}(r_{O1}\|r_{O3})[1 + (g_{m5} + g_{mb5})r_{O5}]\,R_D}{R_D + R_{cas}}$. It is non-inverting. (The approximate form uses $(g_{m5}+g_{mb5})(r_{O1}\|r_{O3}) \gg 1$; it overestimates by the factor $R_{cas}/(R_{cas} - r_{O5})$, normally a few percent.)
- PMOS input pair; the drain of $M_1$ joins $M_3$ and the source of cascode $M_6$ (right output), the drain of $M_2$ joins $M_4$ and cascode $M_5$ (left output); $M_3$–$M_6$ have fixed gate bias.
- A positive $v_{in1}$ reduces the current of PMOS $M_1$ by $g_{m1}v_{in1}$ (P is a virtual ground), which increases the current of $M_6$ and lowers the right output; symmetrically the left output rises, so $V_{out} = V_{left} - V_{right}$ increases.
- Output resistance at each output: $R_D$ in parallel with the cascode $R_{cas}$ (the cascode degenerated by $r_{O1}\|r_{O3}$); the short-circuit transconductance is ≈ $g_{m1}$.

## Grading notes

+2: magnitude $g_{m1}(R_D\|R_{cas})$ with the correct $R_{cas}$ (including $r_{O1}\|r_{O3}$ at the cascode source), positive sign or a correct statement that the stage is non-inverting from $V_{in1}$ to $V_{out}$. +1: $g_{mb5}$ omitted, or the sign not addressed, or $R_{cas}$ approximated as $g_{m5}r_{O5}(r_{O1}\|r_{O3})$ with $R_D$ dominating. 0: correct structure but $R_{cas}$ missing $r_{O3}$ or $r_{O1}$. -2 (asserted as fact): gain $g_{m1}R_D$ with an inverting sign from a misread of the crossed connections and no cascode, $M_3$/$M_4$ treated as part of the signal path as diodes, or the PMOS input treated as NMOS with the sign therefore claimed inverting.
