- 半边电路（half circuit），P 处于交流地：节点 A = 输出端（$M_3$ 的漏极，$R_1$ 的上端），节点 B = $M_1$ 的漏极 = $M_3$ 的栅极（$R_1$ 的下端）。
- A 点的基尔霍夫电流定律（KCL）：$-g_{m3}v_B - v_A/r_{O3} = (v_A - v_B)/R_1$；B 点：$(v_A - v_B)/R_1 = g_{m1}v_{in} + v_B/r_{O1}$。求解即得上述结果。当 λ = 0 时：$v_B = -(g_{m1}/g_{m3})v_{in}$，$v_A = v_B(1 - g_{m3}R_1)$。
