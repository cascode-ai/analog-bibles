# 详细步骤 - R585

**思路。** 跟踪节点 X 上的总电荷。运放的高增益使 X 保持虚地（virtual ground），因此 X 上的任何电荷变化都必须出现在 $C_2$ 上，而 P 点的任何电压变化都以增益 $-C_1/C_2$ 复制到输出。按时间顺序跟踪各开关事件，在 X 点（以及 P 浮空时在 P 点）应用电荷守恒，再拼出完整波形。

### 第 1 步 — 开关误差模型与符号

开关 $S_j$（$j = 1, 2, 3$）的宽度为 $W_j$，长度为 $L_j$，每一侧的交叠电容（overlap capacitance）为 $W_jC_{ov}$。当它在两端电压为 $V_s$ 时关断，其沟道中电子的总电荷量大小为

$$q_j = W_jL_jC_{ox}\,(V_{DD} - V_s - V_{TH,j}),$$

其中比例为 $\alpha_j$ 的部分流向所关注的节点；同时其栅极下降 $V_{DD}$，向每一侧耦合 $-W_jC_{ov}V_{DD}$。两种效应送出的都是**负**电荷。送到低阻抗节点（运放输出端、输入源、地）的电荷被吸收，不产生影响。

设 $t_1$ 为 $S_2$ 关断的时刻，$V_{in0} = V_{in}(t_1)$，$V_{in1} = V_{in}(t_1 + \Delta t)$。

### 第 2 步 — 采样相位（$t < t_1$）

$S_2$ 把输出与 X 短接，因此运放跟随其接地的 + 输入端：

$$V_{out} = V_X = 0, \qquad V_P = V_{in}(t).$$

与 X 相连的各极板上的总电荷为

$$Q_X = C_1\,(V_X - V_P) + C_2\,(V_X - V_{out}) = C_1\,(0 - V_{in}) + C_2\,(0 - 0) = -C_1V_{in}.$$

**输出：** 在整个采样相位内 $V_{out} \approx 0$。

### 第 3 步 — $S_2$ 在 $t_1$ 时刻关断：恒定的正向台阶

$S_2$ 的两端（X 和输出端）都约为 0 V，因此

$$q_2 = W_2L_2C_{ox}\,(V_{DD} - 0 - V_{TH,2}),$$

它**与 $V_{in}$ 无关**。比例为 $1 - \alpha_2$ 的部分以及输出侧的馈通被运放输出端吸收；比例为 $\alpha_2$ 的部分落到 X 上，同时经 X 侧交叠电容耦合过来 $-W_2C_{ov}V_{DD}$。此后 X 没有任何导电路径，因此其电荷保持为

$$Q_X(t_1^+) = -C_1V_{in0} - \alpha_2q_2 - W_2C_{ov}V_{DD}.$$

运放通过 $C_2$ 使 $V_X = 0$，且 $V_P = V_{in0}$：

$$
\begin{aligned}
C_1\,(0 - V_{in0}) + C_2\,(0 - V_{out}) &= -C_1V_{in0} - \alpha_2q_2 - W_2C_{ov}V_{DD}\\
-C_2V_{out} &= -\alpha_2q_2 - W_2C_{ov}V_{DD}\\
V_{out} = \Delta V_2 &\equiv \frac{\alpha_2W_2L_2C_{ox}(V_{DD} - V_{TH,2}) + W_2C_{ov}V_{DD}}{C_2}.
\end{aligned}
$$

**输出：** 一个小的**向上**台阶 $\Delta V_2$：倾倒在 X 上的电子不能停留在那里（X 被保持在 0 V），因此运放通过抬高其输出把它们拉到 $C_2$ 上。由于 X 始终处于 0 V，$\Delta V_2$ 对任何输入电平都相同，是一个**恒定失调**。$t_1$ 才是真正的采样时刻。

### 第 4 步 — $t_1 < t < t_1 + \Delta t$：对输入变化而言的反相放大器

$S_1$ 仍导通，因此 P 跟随 $V_{in}(t)$，而 X 在 $V_X = 0$ 下保持第 3 步中的电荷：

$$
\begin{aligned}
C_1\,(0 - V_{in}(t)) - C_2V_{out}(t) &= -C_1V_{in0} - C_2\Delta V_2\\
V_{out}(t) &= \Delta V_2 - \frac{C_1}{C_2}\,\big[V_{in}(t) - V_{in0}\big].
\end{aligned}
$$

$t_1$ 之后的输入变化以增益 $-C_1/C_2$ 出现在输出端，因此对于插图中上升的输入，**$V_{out}$ 斜坡下降**，它是 $V_{in}$ 按 $C_1/C_2$ 缩放后的反相复制。在该区间结束时

$$V_{out}\big((t_1 + \Delta t)^-\big) = \Delta V_2 - \frac{C_1}{C_2}\,(V_{in1} - V_{in0}).$$

### 第 5 步 — $S_1$ 在 $t_1 + \Delta t$ 时刻关断：向上跳变，然后是平坦段

$S_1$ 的两端处于 $V_{in1}$，因此其沟道电荷**与输入有关**：

$$q_1 = W_1L_1C_{ox}\,(V_{DD} - V_{in1} - V_{TH,1}).$$

$\alpha_1q_1$ 以及馈通电荷 $-W_1C_{ov}V_{DD}$ 落到 P 上（其余部分流向输入源），而此时 P 处于浮空状态。P 的电容为 $C_1$，其另一极板是虚地 X（忽略其他寄生电容），因此 $V_P$ 下降

$$\Delta V_P = \frac{\alpha_1q_1 + W_1C_{ov}V_{DD}}{C_1}, \qquad V_P = V_{in1} - \Delta V_P.$$

X 上的电荷仍然守恒。$C_1$ 的 X 侧极板带电 $C_1(0 - V_P)$，增加了 $C_1\Delta V_P$，因此 $C_2$ 的 X 侧极板必须变化 $-C_1\Delta V_P$：

$$
\begin{aligned}
C_2\,\Delta(0 - V_{out}) &= -C_1\Delta V_P\\
\Delta V_{out} &= +\frac{C_1}{C_2}\,\Delta V_P .
\end{aligned}
$$

**输出：** 一个大小为 $(C_1/C_2)\Delta V_P$ 的**向上**跳变。在接下来的 $\Delta t$ 内，P 浮空，输入不再能到达电路，因此 $V_{out}$ **保持平坦**，其值为

$$V_{out} = \Delta V_2 - \frac{C_1}{C_2}\,(V_{in1} - V_{in0}) + \frac{C_1}{C_2}\,\Delta V_P .$$

### 第 6 步 — $S_3$ 在 $t_1 + 2\Delta t$ 时刻导通：建立到最终值

$S_3$ 把 P 接地。其沟道电荷和上升栅极的馈通主要由地提供，而且一旦它完全导通，P 就被强制为精确的 0 V，因此这些效应至多引起一个短暂的毛刺。

最终 $V_P = V_X = 0$，因此 $C_1$ 上没有电荷，X 上冻结的全部电荷都位于 $C_2$ 上：

$$
\begin{aligned}
C_1\,(0 - 0) + C_2\,(0 - V_{out}) &= -C_1V_{in0} - C_2\Delta V_2\\
V_{out,final} &= \frac{C_1}{C_2}\,V_{in0} + \Delta V_2 .
\end{aligned}
$$

从第 5 步的平坦电平到这一最终值的变化量为

$$\frac{C_1}{C_2}V_{in0} + \Delta V_2 - \left[\Delta V_2 - \frac{C_1}{C_2}(V_{in1} - V_{in0}) + \frac{C_1}{C_2}\Delta V_P\right] = \frac{C_1}{C_2}\,(V_{in1} - \Delta V_P),$$

即向上移动 P 所保持的电压乘以 $C_1/C_2$，这一过程伴随着运放的建立（或压摆）完成。

$\Delta V_P$、$V_{in1}$ 以及 $t_1$ 之后的一切都从最终值中消掉了，因为 X 的电荷在 $t_1$ 时刻已被冻结，而 $C_1$ 的两个极板最终都处于 0 V。只剩下 $S_2$ 与输入无关的注入，因此这种底极板（bottom-plate）开关时序使输出成为 $V_{in0}$ 的线性函数加上一个恒定失调。

### 第 7 步 — 要画出的波形

| 时间区间 | $V_{out}$ | 形状 |
|---|---|---|
| 采样，$t < t_1$ | $0$ | 平坦，处于虚地 |
| $t_1$ 时刻（$S_2$ 关断） | $0 \to \Delta V_2$ | 小的**向上**台阶，对任何输入都相同 |
| $t_1 \to t_1 + \Delta t$ | $\Delta V_2 - \dfrac{C_1}{C_2}[V_{in}(t) - V_{in0}]$ | 斜坡**下降**，是上升输入的反相复制 |
| $t_1 + \Delta t$ 时刻（$S_1$ 关断） | **向上**跳变 $\dfrac{C_1}{C_2}\Delta V_P$ | 与输入有关的跳变 |
| $t_1 + \Delta t \to t_1 + 2\Delta t$ | 恒定 | 平坦（P 浮空） |
| 从 $t_1 + 2\Delta t$ 开始（$S_3$ 导通） | 上升 $\dfrac{C_1}{C_2}(V_{in1} - \Delta V_P)$ | 短暂毛刺，随后向上建立/压摆 |
| 最终 | $\dfrac{C_1}{C_2}V_{in0} + \Delta V_2$ | 平坦 |

$\Delta V_2$ 和 $(C_1/C_2)\Delta V_P$ 都很小（对于小尺寸开关为毫伏量级），若 $\Delta t$ 很短，第一个 $\Delta t$ 内的斜坡也很小；最后上升到 $(C_1/C_2)V_{in0}$ 的过程才是携带信号的大幅跳变。

### 结果

$$V_{out,final} = \frac{C_1}{C_2}\,V_{in0} + \Delta V_2, \qquad \Delta V_2 \approx \frac{\alpha_2W_2L_2C_{ox}(V_{DD} - V_{TH}) + W_2C_{ov}V_{DD}}{C_2},$$

其中 $V_{in0}$ 是 $S_2$ 关断时刻的输入，$\Delta V_2$ 是与输入无关的失调（X 处于 0 V）。波形为：采样期间 $V_{out} \approx 0$；$S_2$ 断开时向上跳一个小台阶 $\Delta V_2$；$S_1$ 仍导通时出现斜坡下降 $-(C_1/C_2)[V_{in}(t) - V_{in0}]$；$S_1$ 断开时向上跳变 $(C_1/C_2)\Delta V_P$，随后是一段平坦段；$S_3$ 闭合时，（经压摆/建立）上升到最终值。$S_1$ 和 $S_3$ 的电荷注入以及 $S_2$ 断开后输入的变化都不会在最终值中留下痕迹。

**常见错误。** 认为最终输出取决于 $S_1$ 的电荷注入，或取决于 $S_1$ 关断时刻的输入。这些因素只在 X 的电荷被冻结时移动 P 的电压，而最终 P 被接地，因此它们被完全抵消；这正是让 $S_2$ 先关断的原因。

**常见错误。** 把台阶的极性弄反。X 上的负电荷会把 $V_{out}$ **向上**推（失调为 $+\Delta V_2$），而 $V_P$ 的下降经 $-C_1/C_2$ 反相，因此 $S_1$ 引起的跳变也是**向上**的。

**常见错误。** 把 $S_2$ 断开后的输出画成以正增益跟踪输入。由于 X 处于虚地而 P 仍被驱动，对于输入变化电路是一个反相放大器，因此在第一个 $\Delta t$ 内 $V_{out}$ 与 $V_{in}$ 的变化方向**相反**。
