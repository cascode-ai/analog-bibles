对于 [图 1] 所示的电路（$\lambda = \gamma = 0$；$R_F$ 和 $R_S$ 构成反馈网络），通过在节点 X 处断开环路来计算环路增益（loop gain）：令 $V_{in} = 0$，在 $M_2$ 的栅极施加测试电压，求返回到节点 X 的电压。为什么这一结果与 $g_{21}A_{v,open}$ 略有不同？其中 $g_{21} = R_S/(R_F+R_S)$，$A_{v,open} = \dfrac{R_{D1}}{R_F\|R_S + 1/g_{m1}}\,g_{m2}[R_{D2}\|(R_F+R_S)]$ 是用二端口方法（two-port method）求得的开环增益（open-loop gain）：输入侧的负载效应通过把 $R_F$ 的右端接地得到，输出侧的负载效应通过把 $R_F$ 的左端开路得到。
