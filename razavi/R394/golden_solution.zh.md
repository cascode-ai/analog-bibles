$T = \dfrac{g_{m1}g_{m2}R_{D1}R_{D2}R_S}{R_{D2} + R_F + R_S + g_{m1}R_S(R_{D2} + R_F)} = g_{m2}R_{D1}\left[R_{D2}\,\Big\|\,\left(R_F + R_S\|\tfrac{1}{g_{m1}}\right)\right]\dfrac{g_{m1}R_S}{R_F + R_S + g_{m1}R_FR_S}$，
而 $g_{21}A_{v,open} = g_{m2}R_{D1}[R_{D2}\|(R_F + R_S)]\dfrac{g_{m1}R_S}{R_F + R_S + g_{m1}R_FR_S}$。两者的输入侧因子完全相同，唯一的差别在于输出端的负载：实际环路看到的是 $R_F$ 与 $R_S\|(1/g_{m1})$ 串联，而二端口估算看到的是 $R_F + R_S$。因此 $T < g_{21}A_{v,open}$；例如，所有电阻均为 2 kΩ，$g_{m1}$ = 4.5 mS，$g_{m2}$ = 2.8 mS 时，T ≈ 2.4，而后者为 3.0。

原因：在栅极处断开环路（栅极不吸取电流）可以得到精确的回归比（return ratio）。二端口方法把反馈网络当作单向的（unilateral）：它对输出端呈现的负载 $g_{11}$ 是在其输出端口开路的条件下计算的，即假设没有电流流入 $M_1$ 的源极，同时还忽略了网络的反向传输（reverse transmission）$g_{12}$。实际上，网络的输出端口接的是 $M_1$ 的源极（≈ $1/g_{m1}$ 与 $R_S$ 并联），因此它从输出端吸取更多电流，而且 $M_1$ 源极处的信号还会经 $R_F$ 反向传播。这里前向放大器（forward amplifier）本身没有内部反馈（λ = 0，无 $C_{GD}$），因此差异完全来自这个双向的（bilateral）反馈网络。

T 的推导：在 $M_2$ 的栅极施加测试电压 $v_t$；$M_2$ 向节点 Y 注入 $-g_{m2}v_t$，Y 的负载为 $R_{D2}$ 以及 $R_F$ 与（$R_S \| 1/g_{m1}$）的串联（即栅极接地的 $M_1$ 的源极）；源极电压是 $v_Y$ 经 $R_F$/（$R_S\|1/g_{m1}$）分压后的部分；随后 $M_1$ 给出 $v_X = g_{m1}R_{D1}v_S$；$T = -v_X/v_t$。
