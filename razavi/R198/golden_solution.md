# Golden Solution - R198

## Reference answer

$A_v = -g_{m1}\left\{r_{O1}\,\big\|\,\left[R_1 + r_{O3} + (g_{m3} + g_{mb3})r_{O3}R_1\right]\right\} \approx -g_{m1}\{r_{O1}\|[(g_{m3} + g_{mb3})r_{O3}R_1]\}$.
- $M_3$ (gate at the fixed $V_{b2}$) is a PMOS current source degenerated by $R_1$; its output resistance is $R_{out3} = R_1 + r_{O3}[1 + (g_{m3} + g_{mb3})R_1]$ (body effect present because its source sits below the $V_{DD}$-connected bulk).
- $P$ is a virtual ground, so the half-circuit gain is $-g_{m1}(r_{O1}\|R_{out3})$; this is the differential gain.

## Grading notes

+2: correct degenerated output resistance with $g_{mb3}$, in parallel with $r_{O1}$. +1: $g_{mb3}$ omitted (body effect neglected), or the "+ $R_1$" term dropped. 0: $R_{out3}$ taken as $r_{O3}$ only (degeneration missed). -2 (asserted as fact): $R_1$ treated as a load resistor from output to $V_{DD}$ (gain $g_{m1}R_1$), $M_3$/$M_4$ treated as diode-connected, or $r_{O1}$ omitted together with a wrong $R_{out3}$.
