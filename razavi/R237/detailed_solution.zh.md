# 详细步骤 - R237

**思路。** 节点 X 直接驱动 $M_1$ 和 $M_2$ 的栅极，因此 $V_X = V_{GS1}$，由 $I_{REF}$ 决定。$V_b$ 通过 $M_0$ 设定节点 A 的电压，$V_A = V_b - V_{GS0}$；它必须足够高，使 $M_1$ 保持饱和（$V_A \ge V_{ov1}$），又必须足够低，使 $M_0$ 保持饱和（$V_X - V_A \ge V_{ov0}$）。$M_0$ 的源极比接地的衬底高 $V_A$，因此其阈值电压（threshold voltage）要计入体效应。

### 第 1 步 — $V_X$ 与两个过驱动电压

$(W/L)_1 = (W/L)_2 = 20/0.5 = 40$，$(W/L)_0 = (W/L)_3 = 60/0.5 = 120$。输出支路是基准支路的复制，因此只需分析基准支路；$M_1$ 和 $M_0$ 都流过 $I_{REF} = 100\ \mu$A。

$$V_{ov1} = \sqrt{\frac{2(100\ \mu\mathrm{A})}{(134\ \mu\mathrm{A/V^2})(40)}} = \sqrt{0.03731\ \mathrm{V^2}} = 0.193\ \mathrm{V}, \qquad V_X = V_{GS1} = 0.7 + 0.193 = 0.893\ \mathrm{V}$$

（$M_1$ 的 $V_{SB} = 0$；这要求 $M_1$ 处于饱和，即下面的第一个条件）。

$$V_{ov0} = \sqrt{\frac{2(100\ \mu\mathrm{A})}{(134\ \mu\mathrm{A/V^2})(120)}} = \sqrt{0.01244\ \mathrm{V^2}} = 0.112\ \mathrm{V} .$$

$M_0$ 的 $V_{SB0} = V_A$，因此

$$V_{TH0}(V_A) = 0.7 + 0.45\left(\sqrt{0.9 + V_A} - \sqrt{0.9}\right), \qquad \sqrt{0.9} = 0.9487 ,$$

$$V_A = V_b - V_{GS0} = V_b - V_{TH0}(V_A) - V_{ov0} .$$

提高 $V_b$ 会抬高 $V_A$，因此每个饱和条件都转化为 $V_b$ 的一个界限。

### 第 2 步 — 下限：$M_1$ 饱和

$V_{DS1} \ge V_{GS1} - V_{TH1}$ 意味着

$$V_A \ge V_{ov1} = 0.193\ \mathrm{V} .$$

在临界点 $V_A = 0.193$ V 处：

$$V_{TH0} = 0.7 + 0.45\left(\sqrt{0.9 + 0.193} - 0.9487\right) = 0.7 + 0.45(1.0455 - 0.9487) = 0.7 + 0.0436 = 0.744\ \mathrm{V} ,$$

$$V_{GS0} = V_{TH0} + V_{ov0} = 0.744 + 0.112 = 0.855\ \mathrm{V}, \qquad V_{b,min} = V_A + V_{GS0} = 0.193 + 0.855 = 1.048\ \mathrm{V} .$$

### 第 3 步 — 上限：$M_0$ 饱和

$M_0$ 的漏极在 X，源极在 A，因此 $V_{DS0} \ge V_{ov0}$ 意味着

$$V_X - V_A \ge V_{ov0} \quad\Longleftrightarrow\quad V_A \le V_X - V_{ov0} = 0.893 - 0.112 = 0.782\ \mathrm{V} .$$

在临界点 $V_A = 0.782$ V 处：

$$V_{TH0} = 0.7 + 0.45\left(\sqrt{0.9 + 0.782} - 0.9487\right) = 0.7 + 0.45(1.2968 - 0.9487) = 0.7 + 0.1566 = 0.857\ \mathrm{V},$$

$$V_{b,max} = V_A + V_{TH0} + V_{ov0} = 0.782 + 0.857 + 0.112 = 1.750\ \mathrm{V} .$$

等价地，由 $V_b - V_X \le V_{TH0}$ 得 $V_{b,max} = V_X + V_{TH0} = 0.893 + 0.857 = 1.750$ V。

### 第 4 步 — 与不计体效应时的比较

若始终取 $V_{TH0} = 0.7$ V：

$$V_{b,min} = V_{ov1} + 0.7 + V_{ov0} = 0.193 + 0.812 = 1.005\ \mathrm{V}, \qquad V_{b,max} = V_X + 0.7 = 1.593\ \mathrm{V} .$$

体效应使上下两个界限都升高：在下限处升高 43 mV（此时 $V_{SB0}$ 较小），在上限处升高 157 mV（此时它较大）。

### 第 5 步 — 为什么这种电流镜是“低电压”的

输出支路复制基准支路，因此 $V_B = V_A$，$I_{out} = I_{REF}$，输出端一直到 $V_{out,min} = V_B + V_{ov3} = V_A + V_{ov0}$ 都保持饱和。当 $V_b$ 接近其下限时，该值约为 $0.193 + 0.112 = 0.31$ V，大约是两个过驱动电压；而栅极接 $2V_{GS}$ 的标准共源共栅结构需要 $V_{GS} + V_{ov} \approx 1.0$ V。实际中通常把 $V_b$ 取得略高于 $V_{b,min}$（例如 1.1–1.2 V），以留出裕量。

### 结果

$$V_X = V_{GS1} = 0.7 + \sqrt{\frac{2(100\ \mu\mathrm{A})}{(134\ \mu\mathrm{A/V^2})(40)}} \approx 0.89\ \mathrm{V} .$$

$$V_{GS0} + (V_{GS1} - V_{TH1}) \le V_b \le V_{GS1} + V_{TH0} \quad\Longrightarrow\quad 1.05\ \mathrm{V} \lesssim V_b \lesssim 1.75\ \mathrm{V}$$

（计入体效应，下限处 $V_{TH0} = 0.744$ V，上限处为 0.857 V）。若不计体效应，范围约为 1.00–1.59 V。

**常见错误。** 把条件弄反，例如写成 $V_b \ge V_{GS1} + V_{TH0}$。下限保护的是 $M_1$（A 点不能低于 $V_{ov1}$）；上限保护的是 $M_0$，若 $V_b$ 比 $V_X$ 高出一个阈值电压以上，它就会进入线性区（triode region）。

**常见错误。** 像标准共源共栅电流镜那样取 $V_X = 2V_{GS}$ 或 $V_X = V_b$。X 只与 $M_1$ 和 $M_2$ 的栅极相连，因此 $V_X = V_{GS1}$。

**常见错误。** 忽略 $M_0$ 的体效应，或者把 $M_0$ 的尺寸取为 20/0.5。其源极比衬底高 0.2–0.8 V，使阈值电压升高 44–157 mV；而且 $M_0$、$M_3$ 是宽器件（60/0.5），因此过驱动电压为 0.112 V。
