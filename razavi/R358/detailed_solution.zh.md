# 详细步骤 - R358

**思路。** 把密勒定理成立的条件与浮空电阻热噪声的物理本质（两个节点之间的单个电流源）进行比较。两者在三个方面不相容；一个简单的例子表明，密勒捷径给出的结果可能错得很多。

### 第 1 步 — 密勒定理的内容

若阻抗 $Z$ 接在节点 X 与 Y 之间，且所研究的激励使 $V_Y = A\,V_X$，则流过 $Z$ 的电流

$$I_Z = \frac{V_X - V_Y}{Z} = \frac{V_X(1 - A)}{Z},$$

与接地阻抗 $Z_1 = \dfrac{Z}{1 - A}$ 从 X 抽取的电流相同，而从 Y 抽取的电流则与接地阻抗 $Z_2 = \dfrac{Z}{1 - 1/A}$ 的相同。**只有当 $A$ 确实是该激励产生的比值 $V_Y/V_X$ 时**，这种替换才成立；该定理涉及的是端口电流和电压，而不是 $Z$ 的内部。

### 第 2 步 — 浮空电阻的噪声

接在 X 与 Y 之间的电阻 $R$ 并联着噪声电流 $I_n$，$\overline{I_n^2} = 4kT/R$；它也可以等价地表示为一个串联电压，其功率谱密度（power spectral density）为 $4kTR$。这个噪声源：

1. 位于要被“密勒等效”的元件**内部**；
2. 是从一个节点流出、流入另一个节点的**单个**电流，因此它在 X 和 Y 处的作用大小相等、方向相反，并且**完全相关**；
3. 其强度只由 $R$ 和温度决定，而与电阻两端的电压无关。

### 第 3 步 — 为什么不能使用该定理

**（a）比值 $A$ 属于另一种激励。** $A$ 通常是从 X 到 Y 的信号增益。电阻自身的噪声向**两个**节点注入电流，一般会产生不同的 $V_Y/V_X$，因此不满足定理的前提条件。

**（b）相关性丢失。** 给两个接地电阻 $Z_1$ 和 $Z_2$ 各配一个噪声源 $4kT/Z_1$ 和 $4kT/Z_2$，就是用两个**相互独立**的噪声源代替了一个完全（负）相关的噪声源，丢掉了交叉项。

**（c）密勒阻抗不是物理电阻。** $Z_1 = R/(1 - A)$ 和 $Z_2 = R/(1 - 1/A)$ 只是对信号电流的等效，而不是处于热平衡的电阻材料。它们可能非常小（$|A|$ 很大时）、非常大，甚至为**负**（$A > 1$ 时 $Z_1 < 0$），而负的“电阻”会具有负的噪声功率。

### 第 4 步 — 具体例子：带反馈电阻的反相放大器

考虑一个从 X 到 Y、增益为 $-A_0$ 的理想电压放大器，其输入阻抗为无穷大、输出阻抗（output impedance）为零；反馈电阻 $R_F$ 接在 X 与 Y 之间，信号源电阻 $R_s$ 接在 X 与地之间。只考虑 $R_F$ 的噪声，并将其表示为从 X 流向 Y 的电流 $I_{nF}$。

<!-- diagram: diagram-01.cir -->

**正确的分析。** 节点 Y 由零输出阻抗驱动，它吸收流入它的那部分 $I_{nF}$。在 X 点应用基尔霍夫电流定律（KCL），并利用 $V_Y = -A_0V_X$：

$$
\begin{aligned}
-\frac{V_X}{R_s} &= \frac{V_X - V_Y}{R_F} + I_{nF} = \frac{(1 + A_0)V_X}{R_F} + I_{nF}\\
V_X &= -\frac{R_sR_F}{R_F + (1 + A_0)R_s}\,I_{nF}.
\end{aligned}
$$

由 $V_Y = -A_0V_X$，

$$\overline{V_{Y}^2}\Big|_{correct} = A_0^2\,\frac{R_s^2R_F^2}{\left[R_F + (1 + A_0)R_s\right]^2}\cdot\frac{4kT}{R_F},$$

当 $A_0 \to \infty$ 时它趋于 $4kTR_F$，即众所周知的反馈电阻以单位权重出现在输出端的噪声。

**密勒分析（错误）。** 取 $A = -A_0$，则 X 到地的 $Z_1 = R_F/(1 + A_0)$，这对**信号**而言是正确的。给它配上“它的”噪声电流 $4kT(1 + A_0)/R_F$（$Z_2$ 的噪声位于由零阻抗驱动的节点 Y，不起作用），该电流流入 $R_s\parallel Z_1 = R_sR_F/[R_F + (1 + A_0)R_s]$：

$$\overline{V_{Y}^2}\Big|_{Miller} = A_0^2\,\frac{R_s^2R_F^2}{\left[R_F + (1 + A_0)R_s\right]^2}\cdot\frac{4kT(1 + A_0)}{R_F} = (1 + A_0)\,\overline{V_{Y}^2}\Big|_{correct}.$$

这种捷径**把噪声功率高估了 $1 + A_0$ 倍**，例如 $A_0 = 100$ 时高估 101 倍；当 $A_0 \to \infty$ 时，它预测的噪声为无穷大，而不是 $4kTR_F$。由于 $R_F$ 两端的电压为 $(1 + A_0)V_X$，密勒电阻正确地承载了信号电流，但物理电阻的噪声电流仍然只有 $4kT/R_F$。

### 第 5 步 — 正确的做法

保持电阻浮空，把它的噪声建模为 X 与 Y 之间的电流（或串联电压），并通过直接分析求出它对输出的影响（结合叠加原理使用 KCL/KVL，或者采用输入短路/输入开路的方法）。密勒定理仍可用于计算输入阻抗或极点等**信号**量，但不能用来产生噪声源。

### 结果

密勒定理不能用于浮空电阻的噪声，原因是：

- 它只对建立比值 $A = V_Y/V_X$ 的那个激励有效。电阻自身的噪声是另一种激励，位于元件内部并同时驱动两个节点，因此该比值不适用；
- 噪声是从一个节点流出、流入另一个节点的同一个电流（完全相关，符号相反）。两个带有独立噪声源的接地密勒电阻会丢失这种相关性；
- 密勒阻抗 $Z/(1 - A)$ 和 $Z/(1 - 1/A)$ 是数学上的等效，而不是处于温度 $T$ 的物理电阻。它们可能极小、极大或为负，因此 $4kT/Z_{Miller}$ 没有意义。在反相放大器的例子中，噪声功率的误差为因子 $1 + A_0$。

必须把噪声建模为浮空电阻本身的电流源（或电压源），并直接进行分析。

**常见错误。** 给输入侧的密勒电阻配上 $4kT(1 - A)/R$ 的噪声，仿佛它是真实的电阻。热噪声只取决于物理电阻和温度；当 $|A|$ 很大时，误差非常大。

**常见错误。** 说噪声电流“按增益比在两个节点之间分配”。实际上是完整的电流从一个节点流出，又完整地流入另一个节点。

**常见错误。** 只回答“密勒定理适用于信号而不适用于噪声”，却不说明原因：$A$ 依赖于激励、相关性会丢失、密勒阻抗不是物理电阻。
