# 详细步骤 - R025

**思路。** 电容的起始电压与漏极电源电压相同，因此 $M_1$ 的漏源电压为零，无论栅极电压如何都不能流过任何电流。因此电路一开始就处于平衡状态，并一直保持。检查 $V_b$ 的每一个取值范围，以及这一状态的稳定性。

### 第 1 步 — $t = 0$ 时的端电压

$C_1$ 的电压只能通过 $M_1$ 的电流改变：

$$I_X = C_1\frac{dV_X}{dt} .$$

在 $t = 0$ 时，$V_X = 3$ V，因此 $M_1$ 的两个沟道端子都处于 3 V：

$$V_{\text{upper}} = V_{DD} = 3\ \mathrm{V}, \qquad V_{\text{lower}} = V_X = 3\ \mathrm{V}, \qquad V_{DS} = 3\ \mathrm{V} - 3\ \mathrm{V} = 0 .$$

### 第 2 步 — 对任何 $V_b$ 都不可能有电流

**情形 $V_b - 3\ \mathrm{V} \le V_{TH}$。** $V_{GS} = V_b - V_X = V_b - 3$ V 至多等于 $V_{TH}$；而考虑到 3 V 的源-衬底电压所引起的体效应（body effect），后者至少为 0.7 V。因此 $M_1$ **截止**，$I_X = 0$。这包括所有 $V_b \le V_{DD}$ 的情况，此时 $V_{GS} \le 0$。

**情形 $V_b - 3\ \mathrm{V} > V_{TH}$。** 沟道存在，且 $V_{DS} = 0 < V_{GS} - V_{TH}$，器件处于线性区（triode region）：

$$I_D = \beta\left[(V_{GS} - V_{TH})V_{DS} - \tfrac12V_{DS}^2\right] = \beta\left[(V_{GS} - V_{TH})\cdot0 - 0\right] = 0 .$$

沟道是一个**两端没有电压**的电阻，因此同样有 $I_X = 0$。

在两种情形下都有 $I_X(0) = 0$，因此 $dV_X/dt = I_X/C_1 = 0$，$V_X$ 不会离开 3 V；同样的论证适用于之后的每一时刻：

$$V_X(t) = 3\ \mathrm{V}, \qquad I_X(t) = 0 \qquad\text{for all } t \ge 0 .$$

晶体管是一个受控电导：当两个沟道端子处于同一电位时，无论栅极把沟道开启得多么充分，都没有任何东西驱动电流。

### 第 3 步 — 这一平衡是否稳定？

假设一个小扰动（例如结漏电）使 $V_X$ 略低于 3 V。

- 若 $V_b - V_X > V_{TH}$，$M_1$ 导通，电流从 $V_{DD}$ 流入节点 X，对 $C_1$ **重新充电**。作为源极跟随器（source follower），它至多能把 X 拉高到 $V_b - V_{TH}$：若 $V_b - V_{TH} \ge 3$ V，则一直回到 3 V，否则回到 $V_b - V_{TH}$。
- 若 $V_b - V_X < V_{TH}$，$M_1$ 保持截止，$V_X$ 只会按漏电所决定的速度缓慢漂移。

在两种情况下，$M_1$ 都不会使 $C_1$ **放电**：电流只能从 $V_{DD}$ 流入 X，绝不会反向，因为这里 $V_X$ 不可能超过 $V_{DD}$。所以在理想电路中，$V_X$ 保持 3 V。

### 第 4 步 — 与电容从 0 V 开始的情形对比

该电路是一个驱动 $C_1$ 的源极跟随器。若 $C_1$ 从 0 V 开始（且 $V_b > V_{TH}$），$M_1$ 会对它充电，$V_X$ 向 $V_b - V_{TH}$ 上升，并随着过驱动电压（overdrive voltage）趋于零而越来越慢。而从 3 V 开始时，电容已经处于电路所能提供的最高电压，因此什么都不会发生。

### 结果

**什么都不会发生。**

$$V_X(t) = 3\ \mathrm{V} \quad\text{and}\quad I_X(t) = 0 \quad\text{for all } t.$$

节点 X（$M_1$ 的源极一侧）起始电位为 $V_X = 3\ \mathrm{V} = V_{DD}$，因此 $V_{DS} = 0$，无论 $V_b$ 为何值，都不可能有漏极电流流过：

- 当 $V_b \le V_{DD}$ 时，由于 $V_{GS} = V_b - 3 \le 0$，器件本身也是截止的；
- 当 $V_b$ 很大时，沟道导通，但其两端电压为零。

两张草图都是水平线：$V_X$ 位于 3 V，$I_X$ 位于 0。

**常见错误。** 照搬源极跟随器的结论，把 $C_1$ 画成向 $V_b - V_{TH}$ 放电或充电。$M_1$ 只能**抬高** X 的电位（电流从 $V_{DD}$ 流入 X），而 X 已经处于 $V_{DD}$。

**常见错误。** 只论证“$M_1$ 截止”。这对大约 $V_b \le 3.7$ V 成立，但对很大的 $V_b$ 不成立；完整的理由是 $V_{DS} = 0$。
