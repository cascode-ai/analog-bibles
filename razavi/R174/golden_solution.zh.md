在题设模型下，即采用平方律（square law）、且 $M_1$–$M_4$ 中没有沟道长度调制和体效应时，阈值失配不会引起任何共模到差模的转换：$A_{CM-DM} = 0$，共模抑制比为无穷大；失配只产生 ≈ 4.2 mV 的固定差分失调（offset）。教科书的标准估算让两边具有相同的负载电阻 $1/g_{m3}$，得到 CMRR ≈ $(g_m/\Delta g_m)(1 + 2g_mR_{SS})$ ≈ 20,200（≈ 86 dB）；它能很好地描述 $M_1$–$M_4$ 中 λ ≠ 0 的实际电路，但不能描述题设的理想化模型。
- 每个二极管负载流过其对应输入器件的电流。由 $I_{D1} = \tfrac12\beta_n(V_{in,CM} - V_P - V_{TH1})^2$ 得 $V_X = V_{DD} - |V_{THP}| - \sqrt{2I_{D1}/\beta_p} = V_{DD} - |V_{THP}| - \sqrt{\beta_n/\beta_p}\,(V_{in,CM} - V_P - V_{TH1})$，$V_Y$ 同理（用 $V_{TH2}$）。因此 $V_X - V_Y = \sqrt{\beta_n/\beta_p}\,(V_{TH1} - V_{TH2}) = 4.18 \times 1\ \mathrm{mV}$，与 $V_{in,CM}$ 和 $V_P$ 无关：共模输入通过 $R_{SS}$ 使 $V_P$ 变化，但不产生差分输出。
- 从小信号角度看，$g_{m1}/g_{m3} = g_{m2}/g_{m4} = \sqrt{\beta_n/\beta_p} = 4.18$。失配使 $g_{m1}$ 和二极管的 $g_{m3}$ 按相同比例变化（$\Delta g_m/g_m = \Delta g_{m3}/g_{m3} = \Delta V_{TH}/V_{ov} = 0.52\%$），两种效应相互抵消。
- 标准估算：$g_{m1} = \sqrt{2(13.4\ \mathrm{m})(0.25\ \mathrm{m})} = 2.59$ mS，过驱动电压（overdrive voltage）为 0.193 V；$\Delta g_m = \mu_nC_{ox}(W/L)\Delta V_{TH} = 13.4\ \mu$S；$R_{SS} = 1/(0.1 \times 0.5\ \mathrm{mA}) = 20$ kΩ，$1 + 2g_{m1}R_{SS} = 104.5$。取 $A_{DM} = g_{m1}/g_{m3}$、$A_{CM-DM} = \Delta g_m(1/g_{m3})/(1 + 2g_mR_{SS})$（两边的 $1/g_{m3}$ 相同），得 CMRR $= (g_m/\Delta g_m)(1 + 2g_mR_{SS}) = 193 \times 104.5 \approx 20{,}200$。
- 若保留 $M_1$–$M_4$ 中的 λ（$\lambda_n = 0.1$，$\lambda_p = 0.2\ \mathrm{V^{-1}}$），精确的小信号结果为 $A_{DM} \approx 3.73$，$A_{CM-DM} \approx 2.0\times10^{-4}$，CMRR ≈ $1.8\times10^4$（≈ 85 dB）。此时转换来自 $r_O \propto 1/I_D$ 在两边之间的差异（而 $1/g_{m3} \propto 1/\sqrt{I_D}$），而不仅仅来自 $g_m$ 失配。
