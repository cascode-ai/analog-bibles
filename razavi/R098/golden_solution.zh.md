具有共源共栅（cascode）增益的反相特性，其转变非常陡峭：在 $M_1$ 的电流达到负载电流 $I_3 = \tfrac12\beta_3(V_{DD} - V_{b2} - 0.8)^2$ 之前，$V_{out} \approx V_{DD}$；随后几乎竖直地下降；然后随着 $M_2$ 和 $M_1$ 进入线性区（triode region）而缓慢下降。

- $V_{in} \le 0.7$ V：没有电流，$V_{out} = V_{DD}$。
- $0.7\ \mathrm{V} < V_{in} < V_{in}^*$：$M_1$ 处于饱和区（saturation region），但吸收的电流小于 $I_3$，因此 $M_3$ 处于线性区，$V_{out}$ 保持略低于 $V_{DD}$，缓慢下降。
- $V_{in} \approx V_{in}^* = 0.7 + \sqrt{2I_3/\beta_1}$：三个器件都饱和；增益 ≈ $g_{m1}[(g_{m2}r_{O2}r_{O1}) \| r_{O3}]$，非常高，因此 $V_{out}$ 几乎竖直地从 ≈ $V_{DD} - |V_{ov3}| = V_{b2} + 0.8$ V（$M_3$ 的饱和边缘）降到 ≈ $V_{b1} - V_{TH2}$（$M_2$ 的饱和边缘）。若 λ = 0，这一下降将是严格竖直的。
- 在 $V_{out} \approx V_{b1} - V_{TH2}$ 以下，$M_2$ 处于线性区，增益降到大约 $g_{m1}(r_{O1}\|r_{O3})$；随着 $V_{out}$ 进一步下降，节点 $X$（$M_1$ 的漏极）也随之下降，当 $V_X < V_{in} - 0.7$ V 时 $M_1$ 进入线性区；此后增益很小，$V_{out}$ 缓慢下降，在 $V_{in} = 3$ V 时趋于一个较低的值（$M_1$ 和 $M_2$ 都处于线性区并流过 $I_3$）。
- 转折点：$V_{in} = 0.7$ V；$V_{in}^*$；$V_{out} = V_{b2} + 0.8$ V，$V_{out} = V_{b1} - V_{TH2}$，以及 $V_X = V_{in} - 0.7$ V。
- 上述顺序假设所选的 $V_{b1}$ 使三个器件在 $V_{in}^*$ 处都饱和：$V_{b1} \ge V_{TH2} + V_{ov2} + V_{ov1}$，且 $V_{b1} - V_{TH2} < V_{b2} + 0.8$ V，其中 $V_{TH2}$ 需计入体效应（body effect），$V_{SB2} = V_X$。若 $V_{b1}$ 较低，$M_1$ 在转变区内就已处于线性区（峰值增益较低）；若 $V_{b1}$ 较高，$M_2$ 会在 $M_3$ 饱和之前进入线性区。
