# 详细步骤 - R584

**思路。** 分别分析两个相位。在采样相位，运放接成单位增益反馈，因此 X 为虚地，输出接近零，$C_H$ 充电到 $V_{in}$。$S_2$ 断开时，节点 X 上的电荷被冻结。在放大相位，$C_H$ 被翻转跨接在运放两端，由 X 点的电荷守恒即可求出输出。然后根据给定的输入和时钟计算各采样值，构建波形。

### 第 1 步 — 采样相位：输出处于虚地，$C_H$ 充电到 $V_{in}$

把 $C_H$ 的左极板记为 P，右极板（即运放的反相输入端）记为 X。$S_1$ 和 $S_2$ 闭合、$S_3$ 断开时，P 处于 $V_{in}$，运放输出与 X 相连。

<!-- diagram: diagram-01.cir -->

$S_2$ 使 $V_{out} = V_X$，而运放（增益为 $A$，同相输入端接地）使 $V_{out} = -A\,V_X$，因此 $V_X(1 + A) = 0$，$V_X = 0 = V_{out}$。采样期间**输出（近似）为零**，而不是 $V_{in}$；跟随输入的是电容，而不是输出。$C_H$ 两端电压为 $V_P - V_X = V_{in}$，其 X 侧极板上的电荷

$$Q_X = C_H\,(V_X - V_P) = C_H\,(0 - V_{in}) = -C_H\,V_{in},$$

持续跟随输入变化。

### 第 2 步 — 采样结束：$S_2$ 先断开

$S_2$ 比 $S_1$ 稍早断开；把这一时刻记为 $t_k$，此时的输入记为 $V_{0k} = V_{in}(t_k)$。此后节点 X 只与 $C_H$ 和不吸取电流的运放输入端相连，因此其电荷被冻结：

$$Q_X = -C_H\,V_{0k}\quad\text{(frozen at } t_k\text{)}.$$

片刻之后 $S_1$ 断开时，它只改变 P 的电压；没有任何导电路径通到 X，因此采样值由 $S_2$ 断开的时刻决定。这就是**底极板采样**（bottom-plate sampling）：采样开关位于虚地节点，因此它的电荷注入（charge injection）与 $V_{in}$ 无关。

### 第 3 步 — 放大相位：X 点的电荷守恒

此时 $S_3$ 闭合，$S_1$、$S_2$ 断开，因此 $C_H$ 接在 $V_{out}$ 与 X 之间，作为运放的反馈元件。设 $C_{in}$ 为运放在 X 处的输入电容（理想运放为零）。

<!-- diagram: diagram-02.cir -->

此时 X 处的电荷为

$$Q_X = C_H\,(V_X - V_{out}) + C_{in}\,V_X .$$

在 $t_k$ 时刻，$C_{in}$ 两端电压为 $V_X = 0$，因此冻结的电荷仍为 $-C_HV_{0k}$，由 X 点的电荷守恒得

$$C_H\,(V_X - V_{out}) + C_{in}\,V_X = -C_H\,V_{0k}.$$

**理想运放**（$A \to \infty$，因此 $V_X \to 0$）：

$$
\begin{aligned}
-C_H\,V_{out} &= -C_H\,V_{0k}\\
V_{out} &= V_{0k}.
\end{aligned}
$$

增益为 $+1$，不反相：保存了 $V_{0k}$ 的电容（正极板在 P）现在 P 端接输出，X 端处于虚地。

**有限增益。** 代入 $V_X = -V_{out}/A$：

$$
\begin{aligned}
C_H\left(-\frac{V_{out}}{A} - V_{out}\right) - C_{in}\frac{V_{out}}{A} &= -C_H\,V_{0k}\\
V_{out}\left[C_H\left(1 + \frac1A\right) + \frac{C_{in}}{A}\right] &= C_H\,V_{0k}\\
V_{out} &= \frac{V_{0k}}{1 + \dfrac{1}{A}\left(1 + \dfrac{C_{in}}{C_H}\right)}.
\end{aligned}
$$

例如，当 $A = 1000$、$C_{in} = 0.1\,C_H$ 时，$V_{out} = V_{0k}/1.0011$，增益误差为 0.11 %，因此 $V_{out} \approx V_{0k}$。

### 第 4 步 — 时序与采样值

**输入。** $V_{in} = 0.5 + 0.5\sin\omega_0t$（单位为 V）：介于 0 与 1 V 之间，周期为 $1/(10\ \mathrm{MHz}) = 100$ ns。

**时钟。** 周期为 $1/(50\ \mathrm{MHz}) = 20$ ns；占空比为 50 %，每个相位持续 10 ns，因此每个输入周期有 $100/20 = 5$ 个采样。

取采样相位为 0–10、20–30、40–50、60–70 和 80–90 ns；放大相位则为 10–20、30–40、50–60、70–80 和 90–100 ns。采样发生在 $t_k = 10, 30, 50, 70, 90$ ns，正弦波的相位每 ns 前进 $3.6^\circ$：

$$
\begin{aligned}
V_{0}(10\ \mathrm{ns}) &= 0.5 + 0.5\sin36^\circ = 0.5 + 0.5(0.5878) = 0.794\ \mathrm{V},\\
V_{0}(30\ \mathrm{ns}) &= 0.5 + 0.5\sin108^\circ = 0.5 + 0.5(0.9511) = 0.976\ \mathrm{V},\\
V_{0}(50\ \mathrm{ns}) &= 0.5 + 0.5\sin180^\circ = 0.500\ \mathrm{V},\\
V_{0}(70\ \mathrm{ns}) &= 0.5 + 0.5\sin252^\circ = 0.5 - 0.5(0.9511) = 0.024\ \mathrm{V},\\
V_{0}(90\ \mathrm{ns}) &= 0.5 + 0.5\sin324^\circ = 0.5 - 0.5(0.5878) = 0.206\ \mathrm{V}.
\end{aligned}
$$

### 第 5 步 — 输出波形

| 时间（ns） | 相位 | $V_{out}$ |
|---|---|---|
| 0 → 10 | 采样 | ≈ 0 |
| 10 → 20 | 放大 | 上升到 **0.794 V** 并保持 |
| 20 → 30 | 采样 | 回到 ≈ 0 |
| 30 → 40 | 放大 | **0.976 V** |
| 40 → 50 | 采样 | ≈ 0 |
| 50 → 60 | 放大 | **0.500 V** |
| 60 → 70 | 采样 | ≈ 0 |
| 70 → 80 | 放大 | **0.024 V** |
| 80 → 90 | 采样 | ≈ 0 |
| 90 → 100 | 放大 | **0.206 V** |
| 100 → | | 重复 |

输出是一串宽 10 ns 的矩形脉冲，每 20 ns 一个，脉冲之间回到零：这是一个**归零**型采样保持波形。每个脉冲的平顶等于该脉冲开始时（即前一个采样相位结束时）的输入，因此各脉冲顶部沿着正弦波分布（0 到 1 V，周期 100 ns）。实际电路中，运放在每个脉冲边沿都必须经历压摆（slewing）和建立（settling）过程，因此输出只在每个保持相位的末尾附近才有效。

### 结果

$V_{out}$ 是一个**归零**型采样保持波形，具有单位增益且不反相：

- 在每个 10 ns 的采样相位内，$V_{out} \approx 0$（单位增益反馈，X 处于虚地），而 $C_H$ 跟踪 $V_{in}$；
- 在每个 10 ns 的放大相位内，$V_{out} = V_{in}(t_k)$，即 $S_2$ 断开时刻的输入值；更精确地说，$V_{out} = V_{0k}/[1 + (1 + C_{in}/C_H)/A]$。

若采样相位位于 0–10、20–30、…… ns，则各脉冲为 0.794、0.976、0.500、0.024 和 0.206 V（每个 100 ns 的输入周期 5 个），每个脉冲之后都回到约 0 V。

**常见错误。** 把 $V_{out}$ 画成在采样相位跟踪 $V_{in}$。$S_2$ 闭合时，运放跟随其自身接地的同相输入端，因此输出被钳在 0 V；只有 $C_H$ 两端的电压跟随输入。

**常见错误。** 把输出画成反相的。保持相位不施加输入；存储了 $+V_{0k}$ 的电容（P 侧为正）重新连接后，P 接输出，X 处于虚地，因此输出为 $+V_{0k}$。

**常见错误。** 画成没有归零的连续阶梯波。该电路在每个采样相位都把输出复位到零，因此保持值只存在于放大相位。
