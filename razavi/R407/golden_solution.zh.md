$\overline{V_{n,in}^2} = \overline{V_{n2}^2}$；$\quad I_{n,in} = \dfrac{G_{m1}V_{n1}}{2} + \dfrac{V_{n2}}{2R_0}$，即 $\overline{I_{n,in}^2} = \dfrac{G_{m1}^2\overline{V_{n1}^2}}{4} + \dfrac{\overline{V_{n2}^2}}{4R_0^2}$；只有当 $G_{m1}^2R_0^2\overline{V_{n1}^2} \gg \overline{V_{n2}^2}$ 时才有 ≈ $G_{m1}^2\overline{V_{n1}^2}/4$（电流中的 $V_{n2}$ 部分与 $V_{n,in}$ 完全相关）。

- 输入端短路（差分输入电压为零）：$G_{m1}$ 的输出电流流入短路线，无法到达输出端，因此只出现 $G_{m2}$ 的噪声，而且恰好表现为输入电压：$V_{n,in} = V_{n2}$。
- 输入端开路：把输入开路时的输出噪声除以闭环跨阻（transimpedance）。令 $A_1 = G_{m1}R_0$，$A_2 = G_{m2}Z_L$，$Z_L = R_0\|(1/sC_1)$，$L = A_1A_2$：$V_{out,n} = A_2(V_{n2} - A_1V_{n1})/(1+L)$，$Z_t = 2R_0A_2/(1+L)$（差分端口电流从一个输入节点流入、从另一个流出，加反馈前端口电阻为 $2R_0$），因此 $I_{n,in} = V_{n2}/(2R_0) - G_{m1}V_{n1}/2$；因子 $(1+L)$ 和 $Z_L$ 都被约去。等价地，$G_{m1}$ 的噪声是注入输入节点的诺顿电流（Norton current）$G_{m1}V_{n1}/2$（开环时它会在 $2R_0$ 上产生 $G_{m1}R_0V_{n1}$；实际的闭环端口电压是该值除以 $1+L$）。$V_{n1}$ 项的符号只是极性约定。
- $C_1$ 不出现在输入参考量中。
- 若改用差分输出电流来定义 $G_m$（$I_{out,d} = G_mV_{in,d}$），电流项变为 $G_{m1}V_{n1}$（只有因子 2 改变）。
