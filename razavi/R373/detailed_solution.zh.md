# 详细步骤 - R373

**思路。** 两种差分对的差模半边电路相同，都是以 $R_S$ 作源极负反馈、以 $R_1$ 为负载的共源（CS）级，因此输入器件、负反馈电阻和负载的贡献完全相同，都等于半边电路输入参考噪声的两倍。两个电路的区别仅在于偏置电流源注入噪声的方式：[图 1] 中尾电流噪声是共模量，会相互抵消；[图 2] 中两个电流源相互独立，其噪声部分表现为差模量。用 KCL 推导每一项贡献，再把热噪声项和闪烁噪声项相加。

### 第 1 步 — 偏置与差分跨导

把 [图 1] 的公共节点记为 P，把 [图 2] 中 $M_1$、$M_2$ 的源极分别记为 $S_1$、$S_2$。由于电源电流相等，两个电路中 $M_1$ 和 $M_2$ 的电流都是 $I_D$，跨导都是 $g_{m1}$；[图 2] 在平衡时 $2R_S$ 中没有直流电流。由于 $\lambda = 0$ 且没有体效应，电流源晶体管中除了其自身的噪声之外没有小信号电流。

对差分信号而言，P（以及 [图 2] 中 $2R_S$ 的中点）是虚地，因此每个半边都是以 $R_S$ 作源极负反馈的共源级，两个电路都有

$$G_m = \frac{g_{m1}}{1 + g_{m1}R_S}, \qquad |A_v| = G_mR_1 .$$

### 第 2 步 — 半边电路的噪声：输入器件、$R_S$ 与负载

在一个半边电路中（$M_1$，$R_S$ 接在其源极与地之间，$R_1$ 接在其漏极，栅极接地）：

**$M_1$ 的沟道噪声。** 对源极节点列 KCL：

$$
\begin{aligned}
-g_{m1}v_s + I_{n1} &= \frac{v_s}{R_S}\\
v_s &= \frac{I_{n1}R_S}{1 + g_{m1}R_S},\\
i_d &= \frac{v_s}{R_S} = \frac{I_{n1}}{1 + g_{m1}R_S}.
\end{aligned}
$$

除以 $G_m$ 得 $I_{n1}/g_{m1}$，因此其贡献为 $4kT\gamma g_{m1}/g_{m1}^2 = 4kT\gamma/g_{m1}$：源极负反馈使信号和噪声按相同比例减小。

**$R_S$ 的噪声。** 源极支路中的串联噪声电压与栅极串联的噪声电压作用完全相同，因此其贡献为 $4kTR_S$。

**$R_1$ 的噪声。** 其噪声电流 $4kT/R_1$ 直接到达输出端，需除以 $G_m^2$：

$$\frac{4kT/R_1}{G_m^2} = \frac{4kT}{R_1}\cdot\frac{(1 + g_{m1}R_S)^2}{g_{m1}^2}.$$

**半边电路总噪声：**

$$\overline{V_{n,half}^2} = 4kT\left[\frac{\gamma}{g_{m1}} + R_S + \frac{(1 + g_{m1}R_S)^2}{g_{m1}^2R_1}\right].$$

由半边电路的对称性，两个相互独立的半边按功率相加：

$$\overline{V_{n,in}^2}\Big|_{\text{common}} = 8kT\left[\frac{\gamma}{g_{m1}} + R_S + \frac{(1 + g_{m1}R_S)^2}{g_{m1}^2R_1}\right].$$

**两个 $R_S$ 与一个 $2R_S$ 的比较。** 在 [图 1] 中，两个相互独立的电阻给出 $2\times4kTR_S = 8kTR_S$。在 [图 2] 中，单个 $2R_S$ 的噪声电压 $4kT(2R_S) = 8kTR_S$ 串联在两个源极之间，是纯差模的，全部出现在差分输入端。两者数值相同，因此这一公共部分对两个电路都适用。

### 第 3 步 — [图 1] 中的尾电流噪声：相互抵消

设 $M_3$ 的噪声电流 $I_{n3}$ 从 P 点抽出。对两个源极节点列 KCL（栅极接地）：

$$
\begin{aligned}
-g_{m1}v_{s1} &= \frac{v_{s1} - v_P}{R_S},\\
-g_{m1}v_{s2} &= \frac{v_{s2} - v_P}{R_S}.
\end{aligned}
$$

两式相减得 $(v_{s1} - v_{s2})(g_{m1} + 1/R_S) = 0$，因此 $v_{s1} = v_{s2}$，两个漏极电流相等（各为 $I_{n3}/2$）。尾电流噪声（无论是热噪声还是闪烁噪声）是纯**共模**量，在完全匹配的情况下不产生差分输出，因此 [图 1] 中没有电流源噪声项。

### 第 4 步 — [图 2] 中的电流源噪声：不会抵消

设 $M_3$ 从 $S_1$ 抽出噪声电流 $I_{n3}$，$M_4$ 从 $S_2$ 抽出 $I_{n4}$，栅极均接地。

<!-- diagram: diagram-01.cir -->

对 $S_1$ 和 $S_2$ 列 KCL（流入的沟道电流 = 经 $2R_S$ 流出的电流 + 流出的噪声电流）：

$$
\begin{aligned}
-g_{m1}v_{s1} &= \frac{v_{s1} - v_{s2}}{2R_S} + I_{n3},\\
-g_{m1}v_{s2} &= \frac{v_{s2} - v_{s1}}{2R_S} + I_{n4}.
\end{aligned}
$$

两式相减：

$$
\begin{aligned}
-g_{m1}(v_{s1} - v_{s2}) &= \frac{v_{s1} - v_{s2}}{R_S} + (I_{n3} - I_{n4})\\
v_{s1} - v_{s2} &= -\frac{(I_{n3} - I_{n4})R_S}{1 + g_{m1}R_S}.
\end{aligned}
$$

于是

$$i_{d1} - i_{d2} = -g_{m1}(v_{s1} - v_{s2}) = \frac{g_{m1}R_S}{1 + g_{m1}R_S}\,(I_{n3} - I_{n4}),$$

再除以 $G_m = g_{m1}/(1 + g_{m1}R_S)$：

$$v_{n,in} = \frac{g_{m1}R_S/(1 + g_{m1}R_S)}{g_{m1}/(1 + g_{m1}R_S)}\,(I_{n3} - I_{n4}) = R_S\,(I_{n3} - I_{n4}).$$

在带源极负反馈的晶体管源极注入的电流，等效于与栅极串联的电压 $I\cdot R_S$；只有公共部分 $(I_{n3} + I_{n4})/2$ 会抵消。

**热噪声部分**（$I_{n3}$、$I_{n4}$ 相互独立，各为 $4kT\gamma g_{m3}$）：

$$\overline{V_{n,in}^2}\Big|_{M_3,M_4} = R_S^2\cdot2\cdot4kT\gamma g_{m3} = 8kT\gamma g_{m3}R_S^2.$$

**闪烁噪声部分。** $M_3$ 的闪烁噪声栅极电压产生漏极电流 $g_{m3}V_{f3}$，其作用与 $I_{n3}$ 完全相同：

$$\overline{V_{n,in}^2}\Big|_{M_3,M_4,\,1/f} = 2R_S^2g_{m3}^2\frac{K_N}{C_{ox}(WL)_3f}.$$

### 第 5 步 — 输入对管的闪烁噪声

$M_1$ 和 $M_2$ 的闪烁噪声本来就是与各自栅极串联的电压，因此对这两个相互独立的器件有

$$\overline{V_{n,in}^2}\Big|_{M_1,M_2,\,1/f} = \frac{2K_N}{C_{ox}(WL)_1f}.$$

### 第 6 步 — 总噪声与比较

**[图 1]：**

$$\overline{V_{n,in}^2} = 8kT\left[\frac{\gamma}{g_{m1}} + R_S + \frac{(1 + g_{m1}R_S)^2}{g_{m1}^2R_1}\right] + \frac{2K_N}{C_{ox}(WL)_1f}.$$

**[图 2]：**

$$\overline{V_{n,in}^2} = 8kT\left[\frac{\gamma}{g_{m1}} + R_S + \frac{(1 + g_{m1}R_S)^2}{g_{m1}^2R_1}\right] + 8kT\gamma g_{m3}R_S^2 + \frac{2K_N}{C_{ox}f}\left[\frac{1}{(WL)_1} + \frac{g_{m3}^2R_S^2}{(WL)_3}\right].$$

- [图 2] 的噪声多出 $8kT\gamma g_{m3}R_S^2$（热噪声）和 $2K_Ng_{m3}^2R_S^2/(C_{ox}(WL)_3f)$（闪烁噪声）。多出的热噪声项是负反馈电阻的 $8kTR_S$ 的 $\gamma g_{m3}R_S$ 倍，因此当 $g_{m3}R_S$ 接近 1 时就变得重要；较小的 $g_{m3}$（$M_3$、$M_4$ 采用较大的过驱动电压）和较大的 $(WL)_3$ 可以减小它。
- [图 1] 的噪声更低，因为其尾电流噪声是纯共模的。
- [图 1] 的代价是电压余度：每个 $R_S$ 都流过偏置电流，产生 $I_DR_S$ 的压降，而 [图 2] 中 $2R_S$ 里没有直流电流。

### 结果

$$\text{[Fig. 1]:}\quad \overline{V_{n,in}^2} = 8kT\left[\frac{\gamma}{g_{m1}} + R_S + \frac{(1 + g_{m1}R_S)^2}{g_{m1}^2R_1}\right] + \frac{2K_N}{C_{ox}(WL)_1f}$$

$$\text{[Fig. 2]:}\quad \overline{V_{n,in}^2} = 8kT\left[\frac{\gamma}{g_{m1}} + R_S + \frac{(1 + g_{m1}R_S)^2}{g_{m1}^2R_1}\right] + 8kT\gamma g_{m3}R_S^2 + \frac{2K_N}{C_{ox}f}\left[\frac{1}{(WL)_1} + \frac{g_{m3}^2R_S^2}{(WL)_3}\right]$$

两个电路的差分跨导同为 $g_{m1}/(1 + g_{m1}R_S)$，对管、负反馈电阻和负载的噪声贡献也相同。[图 1] 的尾电流噪声是共模量，会相互抵消；而 [图 2] 的两个电流源在输入端引入 $(I_{n3} - I_{n4})R_S$。**[图 1] 的噪声更低**；[图 2] 以额外的噪声换取负反馈电阻上没有直流压降。

**常见错误。** 把 [图 1] 的尾电流噪声当作差模噪声。它平均分配到两个半边，在完全匹配的情况下不会出现在差分输出中。

**常见错误。** 以为 [图 2] 中 $M_3$ 和 $M_4$ 的噪声电流也会“由于对称性”而抵消。它们是**相互独立**的；只有它们的公共部分会抵消。系数 $R_S^2/4$ 或 $4R_S^2$ 通常是把 $2R_S$ 当作接地电阻处理的结果；第 4 步的 KCL 推导表明每个噪声源的系数恰好是 $R_S^2$。

**常见错误。** 认为两个电阻 $R_S$ 与一个电阻 $2R_S$ 贡献的噪声不同。两者在差分输入端给出的都是 $8kTR_S$。
