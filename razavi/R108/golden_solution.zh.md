$I_X = I_{D1} - |I_{D2}|$：它从 $-I_2$ 开始，在 $M_1$ 处于线性区（triode region）时上升；两管都处于饱和区（saturation region）时平坦地保持在 $I_1 - I_2$；随着 $M_2$ 进入线性区，它再次上升，在 $V_X = V_{DD}$ 时达到 $I_1$。其中 $I_1 = \tfrac12\beta_n(V_{b2} - 0.7)^2$，$I_2 = \tfrac12\beta_p(V_{DD} - V_{b1} - 0.8)^2$。

- $M_1$：$V_X < V_{b2} - 0.7$ V 时处于线性区，$I_{D1} = \beta_n[(V_{b2} - 0.7)V_X - V_X^2/2]$；此后饱和，电流为 $I_1$。
- $M_2$：$V_X \le V_{b1} + 0.8$ V 时饱和（电流为 $I_2$）；高于此值时处于线性区，其电流在 $V_X = 3$ V 处降为 0。
- 若 $V_{b2} - 0.7 < V_{b1} + 0.8$：在 0 处 $I_X = -I_2$，在 $V_X = V_{b2} - 0.7$ V 处上升到 $I_1 - I_2$，然后保持平坦直到 $V_X = V_{b1} + 0.8$ V，再上升到 3 V 时的 $I_1$；若计入沟道长度调制（channel-length modulation），平坦段的斜率为 $\lambda_nI_1 + \lambda_pI_2$。（若两个转折点的顺序相反，中间段两管都处于线性区，并持续上升。）
- 转折点：$V_X = V_{b2} - 0.7$ V 和 $V_X = V_{b1} + 0.8$ V。
