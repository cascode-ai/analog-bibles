# 详细步骤 - R108

**思路。** 两个栅极都接固定偏置，因此 $M_1$（NMOS）和 $M_2$（PMOS）是两个电流源（current source），其公共漏极由 $V_X$ 驱动。由漏极节点的基尔霍夫电流定律（KCL）得 $I_X = I_{D1} - |I_{D2}|$。然后利用各器件的输出特性：$M_1$ 在 $V_X$ 较低时处于线性区，在 $V_{b2} - 0.7$ V 以上处于饱和区；$M_2$ 在 $V_X$ 较低时处于饱和区，在 $V_{b1} + 0.8$ V 以上处于线性区。

### 第 1 步 — 漏极节点的 KCL

$I_X$ 和 $M_2$ 的漏极电流 $|I_{D2}|$ 流入 $X$，$M_1$ 的漏极电流流出：

$$I_X + |I_{D2}| = I_{D1} \quad\Longrightarrow\quad I_X = I_{D1} - |I_{D2}| .$$

两个器件都导通（$V_{b2} > 0.7$ V，$V_{DD} - V_{b1} > 0.8$ V），且没有体效应（body effect），饱和电流为

$$I_1 = \frac12\beta_n(V_{b2} - 0.7)^2, \qquad I_2 = \frac12\beta_p(V_{DD} - V_{b1} - 0.8)^2 = \frac12\beta_p(2.2 - V_{b1})^2 .$$

取 $\lambda = 0$（题目未给出）；$\lambda > 0$ 的情况在第 4 步讨论。

### 第 2 步 — $M_1$ 的输出特性

$V_{GS1} = V_{b2}$，$V_{DS1} = V_X$：

- **线性区，$V_X < V_{b2} - 0.7$ V：** $I_{D1} = \beta_n\left[(V_{b2} - 0.7)V_X - \tfrac12V_X^2\right]$，从 $V_X = 0$ 时的 0 开始上升；
- **饱和区，$V_X \ge V_{b2} - 0.7$ V：** $I_{D1} = I_1$。

### 第 3 步 — $M_2$ 的输出特性

$V_{SG2} = 3 - V_{b1}$（固定），$V_{SD2} = 3 - V_X$，因此饱和要求

$$3 - V_X \ge 3 - V_{b1} - 0.8 \quad\Longleftrightarrow\quad V_X \le V_{b1} + 0.8\ \mathrm{V}$$

即漏极电压最高可升到比 $V_{DD}$ 低一个过驱动电压（overdrive voltage）的位置：$V_{DD} - |V_{ov2}| = V_{DD} - (V_{DD} - V_{b1} - 0.8) = V_{b1} + 0.8$。

- **饱和区，$V_X \le V_{b1} + 0.8$ V：** $|I_{D2}| = I_2$；
- **线性区，$V_X > V_{b1} + 0.8$ V：** $|I_{D2}| = \beta_p\left[(2.2 - V_{b1})(3 - V_X) - \tfrac12(3 - V_X)^2\right]$，下降并**在 $V_X = 3$ V 处降为零**，此时 $V_{SD2} = 0$。

### 第 4 步 — 合成（通常的顺序 $V_{b2} - 0.7 < V_{b1} + 0.8$）

| $V_X$ 的范围 | $M_1$ | $M_2$ | $I_X$ | 斜率 $dI_X/dV_X$ |
|---|---|---|---|---|
| $0 \le V_X < V_{b2} - 0.7$ | 线性区 | 饱和 | $\beta_n[(V_{b2} - 0.7)V_X - V_X^2/2] - I_2$ | $\beta_n(V_{b2} - 0.7 - V_X)$，降到 0 |
| $V_{b2} - 0.7 \le V_X \le V_{b1} + 0.8$ | 饱和 | 饱和 | $I_1 - I_2$（平坦） | 0 |
| $V_{b1} + 0.8 < V_X \le 3$ | 饱和 | 线性区 | $I_1 - \beta_p[(2.2 - V_{b1})(3 - V_X) - (3 - V_X)^2/2]$ | $\beta_p(V_X - V_{b1} - 0.8)$，上升 |

- **起点：** $I_X(0) = -I_2$：$V_{DS} = 0$ 时 $M_1$ 中没有电流，而 $M_2$ 把其全部电流 $I_2$ 注入电压源。
- **终点：** $I_X(3\ \mathrm{V}) = I_1$：$V_{SD} = 0$ 时 $M_2$ 中没有电流，而 $M_1$ 吸取 $I_1$。
- **中间段：** 一段位于 $I_1 - I_2$ 的平坦段，其正负取决于哪个电流源更强。当 $\lambda = 0$ 时其斜率恰好为零；若计入沟道长度调制，斜率为 $\lambda_nI_1 + \lambda_pI_2 = 1/r_{O1} + 1/r_{O2}$。
- **顺序相反**（$V_{b2} - 0.7 > V_{b1} + 0.8$）：在中间范围内两个器件都处于线性区，$I_X$ 在那里持续上升，而不是保持平坦。

$I_X$ 从 $-I_2$ 单调增大到 $+I_1$。

**过零点**（即去掉电压源后的节点电压）。若 $I_1 < I_2$，平坦段为负，过零点位于最后一段，此时（处于线性区的）$M_2$ 已减弱到 $I_1$：$\beta_p[(2.2 - V_{b1})(3 - V_X) - \frac12(3 - V_X)^2] = I_1$。若 $I_1 > I_2$，过零点位于第一段，此时（处于线性区的）$M_1$ 流过 $I_2$：$\beta_n[(V_{b2} - 0.7)V_X - \frac12V_X^2] = I_2$。只有当 $I_1 = I_2$ 时，整个平坦段都位于零，此时（在 $\lambda = 0$ 的情况下）节点电压在两个转折点之间是不确定的。

### 第 5 步 — 数值示例

为便于说明，取 $V_{b2} = 1.0$ V，$\beta_n = 4\ \mathrm{mA/V^2}$，$V_{b1} = 1.5$ V，$\beta_p = 1\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_1 &= \tfrac12(4\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 0.18\ \mathrm{mA},\qquad V_{b2} - 0.7 = 0.3\ \mathrm{V},\\
I_2 &= \tfrac12(1\ \mathrm{mA/V^2})(0.7\ \mathrm{V})^2 = 0.245\ \mathrm{mA},\qquad V_{b1} + 0.8 = 2.3\ \mathrm{V}.
\end{aligned}
$$

当 $V_X > 2.3$ V 时，令 $s = 3 - V_X$，则 $|I_{D2}| = (1\ \mathrm{mA/V^2})(0.7s - 0.5s^2)$。由过零条件 $0.18 = 0.7s - 0.5s^2$ 得 $s = 0.339$ V，即 $V_X = 2.66$ V。

| $V_X$ (V) | $I_{D1}$ (mA) | $\lvert I_{D2}\rvert$ (mA) | $I_X$ (mA) |
|---|---|---|---|
| 0 | 0 | 0.245 | −0.245 |
| 0.1 | 0.100 | 0.245 | −0.145 |
| 0.2 | 0.160 | 0.245 | −0.085 |
| 0.3 | 0.180 | 0.245 | −0.065 |
| 1.5 | 0.180 | 0.245 | −0.065 |
| 2.3 | 0.180 | 0.245 | −0.065 |
| 2.6 | 0.180 | 0.200 | −0.020 |
| 2.66 | 0.180 | 0.180 | 0 |
| 2.8 | 0.180 | 0.120 | 0.060 |
| 3.0 | 0.180 | 0 | 0.180 |

### 结果

$$I_X = I_{D1} - |I_{D2}|, \qquad I_1 = \tfrac12\beta_n(V_{b2} - 0.7)^2, \quad I_2 = \tfrac12\beta_p(V_{DD} - V_{b1} - 0.8)^2 .$$

$I_X$ 从 $-I_2$ 开始，在 $M_1$ 处于线性区时上升；两个器件都饱和时平坦地保持在 $I_1 - I_2$；随着 $M_2$ 进入线性区，它再次上升，在 $V_X = V_{DD}$ 时达到 $I_1$。

- **$M_1$：** $V_X < V_{b2} - 0.7$ V 时处于线性区，$I_{D1} = \beta_n[(V_{b2} - 0.7)V_X - V_X^2/2]$；此后饱和，电流为 $I_1$。
- **$M_2$：** $V_X \le V_{b1} + 0.8$ V 时饱和（电流为 $I_2$）；高于此值时处于线性区，其电流在 $V_X = 3$ V 处降为 0。
- **若 $V_{b2} - 0.7 < V_{b1} + 0.8$：** 在 0 处 $I_X = -I_2$，在 $V_X = V_{b2} - 0.7$ V 处上升到 $I_1 - I_2$，然后保持平坦（若计入沟道长度调制，斜率为 $\lambda_nI_1 + \lambda_pI_2$）直到 $V_X = V_{b1} + 0.8$ V，再上升到 3 V 时的 $I_1$。若两个转折点的顺序相反，中间段两管都处于线性区，并持续上升。
- **转折点：** $V_X = V_{b2} - 0.7$ V 和 $V_X = V_{b1} + 0.8$ V。

**常见错误。** 把 $M_2$ 的转折点放在 $V_X = V_{b1} - 0.8$ V 处。源极接 $V_{DD}$ 的 PMOS 的饱和条件为 $V_X \le V_{b1} + |V_{THP}|$：漏极电压最多可以比栅极电压**高**一个阈值电压（threshold voltage）。

**常见错误。** 让曲线终止于 $I_1 - I_2$，或从那里开始。在 $V_X = V_{DD}$ 处，$M_2$ 中没有电流，因此 $I_X = I_1$；在 $V_X = 0$ 处，$M_1$ 中没有电流，因此 $I_X = -I_2$。

**常见错误。** 只画出一个器件的输出特性。测试源既要向 $M_1$ 供电，**又**要吸收 $M_2$ 的电流，因此二者要合成，其中 $M_2$ 的电流取负。
