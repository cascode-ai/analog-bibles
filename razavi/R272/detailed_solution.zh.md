# 详细步骤 - R272

**思路。** 在输入端加一个小的测试电压 $v_{in}$，求出它引起的电流 $i_{in}$，再求 $Z_{in} = v_{in}/i_{in}$。信号沿一个环路传递：输入驱动 $M_1$，其电流在节点 Y（负载为二极管连接的 $M_3$ 和 $C_1$）上产生电压，$M_2$ 再把该电压转换回输入端的电流。先忽略沟道长度调制，再加入 $r_O$ 项。

### 第 1 步 — 小信号模型（small-signal model）

把输入节点称为 X。对小信号而言，理想的 $I_1$ 相当于开路。忽略沟道长度调制：

- $M_1$ 从 Y 向地吸取电流 $g_{m1}v_{in}$；
- 二极管连接的 $M_3$ 相当于从 Y 到交流地的电阻 $1/g_{m3}$，与 $C_1$ 并联；
- $M_2$（$v_{gs} = v_Y$）相当于一个电流源 $g_{m2}v_Y$，电流从 X **流出**、流向交流地；
- $M_1$ 的栅极不取电流。

### 第 2 步 — 节点 Y 的电压

节点 Y 的基尔霍夫电流定律（KCL）方程：

$$g_{m1}v_{in} + g_{m3}v_Y + sC_1v_Y = 0 \quad\Longrightarrow\quad v_Y = -\frac{g_{m1}}{g_{m3} + sC_1}\,v_{in},$$

这就是低频时以二极管连接器件为负载的共源级（common-source stage）增益 $-g_{m1}/g_{m3}$，在较高频率下被 $C_1$ 旁路。

### 第 3 步 — 输入电流

电流只能经 $M_2$ 离开 X（$I_1$ 是理想的，$M_1$ 的栅极不取电流），因此

$$i_{in} = g_{m2}v_Y = -\frac{g_{m1}g_{m2}}{g_{m3} + sC_1}\,v_{in}.$$

输入导纳为**负**：

$$Y_{in} = \frac{i_{in}}{v_{in}} = -\frac{g_{m1}g_{m2}}{g_{m3} + sC_1}.$$

升高 $v_{in}$ 会使 $M_1$ 把 $v_Y$ 拉低，于是 PMOS $M_2$ 向 X **注入更多**电流：这是正反馈，表现为负电阻。

### 第 4 步 — 输入阻抗与电感项

对导纳取倒数：

$$Z_{in} = \frac{1}{Y_{in}} = -\frac{g_{m3} + sC_1}{g_{m1}g_{m2}} = \underbrace{-\frac{g_{m3}}{g_{m1}g_{m2}}}_{R_{eq}} + s\underbrace{\left(-\frac{C_1}{g_{m1}g_{m2}}\right)}_{L_{eq}} ,$$

即一个电阻与一个电感串联：

- **负电阻：** $R_{eq} = -\dfrac{g_{m3}}{g_{m1}g_{m2}}$；若 $M_2$ 与 $M_3$ 相同（$g_{m2} = g_{m3}$），它等于 $-1/g_{m1}$。
- **负电感：** $L_{eq} = -\dfrac{C_1}{g_{m1}g_{m2}}$。

经过 $M_1$ 和 $M_2$ 的环路起回转器（gyrator）的作用，把 Y 处的导纳 $sC_1$ 转换为 X 处正比于 $sC_1$ 的阻抗；环路中额外的一次符号反转使电感为负。量纲检验：$C_1/(g_{m1}g_{m2})$ 的单位为 $\mathrm{F}/\mathrm{S^2} = \mathrm{F\,\Omega^2} = \mathrm{s\,\Omega} = \mathrm{H}$ ✓。

### 第 5 步 — 计入沟道长度调制

在节点 Y，$r_{O1}$ 和 $r_{O3}$ 引入了与 $g_{m3}$ 和 $sC_1$ 并联的电导：

$$v_Y = -\frac{g_{m1}}{g_{m3} + 1/r_{O1} + 1/r_{O3} + sC_1}\,v_{in}.$$

在节点 X，$r_{O2}$ 给 $Y_{in}$ 增加了一个与反馈通路并联的电导 $1/r_{O2}$。因此

$$Z_{in} = r_{O2}\ \Big\|\ \left[-\frac{g_{m3} + 1/r_{O1} + 1/r_{O3} + sC_1}{g_{m1}g_{m2}}\right].$$

电感部分 $-C_1/(g_{m1}g_{m2})$ 保持不变；只有串联的负电阻多了一些很小的 $1/r_O$ 修正项，并且整个支路被很大的 $r_{O2}$ 并联。

### 结果

忽略沟道长度调制时：

$$Z_{in} = -\frac{g_{m3} + sC_1}{g_{m1}g_{m2}} = -\frac{g_{m3}}{g_{m1}g_{m2}} - s\,\frac{C_1}{g_{m1}g_{m2}},$$

即**负电阻** $-g_{m3}/(g_{m1}g_{m2})$（若 $M_2$ 与 $M_3$ 相同，则 $= -1/g_{m1}$）与如下的**负电感**串联：

$$L = -\frac{C_1}{g_{m1}g_{m2}}.$$

计入 $r_O$ 时：$Z_{in} = r_{O2}\,\|\,[-(g_{m3} + 1/r_{O1} + 1/r_{O3} + sC_1)/(g_{m1}g_{m2})]$，电感项相同。

**常见错误。** 在环路中丢掉一个负号，从而给出正电感 $C_1/(g_{m1}g_{m2})$。$M_1$ 起反相作用，而 PMOS $M_2$ 把**下降的**栅极电压转换为**流入** X 的**更多**电流，因此输入电流与 $v_{in}$ 方向相反，$R$ 和 $L$ 都为负。

**常见错误。** 根据“输入端接了什么”就写出 $Z_{in} = 1/g_{m1}$。输入节点没有到地的电阻性通路（只有理想的 $I_1$、一个栅极以及 $M_2$ 的高阻漏极）；它的全部小信号电流都来自经 $M_1$ 和 $M_2$ 的反馈。

**常见错误。** 因为唯一的电抗元件是电容，就断定 $Z_{in}$ 是容性（capacitive）的。$C_1$ 位于导纳的**分母**中，因此在阻抗中以分子上的 $sC_1$ 出现：这是一个感性（inductive）项。
