极低频：$A_v = \dfrac{1 - g_{m1}(R_2+R_3)}{1 + g_{m1}R_1} = -\dfrac{19}{11} \approx -1.73$（理想值应为 $-(R_2+R_3)/R_1 = -2$）。极高频：$A_v = -g_{m1}R_3\dfrac{R_2}{R_1+R_2} = -5$。

- 低频：$C_1$ 开路，反馈电阻为 $R_F = R_2 + R_3 = 4\ \mathrm{k\Omega}$。输出节点上没有其他电导（λ = 0，$M_2$ 为理想电流源），因此 $M_1$ 的漏极电流全部流过 $R_F$：$g_{m1}v_G = (v_G - v_{out})/R_F$。在栅极处，$(v_{in} - v_G)/R_1 = g_{m1}v_G$ → $v_G = v_{in}/(1 + g_{m1}R_1) = v_{in}/11$；$v_{out} = v_G(1 - g_{m1}R_F) = -19v_{in}/11$。
- 高频：$C_1$ 把 $R_2$–$R_3$ 的连接点对地短路，反馈消失：栅极看到的是分压器 $R_1$–$R_2$（$v_G = v_{in}/2$），漏极只以 $R_3$ 为负载：$v_{out} = -g_{m1}R_3v_G = -10 \times v_{in}/2 = -5v_{in}$。
- $g_{m2}$ 不起作用（$M_2$ 的栅极接固定偏置，λ = 0）。
