# 详细步骤 - R343

**思路。** 在输入短路时求输入参考噪声电压（输出噪声除以电压增益的平方），在输入开路时求输入参考噪声电流（输出噪声除以跨阻的平方）。对于共栅级，两者都很重要：它的输入阻抗很低，因此信号源阻抗的影响不可忽略。

### 第 1 步 — 小信号模型（small-signal model）

- **$M_1$：** 从输出端流向源极（即输入端）的电流 $g_m(v_G - v_{in})$，其沟道噪声 $I_{n1}$（$\overline{I_{n1}^2} = 4kT\gamma g_m$）与之并联；由于 $\lambda = 0$ 且无体效应，没有 $r_O$ 和 $g_{mb}$。
- **$R_G$：** 接在栅极节点 G 与交流地（$V_b$）之间，与其噪声电压 $V_{nG}$（$\overline{V_{nG}^2} = 4kTR_G$）串联。忽略电容时，$R_G$ 中没有栅极电流，因此
$$v_G = V_{nG}.$$
- **$R_D$：** 接在输出端与交流地之间，其诺顿噪声 $I_{nD}$（$\overline{I_{nD}^2} = 4kT/R_D$）流入输出端。

### 第 2 步 — 共栅级的电压增益

关闭噪声（$v_G = 0$），在源极加理想的 $v_{in}$，则 $M_1$ 从输出端抽取电流 $g_m(0 - v_{in}) = -g_mv_{in}$，该电流来自 $R_D$：$(0 - v_{out})/R_D = -g_mv_{in}$。因此（同相）增益为

$$A_v = \frac{v_{out}}{v_{in}} = g_mR_D .$$

### 第 3 步 — 输入参考噪声电压（输入短路）

源极接交流地时：

- **$M_1$：** $I_{n1}$ 从输出端流向地，因此 $v_{out} = -R_DI_{n1}$，$\overline{V_{n,out}^2} = 4kT\gamma g_mR_D^2$。折算到输入端：
$$\frac{4kT\gamma g_mR_D^2}{g_m^2R_D^2} = \frac{4kT\gamma}{g_m}.$$
- **$R_D$：** $v_{out} = R_DI_{nD}$，因此 $\overline{V_{n,out}^2} = 4kTR_D$。折算到输入端：
$$\frac{4kTR_D}{g_m^2R_D^2} = \frac{4kT}{g_m^2R_D}.$$
- **$R_G$：** $v_{GS} = V_{nG}$，因此漏极电流为 $g_mV_{nG}$，$v_{out} = -g_mR_DV_{nG}$，$\overline{V_{n,out}^2} = g_m^2R_D^2\cdot4kTR_G$。折算到输入端：
$$\frac{g_m^2R_D^2\cdot4kTR_G}{g_m^2R_D^2} = 4kTR_G .$$

$R_G$ 的噪声**一比一地**折算到输入端：晶体管只对 $v_{GS}$ 作出响应，因此栅极上的电压与源极上符号相反的电压作用相同。把互不相关的功率相加：

$$\overline{V_{n,in}^2} = \frac{4kT\gamma}{g_m} + 4kTR_G + \frac{4kT}{g_m^2R_D}.$$

### 第 4 步 — 输入参考噪声电流（输入开路）

输入开路时，源极节点只与 $M_1$ 相连，因此该节点的基尔霍夫电流定律（KCL）迫使**流过 $M_1$ 的总电流**为零：

$$g_m(v_G - v_S) + I_{n1} = 0 .$$

因此 **$I_{n1}$ 和 $V_{nG}$ 都到达不了输出端**；它们只改变浮空的源极电压，$v_S = V_{nG} + I_{n1}/g_m$。输出噪声只来自 $R_D$，$v_{out} = R_DI_{nD}$：

$$\overline{V_{n,out}^2}\Big|_{open} = 4kTR_D .$$

注入源极的信号电流 $i_{in}$ 必须全部流过 $M_1$，再流过 $R_D$：

$$|v_{out}| = R_D\,|i_{in}| \quad\Longrightarrow\quad |R_T| = R_D ,$$

$$\overline{I_{n,in}^2} = \frac{\overline{V_{n,out}^2}|_{open}}{R_T^2} = \frac{4kTR_D}{R_D^2} = \frac{4kT}{R_D}.$$

### 第 5 步 — 物理解释

$R_G$ 出现在噪声电压中，却**不**出现在噪声电流中：输入开路时，源极只是跟随栅极变化。噪声电流中只有 $R_D$ 的贡献，因为任何输入电流都原样经 $M_1$ 到达负载，使负载的噪声电流与输入电流无法区分。这两个等效噪声源一般是相关的（两者都包含 $R_D$ 的噪声），只有在与有限的信号源阻抗一起使用时，这一点才有影响。

### 结果

$$\overline{V_{n,in}^2} = \frac{4kT\gamma}{g_m} + 4kTR_G + \frac{4kT}{g_m^2R_D},\qquad \overline{I_{n,in}^2} = \frac{4kT}{R_D}$$

- 电压（输入短路，增益为 $g_mR_D$）：$M_1$ 给出 $4kT\gamma/g_m$，$R_D$ 给出 $4kT/(g_m^2R_D)$；$R_G$ 的噪声电压直接加在栅极上，给出 $4kTR_G$。
- 电流（输入开路）：$M_1$ 中的总电流必须为零，因此 $M_1$ 和 $R_G$ 的噪声到达不了输出端。输出噪声为 $4kTR_D$，跨阻为 $R_D$，得到 $4kT/R_D$。

**常见错误。** 因为栅极不吸取电流，就在噪声电压中略去 $R_G$。$R_G$ 中虽然没有电流，但它的噪声**电压**仍然出现在栅极上并改变 $v_{GS}$，贡献 $4kTR_G$。

**常见错误。** 在输入参考噪声电流中保留 $M_1$ 或 $R_G$ 的噪声，例如把输入**短路**时的输出噪声除以 $R_D^2$，得到 $4kT(\gamma g_m + g_m^2R_G + 1/R_D)$。输入**开路**时，$M_1$ 根本没有净电流。

**常见错误。** 求增益或跨阻时把该级当作共源级（common-source stage）。输入端是**源极**：增益为 $+g_mR_D$，输入电流以单位电流增益到达负载。
