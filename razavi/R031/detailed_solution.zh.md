# 详细步骤 - R031

**思路。** $M_1$ 是一个驱动 $C_1$ 的源极跟随器（漏极接 $V_{DD}$，输出取自源极）。阶跃之前它截止；阶跃之后其栅极为 3 V，它把 $C_1$ 向上充电。栅极与漏极处于同一电位，因此它始终处于饱和区，由此得到一个非线性微分方程。当 $V_{GS}$ 降到 $V_{TH}$ 时充电停止，体效应决定了这一最终值。求出初始电流、最终值以及趋近过程的形状。

### 第 1 步 — 阶跃之前（$t < 0$）

$V_{GS} = 0 - 1 = -1\ \mathrm{V} < V_{TH}$，因此 **$M_1$ 截止**，$V_X$ 保持 1 V。

### 第 2 步 — 阶跃之后：控制方程

当 $t > 0$ 时：

$$
\begin{aligned}
V_{GS} &= 3 - V_X,\\
V_{DS} &= 3 - V_X,\\
V_{SB} &= V_X .
\end{aligned}
$$

由于 $V_{DS} = V_{GS}$，**$M_1$ 只要导通就处于饱和区**。计入体效应，

$$V_{TH}(V_X) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - 0.9487\right)\ \mathrm{V},$$

全部漏极电流都给 $C_1$ 充电：

$$C_1\frac{dV_X}{dt} = \tfrac12\beta\left[3 - V_X - V_{TH}(V_X)\right]^2 .$$

### 第 3 步 — 初始电流与斜率

在 $t = 0^+$ 时，$V_X = 1$ V（电容电压不能突变）：

$$
\begin{aligned}
V_{TH} &= 0.7 + 0.45\left(\sqrt{1.9} - 0.9487\right) = 0.7 + 0.45\times0.4297 = 0.893\ \mathrm{V},\\
V_{ov} &= V_{GS} - V_{TH} = 2 - 0.893 = 1.107\ \mathrm{V},\\
I_D(0^+) &= \tfrac12\beta\,(1.107\ \mathrm{V})^2 = 0.61\,\beta\ \mathrm{V^2},\\
\left.\frac{dV_X}{dt}\right|_{0^+} &= \frac{0.61\,\beta}{C_1}\ (\mathrm{V^2}) .
\end{aligned}
$$

所以 $V_X$ 从 1 V 以有限的斜率开始上升，没有跳变。

### 第 4 步 — 最终值

当过驱动电压降到零时，充电停止：

$$3 - V_X = V_{TH}(V_X) = 0.7 + 0.45\sqrt{0.9 + V_X} - 0.4269 .$$

令 $u = \sqrt{0.9 + V_X}$（$V_X = u^2 - 0.9$）：

$$
\begin{aligned}
3 - u^2 + 0.9 &= 0.2731 + 0.45u\\
u^2 + 0.45u - 3.6269 &= 0\\
u &= \frac{-0.45 + \sqrt{0.2025 + 14.5076}}{2} = \frac{-0.45 + 3.8354}{2} = 1.6927\\
V_{X,\infty} &= u^2 - 0.9 = 2.8652 - 0.9 = 1.965\ \mathrm{V}.
\end{aligned}
$$

验算：$V_{TH}(1.965\ \mathrm{V}) = 0.7 + 0.45(1.6927 - 0.9487) = 1.035$ V，$3 - 1.965 = 1.035$ V。✓

所以 $V_X \to$ **≈ 1.97 V**。若没有体效应，极限值将为 $3 - 0.7 = 2.3$ V：源极比接地衬底高出约 2 V，使阈值电压（threshold voltage）升高到约 1.03 V，输出因此损失约 0.33 V。

### 第 5 步 — 趋近过程的形状

记过驱动电压 $u_{ov} = 3 - V_X - V_{TH}(V_X)$，$\eta = dV_{TH}/dV_X = \gamma/(2\sqrt{0.9 + V_X})$（这里约为 0.13–0.16），

$$\frac{du_{ov}}{dt} = -(1 + \eta)\frac{dV_X}{dt} = -(1 + \eta)\frac{\beta}{2C_1}\,u_{ov}^2 .$$

由于 $\eta$ 几乎恒定，其解为

$$u_{ov}(t) \approx \frac{u_{ov}(0)}{1 + (1 + \eta)\dfrac{\beta\,u_{ov}(0)}{2C_1}\,t},$$

因此距最终值的剩余差值按 **$1/t$（双曲线型）而不是指数规律**减小：电流正比于剩余过驱动电压的**平方**，并且 $M_1$ 始终处于饱和区。在实际器件中，亚阈值（subthreshold）导电会继续使 $V_X$ 非常缓慢地升高到超过这一数值。

### 第 6 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF（初始电流为 0.61 mA，初始斜率为 0.61 V/ns），数值积分给出：

| $t$ (ns) | $V_X$ (V) | 过驱动电压 (V) | $I_D$ (mA) | 不计体效应时的 $V_X$ (V) |
|---|---|---|---|---|
| $0^-$ | 1.00 | —（截止） | 0 | 1.00 |
| $0^+$ | 1.00 | 1.107 | 0.61 | 1.00 |
| 0.5 | 1.23 | 0.84 | 0.35 | 1.32 |
| 1 | 1.37 | 0.68 | 0.23 | 1.51 |
| 2 | 1.54 | 0.49 | 0.12 | 1.74 |
| 5 | 1.73 | 0.27 | 0.035 | 1.99 |
| 10 | 1.83 | 0.15 | 0.011 | 2.13 |
| 50 | 1.94 | 0.034 | 0.0006 | 2.26 |
| ∞ | 1.965 | 0 | 0 | 2.30 |

（最后一列采用不计体效应时的精确解 $V_X = 2.3 - 1.3/(1 + 1.3\beta t/2C_1)$。）

### 结果

- **$t < 0$：** $V_X = 1$ V（$M_1$ 截止，$V_{GS} = -1$ V）。
- **$t > 0$：** 源极跟随器对 $C_1$ 充电。$M_1$ 始终处于饱和区（$V_{DS} = V_{GS}$），满足 $C_1\,dV_X/dt = \tfrac12\beta[3 - V_X - V_{TH}(V_X)]^2$。
  - 在 $t = 0^+$ 时：$V_{GS} = 2$ V，$V_{TH}(V_{SB} = 1\ \mathrm{V}) = 0.89$ V，初始电流为 $\tfrac12\beta(1.11)^2 = 0.61\beta$，初始斜率为 $0.61\beta/C_1$。
  - $V_X$ 从 1 V 开始上升，起初很快，然后越来越慢，渐近地趋向 **≈ 1.97 V**。该点满足 $3 - V_X = V_{TH}(V_X)$，即 $V_X + 0.7 + 0.45(\sqrt{0.9 + V_X} - \sqrt{0.9}) = 3$，解得 $V_X \approx 1.965$ V，此时 $V_{TH} \approx 1.03$ V。若没有体效应，极限值将为 2.3 V。
  - 由于过驱动电压缩小到零，趋近过程是双曲线型的（$\propto 1/t$），而不是指数型的。

**常见错误。** 让 $V_X$ 随输入跳变，或者稳定在 3 V。$V_X$ 是电容电压，而跟随器只能把其源极抬高到比栅极低一个阈值电压的位置。

**常见错误。** 计算最终值时使用 $V_{TH} = 0.7$ V，得到 2.3 V。源极比接地衬底高出约 2 V，阈值电压约为 1.03 V，因此输出停在 1.97 V 附近。

**常见错误。** 画成类似 $RC$ 的指数趋近。器件永远不会进入线性区（triode region），其电流按剩余过驱动电压的平方下降，因此按 $1/t$ 的规律趋近最终值。
