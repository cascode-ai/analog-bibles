# 详细步骤 - R152

**思路。** 沿用 NMOS 的分析思路，只是所有电压都从 $V_{DD}$ 而不是从地算起。PMOS 在栅极比源极**低**至少 $|V_{THP}|$ 时导通，因此输入对在**较低**的输入共模电平下导通、在较高的共模电平下截止：这些曲线就是 NMOS 的曲线关于 $V_{in,CM} = V_{DD}/2$ 的镜像，而输出电压从地向上计量。

### 第 1 步 — PMOS 电路及其方程

$M_1$ 和 $M_2$ 的漏极分别记为 $X$ 和 $Y$。

<!-- diagram: diagram-01.cir -->

电流从 $V_{DD}$ 流经 $M_3$，在 $M_1$ 和 $M_2$ 之间平均分配，再向下流经电阻到地：

$$I_{D1} = I_{D2} = \tfrac12 I_{D3}, \qquad V_{out1} = V_{out2} = R_D\,I_{D1}, \qquad V_P = V_{in,CM} + |V_{GS1}| .$$

导通的 PMOS 的源极比其栅极**高** $|V_{GS1}|$；记 $V_{SG} = |V_{GS}|$，$|V_{TH}| = 0.8$ V，若 $V_{SG} > |V_{TH}|$，PMOS 导通；若 $V_{SD} \ge V_{SG} - |V_{TH}|$，PMOS 处于饱和。

### 第 2 步 — $V_{in,CM}$ 较高：输入对截止

只有当 $V_P - V_{in,CM} > |V_{TH1}|$ 时 $M_1$ 和 $M_2$ 才导通，而 $V_P$ 不能超过 $V_{DD}$，因此当

$$V_{in,CM} > V_{DD} - |V_{TH1}| = 3 - 0.8 = 2.2\ \mathrm{V}$$

时，输入对**截止**：$I_{D1} = I_{D2} = 0$。此时：

- 虽然 $M_3$ 的沟道是导通的（$V_{SG3} = V_{DD} - V_b > |V_{TH3}|$），但它没有电流，因此 $V_{SD3} = 0$：它处于深线性区，把 $V_P$ 上拉到 $V_{DD}$；
- 电阻中没有电流，因此 $V_{out1} = V_{out2} = 0$。

（此时 $V_P = V_{DD}$，因此即使衬底接 $V_{DD}$ 也没有体效应，转折点恰好是 $V_{DD} - |V_{THP}| = 2.2$ V。）这与 NMOS 差分对在 $V_{in,CM} < V_{TH1}$ 时截止互为镜像。

### 第 3 步 — 中等 $V_{in,CM}$：尾电流管处于线性区

当 $V_{in,CM}$ 降到 2.2 V 以下时，$M_1$ 和 $M_2$ 导通。起初电流很小，$M_3$ 只需要很小的 $V_{SD3}$：它处于**线性区**，相当于 $V_{DD}$ 与 $P$ 之间的一个电阻。进一步降低 $V_{in,CM}$ 会使 $V_{SG1}$ 增大：

- $I_{D1}$、$I_{D2}$ 从零开始上升（起初大致按平方规律）；
- $V_P = V_{in,CM} + |V_{GS1}|$ 从 $V_{DD}$ 开始下降，离开时斜率为零，然后逐渐变陡，趋向约为 1 的斜率；
- $V_{out} = R_DI_{D1}$ 从 0 开始上升。

**$M_3$ 进入饱和**的条件是 $V_{SD3} = V_{DD} - V_P$ 达到其过驱动电压（overdrive voltage）$|V_{GS3} - V_{TH3}| = V_{SG3} - |V_{TH3}|$：

$$
\begin{aligned}
V_{DD} - V_P &= |V_{GS3} - V_{TH3}|\\
V_{DD} - V_{in,CM} - |V_{GS1}| &= |V_{GS3} - V_{TH3}|\\
V_{in,CM} &= V_{DD} - |V_{GS1}| - |V_{GS3} - V_{TH3}| ,
\end{aligned}
$$

其中 $|V_{GS1}|$ 按满电流 $I_{SS}/2$ 计算：这是 NMOS 转折点 $V_{GS1} + (V_{GS3} - V_{TH3})$ 的镜像。

### 第 4 步 — $V_{in,CM}$ 较低：尾电流管饱和

当 $V_{in,CM} \le V_{DD} - |V_{GS1}| - |V_{GS3} - V_{TH3}|$ 时，$M_3$ 是提供 $I_{SS}$ 的电流源（current source）：

- $I_{D1} = I_{D2} = I_{SS}/2$，保持平坦；
- $V_{out1} = V_{out2} = R_DI_{SS}/2$，保持平坦，从地向上计量（NMOS 的输出稳定在 $V_{DD} - R_DI_{SS}/2$）；
- $V_P = V_{in,CM} + |V_{GS1}|$，是一条斜率 ≈ 1 的直线，位于输入**上方** $|V_{GS1}|$ 处（NMOS 的这条线位于输入下方 $V_{GS1}$ 处）。若 $M_1$、$M_2$ 的衬底接 $V_{DD}$，则随着 $V_P$ 下降，体效应使 $|V_{TH1}|$ 增大，从而使斜率略小于 1，转折点也略有移动。

**有效范围的下限。** 只有当 $V_{SD1} \ge V_{SG1} - |V_{TH1}|$ 时 $M_1$ 才保持饱和：

$$
\begin{aligned}
V_P - V_{out} &\ge V_P - V_{in,CM} - |V_{TH1}|\\
V_{in,CM} &\ge V_{out} - |V_{TH1}| = \frac{R_DI_{SS}}{2} - |V_{TH1}| .
\end{aligned}
$$

若该界限为正，则低于它时输入对进入线性区。尾电流管仍然饱和，所以电流和输出不变，但差分增益下降，而且 $V_P$ 停留在直线上方（它不能再降到输出电平以下）。因此允许的共模范围为

$$\frac{R_DI_{SS}}{2} - |V_{TH1}| \;\le\; V_{in,CM} \;\le\; V_{DD} - |V_{GS1}| - |V_{GS3} - V_{TH3}| .$$

### 第 5 步 — 一个说明性的例子

仅为说明起见，取 $I_{SS} = 0.5$ mA，$|V_{GS3} - V_{TH3}| = 0.3$ V，$M_1$、$M_2$ 在 0.25 mA 时的过驱动电压为 0.2 V（因此 $|V_{GS1}| = 1.0$ V，忽略体效应），$R_D = 4$ kΩ（因此 $R_DI_{SS}/2 = 1.0$ V）。于是各转折点为：

- 输入对截止：$V_{DD} - |V_{TH1}| = 3 - 0.8 = 2.2$ V；
- 尾电流管饱和：$V_{DD} - |V_{GS1}| - |V_{GS3} - V_{TH3}| = 3 - 1.0 - 0.3 = 1.7$ V；
- 输入对离开饱和区：$R_DI_{SS}/2 - |V_{TH1}| = 1.0 - 0.8 = 0.2$ V。

逐点求解平方律（square-law）方程得：

| $V_{in,CM}$ (V) | $I_{D1} = I_{D2}$ (mA) | $V_P$ (V) | $V_{out1} = V_{out2}$ (V) | 工作区 |
|---|---|---|---|---|
| 3.0 | 0 | 3.00 | 0 | 输入对截止 |
| 2.2 | 0 | 3.00 | 0 | 导通点 |
| 2.1 | 0.037 | 2.98 | 0.15 | $M_3$ 线性区 |
| 2.0 | 0.104 | 2.93 | 0.42 | $M_3$ 线性区 |
| 1.9 | 0.173 | 2.87 | 0.69 | $M_3$ 线性区 |
| 1.8 | 0.227 | 2.79 | 0.91 | $M_3$ 线性区 |
| 1.7 | 0.250 | 2.70 | 1.00 | $M_3$ 刚好饱和 |
| 1.0 | 0.250 | 2.00 | 1.00 | 全部饱和 |
| 0.2 | 0.250 | 1.20 | 1.00 | $M_1$、$M_2$ 处于线性区边缘 |
| 0 | 0.250 | 1.08 | 1.00 | $M_1$、$M_2$ 处于线性区 |

### 结果

PMOS 差分对的曲线就是 NMOS 曲线**关于 $V_{in,CM} = V_{DD}/2$ 的镜像**，输出以地为参考：

- **$I_{D1}$、$I_{D2}$ 随 $V_{in,CM}$ 的变化：** 当 $V_{in,CM} > V_{DD} - |V_{TH1}| \approx 2.2$ V 时为零（输入对截止，$M_3$ 处于深线性区）。随 $V_{in,CM}$ 降低而上升（$M_3$ 处于线性区，相当于一个电阻）。当 $V_{in,CM} \le V_{DD} - |V_{GS1}| - |V_{GS3} - V_{TH3}|$ 时 $M_3$ 饱和，电流恒为 $I_{SS}/2$。
- **$V_P$ 随 $V_{in,CM}$ 的变化：** 输入对截止时等于 $V_{DD}$。在 2.2 V 以下，它满足 $V_P = V_{in,CM} + |V_{GS1}|$，是一条斜率 ≈ 1 的直线，位于输入**上方** $|V_{GS1}|$ 处，并在 $V_{in,CM} \to 2.2$ V 时向上弯曲，以零斜率与 $V_{DD}$ 相接。
- **$V_{out1}$、$V_{out2}$ 随 $V_{in,CM}$ 的变化：** $V_{out} = R_DI_{D1}$。当 $V_{in,CM} > 2.2$ V 时为零，随 $V_{in,CM}$ 降低而上升，当 $V_{in,CM} \le V_{DD} - |V_{GS1}| - |V_{GS3} - V_{TH3}|$ 时恒为 $R_DI_{SS}/2$。
- **转折点：** $V_{DD} - |V_{TH1}|$（= 2.2 V）和 $V_{DD} - |V_{GS1}| - |V_{GS3} - V_{TH3}|$。有效范围的下边界：$V_{in,CM} \ge R_DI_{SS}/2 - |V_{THP}|$，低于此值时 $M_1$、$M_2$ 进入线性区，差分增益下降。

**常见错误。** 原样照搬 NMOS 的曲线，让电流在共模电平**上升**超过 $V_{TH}$ 时导通。PMOS 差分对是在 $V_{in,CM}$ **下降**到 $V_{DD} - |V_{THP}|$ 以下时导通的。

**常见错误。** 把输出画在 $V_{DD}$ 附近、并下降到 $V_{DD} - R_DI_{SS}/2$。负载电阻接地，因此 $V_{out} = R_DI_D$ 从零上升到 $R_DI_{SS}/2$。

**常见错误。** 把 $V_P$ 画在 $V_{in,CM}$ 以下。导通的 PMOS 的源极是电位**较高**的端子，$V_P = V_{in,CM} + |V_{GS1}|$；输入对截止时 $V_P$ 趋于 $V_{DD}$（而不是地）。
