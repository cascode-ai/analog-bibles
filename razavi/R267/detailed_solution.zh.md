# 详细步骤 - R267

**思路。** 参考侧由 $I_{REF}$ 和二极管连接（diode-connected）的 $M_2$ 组成，它确定了 $M_1$ 和 $M_2$ 的公共栅极电压。$M_1$ 的源极接在 $C_1$ 上，因此它的电流给电容充电，源极电压上升，电流衰减。同一电流流过共源共栅（cascode）器件 $M_3$ 和 $R_1$，因此由 $R_1$ 可得 $V_Y$，由 $M_3$ 在该衰减电流下的栅源电压（计入体效应）可得 $V_X$。

### 第 1 步 — $M_1$ 的栅极电压恒定

$M_2$ 始终流过 $I_{REF}$（$M_1$ 的栅极不取电流），且其源极接地，因此

$$V_G = V_{GS2} = 0.7 + V_{ov}, \qquad V_{ov} = \sqrt{\frac{2I_{REF}}{\beta}},$$

它不随时间变化。衬底接地时，$V_{SB1} = V_{C1}$，$V_{SB3} = V_X$，且 $V_{TH}(V_{SB}) = 0.7 + 0.45(\sqrt{0.9 + V_{SB}} - \sqrt{0.9})$ V；$\lambda = 0$，且 $M_1$、$M_3$ 饱和（题目给定）。

### 第 2 步 — $t = 0^+$ 时的初始值

在 $t = 0^+$ 时，$V_{C1} = 0$，因此 $M_1$ 的源极与 $M_2$ 的源极一样处于地电位；由于栅极电压相同，$M_1$ 复制参考电流：

$$I_{D1}(0^+) = I_{REF}.$$

该电流向上流过 $M_3$ 和 $R_1$，因此

$$V_Y(0^+) = V_{DD} - R_1I_{REF}, \qquad V_X(0^+) = V_b - V_{GS3}(I_{REF}) = V_b - V_{TH3}(V_X) - \sqrt{\frac{2I_{REF}}{\beta}} ,$$

因为节点 X 比 $M_3$ 固定的栅极电压低一个 $V_{GS3}$。

### 第 3 步 — $C_1$ 充电，$M_1$ 的电流衰减

$M_1$ 的源极电流只流入 $C_1$：

$$C_1\frac{dV_{S1}}{dt} = I_{D1} = \frac{\beta}{2}\left[V_G - V_{S1} - V_{TH1}(V_{S1})\right]^2 .$$

**不计体效应时**（$V_{TH1} = 0.7$ V），令 $w = V_{ov} - V_{S1}$ 为 $M_1$ 的过驱动电压，$w(0) = V_{ov}$，$dw = -dV_{S1}$：

$$
\begin{aligned}
\frac{dw}{w^2} &= -\frac{\beta}{2C_1}\,dt\\
\frac{1}{w(t)} &= \frac{1}{V_{ov}} + \frac{\beta t}{2C_1}\\
w(t) &= \frac{V_{ov}}{1 + t/\tau}, \qquad \tau = \frac{2C_1}{\beta V_{ov}} = \frac{2C_1}{g_m}, \quad g_m = \sqrt{2\beta I_{REF}},\\
I_{D1}(t) &= \frac{\beta}{2}w^2 = \frac{I_{REF}}{(1 + t/\tau)^2}.
\end{aligned}
$$

$M_1$ 的源极电压向 $V_G - V_{TH1}$ 攀升，电流逐渐消失：起初很快，之后呈现按 $1/t^2$ 缓慢衰减的拖尾。

**计入体效应时**，$dw = -(1 + \eta_1)\,dV_{S1}$，其中 $\eta_1 = \gamma/(2\sqrt{0.9 + V_{S1}}) \approx 0.22$。衰减约快 $1 + \eta_1$ 倍，源极电压停在稍低的位置，即 $V_{S1} + V_{TH1}(V_{S1}) = V_G$ 处。

### 第 4 步 — $V_Y(t)$：回升到 $V_{DD}$

$R_1$ 流过 $M_3$ 的电流，而它等于 $M_1$ 的电流：

$$V_Y(t) = V_{DD} - R_1I_{D1}(t) \approx V_{DD} - \frac{R_1I_{REF}}{(1 + t/\tau)^2} .$$

$V_Y$ 从 $V_{DD} - R_1I_{REF}$ 开始，**向 $V_{DD}$ 上升**，先快后慢。

### 第 5 步 — $V_X(t)$：向 $V_b - V_{TH3}$ 上升

$M_3$ 饱和，流过 $I_{D1}(t)$：

$$V_X(t) + V_{TH3}\big(V_X(t)\big) = V_b - \sqrt{\frac{2I_{D1}(t)}{\beta}} .$$

随着电流衰减，$M_3$ 所需的过驱动电压减小，因此其源极 X **上升**。当电流消失后：

$$V_{X,\infty} = V_b - V_{TH3}(V_{X,\infty}).$$

总的上升量等于初始过驱动电压减去源极升高（体效应）所引起的额外阈值电压（threshold voltage）：

$$\Delta V_X = V_{X,\infty} - V_X(0^+) = \sqrt{\frac{2I_{REF}}{\beta}} - \left[V_{TH3}(V_{X,\infty}) - V_{TH3}(V_X(0^+))\right].$$

**波形形状。** $V_X$ 按与 $\sqrt{I_{D1}} \propto 1/(1 + t/\tau)$ 成正比的规律趋近其终值，即按 $1/t$ 衰减的拖尾，比 $V_Y$ 按 $1/t^2$ 衰减的拖尾更慢。

**饱和检查。** $V_{DS1} = V_X - V_{S1}$ 几乎保持不变（两个节点上升的幅度相近），而 $M_1$ 的过驱动电压减小；$V_{DS3} = V_Y - V_X$ 增大（$V_Y$ 上升约 $R_1I_{REF}$，远大于 $V_X$ 的上升量），因此只要两管一开始饱和，就会一直保持饱和。

### 第 6 步 — 数值示例

取 $\beta = 2.68\ \mathrm{mA/V^2}$（$W/L = 10/0.5$），$I_{REF} = 100\ \mu\mathrm{A}$，$R_1 = 10\ \mathrm{k}\Omega$，$C_1 = 10$ pF，$V_b = 2$ V。

$$
\begin{aligned}
V_{ov} &= \sqrt{2(100\ \mu\mathrm{A})/(2.68\ \mathrm{mA/V^2})} = 0.273\ \mathrm{V}, \qquad V_G = 0.973\ \mathrm{V},\\
g_m &= \sqrt{2(2.68\ \mathrm{mA/V^2})(100\ \mu\mathrm{A})} = 0.732\ \mathrm{mS}, \qquad \tau = \frac{2(10\ \mathrm{pF})}{0.732\ \mathrm{mS}} = 27.3\ \mathrm{ns},\\
V_Y(0^+) &= 3 - (10\ \mathrm{k}\Omega)(100\ \mu\mathrm{A}) = 2.00\ \mathrm{V}.
\end{aligned}
$$

**$V_X(0^+)$：** 求解 $V_X + 0.7 + 0.45(\sqrt{0.9 + V_X} - 0.949) = 2 - 0.273 = 1.727$ V。试取 $V_X = 0.857$ V：$V_{TH3} = 0.7 + 0.45(\sqrt{1.757} - 0.949) = 0.870$ V，且 $0.857 + 0.870 = 1.727$ ✓。

**$V_{X,\infty}$：** 求解 $V_X + V_{TH3}(V_X) = 2$ V。试取 $V_X = 1.092$ V：$V_{TH3} = 0.7 + 0.45(\sqrt{1.992} - 0.949) = 0.908$ V，且 $1.092 + 0.908 = 2.000$ ✓。

因此 $\Delta V_X = 1.092 - 0.857 = 0.235$ V $= 0.273 - (0.908 - 0.870)$ ✓，$M_1$ 的源极最终约为 0.22 V（此时 $V_{S1} + V_{TH1}(V_{S1}) = 0.973$ V）。

### 结果

- **在 $t = 0^+$ 时**，$M_1$（源极为 0 V）复制 $I_{REF}$：$V_X = V_b - V_{GS3}(I_{REF})$，$V_Y = V_{DD} - R_1I_{REF}$。
- **随后**，该电流给 $C_1$ 充电，$M_1$ 的源极电压向 $V_{GS2} - V_{TH1}$ 上升，电流逐渐消失，$I_{D1} \approx I_{REF}/(1 + t/\tau)^2$，其中 $\tau = 2C_1/\sqrt{2\beta I_{REF}}$（不计体效应；体效应会使衰减稍快，并使源极停在稍低的位置）。
- **$V_Y$ 回升并趋向 $V_{DD}$**，其变化规律为 $V_{DD} - R_1I_{D1}(t)$。
- **$V_X$ 上升并趋向 $V_b - V_{TH3}(V_X)$**，上升量为 $\Delta V_X = \sqrt{2I_{REF}/\beta} - [V_{TH3}(V_{X,\infty}) - V_{TH3}(V_{X,0})]$，略小于初始过驱动电压，因为升高的 $V_X$ 使 $V_{TH3}$ 增大。
- 两者都是先快后慢地上升。电流不会一直保持为 $I_{REF}$。

**常见错误。** 像对待普通共源共栅电流镜（current mirror）那样，认为电路会一直复制 $I_{REF}$。$M_1$ 的源极接在对电流进行积分的电容上；一旦源极电压升高约一个过驱动电压，$M_1$ 就截止。

**常见错误。** 认为 $V_X$ 恒定。$V_X$ 由共源共栅器件 $M_3$ 决定，随着电流衰减，其 $V_{GS}$ 从 $V_{TH3} + V_{ov}$ 减小到 $V_{TH3}$，因此 X 上升将近 $V_{ov}$。

**常见错误。** 让 $V_Y$ 下降，或让 $V_X$ 降到 0。流过 $R_1$ 和 $M_3$ 的电流只会随时间**减小**，因此 $R_1$ 上的压降减小（$V_Y$ 上升），$M_3$ 所需的栅源电压也减小（$V_X$ 上升）。
