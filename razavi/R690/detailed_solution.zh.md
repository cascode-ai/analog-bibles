# 详细步骤 - R690

**思路。** $M_1$ 是以二极管连接（diode-connected）的 PMOS 管 $M_2$ 为负载的共源级（common-source stage）。对一般的阈值电压，由 $I_{D1} = I_{D2}$ 推导传输曲线，然后分别代入目标阈值（$V_{THN} = 0.7$ V，$|V_{THP}| = 0.8$ V）和缺少注入时保留的原生阈值（$V_{THN} \approx 0$，$|V_{THP}| \approx 1$ V）进行计算。

### 第 1 步 — 一般阈值下的传输曲线

记 $V_{TN} = V_{THN}$，$V_{TP} = |V_{THP}|$。每个管子的衬底都接到各自的源极，因此没有体效应（body effect）；取 $\lambda = 0$。二极管连接的 $M_2$ 只要导通就总处于饱和区，其 $V_{SG2} = V_{DD} - V_{out}$：

$$I_{D2} = \tfrac12\mu_pC_{ox}(W/L)_2(V_{DD} - V_{TP} - V_{out})^2 .$$

输出端不接负载，因此 $I_{D1} = I_{D2}$。定义强度比

$$A = \sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_2}} .$$

**三个工作区：**

1. **$M_1$ 截止**（$V_{in} \le V_{TN}$）：$I_{D2} = 0$ 要求 $V_{out} \ge V_{DD} - V_{TP}$。按惯例取导通边缘处的值 $V_{out} = V_{DD} - V_{TP}$。（在平方律模型中，直到 $V_{DD}$ 的任何值都给出零电流；$M_2$ 的亚阈值漏电会把输出缓慢地拉向 $V_{DD}$。）
2. **$M_1$ 饱和**：令两管的饱和电流相等，消去 $\tfrac12C_{ox}$ 并除以 $\mu_p(W/L)_2$，
$$A^2(V_{in} - V_{TN})^2 = (V_{DD} - V_{TP} - V_{out})^2 .$$
取正根：
$$V_{out} = (V_{DD} - V_{TP}) - A\,(V_{in} - V_{TN}),$$
这是一条斜率为 $-A$ 的直线，该斜率也就是小信号增益 $-g_{m1}/g_{m2}$。
3. **$M_1$ 处于线性区**，从该直线与 $V_{out} = V_{in} - V_{TN}$ 的交点开始：
$$(V_{DD} - V_{TP}) - A(V_{in} - V_{TN}) = V_{in} - V_{TN} \;\Longrightarrow\; V_{in} - V_{TN} = \frac{V_{DD} - V_{TP}}{1 + A}.$$
此后，令 $M_1$ 的线性区电流 $\mu_nC_{ox}(W/L)_1[(V_{in} - V_{TN})V_{out} - \tfrac12V_{out}^2]$ 等于 $I_{D2}$，并除以 $\tfrac12\mu_pC_{ox}(W/L)_2$：
$$A^2\big[2(V_{in} - V_{TN})V_{out} - V_{out}^2\big] = (V_{DD} - V_{TP} - V_{out})^2 .$$

### 第 2 步 — 目标情况（$V_{TN} = 0.7$ V，$V_{TP} = 0.8$ V）

$$V_{DD} - V_{TP} = 3 - 0.8 = 2.2\ \mathrm{V}.$$

- **$0 \le V_{in} \le 0.7$ V：** $M_1$ 截止，$V_{out} = 2.2$ V。
- **饱和直线：** $V_{out} = 2.2 - A(V_{in} - 0.7)$。
- **线性区转折点：**
$$V_{in,B} = 0.7 + \frac{2.2}{1 + A}, \qquad V_{out,B} = \frac{2.2}{1 + A}.$$
- **线性区尾段：** $A^2[2(V_{in} - 0.7)V_{out} - V_{out}^2] = (2.2 - V_{out})^2$。

### 第 3 步 — 没有注入时（$V_{TN} \approx 0$，$V_{TP} \approx 1$ V）

$$V_{DD} - V_{TP} = 3 - 1 = 2.0\ \mathrm{V}.$$

- **没有“截止”区。** 在 $V_{in} = 0$ 时 $M_1$ 就已处于阈值，因此平坦段消失。此时平方律电流恰好为零，输出位于 $M_2$ 的导通边缘：
$$V_{out}(V_{in} = 0) = V_{DD} - V_{TP} = 2.0\ \mathrm{V}.$$
（实际上，$V_{GS1} = V_{THN}$ 时已有可观的亚阈值电流流过，因此 $V_{out}$ 略低于 2.0 V。）
- **饱和直线：**
$$V_{out} = 2.0 - A\,V_{in}.$$
- **线性区转折点：** 令 $V_{out} = V_{in} - 0$，
$$2.0 - AV_{in} = V_{in} \;\Longrightarrow\; V_{in,B} = V_{out,B} = \frac{2.0}{1 + A}.$$
- **线性区尾段：** $A^2[2V_{in}V_{out} - V_{out}^2] = (2.0 - V_{out})^2$。

### 第 4 步 — 比较两条直线段

$$
\begin{aligned}
\text{target:}\quad V_{out} &= 2.2 - A(V_{in} - 0.7) = (2.2 + 0.7A) - AV_{in},\\
\text{no implant:}\quad V_{out} &= 2.0 - AV_{in}.
\end{aligned}
$$

- **斜率同为 $-A$。** 斜率只取决于 $\mu_n(W/L)_1/[\mu_p(W/L)_2]$，而注入并不影响它，因此小信号增益 $-g_{m1}/g_{m2}$ 不变。
- **垂直偏移。** 在相同的 $V_{in}$ 下，无注入时的直线比目标直线低
$$\Delta V_{out} = (2.2 + 0.7A) - 2.0 = 0.2 + 0.7A\ \ \mathrm{V}.$$
- **几何图像。** $V_{out,new}(V_{in}) = 2.0 - AV_{in} = [2.2 - A((V_{in} + 0.7) - 0.7)] - 0.2 = V_{out,target}(V_{in} + 0.7) - 0.2$。该直线段就是把目标直线段**向左平移 0.7 V**（$V_{THN}$ 降低了 0.7 V，因此 $M_1$ 提前 0.7 V 导通）并**向下平移 0.2 V**（$|V_{THP}|$ 升高了 0.2 V，因此二极管负载上的压降多出 0.2 V）得到的。

### 第 5 步 — $V_{in} = 3$ V 处的低端

没有注入时尾段更低：$M_1$ 的过驱动电压为 $V_{in} - V_{TN} = 3$ V（而不是 2.3 V），因此其线性区电阻更小；而 $M_2$ 的导通范围变为 $V_{out} = 2.0$ V 以下（而不是 2.2 V 以下），因此在给定的 $V_{out}$ 下它提供的电流更小。

**$A = 2$ 时的数值示例。** 展开无注入时的线性区方程：

$$
\begin{aligned}
4(2V_{in}V_{out} - V_{out}^2) &= 4 - 4V_{out} + V_{out}^2\\
5V_{out}^2 - (8V_{in} + 4)V_{out} + 4 &= 0 .
\end{aligned}
$$

在 $V_{in} = 3$ V 处：$8(3) + 4 = 28$，因此

$$V_{out} = \frac{28 - \sqrt{28^2 - 4\cdot5\cdot4}}{2\cdot5} = \frac{28 - \sqrt{784 - 80}}{10} = \frac{28 - 26.53}{10} = 0.147\ \mathrm{V}.$$

对于目标情况（第 2 步的方程，$V_{in} - 0.7 = 2.3$ V），$5V_{out}^2 - 22.8V_{out} + 4.84 = 0$，因此

$$V_{out} = \frac{22.8 - \sqrt{519.84 - 96.8}}{10} = \frac{22.8 - 20.57}{10} = 0.223\ \mathrm{V}.$$

两组线性区方程中的常数不同，因此两条尾段并不是彼此精确平移的复制；只有直线段才是。

### 第 6 步 — 对照表（$A = 2$）

转折点：目标情况 $V_{in,B} = 0.7 + 2.2/3 = 1.433$ V（$V_{out} = 0.733$ V）；无注入时 $V_{in,B} = 2/3 = 0.667$ V（$V_{out} = 0.667$ V）。

| $V_{in}$ (V) | 目标情况 $V_{out}$ (V) | 无注入时 $V_{out}$ (V) |
|---|---|---|
| 0 | 2.20（截止） | 2.00（导通边缘） |
| 0.2 | 2.20（截止） | 1.60（饱和） |
| 0.5 | 2.20（截止） | 1.00（饱和） |
| 0.667 | 2.20（截止） | 0.667（转折点） |
| 0.7 | 2.20（开始导通） | 0.61（线性区） |
| 1.0 | 1.60（饱和） | 0.40 |
| 1.2 | 1.20（饱和） | 0.34 |
| 1.433 | 0.733（转折点） | 0.28 |
| 2.0 | 0.374 | 0.211 |
| 3.0 | 0.223 | 0.147 |

**草图。** 目标曲线在 0.7 V 之前平坦地保持在 2.2 V，然后以斜率 $-A$ 线性下降，在 1.43 V 处弯折，并逐渐变平至 0.22 V。无注入时的曲线在 $V_{in} = 0$ 处从 2.0 V 开始，立即以相同的斜率 $-A$ 下降，在 0.67 V 处弯折，并逐渐变平至约 0.15 V。整个放大区段都向左下方移动了。

### 第 7 步 — 实际后果

放大区内的增益不变，但在给定输入偏置下的工作点却大不相同。输入偏置在 $V_{in} = 1.0$ V 时，正处于目标电路直线段的中部（$V_{out} = 1.6$ V），却会把无注入的电路驱动到深线性区（$V_{out} = 0.4$ V），在那里增益很小，而且电流大得多，因为 $M_1$ 的过驱动电压为 1.0 V 而不是 0.3 V。可用的输入范围下移约 0.7 V。

### 结果

没有阈值调整注入时（$V_{THN} \approx 0$，$|V_{THP}| \approx 1$ V），令 $A = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_2]}$：

- **高电平：** 为 $V_{DD} - |V_{THP}| = 2.0$ V 而不是 2.2 V，并且没有平坦的“截止”区：$M_1$ 在 $V_{in} \approx 0$ 而不是 0.7 V 处开始导通。
- **直线段：** $V_{out} = 2.0 - AV_{in}$，而不是 $2.2 - A(V_{in} - 0.7)$：**斜率同为 $-A$**（小信号增益相同），向左平移 0.7 V、向下平移 0.2 V，即在相同 $V_{in}$ 下低 $0.2 + 0.7A$。
- **线性区转折点：** 位于 $V_{in} = V_{out} = 2/(1 + A)$，而不是 $(0.7 + 2.2/(1 + A),\ 2.2/(1 + A))$。
- **低电平：** 更低；$A = 2$ 时，$V_{out}(3\ \mathrm{V}) \approx 0.15$ V 而不是 0.22 V（转折点位于 0.67 V 而不是 1.43 V）。

**常见错误。** 只考虑 NMOS 阈值的变化。缺少注入还会使 $|V_{THP}|$ 从 0.8 V 升高到 1 V，从而使二极管负载决定的输出电平降低 0.2 V；忽略这一点会使整条曲线的垂直位置出错。

**常见错误。** 断定增益发生了变化。斜率 $-\sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_2]}$ 中不含阈值电压；阈值只会移动直线所在的位置。

**常见错误。** 把曲线向右移动。NMOS 阈值**更低**会使 $M_1$ 在**更小**的输入电压下导通，因此转换区向左移动。
