# 详细步骤 - R005

**思路。** 在平方律模型中，$V_{BS}$ 只通过阈值电压（threshold voltage）起作用，这就是体效应。因此对几个 $V_{BS}$ 值计算 $V_{TH}$，把同一条平方律曲线水平平移到各自的阈值处，再确定转折点（导通点，以及有限 $V_{DS}$ 下从饱和区到线性区的转变点）。

### 第 1 步 — 体效应方程

利用 $V_{SB} = -V_{BS}$，

$$
\begin{aligned}
V_{TH} &= V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right)\\
&= 0.7\ \mathrm{V} + 0.45\ \mathrm{V^{1/2}}\left(\sqrt{0.9\ \mathrm{V} - V_{BS}} - \sqrt{0.9\ \mathrm{V}}\right),
\end{aligned}
$$

下面的各次计算中都取 $\sqrt{0.9} = 0.9487\ \mathrm{V^{1/2}}$。$V_{BS}$ 越负（反向衬底偏置），栅下的耗尽区（depletion region）越宽，因此 $V_{TH}$ 升高。

### 第 2 步 — 各 $V_{BS}$ 值对应的阈值电压

**$V_{BS} = 0$：**

$$V_{TH} = 0.7 + 0.45\,(0.9487 - 0.9487) = 0.700\ \mathrm{V}.$$

**$V_{BS} = -1$ V：**

$$V_{TH} = 0.7 + 0.45\left(\sqrt{1.9} - 0.9487\right) = 0.7 + 0.45\,(1.3784 - 0.9487) = 0.7 + 0.45\times0.4297 = 0.7 + 0.1934 = 0.893\ \mathrm{V}.$$

**$V_{BS} = -2$ V：**

$$V_{TH} = 0.7 + 0.45\left(\sqrt{2.9} - 0.9487\right) = 0.7 + 0.45\,(1.7029 - 0.9487) = 0.7 + 0.45\times0.7543 = 0.7 + 0.3394 = 1.039\ \mathrm{V}.$$

**$V_{BS} = -3$ V：**

$$V_{TH} = 0.7 + 0.45\left(\sqrt{3.9} - 0.9487\right) = 0.7 + 0.45\,(1.9748 - 0.9487) = 0.7 + 0.45\times1.0262 = 0.7 + 0.4618 = 1.162\ \mathrm{V}.$$

**步长逐渐减小。** 相邻两次的平移量依次为

$$
\begin{aligned}
0 \to -1\ \mathrm{V}:&\quad 0.893 - 0.700 = 0.193\ \mathrm{V},\\
-1 \to -2\ \mathrm{V}:&\quad 1.039 - 0.893 = 0.146\ \mathrm{V},\\
-2 \to -3\ \mathrm{V}:&\quad 1.162 - 1.039 = 0.122\ \mathrm{V}.
\end{aligned}
$$

$V_{TH}$ 只按 $0.9\ \mathrm{V} - V_{BS}$ 的**平方根**增长：灵敏度 $\partial V_{TH}/\partial V_{SB} = \gamma/(2\sqrt{2|\phi_F| + V_{SB}})$ 从 $V_{SB} = 0$ 时的 $0.45/(2\times0.9487) = 0.237$ 下降到 $V_{SB} = 3$ V 时的 $0.45/(2\times1.9748) = 0.114$。

### 第 3 步 — 每条曲线的电流

记 $\beta = \mu_nC_{ox}W/L$，$V_{DS}$ 固定，每条曲线都以各自的阈值电压服从平方律：

- **截止**，$V_{GS} < V_{TH}(V_{BS})$：$I_D = 0$。
- **饱和区**，$V_{TH}(V_{BS}) < V_{GS} < V_{TH}(V_{BS}) + V_{DS}$：$I_D = \tfrac12\beta\,[V_{GS} - V_{TH}(V_{BS})]^2$。
- **线性区**，$V_{GS} > V_{TH}(V_{BS}) + V_{DS}$：$I_D = \beta\left\{[V_{GS} - V_{TH}(V_{BS})]V_{DS} - \tfrac12V_{DS}^2\right\}$。

$V_{BS}$ **只出现在 $V_{TH}$ 中**；$\beta$、抛物线形状以及线性区斜率 $\beta V_{DS}$ 对每条曲线都相同。因此每条曲线都是 $V_{BS} = 0$ 的曲线**向右平移** $\Delta V_{TH} = V_{TH}(V_{BS}) - 0.7$ V 的结果。

### 第 4 步 — 转折点

**第一个转折点（导通点）：** $V_{GS} = V_{TH}(V_{BS})$，即 $V_{BS} = 0$、$-1$、$-2$、$-3$ V 时分别为 0.70、0.89、1.04 和 1.16 V。

**第二个转折点（饱和区 → 线性区）：** $V_{GS} = V_{TH}(V_{BS}) + V_{DS}$，它取决于所选的 $V_{DS}$：

- 取 $V_{DS} = 0.5$ V 时，它分别位于 1.20、1.39、1.54 和 1.66 V。超过该点后，每条曲线都变为斜率为 $\beta V_{DS}$ 的直线，并与各自的抛物线相切。
- 若 $V_{DS}$ 较大（例如 $V_{DS} = 3$ V，$V_{GS}$ 扫描到 3 V），则每条曲线都满足 $V_{GS} - V_{TH} \le 2.3\ \mathrm{V} < V_{DS}$，因此第二个转折点落在图外，每条曲线都是纯抛物线。

### 第 5 步 — 曲线族的数值（$V_{DS}$ 较大，所有曲线都饱和）

$I_D/\beta$ 的数值，单位为 V²，由 $I_D/\beta = \tfrac12[V_{GS} - V_{TH}(V_{BS})]^2$ 算出：

| $V_{GS}$ (V) | $V_{BS} = 0$ ($V_{TH} = 0.70$) | $V_{BS} = -1$ V ($0.89$) | $V_{BS} = -2$ V ($1.04$) | $V_{BS} = -3$ V ($1.16$) |
|---|---|---|---|---|
| 1.0 | 0.045 | 0.006 | 0 | 0 |
| 1.5 | 0.320 | 0.184 | 0.106 | 0.057 |
| 2.0 | 0.845 | 0.612 | 0.461 | 0.351 |
| 2.5 | 1.620 | 1.291 | 1.067 | 0.895 |
| 3.0 | 2.645 | 2.219 | 1.922 | 1.690 |

例如，$V_{BS} = -2$ V、$V_{GS} = 2.0$ V 时：

$$\frac{I_D}{\beta} = \tfrac12\,(2.0 - 1.039)^2\ \mathrm{V^2} = \tfrac12\,(0.961)^2\ \mathrm{V^2} = \tfrac12\times0.923\ \mathrm{V^2} = 0.461\ \mathrm{V^2}.$$

**草图。** 四条形状完全相同的抛物线分别从横轴上的 0.70、0.89、1.04 和 1.16 V 处出发；$V_{BS}$ 越负，曲线越**靠右**，在任一给定 $V_{GS}$ 下的电流越小。相邻曲线之间的间距逐渐减小（0.19、0.15、0.12 V）。在相同电流下，各曲线的斜率相同（它们是平移得到的副本）；在相同 $V_{GS}$ 下，反向偏置（reverse-biased）的曲线较平缓，因为其过驱动电压（overdrive voltage）较小。

### 第 6 步 — 正的 $V_{BS}$

正的 $V_{BS}$ 会**降低**阈值电压，使曲线略微左移。例如，$V_{BS} = +0.3$ V 时：

$$V_{TH} = 0.7 + 0.45\left(\sqrt{0.6} - 0.9487\right) = 0.7 + 0.45\,(0.7746 - 0.9487) = 0.7 - 0.0783 = 0.622\ \mathrm{V}.$$

这只在几百毫伏以内有效：$V_{BS} > 0$ 会使源-衬底结正向偏置（forward-biased），超过约 0.4–0.6 V 后，该结会流过相当大的电流，而 MOS 模型无法描述这一电流。

### 结果

$V_{BS}$ 通过体效应使曲线**水平**平移：

$$V_{TH}(V_{BS}) = 0.7 + 0.45\left(\sqrt{0.9 - V_{BS}} - \sqrt{0.9}\right)\ \mathrm{V},$$

对 $V_{BS} = 0$、$-1$、$-2$、$-3$ V，分别得到 $V_{TH} \approx 0.70$、0.89、1.04 和 1.16 V。

- **第一个转折点**位于 $V_{GS} = V_{TH}(V_{BS})$：每条曲线在达到各自的阈值电压之前都为零，之后沿**同一条**平方律抛物线 $\tfrac12\mu_nC_{ox}(W/L)(V_{GS} - V_{TH})^2$ 上升，只是向右平移了 $\Delta V_{TH}$。因子 $\mu_nC_{ox}W/L$ 和曲线形状都不变。
- 对于固定的 $V_{DS}$，**第二个转折点**位于 $V_{GS} = V_{TH}(V_{BS}) + V_{DS}$，超过该点后曲线变为线性区中的直线。$V_{DS}$ 较大时，该点落在图外，所有曲线都保持饱和。
- $V_{BS}$ 等步长变化时，平移量**逐渐减小**（0.19、0.15、0.12 V），这是平方根关系的结果。正的 $V_{BS}$ 会使 $V_{TH}$ 略微降低，但这至多只适用于几百毫伏以内，再大源-衬底结就会导通。

**常见错误。** 对负的 $V_{BS}$ 把曲线向**左**平移。反向衬底偏置增加了栅极必须克服的耗尽电荷，因此阈值电压**升高**，曲线右移。

**常见错误。** 让斜率或因子 $\mu_nC_{ox}W/L$ 随 $V_{BS}$ 改变。在平方律模型中，$V_{BS}$ 只通过 $V_{TH}$ 起作用，因此各曲线彼此之间只是整体平移。

**常见错误。** 把曲线画成等间距，好像 $V_{TH}$ 与 $V_{BS}$ 成线性关系；或者漏掉 $\sqrt{2|\phi_F|}$ 项，这会在 $V_{BS} = -1$ V 时得到 $V_{TH} = 0.7 + 0.45\sqrt{1.9} = 1.32$ V，而不是 0.89 V。
