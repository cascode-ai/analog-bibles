# 详细步骤 - R324

**思路。** (i) 主输入置零后，除 $C_1$ 外的所有元件构成一个由电阻和受控源组成、不含独立源的网络，从 $C_1$ 的端子看进去它就是一个纯电阻 $R_1$；因此 $V_X/I_X = R_1\parallel(1/C_1s)$，其极点位于 $-1/(R_1C_1)$。(ii) 线性电路**任何**传递函数的极点都是电路的自然频率，它们只取决于去掉独立源后的网络，而与信号从何处输入、从何处输出无关。因此主传递函数具有相同的极点。

### 第 1 步 — 电路的其余部分是一个电阻

设 $C_1$ 接在节点 A 与 B 之间，于是 $V_X = V_A - V_B$；设 $I_{rest}$ 为测试源经 A 注入电路其余部分、再经 B 返回的电流。把主输入置零时，电压源变为短路（如图所示，输入端口被短路），电流源变为开路。

去掉 $C_1$ 后从 A、B 看进去，电路的其余部分是一个一端口网络，它：

1. **不含独立源**，因此其戴维南（Thevenin）电压为零；
2. 是**线性**的，因此端口电压与端口电流成正比；
3. **不含储能元件**，因此其方程中不含 $s$，比例常数与频率无关。

因此

$$V_X = R_1\,I_{rest},$$

其中实常数 $R_1$ 按定义就是 **$C_1$ 所看到的电阻**，它是在去掉 $C_1$、输入置零的情况下，于 A–B 之间加测试源求得的。受控源可能使 $R_1$ 与任何单个电阻都不同，甚至为负或无穷大，但它始终与频率无关。

### 第 2 步 — 阻抗 $V_X/I_X$

A 点的基尔霍夫电流定律（KCL），测试电流在 $C_1$ 与电路其余部分之间分流：

$$I_X = C_1s\,V_X + I_{rest} = C_1s\,V_X + \frac{V_X}{R_1},$$

$$
\begin{aligned}
I_X &= V_X\,\frac{1 + R_1C_1s}{R_1}\\
\frac{V_X}{I_X}(s) &= \frac{R_1}{1 + R_1C_1s} = R_1\parallel\frac{1}{C_1s},
\end{aligned}
$$

它只有一个极点，位于

$$s_p = -\frac{1}{R_1C_1},\qquad |\omega_p| = \frac{1}{R_1C_1}.$$

### 第 3 步 — 该极点就是电路的自然频率

**时域。** 当**所有**独立源都为零时，电路就是 $C_1$ 与 $R_1$ 并联。若电容上有初始电荷，A 点的 KCL 给出

$$C_1\frac{dV_X}{dt} = -\frac{V_X}{R_1}\quad\Longrightarrow\quad V_X(t) = V_X(0)\,e^{-t/(R_1C_1)}.$$

电路的其余部分是无记忆的，因此每个电压和电流都是 $V_X$ 的固定倍数，并以相同的指数衰减：一个储能元件给出一个一阶方程，恰好对应**一个自然频率** $s = -1/(R_1C_1)$。

**频域。** 把节点方程写成 $\mathbf{Y}(s)\,\mathbf{V} = \mathbf{J}$，其中 $\mathbf{Y}(s)$ 是节点导纳矩阵（包含电阻、受控源和 $C_1s$），$\mathbf{J}$ 为激励。

- 独立电流源只通过 $\mathbf{J}$ 进入方程；独立电压源确定某个节点电压，该电压从矩阵中消去并移入 $\mathbf{J}$。无论哪种情况，$\mathbf{Y}(s)$ 都是**去掉独立源后网络的矩阵**，即第 1–2 步中所用的网络。
- 由克拉默法则（Cramer's rule），任何节点电压都等于 $\Delta_k(s)/\det\mathbf{Y}(s)$，只有分子 $\Delta_k$ 取决于激励加在何处以及哪个节点作为输出。

因此电路的**每一个**传递函数的分母都是 $\det\mathbf{Y}(s)$。$V_X/I_X$ 就是其中之一，由第 2 步可知其分母在 $s = -1/(R_1C_1)$ 处为零；因此 $\det\mathbf{Y}(s)\propto 1 + R_1C_1s$，主传递函数 $V_{out}/V_{in}$ 的极点为

$$\omega_p = \frac{1}{R_1C_1}$$

（指幅值），除非其分子将它抵消（即零极点对消，例如所选输出与电容电压无关时）。

### 第 4 步 — 含受控源的例子

<!-- diagram: diagram-01.cir -->

以一个共源级（common-source stage）为例：栅极电阻为 $R_S$，漏极电阻为 $R_D$，栅极（A）与漏极（B）之间只有一个电容 $C_{GD}$。把输入置零（栅极经 $R_S$ 接地），去掉 $C_{GD}$，向栅极注入 $I_X$，并使其从漏极返回：

- 栅极：$V_G = I_XR_S$；
- 漏极（来自 $R_D$ 的电流同时供给 $M_1$ 和测试源）：$-V_D/R_D = g_mV_G + I_X$，因此 $V_D = -R_DI_X(1 + g_mR_S)$；
- $V_X = V_G - V_D = I_X\left[R_S + R_D(1 + g_mR_S)\right]$。

因此 $R_1 = R_S + R_D + g_mR_SR_D$，极点为 $1/[(R_S + R_D + g_mR_SR_D)C_{GD}]$，与精确传递函数 $\dfrac{(C_{GD}s - g_m)R_D}{1 + (R_S + R_D + g_mR_SR_D)C_{GD}s}$ 一致。受控源使 $R_1$ 远大于电路中的任何电阻：这正是从电阻角度看到的密勒效应（Miller effect）。

### 结果

主输入置零后，$C_1$ 所看到的网络只含电阻和受控源，不含独立源，因此它是一个与频率无关的电阻 $R_1$。测试电流在 $C_1$ 与 $R_1$ 之间分流：

$$\frac{V_X}{I_X}(s) = R_1\parallel\frac{1}{C_1s} = \frac{R_1}{1 + R_1C_1s},$$

其极点位于 $s = -1/(R_1C_1)$。这是电路唯一的自然频率（无独立源时的响应为 $V_X\propto e^{-t/(R_1C_1)}$），而电路的每一个传递函数都具有相同的分母，即节点方程的行列式，它与激励加在何处、取哪个量作为输出都无关。因此主传递函数的极点为 $|\omega_p| = 1/(R_1C_1)$（除非发生零极点对消）。

**常见错误。** 在主输入仍然起作用时计算 $R_1$，例如把输入电压源当作开路。自然频率属于去掉独立源后的网络：计算 $R_1$ 之前，电压源应变为短路，电流源应变为开路。

**常见错误。** 认为极点取决于信号加在何处或选择哪个输出。只有零点（分子）取决于这些；分母是网络本身的性质。

**常见错误。** 把 $R_1$ 取为某一个实际电阻（例如上例中只取 $R_S$ 或 $R_D$）。存在受控源时，必须用测试源求 $R_1$；它可能远大于任何电阻，甚至为负。
