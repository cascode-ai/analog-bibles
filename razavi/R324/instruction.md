Consider a linear circuit containing only one capacitor, $C_1$ (all other elements are resistors and controlled sources). We set the main input to zero and apply a current source $I_X$ in parallel with $C_1$ (labelled $I_{in}$ in [Fig. 1]), obtaining the voltage across $C_1$, $V_X$, and hence $V_X(s)/I_X(s)$. This impedance has the same pole as the main transfer function. Prove that the pole is given by $1/(R_1C_1)$, where $R_1$ is the resistance seen by $C_1$ (with the main input set to zero).
