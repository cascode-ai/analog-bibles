# 详细步骤 - R696

**思路。** 在给定的（目标）尾电流下，用器件参数写出以有源电流镜为负载的差分对的小信号增益，然后检查每种制造错误改变了哪些参数。由于偏置电流固定，凡是只通过阈值电压（threshold voltage）起作用的因素都会消失；起作用的是输入对管的 $\mu_nC_{ox}(W/L)$ 以及各个 $\lambda$。

### 第 1 步 — 固定尾电流下的增益

把 NMOS 输入对管记为 $M_1$、$M_2$（尾电流为 $I_{SS}$），PMOS 电流镜记为 $M_3$ 和 $M_4$，前者二极管连接（diode-connected），位于 $M_1$ 一侧；输出取自 $M_2$ 与 $M_4$ 的漏极。平衡时每个器件的电流为 $I_D = I_{SS}/2$。该级的标准结果是 $G_m \approx g_{m1}$（电流镜把 $M_1$ 的电流复制到输出端）以及 $R_{out} \approx r_{O2}\parallel r_{O4}$，因此

$$|A_v| = G_mR_{out} = g_{m1}\,(r_{O2}\parallel r_{O4}).$$

利用 $r_O = 1/(\lambda I_D)$：

$$
\begin{aligned}
g_{m1} &= \sqrt{2\mu_nC_{ox}\Big(\frac{W}{L}\Big)_1\frac{I_{SS}}{2}} = \sqrt{\mu_nC_{ox}\Big(\frac{W}{L}\Big)_1I_{SS}},\\
r_{O2}\parallel r_{O4} &= \frac{1}{\lambda_n\dfrac{I_{SS}}{2} + \lambda_p\dfrac{I_{SS}}{2}} = \frac{2}{(\lambda_n + \lambda_p)I_{SS}},\\
|A_v| &= \sqrt{\mu_nC_{ox}\Big(\frac{W}{L}\Big)_1I_{SS}}\cdot\frac{2}{(\lambda_n + \lambda_p)I_{SS}} = \frac{2}{\lambda_n + \lambda_p}\sqrt{\frac{\mu_nC_{ox}(W/L)_1}{I_{SS}}} .
\end{aligned}
$$

在 $I_{SS}$ 等于目标值的情况下，增益只有在以下情况下才会下降：

- **输入**晶体管的 $\mu_nC_{ox}$ 下降（$g_{m1}$ 降低），或
- $\lambda_n$ 或 $\lambda_p$ 增大（$r_O$ 降低），或
- 某个器件因电压余度不足而退出饱和区（saturation region），这属于偏置点问题。

阈值电压、PMOS 的迁移率以及 $g_{m3}$ 都**不出现**在式中：电流镜的跨导（transconductance）决定的是镜像极点（速度），而不是低频增益。

### 第 2 步 — (a) n 阱注入剂量过大：不是原因

n 阱注入剂量增大只影响 **PMOS** 器件 $M_3$、$M_4$；NMOS 输入对管位于衬底中。

- **$|V_{THP}|$ 增大**（耗尽电荷增多）。在固定电流下，它不出现在增益中。
- **空穴迁移率降低**（杂质散射增强）。这会降低 $g_{m3}$，而它只影响镜像极点。
- 在掺杂更重的阱中，**漏极耗尽区更窄**，因此 $\lambda_p$ 减小，$r_{O4}$ **增大**。如果说有影响，增益反而会**升高**。
- 阱电容和漏结电容（junction capacitance）增大，这影响的是速度，而不是直流增益。

(a) 唯一可能造成不利影响的途径是**电压余度**：$|V_{GS3}| = |V_{THP}| + |V_{ov3}|$ 增大，因为阈值更高，并且由于迁移率降低，过驱动电压（overdrive voltage）也更大；于是 $M_1$ 和 $M_2$ 的漏极电位 $V_{DD} - |V_{GS3}|$ 更低，在输入共模电平较高时 $M_1$、$M_2$ 可能进入线性区。这取决于偏置电平，并不是增益本身的降低。**结论：不能解释该现象。**

### 第 3 步 — (b) 阈值调整注入剂量过大：不是原因

常用的 p 型（硼）调整注入剂量增大，会使 $V_{THN}$ 升高、$|V_{THP}|$ 降低。

- **在固定电流下，$V_{TH}$ 不出现在增益中。** $g_m = \sqrt{2\mu C_{ox}(W/L)I_D}$ 和 $r_O = 1/(\lambda I_D)$ 中都不含阈值；器件只是稳定在不同的 $V_{GS} = V_{TH} + V_{ov}$ 上，而 $V_{ov}$ 相同。
- **电压余度。** $|V_{THP}|$ 减小使 $|V_{GS3}|$ 减小，因此 $M_1$、$M_2$ 的漏极电位**更高**，输入对管有更大的余量。$V_{THN}$ 增大会使输入共模范围上移，但其本身不会把任何器件推入线性区；尾电流仍为目标值。
- **二阶效应。** 沟道掺杂加重会使迁移率略有下降（$g_{m1}$ 略低），并使 $\lambda$ 略有减小（$r_O$ 增大）；二者大致相互抵消，影响很小。

**结论：不能解释该现象。**

### 第 4 步 — (c) 栅氧化时间过长：原因所在

较长的氧化时间会生长出**更厚的栅氧化层**，因此所有晶体管的 $C_{ox} = \varepsilon_{ox}/t_{ox}$ 都**减小**。在目标尾电流下：

- **$g_{m1}$ 下降：**
$$g_{m1} = \sqrt{\mu_nC_{ox}\Big(\frac{W}{L}\Big)_1I_{SS}} \;\propto\; \sqrt{C_{ox}} .$$
相同的电流需要更大的过驱动电压，于是 $g_m = 2I_D/V_{ov}$ 更小。
- **$r_O$ 基本不变**，因为 $r_O = 1/(\lambda I_D)$ 与 $C_{ox}$ 无关。如果说有影响的话，较厚的氧化层使栅极控制减弱，沟道长度调制（channel-length modulation）反而会略微加剧。

因此

$$|A_v| = \frac{2}{\lambda_n + \lambda_p}\sqrt{\frac{\mu_nC_{ox}(W/L)_1}{I_{SS}}} \;\propto\; \sqrt{C_{ox}} \;\propto\; \frac{1}{\sqrt{t_{ox}}}$$

会下降。例如，氧化层比设计值厚 30 % 时

$$\frac{|A_v|_{\text{actual}}}{|A_v|_{\text{target}}} = \sqrt{\frac{t_{ox,\text{target}}}{t_{ox,\text{actual}}}} = \sqrt{\frac{1}{1.3}} = 0.877,$$

即增益约降低 12 %；氧化层厚度加倍会使增益降为目标值的 $1/\sqrt2 \approx 0.71$。**结论：是，这能解释增益偏低。**

### 结果

- **(a) n 阱注入剂量过大 — 否。** 它只影响 PMOS 负载：$|V_{THP}|$ 更高，空穴迁移率更低，$\lambda_p$ 更小（$r_{O4}$ 更大）。这些都不会降低 $g_{m1}(r_{O2}\parallel r_{O4})$；只有在输入共模电平较高时损失电压余度才可能产生不利影响。
- **(b) 阈值调整注入剂量过大 — 否。** 它使阈值移动，但在固定偏置电流下 $g_m$ 和 $r_O$ 都与 $V_{TH}$ 无关；输入对管的电压余度甚至会改善。
- **(c) 栅氧化时间过长 — 是。** 较厚的氧化层使 $C_{ox}$ 减小，因此在目标电流下 $g_{m1} = \sqrt{\mu_nC_{ox}(W/L)_1I_{SS}}$ 按 $\sqrt{C_{ox}}$ 下降，而 $r_O$ 不变；增益 $|A_v| = g_{m1}(r_{O2}\parallel r_{O4})$ 相应下降。

**常见错误。** 以“阈值升高会降低 $g_m$”为理由选择 (b)。这只在 $V_{GS}$ 固定时成立；这里固定的是尾电流，因此过驱动电压和 $g_m = \sqrt{2\mu C_{ox}(W/L)I_D}$ 都不变。

**常见错误。** 因为 PMOS 器件性能变差而选择 (a)。电流镜的跨导并不出现在低频增益中，而且阱掺杂加重实际上会**提高** $r_{O4}$。

**常见错误。** 认为较厚的氧化层会提高增益，理由是“$g_m$ 下降时 $r_O$ 会增大”。在固定偏置电流下，$r_O = 1/(\lambda I_D)$ 不变；只有 $g_m$ 下降。
