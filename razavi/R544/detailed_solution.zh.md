# 详细步骤 - R544

**思路。** 利用 $R$ 使 $M_1$ 的漏极比其栅极高 $RI_{REF}$ 这一事实，把每个栅源电压和漏源电压都用内部节点电压表示。于是每个晶体管的饱和条件都给 $RI_{REF}$ 一个界限：$M_1$ 给出上界，$M_2$ 给出下界。体效应通过 $M_1$ 起作用，因为它的源极不在衬底电位上。

### 第 1 步 — 节点与基本关系

把 $M_2$ 的漏极（$M_1$ 的源极）记为 S，$M_1$ 的漏极（$R$ 的上端、$M_2$ 的栅极）记为 D，$R$ 的下端（$M_1$ 的栅极，$I_{REF}$ 从此处抽出）记为 E。栅极不吸取电流，因此 $I_{REF}$ 流过 $M_2$、$M_1$ 和 $R$：

$$V_D - V_E = RI_{REF},$$

$$
\begin{aligned}
M_2:&\quad |V_{GS2}| = V_{DD} - V_D, & |V_{DS2}| &= V_{DD} - V_S,\\
M_1:&\quad |V_{GS1}| = V_S - V_E, & |V_{DS1}| &= V_S - V_D .
\end{aligned}
$$

把后两式与电阻压降结合：

$$|V_{DS1}| = (V_S - V_E) - (V_D - V_E) = |V_{GS1}| - RI_{REF}. \tag{1}$$

若 $|V_{DS}| \ge |V_{GS}| - |V_{TH}|$，即漏极比栅极高出的量不超过 $|V_{TH}|$，则该 PMOS 处于饱和。

### 第 2 步 — $M_1$ 饱和：上界

利用式 (1)：

$$|V_{GS1}| - RI_{REF} \ge |V_{GS1}| - |V_{TH1}| \quad\Longrightarrow\quad RI_{REF} \le |V_{TH1}| .$$

$M_1$ 的漏极（D）比其栅极（E）高 $RI_{REF}$，这个值不能超过一个阈值电压；压降更大就会把 $M_1$ 推入线性区（triode region）。

### 第 3 步 — $M_2$ 饱和：下界

对 $M_2$（栅极为 D，漏极为 S），饱和要求 $V_S \le V_D + |V_{TH2}|$：

$$V_S - V_D \le |V_{TH2}| \quad\Longleftrightarrow\quad |V_{DS1}| \le |V_{TH2}| ,$$

再利用式 (1)：

$$|V_{GS1}| - RI_{REF} \le |V_{TH2}| \quad\Longrightarrow\quad RI_{REF} \ge |V_{GS1}| - |V_{TH2}| .$$

如果压降太小，$M_1$ 就会占用过大的 $|V_{DS}|$，把 $M_2$ 挤入线性区。

### 第 4 步 — 综合结果及其含义

$$\boxed{|V_{GS1}| - |V_{TH2}| \;\le\; RI_{REF} \;\le\; |V_{TH1}|}$$

利用 $|V_{GS1}| = |V_{TH1}| + V_{ov1}$ 以及 $V_{ov1} = \sqrt{2I_{REF}/[\mu_pC_{ox}(W/L)_1]}$：

$$V_{ov1} + \left(|V_{TH1}| - |V_{TH2}|\right) \;\le\; RI_{REF} \;\le\; |V_{TH1}| .$$

不计体效应时（$|V_{TH1}| = |V_{TH2}| = |V_{TH}|$）：

$$V_{ov1} \le RI_{REF} \le |V_{TH}| \approx 0.8\ \mathrm{V}.$$

$R$ 上的压降至少要等于 $M_1$ 的过驱动电压（使 $M_2$ 保持足够的 $|V_{DS}|$），但又要小于一个阈值电压（使 $M_1$ 保持饱和）；只要 $V_{ov1} < |V_{TH2}|$，就存在这样的窗口。

### 第 5 步 — $M_1$ 的体效应

$M_2$ 的源极位于其衬底电位（$V_{DD}$），因此 $|V_{TH2}| = |V_{TH0}| = 0.8$ V。$M_1$ 的源极比其衬底低 $|V_{DS2}|$：

$$|V_{TH1}| = |V_{TH0}| + \gamma\left(\sqrt{2|\phi_F| + |V_{DS2}|} - \sqrt{2|\phi_F|}\right) = 0.8 + 0.4\left(\sqrt{0.8 + |V_{DS2}|} - \sqrt{0.8}\right)\ \mathrm{V}.$$

因此 $|V_{TH1}| > |V_{TH2}|$，两个界限都上移：下界上移 $|V_{TH1}| - |V_{TH2}|$，上界则移到更大的 $|V_{TH1}|$。

**示例。** 两个器件的尺寸都按 $V_{ov1} = V_{ov2} = 0.2$ V 设计，由节点关系得 $|V_{DS2}| = |V_{GS2}| - |V_{DS1}| = |V_{GS2}| - |V_{GS1}| + RI_{REF}$。

- **在下界处**，$M_2$ 处于饱和边缘，$|V_{DS2}| = V_{ov2} = 0.2$ V：
$$|V_{TH1}| = 0.8 + 0.4(\sqrt{1.0} - 0.894) = 0.842\ \mathrm{V},\qquad RI_{REF,min} = 0.2 + 0.042 = 0.24\ \mathrm{V}.$$
- **在上界处**，$RI_{REF} = |V_{TH1}|$，因此 $|V_{DS2}| = (0.2 + 0.8) - (0.2 + |V_{TH1}|) + |V_{TH1}| = 0.8$ V：
$$|V_{TH1}| = 0.8 + 0.4(\sqrt{1.6} - 0.894) = 0.8 + 0.4(1.265 - 0.894) = 0.948\ \mathrm{V} = RI_{REF,max}.$$

因此 $0.24\ \mathrm{V} \lesssim RI_{REF} \lesssim 0.95$ V，而不计体效应时为 $0.2$–$0.8$ V。

### 结果

$$|V_{GS1}| - |V_{TH2}| \;\le\; RI_{REF} \;\le\; |V_{TH1}| .$$

- **最大值** $|V_{TH1}|$ 使 $M_1$ 保持饱和（其漏极比栅极高出的量不能超过一个阈值电压）。
- **最小值** $|V_{GS1}| - |V_{TH2}| = V_{ov1} + (|V_{TH1}| - |V_{TH2}|)$ 使 $M_2$ 保持饱和（它要求 $|V_{DS1}| \le |V_{TH2}|$）。

不计体效应时为 $V_{ov1} \le RI_{REF} \le |V_{TH}| \approx 0.8$ V，其中 $V_{ov1} = \sqrt{2I_{REF}/[\mu_pC_{ox}(W/L)_1]}$。计入体效应时，$M_1$ 的源极比其衬底低 $|V_{DS2}|$，因此 $|V_{TH1}| = 0.8 + 0.4(\sqrt{0.8 + |V_{DS2}|} - \sqrt{0.8})$ V 大于 $|V_{TH2}| = 0.8$ V，两个界限都相应升高。

**常见错误。** 把两个界限弄反，例如写成 $RI_{REF} \ge |V_{TH}|$ 或 $RI_{REF} \le V_{ov}$。$R$ 上的压降越大，$M_1$ 的漏极就越接近“栅极电压加阈值电压”（对 $M_1$ 不利），但同时 $M_1$ 的 $|V_{DS}|$ 降低（对 $M_2$ 有利）。

**常见错误。** 把 $M_1$ 的栅极接到它自己的漏极（$R$ 的上端），这会使它成为二极管连接（diode-connected）的器件，$R$ 也就与它的饱和无关了。这里 $M_1$ 的栅极接在 $R$ 的**下端**，而 $M_2$ 的栅极接在**上端**。

**常见错误。** 不加说明地对两个器件使用同一个阈值电压。$M_1$ 的源极不在 $V_{DD}$，因此体效应会提高其阈值电压，并使两个界限都发生偏移，在上面的示例中偏移约 0.04–0.15 V。
