# 详细步骤 - R101

**思路。** 测试源 $V_X$ 直接决定 $M_1$ 的漏极电压。由漏极节点的 KCL，$I_X$ 等于晶体管电流减去 $R_D$ 提供的电流。分别求出 $M_1$ 在线性区（$V_X < V_b - 0.7$ V）和饱和区（$V_X \ge V_b - 0.7$ V）的电流，再加上电阻电流这一直线项。

### 第 1 步 — 漏极节点的 KCL

$I_X$ 从测试源流入漏极节点，此处 $V_{GS} = V_b$（固定），$V_{DS} = V_X$，$V_{TH} = 0.7$ V。KCL：

$$I_X + \frac{V_{DD} - V_X}{R_D} = I_{D1} \quad\Longrightarrow\quad I_X = I_{D1} - \frac{V_{DD} - V_X}{R_D} .$$

因此 $I_X$ 等于晶体管电流减去电阻电流；电阻项 $-(3 - V_X)/R_D$ 是一条直线，从 $V_X = 0$ 时的 $-3/R_D$ 上升到 $V_X = 3$ V 时的 0。

### 第 2 步 — $M_1$ 的电流与其漏极电压的关系

假设 $V_b > 0.7$ V（否则 $M_1$ 截止，$I_X = (V_X - 3)/R_D$，为一条直线）。过驱动电压（overdrive voltage）固定为 $V_b - 0.7$ V：

- **线性区，$0 \le V_X < V_b - 0.7$ V：**
$$I_{D1} = \beta\left[(V_b - 0.7)V_X - \tfrac12V_X^2\right],$$
在 $V_X = 0$ 时从 0 开始，以逐渐减小的斜率上升。
- **饱和区，$V_X \ge V_b - 0.7$ V：**
$$I_{D1} = I_1 = \frac12\beta(V_b - 0.7)^2 ,$$
为常数（$\lambda = 0$）。

在 $V_X = V_b - 0.7$ 处，线性区公式给出 $\beta[(V_b - 0.7)^2 - \frac12(V_b - 0.7)^2] = \frac12\beta(V_b - 0.7)^2$，因此两段连续衔接。

### 第 3 步 — 各区域中的 $I_X$

**在 $V_X = 0$ 处：** $I_{D1} = 0$，因此

$$I_X(0) = -\frac{V_{DD}}{R_D} = -\frac{3\ \mathrm{V}}{R_D} ,$$

为负值：$R_D$ 向源 $V_X$ 注入电流。

**线性区（$0 < V_X < V_b - 0.7$ V）：**

$$I_X = \beta\left[(V_b - 0.7)V_X - \tfrac12V_X^2\right] - \frac{3 - V_X}{R_D} ,$$

其斜率（即 $V_X$ 看到的增量电导）为

$$\frac{dI_X}{dV_X} = \beta(V_b - 0.7 - V_X) + \frac{1}{R_D} ,$$

即 $M_1$ 的线性区沟道电导与 $1/R_D$ 并联：**在 $V_X = 0$ 处很陡**，等于 $\beta(V_b - 0.7) + 1/R_D$，并在饱和边缘处**减小到 $1/R_D$**。

**饱和区（$V_X \ge V_b - 0.7$ V）：**

$$I_X = I_1 - \frac{3 - V_X}{R_D} = \frac12\beta(V_b - 0.7)^2 - \frac{3 - V_X}{R_D} ,$$

这是一条**斜率为 $1/R_D$ 的直线**，在 $V_X = V_{DD}$ 处电阻电流为零，$I_X = I_1$。（若计入沟道长度调制，斜率将为 $1/R_D + \lambda I_1$。）

**过零点。** 当 $I_{D1} = (3 - V_X)/R_D$ 时 $I_X = 0$，此时的电压就是不接测试源时该节点自身的电压。

### 第 4 步 — 数值示例

为便于说明，取 $V_b = 1.2$ V（过驱动电压为 0.5 V），$\beta = 4\ \mathrm{mA/V^2}$，$R_D = 10\ \mathrm{k}\Omega$：

$$I_1 = \tfrac12(4\ \mathrm{mA/V^2})(0.5\ \mathrm{V})^2 = 0.5\ \mathrm{mA}, \qquad I_X(0) = -\frac{3\ \mathrm{V}}{10\ \mathrm{k}\Omega} = -0.3\ \mathrm{mA}.$$

起始斜率：$(4\ \mathrm{mA/V^2})(0.5\ \mathrm{V}) + 0.1\ \mathrm{mS} = 2.1$ mS；越过边界后的斜率：$0.1$ mS。

**过零点**（在线性区内）：$4(0.5V_X - 0.5V_X^2) = 0.1(3 - V_X)$（电流以 mA 为单位，$V_X$ 以伏特为单位），即 $2V_X^2 - 2.1V_X + 0.3 = 0$，因此 $V_X = (2.1 - \sqrt{4.41 - 2.4})/4 = 0.171$ V。

| $V_X$ (V) | 工作区 | $I_{D1}$ (mA) | $(3 - V_X)/R_D$ (mA) | $I_X$ (mA) |
|---|---|---|---|---|
| 0 | 线性区 | 0 | 0.30 | −0.30 |
| 0.1 | 线性区 | 0.18 | 0.29 | −0.11 |
| 0.171 | 线性区 | 0.283 | 0.283 | 0 |
| 0.3 | 线性区 | 0.42 | 0.27 | 0.15 |
| 0.5 | 边界 | 0.50 | 0.25 | 0.25 |
| 1.0 | 饱和 | 0.50 | 0.20 | 0.30 |
| 2.0 | 饱和 | 0.50 | 0.10 | 0.40 |
| 3.0 | 饱和 | 0.50 | 0 | 0.50 |

### 结果

$$I_X = I_{D1} - \frac{V_{DD} - V_X}{R_D}$$

（漏极节点的 KCL），由此得：

- **起点：** $I_X(0) = -V_{DD}/R_D = -3\ \mathrm{V}/R_D$，因为 $V_{DS} = 0$ 时 $I_{D1} = 0$。
- **$0 < V_X < V_b - 0.7$ V（线性区）：** $I_{D1} = \beta[(V_b - 0.7)V_X - V_X^2/2]$；$I_X$ 急剧上升，斜率 $\beta(V_b - 0.7 - V_X) + 1/R_D$ 在边界处减小到 $1/R_D$。
- **$V_X \ge V_b - 0.7$ V（饱和区）：** $I_{D1} = I_1 = \tfrac12\beta(V_b - 0.7)^2$，因此 $I_X = I_1 - (3 - V_X)/R_D$，这是一条斜率为 $1/R_D$ 的直线（若计入沟道长度调制，还需加上 $\lambda I_1$），在 $V_X = V_{DD}$ 时达到 $I_1$。
- **过零点**满足 $I_{D1} = (3 - V_X)/R_D$。若 $V_b \le 0.7$ V，$M_1$ 截止，$I_X = (V_X - 3)/R_D$。

**常见错误。** 只考虑晶体管电流（一条从 0 开始、饱和于 $I_1$ 的曲线），或只考虑电阻电流。$V_X$ 既要向 $M_1$ 供电，**又**要吸收经 $R_D$ 流下来的电流。

**常见错误。** 弄错电阻项的符号，导致 $I_X$ 随 $V_X$ 减小。随着 $V_X$ 升高，$M_1$ 吸取的电流增大（或不变），而 $R_D$ 提供的电流减小，因此 $I_X$ 单调增大。

**常见错误。** 认为 $M_1$ 在 $V_X = 0$ 时处于饱和区并流过 $I_1$。漏源电压为零时没有电流；器件只有在 $V_X = V_b - 0.7$ V 时才进入饱和。
