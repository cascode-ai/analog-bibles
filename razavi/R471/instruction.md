Determine the slew rate of a fully differential folded-cascode op amp. Let the input differential pair be biased by a tail current $I_{SS}$; let each of the two current sources at the folding nodes carry $I_P$, so that each cascode branch and each output-side current source carries $I_P - I_{SS}/2$ in equilibrium; and let each output drive a load capacitance $C_L$ (neglect other capacitances). Consider a large differential input step.
