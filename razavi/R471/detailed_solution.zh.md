# 详细步骤 - R471

**思路。** 大的差分阶跃会使输入差分对完全切换，因此全部 $I_{SS}$ 都流过一个输入晶体管。此时折叠节点和输出节点处的电流都是确定的，每个输出电容以恒定电流充电或放电。对两侧的折叠节点和输出节点列 KCL 方程，即可得到各 $dV_{out}/dt$ 和差分压摆率，并看出共源共栅管何时截止。

### 第 1 步 — 拓扑与平衡时的电流

题目没有给出电路图，因此采用标准的全差分折叠式共源共栅结构：

- NMOS 输入对管 $M_1$（栅极接 $V_{in1}$，漏极接折叠节点 X）和 $M_2$（栅极接 $V_{in2}$，漏极接折叠节点 Y），尾电流为 $I_{SS}$；
- PMOS 电流源 $M_3$（流入 X）和 $M_4$（流入 Y），各流过 $I_P$；
- PMOS 共源共栅管 $M_5$（从 X 向下接到 $V_{out1}$）和 $M_6$（从 Y 向下接到 $V_{out2}$）；
- 输出端下方的 NMOS 共源共栅管 $M_7$、$M_8$ 和 NMOS 电流源 $M_9$、$M_{10}$，各吸收 $I_P - I_{SS}/2$；
- 每个输出端接负载 $C_L$，忽略其他所有电容。

平衡时（$V_{in1} = V_{in2}$），每个输入器件从各自的折叠节点抽走 $I_{SS}/2$，因此由节点 X 的 KCL，共源共栅管 $M_5$ 流过

$$I_{D5} = I_P - \frac{I_{SS}}{2},$$

恰好等于 $M_9$ 吸收的电流；流入每个 $C_L$ 的净电流为零。

### 第 2 步 — 大的差分阶跃

当 $V_{in1} - V_{in2}$ 远大于差分对平衡时过驱动电压（overdrive voltage）的 $\sqrt2$ 倍时，$M_1$ 获得全部尾电流，$M_2$ 截止：

$$I_{D1} = I_{SS}, \qquad I_{D2} = 0 .$$

其他电流源都保持原值（$M_3$、$M_4$：$I_P$；$M_9$、$M_{10}$：$I_P - I_{SS}/2$），而由于 $C_L$ 的存在，输出不能跳变。

### 第 3 步 — 第 1 侧（折叠节点 X，输出 $V_{out1}$）

**节点 X 的 KCL。** $I_P$ 从 $M_3$ 流入，$I_{SS}$ 经 $M_1$ 流出，因此共源共栅管流过

$$I_{D5} = I_P - I_{SS},$$

这要求 $I_P \ge I_{SS}$（见第 6 步）。

**$V_{out1}$ 的 KCL。** $M_7$/$M_9$ 抽走 $I_P - I_{SS}/2$，因此流入 $C_L$ 的净电流为

$$I_{C1} = (I_P - I_{SS}) - \left(I_P - \frac{I_{SS}}{2}\right) = -\frac{I_{SS}}{2},$$

因此

$$\frac{dV_{out1}}{dt} = \frac{I_{C1}}{C_L} = -\frac{I_{SS}}{2C_L}.$$

### 第 4 步 — 第 2 侧（折叠节点 Y，输出 $V_{out2}$）

$M_2$ 截止，来自 $M_4$ 的 $I_P$ 全部向下流过 $M_6$：$I_{D6} = I_P$。在 $V_{out2}$ 处：

$$I_{C2} = I_P - \left(I_P - \frac{I_{SS}}{2}\right) = +\frac{I_{SS}}{2},$$

$$\frac{dV_{out2}}{dt} = +\frac{I_{SS}}{2C_L}.$$

### 第 5 步 — 差模与共模压摆率

$$
\begin{aligned}
\frac{d(V_{out1} - V_{out2})}{dt} &= -\frac{I_{SS}}{2C_L} - \frac{I_{SS}}{2C_L} = -\frac{I_{SS}}{C_L},\\
\frac{d}{dt}\left(\frac{V_{out1} + V_{out2}}{2}\right) &= \frac12\left(-\frac{I_{SS}}{2C_L} + \frac{I_{SS}}{2C_L}\right) = 0 .
\end{aligned}
$$

因此

$$SR_{single\text{-}ended} = \frac{I_{SS}}{2C_L}, \qquad SR_{differential} = \frac{I_{SS}}{C_L}.$$

两个输出端以相反方向对称地压摆，因此输出共模电平保持不变，共模反馈环路不受干扰（负阶跃时两侧的情况互换）。

| 压摆期间的物理量 | 第 1 侧（$M_1$ 导通） | 第 2 侧（$M_2$ 截止） |
|---|---|---|
| 输入器件电流 | $I_{SS}$ | 0 |
| 共源共栅管电流 | $I_P - I_{SS}$ | $I_P$ |
| 输出侧吸收的电流 | $I_P - I_{SS}/2$ | $I_P - I_{SS}/2$ |
| 流入 $C_L$ 的净电流 | $-I_{SS}/2$ | $+I_{SS}/2$ |
| 输出斜率 | $-I_{SS}/(2C_L)$ | $+I_{SS}/(2C_L)$ |

压摆率由尾电流决定，而不是由 $I_P$ 决定，后者只是让 $I_{SS}$ 经过折叠节点改变流向；每个输出端看到的不平衡电流为 $I_{SS}/2$，因为平衡时每一侧已经流过 $I_{SS}$ 的一半。

### 第 6 步 — 条件 $I_P \ge I_{SS}$，以及不满足时会怎样

上述推导要求 $I_{D5} = I_P - I_{SS} \ge 0$，即 **$I_P \ge I_{SS}$**。（常见的选择是 $I_P = I_{SS}$，这样平衡时每条共源共栅支路流过 $I_{SS}/2$，条件恰好满足。）

若 $I_P < I_{SS}$，$M_1$ 需要的电流超过 $M_3$ 所能提供的：$M_5$ 截止，X 向地崩塌，尾电流源得不到足够的电流，$M_1$/尾电流管退出饱和区（saturation region），整个差分对总共只能吸取 $I_P$。于是：

- $V_{out1}$ 从 $M_5$ 得不到任何电流，以 $(I_P - I_{SS}/2)/C_L$ 的速率下降，**慢于** $I_{SS}/(2C_L)$；
- $V_{out2}$ 仍以 $I_{SS}/(2C_L)$ 的速率上升；
- 差分压摆率变为 $[(I_P - I_{SS}/2) + I_{SS}/2]/C_L = I_P/C_L$；
- 两个斜率不相等会扰动输出共模电平，而且之后 X 必须从崩塌状态重新充电，导致恢复缓慢。

### 结果

对于大的差分阶跃，当 $I_P \ge I_{SS}$ 时，每个输出端的压摆率为

$$SR = \frac{I_{SS}}{2C_L}$$

（一个输出上升，另一个下降），差分输出的压摆率为

$$SR_{diff} = \frac{I_{SS}}{C_L}.$$

输出共模电平保持不变。若 $I_P < I_{SS}$，则有一个共源共栅器件截止：该输出端的压摆率只有 $(I_P - I_{SS}/2)/C_L$，差分压摆率降到 $I_P/C_L$，电流不足的折叠节点会崩塌，导致恢复缓慢。

**常见错误。** 在 $I_P \ge I_{SS}$ 时把压摆率取为 $I_P/C_L$（或 $(I_P - I_{SS}/2)/C_L$）。$I_P$ 与 $I_P - I_{SS}/2$ 在输出节点的 KCL 中相互抵消；只有改变了流向的尾电流会出现。

**常见错误。** 对每个输出端都写成 $I_{SS}/C_L$。每个输出端的净电流只有 $\pm I_{SS}/2$；$I_{SS}/C_L$ 是 $V_{out1} - V_{out2}$ 的压摆率。

**常见错误。** 以为压摆期间共源共栅管的电流保持不变。恰恰是它们的电流发生了变化：一侧为 $I_P - I_{SS}$，另一侧为 $I_P$。
