λ = 0 时 $|A_v| = g_{m1}/g_{m3} \approx 4.2$；计入沟道长度调制（channel-length modulation）时 ≈ 3.6。
- $g_{m1} = \sqrt{2(134\ \mu\times100)(0.5\ \mathrm{mA})} = 3.66$ mS。$M_3$ 流过 $0.2 \times 0.5 = 0.1$ mA：$g_{m3} = \sqrt{2(38.4\ \mu\times100)(0.1\ \mathrm{mA})} = 0.876$ mS（$1/g_{m3} = 1.14$ kΩ）。
- 半边电路（half circuit）：$|A_v| = g_{m1}(1/g_{m3}\|r_{O1}\|r_{O3}\|r_{O5})$，其中 $r_{O1} = 20$ kΩ，$r_{O3} = 1/(0.2\times0.1\ \mathrm{m}) = 50$ kΩ，$r_{O5} = 1/(0.2\times0.4\ \mathrm{m}) = 12.5$ kΩ：$3.66\ \mathrm{m}\times 0.974\ \mathrm{k} \approx 3.57$；λ = 0 时 $g_{m1}/g_{m3} = 4.18$。
- （若没有 $M_5$、$M_6$，同样的负载流过 0.5 mA，得 $g_{m1}/g_{m3} = 1.87$；由于这里 W/L 没有减小，把负载电流减到 20% 使增益提高 √5 倍。）
