# 详细步骤 - R633

**思路。** 低频时电容开路，每个电感除串联电阻 $R_S$ 外相当于短路，因此每个漏极只看到接到 $V_{DD}$ 的 $R_S$。两个交叉耦合（cross-coupled）的共源级构成一个有两次反相的直流耦合环路，即**正**反馈，环路增益为 $g_{m1}g_{m2}R_S^2$。使该环路增益低于单位增益可以防止锁定，并由此给出 $R_S$ 的上限。

### 第 1 步 — 低频时的负载阻抗

直流时 $C_P$ 开路，$L_P$ 退化为其串联电阻 $R_S$；若 $R_P$ 是单独的实际电阻，则与之并联。因此每个漏极看到的阻抗为

$$Z(0) = R_S \parallel R_P \approx R_S,$$

这是因为实际电感满足 $R_S \ll R_P$。（若 $R_P$ 只是谐振时电感损耗的并联等效模型，它在直流时并不存在，负载恰好就是 $R_S$。）

### 第 2 步 — 低频环路增益

在 $M_1$ 的栅极处断开环路（栅极不吸取电流），并加测试电压 $v_t$。$\lambda = 0$ 时，每个晶体管都是从其漏极流向地的电流源（current source）$g_mv_{gs}$，每个漏极都有 $R_S$（以及 $R_P$）接到交流地。

<!-- diagram: diagram-01.cir -->

依次在 X 和 Y 应用 KCL（$M_2$ 的栅极接 X）：

$$v_X = -g_{m1}Z(0)\,v_t, \qquad v_Y = -g_{m2}Z(0)\,v_X = (-g_{m2}Z(0))(-g_{m1}Z(0))\,v_t = g_{m1}g_{m2}Z(0)^2\,v_t .$$

$v_Y$ 返回到 $M_1$ 的栅极，因此

$$A_{loop}(0) = \frac{v_Y}{v_t} = +g_{m1}g_{m2}Z(0)^2 \approx g_{m1}g_{m2}R_S^2 .$$

它是**正**的：两次反相使信号以原来的符号返回，因此直流时的反馈是正反馈。

### 第 3 步 — 为什么直流环路增益必须小于单位增益

$M_1$ 栅极处的扰动 $v$ 绕环一周后变为 $A_{loop}(0)\,v$。

- 若 $A_{loop}(0) < 1$，扰动逐渐消失：对称点（$V_X = V_Y$）在直流下是稳定的，电路可以在谐振回路（tank）的谐振频率处振荡。
- 若 $A_{loop}(0) > 1$，扰动不断增长但不振荡（一个右半平面实极点）：$V_X$ 和 $V_Y$ 向相反方向分开，直到一个晶体管完全导通而另一个截止。电路像静态存储单元一样**锁定**，无法振荡。

### 第 4 步 — $R_S$ 的上限

$$g_{m1}g_{m2}R_S^2 < 1 \quad\Longrightarrow\quad R_S < \frac{1}{\sqrt{g_{m1}g_{m2}}} .$$

对于相同的晶体管，$g_{m1} = g_{m2} = g_m$：

$$R_S < \frac{1}{g_m} .$$

（严格地说应为 $(R_S \parallel R_P) < 1/\sqrt{g_{m1}g_{m2}}$；由于 $R_S \ll R_P$，它给出相同的上限。）

### 第 5 步 — 与振荡条件的兼容性

振荡要求**谐振时**的环路增益达到 1。此时 $L_P$ 与 $C_P$ 相互抵消，每个漏极看到 $R_{tank} = R_P \parallel R_{p,L}$，其中 $R_{p,L} \approx Q_L^2R_S$ 是 $R_S$ 在谐振时的并联等效电阻，$Q_L = \omega_0L_P/R_S$。起振条件为

$$g_{m1}g_{m2}R_{tank}^2 \ge 1, \quad\text{i.e.}\quad g_m \ge \frac{1}{R_{tank}}\ \ (\text{identical devices}),$$

因此结合第 4 步，

$$\frac{1}{R_{tank}} \le g_m < \frac{1}{R_S} .$$

由于谐振时的回路电阻远大于 $R_S$，这一范围很宽。例如，$Q_L = 10$ 时，$R_{tank}$ 最大可达约 $Q_L^2R_S = 100R_S$，因此 $g_m$ 取约 $0.01/R_S$ 到 $1/R_S$ 之间的任何值都可以。

### 结果

低频时负载退化为 $R_S$（$C_P$ 开路，$L_P$ 短路），两个交叉耦合的共源级构成增益为 $g_{m1}g_{m2}R_S^2$ 的正反馈环路。要避免锁定，这一增益必须小于 1：

$$R_S < \frac{1}{\sqrt{g_{m1}g_{m2}}}\quad\left(= \frac{1}{g_m}\ \text{for}\ g_{m1} = g_{m2} = g_m\right).$$

严格地说应为 $(R_S \parallel R_P) < 1/\sqrt{g_{m1}g_{m2}}$；由于 $R_S \ll R_P$，这是同一个上限。

**常见错误。** 用 $R_P$（或谐振时的回路阻抗）作为直流负载。直流时电感把谐振回路短路，只剩下 $R_S$；若用 $R_P$，则所有正常工作的 LC 振荡器都会被判定为锁定，因为振荡本身就要求 $g_mR_P \ge 1$。

**常见错误。** 把不等式写反（$R_S > 1/g_m$）。串联电阻**越大**，每级的直流增益越高，锁定就**越**容易发生。

**常见错误。** 用 $Q$、$L_P$ 或振荡频率来表示这一条件。这些量描述的是谐振；锁定是直流条件，只涉及 $R_S$ 和跨导。
