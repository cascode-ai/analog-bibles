# 详细步骤 - R050

**思路。** 把环形晶体管（ring transistor）看作共用一个漏区的四个普通晶体管并联，由此得到它的等效 $W/L$。然后根据每种版图（layout）的漏区*面积*和*周长*计算其漏结电容（drain-junction capacitance），$C = (\text{area})\,C_j + (\text{perimeter})\,C_{jsw}$。为了公平比较，三种版图必须具有相同的沟道长度 $L$ 和相同的总（等效）宽度。

### 第 1 步 — 环形晶体管的工作原理

以 NMOS 为例，[图 1] 中的版图由以下部分组成：

- 位于中央、边长为 $W$ 的正方形 $n^+$ **漏区**；
- 包围漏区、宽度为 $L$ 的闭合多晶硅（polysilicon）**栅**环；
- 占据环外全部区域的 $n^+$ **源区**。

环的下方是 p 型衬底（substrate），与普通晶体管栅极下方完全一样。从环上引出的细多晶硅条只是栅极的连线。

当 $V_{GS} > V_{TH}$，即栅源电压高于阈值电压（threshold voltage）时，*整个*环的下方都会形成反型层（inversion layer），即沟道。这条沟道在漏区正方形的**四条边**上都把漏区与源区连通。电子从四周的源区出发，经栅极下方向内流入中央的漏区；因此按常规电流方向，电流是从漏区向外流向源区的。

环的每一条边都是一段普通的沟道，宽度 $\approx W$（漏区的边长），长度为 $L$（多晶硅环的宽度，沿电流方向测量）。四条边共用同一个栅极、漏极和源极。因此环形器件的行为就像**四个相同的晶体管并联**。

（穿过源区通向栅极接触孔的多晶硅条，只会在源区的两部分之间形成沟道，而这两部分电位相同。它不传导漏极电流，只增加少量栅电容。）

### 第 2 步 — 等效宽长比（equivalent aspect ratio）

并联的晶体管具有相同的 $V_{GS}$ 和 $V_{DS}$，因此它们的电流相加。在饱和区（saturation region），利用平方律（square law），并以 $\mu_nC_{ox}$ 表示迁移率（mobility）与栅氧电容（oxide capacitance）的乘积：

$$I_D = 4\times\frac12\mu_nC_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2 = \frac12\mu_nC_{ox}\,\frac{4W}{L}\,(V_{GS} - V_{TH})^2 .$$

因此

$$\left(\frac{W}{L}\right)_{eq} \approx \frac{4W}{L} .$$

也就是说，有效宽度等于环的内周长 $4W$。

### 第 3 步 — 修正：四个拐角

环的四个 $L\times L$ 拐角方块也会流过一些电流，但效率不如直边部分，因为从漏区角点到外侧拐角的路径更长。两个简单的估计可以给出真实值的上下界。

- **下界：忽略拐角。** 如果电流只在四个 $W\times L$ 矩形中流动，则 $(W/L)_{eq} = 4W/L$。实际电流还会扩散到拐角中，因此实际器件的导电能力略好一些。（把电流强制限制在受限的路径中只会使电阻增大：这就是汤姆孙（Thomson）最小耗散原理。）
- **上界：正方形等势线。** 假设电位在一组同心正方形上为常数。在距漏区边缘 $x$ 处（$0 \le x \le L$），一个薄正方形环带的周长为 $4(W + 2x)$，厚度为 $dx$。以 $R_\square$ 表示沟道的方块电阻（sheet resistance），该环带相当于一个阻值为下式的电阻：
$$dR = R_\square\,\frac{dx}{4(W + 2x)} .$$
各环带相互串联，因此利用 $\int dx/(W + 2x) = \tfrac12\ln(W + 2x)$ 进行积分：
$$R = \frac{R_\square}{4}\int_0^L\frac{dx}{W + 2x} = \frac{R_\square}{4}\cdot\frac12\Big[\ln(W + 2x)\Big]_0^L = \frac{R_\square}{8}\ln\!\left(\frac{W + 2L}{W}\right).$$
普通矩形沟道的电阻为 $R = R_\square\,L/W$，因此其宽长比为 $W/L = R_\square/R$。按同样的定义，
$$\left(\frac{W}{L}\right)_{eq} = \frac{R_\square}{R} = \frac{8}{\ln(1 + 2L/W)} .$$
把电位强制设定为某种假定的分布，只会*高估*电导。根据狄利克雷（Dirichlet）最小能量原理，在给定端电压下，真实的电位分布使耗散功率最小。因此这是一个上界。

当 $L \ll W$ 时，利用 $\ln(1 + \epsilon) \approx \epsilon - \epsilon^2/2$，取 $\epsilon = 2L/W$：

$$\frac{8}{\ln(1 + 2L/W)} \approx \frac{8}{(2L/W)(1 - L/W)} \approx \frac{4W}{L}\left(1 + \frac{L}{W}\right) = \frac{4W}{L} + 4 = \frac{4(W + L)}{L}.$$

所以

$$\frac{4W}{L} \;\le\; \left(\frac{W}{L}\right)_{eq} \;\le\; \frac{8}{\ln(1 + 2L/W)} \approx \frac{4W}{L} + 4 .$$

上界的近似形式 $4(W + L)/L$ 与按环的*平均*周长计算的结果相同。例如 $W = 10L$ 时，下界和上界分别为 40 和 43.9，可见拐角对结果的影响不到 10 %。**当 $W \gg L$ 时，$(W/L)_{eq} \approx 4W/L$。**

（同样的几何因子在饱和区和线性区（linear region）都适用：按照缓变沟道（gradual-channel）图像，任何偏置下的沟道电流都服从同一个二维连续性方程。）

### 第 4 步 — 电容模型与公平比较的条件

与教材中一样，漏-衬底结电容用底面（bottom-plate）项和侧壁（sidewall）项来建模：

$$C_{DB} = (\text{drain area})\times C_j + (\text{drain perimeter})\times C_{jsw},$$

其中 $C_j$ 为单位面积的底面电容，$C_{jsw}$ 为单位长度的侧壁电容。

为了公平地比较各种版图，三者必须提供**相同的电流**，即具有相同的 $(W/L)_{eq}$。在沟道长度 $L$ 相同的情况下，它们的总宽度也必须相同：

$$W_{eq} = 4W .$$

本题中 $E$ 始终表示源/漏区（source/drain region）的横向尺寸，即从栅边缘到扩散区（diffusion）末端的距离；它**不是**沟道长度。

### 第 5 步 — 环形器件

漏区是 $W\times W$ 的正方形：

$$\text{area} = W^2, \qquad \text{perimeter} = 4W,$$

$$C_{DB,ring} = W^2C_j + 4W\,C_{jsw}.$$

### 第 6 步 — 直条形器件（straight，[图 2]）

单个栅指（gate finger），宽度为 $W_{eq} = 4W$。其漏区是一个长 $W_{eq}$（沿栅方向）、宽 $E$ 的矩形：

$$\text{area} = W_{eq}E = 4WE, \qquad \text{perimeter} = 2(W_{eq} + E) = 8W + 2E,$$

$$C_{DB,straight} = 4WE\,C_j + 2(4W + E)\,C_{jsw}.$$

### 第 7 步 — 折叠器件（folded，[图 3]）

两个栅指并联，每个宽度为 $W_{eq}/2 = 2W$，共用中间的一个漏区。漏区是长 $2W$、宽 $E$ 的矩形：

$$\text{area} = \frac{W_{eq}}{2}E = 2WE, \qquad \text{perimeter} = 2\left(\frac{W_{eq}}{2} + E\right) = 4W + 2E,$$

$$C_{DB,folded} = 2WE\,C_j + 2(2W + E)\,C_{jsw}.$$

折叠使漏区面积减半，因为一个漏区同时服务于两条沟道。

### 第 8 步 — 三种版图的比较

**汇总表：**

| 版图（$W_{eq} = 4W$ 相同） | 漏区面积 | 漏区周长 | $C_{DB}$ | $W = E$ 时的 $C_{DB}$ |
|---|---|---|---|---|
| 环形 | $W^2$ | $4W$ | $W^2C_j + 4WC_{jsw}$ | $E^2C_j + 4EC_{jsw}$ |
| 直条形 | $4WE$ | $8W + 2E$ | $4WEC_j + (8W + 2E)C_{jsw}$ | $4E^2C_j + 10EC_{jsw}$ |
| 折叠 | $2WE$ | $4W + 2E$ | $2WEC_j + (4W + 2E)C_{jsw}$ | $2E^2C_j + 6EC_{jsw}$ |

**当 $W \approx E$ 时**（漏区正方形刚好能容纳一个接触孔）：

- 底面：环形为 $E^2$，直条形为 $4E^2$，折叠为 $2E^2$。即环形分别是直条形器件的 **1/4** 和折叠器件的 **1/2**。
- 周长：环形为 $4E$，后两者分别为 $10E$ 和 $6E$。
- 总电容：环形/直条形之比介于 $1/4$（底面电容占主导）与 $4/10 = 2/5$（侧壁电容占主导）之间；环形/折叠之比介于 $1/2$ 与 $4/6 = 2/3$ 之间。确切数值取决于 $C_{jsw}/(EC_j)$。

**一般的 $W$。** 用另外两种结构的电容减去环形结构的电容：

$$
\begin{aligned}
C_{DB,folded} - C_{DB,ring} &= (2WE - W^2)C_j + (4W + 2E - 4W)C_{jsw} = W(2E - W)\,C_j + 2E\,C_{jsw},\\
C_{DB,straight} - C_{DB,ring} &= (4WE - W^2)C_j + (8W + 2E - 4W)C_{jsw} = W(4E - W)\,C_j + (4W + 2E)\,C_{jsw}.
\end{aligned}
$$

只要 $W \le 2E$，两个差值都为正，因此在这一范围内环形结构占优。令第一个差值为零，即可得到与折叠器件相比的精确分界点：

$$W^2 - 2EW - \frac{2EC_{jsw}}{C_j} = 0 \;\Rightarrow\; W_c = E + \sqrt{E^2 + \frac{2EC_{jsw}}{C_j}} \;(\ge 2E).$$

与直条形器件相比，分界点在 $W \approx 4E$ 附近；计入侧壁电容后会略高一些。

**按单位有效宽度计算。** 将各电容除以 $W_{eq} = 4W$：

$$
\begin{aligned}
\frac{C_{DB,ring}}{W_{eq}} &= \frac{W}{4}C_j + C_{jsw},\\
\frac{C_{DB,straight}}{W_{eq}} &= E\,C_j + 2C_{jsw} + \frac{E}{2W}C_{jsw},\\
\frac{C_{DB,folded}}{W_{eq}} &= \frac{E}{2}C_j + C_{jsw} + \frac{E}{2W}C_{jsw}.
\end{aligned}
$$

对直条形和折叠器件，这一数值基本不变；对环形器件，它却随 $W$ *增大*，因为漏区面积按 $W^2$ 增长，而宽度只按 $4W$ 增长。因此，宽晶体管应当由**多个小环并联**构成（每个环的 $W \approx E$），而不是做成一个大环。

### 第 9 步 — 说明与代价

- **侧壁电容的计算约定。** 上面的简单模型对整个漏区周长都按 $C_{jsw}$ 计算。如果不计面向栅极的那条边（沟道一侧），或者对它单独取值，则每种版图都减去 $4WC_{jsw}$。三者靠栅一侧的漏区边总长都是 $W_{eq} = 4W$，因此差值和结论都不变：简化后的形式分别为 $W^2C_j$、$4WEC_j + (4W + 2E)C_{jsw}$ 和 $2WEC_j + 2EC_{jsw}$。
- **环形结构的代价。** 源区包围着整个器件，因此总面积和源结电容都较大；当源极接地时，这并无害处。拐角使精确的 $W/L$ 较难预测，而且器件是不对称的：必须把较小的内侧端子用作漏极，即敏感节点。

### 结果

- **工作原理。** 环形栅在中央漏区的四周感应出沟道。电流在漏区与四周的源区之间沿四条边流动，相当于四个宽度 $\approx W$、长度为 $L$ 的晶体管并联并共用一个漏区。
- **等效宽长比。**
$$\left(\frac{W}{L}\right)_{eq} \approx \frac{4W}{L}.$$
计入拐角时，$4W/L \le (W/L)_{eq} \le 8/\ln(1 + 2L/W) \approx 4(W + L)/L$。
- **漏结电容**（等效宽度相同，$W_{eq} = 4W$）：
$$C_{ring} = W^2C_j + 4WC_{jsw},\quad C_{straight} = 4WEC_j + 2(4W + E)C_{jsw},\quad C_{folded} = 2WEC_j + 2(2W + E)C_{jsw}.$$
- **比较。** 当 $W \approx E$ 时，环形结构的底面电容约为直条形器件的 1/4、折叠器件的 1/2，周长也最小。其总漏极电容为直条形器件的 1/4–2/5、折叠器件的 1/2–2/3。只要 $W \le 2E$，它就优于折叠版图（精确分界点为 $E + \sqrt{E^2 + 2EC_{jsw}/C_j}$）；在 $W \approx 4E$ 以下，它也优于直条形版图。
- **尺寸缩放。** 由于环形结构的漏区面积按 $W^2$ 增长，大宽度时应采用多个小环并联。

**常见错误。** 把等效宽长比取为 $W/L$（只计了一条边）或 $W/(4L)$（把四条边当成串联）。四段沟道连接的是*同一个*漏区和*同一个*源区，因此它们是并联的，宽度相加：$4W/L$。

**常见错误。** 在相同的版图绘制宽度 $W$ 下比较各版图，或者把 $E$ 当作直条形或折叠器件的沟道长度。只有在电流驱动能力相同（$L$ 相同，$W_{eq} = 4W$ 相同）的前提下，比较才有意义。$E$ 是源/漏扩散区的尺寸，不是沟道长度。

**常见错误。** 认为环形结构的漏极电容*更大*，“因为它是个大正方形”。在实际使用的较小 $W$ 下（$W \lesssim 2E$），它的漏区面积和周长都是三者中最小的。只有试图做成单个很大的环时，它才会处于劣势。
