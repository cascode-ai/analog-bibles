# 详细步骤 - R050

**思路。** 把环形晶体管看作共用一个漏极的四个普通晶体管并联，由此得到其等效 $W/L$。然后在相同沟道长度 $L$、相同总（等效）宽度的条件下，由各版图（layout）漏区的面积和周长计算其漏结电容。

### 第 1 步 — 环形晶体管的工作原理

当 $V_{GS} > V_{TH}$ 时，**整个**环形栅极下方都形成反型层（inversion layer），在漏区正方形的**四条边**上把中央漏极与周围的源极连通。电子从源极出发，经栅极下方向内流入漏极；常规电流则从漏极向外流向源极。

环的每条边都是一个普通沟道，宽度 $\approx W$（漏区边长），长度为 $L$，即多晶硅（poly）环沿电流方向的宽度。四条边共用同一个栅极、漏极和源极，因此环形器件的行为相当于**四个相同的晶体管并联**。

穿过源区连到栅极接触孔的多晶硅条，只在源区的两部分之间形成沟道，而这两部分电位相同；它不传导漏极电流，只增加少量栅极电容。

### 第 2 步 — 等效宽长比

四个并联晶体管的 $V_{GS}$ 和 $V_{DS}$ 相同，因此它们的饱和电流相加：

$$I_D = 4\times\frac12\mu_nC_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2 = \frac12\mu_nC_{ox}\,\frac{4W}{L}\,(V_{GS} - V_{TH})^2 .$$

因此

$$\left(\frac{W}{L}\right)_{eq} \approx \frac{4W}{L} :$$

即有效宽度等于环的内周长 $4W$。

### 第 3 步 — 修正：四个角区

环的四个 $L\times L$ 角区也传导一些电流，但不如直边有效，因为从漏区角点到外角的路径更长。两种简单的估计给出了真实值的上下界。

- **下界：忽略角区。** 如果电流只在四个 $W\times L$ 矩形中流动，则 $(W/L)_{eq} = 4W/L$。实际电流还会扩散到角区，因此实际器件的导电性能稍好一些。根据汤姆孙最小耗散原理（Thomson's minimum-dissipation principle），把电流强制限制在受限的路径中只会增大电阻。
- **上界：正方形等势线。** 假设电势在同心正方形上为常数。在距漏区边缘 $x$ 处（$0 \le x \le L$），一个薄正方形壳层的周长为 $4(W + 2x)$，厚度为 $dx$；设 $R_\square$ 为沟道的方块电阻（sheet resistance），则它是一个电阻
$$dR = R_\square\,\frac{dx}{4(W + 2x)} .$$
各壳层串联，利用 $\int dx/(W + 2x) = \tfrac12\ln(W + 2x)$，得
$$R = \frac{R_\square}{4}\int_0^L\frac{dx}{W + 2x} = \frac{R_\square}{4}\cdot\frac12\Big[\ln(W + 2x)\Big]_0^L = \frac{R_\square}{8}\ln\!\left(\frac{W + 2L}{W}\right).$$
矩形沟道的 $R = R_\square\,L/W$，即 $W/L = R_\square/R$，因此按同一定义
$$\left(\frac{W}{L}\right)_{eq} = \frac{R_\square}{R} = \frac{8}{\ln(1 + 2L/W)} .$$
假设的电势分布只会**高估**电导：根据狄利克雷最小能量原理（Dirichlet's minimum-energy principle），真实的电势分布使耗散功率最小。因此这是一个上界。

当 $L \ll W$ 时，利用 $\ln(1 + \epsilon) \approx \epsilon - \epsilon^2/2$，其中 $\epsilon = 2L/W$：

$$\frac{8}{\ln(1 + 2L/W)} \approx \frac{8}{(2L/W)(1 - L/W)} \approx \frac{4W}{L}\left(1 + \frac{L}{W}\right) = \frac{4W}{L} + 4 = \frac{4(W + L)}{L}.$$

因此

$$\frac{4W}{L} \;\le\; \left(\frac{W}{L}\right)_{eq} \;\le\; \frac{8}{\ln(1 + 2L/W)} \approx \frac{4W}{L} + 4 .$$

上界形式 $4(W + L)/L$ 等于环的**平均**周长除以 $L$。当 $W = 10L$ 时，下界和上界分别为 40 和 43.9，因此角区对结果的影响不到 10 %。**当 $W \gg L$ 时，$(W/L)_{eq} \approx 4W/L$。** 饱和区与线性区（linear region）适用同一几何因子，因为在缓变沟道（gradual-channel）图像中，任何偏置下沟道电流都服从同样的二维连续性方程。

### 第 4 步 — 电容模型与公平的归一化

漏-衬底电容（drain–bulk capacitance）为 $C_{DB} = (\text{drain area})\,C_j + (\text{drain perimeter})\,C_{jsw}$。为了公平比较，三种版图必须给出**相同的电流**，即相同的 $(W/L)_{eq}$；在 $L$ 相同时，它们需要相同的总宽度，

$$W_{eq} = 4W .$$

$E$ 是源/漏区的横向尺寸，即从栅极边缘到扩散区（diffusion）末端的距离，**而不是**沟道长度。

### 第 5 步 — 环形器件

漏区为 $W\times W$ 的正方形：

$$\text{area} = W^2, \qquad \text{perimeter} = 4W,$$

$$C_{DB,ring} = W^2C_j + 4W\,C_{jsw}.$$

### 第 6 步 — 直条形器件（[图 2]）

单个栅指，宽度为 $W_{eq} = 4W$，其漏区是一个沿栅极方向长 $W_{eq}$、宽 $E$ 的矩形：

$$\text{area} = W_{eq}E = 4WE, \qquad \text{perimeter} = 2(W_{eq} + E) = 8W + 2E,$$

$$C_{DB,straight} = 4WE\,C_j + 2(4W + E)\,C_{jsw}.$$

### 第 7 步 — 折叠器件（[图 3]）

两个栅指，每个宽度为 $W_{eq}/2 = 2W$，共用一个中央漏区，即一个长 $2W$、宽 $E$ 的矩形：

$$\text{area} = \frac{W_{eq}}{2}E = 2WE, \qquad \text{perimeter} = 2\left(\frac{W_{eq}}{2} + E\right) = 4W + 2E,$$

$$C_{DB,folded} = 2WE\,C_j + 2(2W + E)\,C_{jsw}.$$

由于一个漏区服务于两个沟道，折叠使漏区面积减半。

### 第 8 步 — 比较三种版图

| 版图（$W_{eq} = 4W$ 相同） | 漏区面积 | 漏区周长 | $C_{DB}$ | $W = E$ 时的 $C_{DB}$ |
|---|---|---|---|---|
| 环形 | $W^2$ | $4W$ | $W^2C_j + 4WC_{jsw}$ | $E^2C_j + 4EC_{jsw}$ |
| 直条形 | $4WE$ | $8W + 2E$ | $4WEC_j + (8W + 2E)C_{jsw}$ | $4E^2C_j + 10EC_{jsw}$ |
| 折叠 | $2WE$ | $4W + 2E$ | $2WEC_j + (4W + 2E)C_{jsw}$ | $2E^2C_j + 6EC_{jsw}$ |

**在 $W \approx E$ 时**（漏区正方形刚好能容纳一个接触孔）：

- 底面：环形为 $E^2$，而直条形为 $4E^2$、折叠为 $2E^2$，即分别为直条形器件的 **1/4** 和折叠器件的 **1/2**。
- 周长：环形为 $4E$，而另两者分别为 $10E$ 和 $6E$。
- 总电容：环形/直条形之比介于 $1/4$（底面电容占主导）与 $4/10 = 2/5$（侧壁电容占主导）之间，环形/折叠之比介于 $1/2$ 与 $4/6 = 2/3$ 之间，具体取决于 $C_{jsw}/(EC_j)$。

**一般的 $W$。** 用其他版图的电容减去环形的电容：

$$
\begin{aligned}
C_{DB,folded} - C_{DB,ring} &= (2WE - W^2)C_j + (4W + 2E - 4W)C_{jsw} = W(2E - W)\,C_j + 2E\,C_{jsw},\\
C_{DB,straight} - C_{DB,ring} &= (4WE - W^2)C_j + (8W + 2E - 4W)C_{jsw} = W(4E - W)\,C_j + (4W + 2E)\,C_{jsw}.
\end{aligned}
$$

只要 $W \le 2E$，两个差值都为正，因此在这一范围内环形器件占优。令第一个差值为零，得到与折叠器件的精确交叉点：

$$W^2 - 2EW - \frac{2EC_{jsw}}{C_j} = 0 \;\Rightarrow\; W_c = E + \sqrt{E^2 + \frac{2EC_{jsw}}{C_j}} \;(\ge 2E).$$

与直条形器件相比，交叉点在 $W \approx 4E$ 附近，计入侧壁后还要稍高一些。

**按单位有效宽度计算。** 把每个电容除以 $W_{eq} = 4W$：

$$
\begin{aligned}
\frac{C_{DB,ring}}{W_{eq}} &= \frac{W}{4}C_j + C_{jsw},\\
\frac{C_{DB,straight}}{W_{eq}} &= E\,C_j + 2C_{jsw} + \frac{E}{2W}C_{jsw},\\
\frac{C_{DB,folded}}{W_{eq}} &= \frac{E}{2}C_j + C_{jsw} + \frac{E}{2W}C_{jsw}.
\end{aligned}
$$

对直条形和折叠器件，这一数值基本恒定。对环形器件，它随 $W$ **增大**，因为漏区面积按 $W^2$ 增长，而宽度只按 $4W$ 增长。因此，宽晶体管应当由**多个小环并联**构成，每个环的 $W \approx E$，而不是用一个大环。

### 第 9 步 — 说明与代价

- **侧壁约定。** 上面的模型对整个漏区周长都按 $C_{jsw}$ 计算。若不计面向栅极的那条边，或对它另取数值，则每种版图都减去 $4WC_{jsw}$：三者面向栅极的漏区边总长都是 $W_{eq} = 4W$，因此差值和结论都不变。简化后的形式为 $W^2C_j$、$4WEC_j + (4W + 2E)C_{jsw}$ 和 $2WEC_j + 2EC_{jsw}$。
- **环形器件的代价。** 源区包围着整个器件，因此总面积和源结电容都很大（源极接地时无妨）。角区使精确的 $W/L$ 较难预测，而且器件不对称：必须把内部的小端子用作漏极，即敏感节点。

### 结果

- **工作原理。** 环形栅极在中央漏区的四周感应出沟道。电流在四条边上流过漏极与周围的源极之间，相当于四个宽度 $\approx W$、长度为 $L$ 的晶体管共用一个漏极并联。
- **等效宽长比。**
$$\left(\frac{W}{L}\right)_{eq} \approx \frac{4W}{L}.$$
计入角区时，$4W/L \le (W/L)_{eq} \le 8/\ln(1 + 2L/W) \approx 4(W + L)/L$。
- **漏结电容**，等效宽度相同（$W_{eq} = 4W$）：
$$C_{ring} = W^2C_j + 4WC_{jsw},\quad C_{straight} = 4WEC_j + 2(4W + E)C_{jsw},\quad C_{folded} = 2WEC_j + 2(2W + E)C_{jsw}.$$
- **比较。** 当 $W \approx E$ 时，环形器件的底面电容约为直条形器件的 1/4、折叠器件的 1/2，周长也最小。其总漏极电容为直条形器件的 1/4–2/5、折叠器件的 1/2–2/3。对任何 $W \le 2E$，它都优于折叠版图（精确交叉点为 $E + \sqrt{E^2 + 2EC_{jsw}/C_j}$）；相对直条形版图，它在 $W \approx 4E$ 以内都占优。
- **缩放。** 由于环形器件的漏区面积按 $W^2$ 增长，大宽度时应采用多个小环并联。

**常见错误。** 把等效宽长比取为 $W/L$（只计一条边）或 $W/(4L)$（四条边串联）。四段沟道把**同一个**漏极连到**同一个**源极，因此它们是并联的，宽度相加：$4W/L$。

**常见错误。** 在相同的版图绘制尺寸 $W$ 下比较各版图，或者把 $E$ 当作直条形或折叠器件的沟道长度。只有在电流驱动能力相同（$L$ 相同，$W_{eq} = 4W$ 相同）时，比较才有意义，而 $E$ 是源/漏区的尺寸。

**常见错误。** 认为环形器件“因为是一个大正方形”而具有**更大的**漏极电容。在实际使用的小 $W$ 下（$W \lesssim 2E$），它的漏区面积和周长都是三者中最小的；只有单个非常大的环才会显出劣势。
