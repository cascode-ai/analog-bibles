工作原理：环形栅极在中央漏区的四周感应出沟道；电流从漏极出发，经环形栅极下方，在四条边上向外流到周围的源极，相当于四个宽度 ≈ W、长度为 L 的晶体管共用一个漏极并联（另外还有角区）。等效宽长比 ≈ $4W/L$（内周长除以 L）；计入角区（或采用平均周长）得到 ≈ $4(W + L)/L$，当 $W \gg L$ 时它 ≈ $4W/L$。

漏结电容（等效宽度相同，$W_{eq} = 4W$）：
- 环形：$C_{DB} = W^2C_j + 4WC_{jsw}$。
- 直条形器件：$C_{DB} = W_{eq}EC_j + 2(W_{eq} + E)C_{jsw} = 4WEC_j + 2(4W + E)C_{jsw}$。
- 折叠器件，两个宽度为 $W_{eq}/2$ 的栅指（gate finger）共用一个漏区：$C_{DB} = 2WEC_j + 2(2W + E)C_{jsw}$。
- 底面电容之比：环形/直条形 = $W/(4E)$，环形/折叠 = $W/(2E)$。当漏区大致为最小尺寸（$W \approx E$）时，环形器件的底面电容约为直条形器件的 1/4、折叠器件的 1/2，周长也最小（4E，对比 ≈ 10E 和 ≈ 6E）；在 $W = E$ 时，总电容之比介于 1/4 与 2/5 之间（相对直条形）以及 1/2 与 2/3 之间（相对折叠），具体取决于 $C_{jsw}/(EC_j)$。$C_{D,fold} - C_{D,ring} = W(2E - W)C_j + 2EC_{jsw}$，因此 $W \le 2E$ 足以保证环形器件占优（精确的交叉点为 $W_c = E + \sqrt{E^2 + 2EC_{jsw}/C_j}$）；由于其漏区面积按 $W^2$ 增长，大宽度时需要用多个小环。代价是：源区面积和总面积较大，并且存在角区效应。
- 侧壁约定：上面的公式对整个漏区周长都按 $C_{jsw}$ 计算（Razavi 的简单模型）。若不计靠栅极一侧的边（或对它另取 $C_{jswg}$），则每个结果都减去 $4WC_{jsw}$：环形为 $W^2C_j$，直条形为 $4WEC_j + (4W + 2E)C_{jsw}$，折叠为 $2WEC_j + 2EC_{jsw}$。三者靠栅极一侧的漏区边长都约为 $4W$，因此差值和比较结论都不变。
