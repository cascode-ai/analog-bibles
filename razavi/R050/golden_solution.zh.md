# Golden Solution - R050

## 参考答案

工作原理：环形栅极在中央漏区的四周感应出沟道；电流从漏极出发，经环形栅极下方，在四条边上向外流到周围的源极，相当于四个宽度 ≈ $W$、长度为 $L$ 的晶体管共用一个漏极并联（另外还有角区）。等效宽长比 ≈ $4W/L$（内周长除以 $L$）；计入角区（或采用平均周长）得到 ≈ $4(W + L)/L$，当 $W \gg L$ 时它 ≈ $4W/L$。

三种版图采用相同沟道长度 $L$ 和相同总有效宽度 $W_{eq}=4W$。漏结电容为
- 环形：$C_{DB} = W^2C_j + 4WC_{jsw}$。
- 直条形器件：$C_{DB} = W_{eq}EC_j + 2(W_{eq} + E)C_{jsw} = 4WEC_j + 2(4W + E)C_{jsw}$。
- 折叠器件，两个宽度为 $W_{eq}/2$ 的栅指（gate finger）共用一个漏区：$C_{DB} = 2WEC_j + 2(2W + E)C_{jsw}$。
- 底面电容之比：环形/直条形 = $W/(4E)$，环形/折叠 = $W/(2E)$。当漏区大致为最小尺寸（$W \approx E$）时，环形器件的底面电容约为直条形器件的 1/4、折叠器件的 1/2，周长也最小（4E，对比 ≈ 10E 和 ≈ 6E）；在 $W = E$ 时，总电容之比介于 1/4 与 2/5 之间（相对直条形）以及 1/2 与 2/3 之间（相对折叠），具体取决于 $C_{jsw}/(EC_j)$。

折叠与环形的差值为 $C_{D,fold} - C_{D,ring} = W(2E - W)C_j + 2EC_{jsw}$，因此 $W \le 2E$ 足以保证环形器件占优（精确的交叉点为 $W_c = E + \sqrt{E^2 + 2EC_{jsw}/C_j}$）；由于其漏区面积按 $W^2$ 增长，大宽度时需要用多个小环。代价是：源区面积和总面积较大，并且存在角区效应。

- 侧壁约定：上面的公式对整个漏区周长都按 $C_{jsw}$ 计算（Razavi 的简单模型）。若不计靠栅极一侧的边，则每个结果都减去 $4WC_{jsw}$：环形为 $W^2C_j$，直条形为 $4WEC_j + (4W + 2E)C_{jsw}$，折叠为 $2WEC_j + 2EC_{jsw}$。三者靠栅极一侧的漏区边长都约为 $4W$，因此差值和大小排序不变。若用独立系数 $C_{jswg}$，则在各式中加回同一项 $4WC_{jswg}$。

## 评分说明

- +2：说明中央漏区四边均通过沟道与外围源区导通，得到等效宽长比 $\approx 4W/L$，或有依据地得到 $4(W+L)/L$。给出环形漏结电容 $W^2C_j+4WC_{jsw}$，在相同总有效宽度下正确比较三种版图，说明 $W$ 与 $E$ 同量级时环形电容较小及优势如何随 $W$ 变化。若明确扣除靠栅的漏区侧壁，且对三种结构一致处理，环形取 $W^2C_j$ 也可得满分。
- +1：工作原理和等效宽长比正确，电容比较仅作了正确的定性判断。
- 0：等效宽长比或电容比较有一项错误或缺失。
- −2（断言为事实）：把等效宽长比写为 $W/L$ 或 $W/(4L)$，认为 $W$ 较小时环形漏结电容更大，或颠倒源漏角色并导致结论错误。

默认三种版图的沟道长度均为 $L$，总有效宽度均为 $W_{eq}=4W$。明确采用其他归一化方式且推导一致，也可接受。在等效宽度比较之外补充相同绘制宽度的比较不扣分。把源漏扩散区的横向尺寸 $E$ 当成沟道长度会使比较失效。

交叉宽度可用忽略侧壁时的近似值（折叠约 $2E$、直条约 $4E$），也可给出含 $C_{jsw}$ 的结果。用正方形等势线积分 $8/\ln(1+2L/W)$，或给出量级为 $4W/L+2$ 的角区修正，都可作为有效细化。将该近似称为精确解仅属轻微不严谨。注明 $W\gtrsim E$ 以容纳漏区接触孔不扣分。
