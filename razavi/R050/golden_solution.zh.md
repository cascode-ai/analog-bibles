工作原理：环形栅在中央漏区的四周感应出一圈沟道；电流从漏区出发，经环下方的沟道向外流到四边的源区，相当于四个宽度 ≈ W、长度为 L 的晶体管并联并共用一个漏区（另有拐角区域）。等效宽长比（equivalent aspect ratio）≈ $4W/L$（内周长除以 L）；若计入拐角（即按平均周长计算），则得 ≈ $4(W + L)/L$，当 $W \gg L$ 时它 ≈ $4W/L$。

漏结电容（drain junction capacitance），取相同的等效宽度 $W_{eq} = 4W$：
- 环形（ring）：$C_{DB} = W^2C_j + 4WC_{jsw}$。
- 直条形器件（straight device）：$C_{DB} = W_{eq}EC_j + 2(W_{eq} + E)C_{jsw} = 4WEC_j + 2(4W + E)C_{jsw}$。
- 折叠器件（folded device），即两个宽为 $W_{eq}/2$ 的栅指（finger）共用一个漏区：$C_{DB} = 2WEC_j + 2(2W + E)C_{jsw}$。
- 底面电容（bottom-plate capacitance）之比：环形/直条形 = $W/(4E)$，环形/折叠 = $W/(2E)$。当漏区接近最小尺寸（$W \approx E$）时，环形结构的底面电容约为直条形器件的 1/4、折叠器件的 1/2，周长也最小（4E，后两者分别 ≈ 10E 和 ≈ 6E）；$W = E$ 时，总电容之比介于 1/4 与 2/5 之间（相对直条形）以及 1/2 与 2/3 之间（相对折叠），具体取决于 $C_{jsw}/(EC_j)$。$C_{D,fold} - C_{D,ring} = W(2E - W)C_j + 2EC_{jsw}$，因此 $W \le 2E$ 足以保证环形结构占优（精确的分界点为 $W_c = E + \sqrt{E^2 + 2EC_{jsw}/C_j}$）；由于其漏区面积按 $W^2$ 增长，大宽度时需要采用多个小环。代价是：源区面积和总面积较大，并存在拐角效应。
- 侧壁电容（sidewall capacitance）的计算约定：上面的公式对整个漏区周长都按 $C_{jsw}$ 计算（Razavi 的简单模型）。如果不计靠栅一侧的边（或对它单独使用 $C_{jswg}$），则每种结构都减去 $4WC_{jsw}$：环形为 $W^2C_j$，直条形为 $4WEC_j + (4W + 2E)C_{jsw}$，折叠为 $2WEC_j + 2EC_{jsw}$。三者靠栅一侧的漏区边长都约为 $4W$，因此差值和比较结论不变。
