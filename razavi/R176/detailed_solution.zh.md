# 详细步骤 - R176

**思路。** （1）增益由半边电路（half circuit）求出：$M_1$ 驱动二极管负载 $1/g_{m3}$，并与 $r_{O1}$ 和 $r_{O3}$ 并联。（2）最小输入共模电平由 0.4 V 的尾电流源电压余度、$M_1$ 的过驱动电压及其受体效应影响的阈值叠加而成。（3）对于摆幅，比较输入器件保持饱和所规定的界限与二极管负载在 0 到 $I_{SS}$ 的电流范围内实际能达到的范围；取较紧的那个限制。

### 第 1 步 — 小信号参数

平衡时每边流过 $I_{SS}/2 = 0.5$ mA。

**输入器件**（$\mu_nC_{ox}(W/L) = (134\ \mu\mathrm{A/V^2})(100) = 13.4\ \mathrm{mA/V^2}$）：

$$g_{m1} = \sqrt{2(13.4\ \mathrm{mA/V^2})(0.5\ \mathrm{mA})} = 3.66\ \mathrm{mS}, \qquad r_{O1} = \frac{1}{\lambda_nI_D} = \frac{1}{(0.1\ \mathrm{V^{-1}})(0.5\ \mathrm{mA})} = 20\ \mathrm{k}\Omega .$$

**PMOS 负载**（$\beta_p = \mu_pC_{ox}(W/L) = (38.4\ \mu\mathrm{A/V^2})(50/1) = 1.92\ \mathrm{mA/V^2}$）：

$$g_{m3} = \sqrt{2(1.92\ \mathrm{mA/V^2})(0.5\ \mathrm{mA})} = 1.386\ \mathrm{mS}\ \ \left(\frac{1}{g_{m3}} = 722\ \Omega\right), \qquad r_{O3} = \frac{1}{(0.2\ \mathrm{V^{-1}})(0.5\ \mathrm{mA})} = 10\ \mathrm{k}\Omega .$$

### 第 2 步 — 差分电压增益

尾节点处于交流地时，每一半都是共源级（common-source stage），负载为二极管 $M_3$（$1/g_{m3}\parallel r_{O3}$）以及 $r_{O1}$：

$$
\begin{aligned}
|A_v| &= g_{m1}\left(\frac{1}{g_{m3}}\parallel r_{O1}\parallel r_{O3}\right) = \frac{g_{m1}}{g_{m3} + 1/r_{O1} + 1/r_{O3}}\\
&= \frac{3.66\ \mathrm{mS}}{1.386\ \mathrm{mS} + 0.05\ \mathrm{mS} + 0.1\ \mathrm{mS}} = \frac{3.66}{1.536} = 2.38 .
\end{aligned}
$$

忽略沟道长度调制（channel-length modulation）时，$|A_v| = g_{m1}/g_{m3} = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_3]} = 3.66/1.386 = 2.64$。增益较低，是因为二极管负载只有约 $1/g_{m3}$。

### 第 3 步 — 最小输入共模电平

尾电流源需要 $V_P \ge 0.4$ V，而输入器件的栅极比 $P$ 高出 $V_{GS1} = V_{TH1} + V_{ov1}$：

$$V_{ov1} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = 0.273\ \mathrm{V}.$$

由 $V_{SB1} = V_P = 0.4$ V：

$$V_{TH1} = 0.7 + 0.45\left(\sqrt{0.9 + 0.4} - \sqrt{0.9}\right) = 0.7 + 0.45(1.1402 - 0.9487) = 0.786\ \mathrm{V}.$$

因此

$$V_{in,CM,min} = V_P + V_{ov1} + V_{TH1} = 0.4 + 0.273 + 0.786 = 1.46\ \mathrm{V}.$$

（不考虑体效应时：$0.4 + 0.273 + 0.7 = 1.37$ V。）

### 第 4 步 — 输入器件决定的摆幅界限

当 $V_{in,CM} = 1.46$ V 且差分输入很小时，$M_1$ 保持饱和的条件为

$$V_X \ge V_{in,CM} - V_{TH1} = 1.46 - 0.786 = 0.673\ \mathrm{V}.$$

完全导向时（$|V_{in1} - V_{in2}| \ge \sqrt2\,V_{ov1} = 0.386$ V），导通器件的栅极约高 0.19 V，它承载全部 $I_{SS}$，尾节点升到约 0.47 V。此时它的阈值约为 0.80 V，因此其漏极必须保持在 $1.65 - 0.80 \approx 0.85$ V 以上。（尾电流源的电压余度只会随差分对的导向而**增大**。）

### 第 5 步 — 二极管连接负载决定的摆幅界限

二极管连接的 PMOS 始终处于饱和，其漏极电压由其电流决定：

$$V_{out} = V_{DD} - |V_{THP}| - \sqrt{\frac{2I_D}{\beta_p}} .$$

每个负载的电流只能在 0 到 $I_{SS}$ 之间变化：

- $I_D \to 0$（另一边承载全部电流）：$V_{out} \to V_{DD} - |V_{THP}| = 3 - 0.8 = 2.2$ V；
- $I_D = I_{SS} = 1$ mA：$V_{out} = 2.2 - \sqrt{2(1\ \mathrm{mA})/(1.92\ \mathrm{mA/V^2})} = 2.2 - 1.021 = 1.18$ V；
- 平衡时（0.5 mA）：$V_{out} = 2.2 - \sqrt{2(0.5)/1.92} = 2.2 - 0.722 = 1.48$ V（输出共模电平）。

所以每个输出只能在 **1.18 V 与 2.2 V 之间**变化。下端远高于输入器件的两个界限（平衡时 0.673 V，完全导向时约 0.85 V），因此输入对永远不会离开饱和区：**决定摆幅的是二极管负载，而不是输入对**。

### 第 6 步 — 最大摆幅

- 单端：每个输出 $2.2 - 1.18 = 1.02$ V 峰峰值。
- 差分：完全导向时一个输出为 2.2 V，另一个为 1.18 V，因此 $V_{out1} - V_{out2}$ 达到 $\pm 1.02$ V，即约 **2.0 V 峰峰值**。

从 $V_{DD} - |V_{THP}|$ = 2.2 V 到 $V_{in,CM} - V_{TH1}$ = 0.673 V 的朴素范围（每个输出 1.53 V）是**无法**达到的：低于 1.18 V 需要二极管电流大于全部尾电流。

### 结果

- **差分增益：** $|A_v| = g_{m1}(1/g_{m3}\parallel r_{O1}\parallel r_{O3}) = (3.66\ \mathrm{mS})(651\ \Omega) \approx 2.4$；若忽略 $\lambda$，则为 $g_{m1}/g_{m3} = 2.64$。
- **最小输入共模电平：** $V_{in,CM,min} = 0.4 + 0.273 + 0.786 \approx 1.46$ V（不考虑体效应时为 1.37 V）。
- **最大输出摆幅：** 受二极管连接负载限制。每个输出只能在 $V_{DD} - |V_{THP}| - \sqrt{2I_{SS}/\beta_p} \approx 1.18$ V 与 $V_{DD} - |V_{THP}| = 2.2$ V 之间变化，单端约 1.0 V 峰峰值。差分输出达到 ±1.02 V，约 2.0 V 峰峰值。

**常见错误。** 使用电流源负载的增益公式 $g_{m1}(r_{O1}\parallel r_{O3}) \approx 24$。二极管连接的负载只呈现 $1/g_{m3} \approx 0.72$ kΩ，因此增益约为 2.4。

**常见错误。** 让输出向上摆到 $V_{DD}$，或者不检查负载能否到达就让输出向下摆到 0.673 V。二极管连接的 PMOS 无法把漏极拉到 $V_{DD} - |V_{THP}|$ 以上，而在最多只有 1 mA 的电流下也无法使其低于 1.18 V。

**常见错误。** 计算最小共模电平时漏掉 0.4 V 的尾电流源电压余度（只得到 $V_{GS1} \approx 1.0$ V），或者忽略了 $V_{TH1}$ 的体效应，而体效应使其升高 86 mV。
