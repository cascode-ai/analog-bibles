# 详细步骤 - R139

**思路。** $V_b$ 决定节点 $X$（$M_1$ 的漏极）的电压：$V_X = V_b - V_{GS2}$。当 $V_b$ 从 0 开始升高时，$M_2$ 先导通，然后 $X$ 升高，$M_1$ 从深线性区进入饱和区。用同一个小信号模型（small-signal model）即可求出各处的增益：其中 $M_1$ 在任何工作区都用 $g_{m1}$ 和 $g_{ds1}$ 描述，$M_2$ 作为共栅器件；跟踪 $g_{m1}$ 和 $g_{ds1}$ 随 $V_b$ 增大的变化，就得到曲线的形状。

### 第 1 步 — 固定的量

由于 $\lambda = \gamma = 0$，两个阈值电压都是 0.7 V，饱和器件的输出电阻（output resistance）为无穷大。$M_1$ 的过驱动电压（overdrive voltage）固定为 $A \equiv V_{in} - 0.7$ V，饱和时流过 $I_1 = \tfrac12\beta_1A^2$（$\beta_1 = \mu_nC_{ox}(W/L)_1$）。$M_2$ 的 $V_{GS2} = V_b - V_X$，且 $V_{out} = V_{DD} - I_DR_D$。

### 第 2 步 — $V_b \le 0.7$ V：没有电流，增益为零

若 $M_2$ 导通，由 $V_X \ge 0$ 可得 $V_{GS2} \le V_b \le 0.7$ V，低于阈值电压，这是矛盾的。因此 $M_2$ 截止，$I_D = 0$：$V_{out} = V_{DD}$，$V_X = 0$（$M_1$ 导通但没有电流），$v_{in}$ 无法产生任何输出电流：

$$A_v = 0\quad\text{for } 0 \le V_b \le 0.7\ \mathrm{V}.$$

### 第 3 步 — $M_2$ 导通时的小信号模型

$V_b$ 和 $V_{DD}$ 为交流地：

- **$M_1$**：从 $X$ 流向地的 $g_{m1}v_{in}$，并联 $1/g_{ds1}$（$g_{m1} = \partial I_{D1}/\partial V_{GS1}$，$g_{ds1} = \partial I_{D1}/\partial V_{DS1}$）；
- **$M_2$**（饱和，共栅）：$v_{gs2} = -v_X$，从 out 流向 $X$ 的电流为 $-g_{m2}v_X$；
- **$R_D$** 从 out 接到交流地。

**$X$ 点的基尔霍夫电流定律（KCL）：**

$$-g_{m2}v_X = g_{m1}v_{in} + g_{ds1}v_X\quad\Longrightarrow\quad v_X = -\frac{g_{m1}}{g_{m2} + g_{ds1}}\,v_{in}.$$

**输出。** 向下流过 $M_2$ 的电流 $-g_{m2}v_X$ 来自 $R_D$：

$$v_{out} = -(-g_{m2}v_X)R_D = g_{m2}R_Dv_X = -\frac{g_{m1}g_{m2}R_D}{g_{m2} + g_{ds1}}\,v_{in},$$

$$A_v = -g_{m1}R_D\cdot\frac{g_{m2}}{g_{m2} + g_{ds1}} .$$

$M_1$ 的信号电流在其自身的 $g_{ds1}$ 与从 $M_2$ 源极看进去的电导 $g_{m2}$ 之间分流；只有流入 $M_2$ 的部分才能到达 $R_D$。对于 $M_1$：

| $M_1$ 的工作区 | $g_{m1}$ | $g_{ds1}$ |
|---|---|---|
| 线性区（$V_X < A$） | $\beta_1V_X$ | $\beta_1(A - V_X)$ |
| 饱和区（$V_X \ge A$） | $\beta_1A$ | 0 |

### 第 4 步 — 刚高于 $V_{TH}$：$M_1$ 处于深线性区，增益从零开始上升

当 $V_b$ 略高于 0.7 V 时，电流很小，$V_{out} \approx V_{DD}$，$M_2$ 处于饱和区，而 $X$ 仅略高于 0 V，因此 $M_1$ 处于**深线性区**：$g_{m1} = \beta_1V_X \approx 0$，而很大的 $g_{ds1} \approx \beta_1A$ 使那一点点信号电流大部分留在 $M_1$ 内部。所以 $|A_v|$ 从**零**开始（与第 2 步连续）。随着 $V_b$ 升高，$V_X = V_b - V_{GS2}$ 升高，$g_{m1}$ 增大而 $g_{ds1}$ 减小：**$|A_v|$ 增大**。电流较小时 $V_X \approx \beta_2(V_b - 0.7)^2/(2\beta_1A)$，因此增益起初增长得非常平缓，大致按 $(V_b - 0.7)^3$ 增长，随后加快。

### 第 5 步 — $M_1$ 进入饱和：增益达到最大值

$M_1$ 在 $V_X = A = V_{in} - 0.7$ V 处进入饱和，此时电流为 $I_1$，$V_{GS2} = 0.7 + \sqrt{2I_1/\beta_2}$：

$$V_b = V_X + V_{GS2} = (V_{in} - 0.7) + 0.7 + \sqrt{\frac{2I_1}{\beta_2}} = V_{in} + \sqrt{\frac{2I_1}{\beta_2}} .$$

此时 $g_{ds1} = 0$，因此全部信号电流都流入 $M_2$：

$$|A_v| = g_{m1}R_D = \beta_1(V_{in} - 0.7)R_D = \sqrt{2\beta_1I_1}\,R_D ,$$

这就是最大值。

### 第 6 步 — 此后：一直到 $V_b = 3$ V 的平坦平台

$V_b$ 更大时，$M_1$ 保持饱和，相当于一个**理想电流源**（$I_D = I_1$，$g_{m1} = \beta_1A$，$g_{ds1} = 0$），因此 $V_{out} = V_{DD} - I_1R_D$ 为常数，且

$$A_v = -g_{m1}R_D .$$

当 $V_{out} < V_b - 0.7$，即 $V_b > V_{DD} - I_1R_D + 0.7$ V 时，$M_2$ 进入线性区，但这**不会**改变增益：由 $X$ 点的 KCL，来自 $M_1$（输出电阻无穷大）的信号电流 $g_{m1}v_{in}$ 只能经 $M_2$ 流入 $R_D$，与 $M_2$ 的小信号参数无关。$M_1$ 保持饱和，因为 $V_X$ 向 $V_{out} = V_{DD} - I_1R_D$ 靠近，而按假设该值高于 $V_{in} - 0.7$ V。平台一直延续到 $V_b = V_{DD}$。

### 第 7 步 — 数值示例

取 $V_{in} = 1.2$ V（$A = 0.5$ V），$\beta_1 = \beta_2 = 2\ \mathrm{mA/V^2}$，$R_D = 4$ kΩ：

$$
\begin{aligned}
I_1 &= \tfrac12(2\ \mathrm{mA/V^2})(0.5\ \mathrm{V})^2 = 0.25\ \mathrm{mA},\\
V_{out} &= 3 - (0.25\ \mathrm{mA})(4\ \mathrm{k\Omega}) = 2\ \mathrm{V} > A\ \ (\text{assumption satisfied}),\\
\text{break point } V_b &= 1.2 + \sqrt{2(0.25)/2}\ \mathrm{V} = 1.2 + 0.5 = 1.7\ \mathrm{V},\\
\text{plateau } |A_v| &= (2\ \mathrm{mA/V^2})(0.5\ \mathrm{V})(4\ \mathrm{k\Omega}) = 4,\\
M_2 \text{ enters triode for } V_b &> 2 + 0.7 = 2.7\ \mathrm{V}.
\end{aligned}
$$

### 结果

$|A_v| = |V_{out}/V_{in}|$ 随 $V_b$ 变化的曲线草图：

- **$0 \le V_b \le V_{TH} = 0.7$ V：** $M_2$ 截止，没有电流，$A_v = 0$。
- **$0.7\ \mathrm{V} < V_b < V_{in} + \sqrt{2I_1/\beta_2}$：** $M_1$ 处于线性区。随着 $X$ 升高，增益从 0 平滑上升，满足 $|A_v| = g_{m1}R_D\,g_{m2}/(g_{m2} + g_{ds1})$，其中 $g_{m1} = \beta_1V_X$，$g_{ds1} = \beta_1(V_{in} - 0.7 - V_X)$。
- **$V_b = V_{in} + \sqrt{2I_1/\beta_2}$**（即 $V_{in} - V_{TH} + V_{GS2}$）：$M_1$ 进入饱和，增益达到 $|A_v| = g_{m1}R_D = \sqrt{2\beta_1I_1}\,R_D$。
- **此后直到 $V_b = V_{DD}$：** 平坦的平台 $A_v = -g_{m1}R_D$（反相），即使 $M_2$ 进入线性区（当 $V_b > V_{DD} - I_1R_D + 0.7$ V 时）也保持不变，因为在 $\lambda = 0$ 时，$M_1$ 的全部信号电流都必须流入 $R_D$。

**常见错误。** 把增益画成在 $V_b$ 较小时最大、随后下降。$V_b$ 较小时，$X$ 接近地电位，$M_1$ 处于深线性区，几乎没有跨导（transconductance），因此增益接近零。

**常见错误。** 声称 $M_2$ 进入线性区时增益下降。在 $\lambda = 0$ 时，$M_1$ 的信号电流除了经 $M_2$ 流到 $R_D$ 之外没有其他通路，因此平台保持在 $g_{m1}R_D$。

**常见错误。** 给出共源共栅本征增益（intrinsic gain）类型的平台，即 $g_{m1}g_{m2}r_{O1}r_{O2}$，或在 $M_2$ 截止时得出非零增益。负载是电阻 $R_D$，并且在 $V_b = 0.7$ V 以下没有电流通路。
