$V_b \le V_{TH}$ 时 $A_v = 0$；$V_b$ 更大时，在 $M_1$ 处于线性区（triode region）期间，增益幅值从 0 开始上升，当 $M_1$ 在 $V_b = V_{in} + \sqrt{2I_1/\beta_2}$ 处进入饱和时达到 $g_{m1}R_D$，此后一直保持为 $-g_{m1}R_D$，直到 $V_b = V_{DD}$。

- $V_b \le 0.7$ V：$M_2$ 截止，没有电流，$A_v = 0$。
- 刚高于该值时：$M_2$ 饱和（漏极接近 $V_{DD}$），电流很小，节点 $X$ 接近 0，因此 $M_1$ 处于深线性区，$g_{m1} = \beta_1V_X$，$g_{ds1} = \beta_1(V_{in} - 0.7 - V_X)$。共栅（common-gate）管 $M_2$ 把电流传送到 $R_D$：$A_v = -g_{m1}R_D\,g_{m2}/(g_{m2} + g_{ds1})$，它从 0 开始，并随 $V_b$（从而 $V_X$）升高而增大。
- 当 $V_b = V_X + V_{GS2} = V_{in} + \sqrt{2I_1/\beta_2}$ 时，$V_X$ 达到 $V_{in} - 0.7$ V：$M_1$ 进入饱和，$|A_v| = g_{m1}R_D = \sqrt{2\beta_1I_1}R_D$，为最大值。
- 此后：$M_1$ 是电流固定为 $I_1$ 的电流源（current source）；即使 $M_2$ 进入线性区（当 $V_b > V_{DD} - I_1R_D + 0.7$ V 时），由于 λ = 0，小信号电流 $g_{m1}v_{in}$ 仍全部流入 $R_D$，因此增益保持为 $-g_{m1}R_D$，直到 $V_b = 3$ V。
