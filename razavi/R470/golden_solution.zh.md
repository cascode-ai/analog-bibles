$\overline{V^2_{n,in}} = \dfrac{8kT\gamma\left[(g_{m1} + g_{m3})(g_{m5}R_1)^2 + g_{m1'} + g_{m5} + g_{m7}\right]}{(g_{m1}g_{m5}R_1 + g_{m1'})^2}$，其中 $R_1 = r_{O1}\|r_{O3}$。

- 从差分输入到每一半电路输出电流的总跨导（transconductance）：$G_m = g_{m1}g_{m5}R_1 + g_{m1'}$（两条通路同相）。
- 每一半电路在输出节点处的噪声电流：$M_5$、$M_7$ 和快速通路器件（$M_1'$ 或 $M_2'$）直接注入 $4kT\gamma(g_{m5} + g_{m7} + g_{m1'})$；$M_1$ 和 $M_3$ 在 X 处注入 $4kT\gamma(g_{m1}+g_{m3})$，它到达输出端时要乘以 $(g_{m5}R_1)^2$。
- 两半电路 → 因子 2（8kT）；尾电流源只贡献共模（common-mode）噪声。
- 当 $g_{m1}g_{m5}R_1 \gg g_{m1'}$ 时，上式简化为 ≈ $8kT\gamma[(g_{m1}+g_{m3})/g_{m1}^2]$，再加上除以 $(g_{m1}g_{m5}R_1)^2$ 的较小的输出级项。
