# 详细步骤 - R470

**思路。** 用短路输出电流（short-circuit output current）来分析。对每一半电路，求出从输入到输出电流的总信号跨导 $G_m$（慢速通路加快速通路，两者同相），以及该半电路中每个晶体管送到同一输出节点的总噪声电流。输入参考噪声等于输出噪声电流除以 $G_m$ 后再平方，并对两个独立的半边电路乘以因子 2。

### 第 1 步 — 信号跨导

令 $R_1 = r_{O1}\parallel r_{O3}$，即 X（和 Y）处的电阻。对于差分输入（$\pm v_{in}/2$），两个尾电流节点都是虚地（virtual ground），注入 $V_{out1}$ 的电流是以下两项之和：

- **慢速通路：** X 变化 $-g_{m1}R_1\,v_{in}/2$，因此 $M_5$ 从 $V_{out1}$ 抽取的电流**减少** $g_{m5}g_{m1}R_1\,v_{in}/2$，即它注入 $g_{m1}g_{m5}R_1\,v_{in}/2$；
- **快速通路：** $M_2'$（栅极电压为 $-v_{in}/2$，漏极交叉连接到 $V_{out1}$）注入 $g_{m1'}\,v_{in}/2$。

两者同相相加，因此每一半电路的跨导为

$$G_m = g_{m1}g_{m5}R_1 + g_{m1'} ,$$

而取 $R_{out} = r_{O5}\parallel r_{O7}\parallel r_{O1'}$，差模增益（differential gain）为 $G_mR_{out}$。

### 第 2 步 — 各噪声源及其到达 $V_{out1}$ 的方式

**输出节点处（直接注入）。** $M_5$、$M_7$ 和快速通路器件 $M_2'$ 的漏极都接在 $V_{out1}$：

$$\overline{I_{n,direct}^2} = 4kT\gamma\,(g_{m5} + g_{m7} + g_{m1'}).$$

（$M_2'$ 的噪声中两个快速差分对器件所共有的部分在差分输出中相互抵消，而差分部分把快速通路的尾电流节点视为虚地，因此对 $v_{out1} - v_{out2}$ 的净效果相当于其全部噪声电流都流入了 $V_{out1}$。）

**节点 X 处（经慢速通路）。** $M_1$（对差分量而言其源极位于虚地）和 $M_3$ 向 X 注入 $4kT\gamma(g_{m1} + g_{m3})$，在 X 处产生 $I_{nX}R_1$，$M_5$ 再把它转换为输出电流 $g_{m5}R_1I_{nX}$：

$$\overline{I_{n,via\,X}^2} = 4kT\gamma\,(g_{m1} + g_{m3})\,(g_{m5}R_1)^2 .$$

**尾电流源。** 每个尾电流源的噪声在其差分对的两个器件之间平均分配，因此是共模的，在匹配电路中会相互抵消。

### 第 3 步 — 半边电路的总输出噪声电流

各噪声源互不相关，因此

$$\overline{I_{n,out1}^2} = 4kT\gamma\left[(g_{m1} + g_{m3})(g_{m5}R_1)^2 + g_{m1'} + g_{m5} + g_{m7}\right].$$

### 第 4 步 — 两半电路及折合到输入端

右半边电路在 $V_{out2}$ 处加入一个功率相同的独立噪声电流，因此

$$\overline{V_{n,out}^2} = 2\,\overline{I_{n,out1}^2}\,R_{out}^2 .$$

除以 $(G_mR_{out})^2$，$R_{out}$ 被约去：

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \frac{2\,\overline{I_{n,out1}^2}\,R_{out}^2}{G_m^2R_{out}^2} = \frac{2\,\overline{I_{n,out1}^2}}{G_m^2}\\
&= \frac{8kT\gamma\left[(g_{m1} + g_{m3})(g_{m5}R_1)^2 + g_{m1'} + g_{m5} + g_{m7}\right]}{\left(g_{m1}g_{m5}R_1 + g_{m1'}\right)^2}, \qquad R_1 = r_{O1}\parallel r_{O3}.
\end{aligned}
$$

### 第 5 步 — 解读（低频）

在低频下 $g_{m1}g_{m5}R_1 \gg g_{m1'}$，因为 $g_{m1}R_1$ 是第一级增益（几十）。将分子和分母同除以 $(g_{m1}g_{m5}R_1)^2$：

$$\overline{V_{n,in}^2} \approx 8kT\gamma\left[\frac{g_{m1} + g_{m3}}{g_{m1}^2} + \frac{g_{m1'} + g_{m5} + g_{m7}}{(g_{m1}g_{m5}R_1)^2}\right].$$

第一项就是我们熟悉的以电流源为负载的 PMOS 差分对（differential pair）的噪声 $8kT\gamma(1/g_{m1} + g_{m3}/g_{m1}^2)$；输出节点处的器件，**包括快速差分对**，都被慢速通路跨导的平方所抑制。在高频下 $G_m \to g_{m1'}$，它们的影响会大得多，但本题关心的是低频值。

### 结果

$$\overline{V_{n,in}^2} = \frac{8kT\gamma\left[(g_{m1} + g_{m3})(g_{m5}R_1)^2 + g_{m1'} + g_{m5} + g_{m7}\right]}{\left(g_{m1}g_{m5}R_1 + g_{m1'}\right)^2}, \qquad R_1 = r_{O1}\parallel r_{O3},\ \gamma = \tfrac23,$$

当 $g_{m1}g_{m5}R_1 \gg g_{m1'}$ 时，它简化为 $\approx 8kT\gamma\left[\dfrac{g_{m1} + g_{m3}}{g_{m1}^2} + \dfrac{g_{m1'} + g_{m5} + g_{m7}}{(g_{m1}g_{m5}R_1)^2}\right]$。尾电流源只贡献共模噪声。

**常见错误。** 使用 $G_m = g_{m1}g_{m5}R_1 - g_{m1'}$。漏极的交叉连接使快速通路同相相加。

**常见错误。** 只用一条通路的增益来折合全部输出噪声，例如除以 $g_{m1'}^2$，或者在 $G_m$ 中漏掉 $g_{m1'}$。输入参考噪声要用**总**跨导来计算。

**常见错误。** 把尾电流源当作差模噪声源，或者漏掉因子 2。尾电流源的噪声是纯共模的，而两半电路中器件的噪声是相互独立的。
