# 详细步骤 - R314

**思路。** 只保留 $C_{GS2}$ 和 $R_G$，且 $\lambda = \gamma = 0$ 时，$M_1$ 从节点 X 吸取固定的信号电流 $g_{m1}V_{in}$。$M_2$ 必须通过其沟道或通过 $C_{GS2}$ 提供这一电流，而这两条通路都受 $V_{GS2}$ 控制。X 点的 KCL 确定了 $V_{GS2}$，且只有沟道部分到达输出端，因此结果与 $R_G$ 无关。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 的漏极（$M_2$ 的源极）记为 X，$M_2$ 的栅极记为 G。$M_1$ 的栅极没有电容，因此 $R_S$ 中没有信号电流，$M_1$ 的栅极电压就是 $V_{in}$；$V_b$ 和 $V_{DD}$ 都是交流地。

- **$M_1$：** 从 X 流向地的电流 $g_{m1}V_{in}$，与 $V_X$ 无关（$\lambda = 0$）。
- **$M_2$：** 从输出端流向 X 的电流 $g_{m2}V_{GS2}$，其中 $V_{GS2} = V_G - V_X$（没有 $g_{mb2}$，也没有 $r_{O2}$）。
- **$C_{GS2}$** 接在 G 与 X 之间，从 G 向 X 流过电流 $C_{GS2}s\,V_{GS2}$；**$R_G$** 接在 G 与地之间；**$R_D$** 接在输出端与地之间。

### 第 2 步 — 节点 X 的 KCL

$M_2$ 的沟道电流 $g_{m2}V_{GS2}$ 和流过 $C_{GS2}$ 的电流 $C_{GS2}sV_{GS2}$ 流入 X，而 $g_{m1}V_{in}$ 经 $M_1$ 流出：

$$g_{m2}V_{GS2} + C_{GS2}s\,V_{GS2} = g_{m1}V_{in}\quad\Longrightarrow\quad V_{GS2} = \frac{g_{m1}V_{in}}{g_{m2} + C_{GS2}s}.$$

$R_G$ 没有出现：流过 $C_{GS2}$ 的电流只由 $V_{GS2}$ 决定。

### 第 3 步 — 传递函数

输出端只连接 $R_D$ 和 $M_2$ 的漏极，因此 $-V_{out}/R_D = g_{m2}V_{GS2}$，即 $V_{out} = -R_D\,g_{m2}V_{GS2}$。代入 $V_{GS2}$：

$$
\begin{aligned}
V_{out} &= -R_D\,\frac{g_{m1}g_{m2}}{g_{m2} + C_{GS2}s}\,V_{in}\\
\frac{V_{out}}{V_{in}}(s) &= -\frac{g_{m1}R_D}{1 + \dfrac{C_{GS2}}{g_{m2}}s}.
\end{aligned}
$$

- 低频增益：$-g_{m1}R_D$，即带电阻负载的共源共栅级的常规增益。
- 一个极点，位于 $\omega_p = g_{m2}/C_{GS2}$，近似等于 $M_2$ 的特征频率（transit frequency）$\omega_T$。
- $R_G$ 和 $R_S$ 都不出现在结果中。

### 第 4 步 — 为什么 $R_G$ 不出现，以及它会改变什么

$M_1$ 迫使电流 $g_{m1}V_{in}$ 从 X 流出，该电流由受同一 $V_{GS2}$ 控制的两条并联通路提供；其中沟道承担的比例为

$$\frac{g_{m2}}{g_{m2} + C_{GS2}s},$$

与 $R_G$ 无关。只有沟道电流到达输出端；电容电流则流过 $C_{GS2}$ 到达 G，再经 $R_G$ 流到 $V_b$ 处的交流地。这与定义晶体管 $\omega_T$ 的电流分配完全相同。

不过 $R_G$ 确实会改变 G 和 X 的电压变化幅度。G 点的 KCL（经 $R_G$ 流入 G 的电流经 $C_{GS2}$ 流出）：

$$-\frac{V_G}{R_G} = C_{GS2}s\,V_{GS2}\quad\Longrightarrow\quad V_G = -R_GC_{GS2}s\,V_{GS2},$$

$$V_X = V_G - V_{GS2} = -V_{GS2}(1 + R_GC_{GS2}s) = -g_{m1}V_{in}\,\frac{1 + R_GC_{GS2}s}{g_{m2} + C_{GS2}s}.$$

因此在高频时，$M_2$ 的栅极和源极一起摆动，X 的摆幅更大，但 $V_{GS2}$ 以及输出都不变。X 点摆幅增大只会通过这里忽略的电容（$C_{DB1}$、$C_{SB2}$、$C_{GD1}$）产生影响。

### 结果

$$\frac{V_{out}}{V_{in}}(s) = -\frac{g_{m1}R_D}{1 + \dfrac{C_{GS2}}{g_{m2}}s}$$

只有一个极点，位于 $g_{m2}/C_{GS2}$（约为 $M_2$ 的 $\omega_T$），低频增益为 $-g_{m1}R_D$。$R_G$（以及 $R_S$）不出现在结果中：$M_1$ 的电流在 $M_2$ 的沟道与 $C_{GS2}$ 之间的分配只取决于 $g_{m2}$ 和 $C_{GS2}s$。$R_G$ 只改变 $M_2$ 栅极和源极的电压变化：$V_X = -g_{m1}V_{in}(1 + R_GC_{GS2}s)/(g_{m2} + C_{GS2}s)$。

**常见错误。** 写出与 $R_G$ 有关的极点，例如 $1/[(R_G + 1/g_{m2})C_{GS2}]$，好像 $C_{GS2}$ 是经 $R_G$ 加上源极电阻充电的。真正起作用的是 X 点的电流分配，它只取决于 $V_{GS2}$；$R_G$ 被精确地抵消了。

**常见错误。** 在 $V_{out}/V_{in}$ 中加入由 $R_G$ 产生的零点。因子 $1 + R_GC_{GS2}s$ 出现在 $V_X$ 中，而不在输出电流 $g_{m2}V_{GS2}$ 中。

**常见错误。** 给出不等于 $-g_{m1}R_D$ 的低频增益（例如包含 $R_S$ 或 $R_G$）。在直流时 $C_{GS2}$ 中没有电流，$M_1$ 的电流全部到达 $R_D$，而 $R_S$ 中没有电流。
