# 详细步骤 - R309

**思路。** 电路是对称的且由差分信号驱动，因此采用**半边电路**：把每个对称的跨接元件（两个 $R_2$ 电阻、$R_1$–$C_1$ 支路）从中点处拆开，中点对差分信号而言是交流地。在半边电路中，$M_1$ 的信号电流由共源共栅器件 $M_6$ 和 $R_1$–$C_1$ 支路分担，只有流过 $M_6$ 的部分才到达负载 $R_2$。在极低频和极高频下计算这一分流关系，即得到两个增益。

### 第 1 步 — 差分对称性

把 $M_1$、$M_2$ 的公共源极节点记为 P，$M_6$ 和 $M_5$ 的源极分别记为 X 和 Y，$M_3$、$M_4$ 的公共栅极节点（两个 $R_2$ 电阻的中点）记为 M。对差分输入，$V_{D6} = -V_{D5}$，$V_X = -V_Y$，因此：

- **M** 点电压为 $(V_{D6} + V_{D5})/2 = 0$，**对差分信号而言是交流地**。没有差分电流流入 $C_2$，因此 **$C_2$ 不影响差模增益**；它只对共模信号起作用。
- **$M_3$、$M_4$** 的栅极（M）和源极（$V_{DD}$）都处于交流地，因此 $v_{gs} = 0$；由于 $\lambda = 0$，它们**不流过信号电流**。
- 因此**每个输出端**都只看到一个接到交流地的 $R_2$。
- **P：** 尾电流源理想，$V_P = (V_{G1} + V_{G2})/2 = 0$，同样是交流地。

### 第 2 步 — 从一侧看 $R_1$–$C_1$ 支路

该支路的电流只取决于 $V_X - V_Y$：

$$I_b = \frac{V_X - V_Y}{R_1 + \dfrac{1}{C_1s}} = \frac{2V_X}{R_1 + \dfrac{1}{C_1s}} ,$$

因此从 X 看，它是一个对地阻抗

$$Z_b = \frac{V_X}{I_b} = \frac12\left(R_1 + \frac{1}{C_1s}\right) = \frac{R_1}{2} + \frac{1}{2C_1s} = \frac{1 + R_1C_1s}{2C_1s},$$

即从 X 到交流地之间是 **$R_1/2$ 与 $2C_1$ 的串联**。

### 第 3 步 — 半边电路

<!-- diagram: diagram-01.cir -->

- $M_1$ 的源极处于交流地（P），栅极电压为 $V_{in}/2$，它从 X 吸取电流 $i_1 = g_{m1}V_{in}/2$，与 $V_X$ 无关（$\lambda = 0$）。
- $M_6$ 的栅极处于交流地（$V_b$），它从 $D6$ 向下向 X 输送电流 $-g_{m5}V_X$（$g_{m6} = g_{m5}$，因为 $M_5$ 与 $M_6$ 相同）；从其源极看进去的输入电阻为 $1/g_{m5}$（$\lambda = \gamma = 0$）。
- $Z_b$ 接在 X 与地之间，$R_2$ 接在 $D6$ 与地之间；$M_3$ 不起任何作用。

### 第 4 步 — X 点的分流与输出电压

在 X 点，$M_1$ 吸取的电流由 $M_6$ 和 $Z_b$ 提供（其流入 X 的电流为 $-V_X/Z_b$）：

$$-g_{m5}V_X - \frac{V_X}{Z_b} = i_1\quad\Longrightarrow\quad V_X = -\frac{i_1}{g_{m5} + 1/Z_b}.$$

流过共源共栅器件的电流就是 $1/g_{m5}$ 与 $Z_b$ 构成的分流器中分得的部分：

$$i_6 = -g_{m5}V_X = i_1\,\frac{g_{m5}}{g_{m5} + 1/Z_b} = i_1\,\frac{Z_b}{Z_b + 1/g_{m5}} .$$

在 $D6$ 处，$M_3$ 不流过信号电流，因此 $i_6$ 来自 $R_2$：$-V_{D6}/R_2 = i_6$，即

$$V_{D6} = -R_2\,i_6 = -R_2\,\frac{g_{m1}V_{in}}{2}\cdot\frac{Z_b}{Z_b + 1/g_{m5}} .$$

由反对称性，$V_{D5} = -V_{D6}$，因此

$$V_{out} = V_{D6} - V_{D5} = 2V_{D6} = -g_{m1}R_2\,\frac{Z_b}{Z_b + 1/g_{m5}}\,V_{in}.$$

### 第 5 步 — 传递函数

代入 $Z_b = (1 + R_1C_1s)/(2C_1s)$，并将分子、分母同乘以 $2C_1s$：

$$
\begin{aligned}
\frac{Z_b}{Z_b + 1/g_{m5}} &= \frac{1 + R_1C_1s}{1 + R_1C_1s + 2C_1s/g_{m5}}\\
&= \frac{1 + R_1C_1s}{1 + (R_1 + 2/g_{m5})C_1s},
\end{aligned}
$$

$$\frac{V_{out}}{V_{in}}(s) = -g_{m1}R_2\,\frac{1 + R_1C_1s}{1 + (R_1 + 2/g_{m5})C_1s}.$$

它有一个位于 $s = -1/[(R_1 + 2/g_{m5})C_1]$ 的极点，以及一个频率稍高、位于 $s = -1/(R_1C_1)$ 的零点：这是一个在高频时降低增益的滞后网络（lag network）。

### 第 6 步 — 极低频与极高频

**极低频**（$s\to0$）：$C_1$ 开路，$Z_b\to\infty$，$M_1$ 的电流全部经共源共栅管流入 $R_2$：

$$\frac{V_{out}}{V_{in}} = -g_{m1}R_2, \qquad |A_v| = g_{m1}R_2 .$$

**极高频**（$s\to\infty$）：$C_1$ 短路，$Z_b\to R_1/2$，它在 X 点与共源共栅管的输入电阻 $1/g_{m5}$ 并联，因此 $M_1$ 的电流中只有比例为 $\dfrac{R_1/2}{R_1/2 + 1/g_{m5}}$ 的部分到达输出端：

$$\frac{V_{out}}{V_{in}} = -g_{m1}R_2\,\frac{R_1}{R_1 + 2/g_{m5}} = -g_{m1}R_2\,\frac{g_{m5}R_1}{2 + g_{m5}R_1}.$$

### 结果

$$\frac{V_{out}}{V_{in}}(s) = -g_{m1}R_2\,\frac{1 + R_1C_1s}{1 + (R_1 + 2/g_{m5})C_1s}$$

- **极低频：** $|A_v| = g_{m1}R_2$。
- **极高频：** $|A_v| = g_{m1}R_2\,\dfrac{R_1}{R_1 + 2/g_{m5}} = g_{m1}R_2\,\dfrac{g_{m5}R_1}{2 + g_{m5}R_1}$。

取 $M_6$ 的漏极电压减去 $M_5$ 的漏极电压作为输出，它相对于 $V_{G1} - V_{G2}$ 是反相的。$C_2$ 对差模增益没有影响，因为两个 $R_2$ 电阻的中点是差分虚地。

**常见错误。** 让 PMOS 器件决定增益，例如得到 $g_{m1}/g_{m3}$，好像它们是二极管连接（diode-connected）的一样。它们的栅极处于差分交流地，因此在 $\lambda = 0$ 时它们是理想电流源，负载为 $R_2$。

**常见错误。** 认为 $C_2$ 会改变差模增益。没有差分电流到达节点 M，因此 $C_2$ 中没有差分电流；它只对共模信号有影响。

**常见错误。** 每侧用 $R_1$ 而不是 $R_1/2$，或者在高频时漏掉 $R_1$（得到零增益或不变的 $g_{m1}R_2$）。每个半边电路看到的是该支路电阻的一半（以及电容的两倍），在高频时它会把 $M_1$ 的一部分电流从共源共栅管分流出去：增益下降，但不会降到零。
