极低频：$|A_v| = g_{m1}R_2$。极高频：$|A_v| = g_{m1}R_2\dfrac{R_1}{R_1 + 2/g_{m5}} = g_{m1}R_2\dfrac{g_{m5}R_1}{2 + g_{m5}R_1}$。
（符号：$M_6$ 漏极处的输出相对于 $M_1$ 的栅极是反相的。）

传递函数（差分形式，$V_{out} = V_{D6} - V_{D5}$，$V_{in} = V_{G1} - V_{G2}$）：
$$\frac{V_{out}}{V_{in}} = -g_{m1}R_2\frac{1 + R_1C_1s}{1 + (R_1 + 2/g_{m5})C_1s}$$
- 对差分信号而言，由于对称性，两个 $R_2$ 电阻的中点（$M_3$、$M_4$ 的栅极）始终处于交流地，与 $C_2$ 无关；$C_2$ 只影响共模（common-mode）信号。因此每个输出端都看到一个接到交流地的 $R_2$，而 $M_3$/$M_4$（λ = 0）不增加任何电导。
- 半边电路（half circuit）：$M_1$ 的电流 $g_{m1}V_{in}/2$ 从节点 X 吸取，X 是共源共栅（cascode）管 $M_6$ 的源极，并且还连接着 $R_1$–$C_1$ 支路；对差分信号而言，该支路的中点是虚地（virtual ground），因此 X 看到的是 $R_1/2$ 与 $2C_1$ 的串联。
- 低频时 $C_1$ 开路，$M_1$ 的电流全部经共源共栅管流入 $R_2$：增益为 $g_{m1}R_2$。高频时 X 看到 $R_1/2$ 与共源共栅管的输入电阻 $1/g_{m5}$ 并联，因此只有比例为 $\dfrac{R_1/2}{R_1/2 + 1/g_{m5}}$ 的电流到达输出端。
