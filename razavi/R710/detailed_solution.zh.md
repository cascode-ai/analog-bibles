# 详细步骤 - R710

**思路。** 只有一种均匀介质时，某层单位面积对衬底的电容为 $\epsilon/h$，因此由给定值可以确定每层金属的高度（以 $\epsilon$ 为单位），而两个叠放极板之间的电容等于 $\epsilon$ 除以它们的间距。计算金属 4–金属 3 和金属 3–金属 2 的电容并相加（它们在两端子之间是并联的），并注意只有底极板，即金属 2，面对衬底。

### 第 1 步 — 由对衬底的电容求高度

由 $h = \epsilon/C_{sub}$，以 $\epsilon/(\mathrm{aF/\mu m^2})$ 为单位：

$$
\begin{aligned}
h_4 &= \frac{1}{7.0} = 0.1429,\\
h_3 &= \frac{1}{9.0} = 0.1111,\\
h_2 &= \frac{1}{15} = 0.0667 ,
\end{aligned}
$$

因此金属 4 是最上层，金属 2 是最下层。

### 第 2 步 — 两个叠放层之间的电容

极板 $i$（上）和 $j$（下）之间隔着厚度为 $h_i - h_j$ 的同一种介质，其单位面积电容为

$$C_{ij} = \frac{\epsilon}{h_i - h_j} = \frac{\epsilon}{\dfrac{\epsilon}{C_{sub,i}} - \dfrac{\epsilon}{C_{sub,j}}} = \frac{1}{\dfrac{1}{C_{sub,i}} - \dfrac{1}{C_{sub,j}}} ,$$

等价地，$1/C_{sub,i} = 1/C_{ij} + 1/C_{sub,j}$（层 $i$ 对衬底的电容是 $C_{ij}$ 与 $C_{sub,j}$ 的串联）。

**金属 4 – 金属 3：**

$$\frac{1}{C_{43}} = \frac{1}{7} - \frac{1}{9} = \frac{9 - 7}{63} = \frac{2}{63}\ \frac{\mu\mathrm{m^2}}{\mathrm{aF}} \quad\Longrightarrow\quad C_{43} = 31.5\ \mathrm{aF/\mu m^2}.$$

**金属 3 – 金属 2：**

$$\frac{1}{C_{32}} = \frac{1}{9} - \frac{1}{15} = \frac{15 - 9}{135} = \frac{6}{135}\ \frac{\mu\mathrm{m^2}}{\mathrm{aF}} \quad\Longrightarrow\quad C_{32} = \frac{135}{6} = 22.5\ \mathrm{aF/\mu m^2}.$$

### 第 3 步 — 两端子之间的总电容

两个端子为 A = 金属 4 + 金属 2，B = 金属 3。金属 3 夹在端子 A 的两块极板之间，因此 $C_{43}$ 和 $C_{32}$ 都连接在 A 与 B 之间，二者**并联**：

<!-- diagram: diagram-01.cir -->

$$C = C_{43} + C_{32} = 31.5 + 22.5 = 54\ \mathrm{aF/\mu m^2}.$$

与两层（金属 4/金属 3）电容相比，中间极板的两面都得到利用，使电容密度提高到 $54/31.5 = 1.71$ 倍。

### 第 4 步 — 寄生电容与比值

金属 2（底极板，属于端子 A）面对衬底，中间没有任何东西：

$$C_P = C_{sub,2} = 15\ \mathrm{aF/\mu m^2}.$$

金属 3 被包在金属 4 和金属 2 之间，金属 4 被金属 3 和金属 2 屏蔽，因此二者对衬底都没有电容（忽略边缘效应）。于是

$$\frac{C_P}{C} = \frac{15}{54} = 0.278 \approx 0.28 ,$$

比两层的金属 4/金属 3 电容（$9/31.5 = 0.29$）略好：电容增大了 71 %，寄生电容增大了 67 %（从 9 增大到 15 aF/µm²，因为金属 2 比金属 3 更靠近衬底）。

### 结果

单位面积上：

$$C = C_{43} + C_{32} = 31.5 + 22.5 = 54\ \mathrm{aF/\mu m^2}, \qquad C_P = 15\ \mathrm{aF/\mu m^2}, \qquad \frac{C_P}{C} \approx 0.28 .$$

**常见错误。** 把各层间电容算成对衬底电容之差或之和（例如 $9 - 7 = 2$ 或 $15 - 9 = 6$ aF/µm²）。电容与间距成反比，因此相减的应是倒数：$C_{ij} = 1/(1/C_{sub,i} - 1/C_{sub,j})$。

**常见错误。** 只计入一个层间电容。金属 4 和金属 2 连在一起后，金属 3 通过其上下两个表面与端子 A 耦合，两个电容相加。

**常见错误。** 把金属 4 或金属 3 对衬底的电容加到 $C_P$ 中。这些极板被屏蔽；只有最下面的极板，即金属 2，面对衬底。
