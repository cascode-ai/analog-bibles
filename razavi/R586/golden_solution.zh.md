采用一阶增益误差近似时，$C_1/C_2 \approx 8.2$（$C_2$ ≈ 0.244 pF）；采用精确表达式时为 8.27（$C_2$ = 0.242 pF）。

- 实际增益：$|V_{out}/V_{in}| = C_1/[C_2 + (C_1 + C_2 + C_{in})/A_{v1}]$。增益误差 ≈ $(C_1 + C_2 + C_{in})/(C_2A_{v1})$，即 1/环路增益（loop gain），其中反馈系数（feedback factor）为 $C_2/(C_1 + C_2 + C_{in})$。
- 令其等于 1%：$C_1 + C_2 + C_{in} = 10C_2$，因此 $C_2 = 2.2\ \mathrm{pF}/9 = 0.244$ pF，$C_1/C_2 = 8.18$。
- 精确解（$x/(1 + x) = 1\%$，其中 $x = (C_1 + C_2 + C_{in})/(C_2A_{v1})$）：$x = 0.0101$，$C_2 = 2.2/9.101 = 0.2417$ pF，比值为 8.27。
