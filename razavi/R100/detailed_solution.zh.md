# 详细步骤 - R100

**思路。** 输出端是 $M_2$ 的*源极*（其栅极固定接 $V_{b1}$），同时也是电流源（current source）$M_1$（栅极接 $V_{b2}$）的漏极。因此 $M_2$ 是一个跟随恒定电压的源极跟随器（source follower），由 $M_1$ 提供偏置，而输入 PMOS 管 $M_3$ 只是从上方提供电流。只要 $M_3$ 能提供 $M_1$ 所需的电流，并给 $M_2$ 留出足够的漏极电压，输出就与 $V_{in}$ 完全无关。先求出这段平台，再找出它在何处结束（取两个条件中先发生的那个），然后跟踪输出一直降到 $V_{in} = V_{DD} - |V_{THP}|$ 处的零。

### 第 1 步 — 电路与关键量

由图可知：$M_3$（PMOS）的源极接 $V_{DD} = 3$ V，栅极接 $V_{in}$，漏极接节点 $D$。$M_2$（NMOS）的漏极接 $D$，栅极接 $V_{b1}$，源极接 $V_{out}$。$M_1$（NMOS）的漏极接 $V_{out}$，栅极接 $V_{b2}$，源极接地。NMOS 的衬底（bulk）接地，因此 $M_2$ 的 $V_{SB2} = V_{out}$。三个管子流过相同的电流 $I$，且 $\lambda = 0$。

**$M_1$ 饱和时的电流**（$V_{out} \ge V_{b2} - 0.7$ V）：

$$I_1 = \frac12\beta_1(V_{b2} - 0.7)^2 .$$

**$M_3$** 的 $V_{SG3} = 3 - V_{in}$；当 $V_{in} < 2.2$ V 时导通，其饱和电流为 $\frac12\beta_3(2.2 - V_{in})^2$，饱和条件为 $V_{SD3} \ge 2.2 - V_{in}$。

**$M_2$** 在 $V_D \ge V_{b1} - V_{TH2}(V_{out})$ 时处于饱和区（saturation region）。

### 第 2 步 — $V_{in}$ 较小时：平坦的平台

$V_{in}$ 较小时，$M_3$ 的栅极驱动很强，能够提供远大于 $I_1$ 的电流。因此电流由 $M_1$ 决定，$I = I_1$，而 $M_3$ 处于**线性区**（triode region），$V_{SD3}$ 很小：节点 $D$ 略低于 $V_{DD}$。

于是 $M_2$ 流过固定电流 $I_1$，栅极接固定电压 $V_{b1}$。在饱和区，$V_{GS2} = V_{TH2} + \sqrt{2I_1/\beta_2}$，因此

$$V_{out} = V_0 = V_{b1} - V_{TH2}(V_0) - \sqrt{\frac{2I_1}{\beta_2}} ,$$

**与 $V_{in}$ 无关**：一条水平线。（这里假设 $V_0 > V_{b2} - 0.7$ V，使 $M_1$ 确实处于饱和区。）输入只改变 $M_3$ 上的压降，即节点 $D$ 的位置；它影响不到输出。

### 第 3 步 — 节点 $D$ 如何移动，以及平台结束的两种方式

随着 $V_{in}$ 升高，$M_3$ 的栅极驱动减弱，因此它需要更大的 $V_{SD3}$ 才能流过 $I_1$：

$$I_1 = \beta_3\left[(2.2 - V_{in})V_{SD3} - \tfrac12V_{SD3}^2\right], \qquad V_D = V_{DD} - V_{SD3} .$$

因此 $V_D$ 下降。只要以下**两个**条件同时成立，平台就持续存在：

1. **$M_2$ 有足够的电压余度（headroom）：** $V_D \ge V_{b1} - V_{TH2}(V_0)$，使 $M_2$ 保持饱和；并且
2. **$M_3$ 仍能提供 $I_1$：** 其饱和电流 $\frac12\beta_3(2.2 - V_{in})^2 \ge I_1$，即
$$V_{in} \le V_{in}^* = 2.2 - \sqrt{\frac{2I_1}{\beta_3}} = 2.2 - (V_{b2} - 0.7)\sqrt{\frac{\beta_1}{\beta_3}} .$$

在 $V_{in}^*$ 处，$M_3$ 恰好处于线性区/饱和区的边界，因此 $V_D(V_{in}^*) = V_{DD} - \sqrt{2I_1/\beta_3}$。哪个条件先不满足，平台就在哪里结束。

### 第 4 步 — 情形 (a)：平台在 $V_{in}^*$ 处结束（竖直下跌）

如果当 $V_{in}$ 到达 $V_{in}^*$ 时 $V_D$ 仍高于 $V_{b1} - V_{TH2}$，那么平台的结束是由于 $M_3$ 进入了电流受限状态。在 $V_{in}^*$ 处，$M_3$ 和 $M_1$ 是两个流过相同电流的饱和电流源，在 $\lambda = 0$ 的情况下，两者之间没有任何东西能确定电压：增益为无穷大，$V_{out}$ 在 $V_{in}^*$ 处**竖直下跌**。它一直降到 $V_{b2} - 0.7$ V，此时 $M_1$ 退出饱和区；在下跌过程中，$M_2$ 的 $V_{GS}$ 随 $V_{out}$ 下降而增大，使其进入线性区，$V_D$ 也随之骤降到接近 $V_{out}$。

**超过 $V_{in}^*$ 之后**，$M_3$ 处于饱和区并决定电流，$I = \frac12\beta_3(2.2 - V_{in})^2 < I_1$。$M_1$（以及 $M_2$）处于线性区，输出由 $M_1$ 的线性区方程决定：

$$\frac12\beta_3(2.2 - V_{in})^2 = \beta_1\left[(V_{b2} - 0.7)V_{out} - \tfrac12V_{out}^2\right],$$

它从 $V_{in}^*$ 处的 $V_{b2} - 0.7$ V 平滑地下降到 $V_{in} = 2.2$ V 处的 0。

### 第 5 步 — 情形 (b)：平台因电压余度不足而结束（逐渐下降）

反之，如果 $V_D$ 在 $V_{in}^*$ 之前就降到 $V_{b1} - V_{TH2}$（$M_3$ 较弱，或 $V_{b1}$ 较高），那么在电流仍为 $I_1$ 时 $M_2$ 就已进入线性区。此后 $M_2$ 相当于一个小电阻，$V_{out}$ 随 $V_D$ 一起下降，这是斜率有限的逐渐下降。当 $V_{out}$ 降到 $V_{b2} - 0.7$ V 时，$M_1$ 也进入线性区，随后电流降到 $I_1$ 以下。这种情形下不会出现竖直跳变，因为 $M_2$ 失去电压余度已在 $V_{in}^*$ 之前把 $V_{out}$ 拉低到 $V_{b2} - 0.7$ V。

### 第 6 步 — $V_{in} \ge 2.2$ V：$M_3$ 截止

当 $V_{in} \ge V_{DD} - |V_{THP}| = 2.2$ V 时，$M_3$ 截止，没有电流流过。$M_1$ 的栅极偏置使其导通，它在零电流下把输出拉到地：

$$V_{out} = 0\qquad (V_{in} \ge 2.2\ \mathrm{V}).$$

### 第 7 步 — 数值示例

作为示例，取 $V_{b1} = 2.0$ V，$V_{b2} = 1.0$ V，$\beta_1 = \beta_2 = 2\ \mathrm{mA/V^2}$，$\beta_3 = 1\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_1 &= \tfrac12(2\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 90\ \mu\mathrm{A},\qquad \sqrt{2I_1/\beta_2} = 0.3\ \mathrm{V},\\
V_0 + V_{TH2}(V_0) &= 2.0 - 0.3 = 1.7\ \mathrm{V} \;\Rightarrow\; V_0 = 0.834\ \mathrm{V}\ \ (V_{TH2} = 0.866\ \mathrm{V}),\\
V_{in}^* &= 2.2 - \sqrt{2(90\ \mu\mathrm{A})/(1\ \mathrm{mA/V^2})} = 2.2 - 0.424 = 1.776\ \mathrm{V},\\
V_D(V_{in}^*) &= 3 - 0.424 = 2.576\ \mathrm{V} > V_{b1} - V_{TH2} = 1.134\ \mathrm{V}.
\end{aligned}
$$

在 $V_{in}^*$ 处 $M_2$ 仍有电压余度，因此属于**情形 (a)**。验证：$V_0 = 0.834$ V 高于 $V_{b2} - 0.7 = 0.3$ V，所以在平台上 $M_1$ 处于饱和区。

**下跌之后**，例如在 $V_{in} = 2.0$ V 处：$\frac12(1\ \mathrm{mA/V^2})(0.2)^2 = 20\ \mu\mathrm{A} = (2\ \mathrm{mA/V^2})[0.3V_{out} - 0.5V_{out}^2]$，即 $V_{out}^2 - 0.6V_{out} + 0.02 = 0$，所以 $V_{out} = (0.6 - \sqrt{0.28})/2 = 0.035$ V。

|---|---|---|---|---|---|
| 0 | 0.834 | 2.959 | 线性区 | 饱和 | 饱和 |
| 1.5 | 0.834 | 2.857 | 线性区 | 饱和 | 饱和 |
| 1.776 | 0.834 → 0.300 | 2.576 → ≈ 0.3 | 饱和 | → 线性区 | → 线性区 |
| 1.8 | 0.200 | 0.239 | 饱和 | 线性区 | 线性区 |
| 1.9 | 0.088 | 0.107 | 饱和 | 线性区 | 线性区 |
| 2.0 | 0.035 | 0.043 | 饱和 | 线性区 | 线性区 |
| ≥ 2.2 | 0 | 0 | 截止 | — | — |

### 结果

$V_{out}$ 先是**平坦**的（与 $V_{in}$ 无关），其电平由跟随器 $M_2$ 决定；当 $M_3$ 不能再使 $M_2$ 的漏极保持足够高的电位，或不能再提供 $I_1 = \tfrac12\beta_1(V_{b2} - 0.7)^2$ 时，便开始**下降**。它在 $V_{in} = V_{DD} - |V_{THP}| = 2.2$ V 处降到 0 V，此后一直保持 0 V。

- **$V_{in}$ 较小时：** $M_3$ 强导通（线性区），其漏极 $D$ 接近 $V_{DD}$；$M_2$ 是处于饱和区、流过 $I_1$ 的源极跟随器：$V_{out} = V_0 = V_{b1} - V_{TH2}(V_0) - \sqrt{2I_1/\beta_2}$，与 $V_{in}$ 无关（假设 $V_0 > V_{b2} - 0.7$ V，使 $M_1$ 处于饱和区）。
- 随着 $V_{in}$ 升高，$M_3$ 需要更大的 $V_{SD}$ 才能流过 $I_1$，于是 $V_D$ 下降。只要 $V_D \ge V_{b1} - V_{TH2}$（$M_2$ 饱和）并且 $M_3$ 仍能提供 $I_1$（$\tfrac12\beta_3(2.2 - V_{in})^2 \ge I_1$），平台就保持不变。
- 如果平台在 $V_{in}^* = 2.2 - (V_{b2} - 0.7)\sqrt{\beta_1/\beta_3}$ 处结束，而此时 $M_1$ 仍处于饱和区，那么该处的增益为无穷大（$\lambda = 0$），$V_{out}$ 竖直下跌到 $V_{b2} - 0.7$ V（下跌过程中 $M_2$ 进入线性区）。此后 $M_3$ 是电流源，$M_1$ 和 $M_2$ 处于线性区，并满足 $\tfrac12\beta_3(2.2 - V_{in})^2 = \beta_1[(V_{b2} - 0.7)V_{out} - V_{out}^2/2]$，直到 2.2 V 处 $V_{out} = 0$。只有当 $M_2$ 因失去电压余度而已在 $V_{in}^*$ 之前把 $V_{out}$ 拉低到 $V_{b2} - 0.7$ V 时，才不会出现跳变。
- **$V_{in} \ge 2.2$ V：** $M_3$ 截止，没有电流，$V_{out} = 0$。
- **转折点（transition point）：** 平台的终点（$V_D = V_{b1} - V_{TH2}$ 或 $V_{in} = 2.2 - \sqrt{2I_1/\beta_3}$，以先到者为准）、$V_{out} = V_{b2} - 0.7$ V、$V_{in} = 2.2$ V。

**常见错误。** 把 $M_2$ 当作输出取自其漏极的共源共栅（cascode）管，从而一开始就得到高增益的反相曲线。这里的输出是 $M_2$ 的*源极*，且其栅极固定：它是 $V_{b1}$ 的跟随器，因此只要 $M_2$ 和 $M_1$ 保持饱和，输出就是平坦的。

**常见错误。** 把输出画成在整个范围内都随 $V_{in}$ 上升（或下降）。在平台上，$V_{in}$ 的变化只改变 $M_3$ 上的压降（从而改变 $V_D$）；电流由 $M_1$ 决定，输出则由 $V_{b1} - V_{GS2}(I_1)$ 决定。

**常见错误。** 在 $V_{in} = 2.2$ V 以上仍画出非零输出。一旦 $M_3$ 截止，就没有任何东西为这一串联支路供电，（偏置导通的）$M_1$ 会把 $V_{out}$ 拉到 0 V。
