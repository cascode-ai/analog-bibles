# 详细步骤 - R100

**思路。** 输出取自 $M_2$ 的**源极**，它是跟随固定电压 $V_{b1}$ 的跟随器，由电流源 $M_1$ 偏置；输入 PMOS $M_3$ 只是从上方提供电流。先求出输出与 $V_{in}$ 无关的平台，再求出平台的终点（两个条件中先满足的那个），然后跟踪输出直到它在 $V_{in} = V_{DD} - |V_{THP}|$ 处降到零。

### 第 1 步 — 关键量

把 $M_3$ 与 $M_2$ 的公共漏极节点记为 $D$。三个晶体管流过相同的电流 $I$（$\lambda = 0$），且 $M_2$ 的 $V_{SB2} = V_{out}$。

**$M_1$ 饱和时的电流**（$V_{out} \ge V_{b2} - 0.7$ V）：

$$I_1 = \frac12\beta_1(V_{b2} - 0.7)^2 .$$

**$M_3$** 的 $V_{SG3} = 3 - V_{in}$；它在 $V_{in} < 2.2$ V 时导通，饱和电流为 $\frac12\beta_3(2.2 - V_{in})^2$，饱和条件为 $V_{SD3} \ge 2.2 - V_{in}$。

**$M_2$** 在 $V_D \ge V_{b1} - V_{TH2}(V_{out})$ 时处于饱和区。

### 第 2 步 — $V_{in}$ 较小：平坦的平台

$V_{in}$ 较小时，$M_3$ 能提供远多于 $I_1$ 的电流，因此电流由 $M_1$ 决定，$I = I_1$，而 $M_3$ 处于**线性区**，$V_{SD3}$ 很小：节点 $D$ 略低于 $V_{DD}$。

于是 $M_2$ 在栅极电压固定为 $V_{b1}$ 的情况下流过固定电流 $I_1$。在饱和区，$V_{GS2} = V_{TH2} + \sqrt{2I_1/\beta_2}$，因此

$$V_{out} = V_0 = V_{b1} - V_{TH2}(V_0) - \sqrt{\frac{2I_1}{\beta_2}} ,$$

它**与 $V_{in}$ 无关**：是一条水平线。（这里假设 $V_0 > V_{b2} - 0.7$ V，从而 $M_1$ 确实处于饱和区。）输入只改变 $M_3$ 上的压降，即节点 $D$ 的位置。

### 第 3 步 — 节点 $D$ 的变化，以及平台结束的两种方式

随着 $V_{in}$ 升高，$M_3$ 的栅极驱动减小，因此需要更大的 $V_{SD3}$ 才能流过 $I_1$：

$$I_1 = \beta_3\left[(2.2 - V_{in})V_{SD3} - \tfrac12V_{SD3}^2\right], \qquad V_D = V_{DD} - V_{SD3} .$$

因此 $V_D$ 下降。只有当以下**两个**条件都满足时，平台才能保持：

1. **$M_2$ 有足够的电压余度：** $V_D \ge V_{b1} - V_{TH2}(V_0)$，使 $M_2$ 保持饱和；并且
2. **$M_3$ 仍能提供 $I_1$：** 其饱和电流 $\frac12\beta_3(2.2 - V_{in})^2 \ge I_1$，即
$$V_{in} \le V_{in}^* = 2.2 - \sqrt{\frac{2I_1}{\beta_3}} = 2.2 - (V_{b2} - 0.7)\sqrt{\frac{\beta_1}{\beta_3}} .$$

在 $V_{in}^*$ 处，$M_3$ 恰好位于线性区/饱和区的边界，因此 $V_D(V_{in}^*) = V_{DD} - \sqrt{2I_1/\beta_3}$。哪个条件先不满足，平台就在那里结束。

### 第 4 步 — 情形 (a)：平台在 $V_{in}^*$ 处结束（竖直下降）

若 $V_{in}$ 到达 $V_{in}^*$ 时 $V_D$ 仍高于 $V_{b1} - V_{TH2}$，平台就因 $M_3$ 受到电流限制而结束。在 $V_{in}^*$ 处，$M_3$ 和 $M_1$ 是两个流过相同电流的饱和电流源，在 $\lambda = 0$ 时，二者之间没有任何元件能确定电压：增益无界，$V_{out}$ 在 $V_{in}^*$ 处**竖直下降**到 $V_{b2} - 0.7$ V，此时 $M_1$ 离开饱和区。在下降过程中，$M_2$（其 $V_{GS}$ 随 $V_{out}$ 下降而增大）进入线性区，$V_D$ 也随之塌落到 $V_{out}$ 附近。

**在 $V_{in}^*$ 之后**，$M_3$ 饱和并决定电流，$I = \frac12\beta_3(2.2 - V_{in})^2 < I_1$。$M_1$（以及 $M_2$）处于线性区，输出由 $M_1$ 的线性区方程给出：

$$\frac12\beta_3(2.2 - V_{in})^2 = \beta_1\left[(V_{b2} - 0.7)V_{out} - \tfrac12V_{out}^2\right],$$

它从 $V_{in}^*$ 处的 $V_{b2} - 0.7$ V 平滑地下降到 $V_{in} = 2.2$ V 处的 0。

### 第 5 步 — 情形 (b)：平台因电压余度不足而结束（平缓下降）

反之，若 $V_D$ 在 $V_{in}^*$ 之前就降到 $V_{b1} - V_{TH2}$（$M_3$ 较弱，或 $V_{b1}$ 较高），$M_2$ 就会在电流仍为 $I_1$ 时进入线性区。此时它相当于一个小电阻，因此 $V_{out}$ 以有限斜率随 $V_D$ 下降。当 $V_{out}$ 降到 $V_{b2} - 0.7$ V 时，$M_1$ 也进入线性区，电流降到 $I_1$ 以下。这种情形下不会出现竖直跳变，因为 $M_2$ 的电压余度不足已经使 $V_{out}$ 在 $V_{in}^*$ 之前降到了 $V_{b2} - 0.7$ V。

### 第 6 步 — $V_{in} \ge 2.2$ V：$M_3$ 截止

当 $V_{in} \ge V_{DD} - |V_{THP}| = 2.2$ V 时，$M_3$ 截止，没有电流。栅极偏置使其导通的 $M_1$ 以零电流把输出拉到地：

$$V_{out} = 0\qquad (V_{in} \ge 2.2\ \mathrm{V}).$$

### 第 7 步 — 数值示例

为便于说明，取 $V_{b1} = 2.0$ V，$V_{b2} = 1.0$ V，$\beta_1 = \beta_2 = 2\ \mathrm{mA/V^2}$，$\beta_3 = 1\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_1 &= \tfrac12(2\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 90\ \mu\mathrm{A},\qquad \sqrt{2I_1/\beta_2} = 0.3\ \mathrm{V},\\
V_0 + V_{TH2}(V_0) &= 2.0 - 0.3 = 1.7\ \mathrm{V} \;\Rightarrow\; V_0 = 0.834\ \mathrm{V}\ \ (V_{TH2} = 0.866\ \mathrm{V}),\\
V_{in}^* &= 2.2 - \sqrt{2(90\ \mu\mathrm{A})/(1\ \mathrm{mA/V^2})} = 2.2 - 0.424 = 1.776\ \mathrm{V},\\
V_D(V_{in}^*) &= 3 - 0.424 = 2.576\ \mathrm{V} > V_{b1} - V_{TH2} = 1.134\ \mathrm{V}.
\end{aligned}
$$

在 $V_{in}^*$ 处 $M_2$ 仍有电压余度，因此属于**情形 (a)**。$V_0 = 0.834$ V $> V_{b2} - 0.7 = 0.3$ V，因此 $M_1$ 在平台上处于饱和区。

**下降之后**，例如在 $V_{in} = 2.0$ V 处：$\frac12(1\ \mathrm{mA/V^2})(0.2)^2 = 20\ \mu\mathrm{A} = (2\ \mathrm{mA/V^2})[0.3V_{out} - 0.5V_{out}^2]$，即 $V_{out}^2 - 0.6V_{out} + 0.02 = 0$，因此 $V_{out} = (0.6 - \sqrt{0.28})/2 = 0.035$ V。

| $V_{in}$ (V) | $V_{out}$ (V) | $V_D$ (V) | $M_3$ | $M_2$ | $M_1$ |
|---|---|---|---|---|---|
| 0 | 0.834 | 2.959 | 线性区 | 饱和 | 饱和 |
| 1.5 | 0.834 | 2.857 | 线性区 | 饱和 | 饱和 |
| 1.776 | 0.834 → 0.300 | 2.576 → ≈ 0.3 | 饱和 | → 线性区 | → 线性区 |
| 1.8 | 0.200 | 0.239 | 饱和 | 线性区 | 线性区 |
| 1.9 | 0.088 | 0.107 | 饱和 | 线性区 | 线性区 |
| 2.0 | 0.035 | 0.043 | 饱和 | 线性区 | 线性区 |
| ≥ 2.2 | 0 | 0 | 截止 | — | — |

### 结果

$V_{out}$ 先**平坦地**保持在由跟随器 $M_2$ 决定的电平上（与 $V_{in}$ 无关）；一旦 $M_3$ 不再能使 $M_2$ 的漏极保持足够高的电位，或不再能提供 $I_1 = \tfrac12\beta_1(V_{b2} - 0.7)^2$，它就开始**下降**。它在 $V_{in} = V_{DD} - |V_{THP}| = 2.2$ V 处降到 0 V，此后一直保持 0 V。

- **$V_{in}$ 较小时：** $M_3$ 强导通（线性区），其漏极 $D$ 接近 $V_{DD}$；$M_2$ 是流过 $I_1$ 的饱和源极跟随器：$V_{out} = V_0 = V_{b1} - V_{TH2}(V_0) - \sqrt{2I_1/\beta_2}$，与 $V_{in}$ 无关（假设 $V_0 > V_{b2} - 0.7$ V，从而 $M_1$ 饱和）。
- 随着 $V_{in}$ 升高，$M_3$ 需要更大的 $V_{SD}$ 才能流过 $I_1$，于是 $V_D$ 下降。只要 $V_D \ge V_{b1} - V_{TH2}$（$M_2$ 饱和），且 $M_3$ 仍能提供 $I_1$（$\tfrac12\beta_3(2.2 - V_{in})^2 \ge I_1$），平台就保持不变。
- 若平台在 $V_{in}^* = 2.2 - (V_{b2} - 0.7)\sqrt{\beta_1/\beta_3}$ 处结束，且此时 $M_1$ 仍处于饱和，则该处的增益无界（$\lambda = 0$），$V_{out}$ 竖直下降到 $V_{b2} - 0.7$ V（途中 $M_2$ 进入线性区）。此后 $M_3$ 是电流源，$M_1$ 和 $M_2$ 处于线性区，并满足 $\tfrac12\beta_3(2.2 - V_{in})^2 = \beta_1[(V_{b2} - 0.7)V_{out} - V_{out}^2/2]$，直到 2.2 V 处 $V_{out} = 0$。只有当 $M_2$ 失去电压余度已经使 $V_{out}$ 在 $V_{in}^*$ 之前降到 $V_{b2} - 0.7$ V 时，才不会出现跳变。
- **$V_{in} \ge 2.2$ V：** $M_3$ 截止，没有电流，$V_{out} = 0$。
- **转折点：** 平台的终点（$V_D = V_{b1} - V_{TH2}$ 或 $V_{in} = 2.2 - \sqrt{2I_1/\beta_3}$，以先到者为准），$V_{out} = V_{b2} - 0.7$ V，$V_{in} = 2.2$ V。

**常见错误。** 把 $M_2$ 当作输出取自其漏极的共源共栅（cascode）管，从而一开始就画出高增益的反相曲线。输出是 $M_2$ 的**源极**，而其栅极电压固定，因此只要 $M_2$ 和 $M_1$ 处于饱和区，输出就保持平坦。

**常见错误。** 把输出画成在整个范围内都随 $V_{in}$ 上升（或下降）。在平台上，$V_{in}$ 只改变 $M_3$ 上的压降；电流由 $M_1$ 决定，输出则由 $V_{b1} - V_{GS2}(I_1)$ 决定。

**常见错误。** 在 $V_{in} = 2.2$ V 以上仍保留非零输出。$M_3$ 一旦截止，就没有电流流入该叠层，而（偏置导通的）$M_1$ 会把 $V_{out}$ 拉到 0 V。
