$V_{out}$ 先是一段平台（与 $V_{in}$ 无关），其电平由跟随器（follower）$M_2$ 决定；当 $M_3$ 不能再使 $M_2$ 的漏极保持足够高的电位，或不能再提供 $I_1$ 时便开始下降，在 $V_{in} = V_{DD} - |V_{THP}| = 2.2$ V 处降到 0 V，此后一直保持 0 V。记 $I_1 = \tfrac12\beta_1(V_{b2} - 0.7)^2$。

- $V_{in}$ 较小时：$M_3$ 强导通，处于线性区（triode region），其漏极 $D$ 接近 $V_{DD}$；$M_2$ 是处于饱和区（saturation region）、流过 $I_1$ 的源极跟随器（source follower）：$V_{out} = V_0 = V_{b1} - V_{TH2}(V_0) - \sqrt{2I_1/\beta_2}$，与 $V_{in}$ 无关（假设 $V_0 > V_{b2} - 0.7$ V，使 $M_1$ 处于饱和区）。
- 随着 $V_{in}$ 升高，$M_3$ 需要更大的 $V_{SD}$ 才能流过 $I_1$，于是 $V_D$ 下降。只要 $V_D \ge V_{b1} - V_{TH2}$（$M_2$ 饱和）并且 $M_3$ 仍能提供 $I_1$（其饱和电流 $\tfrac12\beta_3(2.2 - V_{in})^2 \ge I_1$），平台就保持不变。
- 超出这一范围后，$M_2$ 进入线性区，$V_{out}$ 随 $V_D$ 一起下降；和/或电流降到 $I_1$ 以下（$M_3$ 饱和，起限流作用）；当 $V_{out} < V_{b2} - 0.7$ V 时 $M_1$ 进入线性区；$V_{out}$ 一直降到 0。
- 当 λ = 0 时，如果平台是因为 $M_3$ 的饱和电流降到 $I_1$ 而结束（在 $V_{in}^* = 2.2 - (V_{b2} - 0.7)\sqrt{\beta_1/\beta_3}$ 处），而此时 $M_1$ 仍处于饱和区，那么该处的增益为无穷大，$V_{out}$ 在 $V_{in}^*$ 处竖直下跌到 $V_{b2} - 0.7$ V（下跌过程中 $M_2$ 进入线性区）；此后 $M_3$ 是电流源（current source），$M_1$ 和 $M_2$ 处于线性区，并满足 $\tfrac12\beta_3(2.2 - V_{in})^2 = \beta_1[(V_{b2} - 0.7)V_{out} - V_{out}^2/2]$，直到 2.2 V 处 $V_{out} = 0$。只有当 $M_2$ 因失去电压余度（headroom）而已在 $V_{in}^*$ 之前把 $V_{out}$ 拉低到 $V_{b2} - 0.7$ V 时，才不会出现跳变。
- $V_{in} \ge 2.2$ V：$M_3$ 截止，没有电流，$V_{out} = 0$。
- 转折点（transition point）：平台的终点（$V_D = V_{b1} - V_{TH2}$ 或 $V_{in} = 2.2 - \sqrt{2I_1/\beta_3}$，以先到者为准）、$V_{out} = V_{b2} - 0.7$ V、$V_{in} = 2.2$ V。
