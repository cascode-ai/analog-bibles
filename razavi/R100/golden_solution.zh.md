$V_{out}$ 先平坦地保持在由跟随器 $M_2$ 决定的电平上（与 $V_{in}$ 无关）；一旦 $M_3$ 不再能使 $M_2$ 的漏极保持足够高的电位，或不再能提供 $I_1$，它就开始下降，在 $V_{in} = V_{DD} - |V_{THP}| = 2.2$ V 处降到 0 V，此后一直保持 0 V。令 $I_1 = \tfrac12\beta_1(V_{b2} - 0.7)^2$。

- $V_{in}$ 较小时：$M_3$ 强导通，处于线性区（triode region），其漏极 $D$ 接近 $V_{DD}$；$M_2$ 是工作在饱和区（saturation region）的源极跟随器（source follower），流过 $I_1$：$V_{out} = V_0 = V_{b1} - V_{TH2}(V_0) - \sqrt{2I_1/\beta_2}$，与 $V_{in}$ 无关（假设 $V_0 > V_{b2} - 0.7$ V，从而 $M_1$ 饱和）。
- 随着 $V_{in}$ 升高，$M_3$ 需要更大的 $V_{SD}$ 才能流过 $I_1$，于是 $V_D$ 下降。只要 $V_D \ge V_{b1} - V_{TH2}$（$M_2$ 饱和），且 $M_3$ 仍能提供 $I_1$（其饱和电流 $\tfrac12\beta_3(2.2 - V_{in})^2 \ge I_1$），平台就保持不变。
- 超出这一范围后，$M_2$ 进入线性区，$V_{out}$ 随 $V_D$ 下降，和/或电流降到 $I_1$ 以下（$M_3$ 饱和并起限流作用）；当 $V_{out} < V_{b2} - 0.7$ V 时 $M_1$ 进入线性区；$V_{out}$ 降到 0。
- 在 λ = 0 时，若平台是因 $M_3$ 的饱和电流降到 $I_1$ 而结束（发生在 $V_{in}^* = 2.2 - (V_{b2} - 0.7)\sqrt{\beta_1/\beta_3}$ 处），且此时 $M_1$ 仍处于饱和，则该处的增益无界，$V_{out}$ 在 $V_{in}^*$ 处竖直下降到 $V_{b2} - 0.7$ V（途中 $M_2$ 进入线性区）；此后 $M_3$ 是电流源（current source），$M_1$ 和 $M_2$ 处于线性区，并满足 $\tfrac12\beta_3(2.2 - V_{in})^2 = \beta_1[(V_{b2} - 0.7)V_{out} - V_{out}^2/2]$，直到 2.2 V 处 $V_{out} = 0$。只有当 $M_2$ 失去电压余度（headroom）已经使 $V_{out}$ 在 $V_{in}^*$ 之前降到 $V_{b2} - 0.7$ V 时，才不会出现跳变。
- $V_{in} \ge 2.2$ V：$M_3$ 截止，没有电流，$V_{out} = 0$。
- 转折点：平台的终点（$V_D = V_{b1} - V_{TH2}$ 或 $V_{in} = 2.2 - \sqrt{2I_1/\beta_3}$，以先到者为准），$V_{out} = V_{b2} - 0.7$ V，$V_{in} = 2.2$ V。
