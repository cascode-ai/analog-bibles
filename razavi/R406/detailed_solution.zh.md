# 详细步骤 - R406

**思路。** 把每一级建模为输出电阻（output resistance）为 $R_0$ 的跨导器，在差分半边电路（half circuit）上列基尔霍夫电流定律（KCL）方程，求出 $Z_{in}(s)$，再由其极点和零点读出频率特性。然后用两种等价的方式解释这一结果：一是环路增益随频率下降的并联反馈，二是把 $C_1$ 转换为电感的回转器。

### 第 1 步 — 模型与连接关系

每一级都是一个跨导器：差分输入 $v_d$ 向其两个输出节点分别送入 $\mp G_mv_d/2$，每个输出节点的负载为 $R_0$，因此其差分增益为 $-G_mR_0$。把图 2 的输入端记为 A（上）和 B（下），把 $G_{m2}$ 的输出端记为 $O_1$（上）和 $O_2$（下）。每个输出节点都接有对地的 $R_0$ 和 $C_1$；每个输入节点接有对地的 $R_0$（$G_{m1}$ 的输出电阻）。

升高 $v_A$ 会把 $O_1$ 拉低、把 $O_2$ 抬高；按图中的交叉连接，$G_{m1}$ 随即从 A **抽出**电流，阻止这一变化。该环路为负反馈；由于 $G_{m1}$ 把**电流**送回输入节点（并联混合），它降低了 $Z_{in}$。

### 第 2 步 — 半边电路方程

让差分测试电流 $I_t$ 流入 A、从 B 流出。由对称性，$v_B = -v_A$，$v_{O2} = -v_{O1}$，且 $v_{in} = v_A - v_B = 2v_A$。对每一半：

- 在 $O_1$ 处：$G_{m2}$ 从该节点抽出 $G_{m2}(v_A - v_B)/2 = G_{m2}v_A$，该节点的负载为 $Z(s) = R_0\parallel\dfrac{1}{sC_1} = \dfrac{R_0}{1 + sR_0C_1}$；
- 在 A 处：$I_t$ 流入，$G_{m1}$ 注入 $G_{m1}(v_{O1} - v_{O2})/2 = G_{m1}v_{O1}$，$R_0$ 接地。

<!-- diagram: diagram-01.cir -->

**节点 $O_1$ 的 KCL：**

$$\frac{v_{O1}}{Z} = -G_{m2}v_A \quad\Longrightarrow\quad v_{O1} = -G_{m2}Z\,v_A .$$

**节点 A 的 KCL：**

$$I_t + G_{m1}v_{O1} = \frac{v_A}{R_0} .$$

**联立：**

$$
\begin{aligned}
I_t &= \frac{v_A}{R_0} + G_{m1}G_{m2}Z\,v_A = v_A\,\frac{1 + G_{m1}G_{m2}R_0Z}{R_0}\\
Z_{in} = \frac{2v_A}{I_t} &= \frac{2R_0}{1 + T(s)}, \qquad T(s) = G_{m1}G_{m2}R_0Z(s) = \frac{G_{m1}G_{m2}R_0^2}{1 + sR_0C_1} .
\end{aligned}
$$

分子分母同乘以 $1 + sR_0C_1$：

$$Z_{in}(s) = \frac{2R_0\,(1 + sR_0C_1)}{1 + G_{m1}G_{m2}R_0^2 + sR_0C_1} .$$

### 第 3 步 — $|Z_{in}|$ 随频率的变化

每一级都有很大的本征增益（intrinsic gain），即 $G_mR_0 \gg 1$，因此 $G_{m1}G_{m2}R_0^2 \gg 1$：

| 频率范围 | $\lvert Z_{in}\rvert$ | 特性 |
|---|---|---|
| $\omega \ll 1/(R_0C_1)$ | $\dfrac{2R_0}{1 + G_{m1}G_{m2}R_0^2} \approx \dfrac{2}{G_{m1}G_{m2}R_0}$ | 低而平坦的平台 |
| $\omega_z = \dfrac{1}{R_0C_1}$ | — | 零点：开始上升 |
| $\dfrac{1}{R_0C_1} \ll \omega \ll \dfrac{G_{m1}G_{m2}R_0}{C_1}$ | $\approx \omega\,\dfrac{2C_1}{G_{m1}G_{m2}}$ | 像电感一样以 +20 dB/dec 上升 |
| $\omega_p = \dfrac{1 + G_{m1}G_{m2}R_0^2}{R_0C_1} \approx \dfrac{G_{m1}G_{m2}R_0}{C_1}$ | — | 极点：上升停止 |
| $\omega \gg \omega_p$ | $2R_0$ | 高而平坦的平台（开环值） |

两个平台之比 $1 + G_{m1}G_{m2}R_0^2$ 等于 $\omega_p/\omega_z$，因此上升段恰好跨越两者之间的差距。

### 第 4 步 — 直观解释 1：环路增益不断下降的并联反馈

**低频。** 注入 A 的电流开始使 $v_A$ 升高；$G_{m2}$ 将其放大 $G_{m2}R_0$ 倍，$G_{m1}$ 则从 A 抽回一个电流，它是仅靠 $R_0$ 所能吸收的电流的 $G_{m1}G_{m2}R_0^2$ 倍。送回的电流几乎抵消了全部输入电流，因此 A 几乎是虚地（virtual ground），$Z_{in} = 2R_0/(1 + T)$ 非常小。

**频率升高。** 在 $1/(R_0C_1)$ 以上，$C_1$ 开始把 $G_{m2}$ 的输出端短路。输出摆幅（output swing）以及 $G_{m1}$ 送回的电流按 $1/\omega$ 下降，因此 $T(s)$ 以 20 dB/dec 的速率下降，被抵消的输入电流减少，$|Z_{in}|$ 与 $\omega$ 成正比地增大。

**高频。** 一旦 $|T| < 1$（约在 $G_{m1}G_{m2}R_0/C_1$ 以上），反馈就消失了，输入端只看到开环电阻：单边为 $R_0$，差分为 $2R_0$。

### 第 5 步 — 直观解释 2：回转器（有源电感）

由第 2 步可得输入导纳为

$$\frac{1}{Z_{in}} = \frac{1}{2R_0} + \frac{G_{m1}G_{m2}R_0}{2(1 + sR_0C_1)} = \frac{1}{2R_0} + \frac{1}{\dfrac{2}{G_{m1}G_{m2}R_0} + s\,\dfrac{2C_1}{G_{m1}G_{m2}}} ,$$

因此

$$Z_{in} = 2R_0\ \Big\|\ \left[\frac{2}{G_{m1}G_{m2}R_0} + s\,L_d\right], \qquad L_d = \frac{2C_1}{G_{m1}G_{m2}}$$

（单边：$R_0\parallel[1/(G_{m1}G_{m2}R_0) + sC_1/(G_{m1}G_{m2})]$，电感为 $C_1/(G_{m1}G_{m2})$）。

两个符号相反、背靠背连接的跨导器构成一个**回转器**：一个端口的阻抗为 $1/(G_{m1}G_{m2}Z_{load})$，与另一端口的负载成**反比**。负载 $R_0\parallel C_1$ 的导纳为 $1/R_0 + sC_1$，随频率增大，因此 $C_1$ 在输入端表现为电感，$R_0$ 表现为串联电阻 $1/(G_{m1}G_{m2}R_0)$，而输入节点自身的 $2R_0$ 与之并联。这就是有源电感的原理。

### 结果

$$Z_{in} = \frac{2R_0\,(1 + sR_0C_1)}{1 + G_{m1}G_{m2}R_0^2 + sR_0C_1} = 2R_0\ \Big\|\ \left[\frac{2}{G_{m1}G_{m2}R_0} + s\,\frac{2C_1}{G_{m1}G_{m2}}\right].$$

$|Z_{in}|$ 在低频时很小（$\approx 2/(G_{m1}G_{m2}R_0)$），从 $1/(R_0C_1)$ 开始像电感一样以 +20 dB/dec 上升，在 $\approx G_{m1}G_{m2}R_0/C_1$ 以上趋于平坦，等于开环值 $2R_0$。

直观地看，低频时经 $G_{m1}$ 的并联反馈几乎抵消了任何输入电流，从而把输入电压压得很低。当 $C_1$ 对 $G_{m2}$ 的输出端形成旁路时，环路增益按 $1/\omega$ 下降，反馈减弱，$Z_{in}$ 向 $2R_0$ 上升。等价地，两个跨导器构成一个回转器，把负载电容 $C_1$ 转换为输入端每边 $C_1/(G_{m1}G_{m2})$ 的电感。

**常见错误。** 因为唯一的电容是 $C_1$，就断定输入端呈容性（capacitive）。$C_1$ 位于 $G_{m2}$ 的**输出端**；回转器把它的阻抗求倒，因此它在输入端表现为电感。

**常见错误。** 认为反馈是正反馈，或者认为它提高了 $Z_{in}$。送回的电流与输入电流方向相反，因此 $Z_{in}$ 总是**低于**开环值 $2R_0$。

**常见错误。** 把平台画成趋于零或无穷大。直流环路增益 $G_{m1}G_{m2}R_0^2$ 是有限的，因此 $Z_{in}$ 有下限 $2R_0/(1 + G_{m1}G_{m2}R_0^2)$；在高频下，输入端的各个 $R_0$ 仍然存在，因此 $Z_{in}$ 最终饱和于 $2R_0$。
