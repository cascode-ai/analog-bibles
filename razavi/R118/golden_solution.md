# Golden Solution - R118

## Reference answer

A common-source stage $M_2$ degenerated by the current source $M_1$ ($R_S = r_{O1}$) with the current-source load $M_3$ ($R_D = r_{O3}$):
$A_v = -\dfrac{g_{m2}r_{O2}r_{O3}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}$, which is of order $-r_{O3}/r_{O1}$ (about −1) because the degeneration $r_{O1}$ is huge.

- Degenerated-CS formula $-g_mr_OR_D/[R_D + r_O + R_S + g_mr_OR_S]$ with $R_S = r_{O1}$, $R_D = r_{O3}$ (γ = 0).

## Grading notes

+2: the expression above or an equivalent form, ideally with the remark that the gain is only of order $r_{O3}/r_{O1}$. +1: approximate $-r_{O3}/r_{O1}$ with justification, or one slip. 0: correct method with an algebra error in the final expression. -2 (asserted as fact): degeneration by $r_{O1}$ ignored, giving $-g_{m2}(r_{O2}\|r_{O3})$ (a gain of order $g_mr_O$), positive gain, or output taken at the source of $M_2$.
