# 详细步骤 - R118

**思路。** $M_2$ 是一个共源级，由 NMOS 电流源 $M_1$ 提供源极负反馈，并以 PMOS 电流源 $M_3$ 为负载。把 $M_1$ 和 $M_3$ 替换为它们的输出电阻（output resistance），然后精确求解带源极负反馈的共源级。

### 第 1 步 — 小信号模型（small-signal model）

$M_1$ 和 $M_3$ 的栅极接直流偏置，源极接电源，因此 $v_{gs1} = v_{gs3} = 0$：每个器件都只相当于它的 $r_O$，$g_{m1}$ 和 $g_{m3}$ 不会出现在结果中。把 $M_2$ 的源极记为节点 $S$（$\gamma = 0$）：

- $r_{O3}$ 从 out 接到交流地（$R_D = r_{O3}$）；
- **$M_2$**：$v_{gs2} = v_{in} - v_S$；受控源 $g_{m2}(v_{in} - v_S)$ 从 out（漏极）流向 $S$，$r_{O2}$ 接在 out 与 $S$ 之间；
- $r_{O1}$ 从 $S$ 接到地（$R_S = r_{O1}$）。

同一小信号电流 $i$ 向下流过 $r_{O3}$、$M_2$ 和 $r_{O1}$（只有一条通路）；取向下为正方向。

### 第 2 步 — 方程

$$v_S = i\,r_{O1}, \qquad v_{out} = -i\,r_{O3}\quad\big(i = (0 - v_{out})/r_{O3}\big),$$

$$i = g_{m2}(v_{in} - v_S) + \frac{v_{out} - v_S}{r_{O2}}.$$

### 第 3 步 — 求解增益

代入 $v_S = ir_{O1}$ 和 $v_{out} = -ir_{O3}$：

$$i = g_{m2}v_{in} - g_{m2}r_{O1}\,i + \frac{-ir_{O3} - ir_{O1}}{r_{O2}}.$$

合并含 $i$ 的项，再乘以 $r_{O2}$：

$$i\left(1 + g_{m2}r_{O1} + \frac{r_{O3} + r_{O1}}{r_{O2}}\right) = g_{m2}v_{in},$$

$$i\,(r_{O2} + g_{m2}r_{O1}r_{O2} + r_{O3} + r_{O1}) = g_{m2}r_{O2}\,v_{in},$$

$$i = \frac{g_{m2}r_{O2}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}\,v_{in}.$$

由 $v_{out} = -ir_{O3}$ 得：

$$A_v = \frac{v_{out}}{v_{in}} = -\frac{g_{m2}r_{O2}r_{O3}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}.$$

这就是带源极负反馈的共源级结果 $A_v = -g_mr_OR_D/(R_D + r_O + R_S + g_mr_OR_S)$，其中 $R_S = r_{O1}$，$R_D = r_{O3}$。

### 第 4 步 — 增益有多大？

当 $g_{m2}r_{O2} \gg 1$ 且 $r_{O1}, r_{O2}, r_{O3}$ 数量级相同时，$g_{m2}r_{O1}r_{O2}$ 是 $r_{O1}$ 的本征增益（intrinsic gain）$g_{m2}r_{O2}$ 倍，是 $r_{O2}$、$r_{O3}$ 的约 $g_{m2}r_{O1} \gg 1$ 倍。所以

$$A_v \approx -\frac{g_{m2}r_{O2}r_{O3}}{g_{m2}r_{O1}r_{O2}} = -\frac{r_{O3}}{r_{O1}}.$$

若 $M_1$ 和 $M_3$ 的输出电阻相近，**增益仅约为 $-1$**。

**直观理解。** 两种观点给出相同的答案：

1. **电流固定。** 电流源 $M_1$ 使 $M_2$ 的电流几乎恒定；唯一允许的变化是 $r_{O1}$ 中的电流变化。$v_S$ 跟随 $v_{in}$（$v_{gs2}$ 几乎不变），因此 $i \approx v_{in}/r_{O1}$，$v_{out} = -ir_{O3} \approx -(r_{O3}/r_{O1})v_{in}$。
2. **$G_mR_{out}$ 观点。** 强源极负反馈使 $G_m \approx 1/R_S = 1/r_{O1}$，而输出电阻为 $r_{O3}$ 与非常大的 $r_{O2} + (1 + g_{m2}r_{O2})r_{O1}$ 的并联，即约为 $r_{O3}$。所以 $|A_v| \approx r_{O3}/r_{O1}$。

### 结果

$$A_v = -\frac{g_{m2}r_{O2}r_{O3}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}} \approx -\frac{r_{O3}}{r_{O1}},$$

这是一个反相增益，其幅值仅约等于单位增益，因为极大的负反馈电阻 $r_{O1}$ 几乎“冻结”了 $M_2$ 的电流。

**常见错误。** 忽略源极负反馈，写成 $A_v = -g_{m2}(r_{O2}\parallel r_{O3})$，即增益为 $g_mr_O/2$ 量级。$M_2$ 的源极看到的是 $r_{O1} \gg 1/g_{m2}$，而不是交流地，因此增益骤降到约 $r_{O3}/r_{O1}$。

**常见错误。** 结果中保留了 $g_{m1}$ 或 $g_{m3}$，例如把 $M_1$ 当作二极管（$1/g_{m1}$）。它们的栅极接固定偏置，因此每个器件只贡献其 $r_O$。

**常见错误。** 把输出取在 $M_2$ 的源极，或得出正增益。输出端是漏极：$v_{in}$ 升高时，流过 $r_{O3}$ 的电流略有增大，因此 $v_{out}$ 下降。
