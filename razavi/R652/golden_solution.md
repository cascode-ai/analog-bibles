# Golden Solution - R652

## Reference answer

The XOR characteristic is periodic and contains both slopes: rising for 0 < Δφ < π, falling for π < Δφ < 2π, and so on. For either feedback polarity, the equilibria on one slope are stable and those on the other are unstable, so the loop always ends up locked on whichever slope gives negative feedback. The polarity only selects the lock point (e.g., near +π/2 or near −π/2 ≡ 3π/2); it does not decide whether lock occurs.

Proof. Let Δφ = φin − φout and $\overline{V_{PD}} = F(\Delta\phi)$, the triangle in the figure. Neglecting the LPF dynamics (slow-loop approximation):
$\dfrac{d\Delta\phi}{dt} = \omega_{in} - \omega_{out} = \omega_{in} - \omega_0 - K_{VCO}F(\Delta\phi)$.
- Equilibria satisfy $F(\Delta\phi^*) = (\omega_{in} - \omega_0)/K_{VCO} \equiv V_1$. For $0 < V_1 < V_0$ there is one solution on each rising segment, $\Delta\phi_r = \pi V_1/V_0$, and one on each falling segment, $\Delta\phi_f = 2\pi - \pi V_1/V_0$.
- For a small deviation δ, $\dot\delta = -K_{VCO}F'(\Delta\phi^*)\,\delta$. With $K_{VCO} > 0$: on a rising segment $F' = V_0/\pi > 0$ and δ decays (negative feedback, stable lock). On a falling segment $F' = -V_0/\pi$ and δ grows (positive feedback, unstable).
- If the initial Δφ lies on a negative-slope segment, the error is not corrected there. Δφ drifts away from the unstable point (in either direction), crosses the peak at π or the valley at 2π into an adjacent positive-slope segment, and settles at $\Delta\phi_r$ or at $\Delta\phi_r + 2\pi$ (the same state after one cycle slip). If it starts on a positive-slope segment, it settles there directly.
- Reversing the polarity (e.g., an inverter on one PD input, which turns the XOR into an XNOR, $F(\Delta\phi) \to V_0 - F(\Delta\phi) = F(\Delta\phi + \pi)$, or an inverting loop filter referred to mid-level) simply swaps the roles: the falling-slope equilibria become the stable ones, and the loop locks there. (Swapping the two XOR inputs changes nothing, since $F$ is even. Negating $K_{VCO}$ with the same $\omega_0$ also swaps the stable slope, but the required control voltage $(\omega_{in} - \omega_0)/K_{VCO}$ then changes sign and must still lie within the detector's 0 to $V_0$ range; that is a tuning-range issue, not a polarity issue.)
- With the first-order LPF the loop is second order, $s^2/\omega_{LPF} + s + K_{VCO}F'(\Delta\phi^*) = 0$, but it is stable under the same condition, $K_{VCO}F' > 0$.
- So the sign of the feedback is unimportant as long as the PD characteristic is periodic with both slopes. A frequency detector, by contrast, has a fixed polarity, so with frequency detection the polarity does matter.

## Grading notes

+2: four elements, by a mathematical or a clear physical argument: (1) equilibria exist on both slopes; (2) those on one slope are stable (negative feedback) and those on the other unstable (positive feedback), via the sign of $K_{VCO}F'$ or an equivalent argument; (3) a start on the "wrong" slope makes the phase error grow until it reaches an adjacent region of the opposite slope, where the loop locks; (4) reversing the polarity only swaps which slope is used. +1: one of these elements missing (most often the remark on the polarity swap), the rest correct. 0: only the statement that the characteristic is periodic with both slopes, without the drift-to-the-stable-slope argument; or an analysis restricted to zero detuning ($\omega_{in} = \omega_0$, lock at the cusp $\Delta\phi = 0$ or $2\pi$) that still gives the drift-to-the-other-slope argument and concludes that both polarities lock. -2 (asserted as fact): stable lock claimed on both slopes for the same polarity, a loop with the "wrong" polarity claimed never to lock, or the XOR characteristic treated as monotonic. A remark that, with a unipolar detector output and a fixed $\omega_0$, simply negating $K_{VCO}$ can leave no equilibrium for a given frequency offset is correct and is not a false claim.
