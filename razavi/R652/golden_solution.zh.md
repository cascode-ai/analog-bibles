XOR 的特性是周期性的，并且同时包含两种斜率：0 < Δφ < π 时上升，π < Δφ < 2π 时下降，依此类推。无论反馈极性如何，一种斜率上的平衡点都是稳定的，另一种斜率上的则不稳定，因此环路最终总是锁定在给出负反馈的那一段斜率上。极性只决定锁定点（例如在 +π/2 附近或在 −π/2 ≡ 3π/2 附近），并不决定能否锁定。

证明。令 Δφ = φin − φout，$\overline{V_{PD}} = F(\Delta\phi)$ 即图中的三角波。忽略低通滤波器（LPF）的动态特性（慢环路近似）：
$\dfrac{d\Delta\phi}{dt} = \omega_{in} - \omega_{out} = \omega_{in} - \omega_0 - K_{VCO}F(\Delta\phi)$。
- 平衡点满足 $F(\Delta\phi^*) = (\omega_{in} - \omega_0)/K_{VCO} \equiv V_1$。当 $0 < V_1 < V_0$ 时，每个上升段上有一个解 $\Delta\phi_r = \pi V_1/V_0$，每个下降段上也有一个解 $\Delta\phi_f = 2\pi - \pi V_1/V_0$。
- 对于小偏差 δ，有 $\dot\delta = -K_{VCO}F'(\Delta\phi^*)\,\delta$。设 $K_{VCO} > 0$：在上升段上 $F' = V_0/\pi > 0$，δ 逐渐衰减（负反馈，稳定锁定）；在下降段上 $F' = -V_0/\pi$，δ 不断增长（正反馈，不稳定）。
- 若初始 Δφ 位于负斜率段上，误差在该段上得不到校正。Δφ 会（向任一方向）偏离这个不稳定点，越过 π 处的峰或 2π 处的谷，进入相邻的正斜率段，并稳定在 $\Delta\phi_r$ 或 $\Delta\phi_r + 2\pi$；后者只是经过一次周跳（cycle slip）后的同一状态。若初始 Δφ 位于正斜率段上，则直接在该段上稳定下来。
- 反转极性（例如在鉴相器的一个输入端加一个反相器，使 XOR 变为 XNOR，$F(\Delta\phi) \to V_0 - F(\Delta\phi) = F(\Delta\phi + \pi)$；或者采用以中间电平为参考的反相环路滤波器）只是交换了两种斜率的角色：下降段上的平衡点变为稳定点，环路就锁定在那里。交换 XOR 的两个输入不会带来任何变化，因为 $F$ 是偶函数。在 $\omega_0$ 不变的情况下把 $K_{VCO}$ 取反，同样会交换稳定的斜率，但此时所需的控制电压 $(\omega_{in} - \omega_0)/K_{VCO}$ 会改变符号，而它仍必须落在鉴相器 0 到 $V_0$ 的输出范围内；这是调谐范围（tuning range）的问题，而不是极性问题。
- 若计入一阶 LPF，环路变为二阶：$s^2/\omega_{LPF} + s + K_{VCO}F'(\Delta\phi^*) = 0$，但稳定条件相同，仍为 $K_{VCO}F' > 0$。
- 因此，只要鉴相器特性是周期性的并且同时具有两种斜率，反馈的符号就无关紧要。相比之下，鉴频器（frequency detector）的极性是固定的，所以带有频率检测时，极性就很重要了。
