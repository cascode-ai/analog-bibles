# 详细步骤 - R385

**思路。** 两个“超级源极跟随器”（super source follower）——$M_1$/$M_3$ 和 $M_2$/$M_4$——由 $R_S$ 连接，构成一个电压-电流转换器，现在电流源 $M_5$–$M_8$ 带有噪声。对 $M_1$ 的漏极（它决定源极电压）和源极（它决定 $I_{D3}$）列 KCL，把每个噪声电流都当作带符号的信号，求出 $I_{D3} - I_{D4}$，再除以跨导（transconductance）$2/R_S$；各独立噪声源的功率只在最后才相加。

### 第 1 步 — 节点与带符号的噪声电流

在左半边（右半边与之镜像对称，对应 $M_2$、$M_4$、$M_6$、$M_8$）中，把 $M_1$ 的漏极节点记为 $A_1$，源极节点记为 $S_1$。由于栅极偏置固定且 $\lambda = 0$，各电流源中只有噪声电流。带符号的噪声电流如下：

| 噪声源 | 方向（左半边） | 热噪声功率谱密度 |
|---|---|---|
| $I_{n1}$ | 流过 $M_1$，从 $A_1$ 到 $S_1$ | $4kT\gamma g_{m1}$ |
| $I_{n5}$ | 从 $V_{DD}$ 流入 $A_1$ | $4kT\gamma g_{m5}$ |
| $I_{n7}$ | 从 $S_1$ 流向地 | $4kT\gamma g_{m7}$ |
| $I_{n3}$ | 流过 $M_3$，从 $V_{DD}$ 流入 $S_1$ | $4kT\gamma g_{m3}$ |
| $I_{nR}$ | 跨接在 $R_S$ 上，从 $S_1$ 到 $S_2$ | $4kT/R_S$ |

电流源晶体管的闪烁噪声栅极电压产生的漏极电流等于 $g_m$ 乘以该电压，其作用与它的热噪声电流完全相同。

$A_1$ 只与 $M_5$（只有噪声电流）、$M_1$ 的漏极和 $M_3$ 的栅极相连，因此其阻抗为**无穷大**。$S_1$ 与 $M_1$ 的源极、$M_3$ 的漏极、$M_7$ 和 $R_S$ 相连。$M_1$ 中从 $A_1$ 流向 $S_1$ 的电流为 $g_{m1}(V_{G1} - V_{S1}) + I_{n1}$；$M_3$ 向 $S_1$ 注入电流 $i_{d3}$。

### 第 2 步 — $A_1$ 处的 KCL：源极电压

流入 $A_1$ 的全部电流都必须经 $M_1$ 流出：

$$
\begin{aligned}
g_{m1}(V_{G1} - V_{S1}) + I_{n1} &= I_{n5}\\
V_{S1} &= V_{G1} + \frac{I_{n1} - I_{n5}}{g_{m1}}.
\end{aligned}
$$

源极跟随栅极，但被 $M_1$ 的噪声**以及** $M_5$ 的噪声所偏移：$I_{n5}$ 没有其他通路，只能被迫流过 $M_1$，使其 $V_{GS}$ 改变 $I_{n5}/g_{m1}$。$M_1$ 送入 $S_1$ 的电流为 $I_{n5}$。同理，$V_{S2} = V_{G2} + (I_{n2} - I_{n6})/g_{m1}$（其中 $g_{m2} = g_{m1}$）。

### 第 3 步 — $S_1$ 处的 KCL：$M_3$ 的电流

$M_1$ 的电流 $I_{n5}$ 和 $i_{d3}$ 流入 $S_1$；$I_{n7}$ 和 $R_S$ 支路电流 $(V_{S1} - V_{S2})/R_S + I_{nR}$ 流出：

$$
\begin{aligned}
i_{d3} + I_{n5} &= I_{n7} + \frac{V_{S1} - V_{S2}}{R_S} + I_{nR}\\
i_{d3} &= I_{n7} - I_{n5} + \frac{V_{S1} - V_{S2}}{R_S} + I_{nR}.
\end{aligned}
$$

在右半边，$R_S$ 中的电流流入 $S_2$：

$$i_{d4} = I_{n8} - I_{n6} + \frac{V_{S2} - V_{S1}}{R_S} - I_{nR}.$$

### 第 4 步 — 输出电流差

两式相减：

$$i_{d3} - i_{d4} = (I_{n7} - I_{n8}) - (I_{n5} - I_{n6}) + \frac{2(V_{S1} - V_{S2})}{R_S} + 2I_{nR},$$

其中，由第 2 步得

$$V_{S1} - V_{S2} = V_{in} + \frac{I_{n1} - I_{n2}}{g_{m1}} - \frac{I_{n5} - I_{n6}}{g_{m1}}.$$

代入并合并 $I_{n5} - I_{n6}$ 项：

$$i_{d3} - i_{d4} = \frac{2}{R_S}\left[V_{in} + \frac{I_{n1} - I_{n2}}{g_{m1}}\right] - (I_{n5} - I_{n6})\left(1 + \frac{2}{g_{m1}R_S}\right) + (I_{n7} - I_{n8}) + 2I_{nR}.$$

信号跨导为 $G_m = 2/R_S$，与理想电流源时相同。

**$M_3$ 和 $M_4$ 不出现。** $i_{d3}$ 由 $S_1$ 处的 KCL 决定，$V_{S1}$ 由 $M_1$ 决定，因此 $M_3$ 的噪声（热噪声或闪烁噪声）只会使其栅极电压偏移，$V_{A1} = (I_{n3} - i_{d3})/g_{m3}$：阻抗为无穷大的节点 $A_1$ 使局部环路增益（loop gain）为无穷大。

### 第 5 步 — 折算到输入端（热噪声）

把噪声项除以 $G_m = 2/R_S$：

$$V_{n,in} = \frac{I_{n1} - I_{n2}}{g_{m1}} - (I_{n5} - I_{n6})\left(\frac{1}{g_{m1}} + \frac{R_S}{2}\right) + (I_{n7} - I_{n8})\frac{R_S}{2} + R_SI_{nR}$$

（对于 $M_5$ 项，$\tfrac{R_S}{2}\left(1 + \tfrac{2}{g_{m1}R_S}\right) = \tfrac{R_S}{2} + \tfrac{1}{g_{m1}}$）。各噪声源相互独立，每一对器件给出的功率是单个器件的两倍；$R_S$ 项为 $R_S^2\cdot4kT/R_S = 4kTR_S$：

$$\overline{V_{n,in}^2} = 2\left[\frac{4kT\gamma}{g_{m1}} + 4kT\gamma g_{m5}\left(\frac{1}{g_{m1}} + \frac{R_S}{2}\right)^2 + 4kT\gamma g_{m7}\frac{R_S^2}{4}\right] + 4kTR_S .$$

**两个电流源的权重为何不同。** $I_{n7}$ 只是从 $S_1$ 抽取电流，而这部分电流由 $M_3$ 提供，因此它直接出现在 $I_{D3}$ 中：权重为 $R_S/2$。$I_{n5}$ 同样如此（经由 $M_1$），**并且**还像输入电压一样使 $V_{S1}$ 偏移 $I_{n5}/g_{m1}$：权重为 $1/g_{m1} + R_S/2$。

### 第 6 步 — 闪烁噪声

- $M_1$、$M_2$：它们的闪烁噪声电压与栅极串联，原样传递到 $V_{S1}$、$V_{S2}$：$2K_N/(C_{ox}(WL)_1f)$。
- $M_5$、$M_6$：漏极电流为 $g_{m5}V_{f5}$，权重与 $I_{n5}$ 相同：$2g_{m5}^2(1/g_{m1} + R_S/2)^2K_P/(C_{ox}(WL)_5f)$。
- $M_7$、$M_8$：漏极电流为 $g_{m7}V_{f7}$，权重与 $I_{n7}$ 相同：$2g_{m7}^2(R_S^2/4)K_N/(C_{ox}(WL)_7f)$。
- $M_3$、$M_4$：被环路吸收，没有贡献。

$$\overline{V_{n,in}^2}\Big|_{1/f} = \frac{2}{C_{ox}f}\left[\frac{K_N}{(WL)_1} + g_{m5}^2\left(\frac{1}{g_{m1}} + \frac{R_S}{2}\right)^2\frac{K_P}{(WL)_5} + g_{m7}^2\frac{R_S^2}{4}\cdot\frac{K_N}{(WL)_7}\right].$$

因此电流源晶体管应具有较小的 $g_m$（较大的过驱动电压）和较大的面积，上方的电流源尤其如此，因为它们的噪声还会调制 $V_{GS1}$。

### 结果

热噪声：

$$\overline{V_{n,in}^2} = 2\left[\frac{4kT\gamma}{g_{m1}} + 4kT\gamma g_{m5}\left(\frac{1}{g_{m1}} + \frac{R_S}{2}\right)^2 + 4kT\gamma g_{m7}\frac{R_S^2}{4}\right] + 4kTR_S$$

闪烁噪声：

$$\overline{V_{n,in}^2}\Big|_{1/f} = \frac{2}{C_{ox}f}\left[\frac{K_N}{(WL)_1} + g_{m5}^2\left(\frac{1}{g_{m1}} + \frac{R_S}{2}\right)^2\frac{K_P}{(WL)_5} + g_{m7}^2\frac{R_S^2}{4}\cdot\frac{K_N}{(WL)_7}\right]$$

跨导为 $2/R_S$。$M_3$ 和 $M_4$ 没有贡献（被局部环路吸收）。上方电流源（$M_5$、$M_6$）以权重 $1/g_{m1} + R_S/2$ 折算到输入端，下方电流源（$M_7$、$M_8$）以权重 $R_S/2$ 折算。

**常见错误。** 以为局部反馈能抑制电流源噪声。环路只吸收 $M_3$ 的噪声；电流源噪声会改变 $M_3$ 必须提供的电流，对 $M_5$ 而言还会改变 $M_1$ 的 $V_{GS}$。

**常见错误。** 给上方电流源赋予与下方电流源相同的权重 $R_S/2$。$I_{n5}$ 被迫流过 $M_1$，还会使 $V_{S1}$ 偏移 $I_{n5}/g_{m1}$。

**常见错误。** 在电压功率谱密度中把 $R_S$ 项写成 $4kT/R_S$。其噪声电流以权重 $R_S$ 折算，得到以 V²/Hz 为单位的 $4kTR_S$。
