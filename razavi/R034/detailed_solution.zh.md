# 详细步骤 - R034

**思路：** 忽略节点 X 的寄生电容和沟道长度调制（$\lambda=0$）。$C_1$ 接在节点 X（$M_1$ 的漏极）与 $V_{in}$ 节点（另一个沟道端子）之间，因此 $V_X = V_{in} + V_{C1}$。求出阶跃之前的 $V_X$，并验证 $M_1$ 截止。在阶跃时，由于电容电压不能突变，X 随输入一起下降。阶跃之后，$M_1$ 以 $V_{GS} = 3$ V 导通，在一个局部回路中使 $C_1$ 放电：先是饱和区中的恒流斜坡，然后是线性区中衰减到零的过程。

![R034 示例 $V_X(t)$ 波形](/q/R034/solution-vx.zh.svg)

### 第 1 步 — 阶跃之前（$t < 0$）

由于始终有 $V_X = V_{in} + V_{C1}$，

$$V_X = 3\ \mathrm{V} + 3\ \mathrm{V} = 6\ \mathrm{V}.$$

电位较低的沟道端子，即处于 3 V 的 $V_{in}$ 节点，是源极，因此

$$V_{GS} = V_{DD} - V_{in} = 3 - 3 = 0\ \mathrm{V} < V_{TH} .$$

$M_1$ 截止；3 V 的源-衬底电压所引起的体效应（body effect）只会使 $V_{TH}$ 更高。没有任何东西使 $C_1$ 放电，$V_X$ 保持在 6 V。

### 第 2 步 — $t = 0$ 时的阶跃

$V_{in}$ 从 3 V 降到 0，而 $C_1$ 的电压不能瞬时改变（只能流过有限的电流），因此

$$V_X(0^+) = V_{in}(0^+) + V_{C1}(0^+) = 0 + 3 = 3\ \mathrm{V}.$$

$V_X$ 随输入一起从 6 V 降到 3 V。

### 第 3 步 — 饱和区放电与切换时刻

阶跃后，源极固定在 0 V，栅极固定在 3 V。源极与衬底均为 0 V，因此 $V_{TH}=0.7\ \mathrm{V}$。过驱动电压为 $V_{ov}=V_{GS}-V_{TH}=2.3\ \mathrm{V}$，漏源电压为 $V_{DS}=V_X$。晶体管导通时，若 $V_{DS}\ge V_{ov}$，则处于饱和区。在 $0^+$ 时，$V_{DS}=3\ \mathrm{V}$，满足这一条件。

两个支路的电流均规定为流出 X 为正。漏极电流 $I_D$ 流向源极。电容两端的电压为 $V_X-V_{in}$，以 X 端为正，因此从 X 流向输入端的电容电流为 $C_1\,d(V_X-V_{in})/dt$。对节点 X 列基尔霍夫电流定律，得

$$
C_1\frac{d(V_X-V_{in})}{dt}+I_D=0.
$$

阶跃后 $V_{in}=0$ 保持不变，因此电容电流为 $C_1\,dV_X/dt$。放电时该电流为负，表示电容向 X 提供沟道电流。两个支路在源极再次相接，形成放电回路。

沿用忽略沟道长度调制的模型，饱和区漏极电流只取决于固定的过驱动电压。

$$
I_D=\frac{\beta}{2}(V_{GS}-V_{TH})^2
=\frac{\beta}{2}(2.3\ \mathrm{V})^2
=(2.645\ \mathrm{V^2})\beta.
$$

电流保持不变，节点方程给出恒定斜率 $dV_X/dt=-I_D/C_1$。从初值 $V_X(0^+)=3\ \mathrm{V}$ 积分，得到

$$
V_X(t)=3\ \mathrm{V}-\frac{(2.645\ \mathrm{V^2})\beta}{C_1}t
\qquad (0\le t\le t_1).
$$

这段斜坡持续到 $V_{DS}=V_{ov}$，即 $V_X(t_1)=2.3\ \mathrm{V}$。用电压降除以斜率的绝对值，得到切换时刻

$$
t_1=\frac{C_1(3\ \mathrm{V}-2.3\ \mathrm{V})}{(2.645\ \mathrm{V^2})\beta}
\approx (0.265\ \mathrm{V^{-1}})\frac{C_1}{\beta}.
$$

### 第 4 步 — 线性区放电与精确解

当 $V_X$ 降到 $2.3\ \mathrm{V}$ 以下时，过驱动电压仍为正，且 $0<V_{DS}<V_{ov}$，所以晶体管进入线性区。将线性区电流代入同一个节点方程，得到

$$
I_D=\beta\left[(V_{GS}-V_{TH})V_{DS}-\frac{V_{DS}^2}{2}\right],
\qquad
C_1\frac{dV_X}{dt}
=-\beta V_X\left(2.3\ \mathrm{V}-\frac{V_X}{2}\right).
$$

分离变量，从切换时刻 $t_1$ 开始积分。此时 $V_X=2.3\ \mathrm{V}$，下式用 $v$ 作电压积分变量。

$$
\int_{2.3\ \mathrm{V}}^{V_X(t)}\frac{dv}{v(2.3\ \mathrm{V}-v/2)}
=-\frac{\beta}{C_1}(t-t_1).
$$

被积函数可拆成两个分式。

$$
\frac{1}{v(2.3\ \mathrm{V}-v/2)}=
\frac{1}{2.3\ \mathrm{V}}\left(\frac{1}{v}+\frac{1}{4.6\ \mathrm{V}-v}\right).
$$

由于 $d(4.6\ \mathrm{V}-v)=-dv$，第二项积分后带负号。在积分下限，$v/(4.6\ \mathrm{V}-v)=1$，对数值为零。代入积分上限并定义 $\tau=C_1/[(2.3\ \mathrm{V})\beta]$，得到

$$
\ln\!\left(\frac{V_X(t)}{4.6\ \mathrm{V}-V_X(t)}\right)
=-\frac{t-t_1}{\tau}.
$$

令 $E=e^{-(t-t_1)/\tau}$。两边取指数得 $V_X=E(4.6\ \mathrm{V}-V_X)$，移项后可得

$$
V_X(t)=\frac{(4.6\ \mathrm{V})E}{1+E}
\qquad(t\ge t_1).
$$

在 $t_1$ 时，$E=1$，电压为 $2.3\ \mathrm{V}$。将该电压代入线性区电流式，得 $I_D=\frac{\beta}{2}(2.3\ \mathrm{V})^2$，与饱和区电流相同。由于两段都满足 $dV_X/dt=-I_D/C_1$，斜率也连续。对 $t>t_1$，由 $0<E<1$ 得 $0<V_X<2.3\ \mathrm{V}$，验证了线性区条件。

当 $V_X$ 接近零时，与 $(2.3\ \mathrm{V})V_X$ 相比，$V_X^2/2$ 很小。此时沟道可等效为电阻 $R_{on}\approx 1/[(2.3\ \mathrm{V})\beta]$，时间常数为 $R_{on}C_1\approx\tau$。精确解中 $E\ll1$ 时，末段近似为 $V_X(t)\simeq (4.6\ \mathrm{V})e^{-(t-t_1)/\tau}$。电压趋近零，过驱动电压仍为正。

### 第 5 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF：$I_D = 2.65$ mA，斜坡斜率为 $-2.65$ V/ns，$t_1 = 0.7\ \mathrm{V}/(2.65\ \mathrm{V/ns}) \approx 0.265$ ns，$\tau = 0.43$ ns。

| $t$ | $V_X$ (V) | $M_1$ |
|---|---|---|
| $t < 0$ | 6.0 | 截止 |
| $0^+$ | 3.0 | 饱和区 |
| 0.265 ns | 2.30 | 边界 |
| $t_1 + \tau$ ≈ 0.70 ns | 1.24 | 线性区 |
| $t_1 + 2\tau$ ≈ 1.13 ns | 0.55 | 线性区 |
| $t_1 + 4\tau$ ≈ 2.0 ns | 0.08 | 线性区 |
| ∞ | 0 | 线性区，无电流 |

### 结果

- $t < 0$： $V_X = 6$ V（$V_{in} = 3$ V 加上 $C_1$ 上的 3 V）。$M_1$ 截止，因为其栅极电压 $V_{DD} = 3$ V 等于源极电压。
- $t = 0$： $V_X$ 随输入下降到 3 V。
- 阶段 1： 此时 $V_{GS} = 3$ V，$V_{DS} = 3$ V，因此 $M_1$ 处于饱和区。它以恒定电流 $\tfrac12\beta(2.3\ \mathrm{V})^2 = 2.645\,\beta\,\mathrm{V^2}$ 对 $C_1$（接在其漏极与源极之间）放电，$V_X$ 以 $\frac{(2.645\ \mathrm{V^2})\beta}{C_1}$ 的速率线性下降到 2.3 V。
- 阶段 2： $M_1$ 处于线性区，$V_X$ 大致按指数规律衰减到 0 V（时间常数 ≈ $C_1/((2.3\ \mathrm{V})\beta)$）。

**常见错误：** 因为“电容保持 3 V”，就让 $V_X$ 在阶跃后保持 3 V。在阶跃瞬间确实如此，但此后 $M_1$ 以 $V_{GS} = 3$ V 导通，其沟道正好跨接在 $C_1$ 两端，因此电容会被放电。

**常见错误：** 认为阶跃后 $M_1$ 截止。阶跃之前其源极处于 3 V（等于栅极电压）；阶跃之后源极处于 0 V，因此 $V_{GS} = 3$ V。

**常见错误：** 最终停在一个非零电压上，例如 2.3 V。这只标志着从饱和区到线性区的转变；栅极比源极高 3 V，沟道会一直导通到 $V_{DS} = 0$。
