# 详细步骤 - R034

**思路。** $C_1$ 接在节点 X（$M_1$ 的漏极）与 $V_{in}$ 节点（另一个沟道端子）之间，因此 $V_X = V_{in} + V_{C1}$。求出阶跃之前的 $V_X$，并验证 $M_1$ 截止。在阶跃时，由于电容电压不能突变，X 随输入一起下降。阶跃之后，$M_1$ 以 $V_{GS} = 3$ V 导通，在一个局部回路中使 $C_1$ 放电：先是饱和区中的恒流斜坡，然后是线性区中衰减到零的过程。

### 第 1 步 — 阶跃之前（$t < 0$）

由于始终有 $V_X = V_{in} + V_{C1}$，

$$V_X = 3\ \mathrm{V} + 3\ \mathrm{V} = 6\ \mathrm{V}.$$

电位较低的沟道端子，即处于 3 V 的 $V_{in}$ 节点，是源极，因此

$$V_{GS} = V_{DD} - V_{in} = 3 - 3 = 0\ \mathrm{V} < V_{TH} .$$

**$M_1$ 截止**；3 V 的源-衬底电压所引起的体效应（body effect）只会使 $V_{TH}$ 更高。没有任何东西使 $C_1$ 放电，$V_X$ 保持在 **6 V**。

### 第 2 步 — $t = 0$ 时的阶跃

$V_{in}$ 从 3 V 降到 0，而 $C_1$ 的电压不能瞬时改变（只能流过有限的电流），因此

$$V_X(0^+) = V_{in}(0^+) + V_{C1}(0^+) = 0 + 3 = 3\ \mathrm{V}.$$

$V_X$ **随输入一起从 6 V 降到 3 V**。

### 第 3 步 — 阶段 1：$M_1$ 导通并饱和，线性下降

当 $t > 0$ 时，源极是处于 0 V 的 $V_{in}$ 节点，因此 $V_{SB} = 0$，$V_{TH} = 0.7$ V：

$$
\begin{aligned}
V_{GS} &= 3 - 0 = 3\ \mathrm{V}, \qquad V_{ov} = 3 - 0.7 = 2.3\ \mathrm{V},\\
V_{DS} &= V_X - 0 = 3\ \mathrm{V} > 2.3\ \mathrm{V} \quad\Longrightarrow\quad \text{saturated},
\end{aligned}
$$

$$I_D = \tfrac12\beta\,(2.3\ \mathrm{V})^2 = 2.645\,\beta\ \mathrm{V^2} \approx 2.65\beta .$$

$C_1$ 直接跨接在漏极与源极之间，因此这一电流离开其 X 侧极板，流过沟道，再回到它的另一极板：$C_1$ 在一个局部回路中放电，输入源中没有净电流。由于 $V_{in} = 0$ 恒定，$V_{C1} = V_X$，因此

$$C_1\frac{dV_X}{dt} = -I_D \quad\Longrightarrow\quad V_X(t) = 3\ \mathrm{V} - \frac{2.65\,\beta}{C_1}\,t .$$

**$V_X$ 线性下降**，直到达到饱和区边缘 $V_X = V_{GS} - V_{TH} = 2.3$ V，此时

$$t_1 = \frac{C_1\,(3 - 2.3)\ \mathrm{V}}{2.645\,\beta\ \mathrm{V^2}} = \frac{0.265\,C_1}{\beta\ \mathrm{V}} .$$

### 第 4 步 — 阶段 2：在线性区中衰减到零

当 $V_X < 2.3$ V 时，$M_1$ 处于线性区：

$$C_1\frac{dV_X}{dt} = -\beta\left[2.3V_X - \tfrac12V_X^2\right].$$

以 $t_1$ 时的 2.3 V 为起点，其解（利用部分分式分离变量求得）为

$$V_X(t) = \frac{4.6\ \mathrm{V}\cdot E}{1 + E}, \qquad E = e^{-(t - t_1)/\tau}, \qquad \tau = R_{on}C_1 = \frac{C_1}{2.3\,\beta},$$

其中 $R_{on} = 1/[\beta(3 - 0.7)]$。当 $t - t_1 \gg \tau$ 时，$V_X \approx 4.6\,e^{-(t - t_1)/\tau}$：**这是一个衰减到 0 V 的类指数过程**。栅极始终比源极高 3 V，因此沟道永不关断，$C_1$ 被完全放电。

### 第 5 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF：$I_D = 2.65$ mA，斜坡斜率为 $-2.65$ V/ns，$t_1 = 0.7\ \mathrm{V}/(2.65\ \mathrm{V/ns}) = 0.26$ ns，$\tau = 0.43$ ns。

| $t$ | $V_X$ (V) | $M_1$ |
|---|---|---|
| $t < 0$ | 6.0 | 截止 |
| $0^+$ | 3.0 | 饱和区 |
| 0.26 ns | 2.30 | 边界 |
| $t_1 + \tau$ ≈ 0.70 ns | 1.24 | 线性区 |
| $t_1 + 2\tau$ ≈ 1.13 ns | 0.55 | 线性区 |
| $t_1 + 4\tau$ ≈ 2.0 ns | 0.08 | 线性区 |
| ∞ | 0 | 线性区，无电流 |

### 结果

- **$t < 0$：** $V_X = 6$ V（$V_{in} = 3$ V 加上 $C_1$ 上的 3 V）。$M_1$ 截止，因为其栅极电压 $V_{DD} = 3$ V 等于源极电压。
- **$t = 0$：** $V_X$ **随输入下降到 3 V**。
- **阶段 1：** 此时 $V_{GS} = 3$ V，$V_{DS} = 3$ V，因此 $M_1$ 处于饱和区。它以恒定电流 $\tfrac12\beta(2.3)^2 = 2.65\beta$ 对 $C_1$（接在其漏极与源极之间）放电，$V_X$ 以 $2.65\beta/C_1$ 的速率**线性下降**到 2.3 V。
- **阶段 2：** $M_1$ 处于线性区，$V_X$ **大致按指数规律衰减到 0 V**（时间常数 ≈ $C_1/(2.3\beta)$）。

**常见错误。** 因为“电容保持 3 V”，就让 $V_X$ 在阶跃后保持 3 V。在阶跃瞬间确实如此，但此后 $M_1$ 以 $V_{GS} = 3$ V 导通，其沟道正好跨接在 $C_1$ 两端，因此电容会被放电。

**常见错误。** 认为阶跃后 $M_1$ 截止。阶跃之前其源极处于 3 V（等于栅极电压）；阶跃之后源极处于 0 V，因此 $V_{GS} = 3$ V。

**常见错误。** 最终停在一个非零电压上，例如 2.3 V。这只标志着从饱和区到线性区的转变；栅极比源极高 3 V，沟道会一直导通到 $V_{DS} = 0$。
