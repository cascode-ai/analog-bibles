如 [图 1] 所示，把一个 CMOS 反相器（inverter）用作带电阻反馈的放大器。假设 $(W/L)_{1,2} = 50/0.5$，$R_1 = 1\ \mathrm{k\Omega}$，$R_2 = 10\ \mathrm{k\Omega}$，且 $V_{in}$ 与 $V_{out}$ 的直流电平相等。计算电压增益 $V_{out}/V_{in}$ 和输出阻抗。$M_2$ 的源极和衬底（bulk）都接 $V_{DD}$。

器件参数：$V_{DD} = 3$ V；NMOS 的 $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$V_{TH} = 0.7$ V，$\lambda = 0.1\ \mathrm{V^{-1}}$；PMOS 的 $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$V_{TH} = -0.8$ V，$\lambda = 0.2\ \mathrm{V^{-1}}$。
