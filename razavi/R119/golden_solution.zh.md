$M_2$ 构成源极跟随器（source follower），以电流源（current source）$M_1$ 作负载（$R_S = r_{O1}$），漏极接电流源 $M_3$（$R_D = r_{O3}$）：
$A_v = \dfrac{g_{m2}r_{O1}r_{O2}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}$（略小于 1）。

- 流过 $M_2$ 的电流：$i = g_{m2}(v_{in} - v_{out}) + (v_D - v_{out})/r_{O2}$，$v_D = -ir_{O3}$，$v_{out} = ir_{O1}$。
- 注意 $M_2$ 的漏极不是交流地（接有 $r_{O3}$），这使分母中多出一项 $r_{O3}$。
