# 详细步骤 - R119

**思路。** 输出端是 $M_2$ 的**源极**，因此 $M_2$ 是以 NMOS 电流源 $M_1$ 为负载的源极跟随器，其漏极由 PMOS 电流源 $M_3$ 供电（因此漏极**不是**交流地）。把两个电流源都化简为它们的输出电阻（output resistance），求出流过整个串联支路的唯一电流，再乘以源极电阻即可。

### 第 1 步 — 小信号模型（small-signal model）与支路电流

$M_1$ 和 $M_3$ 的栅极接直流偏置，源极接电源，因此 $v_{gs1} = v_{gs3} = 0$：$M_1$ 只相当于从 out 接到地的 $r_{O1}$，$M_3$ 只相当于从 $M_2$ 的漏极（节点 $D$）接到交流地的 $r_{O3}$。$g_{m1}$ 和 $g_{m3}$ 不会出现在结果中。$M_2$（$\gamma = 0$）的 $v_{gs2} = v_{in} - v_{out}$：受控源 $g_{m2}(v_{in} - v_{out})$ 从 $D$ 流向 out，$r_{O2}$ 接在 $D$ 与 out 之间。

<!-- diagram: diagram-01.cir -->

同一小信号电流 $i$ 向下流过 $r_{O3}$、$M_2$ 和 $r_{O1}$（以向下为正）：

$$v_{out} = i\,r_{O1}, \qquad v_D = -i\,r_{O3}\quad\big(i = (0 - v_D)/r_{O3}\big),$$

$$i = g_{m2}(v_{in} - v_{out}) + \frac{v_D - v_{out}}{r_{O2}}.$$

### 第 2 步 — 求解增益

代入 $v_{out} = ir_{O1}$ 和 $v_D = -ir_{O3}$：

$$i = g_{m2}v_{in} - g_{m2}r_{O1}\,i + \frac{-ir_{O3} - ir_{O1}}{r_{O2}}.$$

合并含 $i$ 的项，再乘以 $r_{O2}$：

$$i\left(1 + g_{m2}r_{O1} + \frac{r_{O1} + r_{O3}}{r_{O2}}\right) = g_{m2}v_{in},$$

$$i\,(r_{O2} + g_{m2}r_{O1}r_{O2} + r_{O1} + r_{O3}) = g_{m2}r_{O2}\,v_{in},$$

$$i = \frac{g_{m2}r_{O2}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}\,v_{in}.$$

乘以 $r_{O1}$：

$$A_v = \frac{v_{out}}{v_{in}} = \frac{g_{m2}r_{O1}r_{O2}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}}.$$

分母等于分子再加上三个正项，因此 $0 < A_v < 1$。

### 第 3 步 — 增益与 1 有多接近，以及 $r_{O3}$ 的作用

将分子和分母同除以 $g_{m2}r_{O1}r_{O2}$：

$$A_v = \frac{1}{1 + \dfrac{1}{g_{m2}r_{O2}} + \dfrac{1}{g_{m2}r_{O1}} + \dfrac{r_{O3}}{g_{m2}r_{O1}r_{O2}}}.$$

每个小项的量级都是 $1/(g_mr_O) \ll 1$，因此

$$A_v \approx 1 - \frac{1}{g_{m2}r_{O2}} - \frac{1}{g_{m2}r_{O1}} - \frac{r_{O3}}{g_{m2}r_{O1}r_{O2}}:$$

**略小于 1**。例如，取 $r_{O1} = r_{O2} = r_{O3}$，$g_{m2}r_{O2} = 50$，则 $A_v = 50/(3 + 50) \approx 0.94$。

**与漏极接地的情况比较。** 令 $r_{O3} \to 0$，将分子和分母同除以 $r_{O1} + r_{O2}$，

$$\frac{g_{m2}r_{O1}r_{O2}}{r_{O1} + r_{O2} + g_{m2}r_{O1}r_{O2}} = \frac{g_{m2}(r_{O1}\parallel r_{O2})}{1 + g_{m2}(r_{O1}\parallel r_{O2})},$$

这就是负载为 $r_{O1}\parallel r_{O2}$ 的跟随器的标准增益。增加的 $r_{O3}$ 使增益再略微降低：当 $v_{in}$ 升高时，$i$ 增大，因此 $D$ 点电压**下降**（$v_D = -ir_{O3}$），而源极电压上升，这使 $v_{DS2}$ 以及流过 $r_{O2}$ 的电流减小。这一影响很小，因为 $r_{O3}$ 只以除以 $g_{m2}r_{O1}r_{O2}$ 的形式出现。

### 结果

$$A_v = \frac{g_{m2}r_{O1}r_{O2}}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O1}r_{O2}},$$

增益为正，略小于 1（不足部分为 $1/(g_mr_O)$ 量级）。

**常见错误。** 从 $M_2$ 的漏极取输出，或得出反相增益。输出端是 $M_2$ 的源极（也是 $M_1$ 的漏极），因此 $v_{out}$ 随 $v_{in}$ 同向变化。

**常见错误。** 不加说明就把 $M_2$ 的漏极当作交流地，从而丢掉 $r_{O3}$，得到 $g_{m2}r_{O1}r_{O2}/(r_{O1} + r_{O2} + g_{m2}r_{O1}r_{O2})$。这作为**近似**是合理的，但漏极节点电压是变化的，精确的分母中应包含 $r_{O3}$。

**常见错误。** 得出恰好等于 1 或更大的增益。由于各 $r_O$ 为有限值，$v_{in}$ 总有一部分落在 $v_{gs2}$ 上，因此 $A_v < 1$。
