# 详细步骤 - R337

**思路。** 跟踪电流的走向。由于 $\lambda = 0$，$M_1$ 是只由其自身栅极电压和噪声决定的理想电流源，从输出端向下流经 $M_2$ 和 $R_F$ 的每一份电流最终都必须流入 $M_1$。因此无论 $M_2$ 和 $R_F$ 如何，$R_D$ 中的电流以及 $v_{out}$ 都只由 $M_1$ 决定。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 与 $M_2$ 之间的节点记为 X（即 $M_1$ 的漏极、$M_2$ 的源极和 $R_F$ 的下端）。

- **$M_1$：** 从 X 流向地的电流源 $g_{m1}v_{in}$，与 $v_X$ 无关，其沟道噪声 $I_{n1}$（$\overline{I_{n1}^2} = 4kT\gamma g_{m1}$）与之并联。
- **$M_2$**（栅极接交流地）：从输出端流向 X 的电流源 $g_{m2}(0 - v_X)$，其噪声 $I_{n2}$（$\overline{I_{n2}^2} = 4kT\gamma g_{m2}$）与之并联。
- **$R_F$：** 接在输出端与 X 之间，其诺顿噪声 $I_{nF}$（$\overline{I_{nF}^2} = 4kT/R_F$）与之并联。
- **$R_D$：** 接在输出端与交流地之间，其诺顿噪声 $I_{nD}$（$\overline{I_{nD}^2} = 4kT/R_D$）从 $V_{DD}$ 流入输出端。

因此输出端与 X 之间有四条并联支路，而 X 与地之间只有 $M_1$。

### 第 2 步 — 节点 X 的基尔霍夫电流定律（KCL）

从输出端经上方四条支路流到 X 的总电流 $i_{OX}$ 必须经 $M_1$ 离开 X：

$$i_{OX} = \underbrace{g_{m2}(0 - v_X) + I_{n2}}_{M_2} + \underbrace{\frac{v_{out} - v_X}{R_F} + I_{nF}}_{R_F} = g_{m1}v_{in} + I_{n1}.$$

由于 $M_1$ 是理想电流源，等式右边不含任何节点电压。因此

$$i_{OX} = g_{m1}v_{in} + I_{n1},$$

**它与 $I_{n2}$、$I_{nF}$、$g_{m2}$ 和 $R_F$ 都无关**；这些量只决定 $i_{OX}$ 在 $M_2$ 与 $R_F$ 之间如何分配，以及电压 $v_X$ 的大小。

### 第 3 步 — 输出节点的 KCL

从 $V_{DD}$ 经 $R_D$ 支路流入的电流等于流向 X 的电流：

$$\frac{0 - v_{out}}{R_D} + I_{nD} = i_{OX} = g_{m1}v_{in} + I_{n1},$$

$$
\begin{aligned}
-\frac{v_{out}}{R_D} &= g_{m1}v_{in} + I_{n1} - I_{nD}\\
v_{out} &= -g_{m1}R_D\,v_{in} - R_DI_{n1} + R_DI_{nD}.
\end{aligned}
$$

式中既没有 $I_{n2}$ 和 $I_{nF}$，也没有 $R_F$ 和 $g_{m2}$。

### 第 4 步 — $M_2$ 和 $R_F$ 的噪声电流的去向

令 $v_{in} = 0$、$I_{n1} = 0$、$I_{nD} = 0$，则 $v_{out} = 0$，$i_{OX} = 0$，节点 X 的 KCL 给出

$$
\begin{aligned}
-g_{m2}v_X + I_{n2} - \frac{v_X}{R_F} + I_{nF} &= 0\\
v_X &= \frac{I_{n2} + I_{nF}}{g_{m2} + 1/R_F}.
\end{aligned}
$$

因此 $I_{n2}$ 和 $I_{nF}$ **只在 $M_2$–$R_F$ 回路内部环流**：它们使 $v_X$ 升高，直到 $M_2$ 和 $R_F$ 送回大小相等、方向相反的电流为止。它们只让节点 X 带有噪声，没有任何噪声到达 $R_D$。

### 第 5 步 — 增益与输入参考噪声

由第 3 步可知，信号增益与简单共源级相同：

$$A_v = \frac{v_{out}}{v_{in}} = -g_{m1}R_D .$$

其余两个互不相关的噪声源给出

$$\overline{V_{n,out}^2} = R_D^2\left(\overline{I_{n1}^2} + \overline{I_{nD}^2}\right) = R_D^2\left(4kT\gamma g_{m1} + \frac{4kT}{R_D}\right),$$

除以 $A_v^2 = g_{m1}^2R_D^2$，得

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \frac{R_D^2\left(4kT\gamma g_{m1} + 4kT/R_D\right)}{g_{m1}^2R_D^2}\\
&= \frac{4kT\gamma}{g_{m1}} + \frac{4kT}{g_{m1}^2R_D}\\
&= 4kT\left(\frac{\gamma}{g_{m1}} + \frac{1}{g_{m1}^2R_D}\right).
\end{aligned}
$$

### 第 6 步 — 这种抵消有多可靠？

上述论证只用到一个事实：输出端与 X 之间的所有元件都与一个理想电流源串联，因此那里的任何元件（包括 $g_{mb2}$ 和 $r_{O2}$）的影响都会抵消；忽略体效应并不是必要条件。只有当 X 有另一条到地的通路时，抵消才会失效，例如有限的 $r_{O1}$，或高频下 X 点的电容：环流的噪声电流有一部分会经这条通路泄漏，于是需要从 $R_D$ 抽取电流来补充。

### 结果

$$\overline{V_{n,in}^2} = 4kT\left(\frac{\gamma}{g_{m1}} + \frac{1}{g_{m1}^2R_D}\right)$$

$M_2$ 和 $R_F$ **没有任何贡献**。由于 $\lambda = 0$，$M_1$ 是理想电流源，因此流过 $R_D$ 的电流恰好是 $g_{m1}v_{in} + I_{n1}$（再加上 $R_D$ 自身的噪声）。$M_2$ 和 $R_F$ 的噪声电流在 $M_2$–$R_F$ 回路中环流，只改变中间节点的电压。增益为 $-g_{m1}R_D$，结果与简单共源级相同。

**常见错误。** 把 $R_F$ 当作接在输出端与交流地之间、与 $R_D$ 并联的电阻，这会同时改变增益和噪声。$R_F$ 接在输出端与 X 之间，流过它的每一份电流都必须经 $M_1$ 返回。

**常见错误。** 为 $M_2$ 加上一个噪声项（例如 $4kT\gamma g_{m2}/g_{m1}^2$，仿佛它的噪声电流注入了输出端）。叠在理想电流源上方的共源共栅器件无法改变送往负载的电流。

**常见错误。** 把这种抵消归因于忽略了体效应。$g_{mb2}$ 和 $r_{O2}$ 同样作用于输出端与 X 之间，也以同样的方式抵消；只有有限的 $r_{O1}$ 或 X 点的电容才会破坏这种抵消。
