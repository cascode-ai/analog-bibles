# 详细步骤 - R692

**思路。** 接触尖刺使某个源/漏结变成该扩散区（diffusion）与其下方衬底或阱之间的短路。列出所有可能发生尖刺的结，分析每处短路的后果，并与正常的小信号增益比较。只有一个候选会使增益**变大**。

### 第 1 步 — 候选的结

在退火过程中，接触孔的金属可能穿过较浅的源/漏扩散区长出尖刺，**使扩散区与其体区短路**，短路通路上至多有一个很小的扩展电阻（spreading resistance）。电路中共有四个位于接触孔下方的扩散区-体区结：

| 结 | 体区电位 | 会被短路的节点 |
|---|---|---|
| (a) $M_1$ 的 n+ 源区 / p 型衬底 | 地 | $M_1$ 的源极（$R_S$ 的上端）对地 |
| (b) $M_1$ 的 n+ 漏区 / p 型衬底 | 地 | $V_{out}$ 对地 |
| (c) $M_2$ 的 p+ 源区 / n 阱 | $V_{DD}$ | $M_2$ 的源极对 $V_{DD}$ |
| (d) $M_2$ 的 p+ 漏区 / n 阱 | $V_{DD}$ | $V_{out}$ 对 $V_{DD}$ |

阱和衬底的接触（n 阱中的 n+、p 型衬底中的 p+）与其所在的体区之间并不构成结，因此在那里发生尖刺不会有任何影响。

### 第 2 步 — 正常的小信号增益

取 $\lambda = 0$：$M_1$ 的 $v_{gs1} = v_{in} - v_S$，并且由于其衬底是接地的 p 型衬底，$v_{bs1} = -v_S$；$R_S$ 接在 S 与地之间；二极管连接（diode-connected）的 $M_2$ 相当于一个从输出端接到交流地的电阻 $1/g_{m2}$，并且由于其源极和衬底都处于 $V_{DD}$，没有体效应（body effect）。

<!-- diagram: diagram-01.cir -->

漏极电流 $i_d$ 流过 $R_S$，因此 $v_S = i_dR_S$，且

$$i_d = g_{m1}(v_{in} - v_S) + g_{mb1}(-v_S) = g_{m1}v_{in} - (g_{m1} + g_{mb1})R_S\,i_d \quad\Longrightarrow\quad i_d = \frac{g_{m1}}{1 + (g_{m1} + g_{mb1})R_S}\,v_{in}.$$

该电流经 $1/g_{m2}$ 从输出端抽出，因此 $v_{out} = -i_d/g_{m2}$，且

$$A_{v,\text{nom}} = \frac{v_{out}}{v_{in}} = -\frac{g_{m1}}{g_{m2}\big[1 + (g_{m1} + g_{mb1})R_S\big]} \approx -\frac{g_{m1}}{g_{m2}(1 + g_{m1}R_S)}$$

（最后一种形式忽略了体效应），即负载 $1/g_{m2}$ 与源极支路电阻 $1/g_{m1} + R_S$ 之比。源极负反馈电阻 $R_S$ **有意降低**了增益（同时使其更加线性）。

### 第 3 步 — 各种可能的尖刺的影响

**(a) $M_1$ 的源结发生尖刺。** $M_1$ 的源极与接地的衬底短路：S 与地之间出现一个小电阻 $R_{sub}$，与 $R_S$ 并联。由于 $R_{sub} \ll R_S$，$v_S = 0$（因而 $v_{bs1} = 0$），由第 2 步得到

$$i_d = g_{m1}v_{in}, \qquad A_v = -\frac{g_{m1}}{g_{m2}} ,$$

比正常值大，倍数为

$$\frac{|A_v|}{|A_{v,\text{nom}}|} = 1 + (g_{m1} + g_{mb1})R_S > 1 .$$

例如，当 $g_{m1}R_S = 1$ 时，增益约增大一倍。直流电流也会增大，但对于二极管连接的负载，$g_{m1}/g_{m2} = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_2]}$ 与偏置电流无关，因此无论新的偏置点在哪里，增益都会更高。**这与故障现象相符。**

其他三种情况都不符合：

| 发生尖刺的结 | 后果 | 增益 |
|---|---|---|
| $M_1$ 源区 / 衬底 | $R_S$ 被旁路（源极负反馈消失） | **增大**到 $\approx g_{m1}/g_{m2}$ |
| $M_1$ 漏区 / 衬底 | $V_{out}$ 对地短路，输出被钳在 0 V 附近 | $\approx 0$ |
| $M_2$ 源区 / n 阱 | 两个节点本来就相同（都处于 $V_{DD}$） | 不变 |
| $M_2$ 漏区 / n 阱 | $V_{out}$ 对 $V_{DD}$ 短路，输出被钳在 $V_{DD}$ 附近 | $\approx 0$ |

### 结果

故障结是 **$M_1$ 的 n+ 源区与接地 p 型衬底之间的结**。尖刺使 $M_1$ 的源极对地短路，与 $R_S$ 并联，从而消除了源极负反馈，因此增益的变化为

$$|A_v| \approx \frac{g_{m1}}{g_{m2}(1 + g_{m1}R_S)} \quad\text{to}\quad |A_v| \approx \frac{g_{m1}}{g_{m2}} .$$

若尖刺发生在 $M_1$ 或 $M_2$ 的漏结，会把 $V_{out}$ 钳在地或 $V_{DD}$（增益 ≈ 0）；若发生在 $M_2$ 的源结，则不会有任何变化。

**常见错误。** 因为“增益是在漏极处决定的”而选择 $M_1$ 的漏结。漏极与衬底之间的短路会使输出节点本身接地，从而使增益完全丧失。

**常见错误。** 把尖刺描述为开路。金属穿透结，使扩散区与体区**短路**；若源极接触开路，则会切断 $M_1$ 的电流，同样使增益消失。

**常见错误。** 忘记了每个体区所处的电位：$M_1$ 下方的衬底接地，$M_2$ 的阱处于 $V_{DD}$，因此 $M_2$ 源极处的尖刺是无害的。
