# 详细步骤 - R008

**思路：** 把 $M_1$ 中电位较低的扩散区端（diffusion terminal）当作源极，然后检查 $V_{GS}$ 是否超过阈值电压（threshold voltage），其中要计入衬底接地带来的体效应。结果表明，$M_1$ 只在 $V_X$ 接近零的一小段范围内导通，并处于饱和区；在其他范围内都截止。

### 第 1 步 — 源极端与阈值电压

衬底接地时，

$$V_{TH} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right) = 0.7 + 0.45\left(\sqrt{0.9 + V_{SB}} - 0.9487\right)\ \mathrm{V}.$$

栅极（1 V）低于 1.9 V 端，因此只有当 $V_X$ 端是源极，**并且**其电位远低于 1 V 时，$V_{GS}$ 才可能为正。

当 $V_X > 1.9$ V 时，电位较低的端子（1.9 V）是源极：

$$V_{GS} = 1\ \mathrm{V} - 1.9\ \mathrm{V} = -0.9\ \mathrm{V} < V_{TH},$$

因此 $M_1$ 截止：$I_X = 0$，$g_m = 0$。

### 第 2 步 — $V_X < 1.9$ V：$M_1$ 的截止点

此时 $V_X$ 端是源极：

$$
\begin{aligned}
V_{GS} &= 1 - V_X,\\
V_{DS} &= 1.9 - V_X,\\
V_{SB} &= V_X - 0 = V_X .
\end{aligned}
$$

$M_1$ 导通的条件是

$$1 - V_X > 0.7 + 0.45\left(\sqrt{0.9 + V_X} - 0.9487\right).$$

升高 $V_X$ 既会降低 $V_{GS}$，又会升高 $V_{TH}$，因此只有一个截止点。令两边相等，并代入 $u = \sqrt{0.9 + V_X}$，则 $V_X = u^2 - 0.9$：

$$
\begin{aligned}
1 - (u^2 - 0.9) &= 0.7 + 0.45u - 0.45\times0.9487\\
1.9 - u^2 &= 0.2731 + 0.45u\\
u^2 + 0.45u - 1.6269 &= 0 .
\end{aligned}
$$

取正根，

$$u = \frac{-0.45 + \sqrt{0.45^2 + 4\times1.6269}}{2} = \frac{-0.45 + \sqrt{6.7101}}{2} = \frac{-0.45 + 2.5904}{2} = 1.0702 ,$$

$$V_X = u^2 - 0.9 = 1.1453 - 0.9 = 0.245\ \mathrm{V}.$$

验算：$V_X = 0.245$ V 时，$V_{TH} = 0.7 + 0.45(1.0702 - 0.9487) = 0.755$ V，$V_{GS} = 1 - 0.245 = 0.755$ V。✓

所以 **$M_1$ 只在 $0 \le V_X < 0.245$ V 范围内导通**，在 $0.245\ \mathrm{V} < V_X < 1.9$ V 范围内截止（$I_X = 0$，$g_m = 0$）。若没有体效应（$V_{TH} = 0.7$ V 固定不变），界限将为 $1 - V_X = 0.7$，即 $V_X = 0.3$ V；体效应使这一界限向内收缩了约 55 mV。

### 第 3 步 — 导通时的工作区

最大过驱动电压为 $V_{ov} = 1 - 0 - 0.7 = 0.3$ V（在 $V_X = 0$ 处），最小 $V_{DS}$ 为 $1.9 - 0.245 = 1.655$ V（在 $V_X = 0.245$ V 处）。由于 $1.655\ \mathrm{V} \gg 0.3\ \mathrm{V}$，**$M_1$ 只要导通就处于饱和区**。

### 第 4 步 — 电流 $I_X$

忽略沟道长度调制（channel-length modulation），

$$I_D = \tfrac12\beta\,(V_{GS} - V_{TH})^2 = \tfrac12\beta\,(1 - V_X - V_{TH})^2 ,$$

该电流从漏极（1.9 V 端）流向源极，然后**流出** $M_1$，流入 $V_X$ 电源，与 $I_X$ 方向相反。因此

$$I_X = -\tfrac12\beta\,(1 - V_X - V_{TH})^2 .$$

逐点计算（阈值电压、过驱动电压、电流）：

- $V_X = 0$：$V_{TH} = 0.700$ V，$V_{ov} = 1 - 0 - 0.700 = 0.300$ V，
$$I_X = -\tfrac12\beta\,(0.3\ \mathrm{V})^2 = -0.045\beta\ \mathrm{V^2}.$$
- $V_X = 0.1$ V：$V_{TH} = 0.7 + 0.45(\sqrt{1.0} - 0.9487) = 0.7 + 0.0231 = 0.723$ V，$V_{ov} = 0.9 - 0.723 = 0.177$ V，
$$I_X = -\tfrac12\beta\,(0.177\ \mathrm{V})^2 = -0.0156\beta\ \mathrm{V^2}.$$
- $V_X = 0.2$ V：$V_{TH} = 0.7 + 0.45(\sqrt{1.1} - 0.9487) = 0.7 + 0.0451 = 0.745$ V，$V_{ov} = 0.8 - 0.745 = 0.055$ V，
$$I_X = -\tfrac12\beta\,(0.055\ \mathrm{V})^2 = -0.0015\beta\ \mathrm{V^2}.$$
- $V_X = 0.245$ V：$V_{ov} = 0$，因此 $I_X = 0$。

**形状：** $dI_X/dV_X = \beta V_{ov}(1 + \eta)$，其中 $\eta = \gamma/(2\sqrt{0.9 + V_X}) \approx 0.21$–$0.24$：$V_X = 0$ 时为 $0.37\beta$（V），到 0.245 V 时降为零。所以 $I_X$ 是一段向下弯曲的小曲线，从 $-0.045\beta$ 开始，在 0.245 V 处**与零轴相切**，之后直到 3 V 都保持为零；在实际器件中，略高于 0.245 V 处还有一个按指数衰减的很小的亚阈值（subthreshold）电流。取 $\beta = 1\ \mathrm{mA/V^2}$ 时，最大电流为 $45\ \mu$A，流入 $V_X$ 电源。

### 第 5 步 — 跨导

在饱和区，

$$g_m = \beta\,(V_{GS} - V_{TH}) = \beta\,(1 - V_X - V_{TH}):$$

$$
\begin{aligned}
V_X = 0:&\quad g_m = \beta\,(0.300\ \mathrm{V}) = 0.30\beta,\\
V_X = 0.1\ \mathrm{V}:&\quad g_m = \beta\,(0.177\ \mathrm{V}) = 0.18\beta,\\
V_X = 0.2\ \mathrm{V}:&\quad g_m = \beta\,(0.055\ \mathrm{V}) = 0.055\beta,\\
V_X \ge 0.245\ \mathrm{V}:&\quad g_m = 0 .
\end{aligned}
$$

由于 $V_{ov}$ 随 $V_X$ 的下降速率为 $1 + \eta \approx 1.2$ V/V，$g_m$ 几乎是一条直线，从 $0.3\beta$ 下降到 0.245 V 处的零，之后为零。

| $V_X$ (V) | $V_{TH}$ (V) | $V_{ov}$ (V) | $I_X/\beta$ (V²) | $g_m/\beta$ (V) |
|---|---|---|---|---|
| 0 | 0.700 | 0.300 | −0.045 | 0.30 |
| 0.1 | 0.723 | 0.177 | −0.0156 | 0.18 |
| 0.2 | 0.745 | 0.055 | −0.0015 | 0.055 |
| 0.245 | 0.755 | 0 | 0 | 0 |
| 0.245 – 3 | — | 截止 | 0 | 0 |
