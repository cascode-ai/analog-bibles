# Golden Solution - R413

## Reference answer

$A_v = +100/134 \approx 0.746$; $R_{out} = 24\ \mathrm{k\Omega}/134 \approx 179\ \Omega$. In general, with all resistors $R$ and $g_{m1} = g_{m2} = g$: $A_v = \dfrac{(gR)^2}{(gR)^2 + 3gR + 4}$, $R_{out} = \dfrac{R(gR+2)}{(gR)^2 + 3gR + 4}$, here $gR = 10$.

- Topology: $M_1$ (common source with $R_{S1}$ at its source) drives $M_2$ (common source). $R_{F1}$ returns the output to the source of $M_1$ (series–shunt, overall negative loop: the two inverting stages give a non-inverting forward path), and $R_{F2}$ closes a local shunt–shunt loop from the output to the gate of $M_2$.
- Nodal equations (A = drain of $M_1$, S = source of $M_1$):
  A: $-v_A/R_{D1} + (v_{out} - v_A)/R_{F2} - g_{m1}(v_{in} - v_S) = 0$;
  S: $g_{m1}(v_{in} - v_S) - v_S/R_{S1} + (v_{out} - v_S)/R_{F1} = 0$;
  out: $-v_{out}/R_{D2} + (v_A - v_{out})/R_{F2} + (v_S - v_{out})/R_{F1} - g_{m2}v_A = 0$;
  → $v_{out} = 0.746v_{in}$ ($v_A = -0.149v_{in}$, $v_S = 0.896v_{in}$). With a test current at the output and $v_{in}$ = 0: $R_{out} = 179\ \Omega$.
- Two-port estimate: $M_1$ degenerated by $R_{S1}\|R_{F1} = 1\ \mathrm{k\Omega}$ ($G_m$ = 0.833 mS); node A loaded by $R_{D1}$ and the Miller-reduced input of the $M_2$/$R_{F2}$ stage (2 kΩ/4.6 = 435 Ω) → 357 Ω; $M_2$ stage gain with load $R_{D2}\|(R_{F1}+R_{S1})$: −3.6; $A_{v,open} = 1.07$, $\beta = 0.5$, loop gain 0.54 → $A_v \approx 0.70$, $R_{out} \approx 286\ \Omega/1.54 \approx 186\ \Omega$. The loop gain is small because $R_{F2}$ heavily loads node A, so the gain is far below $1/\beta = 2$.
