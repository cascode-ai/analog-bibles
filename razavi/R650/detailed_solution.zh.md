# 详细步骤 - R650

**思路。** 鉴相器的输出由携带相位误差的直流（缓变）部分，以及位于输入频率及其谐波处的高频分量组成。锁定时 VCO 需要一个稳定的控制电压，即一个必须经过滤波器传来的直流电平。高通滤波器恰好阻断了这个直流部分，却恰好让不需要的高频部分通过；环路的线性相位域模型也证实了这一点。

### 第 1 步 — 环路中的信号

VCO 满足 $\omega_{out} = \omega_0 + K_{VCO}V_{cont}$，其中 $\omega_0$ 是其自由振荡频率（在 $V_{cont} = 0$ 时，或在滤波器的参考电平处）。鉴相器输出包含：

- 一个**直流或缓变分量** $K_{PD}\Delta\phi$，它与相位误差 $\Delta\phi = \phi_{in} - \phi_{out}$ 成正比：这是有用的信息；
- **高频分量**，即位于输入频率或其谐波处的脉冲或纹波（对于异或鉴相器，是一个位于 $2\omega_{in}$ 的脉冲串，其占空比反映 $\Delta\phi$）：这是不需要的副产物。

### 第 2 步 — 锁定时 VCO 需要什么

锁定时（平均而言）$\omega_{out} = \omega_{in}$，这需要一个**恒定**的控制电压

$$V_{cont} = \frac{\omega_{in} - \omega_0}{K_{VCO}} ,$$

除非恰好 $\omega_{in} = \omega_0$，否则这是一个非零的直流电平。它唯一的来源是经过滤波器的鉴相器输出，因此滤波器必须让直流通过：鉴相器会稳定在某个相位误差上，使其平均输出恰好提供这一电平。

### 第 3 步 — 高通滤波器对直流的作用

高通滤波器的直流增益为零；例如

$$H_{HPF}(s) = \frac{s}{s + \omega_H}$$

满足 $H_{HPF}(0) = 0$。无论鉴相器的平均输出是多少，$V_{cont}$ 的平均值都被钳定在滤波器的参考电平上（这里为 0）。因此，VCO 的**平均**频率保持在 $\omega_0$；恒定的相位误差只会产生一个以时间常数 $1/\omega_H$ 衰减的暂态校正；而且当 $\omega_{in} \ne \omega_0$ 时，环路无法保持 $\omega_{out} = \omega_{in}$，因此既不能锁定，也不能跟踪输入频率。

### 第 4 步 — 由环路传递函数得到同样的结论

在相位域中，VCO 是一个积分器，$\phi_{out}/V_{cont} = K_{VCO}/s$。采用高通滤波器时，环路增益为

$$G(s) = K_{PD}\cdot\frac{s}{s + \omega_H}\cdot\frac{K_{VCO}}{s} = \frac{K_{PD}K_{VCO}}{s + \omega_H}.$$

滤波器在原点处的零点**抵消了 VCO 的积分器**，因此直流环路增益是有限的，$G(0) = K_{PD}K_{VCO}/\omega_H$。对于输入频率的阶跃 $\Delta\omega$（频率是相位的导数，因此频率传递函数等于相位传递函数）：

$$\frac{\omega_{out}}{\omega_{in}} = \frac{G(s)}{1 + G(s)} = \frac{K_{PD}K_{VCO}}{s + \omega_H + K_{PD}K_{VCO}} ,$$

在稳态（$s \to 0$）时

$$\Delta\omega_{out} = \frac{K_{PD}K_{VCO}}{\omega_H + K_{PD}K_{VCO}}\,\Delta\omega, \qquad \Delta\omega - \Delta\omega_{out} = \frac{\omega_H}{\omega_H + K_{PD}K_{VCO}}\,\Delta\omega \ne 0 .$$

存在**永久的频率误差**，因此相位误差无限增长，环路发生周跳，永远达不到 $\omega_{out} = \omega_{in}$。若采用低通滤波器（直流增益为 1），VCO 的积分器得以保留，直流环路增益为无穷大，稳态频率误差为零。

### 第 5 步 — 高通滤波器对高频分量的作用

环路滤波器的第二个任务是抑制鉴相器的高频分量。高通滤波器却把它们直接送到 VCO，使 VCO 的频率在输入频率或其谐波处受到强烈调制；即使环路能够锁定，也会产生很大的边带（杂散）和抖动。

### 结果

高通滤波器不能代替低通滤波器，因为：

1. **它阻断了有用信号。** 相位误差信息是鉴相器输出的直流（平均）分量 $K_{PD}\Delta\phi$。锁定时 VCO 需要一个稳定的控制电压 $(\omega_{in} - \omega_0)/K_{VCO}$，它必须经过滤波器传来。高通滤波器的直流增益为零，因此 $V_{cont}$ 被钳定在其参考电平上，VCO 保持在自由振荡频率。从环路的角度看，滤波器在 $s = 0$ 处的零点抵消了 VCO 的积分器，留下永久的频率误差 $\Delta\omega\,\omega_H/(\omega_H + K_{PD}K_{VCO})$，因此环路既不能锁定，也不能跟踪。
2. **它让不需要的信号通过。** 鉴相器的高频分量（位于 $\omega_{in}$ 或 $2\omega_{in}$ 处的纹波）不经衰减地到达 VCO，调制其频率，产生很大的纹波、边带和抖动。

**常见错误。** 只论证“鉴相器输出含有必须滤除的高频分量”。这只说明了为什么需要滤波器，而没有说明为什么必须是**低通**滤波器：高通滤波器所滤除的直流分量，正是锁定时决定 VCO 频率的量。

**常见错误。** 认为采用高通滤波器时环路仍能锁定，只是纹波更大或带宽不同。没有直流通路，VCO 的平均频率就无法离开 $\omega_0$，因此对于任何其他输入频率，环路都会失锁。

**常见错误。** 认为相位信息由鉴相器的高频分量携带。那些只是副产物；相位误差体现在平均值中。
