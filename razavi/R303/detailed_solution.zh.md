# 详细步骤 - R303

**思路。** 当 $\lambda = \gamma = 0$ 时，每个晶体管都只是一个受控电流源，理想电流源则相当于开路。输出端没有电阻性通路，其 KCL 把共栅器件 $M_1$ 的电流固定住，从而迫使 $v_X = 0$。再由 X 点的 KCL 可知，跟随器 $M_2$ 吸收输入电流，由此确定 $v_{out}$。用有限 $r_O$ 进行验证可以看出反馈是正反馈，这对稳定性有影响，但不影响理想的小信号结果。

### 第 1 步 — 小信号模型（small-signal model）

把输入节点（$R_S$ 右侧）记为 X。$M_1$（栅极接 $V_{b2}$，源极接 X，漏极接输出端）是从 X 到输出端的**共栅**级，$M_2$（漏极接 $V_{DD}$，栅极接输出端，源极接 X）是从输出端回到 X 的**源极跟随器**。二者都不反相，因此环路是**正反馈**。$V_{DD}$ 和 $V_{b2}$ 为交流地，$I_1$、$I_2$ 开路：

- **$M_1$：** $g_{m1}v_{gs1} = g_{m1}(0 - v_X)$，因此它把 $-g_{m1}v_X$ 从输出端送到 X。
- **$M_2$：** $g_{m2}v_{gs2} = g_{m2}(v_{out} - v_X)$，从 $V_{DD}$（交流地）流入 X。

设 $i_{in}$ 为经 $R_S$ 流入 X 的电流。

### 第 2 步 — 输出端的 KCL 迫使 $v_X = 0$

在输出端，$I_1$ 开路，$M_2$ 的栅极不吸取电流，因此唯一的信号电流是 $M_1$ 的电流：

$$-g_{m1}v_X = 0 \quad\Longrightarrow\quad v_X = 0, \qquad Z_{in} = \frac{v_X}{i_{in}} = 0 .$$

输出端没有电阻性通路，$M_1$ 的电流不能变化；而其栅极固定，因此其源极电压 $v_X$ 也不能变化。

### 第 3 步 — 由 X 点的 KCL 求输出电压

$i_{in}$ 从 $R_S$ 流入，$g_{m2}(v_{out} - v_X)$ 从 $M_2$ 流入，$-g_{m1}v_X$ 从 $M_1$ 流入；$I_2$ 开路：

$$i_{in} + g_{m2}(v_{out} - v_X) - g_{m1}v_X = 0 .$$

代入 $v_X = 0$：

$$
\begin{aligned}
i_{in} + g_{m2}v_{out} &= 0\\
v_{out} &= -\frac{i_{in}}{g_{m2}}.
\end{aligned}
$$

跟随器 $M_2$ 必须吸收输入电流，即向 X 注入的电流**减小**，因此其栅极（即输出端）**下降** $i_{in}/g_{m2}$。

### 第 4 步 — 传递函数

由于 $v_X = 0$，$i_{in} = (V_{in} - v_X)/R_S = V_{in}/R_S$，因此

$$\frac{V_{out}}{V_{in}} = -\frac{1}{g_{m2}R_S} .$$

### 第 5 步 — 有限 $r_O$：反馈为正反馈

加入 $r_{O1}$（接在输出端与 X 之间）和 $r_{O2}$（接在 $V_{DD}$ 与 X 之间）。输出端的 KCL（经 $M_1$ 和 $r_{O1}$ 流出的电流必须为零）：

$$-g_{m1}v_X + \frac{v_{out} - v_X}{r_{O1}} = 0 \quad\Longrightarrow\quad v_{out} = (1 + g_{m1}r_{O1})\,v_X .$$

正的 $v_X$ 产生**更大**的正 $v_{out}$，跟随器又把 X 进一步拉高：这就是正反馈。X 点的 KCL，其中从输出端经 $M_1$/$r_{O1}$ 流来的电流为零：

$$
\begin{aligned}
i_{in} + g_{m2}(v_{out} - v_X) - \frac{v_X}{r_{O2}} &= 0\\
i_{in} &= -g_{m2}\,g_{m1}r_{O1}\,v_X + \frac{v_X}{r_{O2}}\\
Z_{in} &= \frac{r_{O2}}{1 - g_{m1}g_{m2}r_{O1}r_{O2}} = -\frac{r_{O2}}{g_{m1}g_{m2}r_{O1}r_{O2} - 1}.
\end{aligned}
$$

由于 $g_{m1}g_{m2}r_{O1}r_{O2}\gg1$，这是一个很小的**负**电阻（negative resistance），约为 $-1/(g_{m1}g_{m2}r_{O1})$，当 $\lambda\to0$ 时趋于 $0^-$，与第 2 步一致。

**稳定性。** 对任何实际的 $R_S > |Z_{in}|$，从 X 到地的净电导 $1/R_S + 1/Z_{in}$ 都为负，因此只要 X 点有任何电容，该偏置点就不稳定，电路会发生锁定（latch）。上面的结果只是在假定偏置点上形式上的小信号解。

### 结果

$$Z_{in} = 0, \qquad \frac{V_{out}}{V_{in}} = -\frac{1}{g_{m2}R_S} .$$

输出端的 KCL（$I_1$ 理想，$M_2$ 无栅极电流）迫使共栅电流 $-g_{m1}v_X$ 为零，因此 $v_X = 0$。输入电流 $V_{in}/R_S$ 被跟随器 $M_2$ 吸收，得到 $v_{out} = -i_{in}/g_{m2}$。该环路是正反馈；若 $r_O$ 有限，输入电阻为 $-r_{O2}/(g_{m1}g_{m2}r_{O1}r_{O2} - 1)$，当 $\lambda\to0$ 时趋于 $0^-$，而这样的偏置点在实际中是不稳定的。

**常见错误。** 给出 $Z_{in} = 1/g_{m1}$（孤立共栅级的输入阻抗）或 $1/(g_{m1} + g_{m2})$（栅极固定时从两个器件源极看进去的阻抗）。$M_2$ 的栅极就是输出节点，其电阻为无穷大，因此环路迫使 $v_X = 0$。

**常见错误。** 给出增益 $g_{m1}/g_{m2}$ 或 $+1/(g_{m2}R_S)$。由于 $v_X = 0$，$M_1$ 不流过信号电流，$g_{m1}$ 不出现在结果中；跟随器必须吸收输入电流，因此其栅极下降，增益为负。

**常见错误。** 把 $M_2$ 误认为 PMOS 共源（common-source）器件（就像在某个相关电路中那样）。在本题中，它是漏极接 $V_{DD}$、源极接 X 的 NMOS 管，即跟随器。
