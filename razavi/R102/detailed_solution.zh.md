# 详细步骤 - R102

**思路。** 电压源 $V_X$ 决定 $M_2$ 的漏极电压，$M_2$ 的栅极位于接在 $V_{DD}$ 与 $V_X$ 之间的 $R_1$–$R_2$ 分压器抽头处，因此其栅极驱动是 $V_{DD} - V_X$ 的一个固定比例。先证明 $M_2$ 只要导通就处于饱和区，再求出它截止的位置；由于其平方律电流和流过 $R_1 + R_2$ 的电流都流入测试源，将二者相加即可。

### 第 1 步 — $M_2$ 的栅极驱动、工作区与截止

栅极没有电流，因此 $R_1$ 和 $R_2$ 对 $V_{DD} - V_X$ 分压：

$$I_R = \frac{V_{DD} - V_X}{R_1 + R_2}, \qquad V_{SG2} = I_RR_1 = (V_{DD} - V_X)\,\frac{R_1}{R_1 + R_2} .$$

源极和衬底都接 $V_{DD}$，因此没有体效应（body effect）。源漏电压是整个 $V_{DD} - V_X$，因此

$$V_{SD2} = V_{DD} - V_X \ge V_{SG2} > V_{SG2} - |V_{THP}| ,$$

$M_2$ 只要导通就处于饱和区，其电流为

$$I_{D2} = \frac12\beta_p\left[(V_{DD} - V_X)\frac{R_1}{R_1 + R_2} - 0.8\right]^2 .$$

当 $V_{SG2} > |V_{THP}| = 0.8$ V 时它导通：

$$
\begin{aligned}
(V_{DD} - V_X)\frac{R_1}{R_1 + R_2} &> 0.8\ \mathrm{V}\\
V_X &< V_{X1} = V_{DD} - 0.8\ \mathrm{V}\cdot\frac{R_1 + R_2}{R_1} .
\end{aligned}
$$

若 $3R_1/(R_1 + R_2) < 0.8$ V，则 $V_{X1} < 0$，$M_2$ 在整个扫描过程中都不导通。

### 第 2 步 — 各区域中的 $I_X$

漏极节点的基尔霍夫电流定律（KCL）方程如下，$M_2$ 的电流和分压器电流都流入测试源：

$$I_X = I_{D2} + \frac{V_{DD} - V_X}{R_1 + R_2} .$$

**$V_X < V_{X1}$（$M_2$ 导通，处于饱和区）：**

$$I_X = \frac{V_{DD} - V_X}{R_1 + R_2} + \frac12\beta_p\left[(V_{DD} - V_X)\frac{R_1}{R_1 + R_2} - 0.8\right]^2 ,$$

$$I_X(0) = \frac{3}{R_1 + R_2} + \frac12\beta_p\left[\frac{3R_1}{R_1 + R_2} - 0.8\right]^2 .$$

**斜率**，其中 $g_{m2} = \beta_p(V_{SG2} - 0.8)$：

$$\frac{dI_X}{dV_X} = -\frac{1}{R_1 + R_2} - \beta_p(V_{SG2} - 0.8)\frac{R_1}{R_1 + R_2} = -\frac{1 + g_{m2}R_1}{R_1 + R_2} .$$

$I_X$ 随 $V_X$ **减小**：在 $M_2$ 强导通处下降得很陡，随着 $g_{m2}$ 减小而变得平缓。（斜率的幅值就是这个“$V_{GS}$ 倍增器”二端电路的电导。）

**$V_{X1} \le V_X \le 3$ V（$M_2$ 截止）：**

$$I_X = \frac{3 - V_X}{R_1 + R_2} ,$$

这是一条直线，**在 $V_X = V_{DD}$ 处降为零**。

在 $V_X = V_{X1}$ 处，$I_{D2}$ 及其导数（与 $V_{SG2} - 0.8$ 成正比）都为零，因此曲线部分与直线**相切**衔接，没有折角。

### 第 3 步 — 数值示例

为便于说明，取 $R_1 = R_2 = 10\ \mathrm{k}\Omega$，$\beta_p = 2\ \mathrm{mA/V^2}$。于是 $V_{SG2} = (3 - V_X)/2$，且

$$V_{X1} = 3 - 0.8\times\frac{20}{10} = 1.4\ \mathrm{V}.$$

在 $V_X = 0$ 处：$I_R = 3\ \mathrm{V}/20\ \mathrm{k}\Omega = 0.15$ mA，$V_{SG2} = 1.5$ V，$I_{D2} = \frac12(2\ \mathrm{mA/V^2})(0.7\ \mathrm{V})^2 = 0.49$ mA，因此 $I_X = 0.64$ mA。

|---|---|---|---|---|
| 0 | 1.50 | 0.150 | 0.490 | 0.640 |
| 0.5 | 1.25 | 0.125 | 0.203 | 0.328 |
| 1.0 | 1.00 | 0.100 | 0.040 | 0.140 |
| 1.2 | 0.90 | 0.090 | 0.010 | 0.100 |
| 1.4 | 0.80 | 0.080 | 0 | 0.080 |

### 结果

$I_X$ **单调减小，并在 $V_X = V_{DD}$ 处降为零**：$M_2$ 导通时为二次项加线性项的形式；$M_2$ 在下式处截止后，为一条直线（只有电阻电流）：

$$V_{X1} = V_{DD} - 0.8\ \mathrm{V}\cdot\frac{R_1 + R_2}{R_1} .$$

- 栅极没有电流，因此栅极位于接在 $V_{DD}$ 与 $V_X$ 之间的 $R_1$–$R_2$ 分压抽头处：$V_{SG2} = (V_{DD} - V_X)R_1/(R_1 + R_2)$，$V_{SD2} = V_{DD} - V_X \ge V_{SG2}$。$M_2$ 只要导通就处于饱和区。
- **$V_X < V_{X1}$：** $I_X = \dfrac{V_{DD} - V_X}{R_1 + R_2} + \tfrac12\beta_p\left[(V_{DD} - V_X)\dfrac{R_1}{R_1 + R_2} - 0.8\right]^2$；在 $V_X = 0$ 处为 $3/(R_1 + R_2) + \tfrac12\beta_p[3R_1/(R_1 + R_2) - 0.8]^2$。
- **$V_{X1} \le V_X \le 3$ V：** $M_2$ 截止，$I_X = (3 - V_X)/(R_1 + R_2)$，这是一条在 $V_X = 3$ V 处降到零的直线。晶体管电流部分与它相切衔接（平方律）。
- 若 $3R_1/(R_1 + R_2) < 0.8$ V，$M_2$ 始终不导通，$I_X$ 在整个范围内都是电阻电流的直线。

**常见错误。** 漏掉电阻支路，以致 $M_2$ 一截止 $I_X$ 就降为零。分压器始终向电压源注入 $(V_{DD} - V_X)/(R_1 + R_2)$ 的电流。

**常见错误。** 把 $V_{SG2}$ 取为 $(V_{DD} - V_X)R_2/(R_1 + R_2)$，或取为整个 $V_{DD} - V_X$。$R_1$ 位于源极（$V_{DD}$）与栅极之间，因此 $V_{SG2}$ 是 $R_1$ 上的压降。

**常见错误。** 认为 $M_2$ 处于线性区（triode region）。它的 $V_{SD}$ 是整个 $V_{DD} - V_X$，总是不小于 $V_{SG2}$。
