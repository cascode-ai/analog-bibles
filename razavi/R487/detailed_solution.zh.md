# 详细步骤 - R487

**思路。** 压摆期间输入对完全切换，因此每个电容都由一个**固定**电流充电或放电，其电压以 $I/C$ 的斜率变化。在节点 X（第一级输出，$C_X$）和节点 Y（源极跟随器输出，$C_Y$）处应用基尔霍夫电流定律（KCL），求出每个节点在每个方向上可提供的最大电流，并对每个边沿取两级中较慢的一级。

### 第 1 步 — 节点 X：KCL 与两个极端电流

输入阶跃很大时，尾电流（tail current）$I_{SS} = 0.5$ mA 全部流过输入对中的一个晶体管。$M_4$ 的栅极不吸取电流，因此 X 处的 KCL（电流从 $M_3$ 流入，经 $M_2$ 流出）给出

$$C_X\frac{dV_X}{dt} = I_{D3} - I_{D2} = \frac{I_{SS}}{2} - I_{D2},$$

其中 $I_{D2}$ 的范围从 0（电流全部导向 $M_1$）到 $I_{SS}$（全部导向 $M_2$）。

**X 上升**（$M_2$ 截止，$I_{D2} = 0$）。只有 $M_3$ 的电流给 $C_X$ 充电：

$$\left.\frac{dV_X}{dt}\right|_{max} = \frac{I_{SS}/2}{C_X} = \frac{0.25\ \mathrm{mA}}{0.5\ \mathrm{pF}} = 0.5\times10^9\ \mathrm{V/s} = 0.5\ \mathrm{V/ns}.$$

**X 下降**（$I_{D2} = I_{SS}$）。$M_2$ 吸收 0.5 mA，而 $M_3$ 仍提供 0.25 mA：

$$\left.\frac{dV_X}{dt}\right|_{min} = \frac{I_{SS}/2 - I_{SS}}{C_X} = -\frac{0.25\ \mathrm{mA}}{0.5\ \mathrm{pF}} = -0.5\ \mathrm{V/ns}.$$

因此在情况 (i) 和 (ii) 中，节点 X 都以 $\pm(I_{SS}/2)/C_X = \pm0.5$ V/ns 对称地压摆，因为两种情况下都有 $C_X = 0.5$ pF。

### 第 2 步 — 节点 Y：源极跟随器能提供多大电流

Y 处的 KCL（电流从 $M_4$ 流入，经 $I_1$ 流出）：

$$C_Y\frac{dV_Y}{dt} = I_{D4} - I_1 .$$

**Y 上升。** X 上升时，$V_{GS4}$ 增大，$M_4$ 导通的电流超过 $I_1$，且不受任何偏置电流的限制，因此输出以 X 的速率跟随 X（斜坡期间 $V_{GS4}$ 略大）。上升沿只受节点 X 限制。

**Y 下降。** X 下降时，$I_{D4}$ 减小，但最多减小到零：$M_4$ 不能**吸收**电流。最快的下降速率由 $I_1$ 单独对 $C_Y$ 放电决定：

$$\left.\frac{dV_Y}{dt}\right|_{min} = -\frac{I_1}{C_Y}.$$

如果这一速率比 X 的下降速率慢，$M_4$ 就会截止，输出以 $I_1/C_Y$ 的速率下降：跟随器上拉能力很强，但下拉只能依靠其偏置电流。

### 第 3 步 — 情况 (i)：$C_X = C_Y = 0.5$ pF

输出端的下拉能力：

$$\frac{I_1}{C_Y} = \frac{0.5\ \mathrm{mA}}{0.5\ \mathrm{pF}} = 1\ \mathrm{V/ns}.$$

这超过了节点 X 的下降速率 0.5 V/ns，因此跟随器能够跟上。在以 0.5 V/ns 下降的斜坡期间，$M_4$ 仍流过

$$I_{D4} = I_1 + C_Y\frac{dV_Y}{dt} = 0.5\ \mathrm{mA} - (0.5\ \mathrm{pF})(0.5\ \mathrm{V/ns}) = 0.5 - 0.25 = 0.25\ \mathrm{mA} > 0,$$

因此它保持导通；在上升斜坡期间它流过 $0.5 + 0.25 = 0.75$ mA。

$$SR = 0.5\ \mathrm{V/ns} = 500\ \mathrm{V/\mu s}\ \text{ in both directions, limited at node X}.$$

### 第 4 步 — 情况 (ii)：$C_X = 0.5$ pF，$C_Y = 1.2$ pF

输出端的下拉能力：

$$\frac{I_1}{C_Y} = \frac{0.5\ \mathrm{mA}}{1.2\ \mathrm{pF}} = 0.417\times10^9\ \mathrm{V/s} = 0.42\ \mathrm{V/ns}.$$

**下降沿。** 此时 $0.42\ \mathrm{V/ns} < 0.5\ \mathrm{V/ns}$。要跟上 X，需要 $I_{D4} = 0.5\ \mathrm{mA} - (1.2\ \mathrm{pF})(0.5\ \mathrm{V/ns}) = 0.5 - 0.6 = -0.1$ mA，这是不可能的，因此 $M_4$ 截止，且

$$SR^- = \frac{I_1}{C_Y} \approx 0.42\ \mathrm{V/ns} = 417\ \mathrm{V/\mu s}.$$

**上升沿。** 仍受 X 限制：

$$SR^+ = \frac{I_{SS}/2}{C_X} = 0.5\ \mathrm{V/ns},$$

斜坡期间 $M_4$ 提供 $I_1 + C_Y(0.5\ \mathrm{V/ns}) = 0.5 + 0.6 = 1.1$ mA。

### 结果

| 情况 | 上升 SR | 下降 SR | 限制因素 |
|---|---|---|---|
| (i) $C_X = C_Y = 0.5$ pF | 0.5 V/ns | 0.5 V/ns | 节点 X：$(I_{SS}/2)/C_X$ |
| (ii) $C_X = 0.5$ pF, $C_Y = 1.2$ pF | 0.5 V/ns | ≈ 0.42 V/ns | 上升：节点 X；下降：输出端，$I_1/C_Y$ |

（0.5 V/ns = 500 V/µs；0.42 V/ns ≈ 417 V/µs。）

**常见错误。** 把节点 X 的限制取为 $I_{SS}/C_X = 1$ V/ns。X 上升时，只有 $M_3$ 的 $I_{SS}/2$ 给 $C_X$ 充电；X 下降时，$M_2$ 吸收 $I_{SS}$，但 $M_3$ 仍提供 $I_{SS}/2$，因此净电流同样是 $I_{SS}/2$。

**常见错误。** 在情况 (ii) 中忘记输出级，给出对称的 0.5 V/ns。跟随器只能靠偏置电流 $I_1$ 下拉输出，在 1.2 pF 负载下只有 0.42 V/ns，比节点 X 慢。

**常见错误。** 认为 $I_1/C_Y$ 限制的是**上升**沿，或认为它限制了情况 (i)。在上升沿 $M_4$ 只需导通更大的电流；而在情况 (i) 中 $I_1/C_Y = 1$ V/ns 比节点 X 更快。
