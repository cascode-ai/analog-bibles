# 详细步骤 - R556

**思路。** $S_2$ 断开时，只有 $I_1$ 流入晶体管，由此决定 $V_X$。$S_1$ 闭合时，运放的反相输入端与输出端相连，使其成为 $V_X$ 的单位增益跟随器。电容只是为下一个相位存储电荷。

### 第 1 步 — 该相位下的电路与 X 处的电压

把反相输入端节点称为 N；它经 $C_2$ 接地，并经 $C_1$ 和 $S_1$ 两者接到 $V_{out}$。在该相位：

- **$S_2$ 断开**，因此 $I_2$ 与 X 断开，流入 X 的唯一电流是 $I_1$。
- **$S_1$ 导通**，因此 N 与 $V_{out}$ 短接，$C_1$ 被短路。

理想运放的 + 输入端不吸取电流，因此 $I_1$ 全部流入 $Q_1$ 的发射极；忽略基极电流时，$I_C = I_1$。基极接地，因此

$$V_X = V_{EB1}(I_1) = V_T\ln\frac{I_1}{I_S}.$$

### 第 2 步 — 运放是单位增益跟随器

$S_1$ 闭合时，输出直接驱动反相输入端，反馈系数（feedback factor）为 1。理想运放迫使 $V_- = V_+ = V_X$，而 $V_{out} = V_-$，因此

$$V_{out} = V_X = V_T\ln\frac{I_1}{I_S}.$$

若增益 $A$ 有限，由 $V_{out} = A(V_X - V_{out})$ 得

$$V_{out} = \frac{A}{1 + A}V_X \;\to\; V_X \quad (A \to \infty).$$

### 第 3 步 — 两个电容的状态

- **$C_1$** 的两个极板接在同一节点上（N = $V_{out}$），因此其电压为零，也没有电荷。
- **$C_2$** 接在 N 与地之间，因此被充电到 $V_N = V_{out}$：
$$V_{C2} = V_{EB}(I_1) = V_T\ln\frac{I_1}{I_S}, \qquad Q_{C2} = C_2\,V_T\ln\frac{I_1}{I_S}.$$

稳态时两个电容中都没有电流，因此在该相位它们不影响直流输出：$C_2$ 记住了 $V_{EB}(I_1)$，而 $C_1$ 被复位。

### 第 4 步 — 该相位的意义（背景）

这是单结带隙基准的“采样”相位。在下一个相位（$S_1$ 断开，$S_2$ 导通），$Q_1$ 流过 $I_1 + I_2$，因此 $V_X$ 升高到 $V_{EB}(I_1 + I_2)$，而此时浮空的 N 保持其电荷不变：

$$C_2V_{EB}(I_1) = C_2V_X' + C_1(V_X' - V_{out}'),$$

其中 $V_X' = V_{EB}(I_1 + I_2)$，$V_{out}'$ 为新的输出。解出 $V_{out}'$：

$$V_{out}' = V_{EB}(I_1 + I_2) + \frac{C_2}{C_1}\,V_T\ln\left(1 + \frac{I_2}{I_1}\right):$$

即一个 $V_{EB}$ 加上一个被放大的与绝对温度成正比（PTAT）项，全部来自同一个结。当前相位为这一结果提供了参考电荷 $C_2V_{EB}(I_1)$。

### 结果

当 $S_1$ 导通、$S_2$ 断开时，运放是单位增益跟随器，$Q_1$ 只流过 $I_1$：

$$V_{out} = V_X = V_{EB1}(I_1) = V_T\ln\frac{I_1}{I_S}.$$

$C_1$ 上的电压为零，$C_2$ 被充电到 $V_{EB}(I_1)$。

**常见错误。** 使用 $V_{EB}(I_1 + I_2) = V_T\ln[(I_1 + I_2)/I_S]$。该相位中 $S_2$ 是断开的，因此只有 $I_1$ 流过 $Q_1$。

**常见错误。** 把 $C_1$ 和 $C_2$ 当作增益为 $1 + C_2/C_1$ 的电容反馈分压器，或者认为 $C_2$ 把反相输入端“拉”到地，从而 $V_{out} = 0$。$S_1$ 闭合时，$C_1$ 被短路，输出直接连到反相输入端，因此增益恰好为 1；$C_2$ 只是被充电到 $V_{out}$。

**常见错误。** 写成 $V_{out} = V_{EB}$ 而不说明是在哪个电流下。两个相位中 $V_{EB}$ 是在两个不同的电流下采样的，因此必须指明电流（这里是 $I_1$）。
