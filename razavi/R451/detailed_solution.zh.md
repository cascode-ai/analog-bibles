# 详细步骤 - R451

**思路。** 这一论证只看了 $r_{O2}$ 中的电流，但 $M_2$ 中还有与 $r_{O2}$ 并联的受控源 $g_{m2}v_{GS2}$。写出完整的小信号方程，求出真正的输出电阻（output resistance），并用数值说明受控源几乎完全抵消了 $r_{O2}$ 中的电流，因此流入漏极端的电流非常小。

### 第 1 步 — 完整写出 $M_2$ 的小信号模型（small-signal model）

$A_1$ 把 $V_X$（接在其“−”输入端）与固定的 $V_b$ 相比较，并驱动 $M_2$ 的栅极，因此

$$v_g = -A_1v_X .$$

$M_2$ 的小信号漏极电流（从漏极流向源极）由**两**部分组成：

$$i_{D2} = \underbrace{g_{m2}v_{GS2}}_{\text{controlled source}} + \underbrace{\frac{v_D - v_X}{r_{O2}}}_{\text{current in } r_{O2}} ,$$

其中 $v_{GS2} = v_g - v_X$。这里忽略了体效应（body effect），它只会在 $g_{m2}$ 上加上 $g_{mb2}$。错误的论证只保留了第二项。代入 $v_g = -A_1v_X$：

$$v_{GS2} = -A_1v_X - v_X = -(1 + A_1)\,v_X .$$

测试源 $v_t = \Delta V$ 驱动漏极；$r_{O2}$ 和 $g_{m2}(v_g - v_X)$ 都接在漏极与 X 之间，$r_{O1}$ 从 X 接到地。

### 第 2 步 — 节点 X 的 KCL：关键约束

$A_1$ 的输入端不吸取电流，因此流入漏极的全部电流都必须经 $r_{O1}$ 从 X 流出：

$$i = i_{D2} = \frac{v_X}{r_{O1}} \qquad\Longrightarrow\qquad v_X = i\,r_{O1}.$$

仅这一点就暴露了错误：端口电流为 $\Delta V_X/r_{O1}$，由于 $A_1$ 使 $\Delta V_X$ **非常小**，无论 $M_2$ 内部发生什么，端口电流都非常小。

### 第 3 步 — 输出电阻

代入 $v_{GS2} = -(1 + A_1)v_X$ 和 $v_X = ir_{O1}$，并令 $v_D = v_t$：

$$
\begin{aligned}
i &= -(1 + A_1)g_{m2}v_X + \frac{v_t - v_X}{r_{O2}}\\
i &= -(1 + A_1)g_{m2}r_{O1}\,i + \frac{v_t - r_{O1}i}{r_{O2}}\\
v_t &= i\left[r_{O1} + r_{O2} + (1 + A_1)g_{m2}r_{O1}r_{O2}\right].
\end{aligned}
$$

因此

$$R_{out} = \frac{v_t}{i} = r_{O1} + r_{O2} + (1 + A_1)g_{m2}r_{O1}r_{O2} \approx (1 + A_1)\,g_{m2}r_{O2}r_{O1}.$$

令 $A_1 = 0$ 即恢复为普通共源共栅结构的 $r_{O1} + r_{O2} + g_{m2}r_{O1}r_{O2}$：辅助放大器把输出电阻**乘以**约 $1 + A_1$。

### 第 4 步 — “$r_{O2}$ 中的大电流”去了哪里

该论证有一点是对的：X 几乎不变时，$\Delta V$ 几乎全部加在 $r_{O2}$ 上，因此其电流约为 $\Delta V/r_{O2}$。但为了保持 X 不变，一旦 X 开始升高，$A_1$ 就把栅极**拉低**，于是 $v_{GS2}$ 变为负值，受控源流过**方向相反**的电流：

$$g_{m2}v_{GS2} = -(1 + A_1)g_{m2}v_X = -(1 + A_1)g_{m2}r_{O1}\frac{v_t}{R_{out}} \approx -\frac{v_t}{r_{O2}} .$$

这两个电流在 $M_2$ 内部循环（向下流过 $r_{O2}$，再经受控源流回上方），永远不会到达端口；剩下的只有 $v_t/R_{out}$。

**数值示例**（示例取值 $g_{m2} = 1$ mS，$r_{O1} = r_{O2} = 50\ \mathrm{k}\Omega$，$A_1 = 50$，$\Delta V = 1$ V）：

| 物理量 | $A_1 = 50$ 时 | 普通共源共栅（$A_1 = 0$） |
|---|---|---|
| $R_{out}$ | 127.6 MΩ | 2.6 MΩ |
| $\Delta V_X$ | 0.39 mV | 19.2 mV |
| $r_{O2}$ 中的电流 | +19.99 μA | +19.62 μA |
| 受控源 $g_{m2}v_{GS2}$ | −19.98 μA | −19.23 μA |
| 端口净电流 $= \Delta V_X/r_{O1}$ | 0.0078 μA | 0.385 μA |

有 $A_1$ 时，$r_{O2}$ 中的电流确实略**大**一些，但端口电流约**小** 50 倍，因为受控源对它的抵消要精确得多。

### 结果

该论证把 $r_{O2}$ 中电流的变化等同于从输出端吸取的电流的变化，忽略了 $M_2$ 的受控源 $g_{m2}v_{GS2}$。漏极电压升高时，$A_1$ 降低栅极电压，因此 $g_{m2}v_{GS2}$ 的变化方向与 $r_{O2}$ 中的电流相反，几乎将其完全抵消。流过 $M_2$ 的净电流等于 $r_{O1}$ 中的电流 $\Delta V_X/r_{O1}$，正因为 $V_X$ 几乎保持不变，这一电流非常小。因此

$$R_{out} = r_{O1} + r_{O2} + (1 + A_1)g_{m2}r_{O1}r_{O2} \approx (1 + A_1)g_{m2}r_{O2}r_{O1},$$

即增益提升使输出阻抗**提高**约 $1 + A_1$ 倍，而不是把它降低到 $r_{O2}$。

**常见错误。** 接受 $R_{out} \approx r_{O2}$，或者断定增益提升会降低输出阻抗；而这一技术的全部目的恰恰是把输出阻抗提高约 $1 + A_1$ 倍。

**常见错误。** 声称 $V_X$ 实际上变化很大，以此来“修补”该论证。$\Delta V_X$ 比普通共源共栅结构中的值**小**约 $1 + A_1$ 倍；问题的答案在于受控源电流的抵消作用。

**常见错误。** 分析电流时把晶体管仅仅看作电阻 $r_{O2}$。其漏极电流中总是包含 $g_m v_{GS}$，而在反馈电路中这一项往往起主导作用。
