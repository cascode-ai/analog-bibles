# 详细步骤 - R330

**思路。** 把每段栅极电阻的噪声建模为一个串联电压源。由于没有栅极电流，每个噪声源都会使其后方**所有**单元晶体管的栅极电压变化相同的量，因此这些晶体管的漏极电流按幅值相加；不同电阻段的噪声相互独立，按功率相加。求和得到总的漏极噪声电流，再与单个集总栅极电阻产生的漏极噪声电流比较。

### 第 1 步 — 模型

设 $g_m$ 为整个晶体管的跨导，则 $n$ 个单元晶体管中每一个的跨导为

$$g_{m,u} = \frac{g_m}{n},$$

每个电阻段为

$$R_{G1} = R_{G2} = \dots = R_{Gn} = \frac{R_G}{n}.$$

把第 $k$ 个单元的栅极引出点记为节点 $g_k$。电阻段 $j$ 带有串联噪声电压 $V_j$，

$$\overline{V_j^2} = 4kT\frac{R_G}{n},$$

由于它们来自各自独立的电阻，各 $V_j$ **互不相关**：当 $i \ne j$ 时 $\overline{V_iV_j} = 0$。

G 由理想信号源驱动，因此对噪声而言它是交流地；忽略沟道噪声后，我们计算漏极的短路噪声电流（D 和 S 都接交流地）。这样每个单元就是接在 D 与 S 之间、受各自引出点电压控制的跨导 $(g_m/n)\,v_{g_k}$。下图给出 $n = 3$ 的情形。

### 第 2 步 — 各电阻段噪声源产生的栅极电压

在低频下没有栅极电流，因此任何电阻段上都没有 $IR$ 压降，每个引出点的电压就是 G 与该引出点之间所有噪声源之和：

$$
\begin{aligned}
v_{g_1} &= V_1,\\
v_{g_2} &= V_1 + V_2,\\
v_{g_3} &= V_1 + V_2 + V_3,\\
&\ \ \vdots\\
v_{g_k} &= \sum_{j=1}^{k}V_j .
\end{aligned}
$$

因此 $V_j$ 以相同的值出现在单元 $j, j+1, \dots, n$ 的栅极上，即作用于 $(n - j + 1)$ 个单元晶体管。电阻段 1（最靠近 G）影响全部 $n$ 个栅极，而电阻段 $n$ 只影响最后一个。

### 第 3 步 — 总的漏极噪声电流

在公共漏极处把各单元电流相加：

$$I_D = \sum_{k=1}^{n}\frac{g_m}{n}\,v_{g_k} = \frac{g_m}{n}\sum_{k=1}^{n}\sum_{j=1}^{k}V_j .$$

交换求和顺序，对于从 $j$ 到 $n$ 的每个 $k$，$V_j$ 都出现一次：

$$I_D = \frac{g_m}{n}\sum_{j=1}^{n}(n - j + 1)\,V_j .$$

由 $V_j$ 引起的 $(n - j + 1)$ 个单元电流是同一波形的副本，因此它们**完全相关**，按幅值相加：电阻段 $j$ 贡献的功率正比于 $(n-j+1)^2$，而不是 $(n-j+1)$。平方后取平均，$i\ne j$ 的交叉项 $\overline{V_iV_j}$ 都为零：

$$
\begin{aligned}
\overline{I_{n,D}^2} &= \left(\frac{g_m}{n}\right)^2\sum_{j=1}^{n}(n - j + 1)^2\,\overline{V_j^2}\\
&= \frac{g_m^2}{n^2}\cdot\frac{4kTR_G}{n}\sum_{j=1}^{n}(n - j + 1)^2 .
\end{aligned}
$$

令 $m = n - j + 1$，它从 $n$ 递减到 $1$，由平方和公式得

$$\sum_{j=1}^{n}(n - j + 1)^2 = \sum_{m=1}^{n}m^2 = \frac{n(n+1)(2n+1)}{6},$$

因此

$$
\begin{aligned}
\overline{I_{n,D}^2} &= \frac{4kTR_Gg_m^2}{n^3}\cdot\frac{n(n+1)(2n+1)}{6}\\
&= 4kTR_G\,g_m^2\,\frac{(n+1)(2n+1)}{6n^2}.
\end{aligned}
$$

### 第 4 步 — 等效集总电阻

与整个晶体管栅极串联的单个电阻 $R_{eq}$ 会把它全部的噪声电压加到栅极上，该电压的功率谱密度（power spectral density）为 $4kTR_{eq}$（同样没有栅极电流），因此

$$\overline{I_{n,D}^2}\Big|_{lumped} = g_m^2\cdot4kTR_{eq}.$$

令其与第 3 步的结果相等：

$$
\begin{aligned}
g_m^2\cdot4kTR_{eq} &= 4kTR_G\,g_m^2\,\frac{(n+1)(2n+1)}{6n^2}\\
R_{eq} &= R_G\,\frac{(n+1)(2n+1)}{6n^2} = R_G\,\frac{2n^2 + 3n + 1}{6n^2}\\
&= R_G\left(\frac13 + \frac{1}{2n} + \frac{1}{6n^2}\right).
\end{aligned}
$$

| $n$ | $R_{eq}/R_G$ |
|---|---|
| 1 | $2\cdot3/6 = 1$（单个晶体管看到全部 $R_G$，理应如此） |
| 2 | $3\cdot5/24 = 0.625$ |
| 10 | $11\cdot21/600 = 0.385$ |
| 100 | $101\cdot201/60000 = 0.338$ |
| $\infty$ | $1/3$ |

真正的分布式栅极对应于 $n \to \infty$ 的极限，此时 $1/(2n)$ 和 $1/(6n^2)$ 两项消失：

$$R_{eq} = \lim_{n\to\infty}R_G\left(\frac13 + \frac{1}{2n} + \frac{1}{6n^2}\right) = \frac{R_G}{3}. \qquad\blacksquare$$

### 第 5 步 — 用连续模型验证

设 $x \in [0, 1]$ 为沿栅极、从 G 起算的归一化位置。一小段 $dx$ 的电阻为 $R_G\,dx$，其噪声电压 $dV$ 的功率谱密度为 $4kTR_G\,dx$。它改变其后方占器件比例为 $(1 - x)$ 的那部分的栅极电压，这部分的跨导为 $g_m(1 - x)$，因此产生漏极电流 $g_m(1 - x)\,dV$。各小段互不相关，因此

$$
\begin{aligned}
\overline{I_{n,D}^2} &= \int_0^1 g_m^2(1 - x)^2\,4kTR_G\,dx\\
&= 4kTR_Gg_m^2\left[-\frac{(1 - x)^3}{3}\right]_0^1\\
&= 4kTR_Gg_m^2\cdot\frac13 .
\end{aligned}
$$

权重是二次的，即 $(1-x)^2$，因为受影响的电流正比于 $(1-x)$，而噪声功率正比于电流的平方；其平均值为 $1/3$，而不是 $(1-x)$ 的平均值 $1/2$。

### 结果

分为 $n$ 个相等的电阻段时，总的漏极噪声电流为

$$\overline{I_{n,D}^2} = 4kTR_G\,g_m^2\,\frac{(n+1)(2n+1)}{6n^2}\ \xrightarrow{\ n\to\infty\ }\ 4kT\,\frac{R_G}{3}\,g_m^2 ,$$

这恰好等于在整个晶体管的栅极串联单个集总电阻 $R_G/3$ 时的漏极噪声。因此，在计算栅极噪声时，分布式栅极电阻可以用 **$R_{eq} = R_G/3$** 代替。

**常见错误。** 把下游各单元晶体管的贡献按功率相加，即用 $(n - j + 1)$ 代替 $(n - j + 1)^2$。它们都由**同一个** $V_j$ 驱动，因此必须先把电流按幅值相加再平方；若把它们当作互不相关，会得到 $\overline{I_{n,D}^2} = 4kTR_Gg_m^2(n+1)/(2n^2)$，它在 $n \to \infty$ 时错误地趋于零。

**常见错误。** 以为“平均而言每段电阻影响半个器件”，从而得出 $R_{eq} = R_G/2$。漏极噪声**功率**取决于受影响比例的平方，其平均值为 $1/3$。
