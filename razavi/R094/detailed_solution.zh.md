# 详细步骤 - R094

**思路：** 这里输入器件是 PMOS $M_2$，而栅极接固定电压 $V_b$ 的 NMOS $M_1$ 是电流源负载；$R_D$ 与 $M_2$ 并联。列出输出节点的基尔霍夫电流定律（KCL）方程，并跟踪 $M_2$ 从线性区（$V_{in}$ 较小，强导通）经饱和区到 $V_{in} = V_{DD} - |V_{THP}|$ 处截止的过程，同时检查 $M_1$ 是否保持饱和。

### 第 1 步 — $M_1$ 的固定电流、$M_2$ 的工作区与 KCL

当 $M_1$ 处于饱和区（$V_{out} \ge V_b - 0.7$ V）时，它吸收恒定电流

$$I_1 = \frac12\beta_1(V_b - 0.7)^2 .$$

$M_2$ 的 $V_{SG2} = V_{DD} - V_{in} = 3 - V_{in}$，因此它在 $V_{in} < 2.2$ V 时导通，在 $V_{in} \ge V_{DD} - |V_{THP}| = 2.2$ V 时截止，其过驱动电压（overdrive voltage）为 $|V_{ov2}| = 2.2 - V_{in}$。当 $V_{SD2} \ge |V_{ov2}|$，即 $3 - V_{out} \ge 2.2 - V_{in}$ 或 $V_{out} \le V_{in} + 0.8$ V 时，它处于饱和区，否则处于线性区。

输出节点的 KCL（$R_D$ 和 $M_2$ 提供电流，$M_1$ 吸收电流）：

$$\frac{V_{DD} - V_{out}}{R_D} + I_{D2} = I_{D1} ,$$

$M_1$ 饱和时 $I_{D1} = I_1$。

### 第 2 步 — $V_{in}$ 较小：$M_2$ 处于线性区，$V_{out}$ 略低于 $V_{DD}$

在本题示例中，$V_{in}$ 较小时，$M_2$ 若处于饱和区，能提供远多于 $I_1$ 的电流，因此它稳定在线性区，$V_{SD2}$ 很小，相当于一个接在 $V_{DD}$ 与输出端之间的电阻 $R_{on2} \approx 1/[\beta_2(2.2 - V_{in})]$：

$$V_{out} \approx V_{DD} - I_1\,(R_{on2}\|R_D),$$

略低于 $V_{DD}$，此时 $M_1$ 显然处于饱和区。

斜率： $M_1$ 对小信号而言相当于开路，因此

$$\frac{dV_{out}}{dV_{in}} = -g_{m2}\,(R_D\|r_{ds2}),$$

其中在线性区，$g_{m2} = \beta_2V_{SD2}$ 和 $r_{ds2} = 1/[\beta_2(2.2 - V_{in} - V_{SD2})]$ 都很小。因此 $V_{out}$ 只是缓慢下降，并随着 $R_{on2}$ 和 $V_{SD2}$ 随 $V_{in}$ 增大而加快。

### 第 3 步 — $M_2$ 饱和：陡峭的下降区

在饱和区，

$$
\begin{aligned}
\frac{V_{DD} - V_{out}}{R_D} + \frac12\beta_2(2.2 - V_{in})^2 &= I_1\\
V_{out} &= V_{DD} - R_D\left[I_1 - \tfrac12\beta_2(2.2 - V_{in})^2\right].
\end{aligned}
$$

转折点： 令上式等于 $V_{in} + 0.8$，并记 $y = 2.2 - V_{in} = |V_{ov2}|$，得 $y = R_D[I_1 - \frac12\beta_2y^2]$，即

$$\tfrac12\beta_2R_Dy^2 + y - R_DI_1 = 0 \quad\Longrightarrow\quad y = \frac{-1 + \sqrt{1 + 2\beta_2R_D^2I_1}}{\beta_2R_D}, \qquad V_{in} = 2.2 - y .$$

斜率：

$$\frac{dV_{out}}{dV_{in}} = R_D\cdot\frac{d}{dV_{in}}\left[\tfrac12\beta_2(2.2 - V_{in})^2\right] = -R_D\,\beta_2(2.2 - V_{in}) = -g_{m2}R_D ,$$

其中 $g_{m2} = \beta_2(2.2 - V_{in})$。斜率在该区域开始处最陡（过驱动电压最大），并在 $V_{in} \to 2.2$ V 时变平直至为零，此时 $g_{m2}$ 消失。

### 第 4 步 — $V_{in} \ge 2.2$ V：$M_2$ 截止，平坦的底部

$M_1$ 的电流全部由 $R_D$ 提供：

$$V_{out} = V_{DD} - I_1R_D\qquad (V_{in} \ge 2.2\ \mathrm{V}),$$

它一直保持不变直到 $V_{in} = 3$ V，并且不是 0 V，因为 $R_D$ 仍把输出端连到 $V_{DD}$。

这里假设 $M_1$ 保持饱和，即 $V_{DD} - I_1R_D \ge V_b - 0.7$。若 $I_1R_D$ 更大，$M_1$ 会在下降过程中进入线性区，下降变得平缓，底部电平由下式的解给出：

$$\frac{V_{DD} - V_{out}}{R_D} = \beta_1\left[(V_b - 0.7)V_{out} - \tfrac12V_{out}^2\right],$$

它低于 $V_b - 0.7$ V，但仍大于 0。

### 第 5 步 — 数值示例

为便于说明，取 $V_b = 1.0$ V，$\beta_1 = 2\ \mathrm{mA/V^2}$，$\beta_2 = 1\ \mathrm{mA/V^2}$，$R_D = 20\ \mathrm{k}\Omega$：

$$
\begin{aligned}
I_1 &= \tfrac12(2\ \mathrm{mA/V^2})(1.0 - 0.7)^2\ \mathrm{V^2} = 90\ \mu\mathrm{A},\\
V_{out,floor} &= 3 - (90\ \mu\mathrm{A})(20\ \mathrm{k}\Omega) = 3 - 1.8 = 1.2\ \mathrm{V},
\end{aligned}
$$

高于 $V_b - 0.7 = 0.3$ V，因此 $M_1$ 始终保持饱和。

$M_2$ 进入饱和区的位置：$\beta_2R_D = 20\ \mathrm{V^{-1}}$，$2\beta_2R_D^2I_1 = 2(1\ \mathrm{mA/V^2})(20\ \mathrm{k}\Omega)^2(90\ \mu\mathrm{A}) = 72$：

$$y = \frac{-1 + \sqrt{73}}{20} = \frac{-1 + 8.544}{20} = 0.377\ \mathrm{V}, \qquad V_{in} = 2.2 - 0.377 = 1.823\ \mathrm{V}, \qquad V_{out} = 2.623\ \mathrm{V},$$

该处的斜率为 $-g_{m2}R_D = -(1\ \mathrm{mA/V^2})(0.377\ \mathrm{V})(20\ \mathrm{k}\Omega) = -7.5$。

### 核对工作区假设

令 $a=V_b-0.7\ \mathrm V$。当输出 $v<a$ 时，NMOS 电流 $I_{D1}(v)$ 取线性区式 $\beta_1(av-v^2/2)$，达到或超过 $a$ 时取常数 $I_1$。若第 3 步试算的 PMOS 边界给出 $V_{out}<a$，改用 $I_{D1}(V_{DD}-y)=y/R_D+\beta_2y^2/2$，并要求 $0<y\le2.2\ \mathrm V$。若在此范围无根，PMOS 可能在扫描开始时已饱和。检验 $M_1$ 进入线性区的条件时，将 $v=a$ 代入 KCL，得 $|I_{D2}(y,V_{DD}-a)|=I_1-(V_{DD}-a)/R_D$，再使用满足工作区判据的 PMOS 电流式。

若平台处 NMOS 在线性区，电平低于 $a$，并高于用饱和电流 $I_1$ 外推得到的值，因为进入线性区后下拉电流减小。同一节点方程也给出 2.2 V 截止及其后的水平段。

### 结果

这是由 PMOS $M_2$ 驱动的反相特性，其中 $I_1 = \tfrac12\beta_1(V_b - 0.7)^2$：

- $V_{in}$ 较小时： $M_2$ 的 $V_{SG} = 3 - V_{in}$ 很大，能够提供多于 $I_1$ 的电流，因此它处于线性区，$V_{SD}$ 很小。$V_{out}$ 略低于 $V_{DD}$，并随 $V_{in}$ 升高而缓慢下降。$M_1$（电流源）处于饱和区。
- 一旦 $V_{out} < V_{in} + 0.8$ V，$M_2$ 进入饱和区：$V_{out} = V_{DD} - R_D[I_1 - \tfrac12\beta_2(2.2 - V_{in})^2]$，斜率为 $-g_{m2}R_D$，其中 $g_{m2} = \beta_2(2.2 - V_{in})$；斜率在该区域开始处最陡，当 $V_{in} \to 2.2$ V 时趋于平缓。
- 若 $V_{out}$ 降到 $V_b - 0.7$ V 以下，$M_1$ 进入线性区，下降变得平缓。
- $V_{in} \ge 2.2$ V： $M_2$ 截止，$V_{out} = V_{DD} - I_1R_D$（若该值高于 $V_b - 0.7$ V；否则由 $R_D$ 和处于线性区的 $M_1$ 共同决定），并一直保持不变直到 $V_{in} = 3$ V。
- 转折点： $M_2$ 在 $V_{out} = V_{in} + 0.8$ V 处发生线性区/饱和区转换；$M_1$ 可能在 $V_{out} = V_b - 0.7$ V 处进入线性区；$M_2$ 在 $V_{in} = V_{DD} - |V_{THP}| = 2.2$ V 处截止。

**常见错误：** 把 $M_1$ 当作输入器件，或者画出同相的曲线。输入驱动的是 PMOS $M_2$；提高 $V_{in}$ 会减小 $V_{SG2}$，因此 $M_2$ 提供的电流减小，$V_{out}$ 下降。

**常见错误：** 认为 $M_2$ 一旦截止，$V_{out}$ 就降到 0 V。$R_D$ 仍把输出端连到 $V_{DD}$，因此输出稳定在 $V_{DD} - I_1R_D$（若该值会低于 $V_b - 0.7$ V，则稳定在受线性区限制的值）。

**常见错误：** 把 $M_2$ 的截止点放在 $V_{in} = 0.8$ V 或 3 V 处。源极接 $V_{DD}$ 的 PMOS 在 $V_{in} = 3 - 0.8 = 2.2$ V 处截止。
