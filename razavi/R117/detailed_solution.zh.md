# 详细步骤 - R117

**思路。** 输出取自 $M_2$ 的**源极**，因此 $M_2$ 是源极跟随器，其负载为二极管连接的 NMOS $M_1$，漏极接二极管连接的 PMOS $M_3$（而不是交流地）。把每个二极管连接器件替换为它的小信号电阻，求出流过整个串联支路的唯一电流，再乘以源极电阻即可。

### 第 1 步 — 小信号模型（small-signal model）与支路电流

二极管连接晶体管满足 $v_{gs} = v_{ds}$，因此它就是电阻 $\frac{1}{g_m}\parallel r_O$。把 $M_2$ 的漏极记为节点 $D$，$V_{DD}$ 为交流地，且 $\gamma = 0$：

$$R_S = \frac{1}{g_{m1}}\,\Big\|\,r_{O1} = \frac{r_{O1}}{1 + g_{m1}r_{O1}}\quad(\text{from out to ground}),$$

$$R_D = \frac{1}{g_{m3}}\,\Big\|\,r_{O3} = \frac{r_{O3}}{1 + g_{m3}r_{O3}}\quad(\text{from } D \text{ to ac ground}).$$

$M_2$ 的 $v_{gs2} = v_{in} - v_{out}$：受控源 $g_{m2}(v_{in} - v_{out})$ 从 $D$（漏极）流向 out（源极），$r_{O2}$ 接在 $D$ 与 out 之间。

<!-- diagram: diagram-01.cir -->

同一小信号电流 $i$ 向下流过 $R_D$、$M_2$ 和 $R_S$（以**向下**为正）：

$$v_{out} = iR_S, \qquad v_D = -iR_D \quad\big(i = (0 - v_D)/R_D\big),$$

$$i = g_{m2}(v_{in} - v_{out}) + \frac{v_D - v_{out}}{r_{O2}}.$$

### 第 2 步 — 求解增益

代入 $v_{out} = iR_S$ 和 $v_D = -iR_D$：

$$i = g_{m2}v_{in} - g_{m2}R_S\,i + \frac{-iR_D - iR_S}{r_{O2}}.$$

合并含 $i$ 的项，再乘以 $r_{O2}$：

$$i\left(1 + g_{m2}R_S + \frac{R_D + R_S}{r_{O2}}\right) = g_{m2}v_{in},$$

$$i\,(r_{O2} + R_D + R_S + g_{m2}r_{O2}R_S) = g_{m2}r_{O2}\,v_{in}.$$

再由 $v_{out} = iR_S$ 得

$$A_v = \frac{v_{out}}{v_{in}} = \frac{g_{m2}r_{O2}R_S}{r_{O2} + R_D + R_S + g_{m2}r_{O2}R_S},\qquad R_S = \frac{1}{g_{m1}}\,\Big\|\,r_{O1},\quad R_D = \frac{1}{g_{m3}}\,\Big\|\,r_{O3}.$$

分母等于分子再加上若干正项，因此 $0 < A_v < 1$，这正是跟随器应有的特性。

**验证。** 若没有 $M_3$（漏极接交流地，$R_D = 0$），将分子和分母同除以 $r_{O2} + R_S$，
$$\frac{g_{m2}r_{O2}R_S}{r_{O2} + R_S + g_{m2}r_{O2}R_S} = \frac{g_{m2}(r_{O2}\parallel R_S)}{1 + g_{m2}(r_{O2}\parallel R_S)},$$
这正是负载为 $R_S \parallel r_{O2}$ 的源极跟随器的标准结果。✓ 增加的 $R_D$ 使增益略有降低：$M_2$ 的漏极与源极反向变化，从而使 $v_{ds2}$ 以及流过 $r_{O2}$ 的电流减小。

### 第 3 步 — 完全展开形式（选读）

代入 $R_S = r_{O1}/(1 + g_{m1}r_{O1})$ 和 $R_D = r_{O3}/(1 + g_{m3}r_{O3})$，并将分子和分母同乘 $(1 + g_{m1}r_{O1})(1 + g_{m3}r_{O3})$。分子变为

$$g_{m2}r_{O2}r_{O1}(1 + g_{m3}r_{O3}),$$

分母变为

$$
\begin{aligned}
&r_{O2}(1 + g_{m1}r_{O1})(1 + g_{m3}r_{O3}) + r_{O3}(1 + g_{m1}r_{O1}) + r_{O1}(1 + g_{m2}r_{O2})(1 + g_{m3}r_{O3})\\
&= r_{O1} + r_{O2} + r_{O3} + g_{m1}r_{O1}r_{O2} + g_{m1}r_{O1}r_{O3} + g_{m2}r_{O1}r_{O2} + g_{m3}r_{O1}r_{O3} + g_{m3}r_{O2}r_{O3} + (g_{m1} + g_{m2})g_{m3}r_{O1}r_{O2}r_{O3} \equiv D.
\end{aligned}
$$

所以

$$A_v = \frac{g_{m2}r_{O1}r_{O2}(1 + g_{m3}r_{O3})}{D}.$$

$D$ 与在 $M_2$ 的漏极取该串联支路的输出时的分母相同：支路电流不变，改变的只是把它转换为输出电压的那个电阻。

### 第 4 步 — 大 $r_O$ 近似与直观理解

若每个器件都满足 $g_mr_O \gg 1$，则 $R_S \approx 1/g_{m1}$，$R_D \approx 1/g_{m3}$，且 $R_D + R_S$ 相对于 $r_{O2}$ 可以忽略。分子分母同除以 $r_{O2}$，并略去 $(R_D + R_S)/r_{O2}$：

$$A_v \approx \frac{g_{m2}R_S}{1 + g_{m2}R_S} \approx \frac{g_{m2}/g_{m1}}{1 + g_{m2}/g_{m1}} = \frac{g_{m2}}{g_{m1} + g_{m2}}.$$

**直观理解。** 输入电压在从 $M_2$ 源极看进去的电阻 $1/g_{m2}$ 与负载 $1/g_{m1}$ 之间分压：

$$A_v \approx \frac{1/g_{m1}}{1/g_{m1} + 1/g_{m2}} = \frac{g_{m2}}{g_{m1} + g_{m2}},$$

当 $g_{m1} = g_{m2}$ 时约为 $1/2$。$M_3$ 只通过 $r_{O2}$ 产生影响，因此在一阶近似下可以不计。

### 结果

$$A_v = \frac{g_{m2}r_{O2}R_S}{r_{O2} + R_D + R_S + g_{m2}r_{O2}R_S},\qquad R_S = \frac{1}{g_{m1}}\,\Big\|\,r_{O1},\quad R_D = \frac{1}{g_{m3}}\,\Big\|\,r_{O3},$$

等价地，$A_v = g_{m2}r_{O1}r_{O2}(1 + g_{m3}r_{O3})/D$，其中 $D$ 见第 3 步。增益为正且小于 1。当 $r_O$ 很大时：

$$A_v \approx \frac{g_{m2}}{g_{m1} + g_{m2}}.$$

**常见错误。** 从 $M_2$ 的漏极取输出，得出反相增益。输出端是 $M_2$ 的源极（与二极管连接的 $M_1$ 共用），因此 $v_{out}$ 跟随 $v_{in}$ 变化，但变化量小于 $v_{in}$。

**常见错误。** 像带电流源（current source）负载的跟随器那样，得出接近（甚至大于）1 的增益。二极管连接负载 $1/g_{m1}$ 与 $1/g_{m2}$ 相当，因此输入电压中有很大一部分落在 $v_{gs2}$ 上。

**常见错误。** 不加说明就把 $M_2$ 的漏极当作交流地。由于 $\lambda \neq 0$，漏极电压会变化（$v_D = -iR_D$），只有在明确声明为近似时才可以略去 $R_D$。
