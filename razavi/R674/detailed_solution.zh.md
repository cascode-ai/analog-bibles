# 详细步骤 - R674

**思路。** 在稳态下，同一漏极电流流过沟道的每个横截面，它等于单位长度的电荷乘以载流子速度。由于速度在 $v_{sat}$ 处饱和，电荷永远不可能为零。然后说明平方律中“夹断点处电荷为零”只是缓变沟道近似的假象，并描述夹断点与漏极之间发生的情况。

### 第 1 步 — 沿沟道的电流连续性

令 $x$ 从源极（$x = 0$）指向漏极（$x = L$），$Q_d(x)$ 为单位面积的可动电荷，$v(x)$ 为载流子速度，则

$$I_D = W\,Q_d(x)\,v(x)$$

在每个 $x$ 处都相同（稳态下电荷不会堆积），因此

$$Q_d(x) = \frac{I_D}{W\,v(x)}.$$

### 第 2 步 — 有限的速度迫使电荷不为零

在高电场下，散射把硅中电子的速度限制在 $v_{sat} \approx 10^7$ cm/s，因此由 $v(x) \le v_{sat}$ 得：

$$Q_d(x) = \frac{I_D}{W\,v(x)} \;\ge\; \frac{I_D}{W\,v_{sat}} > 0 .$$

若某点电荷为零，就需要该处速度为**无限大**才能输运有限的电流。只要有电流流过，可动电荷可以变小，但永远不会为零。

**数值示例。** $I_D = 100\ \mu$A，$W = 10\ \mu\mathrm{m} = 10^{-3}$ cm：

$$Q_{d,min} = \frac{10^{-4}\ \mathrm{A}}{(10^{-3}\ \mathrm{cm})(10^7\ \mathrm{cm/s})} = 10^{-8}\ \mathrm{C/cm^2} \;\approx\; \frac{10^{-8}}{1.6\times10^{-19}} = 6\times10^{10}\ \text{electrons/cm}^2 .$$

在源端，取 $t_{ox} = 5$ nm（$C_{ox} = 6.9\times10^{-7}\ \mathrm{F/cm^2}$），过驱动电压（overdrive voltage）为 0.3 V，则 $Q_d = C_{ox}V_{ov} = 2.1\times10^{-7}\ \mathrm{C/cm^2}$。因此在“夹断”点处，电荷降到源端值的约 5 %，而不是零。

### 第 3 步 — 平方律为何预测电荷为零

**缓变沟道近似**假设纵向电场占主导，因此局部电荷由局部的栅–沟道电压决定，

$$Q_d(x) = C_{ox}\,[V_{GS} - V(x) - V_{TH}],$$

而电流纯粹是漂移电流，$I_D = W\,Q_d(x)\,\mu\,dV/dx$。在饱和区（saturation region），该电荷在 $V(x) = V_{GS} - V_{TH}$ 处降为零。但在那里横向电场

$$E(x) = \frac{dV}{dx} = \frac{I_D}{W\,\mu\,Q_d(x)} \;\to\; \infty\quad\text{as } Q_d \to 0 .$$

（在饱和边缘，$V(x) = V_{ov}(1 - \sqrt{1 - x/L})$，$E = V_{ov}/(2L\sqrt{1 - x/L})$，它在 $x = L$ 处发散。）无限大的横向电场与横向电场很小的假设相矛盾，因此零电荷点只是一种假象。该近似还忽略了漏极附近的二维静电效应、扩散电流以及速度饱和（velocity saturation），而正是速度饱和决定了第 2 步中的最小电荷。计入这些因素后，反型沟道漏端附近的电荷会变小，但仍保持有限。

### 第 4 步 — 夹断点之外发生了什么

当 $V_{DS} > V_{GS} - V_{TH}$ 时，栅–沟道电压降到 $V_{TH}$ 的那一点向源极移动，移到 $L - \Delta L$ 处。

- **漏极附近没有强反型层。** 在 $L - \Delta L$ 与 $L$ 之间，栅–沟道电压低于阈值，因此这一小段区域实质上是一个耗尽区，即漏–衬底结的延伸。
- **横向电场非常高。** 反型沟道上的压降约为 $V_{GS} - V_{TH}$；其余的 $V_{DS} - (V_{GS} - V_{TH})$ 降落在很短的距离 $\Delta L$ 上。
- **载流子被扫入漏极。** 到达反型沟道末端的电子以（接近）$v_{sat}$ 的速度运动，离开表面向硅体内扩散开，并被扫入漏极，就像到达反向偏置结耗尽区边缘的载流子一样：该区域不会阻挡电流，而是把到达的载流子全部输运过去。

因此电流在夹断时**不会**停止；它由反型沟道每秒向夹断点输送多少载流子决定。

### 第 5 步 — 结果：饱和与沟道长度调制

**饱和。** 反型沟道的长度为 $L - \Delta L$，其上的电压为 $V_{GS} - V_{TH}$，与 $V_{DS}$ 无关：

$$I_D \approx \frac12\,\mu C_{ox}\,\frac{W}{L - \Delta L}\,(V_{GS} - V_{TH})^2 .$$

提高 $V_{DS}$ 只会增加夹断区上的电压，因此 $I_D$（几乎）与 $V_{DS}$ 无关。

**沟道长度调制。** $\Delta L$ 随 $V_{DS}$ 增大，因此有效沟道变短，电流略有增大。当 $\Delta L \ll L$ 时，

$$\frac{1}{L - \Delta L} = \frac{1}{L}\cdot\frac{1}{1 - \Delta L/L} \approx \frac{1}{L}\left(1 + \frac{\Delta L}{L}\right),$$

再利用 $\Delta L/L \approx \lambda V_{DS}$，得

$$I_D \approx \frac12\,\mu C_{ox}\,\frac{W}{L}\,(V_{GS} - V_{TH})^2\,(1 + \lambda V_{DS}),$$

这使饱和区器件具有有限的输出电阻（output resistance）$r_O = 1/(\lambda I_D)$。

### 结果

- 可动电荷不可能恰好降为零，因为电流 $I_D = WQ_d(x)v(x)$ 在沟道每一点都必须相同，而载流子速度是有限的（$v \le v_{sat} \approx 10^7$ cm/s）。因此 $Q_d \ge I_D/(Wv_{sat}) > 0$。平方律中零电荷的“夹断”只是缓变沟道近似的假象，该近似在那里失效（它需要无限大的横向电场和速度）。
- 夹断点之外是一段长度为 $\Delta L$ 的短小、耗尽、高电场区域，栅极在那里无法维持反型层。到达那里的少量载流子以（接近）饱和速度运动，离开表面扩散开并被扫入漏极，这与反向偏置结中的情况非常相似。电流由沟道的反型部分决定，因此会饱和；又由于 $\Delta L$ 随 $V_{DS}$ 增大，有效长度变短，$I_D$ 略有增大：这就是沟道长度调制和有限的 $r_O$。

**常见错误。** 认为沟道一旦“夹断”，就没有载流子能到达漏极，因此电流停止。夹断点之外的高电场区会把每一个到达的载流子送到漏极，这正是电流饱和而不是消失的原因。

**常见错误。** 照字面接受夹断点处 $Q_d = 0$ 的结论。电荷为零而电流不为零，就需要无限大的载流子速度；这一结果只说明缓变沟道近似在漏极附近失效。
