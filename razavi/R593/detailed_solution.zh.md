# 详细步骤 - R593

**思路。** 从两幅图中读出输出共模电平 $V_{out,CM} = (V_{out1} + V_{out2})/2$ 随差分输入如何变化。共模反馈环路迫使它所**检测**到的量等于参考值，因此如果检测到的量不是真正的平均值，环路调节的就是错误的量。一种常见的非线性检测电路（共用一个电流源的源极跟随器）大致检测的是**较大**的那个输出，这恰好产生 [图 2] 中的曲线。

### 第 1 步 — 两幅图对共模电平说明了什么

**[图 1]。** $V_{out1}$ 和 $V_{out2}$ 关于一条水平线互为镜像，并在上、下电平的正中间交叉，因此 $V_{out1} + V_{out2}$ 为常数：共模电平固定，每个输出围绕它等幅摆动。

**[图 2]。** 两条曲线在靠近**顶部**处交叉。当 $V_{in} < 0$ 时，$V_{out1}$ 保持在上限电平附近，而 $V_{out2}$ 一直向下摆动；当 $V_{in} > 0$ 时，两者的角色互换。因此共模电平**不是恒定的**：它在 $V_{in} = 0$ 时最高，并随 $|V_{in}|$ 增大而下降。电路保持近似恒定的是**较大**的那个输出，而不是平均值。差模特性并无异常；反常之处完全在共模上，因此原因在于共模反馈。

### 第 2 步 — 共模反馈环路调节的是什么

共模反馈检测一个用来代表 $V_{out,CM}$ 的电压 $V_{sense}$，将其与 $V_{REF}$ 比较，并调节负载（或尾）电流，使两个输出同时移动。在环路增益（loop gain）很高时，它稳定在

$$V_{sense} = V_{REF}.$$

线性平均 $V_{sense} = (V_{out1} + V_{out2})/2 + \text{const}$ 会固定共模电平，得到 [图 1]。任何其他依赖关系仍然给出 $V_{sense} = V_{REF}$，但此时共模电平会随差分摆幅变化。

### 第 3 步 — 非线性检测电路：共用一个电流源的源极跟随器

检测共模电平的一种简单方法是：用 $V_{out1}$ 和 $V_{out2}$ 分别驱动两个源极跟随器 $M_7$、$M_8$，把它们的源极接到**同一个**电流源 $I_S$ 上，再把公共源极节点 S 与 $V_{REF}$ 比较；误差放大器驱动 PMOS 负载管的栅极。

<!-- diagram: diagram-01.cir -->

$M_7$ 和 $M_8$ 构成一个共享 $I_S$ 的源极耦合对（source-coupled pair）。利用 $I_D = \tfrac{\beta}{2}V_{ov}^2$（$\beta = \mu_nC_{ox}W/L$），定义两管的过驱动电压（overdrive voltage）

$$a = V_{out1} - V_S - V_{TH}, \qquad b = V_{out2} - V_S - V_{TH}.$$

**两个跟随器都导通时：**

$$
\begin{aligned}
\tfrac{\beta}{2}a^2 + \tfrac{\beta}{2}b^2 &= I_S \;\Rightarrow\; a^2 + b^2 = \frac{2I_S}{\beta},\\
a - b &= V_{out1} - V_{out2} \equiv \Delta,\\
(a + b)^2 &= 2(a^2 + b^2) - (a - b)^2 = \frac{4I_S}{\beta} - \Delta^2 .
\end{aligned}
$$

由于 $a + b = 2(V_{out,CM} - V_S - V_{TH})$：

$$V_{out,CM} = V_S + V_{TH} + \sqrt{\frac{I_S}{\beta} - \frac{\Delta^2}{4}} .$$

**一个跟随器截止时。** 当 $|\Delta| \ge \sqrt{2I_S/\beta}$ 时，由较低输出驱动的跟随器截止，另一个承载全部 $I_S$：

$$V_S = \max(V_{out1}, V_{out2}) - V_{GS}(I_S), \qquad V_{GS}(I_S) = V_{TH} + \sqrt{2I_S/\beta}.$$

较低的输出不再影响 $V_S$：该电路是一个**最大值检测器**，而不是求平均电路。

### 第 4 步 — 闭合环路后得到 [图 2]

共模反馈迫使 $V_S = V_{REF}$。

**平衡点附近**（两个跟随器都导通）：

$$V_{out,CM} = V_{REF} + V_{TH} + \sqrt{\frac{I_S}{\beta} - \frac{\Delta^2}{4}},$$

它在 $\Delta = 0$ 时最大，并**随差分摆幅增大而减小**。较高的输出 $V_{out,CM} + |\Delta|/2$ 只是缓慢上升，而较低的输出 $V_{out,CM} - |\Delta|/2$ 则陡峭下降。

**大摆幅**（一个跟随器截止）：

$$\max(V_{out1}, V_{out2}) = V_{REF} + V_{TH} + \sqrt{2I_S/\beta} = \text{constant}.$$

较高的输出被钳定在这个平台上，而由于差分对（differential pair）仍然施加差值 $\Delta$，**全部摆幅都出现在较低的输出上**，它一直下降，直到输入管进入线性区（即底部电平）。

**交叉点。** 在 $V_{in} = 0$ 时每个跟随器流过 $I_S/2$，因此

$$V_{out1} = V_{out2} = V_{REF} + V_{TH} + \sqrt{I_S/\beta} = V_{REF} + V_{GS}(I_S/2),$$

而平台为 $V_{REF} + V_{GS}(I_S)$。交叉点略低于上方平台，差值为 $(\sqrt2 - 1)\sqrt{I_S/\beta} \approx 0.41$ 乘以跟随器在 $I_S/2$ 下的过驱动电压：两个输出恰好在顶部下方交叉，一个输出保持在高电平，另一个承担摆幅，与 [图 2] 完全一致。简而言之，公共源极节点跟随较高的栅极，因此环路调节的是较高的输出，根本“看不到”较低的输出。

### 第 5 步 — 为什么设计良好的共模反馈得到 [图 1]

良好的共模反馈在整个摆幅范围内检测的都是真正的平均值：用两个电阻从 $V_{out1}$ 和 $V_{out2}$ 接到一个恰好处于 $(V_{out1} + V_{out2})/2$ 的公共节点，在开关电容（switched-capacitor）共模反馈中则用两个电容；或者采用各自带**独立**电流源的源极跟随器（$V_{GS}$ 恒定），后接电阻平均网络。这样环路把平均值保持在参考值，两个输出对称摆动，交叉点位于正中间，如 [图 1] 所示。

只要检测器件超出其线性范围，其他检测方案也会产生类似的误差（例如，把每个输出与 $V_{REF}$ 比较的差分对在大摆幅下会发生限幅）。另一种外观相似的失效是共模反馈的校正范围已经用尽，使得平衡时负载提供的电流大于 $I_{SS}/2$，把两个输出都推到上限；此时只有输入管吸取电流大于负载电流的那一侧才能向下移动。

### 第 6 步 — 后果

- **摆幅不对称且电压余量（headroom）不足：** 较低的输出提供全部差分摆幅，在平衡点一侧的移动距离约为 [图 1] 情形的两倍；而且平衡时两个输出都接近上限，使负载管几乎没有电压余量。
- **共模电平随信号变化：** $V_{out,CM}$ 随 $\Delta^2$ 变化，可能扰乱下一级的偏置。
- **失真：** 每个单端输出都严重不对称，即含有偶次失真；在匹配不理想时，其中一部分会出现在差分输出中。

### 结果

在 [图 2] 中，输出共模电平没有保持恒定：它在 $V_{in} = 0$ 时最高，并随差分摆幅增大而下降，因为较大的输出停留在一个固定的上限电平附近，而较小的输出承担了全部摆幅。当共模反馈**以非线性方式检测输出共模电平**时就会出现这种情况。典型例子是共用一个电流源的一对源极跟随器：在大摆幅下，由较高输出驱动的跟随器吸走全部电流，因此检测到的电压跟踪的是 $\max(V_{out1}, V_{out2}) - V_{GS}$，而不是平均值。迫使这个检测值等于参考电压，就把较高的输出钳定住了，而较低的输出承担全部摆幅。（按平方律，两个跟随器都导通时 $V_{out,CM} = V_S + V_{TH} + \sqrt{I_S/\beta - (V_{out1} - V_{out2})^2/4}$。）采用线性平均（电阻、电容，或带独立电流源的跟随器）的共模反馈能保持平均值固定，得到 [图 1]。

**常见错误。** 把 [图 2] 归因于差模效应，如较高的差分增益、输入失调或正反馈。这些因素会改变转变区的**斜率**或**位置**，但两个输出仍然关于一个固定的共模电平对称；只有共模环路才能解释共模电平的移动。

**常见错误。** 以为任何共模反馈都能保持**平均**输出恒定。环路只调节它所检测到的量；对于源极耦合的检测对管（或任何超出线性范围工作的检测器件），这个量实际上就是较大的那个输出。
