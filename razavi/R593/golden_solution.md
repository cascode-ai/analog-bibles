# Golden Solution - R593

## Reference answer

In [Fig. 2] the two outputs cross near the top. At balance both outputs sit close to (slightly below) the upper level, and for large $|V_{in}|$ one output stays at that level while only the other falls. The output CM level is thus not constant: it is highest at $V_{in} = 0$ and drops as the differential swing grows.

Typical cause: the CMFB senses the output CM with a nonlinear circuit that does not compute the true average for large differential swings. The typical case is a pair of source followers sharing one current source, or other MOS sense devices with square-law behavior or a limited linear range.
- With source followers sharing a tail, a large swing makes the follower driven by the higher output take all the current. The sensed voltage then tracks max($V_{out1}$, $V_{out2}$) − $V_{GS}$ instead of the average.
- The CMFB loop forces this sensed value to the reference, so the higher output is pinned at (reference + level shift) and the whole differential swing appears on the lower output. At balance each follower carries half the current, so its $V_{GS}$ is smaller and the crossing sits slightly below that upper plateau: $V_0 = V_S + V_{GS}(I/2)$ versus $V_H = V_S + V_{GS}(I)$. In square law, with both followers on, $V_{CM} = V_S + V_{TH} + \sqrt{I/\beta - (V_{out1} - V_{out2})^2/4}$ (with $I_D = \tfrac{\beta}{2}V_{ov}^2$), which falls as the swing grows.
- Other CMFB failures can give a similar curve, e.g. a CMFB whose correction range is exhausted so that the loads source more than $I_{SS}/2$ at balance: both outputs are then pushed to the upper limit (loads in triode) and only the side whose input device takes more than the load current falls. This is a valid alternative explanation if argued consistently.
- With linear sensing (resistors or capacitors averaging the two outputs, as in a well-designed CMFB), the average is held constant and the outputs swing symmetrically about the CM level, giving [Fig. 1].
- Consequences: reduced output swing, a signal-dependent CM level, and even-order distortion.
