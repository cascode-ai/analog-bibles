# 详细步骤 - R197

**思路。** 电路对称而输入是差分的，因此采用**差分半边电路**：尾节点 P 和 $R_1$ 的中点都是虚地，每个输出端看到的是二极管连接负载（$1/g_{m3}$）、$r_{O1}$、$r_{O3}$ 和半个 $R_1$ 的并联。对输出端应用基尔霍夫电流定律（KCL）即可得到增益，并用直接的双节点分析加以验证。

### 第 1 步 — 半边电路的小信号模型（small-signal model）

把左输出端（$M_1$、$M_3$ 的漏极）记为 X，右输出端记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P，并施加 $v_{in1} = +v_d/2$、$v_{in2} = -v_d/2$，其中 $v_d = v_{in1} - v_{in2}$。由对称性 $v_Y = -v_X$，因此 P 是虚地，$R_1$ 的中点也是虚地：对差分信号而言，$R_1$ 分成两个 $R_1/2$，各自从一个输出端接到交流地。

于是左半边电路在 X 点处包含：

- **$M_1$：** 栅极为 $v_d/2$，源极接地，从 X 抽取 $g_{m1}v_d/2$，并有 $r_{O1}$ 从 X 接地；
- **$M_3$（二极管连接）：** 电阻 $1/g_{m3}$ 与 $r_{O3}$ 并联；
- **半个 $R_1$：** $R_1/2$ 从 X 接地。

体效应（body effect）不起作用：$M_3$/$M_4$ 的源极接 $V_{DD}$，即接在其衬底（bulk）上；$M_1$/$M_2$ 的源极则位于虚地 P。

### 第 2 步 — X 点的 KCL 与增益

流出 X 的电流之和为零：

$$g_{m1}\frac{v_d}{2} + g_{m3}v_X + \frac{v_X}{r_{O1}} + \frac{v_X}{r_{O3}} + \frac{v_X}{R_1/2} = 0 .$$

解出 $v_X$：

$$v_X = -\frac{g_{m1}}{g_{m3} + \dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} + \dfrac{2}{R_1}}\cdot\frac{v_d}{2}.$$

由对称性 $v_Y = -v_X$，因此 $v_{out} = v_X - v_Y = 2v_X$：

$$A_v = \frac{v_{out}}{v_{in1} - v_{in2}} = -\frac{g_{m1}}{g_{m3} + \dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} + \dfrac{2}{R_1}} = -g_{m1}\left(\frac{1}{g_{m3}}\Big\|\,r_{O1}\Big\|\,r_{O3}\Big\|\,\frac{R_1}{2}\right).$$

### 第 3 步 — 用直接的双节点分析验证

令 $v_P = 0$，$G = g_{m3} + 1/r_{O1} + 1/r_{O3}$（每个输出端到交流地的电导，不含 $R_1$），对完整电路的 X 点和 Y 点列 KCL：

$$g_{m1}\frac{v_d}{2} + Gv_X + \frac{v_X - v_Y}{R_1} = 0, \qquad -g_{m1}\frac{v_d}{2} + Gv_Y + \frac{v_Y - v_X}{R_1} = 0 .$$

第一式减去第二式：

$$
\begin{aligned}
g_{m1}v_d + G(v_X - v_Y) + \frac{2(v_X - v_Y)}{R_1} &= 0\\
\frac{v_X - v_Y}{v_d} &= -\frac{g_{m1}}{g_{m3} + \dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} + \dfrac{2}{R_1}} ,
\end{aligned}
$$

结果相同。$R_1$ 以 $2/R_1$ 的形式出现，因为流过它的电流正比于 $v_X - v_Y = 2v_X$，是它从 X 接地时电流的两倍。

### 第 4 步 — 物理解释与数值感受

由于 $g_{m3} \gg 1/r_O$，没有 $R_1$ 时增益接近 $g_{m1}/g_{m3}$，即我们熟悉的二极管负载增益；$R_1$ 在每边增加了 $R_1/2$ 的负载，使增益进一步降低。例如，取 $g_{m1} = 1$ mS，$g_{m3} = 0.5$ mS，$r_{O1} = r_{O3} = 50\ \mathrm{k}\Omega$，$R_1 = 4\ \mathrm{k}\Omega$：

$$
\begin{aligned}
g_{m3} + \frac{1}{r_{O1}} + \frac{1}{r_{O3}} + \frac{2}{R_1} &= 0.5 + 0.02 + 0.02 + 0.5 = 1.04\ \mathrm{mS},\\
A_v &= -\frac{1\ \mathrm{mS}}{1.04\ \mathrm{mS}} = -0.96 .
\end{aligned}
$$

若没有 $R_1$，同样的器件将给出 $-1/0.54 = -1.85$。

### 结果

$$A_v = \frac{V_{out}}{V_{in1} - V_{in2}} = -g_{m1}\left(\frac{1}{g_{m3}}\Big\|\,r_{O1}\Big\|\,r_{O3}\Big\|\,\frac{R_1}{2}\right) = -\frac{g_{m1}}{g_{m3} + 1/r_{O1} + 1/r_{O3} + 2/R_1}.$$

在半边电路中，P 和 $R_1$ 的中点都是虚地，因此每个输出端看到的是二极管连接的 $M_3$（$1/g_{m3}\parallel r_{O3}$）、$r_{O1}$ 和 $R_1/2$。

**常见错误。** 在并联组合中用 $R_1$ 代替 $R_1/2$。$R_1$ 连接的两个节点反向变化，因此其中点是虚地，每个输出端只看到它的一半。

**常见错误。** 把 $M_3$/$M_4$ 当作电流源（current source），只保留 $r_{O3}$，从而得到 $-g_{m1}(r_{O1}\parallel r_{O3}\parallel R_1/2)$。每个负载都是二极管连接的，提供很小的电阻 $1/g_{m3}$，它通常起主导作用。

**常见错误。** 漏掉某个输出电阻（output resistance），或者把 $R_1$ 与负载串联。$r_{O1}$、$r_{O3}$、$1/g_{m3}$ 和 $R_1/2$ 都是从 X 接到交流地，彼此并联。
