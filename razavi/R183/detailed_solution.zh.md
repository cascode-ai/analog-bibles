# 详细步骤 - R183

**思路。** $M_3$ 和 $M_4$ 是**带源极负反馈的 PMOS 电流源**，而不是电阻负载，每个最多只能提供电流 $I_P$；由于 $\lambda = 0$，它们的输出电阻（output resistance）为无穷大，因此平衡点处的增益极大。输入共模电平保持在 1.5 V，所以 $V_{out}$ 关于 $V_{in1} = 1.5$ V 奇对称。用平方律（square law）让 $V_{in1}$ 从 0 到 1.5 V 逐个区域进行分析，由对称性得到另一半曲线，再用一个示例设计给曲线标上数值。

### 第 1 步 — 扫描方式及其对称性

把左输出端（$M_1$、$M_3$ 的漏极）记为 X，右输出端（$M_2$、$M_4$ 的漏极）记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P，则 $V_{out} = V_X - V_Y$。由于 $V_{in2} = 3\ \mathrm{V} - V_{in1}$，

$$V_{in,CM} = \frac{V_{in1} + V_{in2}}{2} = \frac{3\ \mathrm{V}}{2} = 1.5\ \mathrm{V}\quad\text{(constant)}, \qquad V_{in1} - V_{in2} = 2V_{in1} - 3\ \mathrm{V},$$

因此输入是纯差分的。把 $V_{in1}$ 换成 $3\ \mathrm{V} - V_{in1}$ 相当于交换两个输入，在对称电路中这就交换了 $V_X$ 和 $V_Y$：

$$V_{out}(3\ \mathrm{V} - V_{in1}) = -V_{out}(V_{in1}).$$

所以 $V_{out}$ **关于 $V_{in1} = 1.5$ V 奇对称**，$V_{out}(1.5\ \mathrm{V}) = 0$，只需分析 $0 \le V_{in1} \le 1.5$ V 的范围即可。

### 第 2 步 — 带源极负反馈的 PMOS 负载能提供多大电流

由于 $V_{S3} = V_{DD} - I_{D3}R_1$，$M_3$ 的饱和电流满足

$$I_{D3} = \tfrac12\mu_pC_{ox}\left(\frac WL\right)_3\left(V_{DD} - I_{D3}R_1 - V_{b2} - |V_{THP}|\right)^2 .$$

其唯一解记为 $I_P$，它只取决于 $V_{b2}$、$R_1$ 和 $M_3$ 的尺寸，而与漏极电压无关（$\lambda = 0$）；$M_4$ 饱和时也提供同样的 $I_P$。只要 $V_{SD3} \ge V_{SG3} - |V_{THP}|$，$M_3$ 就处于饱和区，即

$$V_X \le V_{b2} + |V_{THP}| = V_{b2} + 0.8\ \mathrm{V}.$$

因此，当 $V_X \le V_{b2} + 0.8$ V 时，负载是一个理想电流源 $I_P$；高于此值时，负载处于线性区，电流小于 $I_P$；只有在 $V_X = V_{S3} = V_{DD}$（$R_1$ 上没有压降）时，其电流才为零。它的小信号输出电阻就是带源极负反馈器件的输出电阻，

$$R_{up} = R_1 + r_{O3}(1 + g_{m3}R_1),$$

在 $\lambda = 0$ 时它为无穷大：$R_1$ 使负载成为更理想的电流源；它**不是**负载电阻。

**标称设计。** 选择偏置，使每个负载提供一半的尾电流，即 $2I_P = I_{SS}$（否则会有什么变化，见第 8 步）。

**示例设计（尺寸可自由选取）。** 取 $\beta_n = \mu_nC_{ox}(W/L)_{1,2} = 2\ \mathrm{mA/V^2}$；$V_{b1} = 1.0$ V，$\mu_nC_{ox}(W/L)_5 = 4.44\ \mathrm{mA/V^2}$；$R_1 = R_2 = 5\ \mathrm{k}\Omega$，$V_{b2} = 1.4$ V，$\beta_p = \mu_pC_{ox}(W/L)_{3,4} = 2.22\ \mathrm{mA/V^2}$。于是：

$$
\begin{aligned}
I_{SS} &= \tfrac12(4.44\ \mathrm{mA/V^2})(1.0 - 0.7)^2\ \mathrm{V^2} = \tfrac12(4.44\ \mathrm{mA/V^2})(0.09\ \mathrm{V^2}) = 200\ \mu\mathrm{A},\\
\text{try } I_P = 100\ \mu\mathrm{A}:\quad V_{S3} &= 3\ \mathrm{V} - (100\ \mu\mathrm{A})(5\ \mathrm{k}\Omega) = 2.5\ \mathrm{V},\\
V_{SG3} - |V_{THP}| &= 2.5 - 1.4 - 0.8 = 0.3\ \mathrm{V},\\
\tfrac12\beta_p(0.3\ \mathrm{V})^2 &= \tfrac12(2.22\ \mathrm{mA/V^2})(0.09\ \mathrm{V^2}) = 100\ \mu\mathrm{A}.\ \checkmark
\end{aligned}
$$

所以 $I_P = 100\ \mu$A，$2I_P = I_{SS}$，负载的饱和边界为 $V_{b2} + 0.8 = 2.2$ V。

### 第 3 步 — $V_{in1}$ 较低：$M_1$ 截止，$V_{out}$ 接近 $+V_{DD}$

取 $V_{in1} = 0$，$V_{in2} = 3$ V。

**左侧。** $V_{GS1} = 0 - V_P \le 0 < V_{THN}$，因此 $M_1$ 截止；对 X 点应用基尔霍夫电流定律（KCL），得 $I_{D3} = I_{D1} = 0$。于是 $R_1$ 上没有压降（$V_{S3} = V_{DD}$），$M_3$ 的沟道虽然导通（$V_{SG3} = 3 - 1.4 = 1.6\ \mathrm{V} > 0.8$ V），却没有电流流过，因此 $V_{SD3} = 0$：

$$V_X = V_{DD} = 3\ \mathrm{V}.$$

**右侧。** $M_2$ 想要流过全部 $I_{SS}$，但 Y 点的 KCL 把它限制为 $I_{D2} = I_{D4} \le I_P = I_{SS}/2$。所以 Y 被拉低：$M_2$ 进入线性区；又因为尾电流必须减小到 $I_P$，$M_5$ 也退出饱和区（$V_P < V_{b1} - V_{THN}$）。$M_4$ 保持饱和（其漏极远低于 2.2 V），提供 $I_P$。最终状态是 $M_2$ 和 $M_5$ 都处于线性区，各自流过 $I_P$，而 $V_Y = V_{DS5} + V_{DS2}$ 只有零点几伏；把这个电平记为 $V_{low}$。

**数值计算。** $M_5$ 处于线性区，且 $V_{DS5} = V_P$：

$$
\begin{aligned}
100\ \mu\mathrm{A} &= (4.44\ \mathrm{mA/V^2})\left[0.3V_P - \tfrac12V_P^2\right]\\
0.0225 &= 0.3V_P - 0.5V_P^2\\
V_P^2 - 0.6V_P + 0.045 &= 0\\
V_P &= 0.3 - \sqrt{0.09 - 0.045} = 0.3 - 0.212 = 0.088\ \mathrm{V}.
\end{aligned}
$$

（另一个根 0.512 V 超过了 $V_{b1} - V_{THN} = 0.3$ V，不是线性区的解。）一般地，处于线性区、过驱动电压（overdrive voltage）为 $V_{ov}$、电流为 $I$ 的器件满足 $I = \beta\left(V_{ov}V_{DS} - V_{DS}^2/2\right)$，其有效根为 $V_{DS} = V_{ov} - \sqrt{V_{ov}^2 - 2I/\beta}$；下文将反复用到这一结果。对于处于线性区的 $M_2$，$V_{ov2} = V_{in2} - V_P - V_{THN} = 3 - 0.088 - 0.7 = 2.212$ V，并且

$$
\begin{aligned}
100\ \mu\mathrm{A} &= (2\ \mathrm{mA/V^2})\left[2.212V_{DS2} - \tfrac12V_{DS2}^2\right]\\
V_{DS2}^2 - 4.424V_{DS2} + 0.1 &= 0\\
V_{DS2} &= 2.212 - \sqrt{2.212^2 - 0.1} = 2.212 - 2.189 = 0.023\ \mathrm{V}.
\end{aligned}
$$

$$
\begin{aligned}
V_Y &= V_P + V_{DS2} = 0.088 + 0.023 = 0.111\ \mathrm{V},\\
V_{out} &= V_X - V_Y = 3 - 0.111 = +2.89\ \mathrm{V}.
\end{aligned}
$$

在这一区域内，随着 $V_{in1}$ 上升，$V_{in2}$ 下降，于是 $V_{ov2}$ 减小，$V_{DS2}$ 略有增大（$V_{in1} = 0.79$ V 时 $V_Y = 0.123$ V）：$V_{out}$ 几乎保持平坦，约为 $V_{DD} - V_{low} \approx 2.88$–$2.89$ V。当 $V_{GS1} = V_{in1} - V_P$ 达到 $V_{THN}$ 时，$M_1$ 导通：

$$V_{in1} = V_P + V_{THN} = 0.088 + 0.7 \approx 0.79\ \mathrm{V}.$$

### 第 4 步 — $M_1$ 导通：正电平下垂

当 $V_{in1} > 0.79$ V 时，$M_1$ 流过电流 $I_{D1}$；由于其漏极 X 的电位很高，它处于饱和区。

- **节点 X。** $M_3$ 必须恰好提供 $I_{D1} < I_P$，因此它处于线性区（$V_X > V_{b2} + 0.8$ V）。随着 $I_{D1}$ 增大，$V_X$ 从 $V_{DD}$ 向饱和边缘 $V_{b2} + |V_{THP}| = 2.2$ V 下降。
- **节点 Y。** $M_4$ 仍然饱和，因此 $I_{D2} = I_P$。尾电流 $I_{D5} = I_{D1} + I_P$ 增大，于是 $M_5$ 脱离深线性区，$V_P$ 上升，$V_Y = V_P + V_{DS2}$ 也随之上升。
- **区域终点。** 当 $I_{D1} = I_P$ 时，这一区域结束。此时 $I_{D5} = 2I_P = I_{SS}$，$M_5$ 恰好处于饱和边缘，$V_P = V_{b1} - V_{THN} = 0.3$ V。$M_1$ 饱和且电流为 $I_P$，因此：

$$
\begin{aligned}
V_{ov,P} &= \sqrt{\frac{2I_P}{\beta_n}} = \sqrt{\frac{2(100\ \mu\mathrm{A})}{2\ \mathrm{mA/V^2}}} = \sqrt{0.1}\ \mathrm{V} = 0.316\ \mathrm{V},\\
V_{in1} &= V_P + V_{THN} + V_{ov,P} = 0.3 + 0.7 + 0.316 = 1.316\ \mathrm{V}.
\end{aligned}
$$

**计算一个点：$V_{in1} = 1.0$ V**（$V_{in2} = 2.0$ V）。未知量为 $V_P$ 和 $I_{D1}$，由 P 点的 KCL（$M_5$ 处于线性区）和 $M_1$ 饱和这两个条件求出：

$$I_{D1} + 100\ \mu\mathrm{A} = (4.44\ \mathrm{mA/V^2})\left[0.3V_P - \tfrac12V_P^2\right], \qquad I_{D1} = \tfrac12(2\ \mathrm{mA/V^2})(1.0 - V_P - 0.7)^2 .$$

求解（例如对 $V_P$ 逐个试值）得 $V_P = 0.124$ V。验证：

$$
\begin{aligned}
I_{D1} &= (1\ \mathrm{mA/V^2})(0.176\ \mathrm{V})^2 = 31.0\ \mu\mathrm{A},\\
(4.44\ \mathrm{mA/V^2})[0.3(0.124) - 0.5(0.124)^2] &= (4.44\ \mathrm{mA/V^2})(0.0295\ \mathrm{V^2}) = 131\ \mu\mathrm{A} = 31 + 100\ \mu\mathrm{A}.\ \checkmark
\end{aligned}
$$

$M_3$ 处于线性区，电流为 31 µA：

$$
\begin{aligned}
V_{S3} &= 3 - (31\ \mu\mathrm{A})(5\ \mathrm{k}\Omega) = 2.845\ \mathrm{V},\\
V_{SG3} - |V_{THP}| &= 2.845 - 1.4 - 0.8 = 0.645\ \mathrm{V},\\
31\ \mu\mathrm{A} &= (2.22\ \mathrm{mA/V^2})\left[0.645V_{SD3} - \tfrac12V_{SD3}^2\right]\\
V_{SD3} &= 0.645 - \sqrt{0.645^2 - \frac{2(31\ \mu\mathrm{A})}{2.22\ \mathrm{mA/V^2}}} = 0.645 - \sqrt{0.416 - 0.028} = 0.645 - 0.623 = 0.022\ \mathrm{V},\\
V_X &= 2.845 - 0.022 = 2.823\ \mathrm{V}.
\end{aligned}
$$

$M_2$ 处于线性区，电流为 100 µA，且 $V_{ov2} = 2.0 - 0.124 - 0.7 = 1.176$ V：

$$
\begin{aligned}
V_{DS2} &= 1.176 - \sqrt{1.176^2 - 0.1} = 1.176 - 1.133 = 0.043\ \mathrm{V},\\
V_Y &= 0.124 + 0.043 = 0.167\ \mathrm{V},\\
V_{out} &= 2.823 - 0.167 = +2.66\ \mathrm{V}.
\end{aligned}
$$

### 第 5 步 — 从 $V_{in1} \approx 1.32$ V 到平衡点

此时 $I_{D1} = I_{D2} = I_P$，$M_5$ 饱和（$I_{D5} = I_{SS} = 2I_P$）。两个输入器件电流相等，但 $V_{GS2} > V_{GS1}$，因此它们不可能都饱和：$M_2$ 处于线性区（它较小的 $V_{DS}$ 抵消了较大的 $V_{GS}$），而饱和的 $M_1$ 决定了尾节点的电压，

$$V_P = V_{in1} - V_{THN} - V_{ov,P}.$$

**节点 Y** 由 $M_2$ 的线性区方程求出。当 $V_{in1} = 1.4$ V 时：

$$
\begin{aligned}
V_P &= 1.4 - 0.7 - 0.316 = 0.384\ \mathrm{V},\\
V_{ov2} &= 1.6 - 0.384 - 0.7 = 0.516\ \mathrm{V},\\
V_{DS2} &= 0.516 - \sqrt{0.516^2 - 0.1} = 0.516 - 0.408 = 0.108\ \mathrm{V},\\
V_Y &= 0.384 + 0.108 = 0.492\ \mathrm{V}.
\end{aligned}
$$

当 $V_{in1}\to1.5$ V 时，$M_2$ 趋近其饱和边缘，$V_Y \to V_{in2} - V_{THN} = 0.8$ V。

**节点 X。** 在 $\lambda = 0$ 时，$M_3$ 和 $M_1$ 是两个数值同为 $I_P$ 的理想电流源串联，仅靠平方律无法确定 $V_X$，而任何微小的输出电导（output conductance）都能确定它。$V_Y$ 远低于 $V_X$，因此 $M_4$ 的 $V_{SD}$ 较大，提供的电流略大于 $M_3$。由于尾电流固定，$M_1$ 得到的电流就略小于 $M_3$ 所提供的电流，于是 $V_X$ 上升，直到 $M_3$ 刚好进入线性区：

$$V_X \approx V_{b2} + |V_{THP}| = 2.2\ \mathrm{V}.$$

所以在这一范围内 $V_{out} \approx 2.2 - V_Y$，它从约 1.83 V 下降到约 $2.2 - 0.8 = 1.4$ V。

### 第 6 步 — 平衡点处：（几乎）垂直的过零

在 $V_{in1} = V_{in2} = 1.5$ V 处，五个晶体管都处于饱和区，且 $I_{D1} = I_{D2} = I_{SS}/2 = I_P$。对于小的差分输入，P 点是虚地（virtual ground），因此每半边都是一个共源级（common-source stage）：$M_1$ 以第 2 步中带源极负反馈的 PMOS 为负载：

<!-- diagram: diagram-01.cir -->

节点 X 处注入的电流为 $g_{m1}v_{in,d}/2$，它对交流地的电阻为 $r_{O1}$ 与 $R_{up}$ 的并联：

$$R_{out} = r_{O1}\parallel\left[R_1 + r_{O3}(1 + g_{m3}R_1)\right], \qquad v_X = -g_{m1}R_{out}\frac{v_{in,d}}{2}.$$

另一半边的输入为 $-v_{in,d}/2$，因此 $v_Y = +g_{m1}R_{out}v_{in,d}/2$，且

$$A_v = \frac{v_X - v_Y}{v_{in,d}} = -g_{m1}R_{out}, \qquad v_{in,d} = v_{in1} - v_{in2}.$$

由于 $V_{in1} - V_{in2} = 2V_{in1} - 3$ V，所画曲线的斜率为

$$\frac{dV_{out}}{dV_{in1}} = 2A_v = -2g_{m1}R_{out}.$$

在 $\lambda = 0$ 时，$r_{O1} = r_{O3} = \infty$，所以 $R_{out} = \infty$，斜率为无穷大。曲线在 $V_{in1} = 1.5$ V 处**垂直**穿过 $V_{out} = 0$，在本例中从约 $+1.4$ V 变到约 $-1.4$ V：两个输出节点都只与电流源相连，因此任何电流不平衡都会使节点电压一直变化下去，直到某个晶体管退出饱和区为止。

**若取实际的 $\lambda$**（例如在 100 µA 下取 0.1 V⁻¹）：$r_O = 100\ \mathrm{k}\Omega$，$g_{m1} = \sqrt{2\beta_nI_P} = 0.632$ mS，$g_{m3} = \sqrt{2\beta_pI_P} = 0.667$ mS。于是

$$
\begin{aligned}
R_{up} &= 5\ \mathrm{k}\Omega + (100\ \mathrm{k}\Omega)(1 + 3.33) = 438\ \mathrm{k}\Omega,\\
R_{out} &= 100\ \mathrm{k}\Omega\parallel438\ \mathrm{k}\Omega = 81\ \mathrm{k}\Omega,\\
|A_v| &= (0.632\ \mathrm{mS})(81\ \mathrm{k}\Omega) \approx 51 .
\end{aligned}
$$

此时斜率约为 100 V/V，因此 ±1.4 V 的摆幅仍发生在 1.5 V 附近约 ±14 mV 的范围内，在 0–3 V 的坐标轴上看起来就是垂直的。

### 第 7 步 — $V_{in1} > 1.5$ V：镜像部分

根据第 1 步的奇对称性，曲线的右半部分就是左半部分绕点 (1.5 V, 0) 旋转 180° 得到的。此时 $M_2$ 的电流减小，Y 上升（先升到 2.2 V，当 $V_{in1} \approx 2.21$ V 时 $M_2$ 截止，Y 再升到 $V_{DD}$），而 X 被拉低到 $V_{low} \approx 0.11$ V。$V_{out}$ 最终为 $-(V_{DD} - V_{low}) \approx -2.89$ V。

### 第 8 步 — 如果 $2I_P \ne I_{SS}$ 会怎样？

在没有共模反馈（common-mode feedback）的情况下，这两个电流永远不会精确相等。在任何情况下曲线都关于 1.5 V 奇对称；改变的只是它的中间部分。

- **$2I_P > I_{SS}$（负载较强）。** 在平衡点附近，每个负载只需提供 $I_{SS}/2 < I_P$，因此两个 PMOS 器件都处于线性区，两个输出都偏高，高于 $V_{b2} + 0.8$ V。处于线性区的负载相当于阻值适中的电阻，因此过零处的增益有限且适中。若甚至 $I_P > I_{SS}$，导通一侧不再被拉低，因为它的 PMOS 能够提供全部 $I_{SS}$；此时两端电平缩小到约 $\pm(I_{SS}R_1 + |V_{SD}|)$。
- **$2I_P < I_{SS}$（尾电流较强）。** 在平衡点附近，尾电流管得不到 $I_{SS}$，因此 $M_5$ 和输入对管被推入线性区，两个输出都偏低。平衡点处的增益同样是有限的，而陡降部分向外移动，移到某个输入器件的电流达到 $I_P$ 的位置。

### 结果

$V_{out}$ 是一条**反相的、类似比较器的特性曲线，关于 $V_{in1} = 1.5$ V 奇对称**（该处 $V_{out} = 0$）。在标称偏置 $2I_P = I_{SS}$ 下（$I_P$ 为每个带源极负反馈的 PMOS 电流源的电流，由 $V_{b2}$、$R_1$ 和其尺寸决定）：

- **$V_{in1}$ 较低时**（$M_1$ 截止）：左输出端处于 $V_{DD}$，因为 $M_3$ 中没有电流，$R_1$ 上没有压降。右输出端被拉低到 $V_{low}$，只有零点几伏，因为 $M_4$ 只能提供 $I_P < I_{SS}$，迫使 $M_2$ 和尾电流管进入线性区。所以 $V_{out} \approx V_{DD} - V_{low}$（本例中 ≈ +2.9 V）。
- **当 $M_1$ 导通后**（$V_{in1} \gtrsim V_P + 0.7$ V），$I_{D1}$ 向 $I_P$ 增大。左输出端从 $V_{DD}$ 下降到 $M_3$ 的饱和边缘 $V_{b2} + |V_{THP}|$，右输出端从约 $V_P$ 向 $V_{in2} - V_{THN}$ 上升，因此高电平下垂（本例中为 2.89 → 1.4 V）。
- **在 $V_{in1} = 1.5$ V 处**，斜率为 $dV_{out}/dV_{in1} = -2g_{m1}\{r_{O1}\parallel[R_1 + r_{O3}(1 + g_{m3}R_1)]\}$；由于带源极负反馈的 PMOS 负载是理想电流源，在 $\lambda = 0$ 时该斜率为无穷大。曲线**垂直**过零。
- **$V_{in1}$ 较高时**：与上面镜像对称，最终接近 $-(V_{DD} - V_{low})$。

**常见错误。** 把 $R_1$ 和 $R_2$ 当作负载电阻，从而得到一条平缓的 S 形曲线，增益为 $g_{m1}R_1$，两端电平为 $\pm I_{SS}R_1$。$R_1$ 位于 $M_3$ 的**源极**，它把负载的输出电阻提高到 $R_1 + r_{O3}(1 + g_{m3}R_1)$。

**常见错误。** 把 $M_3$/$M_4$ 当作二极管连接（diode-connected）的负载，或者把高输出电平限制在 $V_{DD} - |V_{THP}|$。它们的栅极接固定偏置 $V_{b2}$，因此当 $M_1$ 截止时，处于线性区且电流为零的沟道会把 $V_X$ 一直拉到 $V_{DD}$。

**常见错误。** 认为导通一侧稳定在 $V_{DD} - I_{SS}R_1$。该侧的 PMOS 只能提供 $I_{SS}/2$，而其输入器件要求 $I_{SS}$，因此该节点电压会跌落到零点几伏，输入器件和尾电流管都处于线性区。
