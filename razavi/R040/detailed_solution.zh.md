# 详细步骤 - R040

**思路。** 把器件建模为 $n$ 个相同的段，各段之间由栅极电阻段 $R_G/n$ 相连；进行 $f_T$ 测试（栅极用电流驱动，源极和漏极接交流地），并对整个栅极网络应用 KCL。电阻只是在各段之间重新分配输入电流；由于每一段的比值 $g_m/C$ 都相同，总漏极电流只取决于总输入电流。

### 第 1 步 — 分布式模型

若只有一个集总的 $R_G$，结论是显然的：电流源（current source）迫使 $I_{in}$ 经过 $R_G$ 流入内部栅极，$R_G$ 只是使输入端电压升高 $I_{in}R_G$。在分布式模型中，各段的栅极电压不同，因此需要证明。

设整个器件的参数为 $g_m$、$C_{GS}$ 和 $C_{GD}$，并定义总栅极电容

$$C = C_{GS} + C_{GD} .$$

第 $k$ 段（$k = 1, \dots, n$）具有内部栅极电压 $V_k$、从漏极到源极的受控源 $(g_m/n)V_k$，以及电容 $C_{GS}/n$ 和 $C_{GD}/n$。所有源极连在一起，所有漏极也连在一起，在 $f_T$ 测试中二者都接交流地，因此每一段从其栅极节点到地都有电容 $C/n$；结电容（junction capacitance）和 $r_O$ 都不流过信号电流。

在自然的梯形连接中，输入端经 $R_G/n$ 接到栅极节点 1，节点 1 经 $R_G/n$ 接到节点 2，依此类推，沿栅指（gate finger）排列。图中给出了 $n = 3$ 的情形；$C_k$ 是第 $k$ 段的 $C/n$，0 V 电压源 `VD` 把公共漏极接回地，其中流过 $I_{out}$。

证明并不依赖梯形连接：它对任何把输入端与各栅极节点相连的电阻网络都成立，包括每个栅极各自经 $R_G/n$ 从公共节点馈电的“星形”连接。

### 第 2 步 — 对整个栅极网络应用 KCL

作一个闭合面，把输入端、所有栅极电阻段和所有内部栅极节点都包围在内。$I_{in}$ 流入该闭合面；电阻全部位于面内，因此电流只能经栅极电容 $C/n$ 流到交流地：

$$I_{in} = \sum_{k=1}^{n} j\omega\,\frac{C}{n}\,V_k = j\omega\,\frac{C}{n}\sum_{k=1}^{n} V_k \quad\Longrightarrow\quad \sum_{k=1}^{n} V_k = \frac{n\,I_{in}}{j\omega C} .$$

各个 $V_k$ 与 $R_G$ 有关（远离接触点的段上的电压更小、更滞后），但它们的**和**只由 $I_{in}$ 决定。

**验证 $n = 2$（梯形）的情形。** 对每个栅极节点列 KCL：

$$
\begin{aligned}
\text{node 1:}\quad I_{in} &= j\omega\frac{C}{2}V_1 + \frac{V_1 - V_2}{R_G/2},\\
\text{node 2:}\quad \frac{V_1 - V_2}{R_G/2} &= j\omega\frac{C}{2}V_2 .
\end{aligned}
$$

把第二式代入第一式，

$$I_{in} = j\omega\frac{C}{2}V_1 + j\omega\frac{C}{2}V_2 = j\omega\frac{C}{2}(V_1 + V_2),$$

这正是 $n = 2$ 时的一般结果：节点之间电阻中的电流相互抵消。

### 第 3 步 — 总漏极电流

各漏极连在一起，因此输出电流是各段电流之和。与标准的 $f_T$ 推导一样，忽略经 $C_{GD}$ 的很小的前馈（feedforward）电流，并利用每一段的跨导都等于 $g_m/n$ 这一事实：

$$I_{out} = \sum_{k=1}^{n}\frac{g_m}{n}V_k = \frac{g_m}{n}\sum_{k=1}^{n}V_k = \frac{g_m}{n}\cdot\frac{n\,I_{in}}{j\omega C} = \frac{g_m\,I_{in}}{j\omega C} .$$

### 第 4 步 — 电流增益与 $f_T$

$$\frac{I_{out}}{I_{in}} = \frac{g_m}{j\omega\,(C_{GS} + C_{GD})}, \qquad \left|\frac{I_{out}}{I_{in}}\right| = \frac{g_m}{\omega\,(C_{GS} + C_{GD})} .$$

这正是没有栅极电阻时的表达式；其中既不出现 $R_G$，也不出现 $n$。在 $\omega_T = 2\pi f_T$ 处令幅值等于 1：

$$\frac{g_m}{2\pi f_T\,(C_{GS} + C_{GD})} = 1 \quad\Longrightarrow\quad f_T = \frac{g_m}{2\pi\,(C_{GD} + C_{GS})} .$$

**计入前馈电流。** 每一段的漏极电流精确地等于 $(g_m/n - j\omega C_{GD}/n)V_k$，因此

$$I_{out} = \frac{g_m - j\omega C_{GD}}{n}\sum_{k}V_k = \frac{(g_m - j\omega C_{GD})\,I_{in}}{j\omega C},$$

仍与集总器件的结果相同。因此，与 $R_G$ 无关这一结论是精确的，而不是近似。

### 第 5 步 — 物理解释与结论的适用条件

每一段的漏极电流为 $(g_m/n)V_k = (g_m/C)\cdot(C/n)V_k$，即其栅极电荷的 $g_m/C$ 倍。因此总漏极电流是总栅极电荷的 $g_m/C$ 倍；而电阻不储存电荷，所以总栅极电荷只由 $I_{in}$ 决定：$R_G$ 改变的是电荷**分布在哪里**，而不是电荷**有多少**。

该结果依赖两个条件：

- **电流驱动。** 若由电压源驱动，$R_G$ 与栅极电容会构成低通滤波器（low-pass filter）。这就是 $R_G$ 虽然不改变 $f_T$，却会限制功率增益（$f_{max}$）并引入热噪声（thermal noise）的原因。
- **每一段的 $g_m/C$ 都相同。** 否则 $V_k$ 的不均匀分布会改变 $I_{out}$。

### 结果

对于电流驱动的栅极，无论电阻取何值，对栅极网络应用 KCL 都得到 $\sum_k V_k = nI_{in}/(j\omega C)$；又因为每一段的跨导为 $g_m/n$、电容为 $C/n$：

$$I_{out} = \frac{g_m}{n}\sum_k V_k = \frac{g_mI_{in}}{j\omega(C_{GS} + C_{GD})} \quad\Longrightarrow\quad f_T = \frac{g_m}{2\pi\,(C_{GD} + C_{GS})},$$

与 $R_G$ 和 $n$ 都无关。

**常见错误。** 在电流增益中加入位于 $1/(R_GC)$ 处的极点。该极点属于从电压源经 $R_G$ 的**电压**传输；在定义 $f_T$ 所用的电流驱动下，$I_{in}$ 仍然全部到达栅极电容。

**常见错误。** 只对单个集总的 $R_G$ 证明这一结果。有多个段时，各个栅极电压**确实**与 $R_G$ 有关；关键的一步是只有它们的和才起作用，这需要用到闭合面 KCL 以及每一段的 $g_m/C$ 都相等这一条件。

**常见错误。** 得出 $f_T$ 与 $n$ 有关的结论。每一段 $g_m$ 中的因子 $1/n$ 与 $\sum_k V_k$ 中的因子 $n$ 相抵消。
