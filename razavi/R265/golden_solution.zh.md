- 用 $(V_{DD}-V_{X0})/R_1 = \tfrac{\beta}{2}(V_{X0}-V_{TH})^2$ 定义 $V_{X0}$（无电容电流时的值），用 $(V_{DD}-V_{X1})/R_1 = \beta(V_{X1}-V_{TH})^2$ 定义 $V_{X1} < V_{X0}$。
- 第 1 阶段：在 $t = 0^+$ 时，$V_X = V_{X1}$，$V_Y = V_{X1} + V_0$。节点 Y 只与 $C_1$ 和 $M_1$ 相连，因此 $M_1$ 的漏极电流经 $C_1$ 从节点 X 流出：$R_1$ 必须同时为 $M_2$ 和 $M_1$ 提供电流，在 $M_1$ 处于饱和区（saturation region）时两者电流相等，均为 $I_1 = \tfrac{\beta}{2}(V_{X1}-V_{TH})^2$。$V_X$ 保持为 $V_{X1}$，$V_Y$ 以斜率 $-I_1/C_1$ 线性下降。
- 第 2 阶段：当 $V_Y$ 降到 $V_{X1} - V_{TH}$ 时（经过 $t_1 = C_1(V_0 + V_{TH})/I_1$ 之后），$M_1$ 进入线性区（triode region），其电流减小，$V_Y$ 向 0 衰减（越来越慢），$V_X$ 则从 $V_{X1}$ 回升到 $V_{X0}$。
- 最终状态：$V_Y = 0$，$V_X = V_{X0}$，$M_1$ 导通但电流为零，$C_1$ 上保持 $-V_{X0}$ 的电压（Y 低于 X）。
