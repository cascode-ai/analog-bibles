# 详细步骤 - R265

**思路。** 节点 Y 只与 $C_1$ 和 $M_1$ 的漏极相连，因此 $M_1$ 吸取的任何电流都必须经 $C_1$ 来自节点 X，也就是来自 $R_1$。由节点 X 和 Y 的基尔霍夫电流定律（KCL）可知，$V_X$ 由 $R_1$ 和两个晶体管的电流以代数方式确定，而 $C_1$ 对 $M_1$ 的电流积分。由此得到两个阶段：$M_1$ 饱和时 $V_Y$ 线性斜坡下降；$M_1$ 进入线性区后，$V_Y$ 衰减到零（同时 $V_X$ 恢复）。

### 第 1 步 — 节点 X 和 Y 的 KCL

令 $v_C = V_Y - V_X$ 为电容电压（$t = 0$ 时 $v_C = V_0$）；$\lambda = 0$，$V_{TH} = 0.7$ V。在节点 Y，唯一的电流经 $C_1$ 流入，经 $M_1$ 流出：

$$C_1\frac{dv_C}{dt} = -I_{D1}. \tag{1}$$

在节点 X，$R_1$ 为 $M_2$ 提供电流，同时提供电容电流，由 (1) 可知后者等于 $I_{D1}$：

$$\frac{V_{DD} - V_X}{R_1} = I_{D2} + I_{D1}. \tag{2}$$

方程 (2) 中没有时间导数：只要 $M_1$ 的状态确定，它就立即确定 $V_X$。

### 第 2 步 — $V_X$ 的两个参考电平

- $V_{X0}$：$M_1$ **没有**电流时的值（只有 $M_2$ 作为 $R_1$ 的负载）：
$$\frac{V_{DD} - V_{X0}}{R_1} = \frac{\beta}{2}(V_{X0} - V_{TH})^2 .$$
- $V_{X1}$：$M_1$ 饱和且与 $M_2$ 流过**相同**电流时的值（因此 $R_1$ 提供两倍的电流）：
$$\frac{V_{DD} - V_{X1}}{R_1} = \beta(V_{X1} - V_{TH})^2 .$$

第二种情况下 $R_1$ 提供的电流更大，因此 $V_{X1} < V_{X0}$。

### 第 3 步 — 第 1 阶段：$M_1$ 饱和，$V_X$ 平坦，$V_Y$ 线性下降

在 $t = 0^+$ 时电容电压不能突变，因此 $V_Y = V_X + V_0$。$M_1$ 饱和（$V_{DS1} = V_X + V_0 > V_X - V_{TH}$），且与 $M_2$ 流过相同的电流：

$$I_{D1} = I_{D2} = \frac{\beta}{2}(V_X - V_{TH})^2 .$$

方程 (2) 变为 $(V_{DD} - V_X)/R_1 = \beta(V_X - V_{TH})^2$，因此

$$V_X = V_{X1} \quad \text{(constant)}, \qquad I_{D1} = I_1 \equiv \frac{\beta}{2}(V_{X1} - V_{TH})^2 \quad \text{(constant)}.$$

因此 **$V_X$ 在 $t = 0^+$ 时阶跃下降到 $V_{X1}$**：$R_1$ 突然要为两个晶体管供电。由于 $I_{D1}$ 恒定，对 (1) 积分得到一条直线：

$$v_C(t) = V_0 - \frac{I_1}{C_1}t \quad\Longrightarrow\quad V_Y(t) = V_{X1} + V_0 - \frac{I_1}{C_1}t .$$

**$V_Y$ 线性下降**，斜率为 $-I_1/C_1$：$M_1$ 相当于一个给 $C_1$ 放电的恒流源，其电流经电容取自 X。

**第 1 阶段结束。** 当 $V_Y = V_X - V_{TH} = V_{X1} - V_{TH}$，即 $V_Y$ 下降了 $V_0 + V_{TH}$ 之后，$M_1$ 退出饱和区：

$$t_1 = \frac{C_1(V_0 + V_{TH})}{I_1}.$$

### 第 4 步 — 第 2 阶段：$M_1$ 处于线性区，$V_Y \to 0$，$V_X$ 恢复

此时 $I_{D1} = \beta[(V_X - V_{TH})V_Y - \tfrac12V_Y^2]$，它小于 $I_{D2}$，并随 $V_Y$ 下降而减小：

- 由 (1)，$C_1$ 继续放电，但越来越慢，因此 **$V_Y$ 向 0 衰减**；
- 由 (2)，$R_1$ 需要提供的电流减小，因此 **$V_X$ 从 $V_{X1}$ 回升到 $V_{X0}$**。

**最后的趋近过程。** 当 $V_Y$ 很小时，$M_1$ 相当于一个电阻：$I_{D1} \approx \beta(V_X - V_{TH})V_Y = g_{m0}V_Y$，其中 $g_{m0} = \beta(V_{X0} - V_{TH})$——$M_1$ 在深线性区（deep triode region）的电导等于 $M_2$ 在相同过驱动电压（overdrive voltage）下的饱和区 $g_m$。在 $V_{X0}$ 附近将 (2) 线性化：

$$
\begin{aligned}
-\frac{\delta V_X}{R_1} &= g_{m0}\,\delta V_X + g_{m0}V_Y\\
\delta V_X &= -\frac{g_{m0}R_1}{1 + g_{m0}R_1}V_Y .
\end{aligned}
$$

因此电容电压的变化量为 $d(V_Y - V_X) = \left(1 + \frac{g_{m0}R_1}{1 + g_{m0}R_1}\right)dV_Y$，由 (1) 得

$$C_1\left(1 + \frac{g_{m0}R_1}{1 + g_{m0}R_1}\right)\frac{dV_Y}{dt} = -g_{m0}V_Y \quad\Longrightarrow\quad V_Y \propto e^{-t/\tau_f}, \qquad \tau_f = \frac{C_1}{g_{m0}}\left(1 + \frac{g_{m0}R_1}{1 + g_{m0}R_1}\right) \approx \frac{2C_1}{g_{m0}} .$$

**最终状态：** $V_Y = 0$，$V_X = V_{X0}$，$M_1$ 导通（栅极电压为 $V_{X0}$），但由于 $V_{DS1} = 0$ 而没有电流。电容最终电压为 $v_C = V_Y - V_X = -V_{X0}$：此时 Y **低于** X，与初始极性相反。

### 第 5 步 — 数值示例

取 $\beta = 2.68\ \mathrm{mA/V^2}$（$W/L = 10/0.5$），$R_1 = 10\ \mathrm{k}\Omega$，$C_1 = 10$ pF，$V_0 = 1$ V。

**$V_{X0}$：** 令 $u = V_{X0} - 0.7$，$(2.3 - u)/(10\ \mathrm{k}\Omega) = (1.34\ \mathrm{mA/V^2})u^2$，即 $13.4u^2 + u - 2.3 = 0$：

$$u = \frac{-1 + \sqrt{1 + 4(13.4)(2.3)}}{2(13.4)} = \frac{-1 + 11.148}{26.8} = 0.379\ \mathrm{V}, \qquad V_{X0} = 1.079\ \mathrm{V}, \quad I_{D2} = 192\ \mu\mathrm{A}.$$

**$V_{X1}$：** $26.8u^2 + u - 2.3 = 0$：

$$u = \frac{-1 + \sqrt{1 + 4(26.8)(2.3)}}{2(26.8)} = \frac{-1 + 15.734}{53.6} = 0.275\ \mathrm{V}, \qquad V_{X1} = 0.975\ \mathrm{V}, \quad I_1 = (1.34\ \mathrm{mA/V^2})(0.275)^2 = 101\ \mu\mathrm{A}.$$

验算：$R_1$ 中的电流为 $(3 - 0.975)/10\ \mathrm{k}\Omega = 202.5\ \mu\mathrm{A} = 2I_1$ ✓。

**第 1 阶段：** $V_Y(0^+) = 0.975 + 1 = 1.975$ V。斜率为 $-I_1/C_1 = -101\ \mu\mathrm{A}/10\ \mathrm{pF} = -10.1\ \mathrm{V}/\mu\mathrm{s}$，且

$$t_1 = \frac{(10\ \mathrm{pF})(1 + 0.7)\ \mathrm{V}}{101\ \mu\mathrm{A}} = 168\ \mathrm{ns}, \qquad V_Y(t_1) = 0.975 - 0.7 = 0.275\ \mathrm{V}.$$

**第 2 阶段：** $g_{m0} = (2.68\ \mathrm{mA/V^2})(0.379\ \mathrm{V}) = 1.015$ mS，$g_{m0}R_1 = 10.15$，因此

$$\tau_f = \frac{10\ \mathrm{pF}}{1.015\ \mathrm{mS}}\left(1 + \frac{10.15}{11.15}\right) = 9.85\ \mathrm{ns}\times1.91 = 18.8\ \mathrm{ns}.$$

对 (1)–(2) 进行数值积分：

| $t$ | $V_X$ (V) | $V_Y$ (V) | $I_{D1}$ | $M_1$ |
|---|---|---|---|---|
| $0^+$ | 0.975 | 1.975 | 101 μA | 饱和区 |
| 50 ns | 0.975 | 1.469 | 101 μA | 饱和区 |
| 100 ns | 0.975 | 0.962 | 101 μA | 饱和区 |
| 168 ns | 0.975 | 0.275 | 101 μA | 线性区边缘 |
| 180 ns | 0.987 | 0.168 | 91 μA | 线性区 |
| 200 ns | 1.029 | 0.066 | 52 μA | 线性区 |
| 250 ns | 1.074 | 0.005 | 5 μA | 线性区 |
| $\infty$ | 1.079 | 0 | 0 | 线性区，$V_{DS} = 0$ |

### 结果

- **$t = 0^+$：** $V_X$ 下降到由 $(V_{DD} - V_{X1})/R_1 = \beta(V_{X1} - V_{TH})^2$ 定义的 $V_{X1}$，因为 $R_1$ 必须同时为 $M_2$ 和 $M_1$ 提供电流，两者电流相等，均为 $I_1 = \tfrac{\beta}{2}(V_{X1} - V_{TH})^2$。$V_Y$ 从 $V_{X1} + V_0$ 开始。
- **第 1 阶段**（$M_1$ 饱和）：$V_X$ 保持在 $V_{X1}$ 不变，而 $V_Y$ 以斜率 $-I_1/C_1$ 线性下降，因为 $M_1$ 的恒定电流给 $C_1$ 放电。
- **第 2 阶段：** 经过 $t_1 = C_1(V_0 + V_{TH})/I_1$ 后，$V_Y$ 降到 $V_{X1} - V_{TH}$，$M_1$ 进入线性区。其电流减小，$V_Y$ 向 0 衰减（越来越慢，最终时间常数为 $\tau_f \approx 2C_1/g_{m0}$），$V_X$ 则从 $V_{X1}$ 回升到只有一个二极管连接（diode-connected）器件时的值 $V_{X0}$，其中 $(V_{DD} - V_{X0})/R_1 = \tfrac{\beta}{2}(V_{X0} - V_{TH})^2$。
- **最终状态：** $V_Y = 0$，$V_X = V_{X0}$，$M_1$ 导通但电流为零，$C_1$ 上保持 $-V_{X0}$ 的电压（Y 低于 X）。

**常见错误。** 认为 $V_X$ 始终不变。$M_1$ 导通期间，其电流经 $C_1$ 取自节点 X，因此 $R_1$ 要提供两个晶体管的电流，$V_X$ 停留在较低的电平 $V_{X1}$，直到 $M_1$ 的电流消失为止。

**常见错误。** 让 $V_Y$ 稳定在 $V_X$ 或 $V_{DD}$。Y 没有通向 $V_{DD}$ 的通路，只有经 $M_1$ 沟道到地的通路以及 $C_1$；$M_1$ 保持导通（栅极电压 $V_{X0} > V_{TH}$），并一直吸收电流直到 $V_{DS1} = 0$，因此 $V_Y \to 0$。

**常见错误。** 把第 1 阶段描述为 RC 指数放电。饱和的 MOSFET 吸取恒定电流，因此 $C_1$ 的电压**线性**变化；只有在 $M_1$ 进入线性区后，才会出现越来越慢的拖尾。
