# 详细步骤 - R266

**思路。** 在节点 X 和 $M_2$ 的源极应用基尔霍夫电流定律（KCL）。$M_2$ 和 $C_1$ 构成一个挂在节点 X 上的闭合环路：$M_2$ 从 X 吸取的任何电流都会经 $C_1$ 直接回到 X。因此左侧的 $R_1$ 中没有电流，$V_X$ 保持为 $V_{DD}$；$M_1$ 的栅极固定在 $V_{DD}$，它吸取恒定电流，因此 $V_Y$ 也恒定。唯一的暂态过程发生在 $M_2$–$C_1$ 环路内部。

### 第 1 步 — 由 KCL 可知左侧 $R_1$ 中没有电流

$M_2$ 的源极只与 $M_2$ 和 $C_1$ 相连，因此从 $M_2$ 源极流出的电流 $I_{D2}$ 进入 $C_1$ 的负极板，同样的 $I_{D2}$ 从其正极板流出并**流入节点 X**。在节点 X 列 KCL，其中 $I_{R1} = (V_{DD} - V_X)/R_1$ 从左侧 $R_1$ 流入，$I_{D2}$ 流出到 $M_2$ 的漏极（栅极不取电流）：

$$I_{R1} + I_{D2} = I_{D2} \quad\Longrightarrow\quad I_{R1} = 0 \quad\Longrightarrow\quad V_X = V_{DD} \ \ \text{for all } t.$$

$M_2$ 的电流只是沿环路 X → $M_2$ → 源极 → $C_1$ → X **循环流动**，不需要电源提供任何电流。

### 第 2 步 — $V_Y$ 恒定

$M_1$ 的栅极电压为 $V_X = V_{DD} = 3$ V，源极接地，因此对所有 $t \ge 0$ 有 $V_{GS1} = 3$ V，过驱动电压（overdrive voltage）为 $V_{GS1} - V_{TH} = 2.3$ V（$\lambda = 0$）。节点 Y 的 KCL：

$$\frac{V_{DD} - V_Y}{R_1} = I_{D1}.$$

**处于哪个工作区？** 只有当 $V_Y \ge 2.3$ V 时 $M_1$ 才饱和。在饱和区中

$$V_Y = V_{DD} - R_1\frac{\beta}{2}(2.3\ \mathrm{V})^2 = 3 - 2.645\,\beta R_1\ \mathrm{V},$$

只有当 $\beta R_1 \le 0.7/2.645 = 0.265\ \mathrm{V^{-1}}$ 时它才不低于 2.3 V，这对应非常小的电阻或非常弱的器件。对于通常的参数值，$\beta R_1 \gg 0.265\ \mathrm{V^{-1}}$，因此 **$M_1$ 处于线性区**，$V_Y$ 满足

$$\frac{V_{DD} - V_Y}{R_1} = \beta\left[(V_{DD} - 0.7)V_Y - \tfrac12V_Y^2\right],$$

解得的是一个很低的值。无论哪种情况，**$V_Y$ 都不随时间变化**，因为其方程中没有任何量发生变化。

**示例**（$\beta = 2.68\ \mathrm{mA/V^2}$，$R_1 = 10\ \mathrm{k}\Omega$，因此 $\beta R_1 = 26.8\ \mathrm{V^{-1}}$）。将线性区方程两边乘以 $R_1$：

$$
\begin{aligned}
3 - V_Y &= 26.8\left(2.3V_Y - 0.5V_Y^2\right) = 61.64V_Y - 13.4V_Y^2\\
13.4V_Y^2 - 62.64V_Y + 3 &= 0\\
V_Y &= \frac{62.64 - \sqrt{62.64^2 - 4(13.4)(3)}}{2(13.4)} = \frac{62.64 - 61.34}{26.8} = 0.048\ \mathrm{V}.
\end{aligned}
$$

（另一个根高于 $V_{DD}$。）因此 $V_Y \approx 48$ mV：$M_1$ 相当于一个阻值约为 $1/[\beta(2.3\ \mathrm{V})] = 162\ \Omega$ 的开关，把 Y 拉到地。

### 第 3 步 — 实际发生的过程：$C_1$ 在环路内部放电

$C_1$ 直接跨接在 $M_2$ 的栅极和源极之间；由于 $M_2$ 是二极管连接（diode-connected）的，它也跨接在漏极和源极之间：$V_{GS2} = V_{DS2} = v_C$。因此 $M_2$ 只要导通就处于饱和区。其源极电压为 $V_{S2} = V_{DD} - v_C$，衬底接地，因此体效应使 $V_{TH2}$ 升高；在其源极列 KCL 得

$$C_1\frac{dv_C}{dt} = -I_{D2} = -\frac{\beta}{2}\left[v_C - V_{TH}(V_{DD} - v_C)\right]^2, \qquad V_{TH}(V_{SB}) = 0.7 + 0.45\left(\sqrt{0.9 + V_{SB}} - \sqrt{0.9}\right)\ \mathrm{V}.$$

- 若 $v_C > V_{TH2}$，$M_2$ 导通并使 $C_1$ 放电；其源极电压从 $V_{DD} - V_0$ 开始上升。
- 当 $v_C = V_{TH2}$ 时放电停止：
$$v_C = 0.7 + 0.45\left(\sqrt{0.9 + 3 - v_C} - \sqrt{0.9}\right).$$
试取 $v_C = 1.035$ V：$\sqrt{3.9 - 1.035} = 1.693$，$0.45(1.693 - 0.949) = 0.335$，且 $0.7 + 0.335 = 1.035$ ✓。因此 **$C_1$ 最终约为 1.03 V**，$M_2$ 的源极最终约为 $3 - 1.03 = 1.97$ V。
- 若 $V_0$ 本来就低于这个阈值电压（约 1.03 V），$M_2$ 从一开始就截止，什么也不会发生。

与任何通过二极管连接 MOSFET 放电的电容一样，这一放电过程呈越来越慢的双曲型。例如，取 $\beta = 2.68\ \mathrm{mA/V^2}$，$C_1 = 10$ pF，$V_0 = 2$ V：在 $t = 0$、5、10、20、50、100 ns 时，$v_C = 2.00$、1.56、1.39、1.26、1.14、1.09 V。

在整个内部暂态过程中，第 1–2 步的结论仍然成立：$V_X = V_{DD}$，$V_Y$ 恒定。只有 $M_2$ 的源极节点在变化。

### 结果

- **对所有 $t$，$V_X = V_{DD}$ 恒定。** $M_2$ 的源极只与 $C_1$ 相连，后者的另一个极板接在 X 上。$M_2$ 从 X 吸取的电流经 $C_1$ 回到 X，因此 $R_1$ 中没有电流（$M_1$ 的栅极也不取电流）。
- **$V_Y$ 恒定**，保持在由 $M_1$（$V_{GS1} = V_{DD}$）与 $R_1$ 共同决定的电平上。对于通常的参数值（$\beta R_1 > 0.265\ \mathrm{V^{-1}}$），$M_1$ 处于线性区，$V_Y$ 很低，由 $(V_{DD} - V_Y)/R_1 = \beta[(V_{DD} - 0.7)V_Y - V_Y^2/2]$ 求得（对于 $\beta = 2.68\ \mathrm{mA/V^2}$、$R_1 = 10\ \mathrm{k}\Omega$，约为 48 mV）。否则 $M_1$ 饱和，$V_Y = V_{DD} - \tfrac{\beta R_1}{2}(2.3\ \mathrm{V})^2 \ge 2.3$ V。
- **唯一的暂态过程发生在内部：** 若 $V_0 > V_{TH2}$，$C_1$ 通过 $M_2$ 放电，直到其电压等于 $M_2$ 计入体效应的阈值电压，约 1.03 V（$M_2$ 的源极从 $V_{DD} - V_0$ 升高到约 1.97 V）。否则什么也不会发生。

**常见错误。** 让 $V_X$ 跟随电容电压变化或向 $V_{TH}$ 衰减，仿佛 $C_1$ 接在 X 与地之间。这里 $C_1$ 接在 X 与 $M_2$ 的源极之间，因此它并不决定 $V_X$，后者由 $R_1$ 保持在 $V_{DD}$。

**常见错误。** 误以为 $C_1$ 或 $M_2$ 的源极接地。那样的话，电流镜（current mirror）将从 $R_1$ 吸取电流，$V_X$ 将停在 $V_{GS}$ 附近；而在实际的连接方式下，环路电流根本不会流到地。

**常见错误。** 让 $V_Y$ 向 $V_{DD}$ 上升或随时间变化。从 $t = 0^+$ 起 $M_1$ 的栅极就恒为 3 V，因此它的电流以及右侧 $R_1$ 上的压降都恒定。
