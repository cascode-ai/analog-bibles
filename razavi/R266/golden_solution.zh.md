$V_X$ 和 $V_Y$ 都保持恒定：对所有 $t$，$V_X = V_{DD}$；$V_Y$ 则保持在由 $M_1$（$V_{GS1} = V_{DD}$）与 $R_1$ 共同决定的电平上：对于通常的参数值，该电平很低，$M_1$ 处于线性区（triode region），满足 $(V_{DD}-V_Y)/R_1 = \beta[(V_{DD}-0.7)V_Y - V_Y^2/2]$（$\beta R_1 > 0.265\ \mathrm{V^{-1}}$）；否则 $M_1$ 处于饱和区（saturation region），$V_Y = V_{DD} - \tfrac{\beta R_1}{2}(2.3\ \mathrm{V})^2 \ge 2.3$ V。唯一的暂态过程发生在内部：$C_1$ 通过 $M_2$ 放电。

- $M_2$ 的源极只与 $C_1$ 相连，后者的另一个极板接在 X 上。$M_2$ 从 X 吸取的任何电流都经 $C_1$ 回到 X，因此 $R_1$ 中没有电流，$V_X = V_{DD}$（$M_1$ 的栅极也不取电流）。
- 在环路内部，$C_1$ 直接跨接在 $V_{GS2}$ 上（$V_{GS2} = V_{DS2}$ = 电容电压）。若 $V_0 > V_{TH2}$，$M_2$ 使 $C_1$ 放电，直到电容电压等于因体效应（body effect）而升高的 $V_{TH2}$（$V_{SB2} = V_{DD} - V_C$）：由 $V_C = 0.7 + 0.45(\sqrt{3.9 - V_C} - \sqrt{0.9})$ 得 ≈ 1.03 V。$M_2$ 的源极从 $V_{DD} - V_0$ 升高到 ≈ 1.97 V。若 $V_0$ 低于该阈值电压（threshold voltage），则什么也不会发生。
- 从 $t = 0$ 起，$M_1$ 的 $V_{GS} = V_{DD}$，因此 $V_Y$ 恒定。
