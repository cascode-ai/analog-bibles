# 详细步骤 - R354

**思路。** 计入所有噪声电流，在两个漏极节点列 KCL 方程，再将两式相减。相减消去了尾节点，只剩下一个用差分输入和噪声电流表示差分输出的方程；把噪声项除以信号项即可折算到输入端，再把互不相关的功率相加。

### 第 1 步 — 小信号模型（small-signal model）与噪声源

把左、右两个漏极节点分别记为 A 和 B，尾节点记为 P。输入为 $v_{in} = v_{in1} - v_{in2}$，输出为 $v_{out} = v_A - v_B$。

- **二极管连接负载 $M_5$、$M_6$：** 它们分别向 A 送入 $g_{m5}(0 - v_A)$、向 B 送入 $g_{m6}(0 - v_B)$，即每个节点到交流地之间有一个电阻 $1/g_{m5}$。
- **交叉耦合管 $M_3$、$M_4$：** $M_3$（栅极接 B）向 A 送入 $g_{m3}(0 - v_B)$；$M_4$（栅极接 A）向 B 送入 $g_{m4}(0 - v_A)$。
- **输入对管：** $M_1$ 从 A 向 P 抽取 $g_{m1}(v_{in1} - v_P)$；$M_2$ 从 B 向 P 抽取 $g_{m2}(v_{in2} - v_P)$。
- **尾电流源：** 理想的 $I_{SS}$ 对交流信号相当于开路，且不增加噪声。

六个互不相关的噪声电流（功率谱密度均为 $4kT\gamma g_m$）为：流入 A 的 $I_{n5}$、$I_{n3}$；流入 B 的 $I_{n6}$、$I_{n4}$；从 A 流向 P 的 $I_{n1}$；从 B 流向 P 的 $I_{n2}$。已知：$g_{m1} = g_{m2}$，$g_{m5} = g_{m6}$，$g_{m3} = g_{m4} = 0.5\,g_{m5}$。

### 第 2 步 — 节点 A 和 B 的 KCL

在每个节点，两个 PMOS 器件送入的电流等于输入管抽取的电流：

$$-g_{m5}v_A + I_{n5} - g_{m3}v_B + I_{n3} = g_{m1}(v_{in1} - v_P) + I_{n1},$$

$$-g_{m6}v_B + I_{n6} - g_{m4}v_A + I_{n4} = g_{m2}(v_{in2} - v_P) + I_{n2}.$$

定义总的负载噪声电流

$$I_{nA} = I_{n5} + I_{n3}, \qquad I_{nB} = I_{n6} + I_{n4}.$$

### 第 3 步 — 相减得到差分方程

用 A 的方程减去 B 的方程，并利用 $g_{m5} = g_{m6}$、$g_{m3} = g_{m4}$ 和 $g_{m1} = g_{m2}$：

$$-g_{m5}(v_A - v_B) - g_{m3}(v_B - v_A) + (I_{nA} - I_{nB}) = g_{m1}(v_{in1} - v_{in2}) - g_{m1}(v_P - v_P) + (I_{n1} - I_{n2}).$$

尾节点电压 $v_P$ 被消去，左边化为 $-(g_{m5} - g_{m3})v_{out}$：

$$
\begin{aligned}
-(g_{m5} - g_{m3})\,v_{out} + (I_{nA} - I_{nB}) &= g_{m1}v_{in} + (I_{n1} - I_{n2})\\
(g_{m5} - g_{m3})\,v_{out} &= -g_{m1}v_{in} - (I_{n1} - I_{n2}) + (I_{nA} - I_{nB}).
\end{aligned}
$$

对差分信号而言，二极管连接负载呈现电导 $g_{m5}$，交叉耦合对呈现**负**电导 $-g_{m3}$，因此净差分负载电导为 $g_{m5} - g_{m3}$。

### 第 4 步 — 差模增益

$$A_v = \frac{v_{out}}{v_{in}} = -\frac{g_{m1}}{g_{m5} - g_{m3}} = -\frac{g_{m1}}{g_{m5} - 0.5\,g_{m5}} = -\frac{2g_{m1}}{g_{m5}},$$

是只用二极管连接负载时增益（$-g_{m1}/g_{m5}$）的两倍。

### 第 5 步 — 输入参考噪声电压

把噪声部分除以信号系数 $-g_{m1}$，负载电导 $g_{m5} - g_{m3}$ 被约去：

$$v_{n,in} = \frac{(I_{n1} - I_{n2}) - (I_{nA} - I_{nB})}{g_{m1}} = \frac{I_{n1} - I_{n2} - I_{n5} - I_{n3} + I_{n6} + I_{n4}}{g_{m1}}.$$

六个噪声源互不相关：

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \frac{4kT\gamma\left(g_{m1} + g_{m2} + g_{m5} + g_{m3} + g_{m6} + g_{m4}\right)}{g_{m1}^2}\\
&= \frac{4kT\gamma\left(2g_{m1} + 2g_{m3} + 2g_{m5}\right)}{g_{m1}^2}\\
&= 8kT\gamma\left(\frac{1}{g_{m1}} + \frac{g_{m3} + g_{m5}}{g_{m1}^2}\right).
\end{aligned}
$$

代入 $g_{m3} = 0.5\,g_{m5}$：

$$\overline{V_{n,in}^2} = 8kT\gamma\left(\frac{1}{g_{m1}} + \frac{1.5\,g_{m5}}{g_{m1}^2}\right).$$

### 第 6 步 — 物理解释

因子 $8kT$ 反映了两个相互独立的半边。交叉耦合对通过减小差分负载电导来提高增益，但每个噪声电流看到的也是同一个电导，因此它在负载项中**增加**了 $g_{m3}$，而不是抵消了什么。若采用跨导（transconductance）为 $0.5\,g_{m5}$ 的普通二极管连接负载，可以得到相同的增益 $2g_{m1}/g_{m5}$，而负载项为 $0.5\,g_{m5}/g_{m1}^2$，只有这里所得 $1.5\,g_{m5}/g_{m1}^2$ 的三分之一。尾电流源若有噪声，则属于共模（common-mode）噪声，会在 $v_A - v_B$ 中抵消。

### 结果

$$\overline{V_{n,in}^2} = 8kT\gamma\left(\frac{1}{g_{m1}} + \frac{g_{m3} + g_{m5}}{g_{m1}^2}\right) = 8kT\gamma\left(\frac{1}{g_{m1}} + \frac{1.5\,g_{m5}}{g_{m1}^2}\right)$$

差模增益为 $-g_{m1}/(g_{m5} - g_{m3}) = -2g_{m1}/g_{m5}$。折算到输入端时负载电导被约去，因此六个晶体管都有贡献：两个输入器件各贡献 $4kT\gamma/g_{m1}$，四个负载器件各贡献 $4kT\gamma g_m/g_{m1}^2$。

**常见错误。** 把负载项写成 $\propto g_{m5} - g_{m3}$，仿佛交叉耦合对抵消了部分二极管负载噪声。它抵消的是部分负载**电导**，而不是**噪声**：$M_3$ 和 $M_4$ 的噪声功率要加到 $M_5$ 和 $M_6$ 的噪声功率上。

**常见错误。** 略去交叉耦合器件，得到 $8kT\gamma(1/g_{m1} + g_{m5}/g_{m1}^2)$。$M_3$ 和 $M_4$ 与二极管连接负载一样，把噪声直接注入输出节点。

**常见错误。** 给出不含因子 2 的半边电路（half circuit）结果 $4kT\gamma\left(1/g_{m1} + 1.5\,g_{m5}/g_{m1}^2\right)$，或者把输出噪声除以只有二极管负载时的增益 $g_{m1}/g_{m5}$。两个半边都有贡献，而且噪声和增益必须使用同一个负载电导 $g_{m5} - g_{m3}$。
