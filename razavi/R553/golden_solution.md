# Golden Solution - R553

## Reference answer

$\dfrac{1}{R_D}\dfrac{dR_D}{dT} = +\dfrac{3}{4T} \approx +2.5\times10^{-3}\ \mathrm{K^{-1}}$ (+2500 ppm/K, +0.25 %/K) at 300 K, i.e. $R_D \propto T^{3/4}$ locally.
- At constant $I_{SS}$, $g_m = \sqrt{\mu C_{ox}(W/L)I_{SS}} \propto \mu^{1/2} \propto T^{-3/4}$, so $(1/g_m)(dg_m/dT) = -3/(4T) = -0.25$ %/K. $R_D$ must rise at the same fractional rate.
