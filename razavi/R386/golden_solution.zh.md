最大闭环增益的幅值 ≈ 1.4–1.55：若采用常用的一阶增益误差 $1/(\beta A)$，则 $C_1/C_2 \approx 1.5$（增益 ≈ −1.43，标称值 −1.5）；若误差严格定义为 $1 - |A_v|/(C_1/C_2)$，则 $C_1/C_2 \approx 1.63$（增益 ≈ −1.55）。低频输出阻抗：$Z_{out} = r_{O1}/(1 + g_{m1}r_{O1}\,C_2/(C_1+C_2)) = r_{O1}/21 \approx 2.4/g_{m1}$（按严格定义 ≈ $r_{O1}/20 = 2.5/g_{m1}$）。

推导（$A = g_{m1}r_{O1} = 50$）：
- 低频时 $C_2$ 从输出端吸取的电流可以忽略，因此 $V_{out} = -AV_X$，再由 $(V_{out} - V_X)C_2 = (V_X - V_{in})C_1$ 得 $\dfrac{V_{out}}{V_{in}} = -\dfrac{1}{(1+1/A)C_2/C_1 + 1/A} = -\dfrac{C_1/C_2}{1 + (1 + C_1/C_2)/A}$。
- 反馈系数（feedback factor）$\beta = C_2/(C_1+C_2)$；相对增益误差 ≈ $1/(\beta A) = (1 + C_1/C_2)/A \le 0.05$ → $1 + C_1/C_2 \le 2.5$，$C_1/C_2 \le 1.5$；实际增益 $= -1.5/(1 + 2.5/50) = -1.43$。
- 严格定义：$1/[1 + (1+C_1/C_2)/A] \ge 0.95$ → $1 + C_1/C_2 \le 2.63$，增益 ≈ −1.55。
- 输出阻抗（$V_{in} = 0$，在输出端加测试电压）：$V_X = V_{out}C_2/(C_1+C_2)$，$I = V_{out}/r_{O1} + g_{m1}V_X$（低频时串联的 $C_1$–$C_2$ 支路相当于开路），因此 $Z_{out} = r_{O1}/(1 + \beta g_{m1}r_{O1})$，其中环路增益（loop gain）$\beta A = 20$（严格定义下为 19）：$r_{O1}/21 = (50/21)/g_{m1}$。
