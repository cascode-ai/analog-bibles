# 详细步骤 - R250

**思路。** $M_2$ 为二极管连接（diode-connected），由 $I_{REF}$ 供电，但 $I_{REF}$ 的一部分可能经 $R_2$ 分流到 Y（也可能有额外电流从 Y 流来），而 $M_1$ 镜像 $M_2$ 中的任何电流。对 X 和 Y 列 KCL 可知，X 保持在二极管电压 $V_{GS}(I_{REF})$ 附近，而 Y 通过类似分压器的关系跟随 $V_1$；两条曲线在 $R_2$ 中没有电流处相交。

### 第 1 步 — 节点方程

令 $V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$，即二极管恰好流过 $I_{REF}$ 所需的栅极电压。对 X 点（$I_{REF}$ 流入；经 $M_2$ 和 $R_2$ 流出）和 Y 点（从 $V_1$ 经 $R_1$、从 X 经 $R_2$ 流入；经 $M_1$ 流出）列 KCL：

$$I_{REF} = I_{D2} + \frac{V_X - V_Y}{R_2} , \qquad (1)$$

$$\frac{V_1 - V_Y}{R_1} + \frac{V_X - V_Y}{R_2} = I_{D1} . \qquad (2)$$

$M_1$ 饱和时，$I_{D1} = I_{D2}$（$V_{GS} = V_X$ 相同）。

### 第 2 步 — 交点

若 $V_X = V_Y$，则 $R_2$ 中没有电流，由 (1) 得 $I_{D2} = I_{REF}$，$V_X = V_{GS}(I_{REF})$，而 $M_1$（$V_{DS1} = V_{GS1}$，饱和）也流过 $I_{REF}$。于是 (2) 变为 $(V_1 - V_Y)/R_1 = I_{REF}$，因此交点位于

$$V_1 = V_{GS}(I_{REF}) + R_1I_{REF} = 0.7 + \sqrt{\frac{2I_{REF}}{\beta}} + R_1I_{REF},$$

此时 $V_X = V_Y = V_{GS}(I_{REF})$。

- **低于这一 $V_1$ 时：** $V_Y < V_X$，电流从 X 经 $R_2$ 流到 Y，$M_2$ 的电流**小于** $I_{REF}$，因此 $V_X$ 略**低于** $V_{GS}(I_{REF})$。
- **高于这一点时：** $V_Y > V_X$，电流从 Y 流入 X，$M_2$ 的电流**大于** $I_{REF}$，因此 $V_X$ 略**高于** $V_{GS}(I_{REF})$。

### 第 3 步 — $V_1$ 较小时：可能出现的截止区

若两个晶体管都截止，$I_{REF}$ 必须全部从 X 经 $R_2$ 和 $R_1$ 流入电压源 $V_1$：

$$V_Y = V_1 + I_{REF}R_1, \qquad V_X = V_1 + I_{REF}(R_1 + R_2) ,$$

只有当 $V_X < 0.7$ V 时这才是自洽的，即

$$V_1 < 0.7\ \mathrm{V} - I_{REF}(R_1 + R_2) .$$

因此，若 $I_{REF}(R_1 + R_2) < 0.7$ V，扫描开始时两条曲线都以斜率 1 上升，X 比 Y 高 $I_{REF}R_2$，直到 $V_X$ 达到 0.7 V；若 $I_{REF}(R_1 + R_2) \ge 0.7$ V，则在 $V_1 = 0$ 时晶体管就已经导通。

### 第 4 步 — 导通区：$V_X$ 几乎平坦，$V_Y$ 大致线性

**$V_X$。** $M_2$ 是流过 $I_{D2} = I_{REF} + (V_Y - V_X)/R_2$ 的二极管，因此 $V_X = 0.7 + \sqrt{2I_{D2}/\beta}$。变化量 $dV_Y$ 使 $I_{D2}$ 改变 $(dV_Y - dV_X)/R_2$，二极管再把它转换为 $dV_X = dI_{D2}/g_m$：

$$dV_X = \frac{dV_Y}{1 + g_mR_2}, \qquad g_m = \sqrt{2\beta I_{D2}} .$$

当 $g_mR_2 \gg 1$ 时，**$V_X$ 几乎是平坦的**，在 $V_{GS}(I_{REF})$ 附近缓慢上升。

**$V_Y$。** 由 $I_{D1} = I_{D2} = I_{REF} + (V_Y - V_X)/R_2$，(2) 变为

$$\frac{V_1 - V_Y}{R_1} = I_{REF} + \frac{2(V_Y - V_X)}{R_2} ,$$

其中因子 2 的来源是：$R_2$ 中的电流既改变 $M_2$ 的电流（$M_1$ 会复制这一变化），又直接流入 Y 点。求微分并利用 $dV_X = dV_Y/(1 + g_mR_2)$：

$$\frac{dV_1 - dV_Y}{R_1} = \frac{2}{R_2}\cdot\frac{g_mR_2}{1 + g_mR_2}\,dV_Y \;\Longrightarrow\; \frac{dV_Y}{dV_1} = \frac{1}{1 + \dfrac{2g_mR_1}{1 + g_mR_2}} \approx \frac{R_2}{R_2 + 2R_1}\quad(g_mR_2 \gg 1) .$$

因此 **$V_Y$ 大致线性地上升**，比 $V_X$ 快得多，并在第 2 步给出的点与之相交。

**$M_1$ 会进入线性区吗？** 这需要 $V_Y < V_X - 0.7$ V，而由 (1) 得 $V_X - V_Y = R_2(I_{REF} - I_{D2}) \le R_2I_{REF}$。因此只有当 $I_{REF}R_2 > 0.7$ V 时才可能（在 $V_1$ 较小时）进入线性区，而 $R_1$ 较小时更可能出现；否则 $M_1$ 在整个扫描范围内都处于饱和。

### 第 5 步 — 数值示例

$I_{REF} = 100\ \mu$A，$W/L = 10/0.5$（$\beta = 2.68\ \mathrm{mA/V^2}$），$R_1 = R_2 = 10\ \mathrm{k}\Omega$：$V_{GS}(I_{REF}) = 0.7 + 0.273 = 0.973$ V，交点位于 $V_1 = 0.973 + 1.0 = 1.97$ V，且 $I_{REF}(R_1 + R_2) = 2$ V $> 0.7$ V（没有截止区）。求解 (1) 和 (2)：

| $V_1$ (V) | 0 | 0.5 | 1.0 | 1.5 | 1.97 | 2.5 | 3.0 |
|---|---|---|---|---|---|---|---|
| $V_X$ (V) | 0.868 | 0.900 | 0.927 | 0.952 | 0.973 | 0.995 | 1.015 |
| $V_Y$ (V) | 0.245 | 0.433 | 0.618 | 0.801 | 0.973 | 1.164 | 1.343 |
| $I_{D1} = I_{D2}$ (μA) | 38 | 53 | 69 | 85 | 100 | 117 | 133 |
| $R_2$ 中的电流 X→Y (μA) | 62 | 47 | 31 | 15 | 0 | −17 | −33 |

$M_1$ 保持饱和（$V_X - V_Y \le 0.62$ V $< 0.7$ V）。$V_Y$ 的斜率约为 0.36，接近 $R_2/(R_2 + 2R_1) = 0.33$，而 $V_X$ 在整个扫描范围内只变化 0.15 V。

### 结果

两个电压都随 $V_1$ 单调上升：

- **$V_X$** 是二极管电压，只缓慢上升，保持在 $V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$ 附近：$V_1$ 较小时略低于它（$I_{REF}$ 的一部分经 $R_2$ 流走），$V_1$ 较大时略高于它。
- **$V_Y$** 大致线性地上升，$M_1$ 饱和时斜率 $\approx R_2/(R_2 + 2R_1)$。
- 二者**在 $V_1 = V_{GS}(I_{REF}) + R_1I_{REF}$ 处相交**，此时 $V_X = V_Y = V_{GS}(I_{REF})$，$R_2$ 中没有电流。低于该点时 $V_Y < V_X$，高于该点时 $V_Y > V_X$。
- 若 $I_{REF}(R_1 + R_2) < 0.7$ V，扫描开始时两个晶体管都截止：$V_X = V_1 + I_{REF}(R_1 + R_2)$，$V_Y = V_1 + I_{REF}R_1$（斜率为 1），直到 $V_X$ 达到 0.7 V。

（示例：$I_{REF} = 100\ \mu$A，$\beta = 2.68\ \mathrm{mA/V^2}$，$R_1 = R_2 = 10\ \mathrm{k}\Omega$；$V_1 = 0, 2, 3$ V 时，$V_X \approx 0.87, 0.97, 1.02$ V，$V_Y \approx 0.25, 0.98, 1.34$ V。）

**常见错误。** 把 $V_X$ 当作恒定的 $V_{GS}(I_{REF})$，并写出 $V_Y = V_1 - R_1I_{REF}$，忽略了 $R_2$。$R_2$ 中的电流既改变二极管电流，又直接流入 Y，因此 $V_Y$ 的斜率约为 $R_2/(R_2 + 2R_1)$，而不是 1。

**常见错误。** 晶体管导通后仍让 $V_X$ 跟随 $V_1$。$M_2$ 像二极管一样钳住 X 点，Y 点的变化传到 X 时被衰减 $1 + g_mR_2$ 倍。

**常见错误。** 把 $R_1$ 看成接到 $V_{DD}$，或者把 $V_Y$ 画成随 $V_1$ 下降。$R_1$ 接的是被扫描的电压源 $V_1$，因此提高 $V_1$ 会抬高 Y。
