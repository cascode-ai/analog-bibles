两者都随 $V_1$ 单调上升：$V_X$ 只是缓慢上升（它是一个二极管电压，$V_1$ 较小时略低于 $V_{GS}(I_{REF})$，$V_1$ 较大时略高于它），$V_Y$ 则大致线性上升。两条曲线在 $V_1 = V_{GS}(I_{REF}) + R_1I_{REF}$ 处相交，此时 $V_X = V_Y = V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$，$R_2$ 中没有电流。

- KCL：在 X 点，$I_{D2} = I_{REF} + (V_Y - V_X)/R_2$；在 Y 点，$(V_1 - V_Y)/R_1 = I_{D1} + (V_Y-V_X)/R_2$；$M_1$ 在饱和区（saturation region）时复制 $M_2$ 的电流。
- $V_1$ 较小时：$Y$ 经 $R_1$ 被拉低，$I_{REF}$ 的一部分从 X 经 $R_2$ 流向 Y，因此 $M_2$ 流过的电流小于 $I_{REF}$，$V_X < V_{GS}(I_{REF})$；$V_Y$ 只有几百 mV。由于 $V_X - V_Y = R_2(I_{REF} - I_{D2}) \le R_2I_{REF}$，只有当 $I_{REF}R_2 > 0.7$ V 时，$M_1$ 才可能在此处进入线性区（triode region），$R_1$ 较小时这种可能性更大。
- 若 $I_{REF}(R_1+R_2) < 0.7$ V，则当 $V_1 < 0.7\ \mathrm{V} - I_{REF}(R_1+R_2)$ 时两个晶体管都截止：$I_{REF}$ 全部经 $R_2$ 和 $R_1$ 流入 $V_1$，因此 $V_X = V_1 + I_{REF}(R_1+R_2)$，$V_Y = V_1 + I_{REF}R_1$（斜率为 1，X 比 Y 高 $I_{REF}R_2$）。
- $M_1$ 饱和且 $V_X$ 近似不变时，$(V_1 - V_Y)/R_1 = I_{REF} + 2(V_Y - V_X)/R_2$，因此 $dV_Y/dV_1 \approx R_2/(R_2 + 2R_1)$。
- $V_1$ 较大时：$V_Y > V_X$，电流从 Y 流入 X，$M_2$ 流过的电流大于 $I_{REF}$，$V_X$ 升到 $V_{GS}(I_{REF})$ 以上。
- 示例（$I_{REF}$ = 100 μA，W/L = 10/0.5，$R_1 = R_2$ = 10 kΩ）：$V_1$ = 0、2、3 V → $V_X$ ≈ 0.87、0.97、1.02 V；$V_Y$ ≈ 0.25、0.98、1.34 V。
