# 详细步骤 - R399

**思路。** $M_1$ 是带电容性电压并联反馈的共源级（common-source stage）：$C_2$ 检测输出并把电流送回栅极，$C_1$ 把输入耦合到栅极。负载为理想电流源且 $\lambda = 0$ 时，输出节点没有电阻性通路，因此环路增益为无穷大。暂时在输出端加一个电阻 $R_L$，应用布莱克曼阻抗公式（Blackman's formula），再令 $R_L \to \infty$，并用直接列基尔霍夫电流定律（KCL）方程的方法验证每个结果。

### 第 1 步 — 小信号模型（small-signal model）与方法

把栅极节点记为 G。于是：

- $C_1$ 接在 in 与 G 之间；$C_2$ 接在 G 与 out 之间；栅极不吸取电流；
- $M_1$：电流 $g_{m1}v_G$ 从 out 流向地（不含 $r_O$）；
- $I_1$：相当于开路（另加辅助电阻 $R_L$ 接在 out 与地之间，最后令 $R_L \to \infty$）。

$C_2$ 检测 $v_{out}$ 并把电流送回 G（**电压并联反馈**），且环路为负反馈：$v_G\uparrow$ → $v_{out}\downarrow$ → 经 $C_2$ 从 G 抽出电流 → $v_G\downarrow$。

布莱克曼阻抗公式把端口阻抗表示为

$$Z = Z_0\,\frac{1 + T_{sc}}{1 + T_{oc}},$$

其中 $Z_0$ 为 $g_{m1} = 0$ 时的端口阻抗，$T_{sc}$、$T_{oc}$ 分别为端口短路和开路时的环路增益（在受控源处断开环路）。

### 第 2 步 — 从栅极节点 G 看进去的阻抗

对于 G 与地之间的端口（不含 $C_1$）：

- $Z_0$：经 $C_2$ 到输出端，再经 $R_L$ 到地，$Z_0 = \dfrac{1}{sC_2} + R_L$；
- $T_{sc}$：G 短路时，无论 $M_1$ 如何都有 $v_G = 0$，因此 $T_{sc} = 0$；
- $T_{oc}$：测试源 $g_{m1}\cdot1$ 从输出端吸取 $g_{m1}$，因此 $v_{out} = -g_{m1}R_L$；G 开路时 $C_2$ 中没有电流，因此 $v_G = -g_{m1}R_L$，$T_{oc} = g_{m1}R_L$。

$$Z_G = \frac{1/(sC_2) + R_L}{1 + g_{m1}R_L} \;\xrightarrow{R_L\to\infty}\; \frac{1}{g_{m1}}.$$

**直接验证**（$R_L \to \infty$）。注入 G 的电流 $i$ 流过 $C_2$，$i = sC_2(v_G - v_{out})$，而在输出端只有 $M_1$ 能吸收它，$sC_2(v_G - v_{out}) = g_{m1}v_G$。因此 $i = g_{m1}v_G$，且

$$Z_G = \frac{v_G}{i} = \frac{1}{g_{m1}}\quad\text{exactly, at all frequencies;}$$

输出电压只是随之变化，直到 $C_2$ 中的电流等于 $g_{m1}v_G$。

### 第 3 步 — 输入阻抗

从 $V_{in}$ 看，$C_1$ 与栅极节点串联：

$$Z_{in} = \frac{1}{sC_1} + Z_G = \frac{1}{sC_1} + \frac{1}{g_{m1}}.$$

低频时 $1/(sC_1)$ 占主导；高频时输入端看起来相当于 $1/g_{m1}$。

### 第 4 步 — 输出阻抗

令 $V_{in} = 0$（$C_1$ 接在 G 与地之间），在输出端口：

- $Z_0$：$R_L$ 与串联的 $C_2$、$C_1$ 相并联；记 $C_s = C_1C_2/(C_1 + C_2)$，
$$Z_0 = R_L\parallel\frac{1}{sC_s} \equiv Z_p ;$$
- $T_{sc}$：输出端短路时 $v_G = 0$，因此 $T_{sc} = 0$；
- $T_{oc}$：从输出端吸取测试电流 $g_{m1}$，得 $v_{out} = -g_{m1}Z_p$，而 G 位于电容分压器的抽头上，
$$v_G = \frac{C_2}{C_1 + C_2}v_{out} = \beta v_{out}, \qquad \beta = \frac{C_2}{C_1 + C_2},$$
因此 $T_{oc} = g_{m1}\beta Z_p$。

$$Z_{out} = \frac{Z_p}{1 + g_{m1}\beta Z_p} = \frac{1}{1/Z_p + g_{m1}\beta}.$$

由 $1/Z_p = 1/R_L + sC_s \to sC_s$ 得：

$$
\begin{aligned}
Z_{out} &= \frac{1}{sC_s + g_{m1}\beta} = \frac{1}{\dfrac{sC_1C_2}{C_1 + C_2} + \dfrac{g_{m1}C_2}{C_1 + C_2}}\\
&= \frac{C_1 + C_2}{C_2\,(g_{m1} + sC_1)}.
\end{aligned}
$$

**直接验证。** 在输出端加 $v_X$，$v_G = v_XC_2/(C_1 + C_2)$，测试电流同时流入 $M_1$ 和串联电容：

$$I_X = g_{m1}\frac{C_2}{C_1 + C_2}v_X + s\frac{C_1C_2}{C_1 + C_2}v_X = \frac{C_2(g_{m1} + sC_1)}{C_1 + C_2}v_X,$$

得到相同的 $Z_{out}$ ✓。它是一个电阻与一个电容的并联，

$$Z_{out} = \frac{1 + C_1/C_2}{g_{m1}}\ \Big\|\ \frac{1}{s\,C_1C_2/(C_1 + C_2)} ,$$

其中 $1/(g_{m1}\beta)$ 是无穷大的开环电阻除以无穷大的环路增益 $g_{m1}\beta R_L$ 的结果，而电容则是反馈网络（串联的 $C_2$–$C_1$）对输出端的负载。低频时 $Z_{out} \approx (1 + C_1/C_2)/g_{m1}$。

### 结果

$$Z_{in} = \frac{1}{sC_1} + \frac{1}{g_{m1}}, \qquad Z_{out} = \frac{C_1 + C_2}{C_2(g_{m1} + sC_1)} = \frac{1 + C_1/C_2}{g_{m1}}\ \Big\|\ \frac{1}{s\,C_1C_2/(C_1 + C_2)},$$

即低频时 $Z_{out} \approx (1 + C_1/C_2)/g_{m1}$。栅极节点看起来恰好是 $1/g_{m1}$，因为无穷大的环路增益迫使流过 $C_2$ 的电流等于 $g_{m1}v_G$；输出电阻为 $1/(g_{m1}\beta)$，其中 $\beta = C_2/(C_1 + C_2)$，并与 $C_1$、$C_2$ 的串联电容相并联。

**常见错误。** 把 $C_2$ 当作密勒电容（Miller capacitance），写成 $Z_{in} = 1/(sC_1) + 1/[sC_2(1 + A)]$，或者只写 $1/(sC_1)$。精确的 KCL 分析表明，栅极节点呈电阻性，为 $1/g_{m1}$。

**常见错误。** 因为负载理想且 $\lambda = 0$，就断定 $Z_{out}$ 为无穷大。反馈使 $M_1$ 吸取与输出电压成正比的电流。

**常见错误。** 把分压比弄反，写成 $(1 + C_2/C_1)/g_{m1}$。到达 G 的输出电压比例是 $C_2/(C_1 + C_2)$，因此电阻为 $(1 + C_1/C_2)/g_{m1}$。
