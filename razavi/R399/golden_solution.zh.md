$Z_{in} = \dfrac{1}{sC_1} + \dfrac{1}{g_{m1}}$；$\quad Z_{out} = \dfrac{C_1+C_2}{C_2(g_{m1} + sC_1)} = \dfrac{1 + C_1/C_2}{g_{m1}}\ \Big\|\ \dfrac{1}{s\,C_1C_2/(C_1+C_2)}$，即低频时 ≈ $(1 + C_1/C_2)/g_{m1}$。

- 反馈：$C_2$ 检测 $V_{out}$ 并把电流送回栅极 G，构成电压并联反馈（shunt–shunt feedback）；$C_1$ 与输入端串联。
- G 点的阻抗：输出节点除 $C_2$ 外没有任何电导（$I_1$ 理想，λ = 0），因此经 $C_2$ 流入 G 的电流必须等于 $g_{m1}v_G$：$Z_G = 1/g_{m1}$ 严格成立，因为输出端的环路增益（loop gain）为无穷大。因此 $Z_{in} = 1/(sC_1) + 1/g_{m1}$。
- $Z_{out}$（$V_{in}$ = 0）：$v_G = v_XC_2/(C_1+C_2)$；$I_X = g_{m1}v_G + sv_X C_1C_2/(C_1+C_2)$。用反馈的语言来说：开环输出电阻（output resistance）为 ∞，$\beta = C_2/(C_1+C_2)$，闭环电阻为 $1/(g_{m1}\beta)$，再与 $C_1$、$C_2$ 串联构成的电容支路并联。
