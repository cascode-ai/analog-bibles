# Golden Solution - R412

## Reference answer

$A_v \approx +3.2$ (3.23 exact nodal, 3.27 two-port) and $R_{out} \approx 0.11\ \mathrm{k\Omega}$ (114 Ω), with body effect and λ; the ideal value $1 + R_2/R_1$ is 4.08.

- Bias: no current in $R_2$, $V_{out} = V_B = 0.5\ \mathrm{mA} \times 0.973\ \mathrm{k\Omega} = 0.487$ V = $V_{SB1}$. $g_{m1} = g_{m2} = 3.66$ mS, $g_{mb1} = g_{m1}\cdot 0.45/(2\sqrt{1.387}) = 0.70$ mS ($\eta = 0.19$); $r_{O1} = r_{O2} = 20\ \mathrm{k\Omega}$, $r_{O3} = r_{O4} = 10\ \mathrm{k\Omega}$.
- Series–shunt feedback, $\beta = R_1/(R_1+R_2) = 0.245$.
- Open loop: $M_1$ degenerated by $R_1\|R_2 = 0.735\ \mathrm{k\Omega}$: $G_{m1} = g_{m1}/[1 + (g_{m1}+g_{mb1})0.735\ \mathrm{k\Omega}] = 0.871$ mS; node A: $r_{O3}$ in parallel with ≈ 85 kΩ looking into $M_1$ ≈ 8.9 kΩ → $A_1 \approx -7.8$; output: $r_{O2}\|r_{O4}\|(R_1+R_2) = 2.49\ \mathrm{k\Omega}$ → $A_2 = -9.1$; $A_{v,open} \approx 71$.
- Loop gain $\beta(1+\eta)A_{v,open} \approx 0.245 \times 1.19 \times 71 \approx 20.7$ → $A_v \approx 71/21.7 \approx 3.27$; $R_{out} \approx 2.49\ \mathrm{k\Omega}/21.7 \approx 115\ \Omega$. Exact: 3.23, 114 Ω.
- Without body effect: ≈ 3.83–3.86 and ≈ 120 Ω. (With λ = 0 the open-loop gain would be infinite: gain → 4.08/(1+η), $R_{out}$ → 0, so λ has to be kept.)
