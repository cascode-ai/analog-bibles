# 详细步骤 - R388

**思路。** 负载为理想电流源且 $\lambda = 0$ 时，$M_1$ 漏极处的开环输出电阻（output resistance）为无穷大。只有通过环路它才变为有限值：分压器 $C_1$/$C_2$ 对输出采样，$M_2$ 把它转换为 $M_1$ 源极处的电流，$M_1$ 再把其中一部分传回输出端。在输出端施加测试电压，用基尔霍夫电流定律（KCL）沿环路追踪，计算 $V_X/I_X$。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 的源极记为节点 S，$M_2$ 的栅极记为节点 P。令 $V_{in}$ 接交流地，并在输出端接测试源 $V_X$（电流为 $I_X$）：

- $M_1$：栅极和衬底都接交流地，因此 $v_{gs1} = v_{bs1} = -V_S$，它从 out 到 S 流过电流 $-(g_{m1} + g_{mb1})V_S$（不含 $r_{O1}$）。
- $R_S$ 接在 S 与地之间。
- $M_2$：电流 $g_{m2}V_P$ 从 S 流向地（源极和衬底都接地，因此没有体效应；不含 $r_{O2}$）。
- $C_1$ 接在 out 与 P 之间，$C_2$ 接在 P 与地之间；电流源负载相当于开路。

### 第 2 步 — P 点的反馈电压

$M_2$ 的栅极不吸取电流，因此

$$V_P = \frac{C_1}{C_1 + C_2}V_X .$$

低频时，流过串联 $C_1$–$C_2$ 支路的电流（量级为 $\omega C_1C_2V_X/(C_1 + C_2)$）可以忽略，因此该支路只是**检测**输出电压。

### 第 3 步 — $M_1$ 源极处的 KCL

流过 $M_1$ 的电流流入 S，并经 $R_S$ 和 $M_2$ 流出：

$$-(g_{m1} + g_{mb1})V_S = \frac{V_S}{R_S} + g_{m2}V_P ,$$

$$
\begin{aligned}
-V_S\left(g_{m1} + g_{mb1} + \frac{1}{R_S}\right) &= g_{m2}V_P\\
V_S &= -\frac{g_{m2}V_PR_S}{1 + (g_{m1} + g_{mb1})R_S}.
\end{aligned}
$$

于是 $M_1$ 的漏极电流（从 out 到 S）为

$$I_{D1} = -(g_{m1} + g_{mb1})V_S = g_{m2}V_P\,\frac{(g_{m1} + g_{mb1})R_S}{1 + (g_{m1} + g_{mb1})R_S} = g_{m2}V_P\,\frac{R_S}{R_S + \dfrac{1}{g_{m1} + g_{mb1}}}.$$

$M_2$ 从 S 抽走 $g_{m2}V_P$，这部分电流一部分由 $R_S$ 提供，一部分由 $M_1$ 提供（其源极看进去相当于 $1/(g_{m1} + g_{mb1})$）；$M_1$ 提供的那部分取自输出端。

### 第 4 步 — 输出阻抗

由于负载为理想电流源，测试电流只能流过 $M_1$，因此 $I_X = I_{D1}$：

$$I_X = \frac{C_1}{C_1 + C_2}\,g_{m2}\,\frac{(g_{m1} + g_{mb1})R_S}{1 + (g_{m1} + g_{mb1})R_S}\,V_X ,$$

$$Z_{out} = \frac{V_X}{I_X} = \frac{C_1 + C_2}{C_1}\cdot\frac{1 + (g_{m1} + g_{mb1})R_S}{g_{m2}(g_{m1} + g_{mb1})R_S} = \left(1 + \frac{C_2}{C_1}\right)\left[\frac{1}{g_{m2}} + \frac{1}{g_{m2}(g_{m1} + g_{mb1})R_S}\right].$$

### 第 5 步 — 解释与极限情况

- **$(g_{m1} + g_{mb1})R_S$ 很大时：** $M_2$ 的电流几乎全部来自 $M_1$，$Z_{out} \to (1 + C_2/C_1)/g_{m2}$：环路相当于一个跨导为 $g_{m2}\beta$ 的“二极管”，其中 $\beta = C_1/(C_1 + C_2)$。
- **无反馈时**（$g_{m2} = 0$），表达式为无穷大，即开环值。
- **$R_D$ 为有限值时：** 闭环阻抗为 $R_D/(1 + \text{loop gain})$，其中环路增益（loop gain）为 $R_D\,g_{m2}\beta(g_{m1} + g_{mb1})R_S/[1 + (g_{m1} + g_{mb1})R_S]$；令 $R_D \to \infty$ 即得到上面的结果。

**符号检验。** $V_X$ 升高使 $V_P$ 升高，于是 $M_2$ 从 S 吸取更多电流，$V_S$ 下降，$M_1$ 从输出端吸取**更多**电流：输出电阻为正的有限值。

### 结果

$$Z_{out} = \frac{C_1 + C_2}{C_1}\cdot\frac{1 + (g_{m1} + g_{mb1})R_S}{g_{m2}(g_{m1} + g_{mb1})R_S} = \left(1 + \frac{C_2}{C_1}\right)\left[\frac{1}{g_{m2}} + \frac{1}{g_{m2}(g_{m1} + g_{mb1})R_S}\right],$$

当 $(g_{m1} + g_{mb1})R_S$ 很大时，它趋于 $(1 + C_2/C_1)/g_{m2}$。若没有经 $C_1$、$C_2$ 和 $M_2$ 的反馈，输出阻抗将为无穷大。

**常见错误。** 因为负载理想且 $\lambda = 0$，就断定 $Z_{out}$ 为无穷大。那只是开环值；环路使输出端吸取与其电压成正比的电流。

**常见错误。** 把分压比颠倒成 $C_2/(C_1 + C_2)$。$V_P$ 是输出电压中降落在 $C_2$ 上的部分，即 $V_XC_1/(C_1 + C_2)$。

**常见错误。** 忽略 S 点的分流，把 $M_2$ 的电流直接送回输出端。只有 $R_S/[R_S + 1/(g_{m1} + g_{mb1})]$ 这一部分流过 $M_1$；略去 $g_{mb1}$ 会使这一比例略有变化。
