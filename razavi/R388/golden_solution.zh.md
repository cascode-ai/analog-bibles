$Z_{out} = \dfrac{C_1+C_2}{C_1}\cdot\dfrac{1 + (g_{m1}+g_{mb1})R_S}{g_{m2}(g_{m1}+g_{mb1})R_S} = \left(1 + \dfrac{C_2}{C_1}\right)\left[\dfrac{1}{g_{m2}} + \dfrac{1}{g_{m2}(g_{m1}+g_{mb1})R_S}\right]$，当 $(g_{m1}+g_{mb1})R_S$ 很大时趋于 $(1 + C_2/C_1)/g_{m2}$。

- 负载为理想电流源且 λ = 0 时，开环输出电阻为无穷大；经 $C_1$、$C_2$ 和 $M_2$ 的反馈（它把电流送回 $M_1$ 的源极）使其变为有限值。
- 在输出端加测试电压 $V_X$，$V_{in}$ = 0：$V_P = V_XC_1/(C_1+C_2)$；$M_2$ 从 $M_1$ 的源极节点吸取 $g_{m2}V_P$，这一电流在 $R_S$ 与 $M_1$ 的源极（电阻为 $1/(g_{m1}+g_{mb1})$）之间分配：$I_{D1} = V_X\dfrac{C_1}{C_1+C_2}\,g_{m2}\dfrac{R_S}{R_S + 1/(g_{m1}+g_{mb1})}$。
- 由于电流源是理想的，$I_X = I_{D1}$，因此 $Z_{out} = V_X/I_X$ 如上式所示。这也是 $R_D/(1 + \text{loop gain})$ 在 $R_D \to \infty$ 时的极限。低频时，从输出端到地的串联 $C_1$–$C_2$ 支路可以忽略。
- （若保留 λ：$Z_{out} = \dfrac{1 + (g_{m1}+g_{mb1}+1/r_{O1})R'}{1/r_{O1} + g_{m2}R'(g_{m1}+g_{mb1}+1/r_{O1})C_1/(C_1+C_2)}$，其中 $R' = R_S \| r_{O2}$；当 $r_O \to \infty$ 时它简化为上面的结果。）
