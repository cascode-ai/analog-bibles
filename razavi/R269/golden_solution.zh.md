$C_1$ 没有直流放电通路：它的下极板只与 $M_1$ 的衬底相连，而衬底的各个结都处于反向偏置（reverse-biased）。因此串联的 $C_1$ 无法持续地为 $M_3$/$M_1$ 提供电流。实际情况是，Y 和 $M_1$ 的衬底一起下降，$C_1$ 使 $V_Y - V_{B1} \approx V_{DD}$ 保持不变。变负的衬底电压使 $V_{TH1}$ 升高，电流随之消失。这一下降过程很快：其速度只由衬底和 Y 上很小的寄生电容决定（约为 $I_{REF}/C_{par}$，而不是 $I_{REF}/C_1$），在理想电路中则是 $t = 0$ 时的一个阶跃。之后 $V_X$ 和 $V_Y$ 保持在恒定的最终电平上。

- 令 $u = \sqrt{2I_{REF}/\beta}$，则 $V_{G1} = V_{GS2} = 0.7 + u$。当 $M_1$ 因衬底反偏而截止，或 Y 和 X 降到 0 时，电流停止。这里 $s(u) = (\sqrt{0.9} + u/0.45)^2 - 0.9$ 是使 $V_{TH1} = V_{G1}$ 的 $V_{SB1}$ 值。
- 情况 A，$u < 0.46$ V（$V_{G1} < V_{TH1}(V_{SB} = 3\ \mathrm{V}) \approx 1.16$ V）：$M_1$ 先截止。衬底稳定在 $-s(u)$，$V_Y \to V_{DD} - s(u)$（例如 $u$ = 0.2 V 时 ≈ 1.96 V），$V_X \to \min[V_Y,\ x_s]$，其中 $x_s$ 是 $x_s + V_{TH3}(x_s) = V_b$ 的解。在平方律模型中，随着 $M_1$ 的过驱动电压（overdrive voltage）消失，趋近过程呈现类似 $1/t$ 的缓慢拖尾。
- 情况 B，$u > 0.46$ V：$M_1$ 保持导通，Y 和 X 被拉到 ≈ 0，衬底降到 ≈ $-V_{DD}$。
- 若 $V_b \le V_{TH0}$ = 0.7 V，$M_3$ 从一开始就截止：$V_Y$ 保持为 $V_{DD}$，$V_X = 0$；没有任何变化。
- 在严格的理想模型（没有寄生电容）中，$C_1$ 本身只确定 $V_Y - V_{B1}$，因此零电流的最终状态不唯一。上面给出的电平是寄生电容很小时的极限：此时电流连续衰减，并在到达的第一个零电流状态处停止。若衬底有电容 $C_B$，$C_1$ 上的电压只减少衬底电压摆幅的 ≈ $C_B/C_1$ 倍（$V_Y \approx V_{DD} + (1 + C_B/C_1)V_{B1}$）。不存在按 $I_{REF}/C_1$ 进行的缓慢放电。
- 瞬态仿真（平方律模型，$I_{REF}$ = 100 μA，$V_b$ = 2 V，$C_1$ = 1 pF，衬底、Y 和 X 上各有 10 fF）：$u$ = 0.2 V → $V_Y$ 在 0.4 ns 内由 3 → 2.30 V，8 ns 时为 1.98 V（→ 1.95 V），衬底 → −1.0 V，$V_X \approx$ 1.08 V（$= x_s$）；$u$ = 0.6 V → $V_Y$、$V_X$ 在 ≈ 4 ns 内 → 0，衬底 → −2.97 V，$C_1$ 上仍为 2.97 V。
