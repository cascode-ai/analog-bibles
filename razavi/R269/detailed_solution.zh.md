# 详细步骤 - R269

**思路。** 跟踪电荷的去向。节点 Y 只能通过 $M_3$ 失去电荷，而 $C_1$ 的下极板接 $M_1$ 的衬底，这是一个没有任何直流通路的节点，因此 $C_1$ 不可能被稳定的电流放电。实际情况是，Y 和 $M_1$ 的衬底**一起**下降，越来越负的衬底电压使 $M_1$ 的阈值电压（threshold voltage）升高，直到电流停止。我们由零电流条件求出最终电平，并用一个包含小寄生电容的瞬态仿真加以验证。

### 第 1 步 — $C_1$ 没有直流放电通路

二极管连接（diode-connected）的 $M_2$ 决定 $M_1$ 的栅极电压：

$$V_{G1} = V_{GS2} = 0.7 + u, \qquad u = \sqrt{\frac{2I_{REF}}{\beta}} .$$

把 $C_1$ 的下极板（即 $M_1$ 的衬底）称为节点 B；在 $t = 0$ 时，$V_Y = V_{DD}$，$V_B = 0$。

节点 B 只与 $C_1$ 和 $M_1$ 的衬底相连，只要 B 的电压不高于源极和漏极，衬底与它们之间的结就处于反向偏置。因此，除了给节点 B 上微小的寄生电容 $C_B$ 充放电的电流之外，流过 $C_1$ 的电流为零：

$$I_{C1} = C_B\frac{dV_B}{dt} \approx 0 .$$

节点 Y 只与 $C_1$ 和 $M_3$ 的漏极相连：

$$I_{D3} = I_{C1} + \left(\text{current from the parasitic capacitance } C_Y \text{ of node Y}\right).$$

因此 $M_3$（以及其下方的 $M_1$）只能通过给**很小的**寄生电容放电来获得电流，**而不是**给 $C_1$ 放电；像 $I_{REF}$ 这样持续的电流几乎会瞬间把它们放空。又因为 $I_{C1} \approx 0$，$C_1$ 两端的电压保持为 $V_{DD}$：**Y 和 B 一起变化**，

$$V_Y - V_B \approx V_{DD}.$$

### 第 2 步 — Y 和衬底下降，体效应（body effect）使 $M_1$ 截流

在 $t = 0^+$ 时，$M_1$ 的衬底为 0 V，因此它复制 $I_{REF}$；若 $V_b$ 足够高，$M_3$ 导通。该电流把 Y 拉低，B 则跟随 Y、始终比它低一个 $V_{DD}$，因此

$$V_{SB1} = 0 - V_B = V_{DD} - V_Y > 0, \qquad V_{TH1} = 0.7 + 0.45\left(\sqrt{0.9 + V_{SB1}} - \sqrt{0.9}\right)$$

随之升高。由于 $M_1$ 的栅极固定在 $0.7 + u$，其过驱动电压减小，电流衰减。这一过程在到达的**第一个零电流状态**处停止：

- (A) $M_1$ 因衬底反偏而截止，$V_{TH1} = V_{G1}$；或者
- (B) Y 和 X 一直被拉到 0，所有晶体管都没有剩余的 $V_{DS}$。

**速度。** 量级为 $I_{REF}$ 的电流只给寄生电容（飞法量级）放电，因此下降过程所需时间的量级为 $C_{par}\,\Delta V/I_{REF}$，即零点几纳秒到几纳秒，**而不是** $C_1\Delta V/I_{REF}$。在没有寄生电容的理想模型中，它是 $t = 0$ 时的一个阶跃。此后 $V_X$ 和 $V_Y$ 保持不变。

### 第 3 步 — 截止条件与两种情况

当 $M_1$ 的阈值电压达到其栅极电压时，它截止：

$$
\begin{aligned}
0.7 + 0.45\left(\sqrt{0.9 + V_{SB1}} - \sqrt{0.9}\right) &= 0.7 + u\\
\sqrt{0.9 + V_{SB1}} &= \sqrt{0.9} + \frac{u}{0.45}\\
V_{SB1} = s(u) &\equiv \left(\sqrt{0.9} + \frac{u}{0.45}\right)^2 - 0.9 .
\end{aligned}
$$

由于 $V_Y = V_{DD} - V_{SB1}$ 不能低于 0，衬底最多只能降到约 $-V_{DD}$。两种情况的分界为 $s(u) = V_{DD} = 3$ V：

$$\sqrt{3.9} = 1.975 = 0.949 + \frac{u}{0.45} \quad\Longrightarrow\quad u = 0.46\ \mathrm{V}, \qquad V_{G1} = 1.16\ \mathrm{V} = V_{TH1}(V_{SB} = 3\ \mathrm{V}).$$

- **情况 A，$u < 0.46$ V：** $M_1$ 先截止。衬底稳定在 $-s(u)$，且
$$V_Y \to V_{DD} - s(u).$$
- **情况 B，$u > 0.46$ V：** 即使衬底降到 $-V_{DD}$ 也无法使 $M_1$ 截止。$M_1$ 和 $M_3$ 持续导通，直到 **Y 和 X 降到约 0**，衬底降到约 $-V_{DD}$。

**平凡情况。** 若 $V_b \le V_{TH0} = 0.7$ V，$M_3$ 根本不能导通（$X \ge 0$），因此没有任何变化：$V_Y = V_{DD}$，X 被 $M_1$ 保持在 0。

### 第 4 步 — $V_X$ 的终值

在情况 A 中，$M_3$ 最终电流为零。若 Y 足够高，$M_3$ 是一个过驱动电压为零的饱和跟随器，X 上升到 $x_s$，其定义为

$$x_s + V_{TH3}(x_s) = V_b .$$

若 $V_Y$ 的终值低于 $x_s$，$M_3$ 处于线性区（triode region）且电流为零，这迫使 $V_X = V_Y$。简而言之，

$$V_X \to \min\left[V_Y,\ x_s\right].$$

在情况 B 中，$V_X \to 0$。

**拖尾的形状（情况 A）。** 接近截止时，电流 $\propto (V_{G1} - V_{TH1})^2$，并以与电流成正比的速率改变衬底电压，因此过驱动电压 $w$ 满足 $dw/dt \propto -w^2$：趋近终值的过程是类似 $1/t$ 的缓慢拖尾，而不是指数型的。

### 第 5 步 — 寄生电容的作用与解的唯一性

若寄生电容严格为零，$C_1$ 只确定 $V_Y - V_B$，任何满足该约束的零电流状态都可以，因此在这种理想化下最终状态不唯一。当存在小的寄生电容时，各电压从初始状态连续变化，电流单调下降，电路在第一个零电流状态处停止，由此得到上面的电平。

若衬底有电容 $C_B$，$C_1$ 上的电压会减少衬底电压摆幅的约 $C_B/C_1$ 倍：

$$V_Y \approx V_{DD} + \left(1 + \frac{C_B}{C_1}\right)V_B ,$$

但仍然不存在按 $I_{REF}/C_1$ 进行的缓慢放电。

### 第 6 步 — 数值示例（瞬态仿真）

采用平方律模型，$I_{REF} = 100\ \mu\mathrm{A}$，$V_b = 2$ V，$C_1 = 1$ pF，衬底节点、Y 和 X 上各有 10 fF 的寄生电容。

**$u = 0.2$ V**（$\beta = 2I_{REF}/u^2 = 5\ \mathrm{mA/V^2}$），情况 A：

$$s(0.2) = \left(0.949 + \frac{0.2}{0.45}\right)^2 - 0.9 = (1.393)^2 - 0.9 = 1.041\ \mathrm{V} \ \Longrightarrow\ V_Y \to 3 - 1.041 = 1.96\ \mathrm{V}$$

（计入 $C_B$ 造成的 1 % 电荷损失后为 1.95 V）。$x_s$ 满足 $x_s + V_{TH3}(x_s) = 2$ V，解得 $x_s = 1.09$ V。由于 $1.95 > 1.09$，$V_X \to 1.09$ V。

| $t$ | $V_Y$ (V) | $V_B$ (V) | $V_X$ (V) | $I_{D1}$ |
|---|---|---|---|---|
| 0 | 3.00 | 0 | 1.09 | 100 μA |
| 0.1 ns | 2.70 | −0.30 | 0.97 | 45 μA |
| 0.4 ns | 2.34 | −0.65 | 1.03 | 11 μA |
| 2 ns | 2.07 | −0.92 | 1.07 | 0.9 μA |
| 8 ns | 1.98 | −1.01 | 1.09 | 0.07 μA |
| $\infty$ | ≈ 1.95 | ≈ −1.04 | 1.09 | 0 |

**$u = 0.6$ V**（$\beta = 0.56\ \mathrm{mA/V^2}$），情况 B：$V_Y$ 和 $V_X$ 在约 4 ns 内降到约 0，衬底降到 −2.97 V，而 $C_1$ 上仍保持 2.97 V。

在两种情况下，$C_1$ 两端的电压几乎不变（3.00 V → 2.99 V 或 2.97 V）：$C_1$ **并没有**被放电。

### 结果

- $C_1$ **没有直流放电通路**：它的下极板只与 $M_1$ 的衬底相连，而衬底的各个结都处于反向偏置。因此它无法持续地为 $M_3$/$M_1$ 提供电流。
- 实际情况是，**Y 和 $M_1$ 的衬底一起下降**，$C_1$ 使 $V_Y - V_{B1} \approx V_{DD}$ 保持不变。变负的衬底电压使 $V_{TH1}$ 升高，电流随之消失。这一下降过程很快：其速度只由很小的寄生电容决定（速率量级为 $I_{REF}/C_{par}$，而不是 $I_{REF}/C_1$），在理想电路中则是 $t = 0$ 时的一个阶跃。**之后 $V_X$ 和 $V_Y$ 保持在恒定的最终电平上。**
- 令 $u = \sqrt{2I_{REF}/\beta}$，$s(u) = (\sqrt{0.9} + u/0.45)^2 - 0.9$：
  - **$u < 0.46$ V**（$M_1$ 因体效应而截止）：衬底为 $-s(u)$，$V_Y \to V_{DD} - s(u)$（$u = 0.2$ V 时约为 1.96 V），$V_X \to \min[V_Y, x_s]$，其中 $x_s + V_{TH3}(x_s) = V_b$。趋近过程呈现类似 $1/t$ 的缓慢拖尾。
  - **$u > 0.46$ V：** $M_1$ 保持导通，Y 和 X 被拉到约 0，衬底降到约 $-V_{DD}$。
  - **$V_b \le 0.7$ V：** $M_3$ 截止；没有任何变化（$V_Y = V_{DD}$）。

**常见错误。** 把 $C_1$ 当作接地（或接 $M_1$ 的源极），从而认为 $I_{REF}$ 给它放电，$V_Y$ 以 $I_{REF}/C_1$ 的斜率斜坡下降。电容的下极板接的是衬底这个孤立节点，因此电容不能通过直流电流。

**常见错误。** 在 $M_1$ 和 $M_3$ 有电流时仍让 $V_Y$ 保持为 $V_{DD}$。Y 与电源没有连接；任何流过 $M_3$ 的电流都必然使 $V_Y$ 降低，衬底也随之下降。

**常见错误。** 忽略 $M_1$ 的体效应。正是经 $C_1$ 被推向负电压的 $M_1$ 衬底的反向偏置，切断了电流，并确定了最终电平 $V_{DD} - s(u)$。
