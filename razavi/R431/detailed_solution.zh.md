# 详细步骤 - R431

**思路。** 输出端接到 $M_2$ 的栅极后，运放成为单位增益缓冲器（unity-gain buffer），因此输入对管的栅极跟随输出变化。求出被共源共栅（cascode）管钳定的节点电压，把每个晶体管的饱和条件写成对 $V_{out}$ 的限制，然后取最紧的下限和上限。

### 第 1 步 — 固定的电压

每条支路的电流为 0.5 mA；所有器件的 $W/L = 200$，且 $\gamma = 0$：

$$V_{OD} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{(134\ \mu\mathrm{A/V^2})(200)}} = 0.193\ \mathrm{V},\qquad V_{GS1\text{–}4} = 0.7 + 0.193 = 0.893\ \mathrm{V}.$$

$M_2$ 的漏极（共源共栅管 $M_4$ 的源极）被钳定在

$$V_{D2} = V_{b1} - V_{GS4} = 1.7 - 0.893 = 0.807\ \mathrm{V},$$

与 $V_{out}$ 无关。对于 PMOS 器件，$|V_{OD}| = \sqrt{2(0.5\ \mathrm{mA})/((38.4\ \mu\mathrm{A/V^2})(200))} = 0.361$ V。

### 第 2 步 — 下限：$M_4$

$M_4$ 的栅极接 $V_{b1}$，漏极接 $V_{out}$：

$$V_{out} \ge V_{b1} - V_{TH4} = 1.7 - 0.7 = 1.0\ \mathrm{V}.$$

### 第 3 步 — 上限：$M_2$（以及 $M_1$）

$M_2$ 的栅极接 $V_{out}$，漏极为 0.807 V，因此饱和要求 $V_{D2} \ge V_{G2} - V_{TH2}$：

$$
\begin{aligned}
0.807 &\ge V_{out} - 0.7\\
V_{out} &\le 1.507\ \mathrm{V}.
\end{aligned}
$$

$M_1$ 给出同样的限制（栅极接 $V_{in} \approx V_{out}$，漏极为 $V_{b1} - V_{GS3} = 0.807$ V）。用符号表示，$V_{out,max} = V_{b1} - V_{GS4} + V_{TH2}$。

### 第 4 步 — 其他器件不构成约束

- **PMOS 一侧。** $V_{b2}$ 选择得当时，低电压共源共栅结构 $M_8$/$M_6$ 直到 $V_{out} = V_{DD} - |V_{OD8}| - |V_{OD6}| = 3 - 0.361 - 0.361 = 2.28$ V 都保持饱和，远高于 1.51 V。
- **尾电流源。** 在整个范围内 $V_P = V_{out} - V_{GS2} \ge 1.0 - 0.893 = 0.107$ V，始终高于地电位。
- **$M_3$：** 其漏极电压为 $V_X = V_{DD} - |V_{GS7}| = 1.84$ V，高于 $V_{b1} - V_{TH} = 1.0$ V。✓

### 第 5 步 — 摆幅

$$\text{swing} = 1.507 - 1.0 \approx 0.51\ \mathrm{V}.$$

$V_{out,max} - V_{out,min} = (V_{b1} - V_{GS4} + V_{TH}) - (V_{b1} - V_{TH}) = V_{TH} - V_{OD4} = 0.7 - 0.193$ V，与 $V_{b1}$ 无关：改变 $V_{b1}$ 只会平移这个窗口。升高 $V_{out}$ 会把输入对管推向线性区（triode region），降低它则会把 $M_4$ 推向线性区，因此尽管套筒式共源共栅（telescopic cascode）结构的开环范围宽得多，它仍不适合用作单位增益缓冲器。

### 结果

$$V_{b1} - V_{TH4} = 1.0\ \mathrm{V} \le V_{out} \le V_{b1} - V_{GS4} + V_{TH2} \approx 1.51\ \mathrm{V},$$

因此最大输出摆幅约为 **0.51 V**（$= V_{TH} - V_{OD4}$），下端受 $M_4$ 限制，上端受 $M_2$（以及 $M_1$）限制。

**常见错误。** 给出开环时的输出范围（从 $V_{b1} - V_{TH}$ 到 $V_{DD} - |V_{OD8}| - |V_{OD6}|$，约 1.3 V）。输出端接到 $M_2$ 的栅极后，输入对管设定的上限要低得多。

**常见错误。** 把输入当作固定值，这样就去掉了输入对管带来的上限；在单位增益缓冲器中，$M_2$ 的栅极随输出变化。

**常见错误。** 用 $W/L = 100$ 代替 200，这会得到 $V_{OD} = 0.273$ V，摆幅约为 0.43 V。
