在频率检测模式下，环路比较的是频率而不是相位。因此，VCO 从频率到相位的积分 $K_{VCO}/s$（它在锁相模式下提供原点处两个极点中的一个）不在环路之内。只剩下环路滤波器（loop filter）电容的积分，所以阶数降低一阶（从二阶降为一阶）。

- 频率不同时，相位差持续扫过，PFD 的一个输出几乎一直在输出脉冲。电荷泵的平均电流由频率差 $\omega_{in} - \omega_{out}$ 的符号和大小决定，而与相位无关：从约 $I_P/2$（输入略快于 VCO）到约 $I_P$（输入快得多）；输入较慢时符号相反。
- 因此，被反馈和比较的量就是 VCO 的频率本身。它是控制电压的静态函数，$\omega_{out} = \omega_0 + K_{VCO}V_{cont}$：VCO 相当于一个单纯的增益（V → ω），而不是积分器（V → φ）。
- 在锁相模式下，环路有两个积分器，$(I_P/2\pi)(R_P + 1/C_Ps)\cdot K_{VCO}/s$，即闭环为二阶。在频率检测模式下，只有电容 $C_P$ 在积分。
- 设线性化的鉴频增益为 $K_{FD}$（每 rad/s 对应的电流），则环路增益（loop gain）为 $L = K_{FD}K_{VCO}(R_P + 1/C_Ps)$，且 $\dfrac{\omega_{out}}{\omega_{in}} = \dfrac{K(1 + R_PC_Ps)}{K + (1 + KR_P)C_Ps}$，其中 $K = K_{FD}K_{VCO}$：只有一个极点，因此频率以一阶方式（单调、无条件稳定）趋近 $\omega_{in}$。
- 当泵电流近似恒定时，$V_{cont}$ 和 $\omega_{out}$ 只是斜坡式地趋向锁定；这一过程同样只用一个状态变量来描述，即 $C_P$ 上的电荷。
