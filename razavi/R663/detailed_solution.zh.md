# 详细步骤 - R663

**思路。** 分别数出两种模式下环路中积分器的个数。锁相时有两个：环路滤波器电容和 VCO（频率 → 相位）。在频率捕获（frequency acquisition）期间，PFD 响应的是频率差，因此反馈变量是 VCO 的频率，它是控制电压的静态函数；VCO 的积分器退出环路，只剩下电容。

### 第 1 步 — 锁相模式下阶数的来源

锁定时，PFD/电荷泵是从相位到电流的静态增益，$I_{CP} = \frac{I_P}{2\pi}(\Phi_{in} - \Phi_{out})$；$R_P$–$C_P$ 串联滤波器含有一个积分器（$C_P$）；而 VCO $\Phi_{out} = (K_{VCO}/s)V_{cont}$ 是第二个积分器，因为它设定的是**频率**，而 PFD 比较的是**相位**。环路增益

$$H_{open}(s) = \frac{I_P}{2\pi}\left(R_P + \frac{1}{C_Ps}\right)\frac{K_{VCO}}{s} = \frac{I_PK_{VCO}}{2\pi C_P}\cdot\frac{R_PC_Ps + 1}{s^2}$$

在原点处有两个极点，特征方程 $s^2 + \frac{I_PK_{VCO}R_P}{2\pi}s + \frac{I_PK_{VCO}}{2\pi C_P} = 0$ 是**二阶**的，有两个状态变量：$C_P$ 上的电荷和输出相位 $\phi_{out}$。

### 第 2 步 — 频率不同时 PFD 的行为

假设 $\omega_{in} > \omega_{out}$，且两者相差很远。

- 每个输入边沿都使 $Q_A$ 置位，只有下一个 VCO 边沿（通过复位）才能将其清零；其间多出的输入边沿不起任何作用。因此在每个 VCO 周期的大部分时间里 $Q_A$ 都为高电平，而 $Q_B$ 只产生复位毛刺。
- 相对相位持续扫过（每多出一个输入周期就扫过 $2\pi$），因此不会保持在任何特定相位上。
- 在许多周期上取平均，泵电流由**频率差的符号和大小**决定：输入只是略快时约为 $+I_P/2$，此时随着相位滑移，$Q_A$ 的占空比（duty cycle）从 0 扫到 1，平均为 1/2；输入快得多时则升向 $+I_P$。输入较慢时情况镜像对称：$Q_B$ 起作用，电流为负。

因此平均电流不依赖于瞬时相位；PFD 起到**鉴频器**的作用：

$$\overline{I_{CP}} = f(\omega_{in} - \omega_{out}).$$

### 第 3 步 — VCO 变为静态增益

现在被比较的是 VCO 的**频率**，它与控制电压的关系为

$$\omega_{out} = \omega_0 + K_{VCO}V_{cont},$$

其中没有积分：在这个环路中，VCO 是单纯的增益 $K_{VCO}$（V → rad/s），而不是积分器 $K_{VCO}/s$（V → rad）。输出相位仍然存在，但检测器不再依赖于它，因此它位于反馈环路之外。**从环路中去掉一个原点处的极点，阶数就降低一阶**；只剩下电容的积分，以及来自 $R_P$ 的零点。

### 第 4 步 — 频率捕获的线性化模型

用增益 $K_{FD}$（每 rad/s 对应的电流）将鉴频器线性化，$\overline{I_{CP}} = K_{FD}(\omega_{in} - \omega_{out})$：

$$\omega_{out} = \omega_0 + K_{VCO}K_{FD}\left(R_P + \frac{1}{C_Ps}\right)(\omega_{in} - \omega_{out}).$$

对于小变化（$\omega_0$ 消去），并令 $K = K_{FD}K_{VCO}$（单位为 A/V，即西门子），环路增益

$$L(s) = K\left(R_P + \frac{1}{C_Ps}\right) = K\,\frac{R_PC_Ps + 1}{C_Ps}$$

在原点处只有**一个**极点，且

$$
\begin{aligned}
\frac{\omega_{out}}{\omega_{in}} &= \frac{L}{1 + L} = \frac{K(R_PC_Ps + 1)}{C_Ps + K(R_PC_Ps + 1)}\\
&= \frac{K(1 + R_PC_Ps)}{K + (1 + KR_P)\,C_Ps} .
\end{aligned}
$$

分母是一阶的，只有一个实数极点，位于

$$s = -\frac{K}{(1 + KR_P)\,C_P},$$

因此 $\omega_{out}$ 单调地趋近 $\omega_{in}$，环路无条件稳定。

### 第 5 步 — 大信号图像

频率误差较大时，泵电流近似恒定，$\overline{I_{CP}} \approx +I_P/2$ 到 $+I_P$（当 $\omega_{in} > \omega_{out}$ 时），因此电容电压线性地斜坡上升，

$$\frac{dV_{C_P}}{dt} = \frac{\overline{I_{CP}}}{C_P},$$

VCO 频率也以速率 $K_{VCO}\overline{I_{CP}}/C_P$ 线性上升。唯一储存的量是 $C_P$ 上的电荷：只有**一个状态变量**，是一阶系统（$R_P$ 只给 $V_{cont}$ 加上偏移量 $\overline{I_{CP}}R_P$，不储存任何东西）。一旦 $\omega_{out}$ 足够接近 $\omega_{in}$，使相位不再滑移，PFD 就重新对相位作出响应，VCO 的积分重新进入环路，环路又变回二阶。

### 结果

在频率捕获期间，PFD/电荷泵产生的平均电流由频率差 $\omega_{in} - \omega_{out}$ 而不是相位决定。因此被反馈的量是 VCO 的**频率**，它静态地依赖于控制电压（$\omega_{out} = \omega_0 + K_{VCO}V_{cont}$）：VCO 相当于增益 $K_{VCO}$，而不是锁相时所代表的积分器 $K_{VCO}/s$。原点处的两个极点之一从环路中消失，只剩下环路滤波器电容的积分，因此阶数从二阶降为一阶。若鉴频增益线性化为 $K_{FD}$，则 $\omega_{out}/\omega_{in} = K(1 + R_PC_Ps)/[K + (1 + KR_P)C_Ps]$，$K = K_{FD}K_{VCO}$，只有一个极点。

**常见错误。** 把阶数降低归因于环路滤波器，例如声称 $R_P$ 或 $C_P$ 实际上被断开了，或者电荷泵处于空闲状态。电荷泵和滤波器都在充分工作；消失的是 VCO 从频率到相位的积分。

**常见错误。** 只说“捕获期间环路是非线性的”。这并不能解释阶数为何降低；关键在于检测器不再感知相位，因此联系相位与频率的那个积分位于环路之外。
