对于异或门，鉴相器可用的零输出点位于 Δφ = 90°。在该点，输出处于其范围的中间（对于平衡的差分异或门为零），而且在它两侧输出都是线性的。很大的 $K_{PD}K_{VCO}$ 使锁定点只偏离这一零输出点很小的量。

- 异或门的平均输出随 Δφ 的变化是一个三角形：Δφ = 0 时为 0，π 时为 $V_0$，二者之间是线性的，斜率为 $K_{PD} = V_0/\pi$。
- 它关于 Δφ = 0 对称（在该点无法区分超前和滞后），而且其斜率在 0 和 π 处反向，因此无法在这些点上保持锁定。
- 以中间电平为参考（差分输出，或从 $V_0/2$ 开始计量的 $V_{PD}$），在 0 < Δφ < π 时输出为 $V_{PD} = K_{PD}(\Delta\phi - \pi/2)$。
- 锁定时，鉴相器必须提供使 $\omega_{out} = \omega_{in}$ 的控制电压：$K_{PD}(\Delta\phi - \pi/2) = (\omega_{in} - \omega_0)/K_{VCO}$，其中 $\omega_0$ 为控制电压处于中间电平时的 VCO 频率。
- 因此当 $K_{PD}K_{VCO}$ 很大时，$\Delta\phi = \dfrac{\pi}{2} + \dfrac{\omega_{in} - \omega_0}{K_{PD}K_{VCO}} \to 90^\circ$。
- 乘法器型鉴相器（输出 ∝ cos Δφ，在 90° 处为零）也是如此。90° 这一点还使工作点位于线性范围的中心，在增益反向之前留有 ±90° 的相位偏移余量。
