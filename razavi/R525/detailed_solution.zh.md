# 详细步骤 - R525

**思路。** 灰色区域包含的 $(I_D, g_m)$ 点，其比值 $g_m/I_D$ 超过了任何 MOSFET 所能达到的最大值，即弱反型中的 $1/(\xi V_T)$。因此它的边界是过原点的直线 $g_m = I_D/(\xi V_T)$，其斜率随 $\xi$ 变化。强反型只影响给定器件的曲线在何处离开这条直线。

### 第 1 步 — 为什么边界是一条过原点的直线

把 $k$ 个相同的器件并联、电流变为 $k$ 倍，在端电压相同的情况下，$I_D$ 和 $g_m$ 都乘以 $k$，因此任何工作点都可以沿一条过原点的直线移动（图中的点线就是把器件曲线上的一点移到 $(I_{D1}, g_{m1})$）。因此，一个组合可以实现，当且仅当其比值 $g_m/I_D$ 能在**某个**偏置下达到。该比值在弱反型中最大，$g_m/I_D = 1/(\xi V_T)$；在强反型中较小（例如平方律为 $2/(V_{GS} - V_{TH})$，一旦过驱动电压超过约 $2\xi V_T$，它就低于 $1/(\xi V_T)$）。

因此，**灰色区域**是 $g_m$ 轴与下面这条直线之间的楔形区域：

$$g_m = \frac{I_D}{\xi V_T},$$

即所有满足 $g_m/I_D > 1/(\xi V_T)$ 的点。

### 第 2 步 — $\xi = 1.5$ 和 $\xi = 1.0$ 时的边界斜率

$$\left.\frac{g_m}{I_D}\right|_{max,\ \xi = 1.5} = \frac{1}{1.5\times26\ \mathrm{mV}} = \frac{1}{39\ \mathrm{mV}} = 25.6\ \mathrm{V^{-1}},\qquad
\left.\frac{g_m}{I_D}\right|_{max,\ \xi = 1.0} = \frac{1}{1.0\times26\ \mathrm{mV}} = 38.5\ \mathrm{V^{-1}}.$$

边界的斜率增大的倍数为

$$\frac{38.5}{25.6} = \frac{1.5}{1.0} = 1.5 .$$

| $I_D$ | 最大 $g_m$，$\xi = 1.5$ | 最大 $g_m$，$\xi = 1.0$ |
|---|---|---|
| 10 µA | 0.26 mS | 0.38 mS |
| 100 µA | 2.56 mS | 3.85 mS |
| 1 mA | 25.6 mS | 38.5 mS |

边界线**向 $g_m$ 轴**旋转，因此灰色楔形区域变得**更窄**：无法实现的区域缩小了。所有满足 $25.6\ \mathrm{V^{-1}} < g_m/I_D < 38.5\ \mathrm{V^{-1}}$ 的点都变得可以实现；1 mA 的器件现在最多可以提供 38.5 mS，而不是 25.6 mS。

### 第 3 步 — 器件曲线本身的变化

强反型保持不变，因此只有弱反型段移动到更陡的直线 $g_m = I_D/V_T$ 上，并在**更低**的电流和跨导处与强反型曲线相交。对于平方律强反型曲线 $g_m = \sqrt{2\beta I_D}$（$\beta = \mu_nC_{ox}W/L$），转折点位于

$$\sqrt{2\beta I_D} = \frac{I_D}{\xi V_T} \quad\Longrightarrow\quad 2\beta I_D = \frac{I_D^2}{(\xi V_T)^2} \quad\Longrightarrow\quad I_{D,c} = 2\beta(\xi V_T)^2 .$$

- 从 $\xi = 1.5$ 变为 $1.0$，使 $I_{D,c}$ 乘以 $(1.0/1.5)^2 = 4/9 \approx 0.44$。
- 转折点跨导 $g_{m,c} = I_{D,c}/(\xi V_T) = 2\beta\xi V_T$ 减小为原来的 $2/3$。
- 由 $2I_D/V_{ov} = I_D/(\xi V_T)$ 得转折点的过驱动电压为 $V_{ov,c} = 2\xi V_T$，它从 $2\times1.5\times26 = 78$ mV 降到 $2\times26 = 52$ mV。

曲线先沿一条更陡的直线走过较短的一段，然后弯折到同一条强反型曲线上。

### 第 4 步 — 极限 $\xi = 1$

$\xi = 1 + C_{dep}/C_{ox} \ge 1$，亚阈值摆幅（subthreshold swing）为 $S = \xi V_T\ln10$：
- $\xi = 1.5$：$S = 1.5\times26\ \mathrm{mV}\times2.303 = 90$ mV/decade；
- $\xi = 1.0$：$S = 60$ mV/decade，这是室温下的理想极限。

因此，灰色区域不可能比 $\xi = 1$ 时更小，此时其边界 $g_m/I_D = q/(kT)$ 与双极晶体管（bipolar transistor）相同。

### 结果

无法实现的（灰色）区域**缩小**。其边界是弱反型直线 $g_m = I_D/(\xi V_T)$，即任何器件所能达到的最大 $g_m/I_D$（在 $W/L$ 足够大、处于深弱反型时）。当 $\xi = 1.0$ 时，这条直线的斜率增大到 1.5 倍，从 $1/(1.5\times26\ \mathrm{mV}) \approx 25.6\ \mathrm{V^{-1}}$ 增大到 $1/(26\ \mathrm{mV}) \approx 38.5\ \mathrm{V^{-1}}$，因此该直线向 $g_m$ 轴旋转，楔形区域变窄。$g_m/I_D$ 约在 26 到 38 V⁻¹ 之间的点变得可以实现；在 1 mA 时，最大 $g_m$ 从约 26 mS 增大到 38.5 mS。

曲线的强反型部分不动。对于给定器件，更陡的弱反型段在更低的电流（对平方律器件而言为原转折电流的 4/9）和更低的过驱动电压（52 mV，而不是 78 mV）处与之相交。$\xi = 1$（60 mV/decade）是物理极限，因此该区域不能再进一步缩小。

**常见错误。** 认为灰色区域会扩大。$\xi$ 越小，$g_m/I_D = 1/(\xi V_T)$ **越大**，即边界**越陡**，因此可以实现的组合更多。

**常见错误。** 把强反型曲线也一起移动。$\xi$ 只决定亚阈值区的指数特性，因此只有弱反型段（以及随之变化的灰色边界）发生改变。

**常见错误。** 认为边界与器件尺寸有关。同时按比例缩放 $W$ 和 $I_D$，会使任何点沿一条过原点的直线移动，因此边界只取决于 $g_m/I_D$。
