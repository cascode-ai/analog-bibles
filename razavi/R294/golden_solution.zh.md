记 $R = r_{O1}\|r_{O2}$，$g_m = g_{m1} + g_{m2}$：
$$Z_{in} = \frac{1}{C_1s} + \frac{1 + RC_2s}{C_2s\,[1 + (g_{m1} + g_{m2})R]} = \frac{1}{C_1s} + \frac{1}{[1 + (g_{m1}+g_{m2})R]\,C_2s} + \frac{R}{1 + (g_{m1}+g_{m2})R}$$
即 $C_1$、经密勒效应（Miller effect）倍增的 $C_2$（等于 $[1 + (g_{m1}+g_{m2})(r_{O1}\|r_{O2})]C_2$）以及电阻 $(r_{O1}\|r_{O2})/[1 + (g_{m1}+g_{m2})(r_{O1}\|r_{O2})] \approx 1/(g_{m1} + g_{m2})$ 三者串联。

推导：记节点 A（$M_1$ 与 $M_2$ 的栅极）和节点 D（漏极）。测试电流 $I_x$ 流经 $C_1$ 和 $C_2$ 进入 D：$I_x = (V_A - V_D)C_2s$。对 D 点列基尔霍夫电流定律（KCL）方程：$I_x = (g_{m1} + g_{m2})V_A + V_D/R$，因为两个晶体管都由 $V_A$ 驱动，反相器（inverter）的跨导（transconductance）为 $g_{m1} + g_{m2}$。消去 $V_D = V_A - I_x/(C_2s)$ 得 $I_x[1 + 1/(RC_2s)] = V_A(g_{m1} + g_{m2} + 1/R)$，因此 $V_A/I_x = (1 + RC_2s)/\{C_2s[1 + (g_{m1}+g_{m2})R]\}$；再加上 $1/(C_1s)$。
