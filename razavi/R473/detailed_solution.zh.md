# 详细步骤 - R473

**思路。** 当 $\beta = 1$ 时，环路增益就是放大器的传递函数。60° 的相位裕度确定了增益交点处的相位，由此得到交点频率 $f_u$；再令 $f_u$ 处的环路增益幅值等于 1，即可求出 $A_0$。

### 第 1 步 — 单位增益环路的环路增益

取 $f_{p1} = 10$ MHz、$f_{p2} = 500$ MHz、$\beta = 1$，环路增益为

$$H(jf) = \frac{A_0}{\left(1 + j\dfrac{f}{f_{p1}}\right)\left(1 + j\dfrac{f}{f_{p2}}\right)} ,$$

其幅值与相位分别为

$$
\begin{aligned}
|H(jf)| &= \frac{A_0}{\sqrt{1 + (f/f_{p1})^2}\,\sqrt{1 + (f/f_{p2})^2}},\\
\angle H(jf) &= -\tan^{-1}\frac{f}{f_{p1}} - \tan^{-1}\frac{f}{f_{p2}} .
\end{aligned}
$$

在增益交点 $f_u$ 处，$|H(jf_u)| = 1$，且 $\mathrm{PM} = 180° + \angle H(jf_u)$。

### 第 2 步 — 相位条件：求交点频率

PM = 60° 意味着

$$
\begin{aligned}
180° + \angle H(jf_u) &= 60°\\
\angle H(jf_u) &= -120°\\
\tan^{-1}\frac{f_u}{f_{p1}} + \tan^{-1}\frac{f_u}{f_{p2}} &= 120° .
\end{aligned}
$$

令 $x = f_u/f_{p1} = f_u/10$，$y = f_u/f_{p2} = f_u/500$（$f_u$ 以 MHz 为单位），利用 $\tan(a + b) = (\tan a + \tan b)/(1 - \tan a\tan b)$ 和 $\tan 120° = -\sqrt3$，对两边取正切：

$$\frac{x + y}{1 - xy} = -\sqrt3 .$$

代入 $x + y = f_u\left(\tfrac{1}{10} + \tfrac{1}{500}\right) = 0.102\,f_u$ 和 $xy = f_u^2/5000$：

$$
\begin{aligned}
0.102\,f_u &= -\sqrt3\left(1 - \frac{f_u^2}{5000}\right)\\
0.102\,f_u &= -\sqrt3 + \frac{\sqrt3}{5000}f_u^2\\
f_u^2 - \frac{0.102\times5000}{\sqrt3}f_u - 5000 &= 0\\
f_u^2 - 294.45\,f_u - 5000 &= 0 .
\end{aligned}
$$

正根为

$$f_u = \frac{294.45 + \sqrt{294.45^2 + 4\times5000}}{2} = \frac{294.45 + \sqrt{86\,700 + 20\,000}}{2} = \frac{294.45 + 326.65}{2} = 310.5\ \mathrm{MHz}.$$

**验证。** 当 $x = 31.05$、$y = 0.621$ 时：

$$\tan^{-1}(31.05) = 88.16°, \qquad \tan^{-1}(0.621) = 31.84°, \qquad \text{sum} = 120.00°.\ \checkmark$$

由于 $xy = 19.3 > 1$，两角之和位于 90° 与 180° 之间，因此该根对应 120° 的解，而不是正切值相同的 $-60°$。

第一个极点比 $f_u$ 低 31 倍，已贡献了几乎全部 90° 的相移，因此 60° 的裕度主要是把第二个极点的相移限制在约 30°（此处为 31.8°），这使 $f_u$ 远低于 500 MHz。

### 第 3 步 — 幅值条件：求 $A_0$

$$\frac{A_0}{\sqrt{1 + x^2}\,\sqrt{1 + y^2}} = 1 \quad\Longrightarrow\quad A_0 = \sqrt{1 + x^2}\,\sqrt{1 + y^2},$$

其中

$$
\begin{aligned}
\sqrt{1 + x^2} &= \sqrt{1 + 31.05^2} = \sqrt{1 + 964.4} = \sqrt{965.4} = 31.07,\\
\sqrt{1 + y^2} &= \sqrt{1 + 0.621^2} = \sqrt{1 + 0.386} = \sqrt{1.386} = 1.177 .
\end{aligned}
$$

因此

$$A_0 = 31.07\times1.177 = 36.6 .$$

更大的 $A_0$ 会把交点推到 310.5 MHz 以上，那里的相位更负，相位裕度将低于 60°。此时闭环增益（closed-loop gain）为 $A_0/(1 + A_0) = 36.6/37.6 = 0.973$，接近预期值 1。

### 第 4 步 — 常用的快速近似

假设第一个极点在 $f_u$ 处恰好贡献 90°（$f_u \gg f_{p1}$），并取 $\sqrt{1 + x^2} \approx x$，则第二个极点必须恰好贡献 30°：

$$f_u \approx f_{p2}\tan30° = 500\ \mathrm{MHz}\times0.5774 = 288.7\ \mathrm{MHz},$$

$$A_0 \approx \frac{f_u}{f_{p1}}\sqrt{1 + \left(\frac{f_u}{f_{p2}}\right)^2} = 28.87\times\sqrt{1 + \tfrac13} = 28.87\times1.155 = 33.3 .$$

这一结果约偏低 10 %：第一个极点实际只贡献 88.2° 而不是 90°，因此第二个极点可以贡献 31.8° 而不是 30°，这使交点上移到 310.5 MHz，$A_0$ 也随之增大。

### 结果

$$A_0 \approx 36.6,$$

增益交点位于 $f_u \approx 310.5$ MHz，两个极点在该处共贡献 $88.2° + 31.8° = 120°$ 的相移（PM = 60°）。若粗略地认为第一个极点恰好贡献 90°，则得到 $f_u \approx 289$ MHz 和 $A_0 \approx 33$。

**常见错误。** 把“PM = 60°”理解为“交点处的环路相位为 $-60°$”。$f_u$ 处的相位必须为 $-120°$；按错误的条件，交点会落在 16 MHz 附近，并得到 $A_0 \approx 1.9$，这个值太小了。

**常见错误。** 把交点近似为 $f_u \approx 289$ MHz 之后，又忽略第二个极点的幅值因子，即取 $A_0 \approx f_u/f_{p1} = 28.9$。在 $f_u$ 处，第二个极点已经使环路增益衰减了 1.15–1.18 倍，这一点必须计入。
