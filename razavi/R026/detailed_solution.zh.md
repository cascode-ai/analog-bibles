# 详细步骤 - R026

**思路。** $M_1$ 与电流源 $I_1$ 串联，因此只要电流源能够正常工作，无论处于哪个工作区，它都必须承载 $I_1$，电容以恒定速率 $I_1/C_1$ 放电。跟踪 $M_1$ 经历饱和区和线性区的过程，说明其源极电压会自行调整以保持电流为 $I_1$；然后讨论当电流源的电压余度（headroom）耗尽时斜坡如何结束。

### 第 1 步 — 恒定电流，线性下降

把 $M_1$ 的源极节点记为 S（电压为 $V_S$）。该节点只由 $M_1$ 供给电流，并只由 $I_1$ 抽走电流，因此

$$I_X = I_1 ,$$

又因为 $I_X$ 来自 $C_1$，

$$C_1\frac{dV_X}{dt} = -I_X = -I_1 \quad\Longrightarrow\quad V_X(t) = 3\ \mathrm{V} - \frac{I_1}{C_1}\,t .$$

所以只要电流源持续吸收 $I_1$，**$V_X$ 就线性下降**，$I_X$ 保持恒定。晶体管并不决定电流，只决定节点 S 的电压；接下来的几步将验证在斜坡期间 $M_1$ 始终能够承载 $I_1$。取 $V_{TH} \approx 0.7$ V；题中没有给出体效应（body effect）参数，而且只要 $V_S$ 保持在某个固定值附近，阈值电压（threshold voltage）本来就是恒定的。

### 第 2 步 — 阶段 1：$M_1$ 饱和，$V_S$ 恒定

起初 $V_X = 3$ V，饱和区中 $I_D = I_1$，

$$I_1 = \tfrac12\beta\,(V_b - V_S - V_{TH})^2 \quad\Longrightarrow\quad V_S = V_b - V_{TH} - \sqrt{\frac{2I_1}{\beta}} ,$$

它是**恒定的**：$M_1$ 是一个源极跟随器（source follower），其源极电位比固定的栅极低一个 $V_{GS}$。假设 $V_b$ 足够大，使 $V_S \ge 0$（更准确地说，至少等于电流源所需的最低电压）。饱和要求

$$
\begin{aligned}
V_X - V_S &\ge V_b - V_S - V_{TH}\\
V_X &\ge V_b - V_{TH},
\end{aligned}
$$

因此只要漏极电位高于 $V_b - V_{TH}$，阶段 1 就持续（若 $V_b - V_{TH} \ge 3$ V，$M_1$ 直接从线性区开始，跳过阶段 1），结束于

$$t_1 = \frac{C_1\,[3\ \mathrm{V} - (V_b - V_{TH})]}{I_1} .$$

### 第 3 步 — 阶段 2：$M_1$ 处于线性区，电流仍为 $I_1$

当 $V_X < V_b - V_{TH}$ 时，

$$I_1 = \beta\left[(V_b - V_S - V_{TH})(V_X - V_S) - \tfrac12(V_X - V_S)^2\right].$$

电流源强制电流为 $I_1$，因此 $V_S$ 会移动：随着 $V_X$ 下降，$V_S$ 也随之下降，这会**增大** $V_{GS} = V_b - V_S$，使导通电阻（on-resistance）减小，并**减小** $V_{DS} = V_X - V_S$。两者的作用合起来仍恰好给出 $I_1$，因此 **$I_X = I_1$，线性斜坡在转换前后保持不变**；只有内部节点 S 的行为发生变化（阶段 1 中恒定，阶段 2 中下降）。

当 $V_{DS}$ 较小时，线性区器件大致相当于一个电阻 $R_{on} = 1/[\beta(V_b - V_S - V_{TH})]$，因此 $V_S$ 跟随 $V_X$ 下降，始终比它低约 $I_1R_{on}$；随着 $V_{GS}$ 增大，这一差值缩小，因此 $V_S$ 比 $V_X$ 下降得慢。

### 第 4 步 — 斜坡如何结束

**理想**电流源在任何电压下都会持续吸收 $I_1$，因此 $V_X$（以及比它更低的 $V_S$）会无限下降，这在物理上是不可能的。实际上，当节点 S 到达电流源工作范围的底端 $V_{S,\min}$ 时，斜坡就结束了：

- **实际的（由晶体管构成的）电流源。** 它需要一个最低电压（即其自身的饱和电压，几百毫伏，在本草图的尺度上大约为 0 V）。当 $V_S$ 达到这一电平时，$V_X$ 仍比它高约 $I_1R_{on}$。此后电流源中的晶体管进入线性区，其电流下降；$M_1$ 和该器件相当于两个串联的电阻对 $C_1$ 放电，因此 **$I_X \to 0$**，过程平滑，**$V_X$ 大致按指数规律滑落到 $V_S$ 的电平，即接近 0 V**。
- **理想电流源配合实际的 $M_1$。** $M_1$ 的衬底接地，当 $V_S$ 降到约 $-0.6$ 至 $-0.7$ V 时，源-衬底结正向偏置（forward-biased），改由衬底而不是电容提供 $I_1$。随后沟道电流衰减到零，$V_X$ 稳定在 $V_S \approx -0.6$ 至 $-0.7$ V 附近，漏-衬底结（drain–bulk junction）也会把它钳位（clamp）在这一电平。

无论哪种情况，线性斜坡都一直持续到 $V_X \approx V_{S,\min} + I_1R_{on}$，即持续时间略短于 $3C_1/I_1$，随后是一段短暂的圆滑拖尾，其间 $I_X$ 降到零。

### 第 5 步 — 数值示例

取 $I_1 = 1$ mA，$C_1 = 1$ pF，$\beta = 2\ \mathrm{mA/V^2}$，$V_b = 2$ V。

$$
\begin{aligned}
\frac{dV_X}{dt} &= -\frac{I_1}{C_1} = -\frac{1\ \mathrm{mA}}{1\ \mathrm{pF}} = -1\ \mathrm{V/ns},\\
\sqrt{\frac{2I_1}{\beta}} &= \sqrt{\frac{2\ \mathrm{mA}}{2\ \mathrm{mA/V^2}}} = 1\ \mathrm{V},\\
V_S\ (\text{phase 1}) &= 2 - 0.7 - 1 = 0.3\ \mathrm{V},\\
\text{phase 1 ends at } V_X &= V_b - V_{TH} = 1.3\ \mathrm{V}, \quad t_1 = \frac{(1\ \mathrm{pF})(3 - 1.3)\ \mathrm{V}}{1\ \mathrm{mA}} = 1.7\ \mathrm{ns}.
\end{aligned}
$$

从 1.7 ns 起，$M_1$ 处于线性区，$V_S$ 从 0.3 V 开始随 $V_X$ 一起下降。令 $d = V_{DS} = V_X - V_S$，线性区方程 $2\ \mathrm{mA/V^2}\,[(1.3 - V_X + d)d - \tfrac12d^2] = 1$ mA 以伏特为单位写成

$$d^2 + 2\,(1.3 - V_X)\,d - 1 = 0 .$$

- $V_X = 1.3$ V 时：$d = 1$ V，因此 $V_S = 0.3$ V（与阶段 1 连续）。
- $V_X = 0.8$ V 时：$d^2 + d - 1 = 0$，因此 $d = 0.618$ V，$V_S = 0.18$ V。
- 当 $d = V_X$，即 $V_X^2 - 2.6V_X + 1 = 0$ 时，$V_S$ 降到 0，解得 $V_X = 0.47$ V（在 $t \approx 2.5$ ns 时）。

低于该值后，实际的电流源电压余度耗尽：$I_X$ 衰减，$V_X$ 以拖尾的形式趋向 0 V。

| $t$ (ns) | $V_X$ (V) | $V_S$ (V) | $M_1$ | $I_X$ |
|---|---|---|---|---|
| 0 | 3.0 | 0.3 | 饱和区 | 1 mA |
| 1.0 | 2.0 | 0.3 | 饱和区 | 1 mA |
| 1.7 | 1.3 | 0.3 | 边界 | 1 mA |
| 2.2 | 0.8 | 0.18 | 线性区 | 1 mA |
| 2.5 | 0.47 | ≈ 0 | 线性区 | 1 mA，随后下降 |
| ≳ 3 | → 0 | ≈ 0 | 线性区 | → 0 |

### 结果

- $M_1$ 传输串联电流源的电流，因此 **$I_X = I_1$**（恒定），**$V_X$ 从 3 V 开始以斜率 $-I_1/C_1$ 线性下降**。
- **阶段 1**（$V_X > V_b - V_{TH}$）：$M_1$ 处于饱和区，$V_S = V_b - V_{TH} - \sqrt{2I_1/\beta}$ 恒定（假设 ≥ 0），$I_X = I_1$，$dV_X/dt = -I_1/C_1$。
- **阶段 2**（$V_X < V_b - V_{TH}$）：$M_1$ 处于线性区。它仍然承载 $I_1$，因为 $V_S$ 随 $V_X$ 一起下降（$V_{GS}$ 增大，$V_{DS}$ 减小），所以**线性斜坡以相同的斜率继续**。
- **结束：** 理想电流源会把两个节点无限地向下拉。实际上，当电流源自身的电压 $V_S$ 达到其最小值时，$I_1$ 就会停止：对实际的电流源约为 0 V，或者约为 $-0.7$ V，此时源-衬底结开始提供电流。经过一段短暂的圆滑拖尾后，$I_X \to 0$，$V_X$ 稳定在与 $V_S$ 大致相同的电平（≈ 0 V）。

**常见错误。** 从一开始就画成类似 $RC$ 的指数放电，或者用平方律（square law）由 $V_b$ 计算 $I_X$。电流由 $I_1$ 固定；$M_1$ 只决定节点 S 的电压。

**常见错误。** 认为 $M_1$ 一离开饱和区，$I_X$ 就开始衰减。源极节点只是向下移动，使 $M_1$ 继续承载 $I_1$；只有当电流源的电压余度耗尽时，电流才会下降。

**常见错误。** 让 $V_X$ 稳定在 $V_b - V_{TH}$。那只是 $M_1$ 从饱和区转入线性区的位置；放电并不会在那里停止。
