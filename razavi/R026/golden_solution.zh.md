$M_1$ 传输电流 $I_1$，因此 $I_X = I_1$，$V_X$ 以 $I_1/C_1$ 的速率线性下降。只要电流源仍能吸收 $I_1$，这一斜坡就会持续；对于实际的电流源，$V_X$ 随后在 0 V 附近趋于平稳（此时源极节点到达其范围的底端），$I_X$ 降为零。
- 阶段 1，$V_X > V_b - V_{TH}$：$M_1$ 处于饱和区（saturation region），$V_S = V_b - V_{TH} - \sqrt{2I_1/\beta}$ 恒定（假设 ≥ 0），$I_X = I_1$，$dV_X/dt = -I_1/C_1$。
- 阶段 2，$V_X < V_b - V_{TH}$：$M_1$ 处于线性区（triode region）；它仍然承载 $I_1$，因为 $V_S$ 随 $V_X$ 一起下降（$V_{GS}$ 增大，$V_{DS}$ 减小），所以线性斜坡继续。
- 结束：理想电流源会把两个节点无限地向下拉；实际上，当电流源自身的电压 $V_S$ 达到其最小值时，$I_1$ 就会停止——该最小值约为 0 V，或者约为 −0.7 V，此时源-衬底结（source–substrate junction）开始提供电流。此后 $I_X \to 0$，$V_X$ 稳定在与 $V_S$ 大致相同的电平（≈ 0 V）。
