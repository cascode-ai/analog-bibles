# 详细步骤 - R425

**思路。** 输出端接到 $M_2$ 的栅极后，该运算放大器（op amp）就成为单位增益缓冲器（unity-gain buffer）：两个输入栅极都跟随 $V_{out}$。先求出由 $V_b$ 和 PMOS 电流镜（current mirror）确定的节点电压，再把每个晶体管的饱和条件写成对 $V_{out}$ 的约束；其中最紧的约束给出摆幅。

### 第 1 步 — 过驱动电压（overdrive voltage）与固定的节点电压

由于反馈，$V_{in} \approx V_{out}$，每条支路的电流为 0.5 mA。对于 NMOS 器件（$W/L = 200$）：

$$
\begin{aligned}
V_{OD1\text{–}4} &= \sqrt{\frac{2(0.5\ \mathrm{mA})}{(134\ \mu\mathrm{A/V^2})(200)}} = \sqrt{0.0373\ \mathrm{V^2}} = 0.193\ \mathrm{V},\\
V_{GS1\text{–}4} &= 0.7 + 0.193 = 0.893\ \mathrm{V}.
\end{aligned}
$$

节点 X 位于共源共栅（cascode）管 $M_4$ 的源极和 $M_2$ 的漏极处，其电压为

$$V_X = V_b - V_{GS4} = 1.4 - 0.893 = 0.507\ \mathrm{V},$$

$M_3$ 的源极（$M_1$ 的漏极）也处于同样的 0.507 V，与 $V_{out}$ 无关。对于 PMOS 器件（$W/L = 106/0.5 = 212$）：

$$|V_{OD5\text{–}8}| = \sqrt{\frac{2(0.5\ \mathrm{mA})}{(38.4\ \mu\mathrm{A/V^2})(212)}} = \sqrt{0.1228\ \mathrm{V^2}} = 0.350\ \mathrm{V},\qquad |V_{GS}| = 1.150\ \mathrm{V}.$$

$M_5$ 和 $M_6$ 的栅极接在 $M_3$ 的漏极，比 $V_{DD}$ 低两个二极管压降（$M_7$ 叠在 $M_5$ 之上）：

$$V_{G6} = V_{DD} - 2|V_{GS}| = 3 - 2.30 = 0.70\ \mathrm{V}.$$

### 第 2 步 — 下限：$M_4$ 必须保持饱和

$M_4$ 的栅极接 $V_b$，漏极接 $V_{out}$：

$$V_{out} \ge V_b - V_{TH4} = 1.4 - 0.7 = 0.70\ \mathrm{V}.$$

### 第 3 步 — 上限：$M_2$（以及 $M_1$）必须保持饱和

$M_2$ 的栅极接 $V_{out}$，漏极接固定的节点 X，因此要求 $V_X \ge V_{G2} - V_{TH2}$：

$$
\begin{aligned}
0.507 &\ge V_{out} - 0.7\\
V_{out} &\le 0.507 + 0.7 = 1.207\ \mathrm{V}.
\end{aligned}
$$

$M_1$ 给出同样的限制（栅极接 $V_{in} \approx V_{out}$，漏极为 0.507 V）。用符号表示，$V_{out,max} = V_b - V_{GS4} + V_{TH2}$：$V_{out}$ 升高会使输入栅极升高，而共源共栅管把输入管的漏极钳定，从而把输入对管推向线性区（triode region）。

### 第 4 步 — 其他器件不限制摆幅

- **$M_6$：** 栅极为 0.70 V，因此只要 $V_{out} \le V_{G6} + |V_{THP}| = 0.70 + 0.8 = 1.50$ V，它就保持饱和，这高于 1.207 V 的限制。
- **$M_8$：** 其漏极即 $M_6$ 的源极，电压为 $V_{G6} + |V_{GS6}| = 0.70 + 1.15 = 1.85$ V，因此无论 $V_{out}$ 为多少，都有 $|V_{DS8}| = 1.15\ \mathrm{V} > 0.35$ V。
- **$M_5$、$M_7$：** 二极管连接（diode-connected），总是饱和。
- **$M_3$：** 漏极为 0.70 V，源极为 0.507 V，因此 $V_{DS3} = 0.19$ V，按 PMOS 宽度的设计恰好处于饱和边缘，且与 $V_{out}$ 无关。

### 第 5 步 — 摆幅

$$\text{swing} = V_{out,max} - V_{out,min} = 1.207 - 0.70 = 0.51\ \mathrm{V}.$$

$V_{out,max} - V_{out,min} = (V_b - V_{GS4} + V_{TH}) - (V_b - V_{TH}) = V_{TH} - V_{OD4} = 0.7 - 0.193$ V，与 $V_b$ 无关：套筒式运放（telescopic op amp）不适合用作单位增益缓冲器。

**关于尾电流源的说明。** 尾节点电压为 $V_P = V_{out} - V_{GS1}$，在范围的底端它为负值（$-0.19$ V）；只是因为 $I_{SS}$ 是理想的，这才被允许。若实际的尾电流管（tail transistor）需要 $V_P \ge 0$，下限将变为 $V_{GS1} = 0.89$ V，摆幅缩小到约 0.31 V。

### 结果

$$V_b - V_{TH4} \le V_{out} \le V_b - V_{GS4} + V_{TH2}\ \Longrightarrow\ 0.70\ \mathrm{V} \le V_{out} \le 1.21\ \mathrm{V},$$

因此最大输出摆幅约为 **0.51 V**（$= V_{TH} - V_{OD4}$）。下限由 $M_4$ 决定，上限由栅极跟随输出的 $M_2$（以及 $M_1$）决定。

**常见错误。** 给出套筒式结构开环时的摆幅，即 $V_{DD}$ 减去叠接的各过驱动电压（约 2 V 或更大）。输入栅极接到输出端后，摆幅受输入对管饱和条件的限制。

**常见错误。** 把 $V_{in}$ 当作固定值，于是 $M_1$/$M_2$ 看起来不构成上限。在单位增益缓冲器中，输入随输出变化。

**常见错误。** 用栅源电压代替阈值电压，例如写成 $V_{out} \ge V_b - V_{GS4}$。NMOS 的漏极可以低到 $V_G - V_{TH}$。
