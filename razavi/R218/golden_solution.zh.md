这一结论仍然成立，因为电路仍然是对称且线性的：相同的器件接相同的负载，在大小相等、方向相反的输入驱动下，各处的变化也大小相等、方向相反，而位于对称轴上的公共节点 P 只能保持不动。
- 直观理解：当 $I_1$ 增加 δ 时，$D_1$ 的漏极下降 $R_D\delta$，这通过 $r_O$ 使 $I_1$ 略微减小；另一边 $I_2$ 减小 δ，其漏极上升 $R_D\delta$，使 $I_2$ 略微增大。这两项修正大小相等、方向相反，因此无需 $V_P$ 的任何变化，$I_1 + I_2$ 就保持为 $I_T$；两个漏极反对称地变化，因此哪一边都不会“拉动” P。
- 戴维南等效电路（Thevenin equivalent）观点：从 P 看进去，每半边（器件 + 负载）都是电压源 $V_T = \dfrac{g_mr_O}{1+g_mr_O}V_{in}$ 串联电阻 $R_T = \dfrac{R_D + r_O}{1 + g_mr_O}$。负载相等时，两个 $R_T$ 相等，两个 $V_T$ 的变化大小相等、方向相反，因此 $V_P$ 不变。
- 严格验证：$\Delta I_1 + \Delta I_2 = 0$，且 $\Delta V_X + \Delta V_Y = -R_D(\Delta I_1 + \Delta I_2) = 0$，因此把两个器件的方程相加得 $-2g_m\Delta V_P - 2\Delta V_P/r_O = 0$，即 $\Delta V_P = 0$。
- 负载相等是关键：负载不等时，两个 $R_T$ 不同，P 就会移动。
