从 $t = 0^+$ 起，$V_X$ 恒定在 $V_{DD} - 0.8 - \sqrt{I_{SS}/[\mu_pC_{ox}(W/L)_3]}$，$V_P = 1.5 - V_{GS1}(I_{SS}/2)$ 也恒定。$V_Y$ 从 $V_P$ 开始上升：起初以 $I_{SS}/(2C_1)$ 的斜率线性上升，随后由于处于线性区（triode region）的 $M_2$ 分走越来越多的电流而变慢，并按双曲规律趋近饱和区（saturation region）边缘 $1.5 - V_{TH2}$；当 λ > 0 时，它随后继续缓慢地趋向其终值 $V_X$。

- 基尔霍夫电流定律（KCL）：$|I_{D3}| = I_{D1}$，$|I_{D4}| = I_{D2} + I_C$，$I_{D1} + I_{D2} + I_C = I_{SS}$，$|I_{D4}| = |I_{D3}|$ → 始终有 $I_{D1} = I_{SS}/2$：$V_X$ 和 $V_P$ 都是固定的。
- 在 $t = 0^+$ 时，$V_{DS2} = 0$，因此 $I_{D2} = 0$，$I_C = I_{SS}/2$。
- 令 $v = V_Y - V_P$，$M_2$ 处于线性区时：$I_C = \tfrac{\beta}{2}(V_{ov} - v)^2$，因此 $v(t) = V_{ov}[1 - 1/(1+t/\tau)]$，$\tau = 2C_1/g_m$（$g_m$ 取 $M_2$ 在 $I_{SS}/2$ 下的值）。
- 高于 $1.5 - V_{TH2}$ 后，只有 λ 引起的不平衡电流给该节点充电，时间常数的量级为 $C_1(r_{O2}\|r_{O4})$。
