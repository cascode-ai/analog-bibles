# 详细步骤 - R115

**思路。** $M_1$ 是一个共栅级（栅极接直流偏置，输入加在源极，输出取自漏极），其负载为 PMOS 共源共栅结构 $M_2$–$M_3$。先把共源共栅负载化简为单个电阻 $R_L$，再在输出端列 KCL，解出 $v_{out}/v_{in}$。

### 第 1 步 — 共源共栅负载的电阻 $R_L$

把 $M_3$ 与 $M_2$ 之间的节点记为节点 $P$。偏置电压和 $V_{DD}$ 都是交流地，且 $\gamma = 0$。在输出端加测试电压 $v_x$（去掉 $M_1$），求向上流入 $M_2$ 漏极、再经 $M_3$ 流到 $V_{DD}$ 的电流 $i_x$。

<!-- diagram: diagram-01.cir -->

$M_3$ 的 $v_{gs3} = 0$，因此它只相当于从 $P$ 接到交流地的 $r_{O3}$，且 $v_P = i_xr_{O3}$。对于 $M_2$，$v_{gs2} = 0 - v_P = -v_P$，其漏源电流为 $i_x$：

$$i_x = g_{m2}v_{gs2} + \frac{v_{ds2}}{r_{O2}} = -g_{m2}v_P + \frac{v_x - v_P}{r_{O2}}.$$

代入 $v_P = i_xr_{O3}$，并乘以 $r_{O2}$：

$$i_xr_{O2} = -g_{m2}r_{O2}r_{O3}\,i_x + v_x - i_xr_{O3},$$

$$R_L = \frac{v_x}{i_x} = r_{O2} + r_{O3} + g_{m2}r_{O2}r_{O3} \approx g_{m2}r_{O2}r_{O3}\quad(g_{m2}r_{O2} \gg 1).$$

共源共栅结构把 $r_{O3}$ 放大了约本征增益（intrinsic gain）$g_{m2}r_{O2}$ 倍。

### 第 2 步 — 共栅级的小信号模型（small-signal model）

理想信号源把 $M_1$ 的源极电压强制为 $v_{in}$。$M_1$ 的栅极接交流地，因此 $v_{gs1} = -v_{in}$：受控源 $g_{m1}v_{gs1} = -g_{m1}v_{in}$ 从 out（漏极）流向 in（源极），$r_{O1}$ 接在 out 与 in 之间。负载 $R_L$ 从 out 接到交流地。

### 第 3 步 — 输出节点的 KCL

电流经 $R_L$ 和 $M_1$ 流出输出端，后者的 $r_{O1}$ 中流过 $(v_{out} - v_{in})/r_{O1}$：

$$\frac{v_{out}}{R_L} + \left[-g_{m1}v_{in} + \frac{v_{out} - v_{in}}{r_{O1}}\right] = 0.$$

把 $v_{out}$ 项和 $v_{in}$ 项分开：

$$v_{out}\left(\frac{1}{R_L} + \frac{1}{r_{O1}}\right) = v_{in}\left(g_{m1} + \frac{1}{r_{O1}}\right).$$

两边同乘 $R_Lr_{O1}$：

$$v_{out}\,(r_{O1} + R_L) = v_{in}\,(1 + g_{m1}r_{O1})\,R_L,$$

$$A_v = \frac{v_{out}}{v_{in}} = \frac{(1 + g_{m1}r_{O1})\,R_L}{r_{O1} + R_L}.$$

这里的因子是 $(1 + g_{m1}r_{O1})$ 而不是 $g_{m1}r_{O1}$，因为抬高源极既会降低 $v_{gs1}$，也会改变 $v_{ds1}$，而二者都会减小 $M_1$ 从输出端吸取的电流。

### 第 4 步 — 最终表达式与近似

代入第 1 步求得的 $R_L$：

$$A_v = \frac{(1 + g_{m1}r_{O1})\,(r_{O2} + r_{O3} + g_{m2}r_{O2}r_{O3})}{r_{O1} + r_{O2} + r_{O3} + g_{m2}r_{O2}r_{O3}}.$$

$R_L \approx g_{m2}r_{O2}r_{O3}$ 比 $r_{O1}$ 大约 $g_{m2}r_{O2} \gg 1$ 倍，因此 $R_L/(r_{O1} + R_L) \approx 1$，且

$$A_v \approx 1 + g_{m1}r_{O1} \approx g_{m1}r_{O1}.$$

**直观理解。** 由于负载近似为理想电流源，$M_1$ 的电流几乎不能变化。若 $v_{in}$ 升高 $\Delta v$，则 $v_{gs1}$ 降低 $\Delta v$；为保持电流不变，$v_{ds1}$ 必须升高 $g_{m1}r_{O1}\Delta v$，因此漏极沿与输入相同的方向变化 $(1 + g_{m1}r_{O1})\Delta v$。该级为**同相**放大，增益接近 $M_1$ 的本征增益。

### 结果

$$A_v = \frac{(1 + g_{m1}r_{O1})\,R_L}{r_{O1} + R_L},\qquad R_L = r_{O2} + r_{O3} + g_{m2}r_{O2}r_{O3},$$

增益为正（同相）。由于 $R_L \gg r_{O1}$，$A_v \approx 1 + g_{m1}r_{O1}$。

**常见错误。** 忽略共源共栅结构，把负载只取为 $r_{O3}$（或 $r_{O2}$）。这样只能得到约 $(1 + g_{m1}r_{O1})r_{O3}/(r_{O1} + r_{O3})$，在各 $r_O$ 相近时约为正确值的一半。

**常见错误。** 得出负增益，或者把 $M_1$ 当成共源（common-source）器件。输入驱动的是 $M_1$ 的**源极**：抬高源极会降低 $v_{gs1}$，并减小从输出端吸取的电流，因此输出电压升高。

**常见错误。** 写成 $A_v = g_{m1}R_L$（这是 $r_{O1} = \infty$ 时的共栅级增益）。当负载大到 $R_L \approx g_{m2}r_{O2}r_{O3}$ 时，$r_{O1}$ 把增益限制在约 $1 + g_{m1}r_{O1}$，远低于 $g_{m1}R_L$。
