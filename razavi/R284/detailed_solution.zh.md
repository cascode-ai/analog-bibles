# 详细步骤 - R284

**思路。** 把电源变化 $v_{dd}$ 当作一个小信号源，两个输入都接交流地。$M_3$ 流过固定电流，因此其栅极跟随 $V_{DD}$ 变化；于是 $M_4$ 的栅源电压不变，$M_4$ 的行为就像一个接到电源的单纯电阻 $r_{O4}$。在 P 和输出节点列 KCL，即可说明输出精确地跟随电源变化。最后计算差模增益，以表示电源抑制能力。

### 第 1 步 — $M_3$/$M_4$：栅极跟随电源

$M_3$ 的电流由理想电流源固定，因此 $V_{SG3}$ 固定，公共栅极节点的变化量恰好为 $v_{dd}$。于是

$$v_{sg4} = v_{dd} - v_{dd} = 0,$$

因此 $M_4$ 的受控电流不变，$M_4$ 只剩下接在电源与输出之间的输出电阻（output resistance）：

$$i_{D4}\ (\text{into the output}) = \frac{v_{dd} - v_{out}}{r_{O4}} .$$

### 第 2 步 — 差分对（differential pair）的小信号方程

用 $g_m$、$r_O$ 描述相同的 $M_1$、$M_2$。$M_1$ 的漏极接电源（$v_{dd}$），栅极接交流地，源极电压为 $v_P$；$M_2$ 与之相同，只是其漏极接输出。忽略体效应（body effect）：

$$
\begin{aligned}
i_1\ (\text{supply} \to \text{P}) &= -g_m\,v_P + \frac{v_{dd} - v_P}{r_O},\\
i_2\ (\text{out} \to \text{P}) &= -g_m\,v_P + \frac{v_{out} - v_P}{r_O}.
\end{aligned}
$$

**节点 P 的 KCL**（理想尾电流源没有小信号电流），$i_1 + i_2 = 0$：

$$
\begin{aligned}
-2g_mv_P + \frac{v_{dd} + v_{out} - 2v_P}{r_O} &= 0\\
v_P &= \frac{v_{dd} + v_{out}}{2\left(1 + g_mr_O\right)} .
\end{aligned}
$$

把它代回 $i_2$：

$$i_2 = \frac{v_{out}}{r_O} - \frac{1 + g_mr_O}{r_O}\,v_P = \frac{v_{out}}{r_O} - \frac{v_{dd} + v_{out}}{2r_O} = \frac{v_{out} - v_{dd}}{2r_O} .$$

（若计入体效应，$v_P$ 中的 $g_m$ 变为 $g_m + g_{mb}$，而 $i_2$ 不变。）从输出端看，经 $M_2$、P 和 $M_1$ 回到电源的通路相当于一个**接到 $V_{DD}$** 而不是接地的电阻 $2r_O$。

### 第 3 步 — 电源增益

**输出节点的 KCL**（无负载），$i_{D4} = i_2$：

$$
\begin{aligned}
\frac{v_{dd} - v_{out}}{r_{O4}} &= \frac{v_{out} - v_{dd}}{2r_O}\\
(v_{dd} - v_{out})\left(\frac{1}{r_{O4}} + \frac{1}{2r_O}\right) &= 0\\
v_{out} &= v_{dd}.
\end{aligned}
$$

$$A_{sup} = \frac{\Delta V_{out}}{\Delta V_{DD}} = 1 .$$

**物理验证。** 若输出精确地随电源移动，则 $M_4$ 的 $V_{SD}$ 和 $V_{SG}$ 都不变，因此其电流不变。$M_1$ 和 $M_2$ 的漏极都移动 $\Delta V_{DD}$，因此由对称性，它们的电流保持相等，而在理想尾电流源下，各自保持为 $I_{SS}/2$（节点 P 只移动 $\Delta V_{DD}/(1 + g_mr_O)$）。所有 KCL 方程都得到满足，而线性方程组的解是唯一的。输出端经两个电阻（$r_{O4}$ 和等效的 $2r_O$）接到电源，而没有任何通路接地，因此它只能跟随电源。

### 第 4 步 — 差模增益与电源抑制

**跨导（transconductance）。** 输出短路且 $v_{1,2} = \pm v_d/2$ 时，对称性使 $v_P = 0$，$M_2$ 流过 $g_m(-v_d/2)$。由于没有电流镜（current mirror），$M_1$ 那一半信号电流流入电源而损失掉：

$$|G_m| = \frac{g_{m1}}{2}.$$

**输出电阻。** 从 $M_2$ 的漏极看进去，其源极 P 处看到约 $1/g_{m1}$ 的电阻（即漏极接交流地的 $M_1$ 的源极）。这一源极负反馈（source degeneration）使 $M_2$ 的电阻增大到约 $r_{O2} + (1 + g_{m2}r_{O2})/g_{m1} \approx 2r_{O2}$，再与 $r_{O4}$ 并联：

$$R_{out} \approx (2r_{O2})\,\|\,r_{O4}.$$

**差模增益：**

$$|A_{DM}| = \frac{g_{m1}}{2}\left[(2r_{O2})\,\|\,r_{O4}\right].$$

**电源抑制。** 电源抑制比把差模增益与电源到输出的增益进行比较：

$$\mathrm{PSRR} = \frac{|A_{DM}|}{|A_{sup}|} = |A_{DM}| = \frac{g_{m1}}{2}\left[(2r_{O2})\,\|\,r_{O4}\right].$$

电源纹波会以原有大小出现在输出端，折算到输入端则等于 $\Delta V_{DD}/|A_{DM}|$。

**示例。** 取 $g_{m1} = 1$ mS，$r_{O2} = r_{O4} = 100\ \mathrm{k}\Omega$：$R_{out} = 200\,\|\,100 = 66.7\ \mathrm{k}\Omega$，$|A_{DM}| = 0.5\ \mathrm{mS}\times66.7\ \mathrm{k}\Omega = 33$，PSRR = 33（约 30 dB）。10 mV 的电源纹波在输出端表现为 10 mV，相当于输入端的 0.3 mV。

### 结果

$$\frac{\Delta V_{out}}{\Delta V_{DD}} = 1 :$$

输出一比一地跟随电源，因此电路本身不提供任何电源抑制。$M_3$ 的固定电流使 $M_4$ 的栅极跟随 $V_{DD}$，因此 $M_4$ 只相当于接到电源的 $r_{O4}$，而 $M_2$–$M_1$ 通路也相当于接到电源的 $2r_O$。因此电源抑制比就等于差模增益：

$$\mathrm{PSRR} = \frac{|A_{DM}|}{|A_{sup}|} = \frac{g_{m1}}{2}\left[(2r_{O2})\,\|\,r_{O4}\right].$$

**常见错误。** 认为电流源负载能抑制电源噪声，从而得出接近零或 $1/(g_mr_O)$ 量级的电源增益。$M_4$ 的栅极通过电流固定的 $M_3$ 以 $V_{DD}$ 为参考，因此 $M_4$ 对电源只呈现 $r_{O4}$，而没有任何因素把输出拉向地。

**常见错误。** 在计算电源增益时把 $M_1$ 的漏极当作交流地。对于**差模**增益它确实是交流地，但当 $V_{DD}$ 本身就是信号时它会移动，正因如此，$M_2$–$M_1$ 通路才相当于接到电源而不是接地的 $2r_O$。

**常见错误。** 用 $g_{m1}(r_{O2}\|r_{O4})$ 作为差模增益。没有电流镜时，$M_1$ 的信号电流被倾泻到电源中，因此只有一半差分电流到达输出端，而且 $M_2$ 的输出电阻因 $M_1$ 引入的源极负反馈而加倍。
