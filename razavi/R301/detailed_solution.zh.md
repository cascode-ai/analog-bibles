# 详细步骤 - R301

**思路。** 当 $\lambda = \gamma = 0$ 时，每个晶体管都只是一个受控电流源，理想电流源则相当于开路。输出端没有电阻性通路，其 KCL 迫使 $M_1$ 的电流为零，从而 $v_X = 0$。再由 X 点的 KCL 可知，输入电流被 $M_2$ 吸收，由此确定 $v_{out}$。

### 第 1 步 — 小信号模型（small-signal model）

把输入节点（$R_S$ 右侧）记为 X。$M_1$（栅极接 $V_b$，源极接 X，漏极接输出端）是从 X 到输出端的共栅级，$M_2$（源极接 $V_{DD}$，栅极接输出端，漏极接 X）是从输出端回到 X 的共源级（common-source stage）。环路中只有一次反相：**负反馈**。$V_{DD}$ 和 $V_b$ 为交流地，$I_1$、$I_2$ 开路：

- **$M_1$：** $v_{gs1} = 0 - v_X$，因此电流 $-g_{m1}v_X$ 从输出端（漏极）流向 X（源极）。
- **$M_2$：** $v_{gs2} = v_{out} - 0$，因此电流 $g_{m2}v_{out}$ 从 X（漏极）流向交流地；等价地说，$M_2$ 向 X 注入电流 $-g_{m2}v_{out}$。

设 $i_{in}$ 为经 $R_S$ 流入 X 的电流。

### 第 2 步 — 输出节点的 KCL 迫使 $v_X = 0$

在输出端，$I_1$ 开路，$M_2$ 的栅极不吸取电流，因此唯一的信号电流是 $M_1$ 的电流：

$$-g_{m1}v_X = 0 \quad\Longrightarrow\quad v_X = 0 .$$

$M_1$ 的电流不能变化，其栅极又是固定的，因此其源极电压也不能变化：输出节点的无穷大电阻使环路增益为无穷大，把 X 维持为理想的虚地（virtual ground）。因此，对任何输入电流，

$$Z_{in} = \frac{v_X}{i_{in}} = 0 .$$

### 第 3 步 — 由 X 点的 KCL 求输出电压

$i_{in}$ 从 $R_S$ 流入，$-g_{m1}v_X$ 从 $M_1$ 流入（由第 2 步知其为零），$-g_{m2}v_{out}$ 从 $M_2$ 流入；$I_2$ 开路：

$$i_{in} - g_{m1}v_X - g_{m2}v_{out} = 0 .$$

代入 $v_X = 0$：

$$
\begin{aligned}
i_{in} - g_{m2}v_{out} &= 0\\
v_{out} &= \frac{i_{in}}{g_{m2}}.
\end{aligned}
$$

$M_2$ 必须吸收输入电流，因此它注入 X 的电流必须**减小**：其源栅电压减小，其栅极（即输出端）升高 $i_{in}/g_{m2}$，与输入电流**方向相同**。

### 第 4 步 — 传递函数

由于 $v_X = 0$，

$$i_{in} = \frac{V_{in} - v_X}{R_S} = \frac{V_{in}}{R_S},$$

代入 $v_{out} = i_{in}/g_{m2}$ 得：

$$\frac{V_{out}}{V_{in}} = +\frac{1}{g_{m2}R_S}.$$

该电路是一个跨阻放大器（transimpedance amplifier），跨阻为 $+1/g_{m2}$，由电流 $V_{in}/R_S$ 驱动。

### 第 5 步 — 用有限输出电阻验证

加入 $r_{O1}$（接在输出端与 X 之间）和 $r_{O2}$（从 X 到交流地）。输出端的 KCL（经 $M_1$ 和 $r_{O1}$ 流出的电流必须为零）：

$$-g_{m1}v_X + \frac{v_{out} - v_X}{r_{O1}} = 0 \quad\Longrightarrow\quad v_{out} = (1 + g_{m1}r_{O1})\,v_X .$$

X 点的 KCL，其中从输出端经 $M_1$/$r_{O1}$ 流来的电流为零：

$$i_{in} = g_{m2}v_{out} + \frac{v_X}{r_{O2}} = v_X\left[g_{m2}(1 + g_{m1}r_{O1}) + \frac{1}{r_{O2}}\right],$$

$$Z_{in} = \frac{1}{g_{m2}(1 + g_{m1}r_{O1}) + 1/r_{O2}}\approx\frac{1}{g_{m1}g_{m2}r_{O1}} ,$$

当 $r_{O1}, r_{O2}\to\infty$ 时它趋于 0，证实了第 2 步的结论。

### 结果

$$Z_{in} = 0, \qquad \frac{V_{out}}{V_{in}} = +\frac{1}{g_{m2}R_S}.$$

输出端的 KCL（$I_1$ 理想，$M_2$ 无栅极电流）迫使共栅器件的电流 $-g_{m1}v_X$ 为零，因此 X 是虚地。输入电流 $V_{in}/R_S$ 被 $M_2$ 吸收，这要求 $v_{out} = i_{in}/g_{m2}$。

**常见错误。** 给出 $Z_{in} = 1/g_{m1}$，这是孤立共栅级的输入阻抗，它假设 $M_1$ 的漏极电流可以自由变化。而本题中输出端没有电阻性通路，并且驱动 $M_2$ 的栅极，从而闭合了一个增益为无穷大的负反馈环路，把 X 维持在虚地。

**常见错误。** 符号弄错。$M_2$ 是源极接 $V_{DD}$ 的 PMOS 管：要从 X **抽走**电流，其栅极必须**升高**，因此增益为 $+1/(g_{m2}R_S)$，而不是 $-1/(g_{m2}R_S)$。

**常见错误。** 把 $M_2$ 误认为 NMOS 源极跟随器（source follower），或给出 $g_{m1}/g_{m2}$ 之类的增益。当 $\lambda = 0$ 时，共栅器件不流过信号电流，因此 $g_{m1}$ 不出现在结果中；只有 $M_2$ 把输入电流转换为输出电压。
