# 详细步骤 - R541

**思路。** 在稳态下，运放的输出必须位于 PMOS 栅极所需的直流电压 $V_G = V_{DD} - |V_{GS}|$。有限增益 $A_1$ 只有在其两个输入相差 $V_G/A_1$ 时才能产生这一输出；要求这个残差保持在 $V_e$ 以下，就得到最小增益。然后检查反馈极性，并估计对输出的影响。

### 第 1 步 — 运放必须提供什么

运放驱动 $M_1$–$M_4$ 的公共栅极，而这些管子的源极接 $V_{DD}$，因此其输出必须位于

$$V_G = V_{DD} - |V_{GS}| ,$$

这是一个量级为几伏的固定直流电平。例如，取 $|V_{GS}| \approx 1$ V，即阈值 0.8 V 加上约 0.2 V 的过驱动电压（overdrive voltage），得 $V_G \approx 2$ V；由于 $|V_{GS}| > 0.8$ V，$V_G < 2.2$ V。

### 第 2 步 — 有限增益所需的输入差

同相输入端接 Y，反相输入端接 X，

$$V_G = A_1\,(V_Y - V_X)\quad\Longrightarrow\quad V_Y - V_X = \frac{V_G}{A_1} = \frac{V_{DD} - |V_{GS}|}{A_1}.$$

**极性检查。** 如果栅极电压升高，所有 PMOS 电流都会减小。$V_X$（两个发射极-基极电压）只按对数规律下降，而 $V_Y$ 由于线性的 $I_{D2}R_1$ 项下降得更多，因此 $V_Y - V_X$ 减小，把运放输出推回下方：这是负反馈，稳态时 $V_Y$ 略**高于** $V_X$。

### 第 3 步 — 最小增益

$$\frac{V_{DD} - |V_{GS}|}{A_1} < V_e
\quad\Longrightarrow\quad
\boxed{A_{1,min} = \frac{V_{DD} - |V_{GS}|}{V_e}}$$

当 $V_{DD} = 3$ V、$|V_{GS}| \approx 1$ V 时，$V_G \approx 2$ V，因此

$$A_1 \gtrsim \frac{2\ \mathrm{V}}{V_e}:\qquad V_e = 1\ \mathrm{mV} \Rightarrow A_1 > 2000\ (66\ \mathrm{dB}),\qquad V_e = 0.1\ \mathrm{mV} \Rightarrow A_1 > 20{,}000\ (86\ \mathrm{dB}).$$

该模型在零输入时输出为零。如果运放在零差分输入时的输出电平为 $V_{O0}$，则输入只需提供差值部分，$V_Y - V_X = (V_G - V_{O0})/A_1$，要求变为 $A_1 > |V_G - V_{O0}|/V_e$；自然输出电平接近 $V_G$ 的运放所需的增益更小。

### 第 4 步 — 为什么 $V_e$ 必须很小：对输出的影响

$V_Y - V_X$ 的作用相当于运放的输入失调。设各支路电流都等于 $I$：

$$V_Y = |V_{EB3}| + |V_{EB4}| + IR_1 = V_X + \frac{V_G}{A_1}
\quad\Longrightarrow\quad
IR_1 = 2V_T\ln n + \frac{V_G}{A_1},$$

这里利用了 $V_X - |V_{EB3}| - |V_{EB4}| = 2V_T\ln n$。因此输出 $V_{out} = |V_{EB3}| + |V_{EB4}| + (1 + R_2/R_1)IR_1$ 偏移约

$$\Delta V_{out} \approx \left(1 + \frac{R_2}{R_1}\right)\frac{V_G}{A_1} < \left(1 + \frac{R_2}{R_1}\right)V_e .$$

对于典型的 $1 + R_2/R_1 \approx 8$，1-mV 的残差会变成 8-mV 的输出误差，而且由于 $V_G$ 随温度和电源变化，这个误差也会随之变化。

### 结果

运放必须把输出保持在 PMOS 栅极电压 $V_G = V_{DD} - |V_{GS}|$，这要求差分输入 $|V_Y - V_X| = V_G/A_1$。因此

$$A_{1,min} = \frac{V_{DD} - |V_{GS}|}{V_e} .$$

例：$|V_{GS}| \approx 1$ V 时 $V_G \approx 2$ V，$A_1 \gtrsim 2\ \mathrm{V}/V_e$（$V_e = 1$ mV 时为 2000）。残差 $V_X - V_Y$ 在 PTAT 环路中的表现类似失调，因此输出误差约为它的 $(1 + R_2/R_1)$ 倍。（若运放在零输入时的输出偏置电平为 $V_{O0}$，则要求变为 $|V_G - V_{O0}|/V_e$。）

**常见错误。** 认为反馈使增益无关紧要（“环路强制 $V_X = V_Y$”）。这只在增益无穷大时成立；有限增益需要一个非零输入才能产生 $V_G$，而这个输入**正是**误差 $V_Y - V_X$。

**常见错误。** 把带隙基准的输出（$V_{out} \approx 2.3$–2.5 V）当作运放的输出电压。运放驱动的是 PMOS 的**栅极**，因此其输出为 $V_{DD} - |V_{GS}|$。

**常见错误。** 写出量纲不一致的条件，例如 $A_1 > 1/V_e$。该界限必须是一个电压（$V_G$）除以一个电压（$V_e$）。
