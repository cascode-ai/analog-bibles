# 详细步骤 - R240

**思路。** $V_{out}$ 可以一直升高到 $M_4$ 退出饱和，也可以一直降低到 $M_2$ 退出饱和。上限需要用到 $M_4$ 的过驱动电压；下限需要用到 $M_2$ 的阈值电压（threshold voltage），而由于其源极位于 $V_P$、高于接地的衬底，该阈值电压包含体效应，因此要先求出 $V_P$。

### 第 1 步 — 偏置电流

$M_4$ 镜像由 $I_1$ 偏置的 $M_3$，因此 $I_{D4} = I_1 = 0.25$ mA。输出端没有负载时，$I_{D2} = I_{D4} = 0.25$ mA，而 $I_{D1} = I_{SS} - I_{D2} = 0.25$ mA（$M_1$ 的漏极接 $V_{DD}$）。每个晶体管都流过 0.25 mA，且都有 $W/L = 50/0.5 = 100$。

### 第 2 步 — 上限：$M_4$ 饱和

$V_{SD4} = V_{DD} - V_{out} \ge |V_{ov4}|$ 意味着 $V_{out} \le V_{DD} - |V_{ov4}|$（没有体效应：PMOS 的源极和衬底都接 $V_{DD}$，而且阈值电压在条件中被消去）。电流为 0.25 mA 时，

$$|V_{ov4}| = \sqrt{\frac{2I_{D4}}{\mu_pC_{ox}(W/L)}} = \sqrt{\frac{2(0.25\ \mathrm{mA})}{(38.4\ \mu\mathrm{A/V^2})(100)}} = \sqrt{\frac{0.5\ \mathrm{mA}}{3.84\ \mathrm{mA/V^2}}} = \sqrt{0.1302\ \mathrm{V^2}} = 0.361\ \mathrm{V} ,$$

$$V_{out,max} = 3 - 0.361 = 2.639\ \mathrm{V} .$$

### 第 3 步 — 下限：$M_2$ 饱和

由 $V_{DS2} \ge V_{GS2} - V_{TH2}$ 得

$$V_{out} - V_P \ge V_{in,CM} - V_P - V_{TH2} \quad\Longleftrightarrow\quad V_{out} \ge V_{in,CM} - V_{TH2} .$$

漏极电压最多只能比栅极低一个阈值电压。衬底接地、源极位于 $V_P$ 时，

$$V_{TH2} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_P} - \sqrt{2|\phi_F|}\right) = 0.7 + 0.45\left(\sqrt{0.9 + V_P} - 0.9487\right) .$$

### 第 4 步 — 求解 $V_P$

电流为 0.25 mA 时，

$$V_{ov1} = \sqrt{\frac{2(0.25\ \mathrm{mA})}{(134\ \mu\mathrm{A/V^2})(100)}} = \sqrt{\frac{0.5\ \mathrm{mA}}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.03731\ \mathrm{V^2}} = 0.193\ \mathrm{V} ,$$

再对 $M_2$ 的栅极回路应用基尔霍夫电压定律（KVL），得

$$V_P = V_{in,CM} - V_{TH2} - V_{ov1} = 1.3 - 0.193 - \left[0.7 + 0.45\left(\sqrt{0.9 + V_P} - 0.9487\right)\right] .$$

令 $u = \sqrt{0.9 + V_P}$（$V_P = u^2 - 0.9$）：

$$
\begin{aligned}
u^2 - 0.9 &= 1.3 - 0.193 - 0.7 - 0.45u + 0.4269,\\
u^2 + 0.45u - (0.9 + 1.3 - 0.193 - 0.7 + 0.4269) &= 0,\\
u^2 + 0.45u - 1.7337 &= 0 .
\end{aligned}
$$

取正根，

$$u = \frac{-0.45 + \sqrt{0.2025 + 4(1.7337)}}{2} = \frac{-0.45 + \sqrt{7.1375}}{2} = \frac{-0.45 + 2.6716}{2} = 1.1108 ,$$

$$V_P = u^2 - 0.9 = 1.2339 - 0.9 = 0.334\ \mathrm{V}, \qquad V_{TH2} = 0.7 + 0.45(1.1108 - 0.9487) = 0.7 + 0.0730 = 0.773\ \mathrm{V}$$

（验证：$V_P = 1.3 - 0.773 - 0.193 = 0.334$ V ✓）。

### 第 5 步 — 下限与摆幅

$$V_{out,min} = V_{in,CM} - V_{TH2} = 1.3 - 0.773 = 0.527\ \mathrm{V}$$

（等价地，$V_P + V_{ov2} = 0.334 + 0.193 = 0.527$ V），因此摆幅为

$$V_{out,max} - V_{out,min} = 2.639 - 0.527 = 2.11\ \mathrm{V} .$$

若不计体效应，$V_{TH2} = 0.7$ V，得到 $V_{out,min} = 0.60$ V，摆幅为 $2.64 - 0.60 = 2.04$ V：在这里，较大的阈值电压反而**有利**，它允许漏极电压比栅极低得更多。

$M_1$（漏极接 $V_{DD}$）和二极管连接（diode-connected）的 $M_3$ 始终处于饱和，因此只有 $M_2$ 和 $M_4$ 限制摆幅。这里假设输入共模电平固定；提高输入共模电平会使 $V_{out,min}$ 一对一地升高。

### 结果

$$0.53\ \mathrm{V} \lesssim V_{out} \lesssim 2.64\ \mathrm{V},$$

**摆幅约为 2.1 V**（峰峰值）。

- 上限：$V_{DD} - |V_{GS4} - V_{TH4}| = 3 - 0.361 = 2.64$ V。
- 下限：$V_{in,CM} - V_{TH2} = 1.3 - 0.773 = 0.527$ V，其中 $V_P = 0.334$ V 由体效应方程求出。
- 若忽略体效应：0.60–2.64 V，即 2.04 V。

**常见错误。** 用截止而不是饱和作为界限，例如 $V_{out,min} = V_P$ 或 $V_{out,max} = V_{DD} - |V_{TH}|$。器件一旦进入线性区（triode region），增益就会丧失，因此界限应为 $V_{DS2} = V_{ov2}$ 和 $V_{SD4} = |V_{ov4}|$。

**常见错误。** 每个器件取 0.5 mA，或者认为 $M_1$ 的漏极接到 $M_3$/$I_1$ 节点。$M_1$ 的漏极接 $V_{DD}$，$M_4$ 只复制 $I_1 = 0.25$ mA。

**常见错误。** 混淆器件参数：下限用的是 NMOS 的阈值电压（含体效应），上限用的是 PMOS 的过驱动电压（$\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$）。
