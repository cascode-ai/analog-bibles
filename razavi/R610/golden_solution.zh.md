$W/L$ = 200/0.5 时 THD ≈ 0.049%，而 $W/L$ = 50/0.5 时为 ≈ 0.069%：把 W/L 增大到四倍会使开环增益加倍，但失真只降低 ≈ 1.4 倍，并非“急剧”下降，因为 $\alpha_2$ 也随之增大。
- $W/L = 400$：$V_{ov} = 0.193$ V，$g_m = 10.35$ mS，$\alpha_1 = g_mR_D = 20.7$，$\alpha_2 = \tfrac12\mu_nC_{ox}\tfrac WL R_D = 53.6\ \mathrm{V^{-1}}$。$\alpha_2V_m/(2\alpha_1) = 1.29\%$（10 mV 时的开环 HD2），$(1+\beta\alpha_1)^2 = 5.14^2 = 26.4$，因此 $b/a = 4.9\times10^{-4}$ = 0.049%。
- $W/L = 100$：$\alpha_1 = 10.35$，$\alpha_2 = 13.4\ \mathrm{V^{-1}}$，开环为 0.65%，$(1+\beta\alpha_1)^2 = 9.43$，$b/a$ = 0.069%。
- 解释：$\alpha_1 = g_mR_D \propto \sqrt{W/L}$，但 $\alpha_2 = \tfrac12\mu_nC_{ox}(W/L)R_D \propto W/L$，因此开环失真 $\alpha_2V_m/(2\alpha_1) = V_m/(4V_{ov}) \propto \sqrt{W/L}$ 加倍，因为过驱动电压（overdrive voltage）减半了。“其他参数保持不变”这一前提并不成立。反馈系数（feedback factor）$(1+\beta\alpha_1)^2$ 增大为 2.8×，因此净改善为 2.8/2 = 1.4×。当 $\beta\alpha_1 \gg 1$ 时，$b/a \approx \alpha_2V_m/(2\beta^2\alpha_1^3) \propto (W/L)^{-1/2}$，仍然只是平方根式的改善。
