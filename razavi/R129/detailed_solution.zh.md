# 详细步骤 - R129

**思路。** 节点 $X$ 是共源共栅管 $M_2$ 的源极，其栅极电压固定，因此 $V_X = V_b - V_{GS2}$ 取决于漏极电流。两个器件都饱和时的最大输出摆幅所对应的电流范围，从零（输出位于 $V_{DD}$）一直到 $M_1$ 到达线性区边缘时的电流。计入 $M_2$ 的体效应，计算两端的 $V_X$，再求差值。

### 第 1 步 — $V_X$ 与电流的关系

取 $\lambda = 0$，$\beta_2 = \mu_nC_{ox}(W/L)_2 = (134\ \mu\mathrm{A/V^2})(20) = 2.68\ \mathrm{mA/V^2}$，

$$V_X = V_b - V_{GS2} = V_b - V_{TH2}(V_X) - \sqrt{\frac{2I_D}{\beta_2}},$$

其中阈值电压计入了体效应（$M_2$ 的源极位于 $V_X$，衬底接地）：

$$V_{TH2}(V_X) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right)\ \mathrm{V}.$$

因此 $V_X$ **并不**恒定：电流越大，所需的 $V_{GS2}$ 越大，而栅极电压不能变化，于是 $X$ 下降。

### 第 2 步 — 最大输出摆幅对应的电流范围

由 $V_{out} = V_{DD} - I_DR_D$，每个输出电压都对应一个电流：

- **上端：** $V_{out} \to V_{DD} = 3$ V，即 $I_D \to 0$；由于两个器件的过驱动电压（overdrive voltage）都趋于零，它们仍（勉强）保持饱和。
- **下端：** 当 $V_{DS1} = V_X$ 降到 $V_{ov1}$ 时，$M_1$ 首先退出饱和区。这发生在 $I_D = 0.566$ mA，即 $V_{out} = 3 - 0.566 = 2.434$ V 处，而 $M_2$ 只要求 $V_{out} \ge V_b - V_{TH2} \approx 0.94$ V。

**下端的推导。** 在边缘处 $V_X = V_{ov1}$，又因为 $\beta_1 = 13.4\ \mathrm{mA/V^2} = 5\beta_2$，所以 $V_{ov2} = \sqrt{\beta_1/\beta_2}\,V_{ov1} = \sqrt5\,V_X$。第 1 步的方程变为

$$(1 + \sqrt5)\,V_X + 0.7 + 0.45\left(\sqrt{0.9 + V_X} - 0.9487\right) = 1.705\ \mathrm{V}.$$

当 $V_X = 0.2907$ V 时，左边为 $0.9408 + 0.7 + 0.45(1.0912 - 0.9487) = 0.9408 + 0.7 + 0.0641 = 1.705$ V ✓，因此 $I_D = \tfrac12\beta_1V_X^2 = \tfrac12(13.4\ \mathrm{mA/V^2})(0.2907)^2 = 0.566$ mA。

### 第 3 步 — 摆幅下端的 $V_X$（$V_{out} \approx 2.43$ V）

$$V_{X,min} = V_{ov1} = 0.291\ \mathrm{V}\qquad (I_D = 0.566\ \mathrm{mA},\ V_{GS2} = 0.764 + 0.650 = 1.414\ \mathrm{V}),$$

而且确实有 $V_b - V_{GS2} = 1.705 - 1.414 = 0.291$ V ✓。

### 第 4 步 — 摆幅上端的 $V_X$（$V_{out} \to 3$ V）

当 $I_D \to 0$ 时，$V_{GS2} \to V_{TH2}$：

$$V_X + V_{TH2}(V_X) = V_b\quad\Longrightarrow\quad V_X + 0.7 + 0.45\left(\sqrt{0.9 + V_X} - 0.9487\right) = 1.705 .$$

令 $u = \sqrt{0.9 + V_X}$（$V_X = u^2 - 0.9$）：

$$
\begin{aligned}
u^2 - 0.9 + 0.7 + 0.45u - 0.4269 &= 1.705\\
u^2 + 0.45u - 2.3319 &= 0\\
u &= \frac{-0.45 + \sqrt{0.2025 + 9.3276}}{2} = \frac{-0.45 + 3.0871}{2} = 1.3185\\
V_X &= u^2 - 0.9 = 1.7385 - 0.9 = 0.8385\ \mathrm{V}.
\end{aligned}
$$

验证：$V_{TH2} = 0.7 + 0.45(1.3185 - 0.9487) = 0.7 + 0.1664 = 0.8664$ V，且 $0.8385 + 0.8664 = 1.705$ V ✓。由于 $X$ 比衬底高 0.84 V，体效应在此处把阈值电压提高到 0.87 V。

### 第 5 步 — 节点 $X$ 的摆幅

$$\Delta V_X = V_{X,max} - V_{X,min} = 0.8385 - 0.2907 \approx 0.55\ \mathrm{V}.$$

沿途各点（由相同的方程求得）：

| $I_D$ (mA) | $V_{out}$ (V) | $V_X$ (V) | $V_{TH2}$ (V) |
|---|---|---|---|
| 0 | 3.000 | 0.839 | 0.866 |
| 0.1 | 2.900 | 0.606 | 0.825 |
| 0.3 | 2.700 | 0.438 | 0.794 |
| 0.5（偏置点） | 2.500 | 0.323 | 0.771 |
| 0.566 | 2.434 | 0.291 | 0.764 |

相对于偏置点（$V_X = 0.323$ V），$X$ 只能下降 32 mV，却能上升 0.52 V，这与输出范围的不对称性相对应（向下 66 mV，向上 0.5 V）。

**为什么 $X$ 的摆幅如此之大。** 0.57 V 的输出范围使电流从 0.566 mA 一直变化到零，而在电流接近零时 $V_{GS2}$ 变化很快（过驱动电压按 $\sqrt{I_D}$ 变化），因此 $X$ 的变化几乎与输出一样大：约 0.55 V 对 0.57 V。从小信号的角度看，$X$ 的变化约为 $v_{in}$ 的 $g_{m1}/(g_{m2} + g_{mb2}) \approx 1.9$ 倍，而输出端为 3.6 倍；但在整个大信号（large-signal）范围内，较窄的共源共栅管的 $V_{GS}$ 变化使两者的摆幅相当：共源共栅结构**并不能**把 $X$ 固定住。

### 结果

当输出在两个晶体管都饱和的最大范围内摆动时（从 ≈ 2.43 V 到 3 V），节点 $X$ 的电压从

$$V_{X,min} \approx 0.29\ \mathrm{V}\ (\text{at } V_{out} \approx 2.43\ \mathrm{V},\ M_1 \text{ at the edge of triode})$$

变化到

$$V_{X,max} \approx 0.84\ \mathrm{V}\ (\text{at } V_{out} \to 3\ \mathrm{V},\ I_D \to 0),$$

摆幅为 **≈ 0.55 V**，与输出摆幅本身大致相当。

**常见错误。** 认为 $V_X$ 保持在其偏置值不变，理由是“共源共栅结构屏蔽了 $X$”。$V_X = V_b - V_{GS2}$，而 $V_{GS2}$ 随电流变化。

**常见错误。** 忽略 $M_2$ 的体效应：若把 $V_{TH2}$ 固定为 0.7 V，并取 $V_b = 1.705$ V，上端将算成 $V_X = 1.705 - 0.7 = 1.005$ V，而不是 0.84 V（若按不计体效应的方法重新设计 $V_b$，即 1.634 V，则得到 0.29–0.93 V，上端仍然有误）。在 $V_X \approx 0.84$ V 处，体效应使 $V_{TH2}$ 升高约 0.17 V。

**常见错误。** 以 $M_2$ 进入线性区（$V_{out} \approx 0.94$ V）来确定摆幅。对于电阻负载，$M_1$ 先退出饱和区，此时 $V_{out} \approx 2.43$ V，它决定了 $X$ 摆幅的下端。
