# 详细步骤 - R249

**思路。** 该电路是电阻负载的电流镜，再加上一个源极跟随器（source follower）$M_3$，其栅极接 Y、源极接 X、漏极接 $V_{DD}$；电流镜中每条支路接 $R_1$，$M_2$ 为二极管连接（diode-connected），两个栅极都接 X。对 X 和 Y 列 KCL 可知，$M_3$ 只能以**负**电流导通，而这是不可能的。因此 $M_3$ 截止，$V_X = V_Y$，曲线与普通电流镜相同。

### 第 1 步 — 节点方程

$V_{GS1} = V_{GS2} = V_X$，$V_{GS3} = V_Y - V_X$。衬底接地且源极位于 $V_X > 0$，因此 $M_3$ 的 $V_{TH3} = 0.7 + 0.45(\sqrt{0.9 + V_X} - \sqrt{0.9}) \ge 0.7$ V。它的漏极接 $V_{DD}$，因此若它导通，其电流**流入** X：$I_{D3} \ge 0$。

对 X 点（从 $R_1$ 和 $M_3$ 流入，流出到 $M_2$）和 Y 点（$M_3$ 的栅极不取电流）列 KCL：

$$\frac{V_{DD} - V_X}{R_1} + I_{D3} = I_{D2} , \qquad (1)$$

$$\frac{V_{DD} - V_Y}{R_1} = I_{D1} . \qquad (2)$$

### 第 2 步 — $M_3$ 不可能导通

**情形 A：$M_1$ 饱和。** 它与 $M_2$ 的 $V_{GS}$ 相同，因此 $I_{D1} = I_{D2}$；用 (2) 减去 (1)：

$$\frac{V_{DD} - V_Y}{R_1} - \frac{V_{DD} - V_X}{R_1} - I_{D3} = 0 \quad\Longrightarrow\quad I_{D3} = \frac{V_X - V_Y}{R_1} .$$

$M_3$ 只有在 $V_{GS3} = V_Y - V_X > V_{TH3} > 0$，即 $V_Y > V_X$ 时才导通，而这会使 $I_{D3} < 0$：矛盾。因此 $I_{D3} = 0$，$V_Y = V_X$。这是自洽的：$V_{GS3} = 0 < V_{TH3}$（$M_3$ 截止），且 $V_{DS1} = V_X = V_{GS1}$（$M_1$ 饱和）。

**情形 B：$M_1$ 处于线性区。** 这需要 $V_Y < V_X - 0.7$ V，因此 $V_{GS3} < -0.7$ V，$I_{D3} = 0$。于是由 (1) 和 (2) 得 $I_{D2} = (V_{DD} - V_X)/R_1$，$I_{D1} = (V_{DD} - V_Y)/R_1 > I_{D2}$（因为 $V_Y < V_X$），而在 $V_{GS}$ 相同时，处于线性区的器件的电流**小于**饱和器件。矛盾，因此情形 B 不可能出现。

所以 $M_3$ 始终截止，$V_Y = V_X$：只有当 Y 比 X 高出一个阈值电压（threshold voltage）时跟随器才会导通，而电流镜永远不会让这种情况发生。

### 第 3 步 — 曲线

$M_3$ 截止时，电路就是普通的电阻负载电流镜。当 $0 \le V_{DD} \le 0.7$ V 时，$M_1$ 和 $M_2$ 截止，且

$$V_X = V_Y = V_{DD} .$$

当 $V_{DD} > 0.7$ V 时，对 X 点列 KCL 并结合二极管的平方律，得

$$\frac{V_{DD} - V_X}{R_1} = \frac{\beta}{2}(V_X - 0.7)^2 .$$

令 $w = V_X - 0.7$，$D = V_{DD} - 0.7$，两边乘以 $2R_1$ 得 $\beta R_1w^2 + 2w - 2D = 0$，其正根为

$$V_X = V_Y = 0.7 + \frac{\sqrt{1 + 2\beta R_1(V_{DD} - 0.7)} - 1}{\beta R_1} .$$

斜率 $dV_X/dV_{DD} = 1/\sqrt{1 + 2\beta R_1(V_{DD} - 0.7)}$ 在 0.7 V 处为 1，随后不断减小：呈缓慢的、类似平方根的上升。取 $\beta R_1 = 10\ \mathrm{V^{-1}}$（例如 $\beta = 1\ \mathrm{mA/V^2}$，$R_1 = 10\ \mathrm{k}\Omega$）：

| $V_{DD}$ (V) | 0.5 | 0.7 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 |
|---|---|---|---|---|---|---|---|
| $V_X = V_Y$ (V) | 0.50 | 0.70 | 0.86 | 1.01 | 1.12 | 1.21 | 1.29 |
| $V_{GS3}$ (V) | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

### 结果

**$M_3$ 始终不会导通，且对所有 $V_{DD}$，$V_X = V_Y$：**

- $0 \le V_{DD} \le 0.7$ V：$V_X = V_Y = V_{DD}$。
- $V_{DD} > 0.7$ V：二者都跟随二极管曲线
$$V_X = V_Y = 0.7 + \frac{\sqrt{1 + 2\beta R_1(V_{DD} - 0.7)} - 1}{\beta R_1},$$
以斜率 1 离开 45° 线，随后上升得越来越慢。

KCL 方程给出 $I_{D3} = (V_X - V_Y)/R_1$，只要 $M_3$ 的 $V_{GS}$ 足以使其导通，这个电流就会为负。因此 $I_{D3} = 0$，电路的行为与普通的电阻负载电流镜相同。

**常见错误。** 认为跟随器 $M_3$ 流过可观的电流，并把 X 拉高到接近 $V_Y - V_{TH}$。这需要 $V_Y > V_X + V_{TH3}$，而 KCL 方程排除了这种可能。

**常见错误。** 断言 $M_1$ 会进入线性区。处于线性区的 $M_1$ 电流会小于 $M_2$，而它所在的支路却需要更大的电流。

**常见错误。** 以 $M_3$“稍微导通一点”为由，把 $V_Y$ 画得与 $V_X$ 略有不同。在 $\lambda = 0$ 的平方律模型中，解精确地为 $V_Y = V_X$，且 $V_{GS3} = 0$。
