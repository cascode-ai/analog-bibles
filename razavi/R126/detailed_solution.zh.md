# 详细步骤 - R126

**思路。** 共源共栅管的栅极电压决定了 $M_1$ 的漏极（节点 $X$）电压：$V_X = V_b - V_{GS2}$。先求出使 $M_1$ 比饱和区（saturation region）边缘高 50 mV 的 $V_X$，再计入 $M_2$ 的体效应（源极为 $V_X$，衬底接地）计算 $V_{GS2}$，最后将两者相加。

### 第 1 步 — $M_1$ 的过驱动电压与所需的 $V_X$

$M_1$ 的源极接地，因此 $V_{DS1} = V_X$，条件为 $V_X = V_{ov1} + 50$ mV。由于 $\lambda = 0$，$V_{ov} = \sqrt{2I_D/[\mu_nC_{ox}(W/L)]}$；对于 $M_1$，$(W/L)_1 = 50/0.5 = 100$：

$$
\begin{aligned}
\mu_nC_{ox}(W/L)_1 &= (134\ \mu\mathrm{A/V^2})(100) = 13.4\ \mathrm{mA/V^2},\\
V_{ov1} &= \sqrt{\frac{2(0.5\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.07463\ \mathrm{V^2}} = 0.2732\ \mathrm{V}.
\end{aligned}
$$

（源极和衬底都接地，$V_{TH1} = 0.7$ V，因此输入直流电平为 $V_{GS1} = 0.973$ V；计算 $V_b$ 时不需要它。）于是

$$V_X = V_{ov1} + 0.05\ \mathrm{V} = 0.2732 + 0.05 = 0.3232\ \mathrm{V}.$$

### 第 2 步 — $M_2$ 的过驱动电压

$(W/L)_2 = 10/0.5 = 20$，电流同为 0.5 mA：

$$
\begin{aligned}
\mu_nC_{ox}(W/L)_2 &= (134\ \mu\mathrm{A/V^2})(20) = 2.68\ \mathrm{mA/V^2},\\
V_{ov2} &= \sqrt{\frac{2(0.5\ \mathrm{mA})}{2.68\ \mathrm{mA/V^2}}} = \sqrt{0.3731\ \mathrm{V^2}} = 0.6108\ \mathrm{V}.
\end{aligned}
$$

$M_2$ 的宽度只有 $M_1$ 的五分之一，因此它需要 $\sqrt5 \approx 2.24$ 倍的过驱动电压。

### 第 3 步 — 计入体效应的 $M_2$ 阈值电压

$V_{SB2} = V_X = 0.3232$ V：

$$
\begin{aligned}
V_{TH2} &= V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB2}} - \sqrt{2|\phi_F|}\right),\\
\sqrt{2|\phi_F| + V_{SB2}} &= \sqrt{0.9 + 0.3232} = \sqrt{1.2232} = 1.1060\ \mathrm{V^{1/2}},\\
\sqrt{2|\phi_F|} &= \sqrt{0.9} = 0.9487\ \mathrm{V^{1/2}},\\
V_{TH2} &= 0.7 + 0.45\,(1.1060 - 0.9487) = 0.7 + 0.45\times0.1573 = 0.7 + 0.0708 = 0.7708\ \mathrm{V}.
\end{aligned}
$$

### 第 4 步 — 栅极电压 $V_b$

$$V_b = V_X + V_{GS2} = V_X + V_{TH2} + V_{ov2} = 0.3232 + 0.7708 + 0.6108 = 1.7048\ \mathrm{V} \approx 1.70\ \mathrm{V}.$$

**若不计体效应**（$V_{TH2} = 0.7$ V）：$V_b = 0.3232 + 0.7 + 0.6108 = 1.634$ V，低了约 70 mV。在实际电路中，这会使 $V_X \approx 0.26$ V（由 $V_X + V_{TH2}(V_X) = 1.634 - 0.611$ V 解得），使 $M_1$ 处于线性区**之内**约 10 mV，而不是在其之外 50 mV。

### 第 5 步 — 验证 $M_2$ 处于饱和区

由于 $\lambda = 0$：

$$V_{out} = V_{DD} - I_DR_D = 3\ \mathrm{V} - (0.5\ \mathrm{mA})(1\ \mathrm{k\Omega}) = 2.5\ \mathrm{V},$$

$$V_{DS2} = V_{out} - V_X = 2.5 - 0.323 = 2.18\ \mathrm{V} > V_{ov2} = 0.611\ \mathrm{V},$$

因此 $M_2$ 处于饱和区，裕量约为 1.57 V ✓（在 $M_2$ 进入线性区之前，$V_{out}$ 可以降到 $V_b - V_{TH2} = 1.70 - 0.77 = 0.93$ V）。

### 结果

$$V_b = V_{ov1} + 50\ \mathrm{mV} + V_{TH2} + V_{ov2} = 0.323 + 0.771 + 0.611\ \mathrm{V} \approx 1.70\ \mathrm{V}$$

（若忽略 $M_2$ 的体效应，约为 1.63 V）。中间结果为 $V_{ov1} = 0.273$ V，$V_X = 0.323$ V，$V_{ov2} = 0.611$ V，$V_{TH2} = 0.771$ V。

**常见错误。** 取 $V_X = V_{GS1} + 50$ mV（约 1.02 V），而不是 $V_{ov1} + 50$ mV：饱和区的边缘是 $V_{DS} = V_{GS} - V_{TH}$。

**常见错误。** 忽略 $M_2$ 的体效应。它的源极位于 $X \approx 0.32$ V，比接地的衬底高，这使 $V_{TH2}$ 升高约 71 mV；而目标裕量只有 50 mV，这就把 $M_1$ 推入了线性区。

**常见错误。** 用 $(W/L)_1$ 计算 $V_{GS2}$，或者把 50 mV 的裕量用在 $M_2$ 上。$M_2$ 是较窄的器件（20 对 100），因此其过驱动电压为 0.611 V，而不是 0.273 V；而裕量要求针对的是输入器件 $M_1$。
