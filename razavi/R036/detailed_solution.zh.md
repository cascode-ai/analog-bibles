# 详细步骤 - R036

**思路。** $C_1$ 把输入节点（$M_1$ 的栅极）与节点 X（$M_1$ 的源极）连接起来。在阶跃时，X 被抬高整整 3 V。阶跃之后，$M_1$（漏极接 $V_{DD}$，栅极接 3 V）是一个对 X 充电的源极跟随器（source follower），而 $C_1$ 的另一极板由输入源固定。计入体效应，求出跳变量、初始电流、最终值以及趋近过程的形状。

### 第 1 步 — 阶跃之前的状态

栅极一侧为正，因此 $V_X = V_{in} - V_{C1}$，阶跃之前

$$V_X(0^-) = 0 - 3 = -3\ \mathrm{V}.$$

（题目给出的是该时刻的电容电压；我们把它作为初始条件。）

### 第 2 步 — $t = 0$ 时的跳变

$M_1$ 只能提供有限的电流，因此电容电压不能瞬时改变：

$$V_X(0^+) = V_{in}(0^+) - V_{C1}(0^+) = 3 - 3 = 0\ \mathrm{V}.$$

**$V_X$ 跳变 +3 V，从 −3 V 升到 0 V。**

### 第 3 步 — 阶跃之后：工作区与初始电流

当 $t > 0$ 时：

$$
\begin{aligned}
V_{GS} &= 3 - V_X,\\
V_{DS} &= 3 - V_X = V_{GS},\\
V_{SB} &= V_X ,
\end{aligned}
$$

因此 **$M_1$ 只要导通就处于饱和区**。计入体效应，

$$V_{TH}(V_X) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - 0.9487\right)\ \mathrm{V}.$$

漏极电流从 $V_{DD}$ 流入 X，而 X 的另一个连接只有 $C_1$ 的下极板；上极板此时被 $V_{in}$ 固定在 3 V，因此该电流使 $V_X$ 升高：

$$C_1\frac{dV_X}{dt} = \tfrac12\beta\left[3 - V_X - V_{TH}(V_X)\right]^2 .$$

**在 $t = 0^+$ 时：** $V_X = 0$，因此 $V_{SB} = 0$，$V_{TH} = 0.7$ V，过驱动电压（overdrive voltage）为 $3 - 0 - 0.7 = 2.3$ V：

$$I_D(0^+) = \tfrac12\beta\,(2.3\ \mathrm{V})^2 = 2.65\,\beta\ \mathrm{V^2}, \qquad \left.\frac{dV_X}{dt}\right|_{0^+} = \frac{2.65\,\beta}{C_1}\ (\mathrm{V^2}).$$

### 第 4 步 — 最终值

当过驱动电压降为零时，充电停止：

$$3 - V_X = V_{TH}(V_X) = 0.7 + 0.45\sqrt{0.9 + V_X} - 0.4269 .$$

令 $u = \sqrt{0.9 + V_X}$：

$$
\begin{aligned}
3 - (u^2 - 0.9) &= 0.2731 + 0.45u\\
u^2 + 0.45u - 3.6269 &= 0\\
u &= \frac{-0.45 + \sqrt{0.2025 + 14.5076}}{2} = 1.6927\\
V_{X,\infty} &= 1.6927^2 - 0.9 = 1.965\ \mathrm{V}.
\end{aligned}
$$

此时 $V_{TH} = 3 - 1.965 = 1.035$ V。所以 **$V_X \to$ ≈ 1.97 V**（若没有体效应，则为 $3 - 0.7 = 2.3$ V），最终 $C_1$ 上的电压为 $3 - 1.965 = 1.035$ V。

### 第 5 步 — 形状：双曲线型趋近

记过驱动电压 $u_{ov} = 3 - V_X - V_{TH}(V_X)$，$\eta = dV_{TH}/dV_X = \gamma/(2\sqrt{0.9 + V_X})$（这里介于 0.13 与 0.24 之间），

$$\frac{du_{ov}}{dt} = -(1 + \eta)\frac{\beta}{2C_1}\,u_{ov}^2 ,$$

其解在 $t$ 较大时按 $1/t$ 减小。所以 $V_X$ 的上升**先快后慢**，**渐近地**趋于 1.965 V（双曲线型而不是指数型拖尾），因为电流正比于剩余过驱动电压的平方；$M_1$ 始终处于饱和区。

### 第 6 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF（初始电流为 2.65 mA，初始斜率为 2.65 V/ns），对方程积分得到：

| $t$ (ns) | $V_X$ (V) | 过驱动电压 (V) | $I_D$ (mA) | 不计体效应时的 $V_X$ (V) |
|---|---|---|---|---|
| $0^-$ | −3.00 | — | — | −3.00 |
| $0^+$ | 0 | 2.30 | 2.65 | 0 |
| 0.25 | 0.49 | 1.71 | 1.46 | 0.51 |
| 0.5 | 0.78 | 1.36 | 0.93 | 0.84 |
| 1 | 1.11 | 0.98 | 0.48 | 1.23 |
| 2 | 1.42 | 0.62 | 0.20 | 1.60 |
| 5 | 1.70 | 0.30 | 0.046 | 1.96 |
| 10 | 1.82 | 0.16 | 0.013 | 2.12 |
| 50 | 1.93 | 0.035 | 0.0006 | 2.26 |
| ∞ | 1.965 | 0 | 0 | 2.30 |

（最后一列是不计体效应时的精确解 $V_X = 2.3 - 2.3/(1 + 2.3\beta t/2C_1)$ V。）

### 结果

- **阶跃之前** $V_X = 0 - 3 = -3$ V；**在 $t = 0$ 时它跳变 3 V，到达 0 V**。
- **随后** $M_1$（漏极接 $V_{DD}$，栅极接 3 V，源极位于 X）处于**饱和区**（因为 $V_{DS} = 3 - V_X \ge V_{GS}$），并对 X 充电，而 X 上电容的另一极板由 $V_{in}$ 固定。
  - 初始电流为 $\tfrac12\beta(3 - 0.7)^2 = 2.65\beta$，初始斜率为 $2.65\beta/C_1$。
  - $V_X$ 以逐渐减小的斜率上升，渐近地（双曲线型拖尾）趋向 **≈ 1.97 V**，该处满足 $3 - V_X = V_{TH}(V_X)$（不计体效应时为 2.3 V）。

**常见错误。** 让 $V_X$ 一直上升到 3 V。源极跟随器只能把输出抬高到 $V_{GS}$ 降到 $V_{TH}$ 为止；体效应使 $V_{TH}$ 升高到约 1.03 V，因此这一位置约为 1.97 V。

**常见错误。** 漏掉跳变，或者把跳变方向弄反。在阶跃瞬间 $C_1$ 保持其 3 V 电压，因此 X 与输入完全同步地变化：从 −3 V 升到 0 V。

**常见错误。** 让 $V_X$ 在跳变后停留在 0 V，或者下降。阶跃刚结束时 $V_{GS} = V_{DS} = 3$ V，因此 $M_1$ 强烈导通，电流**流入** X，把它向上充电。
