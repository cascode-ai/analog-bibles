# 详细步骤 - R122

**思路。** $M_1$ 是驱动节点 $A$ 的共源级（即其漏极，也是 $M_3$ 的漏极）；$M_2$ 是从 $A$ 到输出端的源极跟随器（source follower），以理想的 $I_1$ 为负载；输出端驱动 PMOS $M_3$ 的栅极。在输出端（由此确定跟随器增益）和 $A$ 点列基尔霍夫电流定律（KCL）方程并求解。经跟随器闭合后，$M_3$ 的行为类似于二极管连接负载。

### 第 1 步 — 小信号模型（small-signal model）

$V_{DD}$ 为交流地，$\gamma = 0$，理想的 $I_1$ 相当于**开路**。以 $v_A$ 和 $v_{out}$ 为未知量：

- **$M_1$**：$v_{gs1} = v_{in}$；受控源 $g_{m1}v_{in}$ 从 $A$ 流向地，$r_{O1}$ 从 $A$ 接到地。
- **$M_3$**：$v_{gs3} = v_{out}$（源极接交流地）；受控源 $g_{m3}v_{out}$ 从 $A$（漏极）流向交流地，$r_{O3}$ 从 $A$ 接到交流地。
- **$M_2$**：$v_{gs2} = v_A - v_{out}$；受控源 $g_{m2}(v_A - v_{out})$ 从交流地（漏极）流入输出端（源极），$r_{O2}$ 从输出端接到交流地。

### 第 2 步 — 输出端的 KCL：跟随器

$I_1$ 开路，且 $M_3$ 的栅极不吸取电流，因此 $M_2$ 的小信号电流为**零**（$r_{O2}$ 中的电流为 $(0 - v_{out})/r_{O2}$）：

$$g_{m2}(v_A - v_{out}) - \frac{v_{out}}{r_{O2}} = 0.$$

解出 $v_A$：

$$g_{m2}v_A = v_{out}\left(g_{m2} + \frac{1}{r_{O2}}\right)\quad\Longrightarrow\quad v_A = v_{out}\left(1 + \frac{1}{g_{m2}r_{O2}}\right). \tag{1}$$

跟随器的增益为 $v_{out}/v_A = g_{m2}r_{O2}/(1 + g_{m2}r_{O2})$，略小于 1。

### 第 3 步 — 节点 A 的 KCL

电流从 $A$ 点经 $M_1$ 和 $M_3$ 流出：

$$g_{m1}v_{in} + \frac{v_A}{r_{O1}} + g_{m3}v_{out} + \frac{v_A}{r_{O3}} = 0, \tag{2}$$

$$g_{m1}v_{in} = -g_{m3}v_{out} - v_A\left(\frac{1}{r_{O1}} + \frac{1}{r_{O3}}\right).$$

### 第 4 步 — 求解增益

将式 (1) 代入式 (2)：

$$g_{m1}v_{in} = -v_{out}\left[g_{m3} + \left(\frac{1}{r_{O1}} + \frac{1}{r_{O3}}\right)\left(1 + \frac{1}{g_{m2}r_{O2}}\right)\right],$$

$$A_v = \frac{v_{out}}{v_{in}} = -\frac{g_{m1}}{g_{m3} + \left(\dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}}\right)\left(1 + \dfrac{1}{g_{m2}r_{O2}}\right)}.$$

**多项式形式。** 将分子和分母同乘 $g_{m2}r_{O1}r_{O2}r_{O3}$，分母各项变为

$$
\begin{aligned}
g_{m3}\cdot g_{m2}r_{O1}r_{O2}r_{O3} &= g_{m2}g_{m3}r_{O1}r_{O2}r_{O3},\\
\left(\frac{1}{r_{O1}} + \frac{1}{r_{O3}}\right)g_{m2}r_{O1}r_{O2}r_{O3} &= g_{m2}r_{O2}(r_{O1} + r_{O3}),\\
g_{m2}r_{O2}(r_{O1} + r_{O3})\left(1 + \frac{1}{g_{m2}r_{O2}}\right) &= (r_{O1} + r_{O3})(1 + g_{m2}r_{O2}) = g_{m2}r_{O1}r_{O2} + g_{m2}r_{O2}r_{O3} + r_{O1} + r_{O3}.
\end{aligned}
$$

因此

$$A_v = -\frac{g_{m1}g_{m2}r_{O1}r_{O2}r_{O3}}{g_{m2}g_{m3}r_{O1}r_{O2}r_{O3} + g_{m2}r_{O1}r_{O2} + g_{m2}r_{O2}r_{O3} + r_{O1} + r_{O3}}.$$

### 第 5 步 — 近似与直观理解

在紧凑形式中，$(1/r_{O1} + 1/r_{O3})(1 + 1/(g_{m2}r_{O2}))$ 的量级为 $2/r_O$，而 $g_{m3}r_O \gg 1$，因此

$$A_v \approx -\frac{g_{m1}}{g_{m3}}.$$

**为什么它的行为类似于二极管连接负载。** 跟随器中没有信号电流，因此 $v_{out} \approx v_A$：$M_3$ 的栅极随其自身的漏极一起变化，$A$ 点看到约 $1/g_{m3}$ 的电阻（与 $r_{O1}$ 和 $r_{O3}$ 并联）。因此 $M_1$ 到 $A$ 点的增益约为 $-g_{m1}/g_{m3}$，跟随器再把它复制到输出端。从反馈的角度看，$A$ 点升高会抬高 PMOS 的栅极，于是 $M_3$ 流入 $A$ 的电流减小，把它重新拉低。（从直流角度看，$M_3$ 的栅极比其漏极低一个 $V_{GS2}$，这与真正的二极管连接不同，但小信号效果相同。）

**极限情况验证。** 若 $M_3$ 的栅极接固定偏置（$g_{m3} \to 0$），增益变为 $-g_{m1}(r_{O1}\parallel r_{O3})\cdot g_{m2}r_{O2}/(1 + g_{m2}r_{O2})$：即高增益共源级后接跟随器。经 $M_3$ 的反馈把增益降低到约 $g_{m1}/g_{m3}$。

### 结果

$$A_v = -\frac{g_{m1}}{g_{m3} + \left(\dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}}\right)\left(1 + \dfrac{1}{g_{m2}r_{O2}}\right)} = -\frac{g_{m1}g_{m2}r_{O1}r_{O2}r_{O3}}{g_{m2}g_{m3}r_{O1}r_{O2}r_{O3} + g_{m2}r_{O1}r_{O2} + g_{m2}r_{O2}r_{O3} + r_{O1} + r_{O3}} \approx -\frac{g_{m1}}{g_{m3}}.$$

**常见错误。** 忽略经 $M_3$ 的反馈（把栅极当作接固定偏置），写成 $A_v \approx -g_{m1}(r_{O1}\parallel r_{O3})$。$M_3$ 的栅极经由输出端跟随 $A$ 变化，因此 $M_3$ 实际上是一个约为 $1/g_{m3}$ 的二极管连接负载。

**常见错误。** 给 $I_1$ 赋予有限的小信号电阻。由于 $I_1$ 是理想的，且 $M_3$ 的栅极不吸取电流，$M_2$ 的小信号电流恰好为零，由此得到 $v_{out} = v_A\,g_{m2}r_{O2}/(1 + g_{m2}r_{O2})$。

**常见错误。** 把 $-g_{m1}/g_{m3}$ 当作精确答案。它只是 $g_mr_O \gg 1$ 时的极限；精确结果保留了 $(1/r_{O1} + 1/r_{O3})(1 + 1/(g_{m2}r_{O2}))$ 项，该项使增益略有降低。
