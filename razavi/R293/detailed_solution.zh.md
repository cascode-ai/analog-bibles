# 详细步骤 - R293

**思路。** 用 $g_mV_{GS}$ 代替 $M_1$（由于 $\lambda = 0$，没有 $r_O$），在输入端加测试源，并在栅极和漏极列基尔霍夫电流定律（KCL）方程。关键在于：流过 $C_2$ 的电流除了流入 $M_1$ 的漏极之外无处可去。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 的栅极（位于 $C_1$ 与 $C_2$ 之间）称为节点 **A**，把其漏极称为节点 **D**；假设 $M_1$ 工作在饱和区（saturation region）。对小信号而言，理想电流源 $I_1$ 相当于开路；又因 $\lambda = 0$，不存在 $r_O$，所以从 D 到地的唯一元件就是受控源 $g_mV_A$（$V_{GS} = V_A$，源极接地）。在输入端加测试电压 $V_x$，其输入电流为 $I_x$。

<!-- diagram: diagram-01.cir -->

### 第 2 步 — 栅极（A）与漏极（D）的 KCL

栅极不吸取电流，因此经 $C_1$ 流入 A 的电流全部经 $C_2$ 流出：

$$I_{C1} = I_{C2} = I_x .$$

在 D 点，该电流只能经晶体管流走（$I_1$ 开路，且没有 $r_O$）：

$$I_x = g_mV_A \quad\Longrightarrow\quad V_A = \frac{I_x}{g_m}, \qquad Z_A = \frac{V_A}{I_x} = \frac{1}{g_m},$$

它与 $C_2$ 和频率都无关。漏极电压会自行调整，使 $I_x$ 流过 $C_2$：

$$V_D = V_A - \frac{I_x}{C_2s} = I_x\left(\frac{1}{g_m} - \frac{1}{C_2s}\right).$$

实际上，对交流信号而言，$C_2$ 把 $M_1$ 接成了“二极管连接”（diode-connected）形式，因此节点 A 呈现的阻抗为 $1/g_m$。

### 第 3 步 — 从输入端到地应用基尔霍夫电压定律（KVL）

从输入端经 $C_1$ 到节点 A，并代入 $V_A = I_x/g_m$：

$$
\begin{aligned}
V_x &= \frac{I_x}{C_1s} + V_A = \frac{I_x}{C_1s} + \frac{I_x}{g_m}\\
&= I_x\left(\frac{1}{C_1s} + \frac{1}{g_m}\right),
\end{aligned}
$$

$$Z_{in} = \frac{V_x}{I_x} = \frac{1}{C_1s} + \frac{1}{g_m}.$$

输入阻抗为 $C_1$ 与电阻 $1/g_m$ 的串联；$C_2$ 不出现在结果中。

### 第 4 步 — 用密勒定理（Miller's theorem）验证

密勒定理在节点 A 处用 $Z/(1 - A_v)$ 代替 $Z = 1/(C_2s)$，其中 $A_v$ 是从 A 到 D 的**精确**增益。由第 2 步，

$$A_v = \frac{V_D}{V_A} = \frac{I_x\left(\dfrac{1}{g_m} - \dfrac{1}{C_2s}\right)}{I_x/g_m} = 1 - \frac{g_m}{C_2s},$$

因此

$$
\begin{aligned}
1 - A_v &= \frac{g_m}{C_2s},\\
Z_A &= \frac{1/(C_2s)}{1 - A_v} = \frac{1}{C_2s}\cdot\frac{C_2s}{g_m} = \frac{1}{g_m},
\end{aligned}
$$

与第 2 步的结果一致。这里的 $A_v$ 与频率有关；而共源级（common-source stage）的“低频增益”在本题中为无穷大（理想电流源负载，$\lambda = 0$），若用它计算，就会错误地在 A 点得到一个极大的电容。

### 结果

$$Z_{in} = \frac{1}{C_1s} + \frac{1}{g_m}$$

输入端等效为 $C_1$ 与电阻 $1/g_m$ 串联。$C_2$ 不起作用：流过它的电流必须全部被 $M_1$ 的漏极电流 $g_mV_A$ 吸收，因此节点 A 对地总是呈现 $1/g_m$。

**常见错误。** 用固定的增益套用密勒定理，例如写成 $C_2(1 + g_mr_O)$，或认为“增益无穷大使 $C_2$ 变为无穷大”。该因子是 $1 - V_D/V_A$，其中应使用**实际**增益，而本题中实际增益取决于流过 $C_2$ 本身的电流；正确计算得到 $1/g_m$，其中完全不含 $C_2$。

**常见错误。** 忽略晶体管，把电路当作两个串联的电容，得到 $Z_{in} = 1/(C_1s) + 1/(C_2s)$。漏极并不是地；其电压由“$M_1$ 必须吸收电容电流”这一条件决定，而且 $Z_{in}$ 有实部 $1/g_m$。

**常见错误。** 漏掉 $C_1$，只给出 $1/g_m$；这是节点 A 处的阻抗，而不是输入端的阻抗。
