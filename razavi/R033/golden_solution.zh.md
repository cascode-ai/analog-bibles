当 $t < 0$ 时，$V_X = 2$ V（$M_1$ 截止，$V_{in} = 0$）。在 $t = 0$ 时，阶跃通过 $C_1$ 耦合过来：$V_X$ 跳变到 3 + 2 = 5 V。此时 $M_1$（$V_{GS} = 3$ V）处于饱和区（saturation region），以恒定电流 $\tfrac12\beta(2.3)^2 = 2.65\beta$ 对 X 放电，因此 $V_X$ 以 $2.65\beta/C_1$ 的速率线性下降，直到降到 2.3 V。随后 $M_1$ 处于线性区（triode region），$V_X$ 大致按指数规律衰减到 0（时间常数 ≈ $C_1/(2.3\beta)$）。$C_1$ 的最终电压为 −3 V（X 为 0，另一极板为 3 V）。
- 节点 X 只连接 $C_1$（其另一极板由 $V_{in}$ 固定）和 $M_1$ 的漏极，因此跳变量是完整的 3 V。
