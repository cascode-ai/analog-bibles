# 详细步骤 - R033

**思路。** $C_1$ 把输入节点与节点 X 连接起来，而 X 除了 $M_1$ 的漏极之外，没有其他通向固定电压的路径。因此当 $V_{in}$ 阶跃时，电容把 X 抬高整个阶跃幅度。同一阶跃使 $M_1$ 导通，随后 $M_1$ 对 X 放电：先以恒定的饱和电流放电（线性斜坡），然后在线性区放电（类指数拖尾），直到 0 V。

### 第 1 步 — 阶跃之前（$t < 0$）

$C_1$ 上的电压为 2 V，X 端为正，因此 $V_X = V_{in} + V_{C1}$。当 $t < 0$ 时，$V_{in} = 0$，且

$$V_X = 0 + 2 = 2\ \mathrm{V}.$$

$M_1$ 截止（$V_{GS} = 0 < V_{TH}$），因此没有任何东西使 $C_1$ 放电，$V_X$ 保持 2 V。

### 第 2 步 — $t = 0$ 时的跳变

$M_1$ 只能提供有限的电流，在零时间内无法转移电荷，因此在阶跃刚结束时 $V_{C1}$ 仍为 2 V，且

$$V_X(0^+) = V_{in}(0^+) + V_{C1}(0^+) = 3 + 2 = 5\ \mathrm{V}.$$

跳变量是完整的 3 V：节点 X 只连接 $C_1$（其另一极板由 $V_{in}$ 固定）和 $M_1$ 的漏极，因此不存在会衰减阶跃的电容分压器（capacitive divider）。

### 第 3 步 — 阶段 1：$M_1$ 饱和，线性下降

当 $t > 0$ 时：$V_{GS} = 3$ V；由于没有体效应（body effect），$V_{TH} = 0.7$ V，因此 $V_{ov} = 3 - 0.7 = 2.3$ V，而 $V_{DS} = V_X = 5$ V $> 2.3$ V：**$M_1$ 处于饱和区**，且

$$I_D = \tfrac12\beta\,(2.3\ \mathrm{V})^2 = 2.645\,\beta\ \mathrm{V^2} \approx 2.65\beta \quad(\text{constant}).$$

这一电流经漏极离开 X，由输入源经 $C_1$ 提供。此时 $V_{in}$ 恒定，$dV_{C1}/dt = dV_X/dt$，在 X 点列基尔霍夫电流定律（KCL）方程得

$$C_1\frac{dV_X}{dt} = -I_D \quad\Longrightarrow\quad V_X(t) = 5\ \mathrm{V} - \frac{2.65\,\beta}{C_1}\,t .$$

**$V_X$ 线性下降**，直到达到饱和区边缘 $V_X = V_{GS} - V_{TH} = 2.3$ V，此时

$$t_1 = \frac{C_1\,(5 - 2.3)\ \mathrm{V}}{2.645\,\beta\ \mathrm{V^2}} = \frac{1.02\,C_1}{\beta\ \mathrm{V}} .$$

### 第 4 步 — 阶段 2：线性区，衰减到零

当 $V_X < 2.3$ V 时，$M_1$ 处于线性区：

$$C_1\frac{dV_X}{dt} = -\beta\left[2.3V_X - \tfrac12V_X^2\right].$$

分离变量（利用部分分式），并以 $t_1$ 时 $V_X = 2.3$ V 为起点：

$$V_X(t) = \frac{4.6\ \mathrm{V}\cdot E}{1 + E}, \qquad E = e^{-(t - t_1)/\tau}, \qquad \tau = R_{on}C_1 = \frac{C_1}{2.3\,\beta},$$

其中 $R_{on} = 1/[\beta(3 - 0.7)]$ 为深线性区的导通电阻（on-resistance）。在 $t_1$ 时 $E = 1$，$V_X = 2.3$ V；当 $t - t_1 \gg \tau$ 时，$V_X \approx 4.6\,e^{-(t - t_1)/\tau}$。**$V_X$ 大致按指数规律衰减到 0 V**，并且在 $t_1$ 处斜率连续（$V_X = 2.3$ V 时的线性区电流等于饱和电流）。

**最终状态。** $V_X = 0$，$V_{in} = 3$ V，因此 $C_1$ 最终保持 $0 - 3 = -3$ V：此时 X 比另一极板**低** 3 V。$M_1$ 总共从节点 X 移走了 $C_1\times5$ V 的电荷。

### 第 5 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF：$I_D = 2.65$ mA，斜坡的斜率为 $-2.65$ V/ns，$t_1 = 2.7\ \mathrm{V}/(2.65\ \mathrm{V/ns}) = 1.02$ ns，$\tau = 1\ \mathrm{pF}/2.3\ \mathrm{mS} = 0.43$ ns。

| $t$ | $V_X$ (V) | $M_1$ |
|---|---|---|
| $t < 0$ | 2.0 | 截止 |
| $0^+$ | 5.0 | 饱和区 |
| 0.5 ns | 3.68 | 饱和区 |
| 1.02 ns | 2.30 | 边界 |
| $t_1 + \tau$ = 1.45 ns | 1.24 | 线性区 |
| $t_1 + 2\tau$ = 1.89 ns | 0.55 | 线性区 |
| $t_1 + 4\tau$ = 2.76 ns | 0.08 | 线性区 |
| ∞ | 0 | 线性区，无电流 |

（线性区的数值由 $V_X = 4.6E/(1 + E)$ 求得：例如 $E = e^{-1} = 0.368$ 给出 $1.69/1.368 = 1.24$ V，其余类推。）

### 结果

- **$t < 0$：** $V_X = 2$ V（$M_1$ 截止，$V_{in} = 0$）。
- **$t = 0$：** 阶跃通过 $C_1$ 耦合过来，**$V_X$ 跳变到 3 + 2 = 5 V**。节点 X 只连接 $C_1$（其另一极板由 $V_{in}$ 固定）和 $M_1$ 的漏极，因此跳变量是完整的 3 V。
- **阶段 1：** 此时 $M_1$（$V_{GS} = 3$ V）处于饱和区，以恒定电流 $\tfrac12\beta(2.3)^2 = 2.65\beta$ 对 X 放电。$V_X$ 以 $2.65\beta/C_1$ 的速率**线性下降**，在 $t_1 \approx 1.02\,C_1/\beta$ 时降到 2.3 V。
- **阶段 2：** $M_1$ 处于线性区，$V_X$ **大致按指数规律衰减到 0**（时间常数 ≈ $C_1/(2.3\beta)$）。
- $C_1$ 的**最终**电压：−3 V（X 为 0，另一极板为 3 V）。

**常见错误。** 在阶跃时让 $V_X$ 保持 2 V，或者只让它逐渐上升。在阶跃瞬间电容保持其电压不变，因此 X 跳变完整的 3 V。

**常见错误。** 让 $V_X$ 稳定在 5 V 或 2.3 V。栅极为 3 V 时，$M_1$ 会一直导通，直到其漏极降到地电位；2.3 V 只是恒流阶段与线性区阶段之间的分界。

**常见错误。** 把跳变方向弄反，认为在阶跃时栅极会“把漏极拉低”。在 $t = 0^+$ 时，晶体管还来不及转移任何电荷；唯一的瞬时效应是电容耦合，它使 X 升高。
