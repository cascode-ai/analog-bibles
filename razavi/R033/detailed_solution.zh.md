# 详细步骤 - R033

**思路：** 忽略节点 X 的寄生电容及沟道长度调制。$C_1$ 把输入节点与节点 X 连接起来，而 X 除了 $M_1$ 的漏极之外，没有其他通向固定电压的路径。因此当 $V_{in}$ 阶跃时，电容把 X 抬高整个阶跃幅度。同一阶跃使 $M_1$ 导通，随后 $M_1$ 对 X 放电：先以恒定的饱和电流放电（线性斜坡），然后在线性区放电（类指数拖尾），直到 0 V。

![R033 示例 $V_X(t)$ 波形](/q/R033/solution-vx.zh.svg)

### 第 1 步 — 阶跃之前（$t < 0$）

$C_1$ 上的电压为 2 V，X 端为正，因此 $V_X = V_{in} + V_{C1}$。当 $t < 0$ 时，$V_{in} = 0$，且

$$V_X = 0 + 2 = 2\ \mathrm{V}.$$

$M_1$ 截止（$V_{GS} = 0 < V_{TH}$），因此没有任何东西使 $C_1$ 放电，$V_X$ 保持 2 V。

### 第 2 步 — $t = 0$ 时的跳变

$M_1$ 只能提供有限的电流，在零时间内无法转移电荷，因此在阶跃刚结束时 $V_{C1}$ 仍为 2 V，且

$$V_X(0^+) = V_{in}(0^+) + V_{C1}(0^+) = 3 + 2 = 5\ \mathrm{V}.$$

跳变量是完整的 3 V：节点 X 只连接 $C_1$（其另一极板由 $V_{in}$ 固定）和 $M_1$ 的漏极，因此不存在会衰减阶跃的电容分压器（capacitive divider）。

### 第 3 步 — 饱和区放电与切换时刻

输入稳定在 3 V 后，$V_{GS}=3\ \mathrm{V}$。源极接地，因此 $V_{DS}=V_X$。衬底也接地，因此 $V_{TH}=V_{TH0}=0.7\ \mathrm{V}$，过驱动电压为 $V_{ov}=V_{GS}-V_{TH}=2.3\ \mathrm{V}$。导通的 NMOS 在 $V_{DS}\ge V_{ov}$ 时处于饱和区。由于 $V_X(0^+)=5\ \mathrm{V}$，器件起初处于饱和区。取 $\beta=\mu_n C_{ox}W/L$ 且 $\lambda=0$，饱和电流为

$$
I_D=\frac{\beta}{2}(V_{GS}-V_{TH})^2
=\frac{\beta}{2}(2.3\ \mathrm{V})^2
=2.645\,\beta\,\mathrm{V^2}.
$$

取两条支路的电流均以流出节点 X 为正。流向漏极的电流为 $I_D$，从 X 流经 $C_1$ 的电流为 $C_1\,d(V_X-V_{in})/dt$。由基尔霍夫电流定律，两者之和为零。阶跃后 $V_{in}$ 恒定，因此

$$
C_1\frac{d(V_X-V_{in})}{dt}+I_D=0\quad\Longrightarrow\quad C_1\frac{dV_X}{dt}=-I_D.
$$

负号表示晶体管从 X 侧极板抽走电荷。过驱动电压固定，且模型忽略沟道长度调制，所以饱和电流为常数。以 $V_X(0^+)=5\ \mathrm{V}$ 为初值，对恒定斜率积分，得到

$$
V_X(t)-5\ \mathrm{V}=-\frac{I_D}{C_1}t
=-\frac{2.645\,\beta\,\mathrm{V^2}}{C_1}t.
$$

此式适用到 $V_{DS}$ 首次降至 $V_{ov}$ 的时刻 $t_1$，即 $V_X(t_1)=2.3\ \mathrm{V}$。用电压降除以斜率的大小，得到

$$
t_1=\frac{C_1(5.0\ \mathrm{V}-2.3\ \mathrm{V})}{2.645\,\beta\,\mathrm{V^2}}
\approx (1.02\ \mathrm{V^{-1}})\frac{C_1}{\beta}.
$$

### 第 4 步 — 线性区放电与指数尾段

电压降到 2.3 V 以下后，$0<V_{DS}<V_{ov}$，沟道进入线性区。用线性区电流模型，将 $V_{DS}=V_X$ 代入同一个节点方程，得

$$
I_D=\beta\left(V_{ov}V_{DS}-\frac{V_{DS}^2}{2}\right),
\qquad
C_1\frac{dV_X}{dt}=-\beta V_X(V_{ov}-V_X/2).
$$

在 $V_X=V_{ov}$ 处，此电流等于 $\beta V_{ov}^2/2$，所以 $t_1$ 两侧的斜率相同。当 $0<V_X<V_{ov}$ 时，电流仍为正，$V_X$ 继续下降。

为求精确波形，先把电压项和时间项分开。电压项可以拆为两个容易积分的分式。

$$
\frac{dV_X}{V_X(V_{ov}-V_X/2)}=-\frac{\beta}{C_1}\,dt,
\qquad
\frac{1}{V_X(V_{ov}-V_X/2)}
=\frac{1}{V_{ov}}\left(\frac{1}{V_X}+\frac{1}{2V_{ov}-V_X}\right).
$$

合并两项的积分，得到 $\ln[V_X/(2V_{ov}-V_X)]$。分母中的 $-V_X$ 使第二项积分带负号。从 $(t_1,V_{ov})$ 积分到 $(t,V_X(t))$。下限处 $V_{ov}/(2V_{ov}-V_{ov})=1$，因此对数为零，得到

$$
\ln\frac{V_X(t)}{2V_{ov}-V_X(t)}
=-\frac{t-t_1}{\tau},
\qquad
\tau=\frac{C_1}{\beta V_{ov}}=\frac{C_1}{\beta(2.3\ \mathrm{V})}.
$$

记 $E=e^{-(t-t_1)/\tau}$。两边取指数并整理，得到 $V_X(1+E)=2V_{ov}E$，所以

$$
V_X(t)=\frac{(4.6\ \mathrm{V})E}{1+E},
\qquad t\ge t_1.
$$

在 $t_1$，$E=1$，所以 $V_X=2.3\ \mathrm{V}$。此后 $0<E<1$，故 $0<V_X<2.3\ \mathrm{V}$，符合线性区假设。当 $E$ 远小于 1 时，$V_X\simeq(4.6\ \mathrm{V})e^{-(t-t_1)/\tau}$。在这个尾段，电流表达式中的二次项可忽略，沟道近似为电阻 $R_{on}=1/(\beta V_{ov})$，因此时间常数为 $R_{on}C_1=\tau$。

当 $V_X$ 趋近 0 V 时，另一极板仍为 3 V，故 $V_{C1}=V_X-V_{in}\to-3\ \mathrm{V}$。X 侧极板的电荷从 $C_1(2\ \mathrm{V})$ 降到 $C_1(-3\ \mathrm{V})$，因此 $M_1$ 共抽走 $C_1(5\ \mathrm{V})$ 的电荷。

### 第 5 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF：$I_D = 2.65$ mA，斜坡的斜率为 $-2.65$ V/ns，$t_1 = 2.7\ \mathrm{V}/(2.645\ \mathrm{V/ns}) = 1.02$ ns，$\tau = 1\ \mathrm{pF}/2.3\ \mathrm{mS} = 0.43$ ns。

| $t$ | $V_X$ (V) | $M_1$ |
|---|---|---|
| $t < 0$ | 2.0 | 截止 |
| $0^+$ | 5.0 | 饱和区 |
| 0.5 ns | 3.68 | 饱和区 |
| 1.02 ns | 2.30 | 边界 |
| $t_1 + \tau$ = 1.46 ns | 1.24 | 线性区 |
| $t_1 + 2\tau$ = 1.89 ns | 0.55 | 线性区 |
| $t_1 + 4\tau$ = 2.76 ns | 0.08 | 线性区 |
| ∞ | 0 | 线性区，无电流 |

（线性区的数值由 $V_X = (4.6\ \mathrm{V})E/(1 + E)$ 求得：例如 $E = e^{-1} = 0.368$ 给出 $1.69/1.368 = 1.24$ V，其余类推。）

### 结果

- $t < 0$： $V_X = 2$ V（$M_1$ 截止，$V_{in} = 0$）。
- $t = 0$： 阶跃通过 $C_1$ 耦合过来，$V_X$ 跳变到 3 + 2 = 5 V。节点 X 只连接 $C_1$（其另一极板由 $V_{in}$ 固定）和 $M_1$ 的漏极，因此跳变量是完整的 3 V。
- 阶段 1： 此时 $M_1$（$V_{GS} = 3$ V）处于饱和区，以恒定电流 $\tfrac12\beta(2.3\ \mathrm{V})^2 = 2.645\,\beta\,\mathrm{V^2}$ 对 X 放电。$V_X$ 以 $\frac{(2.645\ \mathrm{V^2})\beta}{C_1}$ 的速率线性下降，在 $t_1 \approx (1.02\,\mathrm{V^{-1}})C_1/\beta$ 时降到 2.3 V。
- 阶段 2： $M_1$ 处于线性区，$V_X$ 大致按指数规律衰减到 0（时间常数 ≈ $C_1/((2.3\ \mathrm{V})\beta)$）。
- $C_1$ 的最终电压：−3 V（X 为 0，另一极板为 3 V）。

**常见错误：** 在阶跃时让 $V_X$ 保持 2 V，或者只让它逐渐上升。在阶跃瞬间电容保持其电压不变，因此 X 跳变完整的 3 V。

**常见错误：** 让 $V_X$ 稳定在 5 V 或 2.3 V。栅极为 3 V 时，$M_1$ 会一直导通，直到其漏极降到地电位；2.3 V 只是恒流阶段与线性区阶段之间的分界。

**常见错误：** 把跳变方向弄反，认为在阶跃时栅极会“把漏极拉低”。在 $t = 0^+$ 时，晶体管还来不及转移任何电荷；唯一的瞬时效应是电容耦合，它使 X 升高。
