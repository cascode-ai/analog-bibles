# 详细步骤 - R180

**思路。** 先汇总电压余度的限制：0.4 V 的尾电流源要求决定了最低输入共模电平，从而决定了最低输出电压；PMOS 器件决定了最高输出电压。但二极管负载还决定了输出共模电平，而且每个二极管在 $V_{DD} - |V_{THP}| = 2.2$ V 处停止导通。由于两个二极管总共只分到 0.2 mA，需要对电流如何重新分配进行大信号分析，才能得到真正可用的摆幅，它远小于电压余度限制所暗示的值。

### 第 1 步 — 电流与输出共模电平

所有晶体管的 $W/L = 50/0.5 = 100$，因此 $\beta_n = (134\ \mu\mathrm{A/V^2})(100) = 13.4\ \mathrm{mA/V^2}$，$\beta_p = (38.4\ \mu\mathrm{A/V^2})(100) = 3.84\ \mathrm{mA/V^2}$。

每个输入器件流过 $I_{SS}/2 = 0.5$ mA；其中 $0.8\times 0.5 = 0.4$ mA 由 $M_5$ 提供，因此二极管 $M_3$ 流过 $0.5 - 0.4 = 0.1$ mA（右边同理）。处于饱和的二极管由其电流决定漏极电压：

$$V_X = V_{DD} - |V_{THP}| - \sqrt{\frac{2I_{D3}}{\beta_p}} .$$

平衡时：

$$V_{X,CM} = 3 - 0.8 - \sqrt{\frac{2(0.1\ \mathrm{mA})}{3.84\ \mathrm{mA/V^2}}} = 2.2 - 0.228 = 1.972\ \mathrm{V},$$

由于二极管电流很小，该电平只比 2.2 V 低 0.228 V。

### 第 2 步 — 电压余度限制

**最低输入共模电平。** 尾电流源需要 $V_P \ge 0.4$ V，而 $V_{GS1} = V_{TH1} + V_{ov1}$，其中

$$V_{ov1} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = 0.273\ \mathrm{V}, \qquad V_{TH1} = 0.7 + 0.45\left(\sqrt{0.9 + 0.4} - \sqrt{0.9}\right) = 0.786\ \mathrm{V},$$

$$V_{in,CM,min} = 0.4 + 0.273 + 0.786 = 1.46\ \mathrm{V}.$$

**最低输出电压**（输入器件保持饱和）：$V_{out} \ge V_{in,CM} - V_{TH1} = 1.46 - 0.786 = 0.673$ V。

**最高输出电压：**

- 二极管 $M_3$ 只有在 $V_{SG3} = V_{DD} - V_X > |V_{THP}|$，即 $V_X < 2.2$ V 时才导通；
- $M_5$ 在 $V_X \le V_{DD} - V_{ov5}$ 时保持饱和，其中 $V_{ov5} = \sqrt{2(0.4\ \mathrm{mA})/(3.84\ \mathrm{mA/V^2})} = 0.456$ V，即 $V_X \le 2.54$ V。

若只考虑电压余度，每个输出可以从 0.673 V 变化到 2.2 V（差分约 3 V 峰峰值），但输出实际处于何处由二极管负载决定。

### 第 3 步 — 电流的大信号重新分配

导向 $\Delta$ 的电流：$I_{D1} = 0.5\ \mathrm{mA} + \Delta$，$I_{D2} = 0.5\ \mathrm{mA} - \Delta$。$M_5$ 和 $M_6$ 仍各自提供固定的 0.4 mA，因此全部变化都进入二极管：

$$I_{D3} = 0.1\ \mathrm{mA} + \Delta, \qquad I_{D4} = 0.1\ \mathrm{mA} - \Delta, \qquad I_{D3} + I_{D4} = 0.2\ \mathrm{mA},$$

$$V_X = 2.2\ \mathrm{V} - \sqrt{\frac{2(0.1\ \mathrm{mA} + \Delta)}{\beta_p}}, \qquad V_Y = 2.2\ \mathrm{V} - \sqrt{\frac{2(0.1\ \mathrm{mA} - \Delta)}{\beta_p}} .$$

| $\Delta$ (mA) | $I_{D3}$ (mA) | $I_{D4}$ (mA) | $V_X$ (V) | $V_Y$ (V) | $V_X - V_Y$ (V) |
|---|---|---|---|---|---|
| 0 | 0.100 | 0.100 | 1.972 | 1.972 | 0 |
| 0.025 | 0.125 | 0.075 | 1.945 | 2.002 | −0.058 |
| 0.050 | 0.150 | 0.050 | 1.921 | 2.039 | −0.118 |
| 0.075 | 0.175 | 0.025 | 1.898 | 2.086 | −0.188 |
| 0.100 | 0.200 | 0 | 1.877 | 2.200 | −0.323 |

在 $\Delta = 0.1$ mA 时二极管 $M_4$ 截止：

$$V_X = 2.2 - \sqrt{\frac{2(0.2\ \mathrm{mA})}{3.84\ \mathrm{mA/V^2}}} = 2.2 - 0.323 = 1.877\ \mathrm{V}, \qquad V_Y = 2.2\ \mathrm{V}, \qquad V_X - V_Y = -0.323\ \mathrm{V}.$$

两个输出的变化是**不对称**的：上升的输出移动了 0.228 V（到 2.2 V），下降的输出只移动了 0.095 V，因为在较大电流下二极管的平方根特性变化较慢。

### 第 4 步 — 二极管截止之后的情况

当 $\Delta > 0.1$ mA 时，$M_4$ 截止，而 $M_6$ 仍向 $Y$ 注入 0.4 mA，$M_2$ 却只抽走 $0.5\ \mathrm{mA} - \Delta < 0.4$ mA。多余的电流使 $Y$ 向上充电，直到 $M_6$ 离开饱和区（高于 2.54 V），其电流下降到与 $I_{D2}$ 相等。所以 $V_Y$ 从 2.2 V 跳到 2.54 V 以上：传输曲线上出现一个几乎垂直的台阶，不能算作有效摆幅。

### 第 5 步 — 最大差分摆幅

由对称性，反方向导向时，当 $M_3$ 截止时 $V_X - V_Y = +0.323$ V，因此

$$-0.32\ \mathrm{V} \le V_X - V_Y \le +0.32\ \mathrm{V}\quad\Longrightarrow\quad \approx 0.65\ \mathrm{V}\ \text{peak-to-peak}.$$

在此范围内，输出保持在 1.877 V 与 2.2 V 之间，远高于 0.673 V 的下限：**起决定作用的约束是二极管截止，而不是 0.4 V 的尾电流源要求。**

**为什么不是每个输出 ±0.228 V？** 线性化估计让每个输出在 1.972 V 附近摆动 ±0.228 V，差分约 0.91 V 峰峰值。这是无法达到的：下降的输出要到达 $1.972 - 0.228 = 1.744$ V，其二极管需要 $\tfrac12\beta_p(2.2 - 1.744)^2 = 0.4$ mA，而两个二极管总共只分到 0.2 mA。

### 结果

最大差分输出摆幅只有约 **0.65 V 峰峰值（±0.32 V）**。

- 二极管连接的负载各自只流过 0.1 mA，因此把输出共模电平置于 1.97 V，只比其截止点 $V_{DD} - |V_{THP}| = 2.2$ V 低 0.23 V。
- 在两边之间导向电流使二极管电流在 0 与 0.2 mA 之间变化。当一个二极管截止时（$\Delta = 0.1$ mA），$V_X - V_Y = 1.877 - 2.2 = -0.32$ V。超过这一点，截止一侧的输出跳向 $M_5$/$M_6$ 保持饱和的电压上限，不再受输入的线性控制。
- 电压余度界限始终达不到：$V_{in,CM} = 1.46$ V 时输出可低至 $V_{in,CM} - V_{TH1} = 0.673$ V，$M_5$ 保持饱和的电压上限为 2.54 V。

**常见错误。** 只用电压余度范围作答，即从 0.673 V 到 2.2 V（差分 ≈ 3 V 峰峰值），而不检查二极管负载把输出置于何处。

**常见错误。** 把 $M_5$/$M_6$ 保持饱和的电压上限（$V_{DD} - V_{ov5} \approx 2.54$ V）甚至 $V_{DD}$ 当作上限。高于 2.2 V 时二极管截止，输出会跳变，而不是跟随输入变化。

**常见错误。** 使用线性化估计，即每个输出 ±0.228 V（≈ 0.9 V 峰峰值）。两个二极管总共只分到 0.2 mA，因此上升的输出升高 0.228 V 时，下降的输出只能下降 0.095 V。
