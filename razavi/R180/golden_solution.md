# Golden Solution - R180

## Reference answer

Only about 0.65 V peak-to-peak differential (±0.32 V): the swing is limited by the diode-connected loads turning off, not by the 0.4-V tail headroom.
- Headroom bounds: with the lowest input CM level, $V_{in,CM} = 0.4 + V_{GS1} = 0.4 + 0.273 + 0.786 = 1.46$ V, the outputs may go down to $V_{in,CM} - V_{TH1} = 0.673$ V; upward, each diode load ($M_3$, $M_4$) stops conducting at $V_{DD} - |V_{THP}| = 2.2$ V ($M_5$, $M_6$ would allow 2.54 V).
- The output CM level is fixed by the diodes carrying 0.1 mA: $V_{DD} - 0.8 - \sqrt{2(0.1\ \mathrm{m})/(3.84\ \mathrm{m})} = 1.97$ V, only 0.23 V below the 2.2-V ceiling.
- Large signal: $I_{D1} = 0.5\ \mathrm{mA} + \Delta$, $I_{D2} = 0.5\ \mathrm{mA} - \Delta$, so the diodes carry $0.1\ \mathrm{mA} \pm \Delta$; $M_4$ turns off at $\Delta = 0.1$ mA. At that point $V_{out1} = 2.2 - \sqrt{2(0.2\ \mathrm{m})/(3.84\ \mathrm{m})} = 1.88$ V and $V_{out2} = 2.2$ V, i.e. $V_{out1} - V_{out2} = -0.32$ V. Beyond it the node of the turned-off diode is driven only by a current source and shoots toward $V_{DD}$ (the gain changes abruptly), so the usable differential swing is ≈ ±0.32 V ≈ 0.65 V pp. (A linearized estimate, ±0.23 V on each output around 1.97 V, gives ≈ 0.9 V pp, but it is not reachable: since $I_{D3} + I_{D4} = 0.2$ mA, an output at 1.74 V would need 0.4 mA in its diode.)
