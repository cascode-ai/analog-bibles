# 详细步骤 - R009

**思路。** 对 PMOS 而言，电位较高的扩散区端（diffusion terminal）是源极，因此扫描范围在 $V_X = 1.9$ V 处分为两段。在每一段中计入体效应计算 $|V_{TH}|$：n 阱（n-well）接 $V_{DD} = 3$ V，电位高于两个沟道端子。然后判断 $M_1$ 是否导通、处于哪个工作区，并计算平方律（square law）电流和 $g_m$；计算中使用正的量 $V_{SG}$、$V_{SD}$、$V_{BS} \ge 0$ 以及 $V_{ov} = V_{SG} - |V_{TH}|$。

### 第 1 步 — $V_X < 1.9$ V：体效应使器件截止

电位较高的端子（1.9 V 节点）是源极：

$$
\begin{aligned}
V_{SG} &= 1.9 - 1 = 0.9\ \mathrm{V},\\
V_{BS} &= 3 - 1.9 = 1.1\ \mathrm{V}.
\end{aligned}
$$

计入体效应（$\sqrt{0.8} = 0.8944$）：

$$
\begin{aligned}
|V_{TH}| &= |V_{TH0}| + \gamma\left(\sqrt{2|\phi_F| + V_{BS}} - \sqrt{2|\phi_F|}\right) = 0.8 + 0.4\left(\sqrt{0.8 + V_{BS}} - 0.8944\right)\ \mathrm{V}\\
&= 0.8 + 0.4\left(\sqrt{0.8 + 1.1} - 0.8944\right) = 0.8 + 0.4\,(1.3784 - 0.8944) = 0.8 + 0.4\times0.4840 = 0.994\ \mathrm{V}.
\end{aligned}
$$

由于 $V_{SG} = 0.9\ \mathrm{V} < |V_{TH}| = 0.994$ V，**$M_1$ 截止**：对所有 $V_X < 1.9$ V，$I_X = 0$，$g_m = 0$。此时栅压距阈值电压（threshold voltage）还差约 0.09 V，只有极小的亚阈值（subthreshold）漏电流。若没有体效应（$|V_{TH}| = 0.8$ V），器件在这里**会**导通，过驱动电压（overdrive voltage）为 $0.1$ V；正是 n 阱比源极高 1.1 V 所造成的 0.19 V 阈值电压增量使它截止。

### 第 2 步 — $V_X > 1.9$ V：$V_X$ 端是源极；导通点

此时 $V_X$ 端是源极，1.9 V 端是漏极：

$$
\begin{aligned}
V_{SG} &= V_X - 1,\\
V_{SD} &= V_X - 1.9,\\
V_{BS} &= 3 - V_X,\\
|V_{TH}| &= 0.8 + 0.4\left(\sqrt{3.8 - V_X} - 0.8944\right).
\end{aligned}
$$

随着 $V_X$ 升高，$V_{SG}$ 增大，**同时** $|V_{TH}|$ 减小，因此器件在唯一一点导通，该点满足 $V_{SG} = |V_{TH}|$：

$$V_X - 1 = 0.8 + 0.4\sqrt{3.8 - V_X} - 0.4\times0.8944 .$$

代入 $w = \sqrt{3.8 - V_X}$，即 $V_X = 3.8 - w^2$：

$$
\begin{aligned}
3.8 - w^2 - 1 &= 0.8 + 0.4w - 0.3578\\
2.8 - w^2 &= 0.4422 + 0.4w\\
w^2 + 0.4w - 2.3578 &= 0 .
\end{aligned}
$$

取正根，

$$w = \frac{-0.4 + \sqrt{0.16 + 4\times2.3578}}{2} = \frac{-0.4 + \sqrt{9.5911}}{2} = \frac{-0.4 + 3.0969}{2} = 1.3485 ,$$

$$V_X = 3.8 - w^2 = 3.8 - 1.8184 = 1.98\ \mathrm{V}.$$

验算：$V_{SG} = 0.98$ V，$|V_{TH}| = 0.8 + 0.4(1.3485 - 0.8944) = 0.98$ V。✓ 所以 **$M_1$ 在 $V_X \approx 1.98$ V 之前一直截止**，高于该值后导通。

### 第 3 步 — 导通后处于饱和区还是线性区

饱和要求 $V_{SD} \ge V_{SG} - |V_{TH}|$：

$$
\begin{aligned}
V_X - 1.9 &\ge V_X - 1 - |V_{TH}|\\
|V_{TH}| &\ge 0.9\ \mathrm{V}.
\end{aligned}
$$

$V_X$ 被消去：栅极电位始终比漏极低 0.9 V。$|V_{TH}| = 0.9$ V 的条件为

$$
\begin{aligned}
0.4\left(\sqrt{3.8 - V_X} - 0.8944\right) &= 0.1\\
\sqrt{3.8 - V_X} &= 0.8944 + 0.25 = 1.1444\\
3.8 - V_X &= 1.3097\\
V_X &= 2.49\ \mathrm{V}.
\end{aligned}
$$

因此：

- $1.98\ \mathrm{V} < V_X < 2.49$ V：**饱和区**；
- $2.49\ \mathrm{V} < V_X \le 3$ V：**线性区**（源极电位接近 n 阱电位，$|V_{TH}|$ 已降到 0.9 V 以下）。

### 第 4 步 — 各工作区的电流

电流从 $V_X$ 电源流入 $M_1$，经过沟道，从 1.9 V 漏极流出，与箭头方向一致，因此 **$I_X > 0$**。

**饱和区**（$1.98 < V_X < 2.49$ V）：

$$I_X = \tfrac12\beta_p\,(V_X - 1 - |V_{TH}|)^2 .$$

- $V_X = 2.1$ V：$|V_{TH}| = 0.8 + 0.4(\sqrt{1.7} - 0.8944) = 0.8 + 0.4\times0.4094 = 0.964$ V，$V_{ov} = 1.1 - 0.964 = 0.136$ V，
$$I_X = \tfrac12\beta_p(0.136\ \mathrm{V})^2 = 0.0093\beta_p\ \mathrm{V^2}.$$
- $V_X = 2.3$ V：$|V_{TH}| = 0.8 + 0.4(\sqrt{1.5} - 0.8944) = 0.8 + 0.4\times0.3303 = 0.932$ V，$V_{ov} = 1.3 - 0.932 = 0.368$ V，
$$I_X = \tfrac12\beta_p(0.368\ \mathrm{V})^2 = 0.068\beta_p\ \mathrm{V^2}.$$
- $V_X = 2.49$ V：$|V_{TH}| = 0.900$ V，$V_{ov} = 1.49 - 0.90 = 0.59$ V，
$$I_X = \tfrac12\beta_p(0.59\ \mathrm{V})^2 = 0.174\beta_p\ \mathrm{V^2}.$$

**线性区**（$2.49 < V_X \le 3$ V）：

$$I_X = \beta_p\left[(V_X - 1 - |V_{TH}|)(V_X - 1.9) - \tfrac12(V_X - 1.9)^2\right].$$

- $V_X = 2.7$ V：$|V_{TH}| = 0.8 + 0.4(\sqrt{1.1} - 0.8944) = 0.8 + 0.4\times0.1544 = 0.862$ V，$V_{ov} = 1.7 - 0.862 = 0.838$ V，$V_{SD} = 0.8$ V，
$$I_X = \beta_p\left[(0.838)(0.8) - \tfrac12(0.8)^2\right]\ \mathrm{V^2} = \beta_p(0.670 - 0.320)\ \mathrm{V^2} = 0.351\beta_p\ \mathrm{V^2}.$$
- $V_X = 3$ V：$V_{BS} = 0$，因此 $|V_{TH}| = 0.8$ V；$V_{ov} = 2 - 0.8 = 1.2$ V，$V_{SD} = 1.1$ V，
$$I_X = \beta_p\left[(1.2)(1.1) - \tfrac12(1.1)^2\right]\ \mathrm{V^2} = \beta_p(1.320 - 0.605)\ \mathrm{V^2} = 0.715\beta_p\ \mathrm{V^2}.$$

### 第 5 步 — 跨导

- **截止**（$V_X < 1.98$ V）：$g_m = 0$。
- **饱和区**：$g_m = \beta_pV_{ov} = \beta_p(V_X - 1 - |V_{TH}|)$，从 1.98 V 处的 0 开始，经过 $0.136\beta_p$（2.1 V）和 $0.368\beta_p$（2.3 V），上升到 2.49 V 处的 $0.59\beta_p$。
- **线性区**：$g_m = \beta_pV_{SD} = \beta_p(V_X - 1.9)$，是一条直线，从 2.49 V 处的 $0.59\beta_p$ 上升到 3 V 处的 $1.1\beta_p$。

在边界处 $V_{ov} = V_{SD}$，因此两个表达式都给出 $0.59\beta_p$，$g_m$ 是连续的。

### 第 6 步 — 草图小结

| $V_X$ (V) | 源极 | 工作区 | $\lvert V_{TH}\rvert$ (V) | $I_X/\beta_p$ (V²) | $g_m/\beta_p$ (V) |
|---|---|---|---|---|---|
| 0 – 1.9 | 1.9 V 节点 | 截止 | 0.994 | 0 | 0 |
| 1.9 – 1.98 | $V_X$ 节点 | 截止 | 0.994 → 0.98 | 0 | 0 |
| 2.1 | $V_X$ 节点 | 饱和区 | 0.964 | 0.0093 | 0.136 |
| 2.3 | $V_X$ 节点 | 饱和区 | 0.932 | 0.068 | 0.368 |
| 2.49 | $V_X$ 节点 | 饱和区/线性区边界 | 0.900 | 0.174 | 0.59 |
| 2.7 | $V_X$ 节点 | 线性区 | 0.862 | 0.351 | 0.80 |
| 3.0 | $V_X$ 节点 | 线性区 | 0.800 | 0.715 | 1.10 |

- **$I_X$**：约 1.98 V 之前为零，之后是一段上升的抛物线（饱和区），直到约 2.49 V；然后是一段上升的、近似直线的线性区曲线，在 3 V 时达到 $0.715\beta_p$。
- **$g_m$**：1.98 V 之前为零，之后上升（由于 $|V_{TH}|$ 也在减小，上升得比线性略快），在 2.49 V 时达到 $0.59\beta_p$；然后是一条斜率为 $\beta_p$ 的直线，在 3 V 时达到 $1.1\beta_p$。

**若没有体效应**（始终有 $|V_{TH}| = 0.8$ V），$V_X < 1.8$ V 时器件将以 1.9 V 节点为源极导通并处于饱和区，产生一个很小的**反向**电流 $I_X = -\tfrac12\beta_p(0.1\ \mathrm{V})^2 = -0.005\beta_p$；电流在 1.9 V 处过零，之后器件以 $V_X$ 节点为源极工作在线性区，在 3 V 时同样达到 $0.715\beta_p$（因为此时本来就有 $V_{BS} = 0$）。

### 结果

- **$0 \le V_X \lesssim 1.98$ V：截止。** $V_X < 1.9$ V 时，源极是 1.9 V 节点，$V_{SG} = 0.9$ V，$V_{BS} = 1.1$ V，因此 $|V_{TH}| = 0.8 + 0.4(\sqrt{1.9} - \sqrt{0.8}) = 0.99$ V $> 0.9$ V。$V_X > 1.9$ V 时，源极是 $V_X$ 节点，$V_{SG} = V_X - 1$，$|V_{TH}| = 0.8 + 0.4(\sqrt{3.8 - V_X} - \sqrt{0.8})$；器件在 $V_X \approx 1.98$ V 处导通。$I_X = 0$，$g_m = 0$。
- **$1.98\ \mathrm{V} < V_X < 2.49$ V：饱和区**，$I_X = \tfrac12\beta_p(V_X - 1 - |V_{TH}|)^2 > 0$：2.1 V 时为 $0.009\beta_p$，2.3 V 时为 $0.068\beta_p$，2.49 V 时为 $0.174\beta_p$；$g_m = \beta_p(V_X - 1 - |V_{TH}|)$ 从 0 上升到 $0.59\beta_p$。
- **$V_X > 2.49$ V：线性区**，$I_X = \beta_p\left[(V_X - 1 - |V_{TH}|)(V_X - 1.9) - \tfrac12(V_X - 1.9)^2\right]$，在 3 V 时达到 $0.715\beta_p$；$g_m = \beta_pV_{SD} = \beta_p(V_X - 1.9)$，在 3 V 时达到 $1.1\beta_p$。

**常见错误。** 对所有 $V_X$ 都把 1.9 V 节点当作源极（或者把 $M_1$ 当作 NMOS 来分析）。PMOS 的源极是电位**较高**的端子，因此高于 1.9 V 后两端角色互换，$V_{SG} = V_X - 1$ 随 $V_X$ 增大。

**常见错误。** 忽略体效应。$V_X < 1.9$ V 时 n 阱比源极高 1.1 V，$|V_{TH}|$ 升高到 0.99 V，器件截止；若忽略体效应，就会预测在 1.8 V 以下有一个小的反向电流，并在 1.9 V 而不是 1.98 V 处导通。

**常见错误。** 认为导通后对所有 $V_X$ 都处于饱和区。栅极电位固定比漏极低 0.9 V，因此只有当 $|V_{TH}| > 0.9$ V，即 $V_X \approx 2.49$ V 以前，器件才处于饱和区。
