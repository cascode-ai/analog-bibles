$(W/L)_{1-4} \approx 16.6$（W ≈ 8.3 μm），对应 $V_{OD} \approx 0.67$ V；$(W/L)_{5-8} \approx 93$（W ≈ 46 μm），对应 $|V_{OD}| \approx 0.53$ V。

- X、Y 处的共模电平：$V_{DD} - |V_{GS9}| = 3 - (0.8 + 0.361) = 1.839$ V；200 mV 的峰峰值摆幅意味着 X 在 1.739 V 与 1.939 V 之间变化。
- 下端：X ≥ $V_{ISS} + V_{OD1} + V_{OD3}$ → $V_{OD1} + V_{OD3} \le 1.739 - 0.4 = 1.339$ V。
- 上端：X ≤ $V_{DD} - |V_{OD5}| - |V_{OD7}|$ → $|V_{OD5}| + |V_{OD7}| \le 3 - 1.939 = 1.061$ V。
- 最小宽度：把预算全部用完；对于电流相同的两个串联器件，总宽度 ∝ $1/V_{OD1}^2 + 1/V_{OD3}^2$，平均分配时最小：$V_{OD1} = V_{OD3} = 0.670$ V，$|V_{OD5}| = |V_{OD7}| = 0.530$ V。
- 0.5 mA 下的尺寸：$(W/L)_{1-4} = 2(0.5\ \mathrm{m})/(134\ \mu \times 0.670^2) = 16.6$；$(W/L)_{5-8} = 2(0.5\ \mathrm{m})/(38.4\ \mu \times 0.530^2) = 92.6$。
