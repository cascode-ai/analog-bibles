# 详细步骤 - R636

**思路。** 在输出端注入测试电流 $I_{in}$，分别在源极节点 X 和输出节点列 KCL 方程。X 处的方程表明 $C_2$ 与 $M_1$ 的电流相互抵消，因此二者都不从输出节点吸取净电流。于是传递函数就是谐振回路的阻抗，其极点位于左半平面，因此电路不可能振荡。

### 第 1 步 — 小信号模型（small-signal model）

与考毕兹振荡器（Colpitts oscillator）不同，该电路**没有从 X 接到地的电容**；只有 $C_2$ 连接到 X。对于小信号：

- 谐振回路是从输出节点到交流地的导纳，
$$Y_T(s) = \frac{1}{L_Ps} + \frac{1}{R_P} + C_Ps ;$$
- $M_1$ 的栅极为交流地，它是一个从漏极（输出）流向源极（X）的受控电流 $g_mV_{GS} = g_m(0 - V_X) = -g_mV_X$；
- 理想的 $I_b$ 相当于开路；
- $I_{in}$ 注入输出节点。

### 第 2 步 — 源极节点 X 的 KCL

经 $C_2$ 和经 $M_1$（从漏极到源极）流入 X 的电流之和必须为零：

$$(V_{out} - V_X)C_2s - g_mV_X = 0 .$$

因此

$$
\begin{aligned}
C_2s\,V_{out} &= V_X\,(g_m + C_2s),\\
V_X &= \frac{C_2s}{g_m + C_2s}\,V_{out}.
\end{aligned}
$$

### 第 3 步 — 输出节点的 KCL

$I_{in}$ 经谐振回路离开输出节点的部分为 $Y_T(s)\,V_{out}$，经 $C_2$ 的部分为 $(V_{out} - V_X)C_2s$，经 $M_1$ 的部分为 $-g_mV_X$：

$$I_{in} = Y_T\,V_{out} + \left[(V_{out} - V_X)C_2s - g_mV_X\right].$$

方括号内正是 X 处 KCL 方程的左边，它等于零，因此

$$I_{in} = Y_T\,V_{out} .$$

节点 X 没有到地的小信号通路，因此 $C_2$ 从输出带入 X 的任何电流都会经 $M_1$ 返回输出：二者不吸取净电流，$I_{in}$ 全部流入谐振回路。

### 第 4 步 — 闭环传递函数

$$\frac{V_{out}}{I_{in}} = \frac{1}{Y_T(s)} = L_Ps \parallel R_P \parallel \frac{1}{C_Ps}.$$

分子和分母同乘 $R_PL_Ps$：

$$
\frac{V_{out}}{I_{in}} = \frac{1}{\dfrac{1}{L_Ps} + \dfrac{1}{R_P} + C_Ps} = \frac{R_PL_Ps}{R_P + L_Ps + R_PL_PC_Ps^2} = \frac{R_PL_Ps}{R_PL_PC_Ps^2 + L_Ps + R_P}.
$$

晶体管和 $C_2$ 都已消去：闭环响应就是无源的谐振回路。

### 第 5 步 — 电路能否振荡？

振荡需要闭环极点位于 $j\omega$ 轴上或右半平面内。极点是以下方程的根：

$$R_PL_PC_Ps^2 + L_Ps + R_P = 0 \quad\Longleftrightarrow\quad s^2 + \frac{1}{R_PC_P}\,s + \frac{1}{L_PC_P} = 0 .$$

两根之和为 $-1/(R_PC_P)$，之积为 $1/(L_PC_P)$，因此两者的实部都是

$$\mathrm{Re}\{s\} = -\frac{1}{2R_PC_P} < 0 ,$$

对任何有限的 $R_P$，它们都位于**左半平面**。在 $j\omega$ 轴上响应保持有限，在 $\omega = 1/\sqrt{L_PC_P}$ 处最大，等于 $R_P$。$R_P$ 中的损耗从未得到补偿，因此无论 $g_m$ 取何值，**电路都不会振荡**：晶体管的电流被 $C_2$ 的电流抵消，从不向谐振回路提供能量。

**用电压激励进行一致性检查。** 在栅极加一个小信号 $V_{in}$，X 处的 KCL 给出 $g_m(V_{in} - V_X) + (V_{out} - V_X)C_2s = 0$，输出节点则给出 $Y_TV_{out} = 0$，即 $V_{out} = 0$：栅极信号根本到达不了谐振回路。考毕兹振荡器需要第二个电容 $C_1$ 从 X 接到地，使电容分压器能把一部分输出反馈到源极。

### 结果

$$\frac{V_{out}}{I_{in}} = L_Ps \parallel R_P \parallel \frac{1}{C_Ps} = \frac{R_PL_Ps}{R_PL_PC_Ps^2 + L_Ps + R_P},$$

这就是谐振回路的阻抗。节点 X 没有到地的交流通路，因此 $C_2$ 的电流恰好由 $M_1$ 送回，二者不从输出端吸取净电流。极点的实部为 $-1/(2R_PC_P) < 0$，且响应在 $j\omega$ 轴上有限（在 $\omega = 1/\sqrt{L_PC_P}$ 处达到最大值 $R_P$），因此**电路不可能振荡**。

**常见错误。** 像考毕兹振荡器那样添加一个从 X 接到地的电容 $C_1$，然后求出振荡条件。$I_b$ 为理想电流源时，节点 X 只与 $C_2$ 和 $M_1$ 相连。

**常见错误。** 把 $M_1$ 的电流当作对输出节点的独立贡献，而忘了 X 处的 KCL 把它与 $C_2$ 的电流联系在一起。二者相互抵消，这就是晶体管从 $V_{out}/I_{in}$ 中消失的原因。

**常见错误。** 因为谐振回路有谐振，就认为电路会振荡。单独的谐振回路的极点位于 $\mathrm{Re}\{s\} = -1/(2R_PC_P)$；振荡需要一个能抵消 $R_P$ 损耗的有源元件，而这里的晶体管起不到这种作用。
