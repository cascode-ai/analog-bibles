# 详细步骤 - R518

**思路。** 保持过驱动电压 $V_{ov} = V_{GS} - V_{TH}$ 固定，通过 $\beta \propto W/L$ 把 $g_m$ 和 $I_D$ 写成 $W/L$ 的函数。结果二者都与 $W/L$ 成正比，因此草图是两条过原点的直线，与平方律的图（其中 $I_D = \tfrac12\mu_nC_{ox}\tfrac WL V_{ov}^2$，$g_m = \mu_nC_{ox}\tfrac WL V_{ov}$）相同，只是两条直线之间的比例不同。

### 第 1 步 — 用 $W/L$ 表示假想器件的规律

令 $\beta = k\,W/L$，其中 $k$（单位 A/V³）是与几何尺寸无关的工艺常数。于是

$$g_m = k\,V_{ov}^2\cdot\frac WL,\qquad I_D = \frac{k}{3}\,V_{ov}^3\cdot\frac WL .$$

在 $V_{ov}$ 恒定时：
- $g_m$ 与 $W/L$ **成正比**：一条过原点、斜率为 $kV_{ov}^2$ 的直线；
- $I_D$ 与 $W/L$ **成正比**：一条过原点、斜率为 $kV_{ov}^3/3$ 的直线。

### 第 2 步 — 两条直线之间的比例

$$\frac{g_m}{I_D} = \frac{kV_{ov}^2}{kV_{ov}^3/3} = \frac{3}{V_{ov}} ,$$

它与 $W/L$ 无关，而平方律为 $2/V_{ov}$。与图中唯一的区别是两条直线的相对陡度：在相同的过驱动电压下，假想器件每单位电流提供的 $g_m$ 是平方律器件的 1.5 倍。

### 第 3 步 — 草图的示例数值

取 $V_{ov} = 0.2$ V，$k = 0.24\ \mathrm{mA/V^3}$。两条直线的斜率为

$$
\begin{aligned}
kV_{ov}^2 &= 0.24\ \mathrm{mA/V^3}\times0.04\ \mathrm{V^2} = 9.6\ \mu\mathrm{S}\ \text{per unit } W/L,\\
\frac{k}{3}V_{ov}^3 &= 0.08\ \mathrm{mA/V^3}\times0.008\ \mathrm{V^3} = 0.64\ \mu\mathrm{A}\ \text{per unit } W/L .
\end{aligned}
$$

| $W/L$ | 0 | 25 | 50 | 100 |
|---|---|---|---|---|
| $g_m$（向上画） | 0 | 0.24 mS | 0.48 mS | 0.96 mS |
| $I_D$（向下画） | 0 | 16 µA | 32 µA | 64 µA |
| $g_m/I_D$ | — | 15 V⁻¹ | 15 V⁻¹ | 15 V⁻¹ |

每一点都有 $g_m/I_D = 15\ \mathrm{V^{-1}} = 3/(0.2\ \mathrm{V})$。

**草图。** 在图中的坐标轴上，$W/L$ 轴上方是一条从原点出发、以斜率 $kV_{ov}^2$ 上升的直线（$g_m$），下方是一条以斜率 $kV_{ov}^3/3$ 下降的直线（$I_D$）。两者都没有弯曲、偏移或饱和；$W/L$ 加倍，两者都加倍。

### 第 4 步 — 为什么形状与器件规律无关

在固定的过驱动电压（且 $L$ 不变）下，宽度为 $2W$ 的晶体管就是两个宽度为 $W$ 的晶体管并联。因此任何规律 $I_D = (W/L)\,f(V_{ov})$ 都给出 $I_D \propto W/L$ 和 $g_m = (W/L)\,f'(V_{ov}) \propto W/L$；器件规律只决定斜率。在 **$I_D$ 恒定**或 **$W/L$ 恒定**的条件下画出的曲线会有所不同，但该图保持的是 $V_{ov}$ 恒定。

### 结果

当 $\beta = kW/L$ 且 $V_{GS} - V_{TH}$ 恒定时，

$$g_m = k\,(V_{GS} - V_{TH})^2\,\frac WL \propto \frac WL,\qquad I_D = \frac k3\,(V_{GS} - V_{TH})^3\,\frac WL \propto \frac WL .$$

两条曲线都是**过原点的直线**，形状与平方律器件相同：$g_m$ 向上增大，$I_D$ 向下增大，二者都随 $W/L$ 线性变化。它们的比值固定为 $g_m/I_D = 3/(V_{GS} - V_{TH})$，而平方律为 $2/(V_{GS} - V_{TH})$。

**常见错误。** 把 $g_m$ 画成 $W/L$ 的非线性函数，例如 $g_m \propto (W/L)^{1/3}$，这是错误套用 $g_m = \sqrt[3]{9\beta I_D^2}$ 的结果。那个形式适用于电流恒定的情形；这里恒定的是过驱动电压，因此 $g_m = \beta V_{ov}^2 \propto W/L$。

**常见错误。** 把 $I_D$ 画成与 $W/L$ 无关。在固定的过驱动电压下，更宽的器件相当于更多器件并联，因此其电流与 $W/L$ 成正比。
