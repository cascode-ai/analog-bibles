# Golden Solution - R257

## Reference answer

The two mirrors form a positive-feedback loop ($M_2 \to M_1 \to M_3 \to M_4 \to X$) whose current gain is one when all devices are saturated. With $I_{REF} > 0$ added at X, no all-saturated solution exists (KCL at X would require $I_{REF} = 0$), so the loop latches into a high-current state with $M_1$ in triode ($M_1$ saturated with $M_4$ in triode is impossible: it would need $V_X - V_Y \le 0.7$ V and $> 0.8$ V at once). While $M_4$ is still saturated this gives exactly $V_X - V_Y = 0.7\ \mathrm{V} + \sqrt{2I_{REF}/\beta_n}$, so $M_4$ also enters triode once $I_{REF} > \beta_n(0.1\ \mathrm{V})^2/2$ (about 13 μA for W/L = 10/0.5). $V_X$ rises and $V_Y$ falls monotonically with $I_{REF}$, always with $V_X - V_Y > 0.7$ V: a square-root-like start just above $I_{REF} = 0$, then a slow change while $I_{REF}$ stays below the loop's own current. The levels depend on $r = \sqrt{\beta_n/\beta_p}$: as $I_{REF} \to 0^+$, $V_Y \to 2.2\ \mathrm{V}/(1+r)$ and $V_X \to 0.7\ \mathrm{V} + 2.2\ \mathrm{V}/(1+r)$ (about mid-supply for comparable NMOS and PMOS strengths, near 0.7 V for a much stronger NMOS).

- $I_{REF} = 0$: the solution is not unique. With all devices saturated the unity-gain loop admits any loop current from zero (everything off, $V_X \le 0.7$ V) up to the value where $M_1$ reaches the triode edge ($V_X - V_Y = 0.7$ V; about 0.79 mA, $V_X \approx 1.47$ V, $V_Y \approx 0.77$ V for the example sizes). The limit $I_{REF} \to 0^+$ is that edge state.
- Equations: $I_{D2} = I_{REF} + |I_{D4}|$, $I_{D1} = |I_{D3}|$, $M_3$ diode-connected; with $d = V_X - V_Y$, $I_{REF} = \tfrac{\beta_n}{2}(d - 0.7)^2 + \tfrac{\beta_p}{2}[\max(d - 0.8, 0)]^2$ and $\beta_n[(V_X - 0.7)V_Y - V_Y^2/2] = \tfrac{\beta_p}{2}(2.2 - V_Y)^2$.
- The loop current is set by the transistors (about 0.8 mA for the example sizes); $I_{REF}$ shifts the operating point noticeably only when it becomes comparable to that.
- Example (all W/L = 10/0.5, $\mu_nC_{ox}$ = 134 μA/V², $\mu_pC_{ox}$ = 38.4 μA/V²; square-law simulation): $I_{REF}$ = 1 μA → $V_X$ ≈ 1.48 V, $V_Y$ ≈ 0.75 V; 25 μA → 1.52, 0.69 V; 100 μA → 1.58, 0.62 V; 1 mA → 1.92, 0.44 V.
