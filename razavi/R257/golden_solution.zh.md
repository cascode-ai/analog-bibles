两个电流镜（current mirror）构成一个正反馈环路（$M_2 \to M_1 \to M_3 \to M_4 \to X$），当所有器件都工作在饱和区（saturation region）时，其电流增益为一。在 X 点加入 $I_{REF} > 0$ 后，不存在所有器件都饱和的解，因为在 X 点应用基尔霍夫电流定律（KCL）将要求 $I_{REF} = 0$；因此环路锁定（latch）在大电流状态，此时 $M_1$ 处于线性区（triode region）（$M_1$ 饱和而 $M_4$ 处于线性区是不可能的：这需要同时满足 $V_X - V_Y \le 0.7$ V 和 $> 0.8$ V）。在 $M_4$ 仍饱和时，可以精确地得到 $V_X - V_Y = 0.7\ \mathrm{V} + \sqrt{2I_{REF}/\beta_n}$，因此一旦 $I_{REF} > \beta_n(0.1\ \mathrm{V})^2/2$（W/L = 10/0.5 时约为 13 μA），$M_4$ 也进入线性区。$V_X$ 随 $I_{REF}$ 单调上升，$V_Y$ 单调下降，且始终有 $V_X - V_Y > 0.7$ V：刚超过 $I_{REF} = 0$ 时以类似平方根的方式起始，之后只要 $I_{REF}$ 仍小于环路自身的电流，变化就很缓慢。电平高低取决于 $r = \sqrt{\beta_n/\beta_p}$：当 $I_{REF} \to 0^+$ 时，$V_Y \to 2.2\ \mathrm{V}/(1+r)$，$V_X \to 0.7\ \mathrm{V} + 2.2\ \mathrm{V}/(1+r)$（NMOS 与 PMOS 强度相当时约在电源电压中点附近，NMOS 强得多时则接近 0.7 V）。

- $I_{REF} = 0$：解不唯一。在所有器件都饱和时，这个单位增益环路允许任意大小的环路电流，从零（全部截止，$V_X \le 0.7$ V）一直到 $M_1$ 到达线性区边缘时的值（$V_X - V_Y = 0.7$ V；对于示例尺寸，约为 0.79 mA，$V_X \approx 1.47$ V，$V_Y \approx 0.77$ V）。$I_{REF} \to 0^+$ 的极限就是这个边缘状态。
- 方程：$I_{D2} = I_{REF} + |I_{D4}|$，$I_{D1} = |I_{D3}|$，$M_3$ 为二极管连接（diode-connected）；令 $d = V_X - V_Y$，则 $I_{REF} = \tfrac{\beta_n}{2}(d - 0.7)^2 + \tfrac{\beta_p}{2}[\max(d - 0.8, 0)]^2$，且 $\beta_n[(V_X - 0.7)V_Y - V_Y^2/2] = \tfrac{\beta_p}{2}(2.2 - V_Y)^2$。
- 环路电流由晶体管本身决定（对于示例尺寸约为 0.8 mA）；只有当 $I_{REF}$ 与之相当时，它才会明显改变工作点。
- 示例（所有 W/L = 10/0.5，$\mu_nC_{ox}$ = 134 μA/V²，$\mu_pC_{ox}$ = 38.4 μA/V²；按平方律模型仿真）：$I_{REF}$ = 1 μA → $V_X$ ≈ 1.48 V，$V_Y$ ≈ 0.75 V；25 μA → 1.52、0.69 V；100 μA → 1.58、0.62 V；1 mA → 1.92、0.44 V。
