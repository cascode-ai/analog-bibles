# 详细步骤 - R257

**思路。** NMOS 电流镜（$M_2 \to M_1$）和 PMOS 电流镜（$M_3 \to M_4$）首尾相连构成一个环，当四个晶体管都饱和时，它是一个**电流增益恰好为一的正反馈环路**。由 KCL 可知，一旦 $I_{REF} > 0$，就不存在所有器件都饱和的解；接下来确定哪些晶体管必须退出饱和区，再以闭式形式解出其余方程中的 $V_X$ 和 $V_Y$。

### 第 1 步 — 环路、器件方程与 KCL

$M_1$ 复制二极管连接器件 $M_2$ 的电流，并从二极管连接器件 $M_3$ 中抽取这一电流；$M_4$ 复制 $M_3$ 的电流，并把它送回 X，即注入 $M_2$。每个电流镜的比例都是一，因此环路电流增益为 $1\times1 = 1$，并且反馈是正的：$M_2$ 中的电流增大，回送到 X 的电流也随之增大。

令 $\beta_n = \mu_nC_{ox}(W/L)_n$，$\beta_p = \mu_pC_{ox}(W/L)_p$，并定义

$$d \equiv V_X - V_Y .$$

- **二极管连接的 $M_2$、$M_3$** 始终饱和：
$$I_{D2} = \frac{\beta_n}{2}(V_X - 0.7)^2, \qquad |I_{D3}| = \frac{\beta_p}{2}(V_{DD} - V_Y - 0.8)^2 = \frac{\beta_p}{2}(2.2 - V_Y)^2 .$$
- **$M_1$**（$V_{GS1} = V_X$，$V_{DS1} = V_Y$）在 $V_Y \ge V_X - 0.7$，即 $d \le 0.7$ V 时饱和。
- **$M_4$**（$V_{SG4} = V_{DD} - V_Y$，$V_{SD4} = V_{DD} - V_X$）在 $V_{DD} - V_X \ge V_{DD} - V_Y - 0.8$，即 $d \le 0.8$ V 时饱和。

节点 X 和节点 Y 的 KCL 方程：

$$I_{D2} = I_{REF} + |I_{D4}|, \tag{1}$$

$$I_{D1} = |I_{D3}|. \tag{2}$$

### 第 2 步 — $I_{REF} > 0$ 时不存在全饱和解

如果 $M_1$ 和 $M_4$ 都饱和，两个电流镜将精确地复制电流（$\lambda = 0$）：$I_{D1} = I_{D2}$，$|I_{D4}| = |I_{D3}|$。于是由 (1) 和 (2) 得

$$I_{D2} = I_{REF} + |I_{D3}| = I_{REF} + I_{D1} = I_{REF} + I_{D2} \quad\Longrightarrow\quad I_{REF} = 0 .$$

因此，**对于任意 $I_{REF} > 0$，电路都不可能所有器件同时饱和。** 单位增益环路会把 $M_2$ 电流的每一点增加都送回 X，因此电流不断增大，直到某个晶体管退出饱和区、环路增益（loop gain）降到一以下为止：电路**锁定在大电流状态。**

### 第 3 步 — 哪个晶体管退出饱和区？

二极管连接的器件不可能退出饱和区，因此必须由 $M_1$ 或 $M_4$（或两者）退出饱和区：

- **$M_1$ 饱和，$M_4$ 处于线性区：** 需要同时满足 $d \le 0.7$ V **和** $d > 0.8$ V。不可能。
- **$M_1$ 处于线性区，$M_4$ 饱和：** 需要 $0.7 < d \le 0.8$ V。可能。
- **两者都处于线性区：** $d > 0.8$ V。可能。

因此，对于 $I_{REF} > 0$，**$M_1$ 始终处于线性区**，而 $M_4$ 在 $I_{REF}$ 稍大时也随之进入线性区。在所有情况下都有 $V_X - V_Y > 0.7$ V。

### 第 4 步 — 区域 A：$M_1$ 处于线性区，$M_4$ 饱和

此时 $|I_{D4}| = |I_{D3}| = I_{D1}$（先由 PMOS 电流镜的精确复制，再由 (2)），因此 (1) 变为 $I_{REF} = I_{D2} - I_{D1}$。$M_1$ 处于线性区（$V_{GS1} = V_X$，$V_{DS1} = V_Y$）：

$$
\begin{aligned}
I_{REF} &= \frac{\beta_n}{2}(V_X - 0.7)^2 - \beta_n\left[(V_X - 0.7)V_Y - \frac{V_Y^2}{2}\right]\\
&= \frac{\beta_n}{2}\left[(V_X - 0.7)^2 - 2(V_X - 0.7)V_Y + V_Y^2\right]\\
&= \frac{\beta_n}{2}(V_X - 0.7 - V_Y)^2 = \frac{\beta_n}{2}(d - 0.7)^2 .
\end{aligned}
$$

因此，精确地有

$$V_X - V_Y = 0.7\ \mathrm{V} + \sqrt{\frac{2I_{REF}}{\beta_n}} .$$

当 $d = 0.8$ V 时这一区域结束，对应的电流为

$$I_{REF} = \frac{\beta_n}{2}(0.1\ \mathrm{V})^2 .$$

对于 $W/L = 10/0.5$ 和 $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，有 $\beta_n = 2.68\ \mathrm{mA/V^2}$，该电流为 $\tfrac12(2.68\ \mathrm{mA/V^2})(0.01\ \mathrm{V^2}) = 13.4\ \mu\mathrm{A}$：非常小，因此在大部分范围内 $M_1$ 和 $M_4$ 都处于线性区。

### 第 5 步 — 区域 B：$M_1$ 和 $M_4$ 都处于线性区

$M_4$ 处于线性区，其中 $V_{SG4} - 0.8 = 2.2 - V_Y$，$V_{SD4} = 3 - V_X$。按照与第 4 步相同的代数运算，

$$|I_{D3}| - |I_{D4}| = \frac{\beta_p}{2}\left[(2.2 - V_Y) - (3 - V_X)\right]^2 = \frac{\beta_p}{2}(d - 0.8)^2 .$$

把由 (1) 得到的 $I_{REF}$ 拆成三个差值之和，并利用 (2)：

$$I_{REF} = I_{D2} - |I_{D4}| = (I_{D2} - I_{D1}) + (I_{D1} - |I_{D3}|) + (|I_{D3}| - |I_{D4}|) = \frac{\beta_n}{2}(d - 0.7)^2 + 0 + \frac{\beta_p}{2}(d - 0.8)^2 .$$

两个区域可以用同一个公式表示：

$$I_{REF} = \frac{\beta_n}{2}(d - 0.7)^2 + \frac{\beta_p}{2}\left[\max(d - 0.8,\,0)\right]^2 . \tag{3}$$

右边随 $d$ 增大而增大，因此 **$d = V_X - V_Y$ 随 $I_{REF}$ 单调增大**，并且在 $I_{REF} = 0^+$ 处斜率为无穷大（平方根式的起始）。

### 第 6 步 — 第二个方程：$V_Y$ 的位置

节点 Y 的 KCL 方程 (2)，其中 $M_1$ 处于线性区，且 $V_X = V_Y + d$：

$$\beta_n\left[(d - 0.7)V_Y + \frac{V_Y^2}{2}\right] = \frac{\beta_p}{2}(2.2 - V_Y)^2 . \tag{4}$$

左边随 $V_Y$ 增大而增大，右边则减小，因此对每个 $d$，$V_Y$ 都是唯一的。

**极限 $I_{REF} \to 0^+$**（$d \to 0.7$ V）：

$$\frac{\beta_n}{2}V_Y^2 = \frac{\beta_p}{2}(2.2 - V_Y)^2 \ \Longrightarrow\ \sqrt{\beta_n}\,V_Y = \sqrt{\beta_p}\,(2.2 - V_Y) \ \Longrightarrow\ V_Y = \frac{2.2\ \mathrm{V}}{1 + r}, \quad V_X = 0.7\ \mathrm{V} + \frac{2.2\ \mathrm{V}}{1 + r},$$

其中 $r = \sqrt{\beta_n/\beta_p}$。当 NMOS 与 PMOS 强度相当（$r \approx 1$）时，该电平接近电源电压的中点；当 NMOS 强得多时，$V_Y \to 0$，$V_X \to 0.7$ V。

**变化趋势。** 将 (4) 对 $d$ 求导：

$$\frac{dV_Y}{dd} = -\frac{\beta_nV_Y}{\beta_n(V_X - 0.7) + \beta_p(2.2 - V_Y)} .$$

该式为负，因此随着 $I_{REF}$ 增大，**$V_Y$ 下降**。由于在线性区中 $V_Y < V_X - 0.7$，该导数的绝对值小于一，因此 $dV_X/dd = 1 + dV_Y/dd > 0$：**$V_X$ 上升**。

### 第 7 步 — 特殊情况 $I_{REF} = 0$

当 $I_{REF} = 0$ 时，对于能使 $M_1$ 保持饱和的**任意**环路电流 $I$，全饱和方程都成立：$V_X = 0.7 + \sqrt{2I/\beta_n}$，$V_Y = 2.2 - \sqrt{2I/\beta_p}$。解**不唯一**：从零电流（全部截止，$V_X \le 0.7$ V）到 $M_1$ 到达线性区边缘（$d = 0.7$ V）时的电流，都是可能的解。$I_{REF} \to 0^+$ 时到达的状态恰好就是这个边缘状态，即该范围的上端。

### 第 8 步 — 数值示例与数值表

取所有器件 $W/L = 10/0.5$，$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$：

$$\beta_n = 2.68\ \mathrm{mA/V^2}, \qquad \beta_p = 0.768\ \mathrm{mA/V^2}, \qquad r = \sqrt{2.68/0.768} = 1.868 .$$

边缘状态（$I_{REF} \to 0^+$）：

$$V_Y = \frac{2.2}{2.868} = 0.767\ \mathrm{V}, \quad V_X = 1.467\ \mathrm{V}, \quad I_{loop} = \frac{\beta_n}{2}V_Y^2 = (1.34\ \mathrm{mA/V^2})(0.588\ \mathrm{V^2}) = 0.79\ \mathrm{mA}.$$

在 $I_{REF} = 1\ \mu\mathrm{A}$ 处验算：由 (3)，$d = 0.7 + \sqrt{2(1\ \mu\mathrm{A})/(2.68\ \mathrm{mA/V^2})} = 0.7 + 0.027 = 0.727$ V。于是 (4) 变为二次方程

$$\tfrac12(\beta_n - \beta_p)V_Y^2 + \left[\beta_n(d - 0.7) + 2.2\beta_p\right]V_Y - 2.42\beta_p = 0,$$

即 $0.956V_Y^2 + 1.763V_Y - 1.859 = 0$（各项以 mA 为单位，$V_Y$ 以伏特为单位）。正根为 $V_Y = (-1.763 + \sqrt{1.763^2 + 4(0.956)(1.859)})/(2\times0.956) = 0.750$ V，因此 $V_X = V_Y + d = 1.477$ V。

| $I_{REF}$ | $d = V_X - V_Y$ (V) | $V_X$ (V) | $V_Y$ (V) | 状态 |

| $0^+$ | 0.700 | 1.467 | 0.767 | $M_1$ 处于线性区边缘 |
| 1 μA | 0.727 | 1.477 | 0.750 | $M_1$ 处于线性区，$M_4$ 饱和 |
| 13.4 μA | 0.800 | 1.506 | 0.706 | $M_4$ 处于线性区边缘 |
| 25 μA | 0.835 | 1.522 | 0.686 | 两者都处于线性区 |
| 100 μA | 0.960 | 1.583 | 0.624 | 两者都处于线性区 |
| 500 μA | 1.259 | 1.765 | 0.506 | 两者都处于线性区 |
| 1 mA | 1.483 | 1.924 | 0.442 | 两者都处于线性区 |

环路自身的电流（此处约为 0.8–1.2 mA）由晶体管决定；只有当 $I_{REF}$ 与之相当时，才会明显改变工作点。

### 结果

- 两个电流镜构成一个**单位增益正反馈环路**。任何 $I_{REF} > 0$ 都使全饱和状态不可能出现，因此电路**锁定**在大电流状态，此时 **$M_1$ 处于线性区**（一旦 $I_{REF} > \beta_n(0.1\ \mathrm{V})^2/2$，$M_4$ 也处于线性区；对于 $W/L = 10/0.5$，该值约为 13 μA）。
- 始终有 $V_X - V_Y > 0.7$ V，且 $I_{REF} = \tfrac{\beta_n}{2}(d - 0.7)^2 + \tfrac{\beta_p}{2}[\max(d - 0.8, 0)]^2$，$\beta_n[(V_X - 0.7)V_Y - V_Y^2/2] = \tfrac{\beta_p}{2}(2.2 - V_Y)^2$。
- 随着 $I_{REF}$ 增大，**$V_X$ 单调上升，$V_Y$ 单调下降**：刚超过零时以类似平方根的方式起始，之后变化缓慢。
- 当 $I_{REF} \to 0^+$ 时：$V_Y \to 2.2\ \mathrm{V}/(1 + r)$，$V_X \to 0.7\ \mathrm{V} + 2.2\ \mathrm{V}/(1 + r)$，其中 $r = \sqrt{\beta_n/\beta_p}$。恰好 $I_{REF} = 0$ 时状态不唯一（环路电流可以是从零到该边缘值之间的任意值）。
- 示例（所有器件 $W/L = 10/0.5$）：在 $I_{REF} = 1$ μA、25 μA、100 μA、1 mA 时，$V_X \approx 1.48$、1.52、1.58、1.92 V，$V_Y \approx 0.75$、0.69、0.62、0.44 V。

**常见错误。** 把该电路当作普通电流镜，认为 $V_X = V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta_n}$，而 $M_4$ 只是再加上一份 $I_{REF}$ 的复制电流。这样节点 X 的 KCL 方程给出 $I_{D2} = I_{REF} + I_{D2}$，无解。

**常见错误。** 假设 $V_X = V_Y$，或者认为 $M_1$ 仍然饱和。第 3 步表明，$M_1$ 必须处于线性区，且 $V_X - V_Y$ 始终大于 0.7 V。

**常见错误。** 以为晶体管电流由 $I_{REF}$ 决定。对于这些尺寸，即使 $I_{REF}$ 只有几微安，正反馈也会建立毫安量级的环路电流。
