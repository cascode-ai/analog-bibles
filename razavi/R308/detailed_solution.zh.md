# 详细步骤 - R308

**思路。** 当 $\lambda = \gamma = 0$ 时，没有 $r_O$，也没有体效应（body effect）。理想的尾电流源固定了差分对（differential pair）两管的漏极电流。把电流镜节点 A 和输出端的 KCL 方程相加，可知 A 始终处于交流地，此后只有 $C_1$ 把信号电流转换为输出电压。该电路是一个积分器，$V_{out}/V_{in} = g_{m1}/(2C_1s)$，两个频率极限都可由此得出。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$、$M_2$ 的公共源极节点记为 P，把 $M_1$ 的漏极（$M_3$、$M_4$ 的栅极）记为 A；$V_{in} = V_{G1} - V_{G2}$。$V_{DD}$ 为交流地，理想尾电流源相当于开路，因此没有任何元件把 P 接到地。

- **$M_1$、$M_2$：** 从漏极流向源极的电流分别为 $i_1 = g_{m1}(V_{G1} - V_P)$ 和 $i_2 = g_{m2}(V_{G2} - V_P)$，且 $g_{m1} = g_{m2}$。
- **$M_3$、$M_4$：** 源极处于交流地，栅极接 A，因此二者都有 $v_{gs} = V_A$。每个管子都从其漏极节点（A 或输出端）向交流地（$V_{DD}$）吸取电流 $g_{m3}V_A$，即向该节点注入 $-g_{m3}V_A$（$g_{m4} = g_{m3}$）。
- **$C_1$** 接在 A 与输出端之间。

### 第 2 步 — 差分对的漏极电流

尾电流源是理想的，因此流过 P 的总信号电流为零。由于 $g_{m1} = g_{m2}$：

$$
\begin{aligned}
i_1 + i_2 = g_{m1}(V_{G1} - V_P) + g_{m1}(V_{G2} - V_P) &= 0\\
V_P &= \frac{V_{G1} + V_{G2}}{2},
\end{aligned}
$$

$$i_1 = g_{m1}\left(V_{G1} - \frac{V_{G1} + V_{G2}}{2}\right) = \frac{g_{m1}V_{in}}{2}, \qquad i_2 = -\frac{g_{m1}V_{in}}{2}.$$

由于 $\lambda = 0$，这些电流与漏极电压无关，因此在任何频率下都成立。

### 第 3 步 — A 点与输出端的 KCL

在 A 点，$-g_{m3}V_A$ 从 $M_3$ 流入，$(V_{out} - V_A)C_1s$ 经 $C_1$ 流入，$i_1$ 经 $M_1$ 流出：

$$-g_{m3}V_A + (V_{out} - V_A)C_1s = i_1 . \qquad (1)$$

在输出端，$-g_{m3}V_A$ 从 $M_4$ 流入，$(V_A - V_{out})C_1s$ 经 $C_1$ 流入，$i_2$ 经 $M_2$ 流出：

$$-g_{m3}V_A + (V_A - V_{out})C_1s = i_2 . \qquad (2)$$

### 第 4 步 — 电流镜节点是交流地

将式 (1) 与式 (2) 相加，$C_1$ 项相互抵消：

$$-2g_{m3}V_A = i_1 + i_2 = 0 \quad\Longrightarrow\quad V_A = 0$$

这在所有频率下都成立。电流镜的两个器件同时改变电流，各自改变 $-g_{m3}V_A$，而差分对只是**分配**电流（其总电流由理想尾电流源固定）；因此把 A 和输出端合在一起列 KCL，就要求 $V_A = 0$，电流镜中没有信号电流。

### 第 5 步 — $C_1$ 对信号电流积分

代入 $V_A = 0$，式 (1) 变为

$$V_{out}C_1s = i_1 = \frac{g_{m1}V_{in}}{2},$$

$$\frac{V_{out}}{V_{in}}(s) = \frac{g_{m1}}{2C_1s}.$$

信号电流 $i_1$ 从输出端经 $C_1$ 流到 A，向下经 $M_1$ 流到 P，再向上经 $M_2$（$i_2 = -i_1$）回到输出端，形成环流；$C_1$ 是该环路中唯一把电流转换为电压的元件。（式 (2) 给出相同的结果：$-V_{out}C_1s = i_2 = -i_1$。）

### 第 6 步 — 极低频与极高频

**极低频**（$s\to0$）：

$$\left|\frac{V_{out}}{V_{in}}\right| = \frac{g_{m1}}{2C_1\omega}\to\infty .$$

验证：$C_1$ 开路时，电路就是带有源电流镜负载的差分对，其增益为 $g_{m1}(r_{O2}\parallel r_{O4})$，在 $\lambda = 0$ 时为无穷大。

**极高频**（$s\to\infty$）：

$$\frac{V_{out}}{V_{in}}\to0 .$$

验证：$C_1$ 短路时，A 与输出端成为同一个节点，两个 PMOS 器件都是二极管连接，而差分对从该节点吸取的总电流为 $i_1 + i_2 = 0$，因此 $V_{out} = V_A = 0$。

**过渡。** 幅值在所有频率下都按 $1/\omega$ 下降（−20 dB/十倍频程），相位恒为 $-90^\circ$，并在下式处穿过单位增益：

$$\omega_u = \frac{g_{m1}}{2C_1}.$$

### 结果

$$\frac{V_{out}}{V_{in}}(s) = \frac{g_{m1}}{2C_1s}$$

该电路是一个理想积分器。增益**在极低频时为无穷大**（$\lambda = 0$ 且电流镜负载理想时，输出端没有电阻性通路），**在极高频时为零**（$C_1$ 把输出端与电流镜节点短接，两个 PMOS 器件都变为二极管连接，两条支路的电流相互抵消）。单位增益频率（unity-gain frequency）为 $\omega_u = g_{m1}/(2C_1)$。电流镜节点 A 在所有频率下都处于交流地。

**常见错误。** 给出有限的低频增益，例如 $g_{m1}/g_{m3}$，好像输出端接的是二极管负载。在低频时 $C_1$ 开路，输出端只看到 $M_4$（由电流镜驱动的电流源）和 $M_2$，在 $\lambda = 0$ 时二者的 $r_O$ 都是无穷大。

**常见错误。** 给出有限的高频增益，例如 $g_{m1}/(2g_{m3})$ 或 $1/2$。当 A 与输出端短接时，差分对向合并后的节点注入 $i_1$，同时从中抽取 $-i_1$，因此净效果为零，$V_{out}\to0$。

**常见错误。** 把 $M_3$ 当作电流源。它在 A 点接成二极管连接，$M_4$ 与它共用栅极；这一对匹配的器件迫使 $V_A = 0$。
