$$\frac{V_{out}}{V_{in}}(s) = \frac{g_{m1}}{2C_1s}$$
因此增益在极低频时为无穷大，在极高频时为零（这是一个积分器，在 $\omega = g_{m1}/(2C_1)$ 处达到单位增益）。
- 尾电流源（tail current source）理想且 λ = 0 时，信号电流为 $i_1 = -i_2 = g_{m1}V_{in}/2$（$M_1$ 和 $M_2$ 从漏极流向源极的电流）。
- $M_3$ 和 $M_4$ 的栅源电压相同，因此流过相同的电流 $-g_{m3}V_A$，其中 $V_A$ 为电流镜（current mirror）节点的电压。A 点的基尔霍夫电流定律（KCL）：$-g_{m3}V_A + (V_{out} - V_A)C_1s = i_1$；输出端：$-g_{m3}V_A + (V_A - V_{out})C_1s = i_2$。两式相加：$-2g_{m3}V_A = i_1 + i_2 = 0$，因此在所有频率下 $V_A = 0$。
- 于是 $V_{out}C_1s = i_1$：$V_{out} = g_{m1}V_{in}/(2C_1s)$。
- 低频：$C_1$ 开路，电路就是常规的有源电流镜负载级，λ = 0 时其增益 $g_{m1}(r_{O2}\|r_{O4}) = \infty$。高频：$C_1$ 把输出端与电流镜节点短接，两个 PMOS 管都变为二极管连接（diode-connected），两条支路的电流相互抵消，因此 $V_{out} \to 0$。
