# 详细步骤 - R691

**思路。** 该电路是一个 CMOS 反相器。对一般的阈值电压，由 $I_{D1} = I_{D2}$ 推导传输曲线，然后分别代入目标阈值（$V_{THN} = 0.7$ V，$|V_{THP}| = 0.8$ V）和缺少注入时保留的原生阈值（$V_{THN} \approx 0$，$|V_{THP}| \approx 1$ V）进行计算。

### 第 1 步 — 一般阈值下的过驱动电压与工作区

记 $V_{TN} = V_{THN}$，$V_{TP} = |V_{THP}|$。每个管子的衬底都接到各自的源极，因此没有体效应（body effect）；取 $\lambda = 0$。由于 $V_{GS1} = V_{in}$，$V_{DS1} = V_{out}$，$V_{SG2} = 3 - V_{in}$，$V_{SD2} = 3 - V_{out}$，$M_1$ 的过驱动电压为 $V_{in} - V_{TN}$，$M_2$ 的过驱动电压为 $3 - V_{TP} - V_{in}$。若 $V_{out} \ge V_{in} - V_{TN}$，则 $M_1$ 饱和；若 $V_{out} \le V_{in} + V_{TP}$，则 $M_2$ 饱和。定义强度比

$$r = \sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_2}} .$$

### 第 2 步 — 端点：各器件在何处截止

- **$M_1$ 截止**的条件是 $V_{in} \le V_{TN}$。此时 $M_2$ 导通但电流为零，即处于 $V_{SD2} = 0$ 的深线性区（deep triode），因此 $V_{out} = 3$ V。
- **$M_2$ 截止**的条件是 $V_{SG2} \le V_{TP}$，即 $V_{in} \ge 3 - V_{TP}$。此时 $M_1$ 导通但电流为零，因此 $V_{out} = 0$。
- **两管都导通**的条件是 $V_{TN} < V_{in} < 3 - V_{TP}$：整个转换过程都发生在这个窗口内。

| | 目标情况 | 无注入 |
|---|---|---|
| $M_1$ 开始导通于 | $V_{in} = 0.7$ V | $V_{in} = 0$ |
| $M_2$ 截止于 | $V_{in} = 3 - 0.8 = 2.2$ V | $V_{in} = 3 - 1 = 2.0$ V |
| 两管同时导通的窗口 | 0.7 – 2.2 V（宽 1.5 V） | 0 – 2.0 V（宽 2.0 V） |

没有注入时，输出在 $V_{in} = 0$ 处就开始下降，并在 $V_{in} = 2.0$ V 时已降到 0 V。

### 第 3 步 — 开关阈值 $V_M$（两管都饱和）

在 $V_{in} = V_M$ 处，两个器件都处于饱和区：

$$\tfrac12\mu_nC_{ox}(W/L)_1(V_M - V_{TN})^2 = \tfrac12\mu_pC_{ox}(W/L)_2(3 - V_{TP} - V_M)^2 .$$

两边除以 $\tfrac12\mu_pC_{ox}(W/L)_2$，取正的平方根，并合并含 $V_M$ 的项：

$$r(V_M - V_{TN}) = 3 - V_{TP} - V_M \quad\Longrightarrow\quad V_M = \frac{3 - V_{TP} + rV_{TN}}{1 + r}.$$

**目标情况**（$V_{TN} = 0.7$，$V_{TP} = 0.8$）与**无注入**（$V_{TN} = 0$，$V_{TP} = 1$）：

$$V_{M,\text{target}} = \frac{2.2 + 0.7r}{1 + r}, \qquad V_{M,\text{new}} = \frac{2.0}{1 + r}.$$

**向左的偏移量：**

$$V_{M,\text{target}} - V_{M,\text{new}} = \frac{2.2 + 0.7r - 2.0}{1 + r} = \frac{0.2 + 0.7r}{1 + r}.$$

| $r$ | $V_{M,\text{target}}$ | $V_{M,\text{new}}$ | 偏移量 |
|---|---|---|---|
| 1 | $2.9/2 = 1.45$ V | $2/2 = 1.00$ V | 0.45 V |
| 1.87（$W/L$ 相等，$\mu_n/\mu_p \approx 3.5$） | $3.509/2.87 = 1.22$ V | $2/2.87 = 0.70$ V | 0.53 V |

两种变化的作用方向相同：较低的 $V_{THN}$ 使 NMOS 变强，较大的 $|V_{THP}|$ 使 PMOS 变弱，因此 NMOS 在更低的输入电压下就占了上风。

**垂直段。** 当 $\lambda = 0$ 时，对于使两管都保持饱和的每个 $V_{out}$，即 $V_M - V_{TN} \le V_{out} \le V_M + V_{TP}$，$V_M$ 处的电流平衡都成立。目标情况：从 $V_M + 0.8$ 下降到 $V_M - 0.7$。无注入：从 $V_M + 1$ 下降到 $V_M$（$r = 1$ 时：从 2.0 V 降到 1.0 V）。

### 第 4 步 — $V_M$ 两侧的弯折段

**上弯折段（$V_{TN} < V_{in} < V_M$）：$M_1$ 饱和，$M_2$ 处于线性区。** 令 $x = 3 - V_{out}$：

$$\tfrac12\mu_nC_{ox}(W/L)_1(V_{in} - V_{TN})^2 = \mu_pC_{ox}(W/L)_2\big[(3 - V_{TP} - V_{in})x - \tfrac12x^2\big].$$

两边除以 $\tfrac12\mu_pC_{ox}(W/L)_2$，并取较小的（线性区）根：

$$r^2(V_{in} - V_{TN})^2 = 2(3 - V_{TP} - V_{in})x - x^2 ,$$

$$x = (3 - V_{TP} - V_{in}) - \sqrt{(3 - V_{TP} - V_{in})^2 - r^2(V_{in} - V_{TN})^2}, \qquad V_{out} = 3 - x .$$

**下弯折段（$V_M < V_{in} < 3 - V_{TP}$）：$M_1$ 处于线性区，$M_2$ 饱和。**

$$\mu_nC_{ox}(W/L)_1\big[(V_{in} - V_{TN})V_{out} - \tfrac12V_{out}^2\big] = \tfrac12\mu_pC_{ox}(W/L)_2(3 - V_{TP} - V_{in})^2 .$$

两边除以 $\tfrac12\mu_nC_{ox}(W/L)_1$，并取较小的根：

$$2(V_{in} - V_{TN})V_{out} - V_{out}^2 = \frac{(3 - V_{TP} - V_{in})^2}{r^2},$$

$$V_{out} = (V_{in} - V_{TN}) - \sqrt{(V_{in} - V_{TN})^2 - \frac{(3 - V_{TP} - V_{in})^2}{r^2}} .$$

**示例：无注入，$r = 1$。** 在 $V_{in} = 0.5$ V 处（上弯折段）：

$$x = 1.5 - \sqrt{1.5^2 - 0.5^2} = 1.5 - \sqrt{2.0} = 1.5 - 1.414 = 0.086\ \mathrm{V},\qquad V_{out} = 2.914\ \mathrm{V}.$$

在 $V_{in} = 1.5$ V 处（下弯折段）：

$$V_{out} = 1.5 - \sqrt{1.5^2 - 0.5^2} = 0.086\ \mathrm{V}.$$

### 第 5 步 — 对照表（$r = 1$）

| $V_{in}$ (V) | 目标情况 $V_{out}$ (V) | 无注入时 $V_{out}$ (V) |
|---|---|---|
| 0 | 3.00（$M_1$ 截止） | 3.00（$M_1$ 处于阈值） |
| 0.2 | 3.00 | 2.99 |
| 0.5 | 3.00 | 2.91 |
| 0.8 | 3.00 | 2.69 |
| 1.0 | 2.96 | **2.0 → 1.0（垂直，$V_M$）** |
| 1.2 | 2.87 | 0.31 |
| 1.45 | **2.25 → 0.75（垂直，$V_M$）** | 0.11 |
| 1.5 | 0.41 | 0.09 |
| 1.7 | 0.13 | 0.03 |
| 2.0 | 0.02 | 0（$M_2$ 截止） |
| 2.2 – 3 | 0（$M_2$ 截止） | 0 |

（目标情况的各项由同样的公式取 $V_{TN} = 0.7$，$V_{TP} = 0.8$ 算出。）

**草图。** 两条曲线都具有反相器的形状。无注入时的曲线在 $V_{in} = 0$ 处立即离开 3 V，在 1.0 V（而不是 1.45 V）处翻转，并从 2.0 V（而不是 2.2 V）起保持在 0 V：曲线左移，且其转换区（两个器件都导通的区域）变宽，为 2.0 V 而不是 1.5 V。

### 第 6 步 — 后果

- **噪声容限不对称。** 开关点移到远低于 $V_{DD}/2 = 1.5$ V 的位置，因此低电平一侧的噪声容限减小。
- **$V_{in} = 0$ 时的漏电。** 输入为低电平时，NMOS 恰好处于阈值，因此在“截止”状态下仍有亚阈值（subthreshold）电流流过，输出高电平略有下降。
- **直通电流更大。** 在 $V_M$ 处两个器件流过相同的电流，NMOS 的过驱动电压为
$$V_M - V_{TN} = \frac{2.2 + 0.7r}{1 + r} - 0.7 = \frac{1.5}{1 + r}\ \ \text{(target)}, \qquad V_M - 0 = \frac{2.0}{1 + r}\ \ \text{(no implant)},$$
因此
$$\frac{I_{peak,\text{new}}}{I_{peak,\text{target}}} = \left(\frac{2.0}{1.5}\right)^2 = 1.78 .$$
- **$V_M$ 处的增益（计入沟道长度调制，可选）。** 小信号增益为 $-(g_{m1} + g_{m2})(r_{O1}\parallel r_{O2})$。利用 $g_m = 2I_D/V_{ov}$ 和 $r_{O1}\parallel r_{O2} = 1/[(\lambda_n + \lambda_p)I_D]$：
$$|A_v| = \frac{2}{\lambda_n + \lambda_p}\left(\frac{1}{V_{ov1}} + \frac{1}{V_{ov2}}\right).$$
在 $V_M$ 处，$V_{ov1} = S/(1 + r)$，$V_{ov2} = rS/(1 + r)$，其中 $S = V_{ov1} + V_{ov2} = 3 - V_{TP} - V_{TN}$ 为 1.5 V（目标情况）或 2.0 V（无注入）。于是 $1/V_{ov1} + 1/V_{ov2} = (1 + r)^2/(rS)$，因此 $|A_v| \propto 1/S$，增益降为目标值的 $1.5/2.0 = 0.75$。

### 结果

没有阈值调整注入时，令 $r = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_2]}$：

- 输出在 $V_{in} \approx 0$（而不是 0.7 V）处开始下降，并在 $V_{in} = V_{DD} - |V_{THP}| = 2.0$ V（而不是 2.2 V）处降到 0；两个器件同时导通的范围是 0–2.0 V，而不是 0.7–2.2 V。
- 开关阈值从 $V_M = (2.2 + 0.7r)/(1 + r)$ 降到 $V_M = 2.0/(1 + r)$，即左移 $(0.2 + 0.7r)/(1 + r)$：$r = 1$ 时为 1.45 V → 1.00 V，$W/L$ 相等（$r = 1.87$）时为 1.22 V → 0.70 V。
- 曲线左移且转换区变宽；$V_M$ 处的直通电流约增大为 1.8 倍，NMOS 在 $V_{in} = 0$ 时漏电，并且（计入 $\lambda$ 时）$V_M$ 处的增益约为目标值的 0.75。

**常见错误。** 只考虑 NMOS 的阈值。缺少注入还会使 $|V_{THP}|$ 升高到 1 V，这会把 $M_2$ 截止的点从 2.2 V 移到 2.0 V，并削弱 PMOS；忽略这一点会得到 $V_M = 2.2/(1 + r)$，右侧的转折点也会出错。

**常见错误。** 把 $V_M$ 向右移。较低的 $V_{THN}$ 增强了下拉器件，较高的 $|V_{THP}|$ 削弱了上拉器件，因此 $V_M$ 减小。

**常见错误。** 以为曲线只是平移。两管同时导通的窗口 $V_{DD} - V_{TN} - V_{TP}$ 从 1.5 V 增大到 2.0 V，因此转换区也变宽，峰值电流增大。
