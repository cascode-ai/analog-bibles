# 详细步骤 - R037

**思路。** 节点 X 是 $M_1$ 的栅极和 $C_1$ 的一个极板，因此没有电流能流入或流出该节点：$C_1$ 上的电荷被“困住”了。因此电容电压永远保持 3 V，$V_X$ 只是叠加在输入电压之上。

### 第 1 步 — 节点 X 没有电流通路

$C_1$ 跨接在 $M_1$ 的栅极与源极之间，X 端为正，因此在任一时刻都有

$$V_X = V_{in} + V_{C1}.$$

节点 X 上只连接了 $M_1$ 的绝缘栅极（没有直流电流）、$C_1$ 的极板以及开路的输出端子，因此在 X 点列基尔霍夫电流定律（KCL）方程得

$$C_1\frac{dV_{C1}}{dt} = 0 \quad\Longrightarrow\quad V_{C1}(t) = 3\ \mathrm{V} \ \text{ for all } t .$$

$C_1$ 上的电荷被困在理想电压源（$V_{in}$ 节点）与绝缘栅极之间，因此无论 $M_1$ 如何工作，电容都既不充电也不放电。

### 第 2 步 — 阶跃前后的 $V_X$

$$
\begin{aligned}
t < 0:&\quad V_X = V_{in} + V_{C1} = 0 + 3 = 3\ \mathrm{V},\\
t > 0:&\quad V_X = V_{in} + V_{C1} = 3 + 3 = 6\ \mathrm{V}.
\end{aligned}
$$

**$V_X$ 在 $t = 0$ 时从 3 V 跳变到 6 V，并保持在该值。** 电容把栅极与源极一起抬高，这就是“自举”（bootstrapping），因此 $V_{GS}$ 保持 3 V。

### 第 3 步 — $M_1$ 起什么作用？

$M_1$ 的沟道电流只在 $V_{DD}$（漏极）与理想电压源 $V_{in}$ 之间流动，后者可以吸收或提供任意电流而不改变其电压，因此它永远不会影响节点 X。

- **阶跃之前：** $V_{GS} = V_{C1} = 3$ V，$V_{DS} = 3 - 0 = 3$ V，因此 $M_1$ 从 $V_{DD}$ 向 $V_{in}$ 电源传导电流 $\tfrac12\beta(3 - V_{TH})^2$（$V_{SB} = 0$ 时 $V_{TH} = 0.7$ V），但不会影响 $C_1$。
- **阶跃之后：** $V_{GS}$ 仍为 3 V，但 $V_{DS} = 3 - 3 = 0$，因此沟道虽然导通，却**没有电流**。

### 结果

$$V_X = 3\ \mathrm{V} \ (t < 0), \qquad V_X = 6\ \mathrm{V} \ (t > 0), \ \text{constant thereafter}.$$

- 节点 X 是 $M_1$ 的栅极和 $C_1$ 的上极板，因此没有电流能流入或流出该节点。$C_1$ 保持其 3 V 电压，$V_X = V_{in} + 3$ V。
- $M_1$ 的电流只在 $V_{DD}$ 与理想电压源 $V_{in}$ 之间流动；而且阶跃之后其 $V_{DS} = 0$。
- 草图是在 $t = 0$ 处从 3 V 到 6 V 的阶跃，两侧都是水平的。

**常见错误。** 让 $V_X$ 在跳变后“通过 $M_1$”衰减。沟道位于漏极与源极之间，两者都不是节点 X，而栅极是绝缘的，因此 $C_1$ 上的电荷没有离开的通路。

**常见错误。** 预测一个诸如 $V_{DD} + V_{TH}$ 的最终值，好像 $M_1$ 会钳位（clamp）栅极一样。MOSFET 能限制的是其**源极**电压（作为跟随器），而不是栅极电压。

**常见错误。** 忘记跳变。在阶跃瞬间电容保持其电压，因此 X 与 $V_{in}$ 一样上升 3 V。
