[图 1] 所示为一个电压-电压反馈（voltage–voltage feedback）电路，其中前向放大器（forward amplifier）和反馈网络都用二端口网络（two-port）的 G 参数模型表示，G 参数即逆混合参数（inverse hybrid parameters）。对前向放大器，$I_1 = G_{11}V_1 + G_{12}I_2$，$V_2 = G_{21}V_1 + G_{22}I_2$，其中 $I_1$ 为输入端口电流（即 $I_{in}$），$V_1 = V_e$，$V_2 = V_{out}$，$I_2$ 为流入放大器输出端口的电流，且 $Z_{in} = 1/G_{11}$，$A_0 = G_{21}$，$Z_{out} = G_{22}$。反馈网络同样用 $g_{11}$、$g_{12}$、$g_{21}$、$g_{22}$ 描述，其输入端口跨接在 $V_{out}$ 上，输出端口与放大器输入端串联。放大器输入端口中画出的受控电流源（图中标为 $G_{12}V_{out}$）代表反向传输（reverse transmission）项 $G_{12}I_2$。仍然忽略反馈网络的正向传输（$g_{12}I_{in} = 0$），在不忽略 $G_{12}I_2$ 的情况下计算闭环增益（closed-loop gain）$V_{out}/V_{in}$。然后用 $A_0$、$Z_{in}$ 和 $Z_{out}$ 给出一个关于 $G_{12}$ 的条件，该条件对任意反馈网络都成立，在此条件下该项可以忽略。
