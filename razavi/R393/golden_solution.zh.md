$\dfrac{V_{out}}{V_{in}} = \dfrac{A_0}{\left(1 + \dfrac{g_{22}}{Z_{in}}\right)(1 + g_{11}Z_{out}) + A_0g_{21} - A_0G_{12}g_{11}g_{22}}$（$I_2$ 定义为流入放大器，$I_2 = -g_{11}V_{out}$；若 $I_2$ 取相反方向，$G_{12}$ 项的符号随之改变）。

当 $A_0|G_{12}|g_{11}g_{22} \ll (1 + g_{22}/Z_{in})(1 + g_{11}Z_{out}) + A_0g_{21}$ 时，该项可以忽略。由于 $(1 + g_{22}/Z_{in})(1 + g_{11}Z_{out}) \ge g_{11}g_{22}Z_{out}/Z_{in}$，一个与反馈网络无关的充分条件是 $|G_{12}| \ll \dfrac{Z_{out}}{A_0Z_{in}}$，即 $A_0G_{12}Z_{in}/Z_{out} \ll 1$：反向电流 $G_{12}I_2$（其中 $I_2$ 最大约为 $A_0V_e/Z_{out}$）必须远小于正常的输入电流 $V_e/Z_{in}$。当环路增益（loop gain）很大时，与网络有关的条件 $G_{12} \ll g_{21}/(g_{11}g_{22})$ 就已足够；对于由 $R_1$（上）、$R_2$（下）构成的电阻分压器，该条件为 $G_{12} \ll 1 + R_2/R_1$。

推导：
- 输出端：无负载，因此 $I_2 = -g_{11}V_{out}$；$V_{out} = A_0V_e + Z_{out}I_2$ → $V_e = V_{out}(1 + g_{11}Z_{out})/A_0$。
- 输入电流：$I_{in} = V_e/Z_{in} + G_{12}I_2 = V_e/Z_{in} - G_{12}g_{11}V_{out}$。
- 输入回路：$V_{in} = V_e + g_{22}I_{in} + g_{21}V_{out} = V_e(1 + g_{22}/Z_{in}) + V_{out}(g_{21} - G_{12}g_{11}g_{22})$。
- 联立即得结果；$G_{12} = 0$ 时简化为 $A_0/[(1 + g_{22}/Z_{in})(1 + g_{11}Z_{out}) + g_{21}A_0]$。
