# 详细步骤 - R393

**思路。** 按图中的连接方式把放大器和反馈网络的 G 参数方程联立起来：输入侧端口串联（电流同为 $I_{in}$），输出侧端口并联（电压同为 $V_{out}$）。在保留 $G_{12}I_2$ 的情况下求解 $V_{out}/V_{in}$，然后把该项与分母的其余部分比较，并给出与反馈网络无关的界。

### 第 1 步 — 二端口方程与连接关系

**放大器：**

$$I_{in} = G_{11}V_e + G_{12}I_2, \qquad V_{out} = G_{21}V_e + G_{22}I_2,$$

其中 $Z_{in} = 1/G_{11}$，$A_0 = G_{21}$，$Z_{out} = G_{22}$，$I_2$ **流入**输出端口；$G_{12}$ 是无量纲的反向电流增益。

**反馈网络：** 端口 1（跨接在 $V_{out}$ 上）从输出端吸取电流 $g_{11}V_{out} + g_{12}I_{in}$，其中 $g_{12}I_{in}$ 忽略不计；端口 2（与放大器输入端串联，流过 $I_{in}$）呈现的电压为 $g_{21}V_{out} + g_{22}I_{in}$，即一个反馈电压源串联阻抗 $g_{22}$。

沿输入回路，$V_{in}$ 等于 $V_e$ 加上端口 2 的电压；在无负载的输出端，流出放大器的电流全部流入反馈网络。

### 第 2 步 — 输出侧：用 $V_{out}$ 表示 $I_2$ 和 $V_e$

对输出节点应用基尔霍夫电流定律（KCL）：

$$I_2 + g_{11}V_{out} = 0 \quad\Longrightarrow\quad I_2 = -g_{11}V_{out}.$$

代入放大器的输出方程：

$$
\begin{aligned}
V_{out} &= A_0V_e + Z_{out}I_2 = A_0V_e - g_{11}Z_{out}V_{out}\\
V_{out}(1 + g_{11}Z_{out}) &= A_0V_e\\
V_e &= \frac{1 + g_{11}Z_{out}}{A_0}\,V_{out}.
\end{aligned}
$$

$1 + g_{11}Z_{out}$ 反映了输出端的负载效应：$A_0V_e$ 有一部分损失在 $Z_{out}$ 上。

### 第 3 步 — 计入反向项的输入电流

由 $G_{11} = 1/Z_{in}$ 和 $I_2 = -g_{11}V_{out}$ 得：

$$I_{in} = \frac{V_e}{Z_{in}} + G_{12}I_2 = \frac{V_e}{Z_{in}} - G_{12}g_{11}V_{out}.$$

### 第 4 步 — 沿输入回路应用基尔霍夫电压定律（KVL）

$$
\begin{aligned}
V_{in} &= V_e + g_{22}I_{in} + g_{21}V_{out}\\
&= V_e + g_{22}\left(\frac{V_e}{Z_{in}} - G_{12}g_{11}V_{out}\right) + g_{21}V_{out}\\
&= V_e\left(1 + \frac{g_{22}}{Z_{in}}\right) + V_{out}\left(g_{21} - G_{12}g_{11}g_{22}\right).
\end{aligned}
$$

$1 + g_{22}/Z_{in}$ 反映了输入端的负载效应：回路电压有一部分降落在 $g_{22}$ 上。

### 第 5 步 — 闭环增益

代入第 2 步的 $V_e$：

$$V_{in} = V_{out}\left[\frac{(1 + g_{11}Z_{out})(1 + g_{22}/Z_{in})}{A_0} + g_{21} - G_{12}g_{11}g_{22}\right],$$

$$\frac{V_{out}}{V_{in}} = \frac{A_0}{\left(1 + \dfrac{g_{22}}{Z_{in}}\right)(1 + g_{11}Z_{out}) + A_0g_{21} - A_0G_{12}g_{11}g_{22}}.$$

（最后一项的符号对应于 $I_2$ 定义为流入放大器；若采用相反的约定，符号随之改变。）

**检验。** $G_{12} = 0$ 时：$A_0/[(1 + g_{22}/Z_{in})(1 + g_{11}Z_{out}) + A_0g_{21}]$，即计入负载效应时的常见结果。若同时 $Z_{in} \to \infty$、$Z_{out} \to 0$：$A_0/(1 + A_0g_{21})$，即 $\beta = g_{21}$ 时的理想公式。

送入反馈网络的电流 $I_2$ 以 $G_{12}I_2$ 的形式泄漏回输入端，流过 $g_{22}$，使回路电压改变 $-G_{12}g_{11}g_{22}V_{out}$：相当于反馈系数（feedback factor）变成了 $g_{21} - G_{12}g_{11}g_{22}$。

### 第 6 步 — 何时可以忽略 $G_{12}I_2$？

**精确比较。** 当下式成立时，该项可以忽略：

$$A_0|G_{12}|\,g_{11}g_{22} \ll \left(1 + \frac{g_{22}}{Z_{in}}\right)(1 + g_{11}Z_{out}) + A_0g_{21}.$$

**对任意反馈网络都成立的界。** 对于无源（为正）的 $g_{11}$、$g_{22}$、$g_{21}$ 以及为正的 $Z_{in}$、$Z_{out}$，该乘积不小于其最后一项：

$$\left(1 + \frac{g_{22}}{Z_{in}}\right)(1 + g_{11}Z_{out}) = 1 + \frac{g_{22}}{Z_{in}} + g_{11}Z_{out} + \frac{g_{11}g_{22}Z_{out}}{Z_{in}} \ge \frac{g_{11}g_{22}Z_{out}}{Z_{in}} .$$

因此只需满足

$$A_0|G_{12}|\,g_{11}g_{22} \ll \frac{g_{11}g_{22}Z_{out}}{Z_{in}} \quad\Longleftrightarrow\quad |G_{12}| \ll \frac{Z_{out}}{A_0Z_{in}},$$

即 $A_0|G_{12}|Z_{in}/Z_{out} \ll 1$；$g_{11}$ 和 $g_{22}$ 被约去，因此该条件对**任意**反馈网络都成立。从物理上看，$I_2$ 至多为 $A_0V_e/Z_{out}$ 量级，因此反向电流 $|G_{12}|A_0V_e/Z_{out}$ 必须远小于正常的输入电流 $V_e/Z_{in}$。

**与网络有关的另一种条件。** 环路增益很大时，$A_0g_{21}$ 占主导，只需 $|G_{12}| \ll g_{21}/(g_{11}g_{22})$。对于 $R_1$ 接在输出端与抽头之间、$R_2$ 接在抽头与地之间的电阻分压器，$g_{11} = 1/(R_1 + R_2)$，$g_{21} = R_2/(R_1 + R_2)$，$g_{22} = R_1\parallel R_2$，因此

$$\frac{g_{21}}{g_{11}g_{22}} = \frac{R_2/(R_1 + R_2)}{\dfrac{1}{R_1 + R_2}\cdot\dfrac{R_1R_2}{R_1 + R_2}} = \frac{R_1 + R_2}{R_1} = 1 + \frac{R_2}{R_1}.$$

### 结果

$$\frac{V_{out}}{V_{in}} = \frac{A_0}{\left(1 + \dfrac{g_{22}}{Z_{in}}\right)(1 + g_{11}Z_{out}) + A_0g_{21} - A_0G_{12}g_{11}g_{22}}$$

（$I_2$ 定义为流入放大器，$I_2 = -g_{11}V_{out}$）。当 $A_0|G_{12}|g_{11}g_{22} \ll (1 + g_{22}/Z_{in})(1 + g_{11}Z_{out}) + A_0g_{21}$ 时，反向项可以忽略。由于 $(1 + g_{22}/Z_{in})(1 + g_{11}Z_{out}) \ge g_{11}g_{22}Z_{out}/Z_{in}$，一个对任意反馈网络都成立的充分条件是

$$|G_{12}| \ll \frac{Z_{out}}{A_0Z_{in}} \qquad\left(\text{i.e. } \frac{A_0G_{12}Z_{in}}{Z_{out}} \ll 1\right).$$

**常见错误。** 把条件颠倒成 $G_{12} \ll A_0Z_{in}/Z_{out}$。这个界并不充分：取 $Z_{in} = 1\ \mathrm{M}\Omega$，$Z_{out} = 1\ \mathrm{k}\Omega$，$A_0 = 100$，10 k/10 k 的分压器以及 $G_{12} = 1$，该条件成立，但增益却改变了约一倍。

**常见错误。** 因为图中的标注而把输入端口的受控源当作 $G_{12}V_{out}$。按定义它是 $G_{12}I_2$，其中 $I_2 = -g_{11}V_{out}$。

**常见错误。** 保留 $G_{12}$ 却丢掉负载因子 $(1 + g_{22}/Z_{in})$ 和 $(1 + g_{11}Z_{out})$。它们的量级相当，而忽略 $G_{12}$ 的条件恰恰就是与这些项的比较。
