# 详细步骤 - R105

**思路。** 节点 $X$ 既是底部器件 $M_1$ 的漏极，又是 $M_2$ 的**源极**，后者位于 PMOS 电流源（current source）$M_3$ 之下。由节点 $X$ 的 KCL 得 $I_X = I_{D1} - I_{D2}$。$M_1$ 的电流随 $V_X$ 遵循其普通的输出特性；流经 $M_3$–$M_2$ 支路的电流受二者中较弱者的限制：$M_3$（固定的最大值 $I_3$）或 $M_2$（其栅源电压随 $V_X$ 升高而减小，直至截止）。

### 第 1 步 — 节点 $X$ 的 KCL

把 $M_3$ 与 $M_2$ 的公共漏极记为节点 $Y$。$I_X$ 和支路电流 $I_{D2}$（经 $M_3$ 和 $M_2$ 流下）流入 $X$，$M_1$ 的漏极电流流出：

$$I_X + I_{D2} = I_{D1} \quad\Longrightarrow\quad I_X = I_{D1} - I_{D2} .$$

### 第 2 步 — 底部器件 $M_1$

$V_{GS1} = V_{b2}$ 固定，$V_{DS1} = V_X$：

- **线性区，$V_X < V_{b2} - 0.7$ V：** $I_{D1} = \beta_1[(V_{b2} - 0.7)V_X - \frac12V_X^2]$，从 0 开始上升。
- **饱和区，$V_X \ge V_{b2} - 0.7$ V：** $I_{D1} = I_1 = \frac12\beta_1(V_{b2} - 0.7)^2$。

### 第 3 步 — 上方支路 $M_3$–$M_2$

$M_3$ 的栅极驱动固定为 $V_{SG3} = 3 - V_{b3}$，因此它最多能提供

$$I_3 = \frac12\beta_3(V_{DD} - V_{b3} - 0.8)^2 .$$

$M_2$ 的 $V_{GS2} = V_{b1} - V_X$，且由于 $V_{SB2} = V_X$，$V_{TH2} = 0.7 + 0.45(\sqrt{0.9 + V_X} - \sqrt{0.9})$ V，因此它最多能流过 $\frac12\beta_2(V_{b1} - V_X - V_{TH2})^2$，该值随 $V_X$ 升高而**减小**。

两管串联时，较弱的器件处于饱和区并决定电流，较强的器件则被推入线性区，在 $Y$ 处只有很小的漏源电压：

$$I_{D2} = \min\left\{I_3,\ \tfrac12\beta_2\left(V_{b1} - V_X - V_{TH2}(V_X)\right)^2\right\}.$$

- **$V_X$ 较小时（通常情况）：** $M_2$ 的 $V_{GS}$ 很大，因此由 $M_3$ 限流：$I_{D2} = I_3$，$M_3$ 饱和，$M_2$ 处于线性区（$Y$ 略高于 $X$）。
- 当其电流能力降到 $I_3$ 时，**改由 $M_2$ 限流**：
$$\tfrac12\beta_2\left(V_{b1} - V_{X,a} - V_{TH2}\right)^2 = I_3 \quad\Longrightarrow\quad V_{X,a} = V_{b1} - V_{TH2}(V_{X,a}) - \sqrt{\frac{2I_3}{\beta_2}} .$$
此后 $M_2$ 饱和，$M_3$ 处于线性区（$Y$ 接近 $V_{DD}$），$I_{D2} = \frac12\beta_2(V_{b1} - V_X - V_{TH2})^2$ **按二次规律下降**。
- **$M_2$ 截止**的位置为 $V_{X,off}$，其中 $V_{b1} - V_{X,off} = V_{TH2}(V_{X,off})$，略低于 $V_{b1} - 0.7$ V；高于该电压时 $I_{D2} = 0$。

（若 $\frac12\beta_2(V_{b1} - 0.7)^2 < I_3$，则在 $V_X = 0$ 时 $M_2$ 就已是较弱的器件，不存在 $I_3$ 段。）

### 第 4 步 — 合成：$I_X = I_{D1} - I_{D2}$

- **起点：** 在 $V_X = 0$ 处，$I_{D1} = 0$，因此
$$I_X(0) = -\min\left\{I_3,\ \tfrac12\beta_2(V_{b1} - 0.7)^2\right\} \;(= -I_3\ \text{when } M_3 \text{ is the limiting device}).$$
- **$M_1$ 处于线性区：** $I_X$ 随 $I_{D1}$ 增大而上升。
- **可能出现的平坦段：** 若 $M_1$ 在 $M_2$ 开始限流之前就已饱和（$V_{b2} - 0.7 < V_{X,a}$），则在这两点之间 $I_X = I_1 - I_3$ 为常数。
- **$M_2$ 限流：** 随着 $I_{D2}$ 减小，$I_X$ 再次上升，并在 $I_{D2} = I_{D1}$ 处过零。
- **最终平台：** 当 $V_X \ge V_{X,off}$ 时，$I_X = I_{D1}$；一旦 $V_X$ 也超过 $V_{b2} - 0.7$ V，它就是常数 $I_1$，一直平坦到 3 V。

转折点为 $V_X = V_{b2} - 0.7$ V、$V_X = V_{X,a}$ 和 $V_X = V_{X,off}$；它们的先后顺序取决于偏置电压。

### 第 5 步 — 数值示例

为便于说明，取 $V_{b3} = 1.5$ V，$V_{b1} = 2.0$ V，$V_{b2} = 1.0$ V，$\beta_1 = \beta_2 = 2\ \mathrm{mA/V^2}$，$\beta_3 = 1\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_3 &= \tfrac12(1\ \mathrm{mA/V^2})(3 - 1.5 - 0.8)^2\ \mathrm{V^2} = 0.245\ \mathrm{mA},\\
I_1 &= \tfrac12(2\ \mathrm{mA/V^2})(1.0 - 0.7)^2\ \mathrm{V^2} = 0.090\ \mathrm{mA}\quad(M_1\ \text{saturates at } V_X = 0.3\ \mathrm{V}).
\end{aligned}
$$

在 $V_X = 0$ 处，$M_2$ 能流过 $\frac12(2\ \mathrm{mA/V^2})(1.3\ \mathrm{V})^2 = 1.69$ mA $> I_3$，因此由 $M_3$ 限流，$I_X(0) = -0.245$ mA。

**$V_{X,a}$：** $V_{X,a} + V_{TH2}(V_{X,a}) = 2.0 - \sqrt{0.245} = 1.505$ V，由此得 $V_{X,a} = 0.668$ V（$V_{TH2} = 0.837$ V）。

**$V_{X,off}$：** 由 $u^2 + 0.45u - 2.627 = 0$ 得 $u = 1.411$，因此 $V_{X,off} = 1.092$ V。

| $V_X$ (V) | $I_{D1}$ (mA) | 支路电流 $I_{D2}$ (mA) | 限流器件 | $I_X$ (mA) |
|---|---|---|---|---|
| 0 | 0 | 0.245 | $M_3$ | −0.245 |
| 0.1 | 0.050 | 0.245 | $M_3$ | −0.195 |
| 0.3 | 0.090 | 0.245 | $M_3$ | −0.155 |
| 0.668 | 0.090 | 0.245 | → $M_2$ | −0.155 |
| 0.8 | 0.090 | 0.116 | $M_2$ | −0.026 |
| 0.834 | 0.090 | 0.090 | $M_2$ | 0 |
| 1.0 | 0.090 | 0.011 | $M_2$ | 0.079 |
| 1.092 | 0.090 | 0 | （$M_2$ 截止） | 0.090 |
| 3.0 | 0.090 | 0 | — | 0.090 |

这里 $M_1$ 先进入饱和（0.3 V），然后 $M_2$ 才开始限流（0.668 V），因此在 $I_1 - I_3 = -0.155$ mA 处有一个平坦段。

### 结果

$$I_X = I_{D1} - I_{D2},$$

其中 $I_{D2}$ 是经 $M_3$–$M_2$ 流下来的电流。$I_X$ 从 $-I_3$ 开始（若 $M_2$ 是较弱的器件，则从 $-\tfrac12\beta_2(V_{b1} - 0.7)^2$ 开始），先随 $M_1$ 的线性区电流增大而上升，之后又随 $M_2$ 的电流减小而上升；$M_2$ 截止后，最终平坦地保持在 $I_1 = \tfrac12\beta_1(V_{b2} - 0.7)^2$。

- **$M_1$：** $V_X < V_{b2} - 0.7$ V 时处于线性区（电流从 0 开始上升），之后饱和于 $I_1$。
- **$M_3$–$M_2$ 支路：** $M_3$ 最多能提供 $I_3 = \tfrac12\beta_3(V_{DD} - V_{b3} - 0.8)^2$；$M_2$（栅极接 $V_{b1}$，源极接 $X$，体效应 $V_{SB} = V_X$）最多能流过 $\tfrac12\beta_2(V_{b1} - V_X - V_{TH2})^2$。支路电流取二者中的较小者：$V_X$ 较小时通常为 $I_3$（$M_3$ 饱和，$M_2$ 处于线性区）；一旦 $V_X > V_{b1} - V_{TH2} - \sqrt{2I_3/\beta_2}$，它就等于 $M_2$ 的饱和电流（此时 $M_3$ 处于线性区），并按二次规律下降，在 $V_X = V_{b1} - V_{TH2}(V_X)$ 处降为零。
- **因此：** $I_X(0) = -\min\{I_3, \tfrac12\beta_2(V_{b1} - 0.7)^2\}$。$M_1$ 处于线性区时 $I_X$ 上升；若 $M_1$ 在 $M_2$ 开始限流之前就进入饱和，它可能在 $I_1 - I_3$ 处保持平坦；随着 $I_{D2}$ 减小，它再次上升；当 $V_X \ge V_{b1} - V_{TH2}$ 时，它等于 $I_{D1}$，即一旦 $V_X$ 也超过 $V_{b2} - 0.7$ V，就是平台 $I_1$（一直平坦到 3 V）。
- **转折点：** $V_X = V_{b2} - 0.7$ V；$V_X = V_{b1} - V_{TH2} - \sqrt{2I_3/\beta_2}$；$V_X = V_{b1} - V_{TH2}$。它们的先后顺序取决于偏置电压。

**常见错误。** 认为上方支路对所有 $V_X$ 都是恒定的 $I_3$，从而使 $I_X$ 最终为 $I_1 - I_3$。$X$ 是 $M_2$ 的**源极**：随着 $V_X$ 升高，$M_2$ 最终会限制电流并截止，因此最终平台为 $I_1$。

**常见错误。** 认为支路电流总是由 $M_2$ 决定。$V_X$ 较小时，$M_2$ 能流过的电流远大于 $M_3$ 所能提供的；串联电流取**较小**的那个能力值，因此起始值为 $I_3$。

**常见错误。** 把 $X$ 当作 $M_2$ 的漏极，或者忘记 $M_2$ 的体效应。$V_{SB2} = V_X$ 使 $V_{TH2}$ 升高，从而使 $V_{X,a}$ 和截止点都低于按 $V_{TH} = 0.7$ V 算出的值。
