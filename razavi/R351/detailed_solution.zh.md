# 详细步骤 - R351

**思路。** 由于 $I_1$ 是理想的，且栅极不吸取电流，由基尔霍夫电流定律（KCL）可得两个结论：在输出端，跟随器 $M_1$ 的交流电流为零；在输入节点，当输入开路时，$M_2$ 的交流电流为零。每个结论都使一个晶体管的噪声从两项计算之一中消失。

### 第 1 步 — 小信号模型（small-signal model）

$\lambda = 0$ 且无体效应时：

- **$M_1$**（漏极接交流地，栅极接输入端，源极接输出端）：它向输出端送入 $g_{m1}(v_{in} - v_{out}) + I_{n1}$，其中 $\overline{I_{n1}^2} = 4kT\gamma g_{m1}$。
- **$M_2$**（源极接地，栅极接输出端，漏极接输入端）：它从输入节点抽取 $g_{m2}v_{out} + I_{n2}$，其中 $\overline{I_{n2}^2} = 4kT\gamma g_{m2}$；它的栅极不从输出端吸取电流。
- **$I_1$：** 理想且无噪声，对交流信号相当于开路。

### 第 2 步 — 输出端的 KCL

输出端只与 $M_1$ 的源极、$M_2$ 的栅极和 $I_1$ 相连，因此 $M_1$ 的总交流电流为零：

$$g_{m1}(v_{in} - v_{out}) + I_{n1} = 0\quad\Longrightarrow\quad v_{out} = v_{in} + \frac{I_{n1}}{g_{m1}}. \tag{1}$$

跟随器具有**单位增益**，其自身噪声表现为与输入串联的电压 $I_{n1}/g_{m1}$；$M_2$ **不**构成输出端的负载。

### 第 3 步 — 输入参考噪声电压（输入由信号源驱动）

输入端接理想电压源时，$M_2$ 的漏极电流（信号和噪声）流入该电压源，既不影响 $v_{in}$，也不影响 $v_{out}$。由式 (1)，$A_v = 1$，输出噪声为 $I_{n1}/g_{m1}$：

$$\overline{V_{n,in}^2} = \frac{\overline{I_{n1}^2}}{g_{m1}^2} = \frac{4kT\gamma g_{m1}}{g_{m1}^2} = \frac{4kT\gamma}{g_{m1}}.$$

### 第 4 步 — 输入开路时的输出噪声

输入开路时，输入节点只与 $M_2$ 的漏极和 $M_1$ 的栅极相连，因此 $M_2$ 的总交流电流为零：

$$g_{m2}v_{out} + I_{n2} = 0\quad\Longrightarrow\quad v_{out} = -\frac{I_{n2}}{g_{m2}}. \tag{2}$$

输出完全由 $M_2$ 的噪声决定。$M_1$ 的噪声只改变浮空的输入电压，由式 (1)，$v_{in} = v_{out} - I_{n1}/g_{m1}$：无论 $M_1$ 内部发生什么，输出 → $M_2$ → 输入 → 跟随器 → 输出这个环路都会稳定在 $M_2$ 电流为零的状态。

### 第 5 步 — 跨阻（transimpedance）与输入参考噪声电流

注入输入节点的信号电流 $i_{in}$ 只能经 $M_2$ 流出：

$$g_{m2}v_{out} = i_{in}\quad\Longrightarrow\quad R_T = \frac{v_{out}}{i_{in}} = \frac{1}{g_{m2}}.$$

把式 (2) 除以 $R_T$：

$$I_{n,eq} = \frac{-I_{n2}/g_{m2}}{1/g_{m2}} = -I_{n2},$$

$$\overline{I_{n,in}^2} = \overline{I_{n2}^2} = 4kT\gamma g_{m2}:$$

$M_2$ 的噪声恰好从输入电流进入的节点抽出，因此一比一地折算到输入端。

### 结果

$$\overline{V_{n,in}^2} = \frac{4kT\gamma}{g_{m1}},\qquad \overline{I_{n,in}^2} = 4kT\gamma g_{m2}$$

- 电压（输入由信号源驱动）：跟随器 $M_1$ 具有单位增益（$v_{out} = v_{in} + I_{n1}/g_{m1}$），$M_2$ 的电流流入输入信号源。
- 电流（输入开路）：$M_2$ 的电流必须为零，因此 $v_{out} = -I_{n2}/g_{m2}$；跨阻为 $1/g_{m2}$。$M_1$ 没有贡献。

**常见错误。** 把 $M_2$ 当作输出端的负载，并把跟随器的增益取为 $g_{m1}/(g_{m1} + g_{m2})$。接在输出端的只是 $M_2$ 的**栅极**；由理想电流源偏置的跟随器具有单位增益。

**常见错误。** 在输入参考噪声电流中计入 $M_1$ 的噪声。输入开路时，经 $M_2$ 的环路迫使 $v_{out} = -I_{n2}/g_{m2}$，与 $I_{n1}$ 无关。

**常见错误。** 在输入参考噪声电压中计入 $M_2$ 的噪声。输入由理想信号源驱动时，它流入该信号源，根本到达不了输出端。
