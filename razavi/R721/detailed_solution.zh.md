# 详细步骤 - R721

**思路。** 沿这一行把导线编号为 1–8：1–4 承载电源电流，5–8 承载地（返回）电流，每根都是总电流 $I$ 的四分之一。每根导线上的压降等于其自感乘以自身的 $dI/dt$，加上互感乘以每个相邻导线的 $dI/dt$。由于各导线的压降不同，用一组导线吸收的功率（等价地，其储能）来定义该组的等效电感，$L_{eq}I^2 = \sum_{i,j}L_{ij}I_iI_j$，并把它应用于电源组、地组以及整个电源–地回路。

### 第 1 步 — 建立电感矩阵

取所有导线的参考方向相同（封装 → 芯片）：电源线 1–4 各流过 $+I/4$，地线 5–8 各流过 $-I/4$。电感矩阵中 $L_{ii} = L = 4$ nH，$L_{i,i\pm1} = M = 2$ nH（忽略不相邻导线之间的耦合），耦合系数 $k = M/L = 0.5$，耦合很强。导线 1–4 并联在封装电源与片上电源节点之间，导线 5–8 并联在片上地与封装地之间。导线 $k$ 两端的压降为

$$V_k = \sum_j L_{kj}\frac{dI_j}{dt} = L\frac{dI_k}{dt} + M\sum_{j\ \text{adjacent to}\ k}\frac{dI_j}{dt} ,$$

其中同方向的相邻电流相加。

### 第 2 步 — 每根电源线上的压降

取 $I_k = I/4$（$k = 1, \dots, 4$），单独考虑电源组：

- **导线 1**（位于行的末端，只有一个相邻导线，即导线 2）：
$$V_1 = (L + M)\frac{1}{4}\frac{dI}{dt} = \frac{4 + 2}{4}\frac{dI}{dt} = 1.5\ \mathrm{nH}\cdot\frac{dI}{dt};$$
- **导线 2 和 3**（各有两个相邻的电源线）：
$$V_{2,3} = (L + 2M)\frac{1}{4}\frac{dI}{dt} = \frac{4 + 4}{4}\frac{dI}{dt} = 2\ \mathrm{nH}\cdot\frac{dI}{dt};$$
- **导线 4**（有一个相邻的电源线，即导线 3）：
$$V_4 = (L + M)\frac14\frac{dI}{dt} = 1.5\ \mathrm{nH}\cdot\frac{dI}{dt}.$$

### 第 3 步 — 电源连接的等效电感

在强制电流相等的情况下各压降不相等，因此用输送的功率来定义连接的电感，$P = \sum_k V_kI_k = \frac{I}{4}(V_1 + V_2 + V_3 + V_4)$，并令其等于 $L_{eq}\,I\,dI/dt$：

$$L_{eq}I\frac{dI}{dt} = \frac{I}{4}\left(1.5 + 2 + 2 + 1.5\right)\mathrm{nH}\cdot\frac{dI}{dt} = \frac{7}{4}\ \mathrm{nH}\cdot I\frac{dI}{dt}, \qquad L_{VV} = 1.75\ \mathrm{nH}.$$

**矩阵形式（结果相同）。** 对 $4\times4$ 的电源子块，$L_{eq} = \frac{1}{I^2}\sum_{i,j}L_{ij}I_iI_j = \frac{1}{16}\sum_{i,j}L_{ij}$，其中有四个对角元和三对相邻元（每对出现两次）：

$$L_{VV} = \frac{4L + 2\cdot3\cdot M}{16} = \frac{4(4) + 6(2)}{16} = \frac{16 + 12}{16} = \frac{28}{16} = 1.75\ \mathrm{nH}.$$

若无耦合，四根 4 nH 导线并联得到 $4/4 = 1$ nH；把同方向的导线并排放置使其增大 75 %，达到 1.75 nH，这与使用多个焊盘的目的**背道而驰**。

地线 5–8 构成一个相同的组（都流过相同的 $-I/4$），因此同样有

$$L_{GG} = 1.75\ \mathrm{nH}.$$

### 第 4 步 — 完整的电源–地回路

电源电流经导线 5–8 返回，因此电源跳动由整个回路决定。只有导线 4（电源）与导线 5（地）相邻，二者电流方向**相反**。两组之间的互感项为

$$M_{VG} = \frac{1}{I^2}\sum_{i\in V,\,j\in G}L_{ij}\,|I_i|\,|I_j| = \frac{M}{16} = \frac{2}{16} = 0.125\ \mathrm{nH},$$

对于方向相反的电流，它要被减去：

$$L_{loop} = L_{VV} + L_{GG} - 2M_{VG} = 1.75 + 1.75 - 2(0.125) = 3.25\ \mathrm{nH}.$$

（若忽略这唯一一处电源–地相邻，$L_{loop} = 3.5$ nH。）把它平均分配给两种连接，每种约为 1.6 nH。

**用矩阵验算。** 当八个电流都为 $\pm I/4$ 时，两个对角块贡献 $28 + 28 = 56$，导线 4–导线 5 这一对贡献 $2\times M\times(+1)(-1) = -4$；总计 $52/16 = 3.25$ nH。✓

### 第 5 步 — 讨论

- **为什么分组排列不好。** 同方向的电流相互增强对方的磁场，因此这是使用多个焊盘最差的方式；让电源线和地线交替排列，相邻电流方向相反，互感就会**减小**回路电感。
- **电流平均分配只是一个假设。** 在 $k = 0.5$ 时，电流实际上会重新分配，使所有并联导线的压降相等；按这种方式求解整个网络会得到更小的值（单独一组约 1.67 nH，回路为 2.0 nH），而电流分布非常不均匀。题目规定电流平均分配。

### 结果

四根同方向的导线并排放置且电流平均分配时，每种连接的电感为

$$L_{VV} = L_{GG} = \frac{4L + 6M}{16} = \frac{28}{16} = 1.75\ \mathrm{nH}$$

（无耦合时为 1 nH）。计入唯一一对电流方向相反的相邻电源–地导线后，电源加地回路的电感为 $L_{loop} = 1.75 + 1.75 - 2(0.125) = 3.25$ nH（若忽略这一对之间的耦合则为 3.5 nH）。

**常见错误。** 忽略互感，答案为 $4\ \mathrm{nH}/4 = 1$ nH。相邻的同方向电流使磁通相加，在这里使等效电感增大 75 %。

**常见错误。** 在组内减去互感，例如 $(L - M)/4$。只有对于**方向相反**的电流（例如电源线与地线之间），互感才会减小电感。

**常见错误。** 认为每根导线都有两个相邻导线（每种连接 $(L + 2M)/4 = 2$ nH），或者把四根导线串联相加。两端的导线只有一个同方向的相邻导线，而一种连接的四根导线是并联的。
