反相特性：在 $M_1$ 导通之前为 $V_{DD}$；$M_2$ 处于线性区（triode region）时缓慢下降（负载为 $R_D\|R_{on2}$）；$M_2$ 进入饱和区（saturation region）后下降得更陡：此时它相当于一个恒定电流源（current source），负载为 $R_D$；$M_1$ 进入线性区后曲线趋于平缓。令 $I_2 = \tfrac12\beta_2(V_{DD} - V_b - 0.8)^2$（$M_2$ 的饱和电流；只有当 $V_b < 2.2$ V 时 $M_2$ 才导通）。

- $V_{in} \le 0.7$ V：$M_1$ 截止，各处均无电流，$V_{out} = V_{DD}$（$M_2$ 处于线性区，$V_{SD} = 0$）。
- $M_1$ 导通，$V_{out} > V_b + 0.8$ V：$M_2$ 处于线性区（$V_{SD}$ 较小时，其电阻 ≈ $1/[\beta_2(V_{DD} - V_b - 0.8)]$），与 $R_D$ 并联；$I_{D1} = \tfrac12\beta_1(V_{in} - 0.7)^2$ 流过这一低阻组合；斜率 ≈ $-g_{m1}(R_D\|R_{on2})$，很小。
- $V_{out} < V_b + 0.8$ V：$M_2$ 饱和，提供恒定电流 $I_2$；$V_{out} = V_{DD} - R_D(I_{D1} - I_2)$，斜率为 $-g_{m1}R_D$：这是陡峭的高增益段。
- $V_{out} < V_{in} - 0.7$ V：$M_1$ 进入线性区；斜率减小，$V_{out}$ 在 $V_{in} = 3$ V 时趋于一个较低的值。
- 转折点：$V_{in} = 0.7$ V；$V_{out} = V_b + |V_{THP}| = V_b + 0.8$ V；$V_{out} = V_{in} - 0.7$ V。
- 用参数表示时，输出节点的基尔霍夫电流定律（KCL）方程为 $I_{D1} = (V_{DD} - V_{out})/R_D + I_{D2}$，$R_D$ 和 $M_2$ 都起上拉作用：$M_2$ 在 $V_{in} = 0.7 + \sqrt{(2/\beta_1)[(2.2 - V_b)/R_D + I_2]}$ 处进入饱和（前提是此时 $M_1$ 仍处于饱和）；$M_1$ 在 $\tfrac12\beta_1(V_{in} - 0.7)^2 = (3.7 - V_{in})/R_D + I_2$ 处进入线性区。若 $V_b$ 足够低，使得 $M_1$ 在 $V_{out}$ 降到 $V_b + 0.8$ V 之前就达到 $V_{out} = V_{in} - 0.7$ V，则两个转折的顺序相反；只要理由充分，两种顺序都可以接受。若 $V_b \ge 2.2$ V，则 $M_2$ 截止，电路就是普通的电阻负载共源级（common-source stage，CS）。
