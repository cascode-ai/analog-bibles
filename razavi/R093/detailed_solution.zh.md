# 详细步骤 - R093

**思路。** $M_1$ 是共源输入器件；其负载为 $R_D$ 与 PMOS $M_2$ 的并联，后者的栅极固定在 $V_b$。列出输出节点的 KCL，并跟踪 $V_{in}$ 升高时两个晶体管的变化：$M_2$ 从线性区（相当于小电阻）进入饱和区（相当于恒定电流源），$M_1$ 则从截止进入饱和区，再进入线性区。每次工作区的改变都会使曲线出现一个转折。

### 第 1 步 — $M_2$ 的偏置与输出节点的 KCL

$M_2$ 的栅极驱动是固定的，$V_{SG2} = V_{DD} - V_b$，因此只有当 $V_b < 2.2$ V 时它才导通；下面假设如此（若 $V_b \ge 2.2$ V，$M_2$ 截止，电路就是普通的电阻负载共源级）。其过驱动电压（overdrive voltage）为 $|V_{ov2}| = 2.2\ \mathrm{V} - V_b$，饱和电流为

$$I_2 = \frac12\beta_2(V_{DD} - V_b - 0.8)^2 = \frac12\beta_2(2.2 - V_b)^2 .$$

当 $V_{SD2} \ge V_{SG2} - |V_{THP}|$ 时，它处于饱和区：

$$V_{DD} - V_{out} \ge V_{DD} - V_b - 0.8 \quad\Longleftrightarrow\quad V_{out} \le V_b + 0.8\ \mathrm{V},$$

因此 $M_2$ **在 $V_{out} > V_b + 0.8$ V 时处于线性区**，**在 $V_{out} < V_b + 0.8$ V 时进入饱和区**。

输出节点的 KCL（$M_1$ 吸收电流，$R_D$ 和 $M_2$ 提供电流）：

$$I_{D1} = \frac{V_{DD} - V_{out}}{R_D} + I_{D2} .$$

### 第 2 步 — $V_{in} \le 0.7$ V：$M_1$ 截止

当 $I_{D1} = 0$ 时，两个非负的上拉电流必须都为零，因此 $R_D$ 两端没有电压，$M_2$ 处于线性区且 $V_{SD2} = 0$：

$$V_{out} = V_{DD} = 3\ \mathrm{V}\qquad (V_{in} \le 0.7\ \mathrm{V}).$$

### 第 3 步 — $M_1$ 导通，$M_2$ 处于线性区：缓慢下降

在略高于 0.7 V 处，$M_1$ 处于饱和区（其漏极电压接近 $V_{DD}$），而 $V_{out} > V_b + 0.8$ V 使 $M_2$ 保持在线性区：

$$\frac{\beta_1}{2}(V_{in} - 0.7)^2 = \frac{V_{DD} - V_{out}}{R_D} + \beta_2\left[(2.2 - V_b)(V_{DD} - V_{out}) - \tfrac12(V_{DD} - V_{out})^2\right].$$

当 $V_{SD2}$ 较小时，$M_2$ 相当于一个电阻

$$R_{on2} = \frac{1}{\beta_2(V_{DD} - V_b - 0.8)} ,$$

它通常远小于 $R_D$。

**斜率。** 令 $r_{ds2} = 1/[\beta_2(2.2 - V_b - V_{SD2})]$，$g_{m1} = \beta_1(V_{in} - 0.7)$，则负载为 $R_D\|r_{ds2}$，且

$$\frac{dV_{out}}{dV_{in}} = -g_{m1}\,(R_D\|r_{ds2}) .$$

这里两个因子都很小（刚导通时的 $g_{m1}$，以及 $R_D\|r_{ds2} \approx R_{on2}$），因此曲线**缓慢下降**；随着 $g_{m1}$ 增大以及 $r_{ds2}$ 随 $V_{SD2}$ 升高，曲线逐渐变陡。

### 第 4 步 — $M_2$ 饱和：陡峭的高增益区

当 $V_{out}$ 降到 $V_b + 0.8$ V 时，$M_2$ 进入饱和区；若此时 $M_1$ 仍处于饱和，该点的 KCL 为

$$
\begin{aligned}
\frac{\beta_1}{2}(V_{in} - 0.7)^2 &= \frac{V_{DD} - (V_b + 0.8)}{R_D} + I_2 = \frac{2.2 - V_b}{R_D} + I_2\\
V_{in} &= 0.7 + \sqrt{\frac{2}{\beta_1}\left[\frac{2.2 - V_b}{R_D} + I_2\right]} .
\end{aligned}
$$

此后 $M_2$ 提供恒定电流 $I_2$：

$$V_{out} = V_{DD} - R_D\left(I_{D1} - I_2\right) = V_{DD} - R_D\left[\tfrac12\beta_1(V_{in} - 0.7)^2 - I_2\right].$$

由于 $\lambda = 0$，饱和的 $M_2$ 对小信号而言相当于开路，因此负载只有 $R_D$：

$$\frac{dV_{out}}{dV_{in}} = -g_{m1}R_D .$$

这是曲线的**陡峭部分**。PMOS 提供了 $M_1$ 的大部分偏置电流，因此 $R_D$ 只流过 $I_{D1} - I_2$，可以取得很大而不会产生很大的直流压降。

### 第 5 步 — $M_1$ 进入线性区：曲线趋于平缓

$M_1$ 在下式处进入线性区：

$$V_{out} = V_{in} - 0.7\ \mathrm{V}, \qquad\text{i.e.}\qquad \frac{\beta_1}{2}(V_{in} - 0.7)^2 = \frac{V_{DD} - (V_{in} - 0.7)}{R_D} + I_2 = \frac{3.7 - V_{in}}{R_D} + I_2 .$$

越过这一点后，$g_{m1} = \beta_1V_{DS1}$ 减小，并出现 $M_1$ 的沟道电导，因此**斜率幅值减小**，曲线趋于平缓并逼近一个较低的值。在 $V_{in} = V_{DD}$ 时：

$$\beta_1\left[2.3V_{out} - \tfrac12V_{out}^2\right] = \frac{3 - V_{out}}{R_D} + I_2 ,$$

该值始终大于 0，因为 $R_D$ 和 $M_2$ 一直在提供电流。

**转折的顺序。** 通常 $M_2$ 先进入饱和区，然后 $M_1$ 进入线性区。若 $V_b$ 较低，$M_1$ 可能在 $V_{out}$ 降到 $V_b + 0.8$ V 之前就达到 $V_{out} = V_{in} - 0.7$ V；这时两个转折的顺序相反，陡峭的 $-g_{m1}R_D$ 段被一段较平缓的曲线取代。

### 第 6 步 — 数值示例

为便于说明，取 $V_b = 1.2$ V，$R_D = 10\ \mathrm{k}\Omega$，$\beta_1 = 2\ \mathrm{mA/V^2}$，$\beta_2 = 0.5\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_2 &= \tfrac12(0.5\ \mathrm{mA/V^2})(2.2 - 1.2)^2\ \mathrm{V^2} = 0.25\ \mathrm{mA},\\
R_{on2} &= \frac{1}{(0.5\ \mathrm{mA/V^2})(1.0\ \mathrm{V})} = 2\ \mathrm{k}\Omega .
\end{aligned}
$$

**$M_2$ 进入饱和区**的位置为 $V_{out} = 1.2 + 0.8 = 2.0$ V，即

$$V_{in} = 0.7 + \sqrt{\frac{2}{2\ \mathrm{mA/V^2}}\left[\frac{1.0\ \mathrm{V}}{10\ \mathrm{k}\Omega} + 0.25\ \mathrm{mA}\right]} = 0.7 + \sqrt{0.35}\ \mathrm{V} = 0.7 + 0.592 = 1.292\ \mathrm{V}.$$

**$M_1$ 进入线性区**的位置：令 $x = V_{in} - 0.7$，则 $\frac12(2\ \mathrm{mA/V^2})x^2 = (3 - x)/(10\ \mathrm{k}\Omega) + 0.25$ mA，即 $x^2 + 0.1x - 0.55 = 0$，因此 $x = (-0.1 + \sqrt{2.21})/2 = 0.693$ V：$V_{in} = 1.393$ V，$V_{out} = 0.693$ V。

### 结果

这是一个**反相**特性，其转折点如下：

- **$V_{in} \le 0.7$ V：** $M_1$ 截止，各处均无电流，$V_{out} = V_{DD}$（$M_2$ 处于线性区，$V_{SD} = 0$）。
- **$M_1$ 导通，$V_{out} > V_b + 0.8$ V：** $M_2$ 处于线性区，相当于一个小电阻（$V_{SD}$ 较小时 $\approx 1/[\beta_2(V_{DD} - V_b - 0.8)]$），与 $R_D$ 并联。$I_{D1} = \frac12\beta_1(V_{in} - 0.7)^2$ 流过这一低阻组合；斜率 $\approx -g_{m1}(R_D\|R_{on2})$，很小。
- **$V_{out} < V_b + 0.8$ V：** $M_2$ 饱和，提供恒定电流 $I_2 = \frac12\beta_2(V_{DD} - V_b - 0.8)^2$；$V_{out} = V_{DD} - R_D(I_{D1} - I_2)$，斜率为 $-g_{m1}R_D$，这是陡峭的高增益段。它始于 $V_{in} = 0.7 + \sqrt{(2/\beta_1)[(2.2 - V_b)/R_D + I_2]}$（前提是此时 $M_1$ 仍处于饱和）。
- **$V_{out} < V_{in} - 0.7$ V：** $M_1$ 进入线性区，进入点满足 $\frac12\beta_1(V_{in} - 0.7)^2 = (3.7 - V_{in})/R_D + I_2$；斜率减小，$V_{out}$ 在 $V_{in} = 3$ V 时趋于一个较低的值。
- 若 $V_b$ 足够低，后两个转折的顺序互换；若 $V_b \ge 2.2$ V，$M_2$ 截止，该级就是普通的电阻负载共源放大器。

**常见错误。** 从一开始就把 $M_2$ 当作电流源，从而在刚过 0.7 V 处就画出陡峭的下降。当 $V_{out}$ 接近 $V_{DD}$ 时，$M_2$ 处于线性区，相当于一个小电阻，因此起始段的下降是平缓的。

**常见错误。** 在 $M_1$ 导通之前就让 $V_{out}$ 降到 $V_{DD}$ 以下。$M_1$ 截止时，没有任何元件从输出端吸取电流，因此恰好有 $V_{out} = V_{DD}$。

**常见错误。** 把 $M_2$ 当作输入器件。它的栅极接固定的 $V_b$；变化的只是它的 $V_{SD}$，由此决定它处于线性区还是饱和区。
