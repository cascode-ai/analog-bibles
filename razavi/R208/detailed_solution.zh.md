# 详细步骤 - R208

**思路。** 在差分半边电路中，尾节点 P 和 $R_1$ 的中点都是虚地，因此 X 到地的电阻为 $R_1/2$。$M_1$ 从 X 抽取的信号电流在 $R_1/2$ 与共源共栅管 $M_3$ 的源极之间分流，只有流过 $M_3$ 的那部分才到达二极管负载 $M_5$。先在 $\lambda = 0$ 时推导这一分流关系，其中计入共源共栅管的体效应（body effect）；然后给出 $\lambda \ne 0$ 时的精确结果。

### 第 1 步 — 半边电路

把左输出端（$M_3$、$M_5$ 的漏极）记为 A。施加 $v_{in1} = +v_{in}$、$v_{in2} = -v_{in}$（因此 $v_{in1} - v_{in2} = 2v_{in}$）；由对称性，X 和 Y 反向变化，因此 P 和 $R_1$ 的中点都是交流地。体效应：$M_1$ 的源极位于虚地 P，$M_5$ 的源极接在其衬底（$V_{DD}$）上，但 $M_3$ 的源极 X 在变化而衬底接地，因此 **$M_3$ 存在体跨导（body-effect transconductance）$g_{mb3}$**。

取 $\lambda = 0$，左半边电路为：

- **$M_1$：** 从 X 抽向地的电流 $g_{m1}v_{in}$。
- **$R_1/2$：** 从 X 接地。
- **$M_3$**（栅极接交流地，源极接 X，漏极接 A）：它从 A 向下流入 X 的电流为 $i_3 = g_{m3}(0 - v_X) + g_{mb3}(0 - v_X) = -(g_{m3} + g_{mb3})v_X$。
- **$M_5$（二极管）：** 从 A 接到交流地的电导 $g_{m5}$。

### 第 2 步 — X 点的基尔霍夫电流定律（KCL）：电流分配

经 $M_1$ 和 $R_1/2$ 流出 X 的电流等于从 $M_3$ 流入的电流：

$$g_{m1}v_{in} + \frac{v_X}{R_1/2} = i_3 = -(g_{m3} + g_{mb3})v_X \quad\Longrightarrow\quad v_X = -\frac{g_{m1}v_{in}}{g_{m3} + g_{mb3} + 2/R_1}.$$

于是流过共源共栅管的电流为

$$i_3 = -(g_{m3} + g_{mb3})v_X = g_{m1}v_{in}\,\frac{g_{m3} + g_{mb3}}{g_{m3} + g_{mb3} + 2/R_1} = g_{m1}v_{in}\,\frac{(g_{m3} + g_{mb3})R_1/2}{1 + (g_{m3} + g_{mb3})R_1/2},$$

这是 $R_1/2$ 与共源共栅管源极电阻 $1/(g_{m3} + g_{mb3})$ 之间的电流分配。

### 第 3 步 — 输出端的 KCL 与增益

$i_3$ 从 A 向下流过 $M_3$，由二极管提供：$i_3 = -g_{m5}v_A$，因此

$$v_A = -\frac{i_3}{g_{m5}} = -\frac{g_{m1}}{g_{m5}}\cdot\frac{(g_{m3} + g_{mb3})R_1/2}{1 + (g_{m3} + g_{mb3})R_1/2}\,v_{in}.$$

右输出变化 $-v_A$，因此 $v_{out} = 2v_A$，而 $v_{in1} - v_{in2} = 2v_{in}$，所以差模增益等于半边电路增益：

$$A_v = \frac{V_{out}}{V_{in1} - V_{in2}} = -\frac{g_{m1}}{g_{m5}}\cdot\frac{(g_{m3} + g_{mb3})R_1/2}{1 + (g_{m3} + g_{mb3})R_1/2}\qquad(\lambda = 0).$$

当 $R_1 \to \infty$ 时，$M_1$ 的电流全部流过共源共栅管，$A_v \to -g_{m1}/g_{m5}$，即二极管负载时的值；当 $R_1 \to 0$ 时，X 被短接到虚地，$A_v \to 0$。

### 第 4 步 — 计入沟道长度调制（channel-length modulation），$\lambda \ne 0$

加入 $r_{O1}$（X 到地）、$r_{O3}$（A 到 X）和 $r_{O5}$（A 到地），并定义

$$R_X = r_{O1}\parallel\frac{R_1}{2}, \qquad Z_L = \frac{1}{g_{m5}}\parallel r_{O5}, \qquad G_3 = g_{m3} + g_{mb3}.$$

X 点的 KCL 给出 $i_3 = g_{m1}v_{in} + v_X/R_X$，共源共栅管给出 $i_3 = -G_3v_X + (v_A - v_X)/r_{O3}$，A 点的 KCL 给出 $v_A = -Z_Li_3$。把 $v_X = R_X(i_3 - g_{m1}v_{in})$ 和 $v_A$ 代入共源共栅管的方程：

$$
\begin{aligned}
i_3 &= -\left(G_3 + \frac{1}{r_{O3}}\right)R_X(i_3 - g_{m1}v_{in}) - \frac{Z_L}{r_{O3}}i_3\\
i_3\left[r_{O3} + (1 + G_3r_{O3})R_X + Z_L\right] &= g_{m1}v_{in}(1 + G_3r_{O3})R_X .
\end{aligned}
$$

因此

$$A_v = \frac{v_A}{v_{in}} = -\frac{g_{m1}Z_L(1 + G_3r_{O3})R_X}{r_{O3} + (1 + G_3r_{O3})R_X + Z_L}\ \approx\ -g_{m1}\left(\frac{1}{g_{m5}}\parallel r_{O5}\right)\frac{G_3R_X}{1 + G_3R_X},$$

该近似在 $G_3r_{O3} \gg 1$ 且 $r_{O3} \gg Z_L$ 时成立。在一阶近似下，$\lambda$ 的作用只是把 $R_1/2$ 换成 $R_1/2\parallel r_{O1}$，把 $1/g_{m5}$ 换成 $1/g_{m5}\parallel r_{O5}$。

**数值感受**（$\lambda = 0$）：$g_{m1} = g_{m3} = 0.632$ mS，$g_{mb3} = 0.13$ mS，$g_{m5} = 0.447$ mS，$R_1 = 5\ \mathrm{k}\Omega$：

$$
\begin{aligned}
(g_{m3} + g_{mb3})\frac{R_1}{2} &= (0.762\ \mathrm{mS})(2.5\ \mathrm{k}\Omega) = 1.905,\\
A_v &= -\frac{0.632}{0.447}\cdot\frac{1.905}{2.905} = -1.414\times0.656 = -0.93 .
\end{aligned}
$$

### 结果

当 $\lambda = 0$ 时：

$$A_v = \frac{V_{out}}{V_{in1} - V_{in2}} = -\frac{g_{m1}}{g_{m5}}\cdot\frac{(g_{m3} + g_{mb3})R_1/2}{1 + (g_{m3} + g_{mb3})R_1/2}.$$

在半边电路中，$R_1$ 的中点是虚地，因此 X 看到的是 $R_1/2$。$M_1$ 抽取的电流 $g_{m1}v_{in}$ 在 $R_1/2$ 与共源共栅管 $M_3$ 的源极之间分流，后者的输入电阻为 $1/(g_{m3} + g_{mb3})$；只有流过 $M_3$ 的那部分才到达二极管负载 $1/g_{m5}$。当 $\lambda \ne 0$ 时，近似地把 $R_1/2$ 换成 $R_1/2\parallel r_{O1}$，把 $1/g_{m5}$ 换成 $1/g_{m5}\parallel r_{O5}$（精确形式见第 4 步）。当 $R_1 \to \infty$ 时，增益趋近 $g_{m1}/g_{m5}$；当 $R_1 \to 0$ 时，增益趋于零。

**常见错误。** 认为增益为 $g_{m1}/g_{m5}$，与 $R_1$ 无关。$R_1$ 在 X 点提供了第二条通路（经其处于虚地的中点），信号电流在这条通路与共源共栅管之间分流。

**常见错误。** 把 $R_1$ 当作输入对管的源极负反馈（source degeneration），例如写出 $g_{m1}/(1 + g_{m1}R_1/2)$。$R_1$ 连接的是 $M_1$ 和 $M_2$ 的**漏极**；在 $\lambda = 0$ 时，它不改变 $M_1$ 的电流，只是把这一电流从共源共栅管分走一部分。

**常见错误。** 用 $R_1$ 代替 $R_1/2$，或者漏掉 $g_{mb3}$。每半边只看到电阻的一半；而共源共栅管的源极在变化、衬底却接地，这使其源极电导提高到 $g_{m3} + g_{mb3}$。
