当 λ = 0 时：$A_v = -\dfrac{g_{m1}}{g_{m5}}\cdot\dfrac{(g_{m3} + g_{mb3})R_1/2}{1 + (g_{m3} + g_{mb3})R_1/2}$。
- 半边电路（half circuit）：$R_1$ 的中点是虚地（virtual ground），因此节点 X 到地的电阻为 $R_1/2$。$M_1$ 从 X 抽取的小信号电流 $g_{m1}v_{in}$ 在 $R_1/2$ 与共源共栅管 $M_3$ 的源极（λ = 0 时其输入电阻为 $1/(g_{m3} + g_{mb3})$）之间分流；只有流过 $M_3$ 的那部分才到达二极管负载 $1/g_{m5}$。
- $v_{out,half} = -g_{m1}v_{in}\,\dfrac{R_1/2}{R_1/2 + 1/(g_{m3}+g_{mb3})}\cdot\dfrac{1}{g_{m5}}$，差模增益等于半边电路增益。
- 当 λ ≠ 0 时，近似地把 $R_1/2$ 换成 $R_1/2\|r_{O1}$，把 $1/g_{m5}$ 换成 $1/g_{m5}\|r_{O5}$。当 $R_1 \to \infty$ 时，增益趋近 $g_{m1}/g_{m5}$；当 $R_1 \to 0$ 时，增益趋于零。
