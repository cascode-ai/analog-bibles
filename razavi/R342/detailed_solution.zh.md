# 详细步骤 - R342

**思路。** 把 $M_1$ 与 $M_2$ 之间的节点记为 X。由于 $\lambda = 0$，$M_1$ 和 $M_3$ 是 X 点的理想电流源，因此由 X 点的基尔霍夫电流定律（KCL），共源共栅管 $M_2$ 送到输出端的电流完全由它们决定；$M_2$ 自身的噪声只能改变 $v_X$。写出输出电压，并把剩下的每个噪声项折算到输入端。

### 第 1 步 — 小信号模型（small-signal model）

- **$M_1$：** 从 X 流向地的电流 $g_{m1}v_{in}$，与 $v_X$ 无关，其沟道噪声 $I_{n1}$（$\overline{I_{n1}^2} = 4kT\gamma g_{m1}$）与之并联。
- **$M_3$**（栅极接固定的 $V_{b1}$）：没有小信号电流，输出电阻（output resistance）为无穷大；只剩下其噪声 $I_{n3}$（$\overline{I_{n3}^2} = 4kT\gamma g_{m3}$），从 $V_{DD}$ 流入 X。
- **$M_2$**（栅极接交流地）：从输出端流向 X 的电流 $g_{m2}(0 - v_X)$，其噪声 $I_{n2}$（$\overline{I_{n2}^2} = 4kT\gamma g_{m2}$）与之并联。
- **$R_D$：** 接在输出端与交流地之间，其诺顿噪声 $I_{nD}$（$\overline{I_{nD}^2} = 4kT/R_D$）从 $V_{DD}$ 流入输出端。

### 第 2 步 — 节点 X 的 KCL：$M_2$ 承载的电流

从 $M_2$ 和 $M_3$ 流入 X 的电流经 $M_1$ 流出：

$$\underbrace{-g_{m2}v_X + I_{n2}}_{i_{M2}} + I_{n3} = g_{m1}v_{in} + I_{n1}.$$

因此流过 $M_2$ 的总小信号电流为

$$i_{M2} = g_{m1}v_{in} + I_{n1} - I_{n3},$$

其中既不含 $I_{n2}$，也不含 $v_X$。$I_{n2}$ 只决定 X 点的电压：

$$v_X = \frac{I_{n2} + I_{n3} - g_{m1}v_{in} - I_{n1}}{g_{m2}}.$$

$M_2$ 的噪声只在局部环流：它把 X 点电压推高，直到 $-g_{m2}v_X$ 抵消 $I_{n2}$ 为止。同样，在直流下 $M_2$ 中的电流为 $I_{D1} - |I_{D3}|$，完全由 X 点的两个电流源决定。

### 第 3 步 — 输出端的 KCL

$i_{M2}$ 全部来自 $R_D$ 支路：

$$\frac{0 - v_{out}}{R_D} + I_{nD} = i_{M2} = g_{m1}v_{in} + I_{n1} - I_{n3},$$

$$v_{out} = -g_{m1}R_D\,v_{in} - R_D(I_{n1} - I_{n3}) + R_DI_{nD}.$$

增益为

$$A_v = \frac{v_{out}}{v_{in}} = -g_{m1}R_D :$$

$M_3$ 不分走 $M_1$ 的任何信号电流，因此信号电流全部到达 $R_D$。

### 第 4 步 — 把噪声折算到输入端

剩下的三个噪声源（$M_1$、$M_3$、$R_D$）互不相关，每个都以系数 $\pm R_D$ 出现在输出端：

$$\overline{V_{n,out}^2} = R_D^2\left(4kT\gamma g_{m1} + 4kT\gamma g_{m3} + \frac{4kT}{R_D}\right).$$

除以 $A_v^2 = g_{m1}^2R_D^2$：

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \frac{4kT\gamma g_{m1} + 4kT\gamma g_{m3} + 4kT/R_D}{g_{m1}^2}\\
&= 4kT\left(\frac{\gamma}{g_{m1}} + \frac{\gamma g_{m3}}{g_{m1}^2} + \frac{1}{g_{m1}^2R_D}\right).
\end{aligned}
$$

各项分别来自 $M_1$、$M_3$（其噪声直接向上经 $M_2$ 到达 $R_D$，就像负载电流源的噪声一样）和 $R_D$；$M_2$ 的贡献为**零**。

### 第 5 步 — 设计说明

$M_3$ 提供了 $M_1$ 的一部分偏置电流，因此 $M_1$ 可以工作在大电流下（$g_{m1}$ 大），而 $R_D$ 只承载 $I_{D1} - |I_{D3}|$；于是可以用更大的 $R_D$，既提高增益又减小 $R_D$ 项。代价是多出 $4kT\gamma g_{m3}/g_{m1}^2$ 这一项，这要求 $M_3$ 在给定电流下具有小的 $g_{m3}$，即大的过驱动电压（overdrive voltage）。

### 结果

$$\overline{V_{n,in}^2} = 4kT\left(\frac{\gamma}{g_{m1}} + \frac{\gamma g_{m3}}{g_{m1}^2} + \frac{1}{g_{m1}^2R_D}\right)$$

$M_2$ 没有任何贡献。由于 $\lambda = 0$，$M_1$ 和 $M_3$ 决定了流过 $M_2$ 的电流（$i_{M2} = g_{m1}v_{in} + I_{n1} - I_{n3}$），因此 $M_2$ 的噪声只改变 $v_X$。增益为 $-g_{m1}R_D$，$M_3$ 的噪声表现得像电流源负载的噪声。

**常见错误。** 因为 $M_3$ 只提供偏置电流，就把它当作无噪声元件。它的噪声注入 X，而 $M_1$ 是理想电流源，因此这些噪声全部经 $M_2$ 流入 $R_D$。

**常见错误。** 为共源共栅管 $M_2$ 计入噪声项。它下方的节点只由理想电流源驱动，因此无论其自身噪声如何，它的电流都是确定的；即使计入 $g_{mb2}$ 或 $r_{O2}$ 也是如此，因为它们同样只作用于输出端与 X 之间。

**常见错误。** 让 $M_1$ 的信号电流在 $M_2$ 与 $M_3$ 之间分流，例如把 $M_3$ 当作接到交流地的电阻 $1/g_{m3}$。$M_3$ 的栅源电压固定、输出电阻为无穷大，因此它不承载信号电流，增益就是 $g_{m1}R_D$。
