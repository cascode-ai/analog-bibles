$$\overline{V_{n,in}^2} = 4kT\left(\frac{\gamma}{g_{m1}} + \frac{\gamma g_{m3}}{g_{m1}^2} + \frac{1}{g_{m1}^2R_D}\right)$$
$M_2$ 没有任何贡献。

- 由于 λ = 0，$M_1$ 和 $M_3$ 是节点 X 上的理想电流源，因此流过 $M_2$（以及 $R_D$）的电流由它们决定：$I_{M2} = I_{D1} - |I_{D3}|$，再加上小信号分量 $g_{m1}V_{in} + I_{n1} - I_{n3}$。$M_2$ 自身的噪声电流只能改变 $V_X$，而不能改变 $R_D$ 中的电流。
- $V_{out} = -R_D(g_{m1}V_{in} + I_{n1} - I_{n3}) + R_DI_{n,RD}$；增益为 $-g_{m1}R_D$；$M_3$ 的噪声表现得像负载电流源的噪声：$4kT\gamma g_{m3}/g_{m1}^2$。
- 设计说明：$M_3$ 注入的电流使 $M_1$ 可以工作在大电流下（$g_{m1}$ 大），而 $R_D$ 承载的直流电流较小；代价是多出 $g_{m3}$ 这一项。
