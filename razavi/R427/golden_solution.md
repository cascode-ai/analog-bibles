# Golden Solution - R427

## Reference answer

$\overline{V^2_{n,in}} \approx 8kT\cdot\tfrac23\left(\dfrac{1}{g_{m1}} + \dfrac{g_{m7}}{g_{m1}^2}\right) \approx 6.6\times10^{-18}\ \mathrm{V^2/Hz}$, i.e. ≈ 2.6 nV/√Hz.

- Only the input pair ($M_1$, $M_2$) and the PMOS mirror current sources ($M_7$, $M_8$) contribute significantly; the cascode devices $M_3$–$M_6$ are degenerated by high impedances and contribute negligibly at low frequencies.
- $g_{m1} = 5.18$ mS ($1/g_{m1} = 193\ \Omega$); $g_{m7} = 2(0.5\ \mathrm{mA})/0.35\ \mathrm{V} = 2.86$ mS ($g_{m7}/g_{m1}^2 = 107\ \Omega$).
- $8kT\cdot\tfrac23 = 2.21\times10^{-20}$ J; times $300\ \Omega$ gives $6.6\times10^{-18}\ \mathrm{V^2/Hz}$ → 2.57 nV/√Hz.

## Grading notes

+2: the expression $8kT\gamma(1/g_{m1} + g_{m7}/g_{m1}^2)$ (γ = 2/3, the thermal-noise factor; the given γ = 0 is the body-effect coefficient) with the cascodes neglected, and a value of 2.4–2.8 nV/√Hz (or 5.8–7.6 × 10⁻¹⁸ V²/Hz); also +2 if the cascode contributions are kept with correct (tiny, $r_o$-dependent) weights and the same value results. +1: right expression and contributors with a small numerical slip that keeps the value near the range. 0: right contributors with a slip that moves the value well outside the range, a factor-of-2 error (e.g., 4kT instead of 8kT), or only the input pair counted. -2 (asserted as fact): cascode devices claimed to contribute as much as the input pair, the PMOS term referred with the wrong ratio (e.g., $1/g_{m7}$), or a value off by an order of magnitude.
