设 X 为 $M_2$ 的源极（$M_1$ 的漏极）。

极低频（$C_1$、$C_2$ 开路）：$R_1$ 中没有直流电流，因此 $M_1$ 的栅极电压等于 X 点电压，$M_1$ 为二极管连接（diode-connected），$R_X = (1/g_{m1})\|r_{O1}$；$M_3$ 的栅极接 $V_b$（交流地），因此 $M_3$ 是电流源（current source），其电阻为 $r_{O3}$。$M_2$ 是带源极负反馈（source degeneration）的共源级（common-source stage）：
$$A_{v,low} = -\frac{g_{m2}r_{O2}r_{O3}}{r_{O2} + r_{O3} + (1 + g_{m2}r_{O2})R_X} = -\frac{g_{m2}r_{O2}r_{O3}(1 + g_{m1}r_{O1})}{r_{O1} + r_{O2} + r_{O3} + g_{m1}r_{O1}(r_{O2} + r_{O3}) + g_{m2}r_{O1}r_{O2}}$$
≈ $-\dfrac{g_{m2}r_{O3}}{1 + g_{m2}/g_{m1} + r_{O3}/r_{O2}}$，即当 $r_{O2} \gg r_{O3}$ 时约为 $-\dfrac{g_{m1}g_{m2}}{g_{m1}+g_{m2}}r_{O3}$。

极高频（$C_1$、$C_2$ 短路）：$C_1$ 把 $M_1$ 的栅极接地（使其成为电阻为 $r_{O1}$ 的电流源），$R_1$ 此时把 X 接到交流地；$C_2$ 把 $M_3$ 的栅极接到 X，因此 $R_2$（接到 $V_b$）也成为 X 点的负载，而 $M_3$ 变为由 $v_X$ 驱动的第二个跨导器（transconductor）。记 $R_X' = r_{O1}\|R_1\|R_2$：
$$A_{v,high} = -\frac{g_{m2}r_{O3}\,(g_{m3} + 1/R_X')}{g_{m2} + 1/R_X' + 1/r_{O2} + (r_{O3}/r_{O2})(g_{m3} + 1/R_X')} \approx -g_{m2}r_{O3}\frac{1 + g_{m3}R_X'}{1 + g_{m2}R_X'}\ (r_{O2} \to \infty)$$
当 $g_{m2}R_X' \gg 1$ 时，它趋于 $-g_{m3}r_{O3}$：X 跟随输入变化，而 $M_3$ 的驱动与 $M_2$ 的电流反相，提供了推挽（push–pull）贡献，因此增益远高于其低频值。
