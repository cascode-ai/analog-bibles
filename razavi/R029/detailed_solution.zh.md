# 详细步骤 - R029

**思路。** $M_1$（栅极固定在 2 V）把充电到 3 V 的 $C_1$ 与空的 $C_2$ 连接起来。电流从 $C_1$ 经 $M_1$ 流入 $C_2$，因此 $V_X$ 下降，源极电压 $V_S$ 上升，总电荷守恒。电荷转移在以下两种情况之一发生时停止：$V_S$ 升高到 $2\ \mathrm{V} - V_{TH}$ 使 $M_1$ 截止，或者 $V_X$ 与 $V_S$ 先变得相等。计入体效应，求出初始电流、区分两种情况的条件以及最终电压。

### 第 1 步 — 电荷守恒

把源极节点（$C_2$ 的上极板）记为 S；衬底接地，因此 $V_{SB} = V_S$。流出 $C_1$ 的电流经过 $M_1$ 到达 $C_2$：

$$I_X = -C_1\frac{dV_X}{dt} = C_2\frac{dV_S}{dt} .$$

从 $t = 0$ 开始积分，从 $C_1$ 移走的电荷等于加到 $C_2$ 上的电荷：

$$C_1\,(3 - V_X) = C_2\,V_S \quad\Longrightarrow\quad V_X = 3 - \frac{C_2}{C_1}V_S .$$

令 $r = C_2/C_1$，并计入体效应，

$$V_{TH}(V_S) = 0.7 + 0.45\left(\sqrt{0.9 + V_S} - 0.9487\right)\ \mathrm{V}.$$

### 第 2 步 — 初始电流

在 $t = 0^+$ 时：$V_X = 3$ V，$V_S = 0$，$V_{GS} = 2$ V，$V_{DS} = 3$ V，$V_{TH} = 0.7$ V。$V_{DS} = 3\ \mathrm{V} > V_{ov} = 1.3$ V，因此 $M_1$ 处于**饱和区**，电流从零跳变到

$$I_X(0^+) = \tfrac12\beta\,(2 - 0.7)^2 = \tfrac12\beta\,(1.3\ \mathrm{V})^2 = 0.845\,\beta\ \mathrm{V^2}.$$

### 第 3 步 — 电流如何变化

随着电荷转移，$V_{GS} = 2 - V_S$ 下降，$V_{TH}(V_S)$ 上升（源极电位升到接地衬底之上），在线性区 $V_{DS} = V_X - V_S$ 也会减小。所以 **$I_X$ 从 $0.845\beta$ 单调下降到零**，比阈值电压（threshold voltage）恒定时下降得更快。$M_1$ 处于饱和区的条件是

$$V_X - V_S \ge 2 - V_S - V_{TH} \quad\Longleftrightarrow\quad V_X \ge 2 - V_{TH}(V_S).$$

### 第 4 步 — 源极的截止电平

若 $M_1$ 保持饱和，它会一直导通，直到 $V_{GS}$ 降到 $V_{TH}$：

$$2 - V_S = V_{TH}(V_S) = 0.7 + 0.45\sqrt{0.9 + V_S} - 0.4269 .$$

令 $u = \sqrt{0.9 + V_S}$：

$$
\begin{aligned}
2 - (u^2 - 0.9) &= 0.2731 + 0.45u\\
u^2 + 0.45u - 2.6269 &= 0\\
u &= \frac{-0.45 + \sqrt{0.2025 + 10.5076}}{2} = \frac{-0.45 + 3.2726}{2} = 1.4113\\
V_{S,\mathrm{off}} &= u^2 - 0.9 = 1.9918 - 0.9 = 1.09\ \mathrm{V}.
\end{aligned}
$$

此时 $V_{TH} = 0.91$ V（若没有体效应，则为 $2 - 0.7 = 1.3$ V）。在饱和区，电流按不断减小的过驱动电压（overdrive voltage）的**平方**趋于零，因此这一电平是**渐近**达到的，带有缓慢的（双曲线型，$\propto 1/t$）拖尾，就像源极跟随器（source follower）对电容充电一样。

### 第 5 步 — 以哪种方式结束：电容比

**情形 1：$M_1$ 在饱和状态下截止。** 截止时 $V_S = 1.09$ V，由电荷守恒得

$$V_{X,\mathrm{final}} = 3 - 1.09\,r\ \mathrm{V}.$$

为了自洽，$M_1$ 在该点必须仍处于饱和区，即 $V_X \ge 2 - V_{TH}(1.09) = 1.09$ V：

$$
\begin{aligned}
3 - 1.09\,r &\ge 1.09\\
r &\le \frac{3 - 1.09}{1.09} = 1.75 .
\end{aligned}
$$

只需检查终点即可：$V_X - [2 - V_{TH}(V_S)]$ 是关于 $V_S$ 的向下凹（concave down）函数，因此若它在 $V_S = 0$ 和 $V_S = 1.09$ V 处都为正，则在两者之间也为正。所以当 **$C_2 < 1.75\,C_1$** 时，$V_S \to 1.09$ V，$V_X \to 3 - 1.09\,C_2/C_1$，此时 $M_1$ 刚好截止，$V_X$ 仍高于 $V_S$。

**情形 2：两个节点电压相等。** 当 **$C_2 > 1.75\,C_1$** 时，$V_X$ 在 $V_S$ 达到 1.09 V 之前就与 $V_S$ 相遇。$M_1$ 进入线性区并一直导通到 $V_{DS} = 0$，即 $V_X = V_S = V_f$，这就是普通的电荷分享：

$$
\begin{aligned}
C_1\,(3 - V_f) &= C_2V_f\\
V_f &= \frac{3C_1}{C_1 + C_2} .
\end{aligned}
$$

验证：$V_f < 1.09$ V 恰好等价于 $3/(1 + r) < 1.09$，即 $r > 1.75$，因此两个节点相遇时 $M_1$ 仍然导通（$V_{GS} = 2 - V_f > V_{TH}(V_f)$）。趋近过程是一个类指数的线性区拖尾。

### 第 6 步 — 两个示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF，因此初始电流为 0.845 mA，自然时间尺度为 $C_1/(\beta\cdot1\ \mathrm{V}) = 1$ ns。

**$C_2 = C_1$（$r = 1$，情形 1）。** 最终 $V_S = 1.09$ V，$V_X = 3 - 1.09 = 1.91$ V。

| $t$ (ns) | $V_X$ (V) | $V_S$ (V) | $I_X$ (mA) |
|---|---|---|---|
| 0⁺ | 3.00 | 0 | 0.845 |
| 0.5 | 2.70 | 0.30 | 0.43 |
| 1 | 2.53 | 0.47 | 0.27 |
| 2 | 2.34 | 0.66 | 0.13 |
| 5 | 2.14 | 0.86 | 0.036 |
| 20 | 1.98 | 1.02 | 0.003 |
| ∞ | 1.91 | 1.09 | 0 |

**$C_2 = 3C_1$（$r = 3$，情形 2）。** $V_f = 3/(1 + 3) = 0.75$ V。$M_1$ 大约在 4.7 ns 后离开饱和区（$V_X \approx 1.2$ V，$V_S \approx 0.6$ V），两个节点在约 20 ns 内稳定在 0.75 V，同时 $I_X$ 衰减到零。

### 结果

$M_1$ 把电荷从 $C_1$ 转移到 $C_2$，满足 $C_1(3 - V_X) = C_2V_S$。

- $I_X$ 在 $t = 0^+$ 时跳变到 $\tfrac12\beta(2 - 0.7)^2 = 0.845\beta$（饱和区，$V_S = 0$ 时 $V_{GS} = 2$ V，$V_{TH} = 0.7$ V），然后**单调下降到零**。体效应（$V_{SB} = V_S$）使衰减加快。
- $V_X$ 从 3 V 下降，而 $V_S$ 从 0 上升。
- **情形 1，$C_2 < 1.75\,C_1$：** $M_1$ 保持饱和，并在 $V_S \to 2 - V_{TH}(V_S) = 1.09$ V 时截止（渐近地，带有平方律拖尾；不计体效应时为 1.3 V）。最终 $V_X = 3 - 1.09\,C_2/C_1$ V。
- **情形 2，$C_2 > 1.75\,C_1$：** $V_X$ 先降到 $V_S$；$M_1$ 最终处于线性区，$V_{DS} \to 0$，两个节点都稳定在 $3C_1/(C_1 + C_2)$（简单的电荷分享）。

**常见错误。** 让 $C_1$ 放电到 0 V，好像 $M_1$ 的源极接地一样。源极是 $C_2$ 上的节点 S，它会被充电，最终电压由电荷守恒确定。

**常见错误。** 总是预测电荷分享，或者总是预测在 1.09 V 处截止。究竟哪种机制使电荷转移停止，取决于 $C_2/C_1$ 与 1.75 的比较。

**常见错误。** 把 $I_X$ 画成随时间增大。$V_{GS}$ 下降、$V_{TH}$ 上升和 $V_{DS}$ 减小都会减小电流，因此其最大值出现在 $t = 0^+$。
