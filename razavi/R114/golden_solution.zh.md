$A_v = -\dfrac{g_{m1}r_{O1}r_{O2}(1 + g_{m2}R_S)}{r_{O1} + r_{O2} + R_S(1 + g_{m1}r_{O1} + g_{m2}r_{O2})}$。

- 节点 $S$ = $M_1$ 的源极 = $R_S$ 的上端 = $M_2$ 的栅极（PMOS，源极接 $V_{DD}$，漏极接输出端）。
- $M_1$ 的电流（输出端 → $S$）：$i_1 = g_{m1}(v_{in} - v_S) + (v_{out} - v_S)/r_{O1} = v_S/R_S$。
- 输出节点：$-g_{m2}v_S - v_{out}/r_{O2} = i_1$ → $v_S = -v_{out}R_S/[r_{O2}(1 + g_{m2}R_S)]$；代入即得上述结果。
- 等价地，$A_v = -G_mR_{out}$，其中输出电阻（output resistance）很大；当 $r_O$ 很大时，增益的量级为 $g_{m1}(1 + g_{m2}R_S)r_{O2}r_{O1}/[R_S(g_{m1}r_{O1} + g_{m2}r_{O2})]$，即增益很高。
