# 详细步骤 - R188

**思路。** 两个输入连在一起，因此激励是纯共模（common-mode）的，对称电路两边的电压完全相同。于是电阻串 $R_1$–$R_2$ 中没有电流，$V_{out} = V_X - V_Y$ 始终为零。两个输出的共同电平确实会变化，跟踪它只是作为检验。

### 第 1 步 — 由基尔霍夫电流定律（KCL）得到对称解

把左输出端（$M_1$、$M_3$ 的漏极）记为 X，右输出端（$M_2$、$M_4$ 的漏极）记为 Y，$R_1$ 与 $R_2$ 的连接点（即 PMOS 的栅极）记为 N，$M_1$、$M_2$ 的公共源极节点记为 P。在整个扫描过程中 $V_{in1} = V_{in2} = V_{in,CM}$。

栅极不吸取电流，因此从 X 经 $R_1$ 流到 N 的电流 $I_R$ 会继续从 N 经 $R_2$ 流到 Y：

$$I_R = \frac{V_X - V_N}{R_1} = \frac{V_N - V_Y}{R_2}.$$

试取 $V_X = V_Y$。由于 $R_1 = R_2$，这给出 $V_N = V_X = V_Y$ 和 $I_R = 0$。于是 $M_3$ 和 $M_4$ 的栅极电压（N）、源极电压（$V_{DD}$）和漏极电压都相同，因此 $I_{D3} = I_{D4}$；$M_1$ 和 $M_2$ 的栅极电压（$V_{in,CM}$）、源极电压（$V_P$）和漏极电压也都相同，因此 $I_{D1} = I_{D2} = I_{D5}/2$。X 点的 KCL（$I_{D3} = I_{D1} + I_R$）和 Y 点的 KCL（$I_{D4} + I_R = I_{D2}$）化为同一个方程 $I_{D3} = I_{D1}$。即使 $\lambda = 0$，这个对称解也是唯一的，因为共同电平是被固定的（见第 2 步）。因此

$$V_X = V_Y \quad\Longrightarrow\quad V_{out} = 0\ \text{for every } V_{in,CM}.$$

由于 $R_1$ 和 $R_2$ 中没有电流，每个 PMOS 的栅极都处于其自身的漏极电位，因此对共模信号而言，$M_3$ 和 $M_4$ 是**二极管连接**（diode-connected）的：两半边是完全相同的、以二极管连接器件为负载的放大级，由同一个输入驱动。

### 第 2 步 — 输出的共同电平（仅供参考）

每个等效为二极管连接的 PMOS 都通过其电流 $I_{D3} = I_{D5}/2$ 确定输出电平：

$$V_X = V_Y = V_{DD} - |V_{GS3}|, \qquad |V_{GS3}| = |V_{THP}| + \sqrt{\frac{2I_{D3}}{\beta_p}}, \qquad \beta_p = \mu_pC_{ox}\left(\frac WL\right)_{3,4}.$$

示例设计（尺寸可自由选取）：$\beta_n = \mu_nC_{ox}(W/L)_{1,2} = 2\ \mathrm{mA/V^2}$，$\beta_p = 2.22\ \mathrm{mA/V^2}$，$V_b = 1$ V，$\mu_nC_{ox}(W/L)_5 = 4.44\ \mathrm{mA/V^2}$，于是

$$I_{SS} = \tfrac12(4.44\ \mathrm{mA/V^2})(1 - 0.7)^2\ \mathrm{V^2} = 200\ \mu\mathrm{A}.$$

**(a) $V_{in,CM} < V_{THN} = 0.7$ V：差分对截止。** 不流过电流的二极管连接 PMOS 只要求 $|V_{GS3}| \le |V_{THP}|$，因此在平方律模型中，输出可以位于 $V_{DD} - |V_{THP}| = 2.2$ V 与 $V_{DD} = 3$ V 之间的任何位置。在实际器件中，只要 $V_{SG} > 0$，亚阈值导电就会持续给输出充电，因此电平向 $V_{DD}$ 漂移，只受漏电流限制。

**(b) 差分对导通，尾电流管处于线性区（triode region）。** 刚超过 0.7 V 时，$V_P$ 很小，$M_5$ 处于线性区，尾电流随 $V_{in,CM}$ 增大。每个 PMOS 流过 $I_{D5}/2$，因此输出从约 $V_{DD} - |V_{THP}|$ 开始，随电流增大而下降。

**算例：$V_{in,CM} = 1.0$ V。** 对 P 点列 KCL（$M_5$ 处于线性区），并利用 $M_1$ 饱和的条件：

$$
\begin{aligned}
2I_{D1} &= (4.44\ \mathrm{mA/V^2})\left[0.3V_P - \tfrac12V_P^2\right],\\
I_{D1} &= \tfrac12(2\ \mathrm{mA/V^2})(1.0 - V_P - 0.7)^2 .
\end{aligned}
$$

由此得 $V_P = 0.082$ V，$I_{D1} = (1\ \mathrm{mA/V^2})(0.218\ \mathrm{V})^2 = 47.4\ \mu$A（验证：$(4.44\ \mathrm{mA/V^2})(0.3\times0.082 - 0.5\times0.082^2) = 94.8\ \mu\mathrm{A} = 2I_{D1}$ ✓）。于是

$$
\begin{aligned}
|V_{GS3}| &= 0.8 + \sqrt{\frac{2(47.4\ \mu\mathrm{A})}{2.22\ \mathrm{mA/V^2}}} = 0.8 + \sqrt{0.0427}\ \mathrm{V} = 0.8 + 0.207 = 1.007\ \mathrm{V},\\
V_X = V_Y &= 3 - 1.007 = 1.99\ \mathrm{V}.
\end{aligned}
$$

**(c) 尾电流管饱和。** $M_1$ 以 $I_{SS}/2$ 饱和，当输入满足下式时，$V_P$ 达到 $V_b - V_{THN} = 0.3$ V，尾电流管提供 $I_{SS}$：

$$V_{in,CM} = V_P + V_{THN} + \sqrt{\frac{2(I_{SS}/2)}{\beta_n}} = 0.3 + 0.7 + \sqrt{\frac{2(100\ \mu\mathrm{A})}{2\ \mathrm{mA/V^2}}} = 1.32\ \mathrm{V}.$$

此后每个 PMOS 都流过 $I_{SS}/2$，输出电平保持不变：

$$V_X = V_Y = V_{DD} - |V_{THP}| - \sqrt{\frac{I_{SS}}{\beta_p}} = 3 - 0.8 - \sqrt{\frac{200\ \mu\mathrm{A}}{2.22\ \mathrm{mA/V^2}}} = 3 - 0.8 - 0.3 = 1.9\ \mathrm{V}.$$

在 $V_{in,CM} = V_X + V_{THN} = 2.6$ V 以上，输入器件进入线性区，但饱和的尾电流管仍迫使每个输入器件流过 $I_{SS}/2$，因此电平不变。

| $V_{in,CM}$ (V) | 状态 | $V_X = V_Y$ (V) | $V_{out}$ (V) |
|---|---|---|---|
| 0 到 0.7 | 差分对截止 | 介于 2.2 与 3.0 之间（向 3.0 漂移） | 0 |
| 0.8 | 差分对导通，尾电流管处于线性区 | 2.12 | 0 |
| 1.0 | 同上 | 1.99 | 0 |
| 1.2 | 同上 | 1.92 | 0 |
| ≥ 1.32 | 尾电流管饱和 | 1.90 | 0 |

### 结果

$$V_{out} = 0 \quad\text{for the whole sweep } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

电路是对称的，因此两个输出完全相同，$R_1$、$R_2$ 中没有电流；草图就是一条落在横轴上的水平线。作为参考，输出的共同电平，即等效为二极管连接的负载所确定的 $V_{DD} - |V_{GS3}|$：

- 差分对截止时，介于 $V_{DD} - |V_{THP}|$（平方律极限）与 $V_{DD}$（亚阈值导电）之间；
- 差分对导通后逐渐下降；
- 尾电流管饱和后稳定在 $V_{DD} - |V_{GS3}(I_{SS}/2)|$。

**常见错误。** 画出某一个输出的电压（即共同电平，例如从约 2.2 V 下降到 1.9 V），并把它当作 $V_{out}$。题目要求的是 $V_X - V_Y$，它为零。

**常见错误。** 给出随共模输入变化的非零 $V_{out}$，例如认为电平变化时 $R_1$ 和 $R_2$ 中有电流流过。两个输出完全相同时，电阻串两端没有电压，因此其中没有电流。
