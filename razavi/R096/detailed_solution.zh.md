# 详细步骤 - R096

思路： $M_1$ 是共栅（CG）器件：其栅极接 $V_{b1}$，输入经 $R_S$ 到达其源极。它的负载是 PMOS 电流源 $M_2$。同一电流流过 $M_2$、$M_1$ 和 $R_S$，因此两个晶体管相当于两个串联的电流源：能流过的电流较小的那个决定电流并保持饱和，另一个则被迫进入线性区。求出在 $V_{in}$ 的各个范围内哪个器件起决定作用、二者相持时的输入 $V_{in}^*$（此处增益极大），以及曲线的端点。

### 第 1 步 — 各端电压与工作区边界

设串联电流为 $I$，并把 $M_1$ 的源极节点记为 $S$：

$$V_S = V_{in} + IR_S, \qquad V_{GS1} = V_{b1} - V_S, \qquad V_{SB1} = V_S ,$$

$$V_{TH1} = V_{TH}(V_S) = 0.7 + 0.45\left(\sqrt{0.9 + V_S} - \sqrt{0.9}\right)\ \mathrm{V}.$$

题目没有给出 $\lambda$；先取 $\lambda = 0$，并在第 4 步讨论 $\lambda > 0$ 的情况。

$M_2$ 的栅极驱动固定为 $V_{SG2} = V_{DD} - V_{b2}$，饱和电流为

$$I_2 = \frac12\beta_2(V_{DD} - V_{b2} - 0.8)^2 ,$$

当 $V_{out} \le V_{b2} + 0.8$ V 时它处于饱和区（高于此值时处于线性区）。

$M_1$ 在 $V_{out} - V_S \ge V_{b1} - V_S - V_{TH1}$，即 $V_{out} \ge V_{b1} - V_{TH1}$ 时处于饱和区（低于此值时处于线性区）。

### 第 2 步 — $M_1$ 能流过的电流

在饱和区，

$$I_{1,sat} = \frac12\beta_1\left(V_{b1} - V_S - V_{TH}(V_S)\right)^2, \qquad V_S = V_{in} + IR_S .$$

提高 $V_{in}$ 会使 $V_S$ 升高，既减小 $V_{GS1}$，又提高 $V_{TH1}$，因此 $M_1$ 能流过的电流随 $V_{in}$ 升高而减小，而 $M_2$ 的电流能力 $I_2$ 是固定的。二者在某一输入电压 $V_{in}^*$ 处相交。

### 第 3 步 — $V_{in}$ 较低：$M_1$ 处于线性区，输出跟随输入

当 $V_{in} < V_{in}^*$ 时，$M_1$ 能流过多于 $I_2$ 的电流，因此 $I = I_2$，$M_2$ 饱和，而 $M_1$ 被推入线性区，其 $V_{DS1}$ 恰好足以流过 $I_2$：

$$I_2 = \beta_1\left[(V_{b1} - V_S - V_{TH1})V_{DS1} - \tfrac12V_{DS1}^2\right], \qquad V_S = V_{in} + I_2R_S ,$$

$$V_{out} = V_S + V_{DS1} = V_{in} + I_2R_S + V_{DS1} .$$

输出较低并跟随输入变化，斜率为 $1 + dV_{DS1}/dV_{in}$，略大于 1。随着 $V_{in}$ 升高，$M_1$ 的过驱动电压（overdrive voltage）减小，需要更大的 $V_{DS1}$ 才能流过 $I_2$，因此斜率不断增大，并且在接近饱和边缘时 $V_{DS1}$ 迅速增大。

### 第 4 步 — $V_{in}^*$ 处的转变：竖直跳变

在 $V_{in}^*$ 处，两个器件都饱和，$I = I_2$，且 $V_S^* = V_{in}^* + I_2R_S$：

$$
\begin{aligned}
\tfrac12\beta_1\left(V_{b1} - V_S^* - V_{TH1}\right)^2 &= I_2\\
V_{b1} - V_S^* - V_{TH1} &= \sqrt{2I_2/\beta_1}\\
V_{in}^* &= V_{b1} - V_{TH1} - \sqrt{\frac{2I_2}{\beta_1}} - I_2R_S ,
\end{aligned}
$$

其中 $V_{TH1} = V_{TH}(V_S^*)$，而 $V_S^* = V_{b1} - V_{TH1} - \sqrt{2I_2/\beta_1}$（这是隐式方程，迭代一两次即可）。

转变处的增益： 当 $\lambda = 0$ 时，输出节点位于两个理想电流源之间，因此输出电阻以及该共栅级的增益都是无穷大：曲线在 $V_{in}^*$ 处是竖直的。输出从 $M_1$ 的饱和边缘 $V_{out} \approx V_{b1} - V_{TH1}$ 跳变到 $M_2$ 的饱和边缘 $V_{out} \approx V_{b2} + 0.8$ V。

当 $\lambda > 0$ 时，跳变变成一段非常陡峭的线段。增益为 $G_m(R_{out1}\|r_{O2})$，其中 $G_m \approx (g_{m1} + g_{mb1})/[1 + (g_{m1} + g_{mb1})R_S]$，$R_{out1} = r_{O1} + [1 + (g_{m1} + g_{mb1})r_{O1}]R_S$；当 $(g_{m1} + g_{mb1})R_S \gg 1$ 时，增益约为 $r_{O2}/R_S$。

这一图景成立的条件： 只有当 $V_{b1} - V_{TH1} < V_{b2} + 0.8$ V 时，两个器件才能同时饱和。否则不会出现跳变：输出以有限斜率连续地经过一个两管都处于线性区的范围。

### 第 5 步 — $V_{in}$ 较高：$M_2$ 处于线性区，输出接近 $V_{DD}$

当 $V_{in} > V_{in}^*$ 时，$M_1$ 饱和并决定电流 $I = I_{1,sat} < I_2$，而 $M_2$ 被推入线性区：

$$I_{1,sat} = \beta_2\left[(V_{DD} - V_{b2} - 0.8)(V_{DD} - V_{out}) - \tfrac12(V_{DD} - V_{out})^2\right].$$

$V_{out}$ 接近 $V_{DD}$，并随电流减小而越来越接近它。

$M_1$ 截止： 电流为零时 $V_S = V_{in}$，因此当 $V_{b1} - V_{in} = V_{TH}(V_{in})$ 时 $M_1$ 截止。令 $u = \sqrt{0.9 + V_{in}}$，该条件化为 $u^2 + 0.45u - (V_{b1} + 0.6269) = 0$，由此得 $V_{in,off} = u^2 - 0.9$。此后恰好有 $V_{out} = V_{DD}$（$M_2$ 处于线性区，$V_{SD2} = 0$）。

若 $V_{in}^* < 0$（$I_2$ 较大），输出在整个扫描范围内都很高；若 $V_{in}^* > 3$ V，输出则始终处于低电平跟随区。

### 第 6 步 — 数值示例

为便于说明，取 $V_{b1} = 2.0$ V，$V_{b2} = 1.5$ V，$\beta_1 = 2\ \mathrm{mA/V^2}$，$\beta_2 = 1\ \mathrm{mA/V^2}$，$R_S = 1\ \mathrm{k}\Omega$：

$$
\begin{aligned}
I_2 &= \tfrac12(1\ \mathrm{mA/V^2})(3 - 1.5 - 0.8)^2\ \mathrm{V^2} = 0.245\ \mathrm{mA},\\
\sqrt{2I_2/\beta_1} &= \sqrt{0.245\ \mathrm{V^2}} = 0.495\ \mathrm{V},\qquad I_2R_S = 0.245\ \mathrm{V}.
\end{aligned}
$$

求 $V_{in}^*$： 解方程 $V_S^* + V_{TH}(V_S^*) = 2.0 - 0.495 = 1.505$ V。试取 $V_S^* = 0.668$ V：$V_{TH} = 0.7 + 0.45(\sqrt{1.568} - 0.9487) = 0.837$ V，而 $0.668 + 0.837 = 1.505$ V。✓ 因此

$$V_{in}^* = V_S^* - I_2R_S = 0.668 - 0.245 = 0.423\ \mathrm{V}.$$

跳变从 $V_{b1} - V_{TH1} = 2.0 - 0.837 = 1.163$ V 一直到 $V_{b2} + 0.8 = 2.3$ V，且 $1.163 < 2.3$，因此跳变图景成立。

起点（$V_{in} = 0）： $V_S = 0.245$ V，$V_{TH1} = 0.7 + 0.45(\sqrt{1.145} - 0.9487) = 0.755$ V，过驱动电压为 $2.0 - 0.245 - 0.755 = 1.000$ V。线性区：由 $2\ \mathrm{mA/V^2}\,[1.000\,V_{DS1} - \frac12V_{DS1}^2] = 0.245$ mA 得 $V_{DS1}^2 - 2.000V_{DS1} + 0.245 = 0$，因此 $V_{DS1} = 0.131$ V，$V_{out} = 0.245 + 0.131 = 0.376$ V。

截止： 由 $u^2 + 0.45u - 2.627 = 0$ 得 $u = 1.411$，$V_{in,off} = 1.991 - 0.9 = 1.09$ V。

### 结果

这是带电流源负载的同相共栅特性：$V_{in}$ 较小时 $V_{out}$ 较低并跟随 $V_{in}$ 变化；在某一输入电平 $V_{in}^*$ 附近突然上升（增益极高）；高于该电平时接近 $V_{DD}$。设 $I_2 = \tfrac12\beta_2(V_{DD} - V_{b2} - 0.8)^2$：

- $V_{in} < V_{in}^*$： $M_1$ 能流过多于 $I_2$ 的电流，因此电流为 $I_2$（$M_2$ 饱和），$M_1$ 处于线性区。$V_{out} = V_{in} + I_2R_S + V_{DS1}$ 以略大于 1 的斜率上升，越接近 $V_{in}^*$ 越陡。
- $V_{in} \approx V_{in}^* = V_{b1} - V_{TH1} - \sqrt{2I_2/\beta_1} - I_2R_S$（$V_{TH1}$ 计入体效应，$V_{SB} = V_S$）：两个器件都饱和，增益非常大（$\lambda = 0$ 时无界）；$V_{out}$ 从 $\approx V_{b1} - V_{TH1}$（$M_1$ 的饱和边缘）跳变到 $\approx V_{b2} + 0.8$ V（$M_2$ 的饱和边缘）。
- $V_{in} > V_{in}^*$： $M_1$ 饱和，电流小于 $I_2$，$M_2$ 处于线性区；$V_{out}$ 接近 $V_{DD}$，并随电流减小而越来越接近它。当 $V_{in} \ge V_{b1} - V_{TH}(V_{in})$ 时 $M_1$ 截止，此后 $V_{out} = V_{DD}$。
- 若 $V_{in}^* < 0$，输出在整个范围内都很高；若 $V_{in}^* > 3$ V，输出始终很低。若 $V_{b1} - V_{TH1} > V_{b2} + 0.8$ V，输出则会连续地经过一个两管都处于线性区的区域。

常见错误： 画出反相的曲线。输入（经 $R_S$）驱动的是 $M_1$ 的源极；提高 $V_{in}$ 会减小 $V_{GS1}$ 以及 $M_1$ 所能吸收的电流，因此输出上升。

常见错误： 把转变描述为平缓的，增益只是 1 或某个电阻比之类的适中值。在 $V_{in}^*$ 附近，输出是位于两个电流源之间的高阻节点，因此增益极大（$\lambda = 0$ 时无界）。

常见错误： 认为两个器件始终都处于饱和区。电流由较弱的器件决定：低于 $V_{in}^*$ 时电流为 $I_2$，$M_1$ 处于线性区；高于它时，电流为 $M_1$ 的饱和电流，$M_2$ 处于线性区。
