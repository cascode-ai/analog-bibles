# 参考答案 - R096

## 参考答案

带电流源（current source）负载的同相共栅（common-gate）特性：$V_{in}$ 较小时 $V_{out}$ 较低并跟随 $V_{in}$ 变化；在某一输入电平 $V_{in}^*$ 附近突然上升（增益极高）；高于该电平时 $V_{out}$ 接近 $V_{DD}$。令 $I_2 = \tfrac12\beta_2(V_{DD} - V_{b2} - 0.8)^2$（$M_2$ 的饱和电流）。

- 两个器件流过相同的电流。$M_1$ 的饱和电流为 $\tfrac12\beta_1(V_{b1} - V_S - V_{TH1})^2$，其中源极电压 $V_S = V_{in} + I_DR_S$，并且由于体效应（body effect），$V_{TH1} = V_{TH}(V_S)$；该饱和电流随 $V_{in}$ 升高而减小。
- $V_{in} < V_{in}^*$：$M_1$ 能够流过多于 $I_2$ 的电流，因此电流为 $I_2$，$M_2$ 处于饱和区（saturation region），而 $M_1$ 处于线性区（triode region）：$V_{out} = V_{in} + I_2R_S + V_{DS1}$，以略大于 1 的斜率上升（低电平跟随区）。
- $V_{in} \approx V_{in}^* = V_{b1} - V_{TH1} - \sqrt{2I_2/\beta_1} - I_2R_S$：两管都饱和；增益为带电流源负载的共栅级增益，即 $g_{m1}$ 乘以很大的输出电阻（output resistance），因而非常大，λ = 0 时无界；$V_{out}$ 从 ≈ $V_{b1} - V_{TH1}$（$M_1$ 的饱和边缘）跳变到 ≈ $V_{b2} + 0.8$ V（$M_2$ 的饱和边缘）。
- $V_{in} > V_{in}^*$：$M_1$ 饱和，电流小于 $I_2$，$M_2$ 处于线性区，$V_{out}$ 接近 $V_{DD}$，并随电流减小而越来越接近它；当 $V_{in} \ge V_{b1} - V_{TH}(V_{in})$ 时 $M_1$ 截止，此后 $V_{out} = V_{DD}$。
- 若 $V_{in}^* < 0$（$I_2$ 较大），$V_{out}$ 在整个范围内都很高；若 $V_{in}^*$ 超过 3 V，输出则始终处于低电平区。
- 上述跳变假设在 $V_{in}^*$ 处 $V_{b1} - V_{TH1} < V_{b2} + 0.8$ V，从而两个器件可以同时饱和。若反过来 $V_{b1} - V_{TH1} > V_{b2} + 0.8$ V，输出会以有限斜率连续地经过一个两管都处于线性区的区域；只要说明了条件，两种情况都可以接受。

## 评分说明

+2：说明同相特性，低输入时 $M_1$ 处于线性区且 $M_2$ 饱和，在两管饱和电流相等处出现尖锐高增益转折，之后 $M_2$ 进入线性区、输出接近 $V_{DD}$，并在 $M_1$ 截止后恰为 $V_{DD}$。+1：曲线形状和转折正确，但缺少 $V_{in}^*$ 表达式或工作区标签。0：只描述同相上升趋势，却把转折说成渐变且没有电流源依据。若明确断言特性反相、把 $V_{in}$ 当作栅极输入，或把 $R_S$ 误接地，则扣 2 分。题目未要求忽略沟道长度调制，允许 λ=0 时的竖直跳变，也允许 λ>0 时的陡峭有限增益段。
