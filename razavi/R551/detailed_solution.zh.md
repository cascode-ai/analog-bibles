# 详细步骤 - R551

**思路。** 重新推导一遍，并记清每个量是在哪个温度下取值的。零 TC 条件只在一个温度 $T_0$ 处施加，固定常数 $n$ 就是为了在该温度满足这一条件而选取的，因此得到的公式是 **$T_0$ 处的一个值**，而不是给定电路关于 $T$ 的函数。然后计算电路真实的 $V_{REF}(T)$，并证明其斜率在 $T_0$ 处为零。

### 第 1 步 — 重新推导，并记清 $T_0$

设 $n$ 是由电路决定的固定数值，

$$V_{REF}(T) = V_{BE}(T) + V_T\ln n, \qquad \frac{\partial V_{REF}}{\partial T} = \frac{\partial V_{BE}}{\partial T} + \frac{k}{q}\ln n .$$

设计使它在选定的温度 $T_0$（例如 300 K）处为零：

$$\frac{V_{BE}(T_0) - (4+m)V_{T0} - E_g/q}{T_0} + \frac{k}{q}\ln n = 0, \qquad V_{T0} = \frac{kT_0}{q}.$$

乘以 $T_0$：

$$V_{T0}\ln n = \frac{E_g}{q} + (4+m)V_{T0} - V_{BE}(T_0).$$

**这个方程决定了 $n$。** 例如，300 K 时 $V_{BE}(T_0) = 0.75$ V，则 $V_{T0}\ln n = 1.12 + 0.0646 - 0.75 = 0.4346$ V。（实际中这么大的因子来自乘在 $\ln n$ 上的电阻比，但道理相同。）代回 $T_0$ 处的 $V_{REF}$：

$$
\begin{aligned}
V_{REF}(T_0) &= V_{BE}(T_0) + V_{T0}\ln n\\
&= V_{BE}(T_0) + \frac{E_g}{q} + (4+m)V_{T0} - V_{BE}(T_0)\\
&= \frac{E_g}{q} + (4+m)\frac{kT_0}{q}.
\end{aligned}
$$

教材公式中的“$T$”其实是设计温度 $T_0$。

### 第 2 步 — 错误所在

“$\partial V_{REF}/\partial T \propto (4+m)k/q$”这一步把 $E_g/q + (4+m)kT/q$ 当作某一个电路的函数 $V_{REF}(T)$。但它并不是：

1. **零 TC 条件只在一个温度下成立。** 它是在 $T_0$ 处为确定 $n$ 而施加的；在其他任何温度下，同一个电路（相同的 $n$）并不满足这一条件，因此在那些温度下不能做第 1 步中的代换。
2. **$n$ 是常数，但公式把它隐藏了。** 在公式中“改变 $T$”，实际上隐含地改变了 $n$，使零 TC 条件在每一个新温度下重新得到满足：每个温度对应的都是一个**不同的电路**。

因此，$E_g/q + (4+m)kT_0/q$ 是一个按 $T_0$ 处零 TC 设计的带隙基准**在** $T_0$ 处的输出。它的导数

$$\frac{dV_{REF}(T_0)}{dT_0} = (4+m)\frac{k}{q} = 2.5\times0.08617\ \mathrm{mV/K} = 0.215\ \mathrm{mV/K},$$

说明的是：针对另一个 $T_0$ **重新设计**电路时，这一设计值如何移动。形式上，$dV_{REF}(T_0)/dT_0 = \partial V_{REF}/\partial T + (\partial V_{REF}/\partial n)(dn/dT_0)$：按设计第一项为零，全部斜率都来自 $n$ 的变化。该公式描绘的是一族电路的零斜率点所连成的曲线，而不是其中任何一个电路的曲线。

### 第 3 步 — 固定电路的真实 $V_{REF}(T)$

在集电极电流恒定时，TC 模型是一个微分方程：

$$\frac{dV_{BE}}{dT} - \frac{V_{BE}}{T} = -(4+m)\frac{k}{q} - \frac{E_g}{qT}.$$

两边除以 $T$，左边变为 $\dfrac{d}{dT}\left(\dfrac{V_{BE}}{T}\right)$：

$$\frac{d}{dT}\left(\frac{V_{BE}}{T}\right) = -(4+m)\frac{k}{q}\cdot\frac1T - \frac{E_g}{q}\cdot\frac{1}{T^2}.$$

从 $T_0$ 到 $T$ 积分，再乘以 $T$：

$$V_{BE}(T) = \frac{E_g}{q} + \frac{T}{T_0}\left[V_{BE}(T_0) - \frac{E_g}{q}\right] - (4+m)\frac{kT}{q}\ln\frac{T}{T_0}.$$

采用第 1 步中固定的 $n$，与绝对温度成正比（PTAT）项为

$$V_T\ln n = \frac{T}{T_0}\,V_{T0}\ln n = \frac{T}{T_0}\left[\frac{E_g}{q} + (4+m)V_{T0} - V_{BE}(T_0)\right].$$

两者相加，$\pm(T/T_0)[V_{BE}(T_0) - E_g/q]$ 项相互抵消，且 $(T/T_0)(4+m)V_{T0} = (4+m)kT/q$：

$$
\begin{aligned}
V_{REF}(T) &= \frac{E_g}{q} + (4+m)\frac{kT}{q} - (4+m)\frac{kT}{q}\ln\frac{T}{T_0}\\
&= \frac{E_g}{q} + (4+m)\frac{kT}{q}\left[1 - \ln\frac{T}{T_0}\right].
\end{aligned}
$$

当 $T = T_0$ 时它等于 $E_g/q + (4+m)kT_0/q$；在其他任何温度下它都**不**等于 $E_g/q + (4+m)kT/q$。真实的斜率为

$$
\begin{aligned}
\frac{\partial V_{REF}}{\partial T} &= (4+m)\frac{k}{q}\left[1 - \ln\frac{T}{T_0}\right] + (4+m)\frac{kT}{q}\left(-\frac1T\right)\\
&= -(4+m)\frac{k}{q}\ln\frac{T}{T_0},
\end{aligned}
$$

正如设计的那样，它在 $T = T_0$ 处恰好为零。偏离 $T_0$ 时它很小，并且会改变符号（低于 $T_0$ 时为正，高于时为负），因此 $V_{REF}(T)$ 在 $T_0$ 处有最大值：这就是带隙基准中常见的残余曲率。

### 第 4 步 — 数值

取 $T_0 = 300$ K，$E_g/q = 1.12$ V，$(4+m)k/q = 2.5\times8.617\times10^{-5} = 2.154\times10^{-4}$ V/K：

$$
\begin{aligned}
V_{REF}(T_0) &= 1.12 + (2.154\times10^{-4})(300) = 1.12 + 0.0646 = 1.1846\ \mathrm{V},\\
V_{REF}(200) &= 1.12 + (2.154\times10^{-4})(200)\left[1 - \ln\tfrac{200}{300}\right] = 1.12 + (0.04309)(1.4055) = 1.1806\ \mathrm{V},\\
V_{REF}(400) &= 1.12 + (0.08617)\left[1 - \ln\tfrac{400}{300}\right] = 1.12 + (0.08617)(0.7123) = 1.1814\ \mathrm{V}.
\end{aligned}
$$

| $T$ (K) | 实际 $V_{REF}(T)$ (V) | 实际斜率（mV/K） | “公式”$E_g/q + (4+m)kT/q$ (V) |
|---|---|---|---|
| 200 | 1.1806 | +0.087 | 1.1631 |
| 250 | 1.1837 | +0.039 | 1.1739 |
| 300 | 1.1846 | 0 | 1.1846 |
| 350 | 1.1838 | −0.033 | 1.1954 |
| 400 | 1.1814 | −0.062 | 1.2062 |

实际电路在 200 K 范围内只变化约 4 mV，并且在 300 K 处是平坦的；而被误读的“公式”一栏以 0.215 mV/K 的速率稳定上升，在同一范围内变化 43 mV。两者只在 $T_0$ 处一致。

### 结果

$V_{REF} = E_g/q + (4+m)V_T$ 是基准电压**在施加零 TC 条件的那个温度 $T_0$ 处**的值。它是通过选取固定常数 $n$，使 $V_{T0}\ln n = E_g/q + (4+m)V_{T0} - V_{BE}(T_0)$ 而得到的，而这一等式只在 $T_0$ 处成立。因此它不是给定电路的函数 $V_{REF}(T)$，不能对 $T$ 求导。它的斜率 $(4+m)k/q \approx 0.215$ mV/K 描述的是：针对另一个 $T_0$ 重新设计电路（采用不同的 $n$）时零 TC 值会如何移动，即 $dV_{REF}(T_0)/dT_0$，而不是 $\partial V_{REF}/\partial T$。

固定电路的实际行为是 $V_{REF}(T) = E_g/q + (4+m)(kT/q)[1 - \ln(T/T_0)]$，其导数 $-(4+m)(k/q)\ln(T/T_0)$ 在 $T_0$ 处为零。取 $T_0 = 300$ K，300 K 时为 1.1846 V，200 K 和 400 K 时约为 1.181 V：在 $T_0$ 处 TC 为零，只有很小的残余曲率。

**常见错误。** 接受这一论证，并断定带隙基准“实际上”具有约 0.2 mV/K 的 TC。$n$ 固定的电路按其构造在 $T_0$ 处斜率为零；0.215 mV/K 是连接**不同**设计的那条曲线的斜率。

**常见错误。** 把这一悖论归咎于 $E_g$ 的温度依赖性或 $m$ 的取值。即使 $E_g$ 严格为常数、$m$ 严格等于 $-3/2$，该公式也不能求导，因为它只在一个温度下成立。

**常见错误。** 含糊地说“结果是近似的”。在该模型范围内推导是精确的；错误在于逻辑：一个只在某一点施加的关系被用来消去常数 $n$，然后又被当作在所有温度下都成立。
