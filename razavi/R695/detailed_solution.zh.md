# 详细步骤 - R695

**思路。** 电流为零要么需要电流通路断开，要么需要某个晶体管的栅源电压被固定在阈值以下。逐一检查多晶硅栅 CMOS 工艺的各个掩模步骤，判断**微小的**对准偏差是否可能造成其中任何一种情况。自对准使前道（形成晶体管的）工序能够容忍微小的偏移，因此问题一定出在某个后道工序：接触孔或金属/通孔的图形化。

### 第 1 步 — “输出电流为零”需要什么条件

把底部器件记为 $M_1$（源极接地，栅极接 $V_{b1}$，漏极接节点 X），共源共栅器件记为 $M_2$（源极接 X，栅极接 $V_{b2}$，漏极接输出）。输出电流流经 $M_2$ 和 $M_1$ 到地，只有在以下情况下才为零：

1. **开路**切断了这条通路（输出漏极处、$M_1$ 的源极处，或 X 与晶体管之间缺少连接），或者
2. **某个晶体管截止**：其栅极与自身的源极短路（$V_{GS} = 0$），其偏置连接开路（栅极浮空，通常会向地放电），或其偏置线对地短路。

仅仅使器件尺寸略有改变的对准偏差，或者**增加**一条电流通路的短路，都不可能使电流为零。

### 第 2 步 — 前道工序：受自对准和设计余量保护

各掩模步骤依次为：n 阱（n-well）；有源区（沟道截止注入使用同一块掩模）；阈值调整注入（整片注入或粗略的掩模）；多晶硅栅；n+/p+ 源/漏选择；接触孔；金属 1、通孔、金属 2，等等。

**多晶硅栅与有源区。** 源/漏注入是在栅极图形化**之后**进行的，由多晶硅遮挡沟道，因此 n+ 区总是一直延伸到栅极的两个边缘。

- 沿**沟道长度方向**的偏移使一个源/漏区略微变宽，另一个略微变窄；晶体管仍正常工作。
- 沿**沟道宽度方向**的偏移被多晶硅伸出有源区之外的部分（“端帽”，end cap）所吸收。只有很大的偏移才会留下一条未被覆盖的有源区条带，它会被注入成 n+，从而使源极和漏极**短路**：结果是电流**过大**，而不是为零。

**源/漏选择掩模。** n+ 选择窗口以充裕的余量包围有源区，因此即使有微小偏移，每个源/漏区仍会被掺杂。

**沟道截止注入与阈值调整注入。** 沟道截止注入通过有源区掩模与晶体管自对准，而阈值调整注入是整片注入或只需粗略对准，因此微小的对准偏差不会改变任何东西。

**n 阱掩模。** 间距规则（spacing rule）要求 NMOS 器件与阱之间保持很大的距离，因此阱边缘的微小偏移不会影响到它们。

因此，任何前道工序都不可能通过微小的对准偏差把电流关断。

### 第 3 步 — 接触孔：可能的原因

接触孔与多晶硅栅之间的距离等于（或接近）**最小间距**，并且它所落在的扩散区（diffusion）或多晶硅对它的包围也只有最小值。因此，接触孔掩模的微小对准偏差可能会：

- **使源极接触孔部分落在相邻的栅极多晶硅上**，从而在金属填充后使栅极与源极短路。对于 $M_1$，$V_{GS1} = 0 < V_{THN}$；对于 $M_2$（若节点 X 是一个有接触孔的区域），$V_{GS2} = 0$。无论哪种情况，器件都会截止，输出电流为零。
- **错过扩散区或多晶硅接触区。** 偏离 $M_1$ 源区或 $M_2$ 漏区的接触孔会使电流通路开路；偏离某个栅极多晶硅接触区的接触孔会使该栅极浮空，而浮空的栅极一般无法保持导通所需的偏置电压。

栅极与其**漏极**短路则会使器件成为二极管连接（diode-connected）；电流仍会流动，因此这种情况不能解释该故障现象。

同样的失效也可以描述为多晶硅栅**相对于接触孔**的对准偏差：关键在于这两层的相对位置，而这两层**不是**自对准的。

### 第 4 步 — 金属与通孔图形化：也有可能

金属线以最小宽度和最小间距画在接触孔上方。金属（或通孔）掩模的微小偏移可能会：

- **错过某个接触孔或通孔**，使源极、漏极或栅极的连接开路；
- **与相邻连线桥接**，例如使栅极偏置线 $V_{b1}$ 或 $V_{b2}$ 与地线短路，从而使相应的晶体管截止。

其中每一种情况都会使输出电流为零。

### 第 5 步 — 各步骤汇总

| 光刻步骤 | 微小的对准偏差能否使电流为零？ | 原因 |
|---|---|---|
| n 阱 | 否 | NMOS 远离阱边缘 |
| 有源区 / 沟道截止 | 否 | 沟道截止自对准；多晶硅端帽可吸收偏移 |
| 阈值调整 | 否 | 整片注入或只需粗略对准的注入 |
| 多晶硅栅（相对于源/漏） | 否 | 源/漏注入与栅极自对准；宽度方向的大偏移会使源漏**短路** |
| n+/p+ 选择 | 否 | 对有源区的包围余量很大 |
| **接触孔** | **能** | 栅极与源极短路（$V_{GS} = 0$），或源/漏/栅连接缺失 |
| **金属 / 通孔** | **能** | 连接开路，或偏置线对地短路 |

### 结果

对准偏差一定发生在某个**非自对准的后道工序**中：最可能是**接触孔光刻**（等价地说，多晶硅与接触孔之间的对准），或者是**金属/通孔光刻**。偏移的接触孔可能使某个栅极与其源极短路（使 $M_1$ 或 $M_2$ 截止），或错过源极、漏极或栅极的连接；偏移的金属线可能错过某个接触孔，或使某条偏置线对地短路。它不可能是多晶硅栅相对于源/漏区的对准、源/漏注入，或整片的阈值调整注入 / 沟道截止注入，因为源/漏区与栅极自对准，而这些步骤都有充足的余量。

**常见错误。** 声称多晶硅栅的对准偏差会在沟道与源极或漏极之间留下间隙。源/漏注入以栅极本身作为掩模，因此 n+ 区总是延伸到栅极边缘。

**常见错误。** 提出一种**增加**导电通路的缺陷，例如栅极沿宽度方向偏移导致源漏短路；这会使电流增大。

**常见错误。** 归咎于阈值调整注入或沟道截止注入，而它们是整片注入或自对准的，并不依赖于精细对准。
