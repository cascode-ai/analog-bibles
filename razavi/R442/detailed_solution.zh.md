# 详细步骤 - R442

**思路。** 对各节点列 KCL 方程，可以确定哪个电流流过哪个晶体管；再由平方律（square law）求出各管的栅源电压，源极高于地电位时还要计入体效应。$M_3$ 的栅极就是节点 X 本身，因此 $V_{G3}$ 由 $M_3$ 的电流决定；$M_2$ 的栅极比 X 高一个 $V_{GS2}$。

### 第 1 步 — 各器件中流过哪个电流

把 $M_3$ 的漏极（$M_2$ 的栅极）记为节点 G。$I_1$ 流入 G，而 $M_2$ 的栅极不吸取直流电流，因此

$$I_{D3} = I_1 = 100\ \mu\mathrm{A}.$$

$I_2$ 流入输出端，只能向下经 $M_2$ 流入 X，再经 $M_1$ 流出（$M_3$ 的栅极不吸取电流），这与 $V_{in}$ 把 $M_1$ 偏置在 $I_2$ 相一致：

$$I_{D2} = I_{D1} = I_2 = 0.5\ \mathrm{mA}.$$

所有 NMOS 器件的宽长比（aspect ratio）均为

$$\left(\frac{W}{L}\right)_{1-3} = \frac{100\ \mu\mathrm{m}}{0.5\ \mu\mathrm{m}} = 200 ,$$

并且忽略沟道长度调制。

### 第 2 步 — $M_3$ 的栅极电压（也就是 X 的电压）

$M_3$ 的 $V_{SB3} = 0$，因此其阈值电压（threshold voltage）为 $V_{TH0} = 0.7$ V；对于 100 μA，

$$
\begin{aligned}
V_{ov3} &= \sqrt{\frac{2I_{D3}}{\mu_nC_{ox}(W/L)_3}} = \sqrt{\frac{2\,(100\ \mu\mathrm{A})}{(134\ \mu\mathrm{A/V^2})(200)}}\\
&= \sqrt{\frac{2\times10^{-4}}{2.68\times10^{-2}}}\ \mathrm{V} = \sqrt{7.46\times10^{-3}}\ \mathrm{V}\\
&= 0.086\ \mathrm{V}.
\end{aligned}
$$

因此

$$V_{G3} = V_{GS3} = V_{TH0} + V_{ov3} = 0.7\ \mathrm{V} + 0.086\ \mathrm{V} = 0.786\ \mathrm{V},$$

又由于 $M_3$ 的栅极就是节点 X，

$$V_X = V_{G3} \approx 0.79\ \mathrm{V}.$$

X 由 $M_3$ 而不是由 $M_1$ 确定：环路 $X \to M_3 \to G \to M_2 \to X$ 是负反馈（X 升高会使 $M_3$ 吸收的电流超过 $I_1$，从而把 G 拉低，使 X 回落），因此它稳定在 $M_3$ 恰好流过 $I_1$ 的位置。$M_1$ 只决定叠层中流过的电流。

### 第 3 步 — $M_2$ 的阈值电压（体效应）

$M_2$ 的源极位于 $V_X = 0.786$ V，衬底接地，因此在下式中 $V_{SB2} = 0.786$ V：

$$V_{TH2} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB2}} - \sqrt{2|\phi_F|}\right),$$

由此得

$$
\begin{aligned}
\sqrt{0.9 + 0.786} &= \sqrt{1.686} = 1.2986,\\
\sqrt{0.9} &= 0.9487,\\
V_{TH2} &= 0.7 + 0.45\,(1.2986 - 0.9487)\ \mathrm{V}\\
&= 0.7 + 0.45\times0.3499\ \mathrm{V} = 0.7 + 0.157\ \mathrm{V}\\
&= 0.857\ \mathrm{V}.
\end{aligned}
$$

### 第 4 步 — $M_2$ 的栅极电压

对于 0.5 mA，

$$
\begin{aligned}
V_{ov2} &= \sqrt{\frac{2I_{D2}}{\mu_nC_{ox}(W/L)_2}} = \sqrt{\frac{2\,(0.5\ \mathrm{mA})}{(134\ \mu\mathrm{A/V^2})(200)}}\\
&= \sqrt{\frac{1\times10^{-3}}{2.68\times10^{-2}}}\ \mathrm{V} = \sqrt{0.0373}\ \mathrm{V}\\
&= 0.193\ \mathrm{V},
\end{aligned}
$$

而 $M_2$ 的栅极比 X 高一个栅源电压：

$$
\begin{aligned}
V_{G2} &= V_X + V_{GS2} = V_X + V_{TH2} + V_{ov2}\\
&= 0.786\ \mathrm{V} + 0.857\ \mathrm{V} + 0.193\ \mathrm{V}\\
&= 1.837\ \mathrm{V} \approx 1.84\ \mathrm{V}.
\end{aligned}
$$

若忽略体效应（$V_{TH2} = 0.7$ V），将得到 $0.786 + 0.7 + 0.193 = 1.68$ V，偏低约 160 mV。

### 第 5 步 — 检查每个器件都处于饱和区

- **$M_1$**：同样流过 0.5 mA，$W/L = 200$，因此过驱动电压（overdrive voltage）为 0.193 V，$V_{in} = 0.7 + 0.193 = 0.893$ V；$V_{DS1} = V_X = 0.786\ \mathrm{V} > 0.193$ V。✓
- **$M_3$**：$V_{DS3} = V_{G2} = 1.84\ \mathrm{V} > V_{ov3} = 0.086$ V。✓
- **$M_2$**：当 $V_{out} \ge V_{G2} - V_{TH2} = V_X + V_{ov2} = 0.98$ V 时处于饱和区。
- **PMOS 电流源 $I_1$**（$W/L = 50/0.5 = 100$，100 μA）：
  $$|V_{ov,P1}| = \sqrt{\frac{2\,(100\ \mu\mathrm{A})}{(38.4\ \mu\mathrm{A/V^2})(100)}} = \sqrt{0.0521}\ \mathrm{V} = 0.228\ \mathrm{V},$$
  而 $V_{SD} = V_{DD} - V_{G2} = 3 - 1.84 = 1.16\ \mathrm{V} > 0.228$ V。✓
- **PMOS 电流源 $I_2$**（0.5 mA）：$|V_{ov,P2}| = \sqrt{2(0.5\ \mathrm{mA})/(38.4\ \mu\mathrm{A/V^2}\times100)} = 0.51$ V，因此 $V_{out} \le 3 - 0.51 = 2.49$ V。

因此，输出电压可以位于约 0.98 V 到 2.49 V 之间的任意位置，同时所有器件都保持饱和。

### 结果

- $M_3$ 的栅极（= 节点 X）：$V_{G3} = V_{GS3} = 0.7 + 0.086 \approx 0.79$ V。
- $M_2$ 的栅极：$V_{G2} = V_X + V_{TH2} + V_{ov2} = 0.786 + 0.857 + 0.193 \approx 1.84$ V，其中 $V_{TH2} = 0.857$ V 因体效应而升高（不计体效应时约为 1.68 V）。

**常见错误。** 以为 X 由 $V_{in}$ 或 $M_1$ 决定。$M_1$ 只决定电流；经 $M_3$ 和 $M_2$ 的反馈迫使 X 等于能使 $M_3$ 流过 $I_1$ 的 $V_{GS3}$。

**常见错误。** 认为 $M_3$ 流过电流 $I_2$（或 $M_2$ 流过电流 $I_1$）。由于 $M_2$ 的栅极不吸取电流，$I_1$ 全部且只有 $I_1$ 流过 $M_3$。

**常见错误。** 把 $M_2$ 的源极当作接地来计算 $V_{G2}$（$V_{G2} = V_{GS2} \approx 0.9$ V），或者忘记体效应。$V_X$ 和升高后的 $V_{TH2}$ 都必须计入。
