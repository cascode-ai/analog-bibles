$M_3$ 的栅极（= 节点 X）：$V_{GS3} \approx 0.79$ V。$M_2$ 的栅极：$V_X + V_{GS2} \approx 1.84$ V；若忽略 $M_2$ 的体效应（body effect），则 ≈ 1.68 V。

- $M_3$（源极接地）流过 $I_1 = 100\ \mu$A：$V_{GS3} = 0.7 + \sqrt{2(100\ \mu)/(134\ \mu \cdot 200)} = 0.7 + 0.086 = 0.786$ V。环路迫使 X 等于这个值。
- $M_2$ 流过 $I_2 = 0.5$ mA，源极位于 $V_X$：$V_{OD2} = \sqrt{2(0.5\ \mathrm{m})/(134\ \mu \cdot 200)} = 0.193$ V；$V_{TH2} = 0.7 + 0.45(\sqrt{0.9 + 0.786} - \sqrt{0.9}) = 0.857$ V；$V_{G2} = 0.786 + 0.857 + 0.193 = 1.84$ V。
- 验证：$M_1$（$V_{DS} = 0.79$ V > 0.19 V）和 $M_3$（$V_{DS} = 1.84$ V）均处于饱和区（saturation region）；PMOS 电流源 $I_1$（|V_OD| = 0.23 V）有充足的电压余度（headroom）。
