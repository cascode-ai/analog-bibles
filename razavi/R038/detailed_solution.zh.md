# 详细步骤 - R038

**思路：** 把 $M_1$ 的源极（由 $V_{in}$ 驱动）记为 S，栅极记为 G。$C_1$ 跨接在栅极与源极之间，$C_2$ 跨接在漏极与栅极之间，因此栅极浮接在两个电容之间。在阶跃时，每个节点都上升 3 V。此后 $M_1$ 从 X 抽取电流；由于栅极不取电流，该电流同时流过串联的 $C_2$ 和 $C_1$，因此两个电容失去相同的电荷。当 $C_1$ 上的电压（即 $V_{GS}$）降到阈值电压（threshold voltage）时，放电停止；这里的阈值电压因体效应而升高。

![R038 等电容示例的 $V_X(t)$ 波形](/q/R038/solution-vx.zh.svg)

### 第 1 步 — 阶跃之前的状态

$V_G = V_S + V_{C1}$，$V_X = V_G + V_{C2} = V_S + V_{C1} + V_{C2}$，因此在阶跃之前（$V_S = 0$）：

$$V_S = 0, \qquad V_G = 3\ \mathrm{V}, \qquad V_X = 6\ \mathrm{V}.$$

（由于 $V_{GS} = 3$ V，器件在 $t < 0$ 时就已经导通，因此所给的电容电压只是阶跃瞬间的一个快照；我们把它们作为初始条件。）

### 第 2 步 — $t = 0$ 时的跳变

两个电容的电压都不能瞬时改变，因此 G 和 X 随 S 一起恰好上升 3 V：

$$V_S(0^+) = 3\ \mathrm{V}, \qquad V_G(0^+) = 6\ \mathrm{V}, \qquad V_X(0^+) = 9\ \mathrm{V}.$$

$V_X$ 从 6 V 跳变到 9 V。

### 第 3 步 — 阶跃刚结束时的工作点

$$
\begin{aligned}
V_{GS} &= V_{C1} = 3\ \mathrm{V},\\
V_{DS} &= V_{C1} + V_{C2} = 6\ \mathrm{V},\\
V_{SB} &= 3 - 0 = 3\ \mathrm{V}.
\end{aligned}
$$

源极比接地的衬底高 3 V，因此

$$V_{TH} = 0.7 + 0.45\left(\sqrt{0.9 + 3} - \sqrt{0.9}\right) = 0.7 + 0.45\,(1.9748 - 0.9487) = 0.7 + 0.4618 = 1.162\ \mathrm{V},$$

由于 $V_S$ 被 $V_{in}$ 固定在 3 V，它在 $t > 0$ 时是恒定的。过驱动电压（overdrive voltage）$3 - 1.162 = 1.838$ V 小于 $V_{DS} = 6$ V，因此 $M_1$ 处于饱和区：

$$I_D(0^+) = \tfrac12\beta\,(1.838\ \mathrm{V})^2 = 1.69\,\beta\ \mathrm{V^2}.$$

### 第 4 步 — 漏极电流从哪里来：电荷平衡

在 X 点，只连接了漏极（$I_D$ 流出）和 $C_2$ 的上极板：

$$C_2\frac{dV_{C2}}{dt} = -I_D .$$

在 G 点，栅极不取电流，因此从 $C_2$ 流出的电流全部流入 $C_1$：

$$C_1\frac{dV_{C1}}{dt} = C_2\frac{dV_{C2}}{dt} = -I_D .$$

所以漏极电流是从 $V_{in}$ 节点经 $C_2$ 与 $C_1$ 的串联组合抽取的，两个电容失去相同的电荷 $\Delta Q(t) = \int_0^t I_D\,dt$。由于 $V_S$ 固定，

$$\frac{dV_X}{dt} = \frac{dV_{C1}}{dt} + \frac{dV_{C2}}{dt} = -I_D\left(\frac{1}{C_1} + \frac{1}{C_2}\right).$$

关键的结果是：随着放电进行，$V_{GS} = V_{C1}$ 下降；栅极与 X 一起被拉低。

### 第 5 步 — 放电结束与最终值

在饱和区，放电一直持续到

$$V_{C1}(\infty) = V_{TH} = 1.162\ \mathrm{V}.$$

从 $C_1$（因而也从 $C_2$）移走的电荷为

$$\Delta Q = C_1\,(3 - 1.162)\ \mathrm{V} = 1.838\,C_1\ \mathrm{V},$$

$$V_{C2}(\infty) = 3 - \frac{\Delta Q}{C_2} = 3 - 1.838\,\frac{C_1}{C_2}\ \mathrm{V},$$

以及

$$
\begin{aligned}
V_X(\infty) &= V_S + V_{C1}(\infty) + V_{C2}(\infty)\\
&= 3 + V_{TH} + 3 - \frac{C_1}{C_2}\,(3 - V_{TH})\\
&= 6\ \mathrm{V} + V_{TH} - \frac{C_1}{C_2}\,(3\ \mathrm{V} - V_{TH}).
\end{aligned}
$$

对 $C_1 = C_2$： $V_X(\infty) = 6 + 1.162 - 1.838 = 5.32$ V。（若忽略体效应，$V_{TH} = 0.7$ V 将给出 $6 + 0.7 - 2.3 = 4.4$ V。）

$M_1$ 是否保持饱和？ $V_{DS} \ge V_{GS} - V_{TH}$ 意味着 $V_{C1} + V_{C2} \ge V_{C1} - V_{TH}$，即 $V_{C2} \ge -V_{TH}$。$V_{C2}$ 在结束时最小，因此

$$
\begin{aligned}
3 - 1.838\,\frac{C_1}{C_2} &\ge -1.162\\
\frac{C_1}{C_2} &\le \frac{4.162}{1.838} \approx 2.26 .
\end{aligned}
$$

若 $C_1/C_2 > (3\ \mathrm{V}+V_{TH})/(3\ \mathrm{V}-V_{TH})$，较小的 $C_2$ 放电很快，使 $V_{DS}$ 在 $V_{GS}$ 达到 $V_{TH}$ 之前就降到过驱动电压以下。$M_1$ 进入线性区。当 $V_X\to3$ V 时，由电荷平衡得 $V_{GS}-V_{TH}\to u_0-6\ \mathrm{V}/(1+C_1/C_2)>0$，其中 $u_0=3\ \mathrm{V}-V_{TH}$。此时线性区电流在一阶近似下与 $V_{DS}=V_X-3\ \mathrm{V}$ 成正比，因此末段呈指数衰减。

### 第 6 步 — 随时间的变化（饱和情形）

记过驱动电压 $u = V_{C1} - V_{TH}$，其初值为 $u_0 = 1.838$ V，由 $C_1\,dV_{C1}/dt = -\tfrac12\beta u^2$ 得

$$\frac{du}{dt} = -\frac{\beta}{2C_1}u^2 \quad\Longrightarrow\quad u(t) = \frac{u_0}{1 + t/T}, \qquad T = \frac{2C_1}{\beta u_0} .$$

利用 $V_{C2} = 3 - (C_1/C_2)(u_0 - u)$（移走的电荷相等）：

$$V_X(t) = 3 + (V_{TH} + u) + 3 - \frac{C_1}{C_2}(u_0 - u) = V_X(\infty) + \left(1 + \frac{C_1}{C_2}\right)u(t).$$

所以 $V_X$ 从 9 V 开始以逐渐减小的斜率下降，按 $1/t$ 渐近地趋于 $V_X(\infty)$（平方律拖尾）。

示例： $C_1 = C_2 = 1$ pF，$\beta = 1\ \mathrm{mA/V^2}$，因此 $T = 2\ \mathrm{pF}/(1.838\ \mathrm{mS}) = 1.09$ ns，$V_X(t) = 5.32 + 2u(t)$：

| $t$ (ns) | $u$ (V) | $V_X$ (V) | $I_D$ (mA) |
|---|---|---|---|
| $0^-$ | — | 6.00 | — |
| $0^+$ | 1.838 | 9.00 | 1.69 |
| 0.5 | 1.26 | 7.84 | 0.79 |
| 1 | 0.96 | 7.24 | 0.46 |
| 2 | 0.65 | 6.62 | 0.21 |
| 5 | 0.33 | 5.98 | 0.054 |
| 10 | 0.18 | 5.68 | 0.016 |
| ∞ | 0 | 5.32 | 0 |

初始斜率为 $-1.69\ \mathrm{mA}\times(1/1\ \mathrm{pF} + 1/1\ \mathrm{pF}) = -3.4$ V/ns。

### 结果

- 阶跃之前 $V_X = 6$ V（源极为 0，栅极为 3 V，X 为 6 V；所给的电荷取自该时刻）。
- 在 $t = 0$ 时，所有节点都上升 3 V： 源极为 3 V，栅极为 6 V，$V_X = 9$ V。
- 随后 $M_1$（$V_{GS} = 3$ V，$V_{DS} = 6$ V，饱和区）从 X 抽取电流。这一电流只能经由 $C_2$ 与 $C_1$ 的串联组合流过，因此两个电容放掉相同的电荷：$C_1\,dV_{C1}/dt = C_2\,dV_{C2}/dt = -I_D$，$dV_X/dt = -I_D(1/C_1 + 1/C_2)$。初始电流为 $\tfrac12\beta(3 - 1.16)^2 \approx 1.69\beta$。
- $V_{GS}$（= $C_1$ 上的电压）不断下降，直到 $M_1$ 在 $V_{GS} = V_{TH}(V_{SB} = 3\ \mathrm{V}) \approx 1.16$ V 处截止。$V_X$ 从 9 V 以逐渐减小的斜率下降到
$$V_X(\infty) = 6\ \mathrm{V} + V_{TH} - \frac{C_1}{C_2}(3\ \mathrm{V} - V_{TH}),$$
例如 $C_1 = C_2$ 时 ≈ 5.3 V（若忽略体效应则为 4.4 V），并渐近地趋于该值。最终 $V_{C1} = 1.16$ V，$V_{C2} = 3 - (C_1/C_2)(3 - 1.16)$。
- 电容比不超过上述分界值时，沟道在放电期间保持饱和。超过分界值时，$V_{DS}$ 在 $M_1$ 仍导通时降至过驱动电压以下，沟道进入线性区，$V_X$ 在放电末期按指数规律趋近 3 V。

**常见错误：** 认为阶跃后栅极固定在 6 V（或 3 V）。栅极浮接在 $C_1$ 与 $C_2$ 之间；漏极电流经两者抽取电荷，因此栅极随 X 一起下降，正是这一点最终使 $M_1$ 截止。

**常见错误：** 对于两个相等的电容，让 $V_X$ 放电到 $V_{in} = 3$ V（或 0）。等电容时，$V_{C1}$ 趋于 $V_{TH}$，沟道电流趋于零，此时 $V_{DS}$ 仍约为 2.32 V。

**常见错误：** 使用 $V_{TH} = 0.7$ V。源极比接地的衬底高 3 V，阈值电压约为 1.16 V，这使最终值从 4.4 V 变为约 5.3 V。
