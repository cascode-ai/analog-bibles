# Golden Solution - R428

## Reference answer

A consistent design (one of many): total current 2 mA; $I_{SS} = 1$ mA (0.5 mA per input device), each cascode branch 0.5 mA, so $M_5$/$M_6$ carry 1 mA each. Swing: each output must swing 1.2 V p-p, so $V_{OD3} + V_{OD5} + |V_{OD7}| + |V_{OD9}| \le 3 - 1.2 = 1.8$ V; choose $V_{OD5} = 0.5$, $V_{OD3} = 0.4$, $|V_{OD7}| = |V_{OD9}| = 0.45$ V. Then $(W/L)_{5,6} \approx 60$, $(W/L)_{3,4} \approx 47$, $(W/L)_{7-10} \approx 129$; input pair with $|V_{OD1}| = 0.3$ V: $(W/L)_{1,2} \approx 290$; tail source (1 mA, 0.4 V): $W/L \approx 325$. Gain ≈ 390 (≈ 460 with body effect of the cascodes) — a few hundred for any reasonable design. Yes, the input CM level can be zero.

- Gain: $A_v \approx g_{m1}\{[(g_{m3}+g_{mb3})r_{O3}(r_{O1}\|r_{O5})]\,\|\,[(g_{m7}+g_{mb7})r_{O7}r_{O9}]\}$. Here $g_{m1} = 3.33$ mS, $r_{O1}\|r_{O5} = 10\ \mathrm{k}\|10\ \mathrm{k} = 5$ kΩ, $g_{m3} = 2.5$ mS, $r_{O3} = 20$ kΩ → 250 kΩ; $g_{m7} = 2.22$ mS, $r_{O7} = r_{O9} = 10$ kΩ → 222 kΩ; $R_{out} = 118$ kΩ → $A_v \approx 392$ (≈ 460 including $g_{mb3} \approx 0.19g_{m3}$, $g_{mb7} \approx 0.18g_{m7}$).
- Input CM = 0: with a PMOS pair, $V_P = V_{in,CM} + |V_{GS1}|$ ≈ 1.37 V at $V_{in,CM} = 0$ ($|V_{TH1}| \approx 1.07$ V with the well at $V_{DD}$), leaving 1.6 V for the tail source (needs only 0.4 V). $M_1$ stays saturated if $V_X \le V_{in,CM} + |V_{TH1}| \approx 1.07$ V, while $M_5$ needs $V_X \ge V_{OD5} = 0.5$ V; choosing $V_{b1}$ so that $V_X \approx 0.5$–0.6 V satisfies both. So the input CM can be zero (even slightly negative), a key advantage of the PMOS-input folded cascode.
