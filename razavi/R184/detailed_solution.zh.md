# 详细步骤 - R184

**思路。** 两个输入连在一起，因此激励是纯共模（common-mode）的。对称电路两半边的电流和电压完全相同，因此在任何输入电平下，差分输出 $V_{out} = V_X - V_Y$ 都为零。跟踪两个输出在扫描过程中的共同电平，只是为了检验物理图像。

### 第 1 步 — 两半边为何完全相同

把左输出端（$M_1$、$M_3$ 的漏极）记为 X，右输出端（$M_2$、$M_4$ 的漏极）记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P。在整个扫描过程中 $V_{in1} = V_{in2} = V_{in,CM}$，因此

$$V_{in1} - V_{in2} = 0 .$$

器件匹配（$M_1 = M_2$，$M_3 = M_4$，$R_1 = R_2$）且输入相等时，两半边服从相同的方程：$M_1$ 和 $M_2$ 所受的电压相同，因此由 P 点的基尔霍夫电流定律（KCL），每个器件分得 $I_{D5}/2$；$M_3$、$M_4$ 的栅极偏置 $V_{b2}$ 相同，源极负反馈（source degeneration）相同，电流也相同，因此它们的源极电压同为 $V_{DD} - R_1I_{D5}/2$，漏极电压也相同。任何微小的输出电导（output conductance）$1/r_O$ 都使这一对称解成为唯一的工作点，因此

$$V_X = V_Y \quad\Longrightarrow\quad V_{out} = V_X - V_Y = 0 .$$

共模输入对两半边的作用完全相同，因此没有可供放大的差值：这正是完全匹配的差分对所具有的共模抑制。

### 第 2 步 — 两个输出的共同电平（仅供参考）

设 $I_P$ 为工作在饱和区（saturation region）的带源极负反馈 PMOS 负载的电流，即方程 $I_P = \tfrac12\mu_pC_{ox}(W/L)_3(V_{DD} - I_PR_1 - V_{b2} - |V_{THP}|)^2$ 的解；$I_{SS}$ 为饱和时的尾电流；标称设计取 $2I_P = I_{SS}$。示例设计（尺寸可自由选取）：$\beta_n = \mu_nC_{ox}(W/L)_{1,2} = 2\ \mathrm{mA/V^2}$；$V_{b1} = 1$ V，$\mu_nC_{ox}(W/L)_5 = 4.44\ \mathrm{mA/V^2}$，因此 $I_{SS} = \tfrac12(4.44\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 200\ \mu$A；$R_1 = R_2 = 5\ \mathrm{k}\Omega$，$V_{b2} = 1.4$ V，$\mu_pC_{ox}(W/L)_{3,4} = 2.22\ \mathrm{mA/V^2}$，因此 $I_P = 100\ \mu$A。

**(a) $V_{in,CM} < V_{THN} = 0.7$ V。** $V_{GS1} = V_{in,CM} - V_P \le V_{in,CM} < 0.7$ V，因此 $M_1$ 和 $M_2$ 截止。负载中没有电流，$R_1$、$R_2$ 上没有压降；PMOS 的沟道仍然导通（因为 $V_{SG} = 3 - 1.4 = 1.6\ \mathrm{V} > 0.8$ V），只有当 $V_{SD} = 0$ 时其电流才为零：

$$V_X = V_Y = V_{DD} = 3\ \mathrm{V}.$$

**(b) $V_{in,CM}$ 略高于 0.7 V。** 输入器件导通，但 $V_P$ 仍然很小，因此 $M_5$ 处于线性区（triode region），尾电流小于 $I_{SS}$。每个负载提供 $I_{D5}/2 < I_P$，因此 PMOS 器件处于线性区，输出从 $V_{DD}$ 开始下降。

**算例：$V_{in,CM} = 1.0$ V。** 对 P 点列 KCL（$M_5$ 处于线性区），并利用 $M_1$ 饱和的条件：

$$
\begin{aligned}
2I_{D1} &= (4.44\ \mathrm{mA/V^2})\left[(1.0 - 0.7)V_P - \tfrac12V_P^2\right],\\
I_{D1} &= \tfrac12(2\ \mathrm{mA/V^2})(1.0 - V_P - 0.7)^2 .
\end{aligned}
$$

求解（对 $V_P$ 试值）得 $V_P = 0.082$ V。验证：

$$
\begin{aligned}
I_{D1} &= (1\ \mathrm{mA/V^2})(0.218\ \mathrm{V})^2 = 47.4\ \mu\mathrm{A},\\
(4.44\ \mathrm{mA/V^2})[0.3(0.082) - 0.5(0.082)^2] &= (4.44\ \mathrm{mA/V^2})(0.0213\ \mathrm{V^2}) = 94.8\ \mu\mathrm{A} = 2(47.4\ \mu\mathrm{A}).\ \checkmark
\end{aligned}
$$

$M_3$ 处于线性区，电流为 47.4 µA，由 $V_{SD} = V_{ov} - \sqrt{V_{ov}^2 - 2I/\beta}$（线性区方程的较小根）得：

$$
\begin{aligned}
V_{S3} &= 3 - (47.4\ \mu\mathrm{A})(5\ \mathrm{k}\Omega) = 2.763\ \mathrm{V},\\
V_{SG3} - |V_{THP}| &= 2.763 - 1.4 - 0.8 = 0.563\ \mathrm{V},\\
V_{SD3} &= 0.563 - \sqrt{0.563^2 - \frac{2(47.4\ \mu\mathrm{A})}{2.22\ \mathrm{mA/V^2}}} = 0.563 - \sqrt{0.317 - 0.043} = 0.039\ \mathrm{V},\\
V_X = V_Y &= 2.763 - 0.039 = 2.72\ \mathrm{V}.
\end{aligned}
$$

**(c) $M_5$ 进入饱和。** 当 $V_P$ 达到 $V_{b1} - V_{THN} = 0.3$ V 时，尾电流管提供全部 $I_{SS}$，每边流过 $I_{SS}/2 = I_P$，因此负载到达饱和边缘，$V_X = V_Y = V_{b2} + |V_{THP}| = 2.2$ V。$M_1$ 以电流 $I_P$ 饱和：

$$
\begin{aligned}
V_{ov1} &= \sqrt{\frac{2I_P}{\beta_n}} = \sqrt{\frac{2(100\ \mu\mathrm{A})}{2\ \mathrm{mA/V^2}}} = 0.316\ \mathrm{V},\\
V_{in,CM} &= V_P + V_{THN} + V_{ov1} = 0.3 + 0.7 + 0.316 = 1.32\ \mathrm{V}.
\end{aligned}
$$

**(d) $V_{in,CM} > 1.32$ V。** 所有器件都饱和，尾电流固定为 $I_{SS}$，每个负载都是电流源 $I_P$。在 $\lambda = 0$ 且恰好 $2I_P = I_{SS}$ 时，平方律（square law）不再能确定输出电平。在实际电路中，它取决于 $2I_P$ 与 $I_{SS}$ 的相对大小：若前者略大，输出停在 $V_{b2} + |V_{THP}|$ 附近，负载刚好处于线性区；若前者略小，输出下降，直到输入对管（可能还有尾电流管）进入线性区。这就是这类放大器需要**共模反馈**的原因。无论这一电平是多少，两边总是相同的，因此 $V_{out}$ 不受影响。

**共同电平**（示例设计）：

| $V_{in,CM}$ (V) | 状态 | $V_X = V_Y$ (V) | $V_{out}$ (V) |
|---|---|---|---|
| 0 到 0.7 | $M_1$、$M_2$ 截止 | 3.00 | 0 |
| 0.8 | 差分对导通；$M_5$、$M_3$、$M_4$ 处于线性区 | 2.96 | 0 |
| 1.0 | 同上 | 2.72 | 0 |
| 1.2 | 同上 | 2.41 | 0 |
| 1.32 | $M_5$ 和负载进入饱和区 | 2.20 | 0 |
| 1.32 到 3 | 全部饱和；电平由 $2I_P$ 与 $I_{SS}$ 的相对大小决定（需要 CMFB） | 理想模型无法确定 | 0 |

### 结果

$$V_{out} = 0 \quad\text{for the whole sweep } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

相等的输入加到对称电路上，两个输出端的电压完全相同，因此草图就是一条落在横轴上的水平线。作为参考，两个输出的共同电平在 $M_1$、$M_2$ 截止时（$V_{in,CM} < 0.7$ V）为 $V_{DD}$，差分对导通后开始下降；一旦所有器件都饱和，它就由 PMOS 电流源的电流与尾电流之间的平衡决定。没有共模反馈时这一电平并不确定，但两边始终相同。

**常见错误。** 只画出一个输出，例如差分对导通时从 3 V 开始下降的 $V_X$，并把它当作 $V_{out}$。那是输出的共模电平（common-mode level）；两个输出之差为零。

**常见错误。** 认为扫描过程中尾电流或偏置电流的变化会使 $V_{out}$ 变化。任何这类变化对两半边的作用都相同，在 $V_X - V_Y$ 中相互抵消；只有失配（mismatch）才会产生非零输出，而题目已排除了失配。
