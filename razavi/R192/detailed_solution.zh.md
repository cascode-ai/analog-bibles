# 详细步骤 - R192

**思路。** 两个输入连在一起，因此激励是纯共模（common-mode）的；完全对称的电路两半边的电流和节点电压都相同。因此差分输出 $V_{out} = V_X - V_Y$ 在整个扫描过程中都为零。下面用基尔霍夫电流定律（KCL）说明这一点，并跟踪两个输出的共同电平（它确实会变化）以供参考。

### 第 1 步 — 两半边服从相同的方程

把左输出端（$M_1$、$M_3$、$M_5$ 的漏极）记为 X，右输出端记为 Y，$M_1$、$M_2$ 的公共源极节点记为 P。在整个扫描过程中 $V_{in1} = V_{in2} = V_{in,CM}$。

$M_1$ 和 $M_2$ 的栅极电压（$V_{in,CM}$）和源极电压（P）相同，尺寸也相同，因此只要它们的漏极电压相等，电流就相等：$I_{D1} = I_{D2} = I_{D7}/2$。X 点的 KCL 给出 $I_{D1} = I_{D5} + I_{D3}$，Y 点的 KCL 给出 $I_{D2} = I_{D6} + I_{D4}$；由于 $M_5$、$M_6$ 的栅极偏置 $V_{b1}$ 和源极 $V_{DD}$ 都相同，而 $M_3$、$M_4$ 是相同的二极管，两式右边是节点电压的同一个函数。在 $I_{D1} = I_{D2}$ 时两个 KCL 方程完全相同，因此

$$V_X = V_Y \quad\Longrightarrow\quad V_{out} = V_X - V_Y = 0 .$$

共模输入使两半边以完全相同的方式变化，因此差值始终为零：这就是理想的共模抑制。

### 第 2 步 — 输出的共同电平（仅供参考）

每个输出端都从两个并联的 PMOS 器件得到电流：电流源（$M_5$，最多提供 $I_P$）和二极管（$M_3$），因此其电压取决于 $I_{D1} = I_{D7}/2$ 与 $I_P$ 的相对大小。

**(a) $I_{D1} < I_P$**（差分对截止，$V_{in,CM} < V_{THN} = 0.7$ V，或刚开始导通）。仅 $M_5$ 一个器件能提供的电流就超过了 $M_1$ 吸取的电流，而二极管连接（diode-connected）的 PMOS 只能向 X 输出电流，因此 $M_3$ 截止。$M_5$ 多余的电流把 X 充电抬高，直到 $M_5$ 退出饱和区（saturation region），其线性区（triode region）电流降到 $I_{D1}$；由于 $I_{D1}$ 很小，$M_5$ 只需要很小的 $V_{SD}$，因此

$$V_X = V_Y \approx V_{DD} = 3\ \mathrm{V}.$$

只要尾电流（tail current）小于 $2I_P$，这种状态就会持续。

**(b) $I_{D1} > I_P$**（尾电流大于 $2I_P$）。$M_5$ 饱和并提供 $I_P$，其余部分 $I_{D3} = I_{D1} - I_P$ 由二极管提供：

$$
\begin{aligned}
I_{D1} - I_P &= \tfrac12\beta_p\left(V_{DD} - V_X - |V_{THP}|\right)^2\\
V_X = V_Y &= V_{DD} - |V_{THP}| - \sqrt{\frac{2(I_{D1} - I_P)}{\beta_p}}, \qquad \beta_p = \mu_pC_{ox}\left(\frac WL\right)_{3,4}.
\end{aligned}
$$

随着二极管电流从零开始增大，电平从接近 $V_{DD}$ 迅速下降到略低于 $V_{DD} - |V_{THP}| = 2.2$ V。

**(c) 尾电流管饱和。** 一旦 $M_7$ 饱和，$I_{D1} = I_{SS}/2$，电平变为常数：

$$V_X = V_Y = V_{DD} - |V_{THP}| - \sqrt{\frac{2(I_{SS}/2 - I_P)}{\beta_p}} .$$

**示例数值：** $I_{SS} = 1$ mA，$I_P = 0.4$ mA，$\beta_p = (38.4\ \mu\mathrm{A/V^2})(50/0.5) = 3.84\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
\sqrt{\frac{2(0.5 - 0.4)\ \mathrm{mA}}{3.84\ \mathrm{mA/V^2}}} &= \sqrt{0.0521\ \mathrm{V^2}} = 0.228\ \mathrm{V},\\
V_X = V_Y &= 3 - 0.8 - 0.228 = 1.97\ \mathrm{V}.
\end{aligned}
$$

在约 $V_{in,CM} = V_X + V_{THN} \approx 2.7$ V 以上，输入器件进入线性区，但饱和的尾电流管仍迫使每个输入器件流过 $I_{SS}/2$，因此电平保持不变（只要 $M_7$ 保持饱和）。

| $V_{in,CM}$ | 尾电流 | 负载状态 | $V_X = V_Y$ | $V_{out}$ |
|---|---|---|---|---|
| 低于 0.7 V | 0 | 二极管截止，$M_5$/$M_6$ 处于线性区且电流为零 | $V_{DD}$ | 0 |
| 差分对开始导通 | 小于 $2I_P$ | 二极管截止 | 略低于 $V_{DD}$ | 0 |
| 更高 | 介于 $2I_P$ 与 $I_{SS}$ 之间 | 二极管导通 | 降到 2.2 V 以下 | 0 |
| 尾电流管饱和 | $I_{SS}$ | 二极管流过 $I_{SS}/2 - I_P$ | $V_{DD} - \lvert V_{THP}\rvert - \sqrt{2(I_{SS}/2 - I_P)/\beta_p}$（本例中为 1.97 V） | 0 |

### 结果

$$V_{out} = 0 \quad\text{for the whole sweep } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

相等的输入加到对称电路上，两个输出端的电压完全相同，因此草图就是一条落在横轴上的水平线。作为参考，输出的共同电平：

- 在差分对的电流小于 $2I_P$ 时位于 $V_{DD}$（PMOS 电流源把输出拉高，二极管截止）；
- 二极管导通后降到 $V_{DD} - |V_{THP}|$ 以下；
- 尾电流管饱和后稳定在 $V_{DD} - |V_{THP}| - \sqrt{2(I_{SS}/2 - I_P)/\beta_p}$。

**常见错误。** 只画出一个输出（例如它从 $V_{DD}$ 下降到约 1.97 V 的过程），并把它当作 $V_{out}$。那是输出的共模电平（common-mode level）；两个输出之差为零。

**常见错误。** 以扫描过程中二极管导通或尾电流变化为由，预测 $V_{out}$ 不为零。每一个这样的变化都在两半边中完全相同地发生，在 $V_X - V_Y$ 中相互抵消。
