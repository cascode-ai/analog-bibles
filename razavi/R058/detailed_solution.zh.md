# 详细步骤 - R058

思路： 节点 X 只接 $M_1$ 的栅极和电容 $C_1$，因此 $C_1$ 上的电荷不能改变，$V_X - V_Y$ 始终等于 $V_{GS1}$。负的输入阶跃经 $C_2$ 全部耦合到 Y，X 随之变化。然后检查阶跃后 $M_1$ 的工作区：如果它仍然饱和，就仍然恰好流过 $I_1$，没有净电流流入 $C_2$，此后一切都不再变化。

### 第 1 步 — 初始状态

在 $t = 0$ 之前，$M_1$ 流过 $I_1$，且 $V_{DS1} = V_{DD} - V_Y = V_{GS1}$，因此它处于饱和区；由于 $\lambda = 0$，

$$I_1 = \frac{\beta}{2}(V_{GS1} - V_{TH})^2 \quad\Longrightarrow\quad V_{GS1} = V_{TH} + \sqrt{\frac{2I_1}{\beta}} .$$

令过驱动电压（overdrive voltage）$V_{ov} = \sqrt{2I_1/\beta}$，初始时

$$V_X(0^-) = V_{DD}, \qquad V_Y(0^-) = V_{DD} - V_{GS1} = V_{DD} - V_{TH} - V_{ov} .$$

### 第 2 步 — 节点 X 浮空，因此 $V_X - V_Y$ 恒定

$M_1$ 的栅极不吸取电流（忽略其电容），因此唯一可能向 X 注入电流的元件是 $C_1$，而该电流无处可去：

$$C_1\frac{d(V_X - V_Y)}{dt} = 0 \quad\Longrightarrow\quad V_X(t) - V_Y(t) = V_{GS1}\ \text{for all}\ t .$$

$C_1$ 的作用相当于一个浮动电池：X 复制 Y 的每一次变化，$M_1$ 的栅源电压永不改变。

### 第 3 步 — $t = 0$ 时的跳变

在 $t = 0$ 时，$V_{in}$ 下降 $V_0 = V_{TH}$。有限的电流不能使 $C_2$ 两端的电压瞬间改变，而且没有电荷能经 $C_1$ 流到浮空节点 X，因此整个阶跃都出现在 Y 上，X 随之变化：

$$V_Y(0^+) = V_Y(0^-) - V_{TH} = V_{DD} - V_{GS1} - V_{TH}, \qquad V_X(0^+) = V_{DD} - V_{TH} .$$

### 第 4 步 — 阶跃后 $M_1$ 的工作区

阶跃刚过时：

$$
\begin{aligned}
V_{GS1} &= V_X - V_Y,\\
V_{DS1} &= V_{DD} - V_Y(0^+) = V_{GS1} + V_{TH} .
\end{aligned}
$$

由于

$$V_{GS1} + V_{TH} \;>\; V_{GS1} \;>\; V_{GS1} - V_{TH},$$

$M_1$ 仍然饱和，而且裕量比以前更大：它的源极电位下降了，而漏极仍在 $V_{DD}$。由于 $\lambda = 0$，其电流只取决于不变的 $V_{GS1}$：

$$I_{M1} = \frac{\beta}{2}(V_{GS1} - V_{TH})^2 = I_1 .$$

### 第 5 步 — 在节点 Y 列 KCL：阶跃后一切不再变化

当 $t > 0$ 时 $V_{in}$ 恒定，因此从 $C_2$ 流入 Y 的电流为 $C_2\,d(V_{in} - V_Y)/dt = -C_2\,dV_Y/dt$，而 $C_1$ 中没有电流（第 2 步）。在节点 Y 列 KCL，并代入 $I_{M1} = I_1$：

$$I_{M1} - C_2\frac{dV_Y}{dt} = I_1 \quad\Longrightarrow\quad C_2\frac{dV_Y}{dt} = I_{M1} - I_1 = 0 \quad\Longrightarrow\quad \frac{dV_Y}{dt} = 0 .$$

$M_1$ 提供的电流恰好等于 $I_1$ 吸取的电流，因此 $C_2$ 既不充电也不放电，Y（以及 X）无限期地保持在阶跃后的数值：没有电阻或其他直流通路能把节点拉回去。

这里假设电流源（current source）$I_1$ 两端仍有足够的电压使其正常工作，即 $V_Y(0^+) = V_{DD} - 2V_{TH} - V_{ov}$ 仍高于 $I_1$ 所需的最低电压。

### 第 6 步 — 波形

| 时间 | $V_X$ | $V_Y$ |
|---|---|---|
| $t < 0$ | $V_{DD}$ | $V_{DD} - V_{TH} - \sqrt{2I_1/\beta}$ |
| $t > 0$（恒定） | $V_{DD} - V_{TH}$ | $V_{DD} - 2V_{TH} - \sqrt{2I_1/\beta}$ |

![负阶跃下的 $V_X$ 波形](/q/R058/solution-vx.zh.svg)

![负阶跃下的 $V_Y$ 波形](/q/R058/solution-vy.zh.svg)

两者都是阶跃函数：先是平的，在 $t = 0$ 时突然下降恰好 $V_{TH}$，然后又是平的，两者始终相差 $V_{GS1}$。

数值示例。 假设 $V_{DD} = 3$ V，$V_{TH} = 0.7$ V，$\beta = 1\ \mathrm{mA/V^2}$，$I_1 = 0.1$ mA：

$$V_{ov} = \sqrt{\frac{2(0.1\ \mathrm{mA})}{1\ \mathrm{mA/V^2}}} = 0.447\ \mathrm{V}, \qquad V_{GS1} = 0.7 + 0.447 = 1.147\ \mathrm{V}.$$

$V_X$：之前为 3 V，之后为 2.3 V。$V_Y$：之前为 1.853 V，之后为 1.153 V。$M_1$ 的 $V_{DS}$ 从 1.147 V 增大到 1.847 V，仍远高于 $V_{ov} = 0.447$ V。

与正阶跃的对比。 大于 $V_{TH}$ 的正阶跃会使 Y 升向 $V_{DD}$，把 $V_{DS1}$ 压缩到 $V_{ov}$ 以下，使 $M_1$ 进入线性区（triode region）；随后电流的不足部分会使 $C_2$ 放电。负阶跃只会增大 $V_{DS1}$，因此 $M_1$ 保持饱和，节点停留在阶跃把它们带到的位置。（若 $\lambda$ 不为零，较大的 $V_{DS1}$ 会使 $M_1$ 流过的电流略大于 $I_1$，Y 会缓慢上升；在 $\lambda = 0$ 时它严格保持不变。）

### 结果

在 $t = 0$ 时两个节点都下降 $V_{TH}$，然后保持不变：

$$V_X = V_{DD} - V_{TH}, \qquad V_Y = V_{DD} - V_{GS1} - V_{TH} = V_{DD} - 2V_{TH} - \sqrt{2I_1/\beta}\qquad(t > 0).$$

原因：$C_1$ 无法放电（节点 X 没有电流通路），因此 $V_{GS1}$ 不变。$M_1$ 的 $V_{DS}$ 增大到 $V_{GS1} + V_{TH}$，它保持饱和并恰好流过 $I_1$（$\lambda = 0$），因此没有净电流流入 $C_2$，电压不再变化。

常见错误： 让 $V_X$ 保持在 $V_{DD}$。X 只连接 $C_1$ 和一个绝缘的栅极，因此 $C_1$ 两端的电压固定，X 必须随 Y 一起下降。

常见错误： 预测电压会恢复到原来的数值。$M_1$ 处于饱和区且 $V_{GS}$ 不变，因此它恰好提供 $I_1$，没有任何元件能提供给 $C_2$ 重新充电所需的净电流。

常见错误： 让两个节点向相反方向变化或变化量不同。由于 X 浮空，$C_1$ 只是一个电平移位器（level shifter），因此两个节点沿同一方向变化相同的 $V_{TH}$。
