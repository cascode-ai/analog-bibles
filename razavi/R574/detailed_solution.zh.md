# 详细步骤 - R574

**思路。** $M_1$ 以工作在饱和区的源极跟随器（source follower）方式给 $C_H$ 充电，其跨导 $g_{m1} = \beta(V_{GS} - V_{TH})$ 取决于 $V_{out}$ 已经上升了多少。由大信号充电方程求出 $V_{out}(t)$，代入 $g_{m1}$，再描述所得的曲线。

### 第 1 步 — 工作区以及用 $V_{out}$ 表示的 $g_m$

CK 上升后，栅极和输入端都处于 $V_{DD} = 3$ V，电位较低的端口即输出端是源极，因此 $V_{GS} = V_{DS} = V_{DD} - V_{out}$，只要 $M_1$ 导通就处于饱和区。因此

$$g_{m1} = \frac{\partial I_D}{\partial V_{GS}} = \beta(V_{GS} - V_{TH}) = \beta\left(V_{DD} - V_{TH} - V_{out}\right),$$

$$\beta = \mu_nC_{ox}\frac WL = (134\ \mu\mathrm{A/V^2})(40) = 5.36\ \mathrm{mA/V^2}.$$

在 $t = 0$ 之前，$V_{GS} = 0 < V_{TH}$，因此 $g_{m1} = 0$。

### 第 2 步 — 由大信号方程求 $V_{out}(t)$

漏极电流给 $C_H$ 充电：

$$C_H\frac{dV_{out}}{dt} = \frac12\beta\left(V_{DD} - V_{TH} - V_{out}\right)^2 .$$

记过驱动电压为 $w = V_{DD} - V_{TH} - V_{out}$，且 $dw/dt = -dV_{out}/dt$：

$$\frac{dw}{dt} = -\frac{\beta}{2C_H}w^2 .$$

分离变量，并从 $w(0) = w_0 = V_{DD} - V_{TH} = 2.3$ V 开始积分：

$$
\begin{aligned}
\int_{w_0}^{w}\frac{dw'}{w'^2} &= -\frac{\beta}{2C_H}\int_0^t dt'\\
-\frac1w + \frac1{w_0} &= -\frac{\beta}{2C_H}t\\
w(t) &= \frac{1}{\dfrac{\beta}{2C_H}t + \dfrac{1}{w_0}} .
\end{aligned}
$$

### 第 3 步 — 跨导随时间的变化

由 $g_{m1} = \beta w$：

$$g_{m1}(t) = \frac{\beta}{\dfrac{\beta}{2C_H}t + \dfrac{1}{w_0}} = \frac{\beta w_0}{1 + \dfrac{\beta w_0}{2C_H}t} = \frac{g_{m0}}{1 + t/\tau_0},$$

其中

$$
\begin{aligned}
g_{m0} &= \beta(V_{DD} - V_{TH}) = (5.36\ \mathrm{mA/V^2})(2.3\ \mathrm{V}) = 12.3\ \mathrm{mS}\quad(1/g_{m0} = 81\ \Omega),\\
\tau_0 &= \frac{2C_H}{g_{m0}} = \frac{2\times1\ \mathrm{pF}}{12.3\ \mathrm{mS}} = 162\ \mathrm{ps}.
\end{aligned}
$$

**为什么是 $2C_H/g_{m0}$ 而不是 $C_H/g_{m0}$。** 大信号电流为 $I_D = \tfrac12\beta w^2 = \tfrac12g_m w$，只是 $g_m$ 与过驱动电压乘积的**一半**，因此过驱动电压以 $g_m/(2C_H)$ 的速率减小。若把 $1/g_m$ 当作大信号充电电阻，就会错误地得到 81 ps。

等价地，其倒数随时间线性增大：

$$\frac{1}{g_{m1}(t)} = \frac{1}{g_{m0}} + \frac{t}{2C_H} = 81\ \Omega + \frac{t}{2\ \mathrm{pF}} .$$

### 第 4 步 — 草图所用的数值

| $t$ (ns) | $g_{m1}$ (mS) | $1/g_{m1}$ (Ω) | $V_{out}$ (V) |
|---|---|---|---|
| 0⁻ | 0 | ∞ | 0 |
| 0⁺ | 12.3 | 81 | 0 |
| 0.16 ($= \tau_0$) | 6.2 | 162 | 1.15 |
| 0.3 | 4.3 | 231 | 1.49 |
| 0.5 | 3.0 | 331 | 1.74 |
| 1.0 | 1.7 | 581 | 1.98 |
| 1.7 | 1.07 | 931 | 2.10 |
| 3.0 | 0.63 | 1581 | 2.18 |
| 5.0 | 0.39 | 2581 | 2.23 |

（例如，在 $t = 1$ ns 时：$g_{m1} = 12.3\ \mathrm{mS}/(1 + 1000/162) = 12.3/7.17 = 1.72$ mS。）

当 $t \gg \tau_0$ 时，

$$g_{m1} \approx \frac{g_{m0}\tau_0}{t} = \frac{2C_H}{t},$$

例如 5 ns 时为 $2\ \mathrm{pF}/5\ \mathrm{ns} = 0.4$ mS：随着 $V_{out} \to V_{DD} - V_{TH}$，$g_{m1}$ 趋于零，因为过驱动电压消失了。

### 第 5 步 — 曲线草图

以 $t$（0 到几 ns）为横轴，画出 $g_{m1}$（0 到约 13 mS）：

- **$t < 0$ 时**：$g_{m1} = 0$（开关断开）。
- **$t = 0$ 时**：垂直跳变到 $g_{m0} = 12.3$ mS（理想时钟边沿；$V_{out}$ 仍为 0）。
- **$t > 0$ 时**：单调的**双曲线**衰减，$g_{m0}/(1 + t/\tau_0)$。它在 $\tau_0 = 0.16$ ns 处减半，其初始切线（斜率 $-g_{m0}/\tau_0 = -76$ mS/ns）在 $\tau_0$ 处降到零，1 ns 时降到 1.7 mS，1.7 ns 时（此时 $V_{out} = 2.1$ V）降到 1.07 mS。
- **拖尾**：按 $2C_H/t$ 趋于零，比指数函数慢得多；初始斜率相同的指数函数到 1 ns 时已降到 0.026 mS，而实际曲线仍为 1.7 mS。

在 $1/g_{m1}$ 的曲线上，同样的信息表现为一条从 81 Ω 出发、斜率为 $1/(2C_H) = 0.5\ \Omega/\mathrm{ps}$ 的直线。由于该电阻无限增大，充电过程无法用单一时间常数描述。

### 结果

$$g_{m1}(t) = \beta\left(V_{DD} - V_{out} - V_{TH}\right) = \frac{g_{m0}}{1 + t/\tau_0},$$

其中 $g_{m0} = \beta(V_{DD} - V_{TH}) = 12.3$ mS（$1/g_{m0} = 81\ \Omega$），$\tau_0 = 2C_H/g_{m0} = 162$ ps。

- CK 上升之前 $g_m = 0$。在 $t = 0$ 时它跳变到 12.3 mS，然后按双曲线规律（而不是指数规律）衰减：0.16 ns 时为 6.2 mS，0.5 ns 时为 3.0 mS，1 ns 时为 1.7 mS，1.7 ns 时为 1.07 mS（$V_{out} = 2.1$ V），5 ns 时为 0.39 mS。
- 当 $t \gg \tau_0$ 时，随着 $V_{out} \to V_{DD} - V_{TH}$，$g_m \approx 2C_H/t \to 0$。
- 等价地，$1/g_m = 81\ \Omega + t/(2\ \mathrm{pF})$ 随时间线性增大，这就是充电过程无法用单一时间常数描述的原因。

**常见错误。** 把 $g_m$ 画成常数，或者画成稳定在某个非零值。在这种源极跟随器结构中，随着输出升高，过驱动电压本身被消耗掉，因此 $g_m = \beta V_{ov} \to 0$。

**常见错误。** 画成时间常数为 $C_H/g_{m0} = 81$ ps 的指数衰减，好像 $1/g_m$ 是固定的充电电阻。方程对过驱动电压是二次的，因此得到 $1/(1 + t/\tau_0)$ 规律，其中 $\tau_0 = 2C_H/g_{m0} = 162$ ps，并带有长长的 $1/t$ 拖尾。

**常见错误。** 因为输出电压升高就把 $g_m$ 画成随时间增大。实际上**过驱动电压** $V_{DD} - V_{TH} - V_{out}$ 在减小，漏极电流和 $g_m$ 也随之减小。
