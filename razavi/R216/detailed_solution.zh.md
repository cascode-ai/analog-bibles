# 详细步骤 - R216

**思路。** 对给定的表达式取 $R_{SS} \to \infty$ 的极限，保留主导项。然后直接由小信号方程分析一个尾电流源**理想**（$i_1 + i_2 = 0$）、跨导不相等的差分对，比较两个结果，并检查同一极限下的共模到差分转换。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 和 $M_2$ 的漏极分别记为 X 和 Y，它们的公共源极节点记为 P，则 $v_{out} = v_X - v_Y$。在 $\lambda = \gamma = 0$ 时，

$$i_1 = g_{m1}(v_{in1} - v_P), \qquad i_2 = g_{m2}(v_{in2} - v_P), \qquad v_X = -R_Di_1,\quad v_Y = -R_Di_2,$$

因此 $v_{out} = -R_D(i_1 - i_2)$，$R_{SS}$ 从 P 接地。

### 第 2 步 — 给定公式的来历（仅供参考）

P 点的基尔霍夫电流定律（KCL）给出 $i_1 + i_2 = v_P/R_{SS}$。对于 $v_{in1} = v_d/2$、$v_{in2} = -v_d/2$：

$$
\begin{aligned}
(g_{m1} - g_{m2})\frac{v_d}{2} - (g_{m1} + g_{m2})v_P &= \frac{v_P}{R_{SS}}\\
v_P &= \frac{(g_{m1} - g_{m2})\,v_d/2}{g_{m1} + g_{m2} + 1/R_{SS}} .
\end{aligned}
$$

于是 $i_1 - i_2 = (g_{m1} + g_{m2})\dfrac{v_d}{2} - (g_{m1} - g_{m2})v_P$；通分，利用 $(g_{m1} + g_{m2})^2 - (g_{m1} - g_{m2})^2 = 4g_{m1}g_{m2}$，并将分子分母同乘以 $R_{SS}$：

$$|A_{DM}| = \frac{R_D}{2}\cdot\frac{(g_{m1} + g_{m2})^2 + (g_{m1} + g_{m2})/R_{SS} - (g_{m1} - g_{m2})^2}{g_{m1} + g_{m2} + 1/R_{SS}} = \frac{R_D}{2}\cdot\frac{g_{m1} + g_{m2} + 4g_{m1}g_{m2}R_{SS}}{1 + (g_{m1} + g_{m2})R_{SS}},$$

这就是给定的表达式。

### 第 3 步 — 极限 $R_{SS} \to \infty$

分子分母同除以 $R_{SS}$：

$$|A_{DM}| = \frac{R_D}{2}\cdot\frac{(g_{m1} + g_{m2})/R_{SS} + 4g_{m1}g_{m2}}{1/R_{SS} + g_{m1} + g_{m2}}\ \xrightarrow{\ R_{SS}\to\infty\ }\ \frac{R_D}{2}\cdot\frac{4g_{m1}g_{m2}}{g_{m1} + g_{m2}} ,$$

因此

$$|A_{DM}|_{R_{SS}\to\infty} = \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}} = \frac{2R_D}{\dfrac{1}{g_{m1}} + \dfrac{1}{g_{m2}}} .$$

这是 $R_D$ 乘以两个跨导的**调和平均值**；当 $g_{m1} = g_{m2} = g_m$ 时为 $g_mR_D$。对于小失配 $g_{m1,2} = g_m \pm \Delta g_m/2$，它等于 $R_D\left[g_m - \Delta g_m^2/(4g_m)\right]$，与 $g_mR_D$ 只相差二阶小量。

### 第 4 步 — 理想尾电流源、$g_{m1} \ne g_{m2}$ 时的直接分析

理想尾电流源不流过信号电流，因此 P 点的 KCL 给出 $i_1 + i_2 = 0$：

$$
\begin{aligned}
g_{m1}(v_{in1} - v_P) + g_{m2}(v_{in2} - v_P) &= 0\\
v_P &= \frac{g_{m1}v_{in1} + g_{m2}v_{in2}}{g_{m1} + g_{m2}} .
\end{aligned}
$$

于是

$$i_1 = g_{m1}(v_{in1} - v_P) = g_{m1}\frac{(g_{m1} + g_{m2})v_{in1} - g_{m1}v_{in1} - g_{m2}v_{in2}}{g_{m1} + g_{m2}} = \frac{g_{m1}g_{m2}}{g_{m1} + g_{m2}}(v_{in1} - v_{in2}),$$

$i_2 = -i_1$，且

$$v_{out} = -R_D(i_1 - i_2) = -2R_Di_1 = -\frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}}(v_{in1} - v_{in2}).$$

等价地，用叠加原理：只加 $v_{in1}$ 时，$M_1$ 是一个以从 $M_2$ 源极看进去的 $1/g_{m2}$ 为源极负反馈的共源级，因此两个器件流过方向相反的电流 $i = v_{in1}/(1/g_{m1} + 1/g_{m2})$，$v_X - v_Y = -2R_Dv_{in1}/(1/g_{m1} + 1/g_{m2})$；只加 $v_{in2}$ 时结果相同，但符号相反。

### 第 5 步 — 比较与共模特性

理想尾电流源下的结果

$$|A_{DM}| = \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}},$$

与 $R_{SS} \to \infty$ 的极限**完全相同**，因此**可以**：用尾电流源理想、$g_{m1} \ne g_{m2}$ 的差分对能得到同样的结果。

在理想尾电流源下，$v_{out}$ 只取决于 $v_{in1} - v_{in2}$，因此共模输入不产生输出。当 $R_{SS}$ 有限时，共模输入 $v_c$ 给出

$$v_c - v_P = \frac{v_c}{1 + (g_{m1} + g_{m2})R_{SS}}, \qquad v_{out} = -R_D(g_{m1} - g_{m2})\frac{v_c}{1 + (g_{m1} + g_{m2})R_{SS}},$$

即共模到差模的增益为 $\Delta g_mR_D/[1 + (g_{m1} + g_{m2})R_{SS}]$，它在 $R_{SS} \to \infty$ 时趋于零，因此 CMRR 变为无穷大。无穷大的尾电流源阻抗意味着始终有 $i_1 = -i_2$，这正是理想尾电流源的条件，因此仅有 $g_m$ 失配时，共模输入无法改变任何一个漏极电流。

### 结果

当 $R_{SS} \to \infty$ 时：

$$|A_{DM}| \to \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}} = \frac{2R_D}{1/g_{m1} + 1/g_{m2}},$$

当两个跨导相等时，它等于 $g_mR_D$。共模到差模的转换 $\Delta g_mR_D/[1 + (g_{m1} + g_{m2})R_{SS}]$ 趋于零，因此 CMRR → ∞。

**可以**：用理想尾电流源（$i_1 + i_2 = 0$）且 $g_{m1} \ne g_{m2}$ 进行分析，得到的增益完全相同，因为无穷大的尾电流源阻抗**正是**理想尾电流源的条件。

**常见错误。** 因为 $R_{SS}$ 同时出现在分子和分母中，就断定增益趋于零或无穷大。分子和分母都随 $R_{SS}$ 线性增长，因此比值趋于有限的极限。

**常见错误。** 把极限写成按算术平均计算的增益 $\tfrac12(g_{m1} + g_{m2})R_D$。在理想尾电流源下，两个器件实际上是串联的（$1/g_{m1} + 1/g_{m2}$），因此调和平均才是正确的；两者只在失配的一阶近似下一致。

**常见错误。** 认为在理想尾电流源下，仅有 $g_m$ 失配就会使 CMRR 变差。在 $i_1 + i_2 = 0$ 的约束下，共模输入无法改变任何一个电流。
