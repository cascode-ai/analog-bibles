# Detailed solution - R216

**Approach.** Take the limit $R_{SS} \to \infty$ of the given expression, keeping the dominant terms. Then analyse a pair with an *ideal* tail ($i_1 + i_2 = 0$) and unequal transconductances directly from the small-signal equations, compare the two results, and check the common-mode-to-differential conversion in the same limit.

### Step 1 — The small-signal model

Call the drains of $M_1$ and $M_2$ X and Y and their common source node P, so $v_{out} = v_X - v_Y$. With $\lambda = \gamma = 0$,

$$i_1 = g_{m1}(v_{in1} - v_P), \qquad i_2 = g_{m2}(v_{in2} - v_P), \qquad v_X = -R_Di_1,\quad v_Y = -R_Di_2,$$

so $v_{out} = -R_D(i_1 - i_2)$, with $R_{SS}$ from P to ground.

### Step 2 — Where the given formula comes from (for reference)

KCL at P gives $i_1 + i_2 = v_P/R_{SS}$. For $v_{in1} = v_d/2$, $v_{in2} = -v_d/2$:

$$
\begin{aligned}
(g_{m1} - g_{m2})\frac{v_d}{2} - (g_{m1} + g_{m2})v_P &= \frac{v_P}{R_{SS}}\\
v_P &= \frac{(g_{m1} - g_{m2})\,v_d/2}{g_{m1} + g_{m2} + 1/R_{SS}} .
\end{aligned}
$$

Then $i_1 - i_2 = (g_{m1} + g_{m2})\dfrac{v_d}{2} - (g_{m1} - g_{m2})v_P$, and over a common denominator, using $(g_{m1} + g_{m2})^2 - (g_{m1} - g_{m2})^2 = 4g_{m1}g_{m2}$ and multiplying through by $R_{SS}$:

$$|A_{DM}| = \frac{R_D}{2}\cdot\frac{(g_{m1} + g_{m2})^2 + (g_{m1} + g_{m2})/R_{SS} - (g_{m1} - g_{m2})^2}{g_{m1} + g_{m2} + 1/R_{SS}} = \frac{R_D}{2}\cdot\frac{g_{m1} + g_{m2} + 4g_{m1}g_{m2}R_{SS}}{1 + (g_{m1} + g_{m2})R_{SS}},$$

the expression given.

### Step 3 — The limit $R_{SS} \to \infty$

Dividing numerator and denominator by $R_{SS}$:

$$|A_{DM}| = \frac{R_D}{2}\cdot\frac{(g_{m1} + g_{m2})/R_{SS} + 4g_{m1}g_{m2}}{1/R_{SS} + g_{m1} + g_{m2}}\ \xrightarrow{\ R_{SS}\to\infty\ }\ \frac{R_D}{2}\cdot\frac{4g_{m1}g_{m2}}{g_{m1} + g_{m2}} ,$$

so

$$|A_{DM}|_{R_{SS}\to\infty} = \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}} = \frac{2R_D}{\dfrac{1}{g_{m1}} + \dfrac{1}{g_{m2}}} .$$

This is $R_D$ times the **harmonic mean** of the two transconductances, $g_mR_D$ when $g_{m1} = g_{m2} = g_m$. For a small mismatch, $g_{m1,2} = g_m \pm \Delta g_m/2$, it equals $R_D\left[g_m - \Delta g_m^2/(4g_m)\right]$, differing from $g_mR_D$ only to second order.

### Step 4 — Direct analysis with an ideal tail and $g_{m1} \ne g_{m2}$

An ideal tail carries no signal current, so KCL at P gives $i_1 + i_2 = 0$:

$$
\begin{aligned}
g_{m1}(v_{in1} - v_P) + g_{m2}(v_{in2} - v_P) &= 0\\
v_P &= \frac{g_{m1}v_{in1} + g_{m2}v_{in2}}{g_{m1} + g_{m2}} .
\end{aligned}
$$

Then

$$i_1 = g_{m1}(v_{in1} - v_P) = g_{m1}\frac{(g_{m1} + g_{m2})v_{in1} - g_{m1}v_{in1} - g_{m2}v_{in2}}{g_{m1} + g_{m2}} = \frac{g_{m1}g_{m2}}{g_{m1} + g_{m2}}(v_{in1} - v_{in2}),$$

$i_2 = -i_1$, and

$$v_{out} = -R_D(i_1 - i_2) = -2R_Di_1 = -\frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}}(v_{in1} - v_{in2}).$$

Equivalently, by superposition: with $v_{in1}$ alone, $M_1$ is a common-source stage degenerated by the $1/g_{m2}$ looking into the source of $M_2$, so both devices carry $i = v_{in1}/(1/g_{m1} + 1/g_{m2})$ in opposite directions and $v_X - v_Y = -2R_Dv_{in1}/(1/g_{m1} + 1/g_{m2})$; $v_{in2}$ alone gives the same with the opposite sign.

### Step 5 — Comparison and common-mode behaviour

The ideal-tail result,

$$|A_{DM}| = \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}},$$

is **identical** to the $R_{SS} \to \infty$ limit, so **yes**, the same result follows from a pair with an ideal tail and $g_{m1} \ne g_{m2}$.

With the ideal tail $v_{out}$ depends only on $v_{in1} - v_{in2}$, so a common-mode input produces no output. With finite $R_{SS}$, a common-mode input $v_c$ gives

$$v_c - v_P = \frac{v_c}{1 + (g_{m1} + g_{m2})R_{SS}}, \qquad v_{out} = -R_D(g_{m1} - g_{m2})\frac{v_c}{1 + (g_{m1} + g_{m2})R_{SS}},$$

a CM-to-DM gain of $\Delta g_mR_D/[1 + (g_{m1} + g_{m2})R_{SS}]$, which vanishes as $R_{SS} \to \infty$, so the CMRR becomes infinite. An infinite tail impedance means $i_1 = -i_2$ at all times, exactly the ideal-tail condition, so a $g_m$ mismatch alone cannot change either drain current in response to a common-mode input.

### Result

As $R_{SS} \to \infty$:

$$|A_{DM}| \to \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}} = \frac{2R_D}{1/g_{m1} + 1/g_{m2}},$$

which equals $g_mR_D$ when the transconductances are equal. The CM-to-DM conversion $\Delta g_mR_D/[1 + (g_{m1} + g_{m2})R_{SS}]$ vanishes, so CMRR → ∞.

**Yes**, an analysis with an ideal tail ($i_1 + i_2 = 0$) and $g_{m1} \ne g_{m2}$ gives exactly the same gain, because an infinite tail impedance *is* the ideal-tail condition.

**Common mistake.** Concluding that the gain goes to zero or to infinity because $R_{SS}$ appears in both numerator and denominator. Both grow linearly with $R_{SS}$, so the ratio approaches a finite limit.

**Common mistake.** Writing the limit as the arithmetic-mean gain $\tfrac12(g_{m1} + g_{m2})R_D$. With an ideal tail the two devices are effectively in series ($1/g_{m1} + 1/g_{m2}$), so the harmonic mean is correct; the two agree only to first order in the mismatch.

**Common mistake.** Claiming that a $g_m$ mismatch alone degrades the CMRR with an ideal tail. With $i_1 + i_2 = 0$ enforced, a common-mode input cannot change either current.
