# Detailed solution - R216

**Approach.** First take the limit $R_{SS} \to \infty$ of the given expression, keeping only the dominant terms. Then analyse a pair with an *ideal* tail ($i_1 + i_2 = 0$) and unequal transconductances directly from the small-signal equations, and compare the two results. Finally we check what happens to the common-mode-to-differential conversion in the same limit.

### Step 1 — The circuit and its small-signal model

The circuit is a resistively loaded NMOS pair:

- $M_1$: gate at $v_{in1}$, drain X loaded by $R_D$, source at the tail node P.
- $M_2$: gate at $v_{in2}$, drain Y loaded by $R_D$, source at P.
- The tail current source has output resistance $R_{SS}$ from P to ground.
- $\lambda = \gamma = 0$, so each transistor is just a controlled current from drain to source: $i_1 = g_{m1}(v_{in1} - v_P)$ and $i_2 = g_{m2}(v_{in2} - v_P)$.
- Outputs (Ohm's law on the loads): $v_X = -R_Di_1$, $v_Y = -R_Di_2$, and $v_{out} = v_X - v_Y = -R_D(i_1 - i_2)$.

### Step 2 — Where the given formula comes from (for reference)

KCL at P: $i_1 + i_2 = v_P/R_{SS}$. For a differential input $v_{in1} = v_d/2$, $v_{in2} = -v_d/2$:

$$
\begin{aligned}
(g_{m1} - g_{m2})\frac{v_d}{2} - (g_{m1} + g_{m2})v_P &= \frac{v_P}{R_{SS}}\\
v_P &= \frac{(g_{m1} - g_{m2})\,v_d/2}{g_{m1} + g_{m2} + 1/R_{SS}} .
\end{aligned}
$$

Then $i_1 - i_2 = (g_{m1} + g_{m2})\dfrac{v_d}{2} - (g_{m1} - g_{m2})v_P$, and after combining over a common denominator:

$$|A_{DM}| = \frac{R_D}{2}\cdot\frac{(g_{m1} + g_{m2})^2 + (g_{m1} + g_{m2})/R_{SS} - (g_{m1} - g_{m2})^2}{g_{m1} + g_{m2} + 1/R_{SS}} = \frac{R_D}{2}\cdot\frac{g_{m1} + g_{m2} + 4g_{m1}g_{m2}R_{SS}}{1 + (g_{m1} + g_{m2})R_{SS}},$$

which is the expression given. (We used $(g_{m1} + g_{m2})^2 - (g_{m1} - g_{m2})^2 = 4g_{m1}g_{m2}$ and multiplied numerator and denominator by $R_{SS}$.)

### Step 3 — The limit $R_{SS} \to \infty$

Divide the numerator and the denominator by $R_{SS}$:

$$|A_{DM}| = \frac{R_D}{2}\cdot\frac{(g_{m1} + g_{m2})/R_{SS} + 4g_{m1}g_{m2}}{1/R_{SS} + g_{m1} + g_{m2}}\ \xrightarrow{\ R_{SS}\to\infty\ }\ \frac{R_D}{2}\cdot\frac{4g_{m1}g_{m2}}{g_{m1} + g_{m2}} .$$

So

$$|A_{DM}|_{R_{SS}\to\infty} = \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}} = \frac{2R_D}{\dfrac{1}{g_{m1}} + \dfrac{1}{g_{m2}}} .$$

This is $R_D$ times the **harmonic mean** of the two transconductances. It reduces to $g_mR_D$ when $g_{m1} = g_{m2} = g_m$. For a small mismatch, $g_{m1,2} = g_m \pm \Delta g_m/2$, it equals $R_D\left[g_m - \Delta g_m^2/(4g_m)\right]$, which differs from $g_mR_D$ only to second order in the mismatch.

### Step 4 — Direct analysis with an ideal tail and $g_{m1} \ne g_{m2}$

An ideal tail carries a constant current, so its small-signal current is zero. KCL at P:

$$i_1 + i_2 = 0 .$$

Substitute the transistor equations:

$$
\begin{aligned}
g_{m1}(v_{in1} - v_P) + g_{m2}(v_{in2} - v_P) &= 0\\
v_P &= \frac{g_{m1}v_{in1} + g_{m2}v_{in2}}{g_{m1} + g_{m2}} .
\end{aligned}
$$

Then

$$i_1 = g_{m1}(v_{in1} - v_P) = g_{m1}\frac{(g_{m1} + g_{m2})v_{in1} - g_{m1}v_{in1} - g_{m2}v_{in2}}{g_{m1} + g_{m2}} = \frac{g_{m1}g_{m2}}{g_{m1} + g_{m2}}(v_{in1} - v_{in2}),$$

and $i_2 = -i_1$. The output is

$$v_{out} = -R_D(i_1 - i_2) = -2R_Di_1 = -\frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}}(v_{in1} - v_{in2}).$$

**Superposition view (same result).** Apply $v_{in1}$ alone ($v_{in2} = 0$). $M_1$ is a common-source stage whose source is degenerated by the resistance looking into the source of $M_2$, which is $1/g_{m2}$. Both devices therefore carry the current $i = v_{in1}/(1/g_{m1} + 1/g_{m2})$, in opposite directions, so $v_X - v_Y = -2R_Dv_{in1}/(1/g_{m1} + 1/g_{m2})$. Applying $v_{in2}$ alone gives the same with the opposite sign.

### Step 5 — Comparison and common-mode behaviour

The ideal-tail result,

$$|A_{DM}| = \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}},$$

is **identical** to the $R_{SS} \to \infty$ limit of the given formula. So **yes**, the same result follows from analysing a pair with an ideal tail and $g_{m1} \ne g_{m2}$.

Moreover, with the ideal tail $v_{out}$ depends only on $v_{in1} - v_{in2}$, so a common-mode input produces no output. With finite $R_{SS}$, a common-mode input $v_c$ gives

$$v_c - v_P = \frac{v_c}{1 + (g_{m1} + g_{m2})R_{SS}}, \qquad v_{out} = -R_D(g_{m1} - g_{m2})\frac{v_c}{1 + (g_{m1} + g_{m2})R_{SS}},$$

i.e. a CM-to-DM gain of $\Delta g_mR_D/[1 + (g_{m1} + g_{m2})R_{SS}]$. This vanishes as $R_{SS} \to \infty$, so the CMRR becomes infinite.

*Physical reason:* an infinite tail impedance means the total current through P cannot change, $i_1 = -i_2$ at all times. That is exactly the ideal-tail condition. A $g_m$ mismatch alone then cannot turn a common-mode input into a differential output, because neither drain current can change in response to it.

### Result

As $R_{SS} \to \infty$:

$$|A_{DM}| \to \frac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}} = \frac{2R_D}{1/g_{m1} + 1/g_{m2}},$$

which equals $g_mR_D$ when the transconductances are equal. The CM-to-DM conversion $\Delta g_mR_D/[1 + (g_{m1} + g_{m2})R_{SS}]$ vanishes, so CMRR → ∞.

**Yes**, an analysis with an ideal tail ($i_1 + i_2 = 0$) and $g_{m1} \ne g_{m2}$ gives exactly the same gain, because an infinite tail impedance *is* the ideal-tail condition.

**Common mistake.** Concluding that the gain goes to zero or to infinity because $R_{SS}$ appears in both the numerator and the denominator. Both grow linearly with $R_{SS}$, so their ratio approaches a finite limit set by the coefficients of $R_{SS}$.

**Common mistake.** Writing the limit as the arithmetic-mean gain $\tfrac12(g_{m1} + g_{m2})R_D$. With an ideal tail the two devices are effectively in series between the inputs ($1/g_{m1} + 1/g_{m2}$), so the correct combination is the harmonic mean. The two agree only to first order in the mismatch.

**Common mistake.** Claiming that the ideal-tail analysis gives a different answer, or that a $g_m$ mismatch alone degrades the CMRR with an ideal tail. With $i_1 + i_2 = 0$ enforced, a common-mode input cannot change either current, so there is no CM-to-DM conversion.
