A resistively loaded MOS differential pair (load resistor $R_D$ on each side, λ = γ = 0) has a tail current source with finite output impedance $R_{SS}$, and its input transistors have unequal transconductances $g_{m1}$ and $g_{m2}$. Its differential gain is
$|A_{DM}| = \dfrac{R_D}{2}\,\dfrac{g_{m1} + g_{m2} + 4g_{m1}g_{m2}R_{SS}}{1 + (g_{m1} + g_{m2})R_{SS}}$.
What happens if $R_{SS}$ becomes very large? Can we obtain the same result by analyzing a differential pair having an ideal tail current source but $g_{m1} \ne g_{m2}$?
