# Golden Solution - R216

## Reference answer

As $R_{SS} \to \infty$, $|A_{DM}| \to \dfrac{2g_{m1}g_{m2}R_D}{g_{m1} + g_{m2}} = \dfrac{2R_D}{1/g_{m1} + 1/g_{m2}}$ ($R_D$ times the harmonic mean of the two transconductances; $g_mR_D$ if they are equal), and the CM-to-DM conversion $\Delta g_mR_D/[1 + (g_{m1}+g_{m2})R_{SS}]$ vanishes, so CMRR → ∞. Yes, the ideal-tail analysis gives exactly this.
- With an ideal tail, apply $V_{in1}$ alone: $M_1$ is a CS stage degenerated by $1/g_{m2}$ and $M_2$ a CG stage driven through $1/g_{m1}$; both carry $i = V_{in1}/(1/g_{m1} + 1/g_{m2})$ in opposite directions, so $V_X - V_Y = -2R_DV_{in1}/(1/g_{m1} + 1/g_{m2})$.
- $V_{in2}$ alone gives the same with opposite sign, so $|A_{DM}| = 2R_D/(1/g_{m1} + 1/g_{m2})$, identical to the limit.
- Physically, an infinite tail impedance means $i_1 = -i_2$ at all times, which is exactly the ideal-tail condition; a $g_m$ mismatch alone then cannot convert a CM input into a differential output.
