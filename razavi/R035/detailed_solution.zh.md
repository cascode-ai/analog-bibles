# 详细步骤 - R035

**思路。** $C_1$ 把输入节点（上端）与节点 X 连接起来，而栅极接 $V_{DD}$ 的 $M_1$ 也连接这两个节点。在阶跃时，电容把 X 拉低整整 3 V，到达 −3 V。此后 X 成为 $M_1$ 的源极，该管处于线性区并使 $C_1$ 放电，把 X 拉回到 0 V。

### 第 1 步 — 阶跃之前的状态

上端节点为正，因此 $V_X = V_{in} - V_{C1}$，阶跃之前

$$V_X(0^-) = 3 - 3 = 0\ \mathrm{V}.$$

（题目给出的是该时刻的电容电压；我们把它作为初始条件。）

### 第 2 步 — $t = 0$ 时的跳变

当 $V_{in}$ 降到 0 时，电容电压不能瞬时改变（只能流过有限的电流），因此

$$V_X(0^+) = V_{in}(0^+) - V_{C1}(0^+) = 0 - 3 = -3\ \mathrm{V}.$$

**$V_X$ 向下跳变到 −3 V。**

### 第 3 步 — 源极端与工作区

当 $t > 0$ 时，两个沟道端子分别处于 0 V（上端节点）和 $V_X < 0$，因此电位较低的端子 X 是源极，上端节点是漏极：

$$
\begin{aligned}
V_{GS} &= 3 - V_X \quad (= 6\ \mathrm{V}\ \text{at}\ t = 0^+),\\
V_{DS} &= 0 - V_X = -V_X \quad (= 3\ \mathrm{V}\ \text{at}\ t = 0^+).
\end{aligned}
$$

取 $V_{TH} = 0.7$ V，因为题中未给出体效应（body effect）参数；过驱动电压（overdrive voltage）为 $2.3 - V_X$，线性区条件 $V_{DS} < V_{GS} - V_{TH}$ 可写为

$$-V_X < 2.3 - V_X \quad\Longleftrightarrow\quad 0 < 2.3,$$

这总是成立的：**$M_1$ 始终处于线性区**，其栅极总是比两个沟道端子都高出一个阈值电压（threshold voltage）以上。

### 第 4 步 — 恢复过程的方程

沟道电流从上端节点流向 X，而 X 的另一个连接只有 $C_1$，因此该电流使 $C_1$ 放电并抬高 $V_X$：

$$C_1\frac{dV_X}{dt} = I_D = \beta\left[(V_{GS} - V_{TH})V_{DS} - \tfrac12V_{DS}^2\right].$$

令 $y = -V_X = V_{DS} > 0$，即剩余的电容电压，则 $V_{GS} - V_{TH} = 2.3 + y$，且

$$
\begin{aligned}
I_D &= \beta\left[(2.3 + y)y - \tfrac12y^2\right] = \beta\left[2.3y + \tfrac12y^2\right],\\
C_1\frac{dy}{dt} &= -\beta\left[2.3y + \tfrac12y^2\right].
\end{aligned}
$$

**初始速率。** 在 $y = 3$ V 时：

$$I_D(0^+) = \beta\left[2.3\times3 + \tfrac12\times9\right]\mathrm{V^2} = \beta\,(6.9 + 4.5)\ \mathrm{V^2} = 11.4\,\beta\ \mathrm{V^2},$$

这比固定电阻 $R_{on} = 1/(2.3\beta)$ 给出的 $6.9\beta$ 更大：初始 6 V 的 $V_{GS}$ 使沟道导电性很强，因此恢复过程**起初很快**。

### 第 5 步 — 精确解

令 $a = 2.3$ V，作部分分式分解：

$$\frac{1}{y\,(a + y/2)} = \frac{1}{a}\left(\frac{1}{y} - \frac{1}{2a + y}\right).$$

对 $\dfrac{dy}{y(a + y/2)} = -\dfrac{\beta}{C_1}dt$ 积分：

$$\ln\frac{y}{2a + y} = -\frac{t}{\tau} + K, \qquad \tau = \frac{C_1}{2.3\,\beta} = R_{on}C_1,\quad R_{on} = \frac{1}{\beta\,(3 - 0.7)} .$$

在 $t = 0$ 时 $y = 3$：$K = \ln\dfrac{3}{4.6 + 3} = \ln 0.395$。于是，令 $F = 0.395\,e^{-t/\tau}$，

$$\frac{y}{4.6 + y} = F \quad\Longrightarrow\quad y = \frac{4.6F}{1 - F}, \qquad V_X(t) = -\frac{4.6F}{1 - F}\ \mathrm{V}.$$

验证：在 $t = 0$ 时，$y = 4.6(0.395)/0.605 = 3.0$ V ✓。当 $t \gg \tau$ 时，$y \approx 4.6\times0.395\,e^{-t/\tau} = 1.82\,e^{-t/\tau}$ V：这是**时间常数为 $C_1/(2.3\beta)$ 的指数拖尾**，因为此时 $V_{GS} \to 3$ V，$M_1$ 变成电阻 $R_{on}$。

**最终状态：** $V_X = 0$，$C_1$ 完全放电（两个极板都处于 0 V），$I_D = 0$。

| $t/\tau$ | $V_X$ (V) | $I_D/\beta$ (V²) | 纯指数曲线 $-3e^{-t/\tau}$ (V) |
|---|---|---|---|
| $0^-$ | 0 | — | — |
| $0^+$ | −3.00 | 11.4 | −3.00 |
| 0.25 | −2.04 | 6.8 | −2.34 |
| 0.5 | −1.45 | 4.4 | −1.82 |
| 1 | −0.78 | 2.1 | −1.10 |
| 2 | −0.26 | 0.63 | −0.41 |
| 4 | −0.03 | 0.08 | −0.05 |

恢复过程起初比纯指数曲线快，之后按指数速率变化。

### 第 6 步 — 实际中的注意事项：结的钳位作用

节点 X 是 $M_1$ 位于接地 p 型衬底中的 n+ 扩散区（diffusion），因此把它驱动到 −3 V 会使这个结正向偏置 3 V。在实际电路中，一旦 X 降到约 −0.6 至 −0.7 V 以下，该结就会大量导通，从衬底提供电流，迅速把 $V_X$ 钳位在那里（并经该结使 $C_1$ 部分放电）。上面的理想分析忽略了这一点；若计入该结，$V_X$ 只会下冲到约 −0.7 V，然后经 $M_1$ 恢复到 0 V。

### 结果

- **阶跃之前：** $V_X = 3 - 3 = 0$ V。
- **在 $t = 0$ 时：** 上端节点降到 0，**$V_X$ 跳变到 −3 V**。
- **恢复：** 此时 $M_1$（栅极接 3 V）的源极位于 X（$t = 0^+$ 时 $V_{GS} = 6$ V，$V_{DS} = 3$ V），并且始终处于**线性区**（$V_{DS} = -V_X < V_{GS} - V_{TH} = 2.3 - V_X$）。它使 $C_1$ 放电，因此 $V_X$ 大致按指数规律**回升到 0 V**。起初很快（$V_{GS}$ 很大，因此 $R_{on}$ 很小），接近结束时时间常数 ≈ $C_1/(2.3\beta)$。
- **最终：** $V_X = 0$，$C_1$ 完全放电。
- **实际中的注意事项：** 处于 −3 V 的节点会使 $M_1$ 的 n+/衬底结正向偏置（衬底接 0 V），该结会迅速把 $V_X$ 钳位在 −0.6 至 −0.7 V 附近；理想分析忽略了这一点。

**常见错误。** 让 $V_X$ 停留在 −3 V。阶跃之后 $M_1$ 强导通，其栅极比 X 高 6 V，把 X 与 0 V 的输入节点连接起来，因此电容会被放电。

**常见错误。** 把 $M_1$ 当作对 X 充电的源极跟随器（source follower），让 $V_X$ 稳定在 $V_{DD} - V_{TH} = 2.3$ V。沟道另一侧唯一的电压是 0 V 的输入节点，因此 X 只能被拉回到 0 V。

**常见错误。** 把跳变方向画成向上，或者认为 X 保持为 0。电容的上极板下降了 3 V，在那一瞬间 X 也必须下降同样的量。
