# 参考答案 - R035

## 参考答案

在理想沟道模型中，题给电容电压决定了 $V_X(0^-)=0\ \mathrm{V}$。上极板下降 3 V 时，电容电压连续，因此 $V_X(0^+)=-3\ \mathrm{V}$。

恢复期间，X 是源极。固定 $V_{TH}=0.7\ \mathrm{V}$ 时，$V_{DS}=-V_X<V_{GS}-V_{TH}=2.3\ \mathrm{V}-V_X$。沟道保持在线性区并使 $C_1$ 放电。电压趋近 0 V，尾段时间常数为 $\tau=C_1/[\beta(2.3\ \mathrm{V})]$，图中以此归一化时间。

X 电位足够低时，接地衬底的 pn 结会正向导通。若近似为快速钳位，下冲约受限于 −0.6 至 −0.7 V，随后恢复。实际最低电压取决于衬底结和输入边沿。

## 评分说明

- +2：给出题设初值、理想阶跃至 −3 V 和经线性区恢复至 0 V。若按衬底结正向导通作图，说明近似钳位及随后恢复到 0 V，同样得满分。
- +1：跳变和终值正确，遗漏工作区或放电机制。
- 0：跳变正确但因失误算错终值，或终值正确但漏掉跳变。
- −2（断言为事实）：X 保持在 −3 V、最终稳定在 $V_{DD}-V_{TH}$，或向上跳变。
