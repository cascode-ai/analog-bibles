# 详细步骤 - R464

**思路。** 输入加在 n 阱上时，输入共模电平受每个阱与周围 p 区所构成的 **pn 结**的限制，也受体效应对阈值电压（threshold voltage）的影响。先找出 $V_{in,CM}$ 下降时哪个结最先正向偏置，再看是什么限制了 $V_{in,CM}$ 的上限。

### 第 1 步 — 每个 n 阱的 pn 结

每个 n 阱（电位为 $V_{in,CM}$）构成三个 pn 结；$V_{D,on}$ 表示结开始明显导通时的正向电压（几百毫伏）：

| 结 | p 侧（电位） | n 侧（电位） | 正向偏置的条件 |
|---|---|---|---|
| p+ 源极 / n 阱 | $V_{DD}$ | $V_{in,CM}$ | $V_{in,CM} < V_{DD} - V_{D,on}$ |
| p+ 漏极 / n 阱 | $V_{D1}$（低于 $V_{DD}$） | $V_{in,CM}$ | $V_{in,CM} < V_{D1} - V_{D,on}$ |
| p 型衬底 / n 阱 | 0 | $V_{in,CM}$ | $V_{in,CM} < -V_{D,on}$ |

只要阱的电位高于所有相邻的 p 区，每个结都处于反向偏置，阱基本上不吸取电流，这正是输入端所必需的。

### 第 2 步 — 下限：源-阱结

p+ 源极位于最高电位 $V_{DD}$，因此当 $V_{in,CM}$ 降到 $V_{DD}$ 以下时，源-阱结最先正向偏置。此时它会吸取指数增长的输入电流，并使寄生的纵向 PNP 管（p+ 源极 / n 阱 / p 型衬底）导通，有引发闩锁的风险。在室温下，正向偏置不超过约 0.3–0.5 V 时，结电流可以忽略，因此

$$V_{in,CM} \gtrsim V_{DD} - V_{D,on} \approx V_{DD} - (0.3\ \text{to}\ 0.5)\ \mathrm{V}.$$

若不允许任何正向偏置，严格的条件为 $V_{in,CM} \ge V_{DD}$；余量 $V_{D,on}$ 是由可接受的输入电流决定的工程判断。

漏极远低于 $V_{DD}$（要给 $M_3$、$M_4$ 留出电压空间），因此漏-阱结保持反向偏置；对于任何正的 $V_{in,CM}$，衬底-阱结也处于反向偏置。

### 第 3 步 — 上限

把阱电压提高到 $V_{DD}$ 以上只会增大反向偏置，从而提高阈值电压：

$$|V_{TH}| = |V_{TH0}| + \gamma\left(\sqrt{2|\phi_F| + V_{BS}} - \sqrt{2|\phi_F|}\right), \qquad V_{BS} = V_{in,CM} - V_{DD}.$$

在 $V_{SG} = V_{DD} - V_{b1}$ 固定的情况下，当 $|V_{TH}|$ 达到 $V_{SG}$ 时器件截止：

$$
\begin{aligned}
0.8 + 0.4\left(\sqrt{0.8 + V_{BS}} - \sqrt{0.8}\right) &= V_{SG}\\
\sqrt{0.8 + V_{BS}} &= \sqrt{0.8} + \frac{V_{SG} - 0.8}{0.4}\\
V_{in,CM,max} &= V_{DD} - 0.8 + \left[\sqrt{0.8} + \frac{V_{DD} - V_{b1} - 0.8}{0.4}\right]^2\quad\text{(volts)}.
\end{aligned}
$$

例如，取 $V_{SG} = 1.0$ V，即 $V_{BS} = 0$ 时过驱动电压（overdrive voltage）为 0.2 V，则 $\sqrt{0.8 + V_{BS}} = 0.894 + 0.5 = 1.394$，因此 $V_{BS} = 1.94 - 0.8 = 1.14$ V：要到比 $V_{DD}$ **高**约 1.1 V 时才截止。若输入被限制在电源轨之间，实际的上限为

$$V_{in,CM} \le V_{DD}.$$

### 第 4 步 — 由此得到的范围

$$V_{DD} - (0.3\ \text{to}\ 0.5)\ \mathrm{V} \;\lesssim\; V_{in,CM} \;\lesssim\; V_{DD},$$

这是紧靠正电源下方、宽度只有几百毫伏的窗口。衬底输入端避免了 $V_{GS}$ 对电压余度（headroom）的占用，但它是靠二极管隔离的，必须保持反向偏置。

### 第 5 步 — 实际后果：输出共模电平

电路中没有尾电流源，而在这一范围内，阈值电压从 $V_{BS} = 0$ 时的 $|V_{TH}| = 0.80$ V 变化到

$$|V_{TH}| = 0.8 + 0.4\left(\sqrt{0.8 - 0.4} - \sqrt{0.8}\right) = 0.8 + 0.4(0.632 - 0.894) = 0.695\ \mathrm{V}$$

这是 $V_{BS} = -0.4$ V 时的值。例如取 $V_{SG} = 1.0$ V，在这一范围内 $M_1$/$M_2$ 的电流会增大到 $(0.305/0.2)^2 \approx 2.3$ 倍，而 $M_3$/$M_4$ 吸收的电流固定不变；因此如果没有共模反馈（调节 $V_{b1}$ 或 $V_{b2}$），即使 $V_{in,CM}$ 只有很小的变化，输出共模电平也会碰到电源轨。

### 结果

输入共模电平必须保持在正电源附近：

$$V_{DD} - (0.3\ \text{to}\ 0.5)\ \mathrm{V} \;\lesssim\; V_{in,CM} \;\lesssim\; V_{DD}.$$

- **下限：** 由 p+ 源极 / n 阱结（源极接 $V_{DD}$）的正向偏置决定。严格地说，若不允许任何正向偏置，则 $V_{in,CM} \ge V_{DD}$。
- **上限：** 电源轨；器件本身要到远高于 $V_{DD}$ 时才会截止（体效应使 $|V_{TH}|$ 升高到 $V_{DD} - V_{b1}$）。

由于没有尾电流源，需要用共模反馈来维持输出共模电平。

**常见错误。** 以为“输入端不是栅极”，就声称输入范围可以轨到轨（rail-to-rail）或接近地电位。阱电压只要比源极低出几百毫伏以上，源-阱二极管就会正向偏置，吸取输入电流并有引发闩锁的风险。

**常见错误。** 像栅极输入的差分对那样推导极限，例如 $V_{in,CM} \le V_{DD} - |V_{GS}| - \ldots$；真正起约束作用的是阱的 pn 结和体效应。

**常见错误。** 只考虑衬底-阱结，而它对任何正的输入都是安全的；危险的是源-阱结，因为源极接在 $V_{DD}$ 上。
