# Detailed solution - R448

**Approach.** Break the CMFB loop at the gate of the tail transistor $M_T$, apply a test voltage $v_E$, and follow it around. The tail-current change $g_{mT}v_E$ splits equally between $M_1$ and $M_2$ and is subtracted at the folding nodes, so each output's current changes by $g_{mT}v_E/2$; the common-mode output resistance turns this into $v_{out,CM}$, which the divider senses and the error amplifier returns to $V_E$. A common-mode half circuit is used throughout.

### Step 1 — The loop and its polarity

If $V_{out,CM}$ rises, $V_E$ rises, $M_T$ conducts more, and $M_1$, $M_2$ each pull more current out of their folding nodes. The top PMOS sources supply a fixed current, so *less* current flows down through $M_5$, $M_6$ into the outputs, while the bottom NMOS sources still sink a fixed current: the outputs fall, so the feedback is **negative**. To find the loop-gain magnitude $T$, drive the gate of $M_T$ with $v_E$ (it draws no current, so nothing is loaded), with zero differential input and $V_{REF}$ at ac ground.

### Step 2 — Common-mode half circuit

$v_E$ acts identically on both halves, so $v_{out1} = v_{out2} = v_{out,CM}$. Each half gets half of the shared tail's current, $g_{mT}v_E/2$, and twice its output resistance, $2r_{OT}$. Both ends of $R_1$, $R_2$ move together and the tap feeds only a gate, so the divider carries no current, does not load the outputs, and senses $v_{out,CM}$ exactly.

Call the tail node P, the folding node F, and the drain of the bottom NMOS current source (source of the NMOS cascode) B:

- Tail half: $(g_{mT}/2)v_E$ from P to ground, in parallel with $2r_{OT}$.
- $M_1$ (gate at ac ground): $(g_{m1} + g_{mb1})(-v_P)$ from F to P, with $r_{O1}$ between F and P.
- Top PMOS source: $r_{OP}$ from F to ground.
- PMOS cascode $M_5$: $(g_{m5} + g_{mb5})v_F$ from F to out, with $r_{O5}$ between F and out.
- NMOS cascode: $(g_{mNC} + g_{mbNC})(-v_B)$ from out to B, with $r_{ONC}$ between out and B.
- Bottom NMOS current source: $r_{ONS}$ from B to ground.

### Step 3 — How much current reaches each output (short-circuit transconductance)

Short the output to ac ground.

**Tail to $M_1$.** F then looks into the source of $M_5$, a low impedance, so $v_F \approx 0$. KCL at P (current down through $M_1$ = current leaving through the tail half):

$$
\begin{aligned}
-(g_{m1} + g_{mb1} + 1/r_{O1})\,v_P &= \frac{g_{mT}}{2}v_E + \frac{v_P}{2r_{OT}}\\
v_P &= -\frac{(g_{mT}/2)\,v_E}{g_{m1} + g_{mb1} + 1/r_{O1} + 1/(2r_{OT})}\\
i_1 &= -(g_{m1} + g_{mb1} + 1/r_{O1})\,v_P \approx \frac{g_{mT}}{2}v_E .
\end{aligned}
$$

The source of $M_1$ presents only about $1/g_{m1} \ll 2r_{OT}$, so essentially all of the tail-current change flows through $M_1$.

**$M_1$ to the output.** $i_1$ is pulled *out of* F. KCL at F, with $r_{OP}$ supplying $-v_F/r_{OP}$ and $M_5$ carrying $(g_{m5} + g_{mb5} + 1/r_{O5})v_F$ toward the shorted output:

$$
\begin{aligned}
-\frac{v_F}{r_{OP}} &= i_1 + (g_{m5} + g_{mb5} + 1/r_{O5})\,v_F\\
v_F &= -\frac{i_1}{g_{m5} + g_{mb5} + 1/r_{O5} + 1/r_{OP}}\\
i_5 &= (g_{m5} + g_{mb5} + 1/r_{O5})\,v_F \approx -i_1 .
\end{aligned}
$$

Since $1/(g_{m5} + g_{mb5}) \ll r_{OP}$, nearly all of $i_1$ is taken from the current through $M_5$ into the output. Hence

$$G_{m,CM} \approx \frac{g_{mT}}{2}, \qquad \text{current into each output} = -\frac{g_{mT}}{2}v_E .$$

### Step 4 — Common-mode output resistance per side

**Looking down** (NMOS cascode over the bottom current source): a test current $i_t$ gives $v_B = i_tr_{ONS}$, and

$$
\begin{aligned}
i_t &= (g_{mNC} + g_{mbNC})(-v_B) + \frac{v_t - v_B}{r_{ONC}}\\
v_t &= i_t\left[(g_{mNC} + g_{mbNC})r_{ONC}r_{ONS} + r_{ONC} + r_{ONS}\right],\\
R_{down} &\approx (g_{mNC} + g_{mbNC})r_{ONC}r_{ONS} .
\end{aligned}
$$

**Looking up** ($M_5$ degenerated by the resistance $R_F$ at F):

$$R_{up} = (g_{m5} + g_{mb5})r_{O5}R_F + r_{O5} + R_F \approx (g_{m5} + g_{mb5})r_{O5}R_F .$$

**What loads F for a common-mode change?** Besides $r_{OP}$, the drain of $M_1$, which in the common-mode half circuit is degenerated by $2r_{OT}$:

$$R_{M1,CM} \approx (g_{m1} + g_{mb1})r_{O1}(2r_{OT}) \approx 2g_{m1}r_{O1}r_{OT},$$

enormous (infinite for an ideal tail). Hence $R_F \approx r_{OP}$ and

$$R_{out,CM} = R_{up}\parallel R_{down} \approx \left[(g_{m5} + g_{mb5})r_{O5}r_{OP}\right]\parallel\left[(g_{mNC} + g_{mbNC})r_{ONC}r_{ONS}\right].$$

(Writing the differential-mode value $r_{OP}\parallel r_{O1}$ for $R_F$ is a common, slightly conservative approximation.)

### Step 5 — From $v_E$ to $v_{out,CM}$ and back

$$v_{out,CM} = -\frac{g_{mT}}{2}R_{out,CM}\,v_E .$$

The error amplifier (pair with active mirror load) has short-circuit output current $g_{mE}v_{id}$ and output resistance $r_{OE1}\parallel r_{OE3}$, so $A_E = g_{mE}(r_{OE1}\parallel r_{OE3})$. With $v_{out,CM}$ on the "+" input and $V_{REF}$ at ac ground:

$$v_E' = A_E\,v_{out,CM} = -A_E\,\frac{g_{mT}}{2}R_{out,CM}\,v_E .$$

### Step 6 — Loop gain

$$\frac{v_E'}{v_E} = -g_{mE}(r_{OE1}\parallel r_{OE3})\cdot\frac{g_{mT}}{2}\cdot R_{out,CM} .$$

The minus sign confirms negative feedback, and

$$T = g_{mE}(r_{OE1}\parallel r_{OE3})\cdot\frac{g_{mT}}{2}\cdot R_{out,CM}.$$

If $V_E$ drove the bottom NMOS sources instead (as in the related circuit with $M_3$/$M_4$), each output would receive the full $g_{m3}v_E$; here the tail current is shared by two halves, hence the factor $1/2$.

### Result

$$T \approx g_{mE}(r_{OE1}\parallel r_{OE3})\cdot\frac{g_{mT}}{2}\cdot R_{out,CM},$$

$$R_{out,CM} = \left[(g_{m5} + g_{mb5})r_{O5}r_{OP}\right]\parallel\left[(g_{mNC} + g_{mbNC})r_{ONC}r_{ONS}\right],$$

with negative feedback ($V_{out,CM}\uparrow \Rightarrow$ tail current $\uparrow \Rightarrow$ less current into the outputs $\Rightarrow$ outputs $\downarrow$). For a common-mode change the drain of $M_1$ looks like $\approx 2g_{m1}r_{O1}r_{OT}$ (infinite with an ideal tail), so $r_{O1}$ does not load the folding node; $r_{OP}\parallel r_{O1}$ is an acceptable approximation. $R_1$ and $R_2$ carry no common-mode current.

**Common mistake.** Using $g_{mT}$ per side instead of $g_{mT}/2$. The tail-current change is shared equally by $M_1$ and $M_2$.

**Common mistake.** Arguing that "a differential pair rejects common-mode signals, so the tail current cannot affect the output CM level". A tail-current change is not a common-mode *input voltage*: it directly changes both drain currents and hence the currents folded into the outputs.

**Common mistake.** Letting $R_1$, $R_2$ load the outputs in the CM loop. For a common-mode change no current flows through the divider.
