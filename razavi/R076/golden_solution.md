# Golden Solution - R076

## Reference answer

A horizontal line: $g_mr_O = \dfrac{2}{\lambda(V_{GS} - V_{TH})}$, independent of $W/L$.

- At fixed $V_{GS}$ both $g_m = \mu C_{ox}(W/L)V_{ov}$ and $I_D = \tfrac12\mu C_{ox}(W/L)V_{ov}^2$ scale with $W/L$, so $r_O = 1/(\lambda I_D)$ scales as $(W/L)^{-1}$ and the product does not change; λ is fixed since $L$ is constant.
