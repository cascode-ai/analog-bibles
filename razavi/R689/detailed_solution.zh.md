# 详细步骤 - R689

**思路。** 该电路是一个 CMOS 反相器。用平方律和 $I_{D1} = I_{D2}$ 逐个区域地画出传输曲线，然后注意到 $C_{ox}$ 乘在所有这些方程的两边，因此两个器件共同的氧化层变厚不可能使曲线移动。

### 第 1 步 — 氧化层变厚对器件方程的影响

较长的氧化时间使**两个**晶体管的 $t_{ox}$ 都增大（它们是在同一工序中生长的），因此 $C_{ox} = \varepsilon_{ox}/t_{ox}$ 按一个共同的因子下降：

$$C_{ox,\text{actual}} = \alpha\,C_{ox,\text{target}}, \qquad \alpha = \frac{t_{ox,\text{target}}}{t_{ox,\text{actual}}} < 1 .$$

阈值电压（$V_{THN} = 0.7$ V，$V_{THP} = -0.8$ V）、迁移率和尺寸都不变，因此 $\mu_nC_{ox}$ 和 $\mu_pC_{ox}$ 都按 $\alpha$ 下降。每个管子的衬底都接到各自的源极，因此没有体效应（body effect）。

由于 $V_{GS1} = V_{in}$，$V_{DS1} = V_{out}$，$V_{SG2} = 3 - V_{in}$，$V_{SD2} = 3 - V_{out}$（暂取 $\lambda = 0$），$M_1$ 的过驱动电压为 $V_{in} - 0.7$，$M_2$ 的过驱动电压为 $2.2 - V_{in}$。若 $V_{out} \ge V_{in} - 0.7$，则 $M_1$ 饱和；若 $3 - V_{out} \ge 2.2 - V_{in}$，即 $V_{out} \le V_{in} + 0.8$，则 $M_2$ 饱和。

定义强度比

$$r = \sqrt{\frac{\mu_nC_{ox}(W/L)_1}{\mu_pC_{ox}(W/L)_2}} = \sqrt{\frac{\mu_n(W/L)_1}{\mu_p(W/L)_2}},$$

由第二种写法可见，其中不含 $C_{ox}$。

### 第 2 步 — 曲线的两端

**$V_{in} < 0.7$ V：$M_1$ 截止。** $M_2$ 的 $V_{SG2} = 3 - V_{in} > 2.3$ V，因此其沟道存在；但它必须满足 $I_{D2} = I_{D1} = 0$，这要求 $V_{SD2} = 0$（深线性区）：

$$V_{out} = V_{DD} = 3\ \mathrm{V}.$$

**$V_{in} > 2.2$ V：$M_2$ 截止。** $V_{SG2} = 3 - V_{in} < 0.8\ \mathrm{V} = |V_{THP}|$，因此 $I_{D2} = 0$；而充分导通的 $M_1$ 只有在 $V_{DS1} = 0$ 时电流才为零：

$$V_{out} = 0 .$$

这两个电平都不含 $C_{ox}$。

### 第 3 步 — 开关阈值 $V_M$（两个器件都饱和）

在转换区的中部，两个晶体管都处于饱和区。在 $V_{in} = V_M$ 处：

$$\tfrac12\mu_nC_{ox}(W/L)_1(V_M - 0.7)^2 = \tfrac12\mu_pC_{ox}(W/L)_2(2.2 - V_M)^2 .$$

消去 $\tfrac12C_{ox}$，除以 $\mu_p(W/L)_2$，并取正的平方根（两个过驱动电压都为正）：

$$r^2(V_M - 0.7)^2 = (2.2 - V_M)^2 \quad\Longrightarrow\quad r(V_M - 0.7) = 2.2 - V_M \quad\Longrightarrow\quad V_M(1 + r) = 2.2 + 0.7r,$$

$$\boxed{V_M = \frac{V_{DD} - |V_{THP}| + rV_{THN}}{1 + r} = \frac{2.2 + 0.7r}{1 + r}\ \mathrm{V}}$$

**示例。**

- $r = 1$（把 PMOS 做宽，使其强度与 NMOS 相当）：$V_M = (2.2 + 0.7)/2 = 1.45$ V。
- $W/L$ 相等，并取典型值 $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$：$r = \sqrt{134/38.4} = 1.87$，因此 $V_M = (2.2 + 0.7\times1.87)/2.87 = 3.509/2.87 = 1.22$ V。较强的 NMOS 把阈值拉低。

在 $\lambda = 0$ 时，对于使两个器件都保持饱和的**任何** $V_{out}$，即 $V_M - 0.7 \le V_{out} \le V_M + 0.8$，这一电流方程都成立。因此在理想的平方律模型中，曲线在 $V_{in} = V_M$ 处从 $V_M + 0.8$ **垂直**下降到 $V_M - 0.7$（增益为无穷大）；计入沟道长度调制后，斜率很大但为有限值（第 6 步）。

### 第 4 步 — 上弯折段：$M_1$ 饱和，$M_2$ 处于线性区（$0.7\ \mathrm{V} < V_{in} < V_M$）

高于 0.7 V 后，$M_1$ 吸取一个小电流，由处于线性区的 $M_2$ 以较小的 $V_{SD2}$ 提供，因此 $V_{out}$ 略低于 3 V。令 $x = 3 - V_{out} = V_{SD2}$：

$$\tfrac12\mu_nC_{ox}(W/L)_1(V_{in} - 0.7)^2 = \mu_pC_{ox}(W/L)_2\big[(2.2 - V_{in})x - \tfrac12x^2\big].$$

两边除以 $\tfrac12\mu_pC_{ox}(W/L)_2$（$C_{ox}$ 再次消失）并整理：

$$r^2(V_{in} - 0.7)^2 = 2(2.2 - V_{in})x - x^2 \quad\Longrightarrow\quad x^2 - 2(2.2 - V_{in})x + r^2(V_{in} - 0.7)^2 = 0 .$$

线性区的解是较小的根（它必须满足 $x \le 2.2 - V_{in}$）：

$$x = (2.2 - V_{in}) - \sqrt{(2.2 - V_{in})^2 - r^2(V_{in} - 0.7)^2},\qquad V_{out} = 3 - x .$$

在 $V_{in} = V_M$ 处平方根为零，因此 $x = 2.2 - V_M$，$V_{out} = V_M + 0.8$，即垂直段的顶端。

### 第 5 步 — 下弯折段：$M_1$ 处于线性区，$M_2$ 饱和（$V_M < V_{in} < 2.2$ V）

此时 $M_1$ 以较小的 $V_{DS1}$ 流过 $M_2$ 的饱和电流：

$$\mu_nC_{ox}(W/L)_1\big[(V_{in} - 0.7)V_{out} - \tfrac12V_{out}^2\big] = \tfrac12\mu_pC_{ox}(W/L)_2(2.2 - V_{in})^2 .$$

两边除以 $\tfrac12\mu_nC_{ox}(W/L)_1$：

$$2(V_{in} - 0.7)V_{out} - V_{out}^2 = \frac{(2.2 - V_{in})^2}{r^2}.$$

取较小的根（线性区要求 $V_{out} \le V_{in} - 0.7$）：

$$V_{out} = (V_{in} - 0.7) - \sqrt{(V_{in} - 0.7)^2 - \frac{(2.2 - V_{in})^2}{r^2}} .$$

在 $V_{in} = V_M$ 处，它给出 $V_{out} = V_M - 0.7$，即垂直段的底端；在 $V_{in} = 2.2$ V 处，它给出 $V_{out} = 0$。

**$r = 1$ 时的数值表**（目标氧化层与厚氧化层相同）：

| $V_{in}$ (V) | $M_1$ | $M_2$ | $V_{out}$ (V) |
|---|---|---|---|
| 0 – 0.7 | 截止 | 线性区 | 3.00 |
| 1.0 | 饱和 | 线性区 | 2.96 |
| 1.2 | 饱和 | 线性区 | 2.87 |
| 1.4 | 饱和 | 线性区 | 2.59 |
| 1.45 ($V_M$) | 饱和 | 饱和 | 2.25 → 0.75（垂直） |
| 1.5 | 线性区 | 饱和 | 0.41 |
| 1.7 | 线性区 | 饱和 | 0.13 |
| 1.9 | 线性区 | 饱和 | 0.04 |
| 2.2 – 3 | 线性区 | 截止 | 0 |

$r = 1$ 时，曲线关于点 $(1.45\ \mathrm{V},\ 1.5\ \mathrm{V})$ 中心对称。

### 第 6 步 — 与目标氧化层厚度的比较

在第 2–5 步中，决定 $V_{out}$ 的每个关系式要么以 $C_{ox}$ 作为 $I_{D1} = I_{D2}$ 两边的公共因子，要么与 $C_{ox}$ 无关。因此，对于厚氧化层：

- 输出电平（3 V 和 0 V）以及转折点 $V_{in} = 0.7$ V 和 $2.2$ V 都不变；
- 开关阈值 $V_M = (2.2 + 0.7r)/(1 + r)$ 不变，因为 $r$ 中不含 $C_{ox}$；
- 两个弯折段的形状都不变。

**计入沟道长度调制时 $V_M$ 处的增益。** 两个饱和器件都由 $v_{in}$ 驱动，其电流在输出端相加，因此

$$A_v = -(g_{m1} + g_{m2})(r_{O1}\parallel r_{O2}).$$

在相同的过驱动电压下，$g_m = \mu C_{ox}(W/L)V_{ov} \propto C_{ox}$；而由于 $I_D \propto C_{ox}$，$r_O = 1/(\lambda I_D) \propto 1/C_{ox}$。二者的乘积与 $C_{ox}$ 无关，因此 $V_M$ 处的斜率也不变。

**真正改变的是电流。** 在每个 $V_{in}$ 下，过驱动电压都与目标电路相同，因此每个电流都按 $\alpha$ 缩放。例如，$V_M$ 处的峰值直通电流为

$$I_{peak} = \tfrac12\mu_nC_{ox}(W/L)_1(V_M - 0.7)^2 \;\propto\; C_{ox},$$

而可用于对负载电容充电或放电的电流也按同一因子下降。栅电容（$\propto C_{ox}WL$）也会减小，但结电容（junction capacitance）、连线电容和外部负载电容不变，因此反相器的**驱动能力变弱，边沿变慢**。例如，氧化层比设计值厚 20 % 时 $\alpha = 0.83$：电流减小 17 %。

### 结果

厚氧化层反相器的 $V_{out}$–$V_{in}$ 特性与目标设计**完全相同**，因为 $C_{ox}$ 乘在每个电流平衡方程的两边。令 $r = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_2]}$，则：

- $V_{in} < 0.7$ V：$M_1$ 截止，$V_{out} = 3$ V。
- $0.7\ \mathrm{V} < V_{in} < V_M$：$V_{out}$ 从 3 V 略微向下弯（$M_1$ 饱和，$M_2$ 处于线性区）。
- $V_{in} = V_M = (2.2 + 0.7r)/(1 + r)$：从 $V_M + 0.8$ 陡峭地（理想情况下垂直地）下降到 $V_M - 0.7$；$r = 1$ 时 $V_M = 1.45$ V，$W/L$ 相等（$r = 1.87$）时为 $1.22$ V。
- $V_M < V_{in} < 2.2$ V：$V_{out}$ 趋近于 0（$M_1$ 处于线性区，$M_2$ 饱和）；$V_{in} > 2.2$ V：$M_2$ 截止，$V_{out} = 0$。
- 只有各电流（峰值电流、驱动电流）与 $C_{ox}$ 成比例地下降，因此电路变慢。

**常见错误。** 声称由于“氧化层变厚使 $g_m$ 变小”，$V_M$ 会移动或增益会下降。$V_M$ 只取决于比值 $\mu_nC_{ox}(W/L)_1/[\mu_pC_{ox}(W/L)_2]$ 和阈值电压；而在增益 $(g_{m1} + g_{m2})(r_{O1}\parallel r_{O2})$ 中，$g_m$ 和 $r_O$ 对 $C_{ox}$ 的依赖相互抵消。

**常见错误。** 在 $V_{in} < 0.7$ V 时把 $V_{out}$ 画在 3 V 以下（例如画在 $V_{DD} - |V_{THP}|$）。PMOS 的栅极由 $V_{in}$ 驱动，而不是接到其漏极，因此 $M_2$ 相当于处于深线性区的闭合开关，能把完整的 $V_{DD}$ 传到输出。

**常见错误。** 把 $M_2$ 当作固定的电流源（current source）或二极管连接（diode-connected）负载。两个栅极都随 $V_{in}$ 变化，因此两个器件都会开关，输出可以轨到轨（rail-to-rail）摆动。
