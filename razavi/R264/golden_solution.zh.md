若 $V_0 > V_{TH}$：二极管连接（diode-connected）的 $M_2$ 使 $C_1$ 放电，$V_X$ 从 $V_0$ 开始向 $V_{TH} = 0.7$ V 衰减，先快后慢：$V_X(t) = V_{TH} + \dfrac{V_0 - V_{TH}}{1 + t/\tau}$，$\tau = \dfrac{2C_1}{\beta(V_0 - V_{TH})}$（在平方律模型中永远不会完全达到 $V_{TH}$）。$V_Y$ 从较低的值 $V_{DD} - R_1\tfrac{\beta}{2}(V_0-V_{TH})^2$ 开始——若该值低于 $V_0 - V_{TH}$，则 $M_1$ 处于线性区（triode region），起始值还会更低——随后随着 $M_1$ 的电流 $\tfrac{\beta}{2}(V_X - V_{TH})^2$ 逐渐消失而上升并趋向 $V_{DD}$。若 $V_0 \le V_{TH}$，则什么也不会发生：$V_X = V_0$，$V_Y = V_{DD}$。

- 节点 X 上除了二极管连接的 $M_2$ 和 $M_1$ 的栅极之外，只有 $C_1$：$C_1 dV_X/dt = -\tfrac{\beta}{2}(V_X - V_{TH})^2$，积分即得上述双曲型衰减。
- $M_1$ 与 $M_2$ 的 $V_{GS}$ 相同，并把其电流镜像到 $R_1$ 中。
