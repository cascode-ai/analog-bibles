# 详细步骤 - R270

**思路。** $C_1$ 挂在 PMOS $M_3$ 的 n 阱上，在 $t = 0$ 时 n 阱为 0 V，而 $M_3$ 的 p+ 源极为 $V_{DD}$：一个 pn 结处于强正向偏置，并给 $C_1$ 充电。晶体管环路 $M_1 \to M_3 \to M_2 \to M_1$ 是一个有两个直流状态的正反馈环路，$t = 0$ 时的结电流把它推入锁定状态。最后，随着阱被充电、$M_3$ 的阈值电压（threshold voltage）恢复，跟踪 $V_Y$ 的变化。X 和 Y 的节点电容取为很小，因此 X 和 Y 准静态地跟随变化；各个结用二极管建模（流过大电流时约为 0.7 V）。

### 第 1 步 — $t = 0$：正向偏置的结给 $C_1$ 充电

$M_3$ 的 p+ 源极为 3 V，n 阱为 0 V，因此**源-阱结的正向偏置电压为 3 V**，远远超过 pn 二极管强烈导通所需的电压；只要 $V_Y > 0.7$ V，漏-阱结（p+ 漏极在 Y）也处于正向偏置。其结果是：

- **阱被非常快地充电。** 很大的二极管电流从源极（以及从 Y）流入阱并流到 $C_1$ 上，使阱电压迅速升到约 $V_{DD} - 0.7$ V = 2.3 V，此时正向偏置已降到普通二极管的导通电压。
- **随后它缓慢趋向 $V_{DD}$。** 对于指数型二极管 $I = I_S e^{v/V_T}$（其中 $v = V_{DD} - V_{well}$），对充电规律 $-C_1\,dv/dt = I_Se^{v/V_T}$ 积分得
$$v(t) \approx V_T\ln\frac{C_1V_T}{I_St} \qquad (\text{large } t),$$
因此时间每增加十倍，正向偏置只下降 $V_T\ln10 \approx 60$ mV：这是一个缓慢的、大致按对数规律变化的拖尾。（固定压降的二极管模型则简单地停在约 2.3 V；拖尾的具体形状还取决于结的漏电。）
- 正向偏置的 p+/n 阱结与 p 型衬底构成一个寄生 PNP 晶体管，因此在阱电压较低时，这一早期电流中有一部分也会流向衬底。
- 在这种强正向偏置期间，平方律模型下的体效应公式不适用；此时 $M_3$ 的沟道比正常情况强得多。

当偏置变得适中时，令 $V_{BS} = V_{well} - V_S$，$V_{BS} > 0$ 表示反向偏置（reverse-biased），则计入体效应的 PMOS 阈值电压的大小为

$$|V_{TH3}| = 0.8 + 0.4\left(\sqrt{0.8 + V_{BS}} - \sqrt{0.8}\right)\ \mathrm{V}.$$

### 第 2 步 — 晶体管环路存在正反馈并发生锁定

$M_3$ 的电流稍有增大就会使 $V_Y$ 降低，于是 $M_2$ 向 X 注入更多电流。节点 X 只与 $M_2$ 的漏极和 $M_1$ 的栅极相连（**没有直流负载**），因此 $V_X$ 升高，$M_1$ 从 Y 抽取更多电流，$V_Y$ 进一步下降：这就是正反馈。存在两个直流解：

- **截止状态：** $V_X \le 0.7$ V，$M_1$ 截止，因此各处都没有电流，$M_2$、$M_3$ 截止。只有当没有任何因素从 Y 抽取电流或给 X 充电时，这一状态才是自洽的。
- **锁定状态：** $M_2$ 导通但没有直流负载，因此它的电流必须为零，而导通的 PMOS 只有在 $V_{SD} = 0$ 时才能做到这一点：**$V_X = V_{DD}$**，$M_2$ 处于深线性区。于是 $M_1$ 的 $V_{GS1} = V_{DD} = 3$ V，强烈导通，由 $M_3$ 提供这一电流。

**会到达哪个状态？** 在 $t = 0$ 时，漏-阱结从 Y 抽取电流（若 $V_Y > 0.7$ V），这会把 Y 拉低，使 $M_3$ 和 $M_2$ 导通，并给 X 充电；若 $V_Y$ 本来就低，$M_2$ 也已经导通。无论哪种情况，**锁定状态都是预期的结果**：**$V_X$ 几乎立即升到 $V_{DD}$ 并保持不变。**（在初始节点电压未知、节点电容有限的情况下，并不能严格保证电路启动；截止状态在数学上仍然可能，但结电流使其不太可能出现。）

### 第 3 步 — 锁定状态下 $V_Y$ 的电平

$M_3$ 为二极管连接（diode-connected）并处于饱和区（saturation region），它与栅极为 3 V 的 $M_1$ 流过相同的电流；由于 $V_Y$ 远低于 $V_{GS1} - V_{TH} = 2.3$ V，$M_1$ 处于线性区。节点 Y 的基尔霍夫电流定律（KCL）方程：

$$\frac{\beta_p}{2}\left(V_{DD} - V_Y - |V_{TH3}|\right)^2 = \beta_n\left[(V_{DD} - 0.7)V_Y - \tfrac12V_Y^2\right].$$

$V_Y$ 是一个由 $M_3$ 与 $M_1$ 的强弱对比所决定的低到中等电平，它取决于随阱充电而变化的 $|V_{TH3}|$。

**$\beta_n = \beta_p$ 时的例子**，最终状态（阱电压为 $V_{DD}$，$|V_{TH3}| = 0.8$ V）：

$$
\begin{aligned}
\tfrac12(2.2 - V_Y)^2 &= 2.3V_Y - \tfrac12V_Y^2\\
2.42 - 2.2V_Y + \tfrac12V_Y^2 - 2.3V_Y + \tfrac12V_Y^2 &= 0\\
V_Y^2 - 4.5V_Y + 2.42 &= 0\\
V_Y &= \frac{4.5 - \sqrt{20.25 - 9.68}}{2} = \frac{4.5 - 3.251}{2} = 0.62\ \mathrm{V}.
\end{aligned}
$$

**当阱电压仍在 $V_{DD} - 0.7$ V 附近时**（正向偏置 $V_{BS} = -0.7$ V）：

$$|V_{TH3}| = 0.8 + 0.4\left(\sqrt{0.8 - 0.7} - \sqrt{0.8}\right) = 0.8 + 0.4(0.316 - 0.894) = 0.57\ \mathrm{V}.$$

衬底正向偏置**降低**了 $|V_{TH3}|$，因此 $M_3$ 更强。用 0.57 V 重复上述计算，得 $V_Y^2 - 4.73V_Y + 2.952 = 0$，因此 $V_Y = (4.73 - \sqrt{22.37 - 11.81})/2 = 0.74$ V。

### 第 4 步 — $V_Y$ 随时间的变化

- **非常早期**（阱电压接近 0 V）：$V_Y$ 由正向偏置的漏-阱结和异常强的 $M_3$ 决定。它可能被维持在阱电压 + 0.7 V 附近，一开始可能上升也可能下降，取决于器件尺寸（例如，若 $M_1$ 较弱，它会随阱电压一起上升）；平方律模型在这里给不出多少信息。
- **快速充电之后**（阱电压 ≈ 2.3 V）：$|V_{TH3}| \approx 0.57$ V，$V_Y$ 处于相应的锁定电平（β 相等时 ≈ 0.74 V）。
- **缓慢拖尾：** 随着 $C_1$ 缓慢趋向 $V_{DD}$，正向偏置消失，$|V_{TH3}|$ 恢复到 0.8 V，$M_3$ 变弱，**$V_Y$ 缓慢下降**到其终值（β 相等时 ≈ 0.62 V）。

| 阶段 | 阱（$V_{C1}$） | $V_X$ | $V_Y$（β 相等） |
|---|---|---|---|
| $t = 0$ | 0 | 初始值 | 初始值 |
| 结快速充电 | → 约 2.3 V | → $V_{DD}$（锁定） | 稳定在 0.74 V 附近 |
| 缓慢拖尾 | 缓慢 → 3 V（每十倍时间约 60 mV） | $V_{DD}$ | 缓慢下降 → 0.62 V |

### 结果

- **$C_1$（$M_3$ 的 n 阱）** 从 0 V 开始，因此源-阱结（以及 $V_Y > 0.7$ V 时的漏-阱结）处于强正向偏置。很大的结电流把 $C_1$ 迅速充电到约 $V_{DD} - 0.7$ V，之后它缓慢地趋向 $V_{DD}$（大致按时间的对数规律；固定压降的二极管模型则停在 2.3 V 附近）。
- **$V_X$ 几乎立即升到 $V_{DD}$ 并保持不变。** 结电流把 Y 拉低，使 $M_3$ 和 $M_2$ 导通。X 没有直流负载，因此 $M_2$ 把它拉到 $V_{DD}$（深线性区，电流为零），正反馈环路 $M_1$–$M_3$–$M_2$ 发生锁定。
- **$V_Y$ 稳定在一个低到中等的电平上**，由 $\tfrac{\beta_p}{2}(V_{DD} - V_Y - |V_{TH3}|)^2 = \beta_n[(V_{DD} - 0.7)V_Y - V_Y^2/2]$ 决定（$M_1$ 处于线性区）。当阱仍有轻微正向偏置时，$|V_{TH3}|$ 减小（约 0.57 V），因此 $V_Y$ 稍高。随着阱被充电、$|V_{TH3}|$ 恢复到 0.8 V，$V_Y$ 缓慢下降（β 相等时约从 0.74 V → 0.62 V）。它在非常早期的行为取决于器件尺寸和各个结。

**常见错误。** 把 $C_1$ 当作接在节点 Y 或栅极连线上的电容，并画出 Y 的 RC 型充电过程。$C_1$ 挂在 $M_3$ 的 n 阱上，因此 $t = 0$ 时的物理过程是结导通，而不是沟道电流流入电容。

**常见错误。** 在 3 V 正向偏置下套用体效应公式（或者用错符号）。正向偏置的源-阱结会导通，把偏置钳位（clamp）在 0.7 V 附近；而且衬底正向偏置会**降低** PMOS 阈值电压的大小，因此在阱电压较低时 $M_3$ 更强而不是更弱。

**常见错误。** 让 $V_X$ 稳定在电源中点附近的“镜像”电压上。节点 X 没有直流负载，因此只要 $M_2$ 有一点导通，X 就会被拉到 $V_{DD}$，环路发生锁定。
