$|A_v|$ 起初很小，随 $V_b$ 增大而上升（$M_2$ 的线性区负载电阻增大），在 $M_1$ 进入线性区的点与 $M_2$ 进入饱和区的点之间达到一个有限的最大值（其确切位置取决于 $V_{in}$ 和器件尺寸），随后下降，在 $V_b = V_{DD} - |V_{THP}| = 2.2$ V 处降为零，此后一直为零。两个器件从不同时饱和，因此不存在 $g_{m1}(r_{O1}\|r_{O2})$ 平台。

- $M_1$ 饱和，电流固定为 $I_1 = \tfrac12\beta_1(V_{in} - 0.7)^2$；$M_2$ 处于线性区，其过驱动电压（overdrive voltage）为 $2.2 - V_b$：$|A_v| = g_{m1}r_2$，$r_2 = 1/[\beta_2(2.2 - V_b - V_{SD2})]$。升高 $V_b$ 会削弱 $M_2$：$V_{SD2}$ 增大，$r_2$ 增大，因此 $|A_v|$ 增大（比线性增长更快）。
- 当 $M_2$ 仍处于线性区而 $V_{out}$ 降到 $V_{in} - 0.7$ V 时，$M_1$ 进入线性区：它的 $g_m$（$= \beta_1V_{out}$）减小，输出电导 $\beta_1(V_{in} - 0.7 - V_{out})$ 增大，但 $M_2$ 的线性区电导 $\beta_2(V_{out} - V_b - 0.8)$ 继续减小：$|A_v| = \beta_1V_{out}/[\beta_1(V_{in} - 0.7 - V_{out}) + \beta_2(V_{out} - V_b - 0.8)]$（λ = 0）。记 $A = V_{in} - 0.7$，若 $(\beta_2/\beta_1)(3 - A)^2 < 3A(2 - A)$，则峰值出现在 $M_1$ 进入线性区处（其值为 $g_{m1}r_2$）；在本题情形下，当 $V_{in} < 2.2$ V 时这一条件总是成立。否则（$V_{in}$ 较大，$\beta_2 \gtrsim \beta_1$），$M_1$ 进入线性区后 $|A_v|$ 仍继续上升，并在两点之间或在 $M_2$ 饱和处达到峰值，此时 $|A_v| = V_{out}/(V_{in} - 0.7 - V_{out})$。例如：$V_{in} = 2.7$ V，$\beta_2/\beta_1 = 1.74$：在 $M_1$ 进入线性区处（$V_b$ = 0.55 V）$|A_v|$ = 1.77，在 $M_2$ 饱和处（$V_b$ = 0.73 V）为 3.23。峰值是有限的，两点越接近，峰值越高。
- 峰值之后：电流减小，$V_{out}$ 降低，$M_1$ 更深地进入线性区；$M_2$ 总是在截止之前先进入饱和区，此后 $|A_v| = V_{out}/(V_{in} - 0.7 - V_{out})$（λ = 0）随 $V_{out}$ 下降而持续减小。
- $V_b \ge 2.2$ V：$M_2$ 截止，$V_{out} = 0$，$A_v = 0$。
