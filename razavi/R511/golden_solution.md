# Golden Solution - R511

## Reference answer

$$\frac{V_{out}}{V_{in}}(s) = \frac{(g_{m1} + g_{m7}g_{mA}r_{OA})R_{out}\left(1 + \dfrac{s}{\omega_z}\right)}{\left(1 + \dfrac{s}{\omega_X}\right)\left(1 + \dfrac{s}{\omega_P}\right)\left(1 + \dfrac{s}{\omega_{out}}\right)},$$
with $\omega_X = 1/(r_{OA}C_X)$ (X and Y, one pole for the differential half circuit), $\omega_P \approx g_{m5}/C_P$ (P and Q), $\omega_{out} = 1/(R_{out}C_L)$ ($C_L$ = capacitance at each output), and a left-half-plane zero
$$\omega_z = \frac{g_{m1} + g_{m7}g_{mA}r_{OA}}{g_{m1}r_{OA}C_X} = \omega_X\left(1 + \frac{g_{m7}g_{mA}r_{OA}}{g_{m1}}\right).$$
- Current into P per side: $\dfrac{V_{in}}{2}\left[g_{m1} + \dfrac{g_{m7}g_{mA}r_{OA}}{1 + sr_{OA}C_X}\right] = \dfrac{V_{in}}{2}(g_{m1} + g_{m7}g_{mA}r_{OA})\dfrac{1 + s/\omega_z}{1 + s/\omega_X}$. The fast path ($g_{m1}$) and the slow path (through X) add, so the zero is in the left half plane.
- At P the current divides between $C_P$ and the source of $M_5$ (≈ $1/g_{m5}$, assuming $r_{O2} \parallel r_{O7} \gg 1/g_{m5}$): factor $1/(1 + sC_P/g_{m5})$. The output node gives $R_{out}/(1 + sR_{out}C_L)$.
- The three separate first-order factors assume high intrinsic gain and well-separated P and output poles; with finite $r_O$ the P and output poles are the roots of a coupled second-order denominator, and that more general form (with the same X pole and zero) is equally correct. The gain is per differential output $V_{out}$ (two output terminals); a single-ended output has half this gain with the same poles and zero.
- Cancellation: the zero always lies above the X/Y pole by the boost factor $1 + g_{m7}g_{mA}r_{OA}/g_{m1}$ (> 1 whenever the secondary path is active, ≫ 1 for a substantial gain boost), so it can never cancel that pole; if the output pole lies below $\omega_X$ (ordering $\omega_{out} < \omega_X < \omega_z < \omega_P$), the gain falls at 40 dB/dec between $\omega_X$ and $\omega_z$. It can in principle be placed on another pole by design: on the output pole if $C_X$ is chosen so that $g_{m1}r_{OA}C_X/(g_{m1} + g_{m7}g_{mA}r_{OA}) = R_{out}C_L$ (X then becomes the dominant pole and, if $\omega_P$ is well above it, the unity-gain frequency is ≈ $g_{m1}/C_L$), or on the folding-node pole $g_{m5}/C_P$. Theoretically the exact condition is that the zero coincide with a root of the P/output denominator. Such cancellation relies on matching unrelated time constants, so in practice it is imperfect and leaves a doublet (slow settling).

## Grading notes

The practical caveat (only approximate, doublet) is a plus, not required. A general form with a coupled second-order P/output denominator (finite $r_O$) is +2 if the X pole and zero are right. A single-ended transfer function (half the differential gain) is accepted if labelled as such; claiming the drawn outputs are one shared node is a minor misreading if the answer still gives the correct per-side poles, zero and cancellation.
