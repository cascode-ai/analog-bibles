$$\frac{V_{out}}{V_{in}}(s) = \frac{(g_{m1} + g_{m7}g_{mA}r_{OA})R_{out}\left(1 + \dfrac{s}{\omega_z}\right)}{\left(1 + \dfrac{s}{\omega_X}\right)\left(1 + \dfrac{s}{\omega_P}\right)\left(1 + \dfrac{s}{\omega_{out}}\right)},$$
其中 $\omega_X = 1/(r_{OA}C_X)$ 来自 X 和 Y，对差分半边电路（half circuit）而言只算一个极点；$\omega_P \approx g_{m5}/C_P$（P 和 Q）；$\omega_{out} = 1/(R_{out}C_L)$（$C_L$ = 每个输出端的电容）；另有一个左半平面零点（left-half-plane zero）
$$\omega_z = \frac{g_{m1} + g_{m7}g_{mA}r_{OA}}{g_{m1}r_{OA}C_X} = \omega_X\left(1 + \frac{g_{m7}g_{mA}r_{OA}}{g_{m1}}\right).$$
- 每侧注入 P 的电流：$\dfrac{V_{in}}{2}\left[g_{m1} + \dfrac{g_{m7}g_{mA}r_{OA}}{1 + sr_{OA}C_X}\right] = \dfrac{V_{in}}{2}(g_{m1} + g_{m7}g_{mA}r_{OA})\dfrac{1 + s/\omega_z}{1 + s/\omega_X}$。快通路（$g_{m1}$）与慢通路（经过 X）相加，所以零点位于左半平面。
- 在 P 点，电流在 $C_P$ 与 $M_5$ 的源极（≈ $1/g_{m5}$，假设 $r_{O2} \parallel r_{O7} \gg 1/g_{m5}$）之间分流：因子为 $1/(1 + sC_P/g_{m5})$。输出节点给出 $R_{out}/(1 + sR_{out}C_L)$。
- 写成三个独立的一阶因子，前提是本征增益（intrinsic gain）很高，且 P 点极点与输出极点相距很远；当 $r_O$ 为有限值时，P 点极点与输出极点是一个耦合二阶分母的根，这种更一般的形式（X 点极点和零点不变）同样正确。这里的增益针对差分输出 $V_{out}$（两个输出端）；单端输出的增益为其一半，极点和零点相同。
- 对消问题：零点总是比 X/Y 极点高出一个增益提升因子 $1 + g_{m7}g_{mA}r_{OA}/g_{m1}$（只要辅助通路起作用，该因子就 > 1；要获得可观的增益提升，它须 ≫ 1），因此零点永远无法抵消该极点；若输出极点低于 $\omega_X$（顺序为 $\omega_{out} < \omega_X < \omega_z < \omega_P$），则在 $\omega_X$ 与 $\omega_z$ 之间增益以 40 dB/dec 下降。原则上可以通过设计把零点放在另一个极点上。若选择 $C_X$ 使 $g_{m1}r_{OA}C_X/(g_{m1} + g_{m7}g_{mA}r_{OA}) = R_{out}C_L$，零点就落在输出极点上，此时 X 成为主极点（dominant pole），而若 $\omega_P$ 远高于它，单位增益频率（unity-gain frequency）≈ $g_{m1}/C_L$；零点也可以放在折叠节点（folding node）极点 $g_{m5}/C_P$ 上。理论上，精确的条件是零点与 P/输出分母的某个根重合。这种对消依赖于匹配互不相关的时间常数，因此实际中并不完美，会留下一个零极点对（doublet），导致缓慢建立。
