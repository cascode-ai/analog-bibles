# 详细步骤 - R251

**思路。** $V_1$ 驱动的是二极管连接（diode-connected）的 $M_2$ 的**源极**，而 $M_1$ 的源极仍然接地。提高 $V_1$ 会迫使 $V_X$ 上升；$M_1$ 看到完整的 $V_X$，导通更强，把 Y 拉低，这又使更多的 $I_{REF}$ 从 X 经 $R_2$ 被分流，直到 $M_2$ 截止。此后 $V_1$ 不再出现在任何方程中，两条曲线都变得平坦。下面写出节点方程，跟踪这些趋势，求出截止点和平坦区的电平，并用示例说明。

### 第 1 步 — 节点方程

$V_{GS2} = V_X - V_1$，$V_{GS1} = V_X$。衬底接地时，$V_{SB2} = V_1$，且

$$V_{TH2}(V_1) = 0.7 + 0.45\left(\sqrt{0.9 + V_1} - \sqrt{0.9}\right),$$

它从 $V_1 = 0$ 时的 0.7 V 升高到 $V_1 = 3$ V 时的 1.16 V；$V_{TH1} = 0.7$ V。对 X 和 Y 应用基尔霍夫电流定律（KCL）：

$$I_{REF} = I_{D2} + \frac{V_X - V_Y}{R_2}, \qquad I_{D2} = \frac{\beta}{2}\left(V_X - V_1 - V_{TH2}(V_1)\right)^2 \ \text{(diode, saturated)} , \qquad (1)$$

$$\frac{V_{DD} - V_Y}{R_1} + \frac{V_X - V_Y}{R_2} = I_{D1}(V_{GS} = V_X,\ V_{DS} = V_Y) . \qquad (2)$$

### 第 2 步 — 起始点 $V_1 = 0$

两个源极都接地，电路是 X 与 Y 之间接有 $R_2$ 的电阻负载电流镜。$V_X$ 是电流为 $I_{D2} = I_{REF} + (V_Y - V_X)/R_2$ 时的二极管电压，并不简单地等于 $V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$：通常 $R_1$ 把 Y 拉到 X 之上，因此有一些电流从 Y 流入 X，$M_2$ 的电流略大于 $I_{REF}$。

### 第 3 步 — 提高 $V_1$：$V_X$ 上升

由 (1)，

$$V_X = V_1 + V_{TH2}(V_1) + \sqrt{\frac{2I_{D2}}{\beta}} .$$

前两项都随 $V_1$ 增大，其中第二项是通过体效应（body effect）增大的，因此 **$V_X$ 上升**；由于 $I_{D2}$ 减小，其上升量略小于 $V_1 + \Delta V_{TH2}$。

### 第 4 步 — $V_Y$ 的响应

在 $M_1$ 饱和时对 (2) 求微分（$dI_{D1} = g_{m1}dV_X$，$g_{m1} = \beta(V_X - 0.7)$）：

$$-\frac{dV_Y}{R_1} + \frac{dV_X - dV_Y}{R_2} = g_{m1}\,dV_X \;\Longrightarrow\; dV_Y\left(\frac{1}{R_1} + \frac{1}{R_2}\right) = dV_X\left(\frac{1}{R_2} - g_{m1}\right) ,$$

$$\frac{dV_Y}{dV_1} = \frac{1 - g_{m1}R_2}{1 + R_2/R_1}\cdot\frac{dV_X}{dV_1} .$$

$R_2$ 把 Y 随 X 一起拉高（对应“1”），而 $M_1$ 增加的电流把 Y 拉低（对应“$g_{m1}R_2$”）。**若 $g_{m1}R_2 > 1$**（通常情况），随着 $V_1$ 升高，**$V_Y$ 下降**；若 $g_{m1}R_2 < 1$，$V_Y$ 随 X 上升，之后可能随着 $g_{m1}$ 增大而出现拐点，也可能一直上升到 $M_2$ 截止。若 $M_1$ 进入线性区（$V_Y < V_X - 0.7$ V），同样的关系仍然成立，只是要把 $g_{m1}$ 换成 $\beta V_Y$，并在左边的电导中再加上 $g_{ds1} = \beta(V_X - 0.7 - V_Y)$。

### 第 5 步 — $M_2$ 的电流减小，$M_2$ 截止

由 (1)，$I_{D2} = I_{REF} - (V_X - V_Y)/R_2$。随着 $V_X$ 上升、$V_Y$ 下降，$R_2$ 从 X 向 Y 分走的 $I_{REF}$ 越来越多，因此 **$I_{D2}$ 减小**（在 $V_1 = 0$ 时，$R_2$ 中的电流甚至可能从 Y 流向 X；随着 $V_1$ 升高，它会反向）。当下式成立时 $M_2$ 截止：

$$V_X - V_1 = V_{TH2}(V_1) \qquad\Longleftrightarrow\qquad V_1 + V_{TH2}(V_1) = V_{X,flat},$$

其中 $V_{X,flat}$ 是 $M_2$ 截止后 $V_X$ 的值（见第 6 步）；对典型参数而言，$V_1$ 只需几百毫伏即可达到这一点。

### 第 6 步 — 平坦区（$M_2$ 截止）

由于 $I_{D2} = 0$，$I_{REF}$ 全部从 X 经 $R_2$ 流入 Y：

$$V_X = V_Y + R_2I_{REF}, \qquad \frac{V_{DD} - V_Y}{R_1} + I_{REF} = I_{D1}(V_{GS} = V_Y + R_2I_{REF},\ V_{DS} = V_Y) .$$

**两个方程都不含 $V_1$**，因此 $V_X$ 和 $V_Y$ 一直到 $V_{DD}$ 都保持**恒定**；$M_2$ 的源极继续升高，但 $M_2$ 只是处于截止状态。若 $R_2I_{REF} > 0.7$ V，$M_1$ 在这里处于线性区，因为此时 $V_{DS1} = V_Y < V_{GS1} - 0.7 = V_Y + R_2I_{REF} - 0.7$。

**例外。** 在理想 $I_{REF}$ 且 $R_2I_{REF}$ 很大的情况下，若 $V_{X,flat}$ 超过 $3\ \mathrm{V} + V_{TH2}(3\ \mathrm{V}) = 3 + 1.16 = 4.16$ V，$M_2$ 在扫描范围内永远不会截止，上述趋势会一直持续到 $V_1 = 3$ V。

### 第 7 步 — 数值示例

$I_{REF} = 100\ \mu$A，$W/L = 10/0.5$（$\beta = 2.68\ \mathrm{mA/V^2}$），$R_1 = R_2 = 10\ \mathrm{k}\Omega$，$V_{DD} = 3$ V。

**平坦区。** $R_2I_{REF} = 1$ V $> 0.7$ V，因此 $M_1$ 处于线性区，且 $V_{GS1} - 0.7 = V_Y + 0.3$ V：

$$\frac{3 - V_Y}{10\ \mathrm{k}\Omega} + 0.1\ \mathrm{mA} = (2.68\ \mathrm{mA/V^2})\left[(V_Y + 0.3)V_Y - \tfrac12V_Y^2\right] .$$

以 V 和 mA 为单位，$0.4 - 0.1V_Y = 1.34V_Y^2 + 0.804V_Y$，即 $1.34V_Y^2 + 0.904V_Y - 0.4 = 0$：

$$V_Y = \frac{-0.904 + \sqrt{0.817 + 2.144}}{2.68} = \frac{-0.904 + 1.721}{2.68} = 0.305\ \mathrm{V}, \qquad V_X = 0.305 + 1.0 = 1.305\ \mathrm{V} .$$

**截止点。** $V_1 + V_{TH2}(V_1) = 1.305$ V。在 $V_1 = 0.5$ V 处，$V_{TH2} = 0.7 + 0.45(1.1832 - 0.9487) = 0.806$ V，二者之和为 1.306 V，因此 $M_2$ 在 $V_1 \approx 0.50$ V 处截止。

**完整求解** (1) 和 (2)：

| $V_1$ (V) | 0 | 0.1 | 0.2 | 0.25 | 0.3 | 0.4 | ≥ 0.5 |
|---|---|---|---|---|---|---|---|
| $V_X$ (V) | 1.015 | 1.089 | 1.151 | 1.176 | 1.201 | 1.263 | 1.305 |
| $V_Y$ (V) | 1.343 | 1.033 | 0.716 | 0.567 | 0.443 | 0.341 | 0.305 |
| $I_{D2}$ (μA) | 133 | 94 | 57 | 39 | 24 | 8 | 0 |
| $I_{D1}$ (μA) | 133 | 202 | 272 | 304 | 331 | 358 | 370 |
| $M_1$ | 饱和 | 饱和 | 饱和 | 饱和 | 线性区 | 线性区 | 线性区 |

在 $V_1 = 0$ 时，$g_{m1}R_2 = \beta(V_X - 0.7)R_2 = (2.68\ \mathrm{mA/V^2})(0.315\ \mathrm{V})(10\ \mathrm{k}\Omega) = 8.4 > 1$，因此在 $V_X$ 上升的同时 $V_Y$ 急剧下降。$V_1 = 0$ 时的 $V_X$（1.02 V）之所以不同于 $V_{GS}(I_{REF}) = 0.97$ V，是因为有 33 μA 的电流从 Y 经 $R_2$ 流入 X。

### 结果

- **起始点 $V_1 = 0$：** X 与 Y 之间接有 $R_2$ 的电阻负载电流镜；起始值由节点方程求出（示例：$V_X \approx 1.02$ V，$V_Y \approx 1.34$ V）。
- **$V_1$ 升高时：** $V_X$ 上升，大致按 $V_1 + V_{TH2}(V_1) + \sqrt{2I_{D2}/\beta}$ 变化。若 $g_{m1}R_2 > 1$（典型情况），$V_Y$ **下降**，因为源极接地的 $M_1$ 被驱动得更强；若 $g_{m1}R_2 < 1$，它反而上升（之后可能出现拐点）。一般地，$M_1$ 饱和时 $dV_Y/dV_1 = \frac{1 - g_{m1}R_2}{1 + R_2/R_1}\,\frac{dV_X}{dV_1}$。随着 $R_2$ 分走更多的 $I_{REF}$，$M_2$ 的电流减小。
- 当 $V_1 + V_{TH2}(V_1)$ 达到平坦区的 $V_X$ 时（示例中约为 0.5 V），**$M_2$ 截止**。此后一直到 $V_{DD}$，**两条曲线都是平坦的**，且 $V_X - V_Y = R_2I_{REF}$（$I_{REF}$ 全部经 $R_2$ 流入 $M_1$；若 $R_2I_{REF} > 0.7$ V，$M_1$ 处于线性区）。示例中 $V_X \approx 1.30$ V，$V_Y \approx 0.30$ V。
- 若平坦区的 $V_X$ 超过约 4.16 V（只有在 $R_2I_{REF}$ 很大时才可能），$M_2$ 将在整个范围内保持导通。

**常见错误。** 让 $V_X$ 一直按 $V_1 + V_{GS}$ 跟随到 $V_1 = 3$ V。$M_1$ 把 Y 拉低，$R_2$ 把 $I_{REF}$ 从 $M_2$ 分走，因此 $V_1$ 只需适度升高 $M_2$ 就会截止，此后 X 不再依赖于 $V_1$。

**常见错误。** （对典型参数）把 $V_Y$ 画成从一开始就随 $V_1$ 上升。源极接地的 $M_1$ 的栅极电压升高会增大其电流，只要 $g_{m1}R_2 > 1$，Y 就会下降。

**常见错误。** 把 $M_1$ 的源极也接到 $V_1$。只有 $M_2$ 的源极接 $V_1$，正是这种不对称使该电路不同于普通的电流镜。
