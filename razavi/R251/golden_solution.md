# Golden Solution - R251

## Reference answer

As $V_1$ rises from 0, $V_X$ rises (about $V_1 + V_{GS2}$) and, for $g_{m1}R_2 > 1$ (e.g., the example below), $V_Y$ falls; if $g_{m1}R_2 < 1$, $V_Y$ rises, because $R_2$ pulls Y up with X ($g_{m1} = \beta(V_X - 0.7)$ with $M_1$ saturated, $\beta V_Y$ in triode; $V_Y$ can turn over when this condition changes, or keep rising if $g_{m1}R_2 < 1$ throughout). $M_2$ cuts off where $V_1 + V_{TH2}(V_1)$ reaches the flat-region $V_X$ (a few hundred mV for typical values, later for a large flat-region $V_X$), and from then on $V_X$ and $V_Y$ are constant, with $V_X - V_Y = R_2I_{REF}$ ($M_1$ in triode if $R_2I_{REF} > 0.7$ V, as in the example).

- At $V_1 = 0$ the circuit is a resistor-loaded mirror with $R_2$ between X and Y; the start values follow from the node equations ($I_{D2} = I_{REF} + (V_Y - V_X)/R_2$, so $V_X$ is not simply $V_{GS}(I_{REF})$: 1.02 V vs 0.97 V in the example).
- Raising $V_1$ lifts $M_2$'s source; $V_X \approx V_1 + V_{TH2}(V_{SB}=V_1) + \sqrt{2I_{D2}/\beta}$. $M_1$, with its source grounded, sees the larger $V_{GS1} = V_X$, so $I_{D1}$ grows; in general $dV_Y/dV_X = (1/R_2 - g_{m1})/(1/R_1 + 1/R_2 + g_{ds1})$ ($g_{ds1} = 0$ when saturated), i.e. with $M_1$ saturated $dV_Y/dV_1 = \dfrac{1 - g_{m1}R_2}{1 + R_2/R_1}\,\dfrac{dV_X}{dV_1}$, so $V_Y$ drops when $g_{m1}R_2 > 1$ (and $M_1$ soon enters triode if $R_2I_{REF} > 0.7$ V). As $V_X - V_Y$ grows, $R_2$ carries an increasing share of $I_{REF}$ from X to Y (at $V_1 = 0$ its current may even flow from Y to X, as in the example), so $I_{D2}$ shrinks.
- $M_2$ turns off when $V_X - V_1 = V_{TH2}(V_1)$. Afterwards all of $I_{REF}$ flows through $R_2$: $V_X = V_Y + R_2I_{REF}$, and $V_Y$ follows from $(V_{DD}-V_Y)/R_1 + I_{REF} = I_{D1}(V_{GS} = V_X, V_{DS} = V_Y)$. Neither equation involves $V_1$, so both curves are flat up to $V_{DD}$. (If the flat-region $V_X$ exceeds $3\ \mathrm{V} + V_{TH2}(3\ \mathrm{V}) \approx 4.16$ V, possible with an ideal $I_{REF}$ and a large $R_2I_{REF}$, $M_2$ stays on over the whole range.)
- Example ($I_{REF}$ = 100 μA, W/L = 10/0.5 with $\mu_nC_{ox}$ = 134 μA/V², i.e. β = 2.68 mA/V², $R_1 = R_2$ = 10 kΩ; square-law simulation): $V_1$ = 0 → $V_X$ ≈ 1.02 V, $V_Y$ ≈ 1.34 V; $V_1$ = 0.25 V → 1.18, 0.57 V; for $V_1 \gtrsim 0.5$ V, $M_2$ off and $V_X$ ≈ 1.30 V, $V_Y$ ≈ 0.30 V constant.
