当 $V_1$ 从 0 开始升高时，$V_X$ 上升（约为 $V_1 + V_{GS2}$）；若 $g_{m1}R_2 > 1$（例如下面的示例），$V_Y$ 下降；若 $g_{m1}R_2 < 1$，$V_Y$ 则上升，因为 $R_2$ 会把 Y 随 X 一起拉高。这里 $M_1$ 饱和时 $g_{m1} = \beta(V_X - 0.7)$，处于线性区（triode region）时则为 $\beta V_Y$；当这一条件发生变化时 $V_Y$ 可能出现拐点；若始终有 $g_{m1}R_2 < 1$，则会持续上升。当 $V_1 + V_{TH2}(V_1)$ 达到平坦区的 $V_X$ 时，$M_2$ 截止（对典型参数而言，这发生在几百毫伏处；若平坦区的 $V_X$ 较大，则发生得更晚），此后 $V_X$ 和 $V_Y$ 保持恒定，且 $V_X - V_Y = R_2I_{REF}$（若 $R_2I_{REF} > 0.7$ V，$M_1$ 处于线性区，示例中即是如此）。

- 在 $V_1 = 0$ 时，电路是 X 与 Y 之间接有 $R_2$ 的电阻负载电流镜（current mirror）；起始值由节点方程求出（$I_{D2} = I_{REF} + (V_Y - V_X)/R_2$，因此 $V_X$ 并不简单地等于 $V_{GS}(I_{REF})$：示例中为 1.02 V 对 0.97 V）。
- 提高 $V_1$ 会抬高 $M_2$ 的源极；$V_X \approx V_1 + V_{TH2}(V_{SB}=V_1) + \sqrt{2I_{D2}/\beta}$。$M_1$ 的源极接地，它看到的是更大的 $V_{GS1} = V_X$，因此 $I_{D1}$ 增大；一般地，$dV_Y/dV_X = (1/R_2 - g_{m1})/(1/R_1 + 1/R_2 + g_{ds1})$（饱和时 $g_{ds1} = 0$），即 $M_1$ 饱和时 $dV_Y/dV_1 = \dfrac{1 - g_{m1}R_2}{1 + R_2/R_1}\,\dfrac{dV_X}{dV_1}$，因此当 $g_{m1}R_2 > 1$ 时 $V_Y$ 下降（若 $R_2I_{REF} > 0.7$ V，$M_1$ 很快会进入线性区）。随着 $V_X - V_Y$ 增大，$R_2$ 从 X 向 Y 分走的 $I_{REF}$ 越来越多（在 $V_1 = 0$ 时，其电流甚至可能从 Y 流向 X，示例中即是如此），因此 $I_{D2}$ 减小。
- 当 $V_X - V_1 = V_{TH2}(V_1)$ 时 $M_2$ 截止。此后 $I_{REF}$ 全部流过 $R_2$：$V_X = V_Y + R_2I_{REF}$，而 $V_Y$ 由 $(V_{DD}-V_Y)/R_1 + I_{REF} = I_{D1}(V_{GS} = V_X, V_{DS} = V_Y)$ 求出。两个方程都不含 $V_1$，因此两条曲线一直到 $V_{DD}$ 都是平坦的。（若平坦区的 $V_X$ 超过 $3\ \mathrm{V} + V_{TH2}(3\ \mathrm{V}) \approx 4.16$ V——在理想 $I_{REF}$ 且 $R_2I_{REF}$ 很大时这是可能的——则 $M_2$ 在整个范围内都保持导通。）
- 示例（$I_{REF}$ = 100 μA，W/L = 10/0.5，$\mu_nC_{ox}$ = 134 μA/V²，即 β = 2.68 mA/V²，$R_1 = R_2$ = 10 kΩ；按平方律仿真）：$V_1$ = 0 → $V_X$ ≈ 1.02 V，$V_Y$ ≈ 1.34 V；$V_1$ = 0.25 V → 1.18、0.57 V；当 $V_1 \gtrsim 0.5$ V 时，$M_2$ 截止，$V_X$ ≈ 1.30 V，$V_Y$ ≈ 0.30 V，保持恒定。
