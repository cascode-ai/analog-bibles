# 详细步骤 - R353

**思路。** 把每个晶体管的闪烁噪声放在与其栅极串联的位置：$M_1$ 的噪声于是与输入串联，而 $M_2$ 的噪声成为输出节点上的噪声电流。计入 $M_1$ 的体效应，在输出端列基尔霍夫电流定律（KCL）方程，再把输出噪声除以跟随器的增益；体效应会被抵消。

### 第 1 步 — 噪声源

两个器件都是 NMOS，因此都用 $K_N$：

$$\overline{V_{n1}^2} = \frac{K_N}{C_{ox}(WL)_1\,f}, \qquad \overline{V_{n2}^2} = \frac{K_N}{C_{ox}(WL)_2\,f}.$$

两个噪声源互不相关。

### 第 2 步 — 计入体效应的小信号模型（small-signal model）

- **$M_1$：** 漏极接交流地，衬底（bulk）接地。有效栅极电压为 $v_{in} + V_{n1}$，$v_{bs1} = 0 - v_{out}$，它向输出端送入电流
$$g_{m1}(v_{in} + V_{n1} - v_{out}) + g_{mb1}(0 - v_{out}).$$
- **$M_2$**（源极接地，栅极为交流地加上其噪声 $V_{n2}$）：它从输出端抽取 $g_{m2}V_{n2}$。由于 $\lambda = 0$，它没有输出电阻（output resistance）；由于衬底和源极都接地，它也没有体效应。

### 第 3 步 — 输出端的 KCL

$M_1$ 送入的电流等于 $M_2$ 抽取的电流：

$$g_{m1}(v_{in} + V_{n1} - v_{out}) - g_{mb1}v_{out} = g_{m2}V_{n2},$$

$$
\begin{aligned}
v_{out}(g_{m1} + g_{mb1}) &= g_{m1}(v_{in} + V_{n1}) - g_{m2}V_{n2}\\
v_{out} &= \frac{g_{m1}(v_{in} + V_{n1}) - g_{m2}V_{n2}}{g_{m1} + g_{mb1}}.
\end{aligned}
$$

### 第 4 步 — 增益与输入参考噪声

增益就是熟悉的源极跟随器的值，

$$A_v = \frac{v_{out}}{v_{in}} = \frac{g_{m1}}{g_{m1} + g_{mb1}},$$

输出噪声则是像输入一样被放大的 $M_1$ 的噪声，加上 $M_2$ 的噪声电流流入输出电阻 $1/(g_{m1} + g_{mb1})$ 所产生的电压：

$$v_{out}\Big|_{noise} = \frac{g_{m1}V_{n1} - g_{m2}V_{n2}}{g_{m1} + g_{mb1}}.$$

除以 $A_v$：

$$v_{n,in} = \frac{g_{m1}V_{n1} - g_{m2}V_{n2}}{g_{m1} + g_{mb1}}\cdot\frac{g_{m1} + g_{mb1}}{g_{m1}} = V_{n1} - \frac{g_{m2}}{g_{m1}}V_{n2}.$$

因子 $g_{m1} + g_{mb1}$ 被约去：**体效应不改变输入参考噪声**（忽略 $r_O$ 时），因为它使增益和输出电阻按相同比例减小。把互不相关的功率相加：

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \overline{V_{n1}^2} + \frac{g_{m2}^2}{g_{m1}^2}\overline{V_{n2}^2}\\
&= \frac{K_N}{C_{ox}f}\left[\frac{1}{(WL)_1} + \frac{g_{m2}^2}{g_{m1}^2}\cdot\frac{1}{(WL)_2}\right].
\end{aligned}
$$

### 第 5 步 — 物理解释与设计提示

该结果与跟随器热噪声 $4kT\gamma\left(1/g_{m1} + g_{m2}/g_{m1}^2\right)$ 的结构相同。为减小它，应使 $M_1$ 的面积大，并使 $M_2$ 的面积大且 $g_{m2}$ 相对于 $g_{m1}$ 较小（在给定电流下过驱动电压大）；让 $M_2$ 采用长沟道可以同时做到这两点，即在 $W/L$ 较小的同时使 $WL$ 较大。

### 结果

$$\overline{V_{n,in}^2}\Big|_{1/f} = \frac{K_N}{C_{ox}f}\left[\frac{1}{(WL)_1} + \frac{g_{m2}^2}{g_{m1}^2}\cdot\frac{1}{(WL)_2}\right]$$

$M_1$ 的栅极噪声直接与输入串联。$M_2$ 的噪声电流 $g_{m2}V_{n2}$ 流入输出电阻 $1/(g_{m1} + g_{mb1})$，再除以增益 $g_{m1}/(g_{m1} + g_{mb1})$，得到 $g_{m2}V_{n2}/g_{m1}$。因此体效应被抵消。

**常见错误。** 认为跟随器的输出阻抗（output impedance）很低，所以 $M_2$ 的噪声到达不了输出端。这个阻抗 $1/(g_{m1} + g_{mb1})$ 并不为零，而且 $M_2$ 的噪声折算到输入端为 $(g_{m2}/g_{m1})V_{n2}$，当 $g_{m2} \approx g_{m1}$ 时与 $M_1$ 自身的噪声相当。

**常见错误。** 用 $g_{m2}/g_{m1}$ 而不是 $(g_{m2}/g_{m1})^2$ 作为 $M_2$ 项的权重。被 $g_{m2}/g_{m1}$ 缩放的是**电压** $V_{n2}$，因此其功率谱密度要按平方缩放。

**常见错误。** 对体效应的处理前后不一致，例如把 $M_2$ 项除以 $(g_{m1} + g_{mb1})^2$，而信号却使用增益 $g_{m1}/(g_{m1} + g_{mb1})$。处理一致时，$g_{m1} + g_{mb1}$ 会被约去。
