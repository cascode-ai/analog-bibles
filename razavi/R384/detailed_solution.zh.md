# 详细步骤 - R384

**思路。** 每个半边都是一个“超级源极跟随器”（super source follower）：漏极电流固定的 $M_1$ 迫使其源极跟踪栅极，而 $M_3$ 提供源极节点所需的任何电流。对漏极和源极节点列 KCL 可知，$I_{D3} - I_{D4}$ 等于 $2/R_S$ 乘以两源极电压之差，再加上来自 $R_S$ 噪声的一项；$M_1$、$M_2$ 和 $R_S$ 的噪声会到达输出端，而 $M_3$、$M_4$ 的噪声被局部环路吸收。除以 $2/R_S$，即可把噪声折算到输入端。

### 第 1 步 — 节点与小信号模型（small-signal model）

在左半边（右半边与之镜像对称）中，把 $M_1$ 的漏极节点记为 $A_1$，源极节点记为 $S_1$；$R_S$ 连接 $S_1$ 与 $S_2$。噪声源包括：$M_1$–$M_4$ 的沟道噪声电流 $4kT\gamma g_m$，它们的闪烁噪声栅极电压（$M_1$、$M_2$ 用 $K_N$；$M_3$、$M_4$ 用 $K_P$），以及与 $R_S$ 并联的噪声电流 $\overline{I_{nR}^2} = 4kT/R_S$。

$A_1$ 只与 $M_1$ 的漏极和 $M_3$ 的栅极相连（理想电流源相当于开路，栅极不吸取电流，且 $\lambda = 0$）。$S_1$ 与 $M_1$ 的源极、$M_3$ 的漏极、$R_S$ 以及开路的下方电流源相连。$M_1$ 中从 $A_1$ 流向 $S_1$ 的电流为 $g_{m1}(V_{G1} - V_{S1}) + I_{n1}$，$M_3$ 中从 $V_{DD}$（交流地）流入 $S_1$ 的电流为 $g_{m3}(0 - V_{A1}) + I_{n3}$。

### 第 2 步 — $M_1$ 的漏极电流固定，因此其源极跟随栅极

在 $A_1$ 点只有 $M_1$ 能流过小信号电流，因此其小信号漏极电流为零：

$$
\begin{aligned}
g_{m1}(V_{G1} - V_{S1}) + I_{n1} &= 0\\
V_{S1} &= V_{G1} + \frac{I_{n1}}{g_{m1}}.
\end{aligned}
$$

源极**严格**跟踪栅极，$M_1$ 的热噪声表现为 $S_1$ 处额外的电压 $I_{n1}/g_{m1}$；其闪烁噪声电压 $V_{f1}$ 本来就与栅极串联，直接出现在源极：$V_{S1} = V_{G1} + I_{n1}/g_{m1} + V_{f1}$。同理

$$V_{S2} = V_{G2} + \frac{I_{n2}}{g_{m2}} + V_{f2}, \qquad g_{m2} = g_{m1}.$$

### 第 3 步 — 输出电流差：跨导为 $2/R_S$

对 $S_1$ 列 KCL：$M_1$ 不提供小信号电流（第 2 步），下方电流源是理想的，因此 $M_3$ 的漏极电流全部经 $R_S$ 支路流出（连同 $I_{nR}$，其方向取为从 $S_1$ 到 $S_2$）：

$$i_{d3} = \frac{V_{S1} - V_{S2}}{R_S} + I_{nR}, \qquad i_{d4} = \frac{V_{S2} - V_{S1}}{R_S} - I_{nR}.$$

两式相减：

$$i_{d3} - i_{d4} = \frac{2\,(V_{S1} - V_{S2})}{R_S} + 2I_{nR}.$$

只考虑信号时，$V_{S1} - V_{S2} = V_{G1} - V_{G2} = V_{in}$，因此

$$G_m = \frac{i_{d3} - i_{d4}}{V_{in}} = \frac{2}{R_S}.$$

出现因子 2，是因为 $R_S$ 中的电流从一侧流出、从另一侧流入。

### 第 4 步 — 为什么 $M_3$ 和 $M_4$ 没有贡献

$M_3$ 的噪声没有出现在第 3 步中：$i_{d3}$ 由 $V_{S1}$、$V_{S2}$ 和 $R_S$ 决定，而 $V_{S1}$ 由 $M_1$ 决定。因此 $M_3$ 的总漏极电流由电路的其余部分规定，

$$g_{m3}(0 - V_{A1}) + I_{n3} = i_{d3} \quad\Longrightarrow\quad V_{A1} = \frac{I_{n3} - i_{d3}}{g_{m3}},$$

它的噪声只会使栅极节点 $A_1$ 的电压变化。高阻抗节点 $A_1$ 使局部环路增益为无穷大：$M_3$ 提供的任何额外电流都会抬高 $V_{S1}$，减小 $M_1$ 的电流，从而抬高 $V_{A1}$，直到 $M_3$ 的电流恰好减少 $I_{n3}$ 为止。$M_4$ 以及两者的闪烁噪声也是如此。

### 第 5 步 — 输入参考噪声

把第 2 步中含噪声的源极电压代入第 3 步：

$$i_{d3} - i_{d4} = \frac{2}{R_S}\left[V_{in} + \frac{I_{n1} - I_{n2}}{g_{m1}} + V_{f1} - V_{f2}\right] + 2I_{nR}.$$

把噪声部分除以 $G_m = 2/R_S$：

$$V_{n,in} = \frac{I_{n1} - I_{n2}}{g_{m1}} + V_{f1} - V_{f2} + R_SI_{nR}.$$

各噪声源互不相关，因此功率相加：

$$
\begin{aligned}
\text{$M_1$, $M_2$ thermal:}&\quad 2\cdot\frac{4kT\gamma g_{m1}}{g_{m1}^2} = \frac{8kT\gamma}{g_{m1}},\\
\text{$R_S$:}&\quad R_S^2\cdot\frac{4kT}{R_S} = 4kTR_S,\\
\text{$M_1$, $M_2$ flicker:}&\quad 2\cdot\frac{K_N}{C_{ox}(WL)_1f} = \frac{2K_N}{C_{ox}(WL)_1f}.
\end{aligned}
$$

### 结果

$$\overline{V_{n,in}^2} = \frac{8kT\gamma}{g_{m1}} + 4kTR_S + \frac{2K_N}{C_{ox}(WL)_1f}$$

从 $V_{in}$ 到 $I_{D3} - I_{D4}$ 的跨导为 $2/R_S$。$M_1$ 和 $M_2$ 贡献其折算到栅极的热噪声和闪烁噪声，$R_S$ 贡献 $4kTR_S$，而 **$M_3$、$M_4$ 没有贡献**，因为它们的噪声被增益为无穷大的局部环路吸收（在电流源理想且 $\lambda = 0$ 的条件下）。

**常见错误。** 让 $M_3$ 的噪声电流直接流到输出端。$I_{D3}$ 由 $S_1$ 处的 KCL 决定，$V_{S1}$ 由 $M_1$ 决定；$M_3$ 的噪声只会改变它自己的栅极电压。

**常见错误。** 声称环路也会抑制 $M_1$ 的噪声。$I_{n1}/g_{m1}$ 位于 $M_1$ 的栅极与源极之间，恰好处在跟随器的输入端，因此会无衰减地传递过去。

**常见错误。** 把 $g_{m1}$ 或 $g_{m3}$ 当作跨导，或者漏掉因子 2。用 $2I_{nR}$ 除以 $2/R_S$ 得到 $R_SI_{nR}$，即恰好为 $4kTR_S$（而不是 $kTR_S$ 或 $16kTR_S$）。
