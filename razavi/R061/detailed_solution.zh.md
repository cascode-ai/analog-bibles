# 详细步骤 - R061

**思路。** 采用缓变沟道（gradual-channel）图像：沟道电势 $V(x)$ 从源极处的 0 上升到漏极处的 $V_{DS}$，只有在 $V_G - V(x) > V_{TH}$ 的地方才存在反型层。夹断点是局部沟道电势达到 $V_G - V_{TH}$ 的位置。在 $V_{DS}$ 固定为 1.2 V 的条件下，随着 $V_G$ 依次经过截止区、饱和区和线性区，跟踪这个点的变化。

### 第 1 步 — 沟道在哪里夹断

这里 $V_{GS} = V_G$，$V_{DS} = 1.2$ V（固定）。令 $x$ 沿沟道从源极处的 $x = 0$ 变到漏极处的 $x = L$，沟道电势为 $V(x)$，$V(0) = 0$，$V(L) = V_{DS}$。单位长度的可动电荷为

$$Q_d(x) = WC_{ox}\left[V_G - V(x) - V_{TH}\right],$$

它在源极处最大，向漏极方向减小。沟道在 $Q_d$ 降为零的地方**夹断**：

$$V_G - V(x_p) - V_{TH} = 0 \quad\Longleftrightarrow\quad V(x_p) = V_G - V_{TH} ,$$

即沟道电势等于过驱动电压（overdrive voltage）$V_{ov} = V_G - V_{TH}$ 的地方。

- 若 $V_{DS} > V_{ov}$（**饱和区**），这一电势在到达漏极**之前**就已达到：反型层在 $x_p < L$ 处终止，剩余的电压 $V_{DS} - V_{ov}$ 降落在长度为 $\Delta L = L - x_p$ 的一小段耗尽区（depletion region）上，电子在强横向电场的作用下扫过这一区域。
- 若 $V_{DS} < V_{ov}$（**线性区**），反型层一直延伸到漏极，不存在夹断。

### 第 2 步 — $V_G < V_{TH} = 0.7$ V：没有沟道，也没有夹断点

即使在源端也有 $V_G - 0 < V_{TH}$，因此任何地方都没有反型层，也就无所谓夹断。器件截止，只有很小的亚阈值（subthreshold）电流。

### 第 3 步 — $0.7\ \mathrm{V} < V_G < 1.9$ V：饱和区；夹断点向漏极移动

源端形成沟道。只要满足下式，器件就处于饱和区：

$$V_{DS} > V_G - V_{TH} \quad\Longleftrightarrow\quad 1.2\ \mathrm{V} > V_G - 0.7\ \mathrm{V} \quad\Longleftrightarrow\quad V_G < 1.9\ \mathrm{V}.$$

沟道在 $V(x_p) = V_G - 0.7$ V 处夹断，耗尽间隙上的电压为

$$V_{gap} = V_{DS} - (V_G - V_{TH}) = 1.2 - (V_G - 0.7) = 1.9 - V_G .$$

随着 $V_G$ 增大：

- 发生夹断的电势 $V_G - V_{TH}$ 向 $V_{DS}$ 升高；
- 间隙上的电压 $1.9 - V_G$ 减小；
- 较小的电压只需较短的耗尽区，因此间隙 $\Delta L$ 缩短，**夹断点向漏极移动**；
- 有效沟道长度 $L_{eff} = L - \Delta L$ 增大。

作为粗略的一维估计，在掺杂浓度为 $N_{sub}$ 的衬底中承受电压 $V_{gap}$ 的耗尽区，其长度的量级为 $\sqrt{2\epsilon_{si}V_{gap}/(qN_{sub})}$，因此 $\Delta L$ 大致按 $\sqrt{1.9 - V_G}$ 缩短。若 $V_G$ 固定而 $V_{DS}$ 增大，同样的物理机制会使夹断点**向源极**移动，这就是沟道长度调制（channel-length modulation）的起因。

| $V_G$（V） | $V_G - V_{TH}$（V） | 间隙上的电压 $1.9 - V_G$（V） | 夹断点 |
|---|---|---|---|
| < 0.7 | — | — | 没有沟道 |
| 1.0 | 0.3 | 0.9 | 离漏极最远 |
| 1.3 | 0.6 | 0.6 | 更靠近漏极 |
| 1.6 | 0.9 | 0.3 | 非常靠近漏极 |
| 1.9 | 1.2 | 0 | 位于漏极边缘 |
| > 1.9 | > 1.2 | — | 不存在（线性区） |

### 第 4 步 — $V_G = 1.9$ V：夹断点位于漏极（饱和区边缘）

在 $V_G = V_{TH} + V_{DS} = 0.7 + 1.2 = 1.9$ V 时，沟道电势恰好在漏极处达到 $V_G - V_{TH} = 1.2$ V：反型电荷恰好在漏极边缘降为零，间隙消失。这就是饱和区与线性区的边界 $V_{DS} = V_{GS} - V_{TH}$。

### 第 5 步 — $V_G > 1.9$ V：线性区，没有夹断

此时包括漏极在内，处处都有 $V_G - V(x) - V_{TH} > 0$：

$$Q_d(L) = WC_{ox}(V_G - 1.2 - 0.7) = WC_{ox}(V_G - 1.9) > 0 .$$

反型层从源极到漏极连续分布，**没有夹断点**：器件处于线性区，相当于一个受栅极控制的电阻。继续增大 $V_G$ 会使沟道处处变厚（例如在 $V_G = 2.2$ V 时，漏端的电荷对应于 $0.3$ V 的局部过驱动电压）。

### 结果

- $V_G < 0.7$ V：没有反型层，因此没有夹断点。
- $0.7\ \mathrm{V} < V_G < 1.9$ V（饱和区）：沟道在局部沟道电压等于 $V_G - V_{TH}$ 的地方夹断，位于漏极之前。随着 $V_G$ 升高，这一电压趋近 $V_{DS} = 1.2$ V，夹断点与漏极之间的耗尽间隙（承受 $1.9 - V_G$ 的电压）缩短，**夹断点向漏极移动**；有效沟道长度增大。
- $V_G = V_{TH} + V_{DS} = 1.9$ V：夹断点到达漏极（饱和区边缘）。
- $V_G > 1.9$ V：线性区；反型层连续延伸到漏极，没有夹断点。

**常见错误。** 说随着 $V_G$ 增大，夹断点向源极移动；那是 $V_G$ 固定、$V_{DS}$ 增大时的情形。升高 $V_G$ 会提高发生夹断的沟道电势，因此夹断点向漏极移动。

**常见错误。** 在线性区仍保留夹断点。当 $V_G > 1.9$ V 时，漏端的局部过驱动电压 $V_G - V_{DS} - V_{TH}$ 为正，因此沟道在任何地方都不会夹断。
