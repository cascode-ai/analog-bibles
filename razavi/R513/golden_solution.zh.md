$\mathrm{PM}(\beta_1) = 90° - \tan^{-1}x$，其中 $x = \omega_u/\omega_{p2}$ 满足 $x\sqrt{1 + x^2} = \dfrac{2\beta_1}{3}$，即 $x = \sqrt{\dfrac{\sqrt{1 + 16\beta_1^2/9} - 1}{2}}$。随着 $\beta_1$ 减小，PM 增大并趋近 90°：$\beta_1$ = 0.5 时 ≈ 72°，$\beta_1$ = 0.25 时 ≈ 81°。
- 双极点环路，主极点远低于增益交点（gain crossover），贡献 90° 相移：$|\beta H| \approx \beta A_0\omega_{p1}/[\omega\sqrt{1 + (\omega/\omega_{p2})^2}]$，PM = 90° − $\tan^{-1}(\omega_u/\omega_{p2})$。
- β = 1，PM = 60°：$\omega_{u1} = \omega_{p2}\tan30° = \omega_{p2}/\sqrt3$，因此 $A_0\omega_{p1} = \omega_{u1}\sqrt{1 + 1/3} = \tfrac23\omega_{p2}$。
- 反馈系数为 $\beta_1$ 时：$\beta_1\tfrac23\omega_{p2} = \omega_u\sqrt{1 + (\omega_u/\omega_{p2})^2}$，由此得到上面关于 x 的方程。验算：$\beta_1 = 1$ 时 $x = 1/\sqrt3$，PM = 60°。
- 更简单的近似（忽略第二个极点对幅值的影响）：$\omega_u \approx \beta_1\omega_{u1}$，因此 PM ≈ 90° − $\tan^{-1}(\beta_1/\sqrt3)$：0.5 时 ≈ 74°，0.25 时 ≈ 82°。
- （以上结论在 $\beta_1A_0 \gg 1$ 时成立，此时主极点仍贡献 ≈ 90°。）
