# 详细步骤 - R703

**思路。** 按 $\alpha = 2$ 进行理想（恒定电场）按比例缩小时，每个尺寸，无论纵向还是横向，都按因子 2 缩小。方块电阻 $R_\square = \rho/t$ 取决于多晶硅厚度 $t$，而栅极电阻等于 $R_\square$ 乘以沿栅极的方块数。对两者分别应用按比例缩小，并保持（简并掺杂的）栅极导体的电阻率不变。

### 第 1 步 — 哪些量按比例缩小

恒定电场按比例缩小把 $W$、$L$、$t_{ox}$、结深、**栅极多晶硅厚度 $t$** 以及各电压都除以 $\alpha$，并把衬底掺杂乘以 $\alpha$（以按比例缩小耗尽区宽度）。导体的电阻率保持不变：栅极多晶硅已经简并掺杂，接近固溶度极限，因此其电阻率无法按比例降低（这正是栅极和互连电阻随尺寸缩小而恶化的原因）。这里器件从 $W/L = 100\ \mu\mathrm{m}/0.5\ \mu\mathrm{m}$ 变为 $50\ \mu\mathrm{m}/0.25\ \mu\mathrm{m}$。

### 第 2 步 — 栅极多晶硅的方块电阻

取 $t' = t/2$，$\rho' = \rho$：

$$R'_\square = \frac{\rho'}{t'} = \frac{\rho}{t/2} = 2\,\frac{\rho}{t} = 2R_\square .$$

**方块电阻加倍。**

### 第 3 步 — 栅极总电阻

栅极信号从栅极接触孔进入，**沿器件宽度 $W$ 的方向**在多晶硅条中传播，而多晶硅条本身宽为 $L$，因此该条共有 $n_\square = W/L$ 个方块，且

$$R_G = R_\square\,\frac{W}{L}.$$

**缩小前：**

$$n_\square = \frac{100\ \mu\mathrm{m}}{0.5\ \mu\mathrm{m}} = 200, \qquad R_G = 200\,R_\square .$$

**缩小后：** $W$ 和 $L$ 都减半，因此方块数不变，而每个方块的电阻变为原来的两倍：

$$n'_\square = \frac{50\ \mu\mathrm{m}}{0.25\ \mu\mathrm{m}} = 200, \qquad R'_G = R'_\square\,n'_\square = (2R_\square)(200) = 400\,R_\square = 2R_G .$$

**栅极总电阻加倍。** 在噪声和速度计算中使用的**等效**分布式栅极电阻（对于一端接触的栅极为 $R_\square W/(3L)$）也是如此，因为它同样是 $R_\square$ 乘以不变的 $W/L$。

**一般形式。** 如果多晶硅电阻率也改变为 $\rho'$，则两个量按相同的因子变化：

$$\frac{R'_\square}{R_\square} = \frac{R'_G}{R_G} = \frac{\rho'/(t/2)}{\rho/t} = 2\,\frac{\rho'}{\rho}.$$

如果把多晶硅掺杂也加倍且迁移率不变，则 $\rho' = \rho/2$，两个量都保持不变；但这是一种非标准的理解，因为栅极多晶硅的掺杂已经达到有用的最大值。

### 第 4 步 — 为什么这很重要

- **栅极电阻与跨导（transconductance）。** 理想按比例缩小不改变 $g_m = \mu C_{ox}(W/L)V_{ov}$（$C_{ox} \times 2$，$W/L$ 不变，$V_{ov}/2$），因此 $R_Gg_m$ 加倍，栅极电阻的热噪声（thermal noise）$4kTR_G$ 相对于沟道噪声的重要性变为原来的两倍。
- **栅极 RC 时间常数。** $C_G = WLC_{ox}$ 按 $(1/2)(1/2)(2) = 1/2$ 缩放，因此
$$R'_GC'_G = (2R_G)\left(\tfrac12C_G\right) = R_GC_G,$$
保持不变，而本征延迟减半：相对于器件速度，栅极 RC 的重要性变为原来的两倍。
- **补救措施。** 把宽器件分成更多（更短的）栅指，在栅极两端都加接触，并使用硅化多晶硅，它能使 $R_\square$ 降低一个数量级以上。

### 结果

在多晶硅电阻率不变的情况下（这是理想按比例缩小中对导体的标准约定）：

- **栅极多晶硅的方块电阻：加倍**，$R'_\square = \rho/(t/2) = 2R_\square$，因为多晶硅厚度减半。
- **栅极总电阻：加倍**，$R'_G = 2R_\square\times(50/0.25) = 400R_\square = 2R_G$，因为方块数 $W/L = 200$ 不变，而每个方块的电阻变为原来的两倍。

**常见错误。** 因为“$W$ 减半”而得出栅极电阻减半（或变为四分之一）的结论。栅极电阻取决于**比值** $W/L$，而 $W$ 和 $L$ 都减半了。

**常见错误。** 认为方块电阻保持不变。$R_\square = \rho/t$，而理想按比例缩小使所有纵向尺寸都减半，包括栅极多晶硅的厚度。

**常见错误。** 把“掺杂 $\times\alpha$”规则用于栅极多晶硅，并得出什么都不变的结论。该规则针对的是衬底掺杂；栅极多晶硅已经简并掺杂，因此其电阻率保持不变，两个量都加倍。
