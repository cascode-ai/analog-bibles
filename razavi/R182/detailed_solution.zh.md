# 详细步骤 - R182

**思路。** 输入相等时，对称电路不偏向任何一边，因此两个输出相等，在整个扫描范围内 $V_{out} = 0$。一个简短的 KCL 论证可以确认这一点在每个工作区都成立；为完整起见，还描述了输入升高时输出共同电平的变化。

### 第 1 步 — 扫描的是什么

把左侧输出节点（$M_1$、$M_3$ 的漏极）记为 $X$，右侧记为 $Y$，尾节点记为 $P$；$V_{out} = V_X - V_Y$。两个输入连在一起，$V_{in1} = V_{in2} = V_{in}$，从 0 扫到 3 V：这是纯粹的**共模**（common-mode）扫描。

### 第 2 步 — KCL 论证：两个输出必须相等

设 $I_R = (V_X - V_Y)/R_1$ 从 $X$ 经 $R_1$ 流向 $Y$。两个输出节点的 KCL：

$$I_{D3} = I_{D1} + I_R, \qquad I_{D4} = I_{D2} - I_R .$$

假设 $V_X > V_Y$。则 $I_R > 0$；二极管 $M_3$ 的源栅电压较小（$V_{SG3} = V_{DD} - V_X < V_{DD} - V_Y = V_{SG4}$），因此 $I_{D3} \le I_{D4}$；而 $M_1$、$M_2$ 的 $V_{GS}$ 相同，因此在饱和区（saturation region）$I_{D1} = I_{D2}$，在线性区（triode region）则漏极电压较高的那个（$M_1$）电流较大：无论哪种情况都有 $I_{D1} \ge I_{D2}$。结合 KCL，

$$I_{D3} = I_{D1} + I_R > I_{D1} \ge I_{D2} = I_{D4} + I_R > I_{D4},$$

这与 $I_{D3} \le I_{D4}$ 矛盾。交换两边后，同样的论证可以排除 $V_X < V_Y$。因此

$$V_X = V_Y, \qquad I_R = 0, \qquad V_{out} = 0$$

在任何输入电平下都成立，无论晶体管处于哪个工作区；在这一扫描中 $R_1$ 不起作用。

### 第 3 步 — 输出共同电平如何移动（为完整起见）

两个输出的共同电平确实会变化（忽略体效应和沟道长度调制）：

- **$V_{in} < V_{THN} = 0.7$ V：** $M_1$ 和 $M_2$ 截止，因此二极管中没有电流，$V_{SG} \le |V_{THP}|$：两个输出都位于 $V_{DD} - |V_{THP}| = 2.2$ V 或更高。平方律在导通边缘恰好给出 2.2 V；二极管微弱的亚阈值导电会把输出拉得更高一些，趋向 $V_{DD}$。2.2 V 与 3 V 之间的任何电平都与该模型相符。
- **$V_{in}$ 刚超过 0.7 V：** 差分对导通，而尾电流管 $M_5$ 起初处于线性区（$P$ 接近地）。随着 $V_{in}$ 升高，电流增大，两个输出一起下降，遵循 $V_X = V_{DD} - |V_{THP}| - \sqrt{2I_{D1}/\beta_p}$。
- **$M_5$ 饱和之后：** 每边流过 $I_{SS}/2$，两个输出都稳定在
$$V_X = V_Y = V_{DD} - |V_{THP}| - \sqrt{\frac{I_{SS}}{\beta_p}},$$
并在 $V_{in}$ 更高时保持不变；即使 $M_1$、$M_2$ 进入线性区，尾电流管仍迫使每边流过 $I_{SS}/2$。

在所有三种情况下，两个输出的变化都**完全相同**：完全对称的电路不会把任何共模输入转换成差分输出，$R_1$ 只对差分信号起作用。在实际电路中，失配（mismatch）会留下很小的残余：一个失调（offset）加上对 $V_{in}$ 的微弱依赖。

### 结果

$$V_{out} = V_X - V_Y = 0\quad\text{for all } 0 \le V_{in1} = V_{in2} \le 3\ \mathrm{V}.$$

草图是一条位于零的水平线。由对称性，两个输出始终相等，$R_1$ 中没有电流。（它们的共同电平在差分对截止时介于 2.2 V 与 $V_{DD}$ 之间，差分对导通时下降，并在 $M_5$ 饱和后稳定在 $V_{DD} - |V_{THP}| - \sqrt{I_{SS}/\beta_p}$。）

**常见错误。** 把 $V_{out}$ 画成 S 形曲线或斜坡，好像共模扫描是差分输入一样。

**常见错误。** 描述某一个输出节点的电压（它确实随 $V_{in}$ 变化）并称之为“$V_{out}$”。输出是两个节点之间的**差值**，它始终为零。
