因为密勒因子必须在 $C_{GD1}$ 起作用的频率处计算，而在这些频率下，较大的 $C_L$ 已经把输出端短路了：从 $M_2$ 源极（节点 X）看到的阻抗为
$$Z_X \approx \frac{Z_L}{(g_{m2} + g_{mb2})r_{O2}} + \frac{1}{g_{m2} + g_{mb2}},\qquad Z_L = R_L\left\|\frac{1}{C_Ls}\right.$$
其中 $R_L$ 为 $I_1$ 的高输出电阻（output resistance）。
- 在直流时，$Z_L = R_L$ 很大，$Z_X$ 也可能很大，因此从 $M_1$ 栅极到 X 的低频增益 $-g_{m1}Z_X$ 很大。
- 但 $C_L$ 与很大的 $R_L$（以及共源共栅级的高输出电阻）形成一个频率非常低的输出极点。在约 $1/(r_{O2}C_L)$ 以上，$|Z_L| = 1/(\omega C_L)$ 降到 $r_{O2}$ 以下，第一项可以忽略，$Z_X \to 1/(g_{m2} + g_{mb2})$。
- 输入极点位于 ~$1/\{R_S[C_{GS1} + \ldots]\}$ 处，$C_{GD1}$ 的密勒电容（Miller capacitance）正是在这里起作用，它远高于上述频率。在那里，从 $M_1$ 栅极到 X 的增益只有 ≈ $-g_{m1}/(g_{m2} + g_{mb2})$，因此等效密勒电容 ≈ $[1 + g_{m1}/(g_{m2}+g_{mb2})]C_{GD1}$。
- 换言之，在这里把低频增益用于密勒定理（Miller's theorem）是不成立的：从 $M_1$ 栅极到 X 的增益早在输入极点之前就已随频率下降。很大的直流密勒因子只影响远低于输出主极点（dominant pole）的频率，因此几乎不改变总的传递函数。同理，共栅级（common-gate stage）的负载电容增大时，其输入阻抗趋于 $1/(g_m + g_{mb})$。
