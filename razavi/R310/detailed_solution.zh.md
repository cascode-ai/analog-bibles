# 详细步骤 - R310

**思路。** $C_{GD1}$ 的密勒因子为 $1 - A_X$，其中 $A_X = -g_{m1}Z_X$ 是从 $M_1$ 栅极到节点 X（$M_1$ 的漏极，$M_2$ 的源极）的增益，$Z_X$ 是从 $M_2$ 源极看进去的阻抗。针对 $M_2$ 漏极处的一般负载 $Z_L$ 推导 $Z_X$，并证明它只在极低频时才很大：远在 $C_{GD1}$ 起作用的频率之前，$C_L$ 就已使它骤降到 $1/(g_{m2} + g_{mb2})$，而密勒定理必须使用这些频率下的增益。

### 第 1 步 — 常规论证与表面上的矛盾

把 $M_1$ 的漏极（$M_2$ 的源极）称为节点 **X**。由密勒定理，$C_{GD1}$ 在 $M_1$ 栅极处表现为

$$C_{M} = (1 - A_X)\,C_{GD1}, \qquad A_X = \frac{V_X}{V_{G1}}\approx -g_{m1}Z_X$$

（$Z_X$ 与 $r_{O1}$ 并联）。常用的估计 $Z_X\approx 1/(g_{m2} + g_{mb2})$ 给出 $C_M\approx\left[1 + g_{m1}/(g_{m2} + g_{mb2})\right]C_{GD1}$，约为 $2C_{GD1}$。但当 $M_2$ 的漏极接高阻抗电流源 $I_1$ 时，$Z_X$ 可能大得多（见第 3 步），这似乎预示着密勒因子要大得多。

### 第 2 步 — 从 $M_2$ 源极看进去的阻抗

<!-- diagram: diagram-01.cir -->

$M_2$ 的栅极处于交流地（$V_{b2}$），衬底（bulk）接地；在其源极加测试电压 $V_X$，输入电流为 $I_X$。$M_2$ 等效为从漏极流向源极的电流 $-(g_{m2} + g_{mb2})V_X$ 与 $r_{O2}$ 并联，其漏极（即输出端）的负载为

$$Z_L = R_L\parallel\frac{1}{C_Ls},$$

其中 $R_L$ 是 $I_1$ 的（很高的）输出电阻。测试电流只能向上流过 $M_2$、再向下流过 $Z_L$，因此 $V_{out} = I_XZ_L$，而流过 $M_2$ 的从漏极到源极的电流为 $-I_X$：

$$-I_X = -(g_{m2} + g_{mb2})V_X + \frac{V_{out} - V_X}{r_{O2}} = -(g_{m2} + g_{mb2})V_X + \frac{I_XZ_L - V_X}{r_{O2}}.$$

合并各项，并在最后一个表达式中利用 $(g_{m2} + g_{mb2})r_{O2}\gg1$：

$$
\begin{aligned}
I_X\left(1 + \frac{Z_L}{r_{O2}}\right) &= V_X\left(g_{m2} + g_{mb2} + \frac{1}{r_{O2}}\right)\\
Z_X = \frac{V_X}{I_X} &= \frac{r_{O2} + Z_L}{1 + (g_{m2} + g_{mb2})r_{O2}}\approx\frac{Z_L}{(g_{m2} + g_{mb2})r_{O2}} + \frac{1}{g_{m2} + g_{mb2}}.
\end{aligned}
$$

负载阻抗被 $M_2$ 的本征增益（intrinsic gain）除，再加上 $1/(g_{m2} + g_{mb2})$。

### 第 3 步 — 低频时密勒因子确实很大

在直流时，$Z_L = R_L$；当 $R_L > r_{O2}$ 时（高阻抗电流源正是如此），$Z_X$ 的第一项占主导。对于理想电流源（$R_L\to\infty$），$Z_X\to\infty$，$Z_X\parallel r_{O1}\to r_{O1}$，因此 $|A_X|$ 趋于 $g_{m1}r_{O1}$。题目的前提**在低频时**是正确的。

### 第 4 步 — 在中等频率下 $C_L$ 使 $Z_X$ 骤降

输出电阻 $R_{out} = R_L\parallel\left[r_{O1} + r_{O2} + (g_{m2} + g_{mb2})r_{O1}r_{O2}\right]$ 非常大，因此当 $C_L$ 较大时，输出极点 $\omega_{out}\approx1/(R_{out}C_L)$ 的频率很低（它是该级的主极点）。当 $\omega\gg1/(R_LC_L)$ 时，$|Z_L|\approx1/(\omega C_L)$，而 $Z_X$ 的第一项在下述条件下小于第二项：

$$\frac{1}{\omega C_L} < r_{O2}\quad\Longleftrightarrow\quad \omega > \frac{1}{r_{O2}C_L}.$$

在该频率以上，

$$Z_X\approx\frac{1}{g_{m2} + g_{mb2}}\left(1 + \frac{Z_L}{r_{O2}}\right)\to\frac{1}{g_{m2} + g_{mb2}}, \qquad A_X\approx -\frac{g_{m1}}{g_{m2} + g_{mb2}} .$$

此时 $C_L$ 相当于输出端的交流短路，因此 $M_2$ 是一个漏极接地的共栅器件，输入阻抗为 $1/(g_{m2} + g_{mb2})$（正如共栅级在负载电容很大时，其输入阻抗降为 $1/(g_m + g_{mb})$ 一样）。

### 第 5 步 — 在 $C_{GD1}$ 起作用的频率处计算密勒因子

$C_{GD1}$ 通过**输入极点** $\omega_{in}\approx1/\{R_S[C_{GS1} + (1 - A_X)C_{GD1}]\}$ 起作用；该极点由很小的器件电容和信号源电阻决定，当 $C_L$ 较大时，它远高于输出极点和 $1/(r_{O2}C_L)$。只有使用**所关心频率处**的增益，密勒定理才成立，而在那里 $A_X\approx -g_{m1}/(g_{m2} + g_{mb2})$。因此

$$C_{M}\approx\left(1 + \frac{g_{m1}}{g_{m2} + g_{mb2}}\right)C_{GD1}.$$

**示例**（示例数值，题目中并未给出）：$g_{m1} = g_{m2} + g_{mb2} = 5$ mS，$r_{O1} = r_{O2} = 10\ \mathrm{k\Omega}$，$R_L = 1\ \mathrm{M\Omega}$，$C_L = 1$ pF。输出极点约在 0.47 MHz，$1/(2\pi r_{O2}C_L) = 16$ MHz。密勒因子 $1 - A_X = 1 + g_{m1}(Z_X\parallel r_{O1})$ 的幅值如下：

| 频率 | $\lvert 1 - A_X\rvert$ |
|---|---|
| 直流 | 34 |
| 1 MHz | 14.5 |
| 10 MHz | 2.5 |
| 100 MHz | 1.97 |
| 1 GHz | 1.96 |

在输入极点通常所处的 GHz 范围内，该因子基本上就是 $1 + g_{m1}/(g_{m2} + g_{mb2})\approx2$。

### 第 6 步 — 为什么低频时很大的因子无害

$C_{GD1}$ 在栅极处呈现的导纳（忽略 $r_{O1}$，它只会使导纳减小）为

$$Y_M = C_{GD1}s\,(1 + g_{m1}Z_X) \approx C_{GD1}s\left(1 + \frac{g_{m1}}{g_{m2} + g_{mb2}}\right) + \frac{g_{m1}C_{GD1}}{(g_{m2} + g_{mb2})r_{O2}}\,sZ_L(s).$$

由于 $sZ_L = sR_L/(1 + R_LC_Ls)$ 的幅值从不超过 $1/C_L$，额外项至多相当于一个电导

$$G_{extra}\le\frac{g_{m1}C_{GD1}}{(g_{m2} + g_{mb2})r_{O2}C_L},$$

当 $C_L$ 较大时它非常小（在上例中，若 $C_{GD1} = 20$ fF，它相当于 0.5 MΩ），与 $1/R_S$ 相比可以忽略。在输出极点以下，密勒电容确实很大，但频率太低，其导纳仍不超过这一上限。因此，很大的直流因子不会产生显著的低频输入极点：响应由输出极点主导，而输入极点由较小的因子决定。

### 结果

$M_2$ 源极处的阻抗为

$$Z_X\approx\frac{Z_L}{(g_{m2} + g_{mb2})r_{O2}} + \frac{1}{g_{m2} + g_{mb2}}, \qquad Z_L = R_L\parallel\frac{1}{C_Ls}.$$

它只在极低频时才很大，此时 $Z_L\approx R_L$。较大的 $C_L$ 产生一个频率很低的输出极点；在约 $1/(r_{O2}C_L)$ 以上，$|Z_L| = 1/(\omega C_L)$ 降到 $r_{O2}$ 以下，$Z_X\to1/(g_{m2} + g_{mb2})$。$C_{GD1}$ 的密勒电容起作用的输入极点位于远高于该频率之处，因此相关的、从 $M_1$ 栅极到 X 的增益只有 $-g_{m1}/(g_{m2} + g_{mb2})$，$C_{GD1}$ 只被乘以约 $1 + g_{m1}/(g_{m2} + g_{mb2})$。在这里把低频增益用于密勒定理是不成立的，而很大的直流因子只在几乎不影响响应的频率下起作用。

**常见错误。** 因为直流时 $Z_X$ 很大，就断定密勒因子确实很大。增益必须取电容起作用的频率处的值，而在那里 $C_L$ 已经把输出端短路，$Z_X\approx1/(g_{m2} + g_{mb2})$。

**常见错误。** 把 $C_{GD1}$ 乘以整级增益 $1 + g_{m1}R_{out}$。$C_{GD1}$ 接在 X 上，而不是接在输出端；相关的增益是从 $M_1$ 栅极到 X 的增益。

**常见错误。** 断言无论负载如何，$Z_X$ 总是 $1/g_{m2}$。实际上它等于 $(r_{O2} + Z_L)/[1 + (g_{m2} + g_{mb2})r_{O2}]$；正是较大的 $C_L$ 使它在相关频率下变小。
