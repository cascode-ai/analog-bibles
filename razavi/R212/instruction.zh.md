在 [图 1] 所示的电路中，所有晶体管的 $W/L = 50/0.5$（μm），PMOS 负载 $M_3$ 和 $M_4$（栅极接 $M_1$、$M_2$ 的公共源极节点）应工作在深线性区（deep triode region），导通电阻（on-resistance）为 2 kΩ。假设 $I_{D5} = 20\ \mu$A（$M_5$ 保持饱和），且 λ = γ = 0，计算得到该电阻所需的输入共模电平（common-mode level）。然后，当 $V_{in1}$ 和 $V_{in2}$ 在 0 到 $V_{DD}$ 之间差分变化时，画出 $V_{out1}$ 和 $V_{out2}$ 随之变化的曲线草图；即 $V_{in1}$ 从 0 上升到 $V_{DD}$，同时 $V_{in2} = V_{DD} - V_{in1}$ 从 $V_{DD}$ 下降到 0。$V_{DD} = 3$ V。

数据：NMOS $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$V_{TH} = 0.7$ V；PMOS $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$V_{TH} = -0.8$ V。
