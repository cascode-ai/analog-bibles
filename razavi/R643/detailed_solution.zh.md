# 详细步骤 - R643

**思路。** 电流导向对 $M_5$–$M_6$ 可以把 $I_T$ 的任意部分从输入对转移到交叉耦合（cross-coupled）对。对起振而言，最坏情况是全部 $I_T$ 都流入 $M_3$–$M_4$，输入对只剩下 $I_H$。求出计入交叉耦合对负电阻（negative resistance）后的级增益，在这一最坏情况下施加三级环形振荡器的条件（每级增益 ≥ 2），解出 $I_H$，并验证其他所有控制设置给出的增益都更大。

### 第 1 步 — 单级的小信号增益

$M_5$ 把 $I_{SS}$ 送到 P，$M_6$ 把 $I_1$ 送到交叉耦合对，且 $I_{SS} + I_1 = I_T = 1$ mA；$I_H$ 保证输入对中至少有 $I_H$ 的电流。在振荡边缘，每对管都平分其尾电流（tail current），而对差分信号而言，两个尾节点都是虚地（virtual ground）。在一个输出端的半边电路中：

- $M_1$（或 $M_2$）是从输出流向地的电流 $g_{m1,2}v_{in}$，$R$ 接到交流地；
- 该输出端上的交叉耦合管的栅极接在**另一个**输出端，电压为 $-v_{out}$，因此其从输出流向地的电流 $g_{m3,4}(-v_{out})$ 相当于一个**负电阻** $-1/g_{m3,4}$；
- $C$ 为输出节点电容。

<!-- diagram: diagram-01.cir -->

在输出端应用 KCL（低频，忽略 $C$）：

$$g_{m1,2}v_{in} + \frac{v_{out}}{R} - g_{m3,4}v_{out} = 0 ,$$

$$
\begin{aligned}
v_{out}\left(\frac{1}{R} - g_{m3,4}\right) &= -g_{m1,2}v_{in},\\
\frac{v_{out}}{v_{in}} &= -\frac{g_{m1,2}}{1/R - g_{m3,4}} = -\frac{g_{m1,2}R}{1 - g_{m3,4}R}.
\end{aligned}
$$

只要 $g_{m3,4}R < 1$，等效负载 $R \parallel (-1/g_{m3,4}) = R/(1 - g_{m3,4}R)$ 就会**提高**增益。计入 $C$ 时，单极点位于 $\omega_0 = (1 - g_{m3,4}R)/(RC)$；把电流转移到交叉耦合对会降低这一极点频率，振荡频率正是这样调谐的。

### 第 2 步 — 环形振荡器的条件

在由相同的单极点级构成的三级环形振荡器中，每个极点在 $\sqrt3\,\omega_0$ 处提供 60° 相移，此时每级的增益已经下降了 $\sqrt{1 + 3} = 2$ 倍。因此振荡要求

$$A_0 = \frac{g_{m1,2}R}{1 - g_{m3,4}R} \ge 2 .$$

### 第 3 步 — 最坏情况与最小 $I_H$

**最坏情况：** $M_6$ 取走全部 $I_T$（$I_1 = I_T$，$I_{SS} = 0$）。此时 $M_3$、$M_4$ 各流过 $I_T/2 = 0.5$ mA，按设计 $g_{m3,4}R = 0.5$，而输入对只流过 $I_H$，即每个器件 $I_H/2$。环形振荡器的条件变为

$$\frac{g_{m1,2}R}{1 - 0.5} \ge 2 \quad\Longrightarrow\quad g_{m1,2}R \ge 1 ,$$

其中

$$g_{m1,2} = \sqrt{2\mu_nC_{ox}\left(\frac{W}{L}\right)_{1,2}\frac{I_H}{2}} = \sqrt{\mu_nC_{ox}\left(\frac{W}{L}\right)_{1,2}I_H} ,$$

因此

$$\sqrt{\mu_nC_{ox}\left(\frac{W}{L}\right)_{1,2}I_H}\;R \ge 1 \quad\Longrightarrow\quad I_H \ge \frac{1}{\mu_nC_{ox}(W/L)_{1,2}R^2} .$$

取 $(W/L)_{1,2} = 50/0.5 = 100$：

$$
\begin{aligned}
\mu_nC_{ox}\left(\frac{W}{L}\right)_{1,2}R^2 &= (134\times10^{-6}\ \mathrm{A/V^2})(100)(546\ \Omega)^2 = (1.34\times10^{-2})(2.981\times10^5)\ \mathrm{V/A} = 3995\ \mathrm{V/A},\\
I_{H,min} &= \frac{1}{3995\ \mathrm{V/A}} = 2.50\times10^{-4}\ \mathrm{A} = 0.25\ \mathrm{mA}.
\end{aligned}
$$

**按比例验算。** 当输入对流过全部 1 mA 时，$R = 546\ \Omega$ 给出 $g_{m1,2}R = 2$；跨导（transconductance）减半只需四分之一的电流，即 $I_H = 1\ \mathrm{mA}/4 = 0.25$ mA。✓

### 第 4 步 — 其他所有控制设置都更有利

设 $I_T$ 中比例为 $x$ 的部分流入输入对（输入对的电流为 $xI_T + I_H$），其余 $1 - x$ 流入交叉耦合对。取 $I_H = I_T/4$，并利用 $g_m \propto \sqrt{I}$：

$$g_{m1,2}R = 2\sqrt{x + 0.25}, \qquad g_{m3,4}R = 0.5\sqrt{1 - x}, \qquad A_0 = \frac{2\sqrt{x + 0.25}}{1 - 0.5\sqrt{1 - x}} .$$

| $x$（$I_T$ 中流入 $M_1$–$M_2$ 的比例） | $g_{m1,2}R$ | $g_{m3,4}R$ | $A_0$ |
|---|---|---|---|
| 0（全部流入 $M_3$–$M_4$） | 1.00 | 0.50 | **2.00** |
| 0.25 | 1.41 | 0.43 | 2.49 |
| 0.5 | 1.73 | 0.35 | 2.68 |
| 0.75 | 2.00 | 0.25 | 2.67 |
| 1（全部流入 $M_1$–$M_2$） | 2.24 | 0 | 2.24 |

增益在 $x = 0$ 处最低，恰好等于 2，因此 $I_H = 0.25$ mA 能在整个控制范围内保证 $A_0 \ge 2$。由于处处都有 $g_{m3,4}R \le 0.5 < 1$，净负载始终为正，该级不会锁定。若没有 $I_H$，在 $x = 0$ 时输入对不流过电流，该级没有增益，环形振荡器会在调谐范围（tuning range）的这一端停振。

### 结果

最坏情况是全部 $I_T$ 流入 $M_3$–$M_4$（$g_{m3,4}R = 0.5$），而 $M_1$–$M_2$ 中只有 $I_H$。此时级增益 $g_{m1,2}R/(1 - g_{m3,4}R) \ge 2$ 要求 $g_{m1,2}R \ge 1$，其中 $g_{m1,2} = \sqrt{\mu_nC_{ox}(W/L)_{1,2}I_H}$：

$$I_{H,min} = \frac{1}{\mu_nC_{ox}(W/L)_{1,2}R^2} = \frac{1}{(134\ \mu\mathrm{A/V^2})(100)(546\ \Omega)^2} \approx 0.25\ \mathrm{mA}\ \left(= \frac{I_T}{4}\right).$$

**常见错误。** 把交叉耦合对当作正电阻，即取增益为 $g_{m1,2}R/(1 + g_{m3,4}R)$ 或 $g_{m1,2}R(1 - g_{m3,4}R)$，这会要求 $g_{m1,2}R \ge 3$ 或 $\ge 4$，得到 2.25 mA 或 4 mA 的 $I_H$。该对管在每一侧呈现 $-1/g_{m3,4}$，会**提高**增益。

**常见错误。** 要求每级增益为 1。在振荡频率处每个极点都使增益减半，因此低频增益至少应为 2。

**常见错误。** 按一个器件流过全部 $I_H$ 来计算 $g_{m1,2}$，得到 0.125 mA。在振荡边缘差分对（differential pair）是平衡的，每个器件流过 $I_H/2$。
