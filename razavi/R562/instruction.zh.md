考虑 [图 1] 所示的恒定 $g_m$ 偏置电路，它把传统恒定 $g_m$ 电路中的源极电阻换成了开关电容（switched-capacitor）网络：$S_1$ 和 $S_2$ 由频率为 $f_{CK}$ 的互补时钟（complementary clocks）驱动，得到平均电阻 $R_S = 1/(C_Sf_{CK})$（$C_B$ 只用于滤除开关引起的波动）。$M_3$ 和 $M_4$ 相同，$(W/L)_2 = K(W/L)_1$。假设 $K = 4$，$f_{CK} = 50$ MHz，功耗预算为 1 mW，$V_{DD} = 3$ V。确定 $M_1$–$M_4$ 的宽长比（aspect ratio）以及 $C_S$ 的值，使 $g_{m1} = 1/(500\ \Omega)$。器件数据：NMOS 的 $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$V_{TH0} = 0.7$ V，$\gamma = 0.45\ \mathrm{V^{1/2}}$，$2|\phi_F| = 0.9$ V，衬底（bulk）接地；PMOS 的 $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$V_{TH} = -0.8$ V；忽略沟道长度调制（channel-length modulation）。
