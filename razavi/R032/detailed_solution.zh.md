# 详细步骤 - R032

**思路。** $M_1$ 是一个源极接地的开关，其栅极从 0 阶跃到 3 V。阶跃之前它截止，$C_1$ 保持 1 V。阶跃之后，漏极（1 V）远低于 $V_{GS} - V_{TH}$，因此 $M_1$ 一开始就处于线性区，像一个（略带非线性的）电阻一样使 $C_1$ 放电。求解线性区放电方程，并与纯 $RC$ 指数曲线作比较。

### 第 1 步 — 阶跃之前（$t < 0$）

$V_{GS} = 0 < V_{TH}$，因此 **$M_1$ 截止**，$V_X$ 保持 1 V。

### 第 2 步 — 阶跃之后的工作区

在 $t = 0^+$ 时，电容电压仍为 $V_X = 1$ V，而 $V_{GS} = 3$ V；由于没有体效应（body effect），$V_{TH} = 0.7$ V：

$$V_{GS} - V_{TH} = 3 - 0.7 = 2.3\ \mathrm{V}, \qquad V_{DS} = V_X = 1\ \mathrm{V} < 2.3\ \mathrm{V}.$$

所以 **$M_1$ 立即处于线性区**，并在 $V_X$ 下降的过程中一直保持在线性区；不存在恒流的饱和区（saturation region）阶段。

### 第 3 步 — 放电方程

$$I_D = \beta\left[(V_{GS} - V_{TH})V_{DS} - \tfrac12V_{DS}^2\right] = \beta\left[2.3V_X - \tfrac12V_X^2\right],$$

该电流全部取自 $C_1$：

$$C_1\frac{dV_X}{dt} = -\beta\left[2.3V_X - \tfrac12V_X^2\right].$$

当 $V_X$ 较小时，二次项可以忽略，$M_1$ 相当于一个电阻

$$R_{on} = \frac{1}{\beta\,(V_{in} - V_{TH})} = \frac{1}{2.3\,\beta},$$

因此 $V_X$ 按指数规律衰减，时间常数为

$$\tau = R_{on}C_1 = \frac{C_1}{2.3\,\beta} .$$

### 第 4 步 — 精确解

令 $a = 2.3$ V，分离变量并利用部分分式：

$$\frac{dV_X}{V_X\,(a - V_X/2)} = -\frac{\beta}{C_1}\,dt, \qquad \frac{1}{V_X\,(a - V_X/2)} = \frac{1}{a}\left(\frac{1}{V_X} + \frac{1}{2a - V_X}\right).$$

积分得：

$$\ln\frac{V_X}{2a - V_X} = -\frac{\beta a}{C_1}\,t + K = -\frac{t}{\tau} + K .$$

在 $t = 0$ 时 $V_X = 1$ V，因此 $K = \ln\dfrac{1}{4.6 - 1} = \ln\dfrac{1}{3.6}$。于是

$$\frac{V_X}{4.6 - V_X} = \frac{e^{-t/\tau}}{3.6} \quad\Longrightarrow\quad V_X(t) = \frac{4.6\,E}{1 + E}, \qquad E = \frac{e^{-t/\tau}}{3.6} .$$

验证：

- $t = 0$：$E = 1/3.6 = 0.278$，因此 $V_X = 4.6\times0.278/1.278 = 1.00$ V。✓
- $t \gg \tau$：$E \ll 1$，因此 $V_X \approx 4.6E = 1.28\,e^{-t/\tau}$，这是趋向 **0 V** 的纯指数拖尾。

**初始斜率：**

$$\left.\frac{dV_X}{dt}\right|_{0^+} = -\frac{\beta}{C_1}\left[2.3\times1 - \tfrac12\times1^2\right] = -\frac{1.8\,\beta}{C_1}\ (\mathrm{V^2}),$$

而经过同一起点的纯指数曲线的初始斜率为 $-V_X/\tau = -2.3\beta/C_1$。$-\tfrac12V_{DS}^2$ 项使器件在 $V_{DS} = 1$ V 时的导电能力比 $R_{on}$ 略**弱**，因此起始阶段比指数曲线慢约 22 %，而当 $V_X \to 0$ 时曲线精确地变为指数曲线。

### 第 5 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF：$R_{on} = 1/(2.3\ \mathrm{mS}) = 435\ \Omega$，$\tau = 0.435$ ns，初始电流为 $1.8$ mA，初始斜率为 $-1.8$ V/ns。

| $t$ (ns) | $V_X$ (V)，精确解 | $I_D$ (mA) | 作比较的 $1\ \mathrm{V}\times e^{-t/\tau}$ |
|---|---|---|---|
| $0^-$ | 1.00 | 0 | — |
| $0^+$ | 1.00 | 1.80 | 1.00 |
| 0.25 | 0.62 | 1.24 | 0.56 |
| 0.5 | 0.37 | 0.79 | 0.32 |
| 1.0 | 0.125 | 0.28 | 0.10 |
| 2.0 | 0.013 | 0.03 | 0.010 |

精确曲线略高于纯指数曲线（起始较慢），之后以相同的速率衰减。

### 结果

- **$t < 0$：** $V_X = 1$ V（$M_1$ 截止）。
- **$t = 0$：** 栅极变为 3 V。由于 $V_X = 1\ \mathrm{V} < V_{GS} - V_{TH} = 2.3$ V，**$M_1$ 立即处于线性区**，并使 $C_1$ 放电。
- **$t > 0$：** $C_1\,dV_X/dt = -\beta[2.3V_X - V_X^2/2]$。$V_X$ **从 1 V 衰减到 0**，近似按指数规律衰减，时间常数 $\tau \approx C_1/(2.3\beta)$，即 $R_{on}C_1$，其中 $R_{on} = 1/[\beta(3 - 0.7)]$。精确解为 $V_X = 4.6E/(1 + E)$，其中 $E = e^{-t/\tau}/3.6$。
- 初始斜率为 $-1.8\beta/C_1$（V/s），起始阶段比纯指数曲线略慢；当 $V_X \to 0$ 时，衰减精确地变为指数型。

**常见错误。** 像饱和区那样，在开始时画出一段线性（恒流）斜坡。那需要 $V_{DS} > V_{GS} - V_{TH} = 2.3$ V，而漏极起始电压只有 1 V。

**常见错误。** 让 $V_X$ 稳定在一个非零值，或者随输入跳变。栅极保持 3 V，因此沟道会把 $C_1$ 完全放电；而 $V_X$ 作为电容电压，是连续变化的。

**常见错误。** 计算导通电导时使用 $\beta V_{in}$，而不是 $\beta(V_{in} - V_{TH})$。深线性区的电导由过驱动电压（overdrive voltage）决定，即 $\beta(3 - 0.7)\ \mathrm{V} = 2.3\beta$。
