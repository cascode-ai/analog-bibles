# 详细步骤 - R704

**思路。** 有两项要求决定了版图的形状。(1) 栅极电阻：单个 100 µm 宽的栅极电阻太大，因此每个晶体管都要分成 $N$ 个并联的栅指，$N$ 由 10 Ω 的限制决定。(2) 漏极结电容：把输入器件 $M_1$ 的漏区与共源共栅器件 $M_2$ 的源区合并成一个小的、无接触孔的扩散区，并让每个输出漏区（$M_2$ 的漏区）由两个栅指共享。先确定栅指尺寸，再进行排列。

### 第 1 步 — 单个栅指的栅极电阻

栅极信号从栅指一端的接触孔进入，并沿其宽度方向传播，因此宽度为 $W_f$ 的栅指有 $W_f/L$ 个方块，端到端电阻为 $R_f = R_\square W_f/L$。若整个器件只用一个栅指（$W_f = 100\ \mu$m）：

$$R_f = (5\ \Omega/\square)\times\frac{100\ \mu\mathrm{m}}{0.5\ \mu\mathrm{m}} = 5\times200 = 1000\ \Omega,$$

比要求大一百倍。

**有效（分布式）值。** 栅极电流沿栅指均匀地流入栅电容，因此多晶硅中的电流从接触孔处开始线性下降，$i(y) = I(1 - y/W_f)$，且

$$P = \int_0^{W_f} I^2\left(1 - \frac{y}{W_f}\right)^2\frac{R_f}{W_f}\,dy = I^2R_f\int_0^1(1 - u)^2du = \frac{I^2R_f}{3}.$$

因此一端接触的栅指相当于 $R_f/3$，这一数值决定了栅极的热噪声（thermal noise）和 RC 时间常数；更保守的集总模型则使用完整的 $R_f$。

### 第 2 步 — 栅指数目

$N$ 个宽度为 $W/N$ 的相同栅指并联，每个都在一端接触：

$$R_f = R_\square\frac{W/N}{L} = \frac{1000\ \Omega}{N}, \qquad \text{effective } \frac{R_f}{3} = \frac{333\ \Omega}{N}, \qquad R_G = \frac{1}{N}\cdot\frac{333\ \Omega}{N} = \frac{333\ \Omega}{N^2}.$$

分割带来双重好处：每个栅指的长度缩短为原来的 $N$ 分之一，并且有 $N$ 个栅指并联。

$$\frac{333\ \Omega}{N^2} \le 10\ \Omega \;\Longrightarrow\; N^2 \ge 33.3 \;\Longrightarrow\; N \ge 5.77 .$$

取 $N = 6$（偶数，第 4 步需要这一点）：

$$W_f = \frac{100\ \mu\mathrm{m}}{6} = 16.7\ \mu\mathrm{m}, \qquad R_G = \frac{333\ \Omega}{36} = 9.26\ \Omega \le 10\ \Omega .\ \checkmark$$

共源共栅器件 $M_2$ 的 $W/L$ 相同，因此两个器件都采用 6 个 16.7 µm 的栅指。

**其他自洽的选择。**

| 栅极模型 | 条件 | $N$ | $R_G$ |
|---|---|---|---|
| 分布式，一端接触（本题所选） | $333/N^2 \le 10$ | 6 | 9.3 Ω |
| 集总端到端（保守） | $1000/N^2 \le 10$ | 10 | 10 Ω |
| 分布式，两端接触（每个栅指为 $R_f/12$） | $83.3/N^2 \le 10$ | 4（偶数） | 5.2 Ω |

### 第 3 步 — 哪些结电容是重要的

$M_1$ 的源极接地，因此其电容无害。共源共栅节点 x（$M_1$ 的漏极 / $M_2$ 的源极）决定共源共栅结构的次极点（non-dominant pole），而输出 D（$M_2$ 的漏极）的电容直接加到负载上；两者都应尽量减小：

1. **合并 x。** 把同一支路的 $G_1$ 和 $G_2$ 栅指并排放置，使它们之间的扩散区既是 $M_1$ 的漏区，又是 $M_2$ 的源区。没有其他东西与它相连，因此它**不需要接触孔**，可以按**多晶硅到多晶硅的最小间距** $E_{min}$ 绘制，比带接触孔的扩散区 $E_c$ 窄得多。
2. **共享 D。** 把各支路镜像排列，使每个输出漏区两侧都是 $G_2$ 栅指：每个漏扩散区为两个栅指服务，总漏区面积减半，并且其长边面对的是栅极而不是场氧化层（field oxide）。

### 第 4 步 — 栅指的排列

一个支路（每个器件各一个栅指）沿有源区条带依次为

$$S \;\mid\; G_1 \;\mid\; x \;\mid\; G_2 \;\mid\; D .$$

先关于 D 镜像，再关于 S 镜像，就得到重复的图形

$$S\ G_1\ x\ G_2\ D\ G_2\ x\ G_1\ S\ G_1\ x\ G_2\ D\ G_2\ x\ G_1\ S\ \cdots$$

每个 D 都由两个 $G_2$ 栅指共享，每个内部的 S 都由两个 $G_1$ 栅指共享。为使所有 D 区都被共享，每个器件的栅指数必须是**偶数**；这样条带的两端都是 S 区（地），两端较大的场区边缘侧壁就位于无害的地节点上。

取 $N = 6$ 时，条带上共有 12 个栅指、3 个输出漏区、6 个合并的 x 区和 4 个源区。俯视图（多晶硅栅指 `#` 竖直，有源区条带水平，`o` = 接触孔）：

```
fingers:      G1  G2    G2  G1    G1  G2    G2  G1    G1  G2    G2  G1
                  +=====+=============+=====+=============+=====+   <- G2 bus: cascode bias
                  #     #             #     #             #     #
        +-----#---#-----#---#-----#---#-----#---#-----#---#-----#---#-----+
        |  S  # x #  D  # x #  S  # x #  D  # x #  S  # x #  D  # x #  S  |
        |  o  #   #  o  #   #  o  #   #  o  #   #  o  #   #  o  #   #  o  |
        +-----#---#-----#---#-----#---#-----#---#-----#---#-----#---#-----+
              #             #     #             #     #             #
              +=============+=====+=============+=====+=============+   <- G1 bus: input Vin
```

**布线。**

- **S 区**（4 个）：开接触孔，用一条金属线连到地。
- **D 区**（3 个）：开接触孔，用一条金属线连到输出端（这是唯一的输出扩散区）。
- **x 区**（6 个）：无接触孔，宽度最小。
- **$G_1$ 栅指**（6 个）：向有源区下方延伸，连接到接输入端的金属总线。
- **$G_2$ 栅指**（6 个）：向有源区上方延伸，连接到接共源共栅偏置的金属总线；两条总线位于相对的两侧，因此没有交叉。
- 栅指宽度（有源区条带的竖直尺寸）：$W_f = 16.7\ \mu$m；沟道长度 0.5 µm。如果 12 个栅指的条带长宽比不合适，可以把它折叠成两行相同的结构。

**为什么 x 区不相连也没问题。** 六个分开的 x 区构成六个相同的共源共栅支路，它们并联，栅极电压和输出都相同，因此各 x 节点处于相同电位，即使在它们之间接一根导线也不会有电流流过：该结构就是每个器件 $W/L = 100/0.5$ 的一个共源共栅结构。（在 x 区上开接触孔并用金属连接也可以工作，但接触孔迫使扩散区变宽，并在共源共栅节点上增加金属电容。）合并只改变寄生电容，而不改变偏置电流。

### 第 5 步 — 节省了多少电容

令 $E_c$ 为带接触孔的扩散区长度，$E_{min} < E_c$ 为多晶硅到多晶硅的最小间距：

**输出节点。**

- 单个 100 µm 栅指：漏区面积 $WE_c = 100E_c$；场区边缘周长 $W + 2E_c \approx 100\ \mu$m。
- 折叠、共享的版图：3 个面积为 $W_fE_c$ 的区，总面积 $3\times16.7E_c = 50E_c$（减半）；场区边缘周长只有 $3\times2E_c = 6E_c$，因为长边都面对栅极。

**共源共栅节点 x。**

- 用金属连接的分开器件：$M_1$ 的漏区加上 $M_2$ 的源区，每个都是面积约为 $WE_c$ 的带接触孔扩散区，再加上互连线。
- 合并的版图：面积 $6\times W_fE_{min} = WE_{min}$，没有接触孔，没有金属，沿宽度方向也没有场区边缘侧壁。

### 结果

把每个器件（$M_1$ 和 $M_2$）分成 $N$ 个并联的栅指。采用分布式栅极模型（每个栅指为 $R_f/3$，一端接触）时，$R_G = 333\ \Omega/N^2 \le 10\ \Omega$ 要求 $N = 6$ 个约 16.7 µm 的栅指（$R_G \approx 9.3\ \Omega$）；集总的端到端模型要求 $N = 10$，而两端接触时 $N = 4$ 即可。把栅指排列为

$$S\ G_1\ x\ G_2\ D\ G_2\ x\ G_1\ S\ G_1\ x\ G_2\ D\ G_2\ x\ G_1\ S\ \cdots$$

使得 (i) $M_1$ 的每个漏区与 $M_2$ 的源区是一个合并的、无接触孔的、宽度最小的扩散区（x），(ii) 每个输出漏区 D 由两个 $M_2$ 栅指共享（$N$ 为偶数，条带两端为接地的源区），(iii) $G_1$ 和 $G_2$ 栅指分别在条带相对的两侧连接到各自的总线。

**常见错误。** 把栅极电阻算成 $R_\square L/W$，或者认为栅指越多电阻越大。栅极信号沿每个栅指的**宽度**方向传播，因此 $R_f = R_\square W_f/L$，而 $N$ 个栅指并联会使 $R_G$ 减小 $N^2$ 倍。

**常见错误。** 把 $M_1$ 的漏区和 $M_2$ 的源区画成用金属连接的两个分开的扩散区，这会给共源共栅节点增加两个带接触孔的扩散区和一根连线；一个共享的扩散区电容要小得多。

**常见错误。** 要求**每个栅指**都低于 10 Ω（约需 100 个栅指），或者使用奇数个栅指，使某个输出漏区位于条带边缘。限制针对的是器件的总栅极电阻，而偶数个栅指能使每个输出漏区都被共享。
