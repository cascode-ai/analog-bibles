# 详细步骤 - R469

**思路。** 每个输出端都接收两个信号电流：一个来自慢速通路，即输入对管 → X 或 Y → 共源（common-source）管 $M_5$ 或 $M_6$；另一个直接来自漏极接在输出端的快速差分对 $M_1'$/$M_2'$。求出每个电流，由交叉连接确认它们同相相加，乘以输出电阻（output resistance），再分析哪些器件限制了输出范围。

### 第 1 步 — 慢速通路：送到 $V_{out1}$ 的电流

加上 $v_{g1} = v_{g1'} = +v_{in}/2$ 和 $v_{g2} = v_{g2'} = -v_{in}/2$；对差分信号而言，两个尾电流节点都是虚地（virtual ground）。对节点 X 列 KCL 方程（$M_5$ 的栅极不吸取电流）：

$$
\begin{aligned}
g_{m1}v_{sg1} &= \frac{v_X}{r_{O1}\parallel r_{O3}}, \qquad v_{sg1} = -\frac{v_{in}}{2}\\
v_X &= -g_{m1}(r_{O1}\parallel r_{O3})\frac{v_{in}}{2} .
\end{aligned}
$$

$M_5$（源极接地）从 $V_{out1}$ 抽取 $g_{m5}v_X$，因此它实际上是向该节点**注入**

$$i_{slow} = -g_{m5}v_X = g_{m1}(r_{O1}\parallel r_{O3})\,g_{m5}\,\frac{v_{in}}{2} .$$

两次反相使慢速通路从 $V_{in1}$ 到 $V_{out1}$ 为同相。

### 第 2 步 — 快速通路：送到 $V_{out1}$ 的电流

$V_{out1}$ 接在 $M_2'$ 的漏极上，其栅极变化 $-v_{in}/2$；源栅电压升高 $v_{in}/2$，因此它向 $V_{out1}$ 注入更多电流：

$$i_{fast} = g_{m1'}\,\frac{v_{in}}{2}.$$

它与 $i_{slow}$ **符号相同**，这正是交叉连接的目的：若由 $M_1'$ 给 $V_{out1}$ 供电流，快速通路的电流就会与慢速通路的电流相减。

### 第 3 步 — 输出电阻与增益

在一侧，$M_1$ 从 X 抽取 $g_{m1}v_{in}/2$，X 对地的电阻为 $r_{O1}\parallel r_{O3}$；在 $V_{out1}$ 处，$M_5$ 抽取 $g_{m5}v_X$，$M_2'$ 注入 $g_{m1'}v_{in}/2$，而 $r_{O5}$、$r_{O7}$（栅极固定）和 $r_{O1'}$（属于 $M_2'$，其源极位于虚地）都接到交流地。

对 $V_{out1}$ 列 KCL 方程：

$$
\begin{aligned}
i_{slow} + i_{fast} &= \frac{v_{out1}}{r_{O5}\parallel r_{O7}\parallel r_{O1'}}\\
v_{out1} &= \left[g_{m1}(r_{O1}\parallel r_{O3})\,g_{m5} + g_{m1'}\right](r_{O5}\parallel r_{O7}\parallel r_{O1'})\,\frac{v_{in}}{2} .
\end{aligned}
$$

由对称性，$v_{out2} = -v_{out1}$，因此

$$A_v = \frac{v_{out1} - v_{out2}}{v_{in}} = \left[g_{m1}(r_{O1}\parallel r_{O3})\,g_{m5} + g_{m1'}\right](r_{O5}\parallel r_{O7}\parallel r_{O1'}).$$

慢速通路的跨导等于 $g_{m5}$ 乘以第一级增益 $g_{m1}(r_{O1}\parallel r_{O3})$（通常为 20–50），因此在低频下快速通路只增加几个百分点：

$$A_v \approx g_{m1}g_{m5}(r_{O1}\parallel r_{O3})(r_{O5}\parallel r_{O7}\parallel r_{O1'}).$$

快速通路的价值体现在高频：此时慢速通路已经滚降（X 处的极点），而快速通路仍能向输出端提供 $g_{m1'}$。与普通的两级设计相比，额外的 $r_{O1'}$ 会使输出电阻略为**降低**。

### 第 4 步 — 输出摆幅：哪些器件起限制作用？

**下端。** $M_5$（源极接地）要求 $V_{out} \ge V_{ov5}$；PMOS 管 $M_2'$ 在漏极电压较低时没有问题。因此 $V_{out,min} = V_{ov5}$。

**上端，有两个候选限制。**

1. $M_7$（源极接 $V_{DD}$）：$V_{out} \le V_{DD} - |V_{ov7}|$。
2. $M_2'$（漏极接 $V_{out1}$，栅极位于输入共模电平 $V_{in,CM}$）：
$$V_{out} \le V_{in,CM} + |V_{TH1'}| .$$

快速差分对自己的尾电流源也需要电压余度：$V_{in,CM} \le V_{DD} - |V_{GS1'}| - |V_{ov,tail'}|$，因此利用 $|V_{GS1'}| = |V_{TH1'}| + |V_{ov1'}|$：

$$V_{in,CM} + |V_{TH1'}| \le V_{DD} - |V_{ov1'}| - |V_{ov,tail'}| .$$

除非 $|V_{ov7}|$ 大于 $|V_{ov1'}| + |V_{ov,tail'}|$（这并不常见），否则这一上限低于 $M_7$ 决定的上限；而当输入共模电平低于其最大值时，它还会更低。因此

$$V_{out,max} \approx \min\left(V_{DD} - |V_{ov7}|,\; V_{in,CM} + |V_{TH1'}|\right),$$

它通常由 **$M_1'$ 和 $M_2'$** 决定：把快速差分对的漏极接到输出端，使输出摆幅依赖于输入共模电平，这是前馈（feedforward）通路的代价。

### 结果

$$|A_v| = \left[g_{m1}(r_{O1}\parallel r_{O3})\,g_{m5} + g_{m1'}\right](r_{O5}\parallel r_{O7}\parallel r_{O1'}),$$

由于漏极交叉连接（$M_2'$ 接 $V_{out1}$，$M_1'$ 接 $V_{out2}$），慢速通路和快速通路的跨导同相相加。

输出摆幅通常受**快速通路晶体管 $M_1'$ 和 $M_2'$** 的限制。它们的漏极接在输出端，而栅极位于输入共模电平，因此输出电压一旦升到约 $V_{in,CM} + |V_{TH,P}|$ 以上，就会把它们推入线性区。这一限制通常低于 PMOS 负载管的上限 $V_{DD} - |V_{ov7}|$。下限为 $V_{ov5}$。

**常见错误。** 忽视交叉连接，把快速通路的电流减去，得到 $[g_{m1}(r_{O1}\parallel r_{O3})g_{m5} - g_{m1'}]$。让 $M_2'$（栅极接 $V_{in2}$）给 $V_{out1}$ 供电流，正是为了使慢速通路把 $V_{out1}$ 推高时，它的电流也随之增大。

**常见错误。** 让快速差分对的漏极接到 X/Y，这会使 $g_{m1'}$ 乘上第二级的增益。实际上它们直接接到输出端，并在那里并联了 $r_{O1'}$。

**常见错误。** 断定只有 $M_5$–$M_8$ 决定摆幅。快速差分对的器件挂在输出端上，而 $V_{out} \le V_{in,CM} + |V_{TH}|$ 通常是更严格的上限。
