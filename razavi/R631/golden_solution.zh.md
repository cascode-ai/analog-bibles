$R_{load} = 1/g_{m3}$（当 λ = γ = 0 且跟随器的电流源为理想电流源时严格成立；一般情况下为 $r_{O3} \parallel 1/(A_{SF}\,g_{m3})$，其中跟随器增益 $A_{SF} \approx 1$）。

推导：
- $M_3$ 的工作区：跟随器使 $M_3$ 的栅极比其漏极低 $V_{GS5}$，因此 $|V_{DS3}| = |V_{GS3}| - V_{GS5}$。要工作在饱和区（saturation region），需满足 $|V_{DS3}| \ge |V_{GS3}| - |V_{TH3}|$，即 $V_{GS5} \le |V_{TH3}|$；当 $V_{GS5} \approx |V_{TH3}|$ 时，$M_3$ 恰好处于边缘，因此适用其饱和区跨导 $g_{m3}$（且 λ = 0 时 $r_{O3} \to \infty$）。
- 在 X 处加一个小电压 $v_x$。$M_5$ 的电流恒定（理想电流源；$M_3$ 的栅极不吸取电流），因此 $g_{m5}(v_x - v_{s5}) = 0$ → $v_{g3} = v_{s5} = v_x$（γ = 0 时跟随器具有单位增益）。
- $M_3$ 的源极为交流地，因此其漏极电流变化 $g_{m3}v_{sg3} = -g_{m3}v_x$（从源极流向漏极）；从 X 流入负载的电流为 $i_x = g_{m3}v_x$。因此 $v_x/i_x = 1/g_{m3}$。
- 因此该负载的行为与二极管连接（diode-connected）的 PMOS 相同，但 $M_3$ 只占用 $|V_{DS3}| = |V_{GS3}| - V_{GS5}$ 的电压余度（headroom），约等于其过驱动电压（overdrive voltage），而不是 $|V_{GS3}|$。若 γ 和 λ 不为零：$A_{SF} = g_{m5}/(g_{m5} + g_{mb5}) < 1$，且 $r_{O3}$ 并联出现，因此 $R \approx (1 + g_{mb5}/g_{m5})/g_{m3} \parallel r_{O3}$，仍接近 $1/g_{m3}$。
- 两侧独立工作（$M_5$ 只检测 X），因此差模和共模负载电阻都是 $1/g_{m3}$。
