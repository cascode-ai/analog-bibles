# 详细步骤 - R631

**思路。** 首先检查 $M_3$ 的工作区：源极跟随器使其栅极比漏极低一个 $V_{GS5}$，这使 $M_3$ 恰好处于饱和区边缘，因此适用其饱和区跨导（transconductance）。然后在 X 处加一个小测试电压：跟随器以单位增益把它复制到 $M_3$ 的栅极，因此 $M_3$ 的响应与二极管连接的 PMOS 完全相同，电阻为 $1/g_{m3}$。

### 第 1 步 — $M_3$ 的工作区

跟随器 $M_5$（栅极接 X）驱动 $M_3$ 的栅极，因此 $V_{G3} = V_X - V_{GS5}$，而不是二极管连接时的 $V_{G3} = V_X$。$M_3$ 的源极接 $V_{DD}$：

$$
\begin{aligned}
|V_{GS3}| &= V_{DD} - V_{G3} = V_{DD} - V_X + V_{GS5},\\
|V_{DS3}| &= V_{DD} - V_X = |V_{GS3}| - V_{GS5}.
\end{aligned}
$$

饱和要求 $|V_{DS3}| \ge |V_{GS3}| - |V_{TH3}|$，即

$$|V_{GS3}| - V_{GS5} \ge |V_{GS3}| - |V_{TH3}| \quad\Longrightarrow\quad V_{GS5} \le |V_{TH3}| .$$

当 $V_{GS5} \approx |V_{TH3}|$ 时，这一条件恰好满足：$M_3$ **处于线性区边缘**，但仍然饱和，因此可以用 $g_{m3}$ 和（$\lambda = 0$ 时）无穷大的 $r_{O3}$ 来描述。

### 第 2 步 — 小信号模型

在 X 处加测试电压 $v_x$，求从测试源流入负载的电流 $i_x$。$\lambda = \gamma = 0$ 时：

- **$M_5$：** 漏极为交流地，栅极电压为 $v_x$，源极接节点 $s_5$（即 $M_3$ 的栅极）：受控源 $g_{m5}(v_x - v_{s5})$ 从 $V_{DD}$ 流入 $s_5$。理想偏置电流源相当于开路。
- **$M_3$：** 源极为交流地，栅极接 $s_5$，漏极接 X：受控源 $g_{m3}v_{sg3} = g_{m3}(0 - v_{s5})$ 从 $V_{DD}$ 流入 X。

### 第 3 步 — 跟随器把 $v_x$ 传递到 $M_3$ 的栅极

在节点 $s_5$ 处，其余元件只有理想电流源和 $M_3$ 的栅极，二者都不流过小信号电流，因此由 KCL 得

$$g_{m5}(v_x - v_{s5}) = 0 \quad\Longrightarrow\quad v_{s5} = v_x .$$

跟随器的电流被固定，所以其 $V_{GS}$ 不能变化：它具有**严格的单位增益**，$v_{g3} = v_{s5} = v_x$。

### 第 4 步 — 负载吸取的电流

$$v_{sg3} = v_{s3} - v_{g3} = 0 - v_x = -v_x, \qquad i_{d3} = g_{m3}v_{sg3} = -g_{m3}v_x ,$$

其中 $i_{d3}$ 从 $V_{DD}$ 流入 X。$M_5$ 的栅极不吸取电流，其漏极电流来自 $V_{DD}$，因此测试电流为

$$i_x = -i_{d3} = g_{m3}v_x ,$$

从 X 看进去的电阻为

$$R_X = \frac{v_x}{i_x} = \frac{1}{g_{m3}} .$$

X 升高时，$M_3$ 的栅极升高相同的量，使其电流减小 $g_{m3}v_x$，这与二极管连接的 PMOS 完全一样。

### 第 5 步 — 好处及非理想因素的影响

**电压余度。** 二极管连接的 PMOS 上的压降为 $|V_{GS3}| = |V_{TH3}| + |V_{ov3}|$；而这里 $M_3$ 只占用

$$|V_{DS3}| = |V_{GS3}| - V_{GS5} \approx |V_{GS3}| - |V_{TH3}| = |V_{ov3}|,$$

约一个过驱动电压，因此在负载电阻同为 $1/g_{m3}$ 的情况下，输出可以高出大约 $|V_{TH3}|$。

**当 $\gamma \neq 0$ 或 $\lambda \neq 0$ 时。** 跟随器增益变为 $A_{SF} = g_{m5}/(g_{m5} + g_{mb5}) < 1$，且 $r_{O3}$ 并联出现：

$$R_X = r_{O3} \parallel \frac{1}{A_{SF}\,g_{m3}} \approx \left(1 + \frac{g_{mb5}}{g_{m5}}\right)\frac{1}{g_{m3}} \parallel r_{O3},$$

仍接近 $1/g_{m3}$。每个跟随器只检测自己的节点，因此该负载对差模和共模信号都呈现 $1/g_{m3}$。

### 结果

当 $V_{GS5} \approx |V_{TH3}|$ 时，$M_3$ 处于饱和区边缘（$|V_{DS3}| = |V_{GS3}| - V_{GS5}$）。由理想电流源偏置的源极跟随器具有单位增益（$v_{g3} = v_x$），因此 X 处的测试电压 $v_x$ 使 $M_3$ 的电流变化 $g_{m3}v_x$：

$$R_{load} = \frac{v_x}{i_x} = \frac{1}{g_{m3}} .$$

一般情况下负载为 $r_{O3} \parallel 1/(A_{SF}g_{m3})$，跟随器增益 $A_{SF} \approx 1$，因此仍约为 $1/g_{m3}$。该负载的行为与二极管连接的 PMOS 相同，但只占用约一个过驱动电压的电压余度。

**常见错误。** 把电阻写成 $1/g_{m5}$ 或 $1/(g_{m3} + g_{m5})$。$M_5$ 不从 X 吸取信号电流（栅极不吸取电流，漏极接 $V_{DD}$）；它只是把 X 处的电压复制到 $M_3$ 的栅极。

**常见错误。** 把 $M_3$ 当作线性区电阻，或当作电阻为 $r_{O3}$ 的电流源。跟随器使 $M_3$ 的栅极随其漏极移动，因此 $M_3$ 通过其跨导作出响应；而且由于 $V_{GS5} \le |V_{TH3}|$，它仍保持饱和。

**常见错误。** 认为跟随器是反相的。它是同相的，增益接近 1，因此 X 升高会**减小** $|V_{GS3}|$ 和 $M_3$ 的电流，这正是该负载呈电阻性的原因。
