# 详细步骤 - R320

**思路。** $C_{GS}$ 跨接在栅极与源极之间，$C_{GD}$ 跨接在栅极与漏极之间，因此对每个电容都应用密勒定理，所用增益为从栅极到该电容另一端的低频增益。源极负反馈使源极跟随栅极变化（与源极跟随器一样，减小了等效 $C_{GS}$），并降低了到漏极的增益（减小了 $C_{GD}$ 的密勒倍增）。

### 第 1 步 — 电路与密勒规则

<!-- diagram: diagram-01.cir -->

把源极记为 S，漏极记为 D（即输出端）；$V_{DD}$ 为交流地，$\lambda = 0$，$g_{mb} = 0$。从输入端接到电压为 $AV_{in}$ 的节点的电容 $C$ 吸取的电流为

$$I_C = Cs\,(V_{in} - AV_{in}) = (1 - A)\,Cs\,V_{in},$$

因此它相当于一个接地电容 $(1 - A)C$；若 $A$ 取低频增益，这就是密勒近似，在远低于电路极点的频率下成立。

### 第 2 步 — 到源极和漏极的低频增益

漏极电流 $I_D = g_m(V_{in} - V_S)$ 流过 $R_S$，因此 $V_S = I_DR_S$：

$$
\begin{aligned}
V_S &= g_mR_S(V_{in} - V_S)\\
V_S(1 + g_mR_S) &= g_mR_SV_{in}\\
A_S = \frac{V_S}{V_{in}} &= \frac{g_mR_S}{1 + g_mR_S},
\end{aligned}
$$

这就是源极跟随器的增益：为正且小于 1。于是

$$I_D = g_m(V_{in} - V_S) = g_mV_{in}\left(1 - \frac{g_mR_S}{1 + g_mR_S}\right) = \frac{g_mV_{in}}{1 + g_mR_S},$$

该电流从 $R_D$ 中吸取，因此 $V_D = -R_DI_D$，且

$$A_D = \frac{V_D}{V_{in}} = -\frac{g_mR_D}{1 + g_mR_S},$$

即等效跨导（transconductance）为 $g_m/(1 + g_mR_S)$ 的带源极负反馈共源级的增益。

### 第 3 步 — 两个密勒项

**$C_{GS}$（自举）。** 取 $A = A_S$：

$$
\begin{aligned}
1 - A_S &= 1 - \frac{g_mR_S}{1 + g_mR_S} = \frac{1}{1 + g_mR_S},\\
C_{GS,in} &= (1 - A_S)\,C_{GS} = \frac{C_{GS}}{1 + g_mR_S}.
\end{aligned}
$$

源极随栅极一起变化，因此 $C_{GS}$ 两端只出现 $V_{in}/(1 + g_mR_S)$，与源极跟随器相同。

**$C_{GD}$（密勒倍增）。** 取 $A = A_D$：

$$C_{GD,in} = (1 - A_D)\,C_{GD} = \left(1 + \frac{g_mR_D}{1 + g_mR_S}\right)C_{GD}.$$

漏极与栅极反向变化；源极负反馈降低了增益，从而减小了倍增因子。

### 第 4 步 — 总输入电容

两个等效电容都接在栅极与地之间，因此直接相加：

$$C_{in}\approx\frac{C_{GS}}{1 + g_mR_S} + C_{GD}\left(1 + \frac{g_mR_D}{1 + g_mR_S}\right).$$

**验证。** $R_S = 0$ 时得到 $C_{GS} + (1 + g_mR_D)C_{GD}$，即标准的共源级结果；$R_D = 0$ 时得到 $C_{GS}/(1 + g_mR_S) + C_{GD}$，即源极跟随器的结果。

**示例。** 取 $g_mR_S = 2$，$g_mR_D = 10$：

$$C_{in}\approx\frac{C_{GS}}{3} + C_{GD}\left(1 + \frac{10}{3}\right) = 0.33\,C_{GS} + 4.33\,C_{GD},$$

而无源极负反馈时为 $C_{GS} + 11\,C_{GD}$：两项都减小了，代价是增益从 10 降到 3.3。

**若计入体效应**（此处被忽略），源极增益变为 $g_mR_S/[1 + (g_m + g_{mb})R_S]$，$C_{GS}$ 项变为 $C_{GS}(1 + g_{mb}R_S)/[1 + (g_m + g_{mb})R_S]$：自举作用略有减弱。

### 第 5 步 — 该估算有多准确？

输入电流的精确表达式为

$$I_{in} = C_{GS}s\,(V_{in} - V_S) + C_{GD}s\,(V_{in} - V_D).$$

每一项都已含有因子 $s$，因此在 $s$ 的一阶近似下，可以用 $A_SV_{in}$ 和 $A_DV_{in}$ 代替 $V_S$ 和 $V_D$；电容电流对它们的修正本身正比于 $s$，只会增加 $s^2$ 项：

$$\frac{I_{in}}{V_{in}} = \left[(1 - A_S)C_{GS} + (1 - A_D)C_{GD}\right]s + O(s^2).$$

因此 $C_{in}$ 就是**精确的低频输入电容**（求解完整电路得到的 $s$ 系数与此相同）。在源极和漏极节点的极点附近，$V_S$ 和 $V_D$ 滞后于输入，等效增益发生变化，输入导纳出现实部，因此在那里该公式只是一个估算。

### 结果

$$C_{in}\approx\frac{C_{GS}}{1 + g_mR_S} + C_{GD}\left(1 + \frac{g_mR_D}{1 + g_mR_S}\right).$$

- 源极以增益 $g_mR_S/(1 + g_mR_S)$ 跟随栅极，因此 $C_{GS}$ 被自举，表现为除以 $1 + g_mR_S$。
- 从栅极到漏极的增益为 $-g_mR_D/(1 + g_mR_S)$，因此 $C_{GD}$ 经密勒效应倍增 $1 + g_mR_D/(1 + g_mR_S)$ 倍。
- 两者都使用低频增益（密勒近似）。

**常见错误。** 把 $C_{GS}$ 乘以 $1 + g_mR_S$，好像源极与栅极反向变化。源极是**随**栅极同向变化的，因此 $C_{GS}$ 应**除以** $1 + g_mR_S$。

**常见错误。** 在 $C_{GD}$ 项中使用无负反馈时的增益 $g_mR_D$。有了 $R_S$，从栅极到漏极的增益为 $g_mR_D/(1 + g_mR_S)$，因此密勒倍增要小得多。

**常见错误。** 认为 $C_{GS}$ 不变（“源极负反馈只影响增益”），或把 $C_{GD}$ 除以增益。每个电容都按 $1 - A$ 缩放，所用增益是到**该电容自身**另一端的增益：对 $C_{GS}$ 为正且小于 1，对 $C_{GD}$ 为负。
