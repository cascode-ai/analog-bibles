# 详细步骤 - R214

**思路。** 每个输出都必须处在其所在一侧两个晶体管都保持饱和的窗口内：输出过高时 PMOS 负载 $M_3$ 退出饱和区（saturation region），输出过低时输入器件 $M_1$ 退出饱和区。由偏置电流计算两个极限（平方律，忽略 $\lambda$）；计算下限需要 $M_1$ 的源极电压以及因体效应而升高的阈值电压（threshold voltage）。允许的摆幅就是两个极限之间的距离。

### 第 1 步 — 偏置电流与器件参数

每条支路流过

$$I_D = \frac{I_{SS}}{2} = 0.5\ \mathrm{mA},$$

由 $W/L = 50/0.5 = 100$ 得

$$k_n = \mu_nC_{ox}\frac WL = 13.4\ \mathrm{mA/V^2}, \qquad k_p = \mu_pC_{ox}\frac WL = 3.84\ \mathrm{mA/V^2}.$$

### 第 2 步 — 上限：$M_3$ 必须保持饱和

$V_{SD3} \ge V_{SG3} - |V_{THP}|$ 要求

$$V_{out1} \le V_{DD} - |V_{GS3} - V_{TH3}| ,$$

其中过驱动电压由固定的偏置电流决定：

$$|V_{GS3} - V_{TH3}| = \sqrt{\frac{2|I_{D3}|}{k_p}} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{3.84\ \mathrm{mA/V^2}}} = \sqrt{0.260}\ \mathrm{V} = 0.510\ \mathrm{V}.$$

因此

$$V_{out,max} = 3 - 0.510 = 2.49\ \mathrm{V}.$$

### 第 3 步 — 下限：$M_1$ 必须保持饱和

把 $M_1$、$M_2$ 的公共源极节点记为 P。由 $V_{DS1} = V_{out1} - V_P$ 和 $V_{GS1} = V_{in,CM} - V_P$，条件 $V_{DS1} \ge V_{GS1} - V_{TH1}$ 变为

$$V_{out1} - V_P \ge V_{in,CM} - V_P - V_{TH1}\quad\Longrightarrow\quad V_{out1} \ge V_{in,CM} - V_{TH1}:$$

即输出可以比栅极**低**一个阈值电压。$M_1$ 的源极位于 $V_P > 0$，而衬底接地，因此 $V_{TH1}$ 因体效应而升高，需要先求出 $V_P$。

**$M_1$ 的过驱动电压：**

$$V_{ov1} = \sqrt{\frac{2I_{D1}}{k_n}} = \sqrt{\frac{2(0.5\ \mathrm{mA})}{13.4\ \mathrm{mA/V^2}}} = \sqrt{0.0746}\ \mathrm{V} = 0.273\ \mathrm{V}.$$

**源极电压与阈值电压**（相互耦合）：

$$V_P = V_{in,CM} - V_{ov1} - V_{TH1} = 1.5 - 0.273 - V_{TH1}, \qquad V_{TH1} = 0.7 + 0.45\left(\sqrt{0.9 + V_P} - \sqrt{0.9}\right).$$

从 $V_P = 0.43$ V 开始迭代：

$$
\begin{aligned}
V_{TH1} &= 0.7 + 0.45(\sqrt{1.330} - 0.9487) = 0.7 + 0.45(1.1533 - 0.9487) = 0.792\ \mathrm{V}\ \Rightarrow\ V_P = 1.5 - 0.273 - 0.792 = 0.435\ \mathrm{V},\\
V_{TH1} &= 0.7 + 0.45(\sqrt{1.335} - 0.9487) = 0.7 + 0.45(1.1553 - 0.9487) = 0.793\ \mathrm{V}\ \Rightarrow\ V_P = 0.434\ \mathrm{V}.
\end{aligned}
$$

迭代已收敛：$V_P \approx 0.434$ V，$V_{TH1} \approx 0.793$ V，因此

$$V_{out,min} = V_{in,CM} - V_{TH1} = 1.5 - 0.793 = 0.707\ \mathrm{V}.$$

（若不计体效应，$V_{TH1} = 0.7$ V，下限将为 0.8 V。）

### 第 4 步 — 允许的摆幅

每个输出可以在 0.707 V 与 2.49 V 之间变化。要用满整个窗口，输出共模电平必须位于窗口中心，这一电平由 $V_b$ 或共模反馈（common-mode feedback）设定：

$$V_{out,CM} = \frac{2.49 + 0.707}{2} \approx 1.60\ \mathrm{V}.$$

**单端摆幅**（每个输出）：

$$2.49 - 0.707 = 1.78\ \mathrm{V}\ \text{peak-to-peak}.$$

**差分摆幅。** 两个输出反向变化，因此 $V_{out1} - V_{out2}$ 的范围为 $-1.78$ V 到 $+1.78$ V：

$$2\times1.78 = 3.57\ \mathrm{V}\ \text{peak-to-peak}.$$

若不计体效应：0.8 V 到 2.49 V，即单端 1.69 V、差分 3.38 V。

### 结果

每个输出可以在约 0.71 V 与约 2.49 V 之间摆动：

- **上限：** $V_{DD} - |V_{GS3} - V_{TH3}| = 3 - 0.510 = 2.49$ V（$M_3$ 处于饱和边缘）。
- **下限：** $V_{in,CM} - V_{TH1} = 1.5 - 0.793 = 0.707$ V（$M_1$ 处于饱和边缘；由于 $V_P \approx 0.434$ V，$V_{TH1}$ 因体效应而升高）。

即每个输出约为 1.78 V 峰峰值，或者**差分约为 3.57 V 峰峰值**，输出共模电平约为 1.6 V。若不计体效应：0.8–2.49 V，1.69 V 和 3.38 V。

**常见错误。** 把上限取为 $V_{DD}$ 或 $V_{DD} - |V_{THP}|$。电流源负载只有在其漏极比 $V_{DD}$ 至少低一个**过驱动电压**（0.51 V）时才保持饱和，而不是低一个阈值电压。

**常见错误。** 把下限取为 $V_P = V_{in,CM} - V_{GS1}$（约 0.43 V）。只要 $M_1$ 的漏极比栅极低不超过一个**阈值电压**，它就保持饱和，因此下限为 $V_{in,CM} - V_{TH1}$，其中由体效应得 $V_{TH1} \approx 0.79$ V。

**常见错误。** 用 $\mu_nC_{ox}$ 或全部 1 mA 计算 PMOS 的过驱动电压。$M_3$ 是流过 0.5 mA 的 PMOS：$\sqrt{2(0.5\ \mathrm{mA})/(3.84\ \mathrm{mA/V^2})} = 0.51$ V。
