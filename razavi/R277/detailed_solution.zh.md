# 详细步骤 - R277

**思路。** $C_1$ 把尾节点 P 与二极管连接节点 X 连在一起，且初始未充电，因此在 $t = 0^+$ 时节点 P 与 X 一样高。验证这会使输入差分对截止，从而全部尾电流（tail current）都必须流过 $C_1$；这使 $C_1$ 线性充电，直到 P 降得足够低，$M_1$ 和 $M_2$ 导通。随后差分对接管 $I_{SS}$，电容电流衰减，X 和 Y 移到各自正常的平衡值。整个分析都采用平方律模型，在 X、P 和 Y 列基尔霍夫电流定律（KCL）方程。

### 第 1 步 — KCL 与 $t = 0^+$ 时的状态

令 $I_C$ 为从 X 经 $C_1$ 流入 P 的电流，则 $I_C = C_1\,d(V_X - V_P)/dt$。KCL 方程：

$$\text{X: } |I_{D3}| = I_{D1} + I_C, \qquad \text{P: } I_{D1} + I_{D2} + I_C = I_{SS}, \qquad \text{Y: } |I_{D4}| = I_{D2}.$$

由于节点 Y 上没有电容，最后一个方程在每一时刻都成立。

在 $t = 0^+$ 时，$v_{C1} = 0$，因此 $V_P = V_X$。若 $M_1$ 和 $M_2$ 截止，则由 P 的方程得 $I_C = I_{SS}$，由 X 的方程得 $|I_{D3}| = I_{SS}$：二极管连接的 $M_3$ 经 $C_1$ 提供**全部**尾电流。因此

$$V_X(0^+) = V_P(0^+) = V_{DD} - 0.8 - \sqrt{\frac{2I_{SS}}{\mu_pC_{ox}(W/L)_3}}\ \ (\lambda \to 0),$$

它**低于**正常的电流镜（current mirror）值，因为 $M_3$ 流过的是 $I_{SS}$ 而不是 $I_{SS}/2$。

差分对确实截止：只有当 $V_P < 1.5 - V_{TH}(V_P)$（约 0.66 V，见第 3 步）时，$M_1$ 和 $M_2$ 才导通，而对于通常的尺寸，$V_X(0^+) \approx 1.7$ V ✓。

**$V_Y$。** $M_4$ 的源栅电压很大，但由于 $M_2$ 截止，Y 没有到地的通路。$M_4$ 的电流必须为零，而导通的器件只有在 $V_{SD} = 0$ 时才能做到这一点：

$$V_Y(0^+) = V_{DD}.$$

### 第 2 步 — 第 1 阶段：$V_P$ 线性斜坡下降

差分对截止期间，$I_C = I_{SS}$ 恒定：

$$\frac{d(V_X - V_P)}{dt} = \frac{I_{SS}}{C_1}.$$

$V_X$ 由流过 $I_{SS}$ 的 $M_3$ 确定，因此 **$V_P$ 线性下降**，速率为 $I_{SS}/C_1$，而 **$V_X$ 和 $V_Y = V_{DD}$ 保持不变**。

### 第 3 步 — 差分对导通

当 $V_{GS} = 1.5 - V_P$ 达到阈值电压（threshold voltage）时，$M_1$ 和 $M_2$ 导通；由于它们的源极 P 高于接地的衬底，阈值电压中包含体效应：

$$V_P + 0.7 + 0.45\left(\sqrt{0.9 + V_P} - \sqrt{0.9}\right) = 1.5 .$$

试取 $V_P = 0.664$ V：$V_{TH} = 0.7 + 0.45(\sqrt{1.564} - 0.949) = 0.7 + 0.45(1.2506 - 0.9487) = 0.836$ V，且 $0.664 + 0.836 = 1.500$ ✓。因此差分对在 $V_P \approx 0.66$ V 时导通，所需时间为

$$t_1 = \frac{C_1\left[V_X(0^+) - 0.66\ \mathrm{V}\right]}{I_{SS}}.$$

（截止起始状态要求 $V_X(0^+) > 0.66$ V，即 PMOS 的最终过驱动电压 $\sqrt{I_{SS}/[\mu_pC_{ox}(W/L)_3]} \lesssim 1.09$ V，任何合理的 3 V 设计都满足这一条件；否则 $M_2$ 将从一开始就导通，不存在平台段。）

### 第 4 步 — 第 2 阶段：差分对接管电流，$I_C$ 衰减

导通后，$M_1$ 和 $M_2$（$V_{GS}$ 相同）接管尾电流，因此电容电流从 $I_{SS}$ 向零减小。$M_3$ 的电流从 $I_{SS}$ 降到 $I_{SS}/2$，因此 **$V_X$ 上升**到其最终的电流镜值，$V_P$ 稳定在 $1.5 - V_{GS1}(I_{SS}/2)$。

**时间常数。** 在最终状态附近线性化（$V_X$ 和 $V_P$ 的偏差分别记为 $x$ 和 $p$；$g_{m3}$、$g_{m1}$、$g_{mb1}$ 取 $I_{SS}/2$ 时的值；这里忽略 λ）：

- P：$-2(g_{m1} + g_{mb1})\,p + I_C = 0$，因此 $p = I_C/[2(g_{m1} + g_{mb1})]$；
- X：$-g_{m3}x = -(g_{m1} + g_{mb1})p + I_C = I_C/2$，因此 $x = -I_C/(2g_{m3})$。

电容电压的偏差为 $v = x - p = -I_C\cdot\tfrac12\left[\tfrac{1}{g_{m3}} + \tfrac{1}{g_{m1} + g_{mb1}}\right]$。由 $C_1\,dv/dt = I_C$ 得：

$$I_C \propto e^{-t/\tau}, \qquad \tau = \frac{C_1}{2}\left[\frac{1}{g_{m3}} + \frac{1}{g_{m1} + g_{mb1}}\right].$$

两项都出现，是因为 $V_X$ 上升的同时 $V_P$ 下降：电容看到的是两个节点电阻的串联。

### 第 5 步 — $V_Y$：先停在 $V_{DD}$ 附近，之后才下降

在 $I_C$ 存在期间，$M_3$ 流过 $I_{D1} + I_C$，若 $M_4$ 处于饱和区（saturation region），作为其复制它也将流过同样的电流，这多于 $M_2$ 吸收的电流（$I_{D2} \approx I_{D1}$）。由于始终有 $|I_{D4}| = I_{D2}$，Y 上升，直到 $M_4$ 进入线性区。

当 $M_4$ 饱和时，设 $V_Y = V_X + \Delta V$，则 $|I_{D4}| \approx |I_{D3}| - \Delta V/r_{O4}$，$I_{D2} \approx I_{D1} + \Delta V/r_{O2}$，因此节点 Y 的电流平衡给出

$$I_{D1} + I_C - \frac{\Delta V}{r_{O4}} = I_{D1} + \frac{\Delta V}{r_{O2}} \quad\Longrightarrow\quad V_Y - V_X \approx I_C\,(r_{O2}\|r_{O4}).$$

由于 $r_{O2}\|r_{O4}$ 很大，即使只有几微安的 $I_C$ 也能使 Y 远高于 X；当上式超过 $V_{DD} - V_X$ 时，该节点停在 $V_{DD}$ 附近（$M_4$ 处于线性区）。因此 **$V_Y$ 停在 $V_{DD}$ 附近**，随 $I_{D2}$ 的增大而略有下降，只有在 $I_C$ 几乎消失后才**相当陡峭地下降**到 $\approx V_X$。

### 第 6 步 — 最终状态

$$V_X = V_Y = V_{DD} - |V_{GS3}|\left(\tfrac{I_{SS}}{2}\right), \qquad V_P = 1.5 - V_{GS1}\left(\tfrac{I_{SS}}{2}\right), \qquad v_{C1} = V_X - V_P .$$

### 第 7 步 — 数值示例

$I_{SS} = 200\ \mu\mathrm{A}$，NMOS 的 $W/L = 10/0.5$（$\beta_n = 2.68\ \mathrm{mA/V^2}$），PMOS 的 $W/L = 20/0.5$（$\beta_p = 1.536\ \mathrm{mA/V^2}$），$\lambda_n = 0.1$，$\lambda_p = 0.2\ \mathrm{V^{-1}}$，$C_1 = 1$ pF。

$$
\begin{aligned}
V_X(0^+) &\approx 2.2 - \sqrt{2(200\ \mu\mathrm{A})/(1.536\ \mathrm{mA/V^2})} = 2.2 - 0.51 = 1.69\ \mathrm{V} \quad (1.74\ \mathrm{V with}\ \lambda_p),\\
\text{ramp} &= I_{SS}/C_1 = 200\ \mu\mathrm{A}/1\ \mathrm{pF} = 0.2\ \mathrm{V/ns}, \qquad t_1 = (1.74 - 0.66)/0.2 = 5.4\ \mathrm{ns},\\
g_{m3} &= \sqrt{2(1.536\ \mathrm{mA/V^2})(100\ \mu\mathrm{A})} = 0.554\ \mathrm{mS}, \qquad g_{m1} = \sqrt{2(2.68\ \mathrm{mA/V^2})(100\ \mu\mathrm{A})} = 0.732\ \mathrm{mS},\\
g_{mb1} &= 0.732\ \mathrm{mS}\times\frac{0.45}{2\sqrt{0.9 + 0.45}} = 0.142\ \mathrm{mS},\\
\tau &= \frac{1\ \mathrm{pF}}{2}\left[1.81\ \mathrm{k}\Omega + 1.14\ \mathrm{k}\Omega\right] = 1.5\ \mathrm{ns}.
\end{aligned}
$$

完整平方律方程（含 λ）的瞬态解：

| $t$ | $V_X$ (V) | $V_P$ (V) | $V_Y$ (V) | $I_C$ |
|---|---|---|---|---|
| 0 – 5.4 ns | 1.74 | 1.74 → 0.66（斜坡） | 3.00 | 200 μA |
| 6 ns | 1.77 | 0.57 | 2.97 | 164 μA |
| 8 ns | 1.85 | 0.48 | 2.79 | 40 μA |
| 9.5 ns | 1.87 | 0.46 | 2.38 | 13 μA |
| 11 ns | 1.87 | 0.45 | 2.03 | 4 μA |
| 14.5 ns | 1.87 | 0.45 | 1.88 | 0.2 μA |
| 终值 | 1.874 | 0.449 | 1.874 | 0 |

例如在 9.5 ns 时，$I_C(r_{O2}\|r_{O4}) \approx 13\ \mu\mathrm{A}\times40\ \mathrm{k}\Omega = 0.5$ V，与 $V_Y - V_X$ 吻合。

### 结果

- **$t = 0^+$：** $V_P = V_X \approx V_{DD} - 0.8 - \sqrt{2I_{SS}/[\mu_pC_{ox}(W/L)_3]}$（≈ 1.7 V），高于 $1.5\ \mathrm{V} - V_{TH}$，因此 $M_1$ 和 $M_2$ 截止。全部 $I_{SS}$ 从二极管连接的 $M_3$ 经 $C_1$ 流过，这决定了较低的初始 $V_X$。$M_4$ 没有电流通路，因此处于线性区且电流为零：$V_Y = V_{DD}$。
- **第 1 阶段：** $C_1$ 以 $I_{SS}/C_1$ 的速率充电。$V_X$ 保持不变，$V_P$ 线性下降，$V_Y = V_{DD}$。
- **第 2 阶段：** 当 $V_P$ 降到 $1.5 - V_{TH}(V_P) \approx 0.66$ V 时，差分对导通并接管 $I_{SS}$。电容电流以 $\tau \approx \tfrac{C_1}{2}[1/g_{m3} + 1/(g_{m1} + g_{mb1})]$ 衰减，$V_X$ 上升到 $V_{DD} - 0.8 - \sqrt{I_{SS}/[\mu_pC_{ox}(W/L)_3]}$。$V_Y$ 停在 $V_{DD}$ 附近（因为 $V_Y - V_X \approx I_C(r_{O2}\|r_{O4})$），在电容电流几乎消失后才连续而相当陡峭地下降到 $\approx V_X$。
- **最终状态：** $V_X = V_Y = V_{DD} - |V_{GS3}|(I_{SS}/2)$，$V_P = 1.5 - V_{GS1}(I_{SS}/2)$，$C_1$ 上保持 $V_X - V_P$。

**常见错误。** 认为 $M_1$ 和 $M_2$ 从 $t = 0$ 起就导通，从而 $V_X$ 处于正常值，$V_Y$ 立即开始下降。由于 $C_1$ 未充电，P 的起始电平与 X 相同（约 1.7 V），高于导通电平，因此差分对一开始是截止的。

**常见错误。** 把初始 $V_X$ 取为 $I_{SS}/2$ 对应的电流镜值。在第 1 阶段，$M_3$ 流过全部 $I_{SS}$（流入 $C_1$），因此 $V_X$ 的起始值较低，之后才上升。

**常见错误。** 把 $C_1$ 误读为接在 X 与 Y 之间，或接地。它接到尾节点 P，正因如此它才能夺走尾电流，使差分对截止。
