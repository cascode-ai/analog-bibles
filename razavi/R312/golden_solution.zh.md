$$Z_X = R_D\,\frac{g_{m2} + C_1s}{g_{m2}(1 + g_{m1}R_D) + C_1s} = R_D\left\|\left(\frac{1}{g_{m1}} + \frac{C_1}{g_{m1}g_{m2}}s\right)\right.$$
- $|Z_X|$ 起始于 $R_D\|(1/g_{m1}) = R_D/(1 + g_{m1}R_D)$，在零点 $\omega_z = g_{m2}/C_1$ 与极点 $\omega_p = g_{m2}(1 + g_{m1}R_D)/C_1$ 之间以 +20 dB/dec 的斜率上升，最后趋于平坦，等于 $R_D$：呈感性（inductive）。
- 等效网络：$R_D$ 与（$1/g_{m1}$ 串联 $L = C_1/(g_{m1}g_{m2})$）并联。

推导：测试电流流入 $M_1$ 的漏极（节点 D，也是 $M_2$ 的栅极）：$i_X = v_D/R_D + g_{m1}v_S$，其中 S（$M_2$ 的源极，$M_1$ 的栅极）满足 $g_{m2}(v_D - v_S) = C_1sv_S$（$I_1$ 理想），因此 $v_S = g_{m2}v_D/(g_{m2} + C_1s)$。
直观理解：在低频时，跟随器 $M_2$ 把 $v_D$ 复制到 $M_1$ 的栅极上，使 $M_1$ 表现得像一个二极管（$1/g_{m1}$）；在高频时，$C_1$ 使该栅极保持不动，只剩下 $R_D$。
