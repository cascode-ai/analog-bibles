# 详细步骤 - R312

**思路。** 在 X（$M_1$ 的漏极，也是 $M_2$ 的栅极）加测试电压，每个晶体管都只是一个受控电流源（$\lambda = \gamma = 0$），$I_1$ 开路。由 $M_2$ 源极的基尔霍夫电流定律（KCL）求出 $M_1$ 的栅极电压，再由 X 点的 KCL 求出测试电流。结果是 $R_D$ 与一条“电阻加电感”支路并联，因此 $|Z_X|$ 随频率升高。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_2$ 的源极（$M_1$ 的栅极）称为节点 **S**。环路为 X → 跟随器 $M_2$ → S → 共源（common-source）管 $M_1$ → X。$V_{DD}$ 为交流地，$I_1$ 开路：

- $R_D$ 接在 X 与地之间；
- **$M_1$：** 从 X 流向地的电流 $g_{m1}v_S$；
- **$M_2$：** 从其漏极（交流地）流入 S 的电流 $g_{m2}(v_X - v_S)$；
- **$C_1$** 接在 S 与地之间。

<!-- diagram: diagram-01.cir -->

加上 $v_X$，并设 $i_X$ 为从测试源流入 X 的电流。

### 第 2 步 — S 点的 KCL：跟随器的输出

$M_2$ 的电流只能经 $C_1$ 离开 S（$M_1$ 的栅极不吸取电流，$I_1$ 开路）：

$$
\begin{aligned}
g_{m2}(v_X - v_S) &= C_1s\,v_S\\
g_{m2}v_X &= v_S(g_{m2} + C_1s)\\
v_S &= \frac{g_{m2}}{g_{m2} + C_1s}\,v_X .
\end{aligned}
$$

低频时 $v_S\approx v_X$（跟随器把 X 复制到 S）；高频时 $v_S\to0$（$C_1$ 把 S 对地短路）。

### 第 3 步 — X 点的 KCL：测试电流

测试电流经 $R_D$ 和 $M_1$ 离开 X（$M_2$ 的栅极不吸取电流）：

$$i_X = \frac{v_X}{R_D} + g_{m1}v_S = v_X\left[\frac{1}{R_D} + \frac{g_{m1}g_{m2}}{g_{m2} + C_1s}\right].$$

### 第 4 步 — 阻抗及其等效网络

$$Z_X = \frac{v_X}{i_X} = \frac{1}{\dfrac{1}{R_D} + \dfrac{g_{m1}g_{m2}}{g_{m2} + C_1s}} .$$

将分子、分母同乘以 $R_D(g_{m2} + C_1s)$：

$$Z_X = \frac{R_D(g_{m2} + C_1s)}{g_{m2} + C_1s + g_{m1}g_{m2}R_D} = R_D\,\frac{g_{m2} + C_1s}{g_{m2}(1 + g_{m1}R_D) + C_1s}.$$

把第二项导纳取倒数，

$$\frac{g_{m2} + C_1s}{g_{m1}g_{m2}} = \frac{1}{g_{m1}} + \frac{C_1}{g_{m1}g_{m2}}\,s ,$$

即电阻 $1/g_{m1}$ 与一个电感串联。因此

$$Z_X = R_D\parallel\left(\frac{1}{g_{m1}} + sL\right), \qquad L = \frac{C_1}{g_{m1}g_{m2}} .$$

### 第 5 步 — 极限、转折频率与物理图像

**低频**（$s\to0$）：

$$Z_X\to R_D\,\frac{g_{m2}}{g_{m2}(1 + g_{m1}R_D)} = \frac{R_D}{1 + g_{m1}R_D} = R_D\parallel\frac{1}{g_{m1}} .$$

此时 $C_1$ 开路，跟随器使 $v_S = v_X$，因此 $M_1$ 相当于一个与 $R_D$ 并联的二极管连接（diode-connected）器件（$1/g_{m1}$）。

**高频**（$s\to\infty$）：

$$Z_X\to R_D\,\frac{C_1s}{C_1s} = R_D .$$

此时 $C_1$ 使 $M_1$ 的栅极处于交流地，因此 $M_1$ 是一个电流源（$\lambda = 0$ 时阻抗为无穷大），只剩下 $R_D$。

**零点与极点：**

$$\omega_z = \frac{g_{m2}}{C_1}, \qquad \omega_p = \frac{g_{m2}(1 + g_{m1}R_D)}{C_1}.$$

零点比极点低 $1 + g_{m1}R_D$ 倍，这恰好是高频值与低频值之比。由于 $|Z_X|$ 随频率增大，该阻抗呈**感性**。

### 第 6 步 — 画出 $|Z_X|$ 随频率变化的曲线草图

在双对数坐标中：

- 在 $\omega\ll\omega_z = g_{m2}/C_1$ 时**保持平坦**，值为 $R_D/(1 + g_{m1}R_D)$。
- 在 $\omega_z$ 与 $\omega_p$ 之间**以 +20 dB/十倍频程上升**（斜率为 +1），此时 $|Z_X|\approx\omega L$，其中 $L = C_1/(g_{m1}g_{m2})$。
- 在 $\omega\gg\omega_p = g_{m2}(1 + g_{m1}R_D)/C_1$ 时**保持平坦**，值为 $R_D$。

相位始终为正（感性），并在两个转折频率之间达到峰值。

**示例**（$g_{m1}R_D = 9$，因此两个平台值分别为 $R_D/10$ 和 $R_D$，且 $\omega_p = 10\,\omega_z$）：

| $\omega/\omega_z$ | $\lvert Z_X\rvert/R_D$ | 相位 |
|---|---|---|
| 0.1 | 0.100 | +5° |
| 1 | 0.141 | +39° |
| 3.16 | 0.316 | +55° |
| 10 | 0.711 | +39° |
| 100 | 0.995 | +5° |

### 结果

$$Z_X = R_D\,\frac{g_{m2} + C_1s}{g_{m2}(1 + g_{m1}R_D) + C_1s} = R_D\parallel\left(\frac{1}{g_{m1}} + \frac{C_1}{g_{m1}g_{m2}}\,s\right).$$

$|Z_X|$ 起始于 $R_D\parallel(1/g_{m1}) = R_D/(1 + g_{m1}R_D)$，在零点 $\omega_z = g_{m2}/C_1$ 与极点 $\omega_p = g_{m2}(1 + g_{m1}R_D)/C_1$ 之间以 +20 dB/十倍频程上升，最后趋于平坦，等于 $R_D$。该电路相当于 $R_D$ 与（$1/g_{m1}$ 串联 $L = C_1/(g_{m1}g_{m2})$）并联，即一个有源电感（active inductor）。

**常见错误。** 因为唯一的电抗元件是电容，就断定 $|Z_X|$ 随频率下降。$C_1$ 位于 $M_1$ 的栅极，而不是 X 点；高频时 S 被短路，这**消除**了类似二极管的低阻抗通路，因此 X 点的阻抗**升高**。

**常见错误。** 把低频值取为 $R_D$ 或 $1/g_{m2}$。在低频时，跟随器使 $M_1$ 相当于二极管，因此 X 看到的是 $1/g_{m1}$ 与 $R_D$ 并联；$1/g_{m2}$ 是 S 点的阻抗，而不是 X 点的。

**常见错误。** 电感算错，例如得到 $L = C_1/g_{m2}$ 或 $R_DC_1/g_{m2}$。跟随器在 S 点给出时间常数 $C_1/g_{m2}$，$M_1$ 再通过除以 $g_{m1}$ 把它转换为阻抗：$L = C_1/(g_{m1}g_{m2})$。
