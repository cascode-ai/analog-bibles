# 详细步骤 - R106

**思路。** 这是一个折叠式共源共栅支路：$I_1$ 向节点 $P$ 注入电流，$M_1$（栅极接 $V_{b2}$）从 $P$ 吸收电流，$M_2$（栅极接 $V_{b1}$）把 $P$ 连到测试源。由节点 $P$ 的 KCL 得 $I_X = I_{D1} - I_1$，因此 $I_X$ 受 $M_1$ 的电流控制，而后者取决于 $V_P$；$M_2$ 只决定 $V_P$ 如何跟随 $V_X$ 变化。让 $V_X$ 从较高的值（共源共栅管饱和）一直降到 0 V（此时 $M_2$ 反向导通），跟踪其变化。

### 第 1 步 — 节点 $P$ 的 KCL

把连接 $I_1$、$M_1$ 漏极和 $M_2$ 的节点记为 $P$。$I_1$ 和经 $M_2$ 到达的电流 $I_X$ 流入 $P$，$M_1$ 的漏极电流流出：

$$I_1 + I_X = I_{D1} \quad\Longrightarrow\quad I_X = I_{D1} - I_1 .$$

$V_{GS1} = V_{b2}$ 固定，因此

$$
I_{D1} =
\begin{cases}
\beta_1\left[(V_{b2} - 0.7)V_P - \tfrac12V_P^2\right], & V_P < V_{b2} - 0.7\ \text{(triode)},\\
I_B = \tfrac12\beta_1(V_{b2} - 0.7)^2, & V_P \ge V_{b2} - 0.7\ \text{(saturation)}.
\end{cases}
$$

由于 $I_B > I_1$，饱和的 $M_1$ 吸收全部 $I_1$，还要从 $M_2$ 吸收一些额外电流。

### 第 2 步 — $V_X$ 较大：共源共栅管饱和，平坦的平台

$V_X$ 较大时，$M_2$ 处于饱和区，作为共源共栅管工作（源极位于 $P$、跟随 $V_{b1}$ 的跟随器）。若 $M_1$ 也处于饱和区，它吸收 $I_B$，其中 $I_1$ 来自电流源，因此

$$I_X = I_B - I_1 \quad\text{(constant, the folded-cascode current)}.$$

$M_2$ 流过这一电流，因此

$$V_P = V_{b1} - V_{TH2}(V_P) - \sqrt{\frac{2(I_B - I_1)}{\beta_2}}, \qquad V_{TH2}(V_P) = 0.7 + 0.45\left(\sqrt{0.9 + V_P} - \sqrt{0.9}\right).$$

只要 $V_P \ge V_{b2} - 0.7$ V（$M_1$ 饱和），这一结果就是自洽的；而 $M_2$ 保持饱和的条件是

$$V_X \ge V_{b1} - V_{TH2}(V_P) .$$

**若 $V_{b1}$ 过低**，使 $V_P$ 达不到 $V_{b2} - 0.7$ V，即若 $\tfrac12\beta_2[V_{b1} - (V_{b2} - 0.7) - V_{TH2}(V_{b2} - 0.7)]^2 < I_B - I_1$，则 $M_2$ 进入饱和时 $M_1$ 仍处于线性区，平台低于 $I_B - I_1$，由 $\tfrac12\beta_2[V_{b1} - V_P - V_{TH2}(V_P)]^2 + I_1 = \beta_1[(V_{b2} - 0.7)V_P - V_P^2/2]$ 确定。

### 第 3 步 — $V_X$ 减小：$M_2$ 和 $M_1$ 先后离开饱和区

- 当 $V_X < V_{b1} - V_{TH2}(V_P)$ 时，**$M_2$ 进入线性区**，相当于接在 $X$ 与 $P$ 之间的一个小电阻，因此 **$V_P$ 随 $V_X$ 下降**。只要 $V_P > V_{b2} - 0.7$ V，$M_1$ 就保持饱和，$I_X$ 保持为 $I_B - I_1$：$I_X$ 上**没有明显的转折**。
- 当 $V_P < V_{b2} - 0.7$ V 时（由于 $M_2$ 上有很小的压降，对应的 $V_X$ 略高一些），**$M_1$ 进入线性区**。此后 $I_{D1}$ 随 $V_P$ 下降，$I_X = I_{D1}(V_P) - I_1$ 也随之下降。

### 第 4 步 — 过零点与负的 $I_X$

当处于线性区的 $M_1$ 恰好流过 $I_1$ 时，$I_X = 0$：

$$\beta_1\left[(V_{b2} - 0.7)V_{P0} - \tfrac12V_{P0}^2\right] = I_1 .$$

此时 $M_2$ 中没有电流，因此 $V_{DS2} = 0$，$V_X = V_{P0}$。

**低于 $V_{P0}$ 时（$I_X < 0$）**，$M_1$ 不再能吸收全部 $I_1$，多余的电流经 $M_2$ 流出，此时它**反向**导通：$X$ 低于 $P$，因此 $X$ 成为 $M_2$ 的源极，电流从 $P$ 流入电压源。在 $V_X = 0$ 处，$M_1$ 和 $M_2$ 都处于线性区，源极都在 0 V，共同分担 $I_1$：

$$I_1 = \beta_1\left[(V_{b2} - 0.7)V_P - \tfrac12V_P^2\right] + \beta_2\left[(V_{b1} - 0.7)V_P - \tfrac12V_P^2\right], \qquad I_X(0) = -(I_1 - I_{D1}(V_P)) .$$

**若反过来 $I_B < I_1$**（本题并非如此），多余的 $I_1 - I_B$ 只能经 $M_2$ 流出，因此 $V_X$ 较低时 $I_X = -(I_1 - I_B)$；当 $V_X$ 高于约 $V_{b1} - V_{TH}$ 时，将不再有电流通路，$P$ 会被推到电流源的顺从电压极限。

### 第 5 步 — 数值示例

为便于说明，取 $V_{b2} = 1.0$ V，$\beta_1 = 4\ \mathrm{mA/V^2}$，$I_1 = 0.1$ mA，$V_{b1} = 1.8$ V，$\beta_2 = 2\ \mathrm{mA/V^2}$：

$$
\begin{aligned}
I_B &= \tfrac12(4\ \mathrm{mA/V^2})(0.3\ \mathrm{V})^2 = 0.18\ \mathrm{mA} > I_1,\qquad I_B - I_1 = 0.08\ \mathrm{mA},\\
\sqrt{2(I_B - I_1)/\beta_2} &= \sqrt{0.08}\ \mathrm{V} = 0.283\ \mathrm{V},\quad V_P + V_{TH2}(V_P) = 1.8 - 0.283 = 1.517\ \mathrm{V}\Rightarrow V_P = 0.679\ \mathrm{V},\\
V_{TH2} &= 0.838\ \mathrm{V};\quad M_2\ \text{saturated for } V_X \ge 1.8 - 0.838 = 0.962\ \mathrm{V}.
\end{aligned}
$$

$V_P = 0.679$ V $> V_{b2} - 0.7 = 0.3$ V，因此 $M_1$ 在平台上处于饱和区。

**过零点：** $4(0.3V_{P0} - 0.5V_{P0}^2) = 0.1$（以 mA 为单位），即 $V_{P0}^2 - 0.6V_{P0} + 0.05 = 0$，因此 $V_{P0} = (0.6 - \sqrt{0.16})/2 = 0.1$ V。

**在 $V_X = 0$ 处：** $0.1 = 4(0.3V_P - 0.5V_P^2) + 2(1.1V_P - 0.5V_P^2)$，即 $3V_P^2 - 3.4V_P + 0.1 = 0$，因此 $V_P = 0.030$ V。于是 $I_{D1} = 4(0.3\times0.030 - 0.5\times0.030^2) = 0.034$ mA，$I_X = 0.034 - 0.1 = -0.066$ mA。

| $V_X$ (V) | $V_P$ (V) | $M_1$ | $M_2$ | $I_{D1}$ (mA) | $I_X$ (mA) |
|---|---|---|---|---|---|
| 0 | 0.030 | 线性区 | 线性区（反向） | 0.034 | −0.066 |
| 0.05 | 0.065 | 线性区 | 线性区（反向） | 0.069 | −0.031 |
| 0.1 | 0.100 | 线性区 | 无电流 | 0.100 | 0 |
| 0.2 | 0.173 | 线性区 | 线性区 | 0.148 | 0.048 |
| 0.3 | 0.251 | 线性区 | 线性区 | 0.175 | 0.075 |
| 0.357 | 0.300 | → 饱和 | 线性区 | 0.180 | 0.080 |
| 0.962 | 0.679 | 饱和 | → 饱和 | 0.180 | 0.080 |
| 3.0 | 0.679 | 饱和 | 饱和 | 0.180 | 0.080 |

### 结果

$$I_X = I_{D1} - I_1$$

（对连接 $I_1$、$M_1$ 漏极和 $M_2$ 源极的节点 $P$ 应用 KCL）。$I_X$ 在 $V_X = 0$ 时为负，上升并穿过零点，一旦 $M_1$ 进入饱和（$V_P = V_{b2} - 0.7$ V），就饱和于 $I_B - I_1$。此时 $M_2$ 可能仍处于线性区；它之后在 $V_X = V_{b1} - V_{TH2}(V_P)$ 处才进入饱和，而 $I_X$ 上不会出现明显的转折。

- **$V_X$ 较大时**（$V_X \ge V_{b1} - V_{TH2}(V_P)$）：$M_2$ 是处于饱和区的共源共栅管，$V_P = V_{b1} - V_{TH2}(V_P) - \sqrt{2(I_B - I_1)/\beta_2}$。若该值高于 $V_{b2} - 0.7$ V，则 $M_1$ 饱和，$I_X = I_B - I_1$ 为常数。若 $V_{b1}$ 过低，无法满足这一点，则 $M_2$ 先进入饱和而 $M_1$ 仍处于线性区，平台较低，由 $\tfrac12\beta_2[V_{b1} - V_P - V_{TH2}(V_P)]^2 + I_1 = \beta_1[(V_{b2} - 0.7)V_P - V_P^2/2]$ 确定。
- **$V_X$ 较低时：** $M_2$ 处于线性区，$V_P$ 随 $V_X$ 下降；一旦 $V_P < V_{b2} - 0.7$ V，$M_1$ 就处于线性区，其电流下降，因此 $I_X = I_{D1}(V_P) - I_1$ 减小。
- 在 $V_X = V_{P0}$ 处 **$I_X = 0$**，此时处于线性区的 $M_1$ 恰好流过 $I_1$：$\beta_1[(V_{b2} - 0.7)V_{P0} - V_{P0}^2/2] = I_1$（此时 $M_2$ 的 $V_{DS} = 0$）。
- **$V_X < V_{P0}$：** $I_X < 0$。$M_1$ 无法吸收的那部分 $I_1$ 经 $M_2$（此时以 $V_X$ 为其源极而导通）流入电压源。在 $V_X = 0$ 处，$I_X = -(I_1 - I_{D1}(V_P))$，其中 $V_P$ 由同处于线性区、共同分担 $I_1$ 的 $M_1$ 和 $M_2$ 决定。
- **转折点：** $V_X = V_{P0}$（过零点），$V_P = V_{b2} - 0.7$ V（$M_1$ 进入饱和），$V_X = V_{b1} - V_{TH2}(V_P)$（$M_2$ 进入饱和；若 $M_1$ 已经饱和，$I_X$ 上没有转折），平台 $I_B - I_1$。

**常见错误。** 写成 $I_X = I_{D1} + I_1$，或者把平台取为 $I_B$ 或 $I_1$。电流源是向 $P$ **注入**电流的，因此 $M_1$ 从电流源取得 $I_1$，只有剩余部分 $I_B - I_1$ 来自测试源。

**常见错误。** 在 $M_2$ 进入饱和处画出转折。只要 $M_1$ 处于饱和区，无论 $V_P$ 如何，其电流都是 $I_B$，因此 $I_X$ 已经是平坦的。

**常见错误。** 让曲线止于 $I_X = 0$，或者认为 $V_X$ 较低时 $M_2$ 不能导通。当 $V_X < V_P$ 时，$X$ 端成为 $M_2$ 的源极，$M_1$ 无法吸收的那部分 $I_1$ 经 $M_2$ 流出，从而得到负的 $I_X$。
