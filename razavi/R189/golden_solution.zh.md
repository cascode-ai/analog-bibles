每个负载都是一个 PMOS，其栅极电压取自 $R_1$ 的下端，因此 $M_3$ 流过 $I_{D1}$，左输出端为 $V_{A} = V_{DD} - |V_{THP}| - \sqrt{2I_{D1}/\beta_p} + I_{D1}R_1$（在 $M_3$ 饱和，即 $I_{D1}R_1 < |V_{THP}|$ 时）；右边同理。因此 $V_{out} = f(I_{D1}) - f(I_{D2})$，其中 $f(I) = IR_1 - \sqrt{2I/\beta_p}$。
- 典型情况 $R_1 < 1/g_{m3}$（平衡时 $g_{m3} = \sqrt{\beta_pI_{SS}}$）：一条反相 S 形曲线，与以二极管连接（diode-connected）器件为负载的差分对类似，但增益和摆幅更小。中心斜率为 $dV_{out}/d(V_{in1} - V_{in2}) = -g_{m1}(1/g_{m3} - R_1)$；两端平坦部分对应完全电流导引（current steering），其电平为 $V_{out} = \pm[\sqrt{2I_{SS}/\beta_p} - I_{SS}R_1]$，$V_{in1}$ 较低时为正。截止一侧的输出位于 $V_{DD} - |V_{THP}| = 2.2$ V。
- $R_1 = 1/g_{m3}$：平衡点处的小信号增益为零（曲线在中心处平坦，但由于 $f$ 是凸函数，两端电平仍不为零）。当 $1/g_{m3} < R_1 < \sqrt2/g_{m3}$ 时，中心斜率为正，而两端仍保持反相的符号（曲线非单调）；$R_1$ 更大时，两端电平改变符号，曲线在中心处变为同相，但仍然是非单调的：对任何 $R_1$，在导引区边缘附近斜率都趋于 $-\sqrt{\beta_n/\beta_p}$（电流趋于零的那一边 $1/g_m \to \infty$），因此曲线先越过两端电平，然后以正斜率穿过零点。
- 若 $I_{SS}R_1 > |V_{THP}|$，完全导引时流过大电流的 PMOS 会进入线性区（triode region）。在线性区中 $I = \tfrac12\beta_p[V_{ov}^2 - (IR_1 - |V_{THP}|)^2]$，其中 $V_{ov} = |V_{GS}| - |V_{THP}|$，因此 $V_{in1}$ 较低时的端电平变为 $+\big[\sqrt{2I_{SS}/\beta_p + (I_{SS}R_1 - |V_{THP}|)^2} - I_{SS}R_1\big]$（$V_{in1}$ 较高时取其相反数）；在 $V_{in1}$ 较低的一端，它在代数值上大于把饱和区（saturation region）公式外推所得的值，而不是更小。
- 以上曲线假设尾电流恒定，且输入对管在导引区内饱和（$V_b$ 取正常偏置）；在扫描两端（$V_{in1} \to 3$ V），导通的输入器件会进入线性区，但只要 $M_5$ 继续流过 $I_{SS}$，完全导引时的平台就保持不变。
