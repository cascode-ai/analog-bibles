# 详细步骤 - R701

**思路。** 令平板电容项（$\epsilon W/h$）等于三个边缘电容项，求解归一化宽度 $x = W/h$。方程中含有 $x^{0.25}$，因此没有闭式解；用不动点迭代求解（并用牛顿法验证），然后换算回 $W = xh$。

### 第 1 步 — 建立方程

令 $x = W/h$，令平板电容 = 边缘电容并消去 $\epsilon$：

$$x = 0.77 + 1.06\,x^{0.25} + 1.06\sqrt{\frac{t}{h}} \quad\Longrightarrow\quad x = c + 1.06\,x^{0.25}, \qquad c = 0.77 + 1.06\sqrt{\frac{t}{h}} .$$

**唯一性。** $f(x) = x - c - 1.06x^{0.25}$ 满足 $f(0) = -c < 0$，当 $x$ 很大时 $f \to +\infty$，并且对所有 $x > 0.17$ 都有 $f'(x) = 1 - 0.265x^{-0.75} > 0$，因此恰好有一个正根。

**求解方法。** 迭代 $x_{n+1} = c + 1.06\,x_n^{0.25}$。右边的斜率 $0.265x^{-0.75}$ 在根附近只有约 0.12，因此每迭代一次，误差大约缩小 8 倍。

### 第 2 步 — $h = 3\ \mu$m 的情况（$t = 1\ \mu$m）

$$\sqrt{\frac{t}{h}} = \sqrt{\frac{1}{3}} = 0.5774, \qquad 1.06\times0.5774 = 0.6120, \qquad c = 0.77 + 0.6120 = 1.3820 ,$$

因此 $x = 1.3820 + 1.06\,x^{0.25}$。从 $x_0 = 2$ 开始：

| $n$ | $x_n$ | $x_n^{0.25}$ | $x_{n+1} = 1.3820 + 1.06x_n^{0.25}$ |
|---|---|---|---|
| 0 | 2.0000 | 1.1892 | 2.6426 |
| 1 | 2.6426 | 1.2750 | 2.7335 |
| 2 | 2.7335 | 1.2858 | 2.7450 |
| 3 | 2.7450 | 1.2872 | 2.7464 |
| 4 | 2.7464 | 1.2873 | 2.7466 |

迭代收敛于 $x = 2.7466$（用牛顿法 $x \leftarrow x - f(x)/f'(x)$ 得到 2.74659）。

**验算：** 平板电容 $= 2.7466$；边缘电容 $= 0.77 + 1.06\times1.28736 + 0.6120 = 0.77 + 1.3646 + 0.6120 = 2.7466$。✓

$$W = xh = 2.7466\times3\ \mu\mathrm{m} = 8.24\ \mu\mathrm{m}.$$

### 第 3 步 — $h = 5\ \mu$m 的情况（$t = 1\ \mu$m）

$$\sqrt{\frac{t}{h}} = \sqrt{\frac15} = 0.4472, \qquad 1.06\times0.4472 = 0.4740, \qquad c = 0.77 + 0.4740 = 1.2440 ,$$

因此 $x = 1.2440 + 1.06\,x^{0.25}$。从 $x_0 = 2$ 开始：

| $n$ | $x_n$ | $x_n^{0.25}$ | $x_{n+1} = 1.2440 + 1.06x_n^{0.25}$ |
|---|---|---|---|
| 0 | 2.0000 | 1.1892 | 2.5046 |
| 1 | 2.5046 | 1.2580 | 2.5775 |
| 2 | 2.5775 | 1.2671 | 2.5871 |
| 3 | 2.5871 | 1.2683 | 2.5884 |
| 4 | 2.5884 | 1.2684 | 2.5886 |

因此 $x = 2.5886$。

**验算：** 边缘电容 $= 0.77 + 1.06\times1.26843 + 0.4740 = 0.77 + 1.3445 + 0.4740 = 2.5885 \approx x$。✓

$$W = xh = 2.5886\times5\ \mu\mathrm{m} = 12.94\ \mu\mathrm{m}.$$

### 第 4 步 — 结果解读

**两种分量随宽度的分配**（$h = 3\ \mu$m）：

| $W$ (µm) | $x = W/h$ | 平板电容 | 边缘电容 | 平板电容所占比例 |
|---|---|---|---|---|
| 1 | 0.33 | 0.33 | 2.19 | 13 % |
| 3 | 1.00 | 1.00 | 2.44 | 29 % |
| 8.24 | 2.75 | 2.75 | 2.75 | 50 % |
| 20 | 6.67 | 6.67 | 3.09 | 68 % |
| 50 | 16.7 | 16.7 | 3.52 | 83 % |

- **窄导线以边缘电容为主。** 对于宽度只有几微米或更窄的信号线，仅用 $\epsilon W/h$ 会严重低估电容。
- **介质层加厚的影响。** 从 $h = 3$ 到 $5\ \mu$m，交叉点处的**比值** $W/h$ 略有下降（2.75 → 2.59），因为侧壁项 $1.06\sqrt{t/h}$ 变小；但交叉点处的**宽度**大致与 $h$ 成正比地增大（8.2 → 12.9 µm）。
- 作为量级参考，对于 SiO$_2$ 介质（$\epsilon = 3.9\epsilon_0 = 0.0345$ fF/µm），$h = 3\ \mu$m 交叉点处的总电容为 $C = \epsilon(2\times2.747) \approx 0.19$ fF（每 µm 导线长度）。

### 结果

当 $W/h = 0.77 + 1.06(W/h)^{0.25} + 1.06\sqrt{t/h}$ 时，平板电容与边缘电容相等：

- $h = 3\ \mu$m：$W/h = 2.747$，因此 $W \approx 8.2\ \mu$m；
- $h = 5\ \mu$m：$W/h = 2.589$，因此 $W \approx 12.9\ \mu$m。

更窄的导线以边缘电容为主。

**常见错误。** 把常数 $0.77$ 或 $(W/h)^{0.25}$ 项算作平板电容的一部分。正如题目所述，只有 $W/h$ 是平板电容项。

**常见错误。** 把比值 $x = W/h$ 当作宽度报告，或者在 $h = 5\ \mu$m 时沿用第一个比值。宽度是 $W = xh$，而且比值本身也会通过 $\sqrt{t/h}$ 项随 $h$ 变化。

**常见错误。** 漏掉侧壁项 $1.06\sqrt{t/h}$，或把它算成 $1.06\,t/h$。带平方根时它贡献 0.61（$h = 3\ \mu$m 时），漏掉它会使交叉点宽度偏移约 25 %。
