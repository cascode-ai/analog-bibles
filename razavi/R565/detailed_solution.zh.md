# 详细步骤 - R565

**思路。** 写出修改后电路的环路方程（沿栅源回路列 KVL，PMOS 电流镜迫使两支路电流相等），寻找工作点。然后通过正反馈电流环路的环路增益检查这些工作点的**稳定性**，既计算小信号回归比（return ratio），也追踪大信号电流传输，并与原电路进行比较。

### 第 1 步 — 原电路与修改后电路的环路方程

在两种电路中，1:1 的 PMOS 电流镜（current mirror）都迫使 $I_{REF} = I_{out} = I$。在原电路中，记 $\beta_N = \mu_nC_{ox}(W/L)_N$，沿栅极回路列 KVL 得

$$V_{GS1} = V_{GS2} + IR_S, \qquad \sqrt{\frac{2I}{\beta_N}}\left(1 - \frac{1}{\sqrt K}\right) = IR_S \quad\Longrightarrow\quad I = \frac{2}{\beta_NR_S^2}\left(1 - \frac{1}{\sqrt K}\right)^2 ,$$

它与 $V_{DD}$ 无关：较宽的 $M_2$ 所需的过驱动电压比 $M_1$ 小，省下的电压就降落在 $R_S$ 上。

在修改后的电路中，$M_1$ 仍为二极管连接（栅极和漏极接节点 N），但其源极位于 $IR_S$，因此 $V_N = V_{GS1} + IR_S$；$M_2$ 的源极接地，因此 $V_{GS2} = V_N$：

$$V_{GS2} = V_{GS1} + IR_S .$$

$M_1$ 的源极现在高于其接地的衬底，因此 $V_{TH1} = V_{TH0} + \Delta V_{TH1}$，且当 $I > 0$ 时 $\Delta V_{TH1} > 0$。

### 第 2 步 — 按所标尺寸（$M_2$ 宽 $K$ 倍）：没有工作点

利用平方律（square law）：

$$V_{TH0} + \sqrt{\frac{2I}{K\beta_N}} = V_{TH0} + \Delta V_{TH1} + \sqrt{\frac{2I}{\beta_N}} + IR_S ,$$

$$\sqrt{\frac{2I}{\beta_N}}\left(\frac{1}{\sqrt K} - 1\right) = IR_S + \Delta V_{TH1}.$$

当 $K > 1$ 且 $I > 0$ 时，左边为**负**，右边为**正**，因此唯一的解是 $I = 0$：在相同电流下，较宽的 $M_2$ 需要的 $V_{GS}$ 比 $M_1$ **小**，而环路给它的却**更大**（多出 $IR_S$）。

**电流传输。** 若 $M_4$ 向 $M_1$ 提供 $I_{REF}$，则 $V_{ov1} = \sqrt{2I_{REF}/\beta_N}$，而 $M_2$ 得到的过驱动电压为 $V_{ov1} + I_{REF}R_S + \Delta V_{TH1}$，因此

$$I_{out} = \frac12K\beta_N\left(V_{ov1} + I_{REF}R_S + \Delta V_{TH1}\right)^2 > \frac12K\beta_NV_{ov1}^2 = K\,I_{REF} > I_{REF}.$$

电流镜把 $I_{out}$ 作为新的 $I_{REF}$ 返回，因此在任何电流水平下（包括接近零时，此时与原电路一样增益约为 $K$），电流每绕环路一周都被放大**超过** $K$ 倍。零电流状态同样不稳定，任何微小的电流都会**再生并增长**。

只有当某个晶体管退出饱和区时，增长才会停止：随着电流增大，N（$V_{GS1} + IR_S$）上升而 P（$V_{DD} - |V_{GS3}|$）下降，直到 $M_2$ 或 $M_4$ 进入线性区（二极管连接的 $M_1$ 和 $M_3$ 始终保持饱和）。最终电流由 $V_{DD}$ 和线性区电阻决定：**不再**与电源无关，而且可能非常大。

### 第 3 步 — 尺寸互换（$M_1$ 宽 $K$ 倍）：存在工作点

取 $(W/L)_1 = K(W/L)_2$，$\beta_2 = \mu_nC_{ox}(W/L)_2$，并忽略 $M_1$ 的体效应：

$$
\begin{aligned}
\sqrt{\frac{2I}{\beta_2}} &= \sqrt{\frac{2I}{K\beta_2}} + IR_S\\
\sqrt{\frac{2I}{\beta_2}}\left(1 - \frac{1}{\sqrt K}\right) &= IR_S\\
I &= \frac{2}{\mu_nC_{ox}(W/L)_2R_S^2}\left(1 - \frac{1}{\sqrt K}\right)^2 ,
\end{aligned}
$$

形式与原电路相同。这个工作点能否使用取决于它的稳定性。

### 第 4 步 — 稳定性：工作点处的环路增益

在 $M_4$ 注入 N 的电流处断开环路，注入一个小电流 $i$，并沿环路追踪它（忽略体效应）。

**修改后的电路（尺寸互换）。** 源极接 $R_S$ 的二极管连接器件 $M_1$ 在 N 处呈现的阻抗为 $1/g_{m1} + R_S$（因为 $i = g_{m1}(v_N - v_{S1})$，且 $v_{S1} = iR_S$）。$M_2$ 把 $v_N$ 转换为 $g_{m2}v_N$，电流镜再把它送回 N：

$$L_{mod} = g_{m2}\left(R_S + \frac{1}{g_{m1}}\right).$$

在工作点处 $V_{ov1} = V_{ov2}/\sqrt K$，所以 $IR_S = V_{ov2} - V_{ov1} = V_{ov2}(1 - 1/\sqrt K)$。利用 $g_m = 2I/V_{ov}$：

$$
\begin{aligned}
g_{m2}R_S &= \frac{2IR_S}{V_{ov2}} = 2\left(1 - \frac{1}{\sqrt K}\right),\\
\frac{g_{m2}}{g_{m1}} &= \frac{V_{ov1}}{V_{ov2}} = \frac{1}{\sqrt K},\\
L_{mod} &= 2 - \frac{2}{\sqrt K} + \frac{1}{\sqrt K} = 2 - \frac{1}{\sqrt K} .
\end{aligned}
$$

当 $K = 4$ 时：$L_{mod} = 2 - 0.5 = 1.5 > 1$。

**原电路。** N 处的阻抗为 $1/g_{m1}$，带源极负反馈的 $M_2$ 的跨导为 $g_{m2}/(1 + g_{m2}R_S)$：

$$L_{orig} = \frac{g_{m2}}{g_{m1}(1 + g_{m2}R_S)} .$$

在其工作点处，$g_{m2}/g_{m1} = \sqrt K$，$g_{m2}R_S = 2IR_S/V_{ov2} = 2\sqrt K(1 - 1/\sqrt K) = 2\sqrt K - 2$，因此

$$L_{orig} = \frac{\sqrt K}{2\sqrt K - 1} \quad(= 0.67 \text{ for } K = 4) < 1 .$$

正反馈环路的平衡点只有在 $L < 1$ 时才稳定。原电路满足这一条件；而在修改后的电路中，稍大一点的电流绕环一周后会变得更大，一直增长到受电源限制的状态，稍小一点的电流则会塌缩到零。

### 第 5 步 — 数值示例

取 $\beta = 1$ mA/V²（在原电路和按所标尺寸的情况下指 $M_1$，在尺寸互换的情况下指 $M_2$），$K = 4$，$R_S = 1$ kΩ，忽略体效应。对每个注入的 $I_{REF}$，NMOS 对返回 $I_{out}$（单位均为 mA）：

| $I_{REF}$ | 原电路 | 修改后，按所标尺寸 | 修改后，尺寸互换 |
|---|---|---|---|
| 0.1 | 0.162 | 0.60 | 0.052 |
| 0.4 | 0.431 | 3.35 | 0.359 |
| 0.5 | **0.500** | 4.50 | **0.500** |
| 0.6 | 0.564 | 5.75 | 0.659 |
| 0.8 | 0.681 | 8.53 | 1.026 |

- **原电路：** 低于 0.5 mA 时 $I_{out} > I_{REF}$，高于它时 $I_{out} < I_{REF}$，因此电流从两侧都被推向 0.5 mA：这是稳定的平衡点。
- **按所标尺寸：** $I_{out}$ 总是 $I_{REF}$ 的好几倍：没有平衡点，电流失控增长。
- **尺寸互换：** 低于 0.5 mA 时 $I_{out} < I_{REF}$（电流衰减到零），高于它时 $I_{out} > I_{REF}$（电流失控增长）：这是不稳定的平衡点，该处斜率为 $1.5$，与 $L_{mod}$ 一致。

### 结果

修改后的电路**没有稳定的、与电源无关的工作点**。

- **新的环路方程**（$I_{REF} = I_{out} = I$，两栅极相连，$M_1$ 的源极位于 $IR_S$）：$V_{GS2} = V_{GS1} + IR_S$。
- **按所标尺寸**（$M_2$ 宽 $K$ 倍，$K > 1$），$\sqrt{2I/(K\beta_N)} = \sqrt{2I/\beta_N} + IR_S + \Delta V_{TH1}$ 在 $I > 0$ 时无解，$M_1$ 的体效应使情况更糟。对任意 $I_{REF}$，NMOS 一侧送出 $I_{out} > K\,I_{REF} > I_{REF}$，因此在任何电流下环路增益都大于一。电流不断再生，直到 $M_2$ 或 $M_4$ 进入线性区，此时电流由 $V_{DD}$ 决定。
- **若让 $M_1$ 成为较宽的器件**（$(W/L)_1 = K(W/L)_2$），则存在平衡点 $I = \dfrac{2}{\mu_nC_{ox}(W/L)_2R_S^2}\left(1 - \dfrac{1}{\sqrt K}\right)^2$，但它是不稳定的。其环路增益为 $g_{m2}(R_S + 1/g_{m1}) = 2 - 1/\sqrt K > 1$（$K = 4$ 时为 1.5），而原电路为 $\sqrt K/(2\sqrt K - 1) < 1$（0.67）。任何扰动都会增长，或趋向零电流，或趋向受电源限制的状态。
- **$K$ 和 $R_S$ 的作用：** 负反馈电阻必须接在由二极管连接器件驱动的**较宽**晶体管（$M_2$）的源极。在那里它使工作点处的正反馈环路增益小于一。把 $R_S$ 移到 $M_1$ 会破坏这个有用的工作点，因此修改后的电路不能用作偏置电路。

**常见错误。** 认为在 $M_2$ 较宽的情况下，电路仍能按同样的电流公式工作。$R_S$ 接在 $M_1$ 下方时，环路要求 $V_{GS2} > V_{GS1}$，而流过相同电流的较宽 $M_2$ 无法满足这一要求。

**常见错误。** 互换尺寸后找到一个看似有效的解，就宣称电路与电源无关。在正反馈环路中，直流解只有在其环路增益小于一时才是可用的工作点；这里环路增益为 $2 - 1/\sqrt K > 1$。

**常见错误。** 断定电路由于没有有效的工作点，就只是流过零电流。当 $M_2$ 较宽时，零电流状态同样不稳定（小电流时环路增益大于 $K$），因此任何漏电流或启动（start-up）扰动都会使电流失控增长到一个与电源有关、可能很大的值。
