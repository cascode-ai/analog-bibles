# Golden Solution - R565

## Reference answer

The modified circuit has no stable, supply-independent operating point.
- New loop equation ($I_{REF} = I_{out} = I$, gates tied, $M_1$'s source at $IR_S$): $V_{GS2} = V_{GS1} + IR_S$.
- With the labeled sizes ($M_2$ $K$ times wider, $K > 1$), $\sqrt{2I/(K\beta_N)} = \sqrt{2I/\beta_N} + IR_S + \Delta V_{TH1}$ has no solution with $I > 0$: the left side is smaller than the overdrive of $M_1$ alone, and the body effect of $M_1$ ($V_{SB1} = IR_S$) makes it worse. For any $I_{REF}$, the NMOS side delivers $I_{out} = \tfrac12K\beta_N(V_{ov1} + IR_S + \Delta V_{TH1})^2 > K\,I_{REF} > I_{REF}$. The loop gain exceeds unity at every current (including near zero), so the current regenerates and grows until a transistor leaves saturation ($M_2$ or $M_4$ in triode; the diode-connected $M_1$ and $M_3$ always remain saturated). The current is then set by $V_{DD}$, i.e. not supply-independent.
- If instead $M_1$ is made the wider device ($(W/L)_1 = K(W/L)_2$, $K > 1$), a nonzero solution exists: $I = \dfrac{2}{\mu_nC_{ox}(W/L)_2R_S^2}\left(1 - \dfrac{1}{\sqrt K}\right)^2$ (neglecting $M_1$'s body effect). But it is unstable: the small-signal loop gain there is $g_{m2}(R_S + 1/g_{m1}) = 2 - 1/\sqrt K > 1$ (1.5 for $K = 4$). In the original circuit it is $\sqrt K/(2\sqrt K - 1) < 1$ (0.67 for $K = 4$). Any perturbation grows, and the circuit either collapses to zero current or runs up to the supply-limited state.
- Conclusion: the degeneration must sit in the source of the transistor driven by the diode-connected device ($M_2$), where it lowers the positive-feedback loop gain below unity at the operating point. Moving $R_S$ to $M_1$ destroys the useful operating point.
