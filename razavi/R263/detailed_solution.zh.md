# 详细步骤 - R263

**思路。** 参考支路中，$I_{REF}$ 流入源极接地的二极管连接（diode-connected）器件 $M_2$；这条支路不涉及 $C_1$，因此 $V_X$ 恒定。$M_1$ 的栅极电压相同，但其源极接在 $C_1$ 上：它的漏极电流给 $C_1$ 充电，源极电压升高，过驱动电压和电流减小，$V_Y = V_{DD} - R_1I_{D1}$ 则向 $V_{DD}$ 恢复。下面以闭式求解充电方程（先不计、再计入体效应），并计算一个例子。

### 第 1 步 — $V_X$ 恒定

$M_1$ 的栅极不取电流，因此始终有 $I_{D2} = I_{REF}$，由 $M_2$（二极管连接，源极接地）得

$$V_X = V_{GS2} = 0.7 + \sqrt{\frac{2I_{REF}}{\beta}} = \text{constant}.$$

对所有 $t > 0$，**$V_X$ 是一条水平直线**。令 $V_{ov} = \sqrt{2I_{REF}/\beta}$，则 $V_X = 0.7 + V_{ov}$。

### 第 2 步 — 起始时刻：$t = 0^+$

在 $t = 0^+$ 时，$V_{C1} = 0$，因此 $M_1$ 的源极与 $M_2$ 的源极一样处于地电位；由于 $V_{GS}$ 相同，$M_1$ 复制参考电流：

$$I_{D1}(0^+) = I_{REF}, \qquad V_Y(0^+) = V_{DD} - R_1I_{REF},$$

这里假设 $M_1$ 处于饱和区（saturation region），即 $V_{DD} - R_1I_{REF} > \sqrt{2I_{REF}/\beta}$。

### 第 3 步 — $C_1$ 的充电（不计体效应）

$M_1$ 的漏极电流全部流入 $C_1$：

$$C_1\frac{dV_{S1}}{dt} = I_{D1} = \frac{\beta}{2}\left(V_X - V_{S1} - V_{TH}\right)^2 .$$

先忽略体效应（$V_{TH} = 0.7$ V），则 $V_X - V_{S1} - 0.7 = V_{ov} - V_{S1}$。令 $M_1$ 的过驱动电压为 $w = V_{ov} - V_{S1}$，则 $dw = -dV_{S1}$，且 $w(0) = V_{ov}$：

$$-C_1\frac{dw}{dt} = \frac{\beta}{2}w^2 .$$

分离变量并从 $0$ 到 $t$ 积分：

$$
\begin{aligned}
\frac{dw}{w^2} &= -\frac{\beta}{2C_1}\,dt\\
\left[-\frac{1}{w}\right]_{V_{ov}}^{w(t)} &= -\frac{\beta}{2C_1}\,t\\
\frac{1}{w(t)} &= \frac{1}{V_{ov}} + \frac{\beta t}{2C_1}\\
w(t) &= \frac{V_{ov}}{1 + \beta V_{ov}t/(2C_1)} = \frac{V_{ov}}{1 + t/\tau}, \qquad \tau = \frac{2C_1}{\beta V_{ov}} = \frac{2C_1}{g_m},
\end{aligned}
$$

其中 $g_m = \beta V_{ov} = \sqrt{2\beta I_{REF}}$。于是

$$I_{D1}(t) = \frac{\beta}{2}w(t)^2 = \frac{I_{REF}}{(1 + t/\tau)^2}, \qquad V_{S1}(t) = V_{ov} - w(t) = V_{ov}\frac{t/\tau}{1 + t/\tau}.$$

源极电压向 $V_X - V_{TH}$（即 $V_{ov}$）攀升，电流衰减到零。拖尾按代数规律而非指数规律衰减：给 $C_1$ 充电的电导是 $M_1$ 的 $g_m = \beta w$，它随电流一起减小，因此在长时间后电流按 $1/t^2$ 下降，而不是按 $e^{-t/\tau}$ 下降。

### 第 4 步 — 计入体效应

衬底接地时 $V_{SB1} = V_{S1}$，$V_{TH1}$ 随源极电压升高而增大，$\eta = dV_{TH}/dV_{SB} = \gamma/(2\sqrt{0.9 + V_{S1}})$。此时过驱动电压为 $w = V_X - V_{S1} - V_{TH}(V_{S1})$，且 $dw = -(1 + \eta)\,dV_{S1}$：

$$\frac{dw}{dt} = -(1 + \eta)\frac{\beta}{2C_1}w^2 \quad\Longrightarrow\quad I_{D1}(t) \approx \frac{I_{REF}}{(1 + t/\tau')^2}, \qquad \tau' = \frac{2C_1}{(1 + \eta)\,g_m}$$

（近似把 $\eta$ 当作常数）。由此得到两个结果：

- 电流衰减快约 20 %（此处 $\eta \approx 0.22$–0.24）；
- 源极电压**停在稍低的位置**，即 $V_{S1} + V_{TH}(V_{S1}) = V_X$ 处，而不是 $V_X - 0.7$ 处；它永远不会达到 $V_X$。

### 第 5 步 — $V_Y(t)$

$R_1$ 的电流全部流入 $M_1$，因此

$$V_Y(t) = V_{DD} - R_1I_{D1}(t) \approx V_{DD} - \frac{R_1I_{REF}}{(1 + t/\tau')^2}.$$

$V_Y$ 从 $V_{DD} - R_1I_{REF}$ 开始，**向 $V_{DD}$ 上升**：起初很陡（初始斜率为 $2R_1I_{REF}/\tau'$），之后越来越慢。

**$M_1$ 保持饱和：** 其过驱动电压 $w$ 减小，而 $V_{DS1} = V_Y - V_{S1}$ 增大（$V_Y$ 的上升幅度远大于 $V_{S1}$），因此只要在 $t = 0^+$ 时 $V_{DS1} \ge w$，此后就一直成立。

### 第 6 步 — 数值示例

取 $\beta = 2.68\ \mathrm{mA/V^2}$（$W/L = 10/0.5$），$I_{REF} = 100\ \mu\mathrm{A}$，$R_1 = 10\ \mathrm{k}\Omega$，$C_1 = 10$ pF：

$$
\begin{aligned}
V_{ov} &= \sqrt{2(100\ \mu\mathrm{A})/(2.68\ \mathrm{mA/V^2})} = 0.273\ \mathrm{V}, \qquad V_X = 0.973\ \mathrm{V},\\
g_m &= \sqrt{2(2.68\ \mathrm{mA/V^2})(100\ \mu\mathrm{A})} = 0.732\ \mathrm{mS},\\
\tau &= \frac{2(10\ \mathrm{pF})}{0.732\ \mathrm{mS}} = 27.3\ \mathrm{ns}, \qquad \tau' \approx \frac{27.3\ \mathrm{ns}}{1.237} = 22\ \mathrm{ns},\\
V_Y(0^+) &= 3 - (10\ \mathrm{k}\Omega)(100\ \mu\mathrm{A}) = 2.0\ \mathrm{V}.
\end{aligned}
$$

计入体效应时的最终源极电压：求解 $V_{S1} + 0.7 + 0.45(\sqrt{0.9 + V_{S1}} - 0.949) = 0.973$，得 $V_{S1} = 0.223$ V（不计体效应时为 0.273 V）。

对充电方程进行数值积分（计入体效应）：

| $t$ | $V_{S1}$ (V) | $I_{D1}$ | $V_Y$ (V) | $V_X$ (V) |
|---|---|---|---|---|
| $0^+$ | 0 | 100 μA | 2.00 | 0.973 |
| 5 ns | 0.041 | 66.5 μA | 2.33 | 0.973 |
| 10 ns | 0.069 | 47.5 μA | 2.53 | 0.973 |
| 27 ns | 0.122 | 20.2 μA | 2.80 | 0.973 |
| 50 ns | 0.154 | 9.5 μA | 2.90 | 0.973 |
| 100 ns | 0.182 | 3.3 μA | 2.97 | 0.973 |
| 500 ns | 0.214 | 0.19 μA | 3.00 | 0.973 |

近似式 $I_{REF}/(1 + t/\tau')^2$ 在 5 ns 时给出 66.5 μA，在 27 ns 时给出 20.0 μA，与上表吻合得很好。

### 结果

- **$V_X$ 恒定**，等于 $V_{GS}(I_{REF}) = 0.7 + \sqrt{2I_{REF}/\beta}$：$M_2$ 和 $I_{REF}$ 与 $C_1$ 无关。
- **$V_Y$ 从 $V_{DD} - R_1I_{REF}$ 开始**（$M_1$ 的源极仍为 0 V 时它复制 $I_{REF}$），随着 $C_1$ 充电、$M_1$ 的电流逐渐消失，**回升并趋向 $V_{DD}$**，开始时很快，之后变慢：
$$V_Y(t) = V_{DD} - R_1I_{D1}(t), \qquad I_{D1}(t) = \frac{I_{REF}}{(1 + t/\tau)^2}, \quad \tau = \frac{2C_1}{g_m}, \quad g_m = \sqrt{2\beta I_{REF}}$$
（不计体效应）。这是按代数规律（$1/t^2$）而非指数规律衰减的拖尾。体效应使时间尺度缩短约 $1 + \eta$ 倍，并使 $M_1$ 的源极停在稍低的位置，即 $V_X - V_{TH1}(V_{S1})$。
- $M_1$ 的源极电压从 0 向 $V_X - V_{TH}$ 上升（本例中为 0.22 V），永远不会达到 $V_X$。

**常见错误。** 把 $V_Y$ 画成随时间**下降**，或者恒为 $V_{DD} - R_1I_{REF}$。随着 $C_1$ 充电，$M_1$ 的源极电压升高而栅极电压固定，因此它的电流以及 $R_1$ 上的压降都减小，$V_Y$ 上升。

**常见错误。** 让 $V_X$ 发生变化。$C_1$ 位于 $M_1$ 的源极，而 $M_1$ 的栅极不取电流，因此在这种直流（平方律）分析中，没有任何途径把电容耦合回 X。

**常见错误。** 把衰减描述为 RC 指数衰减，或者让 $M_1$ 的源极一直充电到 $V_X$。充电电流是不断减小的过驱动电压的平方律函数，由此得到 $1/(1 + t/\tau)^2$ 规律；当源极比栅极低一个阈值电压（threshold voltage）时，充电电流消失。
