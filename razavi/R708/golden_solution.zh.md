多晶硅：它对衬底的电容 ≈ 7.5 fF，而 n 阱电阻为 ≈ 144 fF（相差约 19 倍）。

- 多晶硅：$500/60 = 8.33$ 个方块。取 $W = 3\ \mu$m，则 $L = 25\ \mu$m；面积 75 μm²；$C = 75 \times 100\ \mathrm{aF} = 7.5$ fF。
- n 阱：$500/2000 = 0.25$ 个方块。取 $L = 6\ \mu$m（较短的一边），则 $W = 24\ \mu$m；面积 144 μm²；$C = 144 \times 1000\ \mathrm{aF} = 144$ fF。
- 多晶硅的面积也更小，并且线性度好得多、尺寸也控制得更精确：n 阱的方块电阻取决于阱与衬底之间的电压以及宽度，而且温度系数（TC）大、工艺离散性大。
