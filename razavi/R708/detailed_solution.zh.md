# 详细步骤 - R708

**思路。** 对每种材料，求出得到 500 Ω 所需的方块数 $L/W = R/R_\square$，用最小尺寸约束确定几何形状，再把面积乘以单位面积电容（忽略边缘电容），得到对衬底的寄生电容。寄生电容（及面积）较小的材料是更好的选择，线性度和精度方面的考虑也支持这一结论。

### 第 1 步 — 多晶硅电阻（硅化物阻挡）

$$\frac{L}{W} = \frac{R}{R_\square} = \frac{500\ \Omega}{60\ \Omega/\square} = 8.33 .$$

所需方块数多于一个，因此电阻的长度大于宽度，匹配约束确定的是其**宽度** $W = 3\ \mu$m：

$$L = 8.33\times W = 8.33\times3\ \mu\mathrm{m} = 25\ \mu\mathrm{m}, \qquad A_{poly} = WL = (3\ \mu\mathrm{m})(25\ \mu\mathrm{m}) = 75\ \mu\mathrm{m^2},$$

$$C_{poly} = C_A A = (100\ \mathrm{aF/\mu m^2})(75\ \mu\mathrm{m^2}) = 7500\ \mathrm{aF} = 7.5\ \mathrm{fF}.$$

### 第 2 步 — n 阱电阻

$$\frac{L}{W} = \frac{500\ \Omega}{2000\ \Omega/\square} = 0.25 .$$

只需要四分之一个方块，因此电阻的**宽度大于长度**，约束作用于**长度**（沿电流方向）$L = 6\ \mu$m，即短边：

$$W = \frac{L}{0.25} = 4L = 4\times6\ \mu\mathrm{m} = 24\ \mu\mathrm{m}.$$

验算：$R = 2000\ \Omega/\square\times(6/24) = 2000\times0.25 = 500\ \Omega$。✓

$$A_{well} = WL = (24\ \mu\mathrm{m})(6\ \mu\mathrm{m}) = 144\ \mu\mathrm{m^2},$$

而以平板电容形式给出的阱–衬底结电容（junction capacitance）为

$$C_{well} = (1000\ \mathrm{aF/\mu m^2})(144\ \mu\mathrm{m^2}) = 144{,}000\ \mathrm{aF} = 144\ \mathrm{fF}.$$

### 第 3 步 — 比较

| | 方块数 | $W\times L$ | 面积 | 对衬底的 $C$ |
|---|---|---|---|---|
| 多晶硅（60 Ω/□，100 aF/µm²） | 8.33 | 3 µm × 25 µm | 75 µm² | **7.5 fF** |
| n 阱（2 kΩ/□，1000 aF/µm²） | 0.25 | 24 µm × 6 µm | 144 µm² | **144 fF** |

$$\frac{C_{well}}{C_{poly}} = \frac{144\ \mathrm{fF}}{7.5\ \mathrm{fF}} = 19.2 .$$

n 阱的方块电阻很高，通常可以节省面积，但这里的最小长度约束迫使它成为一个短而宽的电阻，而且其单位面积电容是多晶硅的十倍。作为粗略的速度衡量，集总 $RC$ 对多晶硅为 $500\ \Omega\times7.5\ \mathrm{fF} = 3.75$ ps，对 n 阱为 $500\ \Omega\times144\ \mathrm{fF} = 72$ ps。

**选择多晶硅的其他理由。** 随着阱–衬底耗尽区展宽，n 阱的导电厚度会减小，因此其电阻取决于其电压（电压系数很大），其电容也是随电压变化的结电容；氧化层隔离的多晶硅没有这两种效应。n 阱电阻的温度系数也很大，工艺离散性大，宽度还取决于横向扩散。此外，这里多晶硅只需要约一半的面积（75 µm² 对 144 µm²）。

### 结果

采用**多晶硅**。多晶硅电阻为 3 µm × 25 µm（8.33 个方块），面积 75 µm²，对衬底的电容约为 **7.5 fF**；n 阱电阻则为宽 24 µm × 长 6 µm（0.25 个方块），面积 144 µm²，电容约为 **144 fF**，大约是前者的 19 倍。多晶硅的线性度也更好，控制也更精确。

**常见错误。** 把最小尺寸约束用在了错误的一边。对于多晶硅（$R/R_\square > 1$），起约束作用的是最小**宽度**，电阻长 25 µm；对于 n 阱（$R/R_\square < 1$），约束作用于沿电流方向的**长度**，因此它必须宽 24 µm。宽 6 µm、长 1.5 µm 的 n 阱（或长 3 µm 的多晶硅）的阻值是错误的。

**常见错误。** 以“高电阻率层可以节省面积”为理由选择 n 阱。这对大电阻成立；对于 500 Ω，n 阱所需不到一个方块，最小长度规则反而使它更大，电容也大得多。

**常见错误。** 只比较单位面积电容（n 阱差 10×）。最终约 19× 的比值还取决于约束所决定的几何形状。
