Consider the fully differential amplifier shown in [Fig. 1], with $(W/L)_{1-4} = 50\ \mu\mathrm{m}/0.5\ \mu\mathrm{m}$, $I_{SS} = 1$ mA (ideal), an input common-mode level of 1.3 V, and $V_b$ set so that $M_3$ and $M_4$ each carry 0.5 mA. $V_{DD} = 3$ V. In the nominal design all transistors stay in saturation. Suppose we now allow each PMOS device to enter the triode region by 50 mV (at its own output peak, $|V_{DS}|$ is 50 mV below its $|V_{GS} - V_{TH}|$) so as to increase the allowable differential swing by 100 mV. What is the small-signal gain at the peaks of the output swing?

Device data: NMOS $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$, $V_{TH0} = 0.7$ V, $\lambda = 0.1\ \mathrm{V^{-1}}$; PMOS $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$, $V_{TH0} = -0.8$ V, $\lambda = 0.2\ \mathrm{V^{-1}}$.
