# 详细步骤 - R012

**思路。** 分压器 $R_1$–$R_2$ 接在 $V_{DD}$ 与 $V_X$ 之间，NMOS 的源极是 $V_X$ 节点。用 $V_X$ 表示 $V_{GS}$、$V_{DS}$ 和 $V_{SB}$，证明 $M_1$ 只要导通就处于饱和区，再写出平方律（square law）电流和跨导。体效应（衬底接地，源极接 $V_X$）使 $V_{TH}$ 随 $V_X$ 升高，并使截止点提前。

### 第 1 步 — 端电压

由于 $V_X \le V_{DD}$，电位较低的 $V_X$ 节点是源极，$V_{DD}$ 端是漏极。栅极不取电流，因此 $R_1$ 和 $R_2$ 流过的电流为 $(V_{DD} - V_X)/(R_1 + R_2)$，而 $V_{GS}$ 就是 $R_2$ 上的压降：

$$
\begin{aligned}
V_{GS} &= V_G - V_X = (3 - V_X)\frac{R_2}{R_1 + R_2} = k\,(3 - V_X), \qquad k = \frac{R_2}{R_1 + R_2},\\
V_{DS} &= V_{DD} - V_X = 3 - V_X,\\
V_{SB} &= V_X - 0 = V_X .
\end{aligned}
$$

计入体效应，

$$V_{TH}(V_X) = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right)\ \mathrm{V},$$

当源极电位升到接地衬底之上时，它会**增大**：$V_X = 0$ 时为 0.70 V，0.5 V 时为 0.81 V，1 V 时为 0.89 V。

### 第 2 步 — 只要导通就饱和

饱和要求 $V_{DS} \ge V_{GS} - V_{TH}$：

$$3 - V_X \;\ge\; k(3 - V_X) - V_{TH}.$$

由于 $k < 1$，左边至少为 $k(3 - V_X)$，而 $V_{TH} > 0$，因此不等式总是成立：**$M_1$ 只要导通就处于饱和区**。（栅极取自漏极与源极之间的分压抽头，因此 $V_{GS} \le V_{DS}$。）

### 第 3 步 — 漏极电流

忽略沟道长度调制（channel-length modulation），

$$I_X = \tfrac12\beta\,(V_{GS} - V_{TH})^2 = \tfrac12\beta\left[(3 - V_X)\frac{R_2}{R_1 + R_2} - V_{TH}(V_X)\right]^2 ,$$

这里假设 $3R_2/(R_1 + R_2) > 0.7$ V，使 $M_1$ 在 $V_X = 0$ 时导通（否则它在整个扫描范围内都截止）。

升高 $V_X$ 会从两方面削弱栅极驱动：$V_{GS} = k(3 - V_X)$ 以 $k$/V 的速率减小，$V_{TH}$ 以 $\eta = dV_{TH}/dV_{SB} = \gamma/(2\sqrt{0.9 + V_X})$/V 的速率增大（$V_X = 0$ 时为 $0.237$，到 $V_X = 1.2$ V 时降到约 $0.16$）。因此

$$\frac{dI_X}{dV_X} = -\beta\,V_{ov}\,(k + \eta).$$

电流先陡后缓地下降，并以**相切**的方式到达零（其斜率随 $V_{ov}$ 一起趋于零）：近似为一条抛物线。

### 第 4 步 — 截止点

$M_1$ 在 $V_{GS} = V_{TH}$ 处截止：

$$k\,(3 - V_X) = 0.7 + 0.45\sqrt{0.9 + V_X} - 0.45\sqrt{0.9}.$$

令 $u = \sqrt{0.9 + V_X}$（于是 $V_X = u^2 - 0.9$），并利用 $0.7 - 0.45\sqrt{0.9} = 0.7 - 0.4269 = 0.2731$：

$$
\begin{aligned}
k\,(3.9 - u^2) &= 0.2731 + 0.45u\\
k\,u^2 + 0.45u + (0.2731 - 3.9k) &= 0,\\
u &= \frac{-0.45 + \sqrt{0.2025 - 4k\,(0.2731 - 3.9k)}}{2k},\\
V_{X,\mathrm{off}} &= u^2 - 0.9 .
\end{aligned}
$$

**若没有体效应**，条件将为 $k(3 - V_X) = 0.7$，即 $V_X = 3 - 0.7\,(R_1 + R_2)/R_2$。由于 $V_{TH}$ 随 $V_X$ 增大，实际截止点来得**更早**（$V_X$ 更低）。当 $V_X > V_{X,\mathrm{off}}$ 时，$I_X = 0$，$g_m = 0$。

### 第 5 步 — 跨导

在饱和区，

$$g_m = \beta\,(V_{GS} - V_{TH}) = \beta\left[(3 - V_X)\frac{R_2}{R_1 + R_2} - V_{TH}(V_X)\right],$$

其斜率为

$$\frac{dg_m}{dV_X} = -\beta\left(\frac{R_2}{R_1 + R_2} + \frac{dV_{TH}}{dV_X}\right) = -\beta\,(k + \eta),$$

比仅由分压器给出的斜率更陡。由于 $\eta$ 变化很慢（从 0.24 到 0.16），$g_m$ **近似线性地**下降，在 $V_{X,\mathrm{off}}$ 处降为零，曲线略微向上凹（concave up）；之后保持为零。

### 第 6 步 — 数值示例（$R_1 = R_2$，$k = 0.5$）

**截止点：**

$$u = \frac{-0.45 + \sqrt{0.2025 - 4(0.5)(0.2731 - 1.95)}}{2(0.5)} = -0.45 + \sqrt{0.2025 + 3.3538} = -0.45 + 1.8858 = 1.4358,$$

$$V_{X,\mathrm{off}} = 1.4358^2 - 0.9 = 2.0616 - 0.9 = 1.16\ \mathrm{V}.$$

验算：$V_{GS} = 0.5(3 - 1.16) = 0.92$ V，$V_{TH} = 0.7 + 0.45(1.4358 - 0.9487) = 0.92$ V。✓ 若没有体效应，截止点将在 $3 - 0.7\times2 = 1.6$ V 处，因此体效应使它移动了约 0.44 V。

| $V_X$ (V) | $V_{GS}$ (V) | $V_{TH}$ (V) | $V_{ov}$ (V) | $I_X/\beta$ (V²) | $g_m/\beta$ (V) |
|---|---|---|---|---|---|
| 0 | 1.500 | 0.700 | 0.800 | 0.320 | 0.80 |
| 0.25 | 1.375 | 0.756 | 0.619 | 0.192 | 0.62 |
| 0.5 | 1.250 | 0.806 | 0.444 | 0.099 | 0.44 |
| 0.75 | 1.125 | 0.851 | 0.274 | 0.0375 | 0.27 |
| 1.0 | 1.000 | 0.893 | 0.107 | 0.0057 | 0.11 |
| 1.16 | 0.919 | 0.919 | 0 | 0 | 0 |
| 1.16 – 3 | 0.92 → 0 | 0.92 → 1.16 | < 0（截止） | 0 | 0 |

以 $V_X = 0.5$ V 这一行为例：$V_{GS} = 0.5(3 - 0.5) = 1.25$ V；$V_{TH} = 0.7 + 0.45(\sqrt{1.4} - 0.9487) = 0.806$ V；$V_{ov} = 1.25 - 0.806 = 0.444$ V；$I_X = \tfrac12\beta(0.444\ \mathrm{V})^2 = 0.099\beta\ \mathrm{V^2}$；$g_m = 0.444\beta$。每一行中 $V_{DS} = 3 - V_X \ge 1.84$ V，远大于 $V_{ov}$，证实器件处于饱和区。

### 结果

- $V_{GS} = (3 - V_X)\dfrac{R_2}{R_1 + R_2}$，$V_{DS} = 3 - V_X \ge V_{GS}$，$V_{SB} = V_X$，因此 $V_{TH} = 0.7 + 0.45(\sqrt{0.9 + V_X} - \sqrt{0.9})$ 随 $V_X$ 升高。$M_1$（漏极接 $V_{DD}$，源极接 $V_X$）**只要导通就处于饱和区**。
- 假设 $3R_2/(R_1 + R_2) > 0.7$ V，$I_X$ **按二次函数规律下降**，在满足 $(3 - V_X)R_2/(R_1 + R_2) = V_{TH}(V_X)$ 的截止点处降为零，高于该点时为零：
$$I_X = \tfrac12\beta\left[(3 - V_X)\frac{R_2}{R_1 + R_2} - V_{TH}(V_X)\right]^2 .$$
由于体效应，截止点低于不计体效应时的值 $3 - 0.7(R_1 + R_2)/R_2$（对 $R_1 = R_2$，为 1.16 V 而不是 1.6 V）。
- $g_m$ **近似线性地**下降到零，斜率大小为 $\beta\left[R_2/(R_1 + R_2) + dV_{TH}/dV_X\right]$，比仅由分压器给出的更陡；截止后为零：
$$g_m = \beta\left[(3 - V_X)\frac{R_2}{R_1 + R_2} - V_{TH}(V_X)\right].$$

**常见错误。** 把源极当作接地。源极是 $V_X$ 节点，因此 $V_{GS}$ 只是 $R_2$ 上的压降 $(3 - V_X)R_2/(R_1 + R_2)$，它随 $V_X$ 升高而减小；因此 $I_X$ 随 $V_X$ **减小**。

**常见错误。** 忽略体效应。$V_{SB} = V_X$ 在导通范围内使阈值电压（threshold voltage）最多升高约 0.2 V，并使截止点明显提前。

**常见错误。** 认为 $V_X$ 升高时器件会进入线性区（triode region）。由于 $V_{DS} \ge V_{GS}$，器件从饱和区直接进入截止。
