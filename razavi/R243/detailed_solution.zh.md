# 详细步骤 - R243

**思路。** $M_2$ 为二极管连接，因此节点 X 的电压由电阻电流 $(V_{DD} - V_X)/R_1$ 与二极管的平方律电流之间的基尔霍夫电流定律（KCL）关系决定。$M_1$ 的栅源电压相同，因此若它饱和，就会让相同的电流流过相同的电阻，从而使 $V_Y = V_X$。然后验证 $M_1$ 确实饱和，并描述曲线。

### 第 1 步 — 区域 $V_{DD} \le V_{TH} = 0.7$ V

两个栅极都接 X，因此 $V_{GS1} = V_{GS2} = V_X$：这是一个带电阻负载的电流镜（current mirror）。$V_X$ 不可能超过 $V_{DD}$，因此当 $V_{DD} \le 0.7$ V 时两个晶体管都截止，没有电流流动，且

$$V_X = V_Y = V_{DD} \qquad (0 \le V_{DD} \le 0.7\ \mathrm{V}) .$$

两条曲线都沿 45° 线变化。

### 第 2 步 — $V_{DD} > 0.7$ V 时的 $V_X$

二极管连接的 $M_2$ 在饱和区（saturation region）导通。对 X 点列 KCL：

$$\frac{V_{DD} - V_X}{R_1} = \frac{\beta}{2}(V_X - V_{TH})^2 .$$

令过驱动电压（overdrive voltage）$w = V_X - V_{TH}$，$D = V_{DD} - V_{TH}$，则 $V_{DD} - V_X = D - w$，且

$$\frac{D - w}{R_1} = \frac{\beta}{2}w^2 \quad\Longrightarrow\quad \beta R_1w^2 + 2w - 2D = 0 .$$

取正根，

$$w = \frac{-2 + \sqrt{4 + 8\beta R_1D}}{2\beta R_1} = \frac{\sqrt{1 + 2\beta R_1D} - 1}{\beta R_1} ,$$

$$\boxed{V_X = V_{TH} + \frac{\sqrt{1 + 2\beta R_1(V_{DD} - V_{TH})} - 1}{\beta R_1}} \qquad (V_{DD} > 0.7\ \mathrm{V}) .$$

**斜率。** 将 $w$ 对 $D$ 求导：

$$\frac{dV_X}{dV_{DD}} = \frac{1}{\beta R_1}\cdot\frac{2\beta R_1}{2\sqrt{1 + 2\beta R_1D}} = \frac{1}{\sqrt{1 + 2\beta R_1(V_{DD} - V_{TH})}} .$$

在 $V_{DD} = 0.7^+$ 处斜率为 1，因此曲线无折角地离开 45° 线。随后斜率不断减小：它等于 $1/(1 + g_{m2}R_1)$，即 $R_1$ 与二极管的 $1/g_{m2}$ 构成的分压比，随电流增大而下降。当 $V_{DD}$ 较大时，$V_X \approx V_{TH} + \sqrt{2(V_{DD} - V_{TH})/(\beta R_1)}$，呈缓慢的、类似平方根的上升。

### 第 3 步 — $V_Y$：$M_1$ 复制电流

假设 $M_1$（$V_{GS1} = V_X$）饱和。则它流过相同的电流 $I = (V_{DD} - V_X)/R_1$，对 Y 点列 KCL 得

$$V_Y = V_{DD} - R_1I = V_{DD} - R_1\frac{V_{DD} - V_X}{R_1} = V_X .$$

于是 $V_{DS1} = V_Y = V_X = V_{GS1} \ge V_{GS1} - V_{TH}$，$M_1$ 确实如假设那样处于饱和。解是唯一的：在 Y 点，电阻电流随 $V_Y$ 升高而减小，而 $M_1$ 的电流（$V_{GS}$ 固定）在线性区（triode region）内上升、在饱和区内保持不变，因此两条曲线只相交一次。所以

$$V_Y = V_X \qquad\text{for all } V_{DD} .$$

右支路是左支路的精确复制。

### 第 4 步 — 数值示例

例如，取 $\beta = 1\ \mathrm{mA/V^2}$，$R_1 = 10\ \mathrm{k}\Omega$（$\beta R_1 = 10\ \mathrm{V^{-1}}$）：

| $V_{DD}$ (V) | 0.5 | 0.7 | 0.8 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 |
|---|---|---|---|---|---|---|---|---|
| $V_X = V_Y$ (V) | 0.50 | 0.70 | 0.77 | 0.86 | 1.01 | 1.12 | 1.21 | 1.29 |
| 电流 (μA) | 0 | 0 | 3 | 14 | 49 | 88 | 129 | 171 |
| 斜率 $dV_X/dV_{DD}$ | 1 | 1 | 0.58 | 0.38 | 0.24 | 0.19 | 0.16 | 0.15 |

$\beta R_1$ 越大，曲线越早变平，并更接近 $V_{TH}$；反之，曲线在 45° 线附近停留得越久。

### 结果

**对所有 $V_{DD}$，$V_X = V_Y$**，两条曲线完全相同：

- $0 \le V_{DD} \le 0.7$ V：两个晶体管都截止，$V_X = V_Y = V_{DD}$（斜率为 1）。
- $V_{DD} > 0.7$ V：二者都跟随二极管曲线
$$V_X = V_Y = V_{TH} + \frac{\sqrt{1 + 2\beta R_1(V_{DD} - V_{TH})} - 1}{\beta R_1},$$
它在 0.7 V 处以斜率 1 离开 45° 线，随后上升得越来越慢（斜率为 $1/\sqrt{1 + 2\beta R_1(V_{DD} - V_{TH})}$，大致按 $\sqrt{V_{DD}}$ 变化）。

$M_1$ 始终饱和（$V_{DS1} = V_{GS1}$），并流过与 $M_2$ 相同的电流。

**常见错误。** 断言 $M_1$ 处于线性区，或认为 $V_{DD}$ 增大时 $V_Y$ 趋向于零。由于 $V_Y = V_X$，它的 $V_{DS}$ 等于 $V_{GS}$，因此处于饱和，$V_Y$ 与 $V_X$ 完全一样地上升。

**常见错误。** 认为 $V_{DD} > 0.7$ V 时 $V_X$ 被钳位在 $V_{TH}$，或者把它画成始终以斜率 1 上升。二极管的过驱动电压随电流增大，因此 $V_X$ 会持续上升，但增长慢于线性。

**常见错误。** 把电路看成交叉耦合锁存器（cross-coupled latch）。只有 $M_2$ 是二极管连接的，两个栅极都接 X，因此不存在正反馈，也没有双稳态解。
