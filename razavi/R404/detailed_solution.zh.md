# 详细步骤 - R404

**思路。** 电容没有噪声，因此所有噪声都来自运放中的晶体管。先求每个晶体管注入短路输出端的噪声电流，再除以运放跨导（transconductance）的平方，得到运放本身的输入参考噪声。然后说明电容反馈环路不改变输入参考噪声。

### 第 1 步 — 反馈与噪声源

$M_1$ 的栅极（$V_{in}$）是**同相**输入端：升高它会使 $I_{D1}$ 增大，电流镜（current mirror）把这一电流复制到输出端。$M_2$ 的栅极（节点 X）是**反相**输入端，由分压器 $C_1$（输出端到 X）和 $C_2$（X 到地）驱动。低频时电容不对运放构成负载，因此

$$V_X = \beta V_{out}, \qquad \beta = \frac{C_1}{C_1 + C_2} ,$$

该电路是一个同相放大器，闭环增益 $\approx 1/\beta = 1 + C_2/C_1$。（图中未画出 X 的偏置网络，其噪声忽略不计。）

每个晶体管都有一个漏源之间的热噪声（thermal noise）电流 $4kT\gamma g_m$ 和一个折算到栅极的闪烁噪声电压 $K/(C_{ox}WLf)$，对 NMOS 取 $K = K_N$，对 PMOS 取 $K_P$。理想电容不消耗功率，**不产生噪声**。各对管是匹配的：$g_{m1} = g_{m2}$，$g_{m3} = g_{m4}$，$(WL)_1 = (WL)_2$，$(WL)_3 = (WL)_4$。

### 第 2 步 — 方法与运放的跨导

输出端对交流地短路时，输出端的噪声电流 $I_n$ 等效于输入端的噪声电压 $I_n/G_m$，其中 $G_m$ 是短路跨导。输出电阻在这个比值中被约去，因此计算时可以取 $\lambda = 0$。

**$G_m$。** 加 $v_{in1} = v_d/2$，$v_{in2} = -v_d/2$。理想尾电流源不传导信号电流，因此对尾节点 P 列基尔霍夫电流定律（KCL）：

$$g_{m1}(v_{in1} - v_P) + g_{m2}(v_{in2} - v_P) = 0 \ \Longrightarrow\ v_P = \frac{v_{in1} + v_{in2}}{2} = 0 .$$

$M_1$ 中的电流为 $+g_{m1}v_d/2$，电流镜通过 $M_4$ 把它推入输出端；$M_2$ 从输出端抽取的电流**减少**了 $g_{m1}v_d/2$。因此

$$I_{out} = \frac{g_{m1}v_d}{2} + \frac{g_{m1}v_d}{2} = g_{m1}v_d \quad\Longrightarrow\quad G_m = g_{m1} .$$

### 第 3 步 — 各晶体管在短路输出端产生的热噪声电流

输入端接交流地，输出端短路。设二极管连接（diode-connected）节点为 A，即 $M_1$ 的漏极与 $M_3$、$M_4$ 的栅极所在的节点。

**$M_1$。** 其噪声电流 $I_{n1}$ 在 $M_1$ 内部从 A 流向 P。对 P 列 KCL：

$$
\begin{aligned}
g_{m1}(0 - v_P) + I_{n1} + g_{m2}(0 - v_P) &= 0\\
v_P &= \frac{I_{n1}}{2g_{m1}} .
\end{aligned}
$$

- $M_1$ 中的电流：$-g_{m1}v_P + I_{n1} = I_{n1}/2$，由 $M_4$ 推入输出端。
- $M_2$ 中的电流：$-g_{m2}v_P = -I_{n1}/2$，因此 $M_2$ 也向输出端**增加**了 $I_{n1}/2$。

因此 $I_{n1}$ 全部到达输出端。

**$M_2$。** 同样的计算表明（P 点电压变化 $I_{n2}/(2g_{m1})$，一半噪声经镜像传输，另一半直接流入），$I_{n2}$ 全部到达输出端。

**$M_3$。** 输入端接地时，$v_P = 0$，$M_1$ 不传导信号电流，因此 $I_{n3}$ 只能流过二极管连接器件自身的跨导。对 A 列 KCL：

$$
\begin{aligned}
g_{m3}(0 - v_A) + I_{n3} &= 0 \ \Longrightarrow\ v_A = \frac{I_{n3}}{g_{m3}},\\
\text{current from } M_4 \text{ into the output} &= g_{m4}(0 - v_A) = -\frac{g_{m4}}{g_{m3}}I_{n3} = -I_{n3}.
\end{aligned}
$$

因此 $I_{n3}$ 同样全部到达输出端。

**$M_4$。** 其噪声电流直接与输出端并联：$I_{n4}$ 全部到达输出端。

**总和。** 四个噪声源互不相关，因此

$$\overline{I_{n,out}^2} = 4kT\gamma\,(g_{m1} + g_{m2} + g_{m3} + g_{m4}) = 4kT\gamma\,(2g_{m1} + 2g_{m3}) ,$$

再除以 $G_m^2 = g_{m1}^2$：

$$\overline{V_{n,in}^2}\Big|_{th} = \frac{8kT\gamma\,(g_{m1} + g_{m3})}{g_{m1}^2} = \frac{8kT\gamma}{g_{m1}}\left(1 + \frac{g_{m3}}{g_{m1}}\right).$$

因子 8 来自每对匹配管中的两个器件；负载管的噪声通过 $g_{m3}/g_{m1}$ 计入。

### 第 4 步 — 闪烁噪声与尾电流源

- **$M_1$、$M_2$：** 每个闪烁噪声源都是与差分对（differential pair）某一输入端串联的电压，（就功率而言）等效于差分输入端的一个噪声源。合计：$2K_N/[C_{ox}(WL)_1f]$。
- **$M_3$、$M_4$：** 栅极电压 $V_{n3}$ 使 $M_3$ 传导电流 $g_{m3}V_{n3}$，它像第 3 步中的噪声电流一样全部到达输出端。折算到输入端后变为 $g_{m3}V_{n3}/g_{m1}$，因此其功率要乘以 $(g_{m3}/g_{m1})^2$；$M_4$ 也是如此。合计：$2K_P(g_{m3}/g_{m1})^2/[C_{ox}(WL)_3f]$。

$$\overline{V_{n,in}^2}\Big|_{1/f} = \frac{2K_N}{C_{ox}(WL)_1f} + \frac{2K_P}{C_{ox}(WL)_3f}\left(\frac{g_{m3}}{g_{m1}}\right)^2 .$$

**尾电流源。** 其噪声在 $M_1$ 和 $M_2$ 之间平分；$M_1$ 中的一半经镜像送入输出端，$M_2$ 中的一半从输出端抽出，两者相互抵消：尾电流源噪声是共模噪声。

### 第 5 步 — 闭合环路：电容不改变输入参考噪声

把运放的全部噪声归并为一个与同相输入端串联的噪声源 $V_n$（$\overline{V_n^2}$ 由第 3–4 步给出；按图中所示极性，该输入端的电压为 $V_{in} - V_n$），并把运放视为增益为 $A_0$ 的无噪声放大器。

<!-- diagram: diagram-01.cir -->

$$
\begin{aligned}
V_{out} &= A_0\,(V_{in} - V_n - V_X) = A_0\,(V_{in} - V_n - \beta V_{out})\\
V_{out}\,(1 + \beta A_0) &= A_0\,(V_{in} - V_n)\\
V_{out} &= \frac{A_0}{1 + \beta A_0}\,(V_{in} - V_n) .
\end{aligned}
$$

$V_n$ 到达输出端的方式与 $V_{in}$ 的一部分完全相同（其符号不影响噪声功率）。把输出噪声除以闭环增益 $A_0/(1 + \beta A_0)$，得到的正是 $V_n$ 本身：**闭环电路的输入参考噪声就是运放的输入参考噪声**，与 $C_1$ 和 $C_2$ 无关。只有**输出**噪声与它们有关：当 $\beta A_0 \gg 1$ 时，$\overline{V_{n,out}^2} \approx \overline{V_n^2}\,(1 + C_2/C_1)^2$。

### 第 6 步 — 数量级估计（仅作示例）

题目没有给出尺寸，因此作为示例，取 $(W/L)_{1,2} = 50/0.5$，$(W/L)_{3,4} = 100/0.5$，$I_{SS} = 1$ mA，$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$\gamma = 2/3$，$T = 300$ K。每个器件的电流为 0.5 mA。

$$
\begin{aligned}
g_{m1} &= \sqrt{2(134\ \mu\mathrm{A/V^2})(100)(0.5\ \mathrm{mA})} = \sqrt{13.4\times10^{-6}}\ \mathrm{S} = 3.66\ \mathrm{mS},\\
g_{m3} &= \sqrt{2(38.4\ \mu\mathrm{A/V^2})(200)(0.5\ \mathrm{mA})} = \sqrt{7.68\times10^{-6}}\ \mathrm{S} = 2.77\ \mathrm{mS},\\
8kT\gamma &= 8(1.38\times10^{-23})(300)(2/3) = 2.21\times10^{-20}\ \mathrm{J},\\
\overline{V_{n,in}^2}\Big|_{th} &= \frac{2.21\times10^{-20}}{3.66\times10^{-3}}\left(1 + \frac{2.77}{3.66}\right) = 6.03\times10^{-18}\times1.757 = 1.06\times10^{-17}\ \mathrm{V^2/Hz},
\end{aligned}
$$

约为 3.3 nV/√Hz。

### 结果

电容反馈网络没有噪声，也不改变输入参考噪声，因此电路的输入参考噪声就是运放的输入参考噪声：

$$\overline{V_{n,in}^2} = \frac{8kT\gamma}{g_{m1}}\left(1 + \frac{g_{m3}}{g_{m1}}\right) + \frac{2K_N}{C_{ox}(WL)_1f} + \frac{2K_P}{C_{ox}(WL)_3f}\left(\frac{g_{m3}}{g_{m1}}\right)^2 \quad(\gamma = 2/3 \text{ for long-channel devices}),$$

它与 $C_1$ 和 $C_2$ 无关。尾电流源只贡献共模噪声。输出噪声等于该值乘以闭环增益的平方 $\approx(1 + C_2/C_1)^2$。

**常见错误。** 把输入参考噪声除以环路增益（loop gain），或者乘以 $1 + C_2/C_1$。反馈使信号和噪声按同一个闭环增益缩放；只有**输出**噪声才乘以 $(1 + C_2/C_1)^2$。

**常见错误。** 认为 $C_1$ 和 $C_2$ 会产生噪声。理想电容是无损的；与电阻反馈不同，电容网络不会引入噪声。

**常见错误。** 把电流镜的噪声 $4kT\gamma g_{m3}$ 直接加到输入对管的 $4kT\gamma/g_{m1}$ 项上，或者忘记对管带来的因子 2。折算到输入端后，每个负载器件贡献 $4kT\gamma g_{m3}/g_{m1}^2$，并且四个器件都要计入。
