# 详细步骤 - R317

**思路。** 数一数极点。栅极由理想电压源驱动时没有输入极点；对差分信号而言，尾节点是交流地，因此每个半边电路都是只有一个变化节点（即输出端）的共源级。无论是二极管连接负载还是电流源负载，都不会增加内部节点，因此该级是一阶的：其与频率有关的相位滞后趋近但永远不超过 90°，再加上 $C_{GD}$ 的右半平面零点贡献的几度。要在单位增益频率处得到 135° 的相位滞后，需要第二个极点。

### 第 1 步 — “单位增益处 135°”的含义

差分对在直流时的反相只是其增益的符号，而不是与频率有关的相移。这一要求针对的是在 $\omega_u$ 处累积的**附加相位滞后**，其中 $|A_v(j\omega_u)| = 1$；在该处有 135° 的相位滞后，正是相位裕度（phase margin）为 45° 的反馈设计所要求的。（若把直流反相计为 $-180°$，下面这些电路的总相位滞后介于 180° 与 270° 之间，因此同样不可能等于 135°。）

### 第 2 步 — 把电路简化为单个节点

栅极由零阻抗源驱动，因此输入端没有极点，$C_{GS1}$ 不起作用；尾节点是差分交流地。于是每个半边电路都是一个共源级 $M_1$：源极接地，栅极由 $V_{in}/2$ 理想驱动，唯一变化的节点是漏极（输出端）。

输出端有电阻 $R_{out}$ 和接地电容 $C_{out}$（漏极结电容、负载器件的电容以及任何负载），$C_{GD1}$ 把它连接到被驱动的栅极。

- **二极管连接负载**（$M_3$）：$R_{out} = \dfrac{1}{g_{m3}}\parallel r_{O1}\parallel r_{O3}\approx\dfrac{1}{g_{m3}}$，因此 $A_0 = g_{m1}R_{out}\approx g_{m1}/g_{m3}$。
- **电流源负载**（栅极接固定偏置的 $M_3$）：$R_{out} = r_{O1}\parallel r_{O3}$，因此 $A_0 = g_{m1}(r_{O1}\parallel r_{O3})$。

两种负载都不会引入新的节点：二极管只是输出端的 $1/g_{m3}$（外加电容），电流源只是 $r_{O3}$（外加电容）。

### 第 3 步 — 半边电路的传递函数是一阶的

设 $v_1 = V_{in}/2$ 为半边电路的栅极电压。对输出端列基尔霍夫电流定律（KCL）方程，电流经 $C_{GD1}$ 流入，经 $M_1$、$R_{out}$ 和 $C_{out}$ 流出：

$$(v_1 - V_{out})C_{GD1}s = g_{m1}v_1 + \frac{V_{out}}{R_{out}} + C_{out}s\,V_{out}.$$

合并各项：

$$
\begin{aligned}
V_{out}\left[\frac{1}{R_{out}} + (C_{out} + C_{GD1})s\right] &= -(g_{m1} - C_{GD1}s)v_1\\
A_v(s) = \frac{V_{out}}{v_1} &= -\frac{(g_{m1} - C_{GD1}s)R_{out}}{1 + R_{out}C_Ts}, \qquad C_T = C_{out} + C_{GD1},
\end{aligned}
$$

其中半边电路的增益 $V_{out}/(V_{in}/2)$ 等于差模增益（differential gain）。传递函数恰好只有**一个极点** $\omega_p = 1/(R_{out}C_T)$，以及一个右半平面零点 $\omega_z = g_{m1}/C_{GD1}$。

### 第 4 步 — 单位增益频率处的相位滞后（单极点）

忽略零点时，$A_v\approx -A_0/(1 + s/\omega_p)$，其幅值 $A_0/\sqrt{1 + (\omega/\omega_p)^2}$ 在下式处等于 1：

$$\omega_u = \omega_p\sqrt{A_0^2 - 1}.$$

单个极点的相位滞后为 $\arctan(\omega/\omega_p)$，因此

$$\phi_{lag}(\omega_u) = \arctan\sqrt{A_0^2 - 1} < 90^\circ .$$

| $A_0$ | $\omega_u$ 处的 $\phi_{lag}$ |
|---|---|
| 1.41 | 45° |
| 2 | 60° |
| 5 | 78.5° |
| 10 | 84.3° |
| 100 | 89.4° |

无论增益多大，相位滞后都只是趋近 90°，而永远不会超过它。

### 第 5 步 — 右半平面零点只增加很少的相移

零点增加的相位滞后为 $\arctan(\omega/\omega_z)$。当 $A_0$ 非常大时，$\omega_u\approx g_{m1}/\sqrt{C_T^2 - C_{GD1}^2}$，因此 $\omega_u/\omega_z = C_{GD1}/\sqrt{C_T^2 - C_{GD1}^2}$，其反正切为 $\arcsin(C_{GD1}/C_T)$，于是 $\omega_u$ 处的相位滞后趋于

$$\phi_{lag}(\omega_u)\to 90^\circ + \arcsin\frac{C_{GD1}}{C_T}.$$

要达到 135°，$C_{GD1}$ 至少要占输出端全部电容的 $\sin45^\circ\approx71\%$。但 $C_{GD1}$ 只是交叠电容（overlap capacitance），而输出端还接有 $M_1$ 和 $M_3$ 的漏极结电容（每个通常与 $C_{GD1}$ 相当或更大）、$M_3$ 自身的电容以及任何负载。因此 $C_{GD1}/C_T$ 大约只有 0.1–0.3，零点只增加约 5°–17°，远不足以补上所缺的 45°。

### 第 6 步 — 二极管连接负载离要求更远

对于二极管负载，$A_0\approx g_{m1}/g_{m3} = \sqrt{\mu_n(W/L)_1/[\mu_p(W/L)_3]}$，通常只有 1–5，因此 $\omega_u$ 处的相位滞后只有 0°–78°；若 $g_{m1}/g_{m3} < 1$，增益永远达不到单位增益，也就根本不存在单位增益频率。

### 第 7 步 — 需要什么条件

要在 $\omega_u$ 处得到 135° 的相位滞后，需要一个与 $\omega_u$ 相当的**第二个极点**：例如，一个远低于 $\omega_u$、贡献接近 90° 的主极点（dominant pole），再加上一个位于 $\omega_u$ 处、贡献 45° 的第二个极点。这需要一个额外的内部节点，例如电流镜（current mirror）负载（电流镜极点）、共源共栅（cascode）节点、第二个增益级，或驱动输入电容的电阻性信号源；而二极管连接负载和电流源负载都没有这样的节点。

### 结果

由理想电压源驱动时（没有输入极点），且对差分信号而言尾节点处于交流地，差分对的每个半边都是只有一个节点（输出端）的共源级，因此

$$A_v(s)\approx -\frac{A_0}{1 + s/\omega_p},\qquad A_0 = \frac{g_{m1}}{g_{m3}}\ \text{(diode load)}\ \text{or}\ g_{m1}(r_{O1}\parallel r_{O3})\ \text{(current-source load)},\quad \omega_p = \frac{1}{R_{out}C_{out}}.$$

单个极点产生 $\arctan(\omega/\omega_p)$ 的相位滞后；在 $\omega_u = \omega_p\sqrt{A_0^2 - 1}$ 处为 $\arctan\sqrt{A_0^2 - 1} < 90^\circ$。位于 $g_{m1}/C_{GD1}$ 的右半平面零点远高于 $\omega_u$，只增加几度。因此与频率有关的相移介于 0 与约 90° 之间（若计入反相，则介于 180° 与 270° 之间），永远不会是 135°。要达到 135°，需要在 $\omega_u$ 附近有第二个极点；而对于二极管负载，增益甚至可能达不到单位增益。

**常见错误。** 声称存在两个或更多重要的极点，例如“输入极点”或“尾节点极点”。输入由理想电压源驱动，尾节点是差分虚地（virtual ground），因此只有输出端在变化。

**常见错误。** 认为相移**过大**（例如两个极点产生 180°）。问题恰恰相反：单个极点无法提供超过 90° 的相位滞后。

**常见错误。** 把 135° 当作 $180^\circ - 45^\circ$，从而断定 $A_0 = \sqrt2$ 的单极点就能满足要求。180° 只是增益在直流时的符号；要求的是频率响应产生的 135° 相位滞后。
