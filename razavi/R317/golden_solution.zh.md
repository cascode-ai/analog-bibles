由理想电压源驱动时，栅极处没有极点；对差分信号而言，尾节点是交流地。于是每个半边电路（half circuit）都是一个共源级（common-source stage），其唯一重要的极点位于输出节点：$H(s) \approx -\dfrac{A_0}{1 + s/\omega_p}$，其中 $A_0 = g_{m1}/g_{m3}$（二极管负载）或 $g_{m1}(r_{O1}\|r_{O3})$（电流源负载），$\omega_p = 1/(R_{out}C_{out})$。
- 单个极点产生的相位滞后为 $\arctan(\omega/\omega_p)$，总是小于 90°。在单位增益频率（unity-gain frequency）$\omega_u = \omega_p\sqrt{A_0^2 - 1}$ 处，相位滞后为 $\arctan\sqrt{A_0^2 - 1} < 90°$。
- 因此，与频率有关的相移介于 0 与 90° 之间（若计入反相的 180°，则介于 180° 与 270° 之间）：永远不会是 135°。由 $C_{GD}$ 产生的右半平面零点（right-half-plane zero）位于 $g_m/C_{GD}$ 附近，远高于 $\omega_u$，只增加几度的相移。
- 对于二极管连接负载，增益 $g_{m1}/g_{m3}$ 往往接近甚至低于单位增益，因此可能根本不存在单位增益交越点。
- 要达到 135°，需要在与 $\omega_u$ 相当的频率处有第二个极点（或能产生二阶响应的电抗性负载）。
