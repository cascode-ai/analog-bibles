# 详细步骤 - R579

**思路。** 开关关断时，一部分沟道电荷落到 $C_H$ 上（**电荷注入**），而下降的栅极电压通过栅-漏交叠电容耦合到输出端（**时钟馈通**）。找出沟道电荷最大时的输入电平，把它换算成 $C_H$ 上的电压台阶，再计算电容分压引起的馈通台阶，然后进行比较。

### 第 1 步 — 沟道电荷及其最大值的位置

CK 为高电平时，开关处于深线性区（deep triode region），$V_{DS} \approx 0$，沟道是均匀的（没有 2/3 因子，该因子只适用于饱和区）。源极和漏极都约处于 $V_{in}$ 时：

$$Q_{ch} = WLC_{ox}\,(V_{GS} - V_{TH}) = WLC_{ox}\,(V_{DD} - V_{in} - V_{TH}),$$

$$V_{TH} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{in}} - \sqrt{2|\phi_F|}\right).$$

提高 $V_{in}$ 会直接减小过驱动电压（overdrive voltage），还会通过体效应使其进一步减小，因此 $Q_{ch}$ **在 $V_{in} = 0$ 时最大**，此时 $V_{SB} = 0$，$V_{TH} = V_{TH0} = 0.7$ V：

$$WLC_{ox} = (20\ \mu\mathrm{m})(0.5\ \mu\mathrm{m})(3.84\ \mathrm{fF/\mu m^2}) = 38.4\ \mathrm{fF},$$

$$Q_{ch} = (38.4\ \mathrm{fF})(3 - 0 - 0.7\ \mathrm{V}) = (38.4\ \mathrm{fF})(2.3\ \mathrm{V}) = 88.3\ \mathrm{fC}.$$

### 第 2 步 — 电荷注入误差

沟道电荷在源极与漏极之间如何分配，取决于两侧的阻抗和时钟边沿的速度。两种标准的估计：

- **最坏情况**，全部电荷都注入 $C_H$：
$$\Delta V = \frac{Q_{ch}}{C_H} = \frac{88.3\ \mathrm{fC}}{1\ \mathrm{pF}} = 88\ \mathrm{mV}.$$
- **一半**注入 $C_H$（常用的对称分配估计）：
$$\Delta V = \frac{Q_{ch}}{2C_H} = 44\ \mathrm{mV}.$$

沟道电荷由电子构成，因此 **$V_{out}$ 下降**：形成负向台阶。它与输入电平的关系（全部电荷注入 $C_H$，计入体效应）：

| $V_{in}$ (V) | $V_{TH}$ (V) | 过驱动电压（V） | $\Delta V$ (mV) |
|---|---|---|---|
| 0 | 0.700 | 2.300 | 88.3 |
| 0.5 | 0.806 | 1.695 | 65.1 |
| 1.0 | 0.893 | 1.107 | 42.5 |
| 1.5 | 0.970 | 0.530 | 20.3 |

（例如，在 $V_{in} = 1$ V 时：$V_{TH} = 0.7 + 0.45(\sqrt{1.9} - \sqrt{0.9}) = 0.7 + 0.45(1.378 - 0.949) = 0.893$ V。）误差随 $V_{in}$ 增大而减小，而且由于体效应，这种减小是非线性的，因此电荷注入不仅产生失调，还会产生增益误差和失真。

### 第 3 步 — 时钟馈通误差

交叠电容为

$$WC_{ov} = (20\ \mu\mathrm{m})(0.4\ \mathrm{fF/\mu m}) = 8\ \mathrm{fF}.$$

开关断开、输出浮空时，$WC_{ov}$ 和 $C_H$ 从栅极起构成电容分压器（capacitive divider），因此栅极阶跃 $\Delta V_{CK}$ 产生

$$\Delta V = \Delta V_{CK}\,\frac{WC_{ov}}{WC_{ov} + C_H}.$$

对于完整的时钟摆幅 $\Delta V_{CK} = V_{DD} = 3$ V（最坏情况）：

$$\Delta V = (3\ \mathrm{V})\times\frac{8\ \mathrm{fF}}{8\ \mathrm{fF} + 1000\ \mathrm{fF}} = 3\ \mathrm{V}\times7.94\times10^{-3} = 23.8\ \mathrm{mV},$$

它同样为负（时钟下降），并且**与 $V_{in}$ 无关**：是纯粹的失调。

### 第 4 步 — 比较

| 误差 | 数值 | 是否与 $V_{in}$ 有关？ |
|---|---|---|
| 电荷注入，全部注入 $C_H$（$V_{in} = 0$ 时） | 88 mV | 是（随 $V_{in}$ 升高而减小） |
| 电荷注入，一半注入 $C_H$（$V_{in} = 0$ 时） | 44 mV | 是 |
| 时钟馈通 | 24 mV | 否 |

$$\frac{88\ \mathrm{mV}}{23.8\ \mathrm{mV}} = 3.7, \qquad \frac{44\ \mathrm{mV}}{23.8\ \mathrm{mV}} = 1.9 .$$

电荷注入误差大约是时钟馈通的 3.7 倍（最坏情况）或 1.9 倍（一半分配），并且由于两者都把输出往下拉，最坏情况下的总误差约为 110 mV。电荷注入占主导，是因为它与整个栅极面积和过驱动电压成正比，而时钟馈通只与狭窄的交叠区成正比（$WC_{ov} = 8$ fF，而 $WLC_{ox} = 38.4$ fF）。恒定的馈通失调很容易消除（例如采用差分结构）；与输入有关的电荷注入才是危害更大的误差。

### 结果

最大的电荷注入误差出现在 $V_{in} = 0$ 时，此时 $V_{SB} = 0$，$V_{TH} = 0.7$ V：

$$Q_{ch} = WLC_{ox}(V_{DD} - V_{in} - V_{TH}) = 38.4\ \mathrm{fF}\times2.3\ \mathrm{V} = 88.3\ \mathrm{fC},$$

最坏情况下（全部电荷注入 $C_H$）得到 $\Delta V = 88$ mV，若一半注入 $C_H$ 则为 44 mV。它是一个负向台阶。

时钟馈通引起 $\Delta V = V_{DD}\,WC_{ov}/(WC_{ov} + C_H) = 3\ \mathrm{V}\times8\ \mathrm{fF}/1008\ \mathrm{fF} \approx 24$ mV，与 $V_{in}$ 无关。

电荷注入误差约为时钟馈通的 3.7×（按一半分配的假设约为 1.9×）。它还会随 $V_{in}$ 升高而减小（考虑体效应时减小得更快），从而产生增益误差和非线性，而时钟馈通只是一个恒定的失调。

**常见错误。** 使用 $Q_{ch} = WLC_{ox}V_{DD}$（忘记了 $V_{in}$ 和 $V_{TH}$），得到 115 mV；或者像对待饱和器件那样乘以 2/3 的因子。导通的开关处于深线性区，其电荷由过驱动电压 $V_{DD} - V_{in} - V_{TH}$ 决定。

**常见错误。** 在某个中间输入电平下计算电荷注入，却称之为最大值；或者声称两种误差都与输入无关。电荷注入在输入最低时最大，并随 $V_{in}$ 增大而减小；只有时钟馈通与输入无关。

**常见错误。** 断定时钟馈通是较大的误差。交叠电容（0.4 fF/μm，即 8 fF）远小于沟道的栅电容（38.4 fF），因此馈通台阶（24 mV）要小好几倍。
