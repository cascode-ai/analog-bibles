# 详细步骤 - R395

**思路。** $M_1$ 是从栅极节点 N 到输出端的共源放大器，源极跟随器 $M_2$ 检测输出电压并把电流送回 N：这是电压并联（电压-电流）反馈。电流源理想且 $\lambda = 0$ 时，输出节点的电阻为无穷大，因此环路增益为无穷大，N 为虚地，由此可立即得到 $Z_{in}$ 和增益；$Z_{out}$ 则是 $R_{out,open}/(1 + T)$ 的极限，并用直接列 KCL 方程的方法加以验证。

### 第 1 步 — 小信号模型（small-signal model）

把 $R_S$ 右侧的节点（$M_1$ 的栅极、$M_2$ 的源极）记为 N。于是：

- $R_S$ 接在 in 与 N 之间；
- $M_2$：电流 $g_{m2}(v_{out} - v_N)$ 从 $V_{DD}$（交流地）流入 N；
- $M_1$：电流 $g_{m1}v_N$ 从 out 流向地；
- 两个电流源 $I_1$ 都相当于开路；不含 $r_O$，没有体效应（body effect），也没有栅极电流。

### 第 2 步 — 反馈拓扑与环路增益

$M_2$ 的栅极检测输出**电压**，其源极把**电流**送回 N：这是**电压并联反馈**。它是负反馈：$v_N$ 升高会使 $M_1$ 把 $v_{out}$ 拉低，跟随器又把 N 拉回来。

令 $V_{in} = 0$，在 $M_2$ 的栅极处断开环路（由于栅极不吸取电流，这样做是精确的）。跟随器产生非零的 $v_N$，$M_1$ 把它转换为电流 $g_{m1}v_N$，该电流必须流入输出节点。该节点只连接理想电流源、$M_1$ 的漏极（$\lambda = 0$）和 $M_2$ 的栅极，因此 $R_{out,open}$ 为无穷大，且

$$T \to \infty .$$

为处理极限情况，设想在输出端与地之间接一个大电阻 $R_L$（$R_{out,open} = R_L$），最后再令 $R_L \to \infty$。

### 第 3 步 — 输入阻抗：虚地

**反馈观点。** 环路断开时，从 N 看进去的阻抗是 $M_2$ 的源极阻抗 $1/g_{m2}$；在电流驱动下，环路增益为 $T' = g_{m1}R_L$（空载跟随器具有单位增益）。输入端的并联反馈给出

$$Z_{in} = \frac{1/g_{m2}}{1 + g_{m1}R_L} \;\xrightarrow{R_L\to\infty}\; 0 .$$

**直接验证。** 向 N 注入 $i_x$。输出节点的 KCL（$R_L \to \infty$）中只剩下 $M_1$ 的电流，因此 $g_{m1}v_N = 0$，即 $v_N = 0$；N 点的 KCL 给出 $i_x + g_{m2}(v_{out} - v_N) = 0$，因此 $v_{out} = -i_x/g_{m2}$。N 保持在交流地，而电流由 $M_2$ 吸收：

$$Z_{in} = \frac{v_N}{i_x} = 0 .$$

N 是**虚地**；$V_{in}$ 看到的阻抗就是 $R_S$。

### 第 4 步 — 电压增益

经 $R_S$ 流入虚地的电流为 $V_{in}/R_S$，只有 $M_2$ 能把它引走。对 N 列 KCL：

$$
\begin{aligned}
\frac{V_{in}}{R_S} + g_{m2}(V_{out} - 0) &= 0\\
\frac{V_{out}}{V_{in}} &= -\frac{1}{g_{m2}R_S}.
\end{aligned}
$$

用反馈的语言来说，闭环跨阻（transimpedance）趋于 $-1/\beta$，其中 $\beta = g_{m2}$（每伏输出电压送回的电流），且 $V_{out}/V_{in} = (-1/g_{m2})(1/R_S)$。

### 第 5 步 — 输出阻抗

**直接计算。** 令 $V_{in} = 0$（$R_S$ 接在 N 与地之间），在输出端施加测试电压 $v_X$，由 N 点的 KCL 得到跟随器的输出：

$$
\begin{aligned}
g_{m2}(v_X - v_N) &= \frac{v_N}{R_S}\\
v_N &= \frac{g_{m2}R_S}{1 + g_{m2}R_S}\,v_X .
\end{aligned}
$$

测试电流只能流入 $M_1$：

$$I_X = g_{m1}v_N = \frac{g_{m1}g_{m2}R_S}{1 + g_{m2}R_S}\,v_X ,$$

$$Z_{out} = \frac{v_X}{I_X} = \frac{1 + g_{m2}R_S}{g_{m1}g_{m2}R_S} = \frac{1}{g_{m1}} + \frac{1}{g_{m1}g_{m2}R_S}.$$

**反馈观点。** 接入 $R_L$ 后，开环输出电阻为 $R_L$，环路增益（N 以 $R_S$ 为负载）为 $T = g_{m1}R_L\,g_{m2}R_S/(1 + g_{m2}R_S)$，因此

$$Z_{out} = \frac{R_L}{1 + g_{m1}R_L\dfrac{g_{m2}R_S}{1 + g_{m2}R_S}} \;\xrightarrow{R_L\to\infty}\; \frac{1 + g_{m2}R_S}{g_{m1}g_{m2}R_S},$$

结果相同：$Z_{out}$ 保持有限，因为 $R_{out,open}$ 与 $T$ 以相同的速率增大。

### 结果

$$Z_{in} = 0\ (\text{virtual ground}), \qquad Z_{out} = \frac{1 + g_{m2}R_S}{g_{m1}g_{m2}R_S} = \frac{1}{g_{m1}} + \frac{1}{g_{m1}g_{m2}R_S}, \qquad \frac{V_{out}}{V_{in}} = -\frac{1}{g_{m2}R_S}.$$

该电路是环路增益为无穷大的电压并联反馈放大器（$\lambda = 0$，电流源理想）。N 被保持在交流地，输入电流 $V_{in}/R_S$ 由跟随器 $M_2$ 吸收，输出阻抗是 $R_{out,open}/(1 + T)$ 在 $R_{out,open}$ 趋于无穷大时的极限。

**常见错误。** 给出正的增益。为了把输入电流从虚地引走，$M_2$ 需要 $V_{out}$ **低于** N：增益为 $-1/(g_{m2}R_S)$。

**常见错误。** 给出 $Z_{in} = 1/g_{m2}$。那是**开环**值；无穷大的环路增益把它除到了零。

**常见错误。** 断定输出阻抗为无穷大，或者认为反馈会使其升高。电压检测会使它降低到 $1/g_{m1} + 1/(g_{m1}g_{m2}R_S)$。还要注意，$M_2$ 是源极跟随器（栅极接输出端，源极接 N），而不是共栅器件。
