# 详细步骤 - R453

**思路。** 把每个晶体管的闪烁噪声表示为与其栅极串联的电压 $V_{n,j}$，其谱密度为 $\overline{V_{n,j}^2} = K/(C_{ox}W_jL_jf)$；它使漏极电流变化 $g_{mj}V_{n,j}$。追踪该电流到输出端，并与输入端每伏电压产生的电流 $g_{m1}$ 相比较，就得到每个器件折合到输入端的权重；互不相关的噪声功率直接相加。由对称性，$M_1 = M_2$，$M_3 = M_4$，$M_5 = M_6$，$M_7 = M_8$，$M_9 = M_{10}$。

### 第 1 步 — 输入信号如何到达输出端

对于差分输入 $v_{in}$，$M_1$ 和 $M_2$ 的电流分别变化 $\pm g_{m1}v_{in}/2$。每个折叠节点看进一个共源共栅管的源极，阻抗约为 $1/g_{m5}$，远小于 $r_{O1}\parallel r_{O7}$，因此 $M_1$ 的信号电流基本上全部取自流经 $M_5$ 到输出端的电流。于是差分输出电流的大小为 $g_{m1}v_{in}$，输出电压等于该电流乘以 $R_{out}$。

**半边电路（half circuit）。** 把折叠节点记为 F，$M_9$ 的漏极（$M_3$ 的源极）记为 B，作为虚地（virtual ground）的尾电流节点记为 P。$M_1$ 从 F 向 P 抽取电流 $g_{m1}v_{g1}$，并接有 $r_{O1}$；PMOS 电流源 $M_7$ 的源极接交流地，它向 F 注入电流 $g_{m7}v_{sg7} = -g_{m7}v_{g7}$，并有 $r_{O7}$ 从 F 接到地；PMOS 共源共栅管 $M_5$ 接在 F 与输出端之间，NMOS 共源共栅管 $M_3$ 从输出端向下接到 B，$M_9$ 从 B 向地抽取电流 $g_{m9}v_{g9}$，并接有 $r_{O9}$。闪烁噪声电压 $V_{n1}$、$V_{n7}$、$V_{n9}$ 分别与 $M_1$、$M_7$、$M_9$ 的栅极串联。

**折合规则。** 若噪声电流 $I_n$ 以与信号电流相同的方式到达输出端（经过同一输出节点和 $R_{out}$），则它等效于输入电压

$$V_{n,in} = \frac{I_n}{g_{m1}} .$$

### 第 2 步 — 输入对管 $M_1$、$M_2$

$V_{n1}$ 和 $V_{n2}$ 与输入栅极串联，因此本身就已经是输入参考噪声（权重为 1），并且由于互不相关，它们的功率直接相加：

$$\overline{V_{n,in}^2}\Big|_{M_1,M_2} = 2\,\frac{K_N}{C_{ox}(WL)_1f} .$$

### 第 3 步 — PMOS 电流源 $M_7$、$M_8$

$V_{n7}$ 使 $M_7$ 注入 F 的电流发生变化，其大小为 $I_{n7} = g_{m7}V_{n7}$。F 看进 $M_5$ 源极的低阻抗，因此 $I_{n7}$ 经 $M_5$ 流到输出端的方式与 $M_1$ 的信号电流**完全相同**，于是

$$V_{n,in}\Big|_{M_7} = \frac{g_{m7}V_{n7}}{g_{m1}}, \qquad \overline{V_{n,in}^2}\Big|_{M_7} = \frac{g_{m7}^2}{g_{m1}^2}\cdot\frac{K_P}{C_{ox}(WL)_7f} .$$

再加上另一侧的 $M_8$：

$$\overline{V_{n,in}^2}\Big|_{M_7,M_8} = 2\,\frac{K_P}{C_{ox}(WL)_7f}\cdot\frac{g_{m7}^2}{g_{m1}^2} .$$

### 第 4 步 — NMOS 电流源 $M_9$、$M_{10}$

$V_{n9}$ 使 $M_9$ 的电流变化 $I_{n9} = g_{m9}V_{n9}$，该电流取自 $M_3$ 的源极，而该处阻抗（$\approx 1/g_{m3}$）远小于 $r_{O9}$。因此 $I_{n9}$ 基本上全部经 $M_3$ 从输出端抽出，同样与信号电流的路径相同：

$$\overline{V_{n,in}^2}\Big|_{M_9,M_{10}} = 2\,\frac{K_N}{C_{ox}(WL)_9f}\cdot\frac{g_{m9}^2}{g_{m1}^2} .$$

### 第 5 步 — 共源共栅管 $M_3$–$M_6$：可以忽略

$M_3$ 的栅极噪声 $V_{n3}$ 驱动的是一个以 $r_{O9}$ 为源极负反馈电阻的级，因此在输出端接交流地时，它产生

$$I_{out} = \frac{g_{m3}V_{n3}}{1 + g_{m3}r_{O9}} \approx \frac{V_{n3}}{r_{O9}} \qquad (g_{m3}r_{O9} \gg 1)$$

（源极只是跟随栅极噪声）。折合到输入端：

$$V_{n,in}\Big|_{M_3} \approx \frac{V_{n3}}{g_{m1}r_{O9}}, \qquad \overline{V_{n,in}^2}\Big|_{M_3} \approx \frac{\overline{V_{n3}^2}}{(g_{m1}r_{O9})^2} .$$

因子 $1/(g_{m1}r_{O9})^2$ 的典型值为 $10^{-3}$–$10^{-4}$。同理，以 $r_{O7}\parallel r_{O1}$ 为源极负反馈电阻的 $M_5$ 被抑制了 $[g_{m1}(r_{O7}\parallel r_{O1})]^2$ 倍。两者在低频下都可以忽略。

### 第 6 步 — 尾电流管 $M_{11}$：只产生共模噪声

$M_{11}$ 的噪声电流在 $M_1$ 和 $M_2$ 之间平均分配，使两个输出端同样变化，因此在匹配的电路中，它对差模噪声没有贡献。

### 第 7 步 — 总输入参考闪烁噪声

把第 2–4 步的结果相加：

$$
\overline{V_{n,in}^2}\Big|_{1/f} \approx \frac{2}{C_{ox}f}\left[\frac{K_N}{(WL)_1} + \frac{K_P}{(WL)_7}\frac{g_{m7}^2}{g_{m1}^2} + \frac{K_N}{(WL)_9}\frac{g_{m9}^2}{g_{m1}^2}\right].
$$

$M_7$ 和 $M_8$ 的电流是输入对管电流**加上**共源共栅支路电流，因此它们的 $g_m$ 往往较大，通常是重要的噪声来源。它们（以及 $M_9$、$M_{10}$）应采用长沟道和大的过驱动电压（overdrive voltage）以减小 $g_m$，并采用较大的面积 $WL$；输入对管则应具有较大的 $g_{m1}$ 和较大的面积。

### 结果

$$\overline{V_{n,in}^2}\Big|_{1/f} \approx \frac{2}{C_{ox}f}\left[\frac{K_N}{(WL)_1} + \frac{K_P}{(WL)_7}\frac{g_{m7}^2}{g_{m1}^2} + \frac{K_N}{(WL)_9}\frac{g_{m9}^2}{g_{m1}^2}\right]$$

（其中 $M_1 = M_2$，$M_7 = M_8$，$M_9 = M_{10}$）。输入对管的噪声直接出现；电流源 $M_7$–$M_{10}$ 以 $(g_m/g_{m1})^2$ 加权；共源共栅管 $M_3$–$M_6$ 被抑制了 $(g_{m1}r_O)^2$ 倍，可以忽略；尾电流管 $M_{11}$ 只产生共模噪声。

**常见错误。** 忘记因子 2：每一半电路都包含每个噪声源的一个独立副本。

**常见错误。** 用 $1/g_{m7}^2$ 或 $g_{m7}/g_{m1}$ 给电流源加权。$M_7$ 的栅极噪声变为电流 $g_{m7}V_{n7}$，输入端要通过 $g_{m1}$ 重现这一电流，而功率按平方变化，即 $(g_{m7}/g_{m1})^2$。

**常见错误。** 把共源共栅管 $M_3$–$M_6$ 当作主要噪声来源，或者把尾电流管 $M_{11}$ 的噪声计入差模噪声。共源共栅管的源极接有大电阻作为负反馈，而在匹配电路中尾电流管的噪声是纯共模的。
