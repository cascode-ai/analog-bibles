# Golden Solution - R453

## Reference answer

$\overline{V^2_{n,in}}\Big|_{1/f} \approx \dfrac{2}{C_{ox}f}\left[\dfrac{K_N}{(WL)_{1}} + \dfrac{K_P}{(WL)_{7}}\dfrac{g_{m7}^2}{g_{m1}^2} + \dfrac{K_N}{(WL)_{9}}\dfrac{g_{m9}^2}{g_{m1}^2}\right]$ (with $M_1 = M_2$, $M_7 = M_8$, $M_9 = M_{10}$).

- Input pair $M_1$, $M_2$: their gate-referred noise appears directly at the input (factor 2 for the two devices).
- $M_7$, $M_8$ (PMOS current sources at the folding nodes): a gate voltage $v_n$ produces a current $g_{m7}v_n$ that flows through the cascodes to the output exactly like the signal current $g_{m1}v_{in}$; referred to the input it is multiplied by $(g_{m7}/g_{m1})^2$.
- $M_9$, $M_{10}$ (NMOS current sources at the bottom): likewise weighted by $(g_{m9}/g_{m1})^2$.
- Cascodes $M_3$–$M_6$ contribute negligibly at low frequencies (degenerated by high source impedances); the tail $M_{11}$ produces only common-mode noise.
- Since $M_7$/$M_8$ carry both the input and the cascode-branch currents, their $g_m$ is large and they are important contributors; long, wide devices help.
