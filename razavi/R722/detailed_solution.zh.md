# 详细步骤 - R722

**思路。** 沿这一行把导线编号为 1–8；奇数号导线承载电源电流，偶数号导线承载地（返回）电流，每根都是总电流 $I$ 的四分之一。现在每对相邻导线中的电流都**方向相反**，因此每个互感都从自感中减去。先计算每根导线上的电压，再由功率（能量）关系 $L_{eq}I^2 = \sum_{i,j}L_{ij}I_iI_j$ 求出每种连接以及整个回路的等效电感。

### 第 1 步 — 电流与电感矩阵

取所有导线的参考方向相同（封装 → 芯片）：电源线 1、3、5、7 流过 $+I/4$，地线 2、4、6、8 流过 $-I/4$。由于 $L = 4$ nH，且只有相邻导线之间存在 $M = 2$ nH，这一行共有 **7 个相邻对**（1–2、2–3、…、7–8），**每一对都是电源–地对**，电流方向相反；没有两根电源线（或两根地线）相邻。奇数号导线并联在封装电源与片上电源节点之间，偶数号导线并联在片上地与封装地之间。导线 $k$ 两端的压降为

$$V_k = L\frac{dI_k}{dt} + M\sum_{j\ \text{adjacent}}\frac{dI_j}{dt}.$$

### 第 2 步 — 每根导线上的电压

记 $\dot I = dI/dt$：

- **内部导线**（2 到 7）有两个电流方向相反的相邻导线。对于内部的电源线（例如导线 3）：
$$V_3 = L\frac{\dot I}{4} + M\left(-\frac{\dot I}{4}\right) + M\left(-\frac{\dot I}{4}\right) = (L - 2M)\frac{\dot I}{4} = (4 - 4)\frac{\dot I}{4} = 0 ,$$
相邻导线的磁通恰好抵消了该导线自身的磁通（这里 $2M = L$）。
- **端部导线**（1 和 8）只有一个电流方向相反的相邻导线。对于导线 1：
$$V_1 = (L - M)\frac{\dot I}{4} = \frac{4 - 2}{4}\dot I = 0.5\ \mathrm{nH}\cdot\dot I ,$$
导线 8（地）的压降大小同样为 $0.5\ \mathrm{nH}\cdot\dot I$，符号与返回电流一致。

### 第 3 步 — 每种连接的等效电感

**电源连接。** 输入四根电源线的功率为 $P = \sum V_kI_k = \frac{I}{4}(V_1 + V_3 + V_5 + V_7)$，其中 $V_1 = 0.5\,\dot I$ nH，$V_3 = V_5 = V_7 = 0$：

$$L_{V,eff}\,I\dot I = \frac{I}{4}(0.5 + 0 + 0 + 0)\ \mathrm{nH}\cdot\dot I \;\Longrightarrow\; L_{V,eff} = 0.125\ \mathrm{nH}.$$

**地连接。** 由对称性（导线 8 是端部导线，导线 2、4、6 是内部导线），$L_{G,eff} = 0.125$ nH。

这些有效值包含了与另一种连接之间的耦合，这正是电路实际感受到的电感。

### 第 4 步 — 完整的电源–地回路

- **单独的电源组。** 没有两根电源线相邻，因此是四根 4 nH 导线并联：
$$L_{VV} = \frac{4L}{16} = \frac{16}{16} = 1\ \mathrm{nH}.$$
- **单独的地线组。** 同样 $L_{GG} = 1$ nH。
- **两组之间的耦合。** 全部 7 个相邻对都是电流 $I/4$ 方向相反的电源–地对：
$$M_{VG} = 7\times M\times\frac14\times\frac14 = \frac{7\times2}{16} = 0.875\ \mathrm{nH}.$$

对于方向相反的电流，互感项要被减去：

$$L_{loop} = L_{VV} + L_{GG} - 2M_{VG} = 1 + 1 - 2(0.875) = 0.25\ \mathrm{nH}.$$

**验算。** 第 3 步中每种连接的值相加得到同样的总值，$0.125 + 0.125 = 0.25$ nH ✓；用矩阵计算，对角元给出 $8\times4 = 32$，7 个反向对给出 $7\times2\times2\times(-1) = -28$，因此 $(32 - 28)/16 = 0.25$ nH。

### 第 5 步 — 与分组排列的比较

| 排列方式 | 单独的电源组 | 回路电感 | 每种连接（有效值） |
|---|---|---|---|
| 分组（V V V V G G G G） | 1.75 nH | 3.25 nH | ≈ 1.6 nH |
| 交替（V G V G …） | 1 nH | **0.25 nH** | **0.125 nH** |

交错排列使回路电感减小 $3.25/0.25 = 13$ 倍。在分组版图（layout）中，互感是一种不利因素（同方向的相邻电流使磁通相加）；而在这里它是有利因素，因为每根导线的返回电流就在它旁边流动，磁场在很大程度上相互抵消。这就是高速芯片上电源焊盘与地焊盘交替排列的原因。

**电流分配。** 题目假设电流相等。若让电流按使各并联导线压降相等的方式分配（网络的精确解），回路电感会更低，约为 0.13 nH，结论相同。

### 结果

电源线与地线交替排列（且电流平均分配）时，电源加地回路的电感为

$$L_{loop} = \frac{4L}{16} + \frac{4L}{16} - 2\cdot\frac{7M}{16} = 1 + 1 - 1.75 = 0.25\ \mathrm{nH},$$

即每种连接的有效电感约为 **0.125 nH**：内部导线上完全没有压降（$L - 2M = 0$），只有两根端部导线（$L - M$）有贡献。这比分组排列时（3.25 nH）小约 13 倍。

**常见错误。** 对相邻的电源线和地线把互感相加。它们的电流方向相反，因此互感应**相减**。

**常见错误。** 认为每根导线都有两个电流方向相反的相邻导线，这会得到恰好为零的结果。两根端部导线只有一个相邻导线，压降为 $(L - M)I/4$；正是它们决定了剩余的 0.25 nH 回路电感。

**常见错误。** 把四对电源–地导线当作相互独立的回路（每个 $2L - 2M = 4$ nH，四个并联得到 1 nH）。这忽略了每根内部导线与其**另一侧**相邻导线之间的耦合，而这一耦合抵消了它剩余的磁通（得到 $L - 2M = 0$ 而不是 $L - M$），也正是交错排列的主要好处。
