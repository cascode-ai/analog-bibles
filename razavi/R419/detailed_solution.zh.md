# 详细步骤 - R419

**思路。** 沿环路从输入节点出发，经 $M_1$、二极管连接的 $M_3$（与 $C_1$ 并联）和镜像管 $M_2$ 回到输入节点，说明返回的电流与输入电压同相（正反馈）。然后由 $Z_{in} = Z_{open}/(1 - T)$ 求出 $Z_{in}$，用基尔霍夫电流定律（KCL）直接验证，并考察 $C_1$ 在输入端变成了什么元件：它实际上并不是负电容。

### 第 1 步 — 小信号模型（small-signal model）

把输入节点（$M_1$ 的栅极、$M_2$ 的漏极、$I_1$ 的上端）记为 X，把 $M_1$ 的漏极（$M_2$、$M_3$ 的栅极）记为 D。$\lambda = \gamma = 0$，理想的 $I_1$ 相当于开路，$V_{DD}$ 为交流地：

- $M_1$：从 D 流向地的电流 $g_{m1}v_X$。
- $M_3$（二极管连接）：从 D 到交流地的电导 $g_{m3}$；加上 $C_1$，D 处的导纳为 $Y_D = g_{m3} + sC_1$。
- $M_2$：向 X 送入 $g_{m2}v_{SG2} = g_{m2}(0 - v_D)$。

X 上没有连接其他元件，因此 X 处的开环阻抗为无穷大。

### 第 2 步 — 环路及其极性

$$
\begin{aligned}
\text{KCL at D:}\quad Y_Dv_D + g_{m1}v_X &= 0\ \Longrightarrow\ v_D = -\frac{g_{m1}}{g_{m3} + sC_1}\,v_X,\\
\text{current from } M_2 \text{ into X:}\quad i_{2} &= -g_{m2}v_D = \frac{g_{m1}g_{m2}}{g_{m3} + sC_1}\,v_X .
\end{aligned}
$$

低频时 $i_2$ 与 $v_X$ 同号：X 升高使 $M_1$ 把 D 拉低，从而使 $M_2$ 导通得更强，向 X 推入**更多**电流。这就是**正反馈**。

**回归比。** 在 X 与地之间临时接入电阻 $R$，于是 $Z_{open} = R$；在 $M_2$ 的电流处断开环路：注入 X 的测试电流 $i_t$ 产生 $v_X = Ri_t$，环路向 X 送回 $i_2 = \dfrac{g_{m1}g_{m2}}{g_{m3} + sC_1}Ri_t$，**方向相同**。按正反馈的符号约定，

$$T(s) = \frac{g_{m1}g_{m2}R}{g_{m3} + sC_1} .$$

### 第 3 步 — 由反馈关系求 $Z_{in}$

由于返回的电流与注入的电流**相加**，

$$Z_{in} = \frac{Z_{open}}{1 - T(s)} = \frac{R}{1 - \dfrac{g_{m1}g_{m2}R}{g_{m3} + sC_1}} = \frac{R\,(g_{m3} + sC_1)}{g_{m3} + sC_1 - g_{m1}g_{m2}R} .$$

去掉临时电阻（$R \to \infty$）：

$$Z_{in} = \lim_{R\to\infty}\frac{g_{m3} + sC_1}{(g_{m3} + sC_1)/R - g_{m1}g_{m2}} = -\frac{g_{m3} + sC_1}{g_{m1}g_{m2}} .$$

必须保留复数形式的 $T(s)$；只用其幅值会丢掉与频率有关的项。

### 第 4 步 — 直接用 KCL 验证

加电压 $v_X$，设 $I_X$ 为测试源推入 X 的电流。流入 X 的其他电流只有 $i_2$，且没有电流流出（栅极和理想的 $I_1$）：

$$
\begin{aligned}
I_X + \frac{g_{m1}g_{m2}}{g_{m3} + sC_1}\,v_X &= 0\\
I_X &= -\frac{g_{m1}g_{m2}}{g_{m3} + sC_1}\,v_X\\
Z_{in} = \frac{v_X}{I_X} &= -\frac{g_{m3} + sC_1}{g_{m1}g_{m2}},\qquad Y_{in} = -\frac{g_{m1}g_{m2}}{g_{m3} + sC_1} .
\end{aligned}
$$

测试源抬高该节点电压时，反而必须**吸收**电流：这正是负阻抗的标志。

### 第 5 步 — $C_1$ 变成了什么元件？

$$Z_{in} = \underbrace{-\frac{g_{m3}}{g_{m1}g_{m2}}}_{\text{negative resistance}} + \underbrace{s\left(-\frac{C_1}{g_{m1}g_{m2}}\right)}_{sL,\ L\,=\,-C_1/(g_{m1}g_{m2})} .$$

- 第一项是**负电阻** $-\dfrac{1}{g_{m1}}\cdot\dfrac{g_{m3}}{g_{m2}}$（对于 1:1 镜像，为 $-1/g_{m1}$）。
- 第二项与 $s$ 成正比：是一个**电感** $L = -C_1/(g_{m1}g_{m2})$（单位 F/S² = H），且为负值。

因此 $C_1$ 变成了**负电感**，而不是负电容：该环路的作用就像一个回转器，把 D 处的导纳（$g_{m3} + sC_1$）倒置为 X 处的阻抗，并因正反馈而带一个负号。其电抗 $-\omega C_1/(g_{m1}g_{m2})$ 与电容的电抗一样为负，但随 $\omega$ 增大，而电容的电抗 $-1/(\omega C)$ 随频率减小；**负**电容的电抗则应为 $+1/(\omega|C|)$。两者都不符合。

**并联形式。** 当 $\omega C_1 \ll g_{m3}$ 时：

$$Y_{in} = -\frac{g_{m1}g_{m2}}{g_{m3}}\cdot\frac{1}{1 + sC_1/g_{m3}} \approx -\frac{g_{m1}g_{m2}}{g_{m3}} + s\,\frac{g_{m1}g_{m2}C_1}{g_{m3}^2},$$

即一个负电导与一个**正**电容并联。无论用哪种描述，图示电路都不呈现负电容：跨接在二极管连接器件上的 $C_1$ 使返回的电流随频率**下降**，从而产生感性（inductive）项。（负电容要求返回的电流按 $s\,v_X$ **增长**，例如用电容把输入驱动的信号耦合到一个低阻抗节点。）

### 结果

$$Z_{in} = -\frac{g_{m3} + sC_1}{g_{m1}g_{m2}} = -\frac{g_{m3}}{g_{m1}g_{m2}} - \frac{sC_1}{g_{m1}g_{m2}},\qquad Y_{in} = -\frac{g_{m1}g_{m2}}{g_{m3} + sC_1}.$$

正反馈（在输入端临时接入电阻 $R$ 时，环路传输为 $T = g_{m1}g_{m2}R/(g_{m3} + sC_1)$，$R \to \infty$ 时 $Z_{in} = R/(1 - T)$）产生一个负电阻 $-g_{m3}/(g_{m1}g_{m2})$ 与一个**负电感** $L = -C_1/(g_{m1}g_{m2})$ 的串联。图示电路并不产生负电容：由 $C_1$ 产生的元件，其电抗与 $\omega$ 成正比。等价地，低频时输入端是一个负电导 $-g_{m1}g_{m2}/g_{m3}$ 与一个正电容 $g_{m1}g_{m2}C_1/g_{m3}^2$ 的并联。

**常见错误。** 假设为负反馈，得到正的 $Z_{in}$。$M_1$ 反相一次，PMOS 电流镜（current mirror）又反相一次，因此返回 X 的电流与 $v_X$ 同相。

**常见错误。** 没有注意到 $M_3$ 是二极管连接的。漏掉其 $g_{m3}$ 会丢掉负电阻，并改变频率特性。

**常见错误。** 把 $-sC_1/(g_{m1}g_{m2})$ 称为“负电容 $C_1/(g_{m1}g_{m2})$”。**阻抗**中与 $s$ 成正比的项是电感（单位为亨利），这里是负电感。
