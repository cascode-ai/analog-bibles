$Z_{in} = -\dfrac{g_{m3} + sC_1}{g_{m1}g_{m2}} = -\dfrac{g_{m3}}{g_{m1}g_{m2}} - \dfrac{sC_1}{g_{m1}g_{m2}}$（等价地，$Y_{in} = -\dfrac{g_{m1}g_{m2}}{g_{m3} + sC_1}$）。题目的前提不成立：按图示接法，该电路并不产生负电容。正反馈由 $C_1$ 产生的元件是一个负电感 $L = -C_1/(g_{m1}g_{m2})$，它与一个负电阻串联。

- 项 $-sC_1/(g_{m1}g_{m2})$ 与负电阻 $-g_{m3}/(g_{m1}g_{m2}) = -(1/g_{m1})(g_{m3}/g_{m2})$ 串联。它是电感 $L = -C_1/(g_{m1}g_{m2})$ 的阻抗：该环路相当于一个带符号反转的回转器（gyrator），把 $C_1$ 变成 $-L$。其电抗 $-\omega C_1/(g_{m1}g_{m2})$ 为负，与电容的电抗一样，但它与 ω 成正比，而不是与 $1/\omega$ 成正比。
- 若用并联形式表示，低频时 $Y_{in} \approx -g_{m1}g_{m2}/g_{m3} + s\,g_{m1}g_{m2}C_1/g_{m3}^2$：一个负电导与一个正电容并联。两种形式中都不存在负电容。
- 环路：$M_1$（栅极接输入节点）→ 节点 D → 镜像管 $M_2$ → 回到输入节点；在节点 D，二极管连接（diode-connected）的 $M_3$ 与 $C_1$ 并联，阻抗为 $1/(g_{m3} + sC_1)$。
- 加测试电压 $V_x$：$M_1$ 从 D 抽取 $g_{m1}V_x$ → $V_D = -g_{m1}V_x/(g_{m3} + sC_1)$；$M_2$ 向输入节点送入 $-g_{m2}V_D = g_{m1}g_{m2}V_x/(g_{m3} + sC_1)$，与 $V_x$ 同相（正反馈）。测试源必须吸收这一电流：$I_x = -g_{m1}g_{m2}V_x/(g_{m3} + sC_1)$。
- 从反馈的角度看：输入端的开环阻抗为无穷大（栅极以及理想的 $I_1$）。在输入端与地之间临时接入电阻 $R$，回归比（return ratio）为 $T(s) = g_{m1}g_{m2}R/(g_{m3} + sC_1)$（正反馈），因此 $Z_{in} = R/(1 - T(s))$，当 $R \to \infty$ 时趋于 $-(g_{m3} + sC_1)/(g_{m1}g_{m2})$。（必须保留复数形式的 $T(s)$；若只用 $|T|$，就会丢掉电抗项。）
