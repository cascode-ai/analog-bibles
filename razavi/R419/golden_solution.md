# Golden Solution - R419

## Reference answer

$Z_{in} = -\dfrac{g_{m3} + sC_1}{g_{m1}g_{m2}} = -\dfrac{g_{m3}}{g_{m1}g_{m2}} - \dfrac{sC_1}{g_{m1}g_{m2}}$ (equivalently $Y_{in} = -\dfrac{g_{m1}g_{m2}}{g_{m3} + sC_1}$). The premise is false: as drawn, the circuit does not produce a negative capacitance. The component that the positive feedback creates from $C_1$ is a negative inductance $L = -C_1/(g_{m1}g_{m2})$, in series with a negative resistance.

- The term $-sC_1/(g_{m1}g_{m2})$ is in series with the negative resistance $-g_{m3}/(g_{m1}g_{m2}) = -(1/g_{m1})(g_{m3}/g_{m2})$. It is the impedance of $L = -C_1/(g_{m1}g_{m2})$: the loop acts as a gyrator with a sign inversion, turning $C_1$ into the negative inductance $L$. Its reactance $-\omega C_1/(g_{m1}g_{m2})$ is negative, like a capacitor's, but proportional to ω, not to $1/\omega$.
- In parallel form, at low frequencies $Y_{in} \approx -g_{m1}g_{m2}/g_{m3} + s\,g_{m1}g_{m2}C_1/g_{m3}^2$: a negative conductance in parallel with a positive capacitance. In neither form is there a negative capacitance.
- Loop: $M_1$ (gate at the input node) → node D ($M_3$ diode-connected, in parallel with $C_1$: impedance $1/(g_{m3} + sC_1)$) → mirror $M_2$ back into the input node.
- Test voltage $V_x$: $M_1$ draws $g_{m1}V_x$ from D → $V_D = -g_{m1}V_x/(g_{m3} + sC_1)$; $M_2$ delivers $-g_{m2}V_D = g_{m1}g_{m2}V_x/(g_{m3} + sC_1)$ into the input node, in phase with $V_x$ (positive feedback). The test source must absorb it: $I_x = -g_{m1}g_{m2}V_x/(g_{m3} + sC_1)$.
- Feedback view: the open-loop impedance at the input is infinite (gate, ideal $I_1$). Placing a temporary resistor $R$ from the input to ground, the return ratio is $T(s) = g_{m1}g_{m2}R/(g_{m3} + sC_1)$ (positive feedback), so $Z_{in} = R/(1 - T(s))$, which tends to $-(g_{m3} + sC_1)/(g_{m1}g_{m2})$ as $R \to \infty$. (The complex $T(s)$ must be kept; using $|T|$ would lose the reactive term.)
