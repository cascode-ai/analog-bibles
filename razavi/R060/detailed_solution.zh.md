# 详细步骤 - R060

**思路。** 分别处理两个实验。对于负的漏极电压，利用 MOSFET 的对称性：电位较低的端子起源极作用。对于正的衬底电压，使用 $V_{SB}$ 为负时的体效应方程。在两种情况下，还要检查 n+ 区与 p 型衬底之间的 pn 结，它们会变为正向偏置，并最终起主导作用。

### 第 1 步 — 把 $V_D$ 降到零以下：源极和漏极交换角色

在正常工作时（$V_D > 0$），$V_{GS} = 1.5$ V，$V_{GS} - V_{TH} = 0.8$ V，因此 $V_D < 0.8$ V 时器件处于线性区，高于此值时饱和。当 $V_D$ 经过零时，电流也经过零；当 $V_D < 0$ 时，电位较低的端子即漏极端子**起源极作用**，而接地的端子起漏极作用。电流**反向**：它现在从接地端子出发，经过沟道，从“漏极”端子流出。

令 $V_D = -x$，$x > 0$。对于反向工作的器件：

$$V_{GS}' = V_G - V_D = 1.5 + x, \qquad V_{DS}' = 0 - V_D = x, \qquad V_{SB}' = V_D - 0 = -x .$$

**工作区。** 线性区要求 $V_{DS}' < V_{GS}' - V_{TH}$：

$$x < 1.5 + x - V_{TH} \quad\Longleftrightarrow\quad V_{TH} < 1.5\ \mathrm{V},$$

这总是成立的：无论 $V_D$ 变得多负，反向工作的器件都保持在**线性区**，因为有效 $V_{GS}$ 的增长与有效源极电位的下降一样快。

**电流大小。** 利用平方律（square law）的线性区公式，其中 $\beta = \mu_nC_{ox}W/L$：

$$|I_D| = \beta\left[(1.5 + x - V_{TH})\,x - \frac{x^2}{2}\right] = \beta\left[(1.5 - V_{TH})\,x + \frac{x^2}{2}\right].$$

$x^2/2$ 项为正，因此 $|I_D|$ 随 $|V_D|$ **比线性更快地**增大，因为栅极驱动不断增大。

**体效应。** 有效源极现在**低于**接地的衬底，$V_{SB}' = -x < 0$，因此阈值**减小**，进一步增大了电流。例如在 $V_D = -0.4$ V 时：

$$V_{TH} = V_{TH0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}'} - \sqrt{2|\phi_F|}\right) = 0.7 + 0.45\left(\sqrt{0.9 - 0.4} - \sqrt{0.9}\right) = 0.7 + 0.45(0.7071 - 0.9487) = 0.591\ \mathrm{V},$$

$$|I_D| = \beta\left[(1.9 - 0.591)(0.4) - 0.08\right] = 0.44\,\beta\ (\text{in A if }\beta\text{ is in A/V}^2).$$

| $V_D$（V） | −0.1 | −0.2 | −0.4 | −0.6 |
|---|---|---|---|---|
| 反向工作器件的 $V_{TH}$（V） | 0.676 | 0.650 | 0.591 | 0.520 |
| $\lvert I_D\rvert/\beta$（V²） | 0.087 | 0.190 | 0.444 | 0.768 |

### 第 2 步 — 进一步降低 $V_D$：漏-衬底结导通

n+ “漏”区现在处于 $V_D < 0$，而 p 型衬底处于 0 V，因此**漏-衬底结被 $|V_D|$ 正向偏置**，其电流大致按 $I_s\exp(|V_D|/V_T)$ 增长：

- 当 $|V_D|$ 不超过几百毫伏时，与沟道电流相比它可以忽略；
- 一旦 $V_D$ 低于大约 $-0.5$ 到 $-0.7$ V，该结就**大量导通**，这一不受栅极控制的电流（从衬底接触流入漏极端子）很快就占主导地位。

正向偏置的结把电子作为少数载流子注入衬底，这些电子可能被芯片上其他 n 型区收集，而衬底电流可能触发 CMOS 中寄生晶闸管的**闩锁**。当 $|V_{SB}'|$ 接近 $2|\phi_F| = 0.9$ V 时，体效应公式也不再有意义。实际上，NMOS 的漏极（或源极）绝不能被驱动到比衬底低几百毫伏以上。

### 第 3 步 — 把衬底电压 $V_{sub}$ 升到零以上：阈值降低

现在保持 $V_D$ 为正（例如 $V_D = 1$ V，使器件饱和），并把衬底升高到 $V_{sub} > 0$。源极为 0 时，

$$V_{SB} = 0 - V_{sub} = -V_{sub} < 0 .$$

这种**正向衬底偏置**（forward body bias）使体效应反向：衬底电位向沟道电位升高，使耗尽层变窄，需要栅极平衡的耗尽电荷减少，因此阈值**降低**：

$$
\begin{aligned}
V_{sub} = 0.25\ \mathrm{V}:&\quad V_{TH} = 0.7 + 0.45\left(\sqrt{0.65} - \sqrt{0.9}\right) = 0.7 + 0.45(0.8062 - 0.9487) = 0.636\ \mathrm{V},\\
V_{sub} = 0.5\ \mathrm{V}:&\quad V_{TH} = 0.7 + 0.45\left(\sqrt{0.40} - \sqrt{0.9}\right) = 0.7 + 0.45(0.6325 - 0.9487) = 0.558\ \mathrm{V}.
\end{aligned}
$$

因此饱和电流 $\tfrac12\beta(1.5 - V_{TH})^2$ **增大**：

| $V_{sub}$（V） | 0 | 0.25 | 0.5 | 0.7 |
|---|---|---|---|---|
| $V_{TH}$（V） | 0.700 | 0.636 | 0.558 | 0.474 |
| $I_D/\beta$（V²），饱和区 | 0.320 | 0.373 | 0.444 | 0.526 |
| 相对于 $V_{sub} = 0$ | 1 | 1.17 | 1.39 | 1.64 |

（0.7 V 处的数值仅供参考，因为此时第 4 步中的结电流已占主导。）

### 第 4 步 — 进一步升高 $V_{sub}$：结导通与双极晶体管效应

处于 $V_{sub}$ 的 p 型衬底与处于 0 V 的 n+ 源区构成一个**被 $V_{sub}$ 正向偏置**的结（若 $V_D < V_{sub}$，漏结也正向偏置）。

- 在大约 0.4–0.5 V 以下，结电流很小，主要效应是第 3 步中的阈值降低。
- 超过大约 0.6–0.7 V 后，源-衬底结**大量导通**：有很大的电流从衬底端流入源极。
- n+ 源区 / p 衬底 / n+ 漏区结构是一个**横向 npn 双极晶体管**（bipolar transistor），其发射极 = 源极，基极 = 衬底，集电极 = 漏极。其基极-发射极结正向偏置时，从源极注入的电子被电压较高的漏极收集，形成**不再受栅极控制**的漏极电流。
- 大的衬底电流还可能触发 CMOS 芯片中寄生 pnpn 结构的**闩锁**。

由于这些原因，衬底总是接到最负的电源。有时会有意采用小的、受控的正向衬底偏置（几百毫伏）来降低 $V_{TH}$，但绝不会达到结导通的程度。

### 结果

**当 $V_D$ 降到 0 以下时：** 漏极成为电位较低的端子，起源极作用。电流反向（从接地端子流入漏极端子）；器件保持在线性区，有效 $V_{GS} = 1.5 - V_D$ 随 $V_D$ 下降而增大，因此 $|I_D| = \beta[(1.5 - V_{TH})|V_D| + V_D^2/2]$ 比线性增长得更快，负的 $V_{SB}$ 所降低的阈值（$V_D = -0.4$ V 时为 0.59 V）又进一步增大了电流。同时，漏-衬底结正向偏置，低于大约 $-0.6$ V 时大量导通，向衬底注入电流（有闩锁风险）。

**当 $V_{sub}$ 升到 0 以上时：** $V_{SB} = -V_{sub} < 0$，因此阈值降低（0.25 V 时 ≈ 0.64 V，0.5 V 时 ≈ 0.56 V），$I_D$ 增大。源-衬底结（若 $V_D < V_{sub}$，还有漏-衬底结）正向偏置；超过大约 0.6 V 后，有很大的衬底电流流过，寄生的横向 npn 晶体管（源-衬底-漏）导通，使栅极失去对电流的控制，并可能发生闩锁。

**常见错误。** 说当 $V_D$ 变为负值时器件“关断”。电位较低的端子只是变成了源极，有效 $V_{GS}$ 增大，流过的是不断增大的反向电流。

**常见错误。** 声称正的衬底电压会使 $V_{TH}$ 升高。这是**正向**衬底偏置（$V_{SB} < 0$），它使耗尽区（depletion region）变窄并降低阈值，因此电流增大。

**常见错误。** 以为结始终保持反向偏置（reverse biased）。在两个实验中，都有一个 n+/p 衬底结变为正向偏置，超过大约 0.6 V 后，起主导作用的是它的指数型电流，而不是 MOS 方程。
