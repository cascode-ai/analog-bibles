# Golden Solution - R099

## 参考答案

![V_out 随 V_in 变化](/q/R099/solution-transfer.zh.svg)

反相特性，以 PMOS $M_3$ 为输入器件，以共源共栅（cascode）电流源（current source）$M_2$–$M_1$ 为负载：$V_{in}$ 较低时 $V_{out}$ 接近 $V_{DD}$；在 $M_3$ 的电流等于 $I_1 = \tfrac12\beta_1(V_{b2} - 0.7)^2$ 处出现陡峭的高增益下降；随后下降到 $V_{in} = V_{DD} - |V_{THP}| = 2.2$ V 处的 0 V，此后一直为 0 V。

- $V_{in}$ 较小时：$M_3$（$V_{SG}$ 很大）能够提供多于 $I_1$ 的电流，因此它处于线性区（triode region），$V_{out}$ 略低于 $V_{DD}$；$M_2$、$M_1$ 处于饱和区（saturation region），电流为 $I_1$。
- 当 $V_{out} < V_{in} + 0.8$ V 时 $M_3$ 进入饱和区；在 $V_{in}^* = 2.2 - \sqrt{2I_1/\beta_3}$ 处，其饱和电流等于 $I_1$：所有器件都饱和，增益 ≈ $g_{m3}[r_{O3} \| (g_{m2}r_{O2}r_{O1})]$，非常大，$V_{out}$ 从 ≈ $V_{in}^* + 0.8$ V 急剧下降到 ≈ $V_{b1} - V_{TH2}$（$M_2$ 进入线性区）。
- 继续增大输入：节点 $X$ 随 $V_{out}$ 下降，当 $V_X < V_{b2} - 0.7$ V 时 $M_1$ 进入线性区；此后电流由 $M_3$ 决定，为 $\tfrac12\beta_3(2.2 - V_{in})^2 < I_1$，而 $V_{out}$（= 处于线性区的 $M_2$、$M_1$ 上的压降）趋于 0。
- $V_{in} \ge 2.2$ V：$M_3$ 截止，$V_{out} = 0$（由电流为零的 $M_2$、$M_1$ 下拉）。
- 转折点：$V_{out} = V_{in} + 0.8$ V（$M_3$ 的线性区/饱和区转换），$V_{in}^*$，$V_{out} = V_{b1} - V_{TH2}$，$V_X = V_{b2} - 0.7$ V，$V_{in} = 2.2$ V。

## 评分说明

+2：识别 $M_3$ 为输入器件，低输入时输出接近 $V_{DD}$，在 $V_{in}^*$ 附近有陡峭下降，随后 $M_2$、$M_1$ 先后离开饱和区，并在 $V_{in}\ge2.2$ V 时输出为 0。+1：反相趋势、输入器件和 2.2 V 截止正确，但漏掉陡降或器件转折顺序之一。0：反相趋势正确但缺少截止或同时缺少陡降和转折。−2（明确断言错误结论）：同相曲线，把 $M_1$ 当输入器件，或声称 2.2 V 以上仍有非零输出。
