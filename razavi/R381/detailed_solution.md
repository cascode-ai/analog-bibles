# Detailed solution - R381

**Approach.** The input-referred noise current is the current which, injected into the open input of the noiseless circuit, gives the same output as the noise source. So find two transfer functions of the same circuit (input open), from $V_{n1}$ to $V_{out}$ and from an input current to $V_{out}$ (the transimpedance); their ratio is $M_1$'s contribution, to be compared with those of $M_2$ and $M_3$.

### Step 1 — The small-signal circuit with the input open

Call the input node X. With their gates at ac ground, $M_3$ is $r_{O3}$ from $V_{out}$ to ac ground (plus its noise current $4kT\gamma g_{m3}$) and $M_2$ is $r_{O2}$ from X to ground (plus $4kT\gamma g_{m2}$). $M_1$'s channel carries, from out to X,

$$I = g_{m1}(V_{n1} - V_X) - g_{mb1}V_X + \frac{V_{out} - V_X}{r_{O1}}$$

(bulk grounded, $v_{bs} = -V_X$). A test current $I_{in}$ may be injected into X. Let $G \equiv g_{m1} + g_{mb1}$.

KCL at the two nodes:

$$\text{X:}\quad I_{in} + I = \frac{V_X}{r_{O2}}, \qquad\qquad \text{out:}\quad -\frac{V_{out}}{r_{O3}} = I .$$

### Step 2 — Output produced by $V_{n1}$ ($I_{in} = 0$)

With $V_X = Ir_{O2}$ and $V_{out} = -Ir_{O3}$ in the channel equation (then multiplied by $r_{O1}$):

$$
\begin{aligned}
I &= g_{m1}V_{n1} - G\,Ir_{O2} - \frac{Ir_{O3} + Ir_{O2}}{r_{O1}}\\
I\,\left[r_{O1} + Gr_{O1}r_{O2} + r_{O2} + r_{O3}\right] &= g_{m1}r_{O1}V_{n1}.
\end{aligned}
$$

With the common denominator

$$\Delta = r_{O1} + r_{O2} + r_{O3} + (g_{m1} + g_{mb1})\,r_{O1}r_{O2},$$

$I = g_{m1}r_{O1}V_{n1}/\Delta$ and

$$V_{out}\big|_{V_{n1}} = -\frac{g_{m1}r_{O1}r_{O3}}{\Delta}\,V_{n1},$$

small, because $V_{n1}$ sees a CS stage heavily degenerated by $r_{O2}$.

### Step 3 — Transimpedance ($V_{n1} = 0$, current $I_{in}$ into X)

Now $I = -V_{out}/r_{O3}$ and $V_X = r_{O2}(I_{in} + I) = r_{O2}I_{in} - r_{O2}V_{out}/r_{O3}$. The channel equation with $V_{n1} = 0$,

$$-\frac{V_{out}}{r_{O3}} = -GV_X + \frac{V_{out} - V_X}{r_{O1}},$$

multiplied by $r_{O1}$, gives

$$
\begin{aligned}
-\frac{r_{O1}}{r_{O3}}V_{out} &= -Gr_{O1}V_X + V_{out} - V_X\\
V_X\,(1 + Gr_{O1}) &= V_{out}\left(1 + \frac{r_{O1}}{r_{O3}}\right)\\
V_X &= V_{out}\,\frac{r_{O1} + r_{O3}}{r_{O3}(1 + Gr_{O1})}.
\end{aligned}
$$

Equating the two expressions for $V_X$:

$$V_{out}\,\frac{r_{O1} + r_{O3}}{r_{O3}(1 + Gr_{O1})} + \frac{r_{O2}}{r_{O3}}V_{out} = r_{O2}I_{in}.$$

Multiplying by $r_{O3}(1 + Gr_{O1})$:

$$
\begin{aligned}
V_{out}\left[r_{O1} + r_{O3} + r_{O2}(1 + Gr_{O1})\right] &= r_{O2}r_{O3}(1 + Gr_{O1})\,I_{in}\\
R_T \equiv \frac{V_{out}}{I_{in}} &= \frac{\left[(g_{m1} + g_{mb1})r_{O1} + 1\right]r_{O2}r_{O3}}{\Delta},
\end{aligned}
$$

since $r_{O1} + r_{O3} + r_{O2} + Gr_{O1}r_{O2} = \Delta$. For $g_mr_O \gg 1$ (and $r_{O3}$ not much larger than $g_mr_O\,r_{O2}$), $\Delta \approx Gr_{O1}r_{O2}$ and $R_T \approx r_{O3}$: the CG stage passes essentially all of the input current to the output.

### Step 4 — $M_1$'s input-referred noise current

Dividing Step 2 by $R_T$ ($\Delta$ and $r_{O3}$ cancel):

$$I_{n,in}\big|_{M_1} = \frac{V_{out}|_{V_{n1}}}{R_T} = -\frac{g_{m1}r_{O1}}{r_{O2}\left[(g_{m1} + g_{mb1})r_{O1} + 1\right]}\,V_{n1}.$$

For $(g_{m1} + g_{mb1})r_{O1} \gg 1$:

$$|I_{n,in}|_{M_1} \approx \frac{g_{m1}}{g_{m1} + g_{mb1}}\cdot\frac{V_{n1}}{r_{O2}}.$$

With $\overline{V_{n1}^2} = 4kT\gamma/g_{m1}$:

$$\overline{I_{n,in}^2}\Big|_{M_1} \approx \left(\frac{g_{m1}}{g_{m1} + g_{mb1}}\right)^2\frac{4kT\gamma}{g_{m1}r_{O2}^2} \approx \frac{4kT\gamma}{g_{m1}r_{O2}^2}.$$

### Step 5 — Contributions of $M_2$ and $M_3$

**$M_2$.** Its noise current flows between X and ground, in parallel with the input, so it refers to the input with a factor of exactly 1:

$$\overline{I_{n,in}^2}\Big|_{M_2} = 4kT\gamma g_{m2}.$$

**$M_3$.** $I_{n3}$ is injected at the output, where it sees $r_{O3}\parallel R_{down}$, with $R_{down} = r_{O1} + r_{O2} + Gr_{O1}r_{O2}$ the resistance looking into the drain of $M_1$. An input current reaches the output multiplied by the short-circuit current gain $\alpha = (1 + Gr_{O1})r_{O2}/R_{down}$, very close to 1, and indeed $R_T = \alpha\,(r_{O3}\parallel R_{down})$. Hence $I_{n3}$ refers to the input as $I_{n3}/\alpha \approx I_{n3}$:

$$\overline{I_{n,in}^2}\Big|_{M_3} \approx 4kT\gamma g_{m3}.$$

### Step 6 — Comparison

$$\frac{\overline{I_{n,in}^2}|_{M_1}}{\overline{I_{n,in}^2}|_{M_2}} \approx \frac{4kT\gamma/(g_{m1}r_{O2}^2)}{4kT\gamma g_{m2}} = \frac{1}{(g_{m1}r_{O2})(g_{m2}r_{O2})} \sim \frac{1}{(g_mr_O)^2}.$$

With $g_{m1}r_{O2} \approx g_{m2}r_{O2} \approx 50$ the ratio is about $1/2500$, and similarly against $M_3$. **$M_1$'s contribution is negligible**; the noise current is set by $M_2$ and $M_3$. $M_1$'s noise barely reaches the output (gain of order $r_{O3}/r_{O2}$), whereas an input current passes almost unattenuated (transimpedance $\approx r_{O3}$); for $r_{O2} \to \infty$ $M_1$'s contribution vanishes completely.

### Result

$$I_{n,in}\big|_{M_1} = \frac{g_{m1}r_{O1}}{r_{O2}\left[(g_{m1} + g_{mb1})r_{O1} + 1\right]}\,V_{n1} \approx \frac{g_{m1}}{g_{m1} + g_{mb1}}\cdot\frac{V_{n1}}{r_{O2}}, \qquad \overline{I_{n,in}^2}\Big|_{M_1} \approx \frac{4kT\gamma}{g_{m1}r_{O2}^2}$$

(up to the factor $[g_{m1}/(g_{m1} + g_{mb1})]^2$), obtained from $V_{out} = -g_{m1}r_{O1}r_{O3}V_{n1}/\Delta$ and the transimpedance $R_T = [(g_{m1} + g_{mb1})r_{O1} + 1]r_{O2}r_{O3}/\Delta \approx r_{O3}$, with $\Delta = r_{O1} + r_{O2} + r_{O3} + (g_{m1} + g_{mb1})r_{O1}r_{O2}$.

$M_2$ contributes $4kT\gamma g_{m2}$ and $M_3$ about $4kT\gamma g_{m3}$, so $M_1$'s contribution is smaller by roughly $(g_{m1}r_{O2})(g_{m2}r_{O2}) \sim (g_mr_O)^2$: **negligible**.

**Common mistake.** Referring $M_1$'s noise as $g_{m1}V_{n1}$ (i.e. $4kT\gamma g_{m1}$), as if its source were grounded. With the input open the source is degenerated by $r_{O2}$, and the referred current is only $\approx V_{n1}/r_{O2}$.

**Common mistake.** Claiming that $M_1$'s contribution is comparable to $M_2$'s. The ratio is of order $1/(g_mr_O)^2$; the current sources, not the input transistor, set the input noise current of a CG stage.

**Common mistake.** Taking the transimpedance as $r_{O3}\parallel r_{O2}$ or as $r_{O2}$. The input current passes through $M_1$ (current gain ≈ 1) and develops its voltage across essentially $r_{O3}$.
