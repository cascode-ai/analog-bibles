[图 1] 所示电路在 CK 为高电平时（$M_1$ 导通）将输入采样到 $C_1$ 上，在 CK 为低电平时（由 $\overline{CK}$ 驱动的 $M_2$ 导通）把 $C_1$ 与 $C_2$ 连接起来。$M_1$ 和 $M_2$ 是相同的 NMOS 开关：宽度为 W，有效长度为 L，每一侧单位宽度的交叠电容（overlap capacitance）为 $C_{ov}$，衬底（bulk）接地；且 $C_1 = C_2 = C$。CK 与 $\overline{CK}$ 为不交叠（non-overlapping）时钟，在 0 与 $V_{DD} = 3$ V 之间摆动。恒定的输入电平 $V_{in}$（$0 \le V_{in} < V_{DD} - V_{TH}$）已持续施加了许多个时钟周期。由 $M_1$ 和 $M_2$ 的电荷注入（charge injection）和时钟馈通（clock feedthrough）引起的 $V_{out}$ 最大误差是多少？假设 $M_2$ 的沟道电荷（channel charge）在 $C_1$ 与 $C_2$ 之间平均分配。用 W、L、$C_{ox}$、$C_{ov}$、C、$V_{DD}$、$V_{in}$ 和 $V_{TH}$（$V_{TH0} = 0.7$ V）表示结果。
