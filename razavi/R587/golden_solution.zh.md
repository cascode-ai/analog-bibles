$C_1 \approx 19.8$ pF，$C_2 \approx 2.2$ pF，最大标称增益 ≈ 8.9（采用一阶增益误差和 $\tau = (C_1 + C_{in})/G_m$ 时为 8.91；采用精确增益误差 $x/(1+x) \le 1\%$、$x = (C_1 + C_2 + C_{in})/(A_{v1}C_2)$ 时为 9.01，此时 $C_2$ = 2.198 pF。若同时采用精确的单极点 $\tau = (C_1 + C_{in})/[G_m(1 + 1/(A_{v1}\beta))]$，$\beta = C_2/(C_1 + C_2 + C_{in})$，则 $C_1$ = 20.0 pF，$C_2$ = 2.22 pF，增益为 9.01）。

- 没有负载电容时，闭环时间常数为 $\tau = (C_1 + C_{in})/G_m$，与 $C_2$ 无关。一般形式为 $[C_L(C_1 + C_{in} + C_2) + (C_1 + C_{in})C_2]/(G_mC_2)$，此处 $C_L = 0$：即 $C_2$ 与 $C_1 + C_{in}$ 的串联电容，由经反馈系数（feedback factor）衰减后的 $G_m$ 驱动。因此 $\tau \le 2$ ns 要求 $C_1 + C_{in} \le 2\ \mathrm{ns} \times 10\ \mathrm{mS} = 20$ pF，即 $C_1 \le 19.8$ pF。
- 增益误差 $\approx (C_1 + C_2 + C_{in})/(1000\,C_2) \le 1\%$ 要求 $C_2 \ge (C_1 + C_{in})/9$，因此 $C_1/C_2 \le 9C_1/(C_1 + C_{in})$。这个上限随 $C_1$ 增大而升高，因为较大的 $C_1$ 冲淡了 $C_{in}$ 的作用。
- 选取速度限制所允许的最大 $C_1$：$C_1 = 19.8$ pF，$C_2 = 20/9 = 2.22$ pF，$C_1/C_2 = 8.91$。
- 作为对比，若 $C_1 = 2$ pF，τ 仅为 0.22 ns，但增益将被限制在 ≈ 8.2。
