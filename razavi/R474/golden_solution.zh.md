$A_{0,max} = 4$，此时反馈系数（feedback factor）β = 1。
- 环路增益（loop gain）为 $\beta A_0/(1 + j\omega/\omega_p)^2$。PM = 60° 时增益交点（gain crossover）处的相位为 −120°，因此每个极点贡献 60°：$\omega_u = \omega_p\tan 60° = \sqrt3\,\omega_p$。
- $|\beta H(\omega_u)| = \beta A_0/(1 + 3) = 1$，因此 $\beta A_0 = 4$。更大的 $A_0$ 会把交点向外推，使 PM 降低，因此条件为 $A_0 \le 4/\beta$。
- β = 1：$A_{0,max} = 4$。此时实际闭环增益为 4/5 = 0.8（“单位”增益是就名义值 β = 1 而言的）。若要求闭环增益 $A_0/(1 + \beta A_0)$ 恰好等于 1，则 β = 0.8，$A_0 = 5$。
