起初 $M_1$ 截止（$V_G = 0$），因此 $I_X = I_1$，$V_X$ 以 $I_1/C_1$ 的速率线性下降，同时 $I_1$ 以 $I_1/C_2$ 的速率对 $C_2$（栅极）线性充电。经过 $t_1 = V_{TH}C_2/I_1$ 后，栅极电压超过 0.7 V，$M_1$ 导通，其电流按平方律（square law）增大，因此 $I_X = I_1 + I_{D1}$ 平滑地增大，$V_X$ 下降得更快。随后 $M_1$ 进入线性区（triode region），$I_X$ 达到峰值后下降，$C_1$ 放电到约 0 V：$V_X$ 略微降到 0 以下，再缓慢回升趋向 $0^-$，而 $I_X$ 穿过零点，从负值一侧衰减到零。
- $I_X$ 是流出节点 X 的总电流：$I_X = I_1 + I_{D1} = -C_1\,dV_X/dt$。
- $t < t_1$：$I_X = I_1$，$V_X = 3 - I_1t/C_1$，$V_G = I_1t/C_2$（这一过程假设 $3C_1 > V_{TH}C_2$，使 $V_X$ 在 $t_1$ 时仍为正）。
- $t > t_1$：在 $M_1$ 处于饱和区（saturation region）期间（$V_X > V_G - V_{TH}$），$I_{D1} = \tfrac12\beta(V_G - 0.7)^2$ 从零开始按二次函数规律增长（没有跳变）；$V_X$ 的下降快于线性。一旦 $V_X < V_G - V_{TH}$，$M_1$ 就处于线性区，$I_X$ 在此附近达到峰值，然后下降。
- 在 $V_X = 0$ 时，$I_{D1} = 0$，因此仍有 $I_X = I_1$，$V_X$ 过冲到 0 以下；$M_1$ 反向导通（X 充当源极），并且随着 $V_G = I_1t/C_2$ 不断升高，其导通电阻（on-resistance）减小，因此 $V_X \approx -I_1/[\beta(V_G - V_{TH})] \to 0^-$，$I_X$ 是一个很小的负拖尾 $\to 0^-$。对于理想的 $I_1$，不存在真正的直流稳态（栅极一直在充电）；负向下冲的大小取决于 $I_1/\beta$，并可能受漏-衬底结（drain–bulk junction）限制（≈ −0.6 V）。
- 若 $3C_1 < V_{TH}C_2$，$V_X$ 在 $3C_1/I_1$ 时刻、$M_1$ 导通之前就穿过 0，$I_X$ 保持为 $I_1$，不会出现高于它的峰值；随后 $M_1$（反向导通）或漏-衬底结阻止其进一步降到 0 以下；最终状态相同。
（Level-1 模型仿真，$C_1 = C_2 = 1$ pF，$I_1 = 100$ µA：取 $\beta = 1$ mA/V² 时，$I_X$ 的峰值为 0.41 mA，$V_X$ 下冲到 −76 mV，在 100 ns 时为 −11 mV；取 $\beta = 50$ µA/V² 时，下冲达到 −0.53 V。）
