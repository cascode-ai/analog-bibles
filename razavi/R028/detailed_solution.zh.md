# 详细步骤 - R028

**思路。** 电流源 $I_1$ 从节点 X 取走电荷，并把它存放到 $M_1$ 的栅极电容 $C_2$ 上，因此栅极电压从 0 开始线性上升，在达到 $V_{TH}$ 之前 $M_1$ 一直截止。在此之前，只有 $I_1$ 使 $C_1$ 放电（线性斜坡）；之后 $M_1$ 加入一个不断增大的漏极电流，$C_1$ 放电加快，$M_1$ 进入线性区，随着 $V_X$ 趋近零，电流先达到峰值，然后迅速减小。在 X 和栅极列基尔霍夫电流定律（KCL）方程，并依次分析这几个阶段。

### 第 1 步 — 基本方程

把栅极节点记为 G。$I_X$ 是流出 X、流入 $M_1$ 和 $I_1$ 的总电流；设 $I_{D1}$ 为 $M_1$ 的漏极电流；由于没有体效应（body effect），$V_{TH} = 0.7$ V。于是

$$I_X = I_1 + I_{D1} = -C_1\frac{dV_X}{dt}.$$

栅极不取电流，因此 $I_1$ 全部给 $C_2$ 充电：

$$C_2\frac{dV_G}{dt} = I_1 \quad\Longrightarrow\quad V_G(t) = \frac{I_1}{C_2}\,t ,$$

这是一个从 0 开始的**线性斜坡**，与其他一切无关（对理想电流源而言）。

### 第 2 步 — 阶段 1：$M_1$ 截止，$V_X$ 线性下降

在 $t = 0$ 时，$V_G = 0 < V_{TH}$，因此 $M_1$ 截止，且

$$I_X = I_1, \qquad V_X(t) = 3\ \mathrm{V} - \frac{I_1}{C_1}\,t ,$$

直到栅极电压达到阈值电压（threshold voltage）：

$$\frac{I_1}{C_2}\,t_1 = V_{TH} \quad\Longrightarrow\quad t_1 = \frac{V_{TH}C_2}{I_1} ,$$

$$V_X(t_1) = 3 - \frac{I_1}{C_1}\cdot\frac{V_{TH}C_2}{I_1} = 3 - V_{TH}\frac{C_2}{C_1} .$$

假设 $V_X(t_1) > 0$，即 $3C_1 > V_{TH}C_2$（另一种情况在第 5 步中讨论）。

### 第 3 步 — 阶段 2：$M_1$ 导通，饱和区，放电加速

当 $t > t_1$ 时，过驱动电压（overdrive voltage）随时间线性增大，

$$V_G - V_{TH} = \frac{I_1}{C_2}\,(t - t_1),$$

而 $V_X$ 仍远高于 $V_G - V_{TH}$，因此 $M_1$ 处于饱和区：

$$I_{D1} = \tfrac12\beta\,(V_G - V_{TH})^2 = \tfrac12\beta\left(\frac{I_1}{C_2}\right)^2(t - t_1)^2 .$$

$I_{D1}$ 在 $t_1$ 时从**零**开始，随时间**按二次函数规律**增长，因此 $I_X = I_1 + I_{D1}$ 平滑地上升到 $I_1$ 以上（没有跳变），$V_X$ 的下降**快于线性**。

### 第 4 步 — 阶段 3：线性区、$I_X$ 的峰值以及结束过程

$V_X$ 在下降，而 $V_G - V_{TH}$ 在上升，因此两者很快相交，**$M_1$ 进入线性区**：

$$I_{D1} = \beta\left[(V_G - V_{TH})V_X - \tfrac12V_X^2\right].$$

此时因子 $V_X$ 迅速减小，因此 **$I_X$ 在饱和区/线性区转换附近达到峰值**，然后随着 $C_1$ 向 0 V 放电而**下降**。

**$V_X = 0$ 时会发生什么。** 此时 $I_{D1} = 0$，但理想电流源仍从 X 抽走 $I_1$，因此 $I_X = I_1 > 0$，$V_X$ **略微过冲到零以下**。漏极电位低于接地的源极，于是 X 成为 $M_1$ 的源极，该管反向导通，电流从地流入 X。当这一反向电流与 $I_1$ 平衡时，达到准平衡状态；在深线性区，$M_1$ 相当于电阻 $R_{on} \approx 1/[\beta(V_G - V_{TH})]$，因此

$$V_X \approx -I_1R_{on} = -\frac{I_1}{\beta\,(V_G - V_{TH})} .$$

由于 $V_G = I_1t/C_2$ 不断升高，$R_{on}$ 不断减小，$V_X$ 缓慢回升，趋向 $0^-$；而 $I_X = -C_1\,dV_X/dt$ 是一个趋向 $0^-$ 的很小的**负**拖尾。

- 对于理想的 $I_1$，不存在真正的直流稳态，因为栅极一直在充电。负向下冲的大小取决于 $I_1/\beta$；对于较弱的器件，它可能受漏-衬底结限制（约 $-0.6$ V）。
- 实际的浮接电流源两端需要一定的电压，一旦 $V_X$ 降到约等于 $V_G$，它就会停止导通；此后栅极电压保持不变，由 $M_1$ 单独把 $C_1$ 放电到 0 V，不会出现下冲。最终状态相同：$V_X \approx 0$，$I_X \to 0$。

### 第 5 步 — 另一种先后顺序（$3C_1 < V_{TH}C_2$）

若 $C_2$ 较大，$V_X$ 在 $t = 3C_1/I_1$ 时降到 0，此时栅极电压**尚未**达到 $V_{TH}$，$I_X$ 保持等于 $I_1$，不会出现高于它的峰值。一旦 $V_X$ 降到零以下，下降就会被反向导通的 $M_1$（只要 $V_G - V_X$ 超过 $V_{TH}$）或漏-衬底结所阻止。最终状态相同。

### 第 6 步 — 数值示例

取 $C_1 = C_2 = 1$ pF，$I_1 = 100\ \mu$A，$\beta = 1\ \mathrm{mA/V^2}$。

$$
\begin{aligned}
\frac{I_1}{C_1} &= \frac{100\ \mu\mathrm{A}}{1\ \mathrm{pF}} = 0.1\ \mathrm{V/ns} \quad(\text{same for } V_G),\\
t_1 &= \frac{(0.7\ \mathrm{V})(1\ \mathrm{pF})}{100\ \mu\mathrm{A}} = 7\ \mathrm{ns},\\
V_X(t_1) &= 3 - 0.7 = 2.3\ \mathrm{V}.
\end{aligned}
$$

$t_1$ 之后：$I_{D1} = \tfrac12(1\ \mathrm{mA/V^2})(0.1\ \mathrm{V/ns})^2(t - t_1)^2 = 0.005\ \mathrm{mA}\times[(t - t_1)/\mathrm{ns}]^2$。例如，在 $t = 12$ ns 时，$V_G = 1.2$ V，$I_{D1} = 0.005\times25 = 0.125$ mA，因此 $I_X = 0.225$ mA。

对方程逐步积分，得到：

| $t$ (ns) | $V_G$ (V) | $V_X$ (V) | $I_X$ (mA) | $M_1$ |
|---|---|---|---|---|
| 0 | 0 | 3.00 | 0.100 | 截止 |
| 7 | 0.70 | 2.30 | 0.100 | 开始导通 |
| 10 | 1.00 | 1.96 | 0.145 | 饱和区 |
| 12 | 1.20 | 1.59 | 0.225 | 饱和区 |
| 14 | 1.40 | 1.03 | 0.345 | 饱和区（≈ 14.6 ns 起进入线性区） |
| 15 | 1.50 | 0.65 | 0.41（峰值） | 线性区 |
| 16 | 1.60 | 0.27 | 0.31 | 线性区 |
| 17 | 1.70 | 0.05 | 0.15 | 线性区 |
| 20 | 2.00 | −0.076（最小值） | ≈ 0 | 反向导通 |
| 100 | 10.0 | −0.011 | ≈ −0.0001 | 反向导通 |

对于弱得多的器件（$\beta = 50\ \mu\mathrm{A/V^2}$），$I_X$ 的峰值只有约 0.14 mA，降到零以下的下冲达到约 $-0.55$ V，接近 PN 结的限制。

### 结果

- $I_X$ 是流出节点 X 的总电流：$I_X = I_1 + I_{D1} = -C_1\,dV_X/dt$；同时 $I_1$ 给栅极充电：$V_G = I_1t/C_2$。
- **$t < t_1 = V_{TH}C_2/I_1$：** $M_1$ 截止，$I_X = I_1$，$V_X = 3 - I_1t/C_1$（线性斜坡；这一过程假设 $3C_1 > V_{TH}C_2$，使 $V_X$ 在 $t_1$ 时仍为正）。
- **$t > t_1$：** 在 $M_1$ 处于饱和区期间（$V_X > V_G - V_{TH}$），$I_{D1} = \tfrac12\beta(V_G - 0.7)^2$ 从零开始按二次函数规律增长（没有跳变），$V_X$ 的下降快于线性。一旦 $V_X < V_G - V_{TH}$，$M_1$ 就处于线性区，$I_X$ **达到峰值**，然后下降。
- **结束：** $C_1$ 放电到约 0 V。$V_X$ 略微降到 0 以下（$M_1$ 的反向导通与 $I_1$ 平衡，$V_X \approx -I_1/[\beta(V_G - V_{TH})]$），然后缓慢回升，趋向 $0^-$；而 $I_X$ 穿过零点，从负值一侧衰减到零。对于理想的 $I_1$，不存在真正的直流稳态，因为栅极一直在充电。
- 若 $3C_1 < V_{TH}C_2$，$V_X$ 在 $M_1$ 导通之前就降到 0，$I_X$ 保持为 $I_1$，没有峰值，最终状态相同。

**常见错误。** 认为 $M_1$ 从 $t = 0$ 起就导通。它的栅极从 0 V 开始，必须先由 $I_1$ 充电到 $V_{TH}$；在此之前，只有 $I_1$ 使 $C_1$ 放电。

**常见错误。** 在 $M_1$ 导通时把 $I_X$ 画成跳变。栅极电压连续上升，因此漏极电流从零开始，按 $(t - t_1)^2$ 增长。

**常见错误。** 让 $V_X$ 稳定在一个较高的值，或者无限下降。一旦 $M_1$ 导通且栅极电压不断升高，它就会把 X 拉到地，甚至反向导通，阻止 $V_X$ 降到远低于零。
