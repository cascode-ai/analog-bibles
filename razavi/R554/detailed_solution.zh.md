# 详细步骤 - R554

**思路。** 在运放输出端断开环路，在 PMOS 栅极施加一个小的测试变化量 $\delta$。两个 PMOS 的电流变化相同，因此每个节点的变化量等于该电流乘以该节点对地的小信号阻抗。Y（同相输入端）构成负反馈通路，X（反相输入端）构成正反馈通路，因此只有当 Y 处的阻抗大于 X 处时，净反馈才是负反馈。然后针对通常的设计解释这一条件。

### 第 1 步 — 小信号模型与节点阻抗

若栅极电压升高，两个 PMOS 的电流都减小，X 和 Y 都下降。通过 Y（+ 输入端），运放输出下降，抵消栅极电压的升高：这是**负反馈**。通过 X（− 输入端），输出**升高**，加强了这一变化：这是**正反馈**。哪一个占优取决于各节点变化的幅度。

在运放输出端断开环路，用一个小的测试电压 $\delta$ 驱动 PMOS 的栅极。升高 $\delta$ 会使相同的 $M_3$、$M_4$ 的 $V_{SG}$ 降低 $\delta$，因此每个管子向其节点注入 $-g_{mP}\delta$（暂时忽略 $r_O$）。把 $Q_1$、$Q_2$ 等效为 $1/g_{m1}$、$1/g_{m2}$，把运放等效为 $A_1(v_Y - v_X)$，则 X 处看到的是 $R_3$ 与 $1/g_{m1}$ 并联，Y 处看到的是 $R_2$ 与 $R_1 + 1/g_{m2}$ 并联：

<!-- diagram: diagram-01.cir -->

$$Z_X = R_3 \parallel \frac{1}{g_{m1}}, \qquad Z_Y = R_2 \parallel \left(R_1 + \frac{1}{g_{m2}}\right).$$

### 第 2 步 — 环路增益与净负反馈的条件

$$v_X = -g_{mP}\,\delta\,Z_X, \qquad v_Y = -g_{mP}\,\delta\,Z_Y ,$$

$$
\begin{aligned}
v_{out} &= A_1(v_Y - v_X)\\
&= A_1\left(-g_{mP}\delta Z_Y + g_{mP}\delta Z_X\right)\\
&= -A_1g_{mP}\left(Z_Y - Z_X\right)\delta ,
\end{aligned}
$$

因此环路传输为

$$\frac{v_{out}}{\delta} = -A_1g_{mP}\left(Z_Y - Z_X\right):$$

$-A_1g_{mP}Z_Y$ 是经过 Y 的负反馈环路，$+A_1g_{mP}Z_X$ 是经过 X 的正反馈环路。若 $Z_Y - Z_X > 0$，环路为负反馈：

$$\boxed{R_2 \parallel \left(R_1 + \frac{1}{g_{m2}}\right) > R_3 \parallel \frac{1}{g_{m1}}}$$

若计入相等的 $r_{O3}$、$r_{O4}$，就相当于在 $Z_X$ 和 $Z_Y$ 上都并联了相同的 $r_O$；由于 $Z \parallel r_O$ 随 $Z$ 增大而增大，不等式不变。

**裕量。** 正反馈环路相对于负反馈环路的强度为 $Z_X/Z_Y$。好的设计使 $Z_Y$ 约为 $Z_X$ 的**两倍**，这样不仅能保证小信号稳定，还能获得良好的瞬态（大信号）响应。

### 第 3 步 — 通常的设计：$R_2 = R_3$

运放迫使 $V_X = V_Y$，因此 $R_3$ 和 $R_2$ 中的电流分别为 $V_X/R_3$ 和 $V_Y/R_2$。两个 PMOS 的电流相等，因此 **$R_2 = R_3$** 会使集电极电流相等，$I_{C1} = I_{C2} = I_C$，并且

$$g_{m1} = g_{m2} = g_m = \frac{I_C}{V_T}$$

（$g_{m2}$ **并不**是 $g_{m1}$ 的 $n$ 倍：双极型晶体管的 $g_m$ 取决于电流，而不是发射区面积）。令 $R_2 = R_3 = R$：

$$Z_X = R \parallel \frac{1}{g_m}, \qquad Z_Y = R \parallel \left(R_1 + \frac{1}{g_m}\right).$$

由于 $R_1 + 1/g_m > 1/g_m$，**对任何 $R_1 > 0$** 都有 $Z_Y > Z_X$：负反馈环路总是占优。为求裕量，写出并联组合，

$$Z_Y = \frac{R\,(R_1 + 1/g_m)}{R + R_1 + 1/g_m}, \qquad Z_X = \frac{R\,(1/g_m)}{R + 1/g_m},$$

两者相除，并将分子分母同乘以 $g_m^2$：

$$
\begin{aligned}
\frac{Z_Y}{Z_X} &= \frac{(R_1 + 1/g_m)(R + 1/g_m)}{(1/g_m)(R + R_1 + 1/g_m)}\\
&= \frac{(1 + g_mR_1)(1 + g_mR)}{1 + g_mR_1 + g_mR}.
\end{aligned}
$$

若 $R \gg R_1 + 1/g_m$，因子 $(1 + g_mR)/(1 + g_mR_1 + g_mR) \to 1$，于是

$$\frac{Z_Y}{Z_X} \approx 1 + g_mR_1 .$$

### 第 4 步 — 由带隙基准（bandgap reference）设计方程得到的数值

**$g_mR_1$。** 由 $V_X = V_Y$ 得 $|V_{EB1}| = |V_{EB2}| + I_CR_1$，所以 $I_CR_1 = V_T\ln n$（电流相等，面积比为 $n$），且

$$g_mR_1 = \frac{I_C}{V_T}R_1 = \ln n .$$

**$g_mR_2$。** 每个 PMOS 流过 $V_T\ln n/R_1 + |V_{EB1}|/R_2$。取 $\partial|V_{EB}|/\partial T \approx -1.5$ mV/K 和 $k/q \approx 0.087$ mV/K，零 TC 条件给出 $(R_2/R_1)\ln n \approx 17.2$，因此

$$g_mR_2 = \frac{R_2}{R_1}\,g_mR_1 = \frac{R_2}{R_1}\ln n \approx 17.2 .$$

**$n = 8$ 时的比值**（$\ln 8 = 2.08$）：

$$\frac{Z_Y}{Z_X} = \frac{(1 + 2.08)(1 + 17.2)}{1 + 2.08 + 17.2} = \frac{3.08\times18.2}{20.28} = 2.76 \approx 2.8 .$$

**$n = 2$ 时的比值**（$\ln 2 = 0.69$）：

$$\frac{Z_Y}{Z_X} = \frac{(1.69)(18.2)}{18.89} = 1.63 \approx 1.6 .$$

| $n$ | $\ln n = g_mR_1$ | $Z_Y/Z_X$ |
|---|---|---|
| 2 | 0.69 | 1.63 |
| 3 | 1.10 | 1.98 |
| 4 | 1.39 | 2.22 |
| 8 | 2.08 | 2.76 |

因此，约为 2 的裕量要求 $\ln n \gtrsim 1.1$，即 $n \gtrsim 3$。设计规则如下：

1. 采用 $R_2 = R_3$（或者至少不要使 $R_3$ 大于 $R_2$）；更大的 $R_3$ 会提高 $Z_X$，加强正反馈环路。
2. 使 $R_1$ 比 $1/g_m$ 大，即选取足够大的 $n$（$\ln n \gtrsim 1$，通常取 $n = 8$）。正是 $R_1$ 使 $Z_Y$ 区别于 $Z_X$。
3. 保持 $R_2 = R_3 \gg R_1 + 1/g_m$，零 TC 条件本身已经保证了这一点（$g_mR_2 \approx 17$）。

### 结果

Y 处看到的阻抗必须大于 X 处看到的阻抗：

$$R_2 \parallel \left(R_1 + \frac{1}{g_{m2}}\right) > R_3 \parallel \frac{1}{g_{m1}},$$

最好约为后者的两倍。栅极变化 $\delta$ 使两个 PMOS 的电流都改变 $g_{mP}\delta$。X 变化 $g_{mP}\delta Z_X$，它送到反相输入端（正反馈）；Y 变化 $g_{mP}\delta Z_Y$，它送到同相输入端（负反馈）。净环路增益为 $-A_1g_{mP}(Z_Y - Z_X)$。

在通常的 $R_2 = R_3$ 设计下（集电极电流相等，$g_{m1} = g_{m2} = g_m$），对任何 $R_1 > 0$ 该条件都成立，裕量为

$$\frac{Z_Y}{Z_X} = \frac{(1 + g_mR_1)(1 + g_mR_2)}{1 + g_mR_1 + g_mR_2} \approx 1 + g_mR_1 = 1 + \ln n .$$

$n = 8$ 时约为 2.8，$n = 2$ 时只有约 1.6。所以应选取足够大的 $n$（即相对于 $1/g_m$ 足够大的 $R_1$），保持 $R_2 = R_3 \gg R_1 + 1/g_m$，并且不要使 $R_3$ 大于 $R_2$。

**常见错误。** 把两个节点的作用弄反，即要求 $Z_X > Z_Y$。X 驱动的是**反相**输入端，因此它是正反馈通路；Y 的阻抗必须更大。

**常见错误。** 忽略双极型晶体管的电阻，或者只把 $R_3$ 当作 X 处的阻抗。$1/g_m$ 电阻在两个节点阻抗中都占主导；没有它们，这一比较以及 $R_1$ 的作用就都不存在了。

**常见错误。** 因为 $Q_2$ 大 $n$ 倍就认为 $g_{m2} = n\,g_{m1}$。双极型晶体管的 $g_m = I_C/V_T$ 只取决于集电极电流，而当 $R_2 = R_3$ 时两个集电极电流相等。
