# 详细步骤 - R295

**思路。** 输入端是 $M_1$ 的源极；该管是一个共栅（common-gate）器件，但其栅极接在电容串 $C_1$–$C_2$ 上，而不是接地。跟踪测试电流：它穿过沟道，在漏极处唯一的出路是先经 $C_1$、再经 $C_2$，这就确定了栅极电压。然后由计入体效应的晶体管方程（衬底接地而源极电压在变化）求出源极电压和 $Z_{in}$。

### 第 1 步 — 小信号模型（small-signal model）

把 $M_1$ 的漏极、栅极和源极分别记为 D、G 和 S。对小信号而言，理想的 $I_1$ 相当于开路，$\lambda = 0$ 又去掉了 $r_O$，因此除了 $C_1$（经 G 和 $C_2$）之外，没有任何元件把 D 连到交流地。衬底接地，故 $v_{bs} = -V_S$，从漏极流向源极的电流为

$$i_d = g_mv_{gs} + g_{mb}v_{bs} = g_m(V_G - V_S) - g_{mb}V_S .$$

在源极加测试电压 $V_x = V_S$，$I_x$ 从测试源流入 S。

### 第 2 步 — 跟踪测试电流

与 S 相连的只有测试源和晶体管，因此 $I_x$ 经沟道从 S 流向 D：

$$i_d = -I_x . \qquad (1)$$

在 D 点，唯一的出路是 $C_1$（$I_1$ 开路，且没有 $r_O$）；栅极不吸取电流，因此 $I_x$ 继续经 $C_2$ 流到地：

$$V_G = \frac{I_x}{C_2s}. \qquad (2)$$

漏极电压 $V_D = V_G + I_x/(C_1s)$ 只是自行调整，使 $I_x$ 流过 $C_1$，它并不出现在晶体管方程中（没有 $r_O$），因此 $Z_{in}$ 中**不会出现 $C_1$**。

### 第 3 步 — 求源极电压

将晶体管方程与式 (1) 联立，并合并 $V_S$ 项：

$$
\begin{aligned}
g_m(V_G - V_S) - g_{mb}V_S &= -I_x\\
g_mV_G + I_x &= (g_m + g_{mb})V_S\\
V_S &= \frac{I_x + g_mV_G}{g_m + g_{mb}}.
\end{aligned}
$$

代入式 (2) 中的 $V_G$：

$$V_S = \frac{I_x + g_m\dfrac{I_x}{C_2s}}{g_m + g_{mb}} = \frac{I_x}{g_m + g_{mb}}\left(1 + \frac{g_m}{C_2s}\right).$$

### 第 4 步 — 输入阻抗

$$Z_{in} = \frac{V_S}{I_x} = \frac{1}{g_m + g_{mb}}\left(1 + \frac{g_m}{C_2s}\right) = \frac{1}{g_m + g_{mb}} + \frac{g_m}{g_m + g_{mb}}\cdot\frac{1}{C_2s}.$$

这是电阻 $1/(g_m + g_{mb})$ 与如下电容的串联：

$$C_{eq} = \frac{g_m + g_{mb}}{g_m}\,C_2 = (1 + \eta)\,C_2, \qquad \eta = \frac{g_{mb}}{g_m}.$$

**不计体效应时**（$g_{mb} = 0$）：

$$Z_{in} = \frac{1}{g_m} + \frac{1}{C_2s}.$$

### 第 5 步 — 物理图像与验证

- **电阻部分** $1/(g_m + g_{mb})$ 就是栅极电压固定时从源极看进去的常规阻抗。
- **电容部分**的出现是因为栅极电压并不固定：沟道电流对 $C_2$ 充电，使 $V_G$ 升高 $I_x/(C_2s)$，而源极以 $g_m/(g_m + g_{mb})$ 的比例跟随。
- **在直流时**（$s\to0$），$Z_{in}\to\infty$：信号电流从 S 到地没有直流通路，因为漏极接的是理想电流源，而栅极通路呈容性（capacitive）。
- **在高频时**，$C_2$ 把栅极对地短路，电路变成共栅输入，$Z_{in}\to 1/(g_m + g_{mb})$。

### 结果

$$Z_{in} = \frac{1}{g_m + g_{mb}}\left(1 + \frac{g_m}{C_2s}\right) = \frac{1}{g_m + g_{mb}} + \frac{g_m}{g_m + g_{mb}}\cdot\frac{1}{C_2s}$$

若忽略体效应，上式简化为

$$Z_{in} = \frac{1}{g_m} + \frac{1}{C_2s}$$

$C_1$ 不出现在结果中：漏极接理想电流源时，全部测试电流依次流过 $C_1$ 和 $C_2$，只有 $C_2$ 两端的电压（即栅极电压）影响晶体管。

**常见错误。** 把 $C_1$ 和 $C_2$ 串联或并联起来，当作“唯一的”输入电容。$C_2$ 决定栅极电压，而栅极电压控制着晶体管；$C_1$ 只决定漏极电压，而当 $\lambda = 0$ 时漏极电压不起作用。（只有在仍把栅极当作分压器的抽头、即 $V_G = V_D\,C_1/(C_1 + C_2)$ 时，才可以用二者从 D 到地的串联等效电容来计算，这样得到的答案相同。）

**常见错误。** 类比考毕兹（Colpitts）振荡器的核心电路，声称输入电阻为负。在那种电路中，两个电容分别接在栅源之间和源极与地之间，并且阻抗是从栅极测得的。而本题中测试电流依次串联流过沟道、$C_1$ 和 $C_2$，$Z_{in}$ 的实部为正值 $1/(g_m + g_{mb})$。

**常见错误。** 不加说明地略去 $g_{mb}$。衬底接地而源极上有信号，因此 $v_{bs} = -V_S\ne0$；只有在明确说明是近似时，才可以忽略它。
