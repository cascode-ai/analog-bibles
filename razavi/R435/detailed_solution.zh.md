# 详细步骤 - R435

**思路。** X 和 Y 是第二级 PMOS 晶体管 $M_5$ 和 $M_6$ 的栅极，而它们的源极接 $V_{DD}$，因此要求每个管子流过 1 mA 就确定了 $|V_{GS5}|$，从而确定了 X 和 Y 的共模电平。由于 X 和 Y 同时也是输入对管的漏极，这一电平限制了输入共模电压在 $M_1$、$M_2$ 退出饱和区（saturation region）之前能升到多高；计算时要计入输入对管的体效应。

### 第 1 步 — X 和 Y 的共模电平

所有器件的 $W/L = 100/0.5 = 200$；平衡时 $M_1$–$M_4$ 的电流均为 0.5 mA。要使 $M_5$ 在饱和区传导 1 mA：

$$
\begin{aligned}
|V_{OD5}| &= \sqrt{\frac{2|I_{D5}|}{\mu_pC_{ox}(W/L)}} = \sqrt{\frac{2(1\ \mathrm{mA})}{(38.4\ \mu\mathrm{A/V^2})(200)}} = \sqrt{0.2604\ \mathrm{V^2}} = 0.510\ \mathrm{V},\\
|V_{GS5}| &= |V_{THP}| + |V_{OD5}| = 0.8 + 0.510 = 1.310\ \mathrm{V}.
\end{aligned}
$$

$M_5$ 的源极和衬底都接 $V_{DD}$（没有体效应），因此

$$V_{X,CM} = V_{DD} - |V_{GS5}| = 3 - 1.310 = 1.69\ \mathrm{V},$$

同样 $V_{Y,CM} = 1.69$ V。X 和 Y 是高阻抗节点，因此这一电平必须**专门建立**，实际中靠共模反馈（common-mode feedback）实现（例如调节 $V_{b1}$）。作为检验，当 $V_{b1} = V_{DD} - 0.8 - 0.361 = 1.84$ V 时 $M_3$ 的电流为 0.5 mA，且只要 $V_X \le V_{b1} + 0.8 = 2.64$ V 就保持饱和，1.69 V 满足这一条件。

### 第 2 步 — 输入对管的饱和条件

只要 $M_1$ 的漏极不低于比其栅极低一个阈值电压的电平，它就保持饱和：

$$V_X \ge V_{in,CM} - V_{TH1}\ \Longrightarrow\ V_{in,CM} \le V_X + V_{TH1} ,$$

因此由第二级 PMOS 决定的电平限制了输入共模范围的上限。

### 第 3 步 — 极限情况下 $M_1$ 的阈值电压（体效应）

在极限情况下，$M_1$ 处于饱和边缘，因此其 $V_{DS}$ 等于其过驱动电压（overdrive voltage）：

$$
\begin{aligned}
V_{OD1} &= \sqrt{\frac{2(0.5\ \mathrm{mA})}{(134\ \mu\mathrm{A/V^2})(200)}} = \sqrt{0.0373\ \mathrm{V^2}} = 0.193\ \mathrm{V},\\
V_P &= V_X - V_{OD1} = 1.690 - 0.193 = 1.497\ \mathrm{V}.
\end{aligned}
$$

衬底接地，因此 $V_{SB1} = V_P$：

$$
\begin{aligned}
V_{TH1} &= 0.7 + 0.45\left(\sqrt{0.9 + 1.497} - \sqrt{0.9}\right)\\
&= 0.7 + 0.45\,(1.5481 - 0.9487) = 0.7 + 0.45\times0.5994 = 0.970\ \mathrm{V}.
\end{aligned}
$$

### 第 4 步 — 最高输入共模电平

$$V_{in,CM,max} = V_X + V_{TH1} = 1.690 + 0.970 \approx 2.66\ \mathrm{V}.$$

验算：$V_{in,CM} - V_P = 2.66 - 1.497 = 1.163\ \mathrm{V} = V_{TH1} + V_{OD1} = 0.970 + 0.193$ ✓，因此 $M_1$ 在饱和边缘传导 0.5 mA。

若不计体效应，上限只有 $1.69 + 0.7 = 2.39$ V：这里体效应反而**有利**，因为较高的源极节点电压（约 1.5 V）使阈值电压升高了 0.27 V。

### 结果

$$V_{X,CM} = V_{Y,CM} = V_{DD} - |V_{GS5}| = 3 - 1.31 \approx 1.69\ \mathrm{V}$$

此时 $I_{D5} = I_{D6} = 1$ mA。输入对管必须保持饱和，因此

$$V_{in,CM} \le V_X + V_{TH1} \approx 1.69 + 0.97 \approx 2.66\ \mathrm{V}$$

（计入体效应，$V_{SB} \approx 1.5$ V 时 $V_{TH1} \approx 0.97$ V；不计体效应时约为 2.39 V）。可见，第二级的偏置要求决定了输入共模范围的上端。

**常见错误。** 由 $V_{b1}$ 或某个 NMOS 的 $V_{GS}$ 推出 $V_X$。X 和 Y 是第二级 PMOS 器件的**栅极**，因此其电平由 1 mA 下的 $|V_{GS5}|$ 决定。

**常见错误。** 把约束写成 $V_{in,CM} \le V_X$ 或 $V_{in,CM} \le V_X - V_{TH1}$。NMOS 的栅极可以比其漏极**高出**一个阈值电压，器件仍不退出饱和。

**常见错误。** 把结果当作输入电平的**最小值**。提高 $V_{in,CM}$ 会使差分对（differential pair）的源极升高，而 X 保持不变，从而把 $M_1$、$M_2$ 推向线性区（triode region）：这一约束是上限。
