在 [图 1] 所示的两级运算放大器（two-stage op amp）中，$(W/L)_{1-8} = 100\ \mu\mathrm{m}/0.5\ \mu\mathrm{m}$，$I_{SS} = 1$ mA（理想）。$V_{DD} = 3$ V。为使 $I_{D5} = I_{D6} = 1$ mA，必须在 $M_3$ 和 $M_4$ 的漏极（节点 X 和 Y）建立怎样的共模（common-mode）电平？这对最高输入共模电平有何约束？NMOS 器件的衬底（bulk）接地，PMOS 器件的衬底接 $V_{DD}$；偏置计算中忽略沟道长度调制（channel-length modulation）。

器件参数：NMOS 的 $\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$V_{TH0} = 0.7$ V，$\gamma = 0.45\ \mathrm{V^{1/2}}$，$2|\phi_F| = 0.9$ V；PMOS 的 $\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$V_{TH0} = -0.8$ V。
