# 详细步骤 - R145

**思路。** 在输出端用诺顿等效电路代替该级，即电流 $G_mv_{in}$ 与 $R_{out}$ 并联，从而 $A_v = -G_mR_{out}$。在输出端交流短路到地的条件下计算 $G_m$，在输入置零的条件下计算 $R_{out}$，注意符号约定，然后相乘。晶体管模型包含 $g_m$、$g_{mb}$ 和 $r_O$。

### 第 1 步 — 小信号电路与符号约定

$V_{DD}$ 为交流地，理想偏置电流源相当于**开路**。晶体管由 $g_mv_{gs}$ 和 $g_{mb}v_{bs}$（均从漏极流向源极）以及接在漏极与源极之间的 $r_O$ 表示；$R_L$ 从输出端接到地。

在该引理中，诺顿电流源 $G_mv_{in}$ 把电流从输出节点**拉向**地，因此输出端开路时 $v_{out} = -G_mv_{in}R_{out}$。相应地，$G_m = i_{sc}/v_{in}$，其中 $i_{sc}$ 是输出短路线必须**注入**输出节点的电流。对于共源级，这给出 $G_m = +g_m$ 和 $A_v = -g_mR_{out}$，与预期一致。

### 第 2 步 — $G_m$：输出端交流短路到地

<!-- diagram: diagram-01.cir -->

令 $v_{out} = 0$：

$$v_{gs} = v_{in} - 0 = v_{in},\qquad v_{bs} = 0 - 0 = 0,\qquad v_{ds} = 0 - 0 = 0 ,$$

因此体效应（body effect）电流源和 $r_O$ 中都没有电流，$R_L$ 两端没有电压，晶体管从其源极向短路线**送出** $g_mv_{in}$。于是短路线向输出节点注入的电流为 $i_{sc} = -g_mv_{in}$：

$$G_m = \frac{i_{sc}}{v_{in}} = -g_m .$$

与共源级不同，输入升高时跟随器向其输出端**推入**电流。$g_{mb}$ **不**出现，因为源极短路时 $v_{bs} = 0$。

### 第 3 步 — $R_{out}$：输入置零

<!-- diagram: diagram-02.cir -->

栅极接交流地，在输出端加测试电压 $v_x$，

$$v_{gs} = 0 - v_x = -v_x,\qquad v_{bs} = 0 - v_x = -v_x,\qquad v_{ds} = 0 - v_x = -v_x ,$$

因此晶体管的漏源电流为

$$g_mv_{gs} + g_{mb}v_{bs} + \frac{v_{ds}}{r_O} = -\left(g_m + g_{mb} + \frac{1}{r_O}\right)v_x ,$$

即有 $(g_m + g_{mb} + 1/r_O)v_x$ 的电流从输出端向上流过晶体管。测试源提供这一电流再加上 $v_x/R_L$（理想电流源中没有电流）：

$$i_x = \left(g_m + g_{mb} + \frac{1}{r_O} + \frac{1}{R_L}\right)v_x ,$$

$$R_{out} = \frac{v_x}{i_x} = \frac{1}{g_m + g_{mb} + \dfrac{1}{r_O} + \dfrac{1}{R_L}} = \frac{1}{g_m}\,\Big\|\,\frac{1}{g_{mb}}\,\Big\|\,r_O\,\Big\|\,R_L .$$

体效应在这里出现了：当栅极固定而源极变化时，$v_{gs}$ 和 $v_{bs}$ 都会变化，因此 $g_{mb}$ 相当于从源极到交流地的一个额外电导。

### 第 4 步 — 增益

$$A_v = -G_mR_{out} = -(-g_m)\,R_{out} = g_mR_{out},$$

$$A_v = \frac{g_m}{g_m + g_{mb} + \dfrac{1}{r_O} + \dfrac{1}{R_L}} = g_m\left(\frac{1}{g_m}\,\Big\|\,\frac{1}{g_{mb}}\,\Big\|\,r_O\,\Big\|\,R_L\right),$$

增益**为正**（同相）且**小于 1**，因为分母等于 $g_m$ 加上若干正项。

### 第 5 步 — 验证

**直接列基尔霍夫电流定律（KCL）方程**：在输出端，流入的晶体管电流 = 流入 $R_L$ 的电流：

$$g_m(v_{in} - v_{out}) + g_{mb}(0 - v_{out}) + \frac{0 - v_{out}}{r_O} = \frac{v_{out}}{R_L},$$

因此 $g_mv_{in} = v_{out}(g_m + g_{mb} + 1/r_O + 1/R_L)$，结果相同 ✓。

**极限情况。** 当 $\lambda = \gamma = 0$ 时，$A_v = g_mR_L/(1 + g_mR_L)$，这正是教科书中负载为 $R_L$ 的跟随器。当 $R_L, r_O \to \infty$ 时，$A_v \to g_m/(g_m + g_{mb}) = 1/(1 + \eta)$，其中 $\eta = g_{mb}/g_m$：由于体效应，即使是不带负载、衬底接地的跟随器，其增益也小于 1。

### 结果

$$G_m = -g_m,\qquad R_{out} = \frac{1}{g_m}\,\Big\|\,\frac{1}{g_{mb}}\,\Big\|\,r_O\,\Big\|\,R_L,$$

$$A_v = -G_mR_{out} = \frac{g_m}{g_m + g_{mb} + 1/r_O + 1/R_L},$$

增益为正且小于 1（当 $R_L, r_O \to \infty$ 时趋于 $g_m/(g_m + g_{mb})$）。

**常见错误。** 在 $G_m$ 中计入 $g_{mb}$。输出端短路时，源极和衬底都处于交流地，因此 $v_{bs} = 0$；体效应只通过 $R_{out}$ 起作用。

**常见错误。** 把 $R_{out} = R_L$ 或单独的 $1/g_m$ 当作精确结果。从源极看进去是 $1/g_m$、$1/g_{mb}$ 和 $r_O$ 的并联，而 $R_L$ 又与它们全部并联。

**常见错误。** 在 $A_v = -G_mR_{out}$ 中取 $G_m = +g_m$，从而得到负增益：跟随器向短路的输出端**推入**电流，因此按照该引理的约定，$G_m = -g_m$。此外，$g_{mb}/g_m$ 等于 $\eta = \gamma/(2\sqrt{2|\phi_F| + V_{SB}})$，而不是 $\gamma$。
