# 详细步骤 - R124

**思路。** 在 $X$ 和 $Y$ 点列 KCL 可知，$M_1$ 的电流经 $C_1$ 在一个闭合回路中循环，因此 $M_2$ 中没有电流，并把 $X$ 固定在地电位。于是问题简化为一个电容被单个栅源电压恒定的晶体管放电：$M_1$ 饱和时为线性斜坡下降，之后在线性区衰减到零。

### 第 1 步 — 由 KCL 可知 $M_2$ 中没有电流

设 $I_1$ 为 $M_1$ 的漏极电流（$Y \to X$），$I_2$ 为 $M_2$ 的漏极电流（$X \to$ 地），$V_C = V_Y - V_X$ 为按所标极性定义的电容电压。

**$Y$ 点的 KCL。** $Y$ 只与 $C_1$ 的“+”极板和 $M_1$ 的漏极相连，因此

$$I_1 = -C_1\frac{dV_C}{dt}.$$

**$X$ 点的 KCL。** 来自 $M_1$ 的电流分为两路：一路流入 $C_1$ 的“−”极板，其电流为 $C_1\,d(V_X - V_Y)/dt = -C_1\,dV_C/dt$；另一路流入 $M_2$：

$$I_1 = -C_1\frac{dV_C}{dt} + I_2 .$$

将第一个方程代入第二个方程，得 $I_1 = I_1 + I_2$，因此

$$I_2 = 0 .$$

经 $M_1$ 离开“+”极板的电荷到达同一电容的“−”极板：放电回路 $C_1 \to M_1 \to C_1$ 根本不经过 $M_2$。

### 第 2 步 — $V_X$ 保持在 0 V

$M_2$ 的 $V_{GS2} = V_{b2}$，高于其阈值电压（$V_{TH2} = V_{TH0} = 0.7$ V，源极和衬底都接地）。沟道导通的 NMOS 只有在 $V_{DS} = 0$ 时电流才为零（线性区电流 $\beta[(V_{GS} - V_{TH})V_{DS} - V_{DS}^2/2]$ 只在该处为零）。因此

$$V_X(t) = 0\quad\text{for all } t .$$

任何其他的 $V_X$ 都会使 $M_2$ 在 $X$ 点吸入或送出电流，而这是 KCL 所不允许的：$M_2$ 相当于一个闭合的开关，把 $X$ 接到地。

### 第 3 步 — $V_Y$ 的初始值与放电方程

由于 $V_X = 0$，$V_C = V_Y$，因此由 $V_C(0) = V_{DD}$ 得

$$V_Y(0) = V_{DD} = 3\ \mathrm{V}.$$

$M_1$ 的源极为 0 V，因此**没有体效应**：$V_{TH1} = 0.7$ V 和 $V_{GS1} = V_{b1}$ 都是常数，因而下面的量也是常数：

$$V_{ov1} = V_{GS1} - V_{TH1} = V_{b1} - 0.7\ \mathrm{V}.$$

在 $Y$ 点列 KCL，代入 $V_C = V_Y$，并记 $\beta_1 = \mu_nC_{ox}(W/L)_1$：

$$C_1\frac{dV_Y}{dt} = -I_1(V_Y),\qquad I_1 = \begin{cases}\tfrac12\beta_1V_{ov1}^2, & V_Y \ge V_{ov1}\ \ (\text{saturation}),\\[4pt] \beta_1\left(V_{ov1}V_Y - \tfrac12V_Y^2\right), & V_Y < V_{ov1}\ \ (\text{triode}),\end{cases}$$

这是因为 $V_{DS1} = V_Y$。

### 第 4 步 — 阶段 1：线性斜坡（$M_1$ 饱和）

在通常情况 $V_{ov1} = V_{b1} - 0.7 < V_{DD}$ 下，$M_1$ 起初处于饱和区（$V_{DS1} = 3$ V $> V_{ov1}$），相当于一个**恒流源**：

$$\frac{dV_Y}{dt} = -\frac{\beta_1V_{ov1}^2}{2C_1} \quad\Longrightarrow\quad V_Y(t) = V_{DD} - \frac{\beta_1V_{ov1}^2}{2C_1}\,t .$$

斜坡一直持续到 $V_Y = V_{ov1}$，对应时刻为

$$t_1 = \frac{V_{DD} - V_{ov1}}{\beta_1V_{ov1}^2/(2C_1)} = \frac{2C_1(V_{DD} - V_{ov1})}{\beta_1V_{ov1}^2}.$$

### 第 5 步 — 阶段 2：在线性区衰减到零

当 $t > t_1$ 时，$M_1$ 处于线性区：

$$\frac{dV_Y}{dt} = -\frac{\beta_1}{C_1}\left(V_{ov1}V_Y - \tfrac12V_Y^2\right).$$

这是一个逻辑斯谛型方程，在 $V_Y(t_1) = V_{ov1}$ 的条件下，其解为

$$V_Y(t) = \frac{2V_{ov1}}{1 + e^{(t - t_1)/\tau}},\qquad \tau = \frac{C_1}{\beta_1V_{ov1}}.$$

**验证。** 在 $t = t_1$ 时，$V_Y = 2V_{ov1}/2 = V_{ov1}$ ✓，该处斜率为 $-2V_{ov1}/(4\tau) = -\beta_1V_{ov1}^2/(2C_1)$，与斜坡斜率相同，因此曲线在转折处是光滑的 ✓。当 $t$ 很大时，

$$V_Y \approx 2V_{ov1}\,e^{-(t - t_1)/\tau},$$

这是时间常数为 $\tau = R_{on1}C_1$ 的指数衰减，其中 $R_{on1} = 1/(\beta_1V_{ov1})$ 是 $M_1$ 在 $V_{DS}$ 很小时的导通电阻。

**最终状态：** $V_Y \to 0$ 且 $V_X = 0$，因此 $C_1$ **完全**放电：$V_{GS1}$ 保持为 $V_{b1}$，沟道一直导通，电流降为零只是因为 $V_{DS1} \to 0$。

（若 $V_{b1} - 0.7 \ge V_{DD}$，则 $M_1$ 从一开始就处于线性区，$V_Y = 2V_{ov1}/[1 + ((2V_{ov1} - V_{DD})/V_{DD})\,e^{t/\tau}]$，没有线性下降段。）

### 第 6 步 — 草图的数值示例

取 $V_{b1} = 2$ V，则 $V_{ov1} = 1.3$ V；时间以 $T_0 = C_1/(\beta_1\cdot 1\ \mathrm{V})$ 为单位（例如 $C_1 = 1$ pF、$\beta_1 = 1$ mA/V² 时 $T_0 = 1$ ns）：

$$
\begin{aligned}
\text{ramp slope} &= \tfrac12(1.3)^2 = 0.845\ \mathrm{V}/T_0,\\
t_1 &= \frac{3 - 1.3}{0.845}\,T_0 = 2.01\,T_0,\\
\tau &= \frac{1}{1.3}\,T_0 = 0.77\,T_0 .
\end{aligned}
$$

| $t/T_0$ | 0 | 1 | 2.01 | 2.5 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|---|
| $V_Y$ (V) | 3.00 | 2.16 | 1.30 | 0.90 | 0.56 | 0.18 | 0.05 | 0.01 |
| $V_X$ (V) | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

$V_Y$ 先是一条从 3 V 下降到 $V_{b1} - 0.7$ V 的直线，然后平滑地弯折为类似指数的拖尾并趋于 0；$V_X$ 是一条位于 0 的水平线。

### 结果

- **$V_X = 0$ 对所有 $t$ 成立。** $M_1$ 的放电电流经 $C_1$ 自身循环，因此 $X$ 点的 KCL 迫使 $I_{D2} = 0$；又因为 $M_2$ 导通，所以 $V_{DS2} = 0$。
- **$V_Y$** 从 $V_{DD} = 3$ V 开始，在 $M_1$ 饱和期间以斜率 $-\beta_1(V_{b1} - 0.7)^2/(2C_1)$ **线性**下降。当 $V_Y = V_{b1} - 0.7$ V 时，$M_1$ 进入线性区，$V_Y$ 平滑地衰减**到 0**，最后呈时间常数为 $C_1/[\beta_1(V_{b1} - 0.7)]$ 的指数衰减。
- 最终状态：$V_X = V_Y = 0$；$C_1$ 完全放电。

**常见错误。** 认为 $C_1$ 经 $M_2$ 向地放电，从而 $V_X$ 在暂态过程中发生变化。经 $M_1$ 离开“+”极板的电流回到“−”极板，其中没有任何电流流过 $M_2$。

**常见错误。** 像源极跟随器（source follower）那样，让 $V_Y$ 停在某个非零值，例如 $V_{b1} - V_{TH}$。这里下降的节点是 $M_1$ 的**漏极**，而其源极保持在 0 V，因此沟道一直导通，直到 $V_{DS1} = 0$。

**常见错误。** 从一开始就画成单一的指数曲线。当 $V_{DS1} > V_{b1} - 0.7$ V 时，$M_1$ 处于饱和区，电流恒定，因此放电过程以一段直线开始。
