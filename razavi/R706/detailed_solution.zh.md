# 详细步骤 - R706

**思路。** 从每一层必须承担的功能出发，求出导电层（多晶硅和金属）数目的下限，再通过一个具体的布线方案证明这个下限是可以达到的。看起来需要交叉的线网是共质心布局中的对角连接；关键在于：多晶硅可以从金属 1 的**下方**穿过而不与之相连，而且每个半器件的源极梳和漏极梳可以选择朝向，使金属 1 线网永不交叉。

### 第 1 步 — 需要连接什么

把四个象限标记为左上（TL）$=\tfrac12M_1$、右上（TR）$=\tfrac12M_2$、左下（BL）$=\tfrac12M_2$、右下（BR）$=\tfrac12M_1$：

| 线网 | 连接 | 引出结构后接到 |
|---|---|---|
| $G_1$（$M_1$ 的栅极） | TL、BR | 输入 $V_{in1}$ |
| $G_2$（$M_2$ 的栅极） | TR、BL | 输入 $V_{in2}$ |
| $D_1$（$M_1$ 的漏极） | TL、BR | 输出 1 / 负载 |
| $D_2$（$M_2$ 的漏极） | TR、BL | 输出 2 / 负载 |
| $S$（公共源极） | TL、TR、BL、BR | 尾电流源（tail current source） |

**布线规则。** 多晶硅可以与金属交叉（它位于金属下方，中间隔着介质），但不能与另一条多晶硅线或有源区交叉（那会形成不需要的晶体管）。金属 1 可以自由地跨过多晶硅和有源区，但不能与另一条金属 1 线交叉。扩散区只能通过接触孔连到金属，从而与其他节点相连（没有多晶硅到扩散区的接触）。

### 第 2 步 — 下限：一层不够

栅指是多晶硅，因此多晶硅必然存在。有四个栅指时，每个半器件的扩散区为 $S\,D\,S\,D\,S$：三个源区条和两个漏区条被栅极隔开，它们只能通过**金属**相连。因此至少需要**两个**互连层（多晶硅 + 金属 1）；问题在于两层是否也**足够**。

### 第 3 步 — 在一个半器件内部：多晶硅 + 金属 1 就足够

四个竖直栅指在有源区外的一侧（这里是底部）由一条多晶硅横条连在一起，横条再从侧面引出器件。三个源区条由一个金属 1 梳连接，梳柄沿顶部；两个漏区条由另一个金属 1 梳连接，梳柄沿底部，位于多晶硅横条之外，漏极金属条跨过横条而不与之接触。

```
S spine (metal 1)      sssssssssssssssssssssssss
                       s  #     #  s  #     #  s
active area         +--s--#-----#--s--#-----#--s--+
                    |  S  #  D  #  S  #  D  #  S  |
                    +-----#--d--#-----#--d--#-----+
gate bar (poly)           ###x###########x###################
                             d           d
D spine (metal 1)            dddddddddddddddddddddddddddddddd
```

（`#` 为多晶硅，`s`/`d` 为金属 1，`x` 为金属跨过多晶硅之处。）两个梳相互交叉而不接触。由于栅指数为偶数，两侧最外面的扩散区都是源区，漏极梳只需从一侧接入。通过镜像，**源极梳、漏极梳和栅极横条可以放在我们选择的任何一侧**，正是这种自由度使全局布线成为可能。

### 第 4 步 — 用多晶硅 + 金属 1 实现的平面布线

如果像图中那样简单地从中心连线，$G_1$ 会与 $G_2$ 交叉，$D_1$ 会与 $D_2$ 交叉。布线必须使 $G_1$ 和 $G_2$（多晶硅）彼此分开且不经过有源区，使 $D_1$、$D_2$ 和 $S$（金属 1）互不交叉，并且只留下多晶硅从金属下方穿过的交叉。

**各半器件的朝向：**

| 象限 | 漏极梳（栅极横条紧挨着它） | 源极梳 |
|---|---|---|
| TL（$\tfrac12M_1$） | 底部，朝向水平通道 | 顶部 |
| BR（$\tfrac12M_1$） | 顶部，朝向水平通道 | 底部 |
| TR（$\tfrac12M_2$） | 顶部，朝外 | 底部 |
| BL（$\tfrac12M_2$） | 底部，朝外 | 顶部 |

**走线：**

- **$D_1$（金属 1）：** 从 TL 的漏极梳沿两行之间的水平通道直线走到 BR 的漏极梳，并从通道右端引出。
- **$D_2$（金属 1）：** 从 TR 的漏极梳沿顶边走线，沿左列外侧向下，再沿底边到达 BL 的漏极梳；由于它位于外围，可以在左侧任何位置引出。
- **$S$（金属 1）：** TL–TR 经竖直通道的上半部分相连（从 TL 的顶部梳到 TR 的底部梳，位于 $D_1$ 上方）；BL–BR 经竖直通道的下半部分相连（从 BL 的顶部梳到 BR 的底部梳，位于 $D_1$ 下方）；TL–BL 沿左边缘相连，位于 $D_2$ 环路的**内侧**。它从底部、即从 BR 的源极梳引出，接向尾电流源。
- **$G_1$（多晶硅）：** 从 TL 的栅极横条进入竖直通道，一直向下（从 $S$ 和 $D_1$ 下方穿过）到达 BR 的栅极横条，并从竖直通道底部引出接到输入。
- **$G_2$（多晶硅）：** 从 TR 的栅极横条沿顶边走线，再沿左边缘（与 $D_2$ 并行）向下到达 BL 的栅极横条；其输入接触位于左边缘。

### 第 5 步 — 检查每一处交叉

- **金属 1 与金属 1。** $D_1$ 只占用水平通道并从右侧引出；$S$ 的上部连线位于其上方，下部连线位于其下方；$S$ 的左边缘连线在 $D_2$ 内侧走线而不与之接触；$D_2$ 从不进入通道或右侧。**没有金属 1 之间的交叉。**
- **多晶硅与多晶硅。** $G_1$ 始终位于竖直通道中、TL 栅极横条所在高度以下，并从底部引出；$G_2$ 在该高度以上穿过竖直通道的顶部，然后一直沿左侧外围走线，从左侧进入 BL。**没有多晶硅之间的交叉。**
- **多晶硅与有源区。** 两个栅极线网都只在通道中和边缘外围走线，并在有源区之外从栅极横条处进入各半器件。**没有寄生晶体管。**
- **多晶硅与金属 1。** 这是仅有的交叉（标为 `x`，另外还有漏极金属条跨过各栅极横条之处），而且是允许的。

因此**两个互连层，即多晶硅和金属 1，就足够了**；由第 2 步可知它们也是必需的。

### 第 6 步 — 最小方案的代价与实际的选择

两层方案牺牲了采用共质心布局的初衷，即对称性：$D_1$ 很短（从中间穿过），而 $D_2$ 很长（绕外侧一圈），因此两个输出看到的连线电容和电阻不同；而且与 $G_1$ 不同，$G_2$ 是一条很长、电阻很大的多晶硅线（带来噪声和延迟）。因此实际的版图会增加**金属 2** 来处理交叉，使 $D_1$ 和 $D_2$（以及改用金属走线的 $G_1$、$G_2$）对称地从中心穿过：多晶硅 + 金属 1 + 金属 2，共三层。超过三层永远没有必要。

### 结果

最小值为**两个互连层：多晶硅加一层金属（金属 1）**。在每个半器件内部，四个多晶硅栅指由一条多晶硅横条相连，$S\,D\,S\,D\,S$ 扩散区由两个叉指状的金属 1 梳相连。在各象限之间，栅极用多晶硅走线（一条穿过中心，一条绕外侧），它们可以从金属 1 下方自由穿过；而通过让 $\tfrac12M_1$ 的漏极梳朝向中央通道、$\tfrac12M_2$ 的漏极梳朝外，漏极和源极线网可以在金属 1 中实现平面布线。对称、实用的版图通常还会使用第二层金属（总共三层）。

**常见错误。** 声称一层就足够。栅指必须是多晶硅，而分开的源区条和漏区条只能通过接触孔连到金属才能相连。

**常见错误。** 以为一个半器件中叉指排列的源区和漏区无法用一层金属连接。两个从相对两侧接入的交错梳状结构可以无交叉地把它们连起来。

**常见错误。** 因为对角连接“必然会交叉”而回答三层或四层。多晶硅从金属下方穿过的交叉不需要额外的层，而通过选择各半器件的朝向可以理顺金属线网；额外的金属层能改善对称性，但不是必需的。
