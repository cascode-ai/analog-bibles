# 详细步骤 - R352

**思路。** 没有旁路电容时，由理想电流源供电的二极管连接器件会把自身折算到栅极的噪声传到共用的栅极线上，因此每个电流镜的输出都带有其**两个**晶体管的噪声。先把每个电流镜化简为一个噪声电流，再求输入参考噪声电压（输入短路：把输出短路噪声电流与信号电流 $g_{m1}v_{in}$ 比较）和输入参考噪声电流（输入开路：$M_1$ 只是把 $M_2$ 决定的电流传到输出端）。

### 第 1 步 — 去掉电容后的 PMOS 电流镜 $M_4$–$M_3$

每个晶体管的闪烁噪声是与其栅极串联的电压 $V_{nj}$，$\overline{V_{nj}^2} = K/[C_{ox}(WL)_j\,f]$，其中 $M_0$、$M_1$、$M_2$ 取 $K = K_N$，$M_3$、$M_4$ 取 $K = K_P$。五个噪声源互不相关；由于 $\lambda = 0$，每个饱和的晶体管在其漏极都是理想电流源。

$M_4$ 是二极管连接的，流过理想电流 $I_2$，而 $M_3$ 的栅极不吸取电流，因此 $M_4$ 的小信号电流为**零**。计入栅极噪声后，$M_4$ 的电流为 $g_{m4}(v_{sg4} - V_{n4})$（$V_{n4}$ 的符号约定无关紧要），其中 $v_{sg4} = 0 - v_g$（源极接 $V_{DD}$，栅极线电压为 $v_g$）：

$$g_{m4}(-v_g - V_{n4}) = 0\quad\Longrightarrow\quad v_g = -V_{n4}.$$

因此 $M_4$ 的噪声未经滤除地出现在栅极线上。$M_3$ 感受到这个栅极电压以及它自身的噪声，因此它注入输出端的漏极噪声电流为

$$I_{n,M3} = g_{m3}(-v_g - V_{n3}) = g_{m3}(V_{n4} - V_{n3}),$$

$$\overline{I_{n,M3}^2} = g_{m3}^2\left(\overline{V_{n3}^2} + \overline{V_{n4}^2}\right) = \frac{g_{m3}^2K_P}{C_{ox}f}\left(\frac{1}{(WL)_3} + \frac{1}{(WL)_4}\right).$$

### 第 2 步 — 去掉电容后的 NMOS 电流镜 $M_0$–$M_2$

同理，二极管连接的 $M_0$ 流过固定电流 $I_1$，因此共用栅极线的电压随 $M_0$ 的噪声电压变化（$v_g = -V_{n0}$），$M_2$ 再加上它自身的噪声：$I_{n,M2} = g_{m2}(V_{n2} - V_{n0})$，其中

$$\overline{I_{n,M2}^2} = g_{m2}^2\left(\overline{V_{n2}^2} + \overline{V_{n0}^2}\right) = \frac{g_{m2}^2K_N}{C_{ox}f}\left(\frac{1}{(WL)_2} + \frac{1}{(WL)_0}\right).$$

这就是图中标为 $\overline{I_{n2}^2}$ 的电流。它从输入节点（$M_1$ 的源极）流向地。

**化简后的电路。** $M_1$ 画成从输出端流向输入端的受控源 $g_{m1}(V_{n1} - v_{in})$，其栅极节点 G 的电压为 $V_{n1}$（偏置 $V_b$ 为交流地）；噪声电流 $I_{n,M3}$ 注入输出端；噪声电流 $I_{n,M2}$ 从输入节点抽出。

### 第 3 步 — 输入参考噪声电压（输入短路）

把输入短接到交流地。此时：

- $I_{n,M2}$ 流入短路线，**不会**到达输出端。
- $M_1$ 的源极接地，栅极节点 G 的电压为 $V_{n1}$，因此它从输出端抽取噪声电流 $g_{m1}V_{n1}$。
- $I_{n,M3}$ 流入输出端。

噪声电流和信号电流流入同一个输出阻抗（output impedance），在 $\lambda = 0$ 时该阻抗为无穷大（除非后级构成负载），因此只需比较输出短路电流。

**信号。** 源极上的电压 $v_{in}$ 使 $M_1$ 的漏极电流改变 $g_{m1}(0 - v_{in}) = -g_{m1}v_{in}$：从输入到输出的跨导为 $g_{m1}$（无体效应）。

**折算到输入端。** 把噪声电流除以 $g_{m1}$，再把互不相关的功率相加：

$$
\begin{aligned}
\overline{V_{n,in}^2} &= \frac{g_{m1}^2\overline{V_{n1}^2} + \overline{I_{n,M3}^2}}{g_{m1}^2} = \overline{V_{n1}^2} + \frac{g_{m3}^2}{g_{m1}^2}\left(\overline{V_{n3}^2} + \overline{V_{n4}^2}\right)\\
&= \frac{1}{C_{ox}f}\left[\frac{K_N}{(WL)_1} + \frac{g_{m3}^2}{g_{m1}^2}K_P\left(\frac{1}{(WL)_3} + \frac{1}{(WL)_4}\right)\right].
\end{aligned}
$$

### 第 4 步 — 输入参考噪声电流（输入开路）

让输入开路。此时 $M_1$ 的源极节点只与 $M_1$ 和 $M_2$ 相连，因此由基尔霍夫电流定律（KCL），**$M_1$ 的电流恰好等于 $M_2$ 的电流**：

- $I_{n,M2}$（$M_2$ 和 $M_0$ 的噪声）以单位电流增益经 $M_1$ 传到输出端。
- $M_1$ 自身的噪声 $V_{n1}$ 无法改变其电流，因为该电流由 $M_2$ 决定（$\lambda = 0$）；它只改变浮空的源极电压，因此到达不了输出端。
- $I_{n,M3}$ 仍然直接注入输出端。

注入源极节点的输入电流 $i_{in}$ 同样以**单位电流增益**到达输出端，因此到达输出端的噪声电流一比一地折算到输入端：

$$
\begin{aligned}
\overline{I_{n,in}^2} &= \overline{I_{n,M2}^2} + \overline{I_{n,M3}^2}\\
&= \frac{1}{C_{ox}f}\left[g_{m2}^2K_N\left(\frac{1}{(WL)_2} + \frac{1}{(WL)_0}\right) + g_{m3}^2K_P\left(\frac{1}{(WL)_3} + \frac{1}{(WL)_4}\right)\right].
\end{aligned}
$$

### 第 5 步 — 去掉电容的影响

有电容时，在所关心的频率下电流镜的栅极线交流接地，因此 $M_4$ 和 $M_0$ 的噪声被滤除，每个电流镜只贡献其输出器件的噪声。去掉电容后多出了 $\overline{V_{n4}^2}$ 和 $\overline{V_{n0}^2}$：在器件面积相同时，每个电流镜的贡献**加倍**，而且输入参考噪声电流中现在还包含 $M_0$ 的噪声。（如果保留 $M_1$ 的体效应，信号跨导将变为 $g_{m1} + g_{mb1}$，噪声电压结果中的输出噪声电流应除以 $(g_{m1} + g_{mb1})^2$，而不是 $g_{m1}^2$；题目要求忽略体效应。）

### 结果

$$\overline{V_{n,in}^2}\Big|_{1/f} = \frac{1}{C_{ox}f}\left[\frac{K_N}{(WL)_1} + \frac{g_{m3}^2}{g_{m1}^2}K_P\left(\frac{1}{(WL)_3} + \frac{1}{(WL)_4}\right)\right]$$

$$\overline{I_{n,in}^2}\Big|_{1/f} = \frac{1}{C_{ox}f}\left[g_{m2}^2K_N\left(\frac{1}{(WL)_2} + \frac{1}{(WL)_0}\right) + g_{m3}^2K_P\left(\frac{1}{(WL)_3} + \frac{1}{(WL)_4}\right)\right]$$

- 二极管连接器件把自身噪声传到电流镜的栅极：$M_3$ 的噪声电流为 $g_{m3}(V_{n4} - V_{n3})$，$M_2$ 的噪声电流为 $g_{m2}(V_{n2} - V_{n0})$。
- 电压：来自 $M_1$ 和 $M_3$/$M_4$ 电流镜；$M_2$ 的噪声流入输入短路线。
- 电流：来自 $M_2$/$M_0$ 和 $M_3$/$M_4$ 两个电流镜；输入开路时，$M_1$ 自身的噪声不起作用。

**常见错误。** 忽略 $M_4$ 和 $M_0$，即给出有电容旁路时的结果。没有电容时，流过固定电流的二极管连接器件会把它们折算到栅极的噪声无衰减地传到 $M_3$ 和 $M_2$ 的栅极。

**常见错误。** 把 $M_2$ 的噪声计入输入参考噪声电压。输入短路时，$M_2$ 的噪声电流流入短路线，根本到达不了输出端。

**常见错误。** 把 $M_1$ 的噪声计入输入参考噪声电流。输入开路且 $\lambda = 0$ 时，$M_1$ 的电流被迫等于 $M_2$ 的电流，因此它自身的噪声只改变其源极电压。
