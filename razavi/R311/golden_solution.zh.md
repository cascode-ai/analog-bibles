$$Z_X = \frac{1 + R_DC_1s}{g_{m2}(1 + g_{m1}R_D + R_DC_1s)}$$
- $|Z_X|$ 在低频时为 $\dfrac{1}{g_{m2}(1 + g_{m1}R_D)}$，在零点 $\omega_z = 1/(R_DC_1)$ 与极点 $\omega_p = (1 + g_{m1}R_D)/(R_DC_1)$ 之间以 +20 dB/dec 上升，高频时趋于平坦，等于 $1/g_{m2}$：这是一个感性（inductive）阻抗。
- 等效网络：$R_0 = \dfrac{1}{g_{m2}(1+g_{m1}R_D)}$ 与一个并联支路串联，该支路由电阻 $\dfrac{1}{g_{m2}} - R_0$ 和电感 $L = \dfrac{g_{m1}R_D^2C_1}{g_{m2}(1 + g_{m1}R_D)^2} \approx \dfrac{C_1}{g_{m1}g_{m2}}$ 并联而成。

推导：测试电流流入 $M_2$ 的源极（节点 X，它同时也是 $M_1$ 的栅极）；$I_1$ 为理想电流源，因此 $i_X = g_{m2}(v_X - v_D)$，其中 D 为 $M_1$ 的漏极。在 D 点：$v_D(1/R_D + C_1s) = -g_{m1}v_X$。因此 $i_X = g_{m2}v_X[1 + g_{m1}R_D/(1 + R_DC_1s)]$。
直观理解：低频时，$M_1$–$M_2$ 构成的环路（增益为 $g_{m1}R_D$）使跟随器（follower）的 $1/g_{m2}$ 成倍减小；高频时 $C_1$ 使环路增益（loop gain）消失，只剩下 $1/g_{m2}$。
