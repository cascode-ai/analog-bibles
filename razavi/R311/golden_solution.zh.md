$$Z_X = \frac{1 + R_DC_1s}{g_{m2}(1 + g_{m1}R_D + R_DC_1s)}$$
- $|Z_X|$ 在低频时为 $\dfrac{1}{g_{m2}(1 + g_{m1}R_D)}$，在零点 $\omega_z = 1/(R_DC_1)$ 与极点 $\omega_p = (1 + g_{m1}R_D)/(R_DC_1)$ 之间以 +20 dB/dec 的斜率上升，在高频时趋于平坦，等于 $1/g_{m2}$：这是一个感性（inductive）阻抗。
- 等效网络：$R_0 = \dfrac{1}{g_{m2}(1+g_{m1}R_D)}$ 串联上电阻 $\dfrac{1}{g_{m2}} - R_0$ 与电感 $L = \dfrac{g_{m1}R_D^2C_1}{g_{m2}(1 + g_{m1}R_D)^2} \approx \dfrac{C_1}{g_{m1}g_{m2}}$ 的并联组合。

推导：测试电流流入 $M_2$ 的源极（节点 X，也是 $M_1$ 的栅极）；$I_1$ 是理想的，因此 $i_X = g_{m2}(v_X - v_D)$，其中 D 为 $M_1$ 的漏极。在 D 点：$v_D(1/R_D + C_1s) = -g_{m1}v_X$。因此 $i_X = g_{m2}v_X[1 + g_{m1}R_D/(1 + R_DC_1s)]$。
直观理解：在低频时，环路 $M_1$–$M_2$（增益为 $g_{m1}R_D$）使跟随器的阻抗 $1/g_{m2}$ 按比例减小；在高频时，$C_1$ 消除了环路增益（loop gain），只剩下 $1/g_{m2}$。
