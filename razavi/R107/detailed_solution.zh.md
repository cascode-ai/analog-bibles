# 详细步骤 - R107

**思路。** $R_1$ 连接公共漏极节点和公共栅极节点，而栅极不吸取电流，因此 $R_1$ 中没有直流电流，两个栅极都位于 $V_X$。于是两个晶体管都是二极管连接的，只要导通就处于饱和区。由漏极节点的基尔霍夫电流定律（KCL）得 $I_X = I_{D1} - I_{D2}$，并在由 0.7 V 和 $V_{DD} - 0.8 = 2.2$ V 划分的三个 $V_X$ 范围内分别计算。

### 第 1 步 — $R_1$ 中没有电流

公共栅极节点只连接 $R_1$ 和两个栅极，而栅极不吸取直流电流，因此 $R_1$ 中的电流为零，且

$$V_G = V_X .$$

因此两个器件都是**二极管连接**的，$V_{GS1} = V_{DS1} = V_X$，$V_{SG2} = V_{SD2} = 3 - V_X$，所以每个器件**只要导通就处于饱和区**。

### 第 2 步 — 器件电流与 KCL

$$
\begin{aligned}
I_{D1} &= \tfrac12\beta_n(V_X - 0.7)^2 &&\text{for } V_X > 0.7\ \mathrm{V}\ (\text{else } 0),\\
I_{D2} &= \tfrac12\beta_p(3 - V_X - 0.8)^2 = \tfrac12\beta_p(2.2 - V_X)^2 &&\text{for } V_X < 2.2\ \mathrm{V}\ (\text{else } 0).
\end{aligned}
$$

$I_X$ 和 $M_2$ 的漏极电流流入漏极节点，$M_1$ 的漏极电流流出：

$$I_X = I_{D1} - I_{D2} .$$

### 第 3 步 — 三个区段

**(a) $0 \le V_X \le 0.7$ V：只有 $M_2$ 导通。**

$$I_X = -\tfrac12\beta_p(2.2 - V_X)^2 ,$$

为负值（$M_2$ 向测试源注入电流），且

$$
\begin{aligned}
I_X(0) &= -\tfrac12\beta_p(2.2)^2 = -2.42\,\beta_p\ (\mathrm{V^2}),\\
I_X(0.7) &= -\tfrac12\beta_p(1.5)^2 = -1.125\,\beta_p\ (\mathrm{V^2}).
\end{aligned}
$$

**(b) $0.7 \le V_X \le 2.2$ V：两管都导通（都处于饱和区）。**

$$I_X = \tfrac12\beta_n(V_X - 0.7)^2 - \tfrac12\beta_p(2.2 - V_X)^2 .$$

**过零点**，由电流相等以及过驱动电压（overdrive voltage）为正得到：

$$
\begin{aligned}
\sqrt{\beta_n}(V_X - 0.7) &= \sqrt{\beta_p}(2.2 - V_X)\\
V_X(\sqrt{\beta_n} + \sqrt{\beta_p}) &= 0.7\sqrt{\beta_n} + 2.2\sqrt{\beta_p}\\
V_{X0} &= \frac{0.7\sqrt{\beta_n} + 2.2\sqrt{\beta_p}}{\sqrt{\beta_n} + \sqrt{\beta_p}} ,
\end{aligned}
$$

这就是去掉电压源后该节点稳定的电压，也就是输入与输出相连的反相器（inverter）的开关阈值（switching threshold）。当 $\beta_n = \beta_p = \beta$ 时，$V_{X0} = (0.7 + 2.2)/2 = 1.45$ V，该区段是一条直线：

$$
\begin{aligned}
I_X &= \tfrac12\beta\left[(V_X - 0.7)^2 - (2.2 - V_X)^2\right]\\
&= \tfrac12\beta\,(V_X - 0.7 - 2.2 + V_X)(V_X - 0.7 + 2.2 - V_X)\\
&= \tfrac12\beta\,(2V_X - 2.9)(1.5) = 1.5\,\beta\,(V_X - 1.45) .
\end{aligned}
$$

**(c) $2.2 \le V_X \le 3$ V：只有 $M_1$ 导通。**

$$I_X = \tfrac12\beta_n(V_X - 0.7)^2 ,$$

从 2.2 V 时的 $\tfrac12\beta_n(1.5)^2 = 1.125\,\beta_n$ 增大到 3 V 时的 $\tfrac12\beta_n(2.3)^2 = 2.645\,\beta_n$。

### 第 4 步 — 斜率与平滑性

斜率等于两个二极管连接器件的电导 $1/g_m$ 之和：

$$\frac{dI_X}{dV_X} = \beta_n(V_X - 0.7)\big|_{V_X > 0.7} + \beta_p(2.2 - V_X)\big|_{V_X < 2.2} = g_{m1} + g_{m2} > 0 .$$

在 0.7 V 处，刚导通的 $M_1$ 有 $g_{m1} = 0$；在 2.2 V 处，即将截止的 $M_2$ 有 $g_{m2} = 0$，因此斜率在两个转折点处都是**连续**的：没有尖角，只有曲率的变化，即 (a) 段向下凹（concave），(b) 段在 $\beta$ 相等时为直线，(c) 段向上凹（convex）。$I_X$ 在整个范围内**单调增大**。

### 第 5 步 — $\beta_n = \beta_p = 1\ \mathrm{mA/V^2}$ 时的数值

| $V_X$ (V) | $I_{D1}$ (mA) | $I_{D2}$ (mA) | $I_X$ (mA) | 斜率 (mS) |
|---|---|---|---|---|
| 0 | 0 | 2.420 | −2.420 | 2.2 |
| 0.35 | 0 | 1.711 | −1.711 | 1.85 |
| 0.7 | 0 | 1.125 | −1.125 | 1.5 |
| 1.0 | 0.045 | 0.720 | −0.675 | 1.5 |
| 1.45 | 0.281 | 0.281 | 0 | 1.5 |
| 1.8 | 0.605 | 0.080 | 0.525 | 1.5 |
| 2.2 | 1.125 | 0 | 1.125 | 1.5 |
| 2.6 | 1.805 | 0 | 1.805 | 1.9 |
| 3.0 | 2.645 | 0 | 2.645 | 2.3 |

### 结果

$R_1$ 中没有直流电流（它只连接栅极），因此两个栅极都位于 $V_X$，两个晶体管都是二极管连接的，导通时都处于饱和区：

$$I_X = \tfrac12\beta_n(V_X - 0.7)^2 - \tfrac12\beta_p(2.2 - V_X)^2$$

上式在各器件各自导通的范围内成立。

- **$0 \le V_X \le 0.7$ V：** $M_1$ 截止；$M_2$（$V_{SG} = V_{SD} = 3 - V_X$，饱和）向电压源注入电流：$I_X = -\tfrac12\beta_p(2.2 - V_X)^2$，从 0 V 时的 $-2.42\beta_p$ 变化到 0.7 V 时的 $-1.125\beta_p$。
- **$0.7 \le V_X \le 2.2$ V：** 两管都导通且饱和，$I_X = \tfrac12\beta_n(V_X - 0.7)^2 - \tfrac12\beta_p(2.2 - V_X)^2$，上升。它在 $V_X = (0.7\sqrt{\beta_n} + 2.2\sqrt{\beta_p})/(\sqrt{\beta_n} + \sqrt{\beta_p})$ 处过零（$\beta_n = \beta_p$ 时为 1.45 V，此时该区段是一条直线）。
- **$2.2 \le V_X \le 3$ V：** $M_2$ 截止；$I_X = \tfrac12\beta_n(V_X - 0.7)^2$，从 $1.125\beta_n$ 增大到 3 V 时的 $2.645\beta_n$。
- **转折点：** 0.7 V（$M_1$ 导通），2.2 V（$M_2$ 截止），以及过零点。

**常见错误。** 认为 $R_1$ 中有直流电流或其上有压降。栅极不吸取直流电流，因此恰好有 $V_G = V_X$（$R_1$ 只对信号有影响，此时栅极电容会吸取电流）。

**常见错误。** 认为器件处于线性区（triode region）。栅极和漏极电压相同时，$V_{DS} = V_{GS} > V_{GS} - V_{TH}$，因此每个器件只要导通就处于饱和区。

**常见错误。** 把 $I_X$ 画成随 $V_X$ 减小，或在两端画错符号。$V_X$ 较低时，PMOS 向测试源**注入**电流（$I_X$ 为负）；$V_X$ 较高时，NMOS 从测试源**吸取**电流。
