MOSFET $M_1$ 的源极经阻抗 $Z_S$ 形成源极负反馈（source degeneration），漏极交流短路到地。[图 1] 和 [图 2] 给出了其热噪声（thermal noise）的两种表示方法：在 [图 1] 中，噪声表示为漏源之间的电流 $I_n$，栅极接交流地；在 [图 2] 中，噪声表示为与栅极串联的电压 $V_n$。$I_{n,out1}$ 和 $I_{n,out2}$ 分别为由此流过漏极短路线的电流。在低频（不计电容）下，$I_{n,out1} = I_n/[Z_S(g_m + g_{mb} + 1/r_O) + 1]$，$I_{n,out2} = g_mV_n/[Z_S(g_m + g_{mb} + 1/r_O) + 1]$，因此只要 $V_n = I_n/g_m$，两者对任意 $Z_S$ 都等效（即所谓的“引理”）。现在计入栅源电容（gate–source capacitance）$C_{GS}$ 以及与栅极串联的无噪声阻抗 $Z_1$（在 [图 1] 中接在栅极与交流地之间；在 [图 2] 中与 $V_n$ 串联）。推导 $I_{n,out1}$ 和 $I_{n,out2}$ 的表达式，计入 $g_m$、$g_{mb}$ 和 $r_O$。此时引理还成立吗？
