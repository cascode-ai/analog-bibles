# 详细步骤 - R125

**思路。** $C_1$ 的下极板接在理想偏置源 $V_{b1}$ 上，因此 $V_Y$ 从 $V_{b1} + V_{DD}$ 开始，并且只能通过 $M_1$–$M_2$ 串联支路流向地的电流而改变：$C_1\,dV_Y/dt = -I$。节点 $X$ 上没有电容，因此 $V_X$ 始终取使两个漏极电流相等的值。随着 $V_Y$ 下降，跟踪 $M_1$ 和 $M_2$ 的工作区：先是恒流线性斜坡，然后进入线性区，最后两个电压都衰减到零。

### 第 1 步 — 初始值与控制方程

$C_1$ 的“−”极板就是 $M_1$ 的栅极节点，由理想电源 $V_{b1}$ 维持。按所标极性，电容电压为 $V_Y - V_{b1}$，初始值为 $V_{DD}$：

$$V_Y(0) - V_{b1} = V_{DD}\quad\Longrightarrow\quad V_Y(0) = V_{b1} + V_{DD},$$

例如，$V_{b1} = 2$ V 时 $V_Y(0) = 5$ V。

$Y$ 只与 $C_1$ 和 $M_1$ 的漏极相连，因此串联支路电流 $I$（$Y \to M_1 \to X \to M_2 \to$ 地）来自 $C_1$ 的上极板，而其下极板接恒定的 $V_{b1}$：

$$C_1\frac{dV_Y}{dt} = -I .$$

在 $X$ 点（没有电容），每一时刻都有 $I_{D1} = I_{D2} = I$，这就即时确定了 $V_X$。

### 第 2 步 — 器件方程

记 $\beta_i = \mu_nC_{ox}(W/L)_i$：

- **$M_2$**（源极接地）：$V_{TH2} = 0.7$ V 和 $V_{GS2} = V_{b2}$ 都是常数。当 $V_X \ge V_{b2} - 0.7$ V 时它处于饱和区，电流为常数
$$I_{2,sat} = \tfrac12\beta_2(V_{b2} - 0.7)^2 ,$$
否则处于线性区，电流为 $I = \beta_2[(V_{b2} - 0.7)V_X - V_X^2/2]$。
- **$M_1$**（源极接 $X$）存在体效应，
$$V_{TH1} = 0.7 + 0.45\left(\sqrt{0.9 + V_X} - \sqrt{0.9}\right)\ \mathrm{V},$$
它处于饱和区的条件是 $V_Y - V_X \ge V_{b1} - V_X - V_{TH1}$，即
$$V_Y \ge V_{b1} - V_{TH1}(V_X),$$
此时电流为 $\tfrac12\beta_1(V_{b1} - V_X - V_{TH1})^2$。

$M_1$ 起初处于饱和区，因为 $V_Y(0) = V_{b1} + V_{DD}$ 远高于 $V_{b1} - V_{TH1}$。$M_2$ 的初始工作区取决于未给定的尺寸和偏置，因此分两种情形：$M_2$ 饱和（第 3–5 步）和 $M_2$ 处于线性区（第 6 步）。

### 第 3 步 — 阶段 1：线性斜坡，$V_X$ 恒定（两管均饱和）

饱和的 $M_2$ 决定串联支路电流：

$$I = I_{2,sat} = \tfrac12\beta_2(V_{b2} - 0.7)^2 = \text{constant},\qquad V_Y(t) = V_{b1} + V_{DD} - \frac{I_{2,sat}}{C_1}\,t .$$

**$V_X$。** $M_1$ 是工作在饱和区、电流为 $I_{2,sat}$ 的源极跟随器（source follower）：

$$V_{b1} - V_X - V_{TH1}(V_X) = \sqrt{\frac{2I_{2,sat}}{\beta_1}}\quad\Longrightarrow\quad V_X + V_{TH1}(V_X) = V_{b1} - (V_{b2} - 0.7)\sqrt{\beta_2/\beta_1}.$$

右边为常数，因此 **$V_X$ 保持恒定**，其值 $V_{X1}$ 与 $V_Y$ 无关（饱和晶体管的电流与其漏极电压无关）。这一情形适用于 $V_{X1} \ge V_{b2} - 0.7$ V。

当 $M_1$ 退出饱和区时，阶段 1 结束，此时

$$V_Y = V_{b1} - V_{TH1}(V_{X1}).$$

### 第 4 步 — 阶段 2：$M_1$ 处于线性区，斜坡继续，$V_X$ 随 $V_Y$ 下降

一旦 $V_Y < V_{b1} - V_{TH1}$，$M_1$ 就处于线性区。只要 $X$ 仍高于 $V_{b2} - 0.7$ V，$M_2$ 就仍处于饱和区，因此：

- 电流仍为 $I_{2,sat}$，**$V_Y$ 继续沿同一条直线下降**；
- 为了在 $V_{DS1} = V_Y - V_X$ 不断减小的情况下通过这一电流，$M_1$ 需要更大的 $V_{GS1} = V_{b1} - V_X$，因此 **$V_X$ 开始下降**，跟随 $V_Y$ 下降，并比它低 $V_{DS1}$。

当 $V_X$ 降到 $V_{b2} - 0.7$ V、$M_2$ 退出饱和区时，阶段 2 结束。

### 第 5 步 — 阶段 3：两管均处于线性区，衰减到零

此时 $M_2$ 也处于线性区，电流减小，斜坡开始弯曲。两个晶体管都保持导通（$V_{GS2} = V_{b2} > 0.7$ V 固定不变，而 $V_{GS1} = V_{b1} - V_X$ 随 $X$ 下降只会**增大**），因此电流只有在 $V_Y = V_X = 0$ 时才停止。

**衰减的拖尾。** 接近零时，两个器件都相当于导通电阻（$M_1$ 的源极约为 0 V，因此其阈值电压为 0.7 V）：

$$R_{on1} = \frac{1}{\beta_1(V_{b1} - 0.7)},\qquad R_{on2} = \frac{1}{\beta_2(V_{b2} - 0.7)},$$

$$C_1\frac{dV_Y}{dt} = -\frac{V_Y}{R_{on1} + R_{on2}}\quad\Longrightarrow\quad V_Y \propto e^{-t/[(R_{on1} + R_{on2})C_1]},$$

此时 $X$ 处于分压值 $V_X = V_Y\,R_{on2}/(R_{on1} + R_{on2})$。

**最终状态：** $V_Y = V_X = 0$，因此电容两端电压为 $V_Y - V_{b1} = -V_{b1}$：由于其下极板维持在 $V_{b1}$，电容先被放电，然后被反向充电。

### 第 6 步 — 另一种初始情形：$M_2$ 从一开始就处于线性区

若 $V_X$ 的电流平衡值低于 $V_{b2} - 0.7$ V，则 $M_2$ 在 $t = 0$ 时处于线性区，电流由**饱和的 $M_1$** 与处于线性区的 $M_2$ 共同决定：

$$\tfrac12\beta_1(V_{b1} - V_X - V_{TH1})^2 = \beta_2\left[(V_{b2} - 0.7)V_X - \tfrac12V_X^2\right].$$

式中不含 $V_Y$，因此 **$I$ 和 $V_X$ 同样恒定**，$V_Y$ 线性下降。不同之处在于：一旦 $M_1$ 进入线性区（$V_Y < V_{b1} - V_{TH1}$），电流就减小，斜坡立即弯曲，$V_X$ 和 $V_Y$ 一起衰减到 0，拖尾与第 5 步中的指数拖尾相同。

### 第 7 步 — 数值示例

时间以 $T_0 = C_1/(\beta\cdot 1\ \mathrm{V})$ 为单位，取 $\beta_1 = \beta_2 = \beta$（例如 $C_1 = 1$ pF、$\beta = 1$ mA/V² 时 $T_0 = 1$ ns）；表中数值由上述方程的数值解得到。

**示例 1**（第 3–5 步：$V_{b1} = 2$ V，$V_{b2} = 1.2$ V）。

$$
\begin{aligned}
I_{2,sat} &= \tfrac12\beta(1.2 - 0.7)^2 = 0.125\,\beta\ \mathrm{V^2},\qquad \text{slope} = -0.125\ \mathrm{V}/T_0,\\
V_{X1} + V_{TH1}(V_{X1}) &= 2 - 0.5 = 1.5\ \mathrm{V}\ \Rightarrow\ V_{X1} = 0.664\ \mathrm{V},\ V_{TH1} = 0.836\ \mathrm{V}\ \ (V_{X1} \ge 0.5\ \mathrm{V},\ \text{so } M_2 \text{ is saturated}),\\
\text{Phase 1 ends at } V_Y &= 2 - 0.836 = 1.164\ \mathrm{V},\ \ t = (5 - 1.164)/0.125 = 30.7\,T_0,\\
\text{Phase 2 ends at } V_X &= 0.5\ \mathrm{V}\ (V_Y = 0.71\ \mathrm{V}),\ \ t = 34.3\,T_0,\\
\text{tail: } \tau &= (R_{on1} + R_{on2})C_1 = \left(\tfrac{1}{1.3} + \tfrac{1}{0.5}\right)T_0 = 2.77\,T_0 .
\end{aligned}
$$

### 结果

- **$V_Y$** 从 $V_{b1} + V_{DD}$ 开始，以恒定速率 $I/C_1$ **线性下降**。若 $M_2$ 饱和，则 $I = \tfrac12\beta_2(V_{b2} - 0.7)^2$，即使 $M_1$ 进入线性区后斜坡仍会继续，直到 $V_X$ 降到 $V_{b2} - 0.7$ V 以下。若 $M_2$ 一开始处于线性区，则由饱和的 $M_1$ 决定电流，一旦 $M_1$ 进入线性区，斜坡就开始弯曲。随后曲线弯折，并**渐近地衰减到 0**（指数拖尾，$\tau = (R_{on1} + R_{on2})C_1$）。
- **$V_X$** 在 $t = 0$ 时取其电流平衡值，并在 $M_1$ 饱和期间**保持恒定**，即 $V_X = V_{b1} - V_{GS1}$（其中 $V_{TH1}$ 计入体效应）。$M_1$ 进入线性区后，它**与 $V_Y$ 一起下降**，略低于后者，直到 0。在放电过程中它从不上升。
- 最终状态：$V_X = V_Y = 0$，$C_1$ 两端电压为 $-V_{b1}$（相对于所标极性）。

**常见错误。** 取 $V_Y(0) = V_{DD}$。$C_1$ 的“−”极板接在偏置源 $V_{b1}$ 上，而不是接地，因此 $V_Y(0) = V_{b1} + V_{DD}$。

**常见错误。** 让 $V_Y$ 停在某个非零值，例如 $V_{b1} - V_{TH}$。$Y$ 是 $M_1$ 的**漏极**；随着 $X$ 下降，其 $V_{GS}$ 只会增大，而 $M_2$ 保持导通，因此串联支路一直导通，直到 $V_Y = V_X = 0$。

**常见错误。** 在 $M_2$ 饱和的情形下，让线性斜坡在 $M_1$ 进入线性区时就结束，或让 $V_X$ 在阶段 1 中发生变化。在 $M_2$ 退出饱和区之前，电流完全由它决定；而 $M_1$ 饱和时，其电流与 $V_Y$ 无关，因此 $V_X$ 恒定。
