时间常数 $\tau = R_{on}C_1$（$C_2$ 不出现在其中）。开关上消耗的能量：$E = \tfrac12 C_1V_{in0}^2$，与 $R_{on}$ 无关。

- 运放理想时，节点 X 保持在 0 V。已充电到 $V_{in0}$ 的 $C_1$ 经 $R_{on}$ 放电：$V_A(t) = V_{in0}e^{-t/(R_{on}C_1)}$。
- 电流 $i(t) = (V_{in0}/R_{on})e^{-t/\tau}$ 流过 $C_1$ 进入 X，再流入 $C_2$（由运放输出端提供），因此 $V_{out}(t) = (C_1/C_2)V_{in0}(1 - e^{-t/\tau})$。
- $E = \int_0^\infty i^2R_{on}\,dt = (V_{in0}^2/R_{on})(\tau/2) = \tfrac12 C_1V_{in0}^2$：即 $C_1$ 上最初储存的全部能量。
