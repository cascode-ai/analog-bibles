# 详细步骤 - R202

**思路。** 在差分半边电路（half circuit）中，尾节点 P 是虚地，每个输出端的负载由三部分组成：二极管连接的 PMOS $M_3$、PMOS 电流源 $M_5$（栅极偏置固定）以及 $M_1$ 的输出电阻（output resistance）。把它们的小信号电阻并联，再对输出端应用基尔霍夫电流定律（KCL）。

### 第 1 步 — 各负载元件的小信号电阻

把左输出端（$M_1$、$M_3$、$M_5$ 的漏极）记为 X，右输出端记为 Y。体效应（body effect）不起作用：PMOS 的源极与衬底（bulk）都接 $V_{DD}$，$M_1$/$M_2$ 的源极则位于虚地 P。

- **二极管连接的 $M_3$：** 其栅极和漏极都接 X，电流 $g_{m3}v_X + v_X/r_{O3}$ 与 $v_X$ 成正比，因此它相当于接到交流地的电阻 $R_{M3} = 1/g_{m3}\parallel r_{O3}$。
- **电流源 $M_5$：** 其栅极（$V_{b1}$）和源极（$V_{DD}$）都处于交流地，因此 $v_{gs5} = 0$，只剩下 $R_{M5} = r_{O5}$。
- **输入器件 $M_1$：** P 处于交流地，它相当于从 X 流向地的电流 $g_{m1}v_{in}$ 与 $r_{O1}$ 并联。

### 第 2 步 — 对输出节点列 KCL

取 $v_{in1} = +v_d/2$、$v_{in2} = -v_d/2$，X 点的 KCL 为：

$$g_{m1}\frac{v_d}{2} + v_X\left(g_{m3} + \frac{1}{r_{O3}} + \frac{1}{r_{O5}} + \frac{1}{r_{O1}}\right) = 0 \quad\Longrightarrow\quad v_X = -\frac{g_{m1}}{g_{m3} + \dfrac{1}{r_{O1}} + \dfrac{1}{r_{O3}} + \dfrac{1}{r_{O5}}}\cdot\frac{v_d}{2}.$$

由对称性 $v_Y = -v_X$，因此 $v_{out} = 2v_X$，

$$A_v = \frac{v_{out}}{v_{in1} - v_{in2}} = -g_{m1}\left(\frac{1}{g_{m3}}\Big\|\,r_{O1}\Big\|\,r_{O3}\Big\|\,r_{O5}\right) = -\frac{g_{m1}}{g_{m3} + 1/r_{O1} + 1/r_{O3} + 1/r_{O5}} .$$

### 第 3 步 — 为什么要加 $M_5$？（这个电路的要点）

在偏置点，$M_1$ 流过 $I_{D1} = I_{SS}/2$，其中固定的一部分 $I_{D5}$ 由 $M_5$ 提供，因此二极管只流过

$$I_{D3} = I_{D1} - I_{D5}.$$

由于 $g_{m3} = \sqrt{2\mu_pC_{ox}(W/L)_3I_{D3}}$，电流越小，$g_{m3}$ 越小；而 $1/g_{m3}$ 在负载中占主导，因此增益 $\approx g_{m1}/g_{m3}$ **提高**，同时输入对管保持其全部电流和 $g_{m1}$。代价是输出端多并联了一个 $r_{O5}$，但它通常仍远大于 $1/g_{m3}$。

**数值示例。** 取 $I_{SS} = 1$ mA，$I_{D5} = 0.4$ mA，所有器件 $W/L = 50/0.5$，$\mu_nC_{ox} = 134\ \mu\mathrm{A/V^2}$，$\mu_pC_{ox} = 38.4\ \mu\mathrm{A/V^2}$，$\lambda_n = 0.1\ \mathrm{V^{-1}}$，$\lambda_p = 0.2\ \mathrm{V^{-1}}$（示例值）：

$$
\begin{aligned}
g_{m1} &= \sqrt{2(134\ \mu\mathrm{A/V^2})(100)(0.5\ \mathrm{mA})} = 3.66\ \mathrm{mS},\\
g_{m3} &= \sqrt{2(38.4\ \mu\mathrm{A/V^2})(100)(0.1\ \mathrm{mA})} = 0.876\ \mathrm{mS},\\
r_{O1} &= \frac{1}{(0.1\ \mathrm{V^{-1}})(0.5\ \mathrm{mA})} = 20\ \mathrm{k}\Omega\ \ (0.05\ \mathrm{mS}),\\
r_{O3} &= \frac{1}{(0.2\ \mathrm{V^{-1}})(0.1\ \mathrm{mA})} = 50\ \mathrm{k}\Omega\ \ (0.02\ \mathrm{mS}),\\
r_{O5} &= \frac{1}{(0.2\ \mathrm{V^{-1}})(0.4\ \mathrm{mA})} = 12.5\ \mathrm{k}\Omega\ \ (0.08\ \mathrm{mS}),\\
A_v &= -\frac{3.66}{0.876 + 0.05 + 0.02 + 0.08} = -\frac{3.66}{1.026} = -3.57 .
\end{aligned}
$$

若采用普通二极管负载、流过全部 0.5 mA，则 $g_{m3}$ 为 $\sqrt{2(3.84\ \mathrm{mA/V^2})(0.5\ \mathrm{mA})} = 1.96$ mS，$r_{O3} = 10\ \mathrm{k}\Omega$，得到 $A_v = -3.66/(1.96 + 0.05 + 0.1) = -1.73$：通过 $M_5$ 分走 80 % 的负载电流，大约使增益翻了一倍。

### 结果

$$A_v = \frac{V_{out}}{V_{in1} - V_{in2}} = -g_{m1}\left(\frac{1}{g_{m3}}\Big\|\,r_{O1}\Big\|\,r_{O3}\Big\|\,r_{O5}\right).$$

每个输出端看到的是二极管连接的 $M_3$（$1/g_{m3}\parallel r_{O3}$）、电流源 $M_5$（$r_{O5}$）和 $r_{O1}$，P 是虚地。由于 $M_5$ 提供了大部分偏置电流，$g_{m3}$ 很小，因此增益比普通二极管负载时更大。

**常见错误。** 把 $M_5$ 也当作二极管，写出 $g_{m1}/(g_{m3} + g_{m5})$。$M_5$ 的栅极接固定偏置，而不是接 X，因此它只贡献 $r_{O5}$。

**常见错误。** 把 $M_3$ 当作电流源，写出 $-g_{m1}(r_{O1}\parallel r_{O3}\parallel r_{O5})$。$M_3$ 是二极管连接的，它呈现很小的电阻 $1/g_{m3}$，并在负载中占主导。

**常见错误。** 让所有晶体管使用同一个 $g_m$ 和 $r_O$。这掩盖了该电路的目的：$g_{m3}$ 是在**减小了的**电流 $I_{D1} - I_{D5}$ 下计算的，正是这一点提高了增益。
