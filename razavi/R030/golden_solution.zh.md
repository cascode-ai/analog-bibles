# 参考答案 - R030

## 参考答案

$C_2$ 不起作用：$C_1$ 直接接在 $M_1$ 的漏极与源极之间，通过 $M_1$ 在局部回路中放电，没有净电流流入 $C_2$，因此 $V_S=0$ V。采用忽略沟道长度调制（$\lambda=0$）的平方律模型时，$V_X$ 在恒流作用下从 3 V 线性下降到 1.3 V，

$$I_X=\frac12\beta(1.3\ \mathrm{V})^2=(0.845\ \mathrm{V^2})\beta，$$

随后进入线性区并衰减到 0 V。饱和区持续

$$t_1=\frac{C_1(3-1.3)}{(0.845\ \mathrm{V^2})\beta}，$$

之后的特征时间为 $\tau=C_1/[\beta(1.3\ \mathrm{V})]$。

## 评分说明

+2：$V_S$ 保持 0 V；$V_X$ 从 3 V 到 1.3 V 先呈恒流线性下降，再在线性区衰减到 0 V；$I_X$ 先保持不变后衰减。写出 $I_X=0.845\beta$ 以及正确的 $t_1$、$\tau$ 表达式即可。

+1：$V_S=0$ 和最终放电结论正确，但缺少饱和区阶段或 $C_2$ 不充电的 KCL 依据。

0：波形或工作区转折判断错误。

-2：把过程判断为 $C_1$ 与 $C_2$ 电荷分享并令 $V_S$ 上升，或声称 $V_X$ 停在非零电压。
