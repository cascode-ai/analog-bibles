# 详细步骤 - R030

**思路。** $C_1$ 接在 $M_1$ 的漏极（X）与源极（S）之间，而不是接地。在 X 和 S 列 KCL 可知，$C_2$ 得不到净电流，因此源极保持在地电位，问题简化为 $M_1$ 在固定的 $V_{GS} = 2$ V 下对 $C_1$ 放电：先是饱和区中的恒流斜坡，然后是线性区中的衰减。

### 第 1 步 — KCL 表明 $C_2$ 不起作用

把源极节点记为 S。起初 $V_X - V_S = 3$ V，$V_S = 0$。令 $i_{C1} = C_1\,d(V_X - V_S)/dt$ 为从 X 侧极板流入 $C_1$（并从 S 侧极板流出）的电流。

**在 X 点**，只连接了 $M_1$ 的漏极和 $C_1$：

$$I_X + i_{C1} = 0 \quad\Longrightarrow\quad i_{C1} = -I_X .$$

**在 S 点**，$I_X$（来自 $M_1$ 的源极）和 $i_{C1}$（来自 $C_1$）流入 $C_2$：

$$C_2\frac{dV_S}{dt} = I_X + i_{C1} = I_X - I_X = 0 .$$

所以始终有 $dV_S/dt = 0$，且

$$V_S(t) = 0, \qquad V_X(t) = V_{C1}(t).$$

$C_1$ 通过 $M_1$ 在一个**局部回路**中放电：电流从其上极板经过沟道回到它自己的下极板，因此与 $C_2$ 之间不存在电荷分享（charge sharing）。

### 第 2 步 — 阶段 1：饱和区，恒定电流，线性下降

由于 $V_S = 0$：$V_{GS} = 2$ V，$V_{DS} = V_X$，$V_{SB} = 0$（$V_{TH} = 0.7$ V），因此过驱动电压（overdrive voltage）恒定：

$$V_{ov} = V_{GS} - V_{TH} = 2 - 0.7 = 1.3\ \mathrm{V}.$$

当 $V_X \ge 1.3$ V 时 $M_1$ 处于饱和区，在 $t = 0$ 时这一条件成立：

$$I_X = \tfrac12\beta\,(1.3\ \mathrm{V})^2 = 0.845\,\beta\ \mathrm{V^2} \quad(\text{constant}).$$

由于 $I_X = -i_{C1} = -C_1\,dV_X/dt$：

$$V_X(t) = 3\ \mathrm{V} - \frac{0.845\beta}{C_1}\,t ,$$

直到 $V_X = 1.3$ V，此时

$$t_1 = \frac{C_1\,(3 - 1.3)\ \mathrm{V}}{0.845\beta\ \mathrm{V^2}} = \frac{2.01\,C_1}{\beta\ \mathrm{V}} .$$

### 第 3 步 — 阶段 2：线性区中衰减到零

当 $V_X < 1.3$ V 时，$M_1$ 处于线性区：

$$C_1\frac{dV_X}{dt} = -I_X = -\beta\left[1.3V_X - \tfrac12V_X^2\right].$$

利用部分分式 $\dfrac{1}{V_X(1.3 - V_X/2)} = \dfrac{1}{1.3}\left(\dfrac{1}{V_X} + \dfrac{1}{2.6 - V_X}\right)$ 分离变量，并从 $t_1$（此时 $V_X = 1.3$ V）开始积分：

$$V_X(t) = \frac{2.6\ \mathrm{V}\cdot E}{1 + E}, \qquad I_X(t) = \frac{2\beta\,(1.3\ \mathrm{V})^2\,E}{(1 + E)^2}, \qquad E = e^{-(t - t_1)/\tau},$$

其中

$$\tau = R_{on}C_1, \qquad R_{on} = \frac{1}{\beta\,(2 - 0.7)} = \frac{1}{1.3\beta} .$$

在 $t = t_1$（$E = 1$）时，$V_X = 1.3$ V，$I_X = \tfrac12\beta(1.3)^2 = 0.845\beta$，因此电流是连续的。当 $t - t_1 \gg \tau$ 时，$V_X \approx 2.6\,e^{-(t - t_1)/\tau}$：这是一条趋向 **0 V** 的指数拖尾，此时 $M_1$ 相当于电阻 $R_{on}$。

### 第 4 步 — 数值示例

取 $\beta = 1\ \mathrm{mA/V^2}$，$C_1 = 1$ pF：

$$
\begin{aligned}
I_X &= 0.845\ \mathrm{mA}, \quad \frac{dV_X}{dt} = -\frac{0.845\ \mathrm{mA}}{1\ \mathrm{pF}} = -0.845\ \mathrm{V/ns},\\
t_1 &= \frac{1.7\ \mathrm{V}}{0.845\ \mathrm{V/ns}} = 2.01\ \mathrm{ns},\\
\tau &= \frac{1\ \mathrm{pF}}{1.3\ \mathrm{mS}} = 0.77\ \mathrm{ns}.
\end{aligned}
$$

| $t$ (ns) | $V_X$ (V) | $I_X$ (mA) | $V_S$ (V) | $M_1$ |

| 0 | 3.00 | 0.845 | 0 | 饱和区 |
| 1.0 | 2.16 | 0.845 | 0 | 饱和区 |

### 结果

- **$C_2$ 不起任何作用。** $C_1$ 直接接在 $M_1$ 的漏极与源极之间，因此它通过 $M_1$ 在一个局部回路中放电，没有净电流流入 $C_2$：KCL 给出 $C_2\,dV_S/dt = I_X + C_1\,d(V_X - V_S)/dt = 0$，因此**对所有 $t$ 都有 $V_S = 0$**，$V_X$ 等于 $C_1$ 上的电压。
- **阶段 1：** $V_X$ 以恒定电流 $I_X = \tfrac12\beta(2 - 0.7)^2 = 0.845\beta$ **线性下降**，直到 $V_X = 1.3$ V，所需时间为 $t_1 = C_1(3 - 1.3)/(0.845\beta)$。
- **阶段 2：** $M_1$ 处于线性区，$V_X$ 大致按指数规律衰减到 0，时间常数为 $C_1/(1.3\beta)$（$R_{on} = 1/(1.3\beta)$），同时 $I_X$ 衰减到 0。
- $I_X(t)$：先平坦地保持在 $0.845\beta$，然后平滑地衰减到零。

**常见错误。** 把电路当作 $C_1$ 与 $C_2$ 之间的电荷分享，认为 $V_S$ 会上升。$C_1$ 跨接在晶体管两端，因此它送到漏极的电流直接回到它自己的下极板，$C_2$ 永远不会被充电。

**常见错误。** 让 $V_X$ 稳定在 $2 - V_{TH} = 1.3$ V。这只标志着从饱和区到线性区的转变；由于 $V_{GS} = 2$ V，沟道保持导通，会把 $C_1$ 完全放电。

**常见错误。** 从 $t = 0$ 开始就画成纯指数曲线。当 $V_X > 1.3$ V 时，器件处于饱和区，相当于一个电流源，因此放电的前一段是一条直线。
