# 详细步骤 - R302

**思路。** 当 $\lambda = \gamma = 0$ 时，每个晶体管都只是一个受控电流源，理想电流源则相当于开路。两个晶体管都只连接 X 和输出端，因此这两个节点构成一个“孤岛”，外部只能经理想电流源和 $R_S$ 与之相连。输出端的 KCL 给出 $v_{out}$ 与 $v_X$ 的关系；再由 X 点的 KCL 可知没有信号电流能够流入，因此 $Z_{in} = \infty$，$v_X = V_{in}$。

### 第 1 步 — 小信号模型（small-signal model）

把输入节点（$R_S$ 右侧）记为 X。两个栅极都接固定偏置（$M_1$ 接 $V_{b2}$，$M_2$ 接 $V_{b1}$），并且两个晶体管都接在 **X 与输出端之间**。$V_{DD}$、$V_{b1}$、$V_{b2}$ 为交流地，$I_1$、$I_2$ 开路：

- **$M_1$**（源极接 X，漏极接输出端）：$v_{gs1} = 0 - v_X$，因此它把 $-g_{m1}v_X$ **从输出端送到 X**。
- **$M_2$**（源极接输出端，漏极接 X）：$v_{gs2} = 0 - v_{out}$，因此它把 $-g_{m2}v_{out}$ 从 X 送到输出端，即**把 $+g_{m2}v_{out}$ 从输出端送到 X**。

<!-- diagram: diagram-01.cir -->

因此，X 点电压升高会使 $M_1$ 从输出端流向 X 的电流**减小**，而输出电压升高会使 $M_2$ 的电流**增大**。设 $i_{in}$ 为经 $R_S$ 流入 X 的电流。

### 第 2 步 — 输出节点的 KCL

输出端只与开路的 $I_1$ 和两个晶体管相连，因此两个晶体管的总信号电流必须为零：

$$-g_{m1}v_X + g_{m2}v_{out} = 0 \quad\Longrightarrow\quad v_{out} = \frac{g_{m1}}{g_{m2}}\,v_X .$$

当 $M_1$ 的电流减小 $g_{m1}v_X$ 时，$M_2$ 的电流必须增大同样的量，这要求输出端升高 $g_{m1}v_X/g_{m2}$。

### 第 3 步 — X 点的 KCL：没有电流能够流入

流入 X 的有来自 $R_S$ 的 $i_{in}$，以及从输出端经 $M_1$ 和 $M_2$ 流来的电流；$I_2$ 开路，且没有栅极接到 X：

$$i_{in} + \left(-g_{m1}v_X + g_{m2}v_{out}\right) = 0 .$$

由第 2 步，括号内的项为零，因此

$$i_{in} = 0 \quad\text{for any } v_X, \qquad Z_{in} = \frac{v_X}{i_{in}} = \frac{v_X}{0} = \infty .$$

等价地说，围绕 X 和输出端画一个边界，穿过该边界的只有 $R_S$ 以及理想的 $I_1$、$I_2$（栅极不流过电流），因此电流只能在 X 与输出端之间循环流动，而不能从外部流入。

### 第 4 步 — 传递函数

$R_S$ 中没有信号电流流过，因此

$$v_X = V_{in} - i_{in}R_S = V_{in},$$

再利用第 2 步的结果：

$$\frac{V_{out}}{V_{in}} = \frac{v_{out}}{v_X} = +\frac{g_{m1}}{g_{m2}} .$$

增益为正，且与 $R_S$ 无关：$M_1$ 作为共栅级（common-gate stage）把 $v_X$ 转换为电流 $-g_{m1}v_X$，而从源极看进去的 $M_2$ 以 $1/g_{m2}$ 作为它的负载。

### 结果

$$Z_{in} = \infty, \qquad \frac{V_{out}}{V_{in}} = +\frac{g_{m1}}{g_{m2}} .$$

两个晶体管都只连接 X 和输出端。由于 $I_1$ 和 $I_2$ 是理想的，输出端的 KCL 迫使 $g_{m2}v_{out} = g_{m1}v_X$，而这两个电流在 X 点同样相互抵消，因此 $i_{in} = 0$。$R_S$ 中没有电流，故 $v_X = V_{in}$。

**常见错误。** 给出有限的输入阻抗，例如 $1/g_{m1}$ 或 $1/(g_{m1} + g_{m2})$，好像 X 是一个孤立共栅器件的源极。$M_1$ 或 $M_2$ 从 X 抽取的任何电流都流到输出端，并且只能回到 X，因此不可能有输入电流流过。

**常见错误。** 使增益与 $R_S$ 有关，例如认为它与 $Z_{in}$ 构成分压器。由于 $Z_{in}$ 为无穷大，$R_S$ 中没有电流，$v_X = V_{in}$ 严格成立。

**常见错误。** 把 $M_2$ 看成共源（common-source）器件，从而得到负增益。它的栅极接固定偏置 $V_{b1}$，源极接输出端，因此输出电压升高会**增大**其电流，以平衡 X 升高时 $M_1$ 电流的**减小**：输出跟随 X 变化。
