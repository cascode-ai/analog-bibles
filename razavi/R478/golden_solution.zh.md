- 在增益交点 $\omega_1$ 处（β = 1）：$|H(j\omega_1)| = 1$，$\angle H(j\omega_1) = -(180° - \mathrm{PM})$。该处的闭环幅值为 $\left|\dfrac{H}{1 + H}\right| = \dfrac{1}{|1 + e^{-j(180° - \mathrm{PM})}|} = \dfrac{1}{2\sin(\mathrm{PM}/2)}$。
- 50% 的峰值意味着该值等于 1.5：$\sin(\mathrm{PM}/2) = 1/3$，因此 PM = 2 sin⁻¹(1/3) ≈ 38.9°。（验证：PM = 45° 时为 1.31，即熟知的 30% 峰值；PM = 60° 时为 1。）
- 用二阶闭环系统交叉验证：峰值 $M_p = 1/(2\zeta\sqrt{1-\zeta^2}) = 1.5$ 给出 ζ ≈ 0.357，对应的 PM 同样 ≈ 39°。
