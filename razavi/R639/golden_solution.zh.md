频率：$\omega_{osc}^2 = \dfrac{g_mL_1 + R_P(C_1+C_2)}{R_PL_1C_1C_2} \approx \dfrac{1}{L_1\,C_1C_2/(C_1+C_2)}$。条件：$g_mR_P \ge \dfrac{(C_1+C_2)^2}{C_1C_2}$（≥ 4，在 $C_1 = C_2$ 时取最小值）——与考毕兹振荡器完全相同。

推导：
- 向栅极节点 G 注入 $I_{in}$（节点为 G 和 S；漏极接地）。G 点的 KCL：$V_G(1/L_1s + 1/R_P) + C_1s(V_G - V_S) = I_{in}$。S 点：$g_m(V_G - V_S) + C_1s(V_G - V_S) = C_2sV_S$。
- 解得：$\dfrac{V_G}{I_{in}} = \dfrac{R_PL_1s[g_m + (C_1+C_2)s]}{R_PC_1C_2L_1s^3 + (C_1+C_2)L_1s^2 + [g_mL_1 + R_P(C_1+C_2)]s + g_mR_P}$。
- 在 $s = j\omega$ 处：由虚部 → $\omega^2 = [g_mL_1 + R_P(C_1+C_2)]/(R_PL_1C_1C_2) \approx (C_1+C_2)/(L_1C_1C_2)$（当 $g_mL_1 \ll R_P(C_1+C_2)$ 时）；由实部 → $(C_1+C_2)L_1\omega^2 = g_mR_P$，即临界时 $g_mR_P = (C_1+C_2)^2/(C_1C_2)$，要使振荡增长则需更大。
- 结果完全相同的原因：该电路与考毕兹振荡器是同一个三节点网络（电感接在栅极与漏极之间，$C_1$ 接在栅源之间，$C_2$ 接在漏源之间）；只是选作交流地的节点不同，而这并不改变自然频率。等价地说，$M_1$ 与 $C_1$、$C_2$ 一起向电感呈现 $-g_m/(C_1C_2\omega^2)$ 与 $C_1C_2/(C_1+C_2)$ 的串联。
