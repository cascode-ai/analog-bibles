[图 1] 所示的共源级（common-source stage）中，$\lambda = 0$，$M_1$ 工作在饱和区（saturation region），其精确的传递函数为
$$\frac{V_{out}}{V_{in}}(s) = \frac{(C_{GD}s - g_m)R_D}{R_SR_D\xi s^2 + [R_S(1 + g_mR_D)C_{GD} + R_SC_{GS} + R_D(C_{GD} + C_{DB})]s + 1}$$
其中 $\xi = C_{GS}C_{GD} + C_{GS}C_{DB} + C_{GD}C_{DB}$。证明：若 $C_{GD} = 0$，该表达式可简化为两个传递函数的乘积，而这两个传递函数只需把极点分别与输入节点和输出节点相关联即可得到。
