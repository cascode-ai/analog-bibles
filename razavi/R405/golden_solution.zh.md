$Z_{in} = \dfrac{2R_0(1 + sR_0C_1)}{1 + G_{m1}G_{m2}R_0^2 + sR_0C_1} = 2R_0\ \Big\|\ \left[\dfrac{2}{G_{m1}G_{m2}R_0} + s\dfrac{2C_1}{G_{m1}G_{m2}}\right]$（单边：$R_0 \| [1/(G_{m1}G_{m2}R_0) + sC_1/(G_{m1}G_{m2})]$）。

$|Z_{in}|$：低频平台为 $2R_0/(1 + G_{m1}G_{m2}R_0^2) \approx 2/(G_{m1}G_{m2}R_0)$；零点位于 $\omega_z = 1/(R_0C_1)$；随后以 +20 dB/dec 上升，呈感性（inductive）；极点位于 $\omega_p = (1 + G_{m1}G_{m2}R_0^2)/(R_0C_1) \approx G_{m1}G_{m2}R_0/C_1$；在 $\omega_p$ 以上平坦，等于 $2R_0$。

- $G_{m2}$ 每个输出端的负载为 $Z = R_0\|(1/sC_1) = R_0/(1 + sR_0C_1)$，因此 $V_{out} = -G_{m2}Z\,V_{in}$（差分）。
- $G_{m1}$ 检测 $V_{out}$，并向输入节点注入一个与输入相抵抗的电流；每个输入节点都接有一个对地电阻 $R_0$（开环时 $Z_{in} = 2R_0$）。
- 加差分测试电流 $I_t$，列基尔霍夫电流定律（KCL）方程：$2I_t = V_{in}/R_0 + G_{m1}G_{m2}Z\,V_{in}$ → $Z_{in} = 2R_0/[1 + T(s)]$，其中环路增益（loop gain）为 $T(s) = G_{m1}G_{m2}R_0Z = G_{m1}G_{m2}R_0^2/(1 + sR_0C_1)$。
