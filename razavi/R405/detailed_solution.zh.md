# 详细步骤 - R405

**思路。** 把 [图 1] 中的每一级建模为一个跨导器（transconductor），其两个输出端各通过 $R_0$ 接地。$G_{m2}$ 把输入电压转换为其负载（$R_0\parallel C_1$）上的电压，$G_{m1}$ 检测该输出，并向输入节点注入一个与输入相抵抗的电流。这种并联反馈（shunt feedback）使开环输入电阻除以 $1 + T(s)$；我们在差分半边电路（half circuit）上列 KCL 求 $Z_{in}$。

### 第 1 步 — 级模型与环路极性

对于差分输入 $v_d$，每一级的每个输出节点得到电流 $\mp G_mv_d/2$，负载为 $R_0$，因此 $v_{out,d} = -G_mR_0\,v_d$。把图 2 的输入端记为 A（上）和 B（下），输出端记为 $O_1$（上）和 $O_2$（下）。每个输出节点都有对地的 $R_0$ 和 $C_1$；A 和 B 各有一个对地的 $R_0$（$G_{m1}$ 的输出电阻）。

升高 $v_A$（并降低 $v_B$）会使 $G_{m2}$ 把 $O_1$ 拉低、把 $O_2$ 抬高；于是 $G_{m1}$ 从 A **抽出**电流，向 B 注入电流，与输入相抵抗。该环路为负反馈，$G_{m1}$ 把**电流**送回输入节点（并联混合），从而降低输入阻抗。

### 第 2 步 — 差分半边电路

让测试电流 $I_t$ 流入 A、从 B 流出，于是 $v_A = +v_{in}/2$，$v_B = -v_{in}/2$，并且由对称性有 $v_{O2} = -v_{O1}$。于是：

- **节点 A：** $I_t$ 流入，$R_0$ 接地，$G_{m1}$ 注入 $G_{m1}\dfrac{v_{O1} - v_{O2}}{2} = G_{m1}v_{O1}$。
- **节点 $O_1$：** $R_0$ 和 $C_1$ 接地，$G_{m2}$ 抽出 $G_{m2}\dfrac{v_A - v_B}{2} = G_{m2}v_A$。

### 第 3 步 — KCL 方程

每个输出端的负载阻抗为

$$Z(s) = R_0\ \Big\|\ \frac{1}{sC_1} = \frac{R_0}{1 + sR_0C_1} ,$$

**节点 $O_1$ 的 KCL**（$G_{m2}$ 抽出的电流必须由负载提供）：

$$
\begin{aligned}
\frac{v_{O1}}{Z} &= -G_{m2}v_A\\
v_{O1} &= -G_{m2}Z\,v_A .
\end{aligned}
$$

**节点 A 的 KCL：**

$$I_t + G_{m1}v_{O1} = \frac{v_A}{R_0} .$$

**代入 $v_{O1}$：**

$$
\begin{aligned}
I_t - G_{m1}G_{m2}Z\,v_A &= \frac{v_A}{R_0}\\
I_t &= v_A\left(\frac{1}{R_0} + G_{m1}G_{m2}Z\right)\\
\frac{v_A}{I_t} &= \frac{R_0}{1 + G_{m1}G_{m2}R_0Z} .
\end{aligned}
$$

### 第 4 步 — 差分输入阻抗

由 $v_{in} = v_A - v_B = 2v_A$ 得：

$$Z_{in} = \frac{v_{in}}{I_t} = \frac{2R_0}{1 + T(s)}, \qquad T(s) = G_{m1}G_{m2}R_0Z = \frac{G_{m1}G_{m2}R_0^2}{1 + sR_0C_1} ,$$

即开环值 $2R_0$ 除以一加环路增益，而环路增益等于 $G_{m2}Z$（单边，从输入到输出）乘以 $G_{m1}R_0$（从输出回到输入）。代入 $Z(s)$，分子分母同乘以 $1 + sR_0C_1$：

$$Z_{in} = \frac{2R_0}{1 + \dfrac{G_{m1}G_{m2}R_0^2}{1 + sR_0C_1}} = \frac{2R_0\,(1 + sR_0C_1)}{1 + G_{m1}G_{m2}R_0^2 + sR_0C_1} .$$

**等效网络。** 输入导纳为

$$\frac{1}{Z_{in}} = \frac{1}{2R_0} + \frac{G_{m1}G_{m2}R_0}{2(1 + sR_0C_1)} = \frac{1}{2R_0} + \frac{1}{\dfrac{2}{G_{m1}G_{m2}R_0} + s\dfrac{2C_1}{G_{m1}G_{m2}}} ,$$

因此

$$Z_{in} = 2R_0\ \Big\|\ \left[\frac{2}{G_{m1}G_{m2}R_0} + s\,\frac{2C_1}{G_{m1}G_{m2}}\right],$$

即 $2R_0$ 与一个小电阻和一个**电感** $L = 2C_1/(G_{m1}G_{m2})$ 的串联支路相并联。两个跨导器和 $C_1$ 构成一个**回转器**（gyrator）：一个端口上的电容在另一个端口表现为电感。

### 第 5 步 — $|Z_{in}|$ 的曲线草图

- **低频：** $Z_{in} = \dfrac{2R_0}{1 + G_{m1}G_{m2}R_0^2} \approx \dfrac{2}{G_{m1}G_{m2}R_0}$（每一级的增益 $G_mR_0 \gg 1$），由于环路增益很大，它非常小。
- **零点**位于 $\omega_z = \dfrac{1}{R_0C_1}$，此时 $C_1$ 开始把输出负载短路，环路增益开始下降。
- **在零点与极点之间**，$|Z_{in}|$ 像电感一样以 **+20 dB/十倍频程**的斜率上升：$|Z_{in}| \approx \omega L$。
- **极点**位于 $\omega_p = \dfrac{1 + G_{m1}G_{m2}R_0^2}{R_0C_1} \approx \dfrac{G_{m1}G_{m2}R_0}{C_1}$，此时环路增益已降到 1 左右。
- **高频：** $Z_{in} \to 2R_0$：$C_1$ 把输出端短路，$G_{m1}$ 收不到信号，反馈消失。

归一化示例，取 $G_{m1}G_{m2}R_0^2 = 99$（两个平台相差 100 倍）：

| $\omega R_0C_1$ | $\lvert Z_{in}\rvert/(2R_0)$ | 区域 |
|---|---|---|
| 0.1 | 0.010 | 低频平台 $\approx 2/(G_{m1}G_{m2}R_0)$ |
| 1 | 0.014 | 零点 $\omega_z$（+3 dB） |
| 10 | 0.10 | +20 dB/dec，感性 |
| 100 | 0.71 | 极点 $\omega_p$（比高频平台低 3 dB） |
| 1000 | 0.995 | 高频平台 $2R_0$ |

反馈使 $Z_{in}$ 除以 $1 + T(s)$，而 $T(s)$ 在 $1/(R_0C_1)$ 以上以 20 dB/dec 的速率下降，因此 $Z_{in}$ 逐渐回升到开环值 $2R_0$。

### 结果

$$Z_{in} = \frac{2R_0\,(1 + sR_0C_1)}{1 + G_{m1}G_{m2}R_0^2 + sR_0C_1} = 2R_0\ \Big\|\ \left[\frac{2}{G_{m1}G_{m2}R_0} + s\,\frac{2C_1}{G_{m1}G_{m2}}\right]$$

（单边阻抗，即差分驱动下从一个输入节点到地的阻抗，为上式的一半：$R_0\parallel[1/(G_{m1}G_{m2}R_0) + sC_1/(G_{m1}G_{m2})]$）。

$|Z_{in}|$ 具有低频平台 $2R_0/(1 + G_{m1}G_{m2}R_0^2) \approx 2/(G_{m1}G_{m2}R_0)$、位于 $\omega_z = 1/(R_0C_1)$ 的零点、+20 dB/dec 的（感性）上升段、位于 $\omega_p = (1 + G_{m1}G_{m2}R_0^2)/(R_0C_1) \approx G_{m1}G_{m2}R_0/C_1$ 的极点，以及高频平台 $2R_0$。

**常见错误。** 忽略反馈，认为在所有频率下都有 $Z_{in} = 2R_0$。在低频下，$Z_{in}$ 是 $2R_0$ 除以完整的环路增益因子 $1 + G_{m1}G_{m2}R_0^2$。

**常见错误。** 因为“电路中有电容”就把 $|Z_{in}|$ 画成随频率下降。$C_1$ 位于 $G_{m2}$ 的**输出端**，它降低的是环路增益，因此 $|Z_{in}|$ 是**上升**的：回转器把 $C_1$ 变成了电感。

**常见错误。** 混淆单边阻抗与差分阻抗。在流过同一电流 $I_t$ 时，每个输入节点的电压只变化 $v_{in}/2$，因此两端之间的阻抗是单边阻抗的两倍；只要说明清楚，给出哪一个都可以。
