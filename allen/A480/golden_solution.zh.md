电荷定标 MSB 加电压定标 LSB，$N = 9$；例如 $M = 7$（电荷）、$K = 2$（电压），此时 INL ≈ 0.28 LSB，DNL ≈ 0.52 LSB。任何 $K \le 7$（即 $2 \le M \le 8$）的划分也都满足指标；电压 MSB/电荷 LSB 的组合最多只能达到 $N = 7$。

推导：
- 电荷 MSB/电压 LSB：DNL $= 0.01 + (2^N - 1)(0.001) \le 1$ → $2^N \le 991$ → $N \le 9$（N = 9：0.521 LSB；N = 10：1.033 LSB，不满足）。INL $= 2^{K-1}(0.01) + 2^{8}(0.001) = 0.256 + 0.01\cdot2^{K-1} \le 1$ → $2^{K-1} \le 74$ → $K \le 7$。取 $M = 7$、$K = 2$：INL $= 0.02 + 0.256 = 0.276$ LSB，DNL $= 0.521$ LSB（4 个电阻，电容值分散度为 64）。
- 电压 MSB/电荷 LSB：INL $\ge 2^{N-1}(0.01)$ → $2^{N-1} \le 100$ → $N \le 7$（N = 7：0.64 LSB + $2^{K-1}(0.001)$）；DNL $= 2^K(0.011) - 0.001 \le 1$ → $K \le 6$。因此最多 7 位，例如 $M = 1$…6，$K = 7 - M$。
- 因此电荷 MSB/电压 LSB 的 DAC 是更好的选择：9 位。
