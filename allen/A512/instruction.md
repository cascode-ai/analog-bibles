In an ideal pipeline algorithmic ADC each stage compares its input $V_{i-1}$ with zero: the stage bit is 1 ($b_{i-1} = +1$) if $V_{i-1} > 0$ and 0 ($b_{i-1} = -1$) otherwise, and the stage output $V_i = 2V_{i-1} - b_{i-1}V_{REF}$ drives the next stage; the first stage's input is the sampled input and the bits form the output word MSB first. The input is 1.5 V and $V_{REF}$ = 5 V. Find the digital output word up to 8 bits, in order of MSB to LSB. If $V_{REF}$ = 5.2 V and the input is still 1.5 V, at what bit does an error occur (the first bit that differs from the 5-V result)?
