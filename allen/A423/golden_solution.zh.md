$I_{OUT} = I_0 + \dfrac{I_1}{2} + \dfrac{I_2}{4} + \dfrac{I_3}{8}$。

将梯形网络的节点标为 A（$I_3$，R 接地）、B（$I_2$，2R 接地）、C（$I_1$，2R 接地）和 D（输出节点，电位 0 V，$I_0$）；水平电阻 R 分别连接 A–B、B–C 和 C–D。利用叠加原理（superposition）：
- $I_0$ 流入接地的节点 D，全部作为 $I_{OUT}$ 流出。
- C 处的 $I_1$ 有三条到地的通路：2R（竖直）、R（到 D）以及 R + (B 到地 = 2R ∥ (R + R) = R) = 2R。经 R 流到 D 的份额为 $(1/R)/(1/2R + 1/R + 1/2R) = 1/2$。
- B 处的 $I_2$ 看到 2R、R + R = 2R（左侧）和 R + (2R ∥ R) = 5R/3（右侧）；其中 3/8 流向右侧，其 2/3 到达 D：1/4。
- A 处的 $I_3$ 看到 R 和 R + [2R ∥ (5R/3)] = 21R/11；11/32 流向右侧，然后在 B 处取 6/11，在 C 处取 2/3：(11/32)(6/11)(2/3) = 1/8。
节点分析给出同样的结果。
