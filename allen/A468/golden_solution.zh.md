$R_x = 3R$。各开关从左到右依次为 $b_0$（基准节点处的 2R 支路）、$b_1$（基准节点处的 4R 支路）、$b_2$（$R_x$ 之后的 2R 支路）和 $b_3$（$R_x$ 之后的 4R 支路）；于是 $v_{OUT} = V_{REF}\left(\frac{b_0}{2} + \frac{b_1}{4} + \frac{b_2}{8} + \frac{b_3}{16}\right)$。

推导：
- 电源的 + 端接地，因此左下节点的电位为 $-V_{REF}$。每个支路电阻的另一端都处于 0 V（地或虚地），因此各支路电流与开关位置无关。
- $-V_{REF}$ 节点处的支路：$V_{REF}/2R$ 和 $V_{REF}/4R$。
- 节点 B（$R_x$ 右侧）对 0 V 看到的电阻为 $2R \| 4R \| 4R = R$，因此 $V_B = -V_{REF}\frac{R}{R_x + R}$；其支路电流为 $|V_B|/2R$ 和 $|V_B|/4R$。
- 二进制加权要求 $|V_B|/2R = V_{REF}/8R$，即 $|V_B| = V_{REF}/4$ → $R/(R_x + R) = 1/4$ → $R_x = 3R$。
- 被选中的电流从求和节点流出，并由反馈电阻 R 提供，因此 $v_{OUT} = +R\sum I = V_{REF}(b_0/2 + b_1/4 + b_2/8 + b_3/16)$。
