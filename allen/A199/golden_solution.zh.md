$A_i$ = −10 A/A，$R_{in}$ ≈ 1.8 kΩ，$R_{out}$ ≈ 22.2 kΩ。

- 偏置：二极管 M3（50 µA）设定 M1 的栅压，使 M1（W/L 相同）在输入节点为 0 V 时流过 50 µA；p 沟道一侧的 M4/M2 同理。M1 的电流流过二极管 M5，并被 M7 镜像放大 10 倍（100/1 对 10/1）；M2 的电流流过 M6，并被 M8 镜像放大 10 倍。静态时 M7 输出、M8 吸收 500 µA。
- 输入电阻：输入节点是 M1 和 M2 的源极，两管栅极均接固定电压：$R_{in} = 1/(g_{m1}+g_{m2})$，$g_{m1} = \sqrt{2\cdot110\cdot10\cdot50}$ µS = 332 µS，$g_{m2} = \sqrt{2\cdot50\cdot10\cdot50}$ µS = 224 µS → $R_{in}$ = 1.80 kΩ。
- 电流增益：$v_{in} = i_{in}R_{in}$；M1 的电流减小 $g_{m1}v_{in}$，M2 的电流增大 $g_{m2}v_{in}$，因此 M7 少输出 $10g_{m1}v_{in}$，M8 多吸收 $10g_{m2}v_{in}$：$i_{out} = -10(g_{m1}+g_{m2})v_{in} = -10i_{in}$（$i_{out}$ 取箭头方向，即流出放大器）。
- 输出电阻：M7 和 M8 的栅极位于 M5 和 M6 的二极管节点上，输出电压不会扰动这些节点（输出节点只接 M7 和 M8 的漏极，因此不需要题中关于 $g_{ds2}/g_{m6}$ 和 $g_{ds1}/g_{m5}$ 的条件），所以 $R_{out} = r_{ds7}\|r_{ds8} = 1/[(0.05+0.04)\cdot500\ \mu\mathrm{A}]$ = 22.2 kΩ。
- 以上是常用的手算值（标称偏置，直流电流中忽略 λ）。保留完整的 $(1+\lambda V_{DS})$ 直流模型（ngspice level 1）时，$I_{D1} = I_{D2}$ ≈ 49.7 µA，$I_{D7}$ ≈ 518 µA，$I_{D8}$ ≈ 516 µA（输出器件的 $|V_{DS}|$ = 2 V，对应的二极管主控器件 ≈ 1.0–1.1 V），并得到 $A_i$ ≈ −10.3，$R_{in}$ ≈ 1.77 kΩ，$R_{out}$ ≈ 23.4 kΩ；在标称偏置下保留 $g_{ds}$ 项则得到 $A_i$ ≈ −9.9。这些结果都同样正确。
