A CMOS current amplifier is shown in [Fig. 1] (W/L values in µm/µm are marked; supplies ±2 V; both reference sources are 50 µA; the input is driven by the current source $i_{in}$ and the output is short-circuited to ground). Find the small-signal values of the current gain $A_i = i_{out}/i_{in}$, the input resistance $R_{in}$ and the output resistance $R_{out}$. For $R_{out}$, assume that $g_{ds2}/g_{m6}$ is equal to $g_{ds1}/g_{m5}$. Neglect the body effect.

Device data: n-channel $V_T$ = 0.7 V, $K'_N$ = 110 µA/V², λ = 0.04 V⁻¹; p-channel $V_T$ = −0.7 V, $K'_P$ = 50 µA/V², λ = 0.05 V⁻¹.
