Plot the analog output versus the digital input word for a 3-bit DAC that has ±1.5 LSB differential nonlinearity (DNL) and ±0.5 LSB integral nonlinearity (INL), i.e. its largest positive and negative DNL are +1.5 LSB and −1.5 LSB and its largest positive and negative INL are +0.5 LSB and −0.5 LSB. Assume an arbitrary analog full-scale value.

Use these definitions: the ideal output for code $k$ ($k$ = 0 … 7, code 000 … 111) is $k$ LSB; the INL at a code is the actual output minus the ideal output at that code; the DNL at a transition between adjacent codes is the actual step minus 1 LSB.
