$Y_o(z) = z^{-1}X(z) + (1 - z^{-1})^2Q_2(z)$；$Q_1$ 被抵消，该调制器为二阶。

- 第一级：$V_1 = \dfrac{X - z^{-1}Y_1}{1 - z^{-1}}$ 且 $Y_1 = V_1 + Q_1$，因此 $Y_1 = X + (1 - z^{-1})Q_1$（从而 $V_1 = Y_1 - Q_1$）。
- 第二级输入：$z^{-1}V_1 - z^{-1}Y_1 = -z^{-1}Q_1$。
- 第二级（相同的环路）：$Y_2 = -z^{-1}Q_1 + (1 - z^{-1})Q_2$。
- 输出组合：$Y_o = z^{-1}Y_1 + (1 - z^{-1})Y_2$。$Q_1$ 各项相互抵消：$z^{-1}(1 - z^{-1})Q_1 - (1 - z^{-1})z^{-1}Q_1 = 0$。
- 结果：$Y_o = z^{-1}X + (1 - z^{-1})^2Q_2$，即二阶噪声整形（noise shaping）（一个 1-1 MASH 级联结构）。
