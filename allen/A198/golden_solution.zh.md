$R_{in} = \dfrac{r_{ds1}+r_{ds2}}{1 + g_{m2}r_{ds}(g_{m3}+g_{m4})(r_{ds3}\|r_{ds4})} = \dfrac{2r_{ds}}{1+g_mr_{ds}(g_{m3}+g_{m4})(r_{ds3}\|r_{ds4})} \approx \dfrac{2}{g_m(g_{m3}+g_{m4})(r_{ds3}\|r_{ds4})}$，其中 $g_m = g_{m1} = g_{m2}$，$r_{ds} = r_{ds1} = r_{ds2}$。

- 反相器：$v_C = -A v_{in}$，$A = (g_{m3}+g_{m4})(r_{ds3}\|r_{ds4})$；M2 的栅极跟随 $v_C$ 变化。
- 共源节点 S（由于忽略 $r_{ds5}$，尾电流恒定）：$i_{D1}+i_{D2} = 0$，其中 $i_{D1} = g_{m1}v_S + g_{ds1}(v_S - v_{in})$，$i_{D2} = g_{m2}(v_S - v_C) + g_{ds2}v_S$ → $v_S = v_{in}\dfrac{g_{ds1} - g_{m2}A}{g_{m1}+g_{m2}+g_{ds1}+g_{ds2}}$。
- 输入电流等于 M1 流入该节点的漏极电流取负：$i_{in} = g_{ds1}v_{in} - (g_{m1}+g_{ds1})v_S$，一般情况下得到 $R_{in} = \dfrac{g_{m1}+g_{m2}+g_{ds1}+g_{ds2}}{g_{ds1}(g_{m2}+g_{ds2}) + g_{m2}A(g_{m1}+g_{ds1})}$，对完全相同的 M1、M2 即化简为上面的表达式。
- 解释：输入电压升高时，反相器把 M2 的栅极拉低，使尾电流从 M1 转向 M2，于是流入输入节点的电流减小：这是环路增益（loop gain）≈ $g_mA/2$ 的并联负反馈，开环电阻 $2r_{ds}$ 被此环路增益相除而减小。
