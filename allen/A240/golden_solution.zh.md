设镜像比 $B = (W_3/L_3)/(W_2/L_2)$ = 100：
$\dfrac{v_{out}}{v_{in}} = \dfrac{(1+B)g_{m1}R_L}{1+(1+B)g_{m1}R_L}$，$R_{out} = \dfrac{1}{(1+B)g_{m1}} = \dfrac{1}{101g_{m1}}$（不包括 $R_L$）。
数值计算：$A_v$ ≈ 0.70 V/V，$R_{out}$ ≈ 21 Ω（计入 $R_L$ 时 ≈ 15 Ω）。

- M1 的小信号电流 $i_1 = g_{m1}(v_{in}-v_{out})$ 从 M1 的源极流入输出节点；同一电流流过二极管连接的 M2，并由 M3 放大 ×100 复制到输出端。在输出节点列 KCL：$(1+B)g_{m1}(v_{in}-v_{out}) = v_{out}/R_L$。
- 局部反馈（local feedback）使跟随器的跨导乘以 $1+B$，因此 $R_{out} = 1/[(1+B)g_{m1}]$。
- 偏置：1-mA 电流沉流过 M1 的电流加上其 100 倍（直流输出为 0 V，因此没有直流负载电流）：$I_{D1}$ = 1 mA/101 = 9.9 µA，$I_{D3}$ = 0.99 mA。
- $g_{m1} = \sqrt{2\cdot110\cdot100\cdot9.9}$ µS = 467 µS → $(1+B)g_{m1}$ = 47.1 mS → $R_{out}$ = 21.2 Ω；$A_v = 2.357/3.357$ = 0.702（$(1+B)g_{m1}R_L$ = 2.36）。
