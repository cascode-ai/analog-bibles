对于 [图 1] 所示以 p 沟道电流镜为负载的 n 沟道输入 CMOS 差分放大器，每个晶体管的等效输入噪声电压（equivalent input noise voltage）为 $1\ \mathrm{nV}/\sqrt{\mathrm{Hz}}$。若 $W_1/L_1 = W_2/L_2 = 2\ \mu$m$/1\ \mu$m，$W_3/L_3 = W_4/L_4 = 1\ \mu$m$/1\ \mu$m，$I_{SS} = 50\ \mu$A，求该放大器的等效输入噪声电压。在这些条件下，等效输出噪声电流（输出端的短路噪声电流）是多少？所有晶体管均处于饱和区。

器件参数：n 沟道 $K'_N = 110\ \mu\mathrm{A/V^2}$；p 沟道 $K'_P = 50\ \mu\mathrm{A/V^2}$；饱和区中 $i_D = \frac{K'W}{2L}(v_{GS}-V_T)^2$。
