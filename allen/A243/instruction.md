[Fig. 1] shows a model of a nonideal op amp: an ideal op amp (differential gain $A_v$) preceded by elements that model the input offset voltage $V_{OS}$, the noise sources, the input bias currents, the input resistances, and the common-mode rejection. The common-mode rejection ratio is modeled by the voltage-controlled voltage source labeled $v_1/\mathrm{CMRR}$ in series with the inverting input $v_2$, with the polarity shown. The op amp's output is defined as $V_{out} = A_v(V_1 - V_2) \pm A_c\dfrac{V_1 + V_2}{2}$, where $A_c$ is the common-mode gain, and $\mathrm{CMRR} = A_v/A_c$ (in magnitude).

Show that the controlled source designated $v_1/\mathrm{CMRR}$ is in fact a suitable model for the common-mode behavior of the op amp. Ignore $V_{OS}$, the noise sources, the bias currents and $R_{icm}$, $R_{id}$, $C_{id}$, $R_{out}$.
