除数为 3：$+INL = +1$ LSB，$-INL = 0$ LSB；$+DNL = +1/3$ LSB（≈ 0.33），$-DNL = -1$ LSB。输出从不下降，但在 0011→0100、0111→1000 和 1011→1100 处台阶为零（两个码给出相同的输出），因此该 DAC 恰好处于临界：只在不减的意义上单调，而非严格单调。
除数为 5：$+INL = 0$ LSB，$-INL = -0.6$ LSB；$+DNL = +0.6$ LSB，$-DNL = -0.2$ LSB；单调。

推导（1 LSB = $V_{REF}/16$；码 $= 4m + n$，其中 $m = 2b_0 + b_1$，$n = 2b_2 + b_3$）：
- 输出 $= 4m + 4n/d$ LSB；理想值 $= 4m + n$。
- $d = 3$：LSB 部分为 $4n/3$，误差 $+n/3$ = 0, 1/3, 2/3, 1 LSB。组内台阶：4/3 LSB（DNL = +1/3）；在组间跳变处，输出由 $4m + 4$ 变为 $4(m+1)$，台阶为 0（DNL = −1）。
- $d = 5$：LSB 部分为 $0.8n$，误差 $-0.2n$ = 0 … −0.6 LSB。组内台阶：0.8 LSB（DNL = −0.2）；组间跳变处：$4 - 2.4 = 1.6$ LSB（DNL = +0.6）。所有台阶均为正：单调。
