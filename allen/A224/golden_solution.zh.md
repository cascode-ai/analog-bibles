电路 6：$v_{in}$ 为高电平时，p 沟道跟随管 M2 截止，p 沟道电流源 M1 将空载输出一直上拉到 $V_{DD}$。

六个电路的 $v_o(\max)$：
- C1：$v_{in} = V_{DD}$ 时，M1 与二极管连接的 M2 是相同的 n 沟道器件，流过相同电流，因此 $V_{GS1} = V_{GS2}$ → $V_{DD}/2$。
- C2：p 沟道跟随管截止，p 沟道二极管负载使输出上升，直到其电流消失 → $V_{DD} - V_T$。
- C3：$v_{in} = V_{DD}$ 时 n 沟道跟随管对抗接地的 p 沟道二极管连接管：$\sqrt2(V_{DD}-v_o-V_T) = v_o - V_T$ → $v_o = [\sqrt2 V_{DD} - (\sqrt2-1)V_T]/(1+\sqrt2) \approx 0.59V_{DD} - 0.17V_T$。
- C4：p 沟道跟随管截止，接自 $V_{DD}$ 的 n 沟道器件（栅极接 $V_{DD}$）上拉输出，直到其电流消失 → $V_{DD} - V_T$。
- C5：$v_{in} = V_{DD}$ 时 n 沟道跟随管流过电流沉电流 $I$ → $V_{DD} - V_T - \sqrt{2I/\beta_N}$。
- C6：→ $V_{DD}$。
