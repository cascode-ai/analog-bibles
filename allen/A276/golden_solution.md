# Golden Solution - A276

## Reference answer

$A_v \approx 3.1\times10^3$; $R_{out} = 333$ kΩ; $p_1 \approx -1.4\times10^3$ rad/s (≈ −225 Hz); GB ≈ 0.70 MHz; SR = 2 V/µs; $P_{diss}$ = 1.4 mW.

- Currents: M7 (1/1) carries 20 µA; M4 (1/1) mirrors it as the 20-µA tail; M3 (1/1) mirrors half of M8's (2/1) 20 µA, i.e. 10 µA, which balances M1 (10 µA); M6 (5/1) sinks 100 µA, which M5 (10/1) carries at $V_{SG5} = V_{SG3} = V_{SG8} = 2.33$ V.
- First stage (single-ended output at the M1/M3 drains; M2's drain goes to $V_{DD}$): $g_{m1} = \sqrt{2(24\ \mu)(4)(10\ \mu)} = 43.8\ \mu$S; only half of the differential current, $g_{m1}v_{in}/2$, reaches the output node; $R_I = r_{ds1}\|r_{ds3} = 1/[(0.01 + 0.02)(10\ \mu)] = 3.33$ MΩ → $A_1 = (g_{m1}/2)R_I = 73$.
- Second stage: $g_{m5} = \sqrt{2(8\ \mu)(10)(100\ \mu)} = 126.5\ \mu$S, $R_{out} = R_{II} = 1/[(0.02 + 0.01)(100\ \mu)] = 333$ kΩ → $A_2 = 42.2$.
- $A_v = A_1A_2 \approx 3.08\times10^3$ (non-inverting from the + input at M1). (A more careful $R_I = r_{ds3}\|2r_{ds1}$ = 4 MΩ, since M1's source is degenerated by $1/g_{m2}$, gives ≈ 3.7 × 10³.)
- $p_1 \approx -\dfrac{1}{g_{m5}R_{II}R_IC_c} = -\dfrac{1}{42.2 \times 3.33\ \mathrm M \times 5\ \mathrm p} = -1.42\times10^3$ rad/s (−226 Hz); with $(1 + g_{m5}R_{II})$ instead of $g_{m5}R_{II}$: −1.39 × 10³ rad/s.
- $GB = \dfrac{g_{m1}/2}{C_c} = \dfrac{21.9\ \mu}{5\ \mathrm p} = 4.38\times10^6$ rad/s = 0.70 MHz.
- SR: the first-stage output node can be charged by M3's 10 µA (M1 off) or discharged by $20 - 10 = 10$ µA (M1 taking the whole tail), so SR $= 10\ \mu\mathrm A/5\ \mathrm{pF} = 2$ V/µs.
- $P_{diss} = 10\ \mathrm V \times (20 + 20 + 100)\ \mu\mathrm A = 1.4$ mW.

## Grading notes
