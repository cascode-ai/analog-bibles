$\dfrac{i_{out}}{i_{in}} = -\dfrac{r_mR_1}{R_3(R_1 + R_2 - r_m)}$。

- 移位：将电源 $r_mi$ 穿过 $R_2$ 与 $R_3$ 之间的节点，分别移入 $R_2$ 支路和 $R_3$ 支路并与之串联；该节点随之短接到地。在每条支路中，该电源使电阻的远端保持在 $-r_mi$。
- 替代：在 $R_2$ 支路中，电源流过的正是其自身的控制电流 $i$，并沿 $i$ 的方向在压降上增加 $-r_mi$，因此它等效于阻值为 $-r_m$ 的电阻：该支路变为 $R_2 - r_m$。
- 链式计算：输入端分流，$i = i_{in}\dfrac{R_1}{R_1 + R_2 - r_m}$；输出支路，$i_{out} = \dfrac{-r_mi}{R_3}$（$R_3$ 直接并接在理想电源两端，因此不会对电路其余部分形成负载）。于是 $i_{out}/i_{in} = -r_mR_1/[R_3(R_1 + R_2 - r_m)]$。
（用 KCL 验证：$v_A = iR_2 - r_mi$，$i_{in} = v_A/R_1 + i$。）
