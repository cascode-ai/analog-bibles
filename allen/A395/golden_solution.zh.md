环路增益（loop gain）≈ +22.7（忽略输出电导时 ≈ 25），远大于 1，因此该级是双稳态的（具有迟滞）。
- 电流：$i_1 = i_2 = 10\ \mu$A。M6 与 M3、M7 与 M4 分别共用 $V_{SG}$，且 $(W/L)_6/(W/L)_3 = 5$：$i_6 = 5i_3$，$i_7 = 5i_4$。由对称性，$i_3+i_7 = i_3+5i_3 = 10\ \mu$A → $i_3 = i_4 = 1.67\ \mu$A，$i_6 = i_7 = 8.33\ \mu$A。
- $g_{m3} = g_{m4} = \sqrt{2\cdot50\cdot2\cdot1.67}\ \mu\mathrm{S} = 18.3\ \mu$S；$g_{m6} = g_{m7} = \sqrt{2\cdot50\cdot10\cdot8.33}\ \mu\mathrm{S} = 91.3\ \mu$S。
- 环路：$v_{o1}$ 处的变化使 M6 向 $v_{o2}$ 注入 $g_{m6}v_{o1}$，该节点的电导为 $g_{m4}+g_{ds4}+g_{ds6}+g_{ds2} \approx 18.26+0.08+0.42+0.40 = 19.2\ \mu$S；M7 再以同样方式反馈回 $v_{o1}$。每一半给出 $91.3/19.2 = 4.77$（同号），因此 $LG = (4.77)^2 \approx 22.7$。
- 忽略输出电导时，$LG = \dfrac{g_{m6}g_{m7}}{g_{m3}g_{m4}} = \left(\sqrt{5\cdot5}\right)^2 = 25$。
