[图 1] 是一个经曲率校正（curvature correction）的低温度系数（temperature coefficient）电压基准的晶体管级实现。其各电流产生电路给出：$I_{PTAT}' = V_{PTAT}/R_1$，其中 $V_{PTAT} = V_t\ln10$（由 D1 ×1 和 D2 ×10 产生）；$I_{CTAT}' = V_{D3}/R_2$，其中 D3 由 PTAT 电流偏置（α = 1）；$I_{\alpha=0}' = V_{D4}/R_4$，其中 D4 由与温度无关的电流偏置（α = 0）。基准产生电路形成 $V_{REF} = R_5(I_{24} + I_{25} - I_{22})$，其中 M24、M25 和 M23 按各自 $W/L$ 的比例复制 $I_{PTAT}'$、$I_{CTAT}'$ 和 $I_{\alpha=0}'$ 的总线电流（总线器件为 M3、M8 和 M18），M21–M22 电流镜减去 M23 的电流。二极管电压服从 $V_D(T) = V_{G0} - \frac{T}{T_0}\left[V_{G0} - V_D(T_0)\right] - (\gamma - \alpha)V_t\ln\frac{T}{T_0}$，其中 $V_{G0}$ = 1.205 V，γ = 3.2，$V_{D3}(T_0) = V_{D4}(T_0)$ = 0.7 V，室温 $T_0$ 下 $V_t$ = 0.026 V。

原设计采用 1:1 的电流复制和电阻比，使室温下温度系数为零、非线性 $T\ln T$ 项相互抵消，并使 $V_{REF}$ = 1.0 V（取 $R_4$ = 10 kΩ）。假设所有电阻（除设定恒流产生电路的 $R_3$ 外）都相等，重做该设计。假设除 M23、M24 和 M25 外所有晶体管的 $W/L$ 均为 10（二极管面积如 [图 1] 所示）。设计 M23、M24 和 M25 的 $W/L$ 以及这些相等电阻的阻值。
