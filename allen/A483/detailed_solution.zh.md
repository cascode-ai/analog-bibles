# 详细步骤 - A483

每个开关要么把某个电容置为已知电压（$S_2$、$S_3$、$S_4$），要么在两电容之间分享电荷（$S_1$）。$C_1=C_2$ 时，电荷分享使两者电压都变为原电压的平均值。按顺序逐次闭合开关并应用这些规则。

### 第 1 步 — 各开关的作用

- $S_2$：$v_{C1}\to V_{REF}$；$S_3$：$v_{C1}\to0$；$S_4$：$v_{C2}\to0$。
- $S_1$：总电荷 $C_1v_{C1}+C_2v_{C2}$ 守恒，并重新分配到 $C_1+C_2$ 上：

$$
v_{C1}=v_{C2}=\frac{C_1v_{C1}+C_2v_{C2}}{C_1+C_2}=\frac{v_{C1}+v_{C2}}{2}\quad(C_1=C_2).
$$

### 第 2 步 — 开关序列

电压以 $V_{REF}$ 为单位：

| 闭合的开关 | $v_{C1}$ | $v_{C2}$ |
|---|---|---|
| $S_4$ | – | 0 |
| $S_3$ | 0 | 0 |
| $S_1$ | 0 | 0 |
| $S_2$ | 1 | 0 |
| $S_1$ | 0.5 | 0.5 |
| $S_3$ | 0 | 0.5 |
| $S_1$ | 0.25 | 0.25 |
| $S_2$ | 1 | 0.25 |
| $S_1$ | 0.625 | 0.625 |

最后一次重新分配为 $(1+0.25)/2=0.625$。

### 第 3 步 — 结果

$$
v_{C1}=v_{C2}=\frac58V_{REF}=0.625\,V_{REF}.
$$

该序列就是对位 0、1、0、1 按 LSB 在前进行的串行转换（每一位使 $C_1$ 充为 0 或 $V_{REF}$，再与 $C_2$ 求平均），即码字 1010，其值为 $10/16\,V_{REF}$。
