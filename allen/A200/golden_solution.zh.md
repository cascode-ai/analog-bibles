$A_v = \dfrac{v_{out}}{v_{in}} = \dfrac{r_{ds3} + g_{m2}r_{ds2}r_{ds3}}{r_{ds2}+r_{ds3}}$；$A_i = \dfrac{i_{out}}{i_{in}} = -\dfrac{r_{ds1}(1+g_{m2}r_{ds2})}{r_{ds1}(1+g_{m2}r_{ds2}) + r_{ds2}}$。

- M2 为共栅级（common-gate stage），源极为输入节点，漏极为输出节点，M1 为输入节点处的电流沉（$r_{ds1}$），M3 为输出端的电流源（$r_{ds3}$）。
- 电压增益：M2 从漏极到源极的电流为 $g_{m2}(0-v_{in}) + (v_{out}-v_{in})/r_{ds2}$；输出端不接负载时，它必须等于从 M3 流来的电流 $-v_{out}/r_{ds3}$：$v_{out}(g_{ds2}+g_{ds3}) = v_{in}(g_{m2}+g_{ds2})$，即上面的表达式（≈ $g_{m2}(r_{ds2}\|r_{ds3})$，同相）。
- 电流增益：$v_{out}$ = 0 时，$i_{in} = v_{in}(g_{ds1}+g_{m2}+g_{ds2})$，流入输出端的电流为 $i_{out} = -(g_{m2}+g_{ds2})v_{in}$，因此 $A_i = -(g_{m2}+g_{ds2})/(g_{m2}+g_{ds1}+g_{ds2})$，即上面的比值（≈ −1：输入电流经 M2 流到输出端，只减去在 $r_{ds1}$ 中损失的一小部分）。$r_{ds3}$ 不出现，是因为输出端的短路吸收了 M2 的全部信号电流。
