$W_2 = W_1\left[2 + \dfrac{L_2C_{ox}(5 - V_S - V_T)}{CGDO\,(V_S + V_T)}\right]^{-1}$，其中 $V_S = 2$ V，$V_T \approx 1.02$ V：$L_2 = 0.8\ \mu$m 时 $W_2 \approx 0.127\,W_1$（$L_2 = 1\ \mu$m 时 $\approx 0.107\,W_1$）。应采用允许的最小 $L_2$。

- 令 $V_X = V_S + V_T$，其中 $V_T(V_{SB} = 2\ \mathrm{V}) = 0.7 + 0.4(\sqrt{2.7} - \sqrt{0.7}) = 1.023$ V，因此 $V_X = 3.02$ V。
- 当 $\phi_1$ 降到 $V_X$，即 $\bar\phi_1 = 5 - V_X = 1.98$ V 时，M1 关断。此后 $\phi_1$ 从 $V_X$ 降到 0，通过 M1 的交叠电容（overlap capacitance）向 $C_1$ 耦合 $-W_1\,CGDO\,V_X$（其沟道电荷此前已流回电压源）。
- 在 $\bar\phi_1 = V_X$ 之前 M2 截止（其两端均为 2 V）。在 $\bar\phi_1 = 1.98$ V 到 $V_X$ 之间，它经两个交叠电容耦合：$2W_2\,CGDO\,(2V_X - 5)$。高于 $V_X$ 后它导通，从该节点吸取沟道电荷和交叠电荷：$W_2(L_2C_{ox} + 2\,CGDO)(5 - V_X)$。M2 提供的总电荷为 $W_2[2\,CGDO\,V_X + L_2C_{ox}(5 - V_X)]$，与 M1 的符号相反。
- 抵消条件：$W_2[2\,CGDO\,V_X + L_2C_{ox}(5 - V_X)] = W_1\,CGDO\,V_X$，由此得到上述结果。$L_2 = 0.8\ \mu$m 时的数值：$CGDO\,V_X = 6.65\times10^{-10}$ F/m，$L_2C_{ox}(5 - V_X) = 3.91\times10^{-9}$ F/m，$W_2/W_1 = 6.65/(13.3 + 39.1) = 0.127$。
- 该虚拟器件（dummy）比通常的半尺寸虚拟器件小得多，因为在慢速区 M1 的沟道电荷不会到达 $C_1$；需要抵消的只是其交叠馈通，而大部分抵消作用由 M2（宽度很小）的沟道电荷完成。上述推导成立的前提是 $V_X > 2.5$ V（M1 在 M2 导通之前已关断）。
