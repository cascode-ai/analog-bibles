# Golden Solution - A382

## Reference answer

One valid design: $I_6 = I_7 = 750\ \mu$A, $I_5 = 100\ \mu$A; $(W/L)_6 = 120$, $(W/L)_7 = 55$, $(W/L)_3 = (W/L)_4 = 8$, $(W/L)_1 = (W/L)_2 = 15$, $(W/L)_5 = 20$ (all $L = 1\ \mu$m); $C_I \approx 0.3$ pF; predicted $t_p \approx 22$ ns.

- Pole requirement: for small times the two-pole response is $v_{out} \approx A_v(0)V_{in}|p_1p_2|t^2/2$; it reaches half the swing when $t_p = 1/\sqrt{k|p_1p_2|}$. With equal poles ($m = 1$) and $k = 10$: $|p_I| = |p_{II}| = 1/(t_p\sqrt{10}) = 1.265\times10^7$ rad/s.
- Output stage: $|p_{II}| = I_7(\lambda_N+\lambda_P)/C_{II}$ → $I_7 = 1.265\times10^7\cdot5\ \mathrm{pF}/0.09 = 703\ \mu$A → 750 µA. $V_{SD6}(\mathrm{sat}) = V_{DD}-V_{OH} = 0.5$ V: $(W/L)_6 = 2\cdot750/(50\cdot0.25) = 120$; $V_{DS7}(\mathrm{sat}) = V_{OL}-V_{SS} = 0.5$ V: $(W/L)_7 = 2\cdot750/(110\cdot0.25) = 54.5 \to 55$.
- First stage: $|p_I| = (I_5/2)(0.09)/C_I$; equal poles need $I_5 = 2I_7C_I/C_{II}$. $C_{gs6} = \tfrac23(120)(1)(2.47\ \mathrm{fF}) + 0.22(120)\ \mathrm{fF} = 224$ fF alone, so a guess of $C_I \approx 0.3$ pF is needed (0.2 pF is too small): $I_5 = 2\cdot750\cdot0.3/5 = 90\ \mu$A → 100 µA.
- $V_{SG3} = V_{DD}-V_{icm}^++V_{TN} = 1.2$ V: $(W/L)_3 = I_5/[K'_P(0.5)^2] = 100/12.5 = 8$.
- Gain $A_v(0) = (V_{OH}-V_{OL})/V_{in}(\min) = 4000$; $g_{m6} = \sqrt{2\cdot50\cdot120\cdot750}\ \mu\mathrm{S} = 3.0$ mS; $g_{m1} = A_v(g_{ds2}+g_{ds4})(g_{ds6}+g_{ds7})/g_{m6} = 4000\cdot4.5\ \mu\mathrm{S}\cdot67.5\ \mu\mathrm{S}/3\ \mathrm{mS} = 405\ \mu$S; $(W/L)_1 = g_{m1}^2/(K'_NI_5) = 405^2/(110\cdot100) = 14.9 \to 15$.
- $C_I$ check: $C_{gd2} \approx 3.3$ fF, $C_{gd4} \approx 1.8$ fF, $C_{gs6} \approx 224$ fF, $C_{bd2} \approx 48$ fF, $C_{bd4} \approx 21$ fF → ≈ 0.30 pF, consistent with the guess.
- Tail: $V_{GS1} = 0.7+\sqrt{2\cdot50/(110\cdot15)} = 0.946$ V; $V_{DS5}(\mathrm{sat}) = V_{icm}^- - V_{GS1} - V_{SS} = 0.304$ V; $(W/L)_5 = 2\cdot100/(110\cdot0.304^2) = 19.7 \to 20$.
- Check: $|p_I| = 4.5\ \mu\mathrm{S}/0.30\ \mathrm{pF} = 1.5\times10^7$, $|p_{II}| = 67.5\ \mu\mathrm{S}/5\ \mathrm{pF} = 1.35\times10^7$ rad/s → $t_p \approx 1/\sqrt{10\cdot1.5\times10^7\cdot1.35\times10^7} \approx 22$ ns < 25 ns; $A_v = (405/4.5)(3000/67.5) = 4000$. M5 and M7 need separate bias branches (different $V_{GS}$).

## Grading notes

This is a design problem: accept any design that meets every stated specification with correct supporting calculations. +2: currents and sizes that give $|p_1p_2| \gtrsim 1.6\times10^{14}\ \mathrm{s^{-2}}$ (so that $t_p \le 25$ ns for $k = 10$, by the parabolic or the exact two-pole response), $A_v(0) \ge 4000$, $V_{SD6}(\mathrm{sat}) \le 0.5$ V and $V_{DS7}(\mathrm{sat}) \le 0.5$ V at the chosen current, M3 sized for $V_{icm}^+ = 2$ V and M5 for $V_{icm}^- = -1.25$ V, with a check of $C_I$ including $C_{gs6}$ (typical numbers: $I_7$ ≈ 700–800 µA, $(W/L)_6$ ≈ 110–130, $(W/L)_7$ ≈ 50–60). +1: a consistent design that skips or mis-estimates the $C_I$ check (e.g., keeps $C_I = 0.2$ pF although $C_{gs6}$ alone exceeds it) but still meets $t_p$ within ≈ 10 %, or one size with a slip. 0: output stage right but the first stage missing or inconsistent with the gain requirement. −2 (asserted as fact): a design presented as meeting the specifications that clearly does not (e.g., poles from $g_m/C$ instead of $g_{ds}/C$, $t_p$ several times too long, gain below 4000), or the slewing (Class-A current) criterion used instead of the pole criterion with no check of the linear delay. The sizes, bias currents (30 µA, 234 µA) and $C_I = 0.2$ pF annotated in [Fig. 1] belong to the earlier design whose topology is reused; they are not specifications. A design that reuses them is graded like any other: it must be shown to meet the specifications (keeping $C_I = 0.2$ pF without a valid check is the +1 case above).
