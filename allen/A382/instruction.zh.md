设计一个 [图 1] 所示形式的两级开环比较器（n 沟道输入对管 M1–M2，p 沟道电流镜负载 M3–M4，尾电流源 M5；p 沟道共源输出管 M6，n 沟道电流沉 M7；无补偿），使其具有线性（非压摆）响应，并满足以下指标：
输入阶跃为分辨率的 10 倍（$V_{in} = 10\,V_{in}(\min)$）时传播延迟 $t_p = 25$ ns，$V_{in}(\min) = 1$ mV，$V_{OH} = 2$ V，$V_{OL} = -2$ V，$V_{DD} = 2.5$ V，$V_{SS} = -2.5$ V，输出负载 $C_{II} = 5$ pF，输入共模范围从 $V_{icm}^- = -1.25$ V 到 $V_{icm}^+ = 2$ V。所有沟道长度均为 1 µm。给出 M1–M7 的 W/L 以及偏置电流 $I_5$（尾电流）和 $I_6 = I_7$，并核验你的设计所假设的第一级输出端电容 $C_I$。利用线性两极点阶跃响应（极点位于第一级和第二级输出端）将 $t_p$ 与极点联系起来。

器件数据：$K'_N = 110\ \mu\mathrm{A/V^2}$，$K'_P = 50\ \mu\mathrm{A/V^2}$，$V_{TN} = 0.7$ V，$V_{TP} = -0.7$ V，$\lambda_N = 0.04\ \mathrm{V^{-1}}$，$\lambda_P = 0.05\ \mathrm{V^{-1}}$（$L = 1\ \mu$m），$C_{ox} = 24.7\times10^{-4}\ \mathrm{F/m^2}$，$C_{GSO} = C_{GDO} = 220\times10^{-12}$ F/m，$C_J = 770\ \mu\mathrm{F/m^2}$（n），560 µF/m²（p），$C_{JSW} = 380$ pF/m（n），350 pF/m（p）。计算结电容时可假设漏区面积为 $W \times 3\ \mu$m、零偏置。
