$V_{icm}(\text{upper}) = V_{DD} - V_{SD4}(sat) + V_{T1}$；$V_{icm}(\text{lower}) = V_{DS3}(sat) + V_{GS1} = V_{DS3}(sat) + V_{T1} + V_{DS1}(sat)$。代入数值：1.3 V 和 0.4 V，因此 ICMR 为 0.4–1.3 V，即 0.9 V。

- 上限：M1 的漏极被固定在折叠节点电压 $V_{DD} - V_{SD4}(sat)$（M4 处于饱和边缘）；只要 $V_{D1} \ge v_{icm} - V_{T1}$，M1 就保持饱和，由此得 $1.5 - 0.2 + 0 = 1.3$ V。
- 下限：尾电流管 M3 需要 $V_{DS3}(sat)$，M1 需要 $V_{GS1} = V_{T1} + V_{DS1}(sat)$：$0.2 + 0 + 0.2 = 0.4$ V。
- 两个限值都在电源轨之内，因此 ICMR = 0.9 V，大致位于 1.5 V 电源范围的中部。（若采用 0.5 V 阈值的标准输入器件，范围为 0.9 V 到 1.5 V，只有 0.6 V。）
