# 详细步骤 - A517

在 [图 1] 中，失调源与各比较器的输入串联，因此只影响判决；节点电压 $v(i+1)=2v(i)-b_iV_{REF}$ 只取决于输入和各位。在失调使某个比较器看到相反符号之前，一切都不改变，因此引起错误的最小失调等于最接近零的节点电压。

### 第 1 步 — 理想节点电压

以 $V_{REF}$ 为单位，$v(0)=0.6$，$v(i)>0$ 时 $b_i=+1$：

| 节点 | 电压 | 位 |
|---|---|---|
| $v(0)$ | 0.6 | $b_0=+1$ |
| $v(1)$ | $1.2-1=0.2$ | $b_1=+1$ |
| $v(2)$ | $0.4-1=-0.6$ | $b_2=-1$ |
| $v(3)$ | $-1.2+1=-0.2$ | $b_3=-1$ |
| $v(4)$ | $-0.4+1=0.6$ | $b_4=+1$ |

### 第 2 步 — 失调的影响

按图中极性，比较器 $i$ 将 $v(i)+V_{OS}$ 与地比较。若判决不变，各节点电压与上表完全相同，因为 $V_{OS}$ 不在信号通路上。只有当 $v(i)+V_{OS}$ 改变符号时，判决才改变：

- $V_{OS}=+0.2V_{REF}$ 使 $v(3)+V_{OS}$ 从 $-0.2V_{REF}$ 变为零，$b_3$ 翻转；
- $V_{OS}=-0.2V_{REF}$ 使 $v(1)+V_{OS}$ 从 $+0.2V_{REF}$ 变为零，$b_1$ 翻转。

其余节点离零都是 $0.6V_{REF}$。

### 第 3 步 — 最小失调

$$
|V_{OS}|_{min}=\min_i|v(i)|=0.2\,V_{REF}.
$$

失调容限不会沿流水线缩小，因为失调直接作用于每次判决，而不会被后续各级放大。
