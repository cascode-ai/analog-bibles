实现方法：把每个简单电流镜（M1–M2 和 M3–M4）都换成改进型高摆幅共源共栅电流镜。对每个电流镜，输入电流（$I$ 加信号）流入输入侧共源共栅器件（[图 2] 中的 M5）的漏极，该漏极接到两个底部器件（[图 2] 中的 M3、M1）的栅极；共源共栅管的栅极（M5、M2）由另一个 W/L 为其 1/4、由自身参考电流馈电的二极管连接器件偏置在 $V_T + 2V_{ON}$（一条偏置支路可同时服务两个电流镜）。第一个电流镜的输入是 $I$ 和 $i_2$ 流入的节点；其输出侧馈入 $2I$ 和 $i_1$ 流入的节点，该节点即第二个电流镜的输入；第二个电流镜的输出侧馈入带有电流源 $I$ 的输出节点。

每个输入节点都位于某个底部器件的栅极，因此（对 $g_mr_{ds} \gg 1$）$R_{in} \approx 1/g_m$，此处为该器件的跨导（精确值为 $(g_{m5}+g_{ds3}+g_{ds5})/[g_{m3}(g_{m5}+g_{ds5})+g_{ds3}g_{ds5}]$，略大于 $1/g_{m3}$），输入直流电压为 $V_{GS} = V_T + V_{ON}$，其中 $V_{ON} = 2I/g_m$。

三项指标相互矛盾（$I$ = 100 µA，即每个输入侧晶体管的静态电流）：
- 在 100 µA 下 $R_{in}$ = 1 kΩ 要求 $g_m$ = 1 mS → $V_{ON}$ = 0.2 V → $W/L = 2I/(K'V_{ON}^2)$ = 45.5，此时输入直流电压为 0.9 V，而不是 1.0 V。
- 输入为 1.0 V 要求 $V_{ON}$ = 0.3 V → $g_m$ = 0.667 mS → $R_{in}$ = 1.5 kΩ，而不是 1 kΩ。
- 在输入端加串联电阻 $R$（或采用源极负反馈）无济于事：此时 $R_{in} = R + V_{ON}/(2I)$，$V_{in} = V_T + V_{ON} + IR$，因此 $V_{in} - V_T - IR_{in} = V_{ON}/2$，即 $V_{ON}$ = 2(0.3 − 0.1) V = 0.4 V，这要求 $R < 0$。
- 从每个输入端接一个并联电阻到 1.0 V 参考电压（3 kΩ ∥ 1.5 kΩ = 1 kΩ）可以满足输入指标，但会分走信号：每个输入电流只有 $\alpha = 2/3$ 到达电流镜，因此 $i_O = \alpha i_1 - \alpha^2 i_2 = \tfrac23 i_1 - \tfrac49 i_2$，而不是 $i_1 - i_2$（已经仿真证实），除非重新调整电流镜比例和偏置电流加以补偿。
因此仅靠电流镜本身无法同时满足这三项指标。合理的设计：(1) 所有电流镜晶体管 W/L ≈ 45（例如 45 µm/1 µm），各流过 100 µA，偏置二极管 W/L ≈ 11，流过 100 µA，$2I$ = 200 µA：$R_{in}$ = 1 kΩ，输入为 0.9 V；或 (2) 采用相同尺寸，但把所有 n 沟道电流镜器件和共源共栅偏置器件的源极接到一条低阻的 +0.1 V 直流电源轨：输入为 1.0 V，$R_{in}$ ≈ 1 kΩ，100 µA，共源共栅偏置为 1.2 V，并保持 $i_O = i_1 - i_2$（level-1 仿真：0.999 V，1.05 kΩ，电流增益 1.02；多出的 5 % 是因为偏置二极管恰为 1/4 尺寸时 M3 处于线性区边缘，把偏置器件取得稍小一些即可消除）。

另一种理解：若“流入输入端的直流偏置电流”指每个输入端口各流过 100 µA 的直流电流，则矛盾消失，但无法保持 [图 1] 中 1:2:1 的电流源比例：电流镜支路取 150 µA（$V_{ON}$ = 0.3 V，$g_m$ = 1 mS，W/L ≈ 30，偏置二极管 ≈ 7.5），电流源取 50、200 和 150 µA，可得到 1.0 V、1 kΩ 和 $i_O = i_1 - i_2$。
