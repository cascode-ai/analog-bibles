# Golden Solution - A195

## Reference answer

Implementation: replace each simple mirror (M1–M2 and M3–M4) by an improved high-swing cascode mirror. For each mirror the input current ($I$ plus signal) enters the drain of the input-side cascode device (M5 in [Fig. 2]), whose drain is tied to the gates of the two bottom devices (M3, M1 in [Fig. 2]); the cascode gates (M5, M2) are biased at $V_T + 2V_{ON}$ by a separate diode-connected device of 1/4 the W/L fed by its own reference current (one bias branch may serve both mirrors). The first mirror's input is the node where $I$ and $i_2$ enter; its output side feeds the node where $2I$ and $i_1$ enter, which is the input of the second mirror; the output side of the second mirror feeds the output node with its current source $I$.

Each input node sits at the gate of a bottom device, so (for $g_mr_{ds} \gg 1$) $R_{in} \approx 1/g_m$ of that device (exactly $(g_{m5}+g_{ds3}+g_{ds5})/[g_{m3}(g_{m5}+g_{ds5})+g_{ds3}g_{ds5}]$, slightly above $1/g_{m3}$) and the input dc voltage is $V_{GS} = V_T + V_{ON}$, with $V_{ON} = 2I/g_m$.

The three specifications conflict (with $I$ = 100 µA, the quiescent current of each input-side transistor):
- $R_{in}$ = 1 kΩ at 100 µA requires $g_m$ = 1 mS → $V_{ON}$ = 0.2 V → $W/L = 2I/(K'V_{ON}^2)$ = 45.5 and an input dc voltage of 0.9 V, not 1.0 V.
- A 1.0-V input requires $V_{ON}$ = 0.3 V → $g_m$ = 0.667 mS → $R_{in}$ = 1.5 kΩ, not 1 kΩ.
- Adding a series resistance $R$ at the input (or source degeneration) does not help: then $R_{in} = R + V_{ON}/(2I)$ and $V_{in} = V_T + V_{ON} + IR$, so $V_{in} - V_T - IR_{in} = V_{ON}/2$, i.e. $V_{ON}$ = 2(0.3 − 0.1) V = 0.4 V, which needs $R < 0$.
- A shunt resistor from each input to a 1.0-V reference (3 kΩ ∥ 1.5 kΩ = 1 kΩ) meets the input numbers but diverts signal: only $\alpha = 2/3$ of each input current reaches the mirror, so $i_O = \alpha i_1 - \alpha^2 i_2 = \tfrac23 i_1 - \tfrac49 i_2$, not $i_1 - i_2$ (confirmed by simulation), unless the mirror ratios and bias currents are rescaled to compensate.
So the mirror by itself cannot meet all three. Reasonable designs: (1) all mirror transistors W/L ≈ 45 (e.g. 45 µm/1 µm) with 100 µA each, bias diode W/L ≈ 11 with 100 µA, $2I$ = 200 µA: $R_{in}$ = 1 kΩ, input at 0.9 V; or (2) the same sizes with the sources of all n-channel mirror and cascode-bias devices returned to a stiff +0.1-V dc rail: input at 1.0 V, $R_{in}$ ≈ 1 kΩ, 100 µA, cascode bias 1.2 V, $i_O = i_1 - i_2$ kept (level-1 simulation: 0.999 V, 1.05 kΩ, current gain 1.02; the extra 5 % comes from M3 sitting at the triode edge when the bias diode is exactly 1/4 size, which a slightly smaller bias device removes).

Other reading: if "the dc bias current flowing into the input" means a 100-µA dc current carried by each input port, the conflict disappears but the 1:2:1 source ratio of [Fig. 1] cannot be kept: mirror branches at 150 µA ($V_{ON}$ = 0.3 V, $g_m$ = 1 mS, W/L ≈ 30, bias diode ≈ 7.5), sources 50, 200 and 150 µA give 1.0 V, 1 kΩ and $i_O = i_1 - i_2$.

## Grading notes

+2: a correct high-swing-cascode implementation of both mirrors, $R_{in} \approx 1/g_m$ and $V_{in} = V_T + V_{ON}$ derived, and a demonstration that 1 kΩ, 100 µA and 1.0 V cannot all be met by the mirror alone, followed by a design that meets the achievable specifications (W/L ≈ 45, 0.9 V) or a legitimate added element that meets all three while keeping $i_O = i_1 - i_2$ (e.g. the sources of all the n-channel mirror and cascode-bias devices returned to a 0.1-V dc rail, applied consistently to the whole mirror; a shunt resistor to a 1.0-V reference only if its signal division is compensated). Channel-length-modulation refinements (≈ 1 %) are optional; a slightly inconsistent λ correction is not penalized. +1: correct implementation and sizing (W/L ≈ 45, $R_{in}$ = 1 kΩ) with the input voltage correctly computed as 0.9 V but the conflict not discussed; or the conflict found but the proposed fix is an uncompensated shunt resistor claimed to meet everything (it breaks $i_O = i_1 - i_2$); or the other reading (100 µA dc carried by each input port) stated openly and designed correctly, with the change of the source ratio from 1:2:1 acknowledged and $i_O = i_1 - i_2$ kept (e.g. 150-µA branches, W/L ≈ 30, sources 50/200/150 µA). 0: implementation right but sizing missing or wrong by a slip; or the other reading adopted without acknowledging that the Fig. 1 source ratio no longer holds. −2 (asserted as fact): a design claimed to give 1 kΩ, 100 µA and 1.0 V simultaneously with the mirror alone at 100-µA branch current (e.g. W/L ≈ 45 stated to give a 1.0-V input), $R_{in}$ taken as $1/g_m$ of a cascode device in series, the input placed at the cascode-bias node, or a wrong mirror topology.
