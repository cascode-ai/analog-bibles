$\dfrac{v_{out}}{v_{in}} = -\dfrac{A_vR_2}{R_2 + (1 + A_v)R_1} = -\dfrac{R_2}{R_1}\cdot\dfrac{1}{1 + \dfrac{R_1 + R_2}{A_vR_1}}$，当 $A_v \to \infty$ 时趋于 $-R_2/R_1$。

推导：$R_1$、该电源和 $R_2$ 构成一个单回路。设电流 $I$ 从 $R_1$ 上端经电源流向输出节点，再向下流过 $R_2$；则 $v_{out} = IR_2$，$v_1 = -IR_1$。
- 拆分电源：$A_v(v_{in} - v_1) = A_vv_{in} + A_vR_1I$。第二部分是与流过 $R_1$ 的回路电流成正比的电压，即相当于串联了一个电阻 $A_vR_1$。电路化简：将受控部分短路，并将 $R_1$ 乘以 $1 + A_v$；回路中保留一个独立源 $A_vv_{in}$。
- 化简后的回路：$A_vv_{in}$ 与 $(1 + A_v)R_1$ 及 $R_2$ 串联，因此 $I = -A_vv_{in}/[(1 + A_v)R_1 + R_2]$（符号由 $v_1 - v_{out} = A_v(v_{in} - v_1)$ 确定）。
- $v_{out} = IR_2 = -A_vR_2v_{in}/[R_2 + (1 + A_v)R_1]$。
该电路是一个有限增益的反相放大器（inverting amplifier）：当 $A_v$ 很大时，电源迫使 $v_1 \to v_{in}$，回路电流变为 $-v_{in}/R_1$，$v_{out} \to -(R_2/R_1)v_{in}$。
