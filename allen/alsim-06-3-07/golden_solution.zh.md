- 偏置：$I_8 = (5\ \mathrm V - V_{SG8})/R_S$，其中 $V_{SG8} = 0.7 + \sqrt{2I_8/(50\ \mu \cdot 3)}$ → $I_8 = 36.1$ µA（$V_{SG8}$ = 1.39 V）；$I_5 = I_8 = 36.1$ µA（M5 = M8 = 3/1）；$I_7 = I_6 = (5/3)I_8 = 60.1$ µA。

- 输出电阻：$R_{out} = 1/(g_{ds6} + g_{ds7}) = 185$ kΩ。
- 功耗：$P_{diss} = 5\ \mathrm V \times (36.1 + 36.1 + 60.1)\ \mu\mathrm A = 0.66$ mW。
