两种方法给出相同的结果：

$R_{out} = \dfrac{v_o}{i_o} = \dfrac{R_4(R_1R_2 + R_1R_3 + R_2R_3)}{R_1R_2 + R_1R_3 + R_1R_4 + R_2R_3 + R_3R_4 + g_mR_1R_3R_4} = R_4 \,\Big\|\, \dfrac{R_2 + R_1\parallel R_3}{1 + g_m(R_1\parallel R_3)}$。

密勒简化：$v_{in} = 0$ 时，节点 $v_1$ 对地看到的是 $R_1 \parallel R_3 \equiv R_{13}$，并且只通过跨接电阻 $R_2$ 由输出端驱动，因此 $v_1 = v_oR_{13}/(R_2 + R_{13})$，$K = v_o/v_1 = 1 + R_2/R_{13}$。折算到输出端：$R_2K/(K - 1) = R_2 + R_{13}$。受控源吸取的电流为 $g_mv_1 = g_mv_oR_{13}/(R_2 + R_{13})$，相当于一个电阻 $(R_2 + R_{13})/(g_mR_{13})$。因此 $R_{out} = R_4 \parallel (R_2 + R_{13}) \parallel \dfrac{R_2 + R_{13}}{g_mR_{13}} = R_4 \parallel \dfrac{R_2 + R_{13}}{1 + g_mR_{13}}$。（输入侧的元件 $R_2/(1 - K) = -R_{13}$ 抵消了 $R_{13}$，这与节点 $v_1$ 只通过 $R_2$ 馈电相一致。）

直接计算：外加 $v_o$；$v_1(G_1 + G_2 + G_3) = G_2v_o$；$i_o = G_4v_o + g_mv_1 + G_2(v_o - v_1)$，因此 $\dfrac{i_o}{v_o} = G_4 + \dfrac{G_2(G_1 + G_3 + g_m)}{G_1 + G_2 + G_3}$，各项乘以 $R_1R_2R_3R_4$ 后即得上式。

比较：两者完全相同。只要 $K$ 是同一激励下两个节点电压的真实比值，密勒简化就是精确的；这里 $K$ 由分压关系精确得出，因此没有引入任何近似。当 $g_mR_{13} \gg 1$ 且 $R_4$ 很大时，$R_{out} \approx (1 + R_2/R_{13})/g_m$。
