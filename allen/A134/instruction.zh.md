对于 [图 1] 所示的 CMOS 推挽（push-pull）反相器，若 $I_D = 200\ \mu$A，$W_1/L_1 = W_2/L_2 = 5\ \mu$m$/1\ \mu$m，$C_{gd1} = C_{gd2} = 5$ fF，$C_{bd1} = C_{bd2} = 30$ fF，$C_L = 10$ pF，求小信号电压增益 $A_v$、输出电阻 $R_{out}$ 和 −3 dB 频率 $f_{-3\,\mathrm{dB}}$。两个晶体管都处于饱和，输入由理想电压源驱动。

器件参数：n 沟道 $K'_N = 110\ \mu\mathrm{A/V^2}$，$\lambda_N = 0.04\ \mathrm{V^{-1}}$；p 沟道 $K'_P = 50\ \mu\mathrm{A/V^2}$，$\lambda_P = 0.05\ \mathrm{V^{-1}}$；饱和区中 $i_D = \frac{K'W}{2L}(v_{GS}-V_T)^2(1+\lambda v_{DS})$。
