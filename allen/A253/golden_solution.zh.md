- 从 M6 的栅极（第一级输出，电压为 $v_1$）到输出端有两条信号通路：经过晶体管的反相通路（向输出节点注入 $-g_{m6}v_1$）和经过 $C_c$ 的同相前馈（feedforward）通路（$+sC_cv_1$）。短路输出电流为 $(sC_c - g_{m6})v_1$，因此 $V_{out} \propto (g_{m6} - sC_c)$：两条通路在 $s = g_{m6}/C_c$ 处大小相等、符号相反，这就是正实轴上的零点 $z_1 = g_{m6}/C_c$。
- 低频时晶体管通路占主导；高于 $g_{m6}/C_c$ 后电容通路占主导，增益不再下降（该零点像左半平面零点一样抬高幅值），而相位却额外滞后最多 90°（像左半平面极点一样），从而使相位裕度变差。
- CMOS 与 BJT 的比较：$z_1 = g_{m6}/C_c$，而 GB $= g_{m1}/C_c$，因此 $z_1/GB = g_{m6}/g_{m1}$。在相同电流下，MOSFET 的跨导要小得多（$g_m = 2I_D/V_{ov}$，$V_{ov}$ 为几百 mV；而 BJT 的跨导为 $I_C/V_T$，$V_T = 26$ mV），因此在 CMOS 运放中零点靠近 GB（与输出极点相当），不能忽略；而在 BJT 运放中，第二级的大 $g_m$ 使零点远高于 GB。
