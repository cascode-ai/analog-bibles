# Golden Solution - A346

## Reference answer

Common-mode loop gain ≈ $-1.8\times10^4$ V/V (≈ $-g_{m10}\cdot g_{mN}r_{dsN}^2$).

- The loop is the same as without cascodes (M10/M11 → node S → M7 → output), but the output node now sees cascode resistances.
- Down: n-channel cascode, $g_{mN}r_{dsN}^2 = 331.7\ \mu\times(500\ \mathrm{k})^2 = 82.9$ MΩ. Up: the p-channel cascode over M7, whose source is itself degenerated by $r_{ds10}$: several GΩ (≈ 3.3 GΩ). Output CM resistance ≈ 82 MΩ.
- With the output shorted, M7's source resistance is ≈ $1/g_{m7}$ ≪ $r_{ds10}$, so ≈ 98% of M10's current reaches the output.
- $LG \approx -g_{m10}(0.98)(81.8\ \mathrm{M\Omega}) \approx -1.8\times10^4$ V/V (a nodal analysis gives −18,100); the cascoding raises the loop gain by about $g_{mN}r_{dsN}$ ≈ 166 compared with the uncascoded loop of part (a) of the textbook problem (7.3-11(a), LG ≈ −111).
