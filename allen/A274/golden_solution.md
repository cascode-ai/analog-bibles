# Golden Solution - A274

## Reference answer

$P_{diss} = (V_{DD} - V_{SS})(I_8 + I_5 + I_7) = 3\ \mathrm V \times (22.8 + 45.7 + 228)\ \mu\mathrm A \approx 0.89$ mW.
