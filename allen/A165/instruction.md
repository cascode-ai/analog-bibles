If all the devices in the CMOS differential amplifier with a current-mirror load shown in [Fig. 1] are saturated, find the worst-case input-offset voltage $V_{OS}$ using the parameters below. Assume that $10(W_4/L_4) = 10(W_3/L_3) = W_2/L_2 = W_1/L_1 = 10\ \mu$m$/10\ \mu$m. Treat the ± tolerances as the range over which the parameters of each transistor can vary independently. The tail current $I_{SS}$ is not specified: give the worst-case $|V_{OS}|$ as a function of $I_{SS}$ (a first-order expression is acceptable) and evaluate it for $I_{SS} = 100\ \mu$A. State and justify any assumptions you use.

Parameters: n-channel $V_{T0} = 0.7 \pm 0.15$ V, $K'_N = 110\ \mu\mathrm{A/V^2} \pm 10\,\%$; p-channel $V_{T0} = -0.7 \pm 0.15$ V, $K'_P = 50\ \mu\mathrm{A/V^2} \pm 10\,\%$; in saturation $i_D = \frac{K'W}{2L}(v_{GS}-V_T)^2$.
