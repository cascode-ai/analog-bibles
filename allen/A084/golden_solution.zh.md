- 两种电路的输出电阻均为 $r_{out} = r_{ds2}(1 + g_{m2}R_S) + R_S$，其中 $R_S$ 为 M2 源极到地的电阻。要得到相同的 $r_{out}$（≈ 19 MΩ），二极管连接的 M1 必须呈现 $R_S = 100$ kΩ。
- 二极管连接晶体管的 $R_S = 1/(g_{m1} + g_{ds1}) \approx 1/g_{m1}$，因此 $g_{m1} = 10\ \mu\mathrm{A/V}$。
- $g_{m1} = \sqrt{2K'(W/L)_1I}$ → $(W/L)_1 = g_{m1}^2/(2K'I) = (10\ \mu)^2/(2\times110\ \mu\times10\ \mu) = 0.0455 = 1/22$。（保留 $g_{ds1}$ = 0.4 µA/V 时得 $g_{m1}$ = 9.6 µA/V，$W/L$ ≈ 1/24。若严格采用给定的饱和区方程，在偏置方程中计入 $(1+\lambda V_{GS1})$ 并取 $g_{ds1} = \lambda I/(1+\lambda V_{DS1})$，则得 $V_{ON1}$ = 2.07 V，$(W/L)_1$ ≈ 0.038 ≈ 1/26。在该模型的精度范围内，三者都是正确的。）
- 后果：$V_{ON1} = \sqrt{2I/(K'(W/L)_1)} = 2.0$ V，因此 $V_{GS1} = 2.7$ V，压降很大。
