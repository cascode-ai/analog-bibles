A folded-cascode op amp is used open-loop as a comparator. Its relevant data are: differential voltage gain $A_v(0) = 3678$ V/V; output resistance $R_{out} = 7.44$ MΩ, which sets a single dominant pole at the output; n-channel input pair with tail current $I_3 = 100\ \mu$A; folding (p-channel) current sources $I_4 = I_5 = 125\ \mu$A; output range from 0.5 V to 2 V. Find the dominant pole if the load is $C_L = 5$ pF. If the input step is 10 mV, determine whether the response is linear or slewing and find the propagation delay time (time for the output to move half of its 1.5 V swing).
