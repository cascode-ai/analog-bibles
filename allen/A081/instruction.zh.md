[图 1] 所示的四个 MOS 二极管构成一个开关：当 $I_{control}$ = 200 µA（导通）时将 $v_{in}$ 连接到 1 kΩ 负载电阻，当 $I_{control}$ = 0（断开）时将其断开。M1 和 M2 为 n 沟道器件，$W/L$ = 100/1；M3 和 M4 为 p 沟道器件，$W/L$ = 200/1；每个器件都接成二极管连接（diode-connected）形式。$v_{in}$ 不含直流分量。求 $I_{control}$ = 200 µA 时该开关结构导通电阻（on-resistance）的小信号值。开关导通时的开关损耗是多少 dB？若用该开关（四个 MOS 二极管及其控制电流）代替 [图 2] 中的 MOSFET 开关（一个由时钟 $V_\phi$ 驱动栅极、将 $v_{in}$ 连接到电容 $C$ 的 n 沟道 MOSFET），比较这两种开关实现的性能。

器件参数：n 沟道 $V_T = 0.7$ V，$K' = 110\ \mu\mathrm{A/V^2}$；p 沟道 $V_T = -0.7$ V，$K' = 50\ \mu\mathrm{A/V^2}$。忽略沟道长度调制（channel-length modulation）和体效应（body effect）。
