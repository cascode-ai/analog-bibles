$R_{ON} \approx 690\ \Omega$；接 1 kΩ 负载时的损耗 ≈ −4.6 dB。与单个 MOSFET 开关相比，该桥式开关消耗静态功耗，断开时隔离较差，并会引入失调；其优点是电阻由控制电流决定，几乎与信号电平无关，而且信号节点上没有由时钟驱动的栅极。

- 偏置：$v_{in}$ 与 $v_{out}$ 的直流电平均为 0 V 时电桥对称，因此每个二极管流过 100 µA（$R_L$ 和信号源中都没有直流电流）。
- $g_m = \sqrt{2K'(W/L)I}$：n 沟道为 $\sqrt{2\times110\ \mu\times100\times100\ \mu} = 1.48$ mS（1/$g_m$ = 674 Ω）；p 沟道为 $\sqrt{2\times50\ \mu\times200\times100\ \mu} = 1.41$ mS（707 Ω）。二极管连接的器件相当于一个电阻 $1/g_m$。
- 上方节点（M3、M4 的源极）与下方节点（M1、M2 的源极）只通过理想电流源相连，而电流源对小信号相当于开路。从 $v_{in}$ 到 $v_{out}$ 有两条通路：M3–M4（$2\times707 = 1414\ \Omega$）和 M1–M2（$2\times674 = 1348\ \Omega$）。$R_{ON} = 1414 \| 1348 = 690\ \Omega$。
- 损耗：$v_{out}/v_{in} = 1000/(1000 + 690) = 0.592$，即 −4.6 dB。
- 与 [图 2] 中单个开关的比较：
  - 功耗：桥式开关导通期间需要持续提供 $I_{control}$ = 200 µA；MOSFET 开关不消耗静态电流。
  - 导通电阻：桥式开关的 $R_{ON}$ 由 $I_{control}$ 决定，每个二极管约为 $1/g_m$，一阶近似下与 $v_{in}$ 无关。MOSFET 的 $r_{ON} = 1/[K'(W/L)(V_\phi - v_{in} - V_T)]$ 随 $v_{in}$ 和体效应变化很大。在面积相当的情况下，单个 MOSFET（例如 100/1、过驱动 2.5 V，≈ 40 Ω）的 $r_{ON}$ 要低得多，而小尺寸开关的导通电阻则更大。
  - 大信号：桥式开关最多只能向负载提供 ≈ $I_{control}$ 的电流，因此对 $C$ 充电受压摆率（slew rate）限制，而且 $v_{in}$ 距电源必须留出 $V_{GS} + V_{SG}$（约 1.7 V）的余量。两条通路之间的失配会产生直流失调。
  - 断开状态：$I_{control}$ = 0 时二极管截止，但大尺寸器件（100/1 和 200/1）在 $v_{in}$ 与 $v_{out}$ 之间呈现很大的电容，因此断开期间耦合过去的信号比小尺寸单开关更多。控制电流的切换也会注入电荷。
