01001100（书中的答案：各位是比较器对余量 $V_1 \dots V_8$ 的判决），或者同样可以是 10100110（各位是对 $V_0 \dots V_7$ 的判决，第一位是对 $v_{in}^*$ 本身的判决）。题目给出的时序允许这两种理解，两个答案都可接受。

- 电路工作原理（对运放反相输入端应用电荷守恒）：在 $\phi_1$ 期间，$2C$ 电容对保持电压 $V_{SH}$ 采样，反馈电容 $C$ 复位，$\phi_x$/$\phi_y$ 由比较器对 $V_{SH}$ 的判决决定；在 $\phi_2$ 期间电荷转移，运放输出为 $V_{out} = 2V_{SH} + V_{D1} - V_{D2}$，其中 $V_{D1}$、$V_{D2}$ 是另一个电容 $C$ 的下极板在 $\phi_1$ 和 $\phi_2$ 期间的电压。$v_C = 1$（$V_{SH} > 0$）时：$V_{D1} = 0$，$V_{D2} = V_{REF}$ → $V_{out} = 2V_{SH} - V_{REF}$；$v_C = 0$ 时：$V_{out} = 2V_{SH} + V_{REF}$。采样保持电路在 $\phi_2$ 期间采集 $V_{out}$，因此该环路计算 $V_k = 2V_{k-1} - b_{k-1}V_{REF}$，其中 $b = \pm1$ 由 $V_{k-1}$ 的符号决定。
- 序列（以 $V_{REF}$ 为单位）：$V_0 = 0.3$（输入本身，为正），$V_1 = -0.4$，$V_2 = 0.2$，$V_3 = -0.6$，$V_4 = -0.2$，$V_5 = 0.6$，$V_6 = 0.2$，$V_7 = -0.6$，$V_8 = -0.2$。
- 位的时序：$v_C$ 在整个 $\phi_1$–$\phi_2$ 周期内决定 $\phi_x$/$\phi_y$，因此每次判决都保持一个周期；题目没有说明在某个 $\phi_2$ 读取的位是设定该周期的那次判决，还是对刚采集到的余量的判决。(i) 在每个 $\phi_2$ 结束时，对采样保持电路刚采集到的值锁存判决：对 $v_{in}^*$ 的判决在转换开始之前的启动 $\phi_2$ 中完成，在随后八个 $\phi_2$ 相读取的位是对 $V_1 \dots V_8$ 的判决：0 1 0 0 1 1 0 0。对 $0 < v_{in}^* < V_{REF}$，对输入本身的判决总是 1，而这些判决构成 $v_{in}^*/V_{REF}$ 的普通二进制码：$0.3\times256 = 76.8$ → 76 = 01001100。(ii) 在每个 $\phi_1$ 期间对保持值作判决，并在随后的 $\phi_2$ 中作为输出位读取：各位是对 $V_0 \dots V_7$ 的判决：1 0 1 0 0 1 1 0，即 MSB 为 $v_{in}^*$ 符号的双极性（偏移二进制）码：$(0.3 + 1)/2\times256 = 166.4$ → 166 = 10100110。对正输入，这两个字所含的信息相同：10100110 就是 1 后接 01001100 的前七位。
