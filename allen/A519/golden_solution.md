# Golden Solution - A519

## Reference answer

01001100 (the book's answer: the bits are the comparator decisions on the residues $V_1 \dots V_8$), or equally 10100110 (the bits are the decisions on $V_0 \dots V_7$, the first being the decision on $v_{in}^*$ itself). The stated timing allows both readings; both words are accepted.

- Circuit operation (charge conservation at the op amp's inverting input): on $\phi_1$ the $2C$ capacitor samples the held voltage $V_{SH}$ and the feedback capacitor $C$ is reset, with $\phi_x$/$\phi_y$ set by the comparator decision on $V_{SH}$; on $\phi_2$ the charge is transferred and the op amp output is $V_{out} = 2V_{SH} + V_{D1} - V_{D2}$, where $V_{D1}$, $V_{D2}$ are the voltages on the lower plate of the other capacitor $C$ in $\phi_1$ and $\phi_2$. With $v_C = 1$ ($V_{SH} > 0$): $V_{D1} = 0$, $V_{D2} = V_{REF}$ → $V_{out} = 2V_{SH} - V_{REF}$; with $v_C = 0$: $V_{out} = 2V_{SH} + V_{REF}$. The sample-and-hold acquires $V_{out}$ on $\phi_2$, so the loop computes $V_k = 2V_{k-1} - b_{k-1}V_{REF}$ with $b = \pm1$ from the sign of $V_{k-1}$.
- Sequence ($V_{REF}$ units): $V_0 = 0.3$ (the input itself: positive), $V_1 = -0.4$, $V_2 = 0.2$, $V_3 = -0.6$, $V_4 = -0.2$, $V_5 = 0.6$, $V_6 = 0.2$, $V_7 = -0.6$, $V_8 = -0.2$.
- Bit timing: $v_C$ sets $\phi_x$/$\phi_y$ for a whole $\phi_1$–$\phi_2$ cycle, so each decision is held through a cycle; the question does not say whether the bit read at a $\phi_2$ is the decision that set that cycle or the one on the residue just acquired. (i) Decision latched at the end of each $\phi_2$ on the value the S/H has just acquired: the decision on $v_{in}^*$ is made in the start-up $\phi_2$, before the conversion begins, and the bits taken at the eight following $\phi_2$ phases are the decisions on $V_1 \dots V_8$: 0 1 0 0 1 1 0 0. For $0 < v_{in}^* < V_{REF}$ the decision on the input itself is always 1, and these decisions form the ordinary binary code of $v_{in}^*/V_{REF}$: $0.3\times256 = 76.8$ → 76 = 01001100. (ii) Decision made on the held value during each $\phi_1$ and taken as the bit in the following $\phi_2$: the bits are the decisions on $V_0 \dots V_7$: 1 0 1 0 0 1 1 0, the bipolar (offset-binary) code whose MSB is the sign of $v_{in}^*$: $(0.3 + 1)/2\times256 = 166.4$ → 166 = 10100110. The two words carry the same information for a positive input: 10100110 is a 1 followed by the first seven bits of 01001100.

## Grading notes

+2: 01001100 or 10100110, with the circuit identified as a ×2 stage that subtracts or adds $V_{REF}$ according to the comparator (residues −0.4, 0.2, −0.6, −0.2, 0.6, 0.2, −0.6, −0.2) and the word consistent with the residues under the bit timing used (decisions on $V_1 \dots V_8$ → 01001100; decisions on $V_0 \dots V_7$, the first being the sign of $v_{in}^*$ → 10100110). Neither timing reading is an error. +1: a correct word with only a sketchy (but not wrong) description of the circuit, or a correct circuit analysis with a slip in one displayed residue that changes no bit. 0: 01001100 obtained by asserting that the circuit runs the unipolar algorithm (threshold $V_{REF}/2$, $V_{REF}$ only subtracted, i.e. the binary expansion of 0.3): the word matches, but the circuit is misread. −2 (asserted as fact): any other word from a misread circuit (e.g., gain of 1 or 3, reference added when it should be subtracted) or a word inconsistent with the residues.
