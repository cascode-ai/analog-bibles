$A_i(0) = g_{m2}/(g_{m1}+g_{ds1})$ ≈ 0.988；$R_{in} = 1/(g_{m1}+g_{ds1})$ ≈ 2.98 kΩ；$R_{out} = r_{ds2}$ = 250 kΩ；$f_{-3\mathrm{dB}}$ ≈ 970 MHz。

- $g_{m1} = g_{m2} = \sqrt{2\cdot110\cdot5\cdot100}$ µS = 332 µS；$g_{ds} = 0.04\cdot100$ µA = 4 µS。
- 输入节点：二极管连接的 M1 给出 $1/(g_{m1}+g_{ds1})$ = 2.98 kΩ（若忽略 $g_{ds1}$ 则为 3.02 kΩ）。$v_{gs} = i_{in}R_{in}$，$i_{out} = g_{m2}v_{gs}$ → $A_i$ = 332/336 = 0.988（若忽略 $g_{ds1}$ 则恰为 1）。
- 输出：$R_{out} = 1/g_{ds2}$ = 250 kΩ。
- 输入节点处的极点：$R_L$ = 0 时，$C_{gd1}$ 被短路（M1 栅极即漏极），$C_{gd2}$ 接到交流地，$C_{bd2}$ 被短路，因此 $C = C_{gs1}+C_{gs2}+C_{bd1}+C_{gd2}$ = 55 fF。$\omega_{-3\mathrm{dB}} = (g_{m1}+g_{ds1})/C$ = 6.10×10⁹ rad/s → $f_{-3\mathrm{dB}}$ ≈ 971 MHz（仅用 $g_m$ 时为 960 MHz）。经 $C_{gd2}$ 的前馈零点位于 $g_{m2}/C_{gd2}$ ≈ 10.6 GHz，远高于此。
