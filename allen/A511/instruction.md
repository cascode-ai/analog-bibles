A five-stage (5-bit) pipeline algorithmic ADC of the form shown in [Fig. 1] has a sampled input $V_{in}^* = 0.7V_{REF}$. Each stage compares its input $V_{i-1}$ with its comparator threshold: the stage bit is 1 ($b_{i-1} = +1$) if $V_{i-1}$ is above the threshold and 0 ($b_{i-1} = -1$) otherwise, and the stage output $V_i = 2V_{i-1} - b_{i-1}V_{REF}$ drives the next stage; the bits form the output word MSB first. All gains are exactly 2, but the comparators have offsets $V_{OS}$, all equal and nonzero, so that every comparator's threshold is at $V_{OS}$ instead of zero. What is the smallest magnitude of $V_{OS}$ that causes an error in the output word?
