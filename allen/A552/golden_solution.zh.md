$Y(z) = X(z) + (1 - z^{-1})^3Q_3(z)$，因此 $NTF_Q(z) = (1 - z^{-1})^3$（三阶噪声整形；$Q_1$ 和 $Q_2$ 被抵消）。

- 每一级都是一个一阶环路，含无延迟积分器 $1/(1 - z^{-1})$ 和反馈 $z^{-1}Y_i$，因此 $Y_i = U_i + (1 - z^{-1})Q_i$，积分器输出为 $V_i = Y_i - Q_i$。
- 各级输入：$U_1 = X$；$U_2 = V_1 - Y_1 = -Q_1$；$U_3 = V_2 - Y_2 = -Q_2$。
- 各级输出：$Y_1 = X + (1 - z^{-1})Q_1$；$Y_2 = -Q_1 + (1 - z^{-1})Q_2$；$Y_3 = -Q_2 + (1 - z^{-1})Q_3$。
- 组合：$Y = Y_1 + (1 - z^{-1})Y_2 + (1 - z^{-1})^2Y_3$。$Q_1$ 和 $Q_2$ 各项相互抵消，剩下 $Y = X + (1 - z^{-1})^3Q_3$。
