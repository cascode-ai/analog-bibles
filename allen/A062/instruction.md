For an n-channel and a p-channel transistor, each with W/L = 100 µm/10 µm and λ = 0.01 V⁻¹, find:

(i) the values of $g_m$, $g_{mbs}$ and $g_{ds}$ in saturation if the dc value of the magnitude of the drain current is 50 µA and the magnitude of the dc source–bulk voltage is 2 V;

(ii) the values of the small-signal model parameters $g_m$, $g_{mbs}$ and $g_{ds}$ (or $r_{ds}$) in the nonsaturation region if $|V_{GS}|$ = 5 V, $|V_{DS}|$ = 1 V and $|V_{BS}|$ = 2 V, assuming that the value of $K'$ in the nonsaturation region is the same as that for saturation.

Device data: n-channel $V_{T0}$ = 0.7 V, $K'$ = 110 µA/V², γ = 0.4 V$^{1/2}$, $2|\phi_F|$ = 0.7 V; p-channel $V_{T0}$ = −0.7 V, $K'$ = 50 µA/V², γ = 0.57 V$^{1/2}$, $2|\phi_F|$ = 0.8 V.
