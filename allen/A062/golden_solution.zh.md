(i) 饱和区：n 沟道 $g_m$ ≈ 332 µS，$g_{mbs}$ ≈ 40.4 µS，$g_{ds}$ = 0.5 µS；p 沟道 $g_m$ ≈ 224 µS，$g_{mbs}$ ≈ 38.1 µS，$g_{ds}$ = 0.5 µS。
(ii) 非饱和区：n 沟道 $g_m$ = 1.1 mS，$g_{mbs}$ ≈ 134 µS，$g_{ds}$ ≈ 3.28 mS（$r_{ds}$ ≈ 305 Ω）；p 沟道 $g_m$ = 0.5 mS，$g_{mbs}$ ≈ 85.2 µS，$g_{ds}$ ≈ 1.43 mS（$r_{ds}$ ≈ 700 Ω）。

- (i) $g_m = \sqrt{2K'(W/L)|I_D|}$：$\sqrt{2\times110\ \mu\times10\times50\ \mu}$ = 332 µS 和 $\sqrt{2\times50\ \mu\times10\times50\ \mu}$ = 224 µS。$g_{mbs} = g_m\gamma/[2\sqrt{2|\phi_F| + |V_{SB}|}]$：0.4/(2√2.7) = 0.122 → 40.4 µS；0.57/(2√2.8) = 0.170 → 38.1 µS。两者均有 $g_{ds} \approx \lambda|I_D|$ = 0.01 × 50 µA = 0.5 µS。
- (ii) $|V_{SB}|$ = 2 V 时的阈值：$0.7 + 0.4(\sqrt{2.7} - \sqrt{0.7})$ = 1.023 V 和 $0.7 + 0.57(\sqrt{2.8} - \sqrt{0.8})$ = 1.144 V（大小）。β = K'W/L = 1.1 mA/V² 和 0.5 mA/V²。电流 $\beta[(V_{GS} - V_T)V_{DS} - V_{DS}^2/2]$ = 3.83 mA 和 1.68 mA（因 $V_{DS} < V_{GS} - V_T$，处于非饱和区）。
- $g_m = \beta V_{DS}$ = 1.1 mS 和 0.5 mS；$g_{mbs} = \beta\gamma V_{DS}/[2\sqrt{2|\phi_F| + |V_{SB}|}]$ = 134 µS 和 85.2 µS；$g_{ds} = \beta(V_{GS} - V_T - V_{DS})$ = 1.1 mA/V² × 2.977 V = 3.28 mS 和 0.5 mA/V² × 2.856 V = 1.43 mS。
