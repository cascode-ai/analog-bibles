$N$ 位转换器有 $2^N$ 个输出码，它们之间只有 $2^N - 1$ 个判决电平（码跳变）。每个比较器实现一个判决电平，因此 $2^N - 1$ 个比较器就足够了：它们的输出构成温度计码（thermometer code），其有效输出的个数（0 到 $2^N - 1$）已能区分全部 $2^N$ 个码。最低的码对应“没有比较器翻转”，不需要单独的比较器。对 $N = 3$：7 个比较器。

编码器（一种可行的设计）。将比较器编号为 $c_1$（抽头 $0.125V_{REF}$，最下方）到 $c_7$（抽头 $0.875V_{REF}$，最上方）。这里 $c_k = 1$ 表示 $V^*_{in} < V_{tap,k}$，因此对码 $n$，输出为 $c_1 \dots c_n = 0$ 且 $c_{n+1} \dots c_7 = 1$（反相的温度计码）。
- 第 1 级，跳变检测（独热码）：对 $n = 1 \dots 6$，$h_n = \bar c_n\, c_{n+1}$（六个 2 输入与门，每个有一个反相输入端），$h_7 = \bar c_7$（一个反相器）。恰好只有一个 $h_n$ 为 1，$n$ 即为该码（$n = 0$：所有 $h$ = 0）。
- 第 2 级，或平面（ROM）：MSB $= h_4 + h_5 + h_6 + h_7$；中间位 $= h_2 + h_3 + h_6 + h_7$；LSB $= h_1 + h_3 + h_5 + h_7$（三个 4 输入或门）。
- 等效的化简形式：MSB $= \bar c_4$；中间位 $= \bar c_2 c_4 + \bar c_6$；LSB $= \bar c_1 c_2 + \bar c_3 c_4 + \bar c_5 c_6 + \bar c_7$。
- 验证：$V^*_{in} = 0.7V_{REF}$ 时 $c_1 \dots c_5 = 0$，$c_6 = c_7 = 1$，因此 $h_5 = 1$，输出字为 101。

（能容忍气泡误差的变体，例如采用 3 输入与门或格雷码 ROM，是同一方案的改进。）
