# Golden Solution - A150

## Reference answer

$R_{out} \approx \dfrac{1}{g_{ds2} + g_{ds8}}$ and $\dfrac{v_{out}}{v_{in}} \approx \dfrac{0.5\,g_{m2}}{g_{ds2} + g_{ds8}}$ (noninverting).

- M7 and M8 are current-source loads (gates at $V_{BP}$). The output at M2's drain sees $r_{ds2}\,\|\,r_{ds8}$.
- M2's drain current changes by $-g_{m2}v_{in}/2$ (gate at $-v_{in}/2$, source node at ac ground for the symmetric differential signal), so $v_{out} = (g_{m2}v_{in}/2)/(g_{ds2} + g_{ds8})$. M1's signal current is lost in M7 and does not reach the output: only half the transconductance is used.
- (A strict test-source calculation with ideal $I_{SS}$ gives a somewhat higher resistance looking into M2, because M2's source is then degenerated by M1. The intuitive answer above is the expected one.)
