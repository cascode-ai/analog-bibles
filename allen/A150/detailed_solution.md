# Detailed solution - A150

Here M7 and M8 have their gates on the dc bias $V_{BP}$, so they are current-source loads that contribute only their output conductances; there is no mirror. The output is the drain of M2. Following the intuitive approach, find the signal current the input produces in M2 and the resistance it sees at the output. M1's signal current is lost in M7, so only half the transconductance of the pair reaches the output.

### Step 1 — Output resistance

At the output node, M8 (gate and source at ac ground) presents $r_{ds8}$, and M2 presents $r_{ds2}$ to the common source node, which is an ac ground for the differential signal:

$$
R_{out}\approx r_{ds2}\,\|\,r_{ds8}=\frac{1}{g_{ds2}+g_{ds8}} .
$$

### Step 2 — Signal current in M2

With M1's gate at $+v_{in}/2$ and M2's gate at $-v_{in}/2$, an ideal tail and matched halves, the two drain-current changes are equal and opposite and the common source node stays at ac ground. M2 therefore sees $v_{gs2}=-v_{in}/2$:

$$
i_{d2}=-\frac{g_{m2}v_{in}}{2}.
$$

M1's current change, $+g_{m1}v_{in}/2$, flows into M7, a current source whose drain node is not the output, so it does not reach the output.

### Step 3 — Voltage gain

M2 pulls $g_{m2}v_{in}/2$ less current from the output node, and M8 cannot absorb the difference except through $r_{ds8}$, so

$$
\frac{v_{out}}{v_{in}}\approx\frac{0.5\,g_{m2}}{g_{ds2}+g_{ds8}}\quad\text{(noninverting from the + input)}.
$$

Compared with the diode-load version, the gain is much larger because the load conductance is $g_{ds8}$ rather than $g_{m8}$. Compared with a current-mirror load, it is half as large, because without the mirror M1's half of the signal current is wasted.

### Step 4 — Remark on a strict test-source calculation

If a test source is applied at the output with $v_{in}=0$ and an ideal $I_{SS}$, the common source node is no longer an ac ground: a current into M2's drain must leave through M1, so M2's source is degenerated by the path through M1 and M7. This makes the resistance looking into M2 larger, roughly $r_{ds2}(2+r_{ds7}/r_{ds1})$, which raises $R_{out}$ toward $r_{ds8}$. The intuitive result $R_{out}\approx1/(g_{ds2}+g_{ds8})$ with the gain $0.5g_{m2}/(g_{ds2}+g_{ds8})$ is the expected approximate answer for the differential signal.
