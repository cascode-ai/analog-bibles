按图中所画的框图：
$\dfrac{Y(z)}{Q(z)} = \dfrac{(1 - z^{-1})^2}{1 - z^{-1} + 2z^{-2} - z^{-3}} = \dfrac{z(z-1)^2}{z^3 - z^2 + 2z - 1}$
（与 $Y/X$ 的表达式相同，因为 $X$ 是在环路滤波器之后加入的）。其极点位于 $z \approx 0.570$ 和 $z \approx 0.215 \pm j1.307$（$|z| \approx 1.32$），在单位圆之外，因此该环路不稳定。

推导（令 $D = z^{-1}Y$ 为延迟单元的输出）：
- −1 模块把 $-D$ 同时送入左边的积分器和第一个求和点：第一个求和点的输出为 $-D\left(1 + \dfrac{1}{1 - z^{-1}}\right)$。
- 第二个积分器给出 $C = -D\dfrac{2 - z^{-1}}{(1 - z^{-1})^2}$。
- X 求和点将 $X$、$C$ 和 $D$ 相加（其下方输入直接来自延迟单元输出），且 $Y = X + C + D + Q$。
- 代入 $D = z^{-1}Y$：$Y\left[1 - z^{-1} + \dfrac{z^{-1}(2 - z^{-1})}{(1 - z^{-1})^2}\right] = X + Q$，即 $Y\,\dfrac{1 - z^{-1} + 2z^{-2} - z^{-3}}{(1 - z^{-1})^2} = X + Q$。
- 若去掉从延迟单元输出到 X 求和点的直接通路，分母化简为 1，$Y/Q = (1 - z^{-1})^2$：在直流处有两个零点的二阶噪声整形（noise shaping）。
