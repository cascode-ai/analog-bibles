- 反馈系数（feedback factor）为 $\beta = R_1/(R_1+R_2)$ 的反相放大器：闭环极点位于 $\omega_p(1+A_0\beta)$。
- (a) $\beta = 1/26$：$A_0\beta = 38.5$，$\omega_{-3dB} = 10^4(39.5) = 394.6$ krad/s（≈ $GB\cdot\beta$ = 385 krad/s，最粗略的近似为 $GB/25$ = 400 krad/s）；增益 $-25/(1+26/1000) = -24.4$。
- (b) $\beta = 1/6$：每级 $\omega_1 = 10^4(1+166.7) = 1.677$ Mrad/s，增益 −4.97。两个相同极点级联：$\omega_{-3dB} = \omega_1\sqrt{\sqrt2-1} = 0.644\,\omega_1 = 1.08$ Mrad/s；总增益 $(4.97)^2 = 24.7$。
