In a widely used subthreshold model, the gate–source voltage at which a MOS transistor makes the transition from strong to weak inversion is
$$V_{ON} = V_T + f_{ast},\qquad f_{ast} = \frac{kT}{q}\left[1 + \frac{q\cdot\mathrm{NFS}}{\mathrm{COX}} + \frac{\mathrm{GAMMA}\cdot f_s\,(\mathrm{PHI} + v_{SB})^{1/2} + f_n\,(\mathrm{PHI} + v_{SB})}{2(\mathrm{PHI} + v_{SB})}\right]$$
where NFS is the fast-surface-state density, COX the gate-oxide capacitance per unit area, GAMMA the body-effect parameter, PHI = $2|\phi_F|$, and $f_s$ and $f_n$ are short- and narrow-channel correction factors. Calculate the value of $V_{ON}$ for an NMOS transistor in weak inversion assuming that $f_s$ and $f_n$ can be approximated to be unity (1.0).

Data: $v_{SB}$ = 0, $V_T$ = 0.7 V, GAMMA = 0.4 V$^{1/2}$, PHI = 0.7 V, NFS = $7\times10^{11}$ cm⁻², $t_{ox}$ = 140 Å (COX = $24.7\times10^{-4}$ F/m²), T = 300 K.
