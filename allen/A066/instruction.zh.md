在一种广泛使用的亚阈值（subthreshold）模型中，MOS 晶体管从强反型（strong inversion）过渡到弱反型（weak inversion）时的栅源电压为
$$V_{ON} = V_T + f_{ast},\qquad f_{ast} = \frac{kT}{q}\left[1 + \frac{q\cdot\mathrm{NFS}}{\mathrm{COX}} + \frac{\mathrm{GAMMA}\cdot f_s\,(\mathrm{PHI} + v_{SB})^{1/2} + f_n\,(\mathrm{PHI} + v_{SB})}{2(\mathrm{PHI} + v_{SB})}\right]$$
其中 NFS 为快表面态密度，COX 为单位面积栅氧电容，GAMMA 为体效应参数，PHI = $2|\phi_F|$，$f_s$ 和 $f_n$ 分别为短沟道和窄沟道修正因子。假设 $f_s$ 和 $f_n$ 均可近似取为 1.0，计算工作在弱反型区的 NMOS 晶体管的 $V_{ON}$ 值。

数据：$v_{SB}$ = 0，$V_T$ = 0.7 V，GAMMA = 0.4 V$^{1/2}$，PHI = 0.7 V，NFS = $7\times10^{11}$ cm⁻²，$t_{ox}$ = 140 Å（COX = $24.7\times10^{-4}$ F/m²），T = 300 K。
