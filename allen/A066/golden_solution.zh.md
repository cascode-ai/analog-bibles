$V_{ON}$ ≈ 0.757 V，即比 $V_T$ 高 $f_{ast}$ ≈ 56.7 mV。

- 300 K 时 $kT/q$ = 25.85 mV。
- $q\cdot\mathrm{NFS}/\mathrm{COX} = 1.602\times10^{-19}\ \mathrm{C}\times7\times10^{11}\ \mathrm{cm^{-2}}/(2.47\times10^{-7}\ \mathrm{F/cm^2})$ = 0.455。
- 衬底项：$(0.4\sqrt{0.7} + 0.7)/(2\times0.7) = (0.335 + 0.7)/1.4$ = 0.739。
- $f_{ast}$ = 25.85 mV × (1 + 0.455 + 0.739) = 25.85 mV × 2.194 = 56.7 mV，因此 $V_{ON}$ = 0.7 + 0.0567 = 0.757 V。（方括号内的值 ≈ 2.2，起亚阈值斜率因子 n 的作用。）
