# 详细步骤 - A017

问题在于：按给定顺序，是否有某一步能把高剂量 n⁺ 或 p⁺ 掺杂注入到最终位于薄氧化层和多晶硅下方的硅中。对多晶硅线条下方的硅，跟踪它在多晶硅淀积之前和之后能受到哪些注入。

### 第 1 步 — 多晶硅之前发生了什么

在多晶硅淀积之前，流程中只有 n 阱和 p 阱注入、场注入以及栅氧化层生长。这些都是用来设定阱掺杂和隔离的轻剂量注入。此时还没有任何重掺杂注入，因此将来位于多晶硅下方的硅，在生长栅氧化层并覆盖多晶硅时只是轻掺杂的。

### 第 2 步 — 多晶硅之后发生了什么

所有重掺杂注入都在之后进行：n⁺ 和 p⁺ 源/漏注入位于多晶硅图形化、LDD 注入和侧墙形成之后。题中说明多晶硅栅和侧墙阻挡这些注入，这正是工艺自对准的原因：扩散区只在多晶硅旁边形成，从不在其下方形成。因此被多晶硅覆盖的硅不会受到任何高剂量注入。

### 第 3 步 — 结论

**不能。** 在这一流程中，任何薄氧化层和多晶硅下方的硅都是沟道区或阱区，只经过轻剂量的阱注入、场注入和阈值注入掺杂。确实可以制作上面盖有多晶硅的薄氧化层结构，例如 n 阱上的多晶硅构成的积累型电容，但其底极板是轻掺杂的，而不是重掺杂扩散区。

LDD 和源/漏掺杂剂的横向扩展确实会在每个栅边缘下方形成一窄条重掺杂区（栅交叠）。那是依附于每个晶体管边缘的小寄生区域，并不是可用的多晶硅-扩散区结构。

### 第 4 步 — 需要增加什么

要制作多晶硅位于重掺杂扩散区之上、中间隔着薄氧化层的结构，例如底极板电阻很低的多晶硅-扩散区电容，工艺需要在多晶硅淀积之前（栅氧化之前或穿过栅氧化层）增加一块掩模和一次重掺杂注入。给定的流程中没有这样的步骤，因此仅靠它无法制作该结构。
