In an 8-stage algorithmic pipeline ADC each stage compares its input $V_{i-1}$ with its comparator threshold: the stage bit is 1 ($b_{i-1} = +1$) if $V_{i-1}$ exceeds the threshold and 0 ($b_{i-1} = -1$) otherwise, and the stage output $V_i = 2V_{i-1} - b_{i-1}V_{REF}$ drives the next stage; the first stage's input is the sampled input and the bits form the output word MSB first. All elements are ideal except that the comparator of each stage has a dc offset of $+0.3V_{REF}$, so that each comparator outputs a 1 only when its input exceeds $+0.3V_{REF}$. If $V_{in}^* = 0.1V_{REF}$, find the digital output and the bits that are in error (the ideal converter gives 10001100 for this input).
