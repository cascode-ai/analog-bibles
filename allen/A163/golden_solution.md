# Golden Solution - A163

## Reference answer

$V_{IC}(\min) = V_{DS5}(\mathrm{sat}) + V_{GS1} = V_{T1} + V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat})$ (with $V_{SS} = 0$).

$V_{IC}(\max) = v_3 + V_{T1} = V_{CM} + V_{T1}$ (M1 saturated), at most $V_{DD} - V_{SD3}(\mathrm{sat}) + V_{T1}$ since the loads need $V_{CM} \le V_{DD} - V_{SD3}(\mathrm{sat})$. Within the supply, $V_{IC}(\max) = \min(V_{DD},\,V_{CM} + V_{T1})$, which is $V_{DD}$ when $V_{CM} \ge V_{DD} - V_{T1}$ (possible because normally $V_{T1} > V_{SD3}(\mathrm{sat})$; the book's answer).

Minimum supply (ideal CMFB, signal path M1–M5): $V_{DD}(\min) = V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat}) + \max[V_{T1},\,V_{SD3}(\mathrm{sat})] = V_{T1} + V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat}) \approx V_T + 2V_{DS}(\mathrm{sat})$ for the normal case $V_{T1} \ge V_{SD3}(\mathrm{sat})$.

- Lower limit: the source node $V_{IC} - V_{GS1}$ must stay above $V_{DS5}(\mathrm{sat})$, with $V_{GS1} = V_{T1} + V_{DS1}(\mathrm{sat})$.
- Upper limit: M1 stays saturated while $V_{G1} \le V_{D1} + V_{T1}$. The CMFB holds $v_3 = v_4 = V_{CM}$, independent of the input common mode.
- Zero range within 0 to $V_{DD}$: setting $V_{IC}(\min) = V_{DD}$ gives $V_{DD} = V_{T1} + V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat})$; at that point M1 needs $V_{CM} \ge V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat})$ and M3 needs $V_{CM} \le V_{DD} - V_{SD3}(\mathrm{sat})$, compatible when $V_{T1} \ge V_{SD3}(\mathrm{sat})$ (otherwise the max form above). This holds whether $V_{CM}$ is treated as fixed (inside that window) or chosen.
- If the CMFB devices are included (MC3 and MC4 are both diode-connected; MC1, MC2 gates at $V_{CM}$ and the sensed output CM), they add $V_{CM} \ge V_{TC1} + V_{DSC1}(\mathrm{sat}) + V_{DSC5}(\mathrm{sat})$ (MC5) and $V_{CM} \le V_{DD} - |V_{TP}| - V_{SDC3}(\mathrm{sat}) + V_{TC1}$ (MC1). The smallest supply with any in-rail operating point is then $\max\{V_{T1}+V_{DS1}(\mathrm{sat})+V_{DS5}(\mathrm{sat}),\ \max[V_{DS1}(\mathrm{sat})+V_{DS5}(\mathrm{sat}),\,V_{TC1}+V_{DSC1}(\mathrm{sat})+V_{DSC5}(\mathrm{sat})] + \max[V_{SD3}(\mathrm{sat}),\,|V_{TP}|+V_{SDC3}(\mathrm{sat})-V_{TC1}]\}$; with matched thresholds and equal saturation voltages this is $V_T + 3V_{DS}(\mathrm{sat})$, and the in-rail range there is already about $V_{SD3}(\mathrm{sat})$ wide, so a strictly zero-width range does not occur on that reading.

## Grading notes

Three parts: $V_{IC}(\min)$, $V_{IC}(\max)$, $V_{DD}(\min)$. $V_{IC}(\min) = V_{SS} + V_{T1} + V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat})$. For $V_{IC}(\max)$ accept $V_{CM} + V_{T1}$ (or $v_3 + V_{T1}$) as the transistor limit, its largest value $V_{DD} - V_{SD3}(\mathrm{sat}) + V_{T1}$, or the in-rail value $\min(V_{DD}, V_{CM}+V_{T1})$ / $V_{DD}$; clipping to $V_{DD}$ is not required. For $V_{DD}(\min)$ accept $V_{T1} + V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat})$ or the general $V_{DS1}(\mathrm{sat}) + V_{DS5}(\mathrm{sat}) + \max[V_{T1}, V_{SD3}(\mathrm{sat})]$. Reading "zero range" as the onset (smallest $V_{DD}$ with at least one in-rail operating point) is accepted. "All transistors" may be read as M1–M5 with ideal CMFB (the book's reading) or as the whole figure: a correct full-circuit analysis (MC5 floor and MC1/MC3 ceiling on $V_{CM}$, giving about $V_T + 3V_{DS}(\mathrm{sat})$ for matched devices) earns full credit when the reading is stated; noting that the range is then not strictly zero is correct but not required. MC3 and MC4 are both diode-connected in the figure; do not penalize an answer for saying so.
+2: all three parts right under one of these readings. +1: all three right but a wrong claim in an optional side analysis (e.g. a CMFB constraint mishandled or dismissed as a sizing condition) that does not change the stated main results, or a slip in one term. 0: correct limits but $V_{DD}(\min)$ given only as $V_{DS1}(\mathrm{sat}) + V_{SD3}(\mathrm{sat}) + V_{DS5}(\mathrm{sat})$, ignoring the restriction to 0–$V_{DD}$; or one part wrong. −2 (asserted as fact): $V_{IC}(\max)$ set by the load as in a diode-load stage ($V_{DD} - V_{SG3} + V_{T1}$), $V_{DS5}(\mathrm{sat})$ omitted, or a minimum supply below $V_{T1}$.
