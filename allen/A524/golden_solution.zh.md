$C_1 = C/3$，$C_2 = C$，$C_3 = 3C$（比较器 $k$ 在 $V^*_{IN} = V_{REF}\,C/(C + C_k)$ 处翻转，比较器 1、2、3 的阈值分别为 $3V_{REF}/4$、$V_{REF}/2$、$V_{REF}/4$，与电阻串方案相同）。

单个比较器的工作过程（对其反相输入节点 X 应用电荷守恒）：
- $\phi_1$：比较器处于单位增益反馈，因此 X 处于比较器自身的翻转点（存储了其失调 $V_{OS}$）。$C$ 被充电到 $V_{REF} - V_{OS}$，$C_k$ 被充电到 $0 - V_{OS}$。
- $\phi_2$：两个左极板都切换到 $V^*_{IN}$，反馈开关断开：$(C + C_k)(V_X - V^*_{IN}) = C(V_{OS} - V_{REF}) + C_kV_{OS}$，因此 $V_X - V_{OS} = V^*_{IN} - V_{REF}\dfrac{C}{C + C_k}$。
- 比较器根据 $V_X - V_{OS}$ 的符号作判决：阈值为 $V_{REF}C/(C + C_k)$，与 $V_{OS}$ 无关。令其分别等于 $3V_{REF}/4$、$V_{REF}/2$、$V_{REF}/4$，得 $C_k = C/3$、$C$、$3C$。X 点的寄生电容只会衰减 $V_X - V_{OS}$，不会移动阈值。（由于输入接在反相一侧，$V^*_{IN}$ 低于阈值时输出为高，与传统比较器相反；可由编码器或锁存器的互补输出吸收这一差别。）

比较：
- 比较器失调：在传统 ADC 中，每个失调直接叠加到其抽头电压上，因此若阈值误差预算为 ±0.5 LSB，这里 $|V_{OS}|$ 必须小于 $V_{REF}/8$（一般为 $V_{REF}/2^{N+1}$）。各比较器的输入共模电平还随抽头不同而变化，因此 CMRR 会引入与输入相关的失调。在所提出的 ADC 中，失调（以及 1/f 噪声）在 $\phi_1$ 期间被自动调零（auto-zero），且所有比较器都工作在接近地的同一共模电平上，因此不存在 CMRR 问题。
- 速度：传统 ADC 只需要比较（每个采样一次锁存判决），输入端的负载只有比较器的输入电容。所提出的 ADC 每次转换需要两个相（自动调零和基准采样，然后比较）；自动调零环路必须在 $\phi_1$ 内建立（$V_{REF}$ 对 $C$ 充电，地对 $C_k$ 充电），在 $\phi_2$ 内 $C$ 与 $C_k$ 之间经开关的电荷再分配也必须建立（由于 X 浮空，从 $V^*_{IN}$ 吸取的净电荷主要由 X 点的寄生电容和极板寄生电容决定，而不是整个 $C + C_k$）。作为交换，其比较器可以非常简单（例如自动调零的反相器），也不需要精密前置放大器，因此每个时钟的速度可以同样快甚至更快。
- 精度：传统 ADC 依赖电阻匹配，电阻串中有静态电流，存在抽头负载效应，并且需要低失调比较器。所提出的 ADC 的阈值只取决于电容比，而电容比在 CMOS 中匹配良好（≈ 0.1 %），且没有静态功耗，因此通常精度更高。它需要不相等的电容，其取值范围随 $N$ 增大（$C/(2^N - 1)$ 到 $(2^N - 1)C$），并受开关电荷注入、时钟馈通和 kT/C 噪声的限制。
