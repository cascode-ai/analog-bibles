一种设计（S = W/L）：$I_3 = 100\ \mu$A，$I_4 = I_5 = 125\ \mu$A；$S_1 = S_2 \approx 158$；$S_3 \approx 69$；$S_4 = S_5 \approx 33$；$S_6 = S_7 \approx 33$；$S_8 = S_9 = S_{10} = S_{11} \approx 160$（若按 75 µA 静态电流设计则 ≈ 96）；$P_{diss}$ ≈ 0.63 mW；$A_{vd}$ ≈ 5.5×10³。

- 压摆率：$I_3 = SR\cdot C_L = 100\ \mu$A；取 $I_4 = I_5 = 1.25I_3 = 125\ \mu$A，使共源共栅支路永不截止（静态 75 µA，范围 25–125 µA）。取 $I_4 = I_5 = I_3$ 同样得到 $SR = I_3/C_L$（在电流完全导向一侧时，有一条共源共栅支路的电流恰好降到零，这只会减慢恢复）。
- $V_{out}(\min) = -2$ V $= V_{SS} + 0.5$ V：在最大 125 µA 下 $V_{DS5}(\mathrm{sat}) = V_{DS7}(\mathrm{sat}) = 0.25$ V：$S_4 = S_5 = S_6 = S_7 = 2(125)/(120\cdot0.0625) = 33.3$。
- $V_{out}(\max) = -0.5$ V：$V_{SD9}(\mathrm{sat}) = V_{SD11}(\mathrm{sat}) = 0.25$ V：$S_8 = \dots = S_{11} = 2(125)/(25\cdot0.0625) = 160$（按最坏情况电流）。
- $2\pi\,GB = g_{m1}/C_L$：$g_{m1} = 2\pi(10\ \mathrm{MHz})(10\ \mathrm{pF}) = 628\ \mu$S，电流为 50 µA → $S_1 = S_2 = g_{m1}^2/(2K'_P\cdot50\,\mu) = 158$。
- $V_{ic}(\max) = -1$ V 决定 p 沟道尾电流管：$V_{SD3}(\mathrm{sat}) = V_{DD} - V_{ic}(\max) - |V_{TP}| - \sqrt{I_3/(K'_PS_1)} = 1 - 0.5 - 0.159 = 0.341$ V → $S_3 = 2(100)/(25\cdot0.341^2) = 69$。
- $V_{ic}(\min) = -2.5$ V：只要 $V_{SS} + V_{DS4} \le V_{ic} + |V_{TP}|$，M1 就保持饱和，即可低至 $-2.5 + 0.25 - 0.5 = -2.75$ V ✓（只要求 $S_4 \ge 2I_4/(K'_N(0.5)^2) = 8.3$）。
- 功耗：$2.5\ \mathrm{V}\times(I_4+I_5) = 2.5\times250\ \mu\mathrm{A} = 0.63$ mW（另加偏置电路）< 5 mW ✓。
- 增益（共源共栅支路静态电流 75 µA）：$g_{m9} = \sqrt{2(25\,\mu)(160)(75\,\mu)} = 775\ \mu$S，$g_{ds9} = g_{ds11} = 6\ \mu$S → 上方 $g_{m9}r_{ds9}r_{ds11} = 21.5$ MΩ；$g_{m7} = \sqrt{2(120\,\mu)(33.3)(75\,\mu)} = 774\ \mu$S，$g_{ds7} = 4.5\ \mu$S，$g_{ds2} = 4\ \mu$S，$g_{ds5} = 7.5\ \mu$S → 下方 $g_{m7}r_{ds7}(r_{ds2}\|r_{ds5}) = 15.0$ MΩ；$R_{out} = 8.8$ MΩ。输出短路时两个输入半电流都到达输出端（折叠节点为低阻抗），因此 $A_{vd} = g_{m1}R_{out} \approx 628\,\mu\times8.8\,\mathrm{M} \approx 5.5\times10^3$ > 3000 ✓（按电流均分估计的 $0.75g_{m1}R_{out}$ ≈ 4.2×10³ 也超过 3000）。
