# Golden Solution - A301

## Reference answer

One design (S = W/L): $I_3 = 100\ \mu$A, $I_4 = I_5 = 125\ \mu$A; $S_1 = S_2 \approx 158$; $S_3 \approx 69$; $S_4 = S_5 \approx 33$; $S_6 = S_7 \approx 33$; $S_8 = S_9 = S_{10} = S_{11} \approx 160$ (≈ 96 if sized for the 75-µA quiescent current); $P_{diss}$ ≈ 0.63 mW; $A_{vd}$ ≈ 5.5×10³.

- Slew rate: $I_3 = SR\cdot C_L = 100\ \mu$A; choose $I_4 = I_5 = 1.25I_3 = 125\ \mu$A so the cascode branches never cut off (quiescent 75 µA, range 25–125 µA). $I_4 = I_5 = I_3$ also gives $SR = I_3/C_L$ (one cascode branch just reaches zero current under full steering, which only slows recovery).
- $V_{out}(\min) = -2$ V $= V_{SS} + 0.5$ V: $V_{DS5}(\mathrm{sat}) = V_{DS7}(\mathrm{sat}) = 0.25$ V at up to 125 µA: $S_4 = S_5 = S_6 = S_7 = 2(125)/(120\cdot0.0625) = 33.3$.
- $V_{out}(\max) = -0.5$ V: $V_{SD9}(\mathrm{sat}) = V_{SD11}(\mathrm{sat}) = 0.25$ V: $S_8 = \dots = S_{11} = 2(125)/(25\cdot0.0625) = 160$ (worst-case current).
- $2\pi\,GB = g_{m1}/C_L$: $g_{m1} = 2\pi(10\ \mathrm{MHz})(10\ \mathrm{pF}) = 628\ \mu$S at 50 µA → $S_1 = S_2 = g_{m1}^2/(2K'_P\cdot50\,\mu) = 158$.
- $V_{ic}(\max) = -1$ V sets the p-channel tail: $V_{SD3}(\mathrm{sat}) = V_{DD} - V_{ic}(\max) - |V_{TP}| - \sqrt{I_3/(K'_PS_1)} = 1 - 0.5 - 0.159 = 0.341$ V → $S_3 = 2(100)/(25\cdot0.341^2) = 69$.
- $V_{ic}(\min) = -2.5$ V: M1 stays saturated while $V_{SS} + V_{DS4} \le V_{ic} + |V_{TP}|$, i.e. down to $-2.5 + 0.25 - 0.5 = -2.75$ V ✓ (requires only $S_4 \ge 2I_4/(K'_N(0.5)^2) = 8.3$).
- Power: $2.5\ \mathrm{V}\times(I_4+I_5) = 2.5\times250\ \mu\mathrm{A} = 0.63$ mW (plus bias circuitry) < 5 mW ✓.
- Gain (quiescent 75 µA in the cascodes): $g_{m9} = \sqrt{2(25\,\mu)(160)(75\,\mu)} = 775\ \mu$S, $g_{ds9} = g_{ds11} = 6\ \mu$S → upper $g_{m9}r_{ds9}r_{ds11} = 21.5$ MΩ; $g_{m7} = \sqrt{2(120\,\mu)(33.3)(75\,\mu)} = 774\ \mu$S, $g_{ds7} = 4.5\ \mu$S, $g_{ds2} = 4\ \mu$S, $g_{ds5} = 7.5\ \mu$S → lower $g_{m7}r_{ds7}(r_{ds2}\|r_{ds5}) = 15.0$ MΩ; $R_{out} = 8.8$ MΩ. Both input half-currents reach the output when it is shorted (the folding nodes are low impedance), so $A_{vd} = g_{m1}R_{out} \approx 628\,\mu\times8.8\,\mathrm{M} \approx 5.5\times10^3$ > 3000 ✓ (an even-split estimate $0.75g_{m1}R_{out}$ ≈ 4.2×10³ also exceeds 3000).

## Grading notes

Design problem: accept any design meeting every specification with correct supporting calculations for the complementary (p-input) circuit: $I_3$ from the slew rate, folding currents at least $I_3$ (above $I_3$ is the usual margin, not a requirement), output-swing sizing of the four series devices, $S_1$ from $GB$ using $K'_P$ (≈ 158), the tail sized from the upper common-mode limit (≈ 69), the lower limit checked, the gain (several thousand, > 3000) and power (< 5 mW) verified. Sizing the cascodes for the 75-µA quiescent current instead of the worst case is acceptable. M10/M11 form a self-biased cascode mirror (their common gate is tied to the M8 drain), so that node settles at whatever voltage makes M10 carry the branch current; check a stated bias point of this mirror only for saturation of M8–M11, not against an assumed external bias. +1: valid design with one check missing or one derived value slipped; omitting $r_{ds2}$ (or $r_{ds1}$) from the lower cascode resistance $g_{m7}r_{ds7}(r_{ds2}\|r_{ds5})$ overstates the gain — if the corrected gain still exceeds 3000 for that design, this counts as one wrong derived value (+1), not a failed specification. 0: several sizes right but a specification not verified or violated through a slip. −2 (asserted as fact): input pair sized with $K'_N$ (S1 ≈ 33, giving GB well below 10 MHz) while claiming GB = 10 MHz, the tail sized from the wrong (lower) common-mode limit, specifications claimed met that are not, or the original n-input sizes simply copied.
