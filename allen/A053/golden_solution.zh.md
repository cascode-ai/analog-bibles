n 沟道：0 V 时 $C_{BX}$ = 5.20 fF，0.75 V 反向偏置（$v_{BX}$ = −0.75 V）时为 4.07 fF。p 沟道：0 V 时为 4.31 fF，0.75 V 反向偏置（$v_{BX}$ = +0.75 V）时为 3.43 fF。

- 几何尺寸：每个扩散区为 1.6 µm（从栅边缘到有源区边缘）× 2.0 µm（晶体管宽度；栅长为 0.8 µm）：$AX$ = 3.2 µm²，$PX$ = 2(1.6 + 2.0) = 7.2 µm。
- 模型（反向偏置，$v_{BX} \le$ FC·PB）：$C_{BX} = \dfrac{CJ\cdot AX}{(1 + |V_{BX}|/PB)^{MJ}} + \dfrac{CJSW\cdot PX}{(1 + |V_{BX}|/PB)^{MJSW}}$。
- n 沟道，零偏：$770\times10^{-6}\times3.2\times10^{-12}$ = 2.464 fF（底面）+ $380\times10^{-12}\times7.2\times10^{-6}$ = 2.736 fF（侧壁）= 5.20 fF。0.75 V 时：2.464/1.75^0.5 = 1.863 fF 加上 2.736/1.75^0.38 = 2.212 fF，得 4.07 fF。
- p 沟道，零偏：1.792 + 2.520 = 4.31 fF。0.75 V 时：1.792/1.75^0.5 = 1.355 fF 加上 2.520/1.75^0.35 = 2.071 fF，得 3.43 fF。
- 对这样小的扩散区，侧壁电容约占总电容的一半；由于 MJSW < MJ，它随反向偏置下降得较少。
