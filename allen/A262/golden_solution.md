# Golden Solution - A262

## Reference answer

$I_5 = 20$ µA, $I_7 = I_6 \approx 126$ µA; $W_1 = W_2 \approx 7.2$ µm, $W_3 = W_4 = 10$ µm, $W_5 = 20$ µm, $W_6 \approx 126$ µm, $W_7 \approx 126$ µm ($W_8$ = 10 µm given).

- Slew rate: $I_5 = SR\cdot C_c = (10\ \mathrm{V/\mu s})(2\ \mathrm{pF}) = 20$ µA.
- GB: $g_{m1} = GB\cdot C_c = 2\pi(10\ \mathrm{MHz})(2\ \mathrm{pF}) = 125.7\ \mu$S → $S_1 = S_2 = \dfrac{g_{m1}^2}{2K'_N(I_5/2)} = \dfrac{(125.7\ \mu)^2}{2(110\ \mu)(10\ \mu)} = 7.18$ → $W_1 = W_2 \approx 7.2$ µm.
- +ICMR: $V_{in}(\max) = V_{DD} - V_{SG3} + V_{TN}$ → $V_{SG3} = 1 - 0.8 + 0.7 = 0.9$ V (overdrive 0.2 V) → $S_3 = S_4 = \dfrac{2(10\ \mu\mathrm A)}{50\ \mu(0.2)^2} = 10$ → $W_3 = W_4 = 10$ µm.
- −ICMR: $V_{in}(\min) = V_{SS} + V_{DS5}(\mathrm{sat}) + V_{GS1}$ with $V_{GS1} = 0.7 + \sqrt{2(10\ \mu)/(110\ \mu \cdot 7.18)} = 0.859$ V → $V_{DS5}(\mathrm{sat}) \le 0 + 1 - 0.859 = 0.141$ V → $S_5 \ge \dfrac{2(20\ \mu)}{110\ \mu(0.141)^2} = 18.3$. Since M5 must also mirror 2 × 10 µA from M8 ($S_8 = 10$), $S_5 = 20$, $W_5 = 20$ µm ($V_{DS5}(\mathrm{sat}) = 0.135$ V ✓).
- Output stage: $g_{m6} = 10g_{m1} = 1.257$ mS. $V_{SG4} = V_{SG6}$ requires equal overdrive, so $S_6 = S_4\,g_{m6}/g_{m4}$ with $g_{m4} = \sqrt{2(50\ \mu)(10)(10\ \mu)} = 100\ \mu$S: $S_6 = 125.7$ → $W_6 \approx 126$ µm; $I_6 = \dfrac{g_{m6}^2}{2K'_PS_6} = 125.7\ \mu$A.
- $I_7 = I_6 = 125.7$ µA; $S_7 = S_8 I_7/I_8 = 10 \times 12.57 = 125.7$ (equivalently $S_5 I_7/I_5$) → $W_7 \approx 126$ µm.
- Output-stage slew check (falling edge, M6 off): $(I_7 - I_5)/C_L = 10.6$ V/µs, or $I_7/(C_L + C_c) = 10.5$ V/µs, ≥ 10 V/µs ✓; this needs $I_7 \ge I_5(1 + C_L/C_c) = 120$ µA.
- Checks: $|p_2| = g_{m6}/C_L = 2GB$, $z = g_{m6}/C_c = 10GB$ → $\Phi_M \approx 90° - \arctan 0.5 - \arctan 0.1 = 57.7°$ (≈ 60° by the stated rule; $C_c$ = 2 pF is slightly below $0.22C_L$); $A_v = \dfrac{g_{m1}g_{m6}}{(g_{ds2}+g_{ds4})(g_{ds6}+g_{ds7})} \approx 1.55\times10^4$; $P_{diss} = 2\ \mathrm V \times (10 + 20 + 125.7)\ \mu\mathrm A \approx 0.31$ mW.

## Grading notes

Design problem: accept any design meeting every specification with correct supporting calculations. Key values: $I_5 = 20$ µA, $g_{m1}$ ≈ 126 µS and $W_1$ ≈ 7.2 µm, $W_3$ = 10 µm (from $V_{SG3}$ = 0.9 V), $W_5 \ge 18.3$ µm (20 µm to mirror 20 µA from the 10-µA, 10/1 M8), $g_{m6}$ ≈ 1.26 mS, $W_6$ ≈ 126 µm, $I_6 = I_7$ ≈ 126 µA, $W_7$ ≈ 126 µm (±5 %). +2: all of these (or an equally valid alternative choice where the specs leave freedom). +1: one device off by a slip, or $W_5$ = 18.3 µm without reconciling the mirror ratio with M8. 0: about half the devices right. −2 (asserted as fact): GB used without 2π ($W_1$ ≈ 0.18 µm), $I_5/2$ confused with $I_5$ in $S_1$ (gives 3.6 µm) presented as final, $K'_N$ used for the p-channel devices, or $V_{SG4} = V_{SG6}$ ignored with $W_6$ chosen inconsistently with $I_6$. Freedom in the output stage: $g_{m6} = 10g_{m1}$ and $V_{SG4} = V_{SG6}$ fix only $g_{m6}$ and $V_{OV4} = V_{OV6} = 2I_6/g_{m6}$. +ICMR ≥ 0.8 V needs $V_{OV4} \le 0.2$ V ($I_6 \le 126$ µA), and the falling-edge slew rate $\min[I_5/C_c, (I_7 - I_5)/C_L]$ ≥ 10 V/µs needs $I_7 \ge I_5(1 + C_L/C_c) = 120$ µA (the same bound follows from $I_7/(C_L + C_c)$). Any $I_6 = I_7$ from 120 to 126 µA with $W_3 = W_4 = 2I_3/(K'_PV_{OV4}^2)$ (11 down to 10 µm), $W_6 = 2I_6/(K'_PV_{OV6}^2)$ and $W_7 = 10\ \mu\mathrm m \times I_7/10\ \mu\mathrm A$ earns +2. A smaller $I_7$ chosen from $I_7 = SR\cdot C_L$ (e.g. $I_7$ = 100 µA, $W_3 = W_4$ ≈ 15.8 µm, $W_6$ ≈ 158 µm, $W_7$ = 100 µm, +ICMR = 0.84 V) meets every other specification but ignores the current $I_5$ carried by $C_c$, so the output slews down at only ≈ 8 V/µs: +1. Exceeding a target (e.g. +ICMR above 0.8 V) is not an error, and $I_5$ slightly above 20 µA (e.g. 20.75 µA to put −ICMR exactly at 0 V, with $W_5$ scaled to match the M8 mirror) is valid.
