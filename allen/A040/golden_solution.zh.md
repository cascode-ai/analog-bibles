在双对数坐标中：约 10 kHz 以上平坦，为 100 nV/√Hz；转折点以下按 $1/\sqrt{f}$ 上升（斜率为每十倍频程 −1/2 个数量级，即 −10 dB/十倍频程）。

- 1/f 噪声功率谱密度在 $f_c = 10$ kHz 处等于热噪声谱密度，因此 $e_n^2(f) = (100\ \mathrm{nV}/\sqrt{\mathrm{Hz}})^2\,(1 + f_c/f)$，即 $e_n(f) = 100\ \mathrm{nV}/\sqrt{\mathrm{Hz}}\cdot\sqrt{1 + 10^4/f}$。
- 数值：1 Hz 时为 10 µV/√Hz，10 Hz 时为 3.16 µV/√Hz，100 Hz 时为 1.0 µV/√Hz，1 kHz 时 ≈ 330 nV/√Hz，10 kHz 时 ≈ 141 nV/√Hz（两条渐近线在此处相交于 100 nV/√Hz），100 kHz 时 ≈ 105 nV/√Hz，更高频率时 → 100 nV/√Hz。
- 若用均方谱密度表示，等价地：10 kHz 以上平坦，为 $10^{-14}\ \mathrm{V^2/Hz}$；在其下方按 $1/f$ 上升（每十倍频程一个数量级）：1 kHz 时为 $10^{-13}$，1 Hz 时为 $10^{-10}\ \mathrm{V^2/Hz}$。
