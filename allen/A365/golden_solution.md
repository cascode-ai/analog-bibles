# Golden Solution - A365

## Reference answer

Three requirements: (1) $V_{MIN}(in) = V_{ON}$ means the input transistor cannot be diode-connected (its gate is at $V_T + V_{ON}$ while its drain may be only $V_{ON}$), so the gates must be driven by an amplifier or a level shifter; (2) $V_{MIN}(out) = V_{ON}$ means a single transistor between the output and the rail (no cascode); (3) excellent matching means equal $V_{DS}$ for the input and output transistors at every output voltage (and equal $V_{GS}$).

- Circuit: start from the simple mirror M1 (input), M2 (output), gates common. Add an amplifier A (an op amp or a simple differential pair whose input common-mode range reaches $V_{ON}$, e.g. p-channel input for an n-channel mirror) with its inputs at the drains of M1 and M2 and its output driving the common gate, connected for negative feedback around M1 (more $i_{in}$ raises $V_{D1}$, which raises the gate voltage). The loop forces $V_{D1} = V_{D2} = V_{OUT}$, so M1 conducts $i_{in}$ at the same $V_{DS}$ as M2 and $i_{OUT} = i_{in}(S_2/S_1)$ with no channel-length-modulation error (only $V_T$/K' mismatch remains). Both nodes can go down to $V_{ON}$ (M1, M2 at the edge of saturation): $V_{MIN}(in) = V_{MIN}(out) = V_{ON}$.
- Level-shift variant: hold the input drain one level shift below the gate (a source follower or a BJT whose drop ≈ $V_T$ between the input drain and the common gate), giving $V_{MIN}(in) \approx V_{ON}$ with the simple output ($V_{MIN}(out) = V_{ON}$); matching is then exact only when $V_{OUT} \approx V_{D1}$, so an amplifier that equalizes $V_{D2}$ to $V_{D1}$ is still needed for excellent matching. Equalizing with a regulated cascode on the output instead keeps matching but raises $V_{MIN}(out)$ to $2V_{ON}$.
- Why the unmodified mirrors fail: simple mirror $V_{MIN}(in) = V_T + V_{ON}$ and poor matching ($V_{DS1} \ne V_{DS2}$); cascode and Wilson mirrors need $V_T + 2V_{ON}$ (or $2V_{ON}$ at the output with a high-swing bias); regulated cascode $2V_{ON}$ at the output. Bulk-driven (slightly forward-biased bulk) mirrors lower the input voltage too, but with poorer matching.

## Grading notes

+2: a circuit that (i) drives the mirror gates from an amplifier or level shifter rather than a diode connection so the input node can sit at $V_{ON}$, (ii) has a single output transistor so $V_{MIN}(out) = V_{ON}$, and (iii) equalizes $V_{DS1}$ and $V_{DS2}$ (or otherwise justifies excellent matching), with the minimum voltages justified. +1: two of the three met, for example a level-shifted simple mirror with the matching limitation acknowledged, or a regulated-cascode solution with matching but $V_{MIN}(out) = 2V_{ON}$ clearly stated. 0: correct analysis of the minimum voltages of the standard mirrors but no workable modification. −2 (asserted as fact): a standard cascode, Wilson or high-swing cascode mirror claimed to have $V_{MIN}(in) = V_{MIN}(out) = V_{ON}$, a diode-connected input claimed to work at $V_{ON}$, or an amplifier connected for positive feedback. The question lists four mirrors, so an answer may treat each of them; grade the extra modifications on their own correctness. An answer that stacks an amplifier-regulated device on each mirror transistor and reaches $V_{ON}$ only by letting the stacked device (and/or the core device) enter the triode region, says so, and forces the core $V_{DS}$ values equal, is not the −2 case above; if the amplifier-driven simple mirror is also given correctly, score +1. Describing the standard Wilson mirror as having a single transistor in its output path (it has two stacked devices) is a misread of the circuit; a modification built on it is a critical error confined to that part, which caps the score at 0 even when the main scheme is right.
