所需 $g_m = 1/R_1 = 1/3.2\ \mathrm{k\Omega} = 312.5\ \mu$S。一种设计：p 沟道源极耦合对（source-coupled pair），尾电流 $I_{SS}$ = 100 µA，$W/L$ = 20 µm/1 µm，负载为 n 沟道电流镜（例如 5 µm/1 µm），其输出端（电流镜输出管的漏极）接到电流放大器的输入节点。

- 采用电流镜负载时，输出电流为 $i_o = g_m v_{id}$，其中 $g_m$ 是一个输入管在 $I_{SS}/2$ 下的跨导：$g_m = \sqrt{2K'(W/L)(I_{SS}/2)} = \sqrt{K'(W/L)I_{SS}}$。
- $g_m = 312.5\ \mu$S → $(W/L)I_{SS} = g_m^2/K'_P = (312.5\ \mu)^2/50\ \mu = 1.95$ mA → $I_{SS}$ = 100 µA，W/L ≈ 19.5 ≈ 20（$g_m$ = 316 µS）。（若用 n 沟道差分对，则需 $(W/L)I_{SS}$ = 0.89 mA，例如 100 µA 时 W/L ≈ 9。）
- 于是该跨导器起到 $v_{in}/R_1$ 的作用：增益 $= -g_mR_2A_o/(1+A_o) = -(312.5\ \mu)(352\ \mathrm{k})(0.1/1.1) = -10$（符号取决于使用哪个输入端），而且现在具有高阻抗的差分输入。
- 检验：跨导器的输出电阻 $r_{ds}\|r_{ds}$ ≈ 1/[(0.04 + 0.05)(50 µA)] ≈ 220 kΩ ≫ 451 Ω，因此其电流几乎全部进入电流放大器；直流：输出节点约为 −1.7 V，使 n 沟道电流镜器件的 $V_{DS}$ ≈ 1.3 V（饱和），输入接近 0 V 时 p 沟道输入管的 $V_{SD}$ ≈ 2.8 V（饱和）。若用 n 沟道差分对，则输入共模电平必须保持在约 −1 V 以下。
