$V_A \approx 0.90$ V，$V_B \approx 1.00$ V，$V_C \approx 0.094$ V（≈ 0.1 V）。

- 负载电流（由 240/14、电流为 100 µA 的 M7 镜像而来）：$I_3 = 100\ \mu\mathrm{A}\times(144/240) = 60\ \mu$A，$I_4 = 100\ \mu\mathrm{A}\times(240/240) = 100\ \mu$A。
- 对于理想电流源负载，反相器在其驱动管（处于饱和区）流过负载电流时发生翻转：$V_{GS} = V_{TN} + \sqrt{2I/(K'_N W/L)}$。
- $V_A = 0.7 + \sqrt{2(60\ \mu)/(47\ \mu\times 460/7.5)} = 0.7 + 0.204 = 0.904$ V。
- $V_B = 0.7 + \sqrt{2(100\ \mu)/(47\ \mu\times 360/7.5)} = 0.7 + 0.298 = 0.998$ V。
- $V_C = 0.998 - 0.904 = 0.094$ V：这是一个很小的正死区（dead zone），其中两个输出器件都截止，从而获得较低的静态电流。
（若计入沟道长度调制，取 $\lambda_N = 0.05$、$\lambda_P = 0.04$ V⁻¹，并在 ±6 V 电源下令输出处于电源中点，则两个中点分别移动到约 0.893 V 和 0.981 V，$V_C \approx 0.09$ V。）
