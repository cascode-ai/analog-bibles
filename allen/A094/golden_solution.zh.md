版图 1、2 和 4 可以连接成该电流镜；按图中标注以中间的栅指作为 M1 时，版图 3 无法连接成正确的 1:2 电流镜。（只有改用一端的栅指作为二极管连接的输入管，同一几何结构才能构成 1:2 电流镜，但这会对调标注的角色。）

- 版图 1：M1：一个扩散区（例如上方）→ IN，另一个 → GRD，多晶硅 → IN。M2：上方 → OUT，下方 → GRD，多晶硅 → IN。
- 版图 2：M2A 和 M2B：上方区域 → OUT，下方区域 → GRD，两条多晶硅 → IN。M1（旋转放置，栅极竖直）：一侧区域 → IN，另一侧 → GRD，多晶硅 → IN。
- 版图 3：三个栅共用一条连续的扩散区，形成四个区域 R1 | M2A | R2 | M1 | R3 | M2B | R4。M1 需要 R2、R3 中一个接 IN、另一个接 GRD。但 R2 也是 M2A 的端子，R3 也是 M2B 的端子，而这两者的端子只能接 OUT 和 GRD，因此 R2 和 R3 都必须接 GRD，M1 就没有漏极了。M2 的两半中必然有一个以 IN 为端子（例如令 R3 = IN，M2B 就成为与 M1 并联的第二个二极管连接器件，得到 2:1）。因此，按图中标注以中间栅指作为 M1 时，版图 3 无法连接成 1:2 电流镜。若改用一端的栅指作为二极管连接的输入管，同一几何结构确实能构成电学上正确的 1:2 电流镜：R1 = IN，R2 = GRD，R3 = OUT，R4 = GRD，所有栅极接 IN（左侧 5/1 栅指为输入管；中间和右侧栅指并联构成 10/1 输出管）。这对调了 M1 与 M2A 的标注角色，也放弃了 M1 位于 M2 两半之间的对称布置。否则就必须断开扩散区，或重新排列栅指（例如 OUT | GRD | IN | GRD | OUT，并将 M1 拆成两半）。
- 版图 4：三个独立的 5/1 器件：M2A 和 M2B 上方 → OUT，下方 → GRD；M1 上方 → IN，下方 → GRD；三条多晶硅都 → IN。
- 在所有情况下，栅极（多晶硅）都接 IN（M1 的漏极），从而使 M1 成为二极管连接。
