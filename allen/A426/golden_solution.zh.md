对码 k，$v_{out} = -\dfrac{7}{8}\left(\dfrac{b_0}{2} + \dfrac{b_1}{4} + \dfrac{b_2}{8} + \dfrac{b_3}{16}\right)V_{REF} = -\dfrac{7k}{128}V_{REF}$：即理想特性的 7/8。

- 反相求和器（inverting summer）：$v_{out} = -R_0 V_{REF}\sum b_i/R_{i+1}$，其中 $R_0/R_1 = 7/16$，$R_0/R_2 = 7/32$，$R_0/R_3 = 7/64$，$R_0/R_4 = 7/128$。
- 特性是一条过原点（无失调）、均匀且单调的阶梯，台阶为 7/8 LSB（LSB = $V_{REF}/16$）：|v_out| = 0、0.0547、0.109、…、在 1111 处为 0.820 $V_{REF}$，而理想值为 0.9375 $V_{REF}$。
- 纯增益误差（gain error）−12.5 %：偏差随码线性增大，在 1111 处达到 −1.875 LSB（每个台阶的 DNL = −0.125 LSB）。当 $V_{REF}$ 为正时输出为负（图中画的是幅值随码的变化）。
