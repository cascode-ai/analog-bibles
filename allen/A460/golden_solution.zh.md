除数为 2：$+INL = +3$ LSB，$-INL = 0$ LSB；$+DNL = +1$ LSB，$-DNL = -3$ LSB；不单调。
除数为 6：$+INL = 0$ LSB，$-INL = -1$ LSB；$+DNL = +1$ LSB，$-DNL = -1/3$ LSB（≈ −0.33）；单调。

推导（1 LSB = $V_{REF}/16$；将码写成 $4m + n$，其中 $m = 2b_0 + b_1$，$n = 2b_2 + b_3$，各取 0…3）：
- MSB 子 DAC 输出 = $4m$ LSB。LSB 子 DAC 输出 = $(n/4)V_{REF} = 4n$ LSB，除以除数 $d$ 后为 $4n/d$ LSB。理想情况（$d = 4$）：$n$ LSB。
- $d = 2$：LSB 部分 $= 2n$，故输出为 $4m + 2n$ LSB：对于码 0000…1111 依次为 0, 2, 4, 6, 4, 6, 8, 10, 8, 10, 12, 14, 12, 14, 16, 18。误差 $= n$：0 至 +3 LSB。台阶：每组内部为 2 LSB（DNL = +1），在 0011→0100、0111→1000、1011→1100 处为 $4 - 6 = -2$ LSB（DNL = −3）。输出在这些跳变处下降，因此该 DAC 不单调。
- $d = 6$：LSB 部分 $= 2n/3$，故误差为 $-n/3$：0, −1/3, −2/3, −1 LSB。台阶：每组内部为 2/3 LSB（DNL = −1/3），在组间跳变处为 $4 - 2 = 2$ LSB（DNL = +1）。每个台阶都为正，因此该 DAC 单调。
