Its values (all L = 1 µm): M1, M3, M5, M7: W = 200 µm, 1 mA; M2, M4, M6, M8: W = 20 µm, 100 µA, so the current gain of the current amplifier is $A_o = 0.1$; M12: W/L = 20/1 carrying 100 µA; $R_2$ = 352 kΩ, $R_3$ = 300 Ω; the capacitance at the current-amplifier output (gate of M12) is $C_o$ = 105 fF. A second input is added to this amplifier by using another resistor $R_1$ connected from this input to the input of the current amplifier.
