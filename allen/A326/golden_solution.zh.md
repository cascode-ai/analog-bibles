$R_{in} \approx 1.03$ kΩ，$R_{out} \approx 77\ \Omega$，$f_{-3\,dB} \approx 41$ MHz（极点约在 $2.6\times10^8$ rad/s）；低频增益 ≈ −0.87 V/V。

模型：电流放大器输入电阻 $r_i = R_3 + 1/g_{m1} = 300 + 1/6.63\ \mathrm{mS} = 451\ \Omega$；输出电流 $A_o i_{in}$ 由节点 O（M12 的栅极）吸入，$C_o$ 接在 O 上，$R_2$ 从输入节点 N 接到 O；跟随器 $g_{m12} = \sqrt{2(110\ \mu)(20)(100\ \mu)} = 663\ \mu$S。
- 节点 N：$(v_{in} - v_N)/R_1 + (v_{out} - v_N)/R_1 + (v_O - v_N)/R_2 = v_N/r_i$。
- 节点 O：$(v_N - v_O)/R_2 = A_o v_N/r_i + sC_ov_O$；直流时 $v_O = v_N(1 - A_oR_2/r_i) = -77.1\,v_N$。
- 输出：$g_{m12}(v_O - v_{out}) = (v_{out} - v_N)/R_1$（再加上可能的测试电流）。
- 求解：直流时 $v_{out}/v_{in} = -0.872$；一个极点位于 $2.58\times10^8$ rad/s → 41 MHz（开环极点 $(1+A_o)/(R_2C_o)$ = 29.8 Mrad/s 被经第二个 $R_1$ 形成的约 7 的环路增益展宽）。
- 精确地，$v_{out}/v_{in} = -0.872\,(1 - s/1.36\times10^9)/(1 + s/2.58\times10^8)$：经由跟随器有限输出电阻的 $R_1$–$R_1$ 直通路径引入一个约 216 MHz 的右半平面零点，因此真正的半功率频率约为 42.7 MHz（小信号仿真）；41 MHz 是主极点值。
- $R_{in} = v_{in}/i_{in}$：计入反馈后节点 N 的电阻只有约 30 Ω，因此 $R_{in} = 1000 + 30 \approx 1030\ \Omega$。
- $R_{out}$（在 $v_{out}$ 加测试电流，$v_{in}$ = 0）：$v_N = 0.225\,v_{out}$，$v_O = -17.4\,v_{out}$，$i_t = v_{out}[g_{m12}(18.4) + 0.775/1000] = 0.01296\,v_{out}$ → $R_{out} = 77\ \Omega$（跟随器本身的 $1/g_{m12}$ = 1.5 kΩ 被反馈环路减小）。
