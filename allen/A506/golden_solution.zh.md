输出数字字：1001。四次 D/A 转换结束时 $v_{C1} = v_{C2}$ = 0.5、0.75、0.625 和 0.5625 $V_{REF}$。

逐时钟电平（电压以 $V_{REF}$ 为单位，按 $v_{C1}$/$v_{C2}$ 列出；P = 预充电/放电周期，S = 电荷分享周期）：
- 迭代 1，字 “1”：P：1 / 0（C2 复位）；S：0.5 / 0.5。$0.6 > 0.5$ → MSB = 1。
- 间隔：$v_{C2}$ 复位到 0。
- 迭代 2，字 “11”（从 LSB 开始：1, 1）：P：1 / 0；S：0.5 / 0.5；P：1 / 0.5；S：0.75 / 0.75。$0.6 < 0.75$ → 第二位 = 0。
- 间隔：$v_{C2}$ → 0。
- 迭代 3，字 “101”（从 LSB 开始：1, 0, 1）：P：1 / 0；S：0.5 / 0.5；P：0 / 0.5；S：0.25 / 0.25；P：1 / 0.25；S：0.625 / 0.625。$0.6 < 0.625$ → 第三位 = 0。
- 间隔：$v_{C2}$ → 0。
- 迭代 4，字 “1001”（从 LSB 开始：1, 0, 0, 1）：P：1 / 0；S：0.5 / 0.5；P：0 / 0.5；S：0.25 / 0.25；P：0 / 0.25；S：0.125 / 0.125；P：1 / 0.125；S：0.5625 / 0.5625。$0.6 > 0.5625$ → LSB = 1。
