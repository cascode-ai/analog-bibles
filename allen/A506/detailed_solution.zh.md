# 详细步骤 - A506

串行 DAC 实现的是与算法型 DAC 相同的减半递推：在 $C_1=C_2$ 时，每次电荷分享把 $v_{C2}$ 换成新的预充电电平与原 $v_{C2}$ 的平均值。ADC 每判定一位就调用一次该 DAC，试探字逐渐变长；因此对每个试探字逐个时钟周期跟踪 DAC，把其输出与 $0.6V_{REF}$ 比较，并汇总各位。

### 第 1 步 — 一次串行 D/A 转换

$C_2$ 从 $v_{C2}=0$ 开始（S4）。对位 $d_j$（LSB 先输入），预充电周期使 $v_{C1}=d_jV_{REF}$；分享周期中 S1 把两个相等的电容并联，由电荷守恒得

$$
C_1v_{C1}+C_2v_{C2}=(C_1+C_2)v'
\;\Longrightarrow\;
v_{C1}=v_{C2}=v'=\tfrac12\left(d_jV_{REF}+v_{C2}\right).
$$

对字 $d_1d_2\dots d_m$ 的全部 $m$ 位处理完后（MSB $d_1$ 最后输入），

$$
V_{DAC}=V_{REF}\sum_{j=1}^{m}d_j\,2^{-j},
$$

因此试探字 "1" 给出 $0.5V_{REF}$，"11" 给出 $0.75V_{REF}$，依此类推。$m$ 位的字需要 $2m$ 个时钟周期。

### 第 2 步 — 各次迭代与位判定

每次迭代转换已判定的各位后接一个试探位 1 的字，若 $V_{in}^*=0.6V_{REF}>V_{DAC}$ 则保留该 1。以第 3 次迭代、字 101（LSB 先输入：1、0、1）为代表，以 $V_{REF}$ 为单位：

$$
\begin{aligned}
&\text{P: } v_{C1}=1,\ v_{C2}=0 &&\text{S: } \tfrac12(1+0)=0.5\\
&\text{P: } v_{C1}=0,\ v_{C2}=0.5 &&\text{S: } \tfrac12(0+0.5)=0.25\\
&\text{P: } v_{C1}=1,\ v_{C2}=0.25 &&\text{S: } \tfrac12(1+0.25)=0.625
\end{aligned}
$$

由于 $0.6<0.625$，试探位改为 0。四次迭代的全部结果如下（每个周期后的 $v_{C1}$/$v_{C2}$，P = 预充电或放电，S = 分享）：

| 迭代 | 字（LSB 先输入） | 各周期电平 $v_{C1}$/$v_{C2}$ | $V_{DAC}/V_{REF}$ | 判定 |
|---|---|---|---|---|
| 1 | 1 | P 1/0, S 0.5/0.5 | 0.5 | $0.6>0.5$ → 1 |
| 2 | 11 (1, 1) | P 1/0, S 0.5/0.5, P 1/0.5, S 0.75/0.75 | 0.75 | $0.6<0.75$ → 0 |
| 3 | 101 (1, 0, 1) | P 1/0, S 0.5/0.5, P 0/0.5, S 0.25/0.25, P 1/0.25, S 0.625/0.625 | 0.625 | $0.6<0.625$ → 0 |
| 4 | 1001 (1, 0, 0, 1) | P 1/0, S 0.5/0.5, P 0/0.5, S 0.25/0.25, P 0/0.25, S 0.125/0.125, P 1/0.125, S 0.5625/0.5625 | 0.5625 | $0.6>0.5625$ → 1 |

相邻两次迭代之间用一个时钟周期进行比较，并把 $v_{C2}$ 复位到 0。

### 第 3 步 — 波形

各次迭代分别占 2、4、6 和 8 个时钟周期，其间有三个间隔周期，因此转换共持续 $20+3=23$ 个周期。$v_{C1}$ 在每个预充电周期跳到 $V_{REF}$ 或 0，每次分享后等于 $v_{C2}$；$v_{C2}$ 在每次迭代中从 0 重新开始，只在分享周期变化，最终依次为 0.5、0.75、0.625 和 0.5625 $V_{REF}$。

### 第 4 步 — 输出数字字

按 MSB 在先排列已判定的各位，得

$$
\text{digital word}=1001,\qquad V_{DAC}=\tfrac9{16}V_{REF}=0.5625\,V_{REF},
$$

即低于 $0.6V_{REF}$ 的最大 4 位电平（下一个电平 $0.625V_{REF}$ 超过输入）。
