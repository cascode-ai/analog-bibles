一种可行的设计：$I_1 = I_5 = 100\ \mu$A，$W_1/L_1 = 50$；$I_2 = I_6 = 11\ \mu$A，$W_2/L_2 = 5.5$；取 $I_{BIAS} = 100\ \mu$A、$W_4/L_4 = 50$，则 $W_5/L_5 = 50$，$W_6/L_6 = 5.5$（所有 L = 1 µm）。

- 输入：$R_{in} = 1/(g_{m1} + g_{ds1} + g_{ds5}) \approx 1/g_{m1}$。$R_{in} < 1$ kΩ 要求 $g_{m1} > 1$ mS，即 $(W_1/L_1)I_1 \ge g_{m1}^2/(2K'_N) = 4.55\times10^{-3}$ A。选 $I_1$ = 100 µA、$W_1/L_1$ = 50：$g_{m1} = \sqrt{2(110\ \mu)(50)(100\ \mu)} = 1.049$ mS，$R_{in} = 1/(1.049\ \mathrm{m} + 9\ \mu) = 945\ \Omega$。
- 输出：$R_{out} = 1/(g_{ds2} + g_{ds6}) = 1/[(\lambda_N + \lambda_P)I_2] \ge 1$ MΩ 要求 $I_2 \le 1/(0.09\times10^6) = 11.1\ \mu$A。选 $I_2$ = 11 µA：$R_{out}$ = 1.01 MΩ。
- 镜像比 $W_2/L_2 = (W_1/L_1)(I_2/I_1) = 50\times0.11 = 5.5$。
- 电流源提供直流电流：$I_5 = I_1$，$I_6 = I_2$，因此 $(W_5/L_5):(W_6/L_6):(W_4/L_4) = I_1 : I_2 : I_{BIAS}$；取 $I_{BIAS}$ = 100 µA、$W_4/L_4$ = 50，得 50 和 5.5。
- 该设计体现了折中：低 $R_{in}$ 需要大的 $g_{m1}$（即大电流），而高 $R_{out}$ 需要小的输出电流，因此电流镜必须按约 9:1 缩小。
- 关于括号中的增益：R2 把输出反馈到 M1 的漏极，因此当镜像比为 $K = I_2/I_1$ 时，到 M2/M6 漏极的增益为 $\dfrac{R_{out}(1 - Kg_{m1}R_2)}{R_1 + R_2 + R_{out} + g_{m1}R_1[R_2 + (1+K)R_{out}]}$，只有在 $R_{out} \to \infty$ 且 $g_{m1}R_1 \gg 1$ 时才趋于 $-\dfrac{K}{1+K}\dfrac{R_2}{R_1}$（K ≈ 1/9 时 ≈ −10）。在指标的极限值下（$R_{out}$ ≈ 1 MΩ ≈ $R_2$，$g_{m1}R_1$ ≈ 10），本设计的增益约为 −4.8。题目要求的设计与此无关。
