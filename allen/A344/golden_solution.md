# Golden Solution - A344

## Reference answer

One valid design (it fixes the common mode of both stages): use [Fig. 2] with its inputs swapped, gates of M1 and M2 of the sensing circuit grounded ($V_{ocm} = 0$, the ground reference) and gates of M3 and M4 at $v_{o1}$ and $v_{o2}$, and drive the gate of the op amp's tail M5 from the correction node X (the common drain of M3, M4 and M6); M8/M9 stay on $V_{BN}$ and M3/M4 of the op amp on $V_{BP}$.

- Operation: M5 → M6 of [Fig. 2] mirrors $I_5 = I_1 + I_2$ (fixed, gates at 0 V); node X receives $(I_3 + I_4) - I_6$. With identical M1–M4 the loop settles where $I_3 + I_4 = I_1 + I_2$, i.e., output common mode ≈ 0 V.
- Polarity: output CM rises → $V_{SG3}$, $V_{SG4}$ fall → $I_3 + I_4$ falls → X falls → op-amp tail current falls → first-stage outputs (drains of M1/M2, loads fixed by $V_{BP}$) rise → $V_{SG6}$, $V_{SG7}$ fall → outputs fall: negative feedback. The loop sets the tail current equal to the two load currents, so the first-stage common mode is also defined (it settles where M6/M7 carry the M8/M9 currents).
- Sizing (example, square law): [Fig. 2] M1–M4 p-channel W/L = 1 µm/4 µm: at 0 V gates $V_{SG}$ = 2.5 V, $I = \tfrac12(50\ \mu)(0.25)(1.8)^2 \approx 20\ \mu$A each, $I_5 = I_6 \approx 40\ \mu$A; M5 = M6 = 5/1 ($V_{ON} \approx 0.38$ V, diode at ≈ −1.42 V). Op amp (example): M1, M2 7.3/1, tail 14.6/1, all p-channel 16/1, $V_{BP}$ = 1.2 V ($V_G$ = +1.3 V), $V_{BN}$ gate at −1.3 V for M8/M9: 200 µA tail, 100 µA per branch, 0.5 V overdrives, first-stage outputs ≈ +1.3 V, X ≈ −1.3 V.
- DC checks: [Fig. 2] M6 saturated ($V_X - V_{SS} \approx 1.2\ \mathrm{V} > 0.38$ V); M3, M4 saturated since $V_X \le v_o + |V_{TP}| = 0.7$ V; M1, M2 saturated (drain at −1.42 V ≤ 0.7 V); the sensing pair M3/M4 conducts only while $v_o < V_{DD} - |V_{TP}| = 1.8$ V, which bounds the usable output swing. A level-1 simulation of this example gives output CM ≈ −7 mV, unchanged (within 15 mV) when $V_{BP}$ is shifted by ±0.1 V.
- Stability: the CM loop passes through the first-stage node and the output, the same path as the differential signal, so the existing Miller $C_c$/$R_z$ compensation largely covers it; X is a moderate-impedance node, and a capacitor from X to $V_{SS}$ can be added if more phase margin is needed. Exact margins need parasitic data not given.
- Equally valid: the drawn orientation (M1, M2 at the outputs, M3, M4 grounded), where X rises with the output CM, with one inversion before driving a first-stage current (e.g., X → n-channel mirror → diode-connected p-channel device setting $V_{BP}$ of the op amp's loads M3/M4).
- Partial design: the drawn orientation with X driving the gates of M8/M9 directly is negative feedback (CM up → $I_1 + I_2$ down → X up → M8/M9 sink more), but it controls only the second stage; the first-stage common mode is then set by the mismatch of the $V_{BP}$ loads and the $V_{BN}$ tail through high-impedance nodes and is undefined (in simulation a ±0.1 V shift of $V_{BP}$ drives the first-stage output to a rail and the output CM to ≈ 0.47 V). It works only if the first-stage CM is fixed by other means.
- Limitation: the square-law sum grows with the differential swing $x$ per side, shifting the output CM by $\delta = V_{ON} - \sqrt{V_{ON}^2 - x^2}$ ($V_{ON}$ = 1.8 V here; ≈ 70 mV for x = 0.5 V); 0 V is the nominal (zero-differential) target.

## Grading notes

Accept any design that closes a negative-feedback loop from the sensed output CM to a current-setting device of the op amp, references the CM level to ground, defines the first-stage common mode, and has consistent dc levels. +2: correct connection (outputs to the sensing devices, reference at 0 V), correct polarity verified (e.g., swapped sensing to the tail M5, or drawn sensing with one inversion to the $V_{BP}$ loads), the first-stage CM fixed by the loop or by a stated additional mechanism, saturation/level checks and reasonable sizes, and attention to loop stability. The direct X → M8/M9 connection with polarity and dc checks right earns +2 only if the answer also states how the first-stage CM is fixed; without that it is +1. Unsupported phase-margin numbers or a small slip in a swing limit are minor. +1: correct connection and polarity with dc checks or stability omitted. 0: a plausible connection without polarity check that happens to be correct, or correct ideas with a dc-level error that would push a device out of saturation. −2 (asserted as fact): a connection with positive feedback (e.g., node X of the drawn orientation driving the gates of the op amp's p-channel loads M3/M4, or its tail M5, directly), $V_{ocm}$ not tied to ground, a stated operating point at which the sensing currents do not balance, or a design claimed to work whose sensing devices are cut off at $v_o$ = 0. Check the polarity of the answer's main scheme yourself: an extra inversion between X and the gates of M8/M9 (e.g., X driving a p-channel device whose current sets the M8/M9 gate voltage through a diode-connected n-channel device) makes the loop positive, and claiming it negative is −2 even if the direct X → M8/M9 connection is mentioned as a side alternative.
