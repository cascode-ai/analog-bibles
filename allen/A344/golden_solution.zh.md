一种可行的设计（它同时确定了两级的共模电平）：使用输入对调后的 [图 2]，检测电路中 M1 和 M2 的栅极接地（$V_{ocm} = 0$，即地基准），M3 和 M4 的栅极分别接 $v_{o1}$ 和 $v_{o2}$，并由校正节点 X（M3、M4 和 M6 的公共漏极）驱动运放尾电流管 M5 的栅极；M8/M9 仍接 $V_{BN}$，运放的 M3/M4 仍接 $V_{BP}$。

- 工作原理：[图 2] 中 M5 → M6 镜像 $I_5 = I_1 + I_2$（固定，栅极为 0 V）；节点 X 得到 $(I_3 + I_4) - I_6$。若 M1–M4 相同，环路在 $I_3 + I_4 = I_1 + I_2$ 处稳定，即输出共模 ≈ 0 V。
- 极性：输出共模上升 → $V_{SG3}$、$V_{SG4}$ 下降 → $I_3 + I_4$ 下降 → X 下降 → 运放尾电流下降 → 第一级输出（M1/M2 的漏极，负载由 $V_{BP}$ 固定）上升 → $V_{SG6}$、$V_{SG7}$ 下降 → 输出下降：负反馈。环路使尾电流等于两个负载电流之和，因此第一级的共模电平也得以确定（它稳定在 M6/M7 流过 M8/M9 电流的位置）。
- 尺寸（示例，平方律）：[图 2] 中 M1–M4 为 p 沟道，W/L = 1 µm/4 µm：栅极为 0 V 时 $V_{SG}$ = 2.5 V，每管 $I = \tfrac12(50\ \mu)(0.25)(1.8)^2 \approx 20\ \mu$A，$I_5 = I_6 \approx 40\ \mu$A；M5 = M6 = 5/1（$V_{ON} \approx 0.38$ V，二极管约在 −1.42 V）。运放（示例）：M1、M2 为 7.3/1，尾电流管 14.6/1，所有 p 沟道管 16/1，$V_{BP}$ = 1.2 V（$V_G$ = +1.3 V），M8/M9 的 $V_{BN}$ 栅极接 −1.3 V：尾电流 200 µA，每支路 100 µA，过驱动电压 0.5 V，第一级输出 ≈ +1.3 V，X ≈ −1.3 V。
- 直流检查：[图 2] 中 M6 饱和（$V_X - V_{SS} \approx 1.2\ \mathrm{V} > 0.38$ V）；由于 $V_X \le v_o + |V_{TP}| = 0.7$ V，M3、M4 饱和；M1、M2 饱和（漏极 −1.42 V ≤ 0.7 V）；检测对 M3/M4 只有在 $v_o < V_{DD} - |V_{TP}| = 1.8$ V 时才导通，这限制了可用的输出摆幅。对该示例的 level-1 仿真给出输出共模 ≈ −7 mV，当 $V_{BP}$ 偏移 ±0.1 V 时基本不变（变化在 15 mV 以内）。
- 稳定性：共模环路经过第一级节点和输出端，与差模信号的路径相同，因此现有的密勒 $C_c$/$R_z$ 补偿基本也能覆盖它；X 是中等阻抗节点，若需要更大的相位裕度，可在 X 与 $V_{SS}$ 之间加一个电容。精确的裕度需要题中未给出的寄生参数。
- 同样可行：按图中原来的方向连接（M1、M2 接输出，M3、M4 接地），此时 X 随输出共模上升，需在驱动某一第一级电流之前再反相一次（例如 X → n 沟道电流镜 → 二极管连接的 p 沟道器件，由它设定运放负载管 M3/M4 的 $V_{BP}$）。
- 不完整的设计：按原方向连接并由 X 直接驱动 M8/M9 的栅极，这是负反馈（共模上升 → $I_1 + I_2$ 下降 → X 上升 → M8/M9 吸入更多电流），但它只控制第二级；此时第一级的共模电平由 $V_{BP}$ 负载与 $V_{BN}$ 尾电流在高阻抗节点上的失配决定，是不确定的（仿真中 $V_{BP}$ 偏移 ±0.1 V 就会把第一级输出推到电源轨，输出共模变为 ≈ 0.47 V）。只有在第一级共模由其他方式确定时它才可用。
- 局限：平方律求和随每侧差分摆幅 $x$ 增大而增大，使输出共模偏移 $\delta = V_{ON} - \sqrt{V_{ON}^2 - x^2}$（此处 $V_{ON}$ = 1.8 V；x = 0.5 V 时约 70 mV）；0 V 是名义（零差分）目标值。
