# Golden Solution - A302

## Reference answer

One design: I = 100 µA; $W_1 = W_2 = 36\ \mu$m; $W_3 = W_4 = 24\ \mu$m; $W_6 = W_7 = 24\ \mu$m; $W_8 = W_9 = W_{10} = W_{11} = 121\ \mu$m; $W_5 = W_{12} = W_{13} = 1.4\ \mu$m; $W_{14} = 16\ \mu$m; $W_{15} = 4\ \mu$m. Then $R_{out} \approx 9.4$ MΩ and $A_{vd} \approx g_{m1}R_{out} \approx 5.9\times10^3$ V/V.

- Slew rate: if the input is overdriven the output can source or sink I (e.g. M2 takes all of I: M7 carries 0.5I while M11 mirrors 1.5I), so $I = SR\cdot C_L = 100\ \mu$A; M3, M4 carry 150 µA.
- $2\pi\,GB = g_{m1}/C_L$: $g_{m1} = 2\pi(10\ \mathrm{MHz})(10\ \mathrm{pF}) = 628\ \mu$S at 50 µA → $S_1 = (628\,\mu)^2/(2\cdot110\,\mu\cdot50\,\mu) = 35.9$ → 36 µm.
- $V_{out}(\max) = +2$ V: 1 V across M4 and M7, 0.5 V each. M4 at 150 µA: $S_4 = 2(150)/(50\cdot0.25) = 24$ (= $S_3$). M7 can carry up to 150 µA, so $S_6 = S_7 = 24$ (16 if sized for 100 µA).
- $V_{out}(\min) = -2$ V: the M8–M11 cascode mirror (M8 and M10 diode-connected) puts the source of M9 at $V_{SS} + V_{GS10}$, so $V_{out}(\min) = V_{SS} + V_{TN} + 2V_{ov}$ → $V_{ov} = 0.15$ V; at the worst-case 150 µA, $S = 2(150)/(110\cdot0.0225) = 121$ for M8–M11. (This splits the headroom left after the extra $V_{TN}$ equally between the two overdrives. Splitting the actual 1 V of $V_{DS}$ equally is also valid: e.g. M8 = M10 = M11 = 121 µm and M9 ≈ 10.9 µm puts the M9 gate at −1.3 V and its source at −2.5 V, so M9 and M11 each have 0.5 V at $v_{out} = -2$ V and stay saturated.)
- $V_{ic}(\min) = -1$ V: $V_{SS} + V_{DS5}(\mathrm{sat}) + V_{GS1}$ with $V_{GS1} = 0.7 + \sqrt{2\cdot50/(110\cdot36)} = 0.859$ V → $V_{DS5}(\mathrm{sat}) = 1.14$ V → $S_5 = 2(100)/(110\cdot1.14^2) = 1.4$; M12, M13 the same (same current I).
- $V_{ic}(\max)$: the M1 drain (folding node) sits at $V_{G6} + V_{SG6} = 1.3 + 0.7 + 0.41 = 2.41$ V, so $V_{ic}(\max) \approx 2.41 + 0.7 = 3.1$ V ≥ 2 V ✓ (M3 saturation alone would allow 3.2 V).
- Bias: M14 (diode, I) mirrors to M3, M4 (1.5I) → $S_{14} = 24/1.5 = 16$. M15 (diode, I) sets the M6/M7 gates: $V_{SG15} = V_{SD4}(\mathrm{sat}) + V_{SG7} = 0.5 + 0.7 + 0.5 = 1.7$ V → overdrive 1.0 V at 100 µA → $S_{15} = 2(100)/(50\cdot1.0) = 4$.
- Small-signal (quiescent): $g_{m9} = \sqrt{2(110\,\mu)(121)(100\,\mu)} = 1.63$ mS, $r_{ds9} = r_{ds11} = 250$ kΩ → $R_9 = g_{m9}r_{ds9}r_{ds11} = 102$ MΩ; $g_{m7} = 490\ \mu$S, $r_{ds7} = 200$ kΩ, $r_{ds2}\|r_{ds4} = 500\,\mathrm{k}\|133\,\mathrm{k} = 105$ kΩ → upper $g_{m7}r_{ds7}(r_{ds2}\|r_{ds4}) = 10.3$ MΩ; $R_{out} = 102\,\|\,10.3 \approx 9.4$ MΩ.
- Gain: with the output shorted, the M1 current reaches the output through M6 and the M8–M11 mirror, and the M2 current reaches it through M7 (the M7 source is then ≈ $1/g_{m7}$, far below $r_{ds2}\|r_{ds4}$), so the short-circuit transconductance is $g_{m1}$ and $A_{vd} = g_{m1}R_{out} \approx 629\,\mu\times9.4\,\mathrm{M} \approx 5.9\times10^3$ (a full small-signal nodal solution of the circuit gives 5.9×10³). The output is in phase with $v_{id} = v_1 - v_2$.

## Grading notes

Design problem: accept any design that meets every specification with correct supporting calculations (I from the slew rate, $S_1$ from GB, output-swing sizing with the equal split, the extra $V_{TN}$ of the M8–M11 cascode mirror at the lower limit, $S_5$ from $V_{ic}(\min)$, consistent bias devices M12–M15). Sizing M6/M7 and M8–M11 for 100 µA instead of the worst-case 150 µA is acceptable. (With M6/M7 = 16 µm, M3/M4 = 24 µm and M15 = 4 µm, the fully steered M4–M7 branch pushes M4 slightly out of saturation: a level-1 ngspice check gives 144 µA instead of 150 µA with λ = 0, i.e. SR ≈ 9.4 V/µs, but ≈ 150 µA with λ_P = 0.05; this is within the accuracy of the hand model, so not checking it is not penalized, and noting it is a plus.) A lower cascode mirror with M9 narrower than M8, justified by splitting the actual $V_{DS}$ equally and verified by node voltages, is equally correct. For the reference design: $R_{out}$ 8.5–10 MΩ and $A_{vd}$ 5.3–6.5×10³. +1: valid design with one slip (e.g. the M8–M11 lower-limit sizing done without the extra $V_{TN}$, giving W/L ≈ 7.3 (sized for 100 µA) or ≈ 11 (sized for 150 µA) and $V_{out}(\min)$ not actually met but not claimed otherwise), or gain/R_out with a numerical slip. 0: design right but the gain obtained from a current-split formula, $(2+k)/(2+2k)\,g_{m1}R_{out}$ ≈ 3.2×10³ or $0.75g_{m1}R_{out}$ ≈ 4.4×10³ (these double-count the division of the M2 signal current, which is already in $R_{out}$). −2 (asserted as fact): a design claimed to meet a specification that it violates, $GB$ computed with the tail current instead of the 0.5I in M1, or $R_{out}$ taken as a single cascode branch or as $r_{ds}$.
