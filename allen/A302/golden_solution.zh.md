一种设计：I = 100 µA；$W_1 = W_2 = 36\ \mu$m；$W_3 = W_4 = 24\ \mu$m；$W_6 = W_7 = 24\ \mu$m；$W_8 = W_9 = W_{10} = W_{11} = 121\ \mu$m；$W_5 = W_{12} = W_{13} = 1.4\ \mu$m；$W_{14} = 16\ \mu$m；$W_{15} = 4\ \mu$m。由此 $R_{out} \approx 9.4$ MΩ，$A_{vd} \approx g_{m1}R_{out} \approx 5.9\times10^3$ V/V。

- 压摆率：若输入过驱动，输出能提供或吸收电流 I（例如 M2 吸收全部 I：M7 流过 0.5I，而 M11 镜像出 1.5I），因此 $I = SR\cdot C_L = 100\ \mu$A；M3、M4 流过 150 µA。
- $2\pi\,GB = g_{m1}/C_L$：$g_{m1} = 2\pi(10\ \mathrm{MHz})(10\ \mathrm{pF}) = 628\ \mu$S，电流为 50 µA → $S_1 = (628\,\mu)^2/(2\cdot110\,\mu\cdot50\,\mu) = 35.9$ → 36 µm。
- $V_{out}(\max) = +2$ V：M4 和 M7 上共 1 V，各 0.5 V。M4 电流 150 µA：$S_4 = 2(150)/(50\cdot0.25) = 24$（= $S_3$）。M7 最多可流过 150 µA，因此 $S_6 = S_7 = 24$（若按 100 µA 设计则为 16）。
- $V_{out}(\min) = -2$ V：M8–M11 共源共栅电流镜（M8 和 M10 为二极管连接）使 M9 的源极处于 $V_{SS} + V_{GS10}$，因此 $V_{out}(\min) = V_{SS} + V_{TN} + 2V_{ov}$ → $V_{ov} = 0.15$ V；在最坏情况 150 µA 下，M8–M11 的 $S = 2(150)/(110\cdot0.0225) = 121$。（这是把扣除额外 $V_{TN}$ 后剩余的电压余度平均分给两个过驱动电压。把实际的 1 V $V_{DS}$ 平均分配同样可行：例如 M8 = M10 = M11 = 121 µm、M9 ≈ 10.9 µm，使 M9 的栅极处于 −1.3 V、源极处于 −2.5 V，于是在 $v_{out} = -2$ V 时 M9 和 M11 各有 0.5 V，且保持饱和。）
- $V_{ic}(\min) = -1$ V：$V_{SS} + V_{DS5}(\mathrm{sat}) + V_{GS1}$，其中 $V_{GS1} = 0.7 + \sqrt{2\cdot50/(110\cdot36)} = 0.859$ V → $V_{DS5}(\mathrm{sat}) = 1.14$ V → $S_5 = 2(100)/(110\cdot1.14^2) = 1.4$；M12、M13 相同（电流同为 I）。
- $V_{ic}(\max)$：M1 的漏极（折叠节点）处于 $V_{G6} + V_{SG6} = 1.3 + 0.7 + 0.41 = 2.41$ V，因此 $V_{ic}(\max) \approx 2.41 + 0.7 = 3.1$ V ≥ 2 V ✓（仅考虑 M3 饱和则可达 3.2 V）。
- 偏置：M14（二极管连接，电流 I）镜像到 M3、M4（1.5I）→ $S_{14} = 24/1.5 = 16$。M15（二极管连接，电流 I）设定 M6/M7 的栅极电压：$V_{SG15} = V_{SD4}(\mathrm{sat}) + V_{SG7} = 0.5 + 0.7 + 0.5 = 1.7$ V → 100 µA 下过驱动电压为 1.0 V → $S_{15} = 2(100)/(50\cdot1.0) = 4$。
- 小信号（静态）：$g_{m9} = \sqrt{2(110\,\mu)(121)(100\,\mu)} = 1.63$ mS，$r_{ds9} = r_{ds11} = 250$ kΩ → $R_9 = g_{m9}r_{ds9}r_{ds11} = 102$ MΩ；$g_{m7} = 490\ \mu$S，$r_{ds7} = 200$ kΩ，$r_{ds2}\|r_{ds4} = 500\,\mathrm{k}\|133\,\mathrm{k} = 105$ kΩ → 上方 $g_{m7}r_{ds7}(r_{ds2}\|r_{ds4}) = 10.3$ MΩ；$R_{out} = 102\,\|\,10.3 \approx 9.4$ MΩ。
- 增益：输出短路时，M1 的电流经 M6 和 M8–M11 电流镜到达输出端，M2 的电流经 M7 到达输出端（此时 M7 源极电阻 ≈ $1/g_{m7}$，远小于 $r_{ds2}\|r_{ds4}$），因此短路跨导（short-circuit transconductance）为 $g_{m1}$，$A_{vd} = g_{m1}R_{out} \approx 629\,\mu\times9.4\,\mathrm{M} \approx 5.9\times10^3$（对该电路做完整的小信号节点求解也得到 5.9×10³）。输出与 $v_{id} = v_1 - v_2$ 同相。
