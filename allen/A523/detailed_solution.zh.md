# 详细步骤 - A523

每个比较器把其抽头（+ 输入端）与公共输入（− 输入端）比较，因此只有当抽头电压高于 $V^*_{in}$ 时其输出才为高。把七个抽头逐一与 $0.6V_{REF}$ 比较。

### 第 1 步 — 比较器规则

电阻串中的电阻相等，使各抽头位于 $V_{tap,k}=\tfrac{2k-1}{16}V_{REF}$，$k=1,\dots,7$，即 $0.125,0.250,\dots,0.875\,V_{REF}$。抽头接 + 输入端、$V^*_{in}$ 接 − 输入端时，

$$
\text{output}=1\iff V_{tap}>V^*_{in}=0.6\,V_{REF}.
$$

### 第 2 步 — 逐一比较各抽头

| 比较器（从上到下） | 抽头（$V_{REF}$） | 抽头 $>0.6V_{REF}$？ | 输出 |
|---|---|---|---|
| 1 | 0.875 | 是 | 1 |
| 2 | 0.750 | 是 | 1 |
| 3 | 0.625 | 是 | 1 |
| 4 | 0.500 | 否 | 0 |
| 5 | 0.375 | 否 | 0 |
| 6 | 0.250 | 否 | 0 |
| 7 | 0.125 | 否 | 0 |

最接近的抽头为 $0.625V_{REF}$，只比输入高 $0.025V_{REF}$，因此该比较器仍输出 1。

### 第 3 步 — 结果

从上方比较器到下方比较器依次列出，输出为

$$
1\ 1\ 1\ 0\ 0\ 0\ 0 ,
$$

即一个温度计码。输入超过四个抽头，因此编码器给出码 4，即输出字 100。
