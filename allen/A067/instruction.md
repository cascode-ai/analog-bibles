A simple model for hand calculations describes the drain current of an MOS transistor in weak inversion as
$$i_D \approx \frac{W}{L}I_{D0}\exp\!\left(\frac{v_{GS}}{n(kT/q)}\right)$$
where n is the subthreshold slope factor (1 < n < 3) and $I_{D0}$ is a process-dependent parameter. Develop an expression for the small-signal transconductance of an MOS device operating in weak inversion using this large-signal expression.
