它基本上消除了扩散电阻的电压依赖性：n 阱被自举（bootstrapping）到电阻上，因此 p⁺/n 阱结的反向偏置处处 ≈ 0，不再随信号变化，$v_{out}$ 成为 $v_{in}$ 的线性函数。代价是并联了 n 阱电阻（使总电阻减小，并引入 n 阱自身的部分非线性），以及增加了对衬底的寄生电容（parasitic capacitance）。

- 电压系数的成因：扩散电阻的导电截面被它与周围区域所形成的结的耗尽层（depletion layer）所减小。当 n 阱接 5 V 时，该结的反向偏置为 $5\ \mathrm{V} - v(x)$（沿 $R_1$ 约为 2.5–3.75 V），它随 $v_{in}$ 和 $v_{out}$ 变化，因此耗尽层宽度和 $R_1$ 都随信号变化。
- 采用图示连接后，n 阱两端的电位与电阻两端的电位相等；又因为 p⁺ 条和 n 阱都是连接在同样两个节点之间的均匀电阻通路，它们的电位沿长度方向以相同方式线性下降。整个电阻上的结偏置 ≈ 0，与信号无关，因此耗尽层宽度（以及 $R_1$）保持不变：耗尽层调制引起的电压系数在一阶近似下被抵消。
- 于是 $v_{out} = v_{in}R_2/[(R_1\|R_{n\text{-well}}) + R_2]$，与 $v_{in}$ 成线性关系；由于 $R_1\|R_{n\text{-well}} < 10$ kΩ，除非重新调整 $R_1$ 的尺寸，$v_{out}$ 会略高于 1.25 V。
- 二阶效应：n 阱电阻本身有很大的电压系数，由它与接地 p⁻ 衬底之间的结（其偏置为信号电压）决定，而它现在分担了一部分电流。它的方块电阻（~1 kΩ/□）远高于 p⁺ 扩散区的方块电阻（~100 Ω/□），因此它分担的电流以及残余非线性都很小。n 阱到衬底的电容现在成为信号通路的负载；p⁺/n 阱结电容在零偏时最大（但无害，因为两侧电位几乎相同）；该结始终接近零偏，因此不会导通。
