$R_1 = 2V_t\ln 10/I = 0.1197\ \mathrm{V}/I$，$R_2/R_1 = (1.262\ \mathrm{V} - V_{EB3})/(2V_t\ln10)$：当 $V_{EB3}$ = 0.6 V 时，$R_2/R_1$ = 5.53；取 $I$ = 10 µA，则 $R_1$ = 12.0 kΩ，$R_2$ = 66.2 kΩ。叠接使 $R_1$ 上的 PTAT 电压加倍，从而使所需增益 $R_2/R_1$ 减半，放大器失调（offset）及噪声对 $V_{REF}$ 的影响也随之减半；等价地，用 10:1 的器件就得到了面积比为 100:1 的单对晶体管的 PTAT 电压（$2V_t\ln10 = V_t\ln100$），节省了面积。

- 理想放大器使其两输入相等：$V_{EB2a} + V_{EB2b} = V_{EB1a} + V_{EB1b} + I_1R_1$。所有电流相等（M1–M5 相同），且 Q1a、Q1b 的面积为 10 倍，因此 $V_{R1} = 2V_t\ln 10 = 0.1197$ V（PTAT），$I = V_{R1}/R_1$。（要使 $V_{R1} > 0$，Q1a、Q1b 必须是较大的器件。）
- M5 将 $I$ 复制到 $R_2$ 和 Q3 中：$V_{REF} = V_{EB3} + (R_2/R_1)\,2V_t\ln10$。
- 在 $T_0$ 处温度系数为零：$dV_{PTAT}/dT = V_{PTAT}/T_0$，$dV_{EB3}/dT = [V_{EB3} - V_{G0} - (\gamma - \alpha)V_{t0}]/T_0$，因此 $(R_2/R_1)\,2V_{t0}\ln10 = V_{G0} + (\gamma - \alpha)V_{t0} - V_{EB3}$，进而 $V_{REF} = V_{G0} + (\gamma - \alpha)V_{t0} = 1.205 + 2.2\times0.026 = 1.262$ V，与 $V_{EB3}$ 无关。
- 数值：$R_2/R_1 = (1.262 - 0.6)/0.1197 = 5.53$；取 $I$ = 10 µA 得 $R_1$ = 11.97 kΩ，$R_2$ = 66.2 kΩ。
- 叠接：放大器失调 $V_{OS}$ 直接叠加在 $V_{R1}$ 上，并在输出端乘以 $R_2/R_1$。每侧有两个结时，$V_{R1}$ 加倍，$R_2/R_1$ 减半（≈ 5.5 而不是 ≈ 11），因此由 $V_{OS}$ 和放大器噪声引起的输出误差减半。代价是需要更大的电压余度（headroom），即 $2V_{EB} + V_{R1}$ ≈ 1.4 V。
