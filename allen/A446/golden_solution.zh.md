令 $C_i = 2^{N-1-i}C$，$D = \sum_{i=0}^{N-1} b_i C_i/(2^N C) = \sum_{i=0}^{N-1} b_i 2^{-(i+1)}$：

- $b_0 = 1$：$v_{OUT} = -\dfrac{\sum b_i C_i}{2^N C}V_{REF} = -\left(\dfrac{1}{2} + \sum_{i=1}^{N-1}\dfrac{b_i}{2^{i+1}}\right)V_{REF}$。
- $b_0 = 0$：$v_{OUT} = +\dfrac{\sum_{i\ge1} b_i C_i}{2^N C}V_{REF} = +\sum_{i=1}^{N-1}\dfrac{b_i}{2^{i+1}}V_{REF}$。
- 简写为 $v_{OUT} = (1 - 2b_0)\,D\,V_{REF}$：$b_0$ 决定极性（为 1 时其电容还贡献 1/2 这一项）。

工作过程：φ1 期间运放接成跟随器（反相输入端与输出端相连），$2^NC$ 反馈电容的右极板接地；值为 1 的位所对应电容的下极板接在公共线上，若 $b_0 = 1$ 该线为地电位，若 $b_0 = 0$ 则为 $V_{REF}$（值为 0 的位保持接地）。φ2 期间公共线切换到 $V_{REF}$（$b_0 = 1$）或地（$b_0 = 0$），电荷 $\pm V_{REF}\sum b_iC_i$ 转移到 $2^NC$ 上。

失调 $V_{OS}$：表达式不变。φ1 期间跟随器把求和节点保持在 $V_{OS}$，φ2 期间虚地（virtual ground）同样处于 $V_{OS}$；对该节点应用电荷守恒，$\sum C_i(V_{OS} - V_{b,i}^{\phi1}) + 2^NC\,V_{OS} = \sum C_i(V_{OS} - V_{b,i}^{\phi2}) + 2^NC(V_{OS} - v_{OUT})$，得到 $v_{OUT} = -\sum C_i(V_{b,i}^{\phi2} - V_{b,i}^{\phi1})/2^NC$，$V_{OS}$ 被消去。该电路对失调进行了自动调零（auto-zero），因此在一阶近似下失调既不引起失调误差也不引起增益误差（只剩下由有限增益和开关电荷注入引起的二阶残余误差）。
