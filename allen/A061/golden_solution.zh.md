一种设计：保持 M1 = 2 µm/0.8 µm（$R_{on}$ ≈ 1.84 kΩ），并使 M2 为方形栅，W = L ≈ 592 µm（C ≈ 865 pF）。

- 该电路是 RC 低通：M1（无直流电流，$V_{DS}$ = 0）是工作在非饱和区的电阻，M2（已反型，$V_{GS}$ = 2 V）是栅电容，因此 $f_{-3dB} = 1/(2\pi R_{on}C)$ = 100 kHz 要求 $R_{on}C$ = 1.59 µs。
- M1：$V_{T1} = 0.7 + 0.4(\sqrt{2.7} - \sqrt{0.7})$ = 1.023 V（体效应，$V_{SB}$ = 2 V）；W/L = 2.5 时 $R_{on} = 1/[K'(W/L)_1(3 - 1.023)]$ = 1.84 kΩ。
- M2：$C \approx C_{ox}W_2L_2$ = 1.59 µs/1.84 kΩ = 865 pF → $W_2L_2$ = 865 pF/(24.7×10⁻⁴ F/m²) = 3.50×10⁵ µm² → W₂ = L₂ ≈ 592 µm（交叠电容项对此结果的影响 < 0.1%）。
- 验证：$1/(2\pi\times1.84\ \mathrm{k\Omega}\times865\ \mathrm{pF})$ = 100 kHz。
- 其他有效设计可在 R 与 C 之间折中，例如 M1 = 2 µm/80 µm（$R_{on}$ = 184 kΩ），M2 ≈ 59 µm × 59 µm（8.65 pF）；只有把 M1 做得又长又窄，才能减小 M2 的面积。
