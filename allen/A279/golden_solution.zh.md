$A_v = \dfrac{v_{out}}{v_{id}} = \dfrac{g_{m1}g_{m6}}{(g_{ds2} + g_{ds4})(g_{ds6} + g_{ds7})} = \dfrac{2g_{m1}}{I_5(\lambda_2 + \lambda_4)}\cdot\dfrac{g_{m6}}{I_6(\lambda_6 + \lambda_7)}$（其中 $v_{id}$ 为 + 输入减去 − 输入，即 M2 与 M1 的栅极）。

- 第一级：差模输入 $v_{id}$ 在 M1 和 M2 中产生 $\pm g_{m1}v_{id}/2$；M1 的电流经 M3–M4 镜像后在 M2/M4 漏极处与 M2 的电流相加，因此流入第一级输出节点的电流为 $g_{m1}v_{id}$（$g_{m1} = g_{m2}$）。
- 该节点的电阻：$r_{ds2}\|r_{ds4}$ → $v_1 = g_{m1}v_{id}/(g_{ds2} + g_{ds4})$（相对于 + 输入为反相）。
- 第二级：M6 将 $v_1$ 转换为流入 $r_{ds6}\|r_{ds7}$ 的电流 $g_{m6}v_1$ → $v_{out} = -g_{m6}v_1/(g_{ds6} + g_{ds7})$；两次反相使从 + 输入算起的增益为正。
