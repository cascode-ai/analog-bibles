电路 1：$v_o(\max) = V_{DD}/2$，因为在 $v_{in} = V_{DD}$ 时，跟随管 M1 与其相同的二极管连接负载 M2 流过相同电流，栅源电压（以及漏源电压）相等。无论是否考虑沟道长度调制，这一结论都成立。

其他电路（采用平方律，大信号计算中忽略 λ，这是通常的理解；λ 只影响原书该题的小信号部分）：
- C3 ≈ $0.59V_{DD} - 0.17V_T$（n 沟道跟随管对抗接地的 p 沟道二极管连接管；只要 $V_{DD} > 2V_T$ 就高于 $V_{DD}/2$）。
- C5 = $V_{DD}-V_T-V_{ov,N}$，其中 $V_{ov,N} = \sqrt{2I/\beta_N}$（跟随管流过 $I$），它高于 $V_{DD}/2$：公共电流 $I$ 必须在每个电路中两个器件都饱和的条件下可以达到，最紧的约束来自电路 2（p 沟道跟随管上的 p 沟道二极管连接管，在 $v_{in} = 0$、$v_o = V_{DD}/2$ 时电流最大）：$V_{ov,P} = \sqrt2\,V_{ov,N} \le V_{DD}/2 - V_T$。因此 $V_{BN} = V_T + V_{ov,N} < V_{DD}/2$，且 C5 ≥ $V_{DD} - V_T - (V_{DD}/2 - V_T)/\sqrt2 > V_{DD}/2$。（仅由电路 1 自身的约束 $V_{ov,N} \le V_{DD}/2 - V_T$ 就已得到 C5 ≥ $V_{DD}/2$。）
- C2 = C4 = $V_{DD}-V_T$（跟随管截止时负载电流趋于零）；对于任意 $V_{BP}$，C6 = $V_{DD}$（跟随管截止，p 沟道电流源将输出上拉到 $V_{DD}$）。
因此只有电路 1 的 $v_o(\max)$ 最低。

考虑有限 λ 时：在 $v_{in} = V_{DD}$、$v_o = V_{DD}/2$ 处，C5 的两个 n 沟道器件 $V_{DS}$ 相等，因此只有当 $V_{BN} > V_{DD}/2$ 时才有 C5 < $V_{DD}/2$。将此与电路 2 的电流约束（计入 λ，且 $\lambda_P = 2\lambda_N$）结合可知，这要求 $\lambda_N \ge 1/(2V_T)$（例如 $V_T$ = 0.7 V 时 ≥ 0.7 V⁻¹），远超出任何强反型器件的范围；对于实际的 λ，电路 1 仍是唯一答案。（Level-1 验证：$V_{DD}$ = 3 V，$V_T$ = 0.7 V，$\lambda_N$ = 0.05 V⁻¹，$V_{BN}$ 取最大公共电流对应值：C1 1.50 V，C3 1.62 V，C5 1.69 V，C4 2.30 V，C2 和 C6 达到电源轨。）
