$V_{BIAS} = \dfrac{V_{T1} + |V_{T2}|}{2}$，两个阈值均在交越点输出电压 $v_{OUT}$ = 0 处计算：
$V_{T1} = 0.7 + 0.4\left(\sqrt{0.7+|V_{SS}|}-\sqrt{0.7}\right)$ V，$|V_{T2}| = 0.7 + 0.57\left(\sqrt{0.8+V_{DD}}-\sqrt{0.8}\right)$ V。

- 在交越点两个器件都不导通，因此没有负载电流，$v_{OUT}$ = 0。
- 当 $v_{IN}+V_{BIAS} - 0 = V_{T1}$，即 $v_{IN} = V_{T1} - V_{BIAS}$ 时，M1 开始导通。
- 当 $0 - (v_{IN}-V_{BIAS}) = |V_{T2}|$，即 $v_{IN} = V_{BIAS} - |V_{T2}|$ 时，M2 停止导通。
- 令两个转折点相等：$V_{T1} - V_{BIAS} = V_{BIAS} - |V_{T2}|$ → $V_{BIAS} = (V_{T1}+|V_{T2}|)/2$；此时交越发生在 $v_{IN} = (V_{T1}-|V_{T2}|)/2$ 处（当计入体效应的两个阈值不同时，并不恰好在 0）。
- 算例：±2.5 V 电源：$V_{T1}$ = 1.08 V，$|V_{T2}|$ = 1.23 V → $V_{BIAS}$ ≈ 1.15 V；±5 V：1.32 V 和 1.56 V → 1.44 V。忽略体效应时 $V_{BIAS} = V_T$ = 0.7 V。（若使用两个独立电池，则取 $V_{BIAS1} = V_{T1}$，$V_{BIAS2} = |V_{T2}|$。）
