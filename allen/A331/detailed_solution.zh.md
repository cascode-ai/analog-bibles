# 详细步骤 - A331

输出可以一直摆动，直到它与电源轨之间的晶体管漏源电压不够为止。输出与电源轨之间堆叠的每个饱和晶体管至少需要 $V_{DS}(\mathrm{sat})=V_{ON}$，所以某一侧堆叠 $n$ 个器件时，输出能到达距该电源轨 $nV_{ON}$ 处。下面数出每个输出两侧的器件数。

### 第 1 步 — 两级密勒运放 [图 1] 与 [图 2]

[图 1] 中每个输出到 $V_{DD}$ 有一个 p 沟道器件（$v_{o1}$ 处为 M7，$v_{o2}$ 处为 M6），到 $V_{SS}$ 有一个 n 沟道电流源（M9、M8）。保持它们饱和，

$$
V_o(\max)=V_{DD}-V_{SD7}(\mathrm{sat})=V_{DD}-V_{ON},\qquad
V_o(\min)=V_{SS}+V_{DS9}(\mathrm{sat})=V_{SS}+V_{ON}.
$$

其中不出现阈值，因为栅极由前一级驱动，而不是接在输出上。[图 2] 的推挽输出级从每个输出到每个电源轨也只有一个晶体管（M7/M9 与 M14/M8），极限相同。这是五种电路中最宽的输出范围。

### 第 2 步 — 折叠式共源共栅运放 [图 3]

每个输出位于共源共栅堆叠之中：上方为 M4 和 M6（M5 和 M7），下方为 M8 和 M10（M9 和 M11）。每对器件都处于饱和边缘时，

$$
V_o(\max)=V_{DD}-V_{SD4}(\mathrm{sat})-V_{SD6}(\mathrm{sat})=V_{DD}-2V_{ON},\qquad
V_o(\min)=V_{SS}+2V_{ON}.
$$

### 第 3 步 — B 类折叠式共源共栅推挽运放 [图 4]

每个输出上方是折叠电流源及其共源共栅管（M6–M8 与 M7–M9）；下方是共源共栅电流镜 M19–M21 与 M11–M13，其输出侧同样是两个堆叠器件。因此同样有

$$
V_o(\max)=V_{DD}-2V_{ON},\qquad V_o(\min)=V_{SS}+2V_{ON}.
$$

### 第 4 步 — 带共源共栅输出的 AB 类运放 [图 5]

每个输出上方由共源共栅电流源（M9–M13 与 M10–M14）驱动，下方由共源共栅电流源（M11–M15 与 M12–M16）驱动，所以

$$
V_o(\max)=V_{DD}-2V_{ON},\qquad V_o(\min)=V_{SS}+2V_{ON}.
$$

### 第 5 步 — 比较

| 运放 | $V_o(\max)$ | $V_o(\min)$ |
|---|---|---|
| [图 1] | $V_{DD} - V_{ON}$ | $V_{SS} + V_{ON}$ |
| [图 2] | $V_{DD} - V_{ON}$ | $V_{SS} + V_{ON}$ |
| [图 3] | $V_{DD} - 2V_{ON}$ | $V_{SS} + 2V_{ON}$ |
| [图 4] | $V_{DD} - 2V_{ON}$ | $V_{SS} + 2V_{ON}$ |
| [图 5] | $V_{DD} - 2V_{ON}$ | $V_{SS} + 2V_{ON}$ |

两级设计可摆到距每个电源轨一个 $V_{ON}$ 处，共源共栅设计则为两个；各自的差分输出摆幅是单端范围的两倍。共源共栅以每端损失一个 $V_{ON}$ 的摆幅换取更高的输出电阻。
