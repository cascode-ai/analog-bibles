保持 $R_2/R_1$ = 9.39（$V_{REF}$ = 1.262 V，与温度无关）：$R_4/R_1 = 4.74$，$I_{REF} = 0.386\ \mathrm{V}/R_1$。因此 $R_1 = 0.386\ \mathrm{V}/I_{REF}$，$R_2 = R_3 = 3.62\ \mathrm{V}/I_{REF}$，$R_4 = 1.83\ \mathrm{V}/I_{REF}$；例如 $I_{REF}$ = 100 µA 时：$R_1$ = 3.86 kΩ，$R_2 = R_3$ = 36.2 kΩ，$R_4$ = 18.3 kΩ。

- 运放使 $R_2$ 和 $R_3$ 下端的电压相等；由于 $R_2 = R_3$，$I_1 = I_2 = V_{R1}/R_1$，且 $V_{R1} = V_{EB2} - V_{EB1} = V_t\ln10$ = 0.0599 V（PTAT）。$V_{REF} = V_{EB2} + (R_2/R_1)V_t\ln10$。
- M1 为全部三条支路供电：$I_{REF} = I_1 + I_2 + V_{REF}/R_4 = 2V_t\ln10/R_1 + V_{REF}/R_4$。
- 取 $R_2/R_1$ = 9.39 时，$V_{REF} = 0.7 + 9.39\times0.0599 = 1.262$ V，且 $dV_{REF}/dT = 0$。PTAT 部分以 $2V_t\ln10/(R_1T_0)$ 的速率上升；$R_4$ 部分以 $(V_{REF}/R_4)\,TC_{R4}$ 的速率下降。零温度系数：$\dfrac{2V_t\ln10}{R_1T_0} = \dfrac{V_{REF}\,TC_{R4}}{R_4}$，故 $\dfrac{R_4}{R_1} = \dfrac{V_{REF}\,TC_{R4}\,T_0}{2V_t\ln10} = \dfrac{1.262\times0.0015\times300}{0.1197} = 4.74$。
- 于是 $I_{REF} = (0.1197 + 1.262/4.74)/R_1 = 0.386\ \mathrm{V}/R_1$。在此模型中，$I_{REF}$ 在 0 °C 时仅变化 +0.1%，在 70 °C 时仅变化 +0.24%（二阶曲率）。
- 其他组合也可行：一般地，$2V_t\ln10\,(R_4/R_1) = V_{G0} + (\gamma - \alpha)V_{t0} - V_{REF}(1 - TC_{R4}T_0)$，其中 $V_{REF} = V_{EB2} + (R_2/R_1)V_t\ln10$（要求 $R_2/R_1$ < 26.6）。
