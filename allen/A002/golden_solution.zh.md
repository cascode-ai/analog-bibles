输出是零阶保持（zero-order hold）形成的阶梯波：在每个采样时刻 $t = nT$，输出跳变到该时刻正弦波的值，并以未量化的形式一直保持到下一个采样时刻 $(n+1)T$。各保持值（幅度单位，由曲线读出，±0.1）：

- $0 \le t/T < 1$：8.0
- $1 \le t/T < 2$：11.5
- $2 \le t/T < 3$：13.9
- $3 \le t/T < 4$：14.4
- $4 \le t/T < 5$：12.9
- $5 \le t/T < 6$：9.8
- $6 \le t/T < 7$：6.2
- $7 \le t/T < 8$：3.1
- $8 \le t/T < 9$：1.6
- $9 \le t/T < 10$：2.1
- $10 \le t/T < 11$：4.5
- $t/T = 11$：8.0（此后一直保持）

该曲线为 $x(t) \approx 8 + 6.5\sin(2\pi t/11T)$：直流电平 8，在 $t \approx 2.75T$ 处达到峰值 14.5，在 $t \approx 8.25T$ 处达到最小值 1.5，周期为 $11T$，因此各采样值为 $8 + 6.5\sin(2\pi n/11)$。阶梯波跟随正弦波变化，平均延迟约半个采样周期（$T/2$）；其最高台阶（14.4）和最低台阶（1.6）都略未达到真实的极值，因为极值出现在两个采样时刻之间。输出只在采样时刻变化，其间保持不变；幅度仍是模拟量（未量化）。
