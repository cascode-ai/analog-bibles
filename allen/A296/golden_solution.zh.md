在此偏置下，−3.5 V 的下限无法满足：无论 $W_1/L_1$ 取何值，都有 $V_{ic}(\min) > -2.97$ V。上限要求 $W_3/L_3 = W_4/L_4 \ge 3.64/(1.3 - 1.91/\sqrt{S_5})^2$（例如若 $S_5 = S_3$，则 ≥ 8.6）。

- 尾电流：$I_7 = I_{Bias}(S_7/S_{12}) = 80\ \mu\mathrm{A}\times3/6 = 40\ \mu$A；每个输入器件 20 µA。
- 下限：$V_{ic}(\min) = V_{SS} + V_{DS7}(\mathrm{sat}) + V_{T1}(\max) + \sqrt{I_7/(K'_NS_1)}$，其中 $V_{DS7}(\mathrm{sat}) = \sqrt{2\cdot40/(25\cdot3)} = 1.03$ V。所以 $V_{ic}(\min) = -5 + 1.03 + 1.0 + \sqrt{1.6/S_1} = -2.97\ \mathrm{V} + \sqrt{1.6/S_1}$ V，对任何 $S_1$ 都高于 −3.5 V（即使取 $V_T = 0.8$ V，下限也只能到 −3.17 V）。$W_1/L_1 = W_2/L_2$ 无法满足该指标；必须重新设计尾电流管（例如要求 $V_{DS7}(\mathrm{sat}) \le 0.4$ V，则在 40 µA 下需要 $S_7 \ge 20$，此后取 $S_1 \approx 160$ 即可得到 −3.5 V）。
- 上限：$V_{ic}(\max) = V_{DD} - |V_T|(\max) - \sqrt{I_7/(K'_PS_5)} - \sqrt{I_7/(K'_PS_3)} + V_T(\min) \ge 3.5$ V → $\sqrt{3.64/S_5} + \sqrt{3.64/S_3} \le 1.3$ V（要求 $S_5 > 2.15$）→ $S_3 = S_4 \ge 3.64/(1.3 - \sqrt{3.64/S_5})^2$；若 $S_5 = S_3$，则得 $S_3 = S_5 \ge 8.6$。这里按题意假设 M3 和 M4 作为饱和的共源共栅管工作，其栅极偏置不限制共模范围。若按图中所画把它们的栅极接到 M11/M12 节点，$V_{SS} + V_{GS12}$ ≈ −3 V，则 M3 饱和要求其漏极低于 ≈ −2 V，因此 $V_{ic}(\max)$ ≈ $V_{G3} + |V_{TP}| + V_{TN}$ ≈ −1 V，上限同样无法满足。
