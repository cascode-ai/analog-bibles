# 详细步骤 - A265

把每个器件换成互补类型，得到 p 输入版本，使第一级输出仍处在驱动第二级所需的直流电平上。然后在电流和宽长比都相同的条件下，通过各项性能对 $K'$（经 $g_m=\sqrt{2K'SI}$）、$\lambda$ 和直流压降的依赖关系进行比较。关键比值为

$$
r=\sqrt{\frac{K'_N}{K'_P}}=\sqrt{\frac{110}{50}}=1.48 .
$$

### 第 1 步 — p 输入运放的电路图

把每个器件都换成互补类型：p 沟道输入对 M1–M2，p 沟道尾电流源 M5 接 $V_{DD}$；n 沟道电流镜负载 M3–M4 接 $V_{SS}$；n 沟道共源输出管 M6，源极接 $V_{SS}$，栅极接第一级输出（M2 与 M4 的漏极）；p 沟道电流源负载 M7 与 M5 共用偏置；$C_c$ 接在 M6 栅极与输出之间。

<!-- diagram: diagram-01.cir -->

输出级也必须互补。n 沟道电流镜把第一级输出保持在 $V_{SS}+V_{GS3}$ 附近，这正适合驱动源极接 $V_{SS}$ 的 n 沟道 M6（取 $V_{GS6}=V_{GS4}$ 可消除系统失调）。若保留原来的 p 沟道 M6，则该节点须位于 $V_{DD}-V_{SG6}$ 附近，只有在 M3–M4 严重失衡、M2 被推向线性区时才能达到；不加电平移位，这不是可用的设计。

### 第 2 步 — 小信号速度：GB、输出极点、零点与电流镜极点

- **GB** $=g_{m1}/C_c$。电流和尺寸相同时 n 沟道输入对的 $g_m$ 更大，所以 **n 输入版本好 $r\approx1.48$ 倍**。
- **输出极点** $g_{m6}/C_L$ 和**右半平面零点** $g_{m6}/C_c$。p 输入版本中 M6 为 n 沟道，二者都**高 $1.48$ 倍**。相对于各自的 GB，p 输入版本的次极点和零点高 $r^2\approx2.2$ 倍，所以 **p 输入版本的相位裕度明显更好**。
- **电流镜极点** $g_{m3}/C_3$。p 输入版本的电流镜是 n 沟道的，节点电容相同时**高 $1.48$ 倍**。

### 第 3 步 — 增益与压摆率

总增益为

$$
A_v=\frac{g_{m1}}{g_{ds2}+g_{ds4}}\cdot\frac{g_{m6}}{g_{ds6}+g_{ds7}},\qquad
g_{ds2}+g_{ds4}=(\lambda_N+\lambda_P)\frac{I_5}{2},\quad g_{ds6}+g_{ds7}=(\lambda_N+\lambda_P)I_6 .
$$

每一级都有一只 n 沟道和一只 p 沟道器件，所以两种版本的 $g_{ds}$ 之和相同。交换器件类型只是把因子 $r$ 从第一级的 $g_{m1}$ 移到第二级的 $g_{m6}$，乘积 $g_{m1}g_{m6}$ 不变，因此**直流增益基本相同**。压摆率 $I_5/C_c$ 也**相同**。

### 第 4 步 — 输入共模范围

| | $V_{in}(\max)$ | $V_{in}(\min)$ |
|---|---|---|
| n 输入 | $V_{DD}-V_{SG3}+V_{TN}$（接近 $V_{DD}$） | $V_{SS}+V_{DS5}(\mathrm{sat})+V_{GS1}$（远高于 $V_{SS}$） |
| p 输入 | $V_{DD}-V_{SD5}(\mathrm{sat})-V_{SG1}$（远低于 $V_{DD}$） | $V_{SS}+V_{GS3}-\lvert V_{TP}\rvert$（接近 $V_{SS}$） |

n 输入的范围延伸到正电源，p 输入的范围延伸到负电源；各自在另一端差约一个阈值电压加一个饱和电压。

### 第 5 步 — 输出电流驱动能力

n 输入版本中 p 沟道 M6 能输出大电流，但吸收电流受限于 M7 的偏置电流，所以输出级的压摆限制出现在下降沿。p 输入版本中 n 沟道 M6 能吸收大电流，输出电流受限于 M7 的偏置，限制出现在上升沿。

### 第 6 步 — 噪声、体效应与 PSRR

- **热噪声。** 输入参考噪声功率按 $(1/g_{m1})(1+g_{m3}/g_{m1})$ 变化。n 输入版本的 $g_{m1}$ 更大、$g_{m3}$ 更小（p 沟道电流镜），所以**热噪声更低**。以 n 输入版本的 $x=g_{m3}/g_{m1}$ 表示，功率比为 $r(1+r^2x)/(1+x)$，介于 1.48 与 3.3 之间；$(W/L)_3=(W/L)_1$ 时约为 2.2。仅考虑输入对时，功率比为 1.48，噪声电压比为 1.22。
- **1/f 噪声。** p 沟道器件的闪烁噪声系数通常小得多，所以 p 输入版本在低频通常更好。但电流镜的 1/f 噪声以权重 $(g_{m3}/g_{m1})^2$ 折算到输入端，在 p 输入版本中约增大 2.2 倍，因此在没有闪烁噪声数据时，净结果取决于 p 沟道的优势能否抵过这一点。
- **体效应（n 阱工艺）。** p 沟道输入对可以放在独立的阱中，衬底接公共源极，消除体效应（ICMR 和 CMRR 略好）。n 沟道输入对的衬底接 $V_{SS}$。
- **高频 PSRR。** 输出驱动管源极所接的电源（n 输入版本为 $V_{DD}$，p 输入版本为 $V_{SS}$）在高频经 $C_c$ 耦合到输出，所以两种版本高频 PSRR 较差的电源相反。

### 第 7 步 — 汇总

| 特性 | 较好的版本 | 相差 |
|---|---|---|
| GB | n 输入 | ×1.48 |
| 输出极点、右半平面零点、电流镜极点 | p 输入 | ×1.48 |
| 相位裕度（相对 GB 的根位置） | p 输入 | ×2.2 |
| 直流增益、压摆率 $I_5/C_c$ | 相同 | — |
| ICMR | n 输入偏向 $V_{DD}$，p 输入偏向 $V_{SS}$ | 较弱一端约差 $V_T+V_{sat}$ |
| 大输出电流 | n 输入擅长输出，p 输入擅长吸收 | — |
| 热噪声 | n 输入 | 功率 ×1.48–3.3 |
| 1/f 噪声 | 通常 p 输入 | 取决于工艺 |
