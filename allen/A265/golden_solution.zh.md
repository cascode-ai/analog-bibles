电路图：给定电路的互补形式——p 沟道输入对管 M1–M2 及接到 $V_{DD}$ 的 p 沟道尾电流源 M5，接到 $V_{SS}$ 的 n 沟道电流镜负载 M3–M4，n 沟道共源输出管 M6（源极接 $V_{SS}$）及其 p 沟道电流源负载 M7，$C_c$ 接在 M6 栅极与输出端之间。输出级也必须互补：n 沟道电流镜使第一级输出约为 $V_{SS} + V_{GS3}$，因此它必须驱动源极接 $V_{SS}$ 的 n 沟道 M6（为使系统失调为零，$V_{GS6} = V_{GS4}$）；若保留原电路的 p 沟道 M6，则要求第一级输出位于 $V_{DD} - V_{SG6}$，远离位于 $V_{SS} + V_{GS3}$ 的镜像节点。环路可以把高阻节点驱动到该电压，但代价是 M3–M4 中出现很大的系统性失衡，且 M2 被推向线性区，因此 ICMR 缩小到靠近 $V_{DD}$ 的一个窄窗口，失去了采用 p 输入器件所追求的低共模范围（level-1 验证，±2.5 V，采用 Allen 例题的尺寸：保留 M6 的跟随器只在 $V_{cm} \approx 1.0$–$1.6$ V 内能跟踪；在 $V_{cm} = 0$ 时其输出停在 0.61 V，M2 处于线性区）。不加电平移位，它不是一个可用的设计；以下比较针对互补后的电路。

差别（电流和 W/L 相同；比值 $\sqrt{K'_N/K'_P} = \sqrt{110/50} = 1.48$）：
- GB $= g_{m1}/C_c$：n 输入更好，$g_{m1}$ 和 GB 大约 1.48 倍。
- 输出极点 $g_{m6}/C_L$ 和右半平面零点 $g_{m6}/C_c$：p 输入更好（n 沟道 M6），两者都高约 1.48 倍；再加上其 GB 较低，p 输入版本的相位裕度明显更好（次极点和零点相对于 GB 高约 1.48² ≈ 2.2 倍）。
- 镜像极点 $g_{m3}/C_3$：在节点电容 $C_3$ 相同时，p 输入版本（n 沟道电流镜）高约 1.48 倍。
- 直流增益：基本相同——n 输入版本的第一级增益较大，p 输入版本的第二级增益较大，且大出的倍数相同；两级中都出现 $\lambda_N + \lambda_P$，因此乘积 $g_{m1}g_{m6}$ 不变。
- 压摆率 $I_5/C_c$：相同。
- ICMR：n 输入：$V_{in}(\max) = V_{DD} - V_{SG3} + V_{TN}$（接近 $V_{DD}$），$V_{in}(\min) = V_{SS} + V_{DS5}(\mathrm{sat}) + V_{GS1}$（远高于 $V_{SS}$）；p 输入：$V_{in}(\max) = V_{DD} - V_{SD5}(\mathrm{sat}) - V_{SG1}$（远低于 $V_{DD}$），$V_{in}(\min) = V_{SS} + V_{GS3} - |V_{TP}|$（接近 $V_{SS}$）。n 输入的范围延伸到正电源轨，p 输入的范围延伸到负电源轨；各自在另一端差约 $V_T$ 加一个饱和电压。
- 输出电流：n 输入（p 沟道驱动管 M6）可以输出大电流，但吸入电流受限于 M7 的偏置；p 输入版本可以吸入大电流，但只能输出 M7 的偏置电流。相应的输出级压摆限制，n 输入版本出现在下降沿，p 输入版本出现在上升沿。
- 噪声：折合到输入端的热噪声 ∝ $(1/g_{m1})(1 + g_{m3}/g_{m1})$，n 输入版本较低（$g_{m1}$ 较高，负载 $g_{m3}$ 较低；取 $r = 1.48$，n 输入版本的 $x = g_{m3}/g_{m1}$，噪声功率之比为 $r(1 + r^2x)/(1 + x)$，介于 1.48 与 3.3 之间，当 $(W/L)_3 = (W/L)_1$ 时 ≈ 2.2；仅输入对管而言，功率比为 1.48，噪声电压比为 1.22）。1/f 噪声：p 沟道器件的闪烁噪声系数通常低得多，因此 p 输入版本在低频通常更好；电流镜的 1/f 噪声以权重 $(g_{m3}/g_{m1})^2$ 折合到输入端，对 p 输入版本该权重增大约 2.2 倍，因此在没有给出闪烁噪声数据时，低频下的最终优劣取决于 p 沟道的优势能否超过这一点。
- 体效应（n 阱工艺）：p 沟道输入对管可以放在自己的 n 阱中，衬底接源极（无体效应，ICMR 和 CMRR 略好）；n 沟道对管的衬底接 $V_{SS}$。
- 高频 PSRR：输出驱动管源极所接的电源（n 输入版本为 V$_{DD}$，p 输入版本为 V$_{SS}$）在高频时经 $C_c$ 和类似二极管的驱动管耦合到输出，因此较差的高频 PSRR 出现在相反的电源上。
