A two-stage, 2-bit-per-stage subranging pipeline ADC works as follows. Stage 1: a 2-bit ADC with reference $V_{REF}$ converts $v_{in}(1)$ ($0 \le v_{in}(1) < V_{REF}$) into $b_0b_1$ (thresholds $V_{REF}/4$, $V_{REF}/2$, $3V_{REF}/4$; the code counts the thresholds reached), and a 2-bit DAC converts $b_0b_1$ into $v_{out}(1) = (b_0/2 + b_1/4)V_{DAC1}$. The residue $v_{in}(2) = v_{in}(1) - v_{out}(1)$ goes, without amplification, to stage 2: a 2-bit ADC with reference $V_{REF}/4$ (thresholds $V_{REF}/16$, $V_{REF}/8$, $3V_{REF}/16$) that produces $b_2b_3$. The output word is $b_0b_1b_2b_3$.

The reference voltage of the first-stage DAC is $V_{DAC1} = V_{REF} \pm \Delta V_{REF}$; everything else is ideal. What is the largest value of $\Delta V_{REF}$ that keeps the INL within ±1 LSB? Take the INL as the largest deviation of a code transition from its ideal position $kV_{REF}/16$, in LSBs (1 LSB = $V_{REF}/16$).
