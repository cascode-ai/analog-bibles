The simple current mirror shown in [Fig. 1] (M1 diode-connected, $I_1$ and $I_2$ ideal dc current sources from $V_{DD}$, input current $i_{in}$ into the M1 node, output current $i_{out}$ into the drain of M2) is to be used as a current amplifier; its output is short-circuited to a fixed dc voltage ($R_L \approx 0$). If the W/L of M1 is 1 µm/1 µm, design the W/L ratio of M2 to give a current gain of 10. If the value of $I_1$ is 100 µA (and $I_2$ equals the quiescent drain current of M2), find the small-signal input and output resistances. What is the actual value of the current gain when the input current $i_{in}$ is 50 µA? For this last part include channel-length modulation, $i_D = \frac{K'W}{2L}(v_{GS}-V_T)^2(1+\lambda v_{DS})$, and assume the output node is held at a dc voltage equal to the quiescent gate–source voltage of M1 (so that $V_{DS2} = V_{DS1}$ when $i_{in}$ = 0).

Device data (n-channel): $V_T$ = 0.7 V, $K'_N$ = 110 µA/V², λ = 0.04 V⁻¹.
