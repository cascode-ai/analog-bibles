[图 1] 所示比较器（comparator）由一个不加补偿的两级运放（M1–M7）和其后的两个推挽（push–pull）CMOS 反相器 M8–M9 与 M10–M11 构成，后者驱动负载 $C_{II}$。$V_{DD} = 2.5$ V，$V_{SS} = -2.5$ V。两级运放部分的 $(W/L)_6 = 94$（p 沟道输出器件），$(W/L)_7 = 14$，M6/M7 中电流为 95 µA，其低频增益为 7696 V/V。反相器的尺寸为 $W_{10}/L_{10} = 10(W_8/L_8) = 100(W_6/L_6)$，$W_9/L_9 = (K'_P/K'_N)(W_8/L_8)$，$W_{11}/L_{11} = (K'_P/K'_N)(W_{10}/L_{10})$（M8、M10 为 p 沟道；M9、M11 为 n 沟道），其静态电流为：M8 和 M9 中 100 µA，M10 和 M11 中 500 µA。求该比较器的开环增益。然后，若 $C_{II} = 100$ pF，且阶跃输入大到足以引起压摆（使 M10–M11 的栅极从一个电源轨切换到另一个电源轨），求输出反相器 M10–M11 贡献的传播延迟（propagation delay），即 $v_{out}$ 从电源轨压摆到 0 V 所需的时间。

器件数据：$K'_N = 110\ \mu\mathrm{A/V^2}$，$K'_P = 50\ \mu\mathrm{A/V^2}$，$V_{TN} = 0.7$ V，$V_{TP} = -0.7$ V，$\lambda_N = 0.04\ \mathrm{V^{-1}}$，$\lambda_P = 0.05\ \mathrm{V^{-1}}$；所有 $L = 1\ \mu$m。
