某 n 沟道 MOS 晶体管采用 n⁺ 多晶硅栅，栅掺杂浓度 $N_D = 4\times10^{19}\ \mathrm{cm^{-3}}$，栅氧化层厚度 $t_{ox} = 200$ Å，p 型衬底的 $N_A = 3\times10^{16}\ \mathrm{cm^{-3}}$，正界面电荷为 $10^{10}$ 个电荷/cm²（$Q_{ss} = q\times10^{10}\ \mathrm{C/cm^2}$）。若 $V_{SB} = 2$ V，求阈值电压 $V_T$。

利用：$V_T = V_{T0} + \gamma\left(\sqrt{2|\phi_F| + V_{SB}} - \sqrt{2|\phi_F|}\right)$，其中 $V_{T0} = \phi_{MS} - 2\phi_F - Q_{b0}/C_{ox} - Q_{ss}/C_{ox}$，$Q_{b0} = -\sqrt{2q\varepsilon_{Si}N_A\,2|\phi_F|}$，$\gamma = \sqrt{2q\varepsilon_{Si}N_A}/C_{ox}$，$\phi_F = \phi_F(\text{substrate}) = -\frac{kT}{q}\ln(N_A/n_i)$，$\phi_F(\text{gate}) = \frac{kT}{q}\ln(N_D/n_i)$，$\phi_{MS} = \phi_F(\text{substrate}) - \phi_F(\text{gate})$。常数：$kT/q = 0.0259$ V，$n_i = 1.45\times10^{10}\ \mathrm{cm^{-3}}$，$q = 1.6\times10^{-19}$ C，$\varepsilon_0 = 8.854\times10^{-14}$ F/cm，$\varepsilon_{Si} = 11.7\varepsilon_0$，$\varepsilon_{ox} = 3.9\varepsilon_0$。
