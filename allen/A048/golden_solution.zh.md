由 $K'W/(2L) = 500\ \mu\mathrm{A}/(5 - 0.7)^2 = 27.04\ \mu\mathrm{A/V^2}$（$K'W/L = 54.1\ \mu\mathrm{A/V^2}$），各曲线位于第三象限（$v_{DS} < 0$，$i_D < 0$；等价地，画 $-i_D$ 随 $-v_{DS}$ 的变化）。每条曲线从原点出发，按抛物线上升（非饱和区），并在 $v_{DS}(\text{sat}) = V_{GS} - V_T$ 处变为水平（λ = 0）：

- $V_{GS}$ = −1 V：$v_{DS}(\text{sat})$ = −0.3 V，$i_D$ = −2.4 µA
- $V_{GS}$ = −2 V：−1.3 V，−45.7 µA
- $V_{GS}$ = −3 V：−2.3 V，−143 µA
- $V_{GS}$ = −4 V：−3.3 V，−294 µA
- $V_{GS}$ = −6 V：−5.3 V，−760 µA

作图：
- 非饱和区（$|v_{DS}| < |V_{GS}| - 0.7$ V）：$|i_D| = 54.1\ \mu\mathrm{A/V^2}\,[(|V_{GS}| - 0.7)|v_{DS}| - v_{DS}^2/2]$；饱和区：$|i_D| = 27.04\ \mu\mathrm{A/V^2}\,(|V_{GS}| - 0.7)^2$。
