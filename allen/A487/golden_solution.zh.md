一种有效的实现：每一位用一个开关电容增益级，各级都由相同的单元构成，相邻级在相反的相位上工作。

第 $i$ 位的单元（运放，反相输入端 = 求和节点，同相输入端接地）：
- 反馈电容 $C_F = C$，两端并接一个复位开关，在该单元的采样相（sampling phase）闭合。
- 基准电容 $C_R = C$（比值 $C_R/C_F = 1$），实现 $b_iV_{REF}$：若 $b_i = 1$，其左极板在采样相接 $V_{REF}$，在转移相接地；若 $b_i = 0$，则左极板的连接互换（采样相接地，转移相接 $V_{REF}$），从而产生 $-V_{REF}$。（也可以将左极板在 $+V_{REF}$ 与 $-V_{REF}$ 之间切换。）
- 级间电容 $C_P = C/2$（比值 $C_P/C_F = 1/2$），实现因子 ½：左极板在采样相接前一级的输出，在转移相接地。
- $C_R$ 和 $C_P$ 的右极板：采样相接地，转移相接运放求和节点（对寄生不敏感的同相电荷转移）。
- 转移相结束时的结果：$v_i = \frac{C_R}{C_F}b_iV_{REF} + \frac{C_P}{C_F}v_{i+1} = b_iV_{REF} + \frac12 v_{i+1}$，并保持到该单元的下一个采样相。
- 相位安排：单元 $N-1$（LSB）在 $\phi_1$ 采样、在 $\phi_2$ 转移；单元 $N-2$ 在 $\phi_2$ 采样（此时单元 $N-1$ 保持其输出）、在 $\phi_1$ 转移；依此交替。每个单元引入半个时钟周期的延迟，因此框图中每一级的 $z^{-1}$ 对应半个周期；一个数字字的各位以同样的半周期错开加到相继的单元上，每个时钟周期可以输入一个新字，并且第一个单元没有 $C_P$（其 ½ 输入为 0）。输出在单元 0 的转移相取出（或经过最后一个采样保持电路取出）。
- 若改用反相（标准）电荷转移，则每一级都会反相；这可以通过在相间的各级中将 $b_i$ 的极性反过来加以补偿。
