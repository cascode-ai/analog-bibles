要求：M1 和 M2 必须保持饱和，因此 $V_{DS1} = V_{BIAS} - V_{GS3} \ge V_{GS1} - V_{T}$，即 $V_{BIAS} \ge V_{GS3} + V_{DS1(sat)} = V_T + V_{ON3} + V_{ON1}$；它也不应大得太多，以使 M3/M4 在整个输出摆幅范围内保持饱和。由于 $V_{BIAS}$ 以共源节点为参考，它会跟随输入共模电压变化。

一种双晶体管实现方案：
- 一个二极管连接（diode-connected）的 n 沟道晶体管 M13（栅极与漏极相连），其源极接 M1–M2 的共源节点，栅极/漏极接 M3 和 M4 的栅极。
- 一个从 $V_{DD}$ 向 M13 漏极供电的 p 沟道电流源 M14，其栅极接在 M12/M7/M8 的偏置线上，因此它流过偏置电流的一个复制电流 $I_{14}$。
- 确定 M13 的尺寸，使 $V_{GS13} = V_T + V_{ON3} + V_{ON1}$；若各过驱动电压 $V_{ON}$ 相等且电流与 M3 相同，则此值为 $V_T + 2V_{ON}$，可取 $(W/L)_{13} = \frac14(W/L)_3$ 得到（若电流不同，则按 $I_{14}/I_3$ 缩放）。
- 电流核算：$I_{14}$ 流入共源节点，因此尾电流管必须吸收 $I_9 = I_7 + I_8 + I_{14}$，差分对才能保持预定的电流。
