# Golden Solution - A214

## Reference answer

$SR^-$ = −4 V/µs.

A large negative input step cuts M1 off; the 200-µA sink alone discharges the 50-pF capacitor (the resistor current is zero at 0 V): $SR^-$ = −200 µA/50 pF = −4 V/µs.

## Grading notes

+2: −4 V/µs (magnitude 4 with negative direction). +1: units slip. 0: incomplete. −2 (asserted as fact): a value of hundreds of V/µs (M1 assumed to sink current), or the resistor current subtracted at $v_{OUT}$ = 0.
