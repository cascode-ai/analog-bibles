$I_{REF}$ 的范围为 ≈ 3.9 µA 到 ≈ 20.1 µA（25 °C、5 V 下的标称值 ≈ 8.5 µA）：约为标称值的 −54% 到 +136%。

- $I_{REF} = I_1 = (V_{DD} - V_{GS1})/R$，其中 $V_{GS1} = V_T + \sqrt{2I_1/(K'\cdot100)}$（此处过驱动电压只有 30–60 mV）。标称值：$(5 - 0.7 - 0.039)/500\ \mathrm{k} = 8.52\ \mu$A。
- $R(T) = R_{25}(1 + 0.008(T - 25))$，其中 $R_{25}$ = 300–700 kΩ；$V_T(T) = V_{T,25} - 2.3\ \mathrm{mV}\times(T - 25)$。
- 最小电流（70 °C，$V_{DD}$ = 4.5 V，$R_{25}$ = 700 kΩ → $R$ = 952 kΩ，$V_{T,25}$ = 0.85 V → $V_T$ = 0.747 V，$K'$ = 99 µA/V²）：$I = (4.5 - 0.747 - 0.028)/952\ \mathrm{k} = 3.91\ \mu$A。
- 最大电流（0 °C，$V_{DD}$ = 5.5 V，$R_{25}$ = 300 kΩ → $R$ = 240 kΩ，$V_{T,25}$ = 0.55 V → $V_T$ = 0.608 V，$K'$ = 121 µA/V²）：$I = (5.5 - 0.608 - 0.058)/240\ \mathrm{k} = 20.1\ \mu$A。
- 电阻起主导作用：工艺带来 ±40%，温度带来 +36%/−20%，电源再带来 ±10%。阈值电压的变化只贡献百分之几。
