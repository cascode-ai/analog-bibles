每个这样的结构的周长都满足 $P = 2A$（以单位正方形边长 $s$ 为单位：$P = 2A/s$），因此无论路径多长（包括最后一段为分数长度），都有 $A/P = s/2$。于是电容之比严格等于面积之比（例如 12.5 : 18），因为周长（边缘电容和边缘刻蚀）的贡献也按同一比例。

- 由 $n$ 个单位正方形构成的图形有 $P = 4n - 2m$（以 $s$ 为单位），其中 $m$ 为共用边的数目（每条共用边使轮廓减少两条单位边）。
- 在不含 2×2 方块的单位宽度路径中，由共用边连接的正方形构成一条链；简单的开链有 $m = n - 1$，每个闭合环再增加一条共用边。头部的单个环使 $m = n$，因此 $P = 4n - 2n = 2n = 2A$。
- 沿路径方向增加一段长度为 $f$（宽度为一个单位）的分数段，面积增加 $f$，周长增加 $2f$（两条长边；端边只是移动了位置），因此 $P = 2A$ 仍然成立：左边结构为 12 个单位、$P = 24$，加上半个单位后得 $A = 12.5$，$P = 25$；右边结构 $A = 18$，$P = 36$。两者均有 $A/P = 1/2$。
- 阵列中每个电容都有 $C_X = C_{area}A_X + C_{perimeter}P_X = A_X(C_{area} + 2C_{perimeter})$（以 $s$ 为单位；同样，边缘刻蚀误差 $\delta$ 给出 $\Delta A_X \approx -\delta P_X = -2\delta A_X$，对所有电容是相同的比例），因此比值 $C_2/C_1 = A_2/A_1$ 与边缘电容和刻蚀效应无关，并且 $A_2/A_1$ 可以取任意值，而不像相同单位正方形阵列那样只能是整数比。（若没有这个环，开放路径的周长为 $P = 2n + 2$，比值 $A/P = n/(2n + 2)$ 将与 n 有关。）
