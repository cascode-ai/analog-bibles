[图 1] 所示运算放大器工作在弱反型（weak inversion）。虚线框内为差分输入级 M1–M5，以二极管连接的 M3 和 M4 为负载；M8 和 M6 分别镜像 M3 和 M4，M9 和 M7 构成 n 沟道电流镜，M6–M10 和 M7–M11 为共源共栅输出支路，M12–M15 产生共源共栅管 M10 和 M11 的栅极电压（M12 的栅极与 M5 由同一个 $V_{BIAS}$ 驱动）。尾电流为 $I_5 = 100$ nA，晶体管 M1 至 M11 均为 W = 10 µm、L = 1 µm，$V_{DD} = -V_{SS} = 1.5$ V。输出驱动对地电容 $C_c$；其值未给出，因此用 $C_c$ 表示 GB 和 SR。

计算低频电压增益、GB、SR 和功耗。然后，若弱反型晶体管的漏源饱和电压为 0.1 V，设计 M12 至 M15 的 W/L，使输出摆幅达到最大值和最小值，假设 M12 和 M15 各流过 50 nA。

弱反型模型：饱和时 $i_D = (W/L)\,I_{DO}\exp[v_{GS}/(nV_t)]$（p 沟道器件取绝对值），其中 $I_{DO} = 2$ nA，$n_p = 1.5$，$n_n = 2.5$，$V_t = 26$ mV；$g_m = I_D/(nV_t)$；$r_{ds} = 1/(\lambda I_D)$，$\lambda_N = 0.04\ \mathrm{V^{-1}}$，$\lambda_P = 0.05\ \mathrm{V^{-1}}$。忽略体效应。
