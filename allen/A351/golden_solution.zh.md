- 电流：M1–M4 为 50 nA；镜像比 $b = S_6/S_4 = S_8/S_3 = 1$，M9:M7 = 1:1，因此 $I_6 = I_7 = I_8 = 50$ nA。
- 全部差分信号电流都到达输出（M4 → M6 直接到达，M3 → M8 → M9 → M7），因此 $i_{out} = b\,g_{m1}v_{in}$，其中 $g_{m1} = 50\ \mathrm{nA}/(2.5\times26\ \mathrm{mV}) = 0.769$ µS。
- $R_{out} = (g_{m10}r_{ds10}r_{ds6})\,\|\,(g_{m11}r_{ds11}r_{ds7})$：$g_{m10} = 1.28$ µS，$r_{ds6} = r_{ds10} = 400$ MΩ → 205 GΩ；$g_{m11} = 0.769$ µS，$r_{ds7} = r_{ds11} = 500$ MΩ → 192 GΩ；$R_{out}$ = 99.3 GΩ。
- $A_v = g_{m1}R_{out} \approx 76{,}400$，等价地 $A_v = \dfrac{I_5}{2I_7}\,\dfrac{b/n_n}{V_t^2(\lambda_P^2n_p + \lambda_N^2n_n)} = \dfrac{0.4}{(6.76\times10^{-4})(0.00775)}$。
- $GB = b\,g_{m1}/C_c$；最大输出电流为 $bI_5$ = 100 nA，因此 $SR = 100\ \mathrm{nA}/C_c$。
- $P_{diss}$：$V_{DD}$ 为 M3 + M4（100 nA）、M8（50 nA）、M6（50 nA）、M13（50 nA）和 M14（50 nA）供电：300 nA × 3 V = 0.9 µW。
- 摆幅：$v_{out}(\max) = V_{DD} - V_{SD6}(sat) - V_{SD10}(sat) = 1.3$ V 要求 $V_{SD6} = 0.1$ V。M10 的栅极位于 $V_{DD} - V_{SG13}$，其源极位于 $V_{DD} - V_{SG13} + V_{SG10}$，因此 $V_{SG13} - V_{SG10} = 0.1$ V。弱反型时 $V_{SG} = n_pV_t\ln[I/((W/L)I_{DO})]$；取 $I_{13} = I_{10} = 50$ nA：$(W/L)_{13} = (W/L)_{10}\,e^{-0.1/(n_pV_t)} = 10\,e^{-2.564} = 0.77$。M14 与 M13 共栅，必须为 M15 提供 50 nA：$(W/L)_{14} = 0.77$。
