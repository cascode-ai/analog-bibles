连接方式：$R_{CM1}$ 和 $R_{CM2}$ 分别从 $v_{OUT}^-$ 和 $v_{OUT}^+$ 接到 MC2 的栅极（因此它感受到输出共模）；MC1 的栅极接期望的共模电平 $V_{CM}$；MB 和 MC5 为 CMFB 差分对提供偏置；二极管连接的 MC3 的栅极驱动运放电流源 M4 和 M5 的栅极（取代 $V_{PB1}$）。MC4 是 MC2 的负载。

环路增益：$|LG| \approx \dfrac{g_{mC2}}{2g_{mC3}}\,g_{m4}\,R_{out,cm}$，其中 $R_{out,cm} \approx \left[\dfrac{g_{ds4}g_{ds6}}{g_{m6}} + \dfrac{g_{ds8}g_{ds10}}{g_{m8}}\right]^{-1}$（当各 $g_m$、$r_{ds}$ 相等且 $g_{mC2} = g_{mC3}$ 时 ≈ $(g_mr_{ds})^2/4$）。

- 极性：输出共模上升 → MC2 电流增加 $g_{mC2}v_c/2$，MC1 电流减少同样的量 → MC3 的 $V_{SG}$ 下降 $g_{mC2}v_c/(2g_{mC3})$ → M4、M5 的栅极电位上升 → $I_4$、$I_5$ 减小 $g_{m4}g_{mC2}v_c/(2g_{mC3})$ → 折叠进 M6、M7 的电流减小 → 输出下降：负反馈。
- $R_{out,cm}$：对于共模信号，输入对不能改变其总电流（由 M3 固定），因此折叠节点只看到 $r_{ds4}$（$r_{ds5}$）：向上 ≈ $g_{m6}r_{ds6}r_{ds4}$，向下 ≈ $g_{m8}r_{ds8}r_{ds10}$。
- 补偿：共模环路的主极点位于输出端，由对地的单端负载电容决定（与补偿差模环路的是同一个 $C_L$），因此该环路由负载电容补偿；其单位增益频率 ≈ $g_{m4}g_{mC2}/(2g_{mC3}C_L)$ 必须低于环路中的各个次极点：MC3/M4–M5 栅极节点（$g_{mC3}$ 对 M4、M5 的较大栅电容）、折叠节点（$g_{m6}/C_A$）以及检测节点（$R_{CM}/2$ 与 MC2 的栅电容；可用小电容旁路 $R_{CM1}$、$R_{CM2}$）。必要时可减小 $g_{mC2}/g_{mC3}$ 或增大 $C_L$。另一种做法：在别处制造主极点（在 MC2 检测节点加大电容，或在 MC3 控制节点加电容——该节点阻抗为 $1/g_{mC3}$，所需电容大得不现实），只有当它把共模穿越频率压到本已很低的输出极点 $1/(R_{out,cm}C_L)$ 以下时才稳定，因为高阻抗输出总会贡献一个低频极点；这种做法可行，但共模环路会非常慢。
- 注意：$R_{CM1}$、$R_{CM2}$ 对输出构成差模负载；它们必须远大于本已很高的输出电阻，或者改用经缓冲的检测或电容检测，否则会降低差模增益。
