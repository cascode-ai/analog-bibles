一种设计（所有 L = 2 µm）：M3 = M4 = 4 µm/2 µm，M6 = 16/2，M8 = 4/2，M5 ≈ 10.8/2，M7 ≈ 21.5/2；$C_c$ ≈ 16.7 pF；$R_z = 1/g_{m6}$ = 2.5 kΩ；$A_v \approx 1.05\times10^4$；$C_L \lesssim$ 37 pF（60° 裕度）；SR ≈ 6.0 V/µs。

- $g_{m1} = \sqrt{2(110\ \mu)(1)(50\ \mu)} = 104.9\ \mu$S → $C_c = g_{m1}/(2\pi \times 1\ \mathrm{MHz}) = 16.7$ pF。
- λ = 0.01 时的增益：$(g_{ds2} + g_{ds4}) = 0.01 \times 50\ \mu \times 2 = 1\ \mu$S，$(g_{ds6} + g_{ds7}) = 4\ \mu$S，因此 $A_v = g_{m1}g_{m6}/(4\times10^{-12})$ ≥ 5000 要求 $g_{m6} \ge 191\ \mu$S。
- M3 = M4 = 4/2（$S = 2$）：$V_{SG3} = 0.7 + \sqrt{2(50\ \mu)/(50\ \mu \cdot 2)} = 1.7$ V。为使 $V_{SG6} = V_{SG4}$：$S_6 = S_4 I_6/I_4 = 2 \times 200/50 = 8$（16/2），$g_{m6} = \sqrt{2(50\ \mu)(8)(200\ \mu)} = 400\ \mu$S → $A_v = (104.9\ \mu)(400\ \mu)/(4\times10^{-12}) = 1.05\times10^4$ ✓。（另一种方案：$g_{m6}$ = 191 µS，$S_6$ = 1.8，$S_4$ = 0.45，例如 2 µm/4.4 µm，增益 ≈ 5000–7000。）
- 偏置：M8 = 4/2（$S_8 = 2$）：$I_8 = (5 - V_{GS8})/100\ \mathrm k$ → $I_8$ = 37.2 µA；$S_5 = 2 \times 100/37.2 = 5.38$（≈ 10.8/2），$S_7 = 10.8$（≈ 21.5/2）。
- 零共模输入时的饱和检查：$V_{GS1} = 0.7 + \sqrt{2(50)/110} = 1.65$ V，因此 $V_{DS5} = 0.85$ V > $V_{DS5}(\mathrm{sat}) = 0.58$ V ✓；M1 漏极电位为 $V_{DD} - V_{SG3} = 0.8$ V，$V_{DS1} = 2.45$ V > 0.95 V ✓；输出范围 ≈ −1.92 V 至 +1.5 V。
- $R_z = 1/g_{m6} = 2.5$ kΩ 消除右半平面零点。
- 负载：60° 时 $|p_2| = g_{m6}/C_L \ge 1.73\,GB$ → $C_L \le 400\ \mu/(1.73 \times 2\pi \times 10^6) = 36.8$ pF（45° 时 ≈ 64 pF）。
- $SR = I_5/C_c = 100\ \mu\mathrm A/16.7\ \mathrm{pF} = 6.0$ V/µs。
