A five-stage (5-bit) pipeline algorithmic ADC of the form shown in [Fig. 1] has a sampled input $V_{in}^* = 0.7V_{REF}$. Each stage compares its input $V_{i-1}$ with its comparator threshold (ideally zero): the stage bit is 1 ($b_{i-1} = +1$) if $V_{i-1}$ is above the threshold and 0 ($b_{i-1} = -1$) otherwise, and the stage output $V_i = A_iV_{i-1} - b_{i-1}V_{REF}$ drives the next stage; the bits form the output word MSB first. All elements of the converter are ideal except for the multiplier of 2 of the first stage, given as $A_1 = 2(1 + \varepsilon)$. Assuming that the comparator offsets are all zero, what is the smallest magnitude of $\varepsilon$ that causes an error in the output word?
