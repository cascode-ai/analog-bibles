令 $x = \frac14 + \delta$，$|\delta| \le \frac{1}{24}$：最坏情况下 INL $= 3(4x-1)$，DNL $= 4x - 1$ 或 $-3(4x - 1)$，因此 $|INL| \le 0.5$ LSB 且 $|DNL| \le 0.5$ LSB，在端点 $x = 5/24$ 和 $x = 7/24$ 处取等号。

推导（1 LSB $= V_{REF}/16$；码 $= 4m + n$，$m = 2b_0 + b_1$，$n = 2b_2 + b_3$）：
- 输出 $= 4m + 16x\cdot\frac{n}{4} = 4m + 4xn$ LSB；理想值 $4m + n$。
- INL $= (4x - 1)n$；$|4x - 1| \le 4/24 = 1/6$ 且 $n \le 3$ → $|INL| \le 0.5$ LSB（$x = 7/24$：0 … +0.5；$x = 5/24$：0 … −0.5）。
- 组内台阶：$4x$ LSB → DNL $= 4x - 1 \in [-1/6, +1/6]$。
- 组间跳变（$n$：3 → 0，$m$ → $m+1$）：台阶 $= 4 - 12x$ → DNL $= 3 - 12x = -3(4x - 1) \in [-0.5, +0.5]$（$x = 7/24$：−0.5；$x = 5/24$：+0.5）。
- 因此在整个容差范围内，INL 和 DNL 都在 ±0.5 LSB 以内。
