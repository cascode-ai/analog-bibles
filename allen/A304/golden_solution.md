# Golden Solution - A304

## Reference answer

Two results are acceptable, depending on whether the M10/M11 mirror gates are treated as an ac ground (the textbook's regulated-cascode treatment, which the stated upper-amplifier gain presumes) or the shared upper amplifier is analysed exactly as drawn. Regulated-cascode treatment: $R_{out} \approx 0.28$ GΩ; $A_v \approx g_{mP}R_{out} \approx 6.9\times10^3$ V/V; dominant pole ≈ −360 rad/s (57 Hz); $GB \approx g_{mP}/C_L = 2.5$ Mrad/s (0.40 MHz). Drawn connection exactly: $R_{out} \approx 7.2$ MΩ, $A_v \approx 180$, $p_{dom} \approx -1.4\times10^4$ rad/s (2.2 kHz), the same GB (last bullet).

- Enhancement gains: $A_{up} = 0.5(100\,\mu)(2\,\mathrm{M}) = 100$; $A_{low} = 0.5(25\,\mu)(0.5\,\mathrm{M}) = 6.25$.
- $R_{out} \approx [A_{up}g_{m9}r_{ds9}r_{ds11}]\,\|\,[A_{low}g_{m7}r_{ds7}(r_{ds1}\|r_{ds5})]$ (M1's drain is at the source of M7) $=[100\cdot25\,\mu\cdot0.5\,\mathrm{M}\cdot0.5\,\mathrm{M} = 0.625\ \mathrm{G\Omega}]\,\|\,[6.25\cdot100\,\mu\cdot2\,\mathrm{M}\cdot(0.5\,\mathrm{M}\|2\,\mathrm{M}) = 0.50\ \mathrm{G\Omega}] = 0.278$ GΩ.
- With the output shorted, both input half-currents reach the output (the regulated cascode sources are very low impedance), so the short-circuit transconductance is $g_{m1} = g_{mP}$: $A_v = 25\,\mu\times0.278\,\mathrm{G} \approx 6.9\times10^3$.
- $p_{dom} = -1/(R_{out}C_L) = -1/(0.278\,\mathrm{G}\cdot10\,\mathrm{pF}) = -360$ rad/s; $GB = A_v|p_{dom}| = g_{mP}/C_L = 2.5\times10^6$ rad/s ≈ 0.40 MHz.
- (If the signal current of M2 is assumed to split evenly, $A_v = 0.75g_{mP}R_{out}$ ≈ 5.2×10³ and GB ≈ 1.9 Mrad/s; it is wrong here because, with the output shorted, the regulated cascode source seen from each folding node (≈ $1/(g_{mN}(1+A_{low}))$ ≈ 1.4 kΩ) is far below $r_{ds1}\|r_{ds5}$ = 0.4 MΩ, so essentially all of each half-current goes to the output.)
- Using $1+A$ instead of A gives $R_{out}$ ≈ 0.30 GΩ, $A_v$ ≈ 7.6×10³ and $p_{dom}$ ≈ −330 rad/s, within the tolerance.
- Note on the drawn connection: the result above treats the gates of M10/M11 as an ac ground. As drawn, the single upper amplifier drives the gates of both M8 and M9, and the M10/M11 gates are tied to the M8 drain. When the output moves, the amplifier also moves the M8 gate; since the left-branch current is fixed, the mirror gate shifts so that the effective output conductance of M11 rises by ≈ $(1+A_{up})$, cancelling the upper enhancement. A full small-signal analysis of the drawn circuit (ideal enhancement amplifiers) gives $R_{out}$ ≈ 7.2 MΩ, $A_v$ ≈ 180, $p_{dom}$ ≈ −1.4×10⁴ rad/s and the same GB ≈ 2.5 Mrad/s; with the M8 gate on a fixed bias it gives 0.30 GΩ and 7.7×10³, the result above. (Linear small-signal simulation with the given values, ideal enhancement amplifiers, $C_L$ only: drawn connection $R_{out} = 7.20$ MΩ, $A_v = 179$, $f_{-3dB} = 2.21$ kHz, $f_u = 0.396$ MHz; M8 gate fixed $R_{out} = 0.299$ GΩ, $A_v = 7.70\times10^3$, $f_{-3dB} = 53$ Hz, $f_u = 0.41$ MHz.)
