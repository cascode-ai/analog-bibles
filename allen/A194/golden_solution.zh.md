$R_{in} \approx \dfrac{1}{g_{m3}(1+g_{m1}/g_{m6})} = \dfrac{1}{3g_{mN}}$；$A_i = \dfrac{i_{out}}{i_{in}} \approx \dfrac{g_{m6}}{g_{m6}+g_{m1}} = \dfrac13$；$R_{out} \approx r_{ds6}\left(1+\dfrac{g_{m6}}{g_{m1}}\right) = 1.5\,r_{dsP} = 3r_{dsN}$。

把 M5 与 M3 的漏极、M6 的源极以及 M1 的栅极所在的节点称为 X。
- 输入（输出短路）：输出处于交流地时，X 看进 M6 的源极，约为 $1/g_{m6}$。输入节点升高 $v_{in}$ 使 M3 的电流减小 $g_{m3}v_{in}$；由于 M5 提供恒定电流，这部分电流转入 M6，因此 X 升高 $g_{m3}v_{in}/g_{m6}$，M1 于是从输入端多吸收 $g_{m1}g_{m3}v_{in}/g_{m6}$。总计：$i_{in} = g_{m3}v_{in}(1+g_{m1}/g_{m6})$ → $R_{in} = 1/[g_{m3}(1+g_{m1}/g_{m6})]$ = $1/(3g_{mN})$ = $1/(6g_{mP})$。
- 电流增益：输入电流在 M1 与 M3–M6 通路之间分配；流经 M3 的部分（反向后）出现在 M6 中并到达输出端，所占比例为 $g_{m6}/(g_{m6}+g_{m1})$ = 1/3（M2–M4 为固定电流沉）。取 $i_{out}$ 沿箭头方向（流出输出端）为正，$A_i$ = +1/3。
- 输出电阻（输入开路）：此时节点 X 看到的是 M3–M1 环路（X 升高使 M1 把输入节点拉低，从而使 M3 从 X 吸取更多电流），其电阻约为 $1/g_{m1}$。向下看进 n 沟道共源共栅（cascode）结构 M4–M2，约为 $g_{mN}r_{dsN}^2$（非常大）；向上看进由约 $1/g_{m1}$ 构成源极负反馈的 M6，为 $r_{ds6}(1+g_{m6}/g_{m1})$ = 1.5 $r_{dsP}$。因此 $R_{out}$ ≈ 1.5 $r_{dsP}$ = 3 $r_{dsN}$（对 $g_mr_{ds} \sim 100$，精确节点分析的结果与此相差不到百分之几）。
- 注：若输出端改为开路，X 将成为高阻节点，反馈也会强得多，得到 $R_{in} \approx 2.5/(g_{mN}^2r_{dsN})$。
