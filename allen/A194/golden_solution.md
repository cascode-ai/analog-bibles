# Golden Solution - A194

## Reference answer

$R_{in} \approx \dfrac{1}{g_{m3}(1+g_{m1}/g_{m6})} = \dfrac{1}{3g_{mN}}$; $A_i = \dfrac{i_{out}}{i_{in}} \approx \dfrac{g_{m6}}{g_{m6}+g_{m1}} = \dfrac13$; $R_{out} \approx r_{ds6}\left(1+\dfrac{g_{m6}}{g_{m1}}\right) = 1.5\,r_{dsP} = 3r_{dsN}$.

Call X the node at the drains of M5 and M3, the source of M6 and the gate of M1.
- Input (output shorted): with the output at ac ground, X looks into the source of M6, ≈ $1/g_{m6}$. A rise $v_{in}$ of the input node reduces M3's current by $g_{m3}v_{in}$; since M5 supplies a constant current, that current is diverted into M6, so X rises by $g_{m3}v_{in}/g_{m6}$, and M1 then sinks an extra $g_{m1}g_{m3}v_{in}/g_{m6}$ from the input. Total: $i_{in} = g_{m3}v_{in}(1+g_{m1}/g_{m6})$ → $R_{in} = 1/[g_{m3}(1+g_{m1}/g_{m6})]$ = $1/(3g_{mN})$ = $1/(6g_{mP})$.
- Current gain: the input current splits between M1 and the M3–M6 path; the part through M3 appears (reversed) in M6 and at the output, a fraction $g_{m6}/(g_{m6}+g_{m1})$ = 1/3 (M2–M4 is a fixed current sink). With $i_{out}$ taken in the arrow direction (out of the output terminal), $A_i$ = +1/3.
- Output resistance (input open): node X now sees the loop M3–M1 (raising X makes M1 pull the input node down, which makes M3 draw more current from X), a resistance ≈ $1/g_{m1}$. Looking down into the n-channel cascode M4–M2 gives ≈ $g_{mN}r_{dsN}^2$ (very large); looking up into M6 degenerated by ≈ $1/g_{m1}$ gives $r_{ds6}(1+g_{m6}/g_{m1})$ = 1.5 $r_{dsP}$. So $R_{out}$ ≈ 1.5 $r_{dsP}$ = 3 $r_{dsN}$ (exact nodal analysis agrees to within a few percent for $g_mr_{ds} \sim 100$).
- Remark: if the output were left open instead, X would become a high-resistance node and the feedback much stronger, giving $R_{in} \approx 2.5/(g_{mN}^2r_{dsN})$.
