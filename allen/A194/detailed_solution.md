# Detailed solution - A194

Name the node at the drains of M5 and M3, the source of M6 and the gate of M1 as X. The input node is the source of M3 and the drain of M1; M3 (gate at $V_{NB2}$) carries current from X down to the input, and M1 (gate at X) sinks current from the input. Work by inspection: follow a small change through the loop M3 → X → M1, using the resistance each node sees, and treat M5 and M2 as constant-current sources.

### Step 1 — Input resistance (output at ac ground)

With the output at ac ground, X looks into the source of M6, a resistance of about $1/g_{m6}$; M5 is a current source and $r_{ds}$ terms are negligible beside it.

Raise the input node by $v_{in}$. M3's gate is fixed, so its $v_{gs}$ falls and its current drops by $g_{m3}v_{in}$. M5 still supplies a constant current to X, so the difference is diverted into M6, raising X by

$$
v_x=\frac{g_{m3}v_{in}}{g_{m6}} .
$$

M1's gate is X, so M1 sinks an extra $g_{m1}v_x$ from the input. The input source must supply both changes:

$$
i_{in}=g_{m3}v_{in}+g_{m1}\frac{g_{m3}}{g_{m6}}v_{in}
\quad\Rightarrow\quad
R_{in}=\frac{1}{g_{m3}\left(1+g_{m1}/g_{m6}\right)} .
$$

With $g_{m1}=g_{m3}=g_{mN}$ and $g_{m6}=g_{mP}=g_{mN}/2$, $R_{in}=1/(3g_{mN})$.

### Step 2 — Current gain (output at ac ground)

The input current divides between M1 and the M3 path. From Step 1, a fraction

$$
\frac{g_{m3}v_{in}}{i_{in}}=\frac{1}{1+g_{m1}/g_{m6}}=\frac{g_{m6}}{g_{m6}+g_{m1}}
$$

flows as a change of M3's current. Because M5's current is fixed, that change appears with the opposite sign in M6 and hence at the output; M2–M4 form a fixed current sink and contribute no signal. An input current into the input node reduces M3's current, increases M6's, and so pushes current out of the output terminal, in the direction of the $i_{out}$ arrow:

$$
A_i=\frac{i_{out}}{i_{in}}\approx\frac{g_{m6}}{g_{m6}+g_{m1}}=\frac{g_{mP}}{g_{mP}+2g_{mP}}=\frac13 .
$$

### Step 3 — Output resistance (input open)

With the input driven by an ideal current source, a change at X is no longer absorbed by M6 alone. If X rises, M1 pulls the input node down, which raises M3's $v_{gs}$ so that M3 draws more current from X. This local loop makes X a low-resistance node: since M3's current change equals M1's, $g_{m1}v_x$, the resistance at X is about $1/g_{m1}$.

Looking up from the output into M6, degenerated by this $1/g_{m1}$:

$$
R_{up}\approx r_{ds6}\left(1+\frac{g_{m6}}{g_{m1}}\right)=r_{dsP}\left(1+\frac12\right)=1.5\,r_{dsP}.
$$

Looking down into the n-channel cascode M4 over M2 gives $R_{dn}\approx g_{mN}r_{dsN}^2\gg R_{up}$. Therefore

$$
R_{out}\approx R_{up}=r_{ds6}\left(1+\frac{g_{m6}}{g_{m1}}\right)=1.5\,r_{dsP}=3\,r_{dsN}.
$$

A full nodal analysis with $g_mr_{ds}\approx100$ gives $R_{in}=0.34/g_{mN}$, $A_i=0.333$ and $R_{out}=2.93\,r_{dsN}$, confirming the inspection results within a few percent.
