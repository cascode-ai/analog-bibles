Design a CMOS comparator given the following requirements: power dissipation $P_{diss} < 2$ mW, $V_{DD} = 3$ V, $V_{SS} = 0$ V, load capacitance $C_{load} = 3$ pF, propagation delay $t_{prop} < 1\ \mu$s, input common-mode range 1.5 V to 2.5 V, dc gain $A_{v0} > 2200$, and output voltage swing within 1.5 V of either rail. Use 1 µm channel lengths for all transistors. Give the circuit, all W/L values and bias currents, and verify each specification.

Device data: $K'_N = 110\ \mu\mathrm{A/V^2}$, $K'_P = 50\ \mu\mathrm{A/V^2}$, $V_{TN} = 0.7$ V, $V_{TP} = -0.7$ V, $\lambda_N = 0.04\ \mathrm{V^{-1}}$, $\lambda_P = 0.05\ \mathrm{V^{-1}}$ (at $L = 1\ \mu$m); small-signal $g_m = \sqrt{2K'(W/L)I_D}$, $g_{ds} = \lambda I_D$; $C_{ox} = 24.7\times10^{-4}\ \mathrm{F/m^2}$, $C_{GSO} = C_{GDO} = 220\times10^{-12}$ F/m.
