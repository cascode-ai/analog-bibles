标称 $V_{TRP} \approx 1.89$ V；最坏情况 $V_{TRP}(\max) \approx 3.22$ V，$V_{TRP}(\min) \approx 0.39$ V。
- 令两管饱和电流相等，$\tfrac{K'_P}{2}(W/L)_6(V_{DD}-v_{in}-|V_{TP}|)^2 = \tfrac{K'_N}{2}(W/L)_7(V_{BIAS}-V_{SS}-V_{TN})^2$，得
$V_{TRP} = V_{DD}-|V_{TP}|-\sqrt{\dfrac{K'_N(W/L)_7}{K'_P(W/L)_6}}\,(V_{BIAS}-V_{SS}-V_{TN})$。
- 标称值：$4-0.7-\sqrt{22}\,(0.3) = 3.3-1.407 = 1.89$ V。
- 最大值：$V_{DD} = 4.4$，$|V_{TP}| = 0.63$，$K'_N = 99$，$K'_P = 55$，$V_{BIAS} = 0.9$，$V_{TN} = 0.77$：$4.4-0.63-\sqrt{18}\,(0.13) = 3.22$ V。
- 最小值：$V_{DD} = 3.6$，$|V_{TP}| = 0.77$，$K'_N = 121$，$K'_P = 45$，$V_{BIAS} = 1.1$，$V_{TN} = 0.63$：$3.6-0.77-\sqrt{26.9}\,(0.47) = 0.39$ V。
- 翻转点对 $V_{BIAS}-V_{TN}$ 非常敏感（标称值仅 0.3 V，却被乘以 $\sqrt{22} \approx 4.7$）。
