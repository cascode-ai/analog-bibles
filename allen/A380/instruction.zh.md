对于 [图 1] 所示的两级比较器（$V_{DD} = 2.5$ V，$V_{SS} = -2.5$ V，$C_I = 0.2$ pF，$C_{II} = 5$ pF，尺寸和偏置电流见 [图 1]），现将 M2 的栅极保持在 0 V 不变，而 M1 的栅极（不再像图中那样接地）由如下波形驱动：$t < 0.2\ \mu$s 时 $v_{G1} = -2.5$ V，$0.2\ \mu\mathrm{s} < t < 0.4\ \mu$s 时为 $+2.5$ V，$t > 0.4\ \mu$s 时为 $-2.5$ V；每个电平持续的时间都足以使电路达到稳态。输入足够大，以压摆为主。求输出下降沿和上升沿的传播延迟时间（propagation delay time），以及比较器的传播延迟时间（二者的平均值）。将每一级的延迟视为其输出节点从初始值压摆到下一级翻转点所需的时间；比较器所驱动的电路在 0 V 处翻转。

器件数据：$K'_N = 110\ \mu\mathrm{A/V^2}$，$K'_P = 50\ \mu\mathrm{A/V^2}$，$V_{TN} = 0.7$ V，$V_{TP} = -0.7$ V；忽略沟道长度调制和体效应。
