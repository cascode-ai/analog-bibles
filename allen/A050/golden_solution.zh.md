取 $V_{TS} = V_{TD} = V_T$，$\beta = K'W/L$：

$v_{GS} = V_{GS} > V_T$ 恒定时：
- $v_{DS} \ge V_{GS} - V_T$：漏极项为零（$v_{GD} \le V_T$），$i_D = \frac{\beta}{2}(V_{GS}-V_T)^2$，为常数：饱和区（沟道在漏端夹断）。
- $v_{DS} < V_{GS} - V_T$（包括所有负的 $v_{DS}$）：两项都起作用，$i_D = \frac{\beta}{2}[(V_{GS}-V_T)^2 - (V_{GS}-v_{DS}-V_T)^2] = \beta[(V_{GS}-V_T)v_{DS} - v_{DS}^2/2]$：非饱和区。这是一条开口向下、过原点的抛物线，原点处斜率为 $\beta(V_{GS}-V_T)$，恰好在 $v_{DS} = V_{GS}-V_T$ 处达到最大值（斜率为零），并在该点与水平线平滑衔接。
- 对 $v_{DS} < 0$，同一条抛物线延伸到第三象限：$i_D < 0$，$|i_D|$ 按平方关系无限增大，因为此时漏极充当源极，其栅驱动 $v_{GD} = V_{GS} + |v_{DS}|$ 不断增大；在 $v_{GS}$ 保持不变时，负 $v_{DS}$ 一侧不存在饱和。

$v_{GD} = V_{GD} > V_T$ 恒定时：
- $v_{DS} \le -(V_{GD} - V_T)$：源极项为零（$v_{GS} = V_{GD} + v_{DS} \le V_T$），$i_D = -\frac{\beta}{2}(V_{GD}-V_T)^2$，为负的常数：源极与漏极角色互换的饱和区（在源端夹断）。
- $v_{DS} > -(V_{GD} - V_T)$：两项都起作用，$i_D = \beta[(V_{GD}-V_T)v_{DS} + v_{DS}^2/2]$：非饱和区，过原点，斜率为 $\beta(V_{GD}-V_T)$；对 $v_{DS} > 0$，它按平方关系上升，不会饱和。
- 第二幅草图是第一幅绕原点旋转 180° 的结果（点对称），体现了该模型的源漏对称性。

（若 $V_{TS} \ne V_{TD}$，曲线形状相同，只是 $v_{DS} = 0$ 时 $i_D \ne 0$，且区域边界为 $v_{DS} = v_{GS} - V_{TD}$ 和 $v_{DS} = V_{TS} - v_{GD}$。）
