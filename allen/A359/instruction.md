The folded-cascode op amp shown in [Fig. 1] has been designed with the following values (all channel lengths L = 0.5 µm; single supply $V_{DD} = 2.5$ V, the bottom rail is ground; $C_L = 10$ pF): M1 = M2 n-channel, W/L = 33, 50 µA each ($I_3$ = 100 µA in M3, W/L = 15); M4 = M5 p-channel current sources, W/L = 160, 125 µA each; M6 = M7 p-channel cascodes, W/L = 160, 75 µA; M8 = M9 = M10 = M11 n-channel, W/L = 20, 75 µA. Process: $K'_N = 120\ \mu\mathrm{A/V^2}$, $K'_P = 25\ \mu\mathrm{A/V^2}$, $V_{TN} = |V_{TP}| = 0.5$ V, $\lambda_N = 0.06\ \mathrm{V^{-1}}$, $\lambda_P = 0.08\ \mathrm{V^{-1}}$. Find the input-equivalent rms noise voltage of this op amp over a bandwidth of 1 Hz to 100 kHz.

Noise model (gate-referred, per transistor): 1/f, $e^2 = KF/(2fC_{ox}WLK')$ with $KF = 4\times10^{-28}$ F·A (n-channel), $0.5\times10^{-28}$ F·A (p-channel) and $C_{ox} = 24.7\times10^{-4}$ F/m²; thermal, $e^2 = 8kT/(3g_m)$ with T = 300 K. The noise of the cascode transistors M6–M9 and of the tail transistor M3 may be neglected.
