[图 1] 所示的折叠式共源共栅（folded-cascode）运算放大器按以下参数设计（所有沟道长度 L = 0.5 µm；单电源 $V_{DD} = 2.5$ V，下电源轨为地；$C_L = 10$ pF）：M1 = M2 为 n 沟道，W/L = 33，各 50 µA（M3 中 $I_3$ = 100 µA，W/L = 15）；M4 = M5 为 p 沟道电流源，W/L = 160，各 125 µA；M6 = M7 为 p 沟道共源共栅管，W/L = 160，75 µA；M8 = M9 = M10 = M11 为 n 沟道，W/L = 20，75 µA。工艺参数：$K'_N = 120\ \mu\mathrm{A/V^2}$，$K'_P = 25\ \mu\mathrm{A/V^2}$，$V_{TN} = |V_{TP}| = 0.5$ V，$\lambda_N = 0.06\ \mathrm{V^{-1}}$，$\lambda_P = 0.08\ \mathrm{V^{-1}}$。求该运放在 1 Hz 至 100 kHz 带宽内的输入等效均方根噪声电压。

噪声模型（折合到栅极，每个晶体管）：1/f 噪声，$e^2 = KF/(2fC_{ox}WLK')$，其中 $KF = 4\times10^{-28}$ F·A（n 沟道）、$0.5\times10^{-28}$ F·A（p 沟道），$C_{ox} = 24.7\times10^{-4}$ F/m²；热噪声，$e^2 = 8kT/(3g_m)$，T = 300 K。共源共栅管 M6–M9 和尾电流管 M3 的噪声可以忽略。
