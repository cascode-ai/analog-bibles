A 3-bit ADC has zero offset and gain errors, so its first (000→001) and last (110→111) code transitions lie at their ideal input values, and its DNL is ±0.5 LSB: every code width, measured along the analog input axis, lies between 0.5 LSB and 1.5 LSB. The INL is measured along the analog axis as the deviation of each code transition from its ideal position. What is the worst-case symmetrical value of the INL, i.e., the largest $x$ for which the INL of such an ADC can reach both $+x$ and $-x$ LSB? Give a sketch of a characteristic that reaches it.
