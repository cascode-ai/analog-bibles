- 设 $e_1, \dots, e_7$ 为七个跳变点的偏差（以 LSB 计）；$e_1 = e_7 = 0$，六个内部码中的每一个都按其码宽误差改变偏差，因此 $|e_{k+1} - e_k| \le 0.5$ LSB。
- 要在跳变 $i$ 处达到 $+x$、在跳变 $j$ 处达到 $-x$（或顺序相反），路径需要从 $e_1$ 到第一个极值走 $a$ 步，两个极值之间走 $b$ 步，再走 $c$ 步回到 $e_7$，其中 $a + b + c = 6$，$x \le 0.5a$，$2x \le 0.5b$，$x \le 0.5c$。步数取整数时，最佳分配（1, 4, 1 或 2, 2, 2）给出 $x = 0.5$ LSB；$x = 0.75$ LSB 需要 1.5 + 3 + 1.5 = 6 步，但步数为分数，取整后至少为 2 + 3 + 2 = 7 步，而 3 位转换器没有这么多步。
- 示例（理想跳变位于 0.5, 1.5, …, 6.5 LSB）：码 001…110 的码宽 = 1.5, 0.5, 0.5, 1.0, 1.5, 1.0 LSB（DNL 为 +0.5, −0.5, −0.5, 0, +0.5, 0），跳变位于 0.5, 2.0, 2.5, 3.0, 4.0, 5.5, 6.5 LSB，即 INL = 0, +0.5, 0, −0.5, −0.5, 0, 0 LSB。
- （若只要求单一极性，偏差可在中间跳变处累积到 1.5 LSB：码 001–011 宽 1.5 LSB，码 100–110 宽 0.5 LSB。）
