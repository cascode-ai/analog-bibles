# 详细步骤 - A176

每个电路的静态功耗为 $P=V_{DD}I_{DD}$，其中 $I_{DD}$ 是从电源吸取的总直流电流。所有电路的 $V_{DD}$ 相同，因此利用 KCL 和题给偏置电流，比较 $V_{DD}$ 与地之间的支路数及各支路电流即可。

### 第 1 步 — 各电路的电源电流

每个电流源管和共源共栅管都流过 $I$。由图可知：

- **电路 1：** 一条支路：p 沟道电流源（VBP1）→ 输出端 → n 沟道共源共栅管 → n 沟道输入管。$I_{DD}=I$。
- **电路 2：** 一条支路：p 沟道输入管 → p 沟道共源共栅管 → 输出端 → n 沟道电流沉。$I_{DD}=I$。
- **电路 3：** 一条支路：p 沟道电流源 → p 沟道共源共栅管 → 输出端 → n 沟道共源共栅管 → n 沟道输入管。$I_{DD}=I$。
- **电路 4：** 一条支路：p 沟道输入管 → p 沟道共源共栅管 → 输出端 → n 沟道共源共栅管 → n 沟道电流沉。$I_{DD}=I$。
- **电路 5：** 两个 p 沟道电流源接 $V_{DD}$，一个向输出端（及 n 沟道共源共栅管）供电，另一个向共源共栅管的源极节点供电。两路电流都向下流过 n 沟道输入管，由 KCL 该管流过 $2I$。$I_{DD}=2I$。
- **电路 6：** p 沟道输入管从 $V_{DD}$ 流过 $2I$；在共源共栅管的源极节点分为两路：$I$ 经 p 沟道共源共栅管到输出端和 n 沟道电流沉，另 $I$ 流过额外的 n 沟道电流沉。$I_{DD}=2I$。

### 第 2 步 — 最低功耗

$$
P_{1}=P_{2}=P_{3}=P_{4}=V_{DD}I,\qquad P_{5}=P_{6}=2V_{DD}I .
$$

**电路 1、2、3 和 4 的功耗最低**，均为 $V_{DD}I$。电路 5 和 6 是折叠结构：输入管与共源共栅管由并联支路中各自的电流源偏置，因此电源电流为两倍。
