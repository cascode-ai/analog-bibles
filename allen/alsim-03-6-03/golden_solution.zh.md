共七条曲线，每条都从原点陡峭上升（M2 处于非饱和区）直到 $v_2 = V_{GS} - V_T$，然后几乎变平，在 $v_2 = V_{GS1}$ 处穿过 $i_2 = i_1$，并以 ≈ λ$i_1$ 的斜率上升。

- $V_{GS1} = 0.7 + \sqrt{2i_1/(K'W/L)}$ = 0.89、0.97、1.03、1.08、1.12、1.16、1.20 V，对应 $i_1$ = 10 … 70 µA（λ = 0.04 时低几 mV），因此拐点位于 $v_2$ ≈ 0.19 … 0.50 V。
- 饱和区：$i_2 = i_1(1 + \lambda v_2)/(1 + \lambda V_{GS1})$。
- λ = 0.01 V⁻¹：$i_2(5\ \mathrm{V}) ≈ 1.04\,i_1$ = 10.4、20.8、31.2、41.6、51.9、62.3、72.6 µA；输出电阻 ≈ 1/(λ$i_1$) = 10 MΩ … 1.4 MΩ。
- λ = 0.04 V⁻¹：$i_2(5\ \mathrm{V}) ≈ 1.15\,i_1$ = 11.6、23.1、34.6、46.0、57.4、68.8、80.2 µA；输出电阻 2.6 MΩ … 0.37 MΩ。
- 用一次嵌套扫描即可得到整组曲线，例如用 `I1 0 1 DC 10U` 向二极管连接节点供电，并用 `.DC V2 0 5 0.1 I1 10U 70U 10U`。
