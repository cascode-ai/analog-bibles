# Golden Solution - A272

## Reference answer

GB ≈ 7.1 MHz.

$g_{m1} = \sqrt{2K'_N(W/L)_1(I_5/2)} = \sqrt{2(110\ \mu)(10)(22.8\ \mu)} = 224\ \mu$S; $GB = \dfrac{g_{m1}}{2\pi C_c} = \dfrac{224\ \mu\mathrm S}{2\pi(5\ \mathrm{pF})} = 7.1$ MHz (4.48 × 10⁷ rad/s).
