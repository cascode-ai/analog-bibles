$SR^- \approx 9.1$ V/µs。

- 内部限制：第一级最多只能向 $C_c$ 提供 $I_5$：$I_5/C_c = 45.7\ \mu\mathrm A/5\ \mathrm{pF} = 9.1$ V/µs。
- 输出限制：下降沿时 M6 截止，M7 必须同时吸收负载电流和流过 $C_c$ 的电流 $I_5$：$C_L\,dv/dt = I_7 - I_5$ → $(228 - 45.7)\ \mu\mathrm A/20\ \mathrm{pF} = 9.1$ V/µs。等价地，若认为在输出受限的压摆过程中第一级节点电位固定，则 M7 对 $C_L + C_c$ 放电：$I_7/(C_L + C_c) = 228\ \mu\mathrm A/25\ \mathrm{pF} = 9.1$ V/µs（两种形式给出两个限制相等的同一条件 $I_7 = I_5(1 + C_L/C_c)$）。
- 两个限制恰好相同（因为 $I_7 = 5I_5$ 且 $C_L = 4C_c$），因此 $SR^- = \min[I_5/C_c,\ (I_7 - I_5)/C_L] = 9.1$ V/µs。
