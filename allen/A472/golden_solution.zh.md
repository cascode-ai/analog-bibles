一种有效的设计（位 $b_0$ = MSB 至 $b_9$ = LSB）：
- MSB 阵列（上极板节点 = 缓冲器输入）：$16C$（$b_0$）、$8C$（$b_1$）、$4C$（$b_2$）、$2C$（$b_3$）、$C$（$b_4$）；总计 $31C$。
- LSB 阵列：$16C$（$b_5$）、$8C$（$b_6$）、$4C$（$b_7$）、$2C$（$b_8$）、$C$（$b_9$），再加一个端接电容 $C$（底极板接地）；总计 $32C$。
- 接在 LSB 阵列上极板节点与 MSB 阵列上极板节点之间的衰减（定标）电容：$C_s = \frac{32}{31}C \approx 1.032C$。
- 输出：$v_{OUT} = V_{REF}\sum_{i=0}^{9} b_i/2^{i+1}$。

推导：
- $C_s$ 与整个 LSB 侧（32C）串联后，必须等效为端接 MSB 阵列的一个单位电容 $C$（使 MSB 节点看到 $31C + C = 32C$）：$\frac{1}{C_s} + \frac{1}{32C} = \frac{1}{C}$ → $C_s = \frac{32}{31}C$。
- LSB 侧的戴维南等效（Thevenin equivalent）：电压源 $V_L = \frac{V_{REF}}{32}\sum_{i=5}^{9} b_i 2^{9-i}$ 串联 32C；经过 $C_s$ 后，在 MSB 节点处相当于电压源 $V_L$ 串联一个等效电容 $C$。
- MSB 节点的电荷守恒：$v_{OUT} = \frac{C V_{REF}\sum_{i=0}^{4} b_i 2^{4-i} + C V_L}{32C} = V_{REF}\sum_{i=0}^{4}\frac{b_i}{2^{i+1}} + \frac{V_L}{32}$，而 $V_L/32 = V_{REF}\sum_{i=5}^{9} b_i/2^{i+1}$。
- 元件值分散度为 16（单个 10 位二进制阵列则为 512），总电容约为 $64C$ 而不是 $1024C$。
