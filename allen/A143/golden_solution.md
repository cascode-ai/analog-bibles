# Golden Solution - A143

## Reference answer

$|A_{cm}|$ is of order 10⁻²: it is the sum of two nearly cancelling parts, the matched amplifier's own common-mode gain and the mirror-error term, so its value (even its sign) depends on how the 5 % mirror gain is modeled. With $g_{m4} = 1.05\,g_{m3}$ ($g_{ds4}$ kept separately), $A_{cm} \approx -0.006$ V/V (full small-signal analysis: −0.0056; parts ≈ −0.027 and ≈ +0.022). With the mirror's short-circuit current gain $g_{m4}/(g_{m3} + g_{ds3}) = 1.05$ ($g_{ds4}$ separate), $A_{cm} \approx +0.0096$. With the literal relation $i_{d4} = 1.05\,i_{d3}$ for M4's total small-signal current (no separate $g_{ds4}$), $A_{cm} \approx +0.022$. Each is correct for its stated model.

- Parameters: $g_{m1} = g_{m2} = \sqrt{2 \cdot 110\ \mu \cdot 2 \cdot 50\ \mu} = 148.3\ \mu$S, $g_{m3} = \sqrt{2 \cdot 50\ \mu \cdot 1 \cdot 50\ \mu} = 70.7\ \mu$S, $g_{ds1} = g_{ds2} = 2\ \mu$S, $g_{ds3} = g_{ds4} = 2.5\ \mu$S, $r_{ds5} = 1/(0.04 \cdot 100\ \mu) = 250$ kΩ.
- A common-mode input changes each half current by $i_1 = i_2 \approx g_{m1}v_{ic}/(1 + 2g_{m1}r_{ds5}) \approx v_{ic}/(2r_{ds5})$ = 1.97 µS·$v_{ic}$.
- Matched mirror (identical M3 and M4, $g_{m4} = g_{m3}$): by symmetry the output follows the diode node of M3, $v_{out} = v_{d1} = -i_1/(g_{m3} + g_{ds3})$, so $A_{cm,0} \approx -1/[2r_{ds5}(g_{m3} + g_{ds3})] \approx -0.027$ (exact −0.0266). This is $-g_{ds5}/(2g_{m3})$, the same as the diode-load result.
- Mirror error: M4 delivers $1.05\,i_1$ while M2 sinks $i_2 = i_1$, so a net $0.05\,i_1$ flows into $R_{out} = 1/(g_{ds2} + g_{ds4}) = 222$ kΩ: $+0.05 \cdot 1.97\ \mu \cdot 222\ \mathrm{k} \approx +0.022$ ($\approx 0.05/[2r_{ds5}(g_{ds2} + g_{ds4})]$).
- Full nodal solution (KCL at the M3 diode node, the source node and the output, with $g_{m4} = 1.05g_{m3}$): $A_{cm} = -0.0056$ (−0.0055 if $g_{ds4}$ is also scaled by 1.05). CMRR ≈ $A_d/|A_{cm}|$ = 33/0.0056 ≈ 6000 (≈ 75 dB). With this model the mirror's short-circuit current gain is $1.05\,g_{m3}/(g_{m3} + g_{ds3}) = 1.014$.
- Other readings of the 1.05, same three node equations: (b) short-circuit current gain $g_{m4}/(g_{m3} + g_{ds3}) = 1.05$, i.e. $g_{m4} = 1.05(g_{m3} + g_{ds3})$ with $g_{ds4}$ separate. A unity short-circuit gain already makes up for the diode's $g_{ds3}$, so the matched part is only ≈ −0.012 and the 5 % adds ≈ +0.022: $A_{cm} = +0.0096$. (a) $i_{d4} = 1.05\,i_{d3}$ for M4's whole small-signal current (M4 an ideal mirrored source, no $g_{ds4}$): the output sees only $r_{ds2}$, the matched part is ≈ −0.027 and the mirror error $0.05\,i_1 r_{ds2}$ ≈ +0.049: $A_{cm} = +0.0215$. This is close to the book's mismatch-only 0.02, but reached with the matched term included.

## Grading notes

The 1.05 can reasonably be modeled in the three ways of the reference, and because the result is a near cancellation each gives a different value. Accept any of them when the model is stated (or clear from the equations) and the analysis keeps the tail conductance $g_{ds5}$, the M3 diode node and the output node. +2: a full small-signal analysis giving $A_{cm}$ = −0.004 to −0.008 with $g_{m4} = 1.05\,g_{m3}$ ($g_{ds4}$ separate or also scaled), +0.008 to +0.011 with $g_{m4} = 1.05(g_{m3} + g_{ds3})$ ($g_{ds4}$ separate), or +0.019 to +0.024 with $i_{d4} = 1.05\,i_{d3}$ for M4's total current (no separate $g_{ds4}$); or a two-term analysis that shows the matched-amplifier term and the mirror-error term nearly cancelling, with values that fit the model used (e.g. $-g_{ds5}/(2g_{m3}) \approx -0.027$ and ≈ +0.022 for $g_{m4} = 1.05\,g_{m3}$). +1: both terms identified with a slip in one value (result within a factor of two of the value for the model used, same sign). 0: only the mirror-error term ≈ +0.02, with the matched amplifier's common-mode gain assumed to be zero (this is the book's answer; a full analysis under the literal relation that includes the matched term and reaches ≈ +0.022 is +2, not this case); or only the matched term ≈ −0.027. −2 (asserted as fact): the common-mode gain taken as 5 % of the differential gain (≈ 1.6), $r_{ds5}$ ignored (infinite tail resistance giving zero or a huge gain), M5 treated as diode-connected (tail current change $g_{m5}v_s$ instead of $g_{ds5}v_s$), or a mirror ratio of 0.95 used (the mismatch reversed).
