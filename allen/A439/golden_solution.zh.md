N = 11。

- 低频增益 $A_0 = 10^6/100 = 10^4$。
- 从反相输入端看进梯形网络的电阻：R 与节点 1 对地电阻（2R ∥ 2R = R）串联，即 2R；理想电流沉相当于开路。反馈电阻为 R：$\beta = 2R/(2R + R) = 2/3$，环路增益（loop gain）$= 6667$，增益误差 $1/(1 + 6667) = 1.5\times10^{-4}$。
- 最坏情况在满量程处：$(1 - 2^{-N})\cdot1.5\times10^{-4} \le 2^{-(N+1)}$ → $2^{N+1} \lesssim 6670$ → N = 11（误差 0.31 LSB；N = 12 时为 0.61 LSB）。
