求一个 n 沟道 MOS 晶体管的零偏阈值电压 $V_{T0}$ 和体效应系数（body factor）$\gamma$。该晶体管采用掺杂浓度为 $N_D = 1\times10^{19}\ \mathrm{cm^{-3}}$ 的 n⁺ 多晶硅栅，栅氧化层厚度 $t_{ox} = 200$ Å，p 型衬底掺杂浓度 $N_A = 7\times10^{16}\ \mathrm{cm^{-3}}$，氧化层-硅界面处的正电荷为 $10^{10}$ 个电荷/cm²。

利用 $V_{T0} = \phi_{MS} - 2\phi_F - Q_{b0}/C_{ox} - Q_{ss}/C_{ox}$，其中 $Q_{b0} = -\sqrt{2q\varepsilon_{Si}N_A\,2|\phi_F|}$，$\gamma = \sqrt{2q\varepsilon_{Si}N_A}/C_{ox}$，$\phi_F = \phi_F(\text{substrate}) = -\frac{kT}{q}\ln(N_A/n_i)$，$\phi_F(\text{gate}) = \frac{kT}{q}\ln(N_D/n_i)$，$\phi_{MS} = \phi_F(\text{substrate}) - \phi_F(\text{gate})$，$Q_{ss} = q\times10^{10}\ \mathrm{C/cm^2}$。常数：$kT/q = 0.0259$ V，$n_i = 1.45\times10^{10}\ \mathrm{cm^{-3}}$，$q = 1.6\times10^{-19}$ C，$\varepsilon_0 = 8.854\times10^{-14}$ F/cm，$\varepsilon_{Si} = 11.7\varepsilon_0$，$\varepsilon_{ox} = 3.9\varepsilon_0$。
