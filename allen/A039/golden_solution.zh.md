$\dfrac{1}{I_s}\dfrac{dI_s}{dT} \approx 0.165\ \mathrm{K^{-1}}$（16.5 %/°C），$\dfrac{1}{v_D}\dfrac{dv_D}{dT} \approx -2.77\times10^{-3}\ \mathrm{K^{-1}}$（≈ −2775 ppm/°C），对应于 $dv_D/dT \approx -1.94$ mV/°C。

- $\ln I_s = \ln K + 3\ln T - V_{G0}q/(kT)$ ⇒ $\dfrac{1}{I_s}\dfrac{dI_s}{dT} = \dfrac{3}{T} + \dfrac{V_{G0}}{TV_t} = 0.0100 + \dfrac{1.205}{300\times0.0259} = 0.0100 + 0.1551 = 0.165\ \mathrm{K^{-1}}$。
- 在 $I_D$ 不变时 $v_D = V_t\ln(I_D/I_s)$：$\dfrac{dv_D}{dT} = \dfrac{v_D}{T} - V_t\dfrac{1}{I_s}\dfrac{dI_s}{dT} = -\dfrac{V_{G0} - v_D}{T} - \dfrac{3V_t}{T} = -\dfrac{0.505 + 0.0777}{300} = -1.94\ \mathrm{mV/K}$。
- $\dfrac{1}{v_D}\dfrac{dv_D}{dT} = -1.94\times10^{-3}/0.7 = -2.77\times10^{-3}\ \mathrm{K^{-1}}$。
