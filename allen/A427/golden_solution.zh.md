$v_{out} = V_{OS} - D(V_{REF} - V_{OS}) = 0.0645V_{REF} - 0.9355\,D\,V_{REF}$，其中 $D = b_0/2 + b_1/4 + b_2/8 + b_3/16 = k/16$：即约 +1 LSB 的失调，加上增益减小为原来的 $1 - V_{OS}/V_{REF} = 0.9355$ 倍（增益误差 ≈ −6.5 % ≈ −1/16）。

- 反相输入端处于 $V_{OS}$；每个闭合的电阻流过 $(V_{REF} - V_{OS})/R_{i+1}$，断开的电阻不流过电流，所以 $(V_{OS} - v_{out})/R_0 = (V_{REF} - V_{OS})\sum b_i/R_{i+1}$。等效地说，$V_{OS}$ 被随码变化的噪声增益（noise gain）$1 + D$ 放大。
- 码 0000：$v_{out} = +0.0645V_{REF}$（+1.03 LSB，与信号符号相反）；码 1000：−0.403 $V_{REF}$；码 1111：−0.8125 $V_{REF}$（理想值为 −0.9375 $V_{REF}$）。台阶为 0.9355 LSB；以 LSB（$V_{REF}/16$）为单位，$v_{out} = -(29k - 32)/31$。
- 特性仍然是线性、单调的；总误差从 0000 处的 1.03 LSB 增大到 1111 处的恰好 2 LSB（$V_{OS}\cdot31/16 = 0.125V_{REF}$）。
