# 详细步骤 - A190

由于放大器的两个输入端都处于 0 V，电阻电流可以直接由 $v_s$ 和 $v_o$ 写出。在 n 输入端和不接负载的输出节点列基尔霍夫电流定律（KCL）方程，结合 $i_o=A_i(i_p-i_n)$，解出 $v_o/v_s$。

### 第 1 步 — 输入端与输出端的电流

n 输入端为 0 V，因此流过 $R_1$ 的电流（从信号源流向 n 输入端，即 $i_1$ 的方向）和流过 $R_2$ 的电流（从 $v_o$ 流向 n 输入端，即 $i_2$ 的方向）为

$$
i_1=\frac{v_s}{R_1},\qquad i_2=\frac{v_o}{R_2}.
$$

二者都流入 n 输入端，故 $i_n=i_1+i_2$。p 输入端接地且没有其他驱动，故 $i_p=0$。

输出节点只连接放大器输出端和 $R_2$。取 $i_o$ 以流出放大器为正，该节点的 KCL 给出 $i_o=i_2$，即 $v_o=R_2\,i_o$。

### 第 2 步 — 求解环路

代入放大器关系式：

$$
i_o=A_i(i_p-i_n)=-A_i\left(\frac{v_s}{R_1}+i_o\right)
\quad\Rightarrow\quad
i_o=-\frac{A_i}{1+A_i}\,\frac{v_s}{R_1}.
$$

因此

$$
\frac{v_o}{v_s}=-\frac{R_2}{R_1}\left(\frac{A_i}{1+A_i}\right)=-\frac{R_2/R_1}{1+1/A_i}.
$$

### 第 3 步 — 与同相接法比较

其幅值以及对 $A_i$ 的依赖关系与 $v_{out}=\frac{R_2}{R_1}\frac{A_i}{1+A_i}v_{in}$ 相同：$A_i\to\infty$ 时增益趋于 $R_2/R_1$，相对误差为 $1/(1+A_i)$；由于两种情况都是负反馈，单极点的 $A_i$ 给出相同的闭环带宽 $\omega_A(1+A_o)$，与 $R_2/R_1$ 无关。唯一的区别是符号：这里信号与反馈电流一起进入 n（反相）输入端，因此该级是反相的。
