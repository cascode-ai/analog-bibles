[图 1] 和 [图 2] 给出了增益增强型折叠式共源共栅（folded cascode）运放中所用两个增益增强放大器的晶体管级实现。在 [图 1]（上方放大器）中，n 沟道差分对 M1、M2 以 M3 为尾电流沉（tail current sink），M2 的栅极固定在 $V_{DD} - V_{SD}(\mathrm{sat})$，M2 的漏极接 $V_{DD}$；M1 的漏极折叠到 p 沟道共源共栅管 M5（由 p 沟道电流源 M4 偏置），输出节点以 n 沟道电流源 M6 为负载。在 [图 2]（下方放大器）中，p 沟道差分对 M1、M2 以 M3 为尾电流源，M2 的栅极固定在 $V_{DS}(\mathrm{sat})$，M2 的漏极接地；M1 的漏极折叠到 n 沟道共源共栅管 M5（由 n 沟道电流沉 M4 偏置），输出以 p 沟道电流源 M6 为负载。用小信号分析检验增益估计式 $A_v(\mathrm{upper}) \approx -0.5g_{m1}r_{ds6} = -0.5g_{mN}r_{dsN}$ 和 $A_v(\mathrm{lower}) \approx -0.5g_{m1}r_{ds6} = -0.5g_{mP}r_{dsP}$ 的有效性，其中 $g_{mN}, r_{dsN}$（$g_{mP}, r_{dsP}$）为 n 沟道（p 沟道）晶体管的参数。
