$v_{OUT} = k_0[b_0 + k_1(b_1 + k_2b_2)]V_{REF} = \left(\frac{7}{16}b_0 + \frac{5}{16}b_1 + \frac{3}{16}b_2\right)V_{REF}$。
INL：+1 LSB 和 −0.5 LSB；DNL：+0.5 LSB 和 −1.5 LSB；该 DAC 不单调。

特性（LSB $= V_{REF}/8 = 2/16\,V_{REF}$），码 000 … 111：
- 实际值：0, 3/16, 5/16, 8/16, 7/16, 10/16, 12/16, 15/16 $V_{REF}$。
- 理想值（$b_0/2 + b_1/4 + b_2/8$）：0, 2/16, 4/16, 6/16, 8/16, 10/16, 12/16, 14/16 $V_{REF}$。
- INL（LSB）：0, +0.5, +0.5, +1, −0.5, 0, 0, +0.5 → $+INL = +1$（码 011），$-INL = -0.5$（码 100）。
- 台阶（LSB）：1.5, 1, 1.5, −0.5, 1.5, 1, 1.5 → DNL +0.5, 0, +0.5, −1.5, +0.5, 0, +0.5；$+DNL = +0.5$，$-DNL = -1.5$，出现在 011→100 处。输出在该处下降（8/16 → 7/16），因此该 DAC 不单调。
