[Fig. 1] shows the differential input stage of a comparator with internal hysteresis (M3, M4 diode-connected p-channel loads; cross-coupled M6–M7 positive feedback). All channel lengths are 1 µm; $W_1 = W_2 = 10\ \mu$m, $W_6 = W_7 = 10\ \mu$m, $W_3 = W_4 = 2\ \mu$m; tail current $i_5 = 20\ \mu$A; $V_{DD} = 2.5$ V, $V_{SS} = -2.5$ V; the gate of M1 is grounded and the input is applied to the gate of M2 ($K'_N = 110\ \mu\mathrm{A/V^2}$, $V_{TN} = 0.7$ V, $K'_P = 50\ \mu\mathrm{A/V^2}$, $V_{TP} = -0.7$ V).

A hand analysis of the switching points proceeded as follows. For the positive trip point (input rising from a negative value), the circuit switches when the current in M2 equals the current that M6 sources: $i_6 = [(W/L)_6/(W/L)_3]\,i_3 = 5i_3$, $i_3 = i_1 = i_5/(1+5) = 3.33\ \mu$A, $i_2 = i_5-i_1 = 16.67\ \mu$A, $v_{GS1} = \left(\dfrac{2\cdot3.33}{(5)(110)}\right)^{1/2}+0.7 = 0.81$ V, $v_{GS2} = \left(\dfrac{2\cdot16.67}{(5)(110)}\right)^{1/2}+0.7 = 0.946$ V, so $V_{TRP}^+ \approx v_{GS2}-v_{GS1} = 0.136$ V; by the same analysis $V_{TRP}^- \approx -0.136$ V.
