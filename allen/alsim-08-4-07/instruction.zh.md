[图 1] 给出了一个带内部迟滞（hysteresis）的比较器的差分输入级（M3、M4 为二极管连接的 p 沟道负载；交叉耦合的 M6–M7 提供正反馈）。所有沟道长度均为 1 µm；$W_1 = W_2 = 10\ \mu$m，$W_6 = W_7 = 10\ \mu$m，$W_3 = W_4 = 2\ \mu$m；尾电流 $i_5 = 20\ \mu$A；$V_{DD} = 2.5$ V，$V_{SS} = -2.5$ V；M1 的栅极接地，输入加在 M2 的栅极（$K'_N = 110\ \mu\mathrm{A/V^2}$，$V_{TN} = 0.7$ V，$K'_P = 50\ \mu\mathrm{A/V^2}$，$V_{TP} = -0.7$ V）。

对开关点的手工分析如下。对于正翻转点（trip point），即输入从负值上升的情况，当 M2 中的电流等于 M6 所提供的电流时电路翻转：$i_6 = [(W/L)_6/(W/L)_3]\,i_3 = 5i_3$，$i_3 = i_1 = i_5/(1+5) = 3.33\ \mu$A，$i_2 = i_5-i_1 = 16.67\ \mu$A，$v_{GS1} = \left(\dfrac{2\cdot3.33}{(5)(110)}\right)^{1/2}+0.7 = 0.81$ V，$v_{GS2} = \left(\dfrac{2\cdot16.67}{(5)(110)}\right)^{1/2}+0.7 = 0.946$ V，因此 $V_{TRP}^+ \approx v_{GS2}-v_{GS1} = 0.136$ V；同理可得 $V_{TRP}^- \approx -0.136$ V。该电路的 SPICE 仿真给出了 [图 2] 所示的 $v_{o2}$ 随 $v_{in}$ 变化的传输特性。
