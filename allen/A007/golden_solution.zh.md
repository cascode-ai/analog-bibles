$\dfrac{v_2}{v_1} = \dfrac{g_mR_L}{1 + g_mR_L}$，$\dfrac{v_1}{i_1} = R_L + \dfrac{1}{g_m}$。

- 输入端只与受控源相连，因此输入电流就是受控源电流：$i_1 = g_m(v_1 - v_2)$。
- 该电流全部流入 $R_L$：$v_2 = i_1R_L = g_mR_L(v_1 - v_2)$，因此 $v_2(1 + g_mR_L) = g_mR_Lv_1$。
- $v_1 = v_2 + i_1/g_m = i_1R_L + i_1/g_m$，因此 $v_1/i_1 = R_L + 1/g_m$。
（这是串联了一个跨导的跟随器的小信号模型：当 $g_mR_L \gg 1$ 时增益略小于 1，输入电阻为 $R_L + 1/g_m$。）
