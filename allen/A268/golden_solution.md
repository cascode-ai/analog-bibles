# Golden Solution - A268

## Reference answer

One design (all L = 2 µm): M1 = M2 = 2/2, M3 = M4 = 2/2, M6 = 8/2, M8 = 2/2, M5 ≈ 2.9/2, M7 ≈ 5.7/2 (µm/µm); $C_c$ ≈ 11.8 pF; $R_z = 1/g_{m6}$ = 5 kΩ; $A_v \approx 1.5\times10^4$; $C_L \lesssim$ 18 pF for a 60° phase margin (≈ 32 pF for 45°); SR ≈ 4.2 V/µs.

- Bias: with M8 = 2/2 ($S_8 = 1$), $I_8 = (5\ \mathrm V - V_{GS8})/100\ \mathrm{k\Omega}$ and $V_{GS8} = 0.7 + \sqrt{2I_8/110\ \mu}$ give $I_8 = 35.0$ µA ($V_{GS8} = 1.50$ V). (Note $I_8 < 50$ µA for any M8, so the aspect ratios must satisfy $S_5/S_8 = 50/I_8 > 1$ and $S_7/S_8 = 100/I_8$; with equal L this means M5 and M7 wider than M8, but e.g. M5 = 2/2 with a longer M8 = 2/3 is equally valid.) $S_5 = 50/35 = 1.43$ (W ≈ 2.9 µm), $S_7 = 100/35 = 2.86$ (W ≈ 5.7 µm).
- Input pair: minimum size $S_1 = S_2 = 1$: $g_{m1} = \sqrt{2(110\ \mu)(1)(25\ \mu)} = 74.2\ \mu$S. Mirror M3 = M4 minimum ($S = 1$, $V_{SG3} = 0.7 + 1.0 = 1.7$ V).
- Output: for $V_{SG6} = V_{SG4}$ (no systematic offset) $S_6 = S_4 I_6/I_4 = 4$ (W = 8 µm): $g_{m6} = \sqrt{2(50\ \mu)(4)(100\ \mu)} = 200\ \mu$S.
- Gain: $A_v = \dfrac{g_{m1}g_{m6}}{(g_{ds2} + g_{ds4})(g_{ds6} + g_{ds7})} = \dfrac{(74.2\ \mu)(200\ \mu)}{(0.5\ \mu)(2\ \mu)} = 1.48\times10^4 \ge 4000$ (even $S_6 = 1$ would give 7.4 × 10³; with minimum devices the gain specification is exceeded).
- $C_c = g_{m1}/GB = 74.2\ \mu\mathrm S/(2\pi \times 10^6) = 11.8$ pF; $R_z = 1/g_{m6} = 5$ kΩ moves the RHP zero to infinity (a slightly larger $R_z$ puts it in the LHP).
- Load: with the zero removed, $\Phi_M \approx 90° - \arctan(GB/|p_2|)$, $|p_2| = g_{m6}/C_L$. For $\Phi_M \ge 60°$: $|p_2| \ge 1.73\,GB$ → $C_L \le \dfrac{200\ \mu}{1.73 \times 2\pi \times 10^6} = 18.4$ pF (for 45°: $C_L \le g_{m6}/GB = 31.8$ pF).
- Slew rate: $SR = I_5/C_c = 50\ \mu\mathrm A/11.8\ \mathrm{pF} = 4.2$ V/µs (this is the internal, $C_c$-limited value; for falling edges into a large load the output stage limits it to roughly $I_7/(C_L + C_c)$ ≈ 3.3 V/µs at 18 pF — the cruder $(I_7 - I_5)/C_L$ ≈ 2.7 V/µs is a pessimistic bound; a level-1 ngspice follower with these sizes gives a rising slope of 4.2 V/µs and a peak falling slope of 4.2 / 3.7 / 2.4 V/µs for $C_L$ = 5 / 18.4 / 40 pF).
- Ranges: ICMR ≈ −0.33 V to +1.5 V; output ≈ −1.70 V to +1.5 V; all devices saturated at zero common-mode input.

## Grading notes

Design problem: accept any design with W, L ≥ 2 µm, near-minimum devices, gain ≥ 4000 and correct supporting calculations. Key results: $I_8$ < 50 µA so the mirror ratios $S_5/S_8 = 50/I_8$ and $S_7/S_8 = 100/I_8$ exceed 1 (any W/L split realizing them, e.g. a longer M8 instead of wider M5/M7, is fine); $C_c = g_{m1}/(2\pi \cdot 1\ \mathrm{MHz})$ ≈ 11.8 pF for 2/2 input devices; $R_z = 1/g_{m6}$ (or larger, with the zero moved into the LHP/onto $p_2$); maximum $C_L = g_{m6}/(1.73 \cdot 2\pi \cdot 1\ \mathrm{MHz})$ for 60° (or $g_{m6}/GB$ for 45°, or the conservative $|p_2| \ge 2.2\,GB$ rule giving $g_{m6}/(2.2 \cdot 2\pi \cdot 1\ \mathrm{MHz})$ ≈ 14.5 pF here; any stated criterion applied correctly counts); SR $= I_5/C_c$. +2: all of these consistent with the chosen sizes (±5 %). +1: one item wrong or missing. 0: about half right. Using GB in Hz as if in rad/s ($C_c$ ≈ 74 pF, $C_L$ ≈ 140 pF, SR ≈ 0.67 V/µs) is a units slip: the affected parts count as wrong, overall at most 0. A design sized for exactly $A_v = 4000$ (some devices longer than 2 µm, W/L < 1) is acceptable for the sizing item if it keeps $V_{SG6} = V_{SG4}$, i.e. $S_6/S_4 = 2S_7/S_5$, and all devices saturated; a sizing that ignores this balance condition loses the sizing item only — $C_c$, $R_z$, $C_L$ and SR computed consistently from its own $g_{m1}$ and $g_{m6}$ still count: if it merely omits the check (or flags the sizes as first-order), that is +1; if it explicitly asserts that the unbalanced sizes give zero offset / $V_{out} = 0$ / $I_6 = 100$ µA, that is a critical false claim confined to the sizing part, so at most 0. Either form of the loaded falling-edge slew limit, $I_7/(C_L + C_c)$ or $(I_7 - I_5)/C_L$, is acceptable as a side remark when $I_5/C_c$ is given as the slew rate. Taking SR $= I_7/C_L$ while ignoring the smaller $I_5/C_c$ is an error in the SR item only. −2 (asserted as fact): $g_m = \sqrt{K'SI}$ (missing factor 2) used throughout, M5 = M8 claimed to give 50 µA, $R_z$ chosen so that the RHP zero remains, or the gain computed with $r_{ds}$ values of the wrong currents.
