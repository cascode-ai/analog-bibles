一种设计（所有 L = 2 µm）：M1 = M2 = 2/2，M3 = M4 = 2/2，M6 = 8/2，M8 = 2/2，M5 ≈ 2.9/2，M7 ≈ 5.7/2（µm/µm）；$C_c$ ≈ 11.8 pF；$R_z = 1/g_{m6}$ = 5 kΩ；$A_v \approx 1.5\times10^4$；60° 相位裕度下 $C_L \lesssim$ 18 pF（45° 时 ≈ 32 pF）；SR ≈ 4.2 V/µs。

- 偏置：取 M8 = 2/2（$S_8 = 1$），由 $I_8 = (5\ \mathrm V - V_{GS8})/100\ \mathrm{k\Omega}$ 和 $V_{GS8} = 0.7 + \sqrt{2I_8/110\ \mu}$ 得 $I_8 = 35.0$ µA（$V_{GS8} = 1.50$ V）。（注意，无论 M8 取何尺寸，$I_8 < 50$ µA，因此宽长比必须满足 $S_5/S_8 = 50/I_8 > 1$ 和 $S_7/S_8 = 100/I_8$；在 L 相同时，这意味着 M5 和 M7 比 M8 宽，但例如 M5 = 2/2 配合更长的 M8 = 2/3 也同样可行。）$S_5 = 50/35 = 1.43$（W ≈ 2.9 µm），$S_7 = 100/35 = 2.86$（W ≈ 5.7 µm）。
- 输入对管：取最小尺寸 $S_1 = S_2 = 1$：$g_{m1} = \sqrt{2(110\ \mu)(1)(25\ \mu)} = 74.2\ \mu$S。镜像管 M3 = M4 取最小尺寸（$S = 1$，$V_{SG3} = 0.7 + 1.0 = 1.7$ V）。
- 输出级：为使 $V_{SG6} = V_{SG4}$（无系统失调），$S_6 = S_4 I_6/I_4 = 4$（W = 8 µm）：$g_{m6} = \sqrt{2(50\ \mu)(4)(100\ \mu)} = 200\ \mu$S。
- 增益：$A_v = \dfrac{g_{m1}g_{m6}}{(g_{ds2} + g_{ds4})(g_{ds6} + g_{ds7})} = \dfrac{(74.2\ \mu)(200\ \mu)}{(0.5\ \mu)(2\ \mu)} = 1.48\times10^4 \ge 4000$（即使 $S_6 = 1$ 也能得到 7.4 × 10³；采用最小器件时增益超过指标）。
- $C_c = g_{m1}/GB = 74.2\ \mu\mathrm S/(2\pi \times 10^6) = 11.8$ pF；$R_z = 1/g_{m6} = 5$ kΩ 把右半平面零点移到无穷远处（$R_z$ 稍大则零点进入左半平面）。
- 负载：去掉零点后，$\Phi_M \approx 90° - \arctan(GB/|p_2|)$，$|p_2| = g_{m6}/C_L$。要求 $\Phi_M \ge 60°$：$|p_2| \ge 1.73\,GB$ → $C_L \le \dfrac{200\ \mu}{1.73 \times 2\pi \times 10^6} = 18.4$ pF（45° 时：$C_L \le g_{m6}/GB = 31.8$ pF）。
- 压摆率：$SR = I_5/C_c = 50\ \mu\mathrm A/11.8\ \mathrm{pF} = 4.2$ V/µs（这是由 $C_c$ 限制的内部值；驱动大负载的下降沿时，输出级将其限制为约 $I_7/(C_L + C_c)$，18 pF 时 ≈ 3.3 V/µs——较粗略的 $(I_7 - I_5)/C_L$ ≈ 2.7 V/µs 是一个偏悲观的界限；用这些尺寸做 level-1 ngspice 跟随器仿真，上升斜率为 4.2 V/µs，$C_L$ = 5 / 18.4 / 40 pF 时下降斜率峰值为 4.2 / 3.7 / 2.4 V/µs）。
- 范围：ICMR ≈ −0.33 V 至 +1.5 V；输出 ≈ −1.70 V 至 +1.5 V；零共模输入时所有器件均处于饱和区。
