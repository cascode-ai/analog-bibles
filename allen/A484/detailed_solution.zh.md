# 详细步骤 - A484

各开关的作用与电容匹配时相同，但 $C_1\ne C_2$ 时，每次电荷分享（$S_1$）得到的是按电容加权的平均值，而不是简单平均。对整个序列应用加权规则。

### 第 1 步 — 电荷分享规则

$S_2$ 使 $v_{C1}=V_{REF}$，$S_3$ 使 $v_{C1}=0$，$S_4$ 使 $v_{C2}=0$。闭合 $S_1$ 时总电荷守恒，因此在 $C_1=1.05C_2$ 时

$$
v_{C1}=v_{C2}=\frac{C_1v_{C1}+C_2v_{C2}}{C_1+C_2}=\frac{1.05\,v_{C1}+v_{C2}}{2.05}.
$$

### 第 2 步 — 开关序列

电压以 $V_{REF}$ 为单位：

| 闭合的开关 | $v_{C1}$ | $v_{C2}$ | 计算 |
|---|---|---|---|
| $S_4$, $S_3$, $S_1$ | 0 | 0 | |
| $S_2$ | 1 | 0 | |
| $S_1$ | 0.5122 | 0.5122 | $1.05/2.05$ |
| $S_3$ | 0 | 0.5122 | |
| $S_1$ | 0.2499 | 0.2499 | $0.5122/2.05$ |
| $S_2$ | 1 | 0.2499 | |
| $S_1$ | 0.6341 | 0.6341 | $(1.05+0.2499)/2.05$ |

### 第 3 步 — 结果

$$
v_{C1}=v_{C2}\approx0.634\,V_{REF}.
$$

该序列（码字 1010）的理想值为 $0.625V_{REF}$，因此 5% 的失配使输出升高约 $0.009V_{REF}$，约为 4 位转换器的 0.15 LSB。误差的原因是：每次重新分配时，新装入的位以 $C_1/(C_1+C_2)=0.512$ 加权，原有结果以 $0.488$ 加权，而不是各为 $0.5$。
