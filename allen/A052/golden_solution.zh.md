截止区：$C_{GB}$ ≈ 13.05 fF，$C_{GS} = C_{GD}$ = 1.1 fF。饱和区：$C_{GB}$ = 0.70 fF，$C_{GS}$ ≈ 9.33 fF，$C_{GD}$ = 1.1 fF。非饱和区：$C_{GB}$ = 0.70 fF，$C_{GS} = C_{GD}$ ≈ 7.28 fF。

- 基本组成部分：栅到沟道（栅氧）电容 $C_2 = C_{ox}WL = 24.7\times10^{-4}\times5\times10^{-12}$ F = 12.35 fF；交叠电容 $C_1 = C_3$ = CGSO·W = CGDO·W = 1.1 fF；栅-衬底交叠电容 $2C_5$ = CGBO·L = 0.70 fF。
- 截止区（无沟道）：栅极通过栅氧直接面对衬底：$C_{GB} = C_2 + 2C_5$ = 13.05 fF；$C_{GS} = C_{GD}$ = 仅交叠电容 = 1.1 fF。
- 饱和区：反型沟道屏蔽了衬底，并在漏端夹断；$C_2$ 中约 2/3 属于源极：$C_{GS} = 1.1 + \tfrac23(12.35)$ = 9.33 fF（取 0.67 时为 9.37 fF），$C_{GD}$ = 1.1 fF，$C_{GB}$ = 0.70 fF。
- 非饱和区：沟道从源极延伸到漏极，$C_2$ 平均分配：$C_{GS} = C_{GD} = 1.1 + 6.175$ = 7.28 fF，$C_{GB}$ = 0.70 fF。
