PSRR⁺(0) ≈ 1.44×10⁴（83 dB），零点位于 −7.1 MHz 和 −12.0 MHz，极点位于 −494 Hz；PSRR⁻(0) ≈ 1.80×10⁴（85 dB），两个零点相同，极点位于 −65 kHz 和 ≈ −660 MHz。

- 偏置：$V_{SG9} + V_{GS8} = 3$ V，即 $0.7 + \sqrt{2I_8/50\,\mu} + 0.7 + \sqrt{2I_8/110\,\mu} = 3$ → $0.335\sqrt{I_8[\mu A]} = 1.6$ → $I_8 \approx 22.8\ \mu$A（若计入 $1+\lambda V_{DS}$ 则为 24.5 µA）。镜像比：$I_5 = 2I_8 = 45.7\ \mu$A，$I_7 = 10I_8 = 228\ \mu$A。
- $g_{mI} = g_{m1} = \sqrt{2(110\,\mu)(10)(22.8\,\mu)} = 224\ \mu$S；$g_{mII} = g_{m6} = \sqrt{2(50\,\mu)(100)(228\,\mu)} = 1.51$ mS；$G_I = g_{ds2}+g_{ds4} = (0.04+0.05)(22.8\ \mu\mathrm{A}) = 2.06\ \mu$S；$g_{ds6} = 11.4\ \mu$S；$g_{ds7} = 9.13\ \mu$S；（$A_v(0) \approx 8.0\times10^3$）。
- PSRR⁺ $= \dfrac{g_{mI}g_{mII}}{G_Ig_{ds6}}\dfrac{(1+sC_c/g_{mI})(1+sC_{II}/g_{mII})}{1+s\,g_{mII}C_c/(G_Ig_{ds6})}$：直流值 $= 224\,\mu\cdot1.51\,\mathrm{m}/(2.06\,\mu\cdot11.4\,\mu) \approx 1.44\times10^4$；零点位于 $-g_{m1}/C_c = -44.8$ Mrad/s（−7.1 MHz）和 $-g_{m6}/C_L = -75.6$ Mrad/s（−12.0 MHz）；极点位于 $-G_Ig_{ds6}/(g_{m6}C_c) = -3.1$ krad/s（−494 Hz）。
- PSRR⁻ $= \dfrac{g_{mI}g_{mII}}{G_Ig_{ds7}}\dfrac{(1+sC_c/g_{mI})(1+sC_{II}/g_{mII})}{(1+sC_{gd7}/g_{ds7})(1+sC_c/G_I)}$：直流值 ≈ 1.80×10⁴；零点相同；极点位于 $-G_I/C_c = -4.1\times10^5$ rad/s（−65 kHz）和 $-g_{ds7}/C_{gd7} = -9.13\,\mu/2.2\,\mathrm{fF} = -4.2\times10^9$ rad/s（≈ −660 MHz，可忽略）。
- 这些形式沿用教材中单位增益跟随器的测量方法，PSRR ≈ $v_{supply}/v_{out}$ = $(1+A_v)/A_{supply}$；两个零点就是跟随器的闭环极点（精确求解时它们构成一对复数 ≈ $(-3.3 \pm j4.8)\times10^7$ rad/s，$|z| \approx \sqrt{g_{m1}g_{m6}/(C_cC_L)} = 5.8\times10^7$ rad/s，ζ ≈ 0.57）。若改用开环比值 PSRR = $A_v/A_{supply}$，则 $A_v$ 与 $A_{supply}$ 分母相同，运放极点相互抵消，零点则由 $A_v$ 的右半平面零点代替：PSRR⁺ 的极点位于 −3.1 krad/s（−494 Hz），零点位于 $+g_{m6}/C_c = +3.02\times10^8$ rad/s（48 MHz）；PSRR⁻ 的极点位于 −4.1×10⁵ rad/s（−65 kHz）和 −4.2×10⁹ rad/s，右半平面零点相同。两种方法得到的低频值和极点相同。
- 计入尾电流管 M5 的输出电导（题目并未排除）：在这个按比例匹配的设计中，经 $g_{ds5}$ 注入、由第一级和 M6 镜像到输出的 $V_{SS}$ 纹波几乎抵消了 $g_{ds7}$ 的注入，因此完整的小信号分析给出 PSRR⁻(0) ≈ 110–125 dB（按这些数值 ≈ 124 dB），其唯一的低频极点下移到 ≈ 0.75–3 kHz；在几百千赫以上，曲线与上述相同。
- 注：在实际电路中，$I_8$ 随 $V_{DD}-V_{SS}$ 变化（$\Delta V_{GS8} \approx 0.40\,\Delta(V_{DD}-V_{SS})$），因此 M5 和 M7 的电流跟随电源变化；由于设计是按比例匹配的（$S_6/S_4 = 2S_7/S_5$），这些电流同比例变化，它们在输出端的影响大部分相互抵消，这就是上面采用固定偏置估算的原因。
