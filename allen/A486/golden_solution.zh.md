理想值：$v_{OUT} = 0.6016$ V（$= 77/128$ V）。衰减因子为 0.55 时：$v_{OUT} \approx 0.557$ V。

推导：数字字通过所有各级之后，$v_{OUT} = V_{REF}\sum_{i=0}^{N-1} b_i k^i$，其中 $k$ 为衰减因子（第一级前面的因子乘的是 0）。
- 各位 1,0,1,0,0,1,1,0 → $b_i$ = +1, −1, +1, −1, −1, +1, +1, −1。
- $k = 0.5$：$1 - 0.5 + 0.25 - 0.125 - 0.0625 + 0.03125 + 0.015625 - 0.0078125 = 0.6015625$ V。
- $k = 0.55$：$1 - 0.55 + 0.3025 - 0.16638 - 0.09151 + 0.05033 + 0.02768 - 0.01522 = 0.5574$ V（误差为 −0.044 V，约 −2.8 LSB，因为该 8 位转换器相邻输出电平的间隔为 2/128 V = 15.6 mV）。
