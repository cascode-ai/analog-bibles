# 详细步骤 - A095

当 M2 在所有影响电流的方面（有效 $W/L$、工艺梯度、方向和寄生电阻）都恰好是 M1 的两倍时，1:2 电流镜的电流增益才准确。逐一检查各版图的单元匹配、共质心、方向一致性，以及能否正确连接。

### 第 1 步 — 限制比值精度的因素

理想增益为 $(W/L)_2/(W/L)_1=2$。实际中：

- 边缘效应（光刻和刻蚀偏差 $\Delta W$、横向扩散 $\Delta L$）不随宽度成比例变化，因此宽度不同的两个器件有 $(W_2-\Delta W)/(W_1-\Delta W)\ne W_2/W_1$；除非器件是彼此的副本，接触电阻和源/漏电阻也不同；
- 版图上 $K'$、$V_T$ 或氧化层厚度的线性梯度，会使放在不同位置的器件产生偏移；
- 与方向有关的效应（x、y 方向光刻偏差不同、倾斜注入阴影、与应力有关的迁移率）对旋转放置的器件影响不同。

由相同单位器件构成、方向一致并按共质心排列的比值，可以同时消除这三类误差。

### 第 2 步 — 各版图的比较

| 版图 | 结构 | 单元匹配 | 方向相同 | 共质心 | 结论 |
|---|---|---|---|---|---|
| 1 | 一个 5/1 器件和一个 10/1 器件 | 否：比值 $(10-\Delta W)/(5-\Delta W)\ne2$ | 是 | 否 | 受边缘效应和梯度影响 |
| 2 | M2 由两个 5/1 单元构成；M1 旋转 90° | 是 | 否 | 是 | M1 与 M2 的方向效应不同 |
| 3 | 三个栅指共用一个扩散区 | 是 | 是 | 是 | M1 居中时无法接成 1:2 电流镜（共用区迫使 M1 两端都接 GRD） |
| 4 | 三个独立且相同的 5/1 单元，M2A–M1–M2B | 是 | 是 | 是 | 最准确 |

### 第 3 步 — 版图 4 最准确的原因

在版图 4 中，M2A、M1 和 M2B 是形状、接触孔、方向和周边环境都相同的 5/1 晶体管，因此每种边缘效应、接触电阻和寄生参数都严格按单元数目成比例，比值恰好为 2。M2A–M1–M2B 的排列关于 M1 对称，M2 的质心与 M1 重合，沿该行的线性梯度在一阶近似下被抵消：若某参数按 $p_0+gx$ 变化，M1 位于 $x=0$，M2 的两半位于 $\pm d$，则 M2 的平均值为 $p_0=p_{M1}$。因此版图 4 的电流增益最准确。
