$R_{out} = 2R \,\|\, 2r_{ds} = \dfrac{2Rr_{ds}}{R + r_{ds}}$；当 $g_m > g_{ds} > 1/R$（$R \gg r_{ds}$）时，$R_{out} \approx 2r_{ds}$。分压器的反馈恰好抵消了共源共栅的倍增作用。

- 选受控源 $g_{m2}v_{gs2}$ 作为 $k$。令 $g_{m2} = 0$：$R_{out}(k=0) = 2R \,\|\, (r_{ds1} + r_{ds2})$（由于 $v_{gs1} = 0$，M1 的 $g_m$ 不起作用）。
- 端口短路（$v_{out} = 0$）：M2 的栅极为交流地，注入电流 $g_{m2}v_c'$ 流入节点 X（M2 的源极），该节点对地看到的电阻为 $r_{ds1}\|r_{ds2}$，因此 $v_c = -v_X$，$RR_{short} = g_{m2}(r_{ds1}\|r_{ds2}) = g_mr_{ds}/2$。
- 端口开路（$i_{out} = 0$）：在输出节点和 X 处列 KCL，得 $v_{out} = -2Rv_X/r_{ds1}$ 和 $v_{gs2} = v_{out}/2 - v_X = -v_X(1 + R/r_{ds1})$，其中 $v_X = g_{m2}v_c'\,r_{ds1}r_{ds2}/(r_{ds1} + r_{ds2} + 2R)$。因此 $RR_{open} = g_{m2}r_{ds2}(r_{ds1} + R)/(r_{ds1} + r_{ds2} + 2R)$，对相同器件等于 $g_mr_{ds}/2$。
- 一般形式：$R_{out} = [2R\|(r_{ds1} + r_{ds2})]\,\dfrac{1 + g_{m2}r_{ds1}r_{ds2}/(r_{ds1} + r_{ds2})}{1 + g_{m2}r_{ds2}(r_{ds1} + R)/(r_{ds1} + r_{ds2} + 2R)}$。对相同器件，两个回归比相等，因此 $R_{out} = 2R\|2r_{ds}$，与 $g_m$ 无关。当 $R \gg r_{ds}$ 时：$R_{out} \approx 2r_{ds}$。
- $k$ 的另一种选法：分压器增益 $v_{g2} = k_fv_{out}$（$k_f = 1/2$）。$k_f = 0$ 时电路是普通的共源共栅结构，$R_{out}(0) = 2R\,\|\,(2r_{ds} + g_mr_{ds}^2)$；端口短路时 $v_{out} = 0$，因此 $RR_{short} = 0$；端口开路时 $RR_{open} = R_{out}(0)\,g_mg_{ds}/[2(g_m + 2g_{ds})]$，同样得到 $R_{out}(0)/(1 + RR_{open}) = 2R\,\|\,2r_{ds}$。
- （直接分析：$v_{out}$ 的一半到达 M2 的栅极，抵消了共源共栅作用，因此晶体管叠层看起来就是 $r_{ds1} + r_{ds2}$。）
