Five differential-output op amps are shown: [Fig. 1] a two-stage Miller op amp with current-source loads (compensation capacitors $C_c$); [Fig. 2] a two-stage Miller op amp with push–pull output stages (compensation capacitors $C_c$); [Fig. 3] a folded-cascode (class A) op amp; [Fig. 4] a class B, folded-cascode, push–pull op amp; [Fig. 5] a class AB op amp with a cross-coupled differential input stage and cascoded outputs. Each output drives a load capacitance $C_L$ to ground. Compare them from the viewpoint of slew rate, expressing each in terms of the input-stage bias current $I_{SS}$, $C_c$ and $C_L$, assuming that all input differential currents are identical (all input stages provide the same current $I_{SS}$).
