# Golden Solution - A332

## Reference answer

Differential-output slew rate: [Fig. 1] $I_{SS}/C_c$; [Fig. 2] $I_{SS}/C_c$; [Fig. 3] $I_{SS}/C_L$; [Fig. 4] $I_{SS}/C_L$ (each single-ended output slews at half these values); [Fig. 5] $2I_{SS}/C_L$ ($I_{SS}/C_L$ per output) if its maximum differential current is taken as $I_{SS}$ with 1:1 mirrors, and in fact not limited by $I_{SS}$ at all (class AB input). It is clearly faster than [Fig. 3]/[Fig. 4]; against the Miller designs the normalized values compare as $2/C_L$ vs. $1/C_c$ (so [Fig. 5] wins in that model only for $C_L < 2C_c$), but its large-signal current is not bounded by the quiescent $I_{SS}$, so it has the highest slew capability.

- [Fig. 1], [Fig. 2]: the first stage can deliver at most ±$I_{SS}/2$ into each compensation capacitor (current-source loads carry $I_{SS}/2$; the input device carries 0 or $I_{SS}$), so each output slews at $I_{SS}/(2C_c)$ and the differential output at $I_{SS}/C_c$ (provided the second stage can supply $C_L$; in [Fig. 1] the sink current $J$ of each output (M8/M9) must exceed $(C_c + C_L)\,I_{SS}/(2C_c)$, while the push–pull stages of [Fig. 2] can drive $C_L$ freely). If $J$ is smaller, the falling edge of each [Fig. 1] output is load-limited: M6/M7 cut off, their gates clamp, and the edge falls at ≈ $J/(C_c + C_L)$ (≈ $(J - I_{SS}/2)/C_L$ before the clamp). Level-1 check (single-ended Miller follower, tail 20 µA, $C_c$ = 2 pF, $C_L$ = 10 pF): rise 10 V/µs = $I_5/C_c$; fall 3.3, 6.3 and 9.9 V/µs for $J$ = 40, 80 and 150 µA (needed: 120 µA), i.e. $J/(C_c + C_L)$ when $J$ is small and $I_5/C_c$ once $J$ is sufficient.
- [Fig. 3]: the folded structure steers the input current directly into the load capacitors: each output gets at most ±$I_{SS}/2$, giving $I_{SS}/C_L$ differentially (with the folding sources larger than $I_{SS}$ so the cascodes never cut off).
- [Fig. 4]: the class B push–pull paths still carry only the steered input-pair current, so the slew is again $I_{SS}/C_L$.
- [Fig. 5]: its outputs are driven by mirrors of both cross-coupled branches (M9 mirrors M7, which carries the M1 branch current $I_1$, and M11 mirrors M5, which carries the M3 branch current $I_2$; M10/M12 do the same for the other output), so each output receives the full differential current $b(I_1 - I_2)$, not half of it as in [Fig. 3]/[Fig. 4]. If the input stage's maximum differential current is taken as $I_{SS}$ and the mirrors are 1:1, each output slews at $I_{SS}/C_L$ and the differential output at $2I_{SS}/C_L$, twice [Fig. 3]/[Fig. 4]; because the class AB input has no tail-current limit, the actual slew rate is not bounded by $I_{SS}$ at all. With mirror ratio $b$ the general result is $SR_{diff} = 2b\,|I_1 - I_2|_{\max}/C_L$; the peak $|I_1 - I_2|$ depends on the input drive and is not fixed by the quiescent current.

## Grading notes

+2: $I_{SS}/C_c$ for [Fig. 1], [Fig. 2] and $I_{SS}/C_L$ for [Fig. 3], [Fig. 4] (or the single-ended halves, consistently labelled), with the reason (Miller capacitor charged by the input stage vs. input current steered into the load); for [Fig. 5] either $2I_{SS}/C_L$ differential ($I_{SS}/C_L$ per output) or $2b|I_1 - I_2|_{\max}/C_L$ with the peak current stated as undetermined, or the statement that its class AB input makes the slew rate not limited by $I_{SS}$. Calling [Fig. 5] the fastest without the $C_L$ vs. $2C_c$ caveat is not docked (its slew is not bounded by $I_{SS}$). For [Fig. 1], an answer that adds an explicitly stated assumption on the output sink current $J$ and gives the load-limited falling edge ($J/(C_c + C_L)$ or $(J - I_{SS}/2)/C_L$, or the condition $J \ge (C_c + C_L)I_{SS}/(2C_c)$) together with $I_{SS}/C_c$ when $J$ is sufficient is correct, not a $C_L$-only error; a load-limited value with an invented $J$ used as if given, without the $I_{SS}/C_c$ result, counts as [Fig. 1] wrong. [Fig. 4] is not faster than [Fig. 3]. An answer that states its own $I_{SS}$ convention explicitly (e.g., $I_{SS}$ as the current of one input leg) and applies it consistently is graded after converting to the tail-current convention; the convention itself is not an error. +1: right forms with a factor-of-2 slip between designs, or [Fig. 5] given as $I_{SS}/C_L$ differential (the book's value) with the other four right. 0: one design wrong through a critical error (e.g., [Fig. 4] claimed to be twice [Fig. 3]) with the others right, or only the two-stage or only the folded designs right. −2 (asserted as fact): slew rate of the folded cascodes set by $C_c$ (they have no compensation capacitor), or of the two-stage designs set by $C_L$ alone.
