$i_{OUT} = \dfrac{bI_5\left[\exp\!\left(\dfrac{v_{IN}}{nV_t}\right) - 1\right]}{(1 + A) - (A - 1)\exp\!\left(\dfrac{v_{IN}}{nV_t}\right)}$；当 A = 2、b = 1 时：$v_{IN}/(nV_t) = \ln(8/3) \approx 0.981$。

- 尾电流节点 KCL：$i_1 + i_2 = I_5 + A(i_2 - i_1)$。
- 令 $x = \exp[v_{IN}/(nV_t)]$，$i_2 = x\,i_1$：$i_1(1 + x) = I_5 + A\,i_1(x - 1)$，因此 $i_1 = I_5/[(1 + A) - (A - 1)x]$。
- $i_{OUT} = b(i_2 - i_1) = b\,i_1(x - 1)$ → 得到上式。
- 检验：A = 0 时为 $bI_5\tanh[v_{IN}/(2nV_t)]$（普通差分对，在 $bI_5$ 处饱和）；A = 1 时为 $(bI_5/2)(x - 1)$，呈指数增长。
- A = 2、b = 1：$(x - 1)/(3 - x) = 5$ → $6x = 16$ → $x = 8/3$ → $v_{IN}/(nV_t) = 0.981$。
- 当 A > 1 时，分母在 $x = (A+1)/(A-1)$ 处为零（A = 2 时为 3，即 $v_{IN}/nV_t$ = 1.10）：电流将无限增长；实际上，当晶体管脱离弱反型时电流就会受到限制。
