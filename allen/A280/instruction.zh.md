[图 1] 所示为一个能在 1.5 V 电源下工作的 CMOS 运放（单电源 +1.5 V 和地；参考电流 $I$ 流过二极管连接的 p 沟道管 M9，并由 p 沟道管 M10、M11、M12 和 M7 镜像；M10 将电流 $I$ 送入二极管连接的 n 沟道管 M8，后者再将其镜像到尾电流管 M5；M11 和 M12 分别向 n 沟道输入管 M1 和 M2 的漏极提供 $1.5I$；二极管连接的 M3 与 M4 构成 n 沟道电流镜，各流过 $I$；第一级输出即 M1、M4 和 M11 的漏极，它驱动 n 沟道输出管 M6，其 p 沟道负载 M7 为它提供 $10I$ 的电流；$C_c$ 接在 M6 栅极与输出端之间；负载为 10 pF）。所有器件的沟道长度均为 1 µm，且所有晶体管都应工作在饱和区。设计该运放每个晶体管的 W 值，以满足下列指标：

- 压摆率（slew rate）= ±10 V/µs
- $V_{out}(\max) = 1.25$ V，$V_{out}(\min) = 0.75$ V
- $V_{ic}(\min) = 1$ V，$V_{ic}(\max) = 2$ V
- GB = 10 MHz
- 当输出极点 = 2GB 且右半平面零点 = 10GB 时，相位裕度（phase margin）= 60°
- 镜像极点保持 ≥ 10GB（$C_{ox} = 0.5\ \mathrm{fF/\mu m^2}$）

你的设计应达到或超过这些指标。忽略衬底效应，并将各 W 值（取整到微米）、$C_c$ 的值 (pF) 和 $I$ 的值 (µA) 汇总成一个表格，表项为 $C_c$、$I$、$W_1 = W_2$、$W_3 = W_4$、$W_5 = W_8$、$W_6$、$W_7$、$W_9 = W_{10}$、$W_{11} = W_{12}$、$P_{diss}$。采用下列模型参数：$K'_N = 24\ \mu\mathrm{A/V^2}$，$K'_P = 8\ \mu\mathrm{A/V^2}$，$V_{TN} = -V_{TP} = 0.75$ V，$\lambda_N = 0.01\ \mathrm{V^{-1}}$，$\lambda_P = 0.02\ \mathrm{V^{-1}}$（饱和区：$i_D = \frac{K'W}{2L}(v_{GS} - V_T)^2$）。
