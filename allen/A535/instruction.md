A two-stage pipeline ADC is shown in [Fig. 1]. Each 2-bit ADC with reference $V_R$ compares its input with $V_R/4$, $V_R/2$ and $3V_R/4$ and outputs the number of thresholds reached (input ≥ threshold) as a 2-bit code, first bit the MSB. Each 2-bit DAC with reference $V_R$ outputs $(b_i/2 + b_{i+1}/4)V_R$ for its input bits $b_ib_{i+1}$. The summer forms $v_{in}(1) - v_{out}(1)$, which the amplifier multiplies by $A$ to give $v_{in}(2)$. The output word is $b_0b_1b_2b_3$ ($b_0$ = MSB) and the input range is $0 \le v_{in}(1) < V_{REF}$.

All four references equal $V_{REF}$ and everything is ideal except the amplifier gain, which is $A = 2$ instead of 4. Plot the output–input characteristic of this ADC and compare it with the ideal 4-bit characteristic, whose code transitions lie at $kV_{REF}/16$ ($k = 1, \dots, 15$; 1 LSB = $V_{REF}/16$). Express the INL (largest positive and negative vertical difference, in LSBs, between the actual and the ideal staircase characteristics) and the DNL (height of each vertical step of the actual characteristic minus 1 LSB) in terms of a +LSB and a −LSB value, and determine whether the converter is monotonic or not.
