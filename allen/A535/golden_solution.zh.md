+INL = 0 LSB，−INL = −2 LSB；+DNL = +2 LSB，−DNL = 0 LSB；缺失八个码（0010、0011、0110、0111、1010、1011、1110、1111）；单调。

- 第一级是理想的：子区间 $m$ 覆盖 $4m$ 到 $4m+4$ LSB。余量（residue）只有 $2[v_{in}(1) - 4m\ \mathrm{LSB}]$，最大只到 $V_{REF}/2$，因此第二级只产生 00 和 01。当余量达到 $V_{REF}/4$，即在 $4m + 2$ LSB 处，它切换到 01。
- 阶梯（每个码 2 LSB）：0–2 上为 0，2–4 上为 1，4–6 上为 4，6–8 上为 5，8–10 上为 8，10–12 上为 9，12–14 上为 12，14–16 LSB 上为 13。
- 与理想值的垂直差：在每个 2 LSB 宽的码起始处为 0，随着理想码继续增加，变为 −1，再变为 −2（例如在 3–4 LSB 上实际为 1，理想为 3）。从不为正：+INL = 0，−INL = −2 LSB。
- 台阶：0 → 1（1 LSB，DNL 0）以及 1 → 4、5 → 8、9 → 12（3 LSB，DNL = +2）。所有台阶都向上：单调。
