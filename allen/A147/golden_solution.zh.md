$|V_{OS}|_{\max} \approx 26$ mV（0.0263 V），与 $I_{SS}$ 无关。

- 假设：器件服从平方律，忽略 λ。$\beta_1 = \beta_2 = 10^{-5}$ A/V²，$\beta_3 = \beta_4 = 10^{-6}$ A/V²，它们偏离标称值的比例相同（±5 %）。相同的相对变化使 $\beta_3/\beta_1 = \beta_4/\beta_2 = 0.1$ 精确保持不变，因此不产生失调。阈值电压在 1 ± 0.01 V 范围内独立变化。$V_{OS}$ 是使两个二极管电压相等、从而使 $v_{o1}$ 与 $v_{o2}$ 相等的输入。
- 当 $v_{o1} = v_{o2}$ 时，两个负载管的 $V_{SG}$ 相同：$I_1 = \frac{\beta_3}{2}(V_{SG} - |V_{T3}|)^2$，$I_2 = \frac{\beta_4}{2}(V_{SG} - |V_{T4}|)^2$。于是 $V_{GS1} - V_{T1} = \sqrt{2I_1/\beta_1} = \sqrt{\beta_3/\beta_1}(V_{SG} - |V_{T3}|)$，M2 同理。
- $V_{OS} = V_{GS1} - V_{GS2} = (V_{T1} - V_{T2}) + \sqrt{\beta_3/\beta_1}\,(|V_{T4}| - |V_{T3}|)$。由于 $\beta_3/\beta_1 = \beta_4/\beta_2$，$V_{SG}$ 从而 $I_{SS}$ 被消去。
- 最坏情况：$V_{T1} - V_{T2} = 0.02$ V 且 $|V_{T4}| - |V_{T3}| = 0.02$ V，二者同号：$V_{OS} = 0.02 + \sqrt{0.1}(0.02) = 0.02 + 0.0063 = 0.0263$ V。
