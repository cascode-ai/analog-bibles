A DAC uses the binary-weighted current sinks shown in [Fig. 1]. Bit $b_i$ ($i$ = 0 … N−1) switches a sink of current $I/2^{i+1}$ to the output, so the output current is $I(b_0/2 + b_1/4 + \cdots + b_{N-1}/2^N)$; $b_0$ is the MSB and $b_{N-1}$ is the LSB, and 1 LSB = $I/2^N$. The INL must stay below ±0.5 LSB for N bits. Considering the influence of all current sinks (their errors can add), what is the worst-case tolerance in ±percent for each sink?
