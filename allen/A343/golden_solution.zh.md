$A_{vd} \approx (g_mr_{ds})^2$；差分输出电阻 $\approx g_mr_{ds}^2$（每个输出端为 $g_mr_{ds}^2/2$）。

- 输入级：$v_{id}$ 平均分配在 M1 的栅源之间和 M4 的源栅之间（M2 和 M3 亦然），因此 M1 和 M4 中流过 $i_1 = g_mv_{id}/2$，M2 和 M3 中流过 $i_2 = -g_mv_{id}/2$。
- 电流导引：$i_1$ 经 M7 → M9 镜像（向 $v_{o1}$ 供出电流），并经 M6 → M12 镜像（从 $v_{o2}$ 吸入电流）；$i_2$ 经 M8 → M10（向 $v_{o2}$ 供出）和 M5 → M11（从 $v_{o1}$ 吸入）。流入 $v_{o1}$ 的净电流：$i_1 - i_2 = g_mv_{id}$；流入 $v_{o2}$：$-g_mv_{id}$。
- 每侧输出电阻：共源共栅管 M13 叠在 M9 之上，M15 叠在 M11 之上：$g_mr_{ds}^2\|g_mr_{ds}^2 = g_mr_{ds}^2/2$；两个输出端之间为 $g_mr_{ds}^2$。
- $v_{o1} = g_mv_{id}\cdot g_mr_{ds}^2/2 = (g_mr_{ds})^2v_{id}/2$；$A_{vd} = (v_{o1} - v_{o2})/v_{id} = (g_mr_{ds})^2$。
- 这些是 $g_mr_{ds} \gg 1$ 时的主阶结果（低频，无体效应）。若保留低阶项，每条共源共栅支路为 $2r_{ds} + g_mr_{ds}^2$，因此 $R_{od} = r_{ds}(2 + g_mr_{ds})$；在有限的 $g_mr_{ds}$ 下，电平移位器（M17–M22）的有限增益和二极管负载会使增益略低于 $(g_mr_{ds})^2$。
