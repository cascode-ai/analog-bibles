原理：这是一个逐次逼近型 ADC，其 DAC 为带电容减法的两级电阻串。在每个时钟周期内，比较器将 $V_{Analog}$ 与 $V_{DAC} = V_1 - V_2 = (8A + 4B + 2C + D)V_{REF}/16$ 进行比较；$v_X = [V_{Analog} - V_{DAC}]/2$，当 $V_{Analog} > V_{DAC}$ 时输出为低，当 $V_{Analog} < V_{DAC}$ 时输出为高。

- 抽头：$V_1 = (2A + B + 1)V_{REF}/4$（取 $V_{REF}$、$\frac34$、$\frac12$、$\frac14V_{REF}$ 之一）；$V_2 = (4 - 2C - D)V_{REF}/16$（取 $\frac{4}{16}$、$\frac{3}{16}$、$\frac{2}{16}$、$\frac{1}{16}V_{REF}$ 之一），因此 $V_1 - V_2 = (8A + 4B + 2C + D)V_{REF}/16$。
- $\phi_1$（0 到 $T/2$）：运放处于单位增益反馈，因此 $v_X$ 处于虚地，并实现自动调零（auto-zero），即其失调存储在电容上；$V_{Analog}$ 电容的左极板接地，第二个电容（$V_T$ 节点）被充电到 $V_1$。
- $\phi_2$（$T/2$ 到 $T$）：反馈开关断开（比较器模式），第一个电容的左极板接 $V_{Analog}$，$V_T$ 节点接 $V_2$，因此 $\Delta v_X = [C V_{Analog} + C(V_2 - V_1)]/2C = [V_{Analog} - (V_1 - V_2)]/2$；比较器输出在 $\phi_2$ 结束时由 SAR 锁存。
- 第 1 个周期：SAR 置 $ABCD = 1000$（$V_{DAC} = V_{REF}/2$）；若输出为低（$V_{Analog} > V_{REF}/2$），保持 $A = 1$，否则复位为 $A = 0$。
- 第 2 个周期：置 $B = 1$（$V_{DAC} = A\cdot V_{REF}/2 + V_{REF}/4$）并确定 $B$。
- 第 3 个周期：置 $C = 1$（加上 $V_{REF}/8$）并确定 $C$。
- 第 4 个周期：置 $D = 1$（加上 $V_{REF}/16$）并确定 $D$；四个时钟周期（$4T$）之后，数字字 $ABCD$ 就存放在寄存器中（还可再用一个周期来传送结果并复位）。$V_{Analog}$ 在每个 $\phi_2$ 中都被重新采样，因此在转换期间它必须保持不变（外接采样保持电路）。

误差来源：运放/比较器的有限增益、增益带宽积、压摆率以及在 $T/2$ 内的建立，比较器的分辨率（差值在 $v_X$ 处被减半；输入端的 ½ LSB 在该处只有 $V_{REF}/64$）；失调基本被 $\phi_1$ 自动调零消除（只剩残余部分）；电阻失配（电阻串抽头，$R$ 与 $R/4$ 的比值）以及两个电容 $C$ 之间的失配（$V_{Analog}$ 与 $V_{DAC}$ 之间的增益误差）；开关导通电阻（RC 建立）以及电荷注入/时钟馈通，特别是 $\phi_1$ 反馈开关注入到 $v_X$ 上的；寄生电容（$v_X$ 处的寄生电容会衰减比较器输入，底极板寄生电容会加载抽头）；基准的精度、稳定性以及电阻串的负载效应；噪声（$kT/C$、比较器噪声）；以及没有采样保持时输入的变化。
