$\dfrac{V_3(s)}{V_{in}(s)} = -\dfrac{g_{m1}}{2}\,\dfrac{sC_2 + g_{m5} + g_{m6}}{(sC_1 + g_{ds1} + g_{ds5})(sC_2 + g_{m6})} \;\to\; -\dfrac{g_{m1}}{g_{ds1} + g_{ds5}}$（$s \to 0$ 时，$g_{m5} = g_{m6}$）。

数值：低频增益 ≈ −73.7 V/V。极点 $p_1 = -4.5\times10^6$ rad/s（716 kHz）和 $p_2 = -g_{m6}/C_2 = -2.24\times10^8$ rad/s（35.6 MHz）。左半平面零点（LHP zero）$z_1 = -(g_{m5}+g_{m6})/C_2 = -4.47\times10^8$ rad/s（71.2 MHz）。$C_3$ 和 $C_4$ 不出现在 $V_3/V_{in}$ 中。

- M1–M4 各流过 $I/4 = 50\ \mu$A。M1 和 M2 的栅极接 $V_1$，M3 和 M4 的栅极接 $V_2$。M1 驱动 $V_3$（负载 M5）。M3 驱动 M6 的二极管节点 X，M5 将其镜像到 $V_3$。M2 驱动二极管 M7，M4 驱动 $V_4$（负载 M8）。对称差模输入时，公共源极节点为交流地。
- 节点 X：M3 的漏极电流为 $-g_{m3}V_{in}/2$（栅极为 $-V_{in}/2$）。从二极管节点抽取该电流得 $V_X = +g_{m3}(V_{in}/2)/(g_{m6} + sC_2)$。于是 M5 向节点 3 提供 $-g_{m5}V_X$，而 M1 从该节点抽取 $g_{m1}V_{in}/2$。
- 节点 $V_3$：$(sC_1 + g_{ds1} + g_{ds5})V_3 = -g_{m1}V_{in}/2 - \dfrac{g_{m5}g_{m3}V_{in}/2}{g_{m6} + sC_2}$，由此得结果。若在节点 X 计入 $g_{ds3} + g_{ds6}$（$G_X = g_{m6} + g_{ds3} + g_{ds6}$），数值略有变化：直流增益 −73.0，$p_2 = -2.28\times10^8$ rad/s，$z_1 = -4.52\times10^8$ rad/s。
- 参数：$g_{m1} = \sqrt{2 \cdot 110\ \mu \cdot 10 \cdot 50\ \mu} = 331.7\ \mu$S，$g_{m5} = g_{m6} = \sqrt{2 \cdot 50\ \mu \cdot 10 \cdot 50\ \mu} = 223.6\ \mu$S，$g_{ds1} + g_{ds5} = (0.04 + 0.05) \cdot 50\ \mu = 4.5\ \mu$S。增益 $= -331.7/4.5 = -73.7$。
