# 详细步骤 - A046

把每根单位电阻条描述为标称电阻加上实际版图中的各种误差（线性梯度、阵列边缘误差、方向及接触效应），逐一确定各版图中哪些电阻条构成 $R$ 和 $2R$，再计算比值。最佳版图应使每种误差对 $R$ 和 $2R$ 的影响比例相同。

### 第 1 步 — 单位电阻条比值的误差模型

两个电阻都由电阻为 $r$ 的相同单位电阻条构成，标称比值 $2R/R=2r/r=2$。实际第 $i$ 根电阻条存在偏差：

$$
r_i=r\,(1+g\,x_i+\varepsilon_i),
$$

其中 $g$ 为整个版图上的线性梯度（方块电阻、宽度），$x_i$ 为电阻条的位置，$\varepsilon_i$ 为取决于周边环境的误差：一侧没有相邻图形的最外侧电阻条，其刻蚀情况与内部电阻条不同。电阻条方向不同（刻蚀、光刻和应力都与方向有关），或接触与互连电阻不随单元数成比例变化时，还会产生其他误差。只有当 $R$ 与 $2R$ 质心相同（抵消 $g$）、周边环境相同（抵消 $\varepsilon$）、方向相同，且串联接触电阻也满足 2:1 比例时，比值才是准确的。

### 第 2 步 — 梯度：顺序排列与共质心排列

对位于 $x=-1,0,+1$ 的三根竖直电阻条，暂不考虑边缘误差：

$$
\begin{aligned}
\text{(b), (c): } R=r_{-1},\ 2R=r_0+r_{+1}&\ \Rightarrow\ \frac{2R}{R}=\frac{2+g}{1-g}\approx2+3g,\\
\text{(d), (e): } R=r_0,\ 2R=r_{-1}+r_{+1}&\ \Rightarrow\ \frac{2R}{R}=\frac{2r}{r}=2 .
\end{aligned}
$$

把 $R$ 放在中间、夹在 $2R$ 的两半之间，两个电阻便具有共同质心，线性梯度被完全抵消。(b) 和 (c) 为顺序排列（$R$ 在 A 端，其后是两根 $2R$ 电阻条），比值误差是 $g$ 的一阶量。

### 第 3 步 — 边缘误差：虚拟电阻条的作用

设最外侧的有源电阻条（一侧无相邻图形）为 $r(1+\varepsilon)$，内部电阻条为 $r$：

$$
\begin{aligned}
\text{(d): } \frac{2R}{R}&=\frac{2r(1+\varepsilon)}{r}=2(1+\varepsilon),\\
\text{(b): } \frac{2R}{R}&=\frac{r+r(1+\varepsilon)}{r(1+\varepsilon)}=\frac{2+\varepsilon}{1+\varepsilon}\approx2-\varepsilon .
\end{aligned}
$$

(d) 中两根外侧电阻条都属于 $2R$，其边缘误差约为 (b) 的两倍。(c) 和 (e) 在两端增加了虚拟电阻条，每根有源电阻条的相邻图形相同，所有 $\varepsilon_i$ 相等，边缘误差被抵消。因此 (d) 抵消了梯度但未抵消边缘误差，(b) 两者都未抵消；(d) 是否优于 (b) 或 (c)，取决于哪种误差占主导。

### 第 4 步 — 版图 (a) 与 (f)

**(a)** 六个单元串联：$R$ 为内侧两根竖直电阻条，$2R$ 为外侧两根竖直电阻条加上顶部和底部两根水平电阻条。该布局大致为共质心，接触孔数也满足 2:1（$2R$ 一侧 8 个，$R$ 一侧 4 个）。但 $2R$ 同时包含水平和竖直电阻条，而 $R$ 全为竖直，因此不具有方向不变性；内、外侧电阻条周边环境不同；没有虚拟电阻条；而且又长又不等长的金属走线引入了不成比例的串联电阻。

**(f)** 宽度为 $W$、方块电阻（sheet resistance）为 $R_\square$ 的单根电阻条，抽头距 B 端 $2x$、距 A 端 $x$。理想电阻条给出精确的 2:1，但每一段还包含一个电阻为 $R_c$ 的端部接触（及其接触到电阻条的过渡区）：

$$
\frac{R_{B\text{-}tap}}{R_{tap\text{-}A}}=\frac{2xR_\square/W+R_c}{xR_\square/W+R_c}<2 .
$$

$R_c$ 不随长度成比例变化；抽头接触本身扰动电流分布，使有效抽头位置不确定；两段的质心不同，沿电阻条的梯度会直接改变比值。

### 第 5 步 — 结论

| 版图 | 单元匹配 | 共质心 | 方向相同 | 虚拟条 | 主要缺陷 |
|---|---|---|---|---|---|
| (a) | 是 | 大致 | 否 | 否 | 方向混合，周边环境与走线不等 |
| (b) | 是 | 否 | 是 | 否 | 梯度误差 $\approx3g$，边缘误差 $\approx-\varepsilon$ |
| (c) | 是 | 否 | 是 | 是 | 顺序排列；狗骨形窄电阻体增大宽度敏感性 |
| (d) | 是 | 是 | 是 | 否 | 外侧电阻条（$2R$）边缘环境不同：误差 $\approx2\varepsilon$ |
| (e) | 是 | 是 | 是 | 是 | 无上述缺陷 |
| (f) | 否 | 否 | — | 否 | 端部接触不成比例，沿电阻条存在梯度 |

对于理想的相同材料，六种版图的标称比值都是 2:1，区别在于工艺误差如何进入。版图 **(e)** 最佳：三根相同的单位电阻条，$R$（与 A 相连的电阻条）居中，$2R$ 由外侧两根电阻条串联而成，因此单元匹配、共质心（梯度抵消）、方向一致，且两端有虚拟电阻条，使每根有源电阻条的周边环境相同（边缘误差抵消）。
