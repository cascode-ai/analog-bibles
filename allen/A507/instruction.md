A pipeline algorithmic ADC is shown in [Fig. 1], with $V_{REF}$ = 5 V. Each stage compares its input $V_{i-1}$ with zero: the stage bit is 1 ($b_{i-1} = +1$) if $V_{i-1} > 0$ and 0 ($b_{i-1} = -1$) otherwise, and the stage output $V_i = 2V_{i-1} - b_{i-1}V_{REF}$ drives the next stage. The first stage's input is the sampled input, and the stage bits form the output word MSB first. If the sampled analog input is $0.8V_{REF}$ (4 V), find the digital output word to 6 bits.
