输入极点 ≈ $-2.9\times10^9$ rad/s（≈ −460 MHz）；输出极点 ≈ $-(1+A_o)/(R_2C_o)$ ≈ $-30\times10^6$ rad/s（≈ 4.7 MHz）。输入极点约比输出极点高 100 倍（仍比预期的 50 MHz 高约 9 倍），因此输出极点仍是主极点；但它并不高于预期的 500 MHz GB，因而会限制可达到的 GB。

- 电流放大器的输入电阻：$g_{m1} = \sqrt{2(110\ \mu)(200)(1\ \mathrm{m})} = 6.63$ mS；$r_i = R_3 + 1/g_{m1} = 300 + 151 = 451\ \Omega$（M3 不起作用：其栅极就在输入节点上）。$R_1$ 接到（接地的）输入源，$R_2$ 在该频率下接到低阻抗的输出端：$R_N = 451\|3200\|352\mathrm{k} \approx 395\ \Omega$。
- 该节点的电容：$C_{gs3} = 220\mathrm{p}(200\mu) + 0.67(24.7\times10^{-4})(200\times10^{-12}) = 44 + 331 = 375$ fF；$C_{gs4} = 4.4 + 33.1 = 37.5$ fF；$C_{gd3} = 44$ fF；$C_{gd4} = 4.4$ fF；M5 漏极：$C_{gd5} = 44$ fF，$C_{bd5} = 560\mu(400\times10^{-12}) + 350\mathrm{p}(404\mu) = 224 + 141 = 365$ fF。总电容 $C_N \approx 870$ fF。
- $|p_{in}| = 1/(R_NC_N) = 1/(395\times870\ \mathrm{fF}) = 2.91\times10^9$ rad/s（463 MHz）；若只用 $r_i$，则为 2.55×10⁹ rad/s（406 MHz）。
- 输出极点：$1/(R_2C_o) = 1/(352\ \mathrm{k}\times105\ \mathrm{fF}) = 27\times10^6$ rad/s；在闭环放大器中变为 $(1+A_o)/(R_2C_o) = 29.8\times10^6$ rad/s（4.7 MHz）。
