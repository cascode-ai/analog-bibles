缩放因子必须满足 $x = 1/8 \pm 1/112$，即容差为 $\pm 7.14$%（$\pm 1/14$）。若用分压比 $1/x$ 表示，则为 7.47 至 8.62（相对于 8 为 −6.7%、+7.7%）。

推导：
- 只有 LSB 子 DAC 的输出受影响：误差 $= \Delta x\left(\frac{b_3}{2} + \frac{b_4}{4} + \frac{b_5}{8}\right)V_{REF}$。
- 最坏情况 $b_3 = b_4 = b_5 = 1$：$|\Delta x|\cdot\frac{7}{8}V_{REF} \le \frac{1}{2}\cdot\frac{V_{REF}}{64} = \frac{V_{REF}}{128}$ → $|\Delta x| \le \frac{1}{112}$。
- 相对容差：$\frac{1/112}{1/8} = \frac{1}{14} = 7.14$%；$x$ 的范围为 $13/112$ 至 $15/112$。这比单个位的值 $\pm 100\%/2^K = \pm 12.5$% 更严格，因为 LSB 子 DAC 的所有位同时受到影响。
