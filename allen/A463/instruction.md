A 6-bit DAC is formed as shown in [Fig. 1] with $M = 3$ and $K = 3$: an ideal 3-bit MSB subDAC converts $b_0 b_1 b_2$ ($b_0$ is the MSB) and an ideal 3-bit LSB subDAC converts $b_3 b_4 b_5$, both with reference $V_{REF}$; the output of the LSB subDAC passes through the divider, i.e. it is multiplied by the scaling factor $x$, whose ideal value is $x = 1/2^M = 1/8$, and is added to the MSB subDAC output. Find the worst-case tolerance ($\pm$%) of the divider (the scaling factor $x$) that will not cause a conversion error, i.e. that keeps the output within $\pm\frac{1}{2}$ LSB of its ideal value for every input code (1 LSB $= V_{REF}/64$). Assume that the subDACs are ideal in all respects except for the divider.
