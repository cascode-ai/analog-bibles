$R_{out} \approx 0.30$ kΩ（≈ 297 Ω）；$f_{-3\,dB} \approx 10.7$ MHz；接 1 kΩ 负载时 $v_{OUT}$ 被限制在约 ±1 V；$P_{diss} = 3.9$ mW。

- 静态电流：M1 = M2 = 50 µA；M3、M4 = 50 µA；M8（= M3）= 50 µA → M9 = 50 µA → M7（100/1 对 10/1）= 500 µA；M6（100/1 对 M4 的 10/1）= 500 µA。
- 开环：$R_o = 1/(g_{ds6} + g_{ds7}) = 1/[(0.05 + 0.04)(500\ \mu)] = 22.2$ kΩ。
- 环路：$v_{out}$ 驱动 M2；$i_2 = g_{m2}v/2$ 经 M3 → M8 → M9 → M7（×10 吸收电流），$i_1 = -g_{m1}v/2$ 经 M4 → M6（×10 减少提供的电流）。$g_{m1} = \sqrt{2(110\ \mu)(10)(50\ \mu)} = 331.7\ \mu$S；$|LG| = \tfrac12 g_{m1}(10 + 10)R_o = 10\,g_{m1}R_o = 73.7$。
- $R_{out} = R_o/(1 + LG) = 22.2\ \mathrm{k}/74.7 = 297\ \Omega$；$f_{-3\,dB} = 1/(2\pi\cdot 297\cdot 50\ \mathrm{pF}) = 10.7$ MHz。
- 接 1 kΩ 负载时的输出摆幅：当 M1 吸收全部 100 µA 时提供的电流最大：M6 = 10 × 100 µA = 1 mA（M7 截止），因此 $v_{OUT}(\max) = 1\ \mathrm{mA}\times 1\ \mathrm{k\Omega} = +1$ V；对称地，M7 最多吸收 1 mA，$v_{OUT}(\min) = -1$ V（M6/M7 的电压余度约 0.63 V，不是限制因素）。
- $P_{diss} = (V_{DD} - V_{SS})(I_5 + I_8 + I_6) = 6\ \mathrm{V}\times(100 + 50 + 500)\ \mu\mathrm{A} = 3.9$ mW。
- 以上数值采用标准的手算模型：理想的 100 µA 尾电流，电流镜比例只由 W/L 决定（λ 只用于小信号 $r_o$），并把 50 pF 输出极点作为唯一极点。若在直流偏置中也计入沟道长度调制（$I_D \propto 1+\lambda|V_{DS}|$，$v_{IN} = 0$），电流镜两侧 $V_{DS}$ 不等，使 $I_6 = I_7$ 增大到 ≈ 587 µA；此时 level-1 仿真给出 $R_{out} \approx 246\ \Omega$，$f_{-3\,dB} \approx 13.0$ MHz，输出限值 ≈ +1.03 V / −1.20 V，$P_{diss} \approx 4.45$ mW。
