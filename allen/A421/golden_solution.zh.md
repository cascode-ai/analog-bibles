噪声 ≤ 约 21.6–30.5 µV rms，取决于峰值/均方根值的约定（按教材的约定为 21.6 µV，按 rms ≤ 0.5 LSB 为 30.5 µV）；温度系数（temperature coefficient）≤ 0.305 ppm/°C。

- LSB = 1 V/2^14 = 61.0 µV；由参考电压引起的误差必须保持在 ±0.5 LSB = ±30.5 µV 以内（输出与 $V_{REF}$ 成正比，因此满量程输出承受全部参考误差）。
- 噪声：最直接的判据是 rms 噪声 ≤ 0.5 LSB，给出 $V_{n,rms}$ ≤ 30.5 µV。教材则把 ±0.5 LSB 当作噪声峰值，并取峰值 = √2 × rms（类正弦噪声）：$V_{n,rms}$ ≤ 30.5 µV/√2 = 21.6 µV。（更严格的判据给出同一数量级的结果：噪声低于量化噪声 LSB/√12 → 17.6 µV；高斯噪声的 ≈3σ 峰值不超过 0.5 LSB → ≈10 µV。）
- 温度系数：在 100 °C 范围内的漂移必须小于 0.5 LSB：ΔV/V ≤ 30.5 µV/1 V = 30.5 ppm（在 100 °C 范围内）→ TC ≤ 0.305 ppm/°C。
