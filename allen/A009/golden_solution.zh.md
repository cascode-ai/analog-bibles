$\dfrac{v_{out}}{v_{in}} = -\dfrac{r_mR_3}{R_1R_2 + R_1R_3 + R_1r_m + R_2R_3}$。

- 设 $v_1$ 为连接 $R_1$、$R_2$ 和 $R_3$ 的节点的电压。由于 $i_a = v_1/R_2$ 且 $v_{out} = -r_mi_a$（理想电源），$K = v_{out}/v_1 = -r_m/R_2$ 精确成立。
- 密勒简化：跨接电阻 $R_3$ 用从 $v_1$ 到地的 $R_3/(1 - K) = R_2R_3/(R_2 + r_m)$ 代替；输出侧的元件 $R_3K/(K - 1) = r_mR_3/(R_2 + r_m)$ 并接在理想电压源两端，不起作用。
- 分压：$R_2 \parallel \dfrac{R_2R_3}{R_2 + r_m} = \dfrac{R_2R_3}{R_2 + R_3 + r_m}$，因此 $\dfrac{v_1}{v_{in}} = \dfrac{R_2R_3}{R_1(R_2 + R_3 + r_m) + R_2R_3}$。
- $v_{out}/v_{in} = K\,v_1/v_{in} = -r_mR_3/(R_1R_2 + R_1R_3 + R_1r_m + R_2R_3)$。由于 $K$ 是精确的（输出由理想电源决定），密勒简化的结果也是精确的；网孔分析或节点分析给出同样的表达式。
