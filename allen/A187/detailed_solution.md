# Detailed solution - A187

For a differential input the common source node of M1–M2 is an ac ground, so the right half of the circuit is a cascode common-source stage: M2 drives the output through the cascode M4, and the load is the p-channel cascode current source M6 over M8. The output is single-ended and the load is not a mirror, so only M2's half of the differential current reaches it. The gain is that current times the output resistance.

### Step 1 — Signal current reaching the output

With $v_1=+v_{in}/2$ and $v_2=-v_{in}/2$ on the gates of M1 and M2, symmetry keeps the common source node fixed, so

$$
v_{gs2}=-\frac{v_{in}}2,\qquad i_{d2}=g_{m2}v_{gs2}=-\frac{g_{m2}v_{in}}2
$$

(drain current flowing into M2's drain). The gates of M3–M4 sit at a fixed $V_{BIAS}$ above that same node, so they are also at ac ground, and M4 passes $i_{d2}$ to the output unchanged. M7–M8 are plain current sources biased from the fixed M11–M12 line, so the current change in the left half (M1, M3, M5, M7) has no path to the output.

### Step 2 — Output resistance

Looking down from the output, M4 is a common-gate device degenerated by $r_{ds2}$; looking up, M6 is degenerated by $r_{ds8}$. For $g_mr_{ds}\gg1$:

$$
R_{out}=\left[g_{m4}r_{ds4}r_{ds2}\right]\parallel\left[g_{m6}r_{ds6}r_{ds8}\right].
$$

### Step 3 — Voltage gain

A current $-i_{d2}=+g_{m2}v_{in}/2$ is pushed into the output node, so

$$
\frac{v_{out}}{v_{in}}=\frac{g_{m2}}2R_{out}
=\frac{0.5\,g_{m1}}{\dfrac{g_{ds2}g_{ds4}}{g_{m4}}+\dfrac{g_{ds6}g_{ds8}}{g_{m6}}},
$$

using $g_{m1}=g_{m2}$. The gain is positive: raising $v_1$ relative to $v_2$ lowers M2's current, so the load current charges the output upward. It is of order $(g_mr_{ds})^2$, but only half of what the same stage would give with a current-mirror load, because only one side's current reaches the single-ended output.
