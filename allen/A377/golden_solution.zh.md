有用的数值：15 µA 下的 $V_{SD4}(\mathrm{sat})$ = $\sqrt{2\cdot15/(50\cdot4.5)} = 0.37$ V；$I_{SS}/2$ 下 M1/M2 的 $V_{GS}$ = $0.7+\sqrt{30/330} = 1.00$ V，$V_{DS2}(\mathrm{sat}) = 0.30$ V；由线性区 M6 与饱和 M7 的电流平衡得到的输出高电平 $V_{OH} = V_{DD}-(V_{DD}-v_{o1}-|V_{TP}|)\left[1-\sqrt{1-2I_7/[\beta_6(V_{DD}-v_{o1}-|V_{TP}|)^2]}\right]$，$\beta_6 = 1900\ \mu\mathrm{A/V^2}$。

| 条件 | $v_{o1}$ | $v_{out}$ |
|---|---|---|
| (1) $v_{G1} > V_{G2}$ | $V_{DD}-V_{SD4}(\mathrm{sat}) < v_{o1} < V_{DD}$：≈ 2.13–2.5 V | $V_{SS} = -2.5$ V（M6 截止） |
| (2) $v_{G1} \gg V_{G2}$ | ≈ $V_{DD}$ = 2.5 V | −2.5 V |
| (3) $v_{G1} < V_{G2}$ | $V_{S2} < v_{o1} < V_{S2}+V_{DS2}(\mathrm{sat})$，$V_{S2} = v_{G1}-V_{GS1}(I_{SS}/2)$：≈ −1.0 至 −0.7 V | 高，≈ 2.45 V |
| (4) $v_{G1} \ll V_{G2}$ | → $V_{SS}$ ≈ −2.5 V | 高，≈ 2.47 V |
| (5) $v_{G2} > V_{G1}$ | $V_{S2}(I_{SS}/2) < v_{o1} < V_{S2}(I_{SS}/2)+V_{DS2}(\mathrm{sat})$：≈ −1.0 至 −0.7 V | ≈ 2.45 V |
| (6) $v_{G2} \gg V_{G1}$ | ≈ −1.0 V（略高于 $V_S$） | ≈ 2.46 V |
| (7) $v_{G2} < V_{G1}$ | ≈ 2.13–2.5 V | −2.5 V |
| (8) $v_{G2} \ll V_{G1}$ | ≈ 2.5 V | −2.5 V |

推理：
- 当 M1 的电流大于 M2 时，电流镜（M3–M4）注入 $v_{o1}$ 节点的电流大于 M2 吸收的电流，因此 $v_{o1}$ 上升，直到 M4 退出饱和、$i_4 = i_2$（若 $i_2 = 0$ 则升至 $V_{DD}$）。此时 $V_{SG6} < 0.37$ V < $|V_{TP}|$，M6 截止，M7 将 $v_{out}$ 拉到 $V_{SS}$。
- 当 M2 的电流较大时，$v_{o1}$ 下降，直到 M2 进入线性区。在直流稳态下，$v_{o1}$ 处的 KCL 迫使 $i_2 = i_4 = i_1$，即 $i_1 = i_2 = I_{SS}/2$；共源节点位于较低的栅极电压减去 $V_{GS}(15\ \mu\mathrm{A}) = 1.0$ V 处，因此当较低的栅极电压接近 0 V 时 $v_{o1} \approx -1.0$ V（至 −0.7 V）。此时 M6 强导通（线性区），$v_{out} \approx 2.45$–2.46 V。
- (6)：由于 $V_{G1} = 0$ 固定，无论 $v_{G2}$ 升得多高，M1 都把源极节点钳在 ≈ −1.0 V（M5 保持饱和），因此 $v_{o1}$ 保持在 ≈ −1.0 V；$i_1 = 0$、$i_2 = I_{SS}$ 只在瞬态中成立。
- (4)：M1 截止（$i_1 = 0$）时，没有电流经 M4 流入该节点，因此 $C_I$ 通过 M2 和 M5 放电，直到 M5 退出饱和：$v_{o1} \to V_{SS}$，$v_{out} = V_{DD}-4.3[1-\sqrt{1-468/(1900\cdot18.49)}] \approx 2.47$ V。
