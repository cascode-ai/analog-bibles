# Golden Solution - A202

## Reference answer

$R_{out} = r_{ds2}\|r_{ds3} = \dfrac{r_{ds2}r_{ds3}}{r_{ds2}+r_{ds3}}$.

- With the input node held at ac ground by the voltage source, M2 has gate and source at ac ground, so looking into its drain gives just $r_{ds2}$; M3 contributes $r_{ds3}$ in parallel.
- (If instead the input were driven by a current source, M2 would be degenerated by $r_{ds1}$ and $R_{out} = r_{ds3}\|[r_{ds1}+r_{ds2}+g_{m2}r_{ds2}r_{ds1}] \approx r_{ds3}$.)

## Grading notes

+2: $r_{ds2}r_{ds3}/(r_{ds2}+r_{ds3})$. +1: the current-driven result given instead with a clear statement of that assumption. 0: correct reasoning with a slip. −2 (asserted as fact): $R_{out} = g_{m2}r_{ds2}r_{ds1}$-type cascode value under the stated voltage drive, or $R_{out} = 1/g_{m2}$.
