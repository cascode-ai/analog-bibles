INL = +3 LSB 和 −3 LSB；DNL = +2 LSB 和 −3 LSB。

以 $V_{REF}/16$ 为输入单位读图；理想码在 $V_{REF}/8$ 的每个整数倍处加一：
- 实际码：000（0–1），001（1–2），100（2–5），010（5–7），101（7–10），011（10–13），110（13–14），111（14–16）。
- 十六个区间上实际值减理想值：0, +1, +3, +3, +2, 0, −1, +2, +1, +1, −2, −2, −3, 0, 0, 0 → INL 从 +3 LSB（在 2/16–4/16 处，理想码为 001 而实际为 100）到 −3 LSB（在 12/16–13/16 处，理想码为 110 而实际为 011）。
- 竖直台阶：1/16 处 +1（DNL 0），2/16 处 +3（+2），5/16 处 −2（−3），7/16 处 +3（+2），10/16 处 −2（−3），13/16 处 +3（+2），14/16 处 +1（0）→ DNL 从 +2 LSB 到 −3 LSB（该转换器也是非单调的）。
