$V_{REF} = V_T$（M1 的阈值电压），与 $I$ 和电源电压都无关。

- 令 $V_{ON} = \sqrt{2I/(4K')}$ 为 $W/L = 4$ 的器件在电流 $I$ 下的过驱动电压。M1 和 M3 流过 $I$：$V_{GS1} = V_{GS3} = V_T + V_{ON}$，因此 M3 和 M4 的栅极电压为 $2V_T + 2V_{ON}$。
- M2 与 M1 的栅极电压和尺寸相同，因此（饱和时）流过 $I$；M4 与其串联，也流过 $I$，但由于 $W/L = 1$，其过驱动电压为 $\sqrt{2I/K'} = 2V_{ON}$，因此 $V_{GS4} = V_T + 2V_{ON}$。
- $V_{REF} = V_{G4} - V_{GS4} = 2V_T + 2V_{ON} - V_T - 2V_{ON} = V_T$。
- 适用条件：M2 饱和要求 $V_{DS2} = V_T \ge V_{ON}$，即 $I \le 2K'V_T^2$（$K'$ = 110 µA/V²、$V_T$ = 0.7 V 时 ≈ 108 µA）。计入体效应时，$V_{REF} = V_{T1} + V_{T3} - V_{T4}$，略高于 $V_T$。
