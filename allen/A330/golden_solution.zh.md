| 运放 | $V_{ic}(\max)$ | $V_{ic}(\min)$ |
|---|---|---|
| [图 1] | $V_{DD} - V_{ON}$ | $V_{SS} + 2V_{ON} + V_T$ |
| [图 2] | $V_{DD} - V_{ON}$ | $V_{SS} + 2V_{ON} + V_T$ |
| [图 3] | $V_{DD} - V_{ON} + V_T$ | $V_{SS} + 2V_{ON} + V_T$ |
| [图 4] | $V_{DD} - V_{ON} + V_T$ | $V_{SS} + 2V_{ON} + V_T$ |
| [图 5] | $V_{DD} - V_{ON}$ | $V_{SS} + 3V_{ON} + 2V_T$ |

- [图 1]、[图 2]：输入管的漏极位于由 p 沟道第二级器件决定的 $V_{DD} - V_{SG}$ 处（$V_{DD} - V_T - V_{ON}$）；保持 M1 饱和（$V_D \ge V_G - V_T$）得 $V_{DD} - V_{ON}$。最小值：尾电流管 $V_{DS5}(\mathrm{sat}) + V_{GS1} = V_{ON} + (V_T + V_{ON})$。
- [图 3]、[图 4]（折叠式）：输入管漏极位于折叠节点，$V_{DD} - V_{SD}(\mathrm{sat}) = V_{DD} - V_{ON}$，因此 $V_{ic}(\max) = V_{DD} - V_{ON} + V_T$（可接近甚至超过 $V_{DD}$）；最小值同上。这是可达到的最大值：一般情况下折叠节点位于 $V_{PB2} + V_T + V_{ON}$，得 $V_{ic}(\max) = V_{PB2} + 2V_T + V_{ON}$，当采用高摆幅偏置 $V_{PB2} = V_{DD} - V_T - 2V_{ON}$ 时（折叠节点处于 M4/M5 饱和的边缘）即等于表中的值；不那么激进的 $V_{PB2}$ 会使它降低。
- [图 5]：M1 的漏极位于 $V_{DD} - V_{SG7}$（二极管 M7），得 $V_{DD} - V_{ON}$。最小值：$V_{SS} + V_{GS6} + V_{SD4}(\mathrm{sat}) + V_{GS1} = V_{SS} + (V_T + V_{ON}) + V_{ON} + (V_T + V_{ON})$，是五种中范围最窄的。
