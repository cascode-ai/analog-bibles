$+INL = +0.75$ LSB，$-INL = -3$ LSB；$+DNL = +0.25$ LSB，$-DNL = -1.75$ LSB；该 DAC 不单调（输出在 0011→0100、0111→1000 和 1011→1100 处下降 0.75 LSB）。

推导（码 $= 4m + n$，$m = 2b_0 + b_1$，$n = 2b_2 + b_3$，均取 0…3；数值以 LSB $= V_{REF}/16$ 为单位）：
- 实际输出 $= 0.75(4m) + 1.25n = 3m + 1.25n$；理想值 $= 4m + n$。
- 误差 $= -m + 0.25n$：最大为 $+0.75$（$m = 0$，$n = 3$，码 0011），最小为 $-3$（$m = 3$，$n = 0$，码 1100）。
- 台阶：组内为 1.25 LSB → DNL = +0.25；在组间跳变处（$n$：3 → 0，$m$ → $m+1$）台阶为 $3 - 3.75 = -0.75$ LSB → DNL = −1.75。负台阶说明该 DAC 不单调。
