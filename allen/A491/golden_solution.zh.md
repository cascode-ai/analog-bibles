$-0.349 \le \Delta A \le +0.163$（增益 $A$ 约为 0.151 至 0.663）；若取对称容差，则 $|\Delta A| \le 0.16$。

推导：
- 各位按 LSB 在先依次为：+1, −1, −1, +1, +1。增益为 $A$ 时：$v_1 = 1$，$v_2 = -1 + A$，$v_3 = -1 + Av_2$，$v_4 = 1 + Av_3$，$v_5 = 1 + Av_4$，因此 $v_{OUT}/V_{REF} = f(A) = 1 + A - A^2 - A^3 + A^4$（$f(0.5) = 19/16$）。
- 该 5 位转换器的输出电平为 $\sum \pm 2^{-i}V_{REF}$，间隔为 $2\cdot2^{-4}V_{REF} = V_{REF}/8$；±½ LSB = ±$V_{REF}/16$，因此 $1.125 \le f(A) \le 1.25$。
- $f$ 在 $A \approx 0.39$ 处有最大值 1.202，因此上限永远达不到；$f(A) = 1.125$ 出现在 $A = 0.151$ 和 $A = 0.663$。因此 $0.151 \le A \le 0.663$，即 $\Delta A$ 的范围为 −0.349 至 +0.163。
