[Fig. 1] shows the parallel form of a temperature-independent voltage reference: a pseudo-PTAT current $I_{PTAT}' = V_{PTAT}/R_1$ and a pseudo-CTAT current $I_{CTAT}' = V_{CTAT}/R_2$ are summed in $R_3$, so $V_{REF} = (R_3/R_1)V_{PTAT} + (R_3/R_2)V_{CTAT}$. Assume $V_{PTAT} = V_t\ln(A_2/A_1)$ with $A_2/A_1$ = 10, and $V_{CTAT}$ = 0.6 V at room temperature; $R_1$, $R_2$ and $R_3$ have the same temperature dependence. Find the values of $R_1$, $R_2$ and $R_3$ that give a temperature-independent value of the reference voltage at room temperature equal to 1 V, where $V_{t0}$ = 0.026 V, if $R_1$ = 1 kΩ. Use the CTAT model $V_{CTAT}(T) = V_{G0} - \frac{T}{T_0}\left[V_{G0} - V_{CTAT}(T_0)\right] - (\gamma - \alpha)\frac{kT}{q}\ln\frac{T}{T_0}$ with $V_{G0}$ = 1.205 V and $\gamma - \alpha$ = 2.2.
